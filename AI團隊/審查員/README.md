# 審查員

2026-10-09 作者提議建立。同一份稿換個角度看，結論差很多：Canon 無衝突的稿，只讀故事的讀者可能想跳過；結構完整的稿，偵探可能一眼看出某人不該知道那件事。這裡放七種**審查角度**，派工時依稿件挑選，不是七個常駐 Agent。

先讀[獨立讀者Reviewer](../獨立讀者Reviewer.md)（審查統籌入口）與[共用創作準則](../修仙故事創作準則.md)。

| 角度 | 只負責看什麼 | 什麼時候派 |
|---|---|---|
| [一般讀者](一般讀者.md) | 想不想翻下一頁、哪句開始想跳、看不看得懂；不看設定 | 每份大綱 |
| [修仙愛好者](修仙愛好者.md) | 仙感、修行與境界的爽點和代價、奇觀可不可替換、像不像換皮武俠 | 有修行、戰鬥、秘境 |
| [主角視角](主角視角.md) | 主角的選擇像不像他、是推動者還是工具人、前後是不是同一個人 | 主角主導的篇 |
| [強敵與配角視角](強敵與配角視角.md) | 站到對手和配角那邊：輸得合不合理、有沒有主動反制、天驕是不是陪跑 | 有主要對手或群像 |
| [PM 結構與節奏](PM結構與節奏.md) | 中段牽引、篇幅過載、跨篇伏筆埋收、與總覽和年表對齊 | 篇章大綱、整卷整合 |
| [偵探與邏輯](偵探與邏輯.md) | 因果、動機、誰何時知道什麼、線索公平、「為何不直接⋯⋯」、時間地點排不排得通 | 有陰謀、揭露、推理 |
| [Canon 核對](../Canon核對員.md) | 既有設定、境界、時間、交通、揭露鎖 | 定稿前 |

## 用法

1. **挑二到三位**，不全派。例：秘境篇派一般讀者、修仙愛好者、強敵視角；陰謀篇派一般讀者、偵探、Canon。
2. **讀者類先審，Canon 最後**：先問好不好看，再問說不說得通，最後才查設定（作者 10-09「故事優先於規格」）。
3. 每位審查員**未參與本輪構思**，各寫自己的審查，不互讀；評語放 `待整理/` 的工作資料夾，不寫進正式主稿。
4. 由[主編統籌](../主編統籌.md)彙整成**一張取捨表**交作者：哪些意見互相衝突、建議採哪個、為什麼。不讓作者自己比對多份審查。
5. 通過只代表本輪審查，不代表作者批准、候選升格 Canon 或正文解凍（[正文凍結](../../待整理/設定/00_故事定位/大綱完成前正文凍結.md)）。
