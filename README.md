# 《劫》新故事設計工作區

目前階段：先設計歷史背景、世界、人物及故事結構，再進入正文。

本案以重新建立背景為前提。舊版人物、關係或素材是否沿用，逐項選擇；舊版設定不自動成為新版必須遵守的前提。

## 從哪裡開始

| 文件 | 用途 |
|---|---|
| [故事定位](設定/00_故事定位.md) | 確認保留什麼、重建什麼，以及故事要寫什麼 |
| [世界格局](設定/01_世界格局.md) | 仙界、異域、九界、王庭、交通與各地生活 |
| [歷史背景](設定/02_歷史背景.md) | 上古事件、因果、各方責任及歷史版本 |
| [人物設定](設定/03_人物設定.md) | 三位核心人物、古代人物、現代對手與人物關係 |
| [修行與特殊事物](設定/04_修行與特殊事物.md) | 修行規則、力量限制、指骨、厄等 |
| [故事主線與揭露](設定/05_故事主線與揭露.md) | 人物怎麼進入事件，讀者何時知道什麼 |
| [待定與決策紀錄](設定/06_待定與決策紀錄.md) | 集中管理尚未選定的問題和後續定案 |

建議討論順序：故事定位 → 世界格局 → 古戰因果 → 人物及當代生活 → 修行規則 → 主線。可以往返調整，不必先填滿所有地名與人名。

## 設定狀態

- **已選方向**：來源明確記載作者選定的大方向，細節仍可能未定。
- **候選**：正在考慮的方案，不當成已發生的史實。
- **待設計**：目前沒有答案。
- **正式定案**：後續由作者明確確認，記入決策紀錄後才使用此標記。

本次只拆分整理既有資料與設計問題，沒有把兩份探索資料整體升格為正式設定。各主題文件管理整理後的內容；原始來源保留討論脈絡，不覆寫。
