# 《劫》｜瘋・封寒修仙武學與傳承體系提案

## ------問劍、問底鐧、天地三問、無面法相、求真界與「唯一」

> **狀態：候選 Source／待 Canon Review**
>
> 以 GitHub
> 現行封寒設定為硬底：**知為道、極為性；親知到底；問劍峰劍修出身；第18篇轉鐧、第19篇自鑄問底鐧；技能越來越準、招式越來越少；黑洞→白洞→歸墟只是他問過問題留下的力量痕跡，不反過來定義他的道。**
>
> 本提案不把封寒寫成「拿鐧的武俠高手」。鐧只是最後的**落點**；真正的封寒必須有根本仙經、神通、法相、領域、天地異象、古代巨頭傳承與自身道術。
>
> **劫：越學越多 → 越改越多 → 天譴越來越複雜。**\
> **瘋：越學越多 → 越驗越深 → 越刪越少 → 最後只剩唯一。**

# 一、人物根本

封寒不能接受「聽說」被當成答案。他要去看、去試、去碰、自己做到，一層一層驗到底。

所以技能趨勢必須是：

> **先多，後少。**

前期真的學很多；中期真的驗很多；後期把已經知道的東西一門門放下。最後留下的是：**所有錯誤可能都被排除後，那唯一正確的一擊。**

# 三、霧鐘島封家｜潮圖是一生的第一門「看路」

潮圖家學不只航海，而是封寒所有高階能力的認知根：

-   潮從哪裡來；
-   往哪裡去；
-   何時轉；
-   哪一點力最大；
-   哪一點最薄；
-   一條路最後落在哪裡。

少年看潮路，青年看氣機，後來看法力、空間、神通、領域與大道。

> **問底鐧最後落得準，不是突然得到必中；他從小就在看路。**

# 四、問劍峰｜仙道劍宗，不是武俠劍派

問劍峰應有真正的：

-   根本仙經；
-   御劍；
-   劍意；
-   劍域；
-   神識鎖敵；
-   天地借勢；
-   劍陣；
-   劍相／法相；
-   高階問道神通。

## 根本仙經候選：《問天經》

劍只是歷代問劍峰最常使用的載體。真正核心：

> **以神識問法，以自身證法。**

前期可以有萬劍異象、劍域等大修士手段，因為封寒後面必須真的「有東西可捨」。

> 他不是因為不會萬劍，所以只打一鐧。\
> **他是真的會，甚至練到極好，最後仍然不用。**

# 五、頂級古劍傳承

上無極／古界路階段可安排一套足以讓普通劍修奉為終身根本的古劍傳承。

它的作用不是讓封寒永遠當劍修，而是讓第18篇「棄劍轉鐧」更重：

> **劍道已經給過他近乎完美的答案。**
>
> **他練懂了，然後發現那仍不是自己的最後答案。**

# 六、從劍到鐧：換的不是武器，是問題

劍常問：怎麼更快、更利、更準地斬開？

封寒真正想問：

> **這東西到底靠什麼成立？**
>
> **一路往裡打，最底下是什麼？**

所以他選擇無鋒之鐧。

不靠刃口切表面，而是：

> **打進結構。**

------------------------------------------------------------------------

# 七、本命兵器｜問底鐧

現行 Canon：第19篇自鑄；無鋒；本質上品寶器；日後依升品規則成長。

## 視覺方向

與陸沉雙刃相反：

-   只有一柄；
-   深黑／玄黑；
-   無鋒；
-   方正；
-   沉重；
-   越到後期越樸素。

早期可有配重、法紋、槽、輔助結構與不同仙材。封寒每真正「知道」一件事：

> **拿掉一樣。**

不是升級一直加零件，而是越來越少。

終局的問底鐧幾乎什麼裝飾都沒有，只剩一柄黑鐧。

------------------------------------------------------------------------

# 八、問底鐧不是「鐧法」載體

封寒不需要九式鐧法。

問底鐧真正作用只有：

# 落點

潮圖看路；問劍峰看勢；古經看法；天地神通看力量去向；求真界排除錯誤答案。

最後：

> **問底鐧落下。**

# 九、天地三問｜黑洞、白洞、歸墟的修仙化

現行人物檔已定：**不要為黑洞硬造哲學；能力只是他問過的問題，在力量上留下的痕跡。**

因此不是「黑洞大道」，而是三次真正的親知。

## 第一問｜萬物入後，何往？------《吞天》

黑洞只是天地異象。真正仙術名候選：

# 《吞天》

封寒身後浮現極暗天淵。靈氣、法力、法寶餘威、神通甚至光都向其中沉去。

但他真正問的是：

> **進去了，然後呢？**

## 第二問｜既有入，可有出？------《照世》

身後第一次出現與黑淵相反的白色神輪。

不是「白洞炮」，而是：

# 《照世》

吞入的力量不原樣吐回。封寒已經讀過其結構，再重新放出。

形成黑淵「吞」與白輪「照」兩種天地異象。

## 第三問｜入與出皆非終點，終歸何處？------《歸墟》

「歸墟」直接保留中國仙話意象。

> 吞不是答案。出也不是答案。

《歸墟》展開時，法相、領域、神通與周圍天地靈氣都開始向一個「不存在的深處」歸去。

不是爆炸，是：

> **歸。**

  問       大術   問題
  -------- ------ ----------------------------
  第一問   吞天   萬物入後，何往？
  第二問   照世   既有入，可有出？
  第三問   歸墟   入與出皆非終點，終歸何處？

三問必須跨長篇幅，每一問都由一次真正的「親知」打開。

# 十、法相｜無面問天法相

沿用過去「無臉白面具法相」的視覺方向，正式修仙化。

工作名：

# 《無相問天身》

或《問天法相》，名稱待 originality review。

## 外觀

-   巨大人形法相；
-   白衣／玄白仙衣；
-   無五官，或覆純白無紋面具；
-   身後可隨境界浮現黑淵、白輪；
-   不必持巨大問底鐧，避免只是放大版封寒。

## 為什麼無面？

> **答案尚未找到。**

只要天地仍有未知，它就不完整。因此終局也不必長出封寒的臉。

# 十一、領域｜《求真界》

工作名可再修，但機制保留。

領域展開後不是無差別攻擊，而是：

> **假的東西越來越難存在。**

逐層剝離：

-   幻象；
-   替身；
-   假身；
-   隱藏氣機；
-   虛假路徑；
-   偽裝法力；
-   神通表象。

敵人有一百種可能。

封寒一層一層驗。

最後：

> **九十九種被排除，只剩一個。**

那一刻才舉起問底鐧。

# 十四、技能演化必須是減法

陸沉：技能越來越多、版本越來越多。

封寒：

> **技能先增加，然後一門一門消失。**

示意：

問劍峰萬劍\
→ 留幾門真正有用的劍術\
→ 古劍傳承\
→ 全部練懂\
→ 轉鐧\
→ 天地三問\
→ 法相\
→ 領域\
→ 歸墟\
→ 連很多大神通都不再主動展開\
→ **一鐧**

不是退化。

> **他知道每一個答案，所以不再需要把每一個答案都演一遍。**

# 十五、最終道術｜《唯一》

工作名：

# 《唯一》

名字極簡，因為它必須和封寒最後的狀態一致。

施展之前：

-   潮圖已看完所有路；
-   問劍已驗過所有勢；
-   求真界已剝掉所有假答案；
-   吞天知道力量如何入；
-   照世知道力量如何出；
-   歸墟知道力量終歸何處；
-   無相問天身已照過神、法、身、道。

天地之間：

> **只剩一個答案。**

封寒舉起問底鐧。

沒有萬劍。

沒有黑白神輪搶畫面。

沒有巨大法相喧賓奪主。

只剩：

# 唯一

一鐧落下。

這才是「技能最後只剩一擊」真正的修仙版本。

## 《唯一》絕不能等於必中

它不是「我叫唯一，所以你不能躲」。

而是封寒付出漫長觀察、驗證、試錯與代價，把其他可能一個個排除。

只要：

-   資訊不足；
-   敵人還有未見變化；
-   某一層沒有驗完；
-   對手餵了假答案；
-   天地條件突然改變；

「唯一」就可能不成立。

這保留了封寒最重要的弱點：

> **他怕還差一層。**

# 十六、封寒的頂級傳承不能都服務戰鬥

「知」若只等於戰鬥分析，會變窄。

頂級傳承還應包含：

-   魂與肉身；
-   界路；
-   天地流向；
-   古史真相；
-   因果／契約邊界；
-   死亡與神魂；
-   「有些東西能知道，但是否該知道」的禁忌傳承。

這才能接上玉壺答案庫、殮錄、魂冊、蒼梧舊約。

封寒真正最難的神通不是「看穿」。

而是：

> **看得穿之後，能不能選擇不看。**

------------------------------------------------------------------------

# 十七、蒼梧舊約是他的最高級「不出手」

現行 Canon 已非常漂亮：

第27篇以前，他只能「被擋」，不能自己停。

第27篇魂冊前第一次停下。

第28篇後蒼梧主動說「你看吧」，他反而背對骨刺坐下。

最後同命契上親手寫：

> **終生不讀舊約。**

這應與最終武學形成鏡像：

-   戰鬥上，他把所有可能排除到只剩唯一；
-   人生上，他第一次主動保留一個永遠不知道的可能。

所以《唯一》不能被寫成「封寒證明萬物皆可知」。

恰恰相反：

> **他有能力知道更多，卻終於知道何時不再往下一層。**

# 二十、回填 GitHub 前 Review

## power-system

-   《吞天》《照世》《歸墟》各自的能源、範圍、代價與境界門檻。
-   吞天不可無限制吞任何高境神通。
-   照世不可變成免費複製敵人能力。
-   歸墟不可成為「碰到就刪除」。
-   求真界必須有資訊與境界限制。
-   《唯一》絕不能規則級必中。

## canon

-   問劍峰根本仙經名稱。
-   古劍傳承來源、原主與篇位。
-   天地三問是傳承引路、天地現象啟發，還是兩者混合。
-   無面法相的正式名稱。
-   問底鐧外觀與「越升級越減法」是否採用。

-   第18篇前必須讓讀者真正看見他是優秀劍修，轉鐧才有重量。
-   第19篇自鑄問底鐧不動。
-   天地三問不可一次拿齊。
-   每一門被放下的法，都應先有至少一次真正高光。
-   第27篇以前不能讓他主動「選擇不知」。

## character

每得到一門頂級傳承都問： 1. 他想知道什麼？ 2. 為什麼非親自驗不可？ 3.
他驗到哪一層才肯說「知道」？ 4. 這個答案又產生了什麼新問題？ 5.
最後他為什麼放下這門法？

# 二十一、作者層一句話

> **封寒不是把一招練一萬遍的人。**
>
> **他是把天下一萬種答案都親自驗過，最後只留下一個的人。**

所以問底鐧真正可怕的從來不是它有多重。

而是當它終於落下時：

> **封寒已經沒有第二個落點。**

這就是瘋。

這就是「親知到底」。
