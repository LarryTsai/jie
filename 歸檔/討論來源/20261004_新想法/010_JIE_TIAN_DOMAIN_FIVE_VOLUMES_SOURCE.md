# 《劫》天域前期 × 地獄行後五卷 Source

> 狀態：2026-10-04 討論整合稿。承接四大書院、地獄行、南荒域級異變設定。
> 核心：四院不是第二個太玄宗，而是修仙界頂級人才培育／研究／任務平台，近似「小型公司」。太玄才是家。

# 1. 五域大比後到南荒的完整順序

五域大比決勝（俞清漪勝陸沉）
→ 賽後頒獎／天域級機緣
→ 四院招攬、接觸、報名
→ 等待正式報到的天域自由期
→ 從天域資訊得知戰葬殘響來源
→ 劫＋瘋＋雲《地獄行》
→ 第三雷・震魂
→ 返回天域
→ 正式四院報到
→ 約五卷天域生活／任務期
→ 南荒異常由背景消息逐步升高
→ 四院聯合令
→ 南荒大篇

# 2. 大比賽後獎勵

不能只有靈石。獎勵本身要展示天域家底。

固定層可有高階資源、特殊修煉地額度、四院公共寶地資格。

高位／特殊表現可有：
- 進古殿選法資格；
- 聖階功法；
- 高階仙術；
- 神識法；
- 身法；
- 分身控制法；
- 雷道運行總綱；
- 仙術殘式；
- 特殊寶物／權限。

紅線：不要直接給替陸沉寫完雷道答案的「無敵雷經」。大比給工具，不給人生答案。

# 3. 四院招攬與報名

東院：正式、嚴謹，正統仙術最完整。
西院：百藝導向，會直接談禁、丹、器、陣等能力與資源。
北院：看皇路、統御、決斷、王道與未來掌權潛力。
南院：最自由，甚至不太主動搶人。

報名不等於正式入院。各院應有自己的確認／入門方式，但不要再打一場完整大比。

東院可查根基、問道、驗法。
西院可要求「做一件東西」，證明自己真的有一門藝。
北院可給需要決策、調度、取捨與承擔的問題。
南院沒有標準答案，難點是沒人告訴你怎麼過。

# 4. 地獄行的位置

地獄行放在「已報名／被招攬，但尚未正式報到」的自由期。

所有人準備開始書院人生時，陸沉從天域強者、古籍、大比獎勵開放的古殿或高階資料中拼出：

> 「那不是戰葬的東西。」
> 「你聽見的是下面的聲音。」

劫、瘋、雲自己追下去，不是老師派的書院任務。

取得第三雷震魂後返回天域，甚至差點錯過報到。

# 5. 四院不是家

太玄／鎮岳峰：家、師徒、師兄弟、長期歸屬。
四院：階段性人才平台、研究機構、任務平台、資源平台。

院長像組織最高負責人；師長像高階專家／研究主管；學長姐像 Senior／任務前輩；同屆是 peer。

最高級紅線：

> **四院不能寫成太玄宗 2.0。**

太玄教陸沉「有人會等你回來」。
四院教陸沉「世界不會等你」。

# 6. 南院的公司感

南院不是自由大家庭，更像超自由的新創／研究所。

它不一定提供最多資源，而是提供選擇與時間。可跨院蹭課、自己找師長、自己組修行、自己申請任務，也自己承擔失敗。

候選：

陸沉：「有雷法老師嗎？」
「東院比較多。」
「禁制呢？」
「西院。」
「那南院有什麼？」
「時間。」

# 7. 師長與學長姐的出場

必須像太玄一樣靠故事逐步認識，但關係不必像家人。

第一個學長可由報到認識；第一個師長在三雷失控時出現；某學姐帶第一次任務；高階老師在登塔後才注意他；院長甚至可以很晚才真正進場。

不能用一段介紹把院長、老師、學長姐全部帶過。

# 8. 三雷時代

第三雷取得後不能立刻找第四雷。

要完整存在「星羅＋兩儀＋震魂」三雷時代。

震魂加入後可帶來：
- 神識資訊過載；
- 三身控制新問題；
- 三具身體同時收到不同訊息；
- 「我」到底在哪一具的遠期伏筆。

候選小型失控：陸沉同時使用三雷／三身後不是爆炸，而是「太吵」，自己、分身、周圍神魂波動、雷、禁全部同時湧入，站著不動、叫不回來。

# 9. 地獄行後五卷第一版

## 卷A《入院》（暫名）
核心：**我是新人。**

內容：
- 地獄行歸來；
- 四院正式報到；
- 劫南、雲南、瘋東、生東、文西；
- 身份、洞府、資源額度、權限；
- 四院不同 onboarding；
- 第一批師長／學長姐自然出場；
- 大比獎勵開始修；
- 三雷初步磨合；
- 陸沉第一次懷疑南院是不是選錯；
- 南院資源制度正式出現。

卷末：陸沉發現三雷修煉非常耗資源。
「怎麼拿？」
「闖塔。」

## 卷B《登天塔》（暫名）
核心：**我能拿到多少資源？**

四院共有試煉塔／修煉寶地，不屬任何一院，是共同的人才評估、資源分配與修煉機制。

塔不能只是逐層打怪，可考戰、神魂、悟性、禁、生存、選擇，甚至某層完全不用打。

闖高可得到：
- 修煉額度；
- 高階仙術權限；
- 特殊寶地；
- 高階任務資格；
- 寶物；
- 高階師長注意。

五個熟人第一次以不同院學生身份重新交錯，也各自帶著新朋友、新對手、新前輩。

陸沉開始把大比獎勵＋院內仙法＋三雷＋體＋神識＋禁真正混合。

塔中獎勵最好不是又一本功法，可是長期寶物或一次特殊寶地權限。

## 卷C《天域行》（暫名）
核心：**我能不能真正做事？**

開始正式書院任務：護送、調查、仙城問題、靈脈、王族糾紛、古地、跨域貨物、失蹤、查帳、小型救援、跨院專案。

不是每件事都世界危機。

北院皇道天驕在這卷真正立起來：某次任務陸沉戰力很強，但對方可能一場架都沒打，靠談判、調度、撤離、分配把事情做得更漂亮。陸沉第一次看到「有一種強跟我完全不同」。

南荒第一個背景訊號只需要一句：
> 「今年南荒藥價掉得很兇。」

大家甚至覺得是好事。

## 卷D《越界》（暫名）
核心：**我還是我。**

前三卷逐漸職場化，這卷故意重新少年一點。

劫＋瘋先因好奇偷偷進西院某禁庫／限制區。不是偷寶，只是想知道裡面有什麼。文奕可能被迫一起收拾。

西院某古物、禁或資料再牽到北院王族收藏／古檔。劫瘋繼續追，第一次看到皇路世界背後的秘密、協議、歷史或不能公開的五域決策。

北院長期皇道對手可抓到他們，但不告發，只留：
> 「你們欠我一次。」

這份人情可幾百章後再收。

## 卷E《歸山》（暫名）
核心：**我從哪裡來？**

書院出現休整期／任務空窗。有人回家、有人留院、有人遊歷。

劫＋生回太玄。

陸沉在天域是三雷天驕、「劫」、南院修士；回鎮岳仍然是「老七」。

岳沉淵、老大～老六、顧小滿、藥閣與以前生活過的地方自然出現，不需要每人一段感人對話，重點是生活。

劫生感情可在「一起走以前走過的地方」自然加深，而不是再靠生死救援。

後半南荒訊號逐步升高：
- 藥材便宜；
- 百年藥提前成熟；
- 妖獸遷徙；
- 潮霧出現在不該出現的位置；
- 書院開始派小型調查任務。

最後有人從南荒回來說：
> 「我一直聽見有人叫我。」

劫、瘋、雲都知道：**下面。**

南荒多地同時異常，天域判定域級事件，四院聯合令下達。

下一階段：《南荒》。

# 10. 五卷的成長功能

卷A：我是新人。
卷B：我能拿到多少資源？
卷C：我能不能真正做事？
卷D：進了書院，我仍然是我。
卷E：我從哪裡來，現在又要去哪裡？

南荒則是第一次真正的大型跨域 Project。

# 11. 天域期不能只有修雷

陸沉的進步應同時包含：
- 五域大比獎勵；
- 聖階功法／仙術；
- 南院修習的新法；
- 三雷磨合；
- 禁制；
- 神識；
- 體修；
- 試煉塔寶物／權限；
- 任務實戰。

雷是主幹，不是唯一升級方式。

# 12. 回太玄的意義

天域不應取代太玄成為「第二個家」。

恰恰相反，書院越像工作平台，回太玄越有力量。

外面叫「劫」；鎮岳叫「老七」。

這段必須保留。
