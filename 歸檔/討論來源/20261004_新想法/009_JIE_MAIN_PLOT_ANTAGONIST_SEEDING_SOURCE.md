# 《劫》主線 × 反派 × 臥底 × 長線埋線 Source

> 狀態：2026-10-04 討論整合稿。
> 核心：真正主線不能到天域才突然開始。前期其實已有古戰、共天、救援派、界樁、戰葬等痕跡；最新方向是從東溟階段開始逐步把主線由「古老痕跡」變成「現在有人正在行動」，並引入普通反派、外圍勢力、跨域高階行動者與天域臥底。

# 1. 主線其實早就存在

目前已經具備的主線性元素包括：
- 共天／九天接脈遺構／未竟之接；
- 古戰與救援派；
- 界樁被上層力量「對齊」；
- 溫棠尋找救援派醫所；
- 巡天舟巡過、雷池靜三息；
- 「它不是看不起我們，是根本沒看」；
- 戰葬殘響；
- 地獄／下方世界；
- 沉降堵塞；
- 南荒後續生機異常。

因此不是「天域才開始主線」，而是：

> **前面一直踩在主線留下的腳印上，只是不知道腳印屬於誰。**

# 2. 主線揭露應分階段

| 階段 | 陸沉／讀者的認知 |
|---|---|
| 太玄／東溟前段 | 世界上有很多不知道的舊事 |
| 東溟中後段 | 某些舊事可能彼此有關，而且有人現在還在碰 |
| 中神州／五域 | 行動開始跨域，某些名字／痕跡重複出現 |
| 地獄行 | 世界本身有地方不對 |
| 天域書院期 | 有人知道世界不對，而且現在仍在處理、利用或遮掩 |
| 南荒 | 這不是歷史問題，它正在影響現在 |
| 更後面 | 才逐步追「誰造成」「為什麼」「仙帝長子／異域公主真正因果」 |

紅線：現在不要直接把仙帝長子、異域公主與終極答案全部搬上台。

# 3. 主線必須從「謎」變成「人」

前期看到：
- 遺跡；
- 古戰痕；
- 不一致的歷史；
- 異常世界結構。

到了東溟中後段開始加入：

> **有人正在利用、收集、研究、掩蓋這些東西。**

如此主線才有「現在式」。

# 4. 反派／敵對勢力分層

不要所有壞事都來自同一個「曉組織」。

## 第一層：普通反派
為錢、權力、資源、家族、功法、私仇做事。

例：
- 偷材料；
- 偷捕靈獸；
- 私賣情報；
- 王族爭權；
- 趁災搶資源。

他們可以與終極主線完全無關。

普通反派必須存在，否則世界會變成所有案件都是同一組織。

## 第二層：主線外圍勢力
知道某些古老秘密／異常物有價值，但不知道全貌。

可能專門收：
- 古戰遺物；
- 救援派遺物；
- 界屑；
- 異常神魂；
- 古禁；
- 「不該存在的東西」。

外圍者可能只替上家收貨，甚至不知道自己替誰工作。

## 第三層：跨域高階行動者（工作稱「曉級人物」）
不是正式名稱，只代表角色層級與敘事功能。

特徵：
- 成員少；
- 跨域活動；
- 各自能力極強；
- 各自有任務；
- 不會每天聚在秘密基地；
- 彼此理念甚至不同；
- 可能一年都不見一次；
- 有人在北天、有人南荒、有人天域、有人異域。

他們不一定全是反派。

有人想救人；有人想知道真相；有人想拆封印；有人覺得九界秩序本身就是錯的；有人真的危險。

## 第四層：真正主線知情者
知道仙帝長子、異域公主、大戰真因、九界現狀等更深內容。

目前不要讓陸沉真正碰到這層。

最多只讓第三層收到不明來源的命令。

# 5. 「曉級組織」不能照抄曉

可以有跨九界少數高階行動者的組織，但不要變成「幾個披風人固定開會」。

每個人應有自己的人生與任務。

重要原則：

> **他們在陸沉出生以前就已經做自己的事。**

陸沉不是世界中心。

陸沉十五六歲才知道世界不對；這些人可能已經查了三百年。

有人第一次見陸沉甚至可以：
> 「劫？沒聽過。」

# 6. 臥底要早出現，而且先是「人」

天域可有一位學長姐／師長／任務前輩：
- 很正常；
- 帶過陸沉；
- 救過人；
- 幫過他；
- 南荒時也可能很努力；
- 讀者不覺得他是黑衣反派。

幾卷後資料少一頁，沒人懷疑。

很久後才知道：

> **他一直在找某樣東西。**

臥底不是站在陰影裡說「計畫開始」。

# 7. 第一個高階行動者可以東溟就出現

高度推薦：

> **第一個真正「曉級人物」在東溟就與陸沉擦肩，但完全不揭身份。**

他可以：
- 喝過酒；
- 同行過；
- 交換情報；
- 一起進過秘境；
- 打過一次；
- 甚至救過陸沉。

陸沉只當他是厲害散修／陌生修士。

到了天域某人看到他留下的東西：

> 「這誰給你的？」

陸沉報名字。

對方第一次變臉。

這種回收比東溟直接揭組織強。

# 8. 卷1～9的主線滲透策略

不要推翻現有東溟骨架，而是「補針」。

| 卷段 | 主線可見度 | 建議 |
|---|---:|---|
| 卷1 留舟島 | ★ | 只有痕跡；某物缺角、某記錄不一致，完全不追 |
| 卷2 入太玄 | ★ | 舊物／舊陣有一處對不上，仍只是世界厚度 |
| 卷3 宗門生活 | ★★ | 普通任務出現「不該在這裡的東西」 |
| 卷4 第二雷 | ★★ | 深處第一次發現**最近有人先一步來過** |
| 卷5 宗門／七峰 | ★★ | 某情報販子／人物第二次出現，但看似正常 |
| 卷6 戰葬 | ★★★ | 戰葬殘響＋第一個研究／收集相關現象的外圍人物 |
| 卷7 東溟行 | ★★★ | 第一次真正碰主線外圍者／高階行動者 |
| 卷8 百宗盟試 | ★★★★ | 現在式行動與百宗事件交叉；有人關注的根本不是比賽 |
| 卷9 東溟收束 | ★★★★ | 開始懷疑前面幾件事屬於同一條線 |
| 中神州 | ★★★★ | 組織活動跨域；名字／物件／手法開始重複 |
| 天域 | ★★★★★ | 確認有人已經做這件事很多年 |

# 9. 前三卷不要出「神秘組織」

卷1～3必須克制。

不要：
> 黑袍人站在山上：「他就是那個孩子。」

更好的伏筆：

陸沉看見某處缺了一角。

當時只想：
> 「這裡怎麼缺了一角？」

三百章後才知道：
> **那一角是被人拿走的。**

# 10. 卷4：第一次「有人先來過」

第二雷大故事非常適合。

劫瘋深入後以為自己是第一批進這麼深的人，卻發現：
- 很新的腳印／術痕；
- 被取走的東西；
- 半年／三月／數日前留下的痕跡。

封寒：
> 「有人來過。」

陸沉：
> 「拿走什麼了？」

不知道。

不追，繼續本卷自己的故事。

主線第一次從「古代」變成「現在」。

# 11. 卷6戰葬：第一個外圍人物

戰葬已與地獄／震魂長線相連。

可以有一個人也在研究戰死者殘響。

他不必是敵人。

甚至可以：
- 交換情報；
- 幫劫瘋；
- 很討喜；
- 正常離開。

幾百章後才知道：

> **他在替某個勢力收集「洩口」資訊。**

# 12. 卷7東溟行：主線外圍勢力真正進故事

此時陸沉開始大量出宗門：
- 仙城；
- 商盟；
- 任務；
- 散修；
- 其他宗門。

可安排完整中型案件，例如修士失蹤／神魂被收集。

抓到的反派可能真的只是壞人，但他替某個人收東西。

再往上追：
> **斷了。**

故事本身要能完整結束，不強迫陸沉追遍天下。

# 13. 卷8百宗盟試：暗線必須存在

百宗盟試聚集東溟大量天驕、宗門、資源。

主線勢力不應完全缺席。

但他們的目的可以跟比賽毫無關係。

所有人都在看：
> 誰第一。

某個人卻一直在看：
> **百宗盟試下面那座舊陣／舊戰痕／某個古老節點。**

陸沉封舊戰痕時，意外暴露或破壞了對方正在做的事情。

對方不是「終於找到主角」。

只是：
> **「麻煩。」**

# 14. 天域五卷如何帶主線

天域不能只有入職、登塔、任務、偷院、回家。

每卷底下要有一個主線碎片，但不能吃掉表層故事。

## 《入院》
表層：報到、師長、資源、三雷。
主線：高階資料中某段古史前後對不上。
人物暗線：未來臥底正常登場，沒人懷疑。

## 《登天塔》
表層：公共試煉塔、功法、寶物。
主線：塔中出現與官方歷史不相容的古痕／救援派標記。
人物暗線：某個高階行動者也在找塔內某物，但陸沉不知道。

## 《天域行》
表層：第一批正式任務。
主線：有人正在回收／偷走古戰相關物件；第一次真正跟外圍勢力交手。
更重要：某份本應上報的紀錄被壓成低級事件，證明「現在有人知道」。

## 《越界》
表層：劫瘋偷西院／北院。
主線：西院資料與北院古檔拼起來，證明有人故意把資訊拆開。
臥底甚至可能暗中放線，讓他們「剛好」查到。

但查到一半必須斷，不能提前解主線。

## 《歸山》
表層：劫生回太玄、生活與感情。
主線：陸沉現在看得懂以前看不懂的某個太玄舊陣／舊物，發現同源古痕。

效果：
> **原來主線從第一卷就一直在他身邊。**

# 15. 南荒：第一次多方勢力同場

南荒域級事件應讓很多線同時進場：

- 四院：穩住南荒；
- 南荒本地：保護自己；
- 妖族：防止人族趁機越界；
- 商人：看到利益；
- 普通反派：趁亂搶資源；
- 主線外圍勢力：尋找沉降恢復後出現的東西；
- 天域臥底：混在四院隊伍；
- 高階行動者：可能也已到南荒；
- 陸沉：只是其中一條線。

這才是「很多線交叉」，不是一條主線串幾個圓。

# 16. 主線可見度比例

建議大方向：

- 卷1～3：95% 本卷故事／5% 主線
- 卷4～6：90／10
- 卷7～9：80～85／15～20
- 中神州：75／25
- 天域：65～70／30～35
- 南荒：主線與本卷故事開始無法完全分離

不是硬算章數，只是控制感。

# 17. 埋線三問

每次想把主線塞進既有卷，先問：

1. **這卷能不能留一個主線痕跡？**
2. **這卷有沒有適合自然出現一個現在式人物？**
3. **就算這伏筆永遠不回收，本卷故事本身是否仍然成立？**

第三題若答案是 No，就不要塞。

# 18. 最終目標

理想閱讀效果：

天域某次揭露後，讀者突然回想：

> 卷四那個新痕。
> 卷六戰葬那個修士。
> 卷七失蹤案。
> 百宗地下那座舊陣。
> 中神州那件東西。

然后才發現：

> **它們不是作者隨便寫的小故事。**

但第一次讀那些章節時，它們又都必須是完整、好看的故事。

一句話：

> **主線不是從天域開始，而是從很早以前就在世界裡；東溟開始讓它從「痕跡」長出「人」，天域讓陸沉第一次主動追，南荒則讓這條古老問題第一次真正影響現在活著的世界。**
