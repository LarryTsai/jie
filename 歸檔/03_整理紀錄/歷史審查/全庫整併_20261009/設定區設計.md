## 二、各類乾淨度規則

通則（寫入 `設定/README.md`）：一主題一檔；同一事實一個現行出處；大檔（約 60KB 以上或混多主題）拆成有階層的子檔；效力寫在檔頭「狀態」一行，README 以〔〕標出非定案；不放競稿、提案原稿、修訂往返、審查與核對紀錄、工作流水、故事順序與篇章大綱。

效力詞固定五級：**作者定／定案**（有 D 號）＞**設計採用**＞**現行提案**（作現行用，作者可改）＞**候選**（可用於創作，不是 Canon）＞**留白**（不得自行補寫）。

| 類 | 放 | 不放 | 特別規則 |
|---|---|---|---|
| 00_故事定位 | 作者給的敘事方向、Writer Rule、戰鬥硬規則 | 工作流程規約、母稿試寫、移植待辦 | 一條規則一檔，檔內寫 D 號與生效日；改寫在檔內註記，不另開版本檔 |
| 01_世界／天地結構、故土、勢力 | 地理、層次、通行、勢力定位與家底 | 篇章安排、某篇發生什麼 | 總表管定位，家底卡管深入；候選數值檔內標候選 |
| 01_世界／修仙文明 | 規格目錄、已裁定細則 | 詰辯、未採方案、推薦理由 | 細則檔頭寫「作者定（Dxxx）；原提案見討論區」 |
| 01_世界／聖土 | 規則、當代資料、家底卡、人物、勢力、反派、文明細則 | 三訪故事線、事件骨架 | 命名照體例：音譯人名地名＋西式機構詞（劍廷、魂院、陣會），不接中式宗、堂；故事候選不因放在設定區升格 |
| 02_歷史 | 公開史實的時間線與責任 | 作者層真相（放 05） | 先後與史實邊界，事件長大再獨立成檔 |
| 03_人物 | 人物卡、名冊、關係、感情線節點 | 篇章事件細節（連大綱） | 同代人未設情感線者不自行補；名冊與分檔並存是檢索層次 |
| 04_修行 | 境界、雷、武學、丹、寶、基準、特殊事物 | 篇位排程（只寫取得條件與限制） | 能力要寫得出限制、消耗、反制；作者層工作詞（變／知／無）不當能力規則 |
| 05_主線揭露 | 古戰真相、罪責、錯誤答案、揭露層次 | 揭露篇位（大綱）、作廢的查案機制 | 檔頭標「作者層，不直接入正文」 |
| 決策 | D 號條目、待決題 | 提案原稿、審查 | 見第三節 |

## 三、決策區結構

```
決策/
├─ README.md            讀法、結構、寫入規則、最新覆蓋（第二批從近期決策移入）、D 號索引表
├─ 01_決策紀錄/
│   ├─ README.md        D 號區段索引
│   ├─ 近期決策.md      第一批：原 設定/06 README（D101–D129、2026-10 未編號裁定、最新覆蓋、歷史查找）
│   ├─ 完整歷史.md      第一批：原 歸檔/設定歷史/…/決策紀錄_完整歷史.md（D011–D127 完整條文）
│   └─ ★ D000_編號前工作決策.md、D011_太玄宗主峰與七峰重設.md … D129_聖土王室臥底合謀結構.md

    ├─ README.md
    ├─ 待定問題.md
    ├─ 新想法待定矩陣.md
    └─ ★ 待作者決定總清單.md（各區設計檔的作者題、各檔「待作者」留白，一題一列）
```

寫入規則：只由主 Agent 依作者裁定寫入；每條寫 D 號、日期、範圍（影響哪些檔）、出處（作者原話日期或方案檔連結）；作者裁定才給號，連號遞增；過時條目加註「已由 Dxxx 修改」與範圍，不刪；裁定後同一次提交寫決策條、改對應設定或大綱檔、同步總覽。

**為什麼兩份紀錄第一批只搬不拆**：`近期決策`（50KB）與 `完整歷史`（304KB）在 D101–D127 重疊，前者是後者的濃縮版。拆檔要逐條決定以哪份為正文，屬內容工作。

**第二批拆法**：
