## 總原則

> 境界是往上走的，但人生不必一直往上走；地圖更不該用完就丟。

- **九界是故鄉，不是新手村。**一生反覆回來，每次看到的九界都不同。
- **下無極是大舞台，不是第二張地圖。**可以早期偷渡、正式進入、後期重返。
- **上無極不是下無極的升級版。**第一次最好不是正常進去（例：九界→下無極→某古界→從另一側掉進上無極，對方第一句是「你從哪裡進來的？」——別人走門，他把牆弄出一條路）。
- **大羅很早就存在於故事裡，很晚才真正踏進去。**例：看見大羅的人 → 碰到大羅留下的東西 → 被大羅的人追 → 偷偷進去一次 → 被趕出來 → 才真正踏進大羅。
- **聖土是橫向世界，多次往返、每次意義不同。**第一次是冒險（很弱、不知道這世界在宇宙裡的位置）；第二次是故人（當年的小朋友已是一門之主，當年的強者已死，當年不敢靠近的雷域，現在站在外面看了很久：「原來是這個。」）；第三次是真相（大羅之後，聖土牽涉古戰全貌）。
- **失敗可以讓路線往下。**高境界照樣可能被打回九界：道基、雷身、身分、通道全部出問題，掉進最陌生的一界，沒人認識他，力量又不能亂開——讀者才發現九界仍巨大得可怕，只是鏡頭以前一直跟著陸沉。
- **重返舊地不是懷舊篇，而是「以前的我根本沒看懂這裡」。**同一個地方陪角色活一輩子：少年看見一座有雷的山；百年後發現不是天然雷域；再後來發現整座山是某個東西露在九界的一角；最後發現改變他一生的地方，只是另一個世界留下的一道傷。
- **路線像他的道**：出去 → 看懂一點 → 離開 → 變強 → 回來 → 發現以前理解錯了 → 重走（看見不足 → 破 → 重構 → 超越 → 再看見新的不足）。

## 轉折候選池（第一輪，三組專家：讀者爽點、偵探主線、世界機制；2026-10-01）

**九界（故鄉，反覆回來）**
1. ★伏雷坳三讀：少年只當危險地 → 壓境回來認出雷紋與封合縫劫雲同源 → 對上太玄閣修脈簿「祖脈第七節」缺的一刻地脈數據。有雷的山原來是撤護持燒出的傷疤。
2. ★宗訓是她的遺字：太玄閣已不在，宋知微當年留的「這裡」被新宗刻成宗訓，無人知出處。新弟子問：「前輩也背過？」
3. 祠堂的第二碗粥：雨夜才看出那碗粥朝向斷階、筷子按客禮擺；讀到殮錄「遺骸缺一指」才懂給誰；終局換他自己擺。

5. 寇平的位置：自己帶錨印壓境一次，才懂當年寇平為什麼沒人救；回頭在壓境簿查到那一筆的擔保人。
6. 量水山拿自己釣魚：故意壓境入簿，調閱一份假記錄，看誰起反應。
7. ★你從哪裡進來的（終局鏡像）：留舟島伏雷坳是另一個世界的傷口，有少年從裡面掉出來，換陸沉問：「你從哪裡進來的？」

**九界 → 下無極（第一次誤入）**
8. 誤入下無極三種變化：（a）誤上頂名舟，用死人的名字活一個月，點名時應「在」；（b）界潮捲進失事界舟殘骸，撿到半本通行簿，多年後被批「九弱」才看懂是頂名名單早期版；（c）接引台中途斷裂，被拋到下無極拋落場，成了黑戶，一遣返就暴露。

**上無極（第一次不是正常飛升）**
9. ★古界路殘身：古界路外段沉成九界、內段崩成斷峰群，他沿夾層裡漂著的路身碎片走，從斷峰群「牆裡」掉出來。巡查者問「你從哪裡進來的」，語氣是：「走那條路的人，都死了。」（文奕認出禁標年代；那其實是被遺忘的門。）
10. 錨印鏽蝕：壓境入望歸界查案超時，越裳王庭拖著不合印。要嘛看最高一重修為被印吃掉，要嘛破印違約。這是第一次「境界往下」。
11. 望歸界的譯例：越裳通譯館舊譯例裡，芸香夜罪名那個聖土詞本義是「給出保護承諾的東道」，不是「仙庭全體」。只埋伏筆，正式聖土篇前不拆。
12. 塔姆林的渡口：壓境下望歸界，每過一道界路解一層封；渡口第一句：「你說過你叫劫。」

**大羅（六步：看見 → 遺物 → 被追 → 偷進 → 被趕 → 正式）**
13. 看見（兩種變化）：（a）大羅巡天舟過九界上空，全界雷池同時靜了三息，大羅連看都沒看九界一眼，陸沉的雷第一次自己低頭，雲行下山去問死了誰；（b）少年在共天關閉時神識沒歸體，漂到總樁，看見一盞不屬於九界的燈。
14. ★遺物：界屑。有人強破錨印被界壁剪下，剪落的修為帶著封有大羅帝本源的界壁碎屑一起落地。
15. 被追：界屑是座標燈，大羅追兵在九界也得壓境，成了同級追逐；九界反過來成了他的避難所。
16. 偷進（兩種變化）：（a）太虛渡虛定位失誤，界屑往家的方向拉，順三十二天向極的「坡度」滑進大羅外緣；（b）只待一炷香，背下天冊正本上長亭天的擔保附冊編號，與下無極抄本對不上。
17. 被趕：大羅道脈只認登籍者，無籍者吐納歸零，被道則一層一層「剝」出去。
18. ★被趕 × 伴星：押他出境的是蒼梧，依自己的舊約，在界門上親手解了同命契：「我的約在你之前。」（D072：伴星編制已撤，蒼梧是旅途中的戰友；同命契是兩人的朋友之約，他自己的舊約先於友情，事件不變。）（D072 作者補記，2026-10-02：蒼梧沒有與陸沉立約，「解了同命契」改讀為依自己的舊約在界門離開；「我的約在你之前」說的是那份舊約。）
19. 正式：歸還界屑，由帝道場擔保登籍，走正門；從此大羅的籍綁住他。

**聖土（三次：冒險 → 故人 → 真相）**
20. ★果林三訪：落潮一年只聽說果林不准進 → 第二次看見接穗自己長出根 → 第三次在根下挖出長子藏的另一份副本，有他對烏蘅的私下稱呼，可驗親筆。
21. 這回你收不收：第二次聖土，他被當成弱者是因為無籍。一層層解封的是別人怎麼稱呼他（外客 → 單契人 → 劫）。德維第一句：「這回你收不收？」
22. 第三份探查記：大羅之後第三次聖土，維達已死，望樓第三份探查記由陸沉親手寫；芸香夜他站上證人席。

**大敗與墜落**
23. ★大敗墜回陌生九界：雷身分處各界、本源撕扯到臨界，本尊道基碎到列陣以下，界壁只秤當下所以放行。修為散在道基裂縫，一聚攏就被剪，開一次少一份，所以力量不能亂開。其他雷身的錨印到期就鏽，他成了上界黑戶。
24. 勿來：墜落後，陸沉第一次對生發出「勿來」；生照樣來，但依同命契先把代價看清楚。
25. ★斷階頂上墜落：被打落時掛在斷階頂，一輩子第一次往下看。磨痕是往下走的，殘口內側有封口時序刻痕。
26. 墜過帝天：重傷墜落穿過帝天骨架，看見末代鬥帝與太宸兩道封口時刻錯開、方向相反。只有墜落看得到。
27. 雜工看天驕：從那一界的雷池雜工橫走到界主面前，不參賽，只維護賽場；有孩子的禁標是文奕的手法：「有個怪人教我先問為什麼。」
28. 縫行：沿封合縫劫雲帶在界壁內側行走，連通西四界；只容列陣以下，有真實死亡率。
29. 拓印失配：道基重構後氣機拓印變了，連自己的名字都頂不回去，只能用頂名手法以「新人」身分重新接引上去。
30. 雷身迷途霜明界：一具雷身落進凝光天冰層，冰裡凍著八萬年前的天光，西天第一個暗下去的是長亭天。

**各組指出的主要張力**：墜落入界未經錨陣（23、25、26）；誤入下無極繞過飛升路徑、與首入聖土時點相撞（8）；大羅很晚才踏進（13、16）；第三次聖土與大羅先後（20、22）；漏影不可通行（9、16a）；雷身偏離錨陣（30）。
