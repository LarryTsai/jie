# 《劫》中神州前段重排 Source

> 狀態：2026-10-04 作者討論整合稿／尚未全部回填 main。  
> 承接：《卷六～卷九重排與擴寫 Source》《九雷取得節點調整案》。  
> 核心：**禁都不是中神州中心；古神禁典放五域大比前；第三雷震魂放五域大比後。**

# 一、核心新方向

1. 中神州是完整而高度繁盛的修仙文明，禁制只是其中非常強盛的一道。
2. 禁都是因禁制文化、禁制世家、古禁交易與禁盟勢力聞名的**重要都城之一**，不是首都、唯一核心或所有天驕必經之地。
3. 東溟入選者由組織統一送抵**中神州東境大型門戶仙城**。
4. 抵達時距五域大比約三個月。
5. 前約兩個月自由活動；最遲大比前一個月到中央主要比試區集合。
6. 《古神禁典》在五域大比前取得，但只開始消化。
7. 五域大比時陸沉仍是**成熟二雷三身＋初步系統化禁制**，沒有第三雷。
8. 第三雷太古震魂雷在五域大比後正式取得。

# 二、中神州不能禁都中心化

中神州同時應存在劍道仙家、丹道聖地、體修古族、魂修宗門、御獸世家、空間／傳送一脈、商盟、大型拍賣、古老道統、散修大城，以及禁制世家、禁盟、古禁學派。

陸沉因為自己會禁，自然走進其中「禁制」這條路；不是因為整個中神州只有禁制故事。

# 三、第一站：東境門戶大城

不是中央區、禁都、大比會場，也不是中神州最大城。

但光是邊境大城就足以震撼東溟少年：

- 東溟罕見大型飛舟，在此只是排隊入港的一艘；
- 高階傳送陣是交通設施；
- 高境修士自然出現在港口、商會、街道；
- 城牆、泊位、街道、傳送台大量使用禁與陣；
- 丹、器、獸、劍、魂、商等文明密度全部提高。

推薦尺度對話：

> 「這是中神州最大的港？」  
> 「不是。」  
> 「最大的城？」  
> 「不是。」  
> 「那這裡是？」  
> **「東邊入口之一。」**

關鍵是「之一」。

# 四、三個月時間結構

抵達時距五域大比約三個月。

- **前約兩個月：自由期。**
- **最後一個月：中央大比區集合／五域前夜。**
- 之後才正式五域大比。

中神州不是比賽場館。角色要先真正生活在中神州。

# 五、前兩個月：第一次大型自由行路期

以前外出通常有宗門任務、指定目的與期限。這次只剩：

> **大比前一個月記得到中央集合。**

其他時間自己決定。

這是陸沉第一次在巨大修仙世界裡真正自由選路。

# 六、群像分流

不要讓東溟天驕組成旅行團跑兩個月。

- 生可去醫道／丹道之地；
- 封寒可去兵器街、古兵冢、劍修／兵家區域；
- 青璃走自己的路；
- 其他人拜訪前輩、道場、秘境、交流任務；
- 有人留東境閉關；
- 有人與其他域新識天驕同行。

這裡第一次明顯告訴讀者：他們不會永遠一起行動。

# 七、陸沉自然走進禁制師世界

他不是被作者派去禁都，而是看到成熟禁制文明後自然停下來。

入口可以是公共禁制、殘禁攤、修復委託、禁盟地方據點、古禁拍賣、禁師論法。

在東溟他已經很會禁；在中神州正統圈眼中卻是**野路子**。

野路子不等於弱：他基礎術語可能不完整，卻真的能看出問題；不知道標準解法，卻能拆出另一條路。

# 八、文奕正式進場

不要以「未來四人組成員」登場。

推薦第一次真正碰撞：

> 陸沉：「這裡可以改。」  
> 文奕：「為什麼要改？」  
> 「這樣比較好。」  
> 「你連它原本為什麼這樣都不知道。」

兩人先看不順眼，再發現對方真的很強，多次碰面、對同一座禁得出不同答案，最後被大型古禁事件捲在一起。

三種視角：

- 劫：哪裡可以改？
- 文：它原本為什麼這樣？
- 瘋：最裡面到底封了什麼？

# 九、《古神禁典》放五域大比前

它不是單純戰力包，而是陸沉第一次從「會拆、會改的野路子」走進真正有歷史、方法與思想的禁制世界。

大型古禁區／仙王遺跡把多方人物捲入。劫、瘋、文第一次真正同行。

推薦保留：

> 「這個禁可以改。」  
> 「你先別動，我還沒看完原陣。」  
> 「你們有沒有想過，它不是在防外面的人進去？」

最後陸沉與文奕從兩端反解同一座古禁，各自以為得到不同內容，最後發現是**同一部《古神禁典》的兩端**，合起來才完整。

# 十、禁典不能即時滿級

取得後到五域大比前要有消化時間。

以前：
> 看 → 拆 → 改。

開始變成：
> **看 → 問「它為什麼這樣」 → 拆 → 再決定要不要改。**

大比時只使用剛開始系統化的禁制理解，不是禁制威力突然十倍。

# 十一、最後一個月：中央集合

前兩個月結束，各域入選者、宗門天驕、散修推薦者前往中神州中央主要比試區。

這裡只是五域大比舉辦與交流的核心區，不等於整個中神州唯一中心。

越靠近：
- 大城更多；
- 古道統更多；
- 高境修士更常見；
- 跨域飛舟更密；
- 其他四域天驕大量出現。

東境門戶城是第一次尺度震撼；中央大比區是第二次。

# 十二、《五域前夜》值得完整寫

最後一個月不要旁白跳過。

所有天驕都到了，但還沒正式開打。

可有酒樓相遇、道場切磋、拍賣、論道、天驕榜、私下挑戰、朋友、敵人、各域文化差。

俞清漪等真正重要天驕必須在大比前就有重量，避免正式比賽才介紹。

# 十三、五域大比：沒有第三雷

陸沉此時應是：

> **成熟二雷三身**
> ＋
> **多年體修、丹、雷道組合與戰鬥累積**
> ＋
> **剛開始系統化的古神禁典理解**

但沒有第三雷。

若大比前同時拿禁典＋震魂，就會變成「新地圖刷兩件神裝再打 Tournament」，壓掉其他天驕，也縮短兩儀生命週期。

# 十四、保留敗俞清漪

陸沉一路走到高位，最後敗給俞清漪的九疊回潮。

他用成熟二雷＋初步禁典＋前面所有人生累積去碰真正天下同代，然後**輸**。

這一敗讓五域有重量。

第三雷不能寫成「輸了所以去刷更強裝備」，必須由另一條因果自然找回來。

# 十五、第三雷震魂放五域大比後

卷六戰葬只是第一次聽見戰死者殘念與特殊神魂雷性，陸沉與封寒都沒問名字，沒有取得。

經過東溟、百宗、歸宗、中神州東境、文奕、古神禁典、五域前夜與五域大比後，在某個大比後續事件／古戰遺址／魂禁事件中：

> **那個聲音再次出現。**

陸沉：
> **「我聽過。」**

若封寒在：
> 「嗯。」

這時才正式展開第三雷故事。

# 十六、為什麼震魂此時才完整

震魂的人生題是：

> **看見別人。**

戰葬時他只是第一次碰到別人的殘念。

到五域大比後，他已經看過太玄同代、東溟百宗、宗外散修、文奕、中神州各大仙家、五域天驕，也真正敗給俞清漪。

此時世界裡真的有很多「別人」了。

再取得震魂，人生意義才完整。

# 十七、推薦卷段（卷號待全書正式重排）

## 《神州東境》
- 抵達東境門戶大城；
- 公布三個月；
- 前兩個月自由；
- 群像分流；
- 陸沉進禁制師世界；
- 文奕碰撞；
- 古禁事件；
- 劫瘋文第一次真正同行；
- 取得古神禁典；
- 開始消化；
- 前往中央區。

## 《五域前夜》
- 最後一個月；
- 五域天驕全部匯聚；
- 仙家、古族、宗門、散修同場；
- 生活、切磋、論道、拍賣、試探；
- 俞清漪等重要人物先活起來；
- 正式大比開幕前收束。

## 《五域大比》
- 正式五域競爭；
- 陸沉二雷三身＋初步禁典；
- 不拿第三雷救場；
- 最終敗俞清漪；
- 大比餘波保留。

## 《震魂》（工作名）
- 大比後由既有事件自然牽出；
- 戰葬殘響回收；
- 第三雷正式取得；
- 不寫成「敗北後刷裝」。

# 十九、紅線

1. **禁都不是中神州中心。**
2. 中神州不能只剩禁制故事。
3. 古神禁典不是即時滿級外掛。
4. 五域大比前不取得第三雷。
5. 第三雷不是「輸了所以找升級」。
6. 自由兩個月不能所有主角團永遠同行。
7. 最後一個月不能一句「眾天驕到齊」跳過。
8. 俞清漪等關鍵對手必須在正式比賽前先成為人物。
9. 東境門戶大城再輝煌也只是邊境入口之一。
10. 中神州真正的巨大感應靠「文明密度與層級」，不是每一城都機械地比上一城大十倍。

# 二十、一句話版

> **東溟天驕被一起送到中神州東境，距五域大比尚有三個月；前兩個月眾人自由分流，陸沉因自己的禁制本事自然走進中神州強盛但並非唯一的禁制世界，與文奕從觀念衝突走到古禁同行，兩人合得《古神禁典》。最後一個月五域天驕在中央比試區匯聚，先活過完整的「五域前夜」，再正式大比。陸沉以成熟二雷三身與初步禁典一路打到高位，敗給俞清漪；第三雷不作賽前外掛，而在大比後由戰葬早已埋下的神魂殘響重新找上他，正式成為太古震魂雷。**
