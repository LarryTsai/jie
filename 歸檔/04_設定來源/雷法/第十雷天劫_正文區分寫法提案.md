### 0.1　已定邊界（各案共同遵守）

- 宇宙自然學留白：「天劫為什麼存在、大道有沒有意志」屬文明層路線圖最後一塊，本提案的雙關**不得回答這一題**。

### 0.2　碰撞窗口其實很窄

第十雷在正文**只在第 28 篇寫一次**（D088）。22、23、27 三段它還沒有名字，只是「胎」「剪不走的一絲」。所以：

- 第 1–27 篇裡出現的「天劫」**全部是通用詞**，不會撞。
- 真正會撞的只有三處：**第 28 篇守錨到簽約那一段**、第 28 篇之後的尾聲，以及設定檔（作者與寫手讀的層）。

## 二、三種區分策略

### 甲案　分層標記：名只在一處立，敘述改叫職

**做法**

1. 第 1–27 篇通用「天劫」照常用，不做配給。
2. 第 28 篇第十雷生成時，用一次**立名句**把名字和「第十雷」綁在一起，之後敘述層一律稱「第十雷」或它的位置與職（「劫核旁那一道」「記往來的那道雷」），**「天劫」兩字只出現在人物台詞裡**。
3. 立名之後，同一篇敘述層的通用義改寫「雷劫／渡劫／劫雲」，不再出現裸「天劫」。

**優點**：規則最簡單，寫手好執行；不必動任何既有設定或前 27 篇；名字仍是作者定的「天劫」。
**缺點**：只是避撞，不生意思。名字出現一次就退到幕後，像被藏起來；作者特意取「天劫」，這案沒有把這兩個字的重量用出來。台詞中的「天劫」仍可能有讀者第一眼讀成通用義。

**試寫（非正文）**

> 錨成立的那一息，劫核旁亮起一點光，不落、不散。後來九界新簿記下它的名字：第十雷，天劫。

### 乙案　通用詞讓位：全書敘述不用「天劫」，兩字留給第十雷

**做法**

1. 全書敘述層把通用義一律改寫為「劫」「雷劫」「渡劫」「起劫」「劫雲」；角色口中也盡量不用「天劫」，只保留極少數成語式的老話。
2. 第 28 篇「天劫」第一次作為專名出現，讀者看到的是一個幾乎乾淨的詞。
3. 設定檔中的通用「天劫」同步改字（清單見第四節之 2）。

**優點**：最乾淨，第 28 篇之後完全不撞；「雷劫、渡劫」本來就是修仙常用詞，讀者不會覺得少了什麼。
**缺點**：成本最高：要改十餘行設定，所有寫手要長期守一條「不准說天劫」的禁令。更大的問題是**欲蓋彌彰**：修仙讀者對「天劫」的通用義是先天的，就算全書不寫，他們看到第十雷叫天劫仍會想到渡劫；作者取名的回聲，被這案當成噪音刪掉。

**試寫（非正文）**

> 第三重雷劫壓下來時，他照渡劫三步把雷引進右臂。劫雲裡那一線生機，他看見了，沒有立刻走過去。

### 丙案　一名兩讀：把雙關做成第 28 篇的看點（推薦）

**核心想法**：通用的天劫是**天往下降**、只有一個方向的劫，落地後留下劫痕，記下「那一刻牽連了多少人」（修士遺痕與後手第 8 條）。第十雷天劫在渡口長出來，**記往來**，兩個方向都有。第 28 篇陸沉剛用過全書最像天劫的一招〈劫數〉（「你本無劫，我來了便有了」，劫痕七階「降」，全書一次），錨成立後，長在他身上的第十雷卻叫天劫，而且什麼都不往下落。同一個名字，從「降」翻成「往來」。這正好接住第十步「不改」：能降，不等於該降。

**做法**

1. **前 27 篇：通用詞配給，不禁用。**日常、戰術層寫「雷劫／劫雲／起劫／渡劫」；「天劫」兩字只留給**有分量的時候**（老修士的敬語、渡劫前清帳的老規矩、劫痕前的沉默、聖土「無天劫」的兩界對照），讓讀者把「天劫＝天往下落的那一道」記得很牢。不必改既有設定檔。
2. **第 28 篇守錨：〈劫數〉段敘述不寫「天劫」。**寫「劫印」「劫雲」「一重」；伏雷坳三讀寫「古劫」「劫痕」。這一篇的裸「天劫」兩字，**全部留給第十雷與它的命名場**。
3. **十雷一體時，胎沒有名字。**第 28 篇守錨中段以胎入局（D088 既有），敘述只寫「那一絲剪不走的」；**「天劫」這個名字永不出現在攻擊句裡**。名字只在錨成立、它單獨亮起而不殺之後才出現。
4. **畫面語法：直與橫。**通用天劫一律有劫雲、從上往下；第十雷**沒有雲、不下落**，在劫核旁、在渡口一進一出，像潮、像呼吸（候選，與 D072「只在劫核旁開出一條往外走的路，兩界之氣從那裡往來」一致）。讀者靠畫面就分得出，不靠解說。
5. **命名場：紀錄雙存。**第 28 篇簽約「紀錄雙存」是既有安排；第十雷的名字也用同一形式落地：
   - 九界這一端：陸沉說出「天劫」。九界修士聽見這兩字，第一反應是渡劫的那個天劫，背先繃緊。名字的重量來自前 27 篇的配給。
   - 聖土這一端：聖土修士突破無天劫（D051），他們沒有「天劫」這個詞，只知道他叫「劫」（第 8、17 篇「你說他叫什麼？」「劫。」「你說過你叫劫」）。所以他們那一卷記下的讀法，自然是「天＋劫」，像「劫那一邊的天」。（候選；聖土那一卷實際用什麼詞、怎麼音譯，依聖土譯名體例由聖土寫手配。）
   - 兩卷都不改。同一個名字在兩界有兩種讀法，**不合一，只往來**，正是第十雷的職。
6. **第一道往來：「是我」。**第十雷記下的第一筆是太宸主動送進來的認罪（D067 既有）。讀者自己會感到：從前是天把劫降給人，這一次是天把自己的帳交出來。**敘述不點破、雷不解讀**，第十雷只記下、不判、不揭（不越 D067）；這層意思是太宸自己說出口造成的，不是雷讀出來的。

**優點**

- 把作者取的名字用足：通用義不是噪音，而是第 28 篇翻轉的前提。
- 不必改既有設定檔，前 27 篇也不加禁令，只加一條配給慣例。
- 接得上既有的〈劫數〉「降」、劫痕「記牽連」、聖土「無天劫」、「你說過你叫劫」、簽約「紀錄雙存」、第十步「不改」，全是已有素材，沒有新增規則或能力。
- 名字在場景裡發生，不靠旁白解說。

**缺點與風險**

- **配給要寫手共同守**：若前 27 篇亂用「天劫」當口頭禪，第 28 篇的翻轉就沒力。需要 PM 在審卷時加查一項。
- **〈劫數〉與第十雷同篇**：寫不好會讀成「他用九霄降劫，然後長出一道會降劫的雷」。第 2、3 條就是為此而設，必須守。
- **聖土那一端的讀法**依賴譯名體例，可能要聖土寫手調整說法；若譯名上不成立，退回只寫九界那一端的繃緊反應，翻轉仍成立。
- **雙關不能說破**：不可讓任何角色解釋「天劫原來是天的劫」，更不可寫成天劫起源的答案。

**試寫（非正文）**

> 寇平提筆停在新簿「記者」一欄：「這要寫什麼？」陸沉看著劫核旁那一點，說：「天劫。」寇平的筆尖頓了一下；九界修士聽見這兩個字，背總是先繃緊。

> （同場，聖土那一端）翁蒂娜在她那一卷上落了另一種寫法，念出來，聽著像「劫那一邊的天」。兩卷都沒改。

> （〈劫數〉段對照）那一夜劫印在對方眉心亮著，他出手一次，雲裡就落一重。錨成之後，他身上新長出的那道雷，一重也沒有落。

## 三、推薦：丙案（吸收甲案的立名紀律）

**理由**

1. 作者自定「天劫」而不採三個無撞名的提案（交泰、問津、鴻爪），可見重量正在這兩個字的回聲；乙案把回聲當噪音刪，甲案把名字藏起來，只有丙案把它用出來。
2. 碰撞窗口本來就只有第 28 篇（D088 全書寫一次）。只要管好這一篇，加上前 27 篇的配給慣例，就能解決混淆，不必全庫改字。
3. 翻轉的每個零件都是既有 Canon：〈劫數〉的「降」、劫痕記牽連、聖土無天劫、「你叫劫」、紀錄雙存、「是我」、不改。沒有新增能力，也沒有新的真相層。
4. 第十雷仍然**不戰、不判、不揭**：名字不出現在攻擊句，胎入局時無名，命名後只記。

**從甲案吸收**：第 28 篇命名後，同篇敘述層要指第十雷時，仍以「第十雷」或「劫核旁那一道」為主，「天劫」兩字集中用在命名場與第一道往來那幾句，不散用。

### 給寫手與審卷的四條速查

1. 前 27 篇：日常、戰術寫雷劫／劫雲／起劫／渡劫；「天劫」只留給有分量的場合。
2. 第 28 篇：〈劫數〉段與伏雷坳三讀不寫「天劫」；裸「天劫」留給第十雷。
3. 「天劫」這個名字永不進攻擊句；十雷一體時胎無名。
4. 通用天劫有雲、往下落；第十雷無雲、不落、一進一出。不說破雙關。

另：避免「一天＋劫X」的斷詞撞；《天譴》照用書名號、第十雷名不加任何括號，兩者字形上分開。

## 四、既有檔是否要改字（只列不改）

### 4.1　丙案下：正文層不需改；設定層建議兩處加註

既有通用「天劫」全在設定與大綱，不是正文，也都在通用語境下自然成立，**不必改字**。只有兩處緊貼雷道討論，D147 之後作者或寫手可能誤讀成第十雷，建議主 Agent 加一個括註（例如「天地天劫（通用渡劫義）」），不改句意：

- `設定/04_修行/02_雷道/九霄劫雷.md:45`
- `設定/01_世界/05_聖土/諸神聖土.md:92`

可選：`設定/01_世界/04_勢力/仙庭與王庭權力根基.md:42` 的用語規則旁補一句「第十雷名天劫見 D147，正文區分見本提案」，讓用語規則有一個入口。

## 五、雙關能否成為故事看點：可以，但只到這裡為止

**可以做的**

- **方向的翻轉**：通用天劫往下降、記牽連；第十雷天劫往來、記往來。第 28 篇〈劫數〉是陸沉最後一次「降」，接著長出一道不降的天劫。這是第十步「不改」的實物。
- **生於渡口**：渡口是長子遇害的地方，也是簽約地（D066）。長出第十雷的是一座錨、一個渡口，不是天。名字寫「天」，誕生處在地上兩岸之間，這個落差讓讀者自己品。
- **兩界讀法**：九界聽見的是劫，聖土聽見的是他的名。紀錄雙存，不合一。
- **第一筆是「是我」**：第十雷記下的第一筆，是天自己送來的帳。意義由太宸的行動產生，不由雷產生。

**不可以做的（紅線）**

- 不讓第十雷讀出、映出或證明任何古戰真相（D067）；它只記經過錨的往來，從第 28 篇那一刻起算，**不回溯**。
- 不解釋天劫的起源、天地有沒有意志（宇宙自然學留白）；不暗示通用天劫是太宸或任何人造的。
- 不賦予第十雷降劫、判罪、審判、反彈天劫等能力；「天劫」之名不等於它能召天劫（比照九霄檔「不等於境界突破時的天地天劫」）。
- 不讓角色說破雙關，不寫「原來天劫的意思是……」式的解說。
- 不把第十雷與劫厄、走潮者的合一綁成同一件事（兩者同篇，但劫厄合一是厄自己的第三次意願，見第 28 篇作者定補註）。
