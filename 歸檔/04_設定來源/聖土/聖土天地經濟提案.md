# 聖土天地經濟提案

狀態：聖土寫手提案（2026-10-02），PM 派工（[文明層路線圖](../../../待整理/設定/06_待定與決策紀錄/文明層路線圖.md)第二梯隊「靈氣經濟學」的聖土一側）。**作者已裁定（2026-10-02，經 PM 轉達）：六題全數採甲。**三十二天一側見[靈氣經濟學提案](../三十二天/靈氣經濟學提案.md)（作者拍板中）；兩界照舊不換算、不並表。照 D073 的寫法：每件有現況、詰辯、方案、推薦理由、接口。

**要回答的問題**：聖土的「天地能量」是不是有限的；鬥氣、魂力、異火、魔核怎麼在一盆之內流動；誰握著閥；斷了以後人怎麼辦；高手是不是耗能大戶。

**用字**：聖土說「**天地能量**」（極濃、濃、中、薄、稀五等）〔既有〕，不說「靈氣」。本檔沿用。

**標記**：
- 〔既有〕：現行設定已有。
- 〔作者定〕：已拍板。
- 〔提案〕：本檔新設。
- **留白**：不硬補。
- 數字都是工作值，正文只寫概數。

**對齊的既有內容**：
- **D065**：兩界之氣同類，質地與流向相反，三十二天向極內收，聖土向外發散；天地補給不相容〔既有〕。
- **D063**：借力者壽短，同格壽元短於仙〔既有〕。
- **盆**：一片地脈自成一體，由盆頂向四方流下；盆頂最濃，宗門與大家族在那裡；盆沿變薄，是小國、自治城與冊外人的地方；全聖土約一百五十盆〔既有〕。
- **堰**：上游築堰（聚靈大陣），下游就乾；這是靈果山脈案的地理根源〔既有〕。卡洛陣會的大堰陣供門環西樞〔既有〕。
- **鬥宗以上長居「薄」以下之地，修為會慢慢鬆動**〔既有〕。
- **盆傾**：地脈改道，盆頂數十年間移動數百里，宗門只能搬山〔既有〕。
- **魔核**：一階至九階，百銖一當，三階核一當〔既有〕；聚靈室以魔核作燃料〔既有〕。
- **雷晶**：封合縫雷晶帶仙界道則殘餘，雷望衛特許配額〔既有〕。
- **魂晶**：北境魂晶礦〔既有〕。
- **異火**：「火生於聚取」，燧冊前段都在地脈匯聚處〔既有〕。

**不碰的東西**：
- 古戰、封合縫、帝路的真相不動。
- 西緣變薄是古戰的傷〔既有〕，只引用。
- 三十二天的第 2 件（生靈生氣）屬三十二天，本檔不跟。

## 第 1 件　天地能量是不是有限的

### 現況

- 天地能量五等；盆頂最濃，盆沿變薄〔既有〕。
- 上游築堰，下游就乾〔既有〕。
- 魔核、雷晶、魂晶都在流通，都有價〔既有〕。

### 詰辯

- **構築**：聖土的氣是**向外發散**的（D065），從盆頂往盆沿流下去。所以聖土的稀缺，首先是**位置**：你在盆的哪一層。
- **邏輯**：
  - 鬥氣修士是**借力**的（D063）：從天地吸進氣旋，以鬥技放出去，放出去的氣又散回天地。
  - 聖土修士的代價主要付在壽元上（借力者壽短），天地本身比較不會被「吃」掉。
  - 真正讓一片地變乾的，不是修士多，是**堰**：把流下去的氣攔在上游。
- **節奏**：讀者要記得住的只有一句：**盆頂生氣，地脈流氣，堰攔氣，獸結氣，人借氣。**

### 方案

**A（作者定）五個字：流、攔、結、聚、借**〔作者定〕

| 字 | 是什麼 | 例 |
|---|---|---|
| **流** | 地脈從盆頂向四方流下；每一盆每年流下的量大致是定的 | 柯涅斯「倒扣的盆」〔既有〕 |
| **攔** | 堰（聚靈大陣）把氣攔在一處；上游濃，下游乾 | 大堰陣；靈果山脈案〔既有〕 |
| **結** | 魔獸把氣結成魔核，是會走的存量；獵一頭，就是取走一塊地幾十年的積蓄 | 魔核一至九階〔既有〕 |
| **聚** | 氣在火山、深井、隕地匯聚，生出異火；火是氣的聚點，不是存量 | 「火生於聚取」〔既有〕 |
| **借** | 鬥氣修士吸進氣旋、以鬥技放出；借了大半會還，付的是壽元 | D063〔既有〕 |

- **流量有限**：一盆每年流下的量大致是定的。
- **存量可取**：魔核、雷晶、魂晶取一塊少一塊；其中雷晶**不再生**（見第 4 件）。
- **稀缺在位置**：同一盆裡，盆頂與盆沿的差，比全盆的總量更要緊。

**B 照三十二天寫「抽得比生得快就衰」**：不採。聖土修士是借、不是耗；照搬會讓聖土的天地也被人吃乾，與「借力者壽短」重複付了兩次代價。

**C 無限**：不採；堰、份額、冊外都沒有意義。

### 推薦理由

A 讓聖土的每一件「爭」都落在位置上：爭盆頂、爭堰、爭獵額。這與三十二天「爭流量」不同味，也正好接住「借力者壽短」：聖土把天地的帳記在人的壽上。

### 接口

[當代地理](../../../設定/01_世界/05_聖土/02_當代/當代地理.md)〇節「盆」補一句「五個字」；[修士經濟（三十二天）](../../../設定/01_世界/02_修仙文明/02_文明細則/修士經濟.md)不動。

## 第 2 件　一盆之內的循環

### 現況

- 盆頂是宗門與大家族；盆谷是王國與城；盆沿是小國、自治城與冊外人〔既有〕。
- 撫恤份額發的是靈脈份額、破境丹份、功法傳承名額、魔核與雷晶採集配額〔既有〕。
- 荊約獵額、中嶺配額、火口租、雷晶配額〔既有〕。

### 方案

**A（作者定）一條主循環、五個閥、三種出口**〔作者定〕

**主循環**：

```
盆頂（宗門據頂、築堰） → 盆谷（王國、城、藥田接支脈） → 盆沿（冊外、獵場、雷緣）
     ↑                                                       ↓
 份額、藥份回流盆頂                         獸結核、人獵核；核換當、當換丹
     ↑                                                       ↓
 冊籍人憑份額領丹 ← ← ← ← 丹路把盆頂的丹運到邊地 ← ← ← ← 公會以核入藥
```

一句話：**氣從盆頂流到盆沿，錢和丹再從盆沿流回盆頂。**冊籍決定誰在這條迴路上排得到。

**五個閥**：

| 閥 | 誰握著 | 做什麼 | 接 |
|---|---|---|---|
| 堰 | 卡洛陣會等築陣的宗門 | 攔氣；下游乾 | 大堰陣〔既有〕；〈傾堰〉〔作者定〕 |
| 份額 | 撫恤署、芸香席 | 決定誰領得到靈脈份額、丹份 | 冊籍〔既有〕 |
| 獵額 | 契約廳、布雷肯獸欄會、荊約簽約方 | 決定誰獵得到核 | 中嶺配額、荊約〔既有〕 |
| 火口 | 奧斯馬克鍛廳、王室 | 租火 | 火口租、喉穴輪租〔既有〕 |
| 雷晶 | 雷望衛 | 特許配額 | 雷晶配額〔既有〕 |

**三種出口**（盆裡出事之後）：
1. **搬山**：盆頂移了，宗門把護山大陣拆下來搬過去；十萬修士跟著走〔既有：盆傾〕。這是聖土的遷徙。
2. **爭堰**：上游加高一層，下游就告。靈果山脈案與卡洛陣會「把大堰再加高一層」都是這條〔既有〕。這是聖土的戰爭，多半打在議事桌上。
3. **下雷緣**：盆沿沒有份額的人，往雷緣、獵場、無主海去拿存量〔既有：採晶、獵魔、海王核〕。這是聖土的開荒。

### 推薦理由

五個閥都已經有人握著；三種出口都已經是既有的大事件（盆傾、靈果山脈案、採晶季），不必另立。

### 接口

[地理勢力與撫恤](../../../設定/01_世界/05_聖土/02_當代/地理勢力與撫恤.md)「八萬年來強者為什麼沒解決」可引主循環；[當代勢力](../../../設定/01_世界/05_聖土/02_當代/當代勢力.md)恩怨第一條（靈脈份額）可引「爭堰」。

## 第 3 件　高手是不是耗能大戶

### 現況

- 鬥宗以上長居「薄」以下之地，修為會慢慢鬆動〔既有〕。
- 聚靈室以魔核作燃料；Kell 中等聚靈室一日兩當〔既有〕。
- 中心城池有翼牌；鬥王以上入城須登記〔既有〕。

### 詰辯

- 聖土修士是借力：吸得多，放得也多。高手的吸納量陡增，但它要的是**濃度**，不是總量：在薄地裡，吸得再快也吸不到。所以高手的「大戶」，表現為**一定要住盆頂**。
- 聖土把天地的帳記在人的壽上，記在核上：高手閉關不是吃天地，是**燒核**。

### 方案

**A（作者定）吸納隨境界陡增，表現為「要濃度」與「燒核」**〔作者定〕

| 境 | 吸納量（相當幾個鬥師，工作值） | 至少要住在 |
|---|---|---|
| 鬥之氣 | 零點三 | 稀以上 |
| 鬥者 | 零點五 | 稀以上 |
| 鬥師 | 一 | 薄以上 |
| 大鬥師 | 三 | 薄以上 |
| 鬥靈 | 十 | 中以上 |
| 鬥王 | 三十 | 中以上 |
| 鬥皇 | 百 | 濃以上 |
| 鬥宗 | 三百 | 濃以上；長居薄以下會鬆動〔既有〕 |
| 鬥尊 | 千 | 濃以上 |
| 鬥聖 | 萬 | 極濃；與法則相融，所在之地就是它的脈眼〔提案〕 |
| 鬥帝 | 自成天地 | 不取（D065） |

- **借還**：鬥技一放，氣散回天地。所以一場大戰之後，戰場上的天地能量會濃一陣，戰後的地反而好修（數月）〔提案〕。這是聖土戰場的一個奇景，三十二天沒有。
- **閉關燒核**：突破時吸納數倍；盆頂不夠，就在聚靈室裡燒核補。一位鬥宗閉關一年燒掉的核，夠一座邊地鎮一冬的燃料〔提案，數量級〕。所以閉關是錢，也是冊籍的事。
- **入城**：鬥王以上入城登記翼牌〔既有〕；高手進城收斂吸納是禮〔提案〕，否則鄰居的打坐會被搶氣。

**由此解釋「宗門據盆頂、冊外住盆沿」**：
1. 高手要濃度，只有盆頂給得起。
2. 盆沿薄，鬥宗住久了會鬆動，所以邊地的強者少〔既有：邊地鬥王已是一方豪強〕。
3. 冊外人住在盆沿，修不快，便拿壽元與命去雷緣換存量。

**B 照三十二天，高手吃掉一片靈田**：不採。聖土是借、不是耗；高手閉關的代價在核與錢上，比「吃掉靈田」更聖土。

### 推薦理由

A 同時解釋了宗門據盆頂、邊地強者少、閉關要錢三件既有的事；又多一個聖土獨有的奇景（戰後的地好修）。

### 接口

[境界對照與跨界](../../../設定/01_世界/05_聖土/01_規則與跨界/跨界總則與限制.md)「補給率」可補「至少要住在」一欄；[當代生活](../../../設定/01_世界/05_聖土/02_當代/當代生活.md)聚靈室補「閉關燒核」。

## 第 4 件　四種存量：核、晶、魂晶、火

### 現況

- 魔核行情與用途〔既有〕；壓晶銖、製當片〔既有〕。
- 封合縫雷晶帶仙界道則殘餘，是聖土最乾淨的仙力補給，雷望衛特許配額〔既有〕。
- 魂晶出北境魂晶礦〔既有〕。
- 異火之地多半不收服，強者寧可控地租火〔既有〕。

### 方案

**A（作者定）四種東西，四種帳**〔作者定〕

| 存量 | 從哪來 | 會不會再生 | 用在哪 | 誰握著 |
|---|---|---|---|---|
| **魔核** | 魔獸把氣結成核 | 會：獸還會長，只是慢；獵得比長得快，獵場就空 | 錢（當）、聚靈室燃料、丹、兵器核、門環陣盤 | 契約廳、獸欄會、荊約〔既有〕 |
| **雷晶** | 封合縫雷域，古戰仙界道則的殘餘 | **不再生**〔提案〕：八萬年前那一場留下的，採一枚少一枚 | 陸沉的補給；雷晶不能用來鎮陣樞（R8）〔既有〕 | 雷望衛〔既有〕 |
| **魂晶** | 北境魂晶礦，魂力沉積的結晶 | 慢到可視為不再生〔提案〕 | 魂器、魂龕、龕線（作者定）、養魂 | 伊爾瓦魂院、諾洛兄弟會、德雷凡王室〔既有〕 |
| **異火** | 氣在地脈匯聚處生出的火 | 不是存量，是**聚點**；火在，氣就一直在那裡聚 | 租火口、契火 | 宗門、王室〔既有〕 |

- **雷晶不再生**這一條，讓雷望衛的配額有了最硬的理由：它守的不只是安全，是一筆用一枚少一枚的遺產。
- **為什麼聖土拿核當錢**：魔核是唯一會再生、可分級、又能久存的存量〔提案〕。三十二天妖獸無核（D077），所以三十二天沒有這種錢。

**B 雷晶會再生**：不採。雷域每年長出新晶，雷望衛的配額就只是保護採晶人，少了「遺產」這一層。

### 推薦理由

把四種東西的帳分清楚，聖土的錢、丹、魂、火各有來路；雷晶不再生，替第 27、28 篇「往來」之後雷晶會不會被搬空埋下一個長遠的問題。

### 接口

[雷與火](../../../設定/01_世界/05_聖土/01_規則與跨界/雷與火.md)「雷域」一節補「雷晶不再生」；[當代生活](../../../設定/01_世界/05_聖土/02_當代/當代生活.md)第〇節通貨補「為什麼拿核當錢」。

## 第 5 件　諸洲各自的天地節律

〔既有，本件只把它們排在一起，看成同一套經濟的五種氣候〕

| 洲 | 天地 | 經濟上的事 |
|---|---|---|
| 柯涅斯 | 一大盆，盆頂極濃，邊地中到稀；西緣是古戰的傷 | 堰與冊籍 |
| 尼倫斯 | 全聖土最厚，大盆最多 | **盆傾**：盆頂移動，搬山 |
| 努瓦羅 | 濃而躁；引火帶 | **齊明**：火脈上湧一月，野火遊走 |
| 茵布瑞 | 隨季節起落；地下魂晶谷四季恆濃 | **大長夜**：長夜三年，鬥宗以上修為鬆動，退進魂晶窟 |
| 廷德拉 | 中至薄，越近東岸越稀 | **退霧**：虛岸露出，下岸採虛晶 |
| 踏石群島與無主海 | 海面薄，島頂中至濃，深海濃 | **大迴流**：海王上浮；九階海王核能讓小島國多撐三百年 |

**一句話**：每一洲都有一個「天地自己動起來」的大事件，那一季就是那一洲的經濟大事。

## 第 6 件　與三十二天的可寫差異（不換算）

| 處 | 三十二天（提案中） | 聖土 |
|---|---|---|
| 用字 | 靈氣 | 天地能量，五等 |
| 稀缺 | 流量：抽得比生得快就衰 | 位置：盆頂、盆沿、堰 |
| 修士 | 用氣 | 借氣；代價記在壽元上 |
| 高手 | 吃掉一片靈田 | 要濃度、燒核 |
| 存量 | 靈石、仙晶、妖獸部位 | 魔核、雷晶、魂晶；異火是聚點 |
| 錢 | 靈石 | 魔核（當、銖） |
| 遷徙 | 脈衰則遷 | 盆傾則搬山 |
| 戰場之後 | **留白** | 地反而好修一陣（提案） |

**可寫的一幕**：陸沉在聖土閉關，雷望衛記下他燒了多少雷晶；聖土人問他「仙人閉關燒什麼」，他答不上來，因為在三十二天那叫吐納，不燒任何東西。
