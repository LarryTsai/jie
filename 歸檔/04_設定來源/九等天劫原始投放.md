# 《劫》｜九等天劫・萬古第一渡劫長線

> **作者新提案，非 Canon。** 供 AI 團隊與現行《劫》修行、雷身、命圖、渡劫年表核對後採用。  
> **作者硬要求**：天劫共九等；陸沉每次真正引劫都引來最高的**第九等**；雷身越多，整場天劫持續越久，異象越駭人；陸沉**每次渡劫都成功**，享受突破與淬鍊，極其強大、帥氣，卻常常傷痕累累。**不要安排渡劫失敗、補考或被別人救過關。**

## 一、最重要的戲劇核心

世人渡劫，是想撐到天劫結束；陸沉渡劫，是期待天地能將自己逼到何等極限。

他並非雷劫免疫：他的每具雷身都是真實本源，受創會牽動全體。他的享受不是痛苦本身，而是**在最可怕的天地淬鍊中，發現自己還能變得更好**。

全書標誌句候選：
- 「世人渡劫，求劫後餘生；陸沉渡劫，求劫後新生。」
- 「天下修士皆畏劫，唯有陸沉，見劫而喜。」
- 「他們在等雷停，我在等雷來。」

**不可寫成**：陸沉永遠毫髮無傷、天劫任他召喚、隨意搶別人的劫、每次都靠一招莫名其妙的新術渡過。

## 二、九等天劫：建議規則

| 等級 | 工作名稱 | 特色（候選） |
|---|---|---|
| 一等 | 凡雷劫 | 基礎雷罰 |
| 二等 | 靈霄劫 | 靈力與肉身共同承壓 |
| 三等 | 玄罡劫 | 雷罡入骨 |
| 四等 | 地煞劫 | 地脈與天雷呼應 |
| 五等 | 天罡劫 | 強宗天驕亦需慎重 |
| 六等 | 六極劫 | 多重劫象交替 |
| 七等 | 七曜劫 | 古代頂尖天驕級 |
| 八等 | 八荒劫 | 一界罕見 |
| **九等** | **無上天劫** | **天地最高劫等，陸沉每次真正引劫都在此級** |

**名稱全部待裁**。九等是「同境下的劫罰等級」，不是九個修煉境界，也不是九種異雷。普通人可能不一定在每次破境都引劫；要先核對現行世界是否存在這種通則。不可讓九等成為所有境界都必須有的硬規定。

### 兩個不同維度：劫等與劫時

- **劫等**：一至九，陸沉固定最高九等。不能憑雷身增加再升成「第十等」。
- **劫時／劫數**：陸沉的雷身越多，越多真實本源需要共同承劫，天劫的波次、劫象複雜度與持續時間就越高。
- **境界尺度**：同是第九等，神火劫與真仙劫的絕對威力當然不同；不能讓少年劫承受真仙級雷罰。
- **不採機械倍數**：不必寫「六具雷身就是六倍時長」。雷身本源、協同、雷種特性與境界共同影響時間；在正文用古籍記錄、日夜更替、旁人撤離與劫雲覆域表現。
- **天劫本身無人格**：不是天道嫉妒陸沉而加碼，也不是雷種自動召來新雷源。

### 為什麼第九等越來越駭人？

早年兩三雷身的九等劫，已令宗門長老驚懼。成年後多雷身共同渡劫，雲層覆蓋的範圍、不同劫象的交替、劫雷與命圖軌道的相互牽引，都遠超前人觀測。後期九雷齊備時，整片天地可能數度明暗，古籍中同等級的記錄也不足以解釋劫時之長。

**作者最終目標**：將陸沉塑造成有史以來遭遇最強天劫的人。前期先由宗門稱同境未見，中期跨域對比古籍，後期由見過古代仙劫的強者作出可信判斷。不要每場都讓路人重複「萬古第一」。

## 三、陸沉的渡劫四部曲

1. **準備**：主動挑遠離居民的劫地，安排撤離與外圍護持。因為知道自己引來的是九等，絕不輕率連累別人。
2. **期待**：雲層第一重壓下，別人發抖，他眼睛發亮；笑是對修行的期待，不是對危險的蔑視。
3. **承劫**：運轉既有《萬體鑄身經》與渡劫三步；雷身各自承擔真正的本源淬鍊，命圖協調分流，但不代替本人思考。天劫可以震裂骨骼、燒焦皮肉、擊散雷身外相，卻不能在作者要求下造成**最終渡劫失敗**。
4. **新生**：最後一道雷後，境界與所有應突破的雷身真正完成蛻變。他遍體鱗傷、站立不穩，卻帶著成功的喜悅。養傷是真實的，並非劫散即滿血。

**戰鬥高光原則**：不是他被打得很慘才有戲，而是每道雷都讓他用已學會的本領完成更驚人的淬鍊。不能讓旁觀者的驚叫取代真正的修行動作。

## 四、七個可回收的渡劫名場面

> **只是場面候選，不等於新增七場正式天劫。** 各境界是否有獨立天劫、雷身數量、現行年份與能力必須由 Agent 核實。特別注意：第一次聖土返界後約十九歲破尊者；九弱約二十歲半神火六雷；真一約二十四歲；天神約二十五歲；虛道約二十七歲半；斬我約二十八歲半；至尊與真仙另依現行時間。不能把九雷提前。

### A｜少年第一次九等：笑著迎雷

山門長老看著劫雲，立即清空數座山頭。陸沉站在山巔，原本就知道會有劫，卻沒想到天地回應得如此猛烈。第一道雷燒去衣袖，手臂焦黑。他看見雷身裡久困的一條承力脈絡終於鬆動，抬頭笑了。**首次名場面：不是不痛，而是他真的喜歡突破。**

### B｜六雷共同神火：黑水裡燃起自己的火

九弱沉船修行場中，六雷交替不斷，神火由陸沉本人維持。天劫落下，水面白亮，沉船內外宛如同時迎來正午。六雷身被逼得外相裂開，卻逐一完成同一境界的轉變。雷紋在焦黑血肉下亮起，劫火初燃。**「劫火生花」仍是候選，不可提前把雷花寫成已定 Canon。**

### C｜真一與天神：雷身越多，劫雲越久

旁人渡劫已散，陸沉的九等天劫仍一輪接一輪。有人以為天劫出了異常，老修士才發現：每具雷身都在承受真正的淬鍊。陸沉以命圖調整各雷身次序，逐一完成蛻變。**最後成功，沒有任何一具被留在舊境**。後續若有跌境，那是另起的故事，不能誤當渡劫失敗。

### D｜虛道：天地間的多雷星圖

命圖主星逐一亮起，八雷各循自身軌道，並非融合成一顆彩虹雷球。雲中劫象一層又一層變換，雷身各自應劫，外界從黃昏等到天明仍未散雲。劫身上的傷越來越多，眼中的興奮卻越來越明亮。最後八雷共同完成虛道突破。

### E｜斬我：捨去已經足夠強的自己

他不是被迫失敗後重來，而是成功渡劫時，主動放棄一種不再適合自己的舊承載方式。雷光擊碎外相，留下真傷。他完成斬我，沒有靠天劫免費抹掉曾經的傷痕。

### F｜九雷齊備：最長、最駭人的九等天劫

此場必須安排在**第九雷九霄已取得之後**的合法渡劫節點。九雷身分立，九種雷性各有本源，不是九道相同光柱。天穹從白日轉黑，又被雷光照成白晝；雲海一再重聚，古老強者觀測劫時，發現已超過已知同境紀錄。陸沉不只抵抗，而是主動借每一輪劫雷重鑄雷身。**最終九雷共同成功**，本人血染長空、身體幾乎無一處完好，卻仍笑著站起來。

### G｜真仙：萬古劫錄，未見此象

玄闕祖脈，九雷真仙大劫。第十雷此時**僅為胎，不得提前出戰**。古代觀劫者對照可靠記錄，確認劫等最高且劫時、劫象超越所知。陸沉以已有雷身、命圖與鑄身經共同承劫，主動撤去不再合適的雷身外形，完成新的重凝。最後一擊後，他遍體鱗傷、仙光初成，沒有失敗；旁觀者不是看到無敵免傷，而是看到一個人把極端危險化成極端成長。

## 五、九等天劫應該如何越寫越燃

| 維度 | 少年 | 成年 | 高境界 |
|---|---|---|---|
| 旁觀者 | 宗門長老驚疑 | 各界天驕、古族記錄 | 見過古代大劫的強者核證 |
| 劫時 | 超過同境常例 | 多輪劫象、日夜交替 | 持續突破古代紀錄 |
| 劫域 | 一處山谷或宗門劫地 | 跨山脈／廣域天地 | 依境界可至仙道尺度 |
| 雷身 | 少量共同承劫 | 多具分工承壓 | 九雷各循本源同渡 |
| 傷勢 | 焦黑、裂骨 | 雷身外相破碎、神魂承壓 | 本源受創、長時間養傷 |
| 陸沉心境 | 第一次發現渡劫樂趣 | 享受變化與極限推演 | 對天地之劫保持敬畏，仍見劫而喜 |
| 讀者期待 | 他能有多強？ | 這次會怎樣變得更強？ | 天地還能逼出怎樣的新陸沉？ |

## 六、對 AI 團隊的硬性要求

### Canon 核對

- 核對所有正式突破、是否確實有雷劫、年齡、雷數、雷身、境界、受傷與養傷安排。
- 九等天劫是新候選世界規則，**不可**未經作者批准便覆蓋其他修士的劫法、古籍或已定天劫機制。
- 不得把九等與九雷硬對應；一雷時也可以遇到第九等，九雷時仍然只有第九等。
- 不得提前九雷合一、天譴新階、第十雷生成；第十雷在第28篇錨成才真正生成。
- 《劫火生花》候選與本案可互相參照，但兩者尚未正式合併。

### 故事寫手

- 每場要有**震撼天地異象、雷身真正淬鍊、陸沉發自內心的喜悅、最後成功、可見的傷痕**五項。
- 不要寫渡劫失敗、借外人代渡、臨時補考或劫散即無傷。
- 同時保持差異：有的突出雷身數量，有的突出劫時，有的突出雷身重鑄，有的突出旁觀古修的震驚。
- 不要為了讓陸沉帥氣而讓其他修士全變蠢。普通強者怕天劫，是因為天劫真的可怕；陸沉也知道它可怕，只是比任何人更享受這種極限修煉。
- 高境界名場面必須有真正的新視覺，不只是雷柱更大。

### Reviewer 驗收

1. 讀者是否能記住這一場與前一場渡劫的不同？
2. 陸沉是否主動完成淬鍊，而非被動挨打？
3. 傷勢是否真實，且未偷換成失敗？
4. 九等的規則與劫時增長是否前後一致？
5. 是否有值得重看的帥氣畫面？
6. 是否遵守已定境界、雷身與雷種時序？

## 七、待作者裁定

1. 九等天劫的九個名稱是否採用？或只用一至九等，不另命名？
2. 「每次正式渡劫必為第九等」是否自第一次引劫起就成立？**本稿按作者目前明示採是。**
3. 劫時是否依雷身數量**單調增加**，還是受境界、雷種與雷身協同共同影響？**建議：大趨勢越多越久，不採簡單乘法。**
4. 「史上最強」要由誰在何時證實？**建議真仙或更晚，以古劫記錄及強者見證確認。**
5. 九等天劫是否只有雷劫，還可能有心劫、道劫等複合劫象？**建議高境界可有不同劫象，但仍以雷霆為陸沉最具代表性的畫面。**
