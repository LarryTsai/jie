# 《劫》｜第九篇《多宗獵殺與九弱沉船》
## 第一段：追兵入水

**連載試稿，非 Canon。** 接續《倒雷井三宗伏殺》。依 GitHub 2026-10-11 現行工作大綱：十九歲，尊者、六雷，尚未神火；費嶽、葛照庭、喬疏月已死，三宗循痕追索。陸沉仍有肩骨裂、肋傷、腕創與各雷身共同疲憊。新增對話與場面不改既有大綱的事件因果。

### 第一章｜黑水九弱

九弱的水是黑的。

不是污黑，而是水下太深，深到白日的光只照得見表層幾丈。三座半沉的聚落散在水脈間，殘柱上長著成片水絲，屋舍與浮架隨著水流慢慢移動。

陸沉坐在商舟尾，掌心按著右肩。

倒雷井一戰已過許多日，骨傷卻沒有因為離開古井便消失。舟身每次換向，肋側都牽出一陣疼痛。現存雷身分擔探路、警戒與休養，本源疲憊卻由各身共同承受。

「到九弱了。」船家說，「別在養絲場亂吐納。你抽空一段脈息，人家一季的收成都沒了。」

陸沉抬頭：「水也有人養？」

「養絲。這裡的網，能承器力。」

他下船，付清舟費。才沿棧道走出不遠，星羅便察覺上游有一縷熟悉的雷性回痕，被另一股法力牽著沿水流試探。

三宗的人，已經追來了。

他們沒有神通廣大到立刻知道他藏在哪裡。追索者持倒雷井留下的接觸樣本，沿一條條真實水道比對；也得乘舟、換路、消耗追香材料。

可只要陸沉再留下新痕，對方便能繼續縮小範圍。

他選了一座無人的浮架，刻下一枚匿雷禁腳，想借換水帶走殘留氣息。

「拿掉。」

鄰架上一名短髮女子正收著細網。

「這一季的水絲是我的。你那道禁會讓下一輪脈息沾上你的雷痕。追你的人一來，我的生意就毀了。」

陸沉看了一眼，收回法力。

「抱歉。」

「被追殺？」

「嗯。」

「那去別處躲。」

女子轉身繼續收網。兩件性質不同的器物在網上先後亮起，其中一件撤力時，另一件仍保持著自己的那一息。

陸沉目光微凝。

這種分載方法，竟與他一直想解決的六雷交接有些相似。

「這張網，賣嗎？」

女子回頭：「我叫阮小蓬。網賣，命不賣。」

### 第二章｜一片雲母換一隻廢籠

九弱沒有免費的藏身處。

租棚要錢，試器槽要錢，連下水用的舊籠都標著維修費。陸沉在水市看見一隻報廢的水籠，籠架還在，壞的是幾條互相牽扯的承力紋。

「不能載人。」賣籠老人說。

「我不載人。」

「你要自己修？」

「試試。」

陸沉拿出倒雷井所得三片雷載雲母中的一片。老人叫器材夥計驗過真偽與裂紋，才按價抵帳。

成交後，陸沉只剩**兩片雲母**。那兩片晴膜殘材仍另外收著，並非同一種東西。

他拖著籠子往下層走，遇見一個少年正練習在水流換向時固定籠索。

少年連續失敗兩次，第三次終於穩住。

「第三次比前兩次快。」陸沉說。

「不是快。」少年抬頭，「我等上一股水自己退一點，才接下一股。」

少年叫遲望，列陣後段。他想學會自己能維持的水下行法，以後接家裡修水籠的活。對這裡的水，他比剛到的尊者陸沉更熟。

他看了一眼舊籠：「底扣別照原樣裝。這裡的水不是它以前走的那條。」

陸沉點頭。

他花錢買來一隻廢籠，卻發現要在九弱立足，還得學不少東西。

### 第三章｜追兵抵達

三宗前鋒在養絲上游逐段查船、查新租棚。

一名神火護道人守住主渡口。他並不準備為追殺一名尊者就毀掉所有養絲架：「先查實路。別把整座水市都變成我們的賠償帳。」

陸沉正在廢籠裡試那枚換脈探針主芯。

星羅短促入芯，穩。

換成兩儀，尾管卻突然發燙。

他立刻撤力。

**單雷能承，兩雷交接仍不成。**

籠外傳來敲擊。

遲望隔著水喊：「有人在找新來的雷修！」

陸沉收起器芯，沿先前驗過的側隙出水。橋頭兩名追兵正迎面而來。

追香器忽然亮了。

短矛破空而至。

陸沉以已知落點避開第一擊，星羅辨出第二矛的實際供力，兩儀牽偏橋下一枚銅扣，借偏移的半步沉入黑水。

追兵欲追，另一人攔住：「下面是養絲場。你亂轟，阮家的帳算誰頭上？」

他們改走正常入口。

陸沉沒有因此擊敗追兵。他只是明白了：九弱有自己的規矩，規矩不是為了救他，也不會永遠護著他。

### 第四章｜阮小蓬的試網

夜裡，陸沉來到阮小蓬的器坊。

「租試器槽。」

「你的雷會燒網。」

「我賠。」

「賠得起？」

他放下換脈主芯與燙壞的尾管，說明各雷的外放尺寸、持續時間與退勢。

阮小蓬收了試驗費，讓他先送一道雷。

第一息，網穩。

第二息，仍穩。

陸沉換雷。

啪。

最小的一張試網燒穿。

阮小蓬把焦網丟在他面前。

「不是你單道雷太強。是上一道還沒真正退出，下一道已經進來。」

陸沉盯著焦口。

「能改嗎？」

「器可以改。可你若指望器替你把自己身體裡的承載全做完，這張網做不到。」

她指向旁邊工臺：「缺錢就修扣。九弱不缺想修行的人，缺能按時交活的人。」

陸沉收起器芯。

「好。」

### 第五章｜遲家的晚飯

幾日後，陸沉靠修好一批水籠短扣，換到第一筆工錢。

遲安海邀他吃飯。鄭絮在桌旁清理泡水符材，遲望則拿著剛買來的護渡耗材，反覆比對水路圖。

「你們一直住這裡？」陸沉問。

遲安海點頭：「住了很多年。」

「沒想過走？」

老人停了一下：「原本有機會。」

鄭絮替陸沉添一碗熱魚湯，沒有急著接話。

飯後，遲安海帶他看向遠處黑水中的殘柱。

「九渡沉船。有人說拿到一塊古符就能開整艘船。」

「真的？」

「假的。我修這麼多年水籠，只知道換流時有一處側隙。」

陸沉望向水底。

深處忽然亮起一線光，像有人把正午的日色藏在黑水之下。

那光只亮了片刻，便又沉下去。

### 第六章｜沉船裡的白晝

翌日，陸沉按遲安海說的路下水。

他沒有立即深入船艙。晁不疑留下的玉符只足以核對當年一處登船接點，不能當作全船鑰匙。無間也只能接已感知的近端。

水下殘柱密布，越往下越黑。

直到他看見那面艙壁。

**黑水深處，竟然有一片白晝。**

不是異火，也不是活人的神魂。一條舊供力脈把多年晨潮凝在壁內，四段乘客路彼此錯位。最深處，一棱骨形亮物藏在光裡。

陸沉凝神看了許久。

它似乎能讓一股力量退出之後，仍保存極弱的續勢。

他想到自己每次換雷便燙壞的器尾，心中生出真正的讚嘆。

可他沒有硬闖。

眼前第一段乘客路尚未完全露出，第二段的承力方向更無法確認。

他在已驗的外艙刻下測流記號，準備撤回。

這時，水底另一側亮起一道長長的舟光。

一艘窄舟沿著已知古脈穩穩滑入，舟首站著一名年輕修士。

那人沒有看陸沉，而是先看向艙壁裡的白晝。

「原來真的在這裡。」

陸沉收住雷絲。

對方終於轉頭。

「你也是來取晝息骨的？」

「我還不知道它叫什麼。」

「那現在知道了。」

年輕修士握住舟邊的器柄，並不急著出手。

「牧昭。」

陸沉看著他。

「陸沉。」

牧昭的目光停了一瞬。

「三宗要找的人？」

「是。」

「那倒巧了。」

他伸手按住舟首，一道已經送入器路的神火緩緩亮起。

「我也在找你。」

陸沉沒有退，卻也沒有拔刀。

因為他已經看出，這個人的舟路比自己熟得多；而對方尚未展開的那一道持續供力，正好克制他現在最不穩的雷勢交接。

水下白晝在兩人之間明滅。

陸沉知道，眼前這個人不是費嶽，也不是葛照庭。

這一次，他未必能贏。

**第一段完。**
