## 閱讀興趣先判

願意看這場。最想看第二輪：奧布里不再落腳接雷印，斷掉鎧外線、打掉他們驗好的地；封寒承認保不住原兩脚，貝提爾自己縮門換落處。低境修士失去原方案後仍有真能做的事，高境守庫者也付出自己家族河階的損失。這比反覆鎖住飛翼更有追讀力。

第一輪只是延誤一息，後兩輪敵人不重踏陷阱，主角組不能靠同一解法循環拖時間。結果是眾人守到記門今日一筆寫完；敵人仍能飛、仍有鬥氣撤走。三方都在爭自己的目標，不以突然心軟或耗盡敵人結束。

較弱的是第三輪有幾句重複保證低境不能硬承，可在正式整合時壓縮；但其中削石失手、門腳換位及高境實際接擊都要保留，不能只留下保證句。

## 供力、空間與時序

| 次序 | 場面事實 | 因果判定 |
|---|---|---|
| 開窗前 | 貝提爾自己驗〈閉門〉、供自身鬥宗鬥氣，門面含上沿；石只有本地石載，先試碎一塊，低境只保兩門腳 | 場域與承力先立，不臨場長出全能高境石陣。陽印、特許和古人都不供防禦力 |
| 第一輪 | 兩鬥皇先飛繞，落力被〈閉門〉接；奧布里落腳另借石傳側撞，陸沉只錯接那條外掛線 | 雷印未落氣旋、翼或肉身，本體鬥氣未降；一息是借地附力的延誤，不是低境拘住高境 |
| 同輪 | 封寒在門後削浮石、留下一層石座，貝提爾重落門；伊萊恩接賈戈外側／高處線，陸沉入中閘 | 陸沉開始缺席，不能持續給外戰施法；封寒止的是卸後石載，不是穿門震鎧 |
| 第二輪 | 奧布里斬外線、碎雷印石、飛回；伊紹爾改以自身鬥氣。敵改打門外石路，地震到門脚才卸大部 | 敵人識破原方案、仍有有效高境優勢，低境沒有無限鎖飛／擊斷自力 |
| 改局 | 封寒報舊脚保不住，貝提爾自己縮門移内腳；生只搬鬆石及傷者，挨卸後碎石，失護圈與丹 | 不是三人法力撐起門面；對方年輕人被救仍反對開門，醫治不換倒戈 |
| 高境交鋒 | 賈戈拆爐支架、轉向特許，伊萊恩捨料亲截，臂傷、薄壁毀；後只用一火守窄角 | 伊萊恩不是名義盟友。有限剩器／火路改變自己的選項，不隨後全額復原 |
| 四至六刻 | 薇恩手抖，兩鬥皇始終空中試門頂；貝提爾亲接並扳回門面，封寒等卸完再削石，生在内挪石護傷者 | 高境力始終由同境／高一境者接。低境沒有一面処理未卸高境掌力，一面又能處理兩門腳 |
| 出閘與落定 | 陸沉從入口出，陽印燒盡；阿勒隆才落封印，薇恩落定才鬆手；敵再攻仍由本土高境接住 | 映門不是提供援軍或新的跨境法力；守的是可完成的有限六刻及寫入時間 |
| 目的失敗 | 今日一筆已寫完，賈戈命撤，兩鬥皇仍可飛；護持者不追 | 此戰贏在守成，不等同殺敵／耗盡敵人 |

貝提爾的供力不是無限：來自自身鬥氣、每次偏撞需親自扳回，必須縮門舍外階，不能離柱追擊，也不能由爐替他續氣。稿沒有宣稱他一人能守全河階或打勝三敵。鬥宗一星對兩鬥皇的局部防禦有现行量級支撑；伊萊恩另拦賈戈，沒有把三敵集中給貝提爾。六刻是有限目标而非无限守住的保证，事件中的退位、失器與有限剩火都表明其過程耗損。
