# 地區路線圖

狀態：001–012 整合，2026-10-04；卷號見[現行對照](../../../大綱/00_全書骨架/卷號與篇號對照.md)，下方舊盤點卡是素材，不是固定行程。

## 一、現行路線

留舟島→太玄入宗／生活／兩儀／七峰／命藏戰葬→東溟行→百宗→歸宗→東溟交流中心→分段跨域實際旅程→中神州東境（距比三月，兩月自由）→中央前夜（最後一月）→登天域正式大比（二雷敗俞清漪）→報到前劫瘋雲地獄行（三雷）→正式四院五卷三雷生活→歸山→南荒四大幕（藏復甦、查驗、古今共存、無名者、第三幕千相、皇血後半）→天域結案／四雷消化→四院代表選拔→界槎中央界潮事故→深層雙岸無間（五雷）→域外九界大比→落潮首入聖土（六雷）→回九界後未滿二十飛升。

禁都只是中神州重要都城之一；天域不是仙界。第三雷地獄行、第五雷界潮均依最新來源，雙岸不再作千溪原取雷地名；千溪原照水尺仍保留。

西極主要人物地域弧在九界大比後，北天更後；原第 5 篇西極古路外緣醫所線僅是必要邊界探查，不等於提前完整西極主場。原醫所、溫棠、裴照川與照水尺物證不刪。後續聖土、下無極、上無極、八界、大羅與驤鳴依原篇路線，012 第八與成熟無間跨界機制待重製。

## 二、停留期的節奏公式

每一段停留，從該地區盤點卡裡取：

| 類 | 例 |
|---|---|
| 宗門 | 太玄宗七峰、東溟三大宗、文家、大衍宗、九鄉會…… |
| 遺跡 | 仙王遺跡（D092）、古戰遺跡、修士遺痕 |
| 禁區 | 觀古門古禁區、西極古路外緣古禁區、渡劫淵、聖土沉域…… |
| 生活 | 坊市、節令、宗門日常、喝酒、師兄弟、戀愛萌芽 |
| 坊市 | 賭石坊、拍賣場、黑市、靈鳶攤、契書市 |
| 主線 | 該段的主線節點（總稿） |
| 附線 | 長線副線 L1–L12、E1–E16；羅蘋與福爾摩斯 |

規則：主線節點只是骨架；停留期的大部分篇幅由其餘六類填，守「不連續四篇比賽」。
