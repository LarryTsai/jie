# 開篇第12章〈漂走的浮石〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。先讓拄杖的祁望第一次問「你還看見什麼」、再由鮑十一帶著繩示意位置詢問陸沉；冬天季後浮石載著偷拿份額的孩子往北灣外漂，陸沉從下面持續報方位，卓青依他指出的方向追上，托石救人後問「剛才誰喊的方向」。陸沉看見石底祖脈也動了一下，因不顧危險追報位置而被罰擦供桌一個月。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照「有人真的聽見、記得並依他的話行動」逐步累積信任。本章不是一場救援後大家立即相信陸沉：祁望先用朋友身分問前情，鮑十一以實物（短繩）對照他看見的位置；事件中卓青接受他報方位並追上去，事後才認出發話者。陸沉的神識第一次直接幫上別人，卻也因跑到低崖邊而受罰；所得是被人記住，不是拿到權力或免責。這種來回為第16章祁望替他喊、鮑十一信他鋪路，不借用原作情節或文字。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段。
