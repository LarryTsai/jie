# 開篇第8章〈多一碗〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。陸沉和父親一起和泥，抱怨氣味、學著攪勻；封泥剝開時他只看見一截發黃的骨頭，父親不解釋並重新封好。雨夜供桌多一碗粥，陸沉問由來、父親只說「規矩」，他想偷喝而被拍手背；不揭示粥碗的去向。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照人物長期生活中有會重複出現的日常和未說透的關係。本章不急著解釋骨頭或粥碗，而讓陸沉跟父親一起和泥、被要求先看再動手、在飯桌上試探家規；祠堂生活與修仙世界的未知同在一個家常雨夜。這種家庭記憶未替陸沉升境，但讓後續被拒、守望與返家能有具體舊事可回想。對照後保留未回答的問題，沒有用旁白告訴讀者碗為誰擺、骨頭是誰的，也不模仿原作橋段或文字。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段。

## 覆核

- 和泥、父親換封泥、匣口開一指寬、陸沉看見發黃骨頭、父親不說話並封回，均依第8章章綱；沒有推測骨頭來歷。
- 雨夜多一碗粥，陸沉沒有親手擺粥；父親只回答「規矩」，沒有連到第14章家規或說明粥的對象。
