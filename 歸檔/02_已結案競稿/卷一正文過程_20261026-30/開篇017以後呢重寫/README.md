# 開篇第17章〈以後呢〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱，合流第1–16章的兩條時線與已埋物件。觀潮夜驗外露錨扣、擦掉一符後只守樁，未翻浮石；鮑十一因不放心上鄰石守著；祁望上最歪的一塊。陸沉被留在家中，仍違禁出門，厄跟出來；他扶牆到坡腳後上不去，神識看見祁望繩扣泛紅、聲音傳不到，便放飛可用的靈鳶停在錨扣旁示警。鮑十一據此拉回祁望，繩斷、浮石與祁家份額落海；陸沉跪在第一塊歇腳石前，母親說經脈未復，他以指定原句問「現在不行……以後呢？」收尾。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照長篇的高潮應由此前的生活、關係、能力與人物記憶一同兌現。本章沒有突然給陸沉境界或力量；救援使用的是第1章修好的放鳶本領、第9章祁望送來並留在身邊的鳶、第11–12章形成的祁望與鮑十一信任，以及第16章已識別但未拆盡的斷繩符。陸沉無法爬坡，便改用能做到的方式讓別人看見危險；鮑十一憑過往相信這個信號，祁望仍失去家中份額，皮老鴉仍逃走。主角成長與代價同時落地，高潮不是免費勝利，也沒有複製原作人物、情節或文字。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段。

## 獨立審查與修訂

獨立Reviewer認為祁望家失去最後份額後，陸沉的情緒焦點偏快回到自己的經脈。修訂後把祁望父親收緊繩扣的動作，接回祁望先前說家中靠這一塊的話；陸沉看見後沒有硬塞安慰台詞，保留兩個少年尚未找到話說的狀態。待獨立Reviewer覆核。

## 擴寫後覆核

- 清晨查錨扣加入名冊、記號與隊伍催促；鮑十一仍逐一確認，孩子和家長的反應讓「守樁」成為實際工作與承擔，不只一句背景說明。
- 增補祁望沒看見坡下手勢、兩人各自握住鳶與護繩的距離；不是把救援寫成無聲默契已經完滿。
- 失去份額後，祁望父親先確認孩子無傷、鮑十一交出備繩，祁望解開陸沉手上的鳶線；損失留在家庭和朋友的互動中。

## 覆核

- 錨扣暗紅只被陸沉以神識看見；守樁者不會自動查石底；重補符僅一條，符合第14、16章與總章綱。
- 陸沉仍未能走上第一塊歇腳石，手腕鳶線有摩擦傷；母親所說經脈未復，未提前治癒。
- 可用鳶是卞老託祁望送來、陸沉留在床邊的那隻；燒穿鳶仍掛祠堂樑上，沒有混淆兩件物品。
- 鮑十一救回祁望，但浮石與祁家本季份額失去；陸沉沒有抓到皮老鴉，拾浮幫只被按倒幾人。
- 章末台詞與「沒人回答」均保留；未替主題作旁白解釋。
