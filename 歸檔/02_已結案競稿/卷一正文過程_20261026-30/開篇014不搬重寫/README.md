# 開篇第14章〈不搬〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。地裂後第四十六日，最後一批隔日採；鄰戶遷往西岸、觀潮執事說明坡封與勘裂安排，父親對冊記「陸家：不遷」，只以「家規」和「等一個說要回來的人」作答，不推理、不解釋。陸沉因傷不能出門，請母親代問祁望與鮑十一；傍晚聽到祁家仍要上、錨扣今晚會驗。燒穿鳶掛樑上由讀者先看見，陸沉沒有注意；夜裡父親照舊睡祠堂，他試「以力作骨」未成。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照外部世界需要持續有自己的日常與限制，不只圍著主角交付設定。本章讓鄰戶收拾搬遷、執事逐戶登冊、祁家依賴最後一份浮石收入、鮑十一另外向觀潮確認錨扣，外面的決定不因陸沉受傷而停擺。家庭之間則靠父親修牆、母親整理藥包和代跑消息維持日常。陸沉沒有越界出門或憑空突破，只能等母親帶回兩句話；家規和浮石鐘因此落在人的選擇與生計上。對照後保持父親對家規不作說明，避免把長鉤變成設定解說。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。獨立審查建議不要讓「等一個說要回來的人」再疊一層主角揣測；修訂後保留章綱要求的原問原答，刪掉陸沉回想父親手停在牆縫、再決定推窗的解說。二次窄修再刪搬遷街談中與執事重複的封坡與尋脈師資訊，並將章末收回坡口守燈及祁望隔日上坡，讓倒數情緒成為最後落點。

## 覆核

- 時間為地裂後第四十六日；前章承諾「明天我去說」，本章只呈現隔日遷戶、執事登冊與母親代問，不替父親交代執行結果。
- 最後一批仍是隔日採收；觀潮說「繩樁有人看」，沒有混同「守樁」與「看石」。
- 家規原句只說一次，父親不知道等誰；旁白不把它連到供粥、指骨或其他原因。
- 陸沉經脈未復、扶牆傷後活動，沒有出門；「以力作骨」沒有凝成形。
- 燒穿鳶由讀者先看見，陸沉沒有往上看；衣物與傷勢未轉移到坡上。
