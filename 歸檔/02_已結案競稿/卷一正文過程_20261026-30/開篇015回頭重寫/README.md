# 開篇第15章〈回頭〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。九歲時用一年看攤錢買《無相離身卷》，卞老只收一半；當夜陸沉凝不出形、鼻血滴在卷上，母親把燈芯撥小。雷季孩子們去到伏雷坳口，陸沉數焦紋未完，沒有雷聲的白光落下，他喊回頭、祁望照做，兩人逃出後看見剛站過的石頭化成白灰；父親將陸沉拖回、手抵在他背後直到躺下，沒罵，從此睡祠堂。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照修行進度要有投入、失敗、代價與日後選擇，而人物關係透過共同經歷變得更牢。本章陸沉用一年的收入換取想學的功法，第一次練就流鼻血，沒有靠天賦直接掌握；之後在伏雷坳，祁望因前面累積的信任聽從他的警告，這次兩人共同逃離真正危險的地方。卞老不只是出售道具、母親不只解說修行、父親以陪護而非責罵回應驚嚇。對照後保留努力與失敗並行，不用一次異象替代修行累積。

擴寫覆核再確認了努力的日常成本：陸沉一年的看攤錢逐枚累積、幾次試練都失敗，母親只挪近水和布；進坳前孩子們爭「多一步算不算」、祁望拉住他別碰焦石，異象來時他又先拉同伴離開。共同冒險建立在熟悉的拌嘴和互相照看上。這些是本章採用作者所說的生活累積與人物來回的方式，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。

## 覆核

- 時線為九歲、春至雷季；功法只買到並開始嘗試，沒有凝出形或取得額外能力。
- 伏雷坳只到坳口；不寫「年輪」、不把光解釋成地裂光，也沒有提早讓陸沉打敗任何人。
- 祁望照陸沉警告回頭，兩人及其他孩子都離開危險區；父親手抵後背到他躺下，沒有斥責。
- 離身卷價錢與鼻血屬身體代價；陸沉不因此停止對身體修行的追求。
