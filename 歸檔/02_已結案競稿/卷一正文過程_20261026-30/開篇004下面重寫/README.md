# 開篇第4章〈下面〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。時間切回陸沉七歲的浮石季，將份額規矩落在沐潮生點名、繩扣與父親正在幫別家孩子繫繩的場面裡；祁望用玩笑維持兩人熟悉的相處，陸沉看得見浮石背面的草，卻碰不到它的影子。章末保留父親按住他的手和「你在下面等」原句。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，對照凌霄閣早期日常會讓人物在同一群體裡反覆相遇，互動有前情。本章和第1章的祁望不是兩段互不相干的友情介紹：第1章他在高處揮手，這章讓讀者看見兩人更早如何鬥嘴、祁望如何照看他，以及三年後那次揮手為何能被認出。對照後保留玩笑與小石子的來回，讓孩子間的相處不只服務於份額規矩；但本章仍是第一次呈現早年關係，競爭、分歧、共同冒險及彼此改變尚待後章逐步發生。此章也不安排境界提升；陸沉未入搬血，修行世界的規矩直接決定他能不能跟上同齡人。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。

## 覆核

- 時線標明七歲；浮石沿祖脈升起、沐潮生念名與數、「各家照舊」、祁望在繩上、陸沉數草並伸手拿繩均保留。
- 份額規矩由現場繫繩和孩子上坡呈現；父親正在替另一家孩子打結，之後按住陸沉的手，章末以章綱指定原句收尾。
