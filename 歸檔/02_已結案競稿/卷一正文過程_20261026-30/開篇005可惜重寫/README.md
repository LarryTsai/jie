# 開篇第5章〈可惜〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱，依季末撿到暖石、見到空手下坡哭泣的子弟和浮石背陰人影，再切到開春看骨、被評「可惜」、首次被叫「劫族的」的順序落筆。把看骨測試保持在現有設定：引靈氣看血氣承載，神識上、根骨下只是起點判斷，不能當終身定論。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照凌霄閣早期讓修行與生活交錯，也讓配角有自己的處境。本章的幾個孩子不是只排隊等陸沉測骨：空手下坡哭的孩子有自己的沉默，排隊的小姑娘反覆問何時輪到她；他們只占短暫場面，沒有搶走陸沉的視角。陸沉的境界沒有因「神識上」而跳升，強項與肉身承載不足在一次實際測試中同時呈現；後續需由他如何練、練錯什麼與誰一起生活來兌現，而非再用評語替代成長。暖石從季末被他帶到開春，是兩場間的物件記憶，也呼應第4章他在下面看浮石的經驗。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。

## 覆核

- 季末與開春兩場有清楚時間轉換；暖石由第一場留在陸沉口袋並帶入第二場。
- 看骨只呈現根骨承載不足、神識敏銳；測骨者明言這次測試不替一生定死，沒有創造額外根骨規則。
- 陸沉未入搬血；被叫「劫族的」是第一次，未提前賦予他成熟的族群觀念。
- 空手哭泣的孩子與排隊的小姑娘有各自動作，但沒有替他們建立超出本章需要的身份或後續承諾。
