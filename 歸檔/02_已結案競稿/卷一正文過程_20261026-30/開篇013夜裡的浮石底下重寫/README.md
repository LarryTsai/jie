# 開篇第13章〈夜裡的浮石底下〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。地裂後第四十五日前後，第三批已收、只餘最後一批。陸沉在床上以神識看見浮石底下被遮住的燈火移動，選擇扶牆出院門，厄鑽進衣襟；經過燒穿鳶原先落地處發現它不在，以為被丟掉；在祠堂後牆看見有人在錨扣附近作記號，其中一人轉過臉。他縮回牆影，父親把他帶回，手在發抖，沒有罵他，只說「明天我去說」。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照主角能力與日常處境一起變化。本章不讓陸沉忽然康復或直接破局：他的神識先看見移動的燈，肉身仍只能扶牆走十來天；他自己決定夜出，厄選擇鑽進衣襟；燒穿的鳶已不在，讓他在追蹤外人前短暫碰到失落。對照後把危險放在小家庭的夜間生活裡，父親的手抖與不責罵延續既有親情，不把救援情緒變成戰力突破。本章的反覆人物交會較少，因為章綱要求陸沉獨自窺見；下一章會把這次所見帶回白天的家庭與遷戶決定。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。

## 覆核

- 浮石批次鐘維持第三批收完、最後一批仍在坡上；沒有提前到封坡或隔日採收。
- 陸沉仍需扶牆，這是他第一次扶牆跨出院門；厄鑽入衣襟，沒有新增力量或對話能力。
- 陸沉只看見錨扣旁畫記號及一張臉，沒有破壞符、追逐、指認或自行查案。
- 燒穿鳶原先落在院子，現時不見；陸沉只能推測已被丟棄，沒有敘述真正去向。
