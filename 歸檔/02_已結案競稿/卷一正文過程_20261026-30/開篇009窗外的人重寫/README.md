# 開篇第9章〈窗外的人〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。祁望冒雨來訪，第一句仍是「你看見那個坐著的人了嗎」；他送來卞老託付、要保持乾燥的靈鳶，說明最後一批由祁家上；腿傷遇濕會痛，厄在被窩裡探頭。用一場探病和互相推開問題的對話，帶出陸沉在意的三筆關係帳，不提前解開它們。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照角色會因先前互動形成記憶，後續再遇時不必重新介紹關係。本章接第1章陸沉隔坡看見祁望揮手、接第4章的童年鬥嘴，也讓祁望與卞老各自做事：祁望冒雨來看人、卞老因停攤託送鳶，最後一批則牽涉祁家生計。話題從鳶、腿傷、浮石份額轉到「為什麼對我好」，祁望不肯給答案，人物因此留下可追的情緒與後續問題。厄出現後，祁望不是只負責送消息，還有自己的好奇與玩笑。修為仍停在搬血，身體受傷與日常照料構成當前限制。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。
