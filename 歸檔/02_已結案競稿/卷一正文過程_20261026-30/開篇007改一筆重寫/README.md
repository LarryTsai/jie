# 開篇第7章〈改一筆〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。時間明確回到七歲開春，看骨幾夜後，陸沉第一次未問母親便改補身丹方；他只改一味，不改全方。母親發現方子後停頓、先喝一口，幾天後以自己的筆跡採用新份量並收起舊方；父親看到新方，陸沉沒有注意。雨夜收尾接第8章。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照修行成長要在生活和反覆人物互動裡發生。本章沒有境界跳升，而是把陸沉「看見一處不夠，立刻動手改」的性格落在家裡一張常見的方子上，母親以先嘗、後採用的行動回應他的選擇，父親的沉默留給讀者看見。母親先喝在本章與第6章同形，但原因不同：此處她察覺兒子改過丹方，在採用前先親自試；第6章她面對的是一個拒喝藥的受傷孩子，先喝是為了讓對方敢喝。這組回返是刻意的前後照應，後續避免機械重複。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。

- 逐章時間錨標明七歲開春，接續第5章看骨後幾夜；不把第6章十歲養傷線誤當成本章前一日。
- 陸沉只動一味的一筆；幾天睡眠改善、母親採用配方、舊方收妥、父親看新方與雨夜均保留。
