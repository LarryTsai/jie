# 開篇第3章〈天會壞〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱，不更動事件、時間線、境界與揭露順序。讓地裂後的第一夜與清晨由陸沉的傷勢、父母照看、島上修補大陣與浮石季照常催促同時推動。厄只由陸沉看見並私下命名，不解釋來歷；「潮樞上坐著一個很老的人」只出現一次。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照凌霄閣早期人物會反覆碰面、互動帶著前情，修行與生活一起推進。本章是地裂後的急性災夜，不適合硬插競爭或長段閒談；改以熟悉的家庭照顧細節延續前兩章（母親摸額、數脈、等他喝藥，父親伸手又停），讓家人不只負責解釋異變。陸沉想起祁望並詢問他的去向，關係記憶延續，但本章沒有新增兩人的共同冒險或分歧；這些需在後續生活線實際發生。修為停在搬血，成長落在傷勢限制與不能參與坡上收石的現實中，沒有把進度標籤冒充突破。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。獨立審查指出臥床資訊在章末又重述「只能躺著聽」；修訂後以陸沉等不到祁望聲音作結，讓外部災情落回他掛念的人，而非重複傷勢限制。
