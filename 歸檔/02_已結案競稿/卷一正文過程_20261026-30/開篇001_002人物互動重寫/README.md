# 開篇第1、2章人物互動改寫

**狀態：** 第1章 v1.1、第2章 v1.0 已完成參考作品對照與內部覆核，待作者閱讀。正式正文與章綱連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本輪方向

依作者新方向，讓修行人生由日常和人物來回逐步長出；同門、外界人物與家人不只負責交付設定或推進單一事件。此次只重寫第1、2章正文，保留作者選定 v1.9 章綱的日期、事件順序、人物所知、地裂章尾與厄初現，不改正式大綱或全書總覽。

## 改寫落點

- **第1章〈卯末開市〉**：以陸沉和卞老共同開攤、修鳶時有來有回的教學與分歧、陸沉放鳶時與祁望隔空互應，以及父親在門口讓出位置的動作，呈現他已經生活在一群人之間。祁望的舊互動承接章綱第10章「我自己走」，沒有另造新人物或提前升溫關係。
- **第2章〈接住〉**：保留短促的異變結構，延續父母熟悉的照看方式、父親手上的新泥，以及前章帶回的燒穿靈鳶；不解釋指骨、光或小龍形物的真相。

## 參考作品對照

依作者對《武煉巔峰》凌霄閣早期生活與龍鳳傳承故事的閱讀印象，對照閱讀效果：日常中人物反覆碰面、互動帶著前情，修行成長由人物行動推動，宗門外人物也有自己的生活。這是本輪後續寫作的參照，不搬用原作人物、情節、場面或文字。

- 第1章已有同一個卞老和陸沉在開攤、修鳶、練手與收攤間持續來回；祁望的再次相見接上先前爬階時的互動；收費人以未報名身分出場，於第18章按章綱報名為包三郎；海族攤販在早市與收攤兩次出現，於第20章按章綱報名為鱗娘。這些回返有後續入口，不是新增一次性群眾。修行成長落在陸沉反覆失手、看懂停手時機、成功放鳶上浮石高度的因果裡，本章沒有境界升等，也沒有硬塞突破。
- 對照後補回收費人提到「拾浮幫逮了幾個、鴉沒抓到」的對話，讓外部威脅透過坊市常客自然進入當日生活；並讓早晨出現的海族攤販在收攤時再次經過，後續按章綱於第20、77章回來。
- 第2章是災變，不承擔長期交往累積；它以父母熟悉的照看動作承接家庭生活，保持短章突變效果。兩章只是長篇生活的入口，人物反覆交會與修為持續成長須在後續篇章逐步兌現，不能用這兩章宣稱已達長篇累積效果。
- 本次比較依作者在對話中指出的閱讀感完成；沒有把未直接讀取或未核實的原作細節寫成結論。後續每次實質正文交付均按同一流程記錄本稿證據、落差及修正／保留理由。
