# 開篇第16章〈斷繩符〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。地裂前三日、浮石季第六日，陸沉從坡下辨出繩樁內側的斷繩符，辨明受力時會從繩心燒開；他認得畫符者是七歲背陰影、八歲割繩的人。祁望替他向坡上喊，鮑十一信他並拉繩，救下另一家的孩子；拾浮幫幾人被捕，皮老鴉未抓到；沐潮生只說「看份額不看孩子」，腳下開始震。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照人物交往要反覆累積，也要讓主角的成長在故事中產生可見作用。本章回收第5章的浮石背影、第11章割繩未被相信、第12章鮑十一第一次聽他說，以及祁望從鬥嘴到在伏雷坳聽他喊回頭的過程：這次祁望主動替他傳話，鮑十一依他的判斷改變救援動作。所得是另一個孩子活著回到坡上、同伴與大人開始記住他的觀察；他仍未能抓住皮老鴉，也沒有勝過敵人。沐潮生把份額放在孩子前面，讓修仙社會的制度壓力和私人信任並置。對照後把成功限制在一個有代價、有後果的救援，不把它放大成主角能獨自查案或懲治劫修。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。

## 獨立審查與修訂

獨立Reviewer指出：鮑十一已叫人不要再踩該繩，孩子卻又被繫上同一根，指令失效沒有原因。修訂後具體補出守樁人開始拖繩準備打禁用結時，被名冊弟子叫去核份額；換班者沒聽見交代、只看見繩仍掛在待用樁上，遂照名冊繫給下一家。保留鮑十一即時發現、救援及事後封存查繩的主場面，待獨立Reviewer覆核此交接原因是否清楚且可信。

## 擴寫後覆核

- 救援後鮑十一檢查繩心、要求封存並改查扣眼；守樁者提出份額延誤的顧慮，讓制度壓力落在現場對話與決策上。
- 祁望照陸沉警告行動，並不是兩人已經無話不信；他以「你喊得像真的會出事」說明當下判斷，陸沉仍說不出畫符者的身分，也沒有證據。
- 陸沉看見祁望幫受傷孩子下坡，自己的緊張延續到手指留下白印；救援後果停留在人物身上，不以抓獲主謀收束。
