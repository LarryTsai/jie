**自查（03-03、03-04、04-02、04-04 四處因果）**：
1. 03-03：劫的快（舊口未關、新口先開）→ 兩口同換頂撞、右腕麻、停手 → 第二日改成先停再轉。動機出自 02-05 符湄那句，不再是提前替高潮備答案。
2. 03-04：文奕算出回灌 → 邴初自驗屬實 → 開口要人站回爐口（他要廢的事）／加厚綁緊、讓熱壓往自己身上走、自己當口 → 選後者、瞞住回灌（加厚本身公開，接 03-06 監工）。符湄拆架看出劫為快法改出的次序正是今年兩口同換要用的 → 「先停」。
3. 04-02：第四十一息回灌先往邴初身上走，他吃不下的才沿潮環壓向兩坊 → 文奕禁、封寒鐧接兩坊接口。
4. 04-04：回灌從第四十一息起一直往他身上灌 → 綁紋越咬越深 → 根骨被扯 → 生衣先問、他鬆開自己那頭、知秋斬肺那頭綁法的壽 → 拖出交丹棚 → 單肺裂沉 → 04-05 兩股熱壓回潮環，第六拍最猛。
四處互相接得上；與 03-06「加厚的肺，更沒有口」、04-01「加厚的那一層肺壁一聲都沒響」、05-02「原來是不該一個人扛」都不衝突。
