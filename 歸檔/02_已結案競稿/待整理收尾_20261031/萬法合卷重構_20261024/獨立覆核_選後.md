## 〇、結論：**有條件通過**

故事核心成立，不必重構，也不必重開競稿。乙底合併稿在讀者層比原稿和三份單案都好：中段有一條從第5章埋到第19章的懸念（第五拍），高潮把六條同伴線收在同一夜，〈劫的右手〉仍是全篇最強的一拍。

但這份稿還不能交作者看，更不能拿來釘板。有兩個高級問題要先修：

1. **第22章〈右手〉的機制和〈第一重〉原文相反**（問題1）。全篇最強的一拍，建立在一條與前篇矛盾的理由上。
2. **生衣那一條終身代價只寫在大綱第五節，章綱沒有任何一章演出來**（問題2）。照章綱讀的人，到第1章已經看到右臂垂著，卻不知道是誰、在哪裡、為什麼不准抬；高潮的賭注沒有在場景裡立起來。

另有一條流程上的高級缺口（問題3）：總覽第84A列仍是重構前內容，違反根 AGENTS 的總覽同步規則。這條不是故事問題，但沒修之前不算收尾完成。

其餘是中、低級窄修。全部可以在原結構上處理，不動五幕、不動勝負、不動任何同伴的勝法。修完之後，由未參與修寫的人再實讀第14、21、22章和新增章，就可以關閉。

**第九節六點的逐項判斷**：

| 第九節要查的 | 判斷 |
|---|---|
| 第22章〈右手〉是否仍是全篇最強一拍 | **是**。但它的理由要按問題1修，否則老讀者會在這一拍出戲 |
| 主卷試改成符湄勝陸沉後，是否搶走了高潮 | **沒有搶走**。第9章是第二幕的中點，勝負是技藝評比，而且符湄那句「我不假設誰摸得到」就是高潮的題目，反而替高潮蓄力 |
| 生衣只剩一條後，「隔著半個灣」是否仍成立 | **成立，而且比四條件好**：她看見的是他守住她唯一定下的那一條。前提是那一條要有一場戲（問題2），還要把她在高潮裡的位置排順（問題5） |
| 第二幕七章是否都有劫的選擇 | **字面上都有**，而且第7、9、10章是真選擇。但十七個「劫」行裡，有三次是「到門口、不進去、先走」的同一個動作（問題7） |

| 總覽連結是否可開 | 篇內連結可開；**總覽第84A列內容過時**（問題3） |

## 一、讀者角度

### 想不想讀

想讀。閱讀欲望約 7/10。第一幕和第五幕略低，第三、四幕高。

### 中段牽引

成立。第5章奚箴說出「最高拍是第五拍」，第15章文奕算出單肺會在第五拍回灌，第16章奚箴量到「第四十一息」，第17章貼出班冊。一個數字被一步一步收窄，讀者知道那一夜一定會出事，只是不知道誰撐得住。這是三份競稿裡都沒有做到的中段懸念。

第二幕的弱點在節奏：第5–11章是七條線輪流各得一場，每章都完整，但第8章（丹棚）和第11章（坊底對紋）推不動主懸念，讀起來像在等。

### 高潮是否兌現

兌現。邴初的肺先真扛住四拍，「世界作證的是他」。第五拍回灌時，每位同伴用的都是前面讀者親眼看過的那件本事：文奕的禁、奚箴的數、駱霜的劍意加上封寒驗過的那一場、雲行從魏班那裡學到的規矩、符湄喊的那個次序。沒有一個人是臨時變出來的。劫的右手抬到一半又放下，這一拍的情緒是全篇累積出來的。

### 最好的場面（保留）

1. 第22章〈劫的右手〉：「沒有一處在等他。」魏班說「換。」
2. 第13章〈第三次〉：「你問的是他要不要好。你沒問他要不要你。」接全書紅線。
3. 第21章〈肺心〉：生衣先問「要我救嗎？」，邴初「這輩子……從沒有人在動他之前先問過他」。這一句也替第13章收了尾。
4. 第5、16章奚箴：「你算得很對，算的是去年的海。」接著她一個人下潮三夜。
5. 第1章船尾：「你看出來了。」「嗯。」「不說？」「妳沒問。」

### 最容易棄讀的地方

1. **第4章〈兩種爐〉的收尾句**「大會的爭題收成一句：一隻肺扛，還是三十六個口輪」。這是作者在對讀者講題目。前面邴初那句「我扛得好，他們就不必站在爐口」已經夠了，這一句可以刪。
2. **第24章〈第一行〉的入卷清單**：五家各自署名、記序、落款，讀起來像帳目。保留魏班三句和「說者魏班」，其餘併成一兩句。
3. **第14章的括號**「萬戰幻境的低量器影，不含劫藏、非對手映身」是規格說明，正文不會這樣寫，大綱也可以拿掉（照「故事優先於規格」）。
4. 第二幕劫在旁邊看的時候（見問題7）。

## 二、問題清單

分級：**高**＝不修不能交作者看；**中**＝釘板前要修；**低**＝順手修或記入待核。

### 高

**問題1｜第22章（大綱第七節〈劫的右手〉）：右半身被寫成「讓壓力穿過自己的那一側」，與〈第一重〉相反**

- 證據：章綱第22章寫「右半身是讓壓力穿過自己的那一側，一抬手，整座第二坊的回灌就從他身上落進海裡，像斷峰定」，大綱第七節同句。〈第一重〉場景概要原文是：祁鈞專打死軌，右半身九雷輪轉斷一拍；陸沉「從第十雷那一位『往來』放出去：壓力從劫核旁那條路經過他……死軌沒有補，也不需要補。卷宗裡最準的那一頁，打在一個他不再用來承重的地方」。斷峰定的穿過走的是第十雷那一位，死軌側正好是**不再用來承重**的地方。
- 影響：全篇最強的一拍，偏偏是讀過〈第一重〉的人最容易出戲的一拍。也連帶模糊了生衣那一條代價的意思：她禁的是右半身再承真仙之力，不是禁止讓壓力穿過去。
- 最小修法：改成「他知道怎麼做：像斷峰定那樣，從第十雷那一位讓回灌穿過自己落進海裡。可是要接住這麼大的壓，九雷得同時作主；九雷一齊作主，右半身就得承真仙的力，那半拍就跟他一輩子。」右手抬到一半的動作保留，賭注改成「抬了，回灌會沒事，那半拍就是終身」。大綱第七節同改。

**問題2｜章綱沒有生衣那一條的場面（N+3–4 路身出口核傷）**

- 證據：大綱第五節有完整的場景和台詞（「右邊這半身，三個月內不准再承一次真仙的力……」「左邊夠了。」「我跟著。」），章綱第1章卻直接從客舟開始，第一句就是「右臂垂著不動」。全篇的賭注、第22章的抬手、第26章的「那一條守了」，都靠這一場成立。
- 影響：照章綱寫正文會漏掉高潮的前提，第26章的收尾也失去回聲。生衣主動到斷峰群、按了很久、只說一句，這一幕本身就是感情線（仙途讀者斷層第1條）最好的一筆，不該只留在大綱裡。
- 最小修法：增一章放在第一幕最前面（見第四節建議），把大綱第五節的場景原樣移進章綱。不改台詞、不改時間。

**問題3｜總覽第84A列仍是重構前內容（流程缺口）**

- 證據：總覽第182行仍寫「生衣四條件下出手」、韶照微、郗泊、阮隰、梅伯衡、棠禾、嚴屹、禚定瀾、擋嚴屹、護標局、翻盤勝郗泊、阮隰古契。融合紀錄第六節已經承認未改，交主編處理。
- 影響：根 AGENTS 的總覽同步規則要求「同一次提交」同步。作者看總覽時會看到一篇已經撤用的故事。
- 最小修法：照融合紀錄第六節的建議文字更新第182行。缺口欄加上本覆核的未結項。

### 中

**問題4｜第14章練功房：右手刻紋讓高潮的賭注變得含糊，而且法器級反震就「斷了半拍」，和損傷的定義不合**

- 證據：第14章第一日「反震沿刻紋的手走進右腕，死軌側輪轉斷了半拍」，第二日改成「左手刻、右手只扶」。損傷的定義（大綱第五節、〈第一重〉所得）是「九雷同時作主時仍斷半拍」。第1、3、10章一路寫右臂不動、左手夠。
- 影響：①讀者要問：他整季守著右臂，第一日為什麼又用右手刻？像是為了製造代價才讓他犯錯。②法器級供量就讓死軌斷半拍，等於說傷比定義的更脆。③讀者已經看過他用右手做事，第22章「抬手」就不再等於「破戒」，問題1的賭注更模糊。融合紀錄補的「法器級反震，不是真仙之力」修好了生衣那一條的帳，但沒有修好這三點。
- 最小修法：第一日就是左手刻、右手扶器；反震沿扶器的手進了右腕，右腕麻半日、他當場停手，不寫「斷了半拍」。第二日只改次序（先停舊口，再轉新口），不改手。生衣當晚按腕那一筆保留。大綱第八節「失去：右腕反震半日」不動。

**問題5｜第20–22章：生衣在高潮裡的位置前後不順**

- 證據：第20章她在丹棚「接最重的」；第21章她走到第一坊肺心，把邴初拖出來，「單肺在第五拍末裂成三截」；第22章「回灌最猛那一陣」，她又「半個灣外……從丹棚抬頭」看見他的右臂放下。回灌最猛是在第五拍第四十一息到第五拍末之間，還是單肺裂了以後？章綱沒有說。如果是前者，她正在肺心。
- 影響：「隔著半個灣」是第87列道侶要回想的那一眼，位置不能含糊。
- 最小修法：在第22章開頭點明時間：「單肺沉下去之後，回灌失了源頭，反而最亂；第六拍是最猛的一陣。」生衣把邴初交給丹棚之後回到自己的爐前，才有抬頭那一眼。或者把第21、22章的順序寫成交錯。

**問題6｜大綱第二節人物表的「與劫的差距」大境數算錯**

- 證據：境界順序是天神→虛道→斬我→遁一→至尊→真仙（[境界與能力尺度](../../../../設定/04_修行/01_境界/境界與能力尺度.md)）。表中生衣天神後段寫「低兩大境」，實際差五個大境；封寒、駱霜、符湄、寧枕微都是虛道，寫「低劫兩大境」，實際差四個；文奕九界尊者後段寫「低劫三大境」，從尊者算到真仙差八個。[人物境界登場紀錄](../../../../大綱/00_全書骨架/01_人物線/人物境界登場紀錄.md)第79、117、208、231、253行照抄。同檔第73行已有2026-10-24勘誤先例：封寒對劫「高五大境（列陣→尊者→神火→真一→天神→虛道）」，是逐境算的。
- 影響：D162 要求讀者讀得出差距。這一篇差距最大的時候，正是劫「不出手」最有分量的時候；差距寫小了，等於把主角的克制寫輕了。
- 最小修法：改成實數，或改寫成「低劫四境（虛道→斬我→遁一→至尊→真仙）」這種寫法。登場紀錄五行同步改。

**問題7｜劫的選擇有三次是同一個動作：到門口，不進去**

- 證據：第6章「夜裡來棚外看了一刻，沒進去」；第12章「送酒到棚門口，沒進去看他的傷」；第16章「在岸上守著她下潮的繩，她上來時他已經走了」。再加上第8、13章兩次「把身體交給別人說話」。
- 影響：乙-6 字面上做到了，讀起來卻是同一種克制重複了五次。讀者會覺得主角在這一篇只是一直在退。
- 最小修法：刪第6章那一行。第10章他自己走進棚裡排班，正好是這個動作的收尾；第6章先讓他沒來過，第10章的走進去才有分量。第12章改成他進去了，跟封寒說一句跟劍無關的話。第16章保留：他守繩卻不下去，正是讓奚箴的勝屬於她自己。

**問題8｜第85–88列的加句一句都還沒落（鉤目前只活在本篇）**

- 證據：大綱第九節〈落地狀態〉已經如實寫明。逐列對過原文，預定加句都只加不改：第85列原文「第一爐在重壓下炸了……她改了火序」，正好能接「先熄舊火口、再起新火口」；〈潮門上〉扣腕那一段可以加按右半身一筆；第87列〈道侶〉「自己走了三百里」可以加一句回想；〈古路亮了一夜〉原文已有「每站有燈戶」「雲紓那一脈的燈戶」，換班規矩接得上；第88列丹堂原文寫母親與徒弟，加寧枕微一句不衝突。
- 影響：D172 八問第2、7兩題目前不成立：本篇的後果還沒有寫進後面各篇。
- 最小修法：主編照融合紀錄第五節的表另派，標「候選・待作者看」。第86列「燈戶分班，他才走得開去破境」要再讀一次：原文雲行是在燈院裡、鑑月陪著破境，並不需要「走開」，建議改成「燈戶分了班，他才有一整夜可以拿來渡劫」。

**問題9｜修仙感：換班規矩讀起來接近工坊勞動條例，有換皮的風險**

- 證據：第6章「一個口一刻；換班不看境界……被叫到的可以不去；到拍就停；停下來的不罰」；第24章公卷第一行就是這三句。走爐坊、銅足、潮環這些奇觀成立，但三十六口靠「人手壓著停口換」（第20章）。把熱壓換成蒸汽、修士換成工人，這一夜幾乎不用改。
- 影響：本篇劫沒有出手，仙感全靠世界本身撐。修仙愛好者讀到高潮，會問境界和神識在哪裡改變了選項。
- 最小修法（不加地名、不加品階）：①寫清熱壓是潮底地火靈脈被三坊同時抽起；爐工吸的是火毒，不是熱氣。②守口不只是手壓：化靈爐工要以自己的靈力和停口栓上的紋共鳴一刻，所以一刻就是極限，「換班不看境界」的意思是真仙守一刻也只能守一刻，因為栓只認一刻。③聚潮夜加一筆天地異象：三坊連通時潮環成一圈火環，從灣口看得見。④第22章劫左手壓口，可以寫他的雷血在栓上留下一道焦痕，下一個化靈學徒坐上來時摸到還是溫的。魏班三句保留，那是這一篇的心。

**問題10｜第21章知秋斬綁法：要多寫一句為什麼在她的能力範圍內**

- 證據：生衣天神後段，邴初至尊圓滿，單肺是中品道器。越境律第6條：知秋只拆尊者門或天神門，「不能秋虛道門：規則不是法的壽」。現稿的處理是「他自己鬆開肺上的綁紋，她用知秋斬的是……法的壽」。讀者會問：他已經鬆開了，為什麼還要斬？如果要斬，斬的是至尊的法，又怎麼沒越門？
- 影響：乙-4 的方向對，但因果還差一句。
- 最小修法：寫成「他鬆開的是自己那一頭；肺那一頭的綁紋還咬著他的根骨，那是一道有壽的法，不是規則。他不抵抗，所以這一刀不是對著至尊出的。」一句就夠，不必列條文。

**問題11｜第14、15、20章：萬年不裂的第二坊為什麼不知道「先停舊口，再轉新口」**

- 證據：第20章「兩口同時換會頂撞，這一夜第二坊沒有一個口頂撞」，靠的是劫在練功房驗出的次序。可是符湄的坊換口換了萬年。
- 影響：偵探式讀者會懷疑：要不是作者硬塞，萬年的手藝怎麼會缺這一步？
- 最小修法：在第14或15章加一句符湄的話：「平常一刻換一口，從來沒有兩口同時換的時候。」這一年有了邴初的單肺，第五拍回灌才第一次逼出兩口同換。這樣劫的貢獻正好是邴初造出來的新局面，因果更緊。

### 低

**問題12｜第18章「世界作證的是他」與〈第一重〉「這一刻，世界作證的是祁鈞」幾乎逐字相同**。乙-5 刪了「和祁鈞一模一樣」的旁白，卻留下一句同樣作用的回聲，第87列鍾離貫也有「世界替他作證」。全書已用三次。建議第18章改成合卷台下的具體反應，例如有人把押第二坊的籌碼換到第一坊，讓讀者自己比。單肺失敗的機制本來就和祁鈞不同：不是扛不住，是沒有出口、回灌到別人那裡。這一點才是本篇真正拉開的差距，應讓它更顯眼。

**問題13｜封寒的傷口數前後不一**。第19章是「掌上第七道舊傷再裂」，大綱第七節寫「掌上舊傷再裂一次」，第八節所得帳寫「左掌、左肩十一道傷再裂一次」。統一成第19章的說法：一道。

**問題14｜第26章「那十年後說清楚」和〈第一重〉〈藥圃那一夜〉的回收點不一致**。〈第一重〉寫「這句話他到第88列扛起兩重那天才答得出來」。生衣說「十年後」，等於約好出關時答，讀者會等出關那一場。建議改成「那等你說得清楚」，不給期限。

**問題15｜邴初四十五歲至尊圓滿，封寒是「鬥法殺伐同代第二」卻只到虛道後段**。這不是本篇造成的，邴初的至尊值在第68列和〈同代去向〉就有（登場紀錄 R-13）。本篇第3章寫「劫右手若能抬，他擋不過三招」，讓同代的境界順序在讀者面前很顯眼。建議記入待核：封寒的「第二」只限鬥法，邴初是器修，不以鬥法論；可以在第3或13章讓封寒或劫一句帶過。

**問題16｜文奕尊者的逆止禁擋至尊單肺的回灌頭（第19章）**。建議加半句：禁落在第二坊本身的逆止紋上（寶器結構），擋回灌的是坊，不是尊者自己的力。這樣不碰「禁域外不正面勝天神」。

**問題17｜陸沉人物卡第246行仍寫生衣四項放行條件、擋嚴屹、翻盤勝郗泊**（融合紀錄第六節已列）。同步時一起改。

**問題18｜D173 結構不符**（融合紀錄第七節已列）。本覆核不重複，只提醒：第四節的增章建議應在改結構時一併落位。

## 五、D172 第八節八問

1. **是否真正承接前文**：是。斷峰定的殘損、右半身斷拍、「渡」被仙域知道、邴初與駱霜的外圍一席、符湄玉河敗而不服、邴初第16與24篇兩次開口，全都帶進來，而且都改變了這一篇的選擇。**唯一例外**是問題1：最強一拍的機制和〈第一重〉相反。
2. **是否留下持續後果**：本篇內成立，每人帶走一件，所得帳清楚。**跨篇不成立**：第85–88列加句未落（問題8）。
3. **關係與處境是否合理變化**：是。生衣與劫從「妳沒問」到「聽話了一次」；文奕與奚箴從論敵到合署；封寒與駱霜從被驗到換我驗你；邴初從「三天替你接好」到「不該一個人扛」。劫的處境從「肯渡的人」多了一層「不必每處都由他渡」，正好替第85列「一個人肯渡，世界就會等他來救」先擺出反面。
4. **是否重複先前的成長模式**：部分重複。一者單扛、一方分擔的對照，與〈第一重〉同構，〈帝落大潮〉承重契又再來一次。本篇靠兩點拉開：劫這次是「不扛」；單肺的失敗是回灌到別人身上，不是扛不住。建議照問題12把逐字回聲拿掉，讓差異自己出來。
5. **設定、記憶、時間線是否矛盾**：有。問題1（死軌與第十雷）、問題4（法器級斷半拍）、問題5（生衣位置）、問題6（大境數）、問題13（傷口數）、問題14（十年後）。時間帳（N0、V1–V72、N+130、第84B列）沒有矛盾。
6. **有沒有已失效的伏筆**：本篇內沒有。原稿十人的鉤已整條撤除。要注意〈鑑月不去〉的第二壺酒：它在第6、25章被用到，但送酒那一場不在章綱裡，等於伏筆的起點不見了（第六節）。
7. **下一篇是否建立在本篇結果上**：方向正確（生衣火序、那一條守了、燈戶分班、邴初不鑄承器、奚箴校點），但要等加句落地才真正成立（問題8）。
8. **刪掉本篇會失去什麼**：仙途裡「重可以分成很多班」這個答案；生衣感情線從「先問」到第87列道侶之間最關鍵的一夜；邴初「不承重」的來源；文奕與奚箴錨網上端的起點；封寒第一次離開路身的一戰；雲行把燈分班的起點。本篇不能刪。
