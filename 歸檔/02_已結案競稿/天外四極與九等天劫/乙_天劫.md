# 乙案｜九等天劫：每一次雷來，他都主動把自己交給更好的自己

狀態：獨立長線競稿，非 Canon；2026-10-11。原投放完整讀取。九等全球規則、名稱、量級全部保候選；既有各正式突破年齡、雷數、共同突破與傷賬不改。不是新增七次正式雷劫的命令，更不把丹劫列成境界劫。

## 這個版本的差別

渡劫不是七次同一句“雷更大，人更慘”，而是逐次回答一個不同的修行難題：先敢引到弱處，再能維持六雷接續，再讓各身完整達標，再不依賴強身替弱身扛，再主動舍舊載形，最後把無法重得的失去仍帶進仙道。看頭放在劫本人看出、改一處、真做成的動作，不讓旁觀點評取代成長。

只用“一至九等”作工作記號，不急着另造九套劫名。每一**真正已成立的境界引劫**都在同境最高九等；同境最高不等跨境最高。雷身增多使劫時、波次和牽連複雜度長期增長，非固定每身翻倍，亦不憑境界下降後重破便一律創造更長的紀錄。天劫無人格，不“嫉妒”他。現行雷身機制有多身累積急增，本案不削成簡單相加。

## 實際來源先分清

現行武學譜把“第一次完整走渡劫三步在首訪聖土尊者劫”仍標候選；正式首訪已改爲十九歲返九界後才首次尊者。因此本稿不用那句舊候選證明聖土已經渡尊者。神火20.5、真一24、天神25、虛道27.5、斬我約28.45、遁一29.5、至尊約31、真仙34.5依總覽與各篇。

少年十五歲東境銘紋、十七歲選拔列陣已有突破故事，但是否有獨立天地天劫未由本輪來源確定。少年“第一次笑迎雷”只能附在經 Canon 核明的首次引劫，不能靠畫面好看新增每境必劫世界法則。前期一痕養血丹可引丹劫，D073有特殊丹劫機制，本案不把它宣稱全書第一場九等境界劫。

雷數不等雷身數：少年2雷已有3身；八雷時期有九身合爐；第22長亭一具本源永久被滅，第25九雷仍不是自動九具存活身。各場正式寫全體實際現存活本源，不造一個按九雷自動分出的九身擺陣。第十雷22成胎、28錨成才生，不承擔本案真仙劫戰力。

## 一｜十九歲首次尊者：把雷引到自己最不敢用的地方

**接口**：首訪聖土返九界後、正式登天追仇前；天然列陣→尊者，六雷，全現存身同域。前面急補法試練斷續是未達標練習，真正引劫後一次成功。

1. 劫先陪父母確認返家、把聖土快補留下的承力不均逐身驗好。殞星一路快不等全體能快；最慢那身真能完成自己的首尾，他才定引劫日，不讓母親留在雲下。
2. 普通劫地第一輪落地，山頭巖紋一層層亮起，遠處長老撤到外圈。劫用已有不崩和鍛骨煉筋承第一雷，發現自己一處舊短筋仍把力全送強側，焦黑的手臂實際抖動。
3. 他沒有笑着隨便吞雷，而是主動把下一擊接到那處已可承但從不肯常用的短筋，收掉一段強側旁接。疼痛和新通路同時發生，他第一次明白自己期待的是什麼，抬眼等下一雷。
4. 所有現存身逐一完成各自舊短處的導力，再同源承末波；命圖僅標位置，不能替它們練。第一場最高九等落幕，所有身真正尊者，沒有漏一具列陣在域外。
5. 新尊者能把雙刃兩處截續各施完整一輪，傷處出血後停手。祭煉、傷養與登天交通佔數旬，不引劫後當日就跳進復仇戰。首次喜悅留一頓家飯，他焦袖還未能穿過母親給的新衣。

**可重看畫面**：第一層雷後眼亮，不是全身無傷擺笑容；最後是六雷各自的新路亮在舊焦痕下。

## 二｜20.5神火：黑水中的火由他自己續住

**接口**：第9九弱沉船自己試槽，尊者→神火，六雷。正式源確認同域劫成本和共同神火，但高潮原爲平靜有慾望苦練；九等異象插入屬重構候選，不宣稱原稿已寫九等雷雲。

1. 先保正式三日、數旬的試爐學習：前雷尾勢散、下一雷接不上，器殼燒壞，而非渡劫失敗補考。各身全達標後開啓唯一正式神火夜。
2. 劫雲像把九弱水面壓成一張黑鏡，雷落使沉船內外同時亮到如午。不是天劫免費替他點神火；他自己已維持的微弱燃勢被雷壓得幾乎斷掉。
3. 不崩能承擊不能續法，他在第一雷尾自行收最亮的爆發，留已練成的可續細勢，下一身按真即時機親接。強雷不搶最慢身的位置，六雷依次完成自身火勢轉換。
4. 中段雷讓兩身外相開裂，活源仍在，傷痛全體承；他們繼續以各自現存可承形發收，不能說撤掉身就少算一份劫。船器分載網留作觀察，劫親撤它，自己的火仍燃一夜。
5. 末輪白光退去，黑水倒映的六色不混成綵球，岸上是他自己的神火。共同突破真成，掌裂骨焦還在。邀遲家喫飯這一已有喜悅保住；不能讓九等嚇哭全城再抵銷他想喫飯的心情。

**後用**：神火接續能以自己力量讓探器穩發收；後來甄四海至尊真敗、源傷、一季修復是另一事件，不倒填本場渡劫失敗。

## 三｜24真一：最慢的那身也親自走完

**接口**：第13程序未決，神火→真一，六雷；壓脈身必須實際歸隊達標，共同突破後才重駐。是否獨立九等天地場景須核該篇完整破境機制，不以“每次都九等”倒推出所有突破必引劫。

1. 他先讓壓脈身交班歸隊，不把長期守一處的實修假設爲自動同步；緩慢來源是它真實的疲勞和發收習慣。其他身陪練，只等它自己的達標，不傳感悟一鍵完成。
2. 真正引劫候選場中，雷雲落成六重可見的明暗環，並非六個分離小劫。強身試圖搶快接續，劫自己主動停掉已有的強路，不是被外人提醒才做。
3. 新劫要求的是各身真一完整凝貫，他把最慢身當成自己的完整部分，讓它先用已有讀、拆、本人短禁釐清一條實接；不是躲開雷、不是拿自己禁替自己免劫。
4. 全體完成新境發收，末波共同貫穿，成功後再駐壓脈身。劫站在燒黑地上第一次不急着看旁人的目光，只聽各身同一新節律；脣裂流血仍笑。
5. 生繼續自己的巡醫與異接觀察，沒有爲他代承天劫。數日神識和筋脈傷復實際佔程序未決後段，低量寶胚孕靈不會因一劫升寶器。

**差別**：等待與共同達標先完成，渡劫是主動驗證已做好之法，不用危險當臨時補課。

## 四｜25天神：歸墟不是吞盡天地劫的免傷口

**接口**：第14；取歸墟七雷、全體歸隊；正式已有另場共同天神，護遲望渡劫不是劫本人首次天神。自身真一→天神成功與25.5鏽退真一分開。

1. 劫護別人的劫後仍要養自己的門禁負荷，不把閉息門一線生機拿來免自身九等。取七雷後的新相容逐身真磨合達標，再開自己的劫地。
2. 劫雲的亮處忽變空暗，山石先收到雷震、隨後雷聲纔來；七雷的歸墟主位給了新的吞納可能，也帶來不同承載遲緩。
3. 他第一反應想全收進歸墟，卻在自己練習已見吞過量會牽其他身，真正引劫時主動只收本身能納的短段，其餘以既有鑄身、分流、逐身真承。歸墟不把其他源變虛假本源。
4. 最可欲的高潮不是雷消失，而是他把已納的小段劫勢在體內化開，另一身用自己的經脈親接下一擊，七雷各循本源完成天神，天空那處暗仍被最後的雷光照穿。
5. 真成功後取得高境可用的有限近點實承，傷身實際養復；隨後纔去奪回骨痕與依法壓境護家。路身逾期鏽蝕導致跌境，不能說他沒過關再補天神；它是有意選擇與另一個故事的代價。

## 五｜27.5虛道：不是融成大雷球，而是各軌真穿過長夜

**接口**：第16玉河鑄相後，天神→虛道，八雷。事故前26八雷與九身合爐已經發生，本稿不讀改豁免五檔，也不爲自己畫面反向改那些故事。

1. 鑄相、邴初先勝和有限空器骨實託真成果照留；他已從自身弱處改完承載再劫，不拿突破洗掉人物衝突。
2. 八雷各軌初亮，劫雲在暮色中顯出各自不同的雷落節拍；全體存活身逐份承，八種雷可由不只八具身承，不作數量鎖。
3. 外環觀者依據同境常例撤到第二泊位，夜半再撤一次；這次時長的敘述是他們實做的事情，不是每頁驚叫。他們能判斷“所見同境未有”，無資格立刻宣告萬古第一。
4. 劫不追最耀眼的軌，先將自己已練的有限實點承載對應到落雷實際接觸處；流光只讓本人看清一念內的變化，不放慢世界、更不看未來劫全部答案。判斷錯一小段會真灼目，他改下一段，不把錯誤寫成整場失敗。
5. 日出仍有劫雲，最後每份活源完成虛道，各軌仍獨立。劫用鮮血在自己的禁架上按一下，笑出聲：自己已能做到前夜不肯信的一次實承。此劫傷養實際排在玉河後、陽閘之前；虛道本就待排容量，不能擠掉陽閘三月回鍾。

## 六｜28.45斬我：主動舍強載，第一次以新方式承雷

**接口**：第19借壽崖冬至，全現存身同域斬我，八雷。原碑內試斬失敗是引劫前方法沒成，不改成正式九等劫補考。

1. 封寒拆自己骨架、劫完成本身斬我條件，這兩條自成，不由朋友的成功直接賜他斬我。劫真的可以維持一套曾很強的舊載，卻看出那套對這次承載不合。
2. 雷落將舊外相照成不斷重疊的人影，他主動撤掉自己最熟的那一組承架，讓雷實擊身肉；不是天劫忽然認識他的悟道而降難度。
3. 撤相不等被滅活源，每一份仍在劫域共同承擔。無間已經先穩，不能突然靠第十雷、九雷合一或未來天譴來接。
4. 他以已有短實點、本人步法和讀供路避“自己舊承架帶來的錯誤”，真正把新載接穩。末波全體斬我完成，血與裂不洗掉；隨後本人穿針刺斷供壽實接點，原勝法保留。
5. 兩門招傷和封右臂首一兩月恢復仍接聖土入境初期，不能用斬我免費滿血。劫的喜悅是他親自割捨強大的慣性，傷手也想再試新法；不是成熟知止已經完成。

## 七｜29.5遁一：聖土旁觀者看見仙修與自己的不同

**接口**：第20聖土；斬我→遁一，八雷，雷望衛外緣護道。仙修在聖土仍起劫、聖土本土突破無天劫，D051現行，不能給本地朋友補一場九等劫。

1. 外圍護道止他人誤入和敵襲，雷望衛不把雷擋給他。劫不把伊萊恩、封寒放在“友情加成”中代劫，自己的補給相容與完整達標先做。
2. 這次雲中光不是更大的雷柱：劫雲從數次劫落留下的舊灼痕形出多片明暗，又在他腳下的實物變化中更新；是可見本源牽連，不把天地寫成有記憶的人格裁判。
3. 劫以既有的分雷發收在本人源內承短段，不拿正在醞釀的新雷丸當救命必成招；真正劫中靠已熟的鑄身與真實供力走完。火蓮啟發、雷丸首試失手仍按本篇原有次序另場發生，不能為天劫帥氣提前宣告穩定雷丸。
4. 八雷同成遁一後，他沒有吞外部真劫把它化成永久新雷種。伊萊恩看到血下的仙修新紋，感到自己修行的陌生與吸引，而不是自己像凡人。各人的煉火、王室線都照常繼續。
5. 劫散後養真實傷，後續再見馬杜恩、爭返燼晶、雙刃孕靈升級爲另一個自己主動做成的故事，不靠九等劫贈刀升級。

## 八｜約31至尊：九雷齊備，最長紀錄第一次有證據

**接口**：二訪聖土段八約30–31歲、遁一時取得九霄，第21至尊先於三宗撤賞；遁一→至尊，九雷。九雷合一首用依然在第24，不能用本場畫面提前首合。九霄本身只是取來的異雷，不讓它召天劫。

1. 他親選遠離雲洲爭脈現場的劫地，各活源都達標。蒼梧只量外緣界度，不代承劫，不把同命契不存在的機制寫出來。
2. 天空白日暗過三次，又被不同雷性照亮，九霄落雲與其他主雷各循原路，不混成常態彩虹球。雷身數量逐案記錄真實展形與活源，不寫“九雷，所以九具”。
3. 中段他把自己最擅長的爆發減掉一半，把空間留給最慢的那份承載，主動用已有鑄身經把最易裂的一條筋從迎擊變成繞骨導擊；其他身真實各做，不免本源傷。
4. 熟古劫的記錄者拿同境舊記核劫時、實落層次和外緣觀測，並承認跨文明記錄有缺頁。本場可證“現有可核至尊舊記未見”，不是無依據說全宇宙從無更強。
5. 末波雷照見血骨，所有活源真至尊。他仍是站不直的成功者，笑着把自己已能使的天譴・四極練到有限一輪；不提前九雷合一。傷養後才接爭脈兩敗一勝、拔樁、三宗親撤賞。沒有一劫替三宗清算。

## 九｜34.5真仙：帶着不能復原的那條死軌渡過去

**接口**：第25正式共同真仙，九雷，第十僅胎，全現存活源。第22被滅的長亭身永不補回。第24已九雷首合、至尊恢復、望歸已合歸、白沙三夜短遊及傷養仍保；跨到三十二天並達標才引真仙。

1. 最慢的殞星主雷現存身發收達標，劫延後一日自己的期待，是真做準備而不是準備會變失敗。封寒在劫域外守旁人，不接仙劫。
2. 天光先沿舊死軌缺處變暗，繼而現存各軌引出真實雷落。死軌不亮、不復活、不因世界最高劫等“獎勵完整”。他已經九雷，不意味着這個人又完整到從未失去。
3. 第十胎僅被動在主位旁，不能幫他戰。劫自己用鑄身經各現存承形迎仙質雷，命圖記軌不減傷、不減劫；強身也不能把未達仙質的他身藏起來。
4. 他在一輪劫間真發現一份承形發得快卻收得慢，主動削自己這份爆發的外伸，收回同一份真實力，再以完整身走下一輪。不是撤掉一具讓全劫少算，不是既破仙又重渡補考。
5. 古代觀劫者以可追溯仙劫錄和真正觀測確認：已核的最高同境九等中，此劫持續、同源展形複雜度與實承界尺度最強；留未知文獻的邊界，可信稱“萬古所見第一”，不讓路人全知古史。
6. 最後每份現存活源真仙成功，仙光在燒焦衣襟和滲血掌骨間初成，他看着自己，真笑。舊本源撕痕、界屑、缺身事實仍在；突破得仙質，不免費清一切舊痛。
7. **既有劫後撤形重凝另起**：正式第25殞星目脈灼傷後，自願撤實形、保活源、至少三日不展，第四日首凝未成、第六日成功辨收。這是已成功真仙的後續修法，不記成失敗天劫或雷身欠境補考，也不能把四/六日過程搶搬到最後一道劫裏。

**最想保的畫面**：雷雲散後，少一條永不亮的軌仍在那裏，剩下真實仙光灼灼。他不是回到無損的自己，而是真的走到了仙道。
