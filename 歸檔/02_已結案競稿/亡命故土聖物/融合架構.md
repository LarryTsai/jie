# 亡命、故土、聖物：選後故事架構

2026-10-10。主編依[獨立比較](獨立比較.md)採[甲](甲.md)，待實改覆核。不混乙丙的爐、病因與聖物；約64個承重事件，不先鎖章數。

## 第一篇：林裡長出第一丈渡口（約22事件）

1. **所求**：劫取回日用環；女修秦濯鑄署名、承滿肯鬆的環骨；盧以水法開渡口。
2. **對手**：岑墟奪環、毀兩箱材，留原印十日驗貨；柯臨識假勢，三方追兵各有所求。
3. **奇觀**：古木吸鐵稍鬆、遲雷開花；秦由積累成靈器層環骨胚，盧試敗後成一丈承水。
4. **改局**：前七日探站、問運、練器。第八日同批發運識假勢後分車；劫先取印進有限外段，環車沿實路到林緣。敵人卸金鐵、推火霧、斬落點，劫撤禁只保真驗三處。
5. **高潮**：秦逼退柯臨、盧送一舟人，劫近身破側接骨；岑主供救高價礦車，劫開實匣追回殘環，另真殺適境滅證者。岑存活且學會反制，林不被全控。
6. **得失**：殘環、環骨胚、水渡真在手，兩箱不回；保烤魚、刻名、畫渡口與摸環不肯睡的喜悅。
7. **前因**：補借勢舟破押：盧本人因真實舊劫舟殺人指認遭合法查問，後被周私人轉押；舊罪不洗白。舟方真護客；劫救盧、秦承器回抽、盧脫押後送客。劫破外器勢、護送者傷、舟失護行力；周失酬款與押人渠道，才逼劫回指定口。

重接：甲加破押前因；還印止本次追索，傷人帳保留。

## 第二篇：根沒回來，帳真清了（約18事件）

1. **所求**：父母保人、文截實際撤路、太玄守脈；劫回來看見失去後，循參與鏈清帳。
2. **對手**：周欲守轉押線，孟渡星以真身正規短印壓列陣入界，利用療材名目襲青潮藥圃；不讓聖子輸比試便殺家。
3. **仙道**：毒附根、母株止毒、封泥封管；錨印限制敵我，本土師長正面逼退入界者。
4. **改局**：文判錯後守回程抓兇；父親封管、母親撤人，圃脈仍毀。遞書本體上行，劫申短印，本尊下界、其餘身留上界。痕、口供、簿冊各證局部；敵轉材換舟撤口，秦盧自主截料。
5. **高潮**：按期合印後劫恢復真一，秦環骨肯鬆使孟自己的護力封退路，劫近身殺同境孟，實際執行者亦死；周天神保主舟、失聖子與凶料，本人尾款留下。下界不得誤稱孟為天神肉身。
6. **得失**：青潮藥圃、母根與兩名藥役不可回復；祠堂、封泥小匣、父母及全島主脈保住。母親另種外島種，清帳結果實送回，父30.5壽終不改。
7. **出口**：秦古林成器後再爭「断骨仍能承法」，報養器試；不添敵手活印病。

重接：甲主幹；下篇藥圃改指青潮藥圃，不加舊院沉海。

## 第三篇：三山的春，一個人的明天（約24事件）

1. **所求**：秦爭器法、器譜與地契；劫試本殿禁圖、備材料，真想去。
2. **對手**：梁聽海爭席護物；供殿醫席願救，主持者不能轉嫁三山春根。
3. **珍寶**：珠中草原吐春絲入三山，續活心脈、不復活或治寇／生。秦真勝後冒險接殘骨異生，試治不成才取春心。
4. **追取實修**：保春舟、輪掌腕絲、首奪失敗；器托與腕絲屬真一可毀層，不拆三山主陣。獨立天神醫修先落場，醫棚在春舟下游約45丈，預布同境承脈陣。劫搶後真被遠手截停、春舟壓碎；醫陣僅撐十餘息治療，主持者仍鎖珠、破陣搶春絲，須在回奪已取用珠與保三山吐脈主供間付先手。最後醫修受傷，殿方奪回空珠，非窄涵逃走。寫手須實排供力、交班、治療息數與轉手；本輪甲已實排上述攻防並經正式限定回驗通過；依正式三篇，不以本架構取代現行大綱。照塵不擊退天神。
5. **高潮**：秦環骨承滿即鬆、盧托舟、劫奪珠。醫修施治、秦鬆殘接，春心續本人心脈；她拿錘敲響，三人爭鋪門朝向。
6. **後果**：空珠被實追回、三山本年道用受損；三殿各按聖物／舟殿血仇／承法傷人聯署。秦保真一、器譜與鋪的未来，盧接付舟資乘客。
7. **岔口**：玄殿推薦仍真，劫主动不赴；照塵護行真、知情護送段橫波亦真，雲仍叫師父卻拒運凶徒貨。曉路只在下無極，末接24.5護遲望。

重接：甲主幹；醫渡提前落場。
