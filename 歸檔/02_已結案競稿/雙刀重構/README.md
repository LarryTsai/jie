## 現行故事

- [雙刃唯一完整大綱](../../../大綱/00_全書骨架/04_無妄與有隙/大綱.md)：少年奇材、拍賣震撼、頂尖宗師、珍材冒險、首訪完整雙刀出世和首戰、十一年孕靈與第二次出世。
- [北天完整故事](../../../大綱/01_少年/24_北天行/大綱.md)：十五歲二雷的照夜洲爭材，有原住者採權、同代真反制、普通交通與合幕撤離。
- [第一次聖土](../../../大綱/02_離鄉/01_第一次聖土/大綱.md)：拍賣、沉聲髓／沉日珀兩場探索、布蘭堡鍛器、西返首戰；52週重排實際取捨。
- [王室臥底](../../../大綱/03_崛起/06_王室臥底/大綱.md)：七之16身份揭、遁一與雷丸兩敗後重逢，返燼晶爭材、本人擴紋與器肯升寶器。
- [全書總覽](../../../大綱/全書故事順序總覽.md)：新增北天第10列，管理序次重新連號，共56個故事。部／卷／篇及資料夾號保留。
