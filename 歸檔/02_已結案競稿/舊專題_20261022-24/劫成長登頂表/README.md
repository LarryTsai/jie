# 劫成長登頂表：地圖 → 成長 → 登頂 → 換圖

2026-10-22｜作者在處理[藏經閣與玄殿提案](../../待整理收尾_20261031/太玄藏經閣與玄殿/作者裁定.md)同輪指示：先不發明新地圖、不再設計更多功法，把現有故事按順序整理成「地圖 → 成長 → 登頂 → 換圖」表，逐段回答六題，找出哪些段已有完整爽點、哪些只有故事線沒有成長回報。

六題：①開始多強 ②真正有價值的成長 ③擊敗值得擊敗的對手 ④登頂時刻 ⑤下一張圖為何值得去（新高度，不是數字變大） ⑥帶走什麼、下一張圖還用不用得上。作者期待：每張地圖有自己的登頂時刻，每次登頂讓讀者看見更高的天空；劫要有主動追求的東西、想打敗的人、想取得的傳承、自己做的選擇。

本表是**診斷**，不提新劇情、不改任何正式大綱、不升降總覽狀態。正文凍結不變。

## 跨段共同病型

1. **缺一份「主動追求、作為地圖目標、帶得走」的高階傳承。** 劫確有主動取得的有名功法——《無相離身卷》（攢一年錢換）、《萬體鑄身經》峰傳、《渡影步》、本界刻紋基譜、〈留日禁〉讀本——但都是基礎或輔助層；他從未以「我要拿到那門法」為一張地圖的目標並拿到。登天塔「殘法抄閱」、歸山「新輔法」無名無來源；離鄉崛起段無師承傳承（拒玄殿試學、不取太素仙篇）；成道入極把〈正午篇〉、祖脈讀法讓出。
2. **贏了被收走、被推走。** 19–27.5 不是缺高潮，是缺**守得住、帶得走的回報**；篇末多由他人程序把劫推往下一張圖，而不是他看見更高處而去。
3. **成果帶不到下一張圖。** 北天母核延後兩年才用；渡劫淵天神同篇鏽回真一；昃環殼、萬象・還重、逆息、弱聲木絡、護爐架之後不再出現。
4. **同代宿敵帳不完整。** 書院「北院皇道同代」出現四篇仍無名、無勝負（總覽第22列「待設」）。費瑜有帳（12歲推薦對試正面勝、18歲千礁親殺），可作對照。
5. **部分缺口來自作者裁定。** 七峰武冠歸生、百宗放棄第一、同伴主場（D157、D159）是作者選定設計，本表只記疊加效果，不建議推翻；是否在相鄰段補回報由作者判斷。

## 與藏經閣提案的接點

提案的核心需要——「真正得到好東西」「想取得的傳承」——正對上病型1，是真缺口。提案由另一工作線處理，來源核對與作者裁定見[來源盤點](../../待整理收尾_20261031/太玄藏經閣與玄殿/來源盤點.md)、[作者裁定](../../待整理收尾_20261031/太玄藏經閣與玄殿/作者裁定.md)：2026-10-22作者已定功法品階兩界皆改七層、不換算（「天階上品」可用），提案的玄殿即上界玄殿、推薦約19歲初入玄殿登籍期。本表只提供缺口位置供該線參考。藏經閣仍須避開卷六命藏主弧與根本功法《萬體鑄身經》位置。可承載位置：

- **卷十九歸山**（16歲，太玄42日，山中第16–28日空白；本身判「缺」）——最乾淨的空位，且緊接書院首年另一張「缺」。
- **卷五七峰獎勵／卷六命藏**（13–15歲）——缺口真實，但命藏主弧「不作傳承商店、前人之路不合身」是既定設計，硬塞完整功法會推翻它。
- **十八歲第23篇返鄉段**（千礁前後）或**約32歲第23篇先返太玄**（B03–B05）——兩處不同；後者須與費氏襲家時序共排。

玄殿現行為上界官史機構；劫經澄霄分殿登天、下無極分殿有弟子籍，本殿試學自拒、列入永失。依作者裁定二，玄殿機緣落在約19歲登籍期，正好落在本表「19–27.5贏了被收走」段的開頭；那一段缺的是守得住、帶得走的回報，玄殿所得應能撐過其後的停籍與除籍。
