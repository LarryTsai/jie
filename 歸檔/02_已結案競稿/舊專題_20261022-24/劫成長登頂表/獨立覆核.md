## 二、README 主要結論核對

### 2.1 「19–27.5 約八年、十一張圖無登頂」：計數對，判斷不被支持

十一張的數目正確。但段C 自己在這十一張裡列出了七次登頂：

| 地圖 | 登頂 |
|---|---|
| 上界追仇 | 倒雷井一日四殺（段C 表列 :142） |
| 九弱 | 神火夜＋爭骨勝牧昭；十三劃（段C 稱「本篇最強越境證明」） |
| 碎錦原雙汐 | 「萬人見神火打倒天神」（段C 表列 04:196，現行號已移） |
| 程序未決 | 真一後回臺再勝葛鳴秋 |
| 渡劫淵 | 天神劫中越至尊牆、天神成 |
| 候審 | 熔成第八雷、擊碎祝旸鏡座 |
| 上界同代年＋陽閘 | 玉河勝邴初四層；閘心取權勝公孫逾 |

這八年的病不是沒有登頂，是**登頂之後馬上被收走**：雙汐勝利轉成奸細罪（04:198）、天神同篇鏽回真一（09:44）、除籍收押（09:40–42），篇末一再停籍、通緝、除籍。README 病型3 已經碰到這一點，但曲線表的「乾段」欄把它說成了「無登頂」，方向就偏了：作者會以為要補高潮，其實要補的是**守得住、帶得走的回報**。

### 2.2 「12–15 約三年無坐頂」：要限定成「名位奪冠」

- 如果「坐頂」指拿下名位第一，成立：七峰武冠歸生（05:412），百宗主動放棄第一（08 主幹）。
- 如果指登頂，就不成立。段A 自己列了：鎮鈴七枚（05:21，「少年段唯一世界作證」）、前段四勝榜首加點戰勝封寒、熔兩儀（04 第21章）、百宗預賽擊敗日後奪第一的人（08:13）。
- README 這一列只寫「七峰（武冠歸生）」，漏了鎮鈴七枚。

### 2.3 「劫幾乎從未取得一門他主動追求、有名字的傳承」：方向對，措辭過寬

反例：

- 《無相離身卷》：01 第15章，攢一年看攤錢換來，主動、有名。
- 《萬體鑄身經》峰傳：主動入鎮岳。
- 《渡影步》：九弱 03:141 列為所得。
- 本界刻紋基譜：第一次聖土 01:170，七次失敗後練成。
- 〈留日禁〉讀本：日月藥天。

段C 寫的「正式傳承：無」是另一回事，指的是正式師承或高階傳承。來源支持的說法應是：**沒有一門高階、完整、由他主動追求並從對手或試煉中爭得的前人傳承；有名字的法多是入門、殘篇、公開譜或實戰技藝。**

## 四、一般讀者角度

### 最傷追讀的三段

1. **約23.5–25.5：程序未決 → 亡命 → 故土清算 → 聖物案 → 渡劫淵。** 連續五篇，篇末依序是停籍、亡命、通緝、除籍、天神鏽回。中間三篇共用同一份「真一六雷」能力表，半年裡能力不動，失去的東西一項項列成「永失」。前面雙汐萬人作證的勝利剛轉成奸細罪，讀者連續看到「贏了也會被收回」，最容易在這裡棄書。這是全書最傷的一段，比「沒有高潮」更嚴重。
2. **約32–33：斷階 → 太玄・驤鳴。** 墜落篇本身可以接受，問題在之後一整年重爬，恢復原尊者與劫藏用一句日帳交代（驤鳴 03:98）。讀者等的是「他爬回一階」的那一場，卻沒有在場面裡發生，違反「活著過去」。勝賀逢山也只在一段裡和別人的成果並列。
3. **16歲：天域書院首年。** 「天才入學院、闖塔、遇同代宿敵」是讀者最熟、最期待的爽點容器，這裡卻寫成額度換物、承認對方更強、偷庫受罰。北院宿敵跨四篇沒有名字，讀者連該恨誰都不知道。歸山的傷害反而較輕，因為知秋開鋒是生的強場面，讀者有得看。

### README 漏掉的登頂與乾段

- **漏登頂**：北天鍔娘真勝；鎮鈴七枚；九弱十三劃；雙汐萬人見；渡劫淵越牆；玉河；陽閘（見 2.1、2.2）。曲線只收「完整」，讀者回報的實際分布被畫得比實情更乾。
- **漏病型**：「勝利被沒收」應該單獨成一條（雙汐→奸細罪、天神→鏽回、九界冠軍個人獎勵「待制度細化」23:46），這是作者「每次登頂讓讀者看見更高的天空」最直接的反面。
- **漏乾段**：段D 依自訂標準應判「缺」的三張（斷階、第三份探查記、間章），README 分段明細寫「9／6／0」，會讓人誤以為成道以後沒有缺口。

- 母核可用性兩段說法不一：段A 說要到列陣、聖土後才用；段B 說十六歲四極就作動機與試火。README 病型3「延後兩年才用」可改為「十六歲成為四極動機，成器要到聖土」。
- README 的「與藏經閣提案的接點」可以補一句讀者角度的排序：最需要「得到好東西」的是 23.5–25.5「回報被沒收」段與書院首年，不只是歸山的空位。這是診斷順序，不是方案。
- 曲線可以加一欄「下一圖仍在用的所得」，讓病型3 直接在表上看得見。
