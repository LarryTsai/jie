# 九分提升｜全書勝法形狀總表（七角度 X-02）

2026-10-23｜主 Agent 發派｜候選、非 Canon。作者 10-23 指示照總表順序開始；全書重打分七位讀者都指出「對方先得手一次，劫同場翻盤」成了公式（[總表](../全書重打分/總表.md)第二節）。

## 目的

逐篇列出陸沉（與主角群）每一場重要勝負的**形狀**，找出重複，提出改成什麼形狀，讓讀者猜不到下一場怎麼收。只出表與改法方向，不改大綱。

## 形狀代碼

| 碼 | 形狀 |
|---|---|
| R | 研究型：敵人研究他（戰影、八簿、上一版），計奏效一次，他同場改版翻盤 |
| F | 先挨一下：開場吃虧／被打中，同場翻盤 |
| C | 碾壓：開場就正面壓倒，沒有翻盤 |
| W | 智取：讀破綻、換氣、半息、拆承點、借力 |
| T | 劫中越牆／劫數計數收場（天劫或〈劫數〉落重定勝負） |
| L | 真輸（D157 三項真敗等） |
| D | 平手、未分、不打、撤走 |
| S | 地形／場地／規則決勝 |
| O | 同伴或他人主力，劫在旁 |

一場可標兩碼（主碼在前）。

## 全書規則（三位架構師共用）

1. **硬邊界不動**：D157（真敗只三項；越至尊牆三次場次；〈劫數・降〉長亭一次；斷階不敗）、D159 同伴定位、作者裁定（[作者方向紀錄](../作者方向紀錄.md)一至七）、作者選定篇的批准範圍。只改形狀，不改勝負結果。
2. **目標比例（每段劫本人的重要戰）**：C 碾壓至少三分之一；R＋F 合計不超過三分之一；W 智取少而精，每段不超過五場、都放在真正的關鍵處；同一形狀不連續出現三篇以上。
3. **2026-10-23 已融合的篇**（五域、七峰、天外四極、入極、長亭、海往天上走）列入表中供比例計算，但**原則上不提改法**，除非它和前後篇撞形狀撞得很明顯。
4. 改法寫到可直接派寫手：哪一場、現形狀、改成什麼形狀、一句改法（要氣魄，不小家子氣；不加免責句與帳）。
