## 一、一般讀者

**想不想往下翻：比舊稿想很多。** 舊稿從第12章漏樁到第17章斷扣，是一條線上的同一個對手，中間夾著規程。新稿從第5章五璧點兵起有了倒數，斷階一人 → 樊晦之三撞 → 北位南位 → 漏樁那一角 → 兩璧一息 → 算席與耳 → 不改 → 降，一章比一章重。「他每打贏一場，管曜就強一分」（第19章）是整場的引擎，讀者會為陸沉的勝利同時感到不安。

**最想保留**
1. 第12章斷階一人：「這是我碎過道基的地方。誰都別上來。」契書帆燒成灰，金庭一個時辰虧三成。
2. 第13章樊晦之三撞：「雷不出光，只剩重量」；正午的日光從他胸口的裂縫落下，留舟島的人把燈吹了。這是全篇最好的配角戰。
3. 第21章不改：「這一場，他改了哪裡？」「沒改。」「寫不進簿子。」把全書的「改版即升級」翻過來用，宿敵用了一輩子的方法第一次失效。
4. 第23章劫從下往上走：留舟島、伏雷坳、渡口的人都看見自己頭頂的雷雲往上升。降從此不能搬到別的地方用。
5. 第25章不降：老婦人在斷口邊鋪油布、擺三隻碗。「手抬到一半，放下來。」

**想跳或卡住的地方**
- **第1–3章截脈**：「三落」「邊口」「側路迴流」「撕痕感知的盲處」接連出現，一般讀者要讀兩遍才知道誰贏了。第2章封寒「唯一，驗過」那一拍救得回來；第3章仍偏說明。（建議，非必修）
- **第8章特許**：五庭剛點完兵，倒數已經開始，這裡卻是「赫爾要求再驗、特許不是開柱封印、潮紋對照私路」，讀起來是規程。讀者最可能在這裡跳。建議壓成兩三句併進第7章點名，或移到第26章簽約前。（建議）
- **第23章五層天、五旗的對應**讀不懂，見必修1。這是高潮裡唯一讓人停下來數的地方。
- **第23章到第24章之間管曜死了，但讀者沒看到**，見必修2。
- **第31章前段**（文奕、赤翎、雲行、青璃）是一段旁白交代，跟前後幾章的完整場面落差明顯。（建議：至少讓其中一人有一個動作，例如雲行把燈時寫在牆上、雲紓改了一刻）

**重複**：「第一次」用得太多（冰鏡前第一次看見全力、雷身第一次全部放出、第一個拒交道脈……）；「X 年前 / 二十一年前」的回扣在第15、19、21章各出現一次，剛好，不要再加。

**舊稿 6.5**：場面好，但終局只有管曜一人，中段被規程與否定句切碎，「不降」只是一句話。**新稿 8.5**：卡在必修1的混亂、第8章拖慢、第1–3章術語密度。

## 二、強敵與配角

**管曜：有臉、有理由、有最後一手。過關。**
- 臉：母親葬在碎錦原東坡，去年那片沉了，他回去找不到墳（表、第5章、第23章、試寫三處呼應，沒有重複成說明）。
- 理由，而且一半是對的：「你等得起萬年，我等不起一年。」讀者會同意他一半。
- 主動的計：第九根漏樁藏在盲處（真拿走一角坊市）；八簿抄本；第21章照婁直那次仙刺複製，真讓第一軌吃虧；不戀戰，改抓脈首；從自己人鄺問懷裡奪璧。
- 最後一手：把留在陣道裡的退路也推進脈首，「不要退路，只要這一拉」。他是信的，所以沒放手。
- 缺一拍：死。見必修2。

**樊晦之**：全篇最有魅力的對手。「我欠的是金庭的錢，不欠你。所以這一戰我打滿。」有自己的帳，打滿、敗、債清、換邊，和 D158 仙途「明夷自己扛」相容。問題是換邊之後，第23章明夷的旗又在降裡被燒，等於把他的轉身抹掉（必修1）。

**司空珩**：「帝不言，即帝許」是全篇最好的一句動機台詞，和父親「帝不言，不可擅動」一夜之隔，到第24章「是我」揭出那一夜沉默的意思。可惜這個揭示只落在司空肅身上；司空珩自己在第19章被踏碎星垣、丟璧之後就消失。建議第24章給他一拍，例如聽見「是我」時他在哪裡、手裡空著。（建議）

**公孫聿**：動機清楚（賣出的席位要兌現），奪璧那一場有份量；但在戰場上他只是「重華璧接得極快」的那個人，敗後去向空白。目前是功能多於人。建議給一個他自己的手，例如戰中他當場把重華一席加價賣給樊晦之或金庭，被拒。（建議）

**像工具人的**：公孫衍（踏進禁域、被關）、鍾離鍔（被斬落）、鍾離算（只寫一個「押」字）、管昀（推演三年，敗得乾淨，但沒有自己想要什麼）。這幾位本來就是同伴的對手，功能化可以接受；管昀若加一句他為什麼推演封寒那一頁（例如他是族兄的影子，想證明白榆不只會看星），北位會更好。

**閭丘觀、鄺問**：短而有反諷（算得最準的人輸在「同一軌打得比他算的重」；聽了一輩子消息的人沒聽見自己落向哪裡），留白符合裁定五。

**公孫蒔**：替文奕斬斷重華自己的支根，「沒有回頭看重華的方向」，一句完成一個人。好。

**同伴高光：各自的，沒有搶，也沒被搶。**

## 三、主角

**「不降」是他親手選的，而且是一個動作。** 第25章把賭注擺在眼前：〈劫數〉在指間、那一角坊市每一片瓦都看得見、斷口邊上已有人擺新攤。他看了很久，手抬到一半放下。沒有旁述替他解釋。這和全書「能改，不等於該改」「先問」接上，而且是他自己看見了別人的生活之後才選，不是被人勸。過關。

小問題：第25章開頭「〈劫數〉的印還在陸沉指間，沒有散」與第23章「劫印收完，劃名」字面打架（必修4）。

**最像他的一刻**：第6章他把回家往後挪，不拿「忙」說輕，也不隔匣用神識偷看；第10章手落在泥匣上，停一下，拿開；第25章手落回泥匣，這次沒有拿開。三個動作串成一條線，比任何獨白都清楚。

**最不像他的一刻**：無明顯違和。第12章「誰都別上來」偏傲，但合他道基碎在那裡的私人理由。

**回家七章（第26–32章）**：七章都在，各自有場面，沒有壓成蒙太奇，符合 §1.3。粥（第27）、泥封（第28）、酒壺（第29）、勿沉（第30）、蹄印（第32）都是完整場面；第26章簽約偏薄但有寇平落名的動作；第31章前段是旁白（見一、建議）。

**前後是不是同一個人**：是。他仍是會替人決定、所以學著先問的人；對敵不問（斷階、樊晦之、管曜都直接打），對人先問（第32章「下次先問」）。第21章「不改」看似違反「改版即升級」，其實是同一個人到這一步才敢不改，成立。

**缺一拍**：「下次先問」的源頭林伯潮在全書卷一後未再出現（見必修5）。

### 4.2 「管長夜進帝天收屍」算不算違反「帝在，王不相伐於帝天」

**判斷：不違反，可保留。** 理由：
1. 舊約字面禁的是「相伐」，不是「入」。管長夜在陣散之後才進去，不對任何人或地出手（〈約束〉已寫明）。
2. 舊約給的理由是「仙王在帝天出手，長亭天先碎」，收屍與抽回自家借出的道脈都不是對長亭天出手，理由不被觸發。
3. 執約者司空肅在場而不攔，「收屍不是相伐」由執約一方默認，故事內有人背書。
4. 他抽回道脈是讓白榆成為「第一個拒交道脈的王庭」，接上〈歸一派〉底線「不經仙帝之戰收場：王庭拒交道脈」，是收尾的推力，不是解圍。

**但「帝天」這個詞本身要改**，見必修3。

## 五、必修（6條）

**1. 五璧、五庭、五脈、五旗對不上；明夷換邊後又在降裡被燒**
- 位置：第5章（五個點兵場景是白榆、重華、紫垣、明夷、金庭，「五顆不動的星」）；第20章（五璧是抱一、重華、紫垣、白榆、算席）；第23章（「五層天：星圖、巨根、星垣、殘蝕、金鏈」「五條借來的道脈」，五旗依序暗下時含明夷、金庭；「重華那一角本來就空著」）。
- 問題：設定裡〈校正〉的陣眼是歸席五璧，道脈是持璧的庭借出的；明夷、金庭出兵但沒有璧。第13章樊晦之已換邊，第23章明夷的旗卻跟著被劫雲燒暗，等於抹掉他的轉身。高潮裡讀者要停下來數。
- 最小修法：第23章五層天改成五璧的脈（白榆星圖、重華巨根、紫垣星垣、抱一的圓、算席的數；後兩者由主 Agent 定一個畫面）。金庭的契帆燒盡可以留，但改成「契鏈上的傭修先撤」那種旁景，不算一條脈。**明夷改為劫雲經過晦光軍頭頂，一道也沒落下**，這正好回收換邊，比現在更好。第5章標題或首句改成「五庭點兵」，「五顆不動的星」明寫是五璧亮起（可加一句閭丘觀、鄺問各自在哪裡持璧）。「重華那一角本來就空著」改成「重華璧第19章已碎，那一角只剩灰」。

**2. 管曜的死不在場面裡**
- 位置：第23章末「劫印收完，劃名。他沒有倒下」→ 第24章末「收屍」。
- 問題：裁定五要他死在長亭；武學譜裡「劃名」只是收帳（婁直劃名後仍活著）。照現在寫法，主要反派的死發生在兩章之間，違反「活著過去」。
- 最小修法：第23章「他沒有倒下」之後加一拍，例如「他站著，沒有再吸下一口氣。腳下的長亭天也沒有再往上來。」站著死可以保留現在的骨氣，也讓第24章管長夜收屍有落點。試寫段同步一句。

**3. 「帝天」撞 Canon 術語**
- 位置：〈五庭〉「仙王為什麼不下場」段、第24章「管長夜從天外走進帝天」、〈約束〉兩處。
- 問題：設定與主線裡「帝天」專指帝境者所成的天地（聖土末代帝的帝天骨架；第22篇陸沉正是在斷階頂從漏影望見帝天骨架）。本篇把同一個詞用在斷階上端的戰場與太宸治下，地點還重疊，等於暗中新增「長亭天／九界是太宸的帝天」這條全界法則。
- 最小修法：舊約改名，例如「帝在，王不相伐於帝前」，〈五庭〉段補一句「帝前」指帝仍在位時其座下所墊之天與接壤上端；第24章改「走進帝前那片天」。管長夜的行動與判斷（4.2）不變。

**4. 兩處字面自相矛盾**
- 第22章「第22道裂縫帶出來的雷胎」：設定是第22篇道基碎裂時的裂縫裡成胎，現在讀成「第二十二道裂縫」。改為「斷階那道裂縫裡結下的雷胎」（正文也不必引篇號）。
- 第25章「〈劫數〉的印還在陸沉指間，沒有散」，對上第23章「劫印收完，劃名」。改為「〈劫數〉的劫意還在陸沉指間，沒有散」或「降的那一指還沒收回」，最後「劫印從指尖淡去」同步改「劫意」。

**5. 任務單 X-07 林伯潮一項未落**
- 位置：第28章宗訓石段。
- 問題：任務單要求林伯潮擇一處補（返閣或長亭）。查〈閣老〉，林伯潮是退任閣主，沒有寫死；全書正式區卷一之後沒有再出現（未讀九界金丹五檔）。第32章「下次先問」說給縫民少年，源頭的人卻不在。
- 最小修法（二選一）：①第28章加一拍，林伯潮仍在閣頂石臺，陸沉這次先問他一句什麼（例如要不要替他看舊傷），他答或不答都可以；②若主 Agent 確認已在別卷（返閣）落了，在〈約束〉註明落點，本篇不加。

**6. 同步與標記（提交前）**
