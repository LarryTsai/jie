三案都比現行好看，沒有要全退的。三案的差別：

- **甲**：讀者有一個追了一整年的問題，就是「天上那個人」。盧修斯從第一章擦身而過，經決賽「從我天上掉下來的那個」、羽信、前夜不長翅膀，一路到落鷹風。他倒地後親筆在薦書上寫「核沙坑一橫」，譜官說「境界欄，填不了」。這是三案裡最好的鷹崖。浮城「這是你的火。你自己說」把寇平那筆帳在聖土回響一次，最像陸沉在長大。缺點有兩個。一是凱爾仍有十一段，沒照讀者C壓成三根柱子。二是布蘭堡沿用現行「首試驚動雷冠」，丟掉設定裡早已寫好的落冠救城、灰牌、「無名，免費」，二訪〈屋頂之帳〉「葛瑞特把當年的灰牌還給他」就沒有來處。
- **乙**：潮骨牌是最強的單一引擎。鷹崖布告牆上幾十種筆跡都寫「不接」，托爾貝克三句話是全段最好的配角弧。問題也大。一年的仇人莫爾坎只是鬥靈後段，首救就被一扣逼退。他的收場是劫閉眼熔煉時殞星自動把他釘上山壁，讀起來是被動收帳。布蘭堡救城線、灰牌線也一起丟了。懸賞「手上護著的東西，另議」貼近厄的伏筆。殺四人，聖土這一年從「尋路」變成「獵人與獵物」，偏離作者首入重建的核心（劫想回去才不得不探索聖土）。
- **丙**：一條天象貫穿全年。第一夜他迎著縫雷走、以為天劫衝他來，塔姆林說「雷不瞄人」。他一拳砸進凍土，因為裂口是他自己站上去的，和替寇平做決定是同一件事。骨河替死去的祖先唱歌，浮城會呼吸，失日海把正午的太陽接走，避雲紀錄畫出一條會呼吸的線。落冠之夜鬥聖焦黑退出，他第一次從上面抓失敗，第二次逆著噴發從火口走進雷冠。熔成那夜腳跟離地一寸，他自己放回去；回九界渡劫時「這一次腳跟離地，他沒有放回去」。這一案最貼聖土設定，也最貼作者首入重建；缺點是盧修斯一段薄，凱爾的對手比較少主動。

## 1. 讀者分數（1–10）與場面取捨

### 1.1 甲｜爭霸

**第35列 8.5／第36列 8.5**
- 想翻頁的原因：L7 一句話就把全年問題交給讀者，L63 墜落時一隻鳶影看他一眼、翅膀一偏走了。之後每一勝都有人往天上送消息：L140 林妮亞問「一橫是誰」，L177 羽信只有一行「上崖，讓我看看。盧修斯。」核沙坑三夜一夜比一夜短（L80），隔天賭簽不寫名字，只寫「一」（L81），世界替他作證，爭霸路線兌現。L82 手抖停不下來，「我家燒了」「他到現在還在替我收帳」，這是三案裡愧最具體的一句。L145「這是你的火。你自己說」是全段最好的主角成長拍。
- 殞星（L215–227）：首試五雷全展開去「接」，殞星穿過網像穿過霧，布蘭堡所有爐火同時暗一下；第二次他「坐到它落的地方」。悟法清楚、場面完整，只輸給丙的落冠之夜。
- 差在哪：①凱爾仍是 L77–117 十一段（核沙坑、木刀、大拍、馬杜恩、齊、羅梵、廢窖、預選），讀者C要的「三根柱子」沒做到；②布蘭堡沒有救城，「恩人／掀屋頂兩派」改由「首試驚動雷冠」自造（L218、L226），和設定擺好的落冠連墜、萊安德兩條帳、休的推薦、葛瑞特灰牌都對不上（見 3.4）；③壓關寫了三次：L188 鷹崖前夜、L224 熔中兩次、L254 返界才放。L188「破了，他明天就能在天上打」又和〈兩界三條路〉「就算想破，也攢不齊那一口」相衝；④L188 聖土上空聚雲一掌寬，作者自己也標了風險。
- **最想保留**：
  1. L197–208 落鷹風加遞薦：「核沙坑一橫」「境界欄，填不了」「明天別走崖路，鳶路有一隻空位。」「我走路。」
  2. L145 浮城「這是你的火。你自己說。」伊萊恩說不。
  3. L140 「從我天上掉下來的那個。」L190「他本來可以有翅膀。」
  4. L210–211 伊萊恩四敗之後第五次，火從爐底燒進疊鎧的縫裡（布蘭堡青年區）。
  5. 次選：L111 托爾貝克在傭兵廳替他作證「一橫扛了我三輪」；L311 莫蒂默在階欄畫的那一橫，一年沒擦。
- **最想刪**：L115–117 預選五個名字；L152–153 箱子分配；L186–190 聚雲那一掌（留柯賓那一問與盧修斯那句話即可）；L63 盧修斯在縫雷裡巡鳶路（可改作者自備的退路：南線第七站看見墜雷）。

### 1.2 乙｜殺伐

**第35列 8.0／第36列 7.5**
- 想翻頁的原因：L75 牌前「活的，三；死的，二」，他把吹歪的牌子扶正就走，接著說「他掛牌，就是不敢自己來」，有王林味。L62「你急著回去做什麼？」「殺人。」「那先把傷養好。死人殺不了人。」三案裡追仇欲望最直接上台面的一句。L118 骨河第一次殺人，五雷分工全開，「我家被燒的那晚，沒有人收手」，齊看了仍然留下。L186 鷹崖的「不接」牆是全段最強的截圖之一；L195 盧修斯一場開場劫先動，三拳都打在他剛離開的位置，最符合「鷹崖不用先吃一記開場」。
- 差在哪：①一年的仇人太輕。莫爾坎鬥靈後段，與列陣同級，首救就被一扣逼走；讀者會問，怕他的應該是牌子，不是他本人。②收帳是被動的：L220「劫沒有睜眼」，殞星倒射釘死莫爾坎。熔煉中雷自己出手，讀起來像能力自動護主，不是劫做了什麼；托爾貝克的「人我不打了」也因此搶走劫的高潮。③布蘭堡變成刺殺局，救城、萊安德、休、灰牌全不在（見 3.4）。④L226 雷冠灌給他「足夠破關的一口」，違反「攢不齊那一口」，乙在 L409 自己也列了。⑤殺四人加上全年獵殺，伊萊恩藥地、失日海、骨河的「看看這個世界」被擠成側邊。
- **最想保留**：
  1. L62 「死人殺不了人。」
  2. L195 盧修斯開場：劫先動，天是空的，三拳都打在他剛離開的位置。
  3. L96、L218 托爾貝克「這個價我不接」「我說過，人我不打了」（只在潮骨牌線存在時成立）。
  4. 次選：L169 諾維雅把牌墊在酒杯底下「我的船上不掛這個」；L186 盧修斯「我不收骨頭錢」。
- **最想刪**：L218–221 托爾貝克坐下與殞星自動釘死整場；L226 雷冠灌一口；L242「連莫爾坎的牌子都只敢寫『另議』的那個東西」；L75 牌上的「指骨」畫像與「另議」一欄。

### 1.3 丙｜奇觀

**第35列 8.0／第36列 9.0**
- 想翻頁的原因：L43 滿天針腳，他是雷修，以為劫衝他來，就迎著雷走，正好走在雷要落的地方。L56–58 塔姆林「雷不瞄人。過縫死的，都是站在要縫的地方的人」，他想起替寇平做的決定，一拳砸進凍土。愧在第一章就浮上水面，而且和全年的「學會雷落在哪裡」綁在同一件事上。L141 長脊獸第一步落在千年骨河上，歷代蛻骨一節一節亮起來，沉聲髓「記住的是這一聲」，到 L255 雙刃一高一低的指向還回收。L165「你剛才，在殺誰？」「一個上界的人。」怒一句就到，不用演講。
- 第36列是全段最高點：L206 雷冠是一座城的屋頂，廳規「雷是蓋子」；L212 他在灰牌地道口當不收錢的嚮導；L217–237 落冠之夜，鬥聖提火進冠、焦黑退出，萊安德面前兩條帳，休說「有個在雷裡走的嚮導」，葛瑞特寫下「無名，免費」；第一次從上面抓失敗、第四顆核從頭頂掠過落進城；老哈斯「你從上面抓，是抓樹梢。根在下面」；第二次逆著噴發從火口往上走。L244–250 腳跟離地一寸，他放回去：「回去再破。」L288 渡劫時這一次沒有放回去。L269–277 過縫時，他把一年裡塔姆林、避雲紀錄、鷹崖的風、雷冠的根學到的東西合成一句，遠處走潮者的步子和他踩在同一條線上。
- 差在哪：①盧修斯只有 L195 一段，沒有「天上那個人」的鋪墊，鷹崖首輪之後就打完；②凱爾對手少主動，羅梵一段（L115）太快；③L237「八萬年第一次露出一線星光」「冠開了一條縫」會搶二訪〈屋頂之帳〉的冠頂之洞，也可能被讀成星天圖投影；④L237 林妮亞跑到布蘭堡城牆上不必要；⑤L189 伊萊恩對伊紹拉一敗之後，全卷他沒有一場在劫面前贏布魯諾；⑥鬥聖分寸要窄修（見 3.3）；⑦L137 拔第一根釘「雷身一具被震回」是多餘的先挨一下。
- **最想保留**：
  1. L217–238 落冠之夜全場（依 3.3 窄修）。
  2. L242–251 腳跟離地一寸，以及 L288 的回收。
  3. L54–61 縫雷下的愧：一拳砸進凍土，指節破了；「明天米蕾要罵你」。
  4. L141 骨河鳴響，與 L255 骨鳴讓兩手指向一高一低的回收。
  5. 次選：L88 齊的五道圈、第六道沒來；L175–179 正午太陽沉進海裡；L269 奧絲拉；L279 維達筆停了很久，什麼也沒寫。
- **最想刪**：L237 星光與冠縫、林妮亞上城牆；L137 雷身被震回；L159 箱子三方分配（已壓成一句可留）；L92「斷在你換氣的那一下」（讓齊自己找，見 5.2）。

### 1.4 共同風險

1. 三案凱爾都超過讀者C的「三根柱子」，丙最短（L77–125 六段）。
2. 三案的柯梭一場幾乎一字照現行，西返仍是 R 名額的一場，這是對的；但三案都在戰後補「柯梭保暗珀、學到同一環不能用兩次」，屬於讀者C點名的勝後對沖。這句移到柯梭再登場時再說，戰後只寫兩份護材都在手裡。
3. 「星羅讀……兩儀牽……」雷術組合句，甲 L134、L242 和乙 L237 仍是同一種排法；丙骨河與雷冠兩場改用天地之法講勝負，這是丙比較不重複的原因之一。

### 3.3 特別判斷一：丙「鬥聖老哈斯焦黑退出、劫從火口走進雷冠」

**判斷：場面本身有設定來源，可以用；但丙的期待句與兩處措辭會被讀成「劫勝過鬥聖」，須窄修。**

來源：
- `設定/01_世界/05_聖土/04_人物/09_奧斯馬克鍛廳與奧斯崔斯.md` 老哈斯條〔初〕：「（首入）落冠連墜之夜，他從雷冠退出來、渾身焦黑，看見一個無翼的少年往裡走。」〔理〕：「他強入雷冠壓核，落了雷傷……他知道那是自己的選擇，不是那個少年的錯。」萊安德條：兩條帳，「點頭讓長帳團推薦的無名少年進雷」。休條：「記得『在雷裡走的邊地嚮導』，向前任廳主推薦了那個少年。」灰牌司條：「一格『無名，免費』」。
- 作者首入重建來源（`歸檔/05_後半部開荒來源/第一次聖土_重傷被救與尋路五階段.md` 第五節）：「冠鳴救城可保留為機緣核心……高境本地人真正抵抗；劫提供的是異體系適合此雷的處理手段，不能寫傷後列陣比鬥聖全面更強。取雷需追尋、實試、承受熔煉與雷冠變薄的後果。」
- `當代勢力.md` L271：「他不擊殺鬥聖」；本場不交手，不觸此條。

所以「鬥聖退出、少年往裡走」不是丙發明的，是首入線的既有畫面。風險只在寫法：丙 L238 期待句「一個鬥聖都退出來的地方，他怎麼進得去」，以及 L231「雷不再找他」、L366「走進他自己剛退出來的那頂雷裡」，三句都在拿兩人的強弱比較。

**安全寫法（融合照此落）：**
1. **兩人做的是兩件事**。老哈斯進冠是「把核壓回去」，要城和屋頂兩樣都保，這件事誰也做不到；他用自己的火撐住了半個時辰，第三顆以後的核才沒有全落進城（寫一句他撐住的結果，讓讀者看見鬥聖真的在抵抗，不是白進去）。劫進冠是「把根拿走」，城保住，屋頂從此變薄。這是萊安德點頭的那條帳，鬥聖不肯付，也不是火修付得出的，因為殞星是雷，不是火。
2. **劫先失敗**。L225 第一次照九界取雷法從上面抓，被甩出來，補給見底，第四顆核從頭頂落進城。保留，這是「傷後列陣不比鬥聖強」的證據。
3. **讀懂冠的是鬥聖**。L227「你從上面抓，是抓樹梢。根在下面」保留，並且是劫走第二次的直接原因，老哈斯是給答案的人。
4. **第二次靠的是雷修本色和天地之法，不是力量**。刪 L238 期待句，改為「火從下面頂上去的路，雷修走得，火修走不得」。L231「雷不再找他」改為「他走在雷自己長出來的路上，雷認不出他是外人」（L364 試寫原句即可），不要和老哈斯受的雷傷並列比較。
5. 老哈斯看見少年往裡走那一句，照 09 檔原意寫「看見一個無翼的少年往裡走」，旁邊不加評語，城牆上的人跪下也刪掉。
6. 刪 L237「八萬年第一次露出一線星光」「冠開了一條縫」，改為「整頂雷冠鬆了一下，又收攏，比先前薄」。理由：二訪〈屋頂之帳〉的冠頂之洞與「可開可關」是第20篇的事；首訪先開一條縫會搶戲，也會被讀成星天圖投影。林妮亞上城牆一句一起刪。

### 3.6 特別判斷四：乙懸賞牌「手上護著的東西，另議」碰厄的伏筆

**判斷：會碰到，而且是兩層。乙不作基底；任何借用潮骨牌的寫法都照下面的安全版落。**

來源：
- `古戰與兩界衝突.md` B4：厄在聖土「被當成未知魔獸，覬覦牠的核」；「無核之獸」在聖土本身就是奇聞；**第19篇在 Hollowbeck 被當成無核之獸送上預展（全書只寫這一次）**；**第8篇在縫口第一次出力**。
- `劫厄與旅途同行者.md` L79：「落潮一年，在封合縫縫口第一次出力（只寫動作，不解釋）。」

乙碰到的兩層：
1. **標價**：L75 牌上畫一根指骨，寫「手上護著的東西，另議」。指骨是厄的殼，剝核人在狹路上看見「傷口裡還沒熄的縫雷殘光」（L57），又盯著指骨。讀者會讀成「有人在首訪就覬覦指骨裡那頭獸」，等於提前拿走第19篇 Hollowbeck「全書唯一一次」的戲。
2. **作者層把兩件事接起來**：L242「一年來一直伏在指骨裡、連莫爾坎的牌子都只敢寫『另議』的那個東西」，L360 試寫莫爾坎獨白「那根指骨裡伏著一樣東西」。這是旁白和人物替讀者把牌子與厄連上，超過「只寫動作，不解釋」。

**安全寫法（若主 Agent 借用潮骨牌或托爾貝克弧）：**
- 牌上只標人與雷：「潮裡掉下來的人。活的，三；死的，二。」不畫指骨，也不寫「手上護著的東西」。

- 厄的「縫口第一次出力」只出現一次。若採丙基底，就放在墜落那一窗（丙 L45）；回程縫口厄不動（丙 L277 只有走潮者）。
