## 採用與理由

採丙。對手在劫最弱的地方（三身搶一口氣）比他強，塔裡讓三身安靜三十息；劫主動遞狀挑戰，對手兩次真反制；劫贏在放掉那份安靜。歸山高點兌現卷五「明天起，掛九個」舊帳，是修行難關型，不撞生的霜降爐、不撞藏經閣選法。卷二十一賽果原樣成為帳的一頁，無新增陸沉敗場。

不採乙：《百足承山》與藏經閣同型（爭一部法、當場取捨），且提前給了三雷同出不炸與卷二十一「各雷只承一段」。不採甲：雷池三息改成改脈危機並搬到山14，撞現行日序與藏經閣時段；點將臺排在 Y484 已出卷十八窗口。

**依獨立比較窄修**：震魂聽預拍改為「記得節奏、用眼看先動的人」，不擴雷招；「不併」不寫旁註、不成新法；越庫庫門給韋自己的理由（例賞閱覽簿顯示劫瘋連日調同一段停用古路，他想起停用閘道仍帶水壓而自起疑）；借乙「整座院城都聽見」的見證層次。

**選後覆核有條件PASS，必修六項已實修**：M1 見證收回北院院內、鎮岳一峰，明註少年段唯一世界作證仍是卷五鎮鈴七枚；M2 破陣補局部修仙異象（鼓面令紋裂縫、分承光熄、沙下絆禁亮）；M3 卷二十二償還標候選；M4 韋當夜輪值夜巡、把巡路繞到西院庫門，與巡簿自領過失一致；M5 [天外四極](../../../../大綱/01_少年/23_天外四極/大綱.md)日表第53–66列補破陣並註處分不取消北院閱覽；M6 [逐卷修行所得與消化總表](../../../../大綱/00_全書骨架/01_人物線/逐卷修行所得與消化總表.md)卷十六至十九列同步。可選第1項（山4–10／山4–9不一致）已修；其餘可選留後。
