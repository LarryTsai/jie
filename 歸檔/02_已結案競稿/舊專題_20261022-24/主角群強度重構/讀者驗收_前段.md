# 讀者驗收：前段七卷（D157／D159 後）

驗收員：讀者視角，未參與 D157、D159 寫作與審查。只讀七卷大綱全文與兩份裁定；未讀整合稿、表格、設定。非正文，不改正式區。

## 逐卷

### 卷五 七峰爭鳴
1. **劫**：強，但強在巧，不在壓。最強一刻是鎮鈴七枚、坪裂到岳沉淵腳邊（L21），這是全卷唯一讓人倒吸一口氣的場面。賀成、岐影、石魁三勝（L261、L265、L305）都是拿肋骨、散形去換，觀感是「拚命贏」；點戰勝封寒（L358）精彩但贏一路雷身之差。卷末停在八強負生（L408），四天比完他以「八強」收場。被救：沈山河承石（L51）、岳沉淵承餘震（L228）。修東西：重鑿 L37–L71 整段是搬石換撐。
2. **同伴**：生最強（請長老等一息 L87、九圈 L93、決賽拍兩路 L478）。封寒只有改劍那一夜（L289–L293），三場正式賽輸三場；「看臺上沒人說封寒的劍輸了」（L364）是旁白替他說話，讀者看不出他是同代第二。
3. **敵人**：冉晴川、青璃寫得夠強；石魁有人生（L190）。
4. **毛病**：D157／D159 標記 42 處，最干擾的是 L309、L317、L319、L412、L418、L422。醫席驗傷與限制（L297、L402、L432、L470）一場賽寫一次，賽事規程（L241–L255、L329、L376–L384）和文末二十四人表、四十八場表（L591–L769）壓住了故事。

### 卷十三 五域大比
1. 強。小組敗後一句「後天」（L11），決賽讓第三疊打實、踩進第七疊換氣處（L13–L14），是前段寫得最好的「敗→討回」。
2. 同伴：無。
3. 俞清漪強，最後留下劫學不會的併拍（L14、L58），讓她輸了也有分量。
4. 本卷只有一張卡，其餘是制度和接口（L21–L66）；所得與賽制用的篇幅比比賽還多。

### 卷二十三 九界大比與返鄉
1. 最強三處：「是他們的。現在是我的」（L13）；念巴篆修陣帳（L64）；千礁「你左肋下第三根骨」（L110）。弱處：作者要的「壓倒性第一」只用概述交代（L15–L17「逐場打穿」「裁場止戰」），四場冠軍戰一場都沒有實際打出來；拆門制服裴照川也只有一句（L58）。強啟後一重不剩（L62）是他的錯，這處寫得好，也必要。
2. 雲行〈攏天〉三場（L37–L41）很好，苻冽跪一膝、全場第一次喊「攏天」。生七劍（L80）好。文奕只做了一件事：叫他停（L60、L62）。封寒缺席。
3. 千礁長老算得清楚、會撤（L112），敵人夠聰明。
4. 千礁長老、裴照川、至尊都是「被嚇住→撤／交人→走」的結構，開始重複。

### 離鄉01 第一次聖土
1. 強：齊見山試拳當場翻盤（L43）；鷹崖「落地以後，是我輸了」（L146）是前段最好的一句敵人台詞。弱：初救「劫仍需被抬回」（L21）；赫珈前退回外槽（L90）；骨河捨大殼帶傷退（L96）；薇瑟先手取器（L103）；柯梭先拿第一份（L188）。一年下來，他多半在修器、養傷、讓步。
2. 同伴四人：只有生在 L229 出現（是情緒戲，不是強者時刻）；其他三人缺席。
3. 盧修斯、奧默夠強。
4. 「不…不…」式的免責句太多（L11–L23、L109、L154–L160），像規格書。旁白概述也多：凱爾、族河、失日海大半是摘要。

### 離鄉02 上界追仇
1. 很強。「九界，陸家」逐一叫名（L102）、先殺最強的甯縈、「我知道。所以她先死」（L118）、丹台「爹，娘。這四個人，我找到了」（L124），是前段情緒與戰力最飽滿的一篇。
2. 同伴只出現在收件表（L16–L39）。
3. 四人各有本事與私心，甯縈「輸在情報，不是本事」（L102），贏得有分量。
4. 開篇先放一張訊件日帳表（L16–L39），讀者要讀三十行郵務才進故事；高潮段（L102–L118）每兩句插一條「不…」限制，打斷節奏。

### 離鄉03 多宗獵殺與九弱沉船
1. 「十三劃」（L143–L155）是前段最像荒的一戰：「上來的，報宗名」「倒雷井那個」。最後一夜爭骨勝牧昭（L130）也成立。弱：第一次爭骨失燈、折尾、右肩回震、丟場費（L73），又是「先手取物」；甄四海一節靠事先驗路撤走（L172），合理，但這已是本卷第二次撤。
2. 生「一炷香」「我替你推了」（L99–L114）乾淨利落，是同伴戲最強的一段。
3. 牧昭有自己的舟夢，像個真對手。
4. L22–L48 長段藥養、收件、代取站，張力最低。

### 離鄉09 渡劫淵到路身
1. 越至尊牆（L23–L29）的設計漂亮：反用歸墟、劫場釘死空間，封寒那句「聲音出不去」在這裡回收。弱：開篇羅不凋又先手取物（L11）；篇末鏽回真一、被蒼梧制住（L44），讀者最後留下的是「又被抓」。
2. 封寒量回聲（L13），算是借他的數，不是他的強者時刻；雲行立契由陸旁觀（L19）；文奕穩門檻（L42），只寫了一句。
3. 至尊與羅不凋夠強。
4. 卷尾工作註記段（L47）很長。

## 總評

**強者感：6／10。** 高峰真的有荒和王林的味道：鎮鈴、後天、千礁、鷹崖、倒雷井、十三劃、越至尊牆，七處都站得住。問題在高峰之間：每篇平均有兩三處「敵人先拿走東西」「帶傷撤」「養傷修器」，加上醫席與規程描寫，讀者對劫的印象被稀釋成「很會付代價的人」。同伴方面，生和雲行已經是真強者；封寒和文奕在前段沒有一個讀者記得住的強者時刻。

**最該再改的五處**
1. **封寒**：九界大比只寫了雲行（一之二），比照它補一張「封寒副場」卡，讓他以先探正面勝一位八界天驕、贏一場整場高光；七峰 L364 那句旁白刪掉，讓結果自己說話。
2. **文奕**：領印日 L60–L62，劫強啟失敗之後，讓文奕的禁把側廊和疏散隊列整段穩住，劫看著拆不了，這正是他「禁道第一」的第一次證明；目前他只有「叫劫停」這一個動作。
3. **「先手取物後退」套路**：薇瑟（聖土 L103）、柯梭（L188）、牧昭（九弱 L73）、羅不凋（渡劫淵 L11），四次同一形。只留牧昭一次；柯梭改為劫當場守住兩份，薇瑟改成未分勝負各退，羅不凋改為劫逼他棄幡、骨痕只帶走一半。
4. **九界冠軍要活出來**：L15–L17 從四場裡挑一場寫成卡（建議決賽梓葉），附一句台詞和一個看臺反應，讓「壓倒性第一」在場上發生，不靠旁白交代。
5. **規程搬出正文**：七峰 L591–L769 的表格、L241–L255 的賽制、上界追仇 L16–L39 的訊件表，都移到附錄或回填紀錄，正文只保留一句規則；各場醫席驗傷合成一段。

**標記清理：需要，建議另做一次。** 七卷合計 D157／D159 標記約 137 處，另有「工作方案／不冒稱／取代」類註記約 55 處，七峰一卷就有 42 處。建議把正文中的（D157）（D159）與「取代舊稿…」移到每卷末的回填紀錄，正文只保留故事；免責式的「不…不…」限制句另移到「設計約束」小節。
