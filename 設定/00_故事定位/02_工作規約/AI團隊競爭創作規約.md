# AI 團隊競爭創作規約

2026-10-08，作者工作模式。適用《劫》大綱、故事弧、正文與重建；補設定與審稿是支撐，不是交付物的全部。核心分工：作者提供方向與喜好，AI 承擔創造、比較、推翻與寫好故事的責任。

## 一、作者不必救稿

作者可以只說「喜歡」「不好看」「角色不像」「太小」「希望多年後再相遇」。主 Agent 將其轉成創作約束，保留其他已接受方向，主動完成新方案，不要求作者發明敵人、機緣或中段轉折才肯繼續。只有缺少不能推斷的必要資訊才問；可自行決定的常規創作先做。

稱讚不是工作成果。要指出構想能長出什麼、真正薄弱處在哪裡，也可提出更精彩的延伸與不同走法。作者否定舊稿時，不能靠補三句合理性宣稱重構完成。

## 二、三份競稿與獨立比較

主 Agent 先寫短任務單：作者核心構想、已接受人物與結果、入口與出口、相关 Canon 来源、可創造區、揭露鎖與上一稿為何無聊。三位寫手收到相同任務單，第一輪不讀彼此方案，分別寫獨立文件；不在共同主稿同時編輯。

真正不同至少改變兩項：核心欲望與承諾、主要對抗者、關係衝突、探索結構、高潮的選擇與代價。換名字、場景順序、寶物顏色或同一條任務鏈不算三版。各版須有可讀的一段關鍵場景試寫，不能全用功能標籤描述。

每份方案包含完整弧：人物當下想得什麼、何事迫使出發、進入後怎樣受阻、對手如何主動反制、局勢與關係如何轉折、高潮如何兌現、留下什麼實得與後果。配套中篇与小故事須改變主弧或某人的人生，不是湊章。

現有四槽時，主 Agent 加三位寫手先競稿；寫手完成後再啟動一位未參與構思的 Reviewer，讀三份稿與原始約束比較。槽位更少可分批，但不把同一人自評包裝獨立 Review。不擅自指定別種模型；只有實際可用與獲授權的模型才稱其參與，不能宣稱 Claude 寫過不存在的稿。

Reviewer 第一輪先比較閱讀欲望、人物与中段，再核 Canon，不參與選前代寫。須指出各版最值得保留的場景、最容易棄讀的段落、主要差異、Canon 風險及推薦／全退理由。評分可輔助，但不得以修到九分作終止條件，也不能用設定完善掩飾無聊。

主 Agent 依比較選出可推薦版本，說明取捨；可以有理由地不同意 Reviewer。若三版全弱，自主讓寫手重構核心對抗，不只潤色。向作者呈現簡潔差異與具體可讀結果，作者隨時可選、否定或改方向；可繼續非依賴性工作，不反覆要求批准常規細節。

## 三、中段必須值得追

大篇不靠好開頭與好結尾支撐。Reviewer 逐段問：這裡讀者期待哪件尚未發生的事？人物自己在追什麼？此次行動改變局面還是只多一份資訊？下一段為何非讀不可？

工作、救援、研究、交易與養傷可以寫，但要有競爭、欲望、未知、人物碰撞、技藝突破、失手或不可逆選擇的實際事件。若連續段落只做流程、付帳、通報、讀資料或善後，即使 Canon 全對也判中段失去牽引。換成凡人工作報告仍成立的核心，須重構修行與天地不可替代之處。

不要求每章大戰。安靜段可有難以說出口的關係變化、值得練的新法、陌生奇觀與真正喜悅；不能用密集反轉、每段死人或免費神寶假造精彩。勝場與所得要兌現、後來能用；代價不能吞掉一切回報。

## 四、Canon 查核與創造自由

主 Agent 保持本次入口状态、境界与能力、年月、持物、人物所知、关系、出口與後續鎖的短表。寫手依來源查，不以記憶猜；Reviewer 指出衝突時給出位置与證據。舊工作方案、新候選与作者定向分清，歷史 PASS 不代表現行稿已通過。

可創造人物、機緣、地方、對手、友情、愛情与大事件，先標工作方案，故事成立再同步設定。不得新增萬能規則解困、忘記可用能力、提前後期招法、無代價越階、把局部路變全界自由交通。作者明確改定之處更新相關入口與下游，保留歷史來源但標撤用，不讓舊紅線暗中否決新授權。

## 五、選後展開與交付

競稿先決定故事，不預鎖幾十章。選後展開完整場景群，Reviewer 重新檢查中段与邊界，再依小說擴寫和閉環審稿技能驗證。結構不好就回到競構，不把唯一版本磨到虛高分。

交付報告只講故事改變、最有看頭之處、採用與捨去理由、實際驗證及待定項。主 Agent 負責發現並修正同步問題。正文變更才要求開發／出版同體；只做大綱就如實說是大綱。可審閱里程碑依既有自動保存授權與 commit-and-push-story 技能提交推送，不force push，不丟棄共享修改，不宣稱下線仍有團隊工作。

本規約取代[舊單寫手／Reviewer 協作方式](../../../待整理/大綱/Phase2_後半部開荒/專職閱讀欲望Reviewer_協作規約.md)的創作流程，保留其閱讀欲望與安全保存原則。

角色派工與共用創作要求見 [AI團隊](../../../AI團隊/README.md)。此入口補強完整修仙故事、人物自主人生與長線回收，不取代本規約的三寫手隔離及獨立比較。
