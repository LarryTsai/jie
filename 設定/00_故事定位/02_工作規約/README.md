# 工作規約

AI 團隊的工作規則：怎麼發展故事、什麼時候不能寫正文。所有 AI Agent 適用，入口摘要在根目錄 [AGENTS.md](../../../AGENTS.md)。

## 收錄

- [AI團隊競爭創作規約](AI團隊競爭創作規約.md)：三寫手競稿加獨立 Reviewer 的流程（2026-10-08 作者要求）。
- [逐章解凍與正文寫作規則](逐章解凍與正文寫作規則.md)：目標章之前所有章節正文定稿，且本章大綱由作者釘板並可直接落筆後，逐章解凍；未解凍章的檢驗用試寫須標「試寫／非正文」（2026-10-24 作者定）。
- [長篇連貫性與劇情規劃規範](長篇連貫性與劇情規劃規範.md)：動筆前檢查、事件六要素（起因、選擇、結果、後果、延續、牽引）、篇章規劃、完稿後連貫性審查與創作優先順序（2026-10-30 作者定，D172）。
- [卷大綱結構標準](卷大綱結構標準.md)：所有分卷照卷一〈浮石之下〉組織——卷導覽、全卷總綱必備各節、分段資料夾與章綱表、段號-章號、正文分段；不符不得釘板開寫（2026-10-30 作者定，D173）。
