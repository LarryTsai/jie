# 世界建構方向

效力：作者於 2026-10-02 同意的文明建構方向。這是建構目標，不表示各項細則或終局答案已批准。具體制度以現行設定及決策為準。

即使拿掉陸沉、封寒、雲行、文奕，世界仍應有自己延續的生活與歷史。仙感要落在生存、出行、傳承、信仰及遭遇裡；人物不是只為主角提供材料或答案。

## 十二個建構面

| 面向 | 大綱與設定要能回答的問題 |
| --- | --- |
| 日常生活 | 修士怎麼居住、吃喝、工作、相處？ |
| 社會制度 | 宗門以外有哪些身分與組織？ |
| 資源生態 | 靈材如何生長、採集、消耗與再生，會引發什麼爭奪？ |
| 知識體系 | 知識怎麼積累、傳授、校驗及失傳？ |
| 基礎設施 | 城市、交通、訊息如何運作？ |
| 法律與暴力 | 誰有權查、判、追捕，遇到強者又怎麼辦？ |
| 生老病死 | 療傷、死亡、繼承與活著的界線如何影響人？ |
| 信仰祭祀 | 普通人相信什麼，有哪些禁忌與祖先習俗？ |
| 歷史層積 | 遺跡、古文字、陣紋、墓葬如何留下不同時代？ |
| 文化差異 | 各界飲食、禮俗、戀愛、師徒與妖族觀念怎麼不同？ |
| 非主角人生 | 普通修士、轉行者、失敗天才是否有自己的故事？ |
| 自然法則 | 世界本身仍有哪些未解之謎？ |

## 作者同意的建構順序

1. 讓世界活：職業人口、普通修士的一生、職業樹、城市日常、資訊與交通。從測資質、求學、轉行到家庭晚年；傳訊的速度、阻斷及偽造能力要能影響故事。
2. 讓文明運轉：靈氣與資源循環、法律、宗門財政、死亡與繼承、教育及古法今法。洞府、功法、本命器與債務的去向，不只是一張背景表。
3. 讓世界有靈魂：九界文化、娛樂與酒、婚姻家庭師徒、喪葬信仰、普通人的夢想與失敗者。這些面向可以生出配角弧，不能只有講解。

職業可涵蓋生產、丹器符製造、陣禁與地脈工程、舟師驛站與界路交通、商會押運、醫療、史官與情報、行政法律、遺跡冒險、樂修及幻術表演；具体准入與能力仍查現行制度。聖土須按自己的鬥氣文明建構，不直接套九界制度。

## 留白與採用邊界

靈氣、大道意志、天劫、世界生死與世界之外，只能保留為作者層問題；本檔不給答案。舊來源的「改道」是探索可能，不是終局選定方向。生活候選尚未批准的細則仍為候選。

創作及裁定流程依[AI 團隊入口](../../AI團隊/README.md)與現行工作規約；舊來源逐題詢問作者的流程不取代作者如今授權 AI 自主發展故事的規則。
