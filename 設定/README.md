# 設定讀取入口

2026-10-08 精簡後：設定是查閱資料，不是每次創作都必須載入的整包上下文。

1. 先讀[故事定位](00_故事定位/README.md)與本次故事入口；最新作者改定優先。
2. 只讀本次人物、境界、雷法與地點的專檔，不預設需要讀全名冊或整份武學譜。
3. 查近期改定用[近期決策入口](06_待定與決策紀錄/README.md)；查舊D號與原方案才開歷史紀錄。
4. 歷史提案、被否決方案及舊版本審查已移到[設定歷史歸檔](../歸檔/設定歷史/20261008/README.md)，不作日常必讀，不從歸檔恢復撤回設定。
5. 未採候選仍可用於創作，不視為 Canon。人物名冊、勢力總表與家底卡各有檢索用途，不按篇幅大小裁掉人物人生。
