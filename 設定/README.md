# 設定

Canon 查閱區：世界、歷史、人物、修行、主線揭露與寫作規則。設定是查閱資料，不是每次創作都要整包載入的上下文；只讀本次用到的人物、境界、地點與規則。

## 讀法

1. 先讀 [00_故事定位](00_故事定位/README.md)：敘事意圖與寫作規則。作者最新指示優先於任何舊檔。
2. 只查本次需要的專檔；各資料夾 README 列出檔案與效力。
3. 近期裁定查 [決策](../決策/README.md)；故事順序與篇章查[大綱區](../大綱/README.md)，入口是[全書故事順序總覽](../大綱/全書故事順序總覽.md)。

## 效力詞

檔頭「狀態」一行寫效力，README 以〔〕標出非定案者：**作者定／定案**（D 號）＞**設計採用**（依授權選定）＞**現行提案**（作現行用，作者可改）＞**候選**（可用於創作，不是 Canon）＞**留白**（不得自行補寫）。效力寫在檔內，不寫在檔名。

## 乾淨度

- 一主題一檔；同一事實只有一個現行出處，其他檔連過去。
- 大檔（約 60KB 以上或混多主題）拆成有階層的子檔，拆分以原章節為界，錨點附對照。
- 不放：競稿、提案原稿、修訂往返、審查與核對紀錄、工作流水、故事順序與篇章大綱。這些放討論區（待整理/）或大綱區。
- 提案經作者裁定後，主 Agent 只把已選條文抽進設定；原提案留討論區追溯。

## 命名

資料夾一律「兩位數序號＋底線＋名稱」；說明檔一律 README.md；其他檔用主題名，同夾有閱讀順序才全部加序號；檔名不放日期、版本、狀態字。
