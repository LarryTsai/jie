依據：作者拍板 Q27「不用化身」全面適用。所有人跨層、跨界都用本體，不論主角或反派；三十二天內部（九界、下無極、上無極、大羅之間）也一樣。撤回雷身化身、分神化身、法身入界等一切「化身入界」寫法。本條由推理主線偵探、修士邏輯、修仙戰力、網文節奏四位專家交叉詰辯後收斂。

### 一、入九界規則（取代「入境上限列陣、高境者以化身入界」）

- **界壁秤本源**：九界界壁承載不了列陣以上的修為，秤的是本源裡實有的修為；自己封住修為過不了界壁。
- **只有兩條路**：
  - **壓境**：只能走正規界路。錨陣把列陣以上的修為壓出、封存在上端，下端守界傳承持對印，兩端合印才取回。代價是修為押在掌管界路的王庭手裡、有期限（量級數月，確切待定）、錨陣容量有限（雷身每具各算一份）、兩端記壓境簿與氣機拓印、身上有壓痕。
  - **退境**：散功，任何路可走，不可逆，出身處記著。
- 天然列陣以下的人不用壓境，走正規界路照樣登記通行簿；走險路、低路不登記。
- **為何上界強者不下界**：只剩列陣之力、仙力不能運轉、修為押給別人、住不久、退境代價是半生修為。
- **為何萬年未解**：壓境就是戰後的解法，卻讓錨陣掌管者握住下界者的修為；補界壁等於動封合縫；救援派、守界傳承、掌管界路的王庭都要這條線留著，只有歸一派想拆。
- **三十二天內部**：無入境上限，本體經仙路關口留記錄；關口歸屬與憑證待定。
- **雷身**：跨層跨界時與本尊同進同出，本源不能分處界壁兩側。
- **用詞**：「壓境」專指上述錨陣壓境；陸沉在聖土「壓著尊者關口不突破」改稱「壓關」。

### 二、證據規則（取代「化身是因果的防火牆」）

本體不能分在兩地。高位者要讓事在九界發生只能派人；因果防火牆改由分段命令承擔：追到被派的人為止，他找得到、搜得了魂，卻只吐得出自己那一段。每個跨界本體都留痕：兩端通行簿與壓境簿（上端會被對齊、下端沒有）、頂得了名籍頂不了氣機拓印、壓痕與散功痕、上界的行程缺口。

## D028：北天天幕展疆與五方格局

北天採天幕展疆規則：不同空間層依天象週期接軌，開出的土地原本便可能有國家、宗門與族群，不能視為無主秘境。疆域分為定疆、候天帶與深北；天圖必須同時記錄方位、開啟時序、維持時間與回程條件。

第一輪代表勢力定為量天臺、逐日城、萬壑宗、鏡海宮與重新接軌的宵衡古國；代表天驕為顧星遲、裴雁回、石聞川、蘇映真、黎見朔。北天以巡天試選拔五域大比人選，兼考正面鬥法、辨路、救援和服從撤離令。當代疊天錯位源於定疆定辰碑與宵衡鎖天輪兩套救人法統爭奪相同天幕節點，與劫、指骨、九雷及上古陰謀沒有直接同源關係。詳見[北天宗派與天驕](../01_世界格局/五域/北天宗派與天驕.md)。
