## D025：南荒三方、五傳承與百川會

南荒由垂天林海、百川水原、赤燼火嶺構成；萬生古盟與青約庭、河網城邦、燼梧諸氏三方並立。五個代表傳承是萬生古盟、燼梧諸氏、回瀾宮、枯榮谷、星槎門；代表天驕為桑遲、烏照夜、俞清漪、寧知微、紀南舟。南荒以個人鬥法及水陣實試並行的百川會選拔人才，大靈汛時另共同推舉不得連任的持潮人。完整內容見[南荒宗派與天驕](../01_世界格局/五域/南荒宗派與天驕.md)。

近二十年的異常靈汛是南荒長期水火地脈與各方行動累積造成的真實問題，不直接源自劫、指骨或上古主線陰謀；敵人可以利用，不能成為一切成因。作者層真相定為定川大陣固定主河、古盟補林造成根系過密、諸氏抽取地火三者共同使地下水穿過遠古枯林層，帶出死氣並滲入火嶺。三項措施過去都曾救人，因此解法必須由三方共同承擔損失。五名天驕曾於水城潰堤共同救災，但不因此預設為摯友或固定代表隊。

## D026：異族年齡、化形、契約與跨族後代

異族以命輪成熟度對照人族二十歲門檻，並檢查心智、實際修行與血脈蛻變，不能靠晚化形或沉睡規避。化形是受生命形態與傳承影響的能力，不是固定境界獎勵；維持獸形不影響人格與參賽權。

自願互惠者為同命契，單方面控制生死者為役魂印；萬生古盟、鳴野宗與南荒城邦禁止後者。跨族後代須視生命形態與修為條件而定，能力不固定各半，龍鳳血脈亦可能隔代或不覺醒。詳見[五域特殊族群分布](../01_世界格局/五域/五域特殊族群分布.md)。

## D027：六域正式名稱與文明核心

作者確認劫故土六域正式定名為**東溟、中神州、北天、西極、南荒、天域**。東溟以海洋文明為核心；中神州是多重文明交匯之地；北天的核心是尚未探盡的未知疆域；西極以道統、古路與前代文明交錯為核心；南荒是火脈、巨林、河川、山國、城邦與多族文明共同生活、持續變動的大地；天域是與其餘五域平級的天空文明，具備完整國土與社會，不只是九院及上界門戶。

舊文件中的「北域、西域、南域」僅為方向泛稱，現行設定一律改用北天、西極、南荒。五域大比是既定賽事名稱，不因大域定名而改稱。詳見[故土六域](../01_世界格局/劫故土六域與太玄宗.md)。

## D029：大羅界、無極與返本入內

作者確認：戰前完整天地稱**大羅界**，仙庭是大羅核心的秩序與帝位所在，與大羅界本身區分；戰後結構為九界 → 下無極 → 上無極 → 大羅界。「無極」指被拉離核心、失去中心的仙土。修行是返本入內，下界仍稱飛升；大羅之內暫稱「道」，不再疊加更高世界。

同時裁定：原始討論中的「萬千下界」不採用，維持九界；上下九庭分組不採用，維持 D013 的王庭不分九強九弱、可跨層立足（作者授權 PM 決定，理由是九強九弱曾被明確撤回，且跨層王庭較利於政治描寫）。取代原「戰前完整天地只稱無極」「仙庭即最內層」的寫法。

影響文件：[權力根基](../01_世界格局/仙庭與王庭權力根基.md)、[世界格局](../01_世界格局/README.md)、[歷史背景](../02_歷史背景/README.md)、朔河王庭。原始討論存於[大羅界與返本入內](../../歸檔/原始討論/JIE_DALUO_RETURN_SOURCE_20260928.md)。天地歸一主張、高境界術語列為 Q13、Q14。

## D030：「九強九弱」保留為錯誤俗稱；下界對上界所知

作者選定：規則上仍無九強九弱正式陣營（D013、D029 不變），但這個說法作為仙界流傳的簡化俗稱存在，常附會成九弱在下無極、九強在上無極；它不準確，可用來寫人物眼界、偏見與利益。

## D028：北天天幕展疆與五方格局

北天採天幕展疆規則：不同空間層依天象週期接軌，開出的土地原本便可能有國家、宗門與族群，不能視為無主秘境。疆域分為定疆、候天帶與深北；天圖必須同時記錄方位、開啟時序、維持時間與回程條件。

第一輪代表勢力定為量天臺、逐日城、萬壑宗、鏡海宮與重新接軌的宵衡古國；代表天驕為顧星遲、裴雁回、石聞川、蘇映真、黎見朔。北天以巡天試選拔五域大比人選，兼考正面鬥法、辨路、救援和服從撤離令。當代疊天錯位源於定疆定辰碑與宵衡鎖天輪兩套救人法統爭奪相同天幕節點，與劫、指骨、九雷及上古陰謀沒有直接同源關係。詳見[北天宗派與天驕](../01_世界格局/五域/北天宗派與天驕.md)。
