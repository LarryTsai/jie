# 文・文奕

## 新版已確認

文奕出身中神州禁制世家。五域大比開始前，各方在中神州集合時，他才與劫等人認識。不是幼年在虛神界已結識的舊版關係。

## 從既有人物保留的參考方向

文奕有深厚的禁制學養，也能正面作戰。他面對前人的答案，傾向先理解為什麼成立；劫傾向追問還能怎麼改。（D071 已定案，見下方「四人定案」。）兩人可以互相啟發、爭論與合作，不是單向授課或隨身解題的關係。友情如何形成，要由具體共同經歷建立。

## 舊稿銜接邊界

舊稿上界文家、幼年降界尋典、虛神界初遇等背景被新版出身與相識順序取代。《古神禁典》、家族祖典、護道人及舊家族劫難不因參考人物檔便自動沿用。文家在中神州的地位已定（見下節）；家人與參賽身分仍待發展。

**《古神禁典》共得（D095 第 1 條；D099-2 修訂時序）**：《古神禁典》由「不沿用」改為回來，是異端禁道仙王所留，**不是文家祖典**（文家另有祖典＝新版文家家學）。文家一直在找它；新卷七中神州仙王遺跡，文奕因此而進，與陸沉從兩頭反解古禁，**各得同一部完整的禁典**（「書無先後，也無正副」）。陸沉在卷一埋王嶺已先得另一位禁道仙王的禁意傳承（讀、拆、布自己的簡單禁），卷七是他的禁「全面起飛」。

## 文家（D060 作者定）

文家是**中神州一流世家**，以禁制傳家，與推演、陣道古宗**大衍宗**論學數百年。家主、家人與文奕在族中的位置未定，不新增人物；文奕在族中的一個位置已定：他是這一代的守燼人（作者再補記，2026-10-02，二；見下文「赤翎的約」）。見[劫故土六域頂級勢力](../../01_世界格局/勢力/劫故土六域頂級勢力.md)。

## 起始目標（作者定，2026-10-03，SETTING FREEZE v1 第 2 件）

> **證明文家禁學沒有失傳。**

- 初登場（第 3 篇中神州集結、五域前）他具體想要的是這個。對頭南榮氏散布「文家禁學已失傳」（見下「對頭」），五域大比、萬禁會守禁一局都是他要證明的場子。
- 這是**家族的目標**，不是他自己的：正好暴露盲點「理解所有立場，自己沒有立場」。他連想要的東西都是替文家想的。
- 走向：第 27 篇赤翎立約，是他第一個自己選的私人立場；第 28 篇立錨、起草九界之禁，是第一個公共立場。從「證明家學」走到「立一個自己的答案」。
- 與守燼的關係：守燼也是家族派的；守燼讓他讀得懂文家禁學的源頭，所以他比誰都知道家學沒失傳，只是有一捧燼他推不出是誰。

## 四人定案（D071，2026-10-02）

> 劫想改變答案，瘋想找到唯一答案，雲不需要答案，文奕只想知道答案為什麼成立。

依[四人核心定案提案](../../../歸檔/設定歷史/20261008/06_待定與決策紀錄/四人核心定案提案.md)第二、四節，作者拍板。

**定位**：第四個核心同行者，**不是第四條道**。他是**理解者，不立道**：理解世界的人。四人裡只有三條道（變、知、無）。

| 項目 | 文・文奕 |
|---|---|
| **道（作者層工作詞）** | **不立道**：理解者，要知道答案為什麼成立 |
| **核心問題** | 它為什麼是這樣？ |
| **一生要回答的** | 我能說明每個答案為什麼成立，哪一個是我自己的？ |
| **認知方式** | **建模與推本質**：給他十息，懂九成九；看得見結構、冗餘和死點。代價是戰場上沒有十息。看得最深，不是算得最快（第 3 篇奚箴比他快），也可能看錯地方（顧星遲「你們兩個是不是看反了」）。這兩場要保留 |
| **IQ** | 作者層硬設定：IQ 230。正文以修士尺度呈現（神識推演的深度、幾息內懂幾成、能同時持住幾條念頭），數字不入正文 |
| **戰鬥風格** | 禁制師，有正面戰力，不是文弱軍師（舊版沿用）。先布後戰；禁越來越能自己轉，人走了禁還在（舊版「禁→生命」）。以**八卦盤**預推。弱點：遭遇戰、推演被打斷、對手不照模型走 |
| **技能趨勢** | 越來越**早**：十息搬到戰前，最後禁在開戰前就把仗打完了 |
| **日常癖好** | 轉八卦盤；吃飯前先推完一局；「給我三天。」「你們兩個先不要動。」（舊版長篇稿原句）；腰背挺直（舊版初登場描寫） |
| **盲點** | 理解所有立場，自己沒有立場；把人也建成模型，忘了人會在他推完之後改變；不會把自己放進模型（所以他和奚箴走得慢） |
| **終極難題** | 理解了，然後呢？從看懂別人的答案，走到立一個自己的答案（第 28 篇立錨、起草九界之禁） |
| **「如果你今天已經天下無敵，明天要做什麼？」** | 「先搞懂我為什麼無敵。有原因，就有破綻。」 |

**八卦盤（正名）**：文家的推演法器，正式名稱定為「八卦盤」（D071）。與荀恆的推演盤（第 25 篇的後手）**不同名、不同用途**，不得混用。品階：**本質上品靈器**，文家祖傳，由他自己祭煉（D073）；見[寶物總錄](../../04_修行與特殊事物/寶物/寶物總錄.md)。

**守則**：不當解說員，不替陸沉解題（D058）。他的理解只能用三種方式進戲：給出一個結論，別人不一定聽；來得太晚（戰場沒有十息）；推錯了，或看錯了地方。**每篇至少有一次是後兩種。**他的學問也有到頂的地方：第 6 篇後裔村祭陣，他看了說「這不是禁，是祭。我的學問到這裡為止。」（建議台詞；祭陣的銘意留給第 12 篇裴照川讀懂。）

**與封寒切開**：他是說知（推知），站在外面，不必碰；封寒是親知，非碰不可。所以第 18 篇破禁讀殮錄的錯只會是封寒的：他推得出殮錄大概寫什麼就滿足了。

**兩兩關係**（全表見[人物關係](../人物關係.md)）：
- **文 × 劫**：研究者對工程師。文奕給深度 → 劫去實驗 → 產生新資料 → 文奕重新理解 → 劫再造。吵點是「給我三天推演」對上「不用，雷下去就知道」。
- **文 × 瘋**：最常吵架，也是最恐怖的組合：看得見瑕疵 × 做得到。「我推得出來，不必進去。」「你推的是你的模型，不是它。」吵完，他給一個點，封寒一擊落在那個點上。
- **文 × 雲**：最能夜談。他推得出所有人，唯獨推不出雲行為什麼不需要知道；雲行是唯一會問他「那你自己呢？」的人。

**四人同場**：他是第三拍：「你們兩個先不要動。先搞懂這是什麼。」每段同行至少要有一次他的「三天」是對的。

**同行方案（甲案）**：第 3–7 篇四人旅行段；第 8 篇他第一個選擇不跟；中段跨界循環；第 22 篇陣核同場；第 25、28 篇重聚。「文奕最後上界」不動。第 27 篇聖土維持現行，**他不去**，在九界與翁蒂娜算窗口。

## 赤翎的約（作者再補記，2026-10-02，二）

赤翎的同命契與文奕立，不與陸沉立（原「蒼梧與文奕立約」已由作者再補記改為蒼梧與封寒）。**家族從小配的。**

**D075 定案（2026-10-02，作者拍板，方案 4A）**：文家保管的是**某一世**的燼。細節依[赤翎文奕與蒼梧封寒緣由提案](../../06_待定與決策紀錄/赤翎文奕與蒼梧封寒緣由提案.md)第二節；赤翎本人見[劫厄與旅途同行者](../../04_修行與特殊事物/劫厄與旅途同行者.md)。

- **古約**：赤翎每死一次就化成燼。燼上的禁紋就是古約本身，是文家祖上親手刻在那捧燼上的禁；古約的另一半刻在驤鳴雷池底，平時被雷水蓋住。條文大意：「代代守，不許散，不許用；池不能劈之日，燼歸其主。」古約上寫的是「須凝核之雷」，不寫人名。
- **燼怎麼並存**：雷池裡是她這一世的燼，每死一次由雷池的天然雷劈回；文家那一捧是古戰那一世分出去的，從來沒有被劈回來過。兩處同源，所以互相感應。
- **文家不知道那捧燼是誰**：「其主」是誰，傳到文奕這一代已經沒人說得出來。禁制世家守著一個讀得懂、卻不知道是誰的禁，這是文奕的第一道題。
- **古約對文家的代價**：每一代挑一個守燼人；燼上的禁要靠活人的神識溫著，隔一段時間不溫就鏽，守燼人不能離燼太久（量級留白）；文家世代守著一個讀得懂、不准用的禁，對禁學世家是很重的帳。對手南榮氏散布「文家禁學已失傳」，可與此咬合，不強求。
- **守燼的童年**：族裡要找一個神識穩、坐得住的孩子。文奕被選中時大約六、七歲；他根本坐不住，族裡選他，是因為他是唯一一個會對著燼說話的孩子（建議台詞，族中長輩：「別人是溫禁，他是在跟它聊天。」不新增有名有姓的文家人物）。每天讀一遍禁紋，用神識把鏽的地方溫回來，然後說話：說天氣，說今天推了什麼局，說和奚箴的論學又輸了一場。燼不回答。
  - **理解者怎麼養出來**：一個不會回答的東西，只能靠讀懂它來認識它。他從禁紋讀出刻禁人的手勢、哪一筆猶豫過、哪一筆後來補過；他後來看人也是這樣看：先看結構，再看哪裡改過。
  - **盲點的起源**：那捧燼從來不會在他推完之後改變；他「忘了人會在他推完之後改變」，就是在這裡養成的。
  - **第一個推不出的東西**：他推了幾十年，推不出它是誰。這和他後來推不出雲行，是同一種空白。
  - **可選暗層**（不改現行寫法）：第 8 篇留在九界，守燼可以是他不說出口的第三條理由，不取代前兩條；第 28 篇起草九界之禁後上界，燼已經歸主，他第一次可以走。
- **第 23 篇，遺痕與後手**：驤鳴炸池，赤翎死在池裡，池中之燼散盡；池底露出古約的另一半禁紋，陸沉認出是文家的手法。同一時間，文家那捧燼**熱了起來**，他讀到禁紋上「池不能劈之日」那一行亮了。兩人的信在路上交錯：陸沉寫「雷池底有你家的筆」，他寫「我守的那捧燼，熱了」。之後他再守十三年，這一次知道自己守的是誰，對燼說的話和小時候不一樣了。
- **第 27 篇出發前，相認**：陸沉在長亭天以殞星劈中那捧燼，她回來。她看陸沉、封寒、生都不認得，看到他，說：「**你是那個每天說今天下雨的人。**」她不記得他，但燼記得：她帶回來的是燼在文家聽了幾十年的聲音。
- **立約（第 27 篇，陸沉入聖土期間，九界這一端）**：她自己問：雷池沒了，她下一次死，燼放哪裡？他先說明古約已經履行完畢、文家可以怎麼安排；她打斷：「那是你家跟雷池的約。我跟你，還沒有。」**差點不立**：他說「給我三天」；她說：「你推了我幾十年，推的是一捧灰。我現在會走、會吵，你再推三天也推不準。」他沒有推完就答應了，**這是他第一次在推完之前做決定**。兩人立同命契；這一場寫短。
- **形式與代價**：她死時契玉碎；他保管碎片與她的燼，等陸沉的殞星；她回來之後要不要再立，由她自己決定，他不能拿殘片替她答應。他從「家族派的」守燼人變成「自己選的」；他的第一個私人立場給了一個會在他推完之後改變的人，每一次她回來，模型都要重建一次。這是第 28 篇立錨（公共的立場）之前，他私人的第一個立場，一私一公，不搶第 28 篇。**守燼是家族派的，立約才是他自己選的**：不得把他寫成早就有立場的人。
- **拿掉劫還好看的戲**：中神州夜市，她要去吃東西。他推她會想回驤鳴，她說想看文家人吵架。他第一次推錯一個「人」，在攤子前愣住，她把一串東西塞到他手裡：「你小時候說過這個好吃。你忘了，我沒忘。」
- **欠的是劫的雷**：她仍然必須靠陸沉的殞星劈回來；約不與陸沉立。

**留白**：文家為什麼守（甲欠命、乙換讀禁、丙只寫「欠」，待作者）；古約年代、是否早到兩界停航以前、文家從立約之初就守還是中途承接；守燼的禁室在哪裡；第 3 到 7 篇四人旅行時守燼怎麼辦（帶著走，或由族中暫代）；「怪人」身分維持懸空。不得碰赤翎一脈怎麼滅絕（D068）。不新增文家人物。
