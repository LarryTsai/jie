## 俞清漪


<a id="俞清漪--身分"></a>
### 身分

南荒回瀾宮當代代表天驕之一，十六歲，出身河網城邦，自幼學習辨認靈河改道與水陣承載。

<a id="俞清漪--性格與願望"></a>
### 性格與願望

俞清漪外表沉靜，實際控制欲很強，習慣把戰場每一處變化納入自己的水勢。她不是為了顯得冷淡而少言，而是總在計算下一股水勢將落到何處。

異常靈汛使她第一次面對回瀾宮既有水法也無法完整解釋的變化。她參加大比，希望接觸其他地域的地脈與陣道，找出南荒主陣忽略的部分。

<a id="俞清漪--修行與招式"></a>
### 修行與招式

- **聽瀾**：由水面、濕氣與靈流變化判斷術法落點。乾燥、烈火或刻意製造的亂流會降低準確度。
- **九疊回潮**：不急著正面抵銷第一擊，而將自身水勢逐層疊入對手節奏，最後一次回推。可借力但有承受上限，超出疏導能力便會反噬自身經脈。
- **分洪線**：在有限範圍內替洪水或水法打開新的流向。它只轉移力量，若沒有安全出口，危險會落到別處。

她持有一面**涵月水鏡**，能保存短時間內接觸過的一種水勢紋理，供她重現其中一部分節奏。水鏡只能留一種，不會複製對方完整法術；更換時舊紋消散，品階待配。

<a id="俞清漪--與劫"></a>
### 與劫

劫的不同雷身能同時改變距離與節奏，是她在五域大比中最難完整納入水勢的對手之一。她可以察覺多道力量彼此相連，不能因此直接知道雷身全部規則。

<a id="俞清漪--與劫：錯過（作者定，2026-10-01；篇次依總稿-v3）"></a>
### 與劫：錯過（作者定，2026-10-01；篇次依總稿 v3）

她是「劫錯過的女人」。第 3 篇五域，水患夜與他並肩救村；五域決勝兩人真分勝負，她以九疊回潮贏了。第 8 篇落潮一年，她來留舟島找過他，早他一個月回南荒，沒有告白，也沒有狗血。很久以後在九界重逢（第 27 篇，他出發去聖土之前）：她已是回瀾宮主、南荒巨擘，在回瀾宮水門親自開了當年那條水路，不關他、不核驗。兩人只說一句：「還活著？」「你都沒死，我急什麼。」然後各自走。見[同代女天驕群像](../同代女天驕群像.md)、[主線路線總稿](../../05_故事主線與揭露/主線路線總稿.md)。

<a id="寧枕微"></a>
## 寧枕微


<a id="寧枕微--身分"></a>
### 身分

南荒枯榮谷當代代表天驕之一，十五歲，修習下界九階丹體系、丹毒與解毒。她不把毒道包裝成邪術，也不認為會煉療傷丹便天然仁善。

<a id="寧枕微--性格與願望"></a>
### 性格與願望

寧枕微說話直接，對劑量、時間與身體反應近乎苛刻。她反感用「大概無礙」掩飾未知，也不會因對手修毒便先判定其邪惡。

她在異常靈汛的洪水中驗出微弱死氣，卻無法從南荒既有靈材與地火找到完整來源，因此希望從其他地域的丹師、毒修與異變記錄中尋找對照。

<a id="寧枕微--丹道與戰鬥"></a>
### 丹道與戰鬥

- **雙相丹**：將作用相反的丹性分置內外兩層。完整服下可依次護脈療傷；震碎特定外層則能散出麻痺經脈的丹霧。實際效果受丹藥階位、雷紋、對象境界與事前配伍限制。
- **辨微火**：由丹火回應辨認少量異質藥性或毒性，必須取得樣本並實際試煉，不能隔空看破未知力量。
- **逆序解丹**：依已知配伍逆推解毒次序。缺少材料、判錯毒性或對方臨時改變配方時都可能失敗。

她使用**轉心丹匣**分隔不同丹藥與引爆用丹殼，匣內禁制可依固定次序彈出丹丸，不能自行煉丹或無限儲物；品階待配。

<a id="寧枕微--與劫"></a>
### 與劫

她可能由雷火落點、控火停頓與成丹習慣察覺劫身上存在數套細微差異，只能得到「這不像單一身體養成的習慣」這一層疑問，不能初見便識破雷身。

<a id="寧枕微--同代交錯（d066；篇號依總稿-v3）"></a>
### 同代交錯（D066；篇號依總稿 v3）

與**生**是最重要的一條：丹醫對丹毒，對手兼摯友。第 4 篇天域書院共享火院一爐兩主，她與劫爭爐位，第一個從爐火看出他「不像單一身體」；第 15 篇她飛升後被請來替九界金丹校劑量，不接受「大概無礙」；第 16 篇上界同代齊聚，她亮出逆序解丹；第 28 篇守錨之戰，與生守住被牽動的人。見[同代女天驕群像](../同代女天驕群像.md)、[主線路線總稿](../../05_故事主線與揭露/主線路線總稿.md)。

<a id="寧枕微--對頭"></a>
### 對頭

枯榮谷叛出的毒修蓼紅；第 16 篇她從玉壺丹方裡驗出的那一味麻散出自蓼紅之手。見[各界反派](../../01_世界格局/勢力/各界反派/陸沉故土.md)。

<a id="桑遲"></a>
## 桑遲


<a id="桑遲--身分與年齡"></a>
### 身分與年齡

萬生古盟、青約庭當代代表天驕之一。她是由古樹落枝重新生根後孕生的新木靈，實際誕生四十餘年，命輪成熟度約等於人族十六歲，符合年輕天驕標準。

<a id="桑遲--性格與本相"></a>
### 性格與本相

桑遲性子急、好奇心強，最討厭別人因她是木靈便認定她沉靜遲緩。「遲」是古盟長者希望她學會等待而取的名字，結果始終沒能約束她。

她平時維持近似人形的木靈姿態，皮膚帶有淺淡木紋，髮間會隨靈力狀態抽出嫩葉。這不是人形比本相高貴，而是她的落枝本體生來便長成適合行動的形態。

<a id="桑遲--修行與招式"></a>
### 修行與招式

她以自身根系接入地面，感知震動、地脈與附近生機。

- **聽根**：由根系辨認腳步、地下空洞與靈力流動。離地、隔絕陣法與混亂地脈會使感知失準。
- **盤春牢**：催生粗根封鎖數個落點，逐步縮小對手活動空間。需要接觸土地，堅石與火場會增加消耗。
- **渡青息**：把自身生機渡給傷者，暫時穩住傷勢。轉移的是桑遲真實擁有的生機，不能無限救人，也不能使死者復生。

她以本體自然脫落的枝節編成**四時木環**，平時套在腕上，落地後可作快速扎根的媒介。木環品階與能承受的破壞待配，不是離開森林便能憑空生成整片樹海的神器。

<a id="桑遲--當代位置"></a>
### 當代位置

異常靈汛使古木根系出現不尋常腐爛，她參加百川會及五域大比，也想離開南荒尋找其他地域是否出現同類徵兆。她曾在水城潰堤時與另外四名南荒天驕共同救災。

[南荒宗派與天驕](../../01_世界格局/五域/南荒宗派與天驕.md)

<a id="桑遲--同代交錯（d066；篇號依總稿-v3）"></a>
### 同代交錯（D066；篇號依總稿 v3）

與**生**：兩人都管生機，一個靠丹、一個靠渡出自己的生機。第 4 篇南荒藥潮，她以自身生機渡人，生第一次看見有人拿「自己」當藥；第 23 篇生用她渡青息的思路替劫撐住裂縫；第 28 篇到場。見[同代女天驕群像](../同代女天驕群像.md)、[主線路線總稿](../../05_故事主線與揭露/主線路線總稿.md)。

<a id="桑遲--對頭"></a>
### 對頭

役魂市的湯九溪，在藥潮換流時以役魂針封住落單的生靈，木靈也是他的貨。見[各界反派](../../01_世界格局/勢力/各界反派/陸沉故土.md)。

<a id="烏照夜"></a>
## 烏照夜


<a id="烏照夜--身分"></a>
### 身分

南荒玄鴉族少年，命輪成熟度約等於人族十六歲。並非燼梧諸氏血脈，卻得到燼梧山涅槃遺火回應。他是鳳裔內部血脈派與守約派爭議最直接的當代人物。

<a id="烏照夜--得火經過"></a>
### 得火經過

玄鴉常在火山熄滅後尋找礦石與焦木，被部分鳳裔輕視為追逐餘燼的低等羽族。一次祖地試煉發生火脈暴動，烏照夜沒有搶奪眼前遺火，而是帶著唯一未熄的引路火穿過煙塵，替受困者標出歸路。涅槃遺火因此落上他的黑羽。

這次回應不證明他是鳳凰轉世，也不使他取得燼梧山所有傳承。

<a id="烏照夜--性格與形態"></a>
### 性格與形態

烏照夜寡言但不陰沉，習慣先看清出口才深入險地。平時保持帶黑翼與羽紋的近人形，必要時顯露玄鴉本相飛行；兩種形態都是他自己，並非化成人形才有資格進城。

<a id="烏照夜--修行與招式"></a>
### 修行與招式

- **照夜燼羽**：放出帶有微光的黑羽，在煙霧、黑暗及混亂靈氣中留下短時可循的路標。羽光能被遮蔽或擊碎。
- **穿煙**：以玄鴉本相穿越狹窄亂流，擅長找路與救援，不等於無視火焰和毒霧。
- **燼中續命**：燃燒受創部位，暫時止住傷勢並驅除部分侵體異力，事後須承受真實灼痛、本源虧損與漫長恢復。不能死而復生，也不能連續無限使用。

當日承載引路火的一枚黑羽被煉成**引燼翎**，可替他穩定遺火與辨認自己留下的燼羽。翎羽若離身太久，續命之火更容易失控；品階待配。

**與赤翎的分別（D069；D072 起赤翎是陸沉旅途中遇到的靈獸朋友，不再稱伴星，差異化照舊）**：同是黑羽，烏照夜是玄鴉、不是鳳，火是燼梧山外來的涅槃遺火，**不能死而復生**，燼中續命燒掉的是受創部位；赤翎是玄燼凰，身上沒有火，只有雷燼，真的會死、須受雷劈才從燼裡回來，代價是記憶。他找出口，她守住回來的那一點。完整對照見[劫厄與旅途同行者](../../04_修行與特殊事物/劫厄與旅途同行者.md)。「引燼翎」與赤翎共用「翎」字，改名為「引路翎」屬可選小改，作者未定前不動。

<a id="烏照夜--當代位置"></a>
### 當代位置

他參加百川會，不是要證明玄鴉比鳳裔高貴，而是要求燼梧諸氏承認遺火已經作出選擇。水城潰堤時，他曾穿越死氣與蒸汽替災民引路。

<a id="烏照夜--對頭"></a>
### 對頭

燼梧諸氏血脈派少主丹穴熾，認定他那一身遺火是「偷的」；也是赤燼火嶺奉焰社暗中的供奉者。見[各界反派](../../01_世界格局/勢力/各界反派/README.md)。

## 紀南舟


<a id="紀南舟--身分"></a>
### 身分

南荒星槎門當代代表天驕之一，十七歲，擅長航標、飛舟與多人陣勢。他的價值不以單挑排名衡量，最強之處是讓一支隊伍在混亂環境中仍能彼此接應。

<a id="紀南舟--性格與願望"></a>
### 性格與願望

紀南舟待人隨和，進入陌生地方的第一件事永遠是找退路，交手前會記住每一名同伴的位置。他可以接受原定戰術失敗，不能容忍有人只為逞強脫隊，迫使其他人回頭送命。

他參加大比，想證明星槎門不只會在災後搬運傷者；一套真正成熟的舟陣，能在戰局崩壞前替所有人保留選擇。

<a id="紀南舟--修行與招式"></a>
### 修行與招式

- **列標**：在空中、水面或地面留下短時航標，標出可用路線。航標需要實際布置，會被發現、移動或摧毀。
- **借流換位**：讓進入兩枚航標之間的同伴借陣勢加速或轉向。它不是空間瞬移，路線被截斷便會失效。
- **斷航續路**：主動放棄已毀陣段，把剩餘航標接成新的撤退或進攻線。重新連接會犧牲原本的速度與覆蓋範圍。

他持有**定流盤**，用來同時記錄七枚核心航標的相對位置及負荷。盤面只顯示自己的航標，不會自動畫出未知地圖；核心標超過七枚後必須捨棄或交由同伴另行控制，品階待配。

<a id="紀南舟--當代位置"></a>
### 當代位置

水城潰堤時，他曾把已失去大半節點的飛舟陣重接成撤離線。五域大比中，他主要作為南荒團隊的調度者，不必安排成每場都親自單挑的選手。
