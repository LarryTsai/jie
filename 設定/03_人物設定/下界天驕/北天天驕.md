<a id="石聞川"></a>
## 石聞川


<a id="石聞川--定位"></a>
### 定位

- 年齡：十八歲。
- 出身：北天萬壑宗。
- 身分：候天帶開路弟子，北天五域大比候選人。
- 核心矛盾：他能替眾人承住崩塌，卻容易把所有代價都算在自己身上。

<a id="石聞川--人物"></a>
### 人物

石聞川不是沉默寡言的石頭性子。他愛與人爭論路圖，也會在休息時模仿不同山谷的回聲；只有真正進入山腹，他才會安靜下來聽地脈。對他而言，山會移位、會拒絕，也會在正確時刻讓路。

他不喜歡萬壑宗被當成替各方收拾殘局的苦力，卻總在道路崩裂時第一個站上去。五域大比對他而言，是證明定脈與承壓之法本身也能成為正面道法的機會。

<a id="石聞川--能力與招式"></a>
### 能力與招式

- **聽山**：以骨傳震感知岩層空洞、斷面與即將錯位之處。離開實地岩層、進入空中或深水後，感知大幅下降。
- **回壑震**：把力量送入既有裂隙，再由另一處震出。它不能無中生有，判錯岩脈時反震會先傷自身筋骨。
- **負嶺樁**：將自身與一段地脈暫時相連，承接崩合時的壓力，替他人爭取通過時間。承住多少，肉身便必須真實承受多少。

<a id="石聞川--器物"></a>
### 器物

**聽壑杵**：一柄沒有鋒刃的短杵，敲擊不同材質可分辨內部裂隙，也能作為負嶺樁的落點。它無法代替使用者承擔反震。

<a id="石聞川--與其他人的關係"></a>
### 與其他人的關係

蘇映真能看見空間重影，石聞川能聽見實體山脈的變化，兩人的判斷常能互補。裴雁回一喊撤退，他有時仍想多撐片刻；這是兩人合作時最危險的衝突。

<a id="蘇映真"></a>
## 蘇映真


<a id="蘇映真--定位"></a>
### 定位

- 年齡：命輪十七歲；實際成形年數較長。
- 種族：鏡冰靈。
- 出身：北天鏡海宮。
- 身分：冰下渡船的辨景者，北天五域大比候選人。
- 核心矛盾：她希望旁人把她視為一個會選擇的人，而不是天象徵兆或可供研究的異靈。

<a id="蘇映真--人物"></a>
### 人物

蘇映真誕生於鏡海兩層天幕重疊之夜，由一塊多年映照眾生的古冰開靈。她的成熟速度與人族不同，因此以神魂與命輪判定參賽資格。她熟悉冰下水路，也知道鏡中所見並不必然是假象；有時倒影只是另一片真實疆域投來的一角。

她待人直接，最厭惡別人沒問過她便討論「冰靈應該如何」。她願意代表鏡海宮參賽，是想親自看看離開北天後，自己是否仍只能被當成稀有種族。

<a id="蘇映真--能力與招式"></a>
### 能力與招式

- **照身**：由附近冰面映出與本體同步的折影，從另一角度完成同一記術法。折影不是能獨立思考的分身，也不能離開可映照的介質太遠。
- **寒鏡折勢**：把看清角度的攻勢折向別處。力量仍會經過她的本命冰心，承受超限時會造成真實裂傷。
- **碎鏡歸核**：主動將外層冰身碎成數十片避開致命一擊，再重新聚合。若藏有本命冰心的核心碎片受損，其餘冰片再多也無法復原。

<a id="蘇映真--器物"></a>
### 器物

**藏鏡匣**：收納並溫養本命冰片的鏡海宮器物，也能保存短暫的天幕倒影。匣中影像只是觀測記錄，不能直接變成通往異地的門。

<a id="蘇映真--與其他人的關係"></a>
### 與其他人的關係

她與黎見昕都曾被定疆人當成「新發現的一部分」，因此最先理解彼此的不耐。石聞川願意先問她哪一層冰面是真的，再決定落樁位置，這使她對他較少戒心。

<a id="裴雁回"></a>
## 裴雁回


<a id="裴雁回--定位"></a>
### 定位

- 年齡：十八歲。
- 出身：北天逐日城。
- 身分：轉光塔守衛家系出身，北天五域大比候選人。
- 核心矛盾：他擅長在危急時帶人回頭，卻厭惡旁人把撤退說成膽怯。

<a id="裴雁回--人物"></a>
### 人物

裴雁回在一座不斷移動的城裡長大。他知道田地、牲畜、工坊與普通人的性命都必須跟上日軌，因此不相信只顧自己衝得最快的人能當領路者。他性格明快、敢作決定，失誤後也不會拿天象替自己辯解。

他最初參加巡天試，是想替逐日城爭取更多穩定路權；經歷疊天錯位後，他開始懷疑「把每條路固定下來」是否真的永遠正確。

<a id="裴雁回--能力與招式"></a>
### 能力與招式

- **收晝**：把長晝靈光蓄入回日輪，供極夜或封閉空間使用。儲量有限，用盡後不能憑空生光。
- **折照壁**：以數面光鏡改變來力與術法的角度，擅長護住身後的人。它依賴角度和預判，不能正面反回遠超自身承受的力量。
- **雁歸線**：放出一道能穿過風雪與薄霧的長光，標記撤離方向。光線同樣會暴露隊伍位置。

<a id="裴雁回--器物"></a>
### 器物

**回日輪**：逐日城轉光塔使用的縮小法輪，能蓄光、分光與測量日軌。它是城市技術的一部分，不是裴雁回獨有的奇遇重寶。

<a id="裴雁回--與其他人的關係"></a>
### 與其他人的關係

裴雁回和石聞川都重視救人，做法卻相反：石聞川傾向先穩住道路，他則會在判斷撐不住時立刻帶人撤退。顧星遲曾三次否決他的近路，他嘴上抱怨，三次都照做。

**篇位（總稿 v3 同代群像排程）**：第 16 篇上界同代齊聚，以北天男性同代身分亮出自己的道；第 28 篇到場。

<a id="顧星遲"></a>
## 顧星遲


<a id="顧星遲--定位"></a>
### 定位

- 年齡：十七歲。
- 出身：北天量天臺。
- 身分：巡天隊中最年輕的正式校圖者之一，北天五域大比候選人。
- 核心矛盾：她敢承認不知道，卻也因此常被急於開路的人指責怯懦。

<a id="顧星遲--人物"></a>
### 人物

顧星遲自幼跟隨巡天隊觀測候天帶。她不把地圖當成權威，而把它視為前人留下、等待後人重新驗證的答案。她說話慢，報出方位前習慣再看一次天色；一旦確定舊圖已錯，也敢當眾劃去名宿留下的路線。

她參加五域大比，不是為證明北天術法玄奇，而是想看到其他大域如何處理天地異變。她真正害怕的不是輸，而是某一天為了維持量天臺的名聲，把「尚未確認」說成「可以通行」。

<a id="顧星遲--能力與招式"></a>
### 能力與招式

- **校星**：把當前星位、界痕與沿途標記逐一比對，找出道路正在向哪一層空間偏移。只能判讀已觀測到的變化，不能預知從未出現過的天象。
- **借位**：以三枚定向針暫時統一小範圍內的方位，使隊友在錯位空間中仍能朝同一方向移動。定向針一旦毀損，借來的位置便會迅速散去。
- **退星線**：沿行進路徑留下只有校圖者能辨認的星痕，供隊伍循線撤回。敵人若理解其規律，也可能反向追蹤。

<a id="顧星遲--器物"></a>
### 器物

**候星尺**：六節相扣的量天尺，可記錄六組相對星角與界痕。它只保存觀測，不會自己給出答案；使用者若判斷錯誤，候星尺同樣會留下錯圖。

<a id="顧星遲--與其他人的關係"></a>
### 與其他人的關係

她尊重黎見昕的宵衡曆，兩人卻經常為「哪一套基準先失效」爭到開幕結束。她認為裴雁回太依賴臨場決斷；真正遇到疊天錯位時，卻又是裴第一個照她指出的死路折返。

<a id="黎見昕"></a>
## 黎見昕


<a id="黎見昕--定位"></a>
### 定位

- 年齡：十七歲。
- 出身：北天深北，宵衡古國。
- 身分：隨使團前往定疆的衡術修士，北天五域大比候選人。
- 核心矛盾：她要讓外界承認宵衡古國的知識，卻也必須接受自己的星曆無法單獨解釋整個北天。

<a id="黎見昕--人物"></a>
### 人物

黎見昕出生時，宵衡古國才剛重新與定疆建立穩定通路。她讀過外界對故國的記載，最不能容忍的是「失落古國」四字——在失聯的漫長歲月裡，宵衡的人從未停止生活、修行和記錄天幕。

她熟悉兩套語言與曆法，說話精準，遇到含糊處會追問到底。她參加巡天試，既是個人選擇，也是宵衡第一次願意讓年輕修士接受北天共同選拔。

<a id="黎見昕--能力與招式"></a>
### 能力與招式

- **定衡**：先選定一個真實參照，再於空間顛倒時辨明上下、遠近與受力方向。參照一旦被移走或摧毀，術法便要重新建立。
- **移衡**：在兩個已標記目標間轉移一部分重量或衝力。力量不會憑空消失，她也不能把超出自身控制的重擊全數卸走。
- **無晝標**：留下不依賴光線與星辰、只以衡感辨認的路標，適合極夜與錯幕。不了解宵衡術的人幾乎無法讀取。

<a id="黎見昕--器物"></a>
### 器物

**雙衡盤**：兩層彼此垂直的古國法盤，用來校準當地受力與空間基準。進入新天地後必須重新校盤，不能拿舊刻度直接套用。

<a id="黎見昕--與其他人的關係"></a>
### 與其他人的關係

她承認顧星遲是定疆同輩中少數願意驗證宵衡曆的人，卻不接受量天臺擁有最後解釋權。蘇映真不用「失落」形容宵衡，兩人因此很快建立起最低限度的信任。
