## 師門如何相處

岳沉淵記得各人的傷與來歷，教法因人而異。沈山河習慣攬責，柳青藤會提醒他別都自己扛；秦照雪與陸行烈一冷一熱，鬥嘴也相互信任；韓鐵衣表面嫌顧小滿吵，卻默默護著她。這些關係在劫來以前就存在，不只等著輪流教主角一項能力。

「六極」保留作六條鑄身方向的合稱。早期映照大道之影，顧小滿不停止時間、韓鐵衣不絕對免傷、柳青藤不消除傷勢。峰主「古嶽真君」是外號，不新增真君境。
