<a id="宋明川"></a>
## 宋明川


<a id="宋明川--身分"></a>
### 身分

西極天山劍宗天隙峰傳人，當代代表天驕之一。靈根普通，入門考核並不顯眼，卻對劍的落點、距離與出手時機異常敏銳。

天隙峰在昔日守山一戰失去大半師長。宋明川尚未受重視時，峰中師父從一次試劍看見他的劍感，將他收下。後來其他劍峰願意接納他，他仍留在天隙峰，想把師父教他的劍練好，也讓世人重新看見這一脈。

<a id="宋明川--性格與願望"></a>
### 性格與願望

爽朗坦率，喜歡結交不同劍修，勝了會高興，輸了也肯認，還會直接追問對方那一劍的門道。提起師父與衰落師門時不遮掩，也不希望別人只因同情而稱讚天隙峰。

他參加五域大比的願望，是把自己真正喜歡的劍法帶到山外，證明天隙峰仍有人能將傳承走下去。

<a id="宋明川--劍道方向"></a>
### 劍道方向

核心是「一線破隙」。劍招簡淨，憑劍感判斷攻守間的距離、落點與銜接空隙，再將劍力凝成一線刺入。若對手守得嚴密，他仍須以步法、試劍和變化創造空隙，不能無條件看見破綻。

師父提案為天隙峰主**覃孤**，尊者，昔日守山一戰後天隙峰僅存的師長之一（D060 現行提案，見[故土六域人物](../05_三十二天/故土六域人物.md)）。正式功法、劍器與招式名稱待定。

<a id="明定"></a>
## 明定


<a id="明定--身分"></a>
### 身分

西極大日禪寺當代代表天驕之一。法號「明定」，修金身與降魔掌印。

<a id="明定--性格與持戒"></a>
### 性格與持戒

天性急烈，平日端正沉穩是多年持戒與禪定的結果。他對自己尤其嚴格，每日禪坐、淬體與誦經都有定課；戒律是他約束怒意、使自己能夠信任自身力量的方法。

遇見不平仍會動怒，修行難處不是將烈性抹掉，而是分辨何時應出手、出手後如何收住。面對喝酒而隨性的雲行，他會先觀察，再真心好奇對方如何修禪，不預設兩人必然敵對。

<a id="明定--修行方向"></a>
### 修行方向

代表修法暫稱「大日熾身」。氣血與法力運轉時，金身逐漸熾熱，掌印帶有灼烈之力；心神越穩，力量越凝聚，也越能準確收放。動怒本身不會直接使他變強，反而可能令出手躁進。

師父提案為大日禪寺戒律院首座**覺愚**，尊者（D060 現行提案，見[故土六域人物](../05_三十二天/故土六域人物.md)）。正式功法、掌印招式及與雲行的具體相遇留待後續。

[西極宗派](../../01_世界/03_故土六域/西極宗派與天驕.md)

<a id="明定--對頭"></a>
### 對頭

師叔覺妄，修大日熾身到極處、走火入魔，認定自己在降魔；他是明定若沒有戒律會長成的樣子。見[各界反派](../../01_世界/04_勢力/05_反派/陸沉故土.md)。

<a id="程燁"></a>
## 程燁


<a id="程燁--身分"></a>
### 身分

西極赤鼎宗當代代表天驕之一，兼修煉器與多器協同。

<a id="程燁--性格與願望"></a>
### 性格與願望

精明健談，熟悉材料、修繕與交換的實際成本，對自己的煉器手藝很有信心。平日算得仔細，真正交手時卻捨得損耗法寶換取勝機，不會為了惜器錯過戰局。

他參加大比除了爭名，也希望讓成套法寶經受不同修士與神通的考驗，找出下一次重煉應改進之處。

<a id="程燁--代表法寶"></a>
### 代表法寶

以三座小鼎為代表，分掌鎮壓、護身與地火攻伐；合用時可圍成爐陣，逐步壓縮對手的活動空間。三鼎須由程燁實際操控、調度，單件受損也會破壞整套配合。

三鼎正式名稱、材質、品階與具體招式待定，不能先寫成能越過境界鎮壓所有對手。

師父提案為赤鼎宗煉器長老**熊炬**，尊者（D060 現行提案，見[故土六域人物](../05_三十二天/故土六域人物.md)）。

<a id="賀凌川"></a>
## 賀凌川


<a id="賀凌川--身分"></a>
### 身分

西極御嵐宗當代代表天驕之一。宗門靠風陣守住草原聚落與靈脈而崛起，他敬重這份功業，也想證明後起大宗在正面鬥法上不輸古老傳承。

<a id="賀凌川--性格與願望"></a>
### 性格與願望

驕傲好勝，待人卻有禮。他會真心稱讚對手，也會把每次落敗的差距牢牢記住，私下反覆修煉；較勁藏在得體言行之下，不靠無故羞辱別人表現自信。

<a id="賀凌川--修行方向"></a>
### 修行方向

最擅長凝風成刃。將高空罡風收束為薄刃，以角度、速度與連續斬切逼出破綻，主動選擇正面攻伐，以自己的戰績替御嵐宗爭得地位。

風刃並非無形必中，仍會受法力、環境、控制距離與對手防禦影響。師承提案為御嵐宗長老**呼延勁**，尊者（D060 現行提案，見[故土六域人物](../05_三十二天/故土六域人物.md)）；正式功法、招式、法器待定。

<a id="路開陽"></a>
## 路開陽


<a id="路開陽--身分"></a>
### 身分

西極鳴野宗當代代表天驕之一，與赤角荒鹿赤衡共同修行。路開陽是同行者，不是赤衡的主人；赤衡也不是坐騎或受命攻敵的法寶。

<a id="路開陽--相識"></a>
### 相識

路開陽幼時在荒野風暴中遇見受傷的赤衡，冒險將牠帶離風口。風暴改變地貌後，他自己反而迷失在紊亂地脈間；赤衡醒來後感知地下水脈與安定地勢，帶他避過塌陷並找到歸路。兩者由互救開始相伴，後來才在鳴野宗的見證下正式選擇彼此。

<a id="路開陽--性格與關係"></a>
### 性格與關係

路開陽開朗愛鬧，喜歡主動與人攀談，也常因一時興起改變路線。赤衡端莊穩重，對地勢與危險比他敏銳，平日看來更像是赤衡在管束少年。

路開陽遇到真正危險時不會拿玩笑壓過赤衡的判斷。若赤衡拒絕前進，他會先查明原因；兩者意見不同時，也必須說服彼此，而非由人族一方下令。

<a id="路開陽--赤角荒鹿・赤衡"></a>
### 赤角荒鹿・赤衡

赤衡能從土石震動、草木含水與靈氣流向感知地脈、水源及逼近的危險。交戰時以赤角牽動淺層地脈，以踏地震開靈力波紋，能破壞對手步法、提醒同伴避開不穩地勢，也能替眾人尋找撤離道路。

牠的感知不是全知：離地飛行、被陣法隔絕或地脈本身混亂時都會受限。牠具有自己的好惡與判斷，必要時可以拒絕路開陽提出的冒險。

<a id="路開陽--大比位置"></a>
### 大比位置

路開陽與赤衡參加五域大比，是要讓其他地域看見鳴野宗的共生之道，也藉陌生地貌驗證兩者能否在離開西極後仍彼此配合。他們是否與劫交手、勝負及後續關係留待大比情節確定。

鳴野宗長老**丘野**，尊者，是路開陽與赤衡正式結伴時的見證者（D060 現行提案，見[故土六域人物](../05_三十二天/故土六域人物.md)）。
