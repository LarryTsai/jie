# 上無極人物

狀態：三十二天人物寫手提案（2026-09-30），D060 採為現行提案（可據以寫作，仍可再改）。勢力見[上無極勢力](../../01_世界/04_勢力/02_無極/上無極勢力.md)。仙帝道場人物見[大羅仙庭與仙帝道場人物](大羅仙庭與仙帝道場人物.md)，王庭人物見兩份王庭人物檔。

陸沉第 14–18 篇在上無極（約 25–28.5 歲，天神至虛道），第 25 篇再回來（約 34–35 歲，真仙；年齡依 D128）；第 19–20 篇在聖土（主線路線總稿 v3（D067））。

## 主要人物

**截雲**（道號）｜鈞天劍宗宗主，仙王。上無極劍道魁首之主，生於古戰之後。收徒只看一件事：劍有沒有「自己的理由」。他看不起下無極的斷雲劍宗，認為分家之後只剩殺伐；但他每年都去看斷雲的弟子試劍。封寒日後轉鐧，他說「可惜」；他的嫡傳駱霜不同意，是第一個說「對」的人（總稿 v3 第 18 篇）。

**澹臺長吟**｜澹臺世家家主，仙王。澹臺世代替大羅記注司抄副本，數萬年來把每一份抄本「對齊」正本。他真心相信對齊是在保護記錄——若各抄各的，天下便沒有可信的史。主線證據規則說「仙界歷代抄錄都把記錄對齊官方版本」，澹臺就是那雙手。他不是陰謀的一部分，他是制度本身。

**澹臺秋毫**｜澹臺世家子弟，天神，陸沉在上無極的同代人。抄錄時發現兩份「已對齊」的副簡之間仍有一處神識烙印的層紋不一，追查下去，發現對齊本身也被人對齊過。她不敢告訴家主，只好帶著問題去琅嬛閣翻私抄。可作封寒打開封存記錄前後的一條平行線。

**息影**（道號）｜洞冥宮主，仙王。神魂與搜魂的專家，替各庭處理搜魂案，收費極高。她最常對委託人說的一句話是：「搜魂只取他相信的。」上無極查案可請她，也可被收買；她自己的界線是不替任何人偽造一段記憶。

**夏侯靜**｜千禁城城守，真仙巔。千禁城由城約治理，不容王庭駐軍，全城的公共禁制由她維持。禁市驗貨反傷無辜的事每年都有，她每次都親自去賠。她說千禁城唯一的規矩是「禁制要留給別人能接手的樣子」。

## 次要人物

- **駱霜**：鈞天劍宗天驕，天神→虛道，陸沉在上無極的同代劍修。與封寒只作劍道知己與對手（作者定，見[同代女天驕群像](../同代女天驕群像.md)）。女。對頭：同門戎霈。
- **鈞天太上**：準仙帝，閉關，道號待定。
- **竺遠**：沖虛觀監院，仙王；公開批評歸一是「返本之偽」的主講者，專講向極與歸一之別。
- **沖虛觀主**：準仙帝，閉關，道號待定。
- **姒清**：洞冥宮魂師，真仙；專治魂傷，與息影意見常不合。
- **韋鑄**：歐冶山主，仙王；替各庭重鑄古戰遺器，總說「重鑄的不是原物」。
- **符子敬**：琅嬛閣主，仙王；收私抄、不對齊，也收了不少偽作。
- **百里嘉**：百里世家家主，真仙巔；上下無極之間仙路的實際維護者，跨層通行的規矩由百里家執行。
- **百里遙**：百里世家巡路使，至尊；陸沉第一次跨層時的引路人（候選）。
- **賈明珠**：合契行首，真仙；契書換物的上無極代理。
- **蔡不語**：千禁城禁市牙人，至尊；賣東西從不說來歷，被問多了就加價。
- **綦音**：天籟宗主，真仙；瓊華講法會常設樂席由天籟擔任。
- **麋遠**：靈犀谷主，真仙；研究同命契四條底線，反對役魂之術。

## 晝衡海三爐灣（仙生，萬法合卷大會；工作創作・候選）

2026-10-22 依 D152 隨[萬法合卷大會](../../../大綱/06_仙途/08_萬法合卷大會/大綱.md)回填；2026-10-24 萬法合卷重構後只剩一位新具名人物（[融合紀錄](../../../歸檔/02_已結案競稿/待整理收尾_20261031/萬法合卷重構_20261024/融合紀錄.md)）。境界為斷峰定後一季（陸沉約45.6歲）當期工作配，未計入[總名冊](總名冊.md)人數。

- **魏班**：第二坊夜班老爐工，化靈；一雙裂了陶的手。換班規矩說了幾十年沒寫下：一個口一刻、換班不看境界、不准連守兩班；「被徵者可拒；到拍必停；停者不罰」三句由符湄提請寫進公卷第一行，卷序記「說者魏班」。聚潮夜守第十六號口，拍陸沉肩膀說「換。」單場人物。
- **奚箴**（既有，大衍宗推演師；D163 接原新造「湛衡星」位）：天神；第一論次以實測勝文奕，三夜下潮量出「第五拍，第四十一息」，與文合署對紋錄；退回大衍宗推演席。A4 對口（D164）。
- **既有人物上場**（不另立條目，見各自人物卡與[同代去向](../../../大綱/06_仙途/00_帝重與帝路.md)）：符湄（虛道，第二坊坊主，護爐主卷試首位）、邴初（至尊圓滿，第一坊單肺）、駱霜（虛道，守晝劍爐卷）、寧枕微（虛道，雙相丹）。
- **只寫職稱**：潮環主辦、第一坊天神監工。
- **撤用**（2026-10-24 重構，連同古契分線 K01–K05 與各自的鉤）：韶照微、郗泊、阮隰、梅伯衡、屈庸、棠禾、嚴屹、江歸笙、秦忍舟、禚定瀾。原條目存於[原稿備份](../../../歸檔/02_已結案競稿/待整理收尾_20261031/萬法合卷重構_20261024/原稿備份.md)與本檔 git 歷史。
