# 亡命同行與諸殿人物

效力：2026-10-10三寫手競稿採甲後的**工作設計**，非作者逐篇批准；只整理三篇已發生的大綱事件，不擴成世界通則。既有人物原設定照留。

現行故事：[亡命](../../../大綱/02_離鄉/06_下無極亡命期/大綱.md)、[故土](../../../大綱/02_離鄉/07_故土越線清算/大綱.md)、[聖物](../../../大綱/02_離鄉/08_諸殿聖物案/大綱.md)。三篇約劫24–24.5歲，劫真一六雷，返故土本人短印壓列陣。

| 人物 | 境界／位置 | 自己的願望、實際行動與後續 |
|---|---|---|
| 秦濯 | 女器修，真一中期；既有同行者 | 要鑄署自己名字的道器。古林成開合環骨器胚、逼退柯臨；再自行闖養器試，贏器譜與鋪地玉券，冒險承斷骨而被殘器抽心脈。清醒完成最後鬆接、救成仍真一；保器譜與器名，另托契行轉讓鋪券，往盧的渡口開小器鋪。舊傷需養，器胚只是靈器層，不瞬成寶器。 |
| 盧潮信 | 男，真一前期；既有同行者 | 要建自己的水渡。古林先敗後撑出一丈承水、送一舟人；真護客拿工錢，因真實劫舟殺守衛舊案被指認，又被周轉作私礦活供。脫押不等於洗清舊殺；救秦時承水被天神打破，仍親自爬岸入遷病陣。後來接第一位付錢乘客，不永遠充當劫的副手。 |

| 周見霜 | 新設，天神；長離航路舟殿地方執事 | 經營真護客生意，也私轉盧作礦舟活供。破押使其失舟器、人傷及私礦利益，買療材隊渠道襲青潮藥圃以逼劫回指定上端。外港清帳保主舟，天神本人存活；不等同全舟殿或王庭幕後。 |

| 梁聽海 | 新設，真一後段；承法殿試者 | 想拿養器席，用回爐術反制秦，秦仍真勝；取珠時因失席及守物職責追劫，未被劫殺。其殿以現場傷人、奪物加入聯署，不是玄殿邀約使者。 |
| 季持秋 | 新設，女天神醫修 | 自求器根抽身後的承脈針法，先醫另一敗者、再與秦互試。封治、求借、外供春絲均真試；同境預布三瓣陣撑十四息救治，兩瓣被破、左手骨折、針器损。秦的反接圖副抄是她的真所得，不奪秦器道。固定付費遷病陣兩端既有、各供仙晶與校驗、只容五本體；醫舍後端真被追毁，不能提供永久免追或任意傳送。 |
| 段橫波 | 新設，天神劫舟凶徒 | 舟婦認出其殺家人舊渡；照塵事先知罪，為承水器材仍護送。雲當場拒運其材，仍認照塵為師父。段不與秦受傷的起因合併，不把曉設成全部仇家幕後。 |
