## D107 新版卷序的取得與消化入口

[逐卷修行所得表](../../../../大綱/00_全書骨架/01_人物線/逐卷修行所得與消化總表.md) 管理十九卷／南荒四幕的資源、教材與驗證；本譜篇號仍指原二十八篇，不直接當新卷號。原卷七中神州禁典補全在現行卷十一，取得完整文字與學會全部禁術分開。
