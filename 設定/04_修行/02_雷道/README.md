# 新版九雷

狀態：012／D144更新；第八流光限制版時間系由作者定，取雷事件與成熟招式採工作設計，完整九雷不宣稱全書凍結。階段依D058、D059：九界五雷 → 落潮一年（十八至十九歲首入聖土，取殞星）→ 無極二雷（下無極歸墟、上無極流光）→ 聖土篇（九霄，第二次聖土）；第十雷於終局長成（D066）。世界有許多異雷，其他修士也能收服、兼修，並非天地只有九種雷。

**D087（2026-10-03）**：核・裂改名《天譴》、取消「只兩道」；雷體階梯連數值搬回；各雷檔「不能做什麼」照[雷檔放寬條文草案](../../../待整理/設定/06_待定與決策紀錄/雷檔放寬條文草案.md)推薦放寬（九道雷檔本身由聖土寫手同步）。**D088**：九雷人生節點（「變」的十步、首次越級、九雷合一、十雷一體時點）。

劫起初沒有集齊九雷的目標。隨修行理解不同雷性如何相容、互補，才逐步推演出自己的九雷格局，再尋找所缺異雷。九雷不是天定名單或預裝九個空位。

**第十雷「天劫」（D066 定案；名稱 D147 作者定，2026-10-09）**：作者定要寫，**單獨時不作戰，只記往來、讓錨成立**（D087：十雷一體裡也增幅、可以作戰；D088：全書寫一次，在第 28 篇，以胎入局，見下「雷體與天譴」）。由兩界交會而生（C10），不收集、不吞、不上榜、不交易、不能被搶：第 22 篇道基碎裂時，九霄、殞星、星羅在裂縫裡隔著漏影與帝天骨架共振成胎；第 23 篇九界每剪他一份修為，總有一絲剪不走；第 27 篇守約往返時隨窗口起伏；第 28 篇錨成立、兩界之氣第一次有規律地往來，它在他身上和渡口同時長成。九雷是取來的，第十雷是長出來的。名稱與具體能力留白；舊「無始」名稱、能力、形成及結局不沿用。舊天地榜排名、進階名亦不沿用；固定戰力倍數只搬雷體階梯一項（D087，見下）。星羅銀雷不再自動稱照命／煌命。**命圖改為新雷新位**（D069，取代原「命圖雷位名不沿用」一句）：太玄命圖已接回，每熔煉成功一道雷，命圖才多出一個主星位，舊命圖的雷位名與星位編號不搬；第十雷的主星位長在劫核旁，通往往來（候選，D072），見下節。

## 太玄命圖：主星位（D069；D072 撤外環，只留雷種配置）

太玄命圖第 2 篇在太玄命藏初開（十人選拔之後、取震魂之前），完整見[太玄命圖](../07_特殊事物/太玄命圖.md)。

- **劫核居中**：劫核是陸沉本人，不發雷，決定各雷為何而發。
- **主星位**：每取得並熔煉成功一道雷，才多出一個主星位；位置依雷性與已有各雷的相容關係排，不依榜次，沒有預裝空位。各位的「職」：星羅＝眼、兩儀＝第一條軌、震魂＝魂錨（主星成三角）、千相＝表、無間＝接（工作職）、殞星＝核、歸墟＝卸、第八流光時間系職待配（八道撕痕的無間落位與因果待重製）、九霄＝穹、第十雷＝往來。是職，不是增幅倍數（增幅只在雷體階梯，D087）。
- **「變」的十步（D088）**：九雷依取得順序對應陸沉的道「變」：星羅看見、兩儀選路、震魂看見別人、千相看錯、無間重構、殞星付帳、歸墟被劫破、第八雷越權、九霄先問、第十雷不改。見[九雷人生節點](../../../大綱/00_全書骨架/九雷人生節點.md)。
- **沒有外環（D072）**：D069 的外環綁雷（鑑月對震魂、蒼梧對太虛、赤翎對殞星）、命印與空痕全部撤除。命圖只排雷，不排人；劫厄不在命圖上，鑑月、蒼梧、赤翎是旅途中遇到的朋友，見[劫厄與旅途同行者](../07_特殊事物/劫厄與旅途同行者.md)。
- **第十雷的位置**：主星位**長在劫核旁，通往往來**（候選）。不屬九雷任何一軌、單獨時不作戰；它不往外撐開新角，只在劫核旁開出一條往外走的路，兩界之氣從那裡往來。蒼梧第 26 篇「這次你走門」是人物層的呼應，不在命圖上對應任何缺口。備案：只寫「長在劫核旁」。

## 雷體與天譴（D087，2026-10-03；取代 D074「核・裂：兩雷共軌」）

- **《天譴》**（舊名核・裂）：陸沉自造的多雷大術。**以他自己為核**：劫核＝他本人，每道異雷從命圖主星位出發沿裂軌向外，裂被打斷，反衝回到他身上。**取消「只兩道」**，改七階（天譴、三相、四極、萬象、諸天、九劫、劫界），一篇最多升一階。各組招名：天譴・逐星（兩儀 × 殞星，舊名核・裂・逐星、斥核）、天譴・還重（九霄 × 星羅）、天譴・串星（流光 × 殞星，候選）。裂看得見、永不修掉；禁九色彩虹雷球；命圖不加倍；第十雷不入天譴；壓境不出。第 22 篇婁直專打裂，天譴碎。
- **雷體階梯**（連數值搬回，翻 D074「倍數不搬」）：一雷體、三雷合體（完全自由配）、九雷合一、十雷一體，被指定的雷各 150%～200%，其餘 100%；**正文不報數**。雷身數量不設上限。代價：任一雷身本源受創沿命圖傳全體，同時全力爆發的身越多反噬越多。雷體是「身」、天譴是「術」，可同場。
- **時點（D088）**：九雷合一首用不早於第 24 篇；十雷一體第 28 篇寫一次，**以胎入局**（守錨中段雷胎入局，錨成立時第十雷才生成、單獨亮起不殺）。
- **雷與雷之間**：〈九曜同墜〉（撞，另立大術，不屬天譴）、〈天地為爐〉（融，一息必炸）、〈物換星移〉（換，須太虛或千相）、〈周而復始〉（銜）；〈交龍〉不採；共振保留給第十雷。
- **紅線 1「不揉成常態」**（舊作「不揉本源」）：可熔一息、熔完必炸、兩雷本源各損一分；不能拿融合雷當常用雷。
- **跨質變點**：只有陸沉可越，三雷合體以上或天譴當下那一階的極致，每次寫代價；第一次正面寫不早於第 15 篇（D088）。

## 放寬的共同底線（D087）

各雷檔「不能做什麼」照[雷檔放寬條文草案](../../../待整理/設定/06_待定與決策紀錄/雷檔放寬條文草案.md)放寬，每條仍附代價與境界門檻。放寬的是「這道雷做得到什麼」，不是「陸沉可以不付帳」。任一大術都**不越三件事**：
1. **真相層**（D067）：揭露靠遺痕與後手，雷不讀出古戰真相與命運。
2. **界路**：跨界一律本體、走界路、壓錨印、入大羅須登籍（D058、D059、D065、P3）；太虛截路不截界路。
3. **第十雷**：不入天譴、不出自〈天地為爐〉、不在〈周而復始〉的環裡。

## 招式原則與第十雷（C9、C10，作者選定）

- **招式（C9 甲）**：每道雷有固定基本招，功能隨境界逐步增加，強招再擴張；可與聖土鬥技的天地玄黃品階互相對照。九雷基本招名（穿針、掛印、鳴、錯影、走線、落冠、收、隔山、壓重）見[主角群武學譜](../03_武學/01_主角群武學譜/README.md)（D074）。**D087**：九雷各一門鎮雷大術（周天星羅、兩儀天衡印、萬古雷音、萬象皆劫、雷行無界／一念千斬、天隕、歸墟葬界、太虛斷界、九霄劫天印），同功能舊招改為前身，見武學譜第三節之 7。
- **第十雷（C10）**：由三十二天與諸神聖土兩界交會而生。須刻意避開鬥破「異火」的影子（見待定 Q22）。形成與功能邊界已由 D066 定（見上）；名稱與具體能力仍待設計。
- **九雷分布（D058 定）**：甲案——歸墟取自下無極、太虛取自上無極、殞星與九霄取自聖土，見[九雷取得與大比年齡線](../../../大綱/00_全書骨架/九雷取得與大比年齡線.md)。

012 依賴邊界：其後提及太虛、流光舊大術的歷史放寬條文，不再授權第二空間雷或第五高速流光。以無間專檔與第八重製候選為準，成熟高路、八界取材與大術門檻見待定矩陣。
