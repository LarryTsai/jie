# 丹藥與雷煉丹

狀態：依作者本輪選項與要求，將適用舊設定完整整理進新版。一般丹藥九階、雷紋四個成熟層次已採用；品質三等加無瑕、丹毒、抗藥性、仙丹稱法與**雷紋的定義**依 D073（2026-10-02 作者拍板）改寫。逐種丹方數值、成丹率與角色掌握時間尚待配置。

## 階、品質、雷紋分開判定

**階**：下界丹藥一至九階，依煉製難度與丹力判定，不逐一對應搬血、洞天等修士境界。每種丹須另列用途、適用境界、承受條件與服用限制。

**品質（D073）**：同一階內分**下品、中品、上品**；判準是雜質與丹毒殘留、藥力是否穩定。罕見的**無瑕**：無可測的丹毒殘留，一般丹師一輩子未必見一次。驗丹看品質，不數紋。

**雷紋（D073 改定）**：丹藥挨過**丹劫**、被天雷淬過留下的痕。一痕到九痕，代表挨過幾道劫雷。雷紋不是任何人的專利：丹劫只在**高階丹（約七階以上）或品質極高（近無瑕）**時才會引來；高明的丹師能以神識、魂力護丹渡劫（D073 補記二），護不住就毀丹，撐過的丹才帶紋。雷紋本身不是品質等級；被劫雷淬過的丹，雜質與相衝藥性會被燒掉一部分，但不受控的劫雷淬得不勻，品質要驗了才知道。劫特殊之處見下「劫的渡丹劫」。

雷紋不能讓丹跨階、無限服用，或讓低境修士任意承受高階丹。九階丹與九痕丹是不同概念。

**常見服用者**（工作參照，不是對應，可越可降）：

| 丹階 | 常見服用者 |
|---|---|
| 一 | 搬血、洞天 |
| 二 | 化靈 |
| 三 | 銘紋 |
| 四 | 列陣 |
| 五 | 尊者 |
| 六 | 神火、真一 |
| 七 | 天神 |
| 八 | 虛道、斬我 |
| 九 | 遁一、至尊 |

**仙丹（D073）**：不續十階，以適用層稱（真仙用、仙王用……），分類細部留白。仙丹以仙力為藥力，帶入九界只能化為法力藥力，大打折扣。

**兩界對照**：三十二天九階止於至尊；聖土煉藥師九品觸及鬥聖。兩邊各自九級，頂端不同，對照不換算（同 D049 原則）。

## 丹毒與抗藥性（D073）

- **丹毒**：未煉化的雜質與相衝藥性殘留在經脈。累積要排（碧梧、醫修、專門的排毒丹）；排不掉會堵經脈、拖慢突破。下品丹毒多，上品少，無瑕無。
- **抗藥性**：同一丹方連服，效力遞減；換方、間隔或改方可恢復。體修與傷者最受影響。這是劫為體修開銷學丹、手上永遠在改丹方的修士理由。

## 妖丹入藥（D077，作者定（2026-10-02））

三十二天妖丹是修為在體內凝成的丹，與血脈長在一起，不是聖土魔核那種可以單獨剖出的力之庫（作者定，見[境界對照與跨界](../../01_世界/05_聖土/01_規則與跨界/README.md)）。作主藥時藥性最濃，但**離體即散**：數日內入爐，否則降一等；封存只能拖慢。開智者的妖丹不取。部位取材的總表見[修士經濟](../../01_世界/02_修仙文明/02_文明細則/修士經濟.md)「無核取材」。

## 雷煉的手藝

一般丹師以地火、獸火、靈火等煉丹。劫的火是雷：將雷意拆成細雷絲，沿爐壁與藥液結構精密控制，分離雜質、協助融合、調整相衝藥性。這是他的控火，**不會留下雷紋**；雷紋只來自丹劫的天雷。不能拿大雷直接轟材料；控雷之外仍須學丹方、辨材、火候、成丹與丹力驗證。

## 劫的渡丹劫（D073）

丹劫落下時，別的丹師是在爐外以神識、魂力護丹，護得住多少看本事。劫不一樣：

- **能隨意引劫**（D073 補記二）：不必等丹到高階或近無瑕，低階丹也能被他用自身的雷勾來丹劫。所以他早期的一痕養血丹就有雷紋。
- **能自己上身去渡那一道劫**：把劫雷接到身上、控住，再拿它來提純丹藥。

所以別人的雷紋丹是高階丹師的本事、而且稀少，他的雷紋丹在低階就有、品質穩定得好。痕數照實記下他替這爐丹接了幾道劫雷。

不同丹方對雷力的耐受不同。多一道雷紋不保證對每名服用者更合適，也不能把暫時壓住的藥性衝突當成已經消除。剖丹、封樣、穩定觀察與服丹反應共同確認品質。

## 雷紋的四個成熟層次

痕數＝這爐丹挨過幾道劫雷（D073）。一、三、六、九是沿用的四個常稱，二、四、五、七、八痕一樣存在。

| 層次 | 外顯與結構 | 新版定位 |
|---|---|---|
| 一痕雷丹 | 一道可辨的細雷痕 | 挨過一道劫雷；雜質與衝突初步燒去 |
| 三痕雷丹 | 三道相連雷紋 | 挨過三道；丹力運轉更協調，需驗證融合及吸收穩定度 |
| 六痕雷丹 | 雷紋形成較完整脈絡 | 挨過六道；丹與配方都要撐得住，對渡劫者控雷要求更高 |
| 九痕劫丹 | 九痕閉合成環 | 挨過九道劫雷；名稱沿用，不代表自動升階 |

痕數不等於品質，品質仍依下、中、上品與無瑕判定。挨過劫雷卻淬得不勻的紋路，不能按痕數出售。舊文固定「藥效高兩至三成」與「天地判定超越品階」不沿用為新版保證。

## 丹劫與承雷

**觸發門檻（D073 補記二）**：一般丹師只在高階丹（約七階以上）或品質極高（近無瑕）時引來丹劫；能以神識、魂力護丹的丹師可撐過，護不住就毀丹。劫能隨意引劫。每一枚雷紋丹都挨過丹劫。丹劫大小、首發事件與劫可承範圍未定。

**兩界**：三十二天與聖土都能以神識或靈魂護丹過丹雷（作者 2026-10-02：「這邊也能」）。兩邊的分別在劫：他不只護，而是上身接雷提純，並且能隨意引劫。

承雷受肉身、雷身穩定度與精控上限約束，可能毀丹、傷身並牽連本尊。過強雷力必須有疏導與中止手段；公共丹房須避開其他爐位及不知情者。舊稿高渡劫成功率只是成熟後方向，不是入門能力。

## 可沿用丹方與命名

養血丹、淬骨丹、安神丹可作基礎丹方素材，依新版需要分配階數與配方。劫入門能獨立煉少數一階丹；具體哪張丹方是一階須另列，不能把所有同名丹一概認為同階。續雷脈丹保留為後續共同研丹素材，不預定初期已能煉成。
