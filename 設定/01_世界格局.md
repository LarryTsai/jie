# 世界格局

來源：`歸檔/原始討論/` 中的《九界與上古戰爭》討論資料。以下區分已選方向與候選機制。

## 已選方向

| 層次 | 已知關係 | 尚缺的設計 |
|---|---|---|
| 仙界 | 有仙帝、仙庭及十八王庭；王庭分九強、九弱 | 統治制度、權力邊界、當代政治 |
| 九弱王庭 | 核心領地仍在仙界，各有一片外圍下沉成九界 | 各家和下界居民的實際關係 |
| 九界 | 源於受古戰影響的九片外圍；陸沉故土是其中之一 | 方位、環境、居民、交通與地方勢力 |
| 異域 | 古時與仙界互通，戰後難以跨越 | 內部政體、族群、生活與當代主張 |

九強不是全員同謀，九弱也不是一致受害、彼此無爭的整體。異域內部同樣可以有不同利益與立場。

## 候選機構與交通

- 九殿可能是仙界對九界的機構，玄殿可能與陸沉所在之界相關；對應與權限未定。
- 九界間可以存在下沉前留下的殘缺通路；古驛站、對岸接應、界潮窗口是候選條件。
- 少數穩定通道可能受王庭控制；交通權可以影響防務、貿易與史料交流。
- 陸沉的禁制能力可能協助理解、局部修復通路，不能因此隨意往返所有世界。

「九界驛道」「界潮」「界錨」都不是已定名稱或規則。

## 先設計陸沉生活的那一界

| 面向 | 需要回答的問題 |
|---|---|
| 地理 | 家鄉、修行場所、市鎮與危險區域怎麼相連？普通人能走多遠？ |
| 生活 | 人如何謀生，修士與凡人的接觸是什麼？ |
| 權力 | 誰管地方、宗門和跨域交通？彼此如何制衡？ |
| 修行資源 | 誰能開始修行，誰掌握機會，失敗者如何生活？ |
| 對外認知 | 普通人知道仙界與其他八界存在嗎？知道到什麼程度？ |
| 歷史痕跡 | 古戰留下哪些已融入日常的地貌、習俗或禁地？ |
| 當代矛盾 | 即使沒有上古陰謀，這裡的人今天仍會為何事衝突？ |

本表是設計欄位，尚未填入新的世界事實。

## 其他八界的設計原則

每界至少有獨立的地方人物、資源需求、權力衝突與值得前往的原因；古戰紀錄只是其中一條線。無須每界固定一件證物，不按編號逐關探索，也不預設陸沉故土是異域唯一入口。
