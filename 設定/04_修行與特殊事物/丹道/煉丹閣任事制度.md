# 煉丹閣任事制度

狀態：丹師稱號與六項能力卡依 D073（2026-10-02 作者拍板）。

## 劫為何來

劫為減輕體修開銷而學丹。入宗共同教習中學辨材、控火與成丹，能獨立煉少數一階丹、通過考核後再承接任務。這取代舊稿先從搬運、清爐起步的主線；日常清爐與備料仍是煉丹工作的一部分。

淬體、養血、傷後修復都消耗丹藥與貢獻。宗門給予修行基礎不等於足以供應劫全部個人需求；他以煉丹維持自己選擇的修行，不一開始就靠雷紋暴富。

## 定額交丹與收益

沿用宗門供料、約定交丹、超額成果自留或內部回售的制度。交回丹藥必須合格；失敗、損耗與材料結餘要記清，不能用不穩定雷紋冒充高品。

舊文低階養血丹示例為十份材料交六枚合格丹，多出的可自留或回售；此例收錄作初版任務模板，不推成九階所有丹方共用的成丹率。普通任務失敗的合理耗材由任務供料承擔，長期不達要求須調整任務或暫停領料。

回售價低於市場價，因宗門已提供材料與爐位，並承擔收購風險。宗門供料煉出的丹不得任意私售；自購材料的私人開爐另外約定。雷紋丹須驗證後估價，不只數表面紋路。

## 實驗丹與私人委託

實驗配方先約定材料、損耗、報酬與分成。洛生衣調方的工作獨立計酬，不併入劫的超額收益。私人委託另訂交付數量與額外成丹歸屬，不能把一種普通丹的制度直接搬到所有任務。

完整舊方案已保存在本專案：普通丹回購市價四至五成、上品六成；成熟後十份交七枚；實驗丹宗門六成、生與劫各兩成；私人委託三份材料交一枚。這些金額比例屬待重新核定的歷史模板，不作新版現行契約。不得一面許諾超額歸弟子、一面事後追收；若任務條件改變，須先重新約定。

## 丹師稱號與能力卡（D073）

**稱號只認穩階**：「X 階丹師」＝能**穩定**煉出 X 階常見丹方。煉丹閣考核即穩階認定，任事可依穩階派。單次偶然成丹稱「偶成」，不算入稱號。考核的具體門檻（連爐成丹比例、品質下限）留白。

**六項能力卡**，各分**生、熟、精**。稱號簡單，人物的長處寫在卡上，用場面呈現；丹階高的人不一定六項都強。

| 項 | 看什麼 |
|---|---|
| 控火 | 火源與火候的精細（地火、獸火、靈火、雷） |
| 辨材 | 認材、知藥齡與產地、識假 |
| 成色 | 煉出的品質上限（下、中、上品與無瑕，見[丹藥與雷煉丹](丹藥與雷煉丹.md)） |
| 改方 | 調整、合併、新創丹方 |
| 驗丹 | 剖丹、封樣、判丹毒與穩定度 |
| 臨床 | 看服丹的人：體質、傷勢、抗藥性、劑量 |

人物卡（陸沉、洛生衣、寧枕微、何靜安等）的穩階與各項數值留白，待逐人配置；生的雙環第三形態屬作者底牌，能力卡不涉。聖土煉藥師九品不換算。

## 雷身不是免費勞力

不同雷身可前來任事、領丹。長時間精控會占用神魂承載，雷核共鳴與回歸可能牽連本尊，修行、休息、煉丹需要取捨。早期不能日夜無限開爐；成熟後成丹率、品質與任務能力的改善，要由具體練習與驗證支撐。

## 可見的宗門日常

清晨先看領料與爐位，再決定當日能接多少活；傍晚把交回的丹、試驗樣丹與未用材料分開。多煉成一枚，可能只夠抵掉一小段淬體開銷。對劫而言，這份本領讓他能持續修行，也讓他逐漸認識丹師、同門與服丹者。
