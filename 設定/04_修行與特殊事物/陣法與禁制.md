# 陣法與禁制

狀態：D058（2026-09-30）自舊庫〈陸沉陣法修習與破陣邊界〉移植。只搬處理層級、破陣流程、失敗來源與「騙過判讀不等於能控制」；舊雷名（照命、煌命等）、舊命圖的戰術解鎖表、原作地名與舊正文實例不帶（命圖本身已由 D069 接回，見[太玄命圖](太玄命圖.md)；命圖只排位、分流、記軌，不提供佈陣與推演能力）。陣道傳承見[藏玄峰](../01_世界格局/勢力/太玄宗/藏玄峰.md)，禁制世家見[文奕](../03_人物設定/主角群/文奕.md)。

## 一、陣與禁的分工

- **陣**：承載與運轉力量——聚、分、導、困、殺、隔、傳送。有陣基、陣眼、節點、循環與供能。
- **禁**：寫在陣上的規則——對誰生效、何時觸發、誰有權限、禁止什麼、代價歸誰、怎麼解除。
- 一座真正的護山大陣通常兩者都有：外圍的陣負責力量，陣中的禁負責身分與權限。「被陣困住」與「被禁擋住」是兩個不同的問題，解法也不同。

## 二、陸沉的位置

- 陣法不是陸沉的主要大道，不另開陣道宿敵、陣塔奪魁或陣圖競賽線。他在太玄宗受過正式、持續的基礎陣法教育，不是憑天賦臨場猜陣。
- 陣是他的工程骨架與生存工具；禁制是他的副道與個人特色；煉體與雷道是正面戰力；神識支撐觀察、記憶與精度。
- 專精：引雷、聚雷、雷力分流、以陣承載禁制。扎實：辨陣、修陣、由運轉現象反推陌生陣法的用途。只懂需要的部分：幻陣、聚靈、煉丹陣等常規門類。能理解與協助、但不是最強設計者：護宗、山河級大陣。
- 文奕的禁制學養與藏玄峰的陣道傳承，都是陸沉取代不了的專業；青璃的相界只管五行，不碰禁制。

## 三、處理層級

| 陣法威脅 | 合理結果 |
|---|---|
| 同境普通陣法 | 能辨識並自行破解 |
| 同境頂級陣法 | 能破解、繞過或局部反制；對方仍可變陣、設假路 |
| 高一境界大陣 | 難以正面拆除，但能護住眼前人、偏移殺機、開短暫生路 |
| 遠古完整大陣 | 只能理解部分規律、局部封禁，或依它允許的規則短暫通行 |
| 遠超己身的殺陣 | 知識補不了力量鴻溝；只能更早察覺、少走一步死路、爭取逃生 |
| 殘缺、失控的大陣 | 最擅長：利用破損、倒灌與失控節點重排局部循環 |

「任何陣法威脅都能處理」的意思是一定能看、能判斷、能採取有效行動，不保證當下完整摧毀。可以困住陸沉，但不能讓他完全失去行動：破不了整陣，也至少完成辨陣、護人、局部斷路、延遲觸發、改變落點、記錄規律之一。

## 四、被大陣保護的寶物：先分四層

| 層次 | 功能 | 能否處理 |
|---|---|---|
| 外圍大陣 | 聚力、困殺、隔絕 | 能辨路、局部破局，未必能完整拆除 |
| 陣中禁制 | 身分、權限、封空、觸發 | 最擅長欺騙、暫停或改寫局部 |
| 寶物封印 | 保護或鎮壓寶物 | 可研究解封，但要先判斷封印目的 |
| 認主禁紋 | 限制持有與催動 | 可解除部分人為限制；有靈性的器物仍有自己的選擇 |

最重要的判斷不是怎麼開鎖，而是**這把鎖防的是外人進去，還是裡面的東西出來**。破得越快，災難可能越早發生；放棄寶物、重新封回或先救人，都可以是勝利。

## 五、固定破陣流程

神識與陣理初判 → 細雷探路，以回響描出真實骨架 → 確認真實節點 → 禁制封住變化與修復 → 雷或肉身擊穿局部 → 依力量決定整陣崩解或只開一線。

幻象與假陣紋可以騙過感官，騙不過真實的能量傳輸；但這只讓人「看得見」，真正破壞仍靠雷力、禁制、肉身、材料與當下修為一起完成。

## 六、七種失敗來源

每場破陣不得照表成功，至少保留一項：

1. 假循環故意餵給探路的雷絲錯誤回響；
2. 陣主臨場換陣、斷路，或以污染反追探路者；
3. 看見了節點，肉身或修為卻來不及抵達；
4. 核心不在陣內，由外部持續重建；
5. 看見的破口，其實是誘人解除鎮壓的陷阱；
6. 為了護人，不能選最有效率的破法；
7. 破局本身引起空間崩塌、倒灌或不可逆反噬。

## 七、完整禁制與驗證類禁制

**完整禁制**是有限規則的閉合結構：禁制對象、作用邊界、觸發、供能、執行、反噬歸屬、解除條件與解除後回收，缺一不算完整。完整不等於公平或無敵；血脈豁免與管理權限可以存在，但也要是明示規則並付相應代價。面對完整禁制，讀懂條款不等於找到漏洞，更不等於能反向接管；合理的破局是依規則取得短暫通行、迫使執行者付出既定代價，或完成它本來的合法解除條件。

**驗證類禁制的欺騙邊界**：能騙的只是陣中負責「身分／權限判讀」的節點，改的是那一次判讀的輸出，不是整套禁制。三個條件缺一不成立：

1. 讀得懂這個判讀機制；
2. 有可被禁制干涉的驗證節點；
3. 有足夠的準備時間。

**根本安全閥**：**騙過一次判讀，不等於取得權限；可欺騙，不等於可控制。** 驗的若是事實本身（例如血脈與某人是否真有因果、魂是否真是那一縷），而不是可竄改的判讀結果，就是這條邊界的天花板——騙得了判斷，騙不了事實。不讓讀者以為「駭一次以後所有門禁都沒用」。

僥倖成功的一次（三條件不齊卻過了）要在正文標明是賭，之後不得當成可重複的方法。

## 八、陣痕與陣痕共振（總稿 v3）

- **陣會記下自己的運轉**：陣盤與禁制的運轉紀錄、祖脈上的陣痕，是修士世界的記錄載體之一。被抹會留空白，被對齊會留層疊（見[修士遺痕與後手](修士遺痕與後手.md)）。
- **太玄閣古測脈陣**：太玄閣地下有一座古測脈陣，閣中的修脈簿就是照它抄錄的。陸沉第 1 篇當學徒時抄到「祖脈第七節」缺了一刻；那不是抄漏，是陣自己停在了那一刻。第 22 篇校正要抹掉的正是這座陣，他分到長亭天的雷身守住陣核，被滅，陣保住；第 25 篇封寒、文奕、奚箴下到閣底喚醒它，讀出停住的那一刻。
- **陣痕共振（P12，候選）**：同一次撤去護持、留在各處的祖脈陣痕，會在道脈再次被大幅牽動時同時重演；只有校正這種規模的牽動才夠。第 25 篇強接派試陣牽動道脈，「三刻」同時亮起：太玄閣古測脈陣停住的那一刻、伏雷坳的那一層劫痕、玄闕祖脈裡商玄度從未觸發的罪證後手（含公冶陣譜記下的演練時刻，由繼承人商應璋放行）。三處斷口都很整齊；天災不會在三處留下同一刻、整齊的斷口。
- 平時沒有人看得到三刻並在一起：陣痕各在一處，道脈不被牽動就不會重演。這是八萬年沒人看破「此乃量劫」的世界層理由之一，不是誰刻意藏的。

## 待定

禁制師的境界門檻與人手下限；護山大陣的通用規格或逐宗專屬；多人合陣如何合力。依[修士邏輯基準](修士邏輯基準.md)，未定前寫留白，不自行補通則。
