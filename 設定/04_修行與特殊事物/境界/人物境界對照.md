# 人物境界對照

## 已有明確決定

| 人物或群體 | 現行結論 |
|---|---|
| 仙庭之主 | 仙帝境；並非世上唯一仙帝境 |
| 照塵，雲行師父 | 天神境遊方禪修，雲行知道其大致修為 |
| 當代九界本土強者 | 天神屬高層，少數達虛道；不等於每界配置相同 |
| 上界降臨本體／化身 | 入境最高列陣；入界後可依下界條件重修 |

## 配角重新配置

祁承晏、祁承朔、烏蘅、商玄度、厲文恪、裴照川、溫棠、商應璋、岑越、許成蹊的精確境界皆待按新体系重新配置，保留姓名、角色經歷與已設計的修行方向，不用舊境界機械對換。人物專檔與定名總覽不得繼續把舊配表當作已採用境界。

裴照川須區分救災、查案與後續衝突時期，不能因悲痛瞬間提升修為。岑越化身進界時不超列陣，當代事件時修至何境仍未定；不得把入境上限當成永遠上限。

劫、封寒、生、文奕、雲行各階段具體境界及年齡另排。兩位皇子的相對戰力、刺殺需要多少同謀與代價，須隨新配置重核，不由舊數字推定。
