# 境界與能力尺度

本檔為現行規則。撤回的境界表與人物分配已移至歸檔，不能以舊表逐階換名。

## 境界順序

搬血 → 洞天 → 化靈 → 銘紋 → 列陣 → 尊者 → 神火 → 真一 → 聖祭 → 天神 → 虛道 → 斬我 → 遁一 → 至尊 → 真仙 → 仙王 → 準仙帝 → 仙帝。

沿用《完美世界》的境界名稱與順序；聖祭為特殊過渡階段，不強制每人必經。每境細分、壽元、跨境規則已由 D073 定（見下「小境、壽元與跨境」）；飛行、神識及肉身能力尚須逐項設計，不能用撤回的能力表代填。皇子、聖子、王主是身分，不是境界。

**上層壽元（D042，工作用，可調）**：真仙約一至三萬年；仙王約十萬年；準仙帝數十萬年；仙帝百萬年級。搬血至至尊各境壽元見下「小境、壽元與跨境」（D073）。
- 道傷折壽且不復原；撼動天地的全力出手也在燃燒壽元，仙帝亦然。
- 封界這類以本源為代價的出手，約削去施術者一半壽元。
- 心魔（例如知而不言、道心有瑕）不減壽，但會使修為長年停滯，可作外證。
- 古戰的道傷普遍削去參與者約半壽，因此約八萬年後仍在世者極為罕見。

## 下界與仙力

下界以靈氣修煉、運用法力；上界可修仙力。同境界使用仙力與法力，威力有明顯差距，但悟道、技藝、肉身與實戰仍影響勝負。

下界不能直接運轉仙力：仙力要連得到極（大羅、上下無極的仙土道脈，或仙帝自立的極）；九界是被斬斷的仙土，道脈還在、斷口卻通往界壁，仙力一放出來就順著斷脈瀉進界壁，所以放不出來。**斷了的路比沒有路更糟。**下無極道脈仍經仙路連回大羅，所以可以運轉（D048、D065）。這條理由只用來解釋九界：聖土從來沒有道脈，沒有東西牽走仙力，仙修在聖土照常運轉仙力（見下「與聖土」）。攜帶到九界的仙力、仙晶與仙器不能繞過規則，必須轉作法力方能使用，仙器不能發揮完整仙威。真仙突破須仙力條件；下界法力修行理論上可至至尊，當代人物分布則是尊者為一方頂尖、天神為高層、少數達虛道，不預設各界皆有同數量強者。

這取代「本土道基相契、外來者因道則不合受限」及「成真仙後必須離開下界」的早期候選。

## 跨界一律本體（D058、D059）

作者定：**所有人跨層、跨界都用本體，不用化身**，不論主角或反派；三十二天內部（九界、下無極、上無極、大羅之間）也一樣。雷身化身、分神化身、法身入界等一切「化身入界」寫法撤回。

- **雷身可單獨跨界（D064，推翻 D059 的同進同出）**：陸沉的雷身不是化身，而是他的本源本身，所以不在撤回之列；本尊可留在一處，雷身單獨跨層跨界。每具雷身入九界各自壓境、各佔錨陣一份、各帶一枚錨印（D065），一樣留壓境簿與氣機拓印；破一具即破一印，各自違約。代價是本源分處界壁兩側被撕扯，分處越多、越久越重。取雷仍須本尊在場。詳見[雷種熔煉與雷身修行](../雷道/雷種熔煉與雷身修行.md)。
- 同一天地之內，他人是否有分身、分身能做到什麼：留白，不作因果防火牆使用（見[主線推理骨架](../../05_故事主線與揭露/主線推理骨架.md)第四節）。

## 入九界：本體最高列陣（D059；壓境形式依 D065 改為錨印）

九界界壁受創最深，本身就是封合縫的一部分，承載不了列陣以上的修為（D048）。**界壁與界潮秤的是當下釋放、承載的層級，不追查本源的最高境界；但只認鑰不在身上的封印**（D065）。自己封住修為、裝成列陣，鑰在自己身上，隨時放得出來，所以過不了界壁（D059 此條照舊）。高於列陣的本體要入九界，只有兩條路：

| | 壓境（錨印） | 退境 |
|---|---|---|
| 做法 | 由正規界路的錨陣在本人道基上烙下**錨印**，把列陣以上的修為一重一重封住（一重對一個大境界，仙王約十重），修為封在本人體內、隨身帶走；**對印**留在錨陣。本體以列陣之力入界，出界時兩端合印解印 | 自行散去列陣以上的修為，真正退回列陣 |
| 走哪條路 | 壓境只能在正規界路完成（要有錨陣）；壓完之後，身上帶著錨印的人當下承載只到列陣，低路界潮一樣放行（見下「三十二天內部與聖土」） | 任何路，含低路與險路 |
| 可逆與否 | 可逆，但有**印期** | 不可逆；回上界不會自動恢復，須重修 |
| 誰點頭 | 須有擔保（宗門或王庭）；上端王庭錨陣烙印並持對印，下端守界傳承持下端副印；解印要兩端合印 | 不須任何人點頭 |
| 留下什麼 | 兩端各記一本壓境簿：名籍、印號、入出日、封了幾重、印期、擔保方、入界時的氣機拓印；破印者另記**破印簿** | 出身處的命牌、宗門名冊、俸冊會記下「此人修為散了」；身上有散功痕 |

**壓境的代價**：
- **對印與擔保在王庭手裡**：錨印屬於王庭，破印即違約。後果見下「破印」。王庭的槓桿不再是扣著修為，而是知情、擔保、回程登記與除籍。
- **印期與鏽蝕**：印期數月，可申長印，最長約一年，擔保加重。印期內須回正規界路兩端合印解印；**逾期錨印會「鏽」**，被封的修為自最高一重起逐重剝落，等同部分退境。不寫成可以住下來的長假。
- **錨陣容量有限**：錨陣借界壁承載，每一枚對印佔一份，一座錨陣同時只掛得住少數幾枚。多身者每具雷身各算一份，陸沉壓境一次就佔掉好幾份。
- **在九界只有列陣之力，強破即被剪**：記憶、見識、神識的精細與技藝都在，力量只有列陣。本地的尊者、天神打得過他。九界之內錨印**只能破、不能解**：強破衝出來的修為會被界壁當場剪掉，等於當場退境，還引來界震，而且照樣算違約。所以壓境者在九界確實只有列陣之力。
- **身上有錨印**：道基的形狀高於列陣，修為卻被一重重封住。同境修士近身看得出，守界傳承一眼就認得。破過印的人，道基留下裂開的**印痕**，終身可見。

**破印**：
- 第一重一開，錨陣上的對印當即裂開，上端當下知道名籍、印號、時刻；氣機拓印無從抵賴。
- 本人記入破印簿，永除正規界路之籍：此後再入九界只能退境。印痕讓宗門、仙籍司、接引處一見就知道此人違過界路之約，晉升、接引、聯姻、擔任職司都受影響。
- 擔保宗門界路通行額凍結，量級數百年；擔保人罰俸、除職。擔保方若是掌管錨陣的王庭本身，界路司可暫收其錨陣掌管權。
- 私入聖土罪同私開界路，界路司立案，仙庭可發追界令。
- 在聖土解封就是破印，規則見[境界對照與跨界](../../01_世界格局/聖土/境界對照與跨界.md)「錨印」。
- 在九界強破，剝落的界壁碎屑就是**界屑**（P6，見下「規則補丁」）。逾期鏽蝕不會自己停，合印才止；在上界自解等於破印（P5）。

**退境**：肉身與神識實際力量相應下降；保留記憶、悟道見識及已取得的剩餘壽元。回上界仍須重修。出身處的名冊與命牌照實記下，在上界藏不住。

**天然列陣以下**的人（上界出生的年輕弟子、低境家臣與遞書吏，或九界本土修士）不用壓境，可走正規界路（照樣登記在通行簿）或低路、險路（不登記）。

進界後可以依當地資源重新修行、突破尊者及以上，仍只能運用法力。列陣是入境上限，不是下界永久戰力上限。壓境者在九界自行突破，等於在錨印之外另長一份修為，解印時兩份相撞，後果待定；行文避免。

### 為何上界強者不隨意下界

- 下去只剩列陣之力，九界本土的尊者、天神、虛道打得過他；強破錨印即被界壁剪去；
- 仙力在九界不能運轉（斷脈瀉力），也沒有修行好處；
- 壓境要有擔保，對印握在掌管該界界路的王庭手裡，名字、印號進兩本簿；破印即除籍、連坐擔保方；
- 印期數月，住不久；
- 退境不可逆，代價是半生修為。

### 修士幾萬年了，為什麼還沒解決

- **解決過，換來了新問題**：壓境本身就是戰後找出來的解法。它讓人下得去，卻讓掌管錨陣的王庭握住了每一個下界者的對印、擔保、回程登記與除籍，成了王庭的制度槓桿。
- **補界壁等於動封合縫**：界壁是封縫的一段，由封界時的帝境本源與道則相撞而成。要讓它承載更高修為，得有仙帝境本源去補，還可能把縫撕開，重演「能封住的邊界正在後退」。
- **有力的人都要這條線留著**：救援派的戰後要求是「有限往來」，列陣上限正是它的保證，上界的軍隊與強者壓不進九界；九界的守界傳承靠它自主；掌管界路的王庭靠錨陣收租、握人。想拆掉這條線的，只有要把九界拉回中心的歸一派。

## 三十二天內部與聖土

- **下無極、上無極、大羅之間**：不設入境上限，不必壓境或退境；本體經仙路關口通行，留仙路通行記錄。關口由誰掌、要什麼憑證、低境者往內走是否承受道則壓力：待定（Q03 殘項「上下無極跨層通行」）。入大羅須登籍（P3，D066）。
- **九界與上無極之間**：除正規界路逐層飛升外，只有古界路路身一條例外（P1，D066）。
- **三十二天與聖土之間**：不設入境上限，限制在路上。**低路**（封合縫的界潮窗口，仙界端在九界邊緣的險地，聖土端在封合縫雷域）只容**當下承載在列陣／鬥靈以下的人**（含列陣）：天然列陣以下、退境者、身上帶著錨印的壓境者、上了縫鎖的聖土人。界潮只秤當下承載，只認鑰不在身上的封印，自封無效。低路本身沒有錨陣，壓境須先在正規界路完成；所以壓成列陣的高境者可以經九界走低路入聖土，到聖土逐重解封，但解封就是破印違約。在對岸長出列陣以上的修為（突破或破印），就過不了回程的界潮，除非求得聖土的縫鎖。**高路**是穿虛能力加存量，去程須留足回程。九界因此成為兩界之間的低階門戶與中轉站（D065）。見[境界對照與跨界](../../01_世界格局/聖土/境界對照與跨界.md)。

## 規則補丁（D066）

主線路線定案時補的九條推論，條文與用處見[主線路線總稿](../../05_故事主線與揭露/主線路線總稿.md)第五節。都是現行規則的推論，不另開新體系。

- **P1 古界路路身**：古界路外段沉成九界、內段崩成上無極斷峰群，夾層裡還漂著路身碎片。從九界那一端進入，只容當下承載在列陣以下的人，出口在斷峰群。這是九界通上無極、不經錨陣的**唯一例外**；漏影仍不可通行。
- **P2 墜落入界**：重傷墜落進九界，界壁以當下的承載能力計（道基碎到列陣以下即放行），不登簿；散失的仙力會往外瀉。墜落的人在九界每動用一份修為，就被界壁剪走一份。
- **P3 入大羅須登籍**：大羅道脈只認登籍者。未登籍的人吐納歸零，被道則一層層外推出去；推的是人，不剝修為。
- **P4 斷脈之物離開九界就失性**：九界特產隨斷脈而生，帶離九界就失去藥性；以封泥封住可以保住。
- **P5 錨印推論**：鏽蝕不會自己停，回錨陣合印才止；在上界自行解印等於破印。多身者共同破境，要等落後（被鏽、被封）的那具雷身補齊。
- **P6 界屑**：強破錨印時，衝出的修為被界壁剪去，同時剝落一片界壁碎屑。界屑封著界壁裡的帝境本源，**偏向極、可被追蹤**；被歸墟吞雷時會一起吞入本源，此後沒有人拿得走，追兵追的是人；只能在大羅帝道場剝出。
- **P8 守約往返**：經錨印去聖土而守得住約，要密集期、長印、窗口剛好接得上三個條件第一次湊齊（D065）；九霄的節律加上潮門的潮曆，兩份合讀才定得出窗口。
- **P9 拓印隨道基改變**：**只限道基碎裂後重構**的場合，氣機拓印會變，連自己的名字都頂不回去；其餘場合拓印不變，所以拓印仍是驗身的硬證據（溫棠案的拓印證據不受影響）。
- **P10 宗門接引不限於參賽者**：仙境宗門接引的對象，不限九界大比的參賽者（見下「上界機會」）。
- **P11 取雷殘影、P12 陣痕共振**（總稿 v3 新增，候選）：不涉境界與跨界，見[雷種熔煉與雷身修行](../雷道/雷種熔煉與雷身修行.md)、[陣法與禁制](../陣法與禁制.md)第八節。

不採：縫行（沿封合縫劫雲帶在界壁內側行走）、陣斷拋送、頂名上界、仙帝壓境。

## 上界機會

未滿二十歲、尊者境或以上者有正常上界通行資格，不須先投靠王庭。人族以實際年齡計算；生命週期不同的異族以命輪成熟度判斷，須相當於人族未滿二十歲，且命輪同時檢查心智成長、實際修行歲月與血脈蛻變，不能靠晚化形或沉睡規避。完整規則見[五域特殊族群分布](../../01_世界格局/五域/五域特殊族群分布.md#年齡與命輪成熟度)。

另一途徑是九界大比獲仙境宗門賞識、本人同意後由宗門接引，可不受前述一般門檻限制。宗門邀請不能代替本人選擇。宗門接引不限於參賽者（P10，D066）。

## 仙帝境與帝位

仙帝是境界，達此境者不只一位。仙庭帝位是政治與天地責任所在，不等於唯一仙帝境。王庭與帝位的制衡見[仙庭與王庭權力根基](../../01_世界格局/仙庭與王庭權力根基.md)。

## 與聖土

- 兩界境界對照見[境界對照與跨界](../../01_世界格局/聖土/境界對照與跨界.md)（D049）：各在主場全力時大致相當，不是換名表；對齊質變點，不對數值。任一方離開自家天地，依客場修正計，修正不越質變點（D065）。
- **境界帶得走，天地帶不走**（D065）：跨界時原有能力完整保留。仙修在聖土照常運轉仙力，神通、仙器、仙威都在；鬥聖在三十二天仍是鬥聖。限制只有兩項：
  1. **天地補給不相容**：初到異界的本地吐納，列陣以下約主場六至七成，尊者至天神約三成，虛道至至尊約一成，真仙以上幾近於無；煉化對方天地之物只取一成上下，其餘是雜氣。自帶仙晶是唯一足量的自帶補給，封合縫雷晶是仙修在聖土最乾淨的補給（雷望衛特許與配額）。
  2. **主場法則有差異**：真仙以上在仙土引道脈之勢，離家只失這份加成（約一至兩小階，不越質變點），己身不減；另有空間、感知、陣與禁制、丹藥、劫五項「不熟」。
- **成長路徑：譯氣**（理解對方天地，不算限制）：客 → 居 → 通三階，轉化效率逐階提高、不熟逐步消失，通階補給最高五至七成；越高越慢；不給主場加成。
- **突破**：真仙必須回三十二天突破，鬥聖必須在聖土突破；以下可在異界突破，但破境之力須以自帶、同源補給與譯氣攢足。不能兼修，只能轉修（D048）。
- **帝境自成天地**，補給與主場隨身；代價是仙帝入聖土即動封（D052）。
- 仙修在聖土破境照樣起劫；聖土修士突破無天劫（D051）。
- 舊稿「仙修在聖土只能運轉法力、仙力轉作法力」「鬥聖離開聖土約退到半聖」作廢（D065）。

## 生死與資訊

力量強不等於全知。辨識術痕不能直接得知所有人的動機，遺骨也不能自動重放完整歷史。神魂徹底毀滅後不能靠殘痕還原完整原人；公主、長子與女子之死不因後期修為提高便作廢。
