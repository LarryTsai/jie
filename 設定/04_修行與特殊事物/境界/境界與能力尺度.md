# 境界與能力尺度

本檔為現行規則。撤回的境界表與人物分配已移至歸檔，不能以舊表逐階換名。

## 境界順序

搬血 → 洞天 → 化靈 → 銘紋 → 列陣 → 尊者 → 神火 → 真一 → 聖祭 → 天神 → 虛道 → 斬我 → 遁一 → 至尊 → 真仙 → 仙王 → 準仙帝 → 仙帝。

沿用《完美世界》的境界名稱與順序；聖祭為特殊過渡階段，不強制每人必經。每境細分、壽元、飛行、神識及肉身能力尚須逐項設計，不能用撤回的能力表代填。皇子、聖子、王主是身分，不是境界。

**上層壽元（D042，工作用，可調）**：真仙約一至三萬年；仙王約十萬年；準仙帝數十萬年；仙帝百萬年級。其餘各境壽元仍待設計。
- 道傷折壽且不復原；撼動天地的全力出手也在燃燒壽元，仙帝亦然。
- 封界這類以本源為代價的出手，約削去施術者一半壽元。
- 心魔（例如知而不言、道心有瑕）不減壽，但會使修為長年停滯，可作外證。
- 古戰的道傷普遍削去參與者約半壽，因此約八萬年後仍在世者極為罕見。

「神火」「天神」「聖祭」保留原名（D033）：此處的「神」指元神、精神，與諸神聖土的神無關；下界或聖土人因字面誤解，可作劇情素材。

## 下界與仙力

下界以靈氣修煉、運用法力；上界可修仙力。同境界使用仙力與法力，威力有明顯差距，但悟道、技藝、肉身與實戰仍影響勝負。

下界不能直接運轉仙力：仙力要連得到極（大羅、上下無極的仙土道脈，或仙帝自立的極），封界斷了九界的道脈；下無極道脈仍經仙路連回大羅，所以可以運轉（D048）。攜帶的仙力、仙晶與仙器不能繞過規則，必須轉作法力方能使用，仙器不能發揮完整仙威。真仙突破須仙力條件；下界法力修行理論上可至至尊，當代人物分布則是尊者為一方頂尖、天神為高層、少數達虛道，不預設各界皆有同數量強者。

這取代「本土道基相契、外來者因道則不合受限」及「成真仙後必須離開下界」的早期候選。

## 跨界一律本體（D058、D059）

作者定：**所有人跨層、跨界都用本體，不用化身**，不論主角或反派；三十二天內部（九界、下無極、上無極、大羅之間）也一樣。雷身化身、分神化身、法身入界等一切「化身入界」寫法撤回。

- **雷身可單獨跨界（D064，推翻 D059 的同進同出）**：陸沉的雷身不是化身，而是他的本源本身，所以不在撤回之列；本尊可留在一處，雷身單獨跨層跨界。界壁與封縫秤的是本源：每具雷身入九界各自壓境、各佔錨陣一份，一樣留壓境簿與氣機拓印。代價是本源分處界壁兩側被撕扯，分處越多、越久越重。取雷仍須本尊在場。詳見[雷種熔煉與雷身修行](../雷道/雷種熔煉與雷身修行.md)。
- 同一天地之內，他人是否有分身、分身能做到什麼：留白，不作因果防火牆使用（見[主線推理骨架](../../05_故事主線與揭露/主線推理骨架.md)第四節）。

## 入九界：本體最高列陣（D059）

九界界壁受創最深，本身就是封合縫的一部分，承載不了列陣以上的修為（D048）。**界壁秤的是本源裡實有的修為，不是外露的法力**，所以自己封住修為、裝成列陣，過不了界壁。高於列陣的本體要入九界，只有兩條路：

| | 壓境 | 退境 |
|---|---|---|
| 做法 | 由正規界路的錨陣，把列陣以上的修為從本體壓出，封存在上端錨陣裡；本體帶著列陣修為入界，出界時取回 | 自行散去列陣以上的修為，真正退回列陣 |
| 走哪條路 | 只能走正規界路（要有錨陣）；低路與險路沒有錨陣，壓不了 | 任何路，含低路與險路 |
| 可逆與否 | 可逆，但有期限 | 不可逆；回上界不會自動恢復，須重修 |
| 誰點頭 | 上下兩端合印：上端王庭封存修為，下端守界傳承持對印；取回也要兩端合印 | 不須任何人點頭 |
| 留下什麼 | 兩端各記一本壓境簿：名籍、入出日、壓存幾份、入界時的氣機拓印 | 出身處的命牌、宗門名冊、俸冊會記下「此人修為散了」；身上有散功痕 |

**壓境的代價**：
- **修為押在別人手裡**：壓出的修為封在上端王庭的錨陣裡，兩端合印才取得回。錨陣受損、界路停航，或任一端不肯合印，人就困在列陣。把半生修為交給別家王庭，是上界強者最不肯做的事。
- **有期限**：修為離身越久越難接回。短期取回無損；逾期就逐層剝落，等同部分退境。確切期限待定，行文以「數月」為量級，不寫成可以住下來的長假。
- **錨陣容量有限**：一座錨陣同時只壓存得了少數幾份。多身者每具雷身各算一份，陸沉壓境一次就佔掉好幾份。
- **在九界只有列陣之力**：記憶、見識、神識的精細與技藝都在，力量只有列陣。本地的尊者、天神打得過他。
- **身上有壓痕**：道基的形狀高於列陣，修為卻被齊齊截斷。同境修士近身看得出，守界傳承一眼就認得。

**退境**：肉身與神識實際力量相應下降；保留記憶、悟道見識及已取得的剩餘壽元。回上界仍須重修。出身處的名冊與命牌照實記下，在上界藏不住。

**天然列陣以下**的人（上界出生的年輕弟子、低境家臣與遞書吏，或九界本土修士）不用壓境，可走正規界路（照樣登記在通行簿）或低路、險路（不登記）。

進界後可以依當地資源重新修行、突破尊者及以上，仍只能運用法力。列陣是入境上限，不是下界永久戰力上限。壓境者在九界自行突破，等於在界內另長一份修為，取回時兩份相撞，後果待定；行文避免。

### 為何上界強者不隨意下界

- 下去只剩列陣之力，九界本土的尊者、天神、虛道打得過他；
- 仙力在九界不能運轉，也沒有修行好處；
- 壓境要把修為押給掌管該界界路的王庭與守界傳承，名字進兩本簿；
- 有期限，住不久；
- 退境不可逆，代價是半生修為。

### 修士幾萬年了，為什麼還沒解決

- **解決過，換來了新問題**：壓境本身就是戰後找出來的解法。它讓人下得去，卻讓掌管錨陣的王庭握住了每一個下界者的修為，成了王庭的槓桿。
- **補界壁等於動封合縫**：界壁是封縫的一段，由封界時的帝境本源與道則相撞而成。要讓它承載更高修為，得有仙帝境本源去補，還可能把縫撕開，重演「能封住的邊界正在後退」。
- **有力的人都要這條線留著**：救援派的戰後要求是「有限往來」，列陣上限正是它的保證，上界的軍隊與強者壓不進九界；九界的守界傳承靠它自主；掌管界路的王庭靠錨陣收租、握人。想拆掉這條線的，只有要把九界拉回中心的歸一派。

## 三十二天內部與聖土

- **下無極、上無極、大羅之間**：不設入境上限，不必壓境或退境；本體經仙路關口通行，留仙路通行記錄。關口由誰掌、要什麼憑證、低境者往內走是否承受道則壓力：待定（Q03 殘項「上下無極跨層通行」）。
- **三十二天與聖土之間**：不設入境上限，限制在路上；低路只容列陣／鬥靈以下（**含列陣**）與退境到列陣者，壓境者走不了低路。見[境界對照與跨界](../../01_世界格局/聖土/境界對照與跨界.md)。

## 上界機會

未滿二十歲、尊者境或以上者有正常上界通行資格，不須先投靠王庭。人族以實際年齡計算；生命週期不同的異族以命輪成熟度判斷，須相當於人族未滿二十歲，且命輪同時檢查心智成長、實際修行歲月與血脈蛻變，不能靠晚化形或沉睡規避。完整規則見[五域特殊族群分布](../../01_世界格局/五域/五域特殊族群分布.md#年齡與命輪成熟度)。

另一途徑是九界大比獲仙境宗門賞識、本人同意後由宗門接引，可不受前述一般門檻限制。宗門邀請不能代替本人選擇。

## 仙帝境與帝位

仙帝是境界，達此境者不只一位。仙庭帝位是政治與天地責任所在，不等於唯一仙帝境。王庭與帝位的制衡見[仙庭與王庭權力根基](../../01_世界格局/仙庭與王庭權力根基.md)。

## 與聖土

- 兩界境界對照見[境界對照與跨界](../../01_世界格局/聖土/境界對照與跨界.md)（D049）：各在主場全力時大致相當，不是換名表；對齊質變點，不對數值。
- 仙修在聖土只能運轉法力，仙力只能轉作法力；以法力可在聖土修到至尊，真仙必須回三十二天突破。鬥聖以上離開聖土約退到半聖，必須在聖土突破。不能兼修，只能轉修（D048）。
- 仙修在聖土破境照樣起劫；聖土修士突破無天劫（D051）。

## 生死與資訊

力量強不等於全知。辨識術痕不能直接得知所有人的動機，遺骨也不能自動重放完整歷史。神魂徹底毀滅後不能靠殘痕還原完整原人；公主、長子與女子之死不因後期修為提高便作廢。
