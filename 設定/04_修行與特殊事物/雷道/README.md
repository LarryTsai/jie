# 新版九雷

狀態：九雷名稱與核心方向已定；取得順序及下界五雷、上界四雷的階段已定。世界有許多異雷，其他修士也能收服、兼修，並非天地只有九種雷。

劫起初沒有集齊九雷的目標。隨修行理解不同雷性如何相容、互補，才逐步推演出自己的九雷格局，再尋找所缺異雷。九雷不是天定名單或預裝九個空位。

| 異雷 | 核心 | 取得次序 |
|---|---|---|
| [星羅銀雷](星羅銀雷.md) | 察脈、雷絲滲透 | 第一；十至十二歲，太玄閣時期；確切取雷年齡待配 |
| [兩儀玄雷](兩儀玄雷.md) | 兩極吸斥、雷印牽引 | 第二；十三歲左右，太玄宗 |
| [太古震魂雷](太古震魂雷.md) | 雷音震魂 | 第三；十四歲左右，百宗盟試之前 |
| [千相紫雷](千相紫雷.md) | 外界光影與聲音幻變 | 第四；十六歲，天域書院時期 |
| [流光金雷](流光金雷.md) | 持續極速，不涉時道 | 第五；十七歲九院大比之後、十八歲九界大比之前 |
| [殞星天雷](殞星天雷.md) | 壓雷成核、爆發 | 第六；上界前期；年齡未定 |
| [歸墟黑雷](歸墟黑雷.md) | 吞雷煉力，不複製雷性 | 第七；上界中期；年齡未定 |
| [太虛神雷](太虛神雷.md) | 穿行虛空 | 第八；上界中後期；年齡未定 |
| [九霄劫雷](九霄劫雷.md) | 聚雲、逐重降雷 | 第九；上界後期；年齡未定 |

第十雷刻意留白：舊「無始」名稱、能力、形成及結局均未定為新版。舊天地榜排名、命圖雷位名、進階名與固定戰力倍數亦不沿用。星羅銀雷不再自動稱照命／煌命。
