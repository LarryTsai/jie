# 新版九雷

狀態：九雷名稱與核心方向已定；取得順序已定。階段依 D058、D059：九界五雷 → 落潮一年（十八至十九歲首入聖土，取殞星）→ 無極二雷（下無極歸墟、上無極太虛）→ 聖土篇（九霄，第二次聖土）；第十雷於終局長成（D066）。世界有許多異雷，其他修士也能收服、兼修，並非天地只有九種雷。

劫起初沒有集齊九雷的目標。隨修行理解不同雷性如何相容、互補，才逐步推演出自己的九雷格局，再尋找所缺異雷。九雷不是天定名單或預裝九個空位。

**第十雷（D066 定案）**：作者定要寫，**不作戰，只記往來、讓錨成立**。由兩界交會而生（C10），不收集、不吞、不上榜、不交易、不能被搶：第 22 篇道基碎裂時，九霄、殞星、星羅在裂縫裡隔著漏影與帝天骨架共振成胎；第 23 篇九界每剪他一份修為，總有一絲剪不走；第 27 篇守約往返時隨窗口起伏；第 28 篇錨成立、兩界之氣第一次有規律地往來，它在他身上和渡口同時長成。九雷是取來的，第十雷是長出來的。名稱與具體能力留白；舊「無始」名稱、能力、形成及結局不沿用。舊天地榜排名、進階名與固定戰力倍數亦不沿用。星羅銀雷不再自動稱照命／煌命。**命圖改為新雷新位**（D069，取代原「命圖雷位名不沿用」一句）：太玄命圖已接回，每熔煉成功一道雷，命圖才多出一個主星位，舊命圖的雷位名與星位編號不搬；第十雷的主星位長在劫核與太虛空痕之間，見下節。

## 太玄命圖：主星位與外環（D069）

太玄命圖第 2 篇在太玄命藏初開（十人選拔之後、取震魂之前），完整見[太玄命圖](../太玄命圖.md)。

- **劫核居中**：劫核是陸沉本人，不發雷，決定各雷為何而發。
- **主星位**：每取得並熔煉成功一道雷，才多出一個主星位；位置依雷性與已有各雷的相容關係排，不依榜次，沒有預裝空位。各位的「職」：星羅＝眼、兩儀＝第一條軌、震魂＝魂錨（主星成三角）、千相＝表、流光＝調度、殞星＝核、歸墟＝卸、太虛＝穿（撕痕落在這條軌上）、九霄＝穹、第十雷＝往來。是職，不是增幅倍數。
- **外環綁雷**：每一道雷入主星位，外環對側就多一道淺痕，大多數一輩子空著。伴星的命印落在所綁之雷的淺痕上：**鑑月對震魂、蒼梧對太虛、赤翎對殞星；劫厄不綁雷**，伏在劫核暗側。外環替內環補邊界，不加倍。見[厄與四伴星](../厄與四伴星.md)。
- **第十雷的位置**：主星位長在**劫核與太虛空痕之間**（蒼梧第 21 篇解印後，太虛外環位成永久空痕）。不佔太虛外環位、不讓空痕癒合、不作戰；那道缺從此成了一扇門，往來從那裡經過。

## 招式原則與第十雷（C9、C10，作者選定）

- **招式（C9 甲）**：每道雷有固定基本招，功能隨境界逐步增加，強招再擴張；可與聖土鬥技的天地玄黃品階互相對照。
- **第十雷（C10）**：由三十二天與諸神聖土兩界交會而生。須刻意避開鬥破「異火」的影子（見待定 Q22）。形成與功能邊界已由 D066 定（見上）；名稱與具體能力仍待設計。
- **九雷分布（D058 定）**：甲案——歸墟取自下無極、太虛取自上無極、殞星與九霄取自聖土，見[九雷取得與大比年齡線](../../05_故事主線與揭露/九雷取得與大比年齡線.md)。
