# 新版九雷

狀態：九雷名稱與核心方向已定；取得順序已定。階段依 D058、D059：九界五雷 → 落潮一年（十八至十九歲首入聖土，取殞星）→ 無極二雷（下無極歸墟、上無極太虛）→ 聖土篇（九霄，第二次聖土）；第十雷於終局長成（D066）。世界有許多異雷，其他修士也能收服、兼修，並非天地只有九種雷。

劫起初沒有集齊九雷的目標。隨修行理解不同雷性如何相容、互補，才逐步推演出自己的九雷格局，再尋找所缺異雷。九雷不是天定名單或預裝九個空位。

**第十雷（D066 定案）**：作者定要寫，**不作戰，只記往來、讓錨成立**。由兩界交會而生（C10），不收集、不吞、不上榜、不交易、不能被搶：第 22 篇道基碎裂時，九霄、殞星、星羅在裂縫裡隔著漏影與帝天骨架共振成胎；第 23 篇九界每剪他一份修為，總有一絲剪不走；第 27 篇守約往返時隨窗口起伏；第 28 篇錨成立、兩界之氣第一次有規律地往來，它在他身上和渡口同時長成。九雷是取來的，第十雷是長出來的。名稱與具體能力留白；舊「無始」名稱、能力、形成及結局不沿用。舊天地榜排名、進階名與固定戰力倍數亦不沿用。星羅銀雷不再自動稱照命／煌命。**命圖改為新雷新位**（D069，取代原「命圖雷位名不沿用」一句）：太玄命圖已接回，每熔煉成功一道雷，命圖才多出一個主星位，舊命圖的雷位名與星位編號不搬；第十雷的主星位長在劫核旁，通往往來（候選，D072），見下節。

## 太玄命圖：主星位（D069；D072 撤外環，只留雷種配置）

太玄命圖第 2 篇在太玄命藏初開（十人選拔之後、取震魂之前），完整見[太玄命圖](../太玄命圖.md)。

- **劫核居中**：劫核是陸沉本人，不發雷，決定各雷為何而發。
- **主星位**：每取得並熔煉成功一道雷，才多出一個主星位；位置依雷性與已有各雷的相容關係排，不依榜次，沒有預裝空位。各位的「職」：星羅＝眼、兩儀＝第一條軌、震魂＝魂錨（主星成三角）、千相＝表、流光＝調度、殞星＝核、歸墟＝卸、太虛＝穿（撕痕落在這條軌上）、九霄＝穹、第十雷＝往來。是職，不是增幅倍數。
- **沒有外環（D072）**：D069 的外環綁雷（鑑月對震魂、蒼梧對太虛、赤翎對殞星）、命印與空痕全部撤除。命圖只排雷，不排人；劫厄不在命圖上，鑑月、蒼梧、赤翎是旅途中遇到的朋友，見[劫厄與旅途同行者](../劫厄與旅途同行者.md)。
- **第十雷的位置**：主星位**長在劫核旁，通往往來**（候選）。不屬九雷任何一軌、不作戰；它不往外撐開新角，只在劫核旁開出一條往外走的路，兩界之氣從那裡往來。蒼梧第 26 篇「這次你走門」是人物層的呼應，不在命圖上對應任何缺口。備案：只寫「長在劫核旁」。

## 核・裂：兩雷共軌（D074，2026-10-02 作者定）

- **定名**：兩道雷共軌的總稱為「**核・裂**」；每一組另有招名，寫「核・裂・某某」或簡稱「某某」（例：核・裂・還重，簡稱還重）。「合軌」「融合雷」不作招名或書內稱呼；「軌」只當理論描述（共軌、留縫）。
- **規則**：只兩道，一道為軌（定路徑、節奏、方向）、一道為性（定效果）；兩色之間留一條看得見的縫，不混色、不成蓮、不揉成一團；縫是刃也是死穴，打斷縫即碎、兩雷各自反衝；每一組都要事件逼出或練出；走既有主星位的職，命圖不因此多星位、不加倍、不減痛；與第十雷無關；壓境不出。
- **全書三組**：斥核（兩儀 × 殞星，第 20 篇前段兩匣人一戰被逼出半成形，屋頂之帳約 55–60 歲第一次主動穩定成形，候選）；還重（九霄 × 星羅，第 24 篇第一次大勝）；走線核（流光 × 殞星，第 25 篇，候選）。第 22 篇婁直專打縫，把核・裂打碎。
- 靈感事件、對照年表與九雷基本招名見[主角群武學譜](../主角群武學譜.md)第三、四節。

## 招式原則與第十雷（C9、C10，作者選定）

- **招式（C9 甲）**：每道雷有固定基本招，功能隨境界逐步增加，強招再擴張；可與聖土鬥技的天地玄黃品階互相對照。九雷基本招名（穿針、掛印、鳴、錯影、走線、落冠、收、隔山、壓重）見[主角群武學譜](../主角群武學譜.md)（D074）。
- **第十雷（C10）**：由三十二天與諸神聖土兩界交會而生。須刻意避開鬥破「異火」的影子（見待定 Q22）。形成與功能邊界已由 D066 定（見上）；名稱與具體能力仍待設計。
- **九雷分布（D058 定）**：甲案——歸墟取自下無極、太虛取自上無極、殞星與九霄取自聖土，見[九雷取得與大比年齡線](../../05_故事主線與揭露/九雷取得與大比年齡線.md)。
