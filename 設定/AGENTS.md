# 設定區工作規則

先讀根 [AGENTS](../AGENTS.md)與 [ROADMAP](../ROADMAP.md)。本檔只補設定責任，作者裁定、正文凍結與只讀區照根規則。

正式區維持主題唯一來源。查核要分清 Canon、作者批准範圍、工作選定、候選與撤用；分清刻意未知和設計缺口。不因放進設定區就定案。審查報告與競稿放討論區。

創造世界與人物時讀 [AI團隊](../AI團隊/README.md)共用準則及對應角色。設定應給故事可欲的力量、修士的生活方式、自主勢力與事件，不只增加禁止事項。新增局部創作可標工作設計；新全界法則或重大歷史改動列清來源、影響與候選修法，不自行改定。

任務決定角色，編輯設定檔不自動等於只做 Canon 審核。保住精彩的可行方案與來源精確性同樣重要；涉及新大綱或裁定，同次同步相關入口與總覽。
