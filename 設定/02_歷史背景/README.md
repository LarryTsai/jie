## 封界與下沉的現行因果

戰前完整天地稱大羅界，仙庭居其核心；第一次大戰後才形成大羅殘存核心、上無極、下無極與九界，「無極」指被拉離核心、失去中心的仙土。內應洩露護界破綻並提前撤去護持，九片仙土受創；救援仙帝護人護土、提出需時間且有風險的回接方案。仙庭之主在更大危機與喪子之痛下，獲部分同境支持而封界，斷絕最後回接可能。救援派反對時機與犧牲，但不再掀仙帝之戰，並爭取保留九界往來。十八王庭戰後處境各異，不分成九強九弱兩類。具體機制與責任見[權力根基](../01_世界格局/仙庭與王庭權力根基.md)，較早的候選不得覆蓋此結論。

古戰距今工作數字約八萬年。仙庭指定外圍九天作界路之約的抵押（D036a，理由改寫為「界路之約須以實地作質」）；聖土「大約」收押與長子「以本名立誓」兩層隨 D045 撤回，長子改為打算親自入聖土自請為質並作證（D046）。遇害機制與同謀利益見[主線推理骨架](../05_故事主線與揭露/主線推理骨架.md)第十二節，均不稀釋內應罪責。
