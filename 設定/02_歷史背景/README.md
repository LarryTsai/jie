## 人物名稱

上古仙帝為祁宗岳，帝號太宸；長子祁承晏、弟弟祁承朔、公主烏蘅。兩位已定名的九強同謀是商玄度與厲文恪。當代人物為裴照川、溫棠、商應璋與岑越；境界及個人經歷見[定名總覽](../03_人物設定/本輪人物與修行定名.md)。以下保留角色稱呼，以便直接看清兩代事件的因果。

## 封界與下沉的現行因果

九強九弱是戰後分化。內應洩露護界破綻並提前撤去護持，九片仙土受創；救援仙帝護人護土、提出需時間且有風險的回接方案。仙庭之主在更大危機與喪子之痛下，獲部分同境支持而封界，斷絕最後回接可能。救援派反對時機與犧牲，但不再掀仙帝之戰，並爭取保留九界往來。具體機制與責任見[權力根基](../01_世界格局/仙庭與王庭權力根基.md)，較早的候選不得覆蓋此結論。
