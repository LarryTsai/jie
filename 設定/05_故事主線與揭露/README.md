# 故事主線與揭露

本檔是結構底稿，不是分卷或章節定案。以下階段可以交錯，不預設章數。

## 人物走進主線的理由

本線依循[故事定位的敘事意圖](../00_故事定位/README.md)。故事先讓人生活、相愛、作出選擇，再讓他們承受歷史與權力造成的後果。

長子在公主死後仍親自查證、止戰，因為被謀害的是他愛的人，而兩族還有活人正因被扭曲的消息互相殺戮。他知道危險，仍想把真相帶回來、阻止更多人死去。寫他的最後行程，應看見他的判斷、防備與未完成之事；身後留下指骨是歷史結果，不是他此行的目的。

陸沉的第一步落在當下。他幼時知道指骨與自己的神識、體弱有關，卻不知道古人的身分與遺願。日後要追查某段歷史，先讓讀者看見眼前哪個人的生活受到影響、他為何不能置之不理，再使舊案成為理解或處理這件事所需的一部分。跨界也由當地的人與事延伸，不按證物數量安排旅程。

前輩救過的人會繼續生活，女子查案前後也有她想完成的事、同伴與判斷。他們相愛、行動、付代價的經歷本身值得寫。即使暫時不揭露兩位聖子，讀者也應能理解他們為何走到下一步。女子有自己的查證選擇；前輩後來傷人，必須經過他親自跨越的界線。

九界各自生活到今天。主角抵達時，有人求助，也有人不想被打擾；能否查出古戰真相，不是衡量一段地方故事是否有價值的唯一標準。

## 兩條長線如何相接

當代線由人物眼前的生活、修行與關係推動；古戰線解釋世界為何變成今天這樣。角色先有必須處理的當下事件，再有追索歷史的理由。

| 結構位置 | 需要成立的故事 | 古戰資訊的界線 |
|---|---|---|
| 家鄉與修行起步 | 陸沉想做什麼、受什麼限制、在乎誰；世界有可生活之處 | 指骨先是家傳物與體質因果 |
| 當代人物與矛盾 | 建立前輩真實功績，讓女子的查證與自主行動成立 | 出現可核對的矛盾，不直接宣告全案 |
| 衝突擴大與跨界 | 主角有需要離鄉的具體原因，各地有自己的難題 | 長子行跡與地方歷史逐步互證 |
| 九界主要衝突 | 前輩的選擇造成必須阻止的傷害，主角付代價回應 | 分辨真證據、誤導與當代命令來源 |
| 仙界權力與戰爭危機 | 玄闕王庭聖子與更大權力結構浮現，各方作出新選擇 | 九界、異域及仙庭材料共同釐清舊案 |

這些是依來源整理的功能位置；女子遇害與前輩轉變相對於開篇的確切時間尚未定；核心人物相識階段見下方新版成長骨架。
