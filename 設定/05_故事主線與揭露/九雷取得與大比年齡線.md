# 九雷取得與大比年齡線

狀態：作者採用本輪安排。下界五雷、上界四雷；取得次序與天下異雷榜名次分開。前兩雷事件已定，後七雷先定成長位置，不提前編造雷域、同行者或勝負。

## 十二至十八歲

| 年齡 | 主線 | 當時雷種 |
|---|---|---|
| 十至十二歲 | 太玄閣修行，取得星羅；十二歲離閣前替閣老引盡殘雷 | 一雷 |
| 十二歲 | 洞天境入太玄宗，恰逢當屆百宗盟試；不參賽，留待下一屆 | 一雷 |
| 十三歲左右 | 與封寒探礦谷取得兩儀，回宗凝成承身 | 二雷 |
| 十四歲左右 | 取得太古震魂雷，繼續宗門生活與修行 | 三雷 |
| 十五歲 | 下一屆百宗盟試；獲東溟代表資格後，同年前往中神州五域大比，賽後入天域書院 | 三雷 |
| 十六歲 | 書院修行、取得千相紫雷 | 四雷 |
| 十七歲 | 九大書院大比，爭取本界代表資格 | 四雷 |
| 十七至十八歲之間 | 九院大比後取得流光，磨合後參與九界大比 | 五雷 |
| 十八歲 | 九界大比，讓仙界宗門觀察挑選 | 五雷 |

太玄宗約三年，書院約三年。五域前在中神州認識文奕，五域大比認識雲行；生於入宗後相識，封寒於入宗選拔相識，均不更動。

百宗每三年一屆，故劫十二、十五、十八歲各有一屆；十八歲他已走書院與九界路線，不因此必須回宗再參加。五域接百宗，十五歲在同年完成。九院選拔在九界大比前一年。九界每五年一次，前屆為劫十三歲、後屆為二十三歲；十三歲可聽聞前屆消息，但是否寫入具體場景未定。

年齡按故事年度配置，生日、月份與賽程先後尚需正式章綱再排；十三、十四歲取雷保留「左右」，不能把兩次取雷擠成入宗當日。十八歲九界大比不等於已定十八歲立即飛升，接引宗門及確切上界時間另定。

## 完整境界與故事節奏

熔煉成功即表示新雷已煉到劫當下完整境界。之後的磨合是精控、雷法與分身配合，不能寫成先收服低境本源再補修。表中未額外指定每次取雷的修士境界，除十二歲入宗洞天外，逐年境界仍待配置。

取雷不固定每年一次，不必都跟比賽或獎品相連。宗門、書院的師承、友情、丹道與日常要有實際篇幅，不能變成取雷之間的過場。星羅榜位較後仍是根基；千相先於更高位異雷，因為適合此時的修行需求。上界四雷不能只依榜位高低走同一套副本。

第三至第九雷的地點、同行者、遇險與收服過程另行設計；九雷格局是劫逐步推演出的成果，少年時不預知作者安排。第十雷仍留白。
