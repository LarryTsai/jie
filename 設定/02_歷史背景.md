# 歷史背景

來源：`歸檔/原始討論/` 中的《九界與上古戰爭》討論資料。此處使用相對順序，年代、壽命跨度及人物存續尚待設計。

## 上古至當代的因果骨架

| 次序 | 事件方向 | 狀態及待解問題 |
|---|---|---|
| 1 | 仙界與異域可以互通，仙帝長子與異域公主相愛 | 已選方向；兩人原有生活與政治影響未定 |
| 2 | 心機皇子與部分九強勢力合謀，殺害公主並嫁禍 | 已選方向；動機組合、兇手及手段未定 |
| 3 | 交涉受阻，戰火落到九弱外圍 | 控制使者、傳訊及洩露防線是候選運作方案 |
| 4 | 長子查證、止戰，被引至日後陸沉故土遇害 | 已選方向；誘餌、部署與遺留證據未定 |
| 5 | 仙帝出手擊退異域，兩界形成鴻溝，九片外圍下沉 | 已選方向；封界與下沉的具體因果未定 |
| 6 | 戰後歷史分裂，遺物與局部紀錄存留 | 整理方向；保存者、保存方式與年代跨度未定 |
| 7 | 當代女子與宗門查到古戰矛盾，女子遇害 | 已選方向；發現過程、知情範圍與行兇配置未定 |
| 8 | 英雄前輩追查，兩位聖子操弄危機，前輩逐步越界 | 已選方向；每一步的決策與代價待設計 |
| 9 | 九強聖子所求的有限危機接近失控，可能引發第二次大戰 | 已選方向；具體發生在主線何時未定 |

## 作者真相與各方記憶

| 事件 | 作者目前掌握的方向 | 可能流傳的版本 |
|---|---|---|
| 公主之死 | 皇子與部分九強勢力合謀 | 異域記得仙庭殺害公主；各派知道多少未定 |
| 長子之死 | 受弟弟設局殺害 | 仙界官方歸因於異域伏擊 |
| 封界與下沉 | 仙帝決策與戰爭後果相關，機制未定 | 仙界可能重視勝利，九界承受失土與隔絕；具體傳說待寫 |

「作者掌握」不等於角色掌握，也不等於所有運作細節已定案。

## 必須逐段補齊的因果

1. 公主之死為何不能透過查證及交涉解決？合謀者有哪些有限而具體的控制能力？
2. 九弱為何首當其衝，當時能否自救或拒絕某些命令？
3. 長子為何相信線索、冒險前往？他已採取哪些合理防備，仍為何失敗？
4. 仙帝為何到這一步才介入，封界有沒有替代方案，他當時知道多少？
5. 古戰參與者哪些活到當代？若仍在，為何不能輕易抹除所有線索？
6. 女子所發現的資料為何直到現在才顯出矛盾？

## 責任界線

弟弟與同謀須承擔謀害、嫁禍及洩密責任；仙帝的損失不能自動免除其決策責任；異域受陷害也不能抹去其軍隊可能造成的傷害。具體行為逐人、逐派系確認。
