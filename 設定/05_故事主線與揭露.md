# 故事主線與揭露

本檔是結構底稿，不是分卷或章節定案。以下階段可以交錯，不預設章數。

## 兩條長線如何相接

當代線由人物眼前的生活、修行與關係推動；古戰線解釋世界為何變成今天這樣。角色先有必須處理的當下事件，再有追索歷史的理由。

| 結構位置 | 需要成立的故事 | 古戰資訊的界線 |
|---|---|---|
| 家鄉與修行起步 | 陸沉想做什麼、受什麼限制、在乎誰；世界有可生活之處 | 指骨先是家傳物與體質因果 |
| 當代人物與矛盾 | 建立前輩真實功績，讓女子的查證與自主行動成立 | 出現可核對的矛盾，不直接宣告全案 |
| 衝突擴大與跨界 | 主角有需要離鄉的具體原因，各地有自己的難題 | 長子行跡與地方歷史逐步互證 |
| 九界主要衝突 | 前輩的選擇造成必須阻止的傷害，主角付代價回應 | 分辨真證據、誤導與當代命令來源 |
| 仙界權力與戰爭危機 | 九強聖子與更大權力結構浮現，各方作出新選擇 | 九界、異域及仙庭材料共同釐清舊案 |

這些是依來源整理的功能位置；女子遇害、三人相遇、前輩轉變相對於開篇的確切時間尚未定。

## 三人的獨立故事

- 陸沉：修行、創造及守護眼前關係，逐漸遇到「可以改變，卻未必有權改變」的事。
- 封寒：追問世界，有自己的發現、關係和錯誤，不能只負責帶隊進秘境。
- 雲行：親自面對取得與放下的代價，不能只替別人勸架或作結論。

同行方式保持開放：兩人同行、三人同行、獨行及多年後重逢，都需由各自的事情推動。

## 線索管理方式

後續每條重要線索記錄：出處、持有人、可驗證方式、能證明的範圍、可能誤讀，以及首次被誰知道。現階段不為九界硬分配九件證物。

## 開篇尚需決定

1. 陸沉的第一個具體願望與困難。
2. 家族、指骨和體弱如何出現在普通生活裡。
3. 第一段關係由誰建立，第一件事改變了什麼。
4. 前輩、女子與核心三人各在何時進入讀者視野。
5. 即使讀者暫時不知道古戰，最初的故事為何值得繼續讀。
