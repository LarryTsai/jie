# 修行與特殊事物

## 設計前提

新版尚未建立完整境界與力量規則。先定能力可以做什麼、做不到什麼、代價如何持續，再取境界與招式名稱。

三人的「變／知／捨」是人物道路候選，不能當成直接授予能力的系統規則。

## 指骨

**已選方向**：劫族傳承的指骨與仙帝長子遺骨有關；陸沉幼年深度共鳴，神魂與神識受到拓展，肉身難以負荷，形成神識強、肉身弱的落差。

**前期認知界線**：家族可以知道它奇異、危險或有人能共鳴，不應直接知道長子身分與古戰全案。前期不頻繁播放古代影像。

**待定**：祖先取得方式、保存理由、歷代共鳴、作用條件、能否中斷、離身後的影響、身體改善方式，以及是否留有有限的可查證痕跡。

指骨不能代替陸沉創造功法、作出道德選擇，或一次給出整場陰謀的完整答案。

## 厄與四伴星

古戰殘留力量經歲月異變、與陸沉相遇後逐漸呈現異質龍形，是厄的候選起源。尚未確定採用，也未建立新版四伴星完整設定。

不能因此直接認定厄是指骨化形、長子的護衛或指定伴生物。若採用，須設計牠作為獨立生命的欲望、選擇和關係。

## 世界規則待設計

| 規則 | 必須能回答的問題 |
|---|---|
| 修行起點 | 如何開始，天賦與資源各影響什麼？ |
| 成長 | 如何突破、如何失敗，哪些代價不能立刻消除？ |
| 神識與肉身 | 兩者如何互相影響，陸沉的異常有哪些實際限制？ |
| 壽命與時間 | 古戰距今多遠，各層人物能活多久？ |
| 戰力上限 | 強者能改變多大範圍，為何不能解決一切？ |
| 界壁與通路 | 誰能跨界、需要何物、付出什麼、如何被阻止？ |
| 九界下沉 | 戰爭、封界和空間變化如何形成可理解的因果？ |
| 證據留存 | 什麼能跨年代保存，如何驗真、偽造或損毀？ |

境界名稱、界錨機制、通道專名及完整功法表均待後續討論。
