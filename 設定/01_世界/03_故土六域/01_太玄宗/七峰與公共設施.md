## 主峰與共同教習


主峰另計於七座傳承峰之外，承接宗務、公共教習與通用閣，不傳單一根本道路。新弟子先在共同教習體系打底，完成基礎後自由探索、擇師，時間依個人成長而定。

<a id="主峰與共同教習--通用閣"></a>
### 通用閣

- 煉丹閣：丹道、藥理、藥性融合與修復丹方；洛生衣可延續在此學習、任事的生活。
- 煉器坊與陣具設施：供弟子學習公開技藝、修補器物、製作基礎陣具；深層器道師承歸赤霞峰。器坊做的多是「修」與法器、靈器的煉成；胥匠是修補精的器師（D078，作者定（2026-10-02））。
- 藏書與資源取用：支持共同教習與跨峰選修；費用、任事報酬和真傳權限另定。

一名鎮岳弟子可以先去丹房換藥，再帶著開裂的護腕到器坊求修。碧梧弟子與赤霞弟子因同一件事見面，各自看到不同的問題；公共設施應長出這樣的日常。

公共課可自由參加，專屬傳承仍須授業者同意。舊稿雷身打工、續雷脈丹事故只作後續素材，不預先定為新版已發生事件。（D074 補：續雷脈丹事故已定為第 2 篇已發生，即生的「共爐續脈」，見[主角群武學譜](../../../04_修行/03_武學/01_主角群武學譜/07_洛生衣.md)第八節。）

<a id="問劍峰--封寒的師父（c6，作者選定）"></a>
### 封寒的師父（C6，作者選定）

嚴守劍理的中年劍修，曾因試新招誤傷同門，所以收徒後的規矩是「讓你改，但每一招先證明」：支持封寒實證改招，要求演示用處與破綻，親自交手指出問題。封寒日後犯下求知之錯時，他是最痛的那個人。

**姓名與誤傷事件（D058）**：師父名**晏守拙**。年輕時試新招「逆鋒回劍」，回劍時斷了師弟**秋澗**的劍脈；秋澗此後不能再修劍，轉入赤霞峰修器，兩人仍同在宗內。晏守拙「讓你改，但每一招先證明」的規矩就從這一劍來。此事與封寒兄長封沂的事件刻意錯開：兄長是家人替封寒擔，這一劍是師父自己的錯。修為待配。

<a id="碧梧峰"></a>
## 碧梧峰


<a id="碧梧峰--傳承"></a>
### 傳承

生機、靈植、血脈、肉身修復與靈性培養。承接原萬靈峰；洛生衣在此修生道，另赴主峰煉丹閣學丹術與任事。御獸和伴生靈獸研究可容納於此，不另添第八傳承峰。

<a id="碧梧峰--可發展的修行生活"></a>
### 可發展的修行生活

古木成蔭，弟子照看受創靈木與生靈，觀察藥物何時有用、何時會傷根。救活之後能否繼續生活，也是修行的一部分。

**地脈（D100）**：峰下是**木／生脈**〔候選名：梧根〕。古雷脈只接回一半會牽動它，靈田減產（與高手閉關「又在吸」的減產分開寫）。見[宗門總覽](README.md)「地脈」。

**古木羣千年老梧（工作設計，2026-10-17 同步）**：碧梧古木羣中一棵千年老梧，**不是碧梧峰得名之樹**，峰名意象不動。十三歲入秋重鑿後減產、抽枝轉慢；開春排除木脈失溫與病蟲後，梅予決定全峰續養三月（[卷五](../../../../大綱/01_少年/05_七峰爭鳴/大綱.md)）。續養到第三月，每夜抽一根新枝、天亮又枯；生想驗「供進去的命究竟去了哪裡」，老梧終於落盡，留下心材與最末二十七根青枝，後成知秋劍胚與護手（[卷六](../../../../大綱/01_少年/06_萬體無我/大綱.md)）。這件事教碧梧弟子：續命不是只看樹又抽芽。

此段地脈為場景方向，尚非已發生事件；老梧一事已在卷五、卷六發生。

<a id="碧梧峰--與其他修行的關係"></a>
### 與其他修行的關係

醫修能力六項（診、接、排、護、養、量）中，碧梧所長是**養**與**量**：救活之後能否繼續生活，以及救不救、救回要付什麼（D079，作者定（2026-10-02））。

「什麼叫活著」的考題素材（D086，作者定（2026-10-02））：成器、神魂切分、奪舍、還形、修為散盡之人，五個法律答得了、生道答不了的案，見[死亡與繼承](../../02_修仙文明/02_文明細則/死亡與繼承.md)第 7 件；答案不由設定給。

生道不等同普通治療；不能憑空創生或任意復活。劫厄與陸沉旅途中結識的靈獸朋友不因此自動歸入御獸管理（D072：原「四伴星」編制已撤）。

## 赤霞峰


<a id="赤霞峰--傳承"></a>
### 傳承

材料、煉器、養器與本命器修行。新版器道獨立成峰。承接舊天工相關素材，但不恢復舊名稱，也不撤掉主峰公共煉器設施。

<a id="赤霞峰--可發展的修行生活"></a>
### 可發展的修行生活

山腹藏爐，地火映霞。有人試煉不同材料，有人修補用了數十年的兵器；一件器物的火候、磨損與修補痕跡也能留下人物經歷。

**霜降爐（工作設計，2026-10-16）**：赤霞山腹深處的一口開鋒爐。霜降過後地火轉寒，山腹爐每年才自起一日霜火——早年近立冬，遲年過了小雪，確切日子由地火決定，爐師前幾日才看得準；赤霞人因此叫它霜降爐。一年一日，一口爐只開一把劍的鋒，爐位要爭或以珍材換。首次用於[卷十九](../../../../大綱/01_少年/24_歸山/大綱.md)〈生的霜降爐〉（洛生衣知秋開鋒）；峰名意象不動，霜火機制不擴成全宗曆法。

此段為場景方向，尚非已發生事件。

<a id="赤霞峰--與其他修行的關係"></a>
### 與其他修行的關係

<a id="鎮岳峰"></a>
## 鎮岳峰


<a id="鎮岳峰--傳承與生活"></a>
### 傳承與生活

保留峰主岳沉淵、六位師兄姊與《萬體鑄身經》。根本是把肉身修成可承大道之器，不只追求力大、堅硬；教習重視站穩、承痛、不崩。弟子少，修行艱苦，各自沿自身缺陷與經歷修出不同的體。

劫由神識強、肉身弱起步，在此學習重鑄自身。選擇此峰的具體事件仍待寫，不由指骨安排命定傳承。

山體如黑鐵，保留鎮岳臺、碎石場、淬骨池、萬體碑林、鎮岳崖與峰主殿等場所。**地脈（D100）**：峰下是**重脈**〔候選名：沉鐵脈〕，「鎮岳峰本來的重」由此而來；雷重域的**重力罰**就在重脈露頭處加壓（D098-10），沈山河〈收重〉首用在此（D097-6）。見[宗門總覽](README.md)「地脈」。初學者在臺上學會穩住呼吸，師兄姊也可能為了新傷重新調整舊有的行力方法；苦修要有指導、恢復與個人選擇，不把受傷本身當成進步。

<a id="鎮岳峰--萬體鑄身經"></a>
### 萬體鑄身經

無屬性的鑄身基礎，先鍛其身，再承其道。基礎方向為鍛骨、煉筋、煉血（舊稱熱血，D074 作者補記改名）、通脈；不是四個新增境界。公共基礎與峰內深傳可以分層，但篇數與新境界配合待定。**取得時機（D177）**：入宗、入峰後才接觸，太玄閣不藏。閣藏的《太玄淬身訣》（凡階上品）是鎮岳早年替各閣編的入門，只教承與導，不署峰名；岳沉淵一看走法就認得。

<a id="鎮岳峰--後崖與太嶽崩天典"></a>
### 後崖與《太嶽崩天典》（2026-10-31 回填）

效力：典名、正本名與「收繳銷燬」（作者裁定六）、純粹強攻（作者裁定七）、鎮岳無上游（作者裁定五）為**作者裁定**，見[太玄藏經閣與玄殿作者裁定](../../../../歸檔/02_已結案競稿/待整理收尾_20261031/太玄藏經閣與玄殿/作者裁定.md)；其餘為**工作選定**（[整合稿](../../../../歸檔/02_已結案競稿/待整理收尾_20261031/太玄藏經閣與玄殿/整合稿.md)第一、二節，適用版見[回填版](../../../../歸檔/02_已結案競稿/待整理收尾_20261031/太玄藏經閣與玄殿/回填版.md)）。來歷見[宗門總覽](README.md)〈戚岱案與鎮岳無上游〉。

- **後崖**：鎮岳四試〈踏罡〉的三十六塊陣石，是戚岱師弟為鎮住山腹而立；山腹裡坐著戚岱的遺念與一百零八部典。鎮岳峰主之間口傳「後崖不開」。陸沉十六歲聽出第三十七拍，岳沉淵擔誓開門、坐第九塊陣石守他肉身；試煉後第九塊陣石裂一道縫，後崖從此只剩三十六拍（[卷十九](../../../../大綱/01_少年/24_歸山/大綱.md)〈後崖選典〉）。
- **不是閣藏、不是峰傳**：太玄宗沒有「藏經閣」；《太嶽崩天典》不在太玄閣閣藏（D177：閣藏只收公開經），也不在鎮岳峰傳、真傳書架上，是禁地遺念傳下的典，宗門傳承層級表不錄。陸沉之前鎮岳無人得過。
- **《太嶽崩天典》**：天階上品（[D178](../../../../決策/01_決策紀錄/D178_功法七階.md)：天階約當天神；品階評整卷，各式只標最低施術境界）；輸出型攻擊招式典，不是根本主修，《萬體鑄身經》的根本地位不動（作者裁定三）。核心只有一件事——**重**：把法力與氣血凝成一座山的勢從上往下砸，不借天火、地脈或別人的勢。招牌畫面：抬手時身後先起山影，手落下，山跟著落下。

| 式 | 樣子 | 最低施術境界 |
|---|---|---|
| 〈截嶽〉 | 一掌劈下，掌後拖出嶽脊影子，地面從腳下裂到對手身後，石脊翻起兩丈 | 銘紋 |
| 〈傾嶂〉 | 往前三步，三重山影一重疊一重倒下 | 列陣 |
| 〈萬嶽臨頂〉 | 雙掌上托再下按，方圓百丈群山之影整片壓落，以一敵眾 | 尊者 |
| 〈崩天〉 | 朝上打頭頂那片天（陣穹、域場天幕、法相的頭），天被撞斜、崩落 | 天神，且〈納劫〉成篇 |
| 〈太嶽〉 | 戚岱只寫半頁：萬山歸一，重到天地規矩也要讓一讓；碰到規則，正是天階與道階之間的門檻 | 未成，永遠殘頁 |

- **兩個大代價**：境界門檻是硬的，勉強去打，山影先壓在自己身上；反噬一樣重，只有《萬體鑄身經》鑄過的身體站得住，每升一式身體都要先鑄到那一層，〈崩天〉之後有一息完全站不住。
- **能被反制**：要時間起勢，越高一式山影越早被看見；游鬥、遠打、不給起勢能讓他砸空，伏殺時起勢等於現身。不是拆門手段，越門牆照 D157。
- **分工**：九雷管變化，典只管重，雷可騎在山勢上；〈不崩〉是**腳下**地脈亮起山紋（守），典是**身後**山影砸落（攻），〈不崩〉不再用「身後山影」；典不控重力，與沈山河〈收重〉不同。九霄〈壓重〉與〈劫數〉是天上的劫雲逐重落雷、記帳落印，典是他把山砸下去，不記帳、不落印，劫雲不入山勢；天譴是多雷共核、留裂為刃，典是錘（照整合稿分工表，2026-10-31 依回填獨立覆核 S6 補）。
- **驗點與首戰**：〈截嶽〉十六歲碎石場與回院驗過，首戰落點候選；〈傾嶂〉無間航道練成、九界會場驗過，首戰十八歲九界決賽（作者裁定八）；〈萬嶽臨頂〉十九歲登天前回峰在碎石場驗過（[太玄師門](../../../../大綱/00_全書骨架/08_太玄師門/大綱.md)十九歲回山第二天，2026-10-31 已回填），十九歲定籍堂撞天花板（非戰場），戰場首用第9篇篇主擇點（候選）；〈崩天〉候選落點約三十一歲至尊之年，未回填。

### 完整人物檔已遷入

[岳沉淵與六位師兄姊](../../../03_人物/02_太玄宗/01_鎮岳峰/README.md)各自有獨立檔案，含完整可沿用背景、性格與關係，不需回舊專案閱讀。 [核對問題](../../../03_人物/02_太玄宗/01_鎮岳峰/沿用核對.md)列出年齡排序、下界身世配置與未沿用的舊終局。

**入峰試與「老七」（D098-15、17，作者定）**：鎮岳入峰試是天黑前走上峰頂，黑鐵般的浮石盤層層往上，重力逐層增加，另有歷代弟子體痕留下的各種屬性領域壓力；陸沉那一屆只有他一人選鎮岳、只有他一人登峰，天黑時還在半途、不停，岳沉淵在峰頂一眼數傷收下他。入峰後全峰七名弟子，師兄姊叫他「老七」。

**為什麼每年幾乎沒人報**（作者定，D098-17）：不是最出名的峰；登峰試太難；峰主岳沉淵是宗門前三強者，但他的強來自古嶽巨人血脈，鎮岳的路別人學了未必強得起來，所以弟子一代比一代少。陸沉那一屆只有他一人報考。

**核心氣質**（作者定，D098-17）：六位師兄姊都是被別處判了沒希望才走到鎮岳的人，所以珍惜這座峰，彼此像家人，新來的老七也是。家人會吵、會嫌、會不認同，照樣是家人。
