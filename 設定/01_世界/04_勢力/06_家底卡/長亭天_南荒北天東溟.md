# 家底卡：長亭天南荒、北天、東溟海族（燼梧諸氏、鏡海宮、滄氏蛟族）

狀態：三十二天寫手提案（2026-10-02），PM 派工、作者已核准任務。文末各題**作者定（2026-10-02）**（全部照推薦），各處已標；其餘為提案，未經作者確認。

依[修仙文明底層規格](../../02_修仙文明/01_底層規格/03_宗門與人口.md)第 16 節卡片格式；每一項能力先過「能力設計檢查條」八條。家底形態照[宗門與天驕家底庫提案](../../../../歸檔/04_設定來源/三十二天/宗門與天驕家底庫提案.md)第二節，不改類型。來源：[南荒宗派與天驕](../../03_故土六域/南荒宗派與天驕.md)、[北天宗派與天驕](../../03_故土六域/北天宗派與天驕.md)、[劫故土六域頂級勢力](../../03_故土六域/劫故土六域頂級勢力.md)、[故土六域人物](../../../03_人物/05_三十二天/故土六域人物.md)、[太素道宮](../03_跨層道統/太素道宮.md)（D068）。

標記：〔既有〕＝現行設定已有；〔家底庫〕＝家底庫提案已寫、本卡沿用；〔提案〕＝本卡新設；**留白**＝沒有來源，不硬補。

**分級口徑**：九界頂級＝天神以上坐鎮的一域之首；一流＝尊者至天神坐鎮、非一域之首（D060、D073）。燼梧諸氏與滄氏蛟族是氏族、海族，不是一般宗門〔既有〕；規模以族中在冊修士計，比宗門低一級（作者定（2026-10-02），見[規模口徑提案](規模口徑.md)）。

**三家的不對稱**：燼梧的家底是一團火，而且火歸誰還在吵；鏡海的家底是一片會映出別的天的冰海，搬不走，也用不出北天；滄氏的家底是血，和一條他們以為在睡的龍。

**妖族無核**：三十二天妖獸、妖族以全身與血脈承載修為，沒有魔核（D073 補記）〔既有〕。本檔三家都適用。

## 一、燼梧諸氏

**家底形態**：**血脈＋遺火**，而且家底歸屬本身在爭〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 南荒火山群最深處的燼梧山〔既有〕 |
| 上游與隸屬 | 數個鳳裔氏族共同守護，對外合稱燼梧諸氏，沒有一位能號令全部氏族的族長〔既有〕 |
| 通常特別擅長 | 借涅槃遺火〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 南荒**頂級**〔既有〕 |
| 規模 | **大**（作者定（2026-10-02）；氏族以族中在冊修士計：數個氏族合計五百以上） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 血脈派之首 | 丹穴耀〔既有〕 | 天神〔既有〕 |
| 守約派之首 | 鳴岐柔〔既有〕 | 天神〔既有〕 |
| 血脈派少主 | 丹穴熾，天驕中的惡人〔既有〕 | 尊者〔既有〕 |
| 外族得火者 | 烏照夜，玄鴉族，非燼梧血脈，卻得到遺火回應〔既有〕 | 留白 |

### 四、傳承

- **根本功法**：《燼梧經》，**玄篇上**（作者定（2026-10-02））。同一部經，兩派讀法不同：血脈派讀「承」，守約派讀「受」〔家底庫：兩派用法〕。
- **招牌神通**：〈涅槃借火〉（作者定（2026-10-02）；既有「借涅槃遺火」），最低施術境界**銘紋**。
- **秘術**：〈焚羽燃身〉（作者定（2026-10-02）），見下方檢查。
- **傳承載體**：涅槃遺火本身〔既有〕。

**〈涅槃借火〉八條**

| 條 | 內容 |
|---|---|
| 源 | 火與涅槃之道；《燼梧經》（玄篇上）。血脈派「承」：以血引火，火只聽族人；守約派「受」：等火自己選人〔家底庫〕 |
| 門 | 銘紋（力外顯）：引一縷遺火入身。列陣（結構）：火成形，羽或翼。尊者：以火封傷，傷處暫時不再惡化。天神（空間）：身周成火域，域內灰往上飄、遁光被燒短 |
| 象 | 他們的火燒起來沒有煙，灰往上飄〔家底庫〕。承的火從身上往外燒，受的火從外往身上落；兩派打起來一眼看得出是哪一派〔家底庫〕 |
| 器 | 本命法寶多以族中落羽祭煉的翎〔提案〕：法器起步；寶器時翎上的火不熄 |
| 傳 | 有條件：族人未必都能覺醒鳳血，外族也可能因古老契約、涅槃火種或遺火回應而進入祖地〔既有〕。烏照夜就是後者〔既有〕 |
| 限 | 遺火逐年衰弱，靠抽地火續命〔既有〕；離燼梧山越遠，借得越少〔提案〕 |
| 價 | 燼梧人每一次全力出手，都在花祖地的老本〔家底庫〕 |
| 萬年問 | 火只認血，或只認它自己選的人；不是想修就修得到。而且火在變弱，修的人越多，火滅得越快 |

**〈焚羽燃身〉八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 同《燼梧經》，祖地秘傳 |
| 門 | 列陣起可用 |
| 象 | 修士整個人燒成一團無煙的火，羽影浮在火上 |
| 器 | 本命翎先燒 |
| 傳 | 兩派都有；血脈派不傳外族 |
| 限 | 一戰一次 |
| 價 | 以自身本源為薪；燒完是燒完，**不能復活**（涅槃不在凡人身上成立；南荒目前沒有已確認存活的純血鳳凰〔既有〕） |
| 萬年問 | 名字叫涅槃，燒的人卻不會重生；只有走投無路的人才用 |

### 五、法寶家底

- **鎮宗之物**：燼梧山腹炭化古梧桐樹心的**涅槃遺火**〔既有〕，不按器論〔家底庫〕。
- **靈獸**：南荒沒有已確認存活的純血鳳凰〔既有〕，不設鎮族靈獸〔家底庫〕。
- **護山大陣、器庫**：留白。

### 六、資源

- 燼梧山與地下地火脈〔既有〕。

### 七、產業與財政

留白。

### 八、人才管道

- 族人覺醒鳳血；外族因遺火回應進入祖地〔既有〕。
- 祖地試煉〔既有：烏照夜得火經過〕。

### 九、外交

- 南荒三方：萬生古盟、河網城邦、燼梧諸氏共同推舉大靈汛的持潮人〔既有〕。
- 百川會：燼梧諸氏有監察席位〔既有〕。

### 十、歷代經驗

- 百餘年前，燼梧為維持衰弱的遺火持續抽取深層地火；與另兩方的作為共同打破地下水火循環〔既有〕。

### 十一、弱點

- 遺火逐年衰弱〔既有〕。
- 兩派內爭：血脈派說外人可以借火、不能繼承核心；守約派說遺火自行選擇眾生，氏族只有守護之責〔既有〕。
- 抽地火的後果〔既有〕。

### 十二、劇情鉤

- 烏照夜與丹穴熾：丹穴熾認定烏照夜那一身遺火是「偷的」〔既有〕，篇外。

**留白**：產業、護山大陣、烏照夜境界。

## 二、鏡海宮

**家底形態**：鎮宗之地（會映出不同天幕的冰海）＋多族〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 北天一片會映出不同天幕的巨型冰海〔既有〕 |
| 上游與隸屬 | 無 |
| 通常特別擅長 | 藉冰面分辨真景、錯景和將要重疊的空間〔既有〕；也經營漁獵、冰下藥田與跨幕渡船，不只是一個鬥法宗門〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 北天**一流**〔既有〕 |
| 規模 | **中**（作者定（2026-10-02））；人族、雪妖與鏡冰靈共同生活〔既有〕 |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 宮主 | 素鏡，雪妖〔既有〕 | 天神〔既有〕 |
| 天驕 | 蘇映真，鏡冰靈〔既有〕 | 留白 |

### 四、傳承

- **根本功法**：《照幕篇》，**玄篇下**（作者定（2026-10-02））。修的是冰與天幕：以法力凝冰為面，以神識讀冰面上映出的那一層天。
- **招牌神通**：〈冰海借幕〉（作者定（2026-10-02）正名；家底庫原名〈借幕〉），最低施術境界**銘紋**。
- **秘術**：**無**（作者定（2026-10-02））。
- **傳承載體**：冰海本身〔既有〕。

**〈冰海借幕〉八條**

| 條 | 內容 |
|---|---|
| 源 | 冰與天幕之道；《照幕篇》（玄篇下） |
| 門 | 銘紋（力外顯）：在冰面上辨真景、錯景〔既有能力〕。列陣（結構）：冰面成鏡，鏡中映出的另一層天有了形狀。尊者：辨出將要重疊的空間〔既有能力〕。天神（空間）：把冰面上映出的另一層天幕借來一瞬，讓對手的術落進錯的那一層〔家底庫〕 |
| 象 | 戰場上空出現第二個天空的倒影；腳下冰面裡有人在往反方向走〔家底庫〕 |
| 器 | 鏡冰靈以本命冰心〔既有：蘇映真〕；人族、雪妖弟子多以冰海冰魄祭煉的冰盤〔提案〕 |
| 傳 | 能；人族、雪妖、鏡冰靈共修〔既有〕 |
| 限 | 要冰、要天幕；在南荒、在東溟，鏡海宮的人只剩辨真，不能借幕〔家底庫〕 |
| 價 | 借幕時自己也站在兩層之間；借錯一層，連自己也落進去〔提案〕 |
| 萬年問 | 會映出別的天的冰海，天下只此一處；離了它，這門功夫只剩一雙好眼 |

### 五、法寶家底

- **鎮宗之物**：冰海本身〔既有〕，不按器論〔家底庫〕。
- **護山大陣、器庫**：留白。
- **靈獸**：無；宮主素鏡是雪妖，雪妖與鏡冰靈是宮中的族人，不是靈獸〔既有〕。

### 六、資源

- 冰海；冰下藥田；漁獵〔既有〕。

### 七、產業與財政

- 漁獵、冰下藥田與跨幕渡船〔既有〕。

### 八、人才管道

- 北天巡天試〔既有〕；其餘留白。

### 九、外交

- 北天五方的聯合校路〔既有〕。
- 蘇映真從不讓太素的人靠近三步之內〔家底庫〕。

### 十、歷代經驗

留白。

### 十一、弱點

- 要冰、要天幕〔家底庫〕。

### 十二、劇情鉤

- 蘇映真：巡天試前的聯合校路，由冰鏡分辨兩層真景〔既有〕。
- 蘇映真的對頭麴九〔既有：各界反派〕。

**留白**：人才管道、護山大陣、歷代經驗、蘇映真境界。

## 三、滄氏蛟族

**家底形態**：血脈＋**被盜用的鎮族靈獸**（偽）〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 東溟伏鱗宮遺跡周圍海域〔既有〕 |
| 上游與隸屬 | 無；東溟的龍裔一線〔既有〕 |
| 通常特別擅長 | 稀薄龍血、龍宮遺跡〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 東溟**一流**〔既有〕 |
| 規模 | **中**（作者定（2026-10-02）；海族以族中在冊修士計：百至五百） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 族長 | 滄鱗，守伏鱗宮遺跡周圍海域〔既有〕 | 天神〔既有〕 |
| 天驕 | 滄漣：試圖返祖的蛟族少女；作者定為太素道宮的成器，第 10 篇返祖成真龍〔既有，D068〕 | 留白 |

### 四、傳承

- **根本功法**：《伏鱗經》，**玄篇下**（作者定（2026-10-02））。修的是水與血：以法力催動血中稀薄的龍血，讓近海的水聽血。
- **招牌神通**：〈龍血鱗潮〉（作者定（2026-10-02）正名；家底庫原名〈鱗潮〉），最低施術境界**銘紋**。龍血越濃，潮越高〔家底庫〕。
- **秘術**：**無**（作者定（2026-10-02））。
- **傳承載體**：血脈；伏鱗宮遺跡〔既有〕。

**〈龍血鱗潮〉八條**

| 條 | 內容 |
|---|---|
| 源 | 水與血脈之道；《伏鱗經》（玄篇下） |
| 門 | 銘紋（力外顯）：以血催近海潮一尺。列陣（結構）：潮成浪牆。尊者：一灣潮。天神（空間）：海在吸氣：海水先退向他們，對手腳下成了空的海床 |
| 象 | 皮膚浮鱗；開打前海水先退向他們，像退潮前那一刻〔家底庫〕 |
| 器 | 本命法寶多以自身蛻下的鱗、角祭煉〔提案〕 |
| 傳 | **不能**。只認血脈；外人學得到經，催不動潮 |
| 限 | 上岸越遠，潮越低；滄氏的力被一片海綁著〔家底庫〕 |
| 價 | 每催一次，血中龍氣淡一分，要很久才養得回來（作者定（2026-10-02））；所以族中少年都想返祖 |
| 萬年問 | 血脈不是修來的；而且龍血越催越淡，這一族一代比一代離龍更遠 |

### 五、法寶家底

- **鎮族靈獸**：伏鱗宮的「沉眠之龍」。族人以為牠在睡，年年祭牠；實際上牠被太素養著取血八萬年〔既有，D068〕。族人知不知道、滄漣知不知道，照 D068 留白。**一家人世代供奉的鎮族之獸，是別人的藥圃**〔家底庫〕。
- **鎮宗之物**：無；伏鱗宮遺跡〔既有〕不按器論。
- **護山大陣、器庫**：留白。

### 六、資源

- 稀薄龍血、龍宮遺跡〔既有〕。

### 七、產業與財政

留白。

### 八、人才管道

- 族中有少年試圖返祖〔既有〕。

### 九、外交

- 鎮溟劍宗：爭海眼〔既有〕。
- 太素道宮東溟舊院：替滄漣接上龍血〔既有，D068〕；族中是否知情，留白。

### 十、歷代經驗

- 年年祭伏鱗宮的沉眠之龍〔家底庫〕。

### 十一、弱點

- 力被一片海綁著〔家底庫〕。
- 龍血一代比一代淡〔提案〕。
- 鎮族之龍是別人的藥圃〔既有〕。

### 十二、劇情鉤

- 第 2 篇：留舟島海眼，滄漣與陸沉並肩逼退黥牙〔既有〕。
- 第 10 篇：滄漣返祖成真龍的喜訊傳遍東溟〔既有〕。
- 第 28 篇：滄漣以真龍之姿到場，陸沉身上的接痕與她的龍血起同源共鳴；他沒有說破〔既有〕。

**留白**：產業、護山大陣、滄漣境界、族中是否知道龍的真相。
