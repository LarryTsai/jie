標記：〔既有〕＝現行設定已有；〔家底庫〕＝家底庫提案已寫、本卡沿用；〔提案〕＝本卡新設；**留白**＝沒有來源，不硬補。

**三家的不對稱**：觀潮宗的家底是一座綁在島上的陣；鎮溟劍宗的家底是一處不屬於自己的海眼，加上一排拔不出來的劍；千礁宗器最多，卻沒有絕學、沒有秘術。三家都是東溟頂級，強的地方不同，缺的也不同。

**分級口徑**：[劫故土六域頂級勢力](../../03_故土六域/劫故土六域頂級勢力.md)把三宗列在東溟「頂級（天神以上坐鎮）」，本卡照用。規模：三宗皆「大」（作者定，2026-10-02）。

## 一、觀潮宗

**家底形態**：鎮宗陣，綁在地上〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 東溟中部潮汐群島〔既有〕；各島三宗分部之一（留舟島分部主事沐潮生）〔既有〕 |
| 上游與隸屬 | 留白（上界有無上游一系，無來源） |
| 通常特別擅長 | 隨潮變陣；各島護島大陣輪值多由觀潮主持；核定浮石份額〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 東溟頂級（三大宗之一）〔既有〕 |
| 規模 | **大**（作者定，2026-10-02）：各島分部加本宗，正式弟子三千以上 |
| 依附人口、地盤 | 潮汐群島〔既有〕；依附人口留白 |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 太上 | 觀海老人，閉關〔既有〕；坐在潮樞上閉關，閉關即替陣供力〔家底庫〕 | 天神巔〔既有〕 |
| 宗主 | 蒲懷海〔既有〕 | 天神〔既有〕 |

| 對外可出戰者 | 留白 | — |

### 四、傳承

- **根本功法**〔提案〕：《潮信篇》，**玄篇下**。修的是潮汐之道：天地靈氣隨月引漲落，修士以法力在體內養一道「潮息」，與東溟的潮同起同落。
- **招牌術**：〈潮信遷樞訣〉（作者定（2026-10-02）；家底庫原名〈候潮換眼〉），最低施術境界**銘紋**。觀潮弟子學的不是怎麼布陣，是「算今天陣眼在哪」。
- **秘術**〔提案〕：〈逆潮〉，見下方檢查。
- **傳承載體**〔提案〕：**潮錄**。歷代觀潮修士逐日記下東溟各島各處的潮時、潮高與陣眼位置，累積數千年；《潮信篇》誰都能抄，潮錄只在本宗。

**〈潮信遷樞訣〉八條**

| 條 | 內容 |
|---|---|
| 源 | 潮汐之道；《潮信篇》（玄篇下）的術。陣眼跟著潮息移動，陣理本身天下陣師共通 |
| 門 | 銘紋：盤陣級，自己陣盤的陣眼隨潮息在盤上移位。列陣（結構）：院陣級，一日兩移。尊者：可主持山門陣級的輪值，替護島大陣換眼。天神（空間）：陣眼可在潮線兩側換位，對手打中的是上一刻的陣眼所在 |
| 象 | 修士報時：「卯末」「潮轉」〔家底庫〕。戰場上的水面、海霧隨陣眼起伏；神識探過去，觀潮修士的氣息像浪一樣有週期〔家底庫〕 |
| 器 | 本命法寶多為**潮盤**〔提案〕：刻潮紋的陣盤。法器起步；靈器時能自記一日潮時；寶器時器靈雛形會「聽潮」，主人入睡也照潮換眼；道器時結合潮汐之則 |
| 傳 | 能。陣理共通，外人學得會換眼；學不到的是潮錄，沒有潮錄就算不出明天的眼在哪 |
| 限 | 離海、離島就弱〔家底庫〕；內陸、無潮之地只剩普通陣法；小潮日、退潮時段力弱 |
| 價 | 術本身不燒什麼；代價在秘術〈逆潮〉 |
| 萬年問 | 潮汐之道綁地綁時。換一片海就要從頭記上百年的潮錄；離開東溟，修了一輩子的眼就不準了。中神州、天域的陣師寧可修不綁地的陣 |

**〈逆潮〉八條**〔提案〕

| 條 | 內容 |
|---|---|
| 源 | 同《潮信篇》，秘傳一章 |
| 門 | 列陣起可用；天神時可整座護島大陣一起逆 |
| 象 | 退潮時段，修士周圍的海水反常上漲，浪頭朝外 |
| 器 | 潮盤承載逆轉的那一刻；寶器以下的潮盤常在逆潮時裂 |
| 傳 | 只傳真傳 |
| 限 | 一個潮期只能逆一次；離海不能用 |
| 價 | 把下一個潮期的力提前借出。之後約半日法力空乏，經脈像退潮後的灘，一碰就痛；多用則潮息紊亂，終身算不準自己的潮 |
| 萬年問 | 借的是自己的潮；用多了，修士連自己的漲落都不認得，等於自廢《潮信篇》 |

## 二、鎮溟劍宗

**家底形態**：鎮宗之地（海眼）；宗門不擁有海眼，只是看守者〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 東溟外海島鏈〔既有〕；留舟島分部守東岸海眼（主事宮霽）〔既有〕 |
| 上游與隸屬 | 留白 |
| 通常特別擅長 | 守海眼；水下與海眼邊的劍；以劍「釘」住水 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 東溟頂級（三大宗之一）〔既有〕 |
| 規模 | **大**（作者定，2026-10-02）：正式弟子三千以上，但**大而分散**：弟子散在外海島鏈各處海眼，每一處只守著幾個人；一處海眼出事，就近趕得到的只有那幾個 |
| 地盤 | 外海島鏈與各島海眼〔既有〕 |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 宗主 | 江斷潮〔既有〕 | 天神〔既有〕 |
| 留舟島分部主事 | 宮霽〔既有〕 | 列陣〔既有〕 |
| 天驕 | 車遠，陸沉百宗盟試時的同代劍修〔既有〕 | 留白 |
| 太上 | 留白 | — |

### 四、傳承

- **根本功法**〔提案〕：《沉渦劍經》，**玄篇下**。劍道加水行：劍修長年在海眼邊練劍，以法力承受海眼的吸力，劍意裡帶「沉」。
- **招牌術**：〈鎮溟劍印〉（作者定（2026-10-02）；家底庫原名〈鎮溟〉），最低施術境界**銘紋**。劍插入水，封一道渦；劍不是用來刺的，是用來釘的〔家底庫〕。
- **秘術**：〈留劍〉（作者定，2026-10-02），見下方檢查。守眼劍就是從這門秘術來的。
- **傳承載體**：海眼本身〔提案〕。沒有海眼，練不出這種重。

**〈鎮溟劍印〉八條**

| 條 | 內容 |
|---|---|
| 源 | 劍道與水行；《沉渦劍經》（玄篇下）的術 |
| 門 | 銘紋：劍意入水，定住一尺之渦。列陣（結構）：劍落成樁，封一段水下暗流。尊者：封住海眼的一道支渦。天神（空間）：釘住海眼口的「吸」，渦往內收的那一層空間被止住 |
| 象 | 劍修腳下水面下陷，人站在水上像站在凹處；收劍時帶起一道向下的漩〔家底庫〕。海面上有一點始終不動 |
| 器 | 本命飛劍。法器起步；在海眼邊受吸力淬鍊，靈器時劍身比看起來重；寶器時劍靈雛形學會「沉」；道器時結合「定」之則 |
| 傳 | 能。劍道天下共有；別家劍修也能學釘水，只是沒有海眼可練 |
| 限 | 無水不成；離海眼越遠，劍越輕。釘住了就走不開，劍道裡沒有追擊〔家底庫〕 |
| 價 | 術本身不燒什麼；長年在海眼邊練劍，吸力磨損經脈〔提案〕 |
| 萬年問 | 這套劍要在海眼邊熬，海眼的吸力一年年磨人；練成了，也只是一輩子站在一個洞口。沒有多少人想這樣過 |

**〈留劍〉八條**（作者定，2026-10-02）

| 條 | 內容 |
|---|---|
| 源 | 同《沉渦劍經》，最後一章 |
| 門 | 尊者起可用 |
| 象 | 劍修把本命劍整柄釘入海眼，劍沒入水中只剩劍柄，海眼的吸聲在那一刻停一拍 |
| 器 | 本命劍成了**守眼劍**，從此不拔 |
| 傳 | 只傳真傳；不教，等劍修自己決定 |
| 限 | 一生一次 |
| 價 | 失去本命劍。本命器受損牽連本人：留劍之後劍修境界退一段，終身不再有本命劍 |
| 萬年問 | 代價是一輩子的劍；所以鎮溟的守眼劍一代比一代多，願意留劍的人一代比一代少 |

### 五、法寶家底

- **鎮宗之物**：各處海眼上的**守眼劍**〔家底庫〕，每一柄是一位前代劍修以〈留劍〉（作者定）釘下的本命劍；劍主死後劍仍在，宗門以此記「這一處誰守過」。品階各劍不一，例：「本質中品寶器｜當前作鎮物用（劍主已死，器靈雛形散去，只剩『釘』）」〔提案〕。留舟島海眼那一處有沒有劍，留白〔家底庫〕。
- **護山大陣**：留白。
- **器庫**：留白。
- **靈獸**：無。海眼海族（寄礁戶）是鄰居，不是靈獸〔既有〕。

### 六、資源

- 海眼深海靈材〔既有〕。
- 海眼本身（看守，不擁有）〔家底庫〕。
- 靈脈、藥圃：留白。

### 七、產業與財政

- 〔提案〕各島按年給鎮溟「守眼供奉」；海眼深海靈材的採取權。
- 其餘留白。

### 八、人才管道

- 三宗分部考核〔既有〕；百宗盟試〔既有〕；挖太玄閣苗子〔既有〕。

### 九、外交

- 與海眼海族的界線之爭，談了一輩子，從沒真的打起來〔既有〕；寄礁戶〔既有〕。
- 與滄氏蛟族爭海眼〔既有〕。
- 鯊族黥牙：寄礁戶每年獻孩子「護礁」，留舟分部睜一眼閉一眼，因為打起來海眼會亂〔既有〕。

### 十、歷代經驗

- 宗訓（江斷潮常說）：「守住，不是填平。」〔既有〕

### 十一、弱點

- 釘住了就走不開，沒有追擊〔家底庫〕。
- 為了海眼不亂，對黥牙一類的事睜一眼閉一眼〔既有〕。
- 守眼劍越來越多，願意留劍的劍修越來越少；宗門人多，攤到每處海眼卻只有幾個，處處守得住、處處調不動。

### 十二、劇情鉤

- 第 2 篇：留舟島海眼，陸沉與滄漣並肩逼退黥牙，海眼的界線從此重劃〔既有〕。
- 第 27 篇：陸沉經留舟島海眼下低路〔既有〕；〔提案，候選〕那時守眼的是誰、讓不讓路。
- 車遠〔既有〕。

**留白**：上游、確切弟子數與各處海眼的人手分布、太上、護山大陣、器庫、車遠的境界與後續、留舟島海眼有無守眼劍。

### 四、傳承

- **根本功法**：《泊陣篇》，**靈篇上**（作者定，2026-10-02）。刻意低一級：千礁的家底不在功法。修的是空間之道的入門：以神識定兩處座標，以法力撐住兩點之間的一線。
- **招牌術**：〈咫尺泊陣訣〉（作者定（2026-10-02）；家底庫原名〈點陣〉），最低施術境界**銘紋**。傳送陣的開合與校驗，是生意，不是殺伐〔家底庫〕。
- **秘術**：**無**（作者定，2026-10-02）。弟子拚命時靠的是器上的一次性禁，不是宗傳秘術。
- **傳承載體**：傳送陣網本身與歷代陣錄〔提案〕。

**〈咫尺泊陣訣〉八條**

| 條 | 內容 |
|---|---|
| 源 | 空間之道入門；《泊陣篇》（靈篇上）的術。傳送陣理天下陣師共通 |
| 門 | 銘紋：校驗一座院陣級傳送陣兩端的座標。列陣（結構）：開合山門陣級傳送陣（島與島之間）。尊者：戰中以隨身陣盤點開一座盤陣級短程陣，換一次位。天神（空間）：不靠陣盤，直接以神識在兩點之間「點」出一線，限一人、限近距 |
| 象 | 陣開時海面上一圈白光，像一枚錢；陣師點陣時指尖先在空中敲兩下，聽兩端的回音 |
| 器 | 千礁弟子少有本命器〔家底庫：器再多也不是本命器〕；用的是器庫的租器，器上烙庫號。真傳的隨身陣盤也從庫裡租 |
| 傳 | 能。傳送陣誰都能學；千礁的家底是陣網與兩端的地，不是技術 |
| 限 | 傳送陣兩端都要有陣；沒有陣的地方，千礁弟子跟一般修士一樣。尊者的短程換位一戰一次 |
| 價 | 術不燒修為；燒的是錢：開一次陣收一次錢〔既有〕，打壞一件器要賠〔家底庫〕 |
| 萬年問 | 傳送陣要兩端、要維護、要人把持。一家把持了，別家建不起；所以不是人人修，是人人付錢 |

### 五、法寶家底

- **鎮宗之物**：**無**〔提案〕。家底是傳送陣網與靈舟商會〔既有〕，以及按月租器的**器庫**〔家底庫〕。
- **器庫**〔家底庫〕：每件器烙庫號；弟子立功減租、犯錯加租；千礁真傳最大的特權是「免租」。庫中多為法器、靈器；寶器數量留白。
- **護山大陣**：留白。
- **靈獸**：無。

### 六、資源

- 千礁群島的港與各島傳送陣〔既有〕。
- 靈脈、藥圃：留白。

### 七、產業與財政

- 傳送陣：陣開一次收一次錢〔既有〕。

- 黑帆的「讓路錢」：私下，不入帳〔既有〕。
