## 一、太素道宮

**家底形態**：傳承寶物（答案庫）＋人作家底（成器護法）；鎮宗之物沒有一件是兵器〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 祖庭在上無極雲海道域（白玉宮、萬松坡、鶴頂）；下無極渡劫淵分院（收殮堂）、接縫分院；九界各界舊院；長亭天太素山；驤鳴鳴谷院；大羅不設院〔既有〕 |
| 上游與隸屬 | 無；自成道統〔既有〕 |
| 通常特別擅長 | 斷肢重生、經脈重塑、殘魂補全，天下第一〔既有〕；以及同一套手法反著走：取材〔既有〕 |
| 鏡像 | 救援派醫修：古戰時同一片沉下去的天地裡，一門接活人，一門收死人〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 上界**頂級**：宮主素懷準仙帝坐鎮；勢力總表各層數目把太素道宮祖庭計入上無極頂級三家之一〔既有〕。對外以醫門行世，不參與排位 |
| 規模 | **中**（作者定（2026-10-02）；上界以地盤計：祖庭一道域）；分院不佔地盤、不計入，另記：遍及三十二天各層，唯大羅無院〔既有〕 |
| 依附人口 | 留白；百年義診那一年，連王庭都派人排隊〔既有〕 |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 宮主 | 素懷（道號），生於古戰之後〔既有〕 | 準仙帝〔既有〕 |
| 藏案 | 檀翁（道號），答案庫守者，守了六萬年〔既有〕 | 仙王〔既有〕 |

對外可出戰者：幾乎不出戰。護法左卿、右卿守門，不遠征〔家底庫：太素幾乎不打遠戰〕。

### 四、傳承

- **根本功法**：《壺中天經》，**仙篇下**（作者定（2026-10-02））。名取門內讀法「壺中天」〔既有〕：天地萬物都裝得進一只壺裡。修的是**形之道**：一個生靈由形、脈、魂、記四樣疊成（答案庫前四層的分法〔既有〕），修士以神識讀出四樣之間的接縫，以法力沿縫行走。
- **招牌神通**：〈續形〉（作者定（2026-10-02）；家底庫原名〈接〉），門內只稱一個字「接」；同一套手法反著走，門內稱「摘」。最低施術境界**銘紋**。
- **秘術**：〈開壺〉（作者定（2026-10-02）），見下方檢查。
- **傳承載體**：答案庫五層（形、脈、魂、記、我）〔既有〕：數十萬年每一次改造的完整紀錄，包括所有失敗〔既有〕。九界舊院八萬年未經上界對齊，地下另有祖庭都沒有的古老卷宗〔既有〕。
- **傳承層級**〔提案〕：〈續形〉的「接」是公開的醫術，診席都教；「摘」只傳器師與收殮，不立文字，只在答案庫裡有卷。

**〈續形〉八條**

| 條 | 內容 |
|---|---|
| 源 | 形之道；《壺中天經》（仙篇下）。醫道的接骨續脈天下共通，〈續形〉是把它推到神魂一層 |
| 門 | 銘紋：接一段斷掉的經脈。列陣（結構）：經脈重塑，換一段根骨。尊者：接回錯位的魂與肉身（柏鶴齡「雷骨裂了七處，魂與肉身已經錯位」那一眼〔既有〕）。天神（空間）：一段肢體或經脈從甲身上移到乙身上，中間不經刀，只經一道接縫。虛道（規則）：殘魂補全〔既有〕。仙王層次：神魂切分（左卿、右卿〔既有〕） |
| 象 | 白袖不沾血；被他們碰過的人不見傷口，只覺得某處「不如從前」〔家底庫〕。施術時，傷處四周浮出一圈極細的白光縫線，一針一針收攏。神識探上去，太素修士自己身上常有幾段氣機不是同一個人的〔家底庫〕 |
| 器 | 本命法寶多為**續脈玉針**〔提案〕：法器起步；靈器時能記住一段經脈的紋路；寶器時器靈雛形能辨「這一段不是他的」；道器時結合形之則，一針可以縫魂。另有祖庭白玉小壺，是信物，不是法器〔既有〕 |
| 傳 | 能。救援派醫修與太玄續脈手、綴錦宗補縫都是同類手藝〔家底庫〕；正派醫門學得到「接」，學不到「摘」，也沒有答案庫 |
| 限 | 要近身、要先讀；對方在動、有護身器隔著、神魂與肉身本來就分散時，讀不準〔家底庫〕。所以太素幾乎不打遠戰。接上去的那一段，必須有來處 |
| 價 | 施術者不付什麼。付代價的是材料：被取的人瞎一隻眼、廢一段經脈、少三十年壽〔既有：取材規矩〕。這一條就是太素 |
| 萬年問 | 為什麼不是人人修到神魂一層？要練到那裡，得拿活人一次次接、一次次失敗；正派醫門不肯，太素肯，而且把每一次失敗都記了數十萬年。手藝人人學得到，答案庫只有一座 |

**〈開壺〉八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 同《壺中天經》，秘傳一章 |
| 門 | 列陣起可用 |
| 象 | 修士捏碎自己的封蠟小壺，壺中拓樣化成一道白光沒入身上某處；那一處的氣機忽然變成一個「更好的他」 |
| 器 | 入門時領的封蠟玉壺，壺裡是自己身上最好的一部分的拓樣〔既有〕；平時是信物，開了就是秘術的載體 |
| 傳 | 每個道宮門人都有一只壺，人人可用；門內視為最後一招 |
| 限 | 一生一次：壺開了就沒有了 |
| 價 | 拓樣一次燒盡，那一部分從此不如從前，修士自己身上也多了一道接縫。太素對別人做的事，這一次做在自己身上 |
| 萬年問 | 代價是自己最好的那一部分；所以道宮門人以壺為榮，很少有人真的開 |

### 五、法寶家底

- **鎮宗之物**：**答案庫**五層〔既有〕，在祖庭地下，**不按器論**〔家底庫〕。一次只准進一層，層數越深價越高；檀翁收「一段記憶」作價（封寒交出礦谷那一夜）〔既有〕。
- **人作家底**：祖庭門口的**左卿、右卿**〔既有〕：兩人都確信自己才是本人，並肩守門數萬年，從不同桌吃飯。太素最強的護法是兩個互不承認的人。
- **偽靈獸**：繞峰仙鶴是**成器鶴**，以多頭鶴的翅骨、喉與眼接成；晨昏鳴鐘時滿山仙鶴只有一種聲音（作者定採用，只作背景細節、不作揭露觸發；家底庫第 4 題）。三十二天妖族無核〔既有，D073 補記〕，成器鶴的材料取的是骨、喉與眼。
- **器庫**：留白。察變署量災用的器具最早出自太素器師〔既有〕。
- **護山大陣**：留白。

### 十、歷代經驗

- 信條：「天賦生在錯的人身上，才是最大的浪費。」〔既有〕
- 取材的規矩（他們自己的「善」）：先救活，再取；不取王族、不取聲名太盛者；取的部分不至死〔既有〕。
- 古戰時取得「無主屍骨收用」特許〔既有〕。

### 十一、弱點

- 要近身、要先讀；不打遠戰〔家底庫〕。
- **取痕整齊**：同一雙手的取法數十萬年不變，收殮過的屍骨上都有同一種痕；八萬年前的古骨與今日的屍骨對得上〔既有：第 14、23 篇〕。
- **檀翁補上的名字**：答案庫的卷宗本來只記編號，檀翁一枚枚補上了名字，因為「記錄要完整」〔既有〕。這是太素最完整的家底，也是它唯一的證據。
- 不能在大羅設院〔既有〕。

### 十二、劇情鉤

篇位見[太素道宮](../03_跨層道統/太素道宮.md)第七節〔既有〕：4 義診消息；5 柏鶴齡救治；7 墨乙向寇平開價；9 收殮堂；13 生探出接痕；14 取痕；15 柏鶴齡要用九弱的經脈治生；16 邴初；19 序段封寒入答案庫；20 祿安借太素之術；22 雲行拒絕；23 驤鳴揭開；24 邴初與收殮堂；28 白鶴繞一圈就走。

- 〔提案，候選〕〈開壺〉：邴初若有一刻開壺，開出來的是八歲那年換進他身上的那段根骨，不是他自己的；他最好的那一部分本來就不是他的。不排篇。

## 二、同歸會

**家底形態**：**什麼都沒有**（無共同絕學）＋信物＋借來的道脈〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 不是宗門，沒有山門。據點：抱一道場（上無極最內側，與紫垣比鄰）；王庭重華、紫垣、白榆〔既有〕 |
| 上游與隸屬 | 抱一仙帝是教義的源頭與道場的主人，不坐歸席〔既有〕 |
| 通常特別擅長 | 統計衰退、遊說各庭、借道脈；把收接道脈也叫「校正」〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | **不適用**〔提案〕：同歸會不是宗門，成員各有本家；背後的抱一道場是仙帝道場 |
| 規模 | **不適用**（作者定（2026-10-02）：非宗門、無地盤）；歸席六席，其一常空〔既有〕 |
| 地盤 | 無自有地盤；據點見上 |

### 三、戰力結構

| 層 | 人 | 境界 |
|---|---|---|
| 教義源頭 | 抱一仙帝（不坐席）〔既有〕 | 仙帝〔既有〕 |
| 歸席 | 抱一席嵇元朗（仙王）、重華席公孫懷璞（仙王）、紫垣席司空肅（仙王）、白榆席管長夜（仙王，帶道傷）、算席閭丘觀（真仙）；空席：帝座〔既有〕 | 見前〔既有〕 |
| 司途 | 招途祿安（至尊）、耳途鄺問（真仙）；錢途由鍾離算兼辦〔既有〕 | 見前〔既有〕 |
| 強接派主陣 | 婁直，抱一道場弟子〔既有〕 | 真仙〔既有〕 |
| 伏根 | 申屠靜（真仙）、蔚北（真一）、萇遙（天神）〔既有〕 | 見前〔既有〕 |

對外可出戰者：各憑本家。陣起之前是一支各說各話的聯軍〔家底庫〕。

### 四、傳承

- **根本功法**：**無共同功法**〔家底庫〕。同途出身各庭，各修各家。抱一道場本身的功法：留白。
- **招牌**：〈校正〉之陣〔既有名，作者定〕。術理原為留白（[歸一派](../03_跨層道統/歸一派.md)待定項）；本卡提出的最小陣理**整套採用（作者定（2026-10-02））**。
- **秘術**：無共同秘術。
- **傳承載體**：教義與衰退數據（刻意漏掉九界的繁衍那一欄）〔既有〕。

**〈校正〉之陣八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 抱一道場的**歸一之道**：天地之氣本有向心，散則衰，抱一則存〔既有教義〕。陣把一片地的道脈往極的方向拉，屬陣法，不屬任何個人神通 |
| 門 | 主陣者最低**真仙**（婁直主陣〔既有〕）。陣級高於界陣以下各級：要撼動一片天的道脈，本錢是王庭借出的道脈，不是主陣者的修為（借陣借的是陣之力〔既有通則〕） |
| 象 | 陣起時，方圓之內的道脈被拉向同一個方向：草木、靈氣、雨絲、修士的神識，都往同一邊斜〔家底庫〕 |
| 器 | **歸席整璧作陣眼**（作者定（2026-10-02））：六枚整璧是陣的六個陣眼，五枚到場即可起陣；空席那一枚（帝座之璧）永遠缺，所以陣永遠「差一席」：能拉一片，拉不動整個無極。半璧是身分，不是法器〔家底庫〕 |
| 傳 | 能。陣理不難，同途的陣師都看得懂；難的是本錢：道脈要別家借出 |
| 限 | 沒有借來的道脈就沒有陣：王庭一拒交，陣就沒有本錢〔家底庫；D041 終局條件〕。缺空席那一枚，陣的上限就是「一片」 |
| 價 | 被校正的地，道脈被抽走一截，地會虛（碎錦原的衰土）；借出道脈的王庭，自家道脈也跟著細一截 |
| 萬年問 | 要拿整個王庭的道脈當本錢，八萬年沒有一家王庭肯；所以同歸會講了萬年，直到太宸的餘壽成了時鐘，強接派才等不及硬推〔既有：第 20、22 篇〕 |

### 五、法寶家底

- **鎮宗之物**：**歸席六枚整璧**〔既有〕；其中空席那一枚（帝座之璧）沒有人持有，放在哪裡、由誰保管，留白〔家底庫〕。同歸會自己也說不清，這正是「沒有首腦」的物證〔家底庫〕。
- 整璧同時是〈校正〉之陣的陣眼（作者定（2026-10-02））。
- **信物**：半璧，每個同途一枚，紋路對不上任何別人的另一半，叫「待合」〔既有〕；衣襟內繡一個沒有缺口的圓〔既有〕。
- **器庫、護山大陣**：無。
- **靈獸**：無。

### 十、歷代經驗

- 規矩：重大事須五席同意；空席那一票永遠缺，所以任何決定都「還差一席」〔既有〕。
- 暗語：「回來了？」「還在路上。」〔既有〕

### 十一、弱點

- 沒有自己的道脈；每一次大陣都要別家借出〔家底庫〕。
- 空席：永遠差一票，也永遠差一枚璧；陣永遠只拉得動「一片」〔既有；陣眼一說作者定（2026-10-02）〕。
- 三派互相拆台：還本對強接是時程，還本對收權是看不起，強接對收權是背罪〔既有〕。
- 論據的破綻：只統計衰退，漏掉九界的繁衍（荀恆原本算進去了）〔既有〕。
