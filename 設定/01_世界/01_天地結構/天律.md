# 天律

狀態：**作者選定**（2026-11-28，[D215](../../../決策/01_決策紀錄/D215_天律四條.md)）。作者選定的是框架與四條主諺；各條行話、讀者落點與後台化清單為工作選定。細則照各原檔，效力不因本檔改變。

來源：規則盤點（210 條、30 條衝突）、三寫手競稿與獨立比較，見[天律討論區](../../../待整理/天律_20261128/README.md)。

## 一、這是什麼

天律是**人口裡的老話**。舟師、守界人、師門長輩、聖土丹師世代傳下來，說的人有身分、有處境，說的時候多半正在吃虧或保命。

- 老話可以只對一半。可以說錯，帶著行當口音，也可以被天驕頂嘴。敘述者不替它補全，也不替它更正。
- 天地為什麼這樣，屬於作者層的**天理**（[D213](../../../決策/01_決策紀錄/D213_天地大謎採丙與墊天讀法.md)，原稱「四條天律」，已改稱天理），由揭露階梯承載，不進任何人的嘴。
- 細則（補給率、印期、窗口、倍率、門數、補丁編號）留在原檔，作者後台嚴謹，正文不出現，見第四節。
- 天律不能拿來解困。它只說誰過不去、要付什麼、哪裡是牆，從不說「所以他過得去」。

## 二、四條

| # | 名 | 人物口中 | 作者層一句 |
|---|---|---|---|
| 一 | 帶不走 | 師門：「**境界帶得走，天地帶不走。**」<br>舟師：「**身上的帶得走，腳下的帶不走。**」 | 修為長在人身上，跟人走；補給與主場留在原處；界壁與界潮只秤人此刻放得出的力，不問來歷；只有自成天地的帝帶得走天，而聖土一次只容一片帝天 |
| 二 | 劫跟人 | 「**劫跟人，不跟地。**」 | 人拆了今日的自己重來，身上就開縫，天地在縫上擋，相磨即劫；劫沒有意志，不看心意、不點名，跟著拆自己的那個人走，他有幾具身就認幾具；不拆自己的人沒有劫 |
| 三 | 門與牆 | 「**隔門莫打，隔牆莫望。**」 | 同境可越，越一境可拚；跨一道門正面不可勝，只有少數人在自己的道上拆得開門；牆誰也拆不掉；隔門隔牆能做的只有逃、拖、借、逼對方付價、改勝負條件 |
| 四 | 扛天折壽 | 「**扛天折壽。**」 | 撼動、撐起、封住天地的出手，都拿壽與本源付；扛得越久燒得越深，仙帝亦然 |

### 天律一　帶不走

**同一句話，各行當各有用法**
- 師門用 D065 原句教弟子。
- 九界舟師與後裔用口語版說吃飯：到了那邊本事都在，可那邊的氣嚼不爛，吃十口頂家裡三口。
- 上界守界人用它說錨印：「界門不問你是誰，只秤你現在多重。」修為封在你身上一重沒少，可是放不出來，所以壓境下來的天神只有列陣之力。
- 接引：「矮門秤肩，不秤骨。」
- 渡虛的人：「出去是爬坡，回來是下坡；下坡停不住。」
- 聖土：「火隨身，爐留家。」老人說帝：「一地不容二天。」所以八萬年沒有帝，觸帝者老死在帝前。

**管什麼**：
- 跨界時能力保留，補給與主場帶不走。
- 九界斷脈、仙力外瀉。人口裡這叫「斷了的路比沒有路更糟」。
- 界壁與界潮秤當下，所以有壓境與退境。
- 真仙要回家破境，落根要在聖土破境。
- 帝自成天地；聖土一地不容二天，成帝等於拆封。
- 兩界的痕互讀不懂。

**不管什麼**：
- 通行的窗口、週期、倍率與路數，這些屬後台。
- 劫，歸天律二。
- 打不打得贏，歸天律三。
- 錨印怎麼烙、印期多長、破了誰賠，屬人規。

**讀者第一次看見**：
- 卷二十三：寇平強破錨印，修為被界壁當場剪去，側廊界壁留下一道齊整的剪痕。返鄉時，他讀出費瑜兄長的錨印殘痕，守界人的行話放在這裡。
- 第一次聖土青苗洞：古洞依境放人，一位祖上從九界過來的後裔老人說出口語版的主諺。

**大代價**：
- 越強越餓：離家的強者只剩存糧，每一場全力出手都在花回程的力。
- 要過界就得先變輕：要嘛封著，人規的代價跟著來；要嘛散掉，回去重修。

### 天律二　劫跟人

**各行當的說法**
- 三十二天修士：「劫跟人，不跟地。」躲到聖土也躲不掉，仙修在聖土照樣起劫。
- 聖土丹師從自己的爐子懂它：「丹要活，先挨雷。」聖土本土唯一常見的劫就是丹雷，所以聖土人第一次看見劫落在一個人身上，最先懂的是丹師：「他把自己當一爐丹在煉。」
- 縫民說反面：「雷不瞄人。」這句是現行塔姆林的台詞。

**管什麼**：
- 劫跟著逆行者走。聖土突破無劫，丹雷例外，仙修在聖土照樣起劫。
- 共同破境：全員同處劫域，成敗一體，一具落後，全體不破。
- 劫沒有意志，不點名，不聽求饒。
- 在聖土解開錨印只是取回，不拆自己，所以不起劫。

**不管什麼**：
- 劫的等級與強弱，屬後台。
- 劫的終極來源，屬天理。
- 誰能切走、承接或替人分擔別人的劫，例如眭無恙的斷劫陣、綦毋煙的陣心。這是修法與陣的本事，老話不說「不能代挨」。
- 不得以九霄劫雷自造劫，這條照雷道原檔，屬後台。

**老話只對一半的地方**：
- 封合縫那片劫雲不是誰的劫，縫民因此說「雷不瞄人」。
- 第六弧那一夜，九界那一份劫「換到別處渡，九界照樣被頂著」，是跟著地走的（[天自己的劫](../../../大綱/06_仙途/14_天自己的劫/大綱.md)）。
- 讀者到那裡才知道這句老話說了一半，背後的全貌在天理。敘述者事先不提醒。

**讀者第一次看見**：
- 重讀卷五〈那我帶一場去〉：九霄的雷雨季今年不來，他把一場劫帶去試場渡。正文一字不改。
- 聖土第一次看見：第二次聖土的鐘崖遁一劫。邊地的「劫」字向來是南邊雷域的地名，這一天聖土人看見劫跟著一個人來。

**大代價**：
- 往上每一步都要親身挨天一擋，渡不過去就死在劫域裡。
- 分出去的身越多，要一起站進劫域的就越多。
- 劫不認心意。

### 天律三　門與牆

**老話、頂嘴與下一句**
- 師門長輩教弟子：隔一道門別跟他打，隔一道牆連神識都別往他身上掃。
- 天驕年少時都頂過一句：「門是給人拆的。」
- 老人接：「牆沒人拆過。」鬥法台上也有人說：「門拆得開，牆撞不倒。」

**管什麼**：
- 跨境律的讀感；門可拆，牆不可越，真仙可被逼退。
- 同伴各在自己的道上拆一道門。
- 客場修正越不過質變點。
- 陣的處理層級與跨境律同構；高於己身的禁只能借陣。

**不管什麼**：
- 陸沉一場拆幾道門、哪一年起能拆兩道，屬數值與後台。
- 陸沉越至尊牆的三次，是 D157 的例外，留在後台，不入本文。
- 真敗只有三項，屬寫作規則。

**讀者第一次看見**：
- 卷十五到卷十八之間，由書院教習或北院軍中舊例說出主諺，落點交章綱。
- 第一次被打破一半在卷二十三領印日：列陣的陸沉拆了尊者裴照川的門，在八界使者面前把他制服。使者說「門是給人拆的」，身邊的人問「牆呢？」，他答「牆沒人拆過」。
- 牆在少年段只聽見，不看見。

**大代價**：
- 拆門要付本源、壽元或傷，依場面而定，戰後記清（D157）。
- 牆前只能保命。

**門與牆只當比喻，不計數**：正文、大綱與審稿見到「第 N 道門」「拆了兩道」一律退回，讓旁觀者的反應說。

### 天律四　扛天折壽

**誰在說**：聽過古戰的老人，看過帝座的上界人，還有站在丹堂、陣心邊上的人。這句話短，多半是看著某個人說的。

**管什麼**：
- 撼動天地的全力出手也在燒壽，仙帝亦然；道傷折壽，不能復原。
- 封界這類以本源為代價的出手，約削去施術者一半壽元。
- 帝座承重八萬年；帝重的承與渡。
- 以修為換封泥這類長年的扛。

**不管什麼**：
- 誰該扛、幾個人扛。老話不說「一片天只壓一副肩」。多人同承、承重契、第六弧九界自簽，都照原檔。
- 帝主可以親征、封界，離座天地不會崩（[權力根基](../../01_世界/04_勢力/仙庭與王庭權力根基.md)）。

**已有的帳（重讀即見，不加字）**：
- 太宸封界削去半壽，之後以帝座承重八萬年。
- 父親陸承遠以修為換封泥，在銘紋壽元帶前段就走了。
- 第六弧陸沉燒去萬年級的壽元與本源。

**讀者第一次聽見**：位置交章綱，建議在父親壽終之後、有人看著封泥說出口。

### 天律與人規

| | 天律 | 人規 |
|---|---|---|
| 誰立的 | 天地自己 | 同境者彼此簽下的約，與王庭、仙庭的制度 |
| 破得了嗎 | 破不了，只能付 | 破得了，破了賠人：除籍、凍額、追界令、印痕、失信 |
| 正文怎麼寫 | 老話、應驗、代價畫面 | 約、罪、人情、擔保人的臉 |
| 例 | 界門只秤當下；劫跟人；牆；扛天折壽 | 錨印與破印簿；登天路未滿二十；鬥法台不收跨質變點；開門辭「兩岸一息，往來不禁」；舊約「帝在，王不相伐於帝前」 |

讀者只要分得清「天不放你」和「人不准你」。跨界與錨印兩類六十四條規則，大半只在人與人的衝突裡露面。

## 三、和天理、順逆一句的關係

- D213 作者層四條改稱「**天理**」：天還沒長完；劫是天落在你身上、被天地擋住的那一份；沒活成的會回去；極在哪裡，劫往哪裡落。天理是大謎的謎底，只在作者層；天律二是天理二在人口裡的那一半。
- 「順則生人，逆則成仙」（[三十二天](三十二天.md)，D035 候選）留候選，只當作者層用語，不入天律，不入人物口中。

| 錨印重數、印期、穩解天數、強破速度、解封異象範圍、凍額年數 | 對印裂開那一聲；印上鏽的顏色；擔保人罰俸那天的臉；破過印的人道基上一輩子的裂痕 |
| 「承載列陣」「承載線」「當下承載」 | 「只秤你現在多重」；界壁把人剪掉的那一下 |

| 天譴階數、雷體百分比、吐納量表、九等天劫等級 | 身體顯相、天地被驚動的畫面 |
| 壽元表、放棄線比例 | 鬢角；一句「我在這道門前蹲了四十年」 |
| 「天律」二字、天律編號 | 只說老話；老話可以說一半、說錯、被頂嘴 |

**總替代規則**：正文要讀者懂某條細則才看得懂人物的選擇時，先試三種替代：一個畫面、一句老話、一筆代價。三種都不行，才讓一個懂行的人用一句行話說出來，同一條細則全書只說這一次。
