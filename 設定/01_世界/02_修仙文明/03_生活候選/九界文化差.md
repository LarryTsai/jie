# 九界文化差

狀態：**候選**。2026-10-10 依作者整理授權，由既有提案抽整推薦主體；入庫不代表採用。依[待決總清單](../../../../決策/02_待決/待決總清單.md) 2-19，可作大綱工作方案，整批設定批准仍待作者。

既有／作者定條文只作來源引用，效力沿正式原檔；未標已定的表格、推導、習俗、人物場景、工作數字均屬候選。不得把候選的推導擴成全界規則，不新增既有人物經歷。原提案的比較、理由與問答留[來源](../../../../歸檔/04_設定來源/生活候選/九界文化差提案.md)。

**目標**（路線圖原文）：吃什麼、怎麼葬、怎麼稱呼師父、怎麼戀愛、怎麼看妖族、什麼事在別界是失禮。讓「跨界像出國」。路線圖範例：某界初見面會開一縷神識，表示「我沒有藏殺意」；劫的雷直接炸了；封寒：「……人家是在打招呼。」


**以什麼為準**（PM 指示）：
- 九界之間的差異以[其他八界](../../04_勢力/04_其他八界/README.md)八份勢力檔為準〔既有，D062〕：每界不套六域四院，各有自己的分法與培養人才的方式。
- **D058、D059 與 D065 的壓境規則**：上界的人進九界只能壓境或退境，不寫化身；錨陣與壓境簿由上端王庭掌管，下端守界傳承持副印〔既有〕。
- **D082**：九界之間沒有網，跨界只能走人，九界之間要經上界轉兩條界路，數月至一年；共天是九界之間一年一月的全文通道〔定〕。
- 人物既有細節（**只引用為禮俗例子，不替人物新增設定**）：雲行喝酒、問死者的名字；文奕的明標與禁標；劫與封寒在路線圖範例裡的那一幕〔既有〕。

**各塊留下的禮俗接口**（本檔一併接上）：神識的禮俗（D082：掃到就察覺，掃高一個質變點的人視同挑釁）；高手入城收斂吐納是禮（D084）；秘境不問、約鬥（D085）；散靈、歸土、記名（D086）。

## 第 3 件　時間與曆法


**九界各用本地曆，跨界文書用上界的仙籍曆**〔提案〕

| 界 | 本地人怎麼記年 |
|---|---|
| 長亭天 | 東溟以浮石季、潮時記；各域各有（D083） |
| 凌汛界 | 以開河記：「第幾次開河」 |
| 昏曉界 | 以長夜記：一年兩段長夜 |
| 懸岳界 | 以山記：「某山漂過某處那年」 |
| 蒹葭界 | 以藥齡記 |
| 千根界 | 以年輪記 |
| 望歸界 | 以窗口記；窗口曆只由口傳七家世代背誦〔既有〕 |
| 驤鳴界 | 以四場記：「第幾個冬場」 |
| 霜明界 | 以冰層記：鑿下幾層 |

- **仙籍曆**〔提案名〕：仙籍司、界路司與遞書吏用的曆。九界本地人多半看不懂；一張遞書吏送來的公文，要找懂仙籍曆的人換算。這是「消息到了，卻不知道是哪一天的事」的一個來處（接 D082 九界同令不同時）。

## 第 4 件　語言


**同文異語：書面同源、口語各異；望歸混舊詞**〔提案〕
- 九界的書面文字同出古仙文，讀得懂大半；口語、口音、詞彙差很大。
- 望歸十二渡的話裡混著聖土舊詞，內陸人聽不懂〔既有〕；聖土舊詞的樣貌由聖土寫手定〔既有〕。
- 通譯：越裳通譯館、望歸通譯塾〔既有〕；九界飛升者在下無極靠九鄉會互相照應〔既有：九鄉會同鄉互助〕。

## 第 5 件　上界裡的九界：九鄉會與帶上去的習慣

### 現況

九界飛升者落地被註「九弱」〔既有〕；九鄉會是下無極的同鄉互助〔既有〕；大羅人對一切來者說「回來了」（D043）〔既有〕。


**習慣跟著人上去**〔提案〕
- 九界飛升者在下無極仍照家鄉的禮：千根人見面開神識、驤鳴人報帳名、霜明人不在別人門口久站。
- 九鄉會裡最常見的爭執，是不同界的人用自己的禮看別人的失禮。
- 上界本地人看九界人，只看得見「九弱」兩個字，看不見這九種禮；這是九弱線的一層質地。

## 第 6 件　人物既有細節作禮俗例（不新增人物設定）


**只示範「同一個既有習慣，到別界讀法不同」，不替人物加設定**〔提案〕

| 人物既有細節 | 可寫的場面（候選，不排篇） |
|---|---|
| **劫與封寒**（路線圖範例） | 千根界的人初見開一縷神識；劫的雷直接炸了；封寒：「……人家是在打招呼。」 |
| **雲行喝酒**〔既有〕 | 每一界的酒不同（凌汛冰窖酒、昏曉火樹花酒、蒹葭葦藥酒之類，**酒名皆候選**）；雲行的九界酒地圖（路線圖）只當地圖，不給他新增能力 |
| **雲行問死者的名字**〔既有〕 | 在驤鳴，逝者抬進無聲谷就不再出聲〔既有〕；他問名字，本地人會停一下。不決定他問不問，只寫那一停 |
| **文奕的明標、禁標**〔既有〕 | 明標要讓本地孩子讀得懂；到了別界，標記的慣例不同（例：霜明人先看冰上留沒留影），他得先學當地的「讀法」 |
