## 閉關的四種目的

閉關的長短要由修士在做什麼決定。調息恢復法力、穩境整理新得修為、破關越過質變點、閉死關則把是否出關押在一次突破上。境界改變時間感，並不代表每次修行必須離開人世數十年。

| 種類 | 候選尺度 | 實際內容 |
|---|---|---|
| 調息 | 時辰至數日 | 回復法力；具體傷勢仍查已採自癒表與秘術自身代價 |
| 穩境 | 旬至數月 | 穩住剛破的小境，適應前、中、後段的修為 |
| 破關 | 依下表 | 專攻質變點；需要脈眼、吐納份額與護關安排 |
| 閉死關 | 不定 | 不破不出，可能越過原先約定的年月；命牌狀態仍按現行規則判讀，不能單靠「暗」推定必在閉死關 |

### 一次破關所用的時間

以下是宗門正常修士一次集中攻關的候選工作值，不是從上一境起算的全部修煉年數，不是每個人最低必花時間，也不改主角年表。原提案未列的神火、真一、聖祭、斬我、遁一等境界不自動內插。

| 所攻關口 | 候選時間 |
|---|---|
| 化靈、銘紋 | 數月 |
| 列陣 | 一兩年 |
| 尊者 | 數年 |
| 天神 | 十年級 |
| 虛道 | 數十年 |
| 至尊 | 百年級 |
| 真仙 | 數百年 |

原提案另有「天驕約可縮到三分之一」與「常帶傷出關」。兩者均未裁定：前者只保留為比較估值，不能套成所有天驕固定倍率；後者不構成每次成功必須受傷。突破可以真正成功，所花時間、資源、錯過的事或器物耗損也可以是代價。

原提案「破關約佔該境壽元一兩成」與上表並不逐項相合，例如數年破尊者不等於數百年壽元的一兩成。此比例保留為**待核候選**，不能與表格同時作必然公式；待決時須分清單次攻關與一生累積閉關時間。

### 修士如何生活在關前、關外與出關後

- **脈眼與份額**：破關時吐納增多，周邊靈田減產，沿既有 D084。有人買護關，有人請師友同門，有人先把宗務、田圃與家事交出去；不能靠一句閉關就抹掉這些人的生活。
- **護關**：師徒、道侶、同門可以共同守一關；渡劫淵護道人收費是既有背景，並非天下破關都須雇同一類人。護關者亦有修行、換班、離開與拒絕續守的選擇。
- **出關錯位**：修士先問過了多久、誰還在。消息經命牌、宗門記錄與遞書吏傳來可能已晚；一次成功出關，可以同時帶來修為的喜悅與朋友已分路的陌生。
- **既有人物**：陸沉年表由正式大綱決定，不以本表拖慢；觀海老人守潮樞、供陣的候選故事不能因本檔而定案。原提案引用的舊篇位與太虛修行安排不作現行事件依據。

## 壽終的身體表現

以下「衰、漏、化」是尚未採用的自然壽終觀察方案，不是所有修士必按同一期限經過的倒數表。道傷折壽、封界耗壽、心魔停滯，以及死亡、坐化、散靈的既有條文，沿[境界與能力尺度](../../../04_修行/01_境界/境界與能力尺度.md)與[死亡與繼承](../02_文明細則/死亡與繼承.md)，不由本檔重定。

| 階段 | 候選時段 | 候選身體表現 |
|---|---|---|
| 衰 | 壽元最後一成 | 平日外貌老得慢，此時才較明顯顯老；調息變慢，自癒能力下降。原提案「自癒退一個質變點」尚未採用，不能回寫已定自癒表 |
| 漏 | 最後數年；高境者可為數十年 | 夜間法力漸難守住，神識所及一年年收縮；草木先感到逸散之氣。具體異象與衰退尺度須由人物、功法和場地支撐 |
| 化 | 最後數日至數月 | 修士自知時日，閉門坐化；修為散回天地的歸氣沿 D086。天神以上坐化時風住、雨落等小異象屬候選，不是每一位都必出現 |

- **耗損與壽終**：長年以修為換物、道傷與封界可能使人提前走到盡頭。不能拿無耗損壽元表斷言人物一定還有多少年。
- **壽元與心魔**：身體接近壽終與修行被心魔卡住是兩件事。太宸兩者兼有的既有設定不改，處於哪一候選階段仍留白。
- **父親的身體**：原提案以陸承遠長年換封泥為例，可供現行第 21 篇父親消息的具體身體描述參考；不移動死亡篇位，不新增陸沉在場見終或返島情節。
- **戰死與自然壽終**：未坐化者的殘力與散靈程序沿 D086，不套三期。

### 延壽仍待核的候選

原提案主張「真正延壽只靠破關；延壽之物稀少，延不過一個小境差距」。這兩句尚未裁定，尤其「只靠」不能直接否定已有燃壽、借壽或其他局部故事機制；本檔保留為待決候選，不給全書延壽上限。
