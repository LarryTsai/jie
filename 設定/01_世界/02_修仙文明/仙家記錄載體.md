# 仙家記錄載體

效力：記錄原則已由 D136 作者裁定；下列小件核對表尚未完成，不以整理入庫代表逐件選定。

## 現行原則

仙界與九界修士的記錄以法寶為載體。抄本、拓本指神識拓錄副簡，差異在神識烙印層紋；「卷」可作計量，默認玉簡。修士書信用傳訊玉符或玉簡。仙界官冊為玉冊，頁為玉頁，帝批是神識批註。

符紙、凡人紙本、下界低階宗門雜務用紙、陸沉母親手寫紙方均為作者保留的例外。聖土不套這套原則。具體已定物件與修訂範圍查[決策紀錄](../../../決策/01_決策紀錄/README.md) D136 及[經濟流通與校驗](01_底層規格/04_經濟流通與校驗.md)。不因「仙」字刪掉紙方筆跡的情感母題。

| 物件 | 核對義務與界線 |
| --- | --- |
| 太玄命圖的無星古圖 | 圖卷或玉圖尚未定，不因默認玉簡擅改祖傳物件。 |

| 宗訓石拓錄、北天星圖冊 | 依載體原則核對現行寫法，不據舊行號判斷仍未修。 |
| 太玄宗貼牆告示 | 告示玉壁是候選；先確認現行場景與凡俗／低階例外。 |

| 陸家摺紙與曬書 | 核對家用紙本與情感用途，不為統一名稱擅刪。 |
| 雲行九界酒地圖 | 多為比喻；只有實物場景才需指定載體。 |
