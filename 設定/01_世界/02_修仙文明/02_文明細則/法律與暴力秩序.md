狀態：作者定（D085，2026-10-02）；七題全採 A。由討論區[法律與暴力秩序提案](../../../../歸檔/04_設定來源/三十二天/法律與暴力秩序提案.md)抽出已裁定條文；推薦理由、比較與未採方案只留在原提案。決策條見 [D085](../../../../決策/01_決策紀錄/D085_法律與暴力秩序.md)。

不碰真相層。證據規則與析木的規矩照 D067 只作世界裡的律例，不當主線引擎。

## 第 1 件　立法原理：法是強者彼此簽下的「不這麼做」

法是同境者彼此簽下的「不這麼做」，再請一個大家都承認的見證人記下來。

### 五層約法

| 層 | 誰簽 | 誰見證、記錄 | 例 |
|---|---|---|---|
| 帝約 | 仙帝與帝座 | 帝座、天冊 | 庇護承諾（仙帝道場對飛升者）；追界令要帝座簽 |
| 庭約 | 十八王庭彼此 | 仙庭三司記注、仙籍 | 接引與錨陣規則、擔保連坐；上界通行資格 |
| 盟約 | 宗門彼此 | 盟會 | 百宗盟；四院大比規則 |
| 城約 | 城與住在城裡的人 | 城主、城吏 | 千禁城以城約自治；坊市約 |
| 門規 | 宗門、家族對自己人 | 戒律、祠堂 | 宗門戒律（通用模板，D073）；陸家家規 |

### 法的牙齒

法的牙齒是四樣東西：**印**（錨印、合印、封印）、**帳**（記一筆：名冊、擔保信用、名額）、**連坐**（擔保鏈）、**陣**（城門陣、護山大陣）。刀只在抓得動時用。

### 仙庭存在的政治理由

王庭彼此簽約，需要一個不統治、不偏、所有人都承認的見證人與記錄者。帝座承重，仙籍與天冊就是約的記錄。所以仙庭無為而治，卻不能沒有。

## 第 2 件　殺人的分類

分類看兩件事：死者被哪一層約保護（有沒有命牌、有沒有宗門、有沒有擔保、在誰的地上），與事情在哪裡發生（城裡、野外、秘境、界路）。

| # | 殺誰、在哪 | 算什麼 | 誰管 | 常見後果 |
|---|---|---|---|---|
| 1 | 修士殺凡人（城裡、皇朝境內） | 犯城約與皇朝律 | 城吏、皇朝官；宗門戒律 | 紙面重罪；抓得動的只到化靈、銘紋；抓不動就**記帳**：修士冊上一筆，下次進城、過門陣被認出（第 5 件） |
| 2 | 修士殺凡人（野外） | 私事 | 多半沒人 | 凡人家屬只能求宗門或城 |
| 3 | 殺散修 | 私仇 | 沒有命牌就沒人知道（D082）；在坊市裡則犯坊市約 | 野外多半不了了之；散修之間靠「不問」與報復 |
| 4 | 殺他宗弟子 | 宗與宗之間的事 | 命牌熄（截熄可辨，D082）；宗門追索；盟會調解 | 多以**賠**了結（賠命價、份額、人）；少數成宗戰 |
| 5 | 宗門內決鬥 | 門規 | 戒律 | **約鬥**可以，須見證、不殺；殺同門是門規裡最重的罪 |
| 6 | 秘境、遺跡裡殺人 | 依入境約 | 秘境的主人或守者 | 多數秘境入口立**入境約**：「入境生死自負」，即「秘境不問」；若入境約寫明不殺，違約者被主人追索 |
| 7 | 跨界殺人（壓境者在九界殺人、過界路殺人） | **毀庭約**：牽動錨印與擔保鏈 | 界路司、守界傳承、錨陣掌管王庭 | 最重的一類：合印收押、破印連坐，擔保宗門凍額、擔保人除職 |
| 8 | 殺未開智妖獸 | 打獵，合法 | 獵區份額 | 照份額；越界獵是偷 |
| 9 | 殺已開智、已化形的妖族 | **同殺人**（D077 開智線） | 依死者所在與所屬，同 1 至 7 | 取材則是殺人取材，重罪（南荒明文） |
| 10 | 受僱殺人（斷命樓一類） | 僱主與殺手同罪；殺人契無效 | 依死者分類 | 契約見證人不見證殺人契；斷命樓只能走暗契 |

## 第 3 件　誰查、誰判、誰抓：抓不抓得動

公式：**抓得動就收押，抓不動就記帳，帳會在另一個地方收。** 記下來的那一筆跟著名冊、擔保信用與名額走，下一次他要人擔保、要名額時就付帳。

### 誰查

| 範圍 | 查的人 |
|---|---|
| 宗內 | 戒律 |
| 城裡 | 城吏、城主（照城約） |
| 宗與宗 | 兩宗各自查，交盟會 |
| 跨界 | 界路司、守界傳承（扃天閣）、錨陣掌管王庭 |
| 跨庭 | 涉事兩庭各自查，交析木 |

### 誰判

| 範圍 | 判的人 |
|---|---|
| 宗內 | 戒律、宗主 |
| 城裡 | 城主依城約 |
| 宗與宗 | 盟會調解（百宗盟一類）；調解不成就是宗戰 |
| 跨界、跨庭 | **析木**受託審證（一案至少兩條互不隸屬的證據鏈）；判決由簽約各方共同承認才生效 |
| 仙庭 | **不判一般案**；只記注（記注司）與登錄（仙籍司）；帝座只簽帝約一層的事（追界令） |

### 誰抓

| 手段 | 抓得動誰 |
|---|---|
| 高境者親自出手 | 低一個質變點以下的人 |
| 城門陣、護山大陣 | 陣的承境以下（D073） |
| 錨印、合印 | 壓境者：修為封在本人體內，錨陣握著（D059、D065）；九界裡法最有力的一顆牙 |
| 擔保連坐 | 抓不到人，就罰擔保的人與宗門 |
| 記帳 | 任何人；不抓，只記 |

### 抓不動的時候

1. 記帳（名冊、擔保信用、名額）。
2. 找他的擔保人與宗門（連坐）。
3. 等他下一次過門陣、過關口、過界路（照囊、驗名籍，D082）。
4. 不追：帝座不簽追界令，就是最高一層的「不追」。

九界的法最有力的牙是錨印。上界的記帳、擔保與名額效力見上表；原提案推薦理由另作「上界的法最有力的牙是帳」，屬說明，不另立一條裁定。

## 第 4 件　刑罰：修士活得久，刑罰長什麼樣

七種刑，以刑役與封修為主，死刑罕見。

| 刑 | 是什麼 | 例 |
|---|---|---|
| **刑役** | 在險地服勞役數年至數十年；修士活得久，這是主刑 | 裴照川在渡劫淵替無道場護持的九弱護道，不殺、不赦〔刑期已由 D128 修改：原三十年改為十年（約 24.5–34.5），裴照川定尊者以上〕 |
| 封修為 | 以力禁封幾重修為，期滿解；寫封要列陣以上 | 力禁（D073） |
| 除籍 | 從宗門、仙籍除名；命牌撤下 | 玄殿除籍 |
| 凍額、罰俸 | 凍結名額、擔保額、份額 | 擔保連坐 |
| 記帳 | 名冊一筆；下一次求擔保、求名額時付帳 | 越裳記陸沉「包庇」 |
| 逐出 | 逐出一片接土、一座城、一域；禁入 | |
| 死刑 | 罕見：殺一個修士，等於跟他的擔保鏈與宗門結仇 | |

- **死刑罕見**：殺不起。一個人的背後有宗門、擔保人、道侶、弟子；判死要所有簽約方都承認，否則判決變成一場仇殺。刑役讓罪人活著還帳，也讓受害的一方看得見。
- **贖**：多數刑可以贖（以份額、以人、以刑役換）。**殺開智生靈取材**與**毀庭約**兩類不贖。

## 第 5 件　接 D083：凡人告修士

- 城吏抓不動修士，所以把案子記進城裡的**修士冊**；修士冊抄給城門陣。
- 那個修士下一次進城，門陣認出他（照囊、驗名籍，D082），要他先賠才放行；不賠，記帳傳給他的宗門。
- 宗門為了面子與城約，多半替弟子賠了，再在門裡罰他。
- 凡人能得到的是**賠**，得不到**罰**。這是凡人世界的不公，也是它的秩序。

## 第 6 件　D078、D082 交下來的四件事

| 事 | 規定 |
|---|---|
| **毒師製毒受管**（D078、D081） | 毒師須在城或宗門備**毒譜**（製什麼毒、賣給誰）；賣毒須契約見證人在場；以毒殺人照殺人分類；未備譜而製毒、賣毒是重罪；黑市的毒走禁市 |
| **截聽與偷符**（D082） | 截聽他人訊樁＝盜網主之物，網主追索；偷符、冒名發碼＝**偽契**，比截聽重；冒名發令（帶令偽造）＝毀庭約 |
| **帶令者的豁免與擔保**（D082） | 合印的帶令者受簽約各方保護：**殺帶令者等於毀約**，是最重之一；帶令者的豁免只限帶令期間、只限令上的事；擔保人照連坐 |
| **自斬命牌＝叛宗**（D082） | 叛宗者除籍；帶走本門真傳、秘傳功法＝**盜傳**，宗門可追索；只帶公開層級的走，宗門不追。追不追、追多遠，依門規 |

## 第 7 件　弱者靠什麼

四樣保護，都來自強者之間的約：

1. **庇護承諾**：仙帝道場的承諾讓王庭不能任意扣人或逼投。
2. **擔保**：一個人有擔保，傷他就是傷擔保人。九弱因此拚命找擔保。
3. **記錄**：有命牌、有仙籍、有名冊，死了就有人知道（D082）；沒有的人最危險。
4. **入約**：住進有城約的城、入有盟約的宗門，就被那一層約保護。散修最不受保護，因為他什麼約都沒簽。

一句話：在三十二天，弱者被保護，是因為**有人簽過字**。
