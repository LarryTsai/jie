# 修士經濟

狀態：D058（2026-09-30）新建。只定流通物與基本規則；兌率、面額、各地物價留白，不從舊庫帶數字。

## 流通物

| 天地 | 流通物 | 說明 |
|---|---|---|
| 下界九界 | **靈石** | 修士之間的交易、報酬、賠償、租爐與陣法供能都用靈石；凡人另有自己的錢，依附修士勢力的城鎮兩者並行。留舟島坊市交易用靈石，傳送陣收靈石（見[九界與陸沉故土](../../01_天地結構/九界與陸沉故土.md)） |
| 上界（下無極、上無極、大羅） | **仙晶** | 蘊含仙力，是上界的交易物與修行資源。帶下九界時與仙器同理，不能直接運轉，必須轉作法力才能用（九界斷脈瀉力，見[境界與能力尺度](../../../04_修行/01_境界/境界與能力尺度.md)）。帶到聖土則可直接補仙力，是仙修在聖土唯一足量的自帶補給，用一顆少一顆（D065） |
| 諸神聖土 | **不流通** | 靈石、仙晶在聖土都不是貨幣；陸沉在聖土以物易物，例如拿雷紋丹換所需之物（見[雷與火](../../05_聖土/01_規則與跨界/雷與火.md)）。聖土自有的交易與錘廳拍賣屬聖土設定，見[地理勢力與撫恤](../../05_聖土/02_當代/地理勢力與撫恤.md) |

## 修士為什麼還需要錢

修士活得久、能自己取靈氣，錢仍然有用，因為真正稀缺的東西買不到也搶不起。靈氣本身是**流量有限、存量可耗**（D084，作者定（2026-10-02））：一條脈每年生多少大致是定的，靈石是脈經年沉積的存量；爭份額是爭流量，爭礦是爭存量，見[靈氣經濟學提案](../../../../歸檔/04_設定來源/三十二天/靈氣經濟學提案.md)。其餘稀缺：

- **份額**：靈脈、浮石、泉路、雷池這些地方的使用權按份額分，份額能租、能押、能換。
- **時間**：丹爐爐位、傳送陣時段、名師講法的席位。
- **別人的手藝**：煉丹、鑄器、修陣、勘脈、製符，高手的一次出手就是一筆大帳。符貴，因為製符者必須自己施得出那門術，還要預付法力與材料（D078，作者定（2026-10-02））。
- **擔保**：契書、保單、名額，本身就是可交易的東西（上下無極以契書換物，見[舊版素材移植清單](../../../../歸檔/04_設定來源/素材/舊版素材移植清單.md)生活元素）。

## 市與拍賣（D081，作者定（2026-10-02））

- **拍賣行**：三十二天常設拍賣行，特色是**契書**（成交給提貨契，憑契到封庫取物；契可轉手、抵押）、**驗寶**（上拍前行內鑑寶師出驗書，寫本質與當前兩個品階）、**保密**（委託人與買家以契號出面）。反覆出現的一家是**三印樓**（驗寶印、契印、封印），中神州天衢城總樓，大城有分樓。
- 聖土錘廳是公開叫價、制度化的另一種〔既有〕；兩界都有拍賣，味道不同。三印樓名稱作者定（2026-10-02）。
- 拍賣行是明的一層；禁市、無燈集、渡牒市、合契行是暗的或半明的一層〔既有〕。
- 職業見[職業樹提案](../../../../歸檔/04_設定來源/三十二天/職業樹提案.md)。

## 物價概數（D083，作者定（2026-10-02））

不定兌率，只立一個錨：**一塊下品靈石，約當一個凡人小戶一月的嚼用**。其餘以「幾塊下品」說，高價只說「以中品計」；票價、陣費以收入月數表示（D082）。

| 東西 | 概數 |
|---|---|
| 酒館一頓（修士） | 一塊下品吃幾頓 |
| 靈鳶一隻 | 下品一兩塊 |
| 傳訊符一對 | 化靈下品數塊；列陣以中品計 |
| 傳送陣一跳 | 下品數塊至數十塊，按被傳者承載收，境界越高越貴 |
| 爐位一日 | 下品十數塊 |
| 一至三階丹一枚 | 下品數塊至數十塊 |
| 宗門外圍一年 | 下品數十至上百塊 |
| 靈舟跨域一程（普艙） | 約一名化靈散修一兩個月的收入；快舟數倍 |
| 拍賣起價 | 以中品計 |

## 學費與入門（D080，作者定（2026-10-02））

| 路 | 誰付 | 怎麼還 |
|---|---|---|
| 宗門正式弟子 | 宗門 | 不收學費；以職事軌的任事抵（貢獻記帳） |
| 宗門外圍、私塾、書院外院 | 自己或家裡 | 靈石；一個凡人小戶要省上幾年 |
| 家族子弟 | 家族 | 全家供一個；這個人一輩子欠家裡 |
| 散修拜師 | 以勞役換 | 替師父看攤、採藥、守爐 |

宗門收人圖的是人才、人手（任事）、推薦權與份額，以及不讓對手收走。考不上的五條退路：再考、小宗門私塾、散修拜師、職業學徒、回凡。兌率照留白。

## 無核取材（D077，作者定（2026-10-02））

〔一處為主（2026-10-09 同步）：本節細則以[靈獸與妖族底盤](靈獸與妖族底盤.md)第 3 件為準，本檔下表為摘要；兩處不一致時以該檔為準。〕

三十二天的妖獸、靈獸沒有魔核（D073 補記），取材取的是部位；各部位依獵物的「相當某境」入材料四等（D073 第 9 件）：洞天至尊者為靈材，天神以上帶一則天賦者為道材。

| 部位 | 主要用途 | 保存 |
|---|---|---|
| 血 | 丹、符、血脈儀式 | 數日；封存可延 |
| 骨 | 器胚、器骨 | 數百年 |
| 皮、鱗、羽 | 甲、衣、器衣 | 久 |
| 筋、角、牙、爪 | 弦、刃、針 | 久 |
| 妖丹 | 丹的主藥 | **離體即散**：數日內入爐，否則降一等；封存只能拖慢 |
| 眼、喉、心 | 罕用；陣與器的「感」與「聲」 | 數日 |

- **開智者不取**：多數地方視取開智生靈之材為殺人取材；南荒城邦明文禁止；下無極與黑市照樣有人取（太素就站在這條線的另一邊）。
- 妖丹趁鮮，所以獵修與丹師之間有一門「幾天內送到爐邊」的生意。
- 兌率、物價照本檔留白。

## 人死債不死（D086，作者定（2026-10-02））

契債先以遺產償，不夠由擔保人承擔（連坐）；宗門份額、職位、真傳功法與宗門地上的洞府不入遺產，由宗門收回。見[死亡與繼承提案](../../../../歸檔/04_設定來源/三十二天/死亡與繼承提案.md)。

## 失去就是失去

交易出去、押掉、被沒收的東西，不因劇情方便回來；見[寶物品階與使用規則](../../../04_修行/05_寶物/品階與使用規則.md)。

## 留白

靈石與仙晶的兌率與面額（靈石品級已由 D073 定為下、中、上品，依純度與礦脈；兌率仍留白）；下界凡人貨幣；上界是否有官鑄仙晶；修士稅賦；各界物價。依[修士邏輯基準](../../../04_修行/06_基準與陣禁/修士邏輯基準.md)，未定前不補數字。
