# 死亡與繼承

狀態：作者定（D086，2026-10-02）；七題全採 A。由討論區[死亡與繼承提案](../../../../待整理/設定/06_待定與決策紀錄/死亡與繼承提案.md)抽出已裁定條文；推薦理由、比較與未採方案只留在原提案。決策條見 [D086](../../../../決策/01_決策紀錄/D086_死亡與繼承.md)。

不碰真相層。太素「無主屍骨收用」的古戰特許只引用為歷史，不展開。信仰、祖先、祭祀留給第三梯隊。命牌四態與三紋見[資訊與交通](資訊與交通.md)第 4 件。

## 第 1 件　屍骨與魂：算不算材料，挖墳合不合法

**死者照生前。** 開智者的屍骨與魂不入材料；安葬是義務，挖墳看對象。

| 對象 | 規定 |
|---|---|
| 開智者的屍骨（人、妖族、靈族） | **不入材料**；取者同殺人取材（D085 不贖之罪）。收殮只能安葬 |
| 開智者的魂、殘魂 | 不入材料；拘魂、取魂、役魂同罪。遺念可讀，不可取〔讀的紅線已由 D099 修改：殘存神魂或傳承禁制可以主動把功法、禁意、傳承給人，須對方選、有條件；被動殘影照舊只能讀。「不可取」不變〕 |
| 未開智妖獸 | 照 D077 取材 |
| 凡人的墳 | 挖者犯城約、皇朝律 |
| 修士的墳、墓穴 | 挖者是盜；墓中的器歸繼承人（第 2 件） |
| 古人的遺跡、古墓 | **器物可取，屍骨須另葬**；取器先問守者（觀古門），無守者照「先到先得、屍骨另葬」 |
| 「無主屍骨」 | **今法不承認**：沒有主的屍骨由收殮人安葬，不能收用 |

## 第 2 件　遺產：遺體、本命器、洞府、功法、債務歸誰

先分「隨身分的」與「隨人的」，再照遺念、家、師承、宗門的順序。

| 東西 | 歸誰 | 說明 |
|---|---|---|
| 宗門份額、職位、爐位 | **宗門收回** | 隨身分軌、職事軌，不入遺產 |
| 真傳、秘傳功法 | **宗門**，不入遺產 | 外傳就是盜傳（D085）；公開層級本來就人人可學 |
| 自創的功法、改本 | 本人；可傳給指定的人 | 外傳卷可賣 |
| 宗門地上的洞府 | 宗門收回 | 洞府在誰的脈上，就歸誰的份額（D084） |
| 私人洞府 | 繼承人 | |
| 本命器 | 繼承人；但**多半陪葬或交還宗門** | 換人要重建聯繫；寶器以上器靈雛形未必肯認新主；強行祭煉照升品三件的「器肯」（D078） |
| 一般法器、芥囊與囊中物 | 繼承人 | 主死印散，誰都打得開，所以芥囊先到誰手上是一場戲；法律上歸繼承人，野外常歸撿到的人 |
| 債務、契債 | **先以遺產償**；不夠由擔保人承擔（連坐） | 人死債不死 |
| 擔保責任 | 隨擔保人死而止；已發生的連坐不止 | |

### 繼承順序

1. **遺念遺囑**：生前以神念烙進玉簡、由契約見證人見證（D081）。神識烙印難竄改，所以遺念遺囑效力最高。
2. **家**：道侶、子女、家族。
3. **師承**：弟子；師父的私物可以傳弟子。
4. **宗門**：以上都沒有，歸宗門。
5. 散修什麼都沒有：誰撿到歸誰。這也是散修最不受保護的地方（D085 第 7 件）。

## 第 3 件　死亡判定

有牌看牌，無牌看人，兩條證據。

- **有命牌**：命牌散熄，命牌堂值守驗紋（散、斬、截三紋，D082），記下時刻；**一旬之後**宗門除籍、撤牌、開繼承。截熄另開查（D085），查清前不開繼承。
- **無命牌**：見屍；或兩條互不隸屬的證據指向死亡。這只是世界裡的通則，照析木常識「一案至少兩條互不隸屬的證據鏈」。
- **鑑月記的名**：渡劫淵的死者，鑑月記得是誰；她的記名可作一條證據，只證是誰，不證案情。
- **斬熄**不是死，是叛宗（D082）。

## 第 4 件　失蹤多久算死

依境界定年限，沉牌不算死。

| 情形 | 何時可立衣冠、開繼承 |
|---|---|
| 牌沉（九界之內被隔絕） | 化靈以下三年；銘紋、列陣十年；尊者以上三十年 |
| 牌沉（已知飛升、過界） | **不算失蹤**；沉牌架上照放（D082） |
| 牌暗、久不復明 | 不判死；暗是重傷或閉死關 |
| 無牌者失蹤 | 家人或擔保人申報後：凡人三年；修士照上表 |

**立衣冠**不等於除籍。人回來了，衣冠冢撤掉，身分照舊；已經開的繼承，照遺產原物還，**已經用掉的不還**。

## 第 5 件　奪舍：法律上還是不是同一個人

**法律看神魂。** 命牌牽的是神魂，法律跟著命牌走。

- **奪舍＝殺人**：原主的神魂散了（命牌散熄），原主法律上已死。奪舍者是殺原主的人，照殺開智者論，**不贖**（D085）。
- 奪舍者**不繼承原主**的任何東西：身分、份額、財產、婚約、擔保都不隨肉身轉移。
- **神魂切分**（左卿、右卿一類）：法律上兩人都**不是原主**；原主已死，兩人各是新人。
- **成器**（接上別人的部分，D068）：神魂沒換，還是本人；被取的那一方是受害人。

## 第 6 件　喪葬實務

散靈、歸土、記名三步。

| 步 | 做什麼 | 誰做 |
|---|---|---|
| **散靈** | 以陣或法力化去遺體裡殘存的修為，免得長成煞靈；境界越高越費事，天神以上要宗門出陣 | 收殮人（D081）、宗門 |
| **歸土** | 散靈之後土葬、海葬或焚化；修為散回天地，稱**歸氣**（延伸「仙死歸土」，是 D084 循環的回收口） | 家人、宗門 |
| **記名** | 宗門撤牌、記簿；家族入譜；無牌者由收殮人記名（渡劫淵有鑑月） | 命牌堂、譜師（D081）、收殮人 |

- **坐化**：壽終的修士多半自知，閉門坐化，修為自己散回天地，不留殘力。這是最體面的死法。
- **衣冠冢**：牌沉多年、屍骨找不到的，立衣冠（第 4 件）。
- **戰場、災地**：沒人散靈的屍骨一多，就成煞地；古戰的煞靈由此而來。
- **收殮的兩面**：正派收殮人散靈安葬；太素收殮堂外表一模一樣（免費、仙鶴、白衣），差別只在取痕（D068）。

## 第 7 件　「什麼叫活著」：給生一個落腳處，不替她回答

只列法律與生道分岔的五個案，不給答案。答案留在生的場面裡。

| 案 | 法律怎麼說 | 生會看見什麼 |
|---|---|---|
| 成器（接了別人的部分） | 還是本人；被取者是受害人 | 這個人活得好好的，身上有別人 |
| 神魂切分（左卿、右卿） | 兩人都不是原主 | 兩個人都在活，都以為自己是他 |
| 奪舍 | 原主已死，奪舍者是殺人者 | 那具身體裡的人在吃飯、在笑 |
| 還形（以他人生機讓死者還形；第 20 篇祿安的提議） | 用了他人生機，是取材 | 師父的樣子回來了，代價是一批九弱 |
| 道傷不復原、修為散盡的人 | 還活著，還是本人 | 救活了，能不能繼續生活 |

檀翁補寫的「在於他每一次是否還做同一種選擇」，是一種回答，不是書的回答。五個案可作碧梧的考題素材。
