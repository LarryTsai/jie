# 靈氣經濟學

狀態：作者定（D084，2026-10-02）；六題全採 A，含第 2 題「天地加生靈」。由討論區[靈氣經濟學提案](../../../../歸檔/04_設定來源/三十二天/靈氣經濟學提案.md)抽出已裁定條文；推薦理由、比較與未採方案只留在原提案。決策條見 [D084](../../../../決策/01_決策紀錄/D084_靈氣經濟學.md)。

數字是工作值，正文只寫概數。**不碰真相層**：生氣機制只說明同歸會的統計算錯在哪，不揭露、不改古戰、封界與校正的任何真相。

## 第 1 件　靈氣是不是有限資源

**流量有限、存量可耗。** 一句話：天地生氣，脈運氣，陣聚氣，石存氣，人用氣。

| 字 | 是什麼 | 例 |
|---|---|---|
| **生** | 天地生氣：日月、地火、水、草木與生靈，每年在一片天地裡生出一定的氣 | 九界是戰後最繁衍的地方 |
| **運** | 靈脈是運氣的路，也是蓄氣的庫；脈有主脈、支脈、脈眼 | 留舟島祖脈與支脈 |
| **聚** | 陣把氣聚到一處（護山大陣、聚靈陣、靈田陣） | 護島大陣 |
| **存** | 靈石是脈經年沉積的結晶，是存量；挖礦等於提前取用一條脈千百年的積蓄 | 靈石依純度與礦脈分品（D073） |
| **用** | 修士吐納、煉丹、煉器、布陣、催符，都在用氣；妖獸也在吸 | 無核取材（D077） |

- **流量有限**：一片天地每年生多少，大致是定的。抽得比生得快，脈就衰。
- **存量可耗**：靈石挖一塊少一塊；礦脈挖空，那一段脈也跟著乾。
- **可以修、可以養**：脈斷了能補，但補的是路，不是氣。養脈要停抽、要等。

爭份額是爭流量，爭礦是爭存量，求太玄閣是求一條修得好的路。

## 第 2 件　天地生氣從哪裡來

**天地生氣有二源**：天地本身（日月、地火、水、草木），加上生靈。生靈越多越雜，生得越多。

- 九界的繁衍會自我加強：族群、文明、生靈越多，生的氣越多，越養得起更多人。
- 中間層衰的是碎土重接、生靈少、抽得多的那幾片接土。
- 同歸會漏掉九界的繁衍，就算成「整個無極在衰」。荀恆推演盤算進九界繁衍，就算出整個無極沒有在衰。

## 第 3 件　循環：靈脈怎麼帶動一切

### 主循環

```
靈脈 → 宗門佔脈、開洞府 → 依附城鎮在脈旁長出 → 靈田接支脈 → 人口增加
   ↑                                                           ↓
 養脈、修脈                                       修士變多、境界變高
   ↑                                                           ↓
脈衰 ← ← ← ← ← ← ← 抽得比生得快 ← ← ← ← ← ← ← 吐納、煉丹、布陣、挖礦
```

### 四個調節閥

| 閥 | 誰握著 | 做什麼 |
|---|---|---|
| 份額 | 握脈的宗門或王庭 | 決定誰能抽多少 |
| 修脈 | 勘脈師（太玄閣） | 補路，讓氣流得回來；不生氣 |
| 陣 | 陣師 | 聚氣到一處，旁邊就薄 |
| 礦 | 礦師與握礦的人 | 提前取用存量 |

### 三種出口

脈衰之後，社會這樣反應：

1. **遷徙**：人往有氣的地方走。妖獸也走，所以脈衰常伴著獸潮（獸潮另論，D077）。
2. **戰爭**：搶脈、搶份額。地裂後支脈靈氣重分，就是一次小型的流量重分。
3. **開荒**：找新脈、開新田、修舊脈。遺跡隊、勘脈師的生意由此而來。

**浮石季**是祖脈一年一次的流量高峰，浮石是被靈潮推上來的存量。

太玄閣補的是路不是氣，所以祖脈出事時三宗都得求它，卻又不怕它。

## 第 4 件　高手是不是耗能大戶

吐納量隨境界陡增，閉關數倍，帝境自足。

| 境 | 吐納量（相當幾個化靈） |
|---|---|
| 搬血 | 零點三 |
| 洞天 | 零點五 |
| 化靈 | 一 |
| 銘紋 | 三 |
| 列陣 | 十 |
| 尊者 | 三十 |
| 神火至真一 | 百 |
| 天神 | 三百 |
| 虛道 | 千 |
| 帝境 | 自成天地，不向天地取（D065） |

- **人均高手大，總量中層大**：以 D079 人數帶乘上表，長亭天全界的用量裡，銘紋與列陣兩層合計約佔四成，天神以上不到一成。
- **閉關**：突破時吐納數倍。一位天神閉關，方圓數十里的靈田會減產。所以宗門的閉關要報、要在脈眼上、要離城。
- **入城收斂**：高手進城收斂吐納，是禮。不收斂，旁人的打坐會「被搶氣」，這也是一種挑釁。

### 仙人居洞天、凡人居城

1. 高手人均吐納大，要住在**脈眼**上才夠；脈眼多在山裡、洞府裡。
2. 高手住城裡會搶走鄰居的氣，凡人的靈田、低境的打坐都受影響；住城外是一種體面。
3. 城要人多，人多的地方生氣也多，城本身就是一塊靈田；高手不住城，城才養得起。
4. 上界接縫城例外：全城修士，好的地段按道脈分（D083）。

## 第 5 件　九界與上界的差

同一張循環圖，不同的燃料與稀缺。

| | 九界 | 下無極 | 上無極 |
|---|---|---|---|
| 燃料 | 法力、靈氣；靈石 | 仙力、仙氣；仙晶 | 同左，濃 |
| 生氣 | 最旺（生靈最多最雜） | 碎土重接，片片不同；有幾片在衰 | 穩 |
| 稀缺的是 | 好的支脈、爐位、份額 | 名額、契書、好地段 | 道域與道脈 |
| 同一個天神 | 一域高層（全界約百人） | 主體之一，排隊的人 | 不起眼 |

九界飛升者被註「九弱」，在這張表上的意思是：從「生氣最旺、自己是高層」的地方，落到「仙氣排隊、自己是主體」的地方。天地補給不相容照 D065，本檔不改補給率。

## 第 6 件　靈石、仙晶與妖獸：三種存量

- **靈石**：靈脈經年沉積的結晶，品級看沉積的年代與純度。挖礦等於提前取用一條脈的積蓄；礦盡則那一段脈乾。
- **仙晶**：上界道脈沉積的結晶，同理。帶下九界不能直接運轉（D065、[修士經濟](修士經濟.md)）。
- **妖獸**：吸了一輩子靈氣的活存量。獵獸取材是從另一個方向取用天地的氣（D077）。脈衰時妖獸先走，獸潮常是脈衰的前兆。

礦工挖存量，獵修取活存量，靈農用流量，三種人站在同一條循環上。

修士死後修為散回天地，稱歸氣，是這條循環的回收口，見[死亡與繼承](死亡與繼承.md)第 6 件（D086）。
