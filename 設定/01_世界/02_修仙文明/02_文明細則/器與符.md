# 器與符

狀態：作者定（[D078](../../../../決策/01_決策紀錄/D078_器與符.md)，2026-10-02）；十一題全部照推薦。帝器材料、涵月水鏡品階、程燁三鼎、符的確切存期數字與聖土的器與符仍留白，見檔尾。由討論區[器與符提案](../../../../待整理/設定/06_待定與決策紀錄/器與符提案.md)抽出已裁定條文；推薦理由、比較與未採方案只留在原提案。

標記：〔既有〕＝D078 之前的現行設定；〔Dxxx 補〕＝後續決策的補充；〔角色校驗推論〕＝原提案角色校驗推得、未單獨拍板。

**一處為主**：D078 十一題的細則以本檔為準。摘要散見[品階與使用規則](../../../04_修行/05_寶物/品階與使用規則.md)（煉成；修、改、重鑄；升品三件；九界修不了仙紋）、[修行與技藝](../01_底層規格/02_修行與技藝.md)第 5、8、11 節、[機構與跨界交通](../../01_天地結構/機構與跨界交通.md)（傳訊符與靈鳶）、[陣法與禁制](../../../04_修行/06_基準與陣禁/陣法與禁制.md)第一節（符）；各處與本檔不一致時以本檔為準。

**照舊不動**：法寶六品、本質／當前雙標示、殘器、封印器、降階器、常見主人境界（D073，見[品階與使用規則](../../../04_修行/05_寶物/品階與使用規則.md)）；材料承力四等與法寶六品不一一對應（D073）；無核取材（D077）；失去就是失去，儲物器不是後門（D058）；陣與禁的分工、禁的「寫」有境界門檻（D073）；傳訊通則：遠距要節點、只傳短碼、可截聽（D058）；主角群的器只給位置，不新增招式（D074）。

# 上編　煉器

## 第 1 件　煉器流程與品階上限

**四步**：

| 步 | 做什麼 | 決定什麼 |
|---|---|---|
| 擇材 | 依材料四等選材，看藥齡、產地、相衝 | 材的上限 |
| 熔胚 | 以地火、獸火、靈火或雷熔材成胚 | 器身是否勻、有無暗傷 |
| 刻紋 | 以神識與法力在胚上刻器紋（器上的陣與禁） | 紋的上限 |
| 孕靈 | 寶器以上：長期溫養，讓器靈雛形自己長出來；道器要讓器紋結合一則 | 靈的上限 |

**三限**：品階上限取材、紋、靈三者中最低的一樣。

| 品 | 材至少 | 煉成的最低境界（器師） | 孕靈 |
|---|---|---|---|
| 法器 | 凡材上品或靈材 | 化靈 | 不需 |
| 靈器 | 靈材 | 列陣 | 不需 |
| 寶器 | 上品靈材或道材 | 尊者 | 器靈雛形，長期溫養 |
| 道器 | 道材 | 虛道 | 器紋結合一則 |
| 仙器 | 仙材 | 真仙 | 以仙力、仙道紋理養 |
| 帝器 | 留白 | 仙帝 | 與仙帝之道相連〔既有〕 |

- **器紋**是寫在器上的陣與禁：陣負責承力運轉，禁負責誰能用、怎麼觸發。
- **器靈雛形是養出來的**，寶器以上不會一爐出爐即滿品。
- **借爐**：在山門陣級的地火大爐、借陣之力，可以越一級煉，但器紋不穩，多為下品；與禁「寫高於自身境界的禁只能借陣」同理〔既有通則〕。
- 「煉成的最低境界」是器師的境界，不是器主的；常見主人境界照 D073 不動。
- 長亭天當代虛道寥寥，九界合計約十〔既有，D060〕；九界幾乎煉不出新道器，九界的道器多是古物。〔勘誤：原提案角色校驗作「九界當代虛道只三人」，三人是長亭天一界的舊提案數，九界約十人以 D060 為準。〕

## 第 2 件　養器與本命器的祭煉

**升品三件，缺一不可**：

1. 主人過質變點，或至少到該品常見主人的境界。
2. 補入更高一等的材料。
3. 寶器以上，器靈雛形同意；不同意就升不上去，強升會裂。

- 本命器不隨主人破境自動升品。每一次升品都是一次補材、一次擴紋、一次器肯不肯。
- 成套本命器要整套一起補材升品（由升品三件直接推得；原出自赤鼎宗角色校驗）。
- 〔D086 補：本命器主人死後歸繼承人，但多半陪葬或交還宗門；寶器以上器靈雛形未必肯認新主，新主強行祭煉照升品三件的「器肯」。見[死亡與繼承](../../../../決策/01_決策紀錄/D086_死亡與繼承.md)。〕

## 第 3 件　修器、改器、重鑄

| 做法 | 是什麼 | 本質品階 | 器靈雛形 | 是不是原物 |
|---|---|---|---|---|
| 修 | 器身、器紋局部受損，以同源材料補、照原紋接 | 不變 | 保住 | 是；補多了漸不是 |
| 改 | 改一道或數道器紋，換一種用法 | 不變 | 保住，但會「不認」改過的那一段 | 是，用法變了 |
| 重鑄 | 器毀之後熔回重煉 | 從低一品起算 | 散去，不回 | 不是 |

- 改器每改一次，器壽減一分（與歐冶〈點化〉一致〔既有〕）。
- 重鑄的器，器紋可照舊譜刻回，器靈要重新養；舊器主人的印記不在了。
- 判準：器靈雛形在就是原物，靈散就不是。
- 改紋不升品。

## 第 4 件　器師能力項

六項，各分生、熟、精：

| 項 | 看什麼 |
|---|---|
| 辨材 | 認材、知等、識假、知相衝 |
| 控火 | 熔胚的火候（地火、獸火、靈火、雷） |
| 刻紋 | 器紋的精度與承力 |
| 孕靈 | 溫養器靈雛形、讓紋結合一則 |
| 修補 | 修器與接回原紋 |
| 改器 | 改紋換用法（歐冶〈點化〉在這一項上是精） |

稱號：「X 器師」只認穩定煉得出的品，例「靈器師」「寶器師」；偶成不算（與丹師同理）。

## 第 5 件　九界與上界的器：互修限制

- 九界器師修得了上界器的器身與法力層的器紋。
- **仙紋要以仙力刻**，九界修不了；壓境下來的上界器師也修不了（只有列陣之力）。仙器的仙紋損了，只能帶上界修。
- 聖土的器另論，兩界不互用，由聖土一側定。

# 下編　符籙

## 第 7 件　符是什麼：品階與製符

- **符**：把一道術（或一段陣、一條禁）事先封在承載物上，灌足法力；觸發即放，放完即失。陣承載運轉、禁寫規則，兩者是持續的；符是事先封存、一次放完的。
- **標法**：以所封之術的最低施術境界標。「列陣符」＝封著一門最低列陣才施得出的術。另以下、中、上品標成色（封得穩不穩、洩不洩）。
- **製符三要素**：
  - **符材**：紙、絹、玉片、骨片、獸皮。材的等決定承得住幾境的符：凡材至化靈、靈材至尊者、道材至天神以上。
  - **符墨**：靈墨，或妖血入墨。墨決定存期。
  - **封術**：製符者必須自己施得出那門術，才封得進去；境界不到，只能借陣（同禁的通則）。
- **存期**：符墨會散。紙符數月到數年，玉符、骨符更久；過期的符不是失效就是走樣。
- **用符**：任何人都能觸發。低境用高境符，傷不到自己，但控不了方向，放出去就是放出去。
- 符貴，因為製符者必須自己施得出那門術，還要預付法力與材料。
- 符牒（天符門替接引處印〔既有〕）是封著一條行禁的符，屬禁符〔角色校驗推論〕。

## 第 8 件　一次性符與符器

| | 符 | 符器 |
|---|---|---|
| 是什麼 | 一次性，封一道術 | 符形的法器：承載物上刻了器紋，可以反覆灌力、反覆用 |
| 品階 | 依所封之術的境界（第 7 件） | 依法寶六品（第 1 件三限） |
| 用完 | 即失 | 器紋在就還能用；壞了照第 3 件修、改、重鑄 |
| 例 | 傳訊符、尊者符 | 紙燕、符紙靈鳶 |

## 第 9 件　傳訊符、紙燕與靈鳶

| | 傳訊符 | 符紙靈鳶（紙燕） |
|---|---|---|
| 類別 | 符（一次性） | 符器（可反覆用） |
| 配對 | 一對符，事先配好；只能傳給另一張 | 事先記住一處或一人的神識印記 |
| 傳什麼 | 短碼（D058） | 短碼；可帶一件極輕的小物 |
| 距離 | 依符的境界：工作值化靈數里、列陣百里、天神千里；正文只寫概數 | 依灌入的法力與天候，慢 |
| 快慢 | 觸發即到 | 要飛，風雨會遲 |
| 價 | 貴：每用一次燒一對符 | 便宜：坊市攤上就有，壞了修 |
| 截聽 | 可，反查得到配對的另一張 | 可，打下來就讀得到 |

- 〔D082 補：傳訊符距離插值，銘紋數十里、尊者數百里。〕
- 經節點轉傳的符可以更遠，但節點會記錄（D058 的截聽與反查照舊）。
- 跨界傳訊本件不碰。〔已由 D082 定：跨界走人；共天作九界一年一月的全文通道。〕
- 賣靈鳶、修紙鳶是修器（第 3 件「修」），不是畫符。

## 第 10 件　符師能力項

六項，各分生、熟、精：

| 項 | 看什麼 |
|---|---|
| 辨材 | 符材與符墨的等、存期、識假 |
| 調墨 | 調靈墨、入血墨 |
| 落筆 | 一筆成符的精度；斷筆即廢 |
| 封術 | 把術封進去不洩；成色（下中上品）看這一項 |
| 驗符 | 判真偽、判存期、判有沒有被改過 |
| 改符 | 改一張符的觸發或方向 |

稱號：「X 境符師」只認穩定製得出的境界，例「列陣符師」；偶成不算。
