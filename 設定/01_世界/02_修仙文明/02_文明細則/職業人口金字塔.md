# 職業人口金字塔

狀態：作者定（[D079](../../../../決策/01_決策紀錄/D079_職業人口金字塔.md)，2026-10-02）；七題全部照推薦。上界凡人、其他八界人數帶、各人數值仍留白，見檔尾。由討論區[職業人口金字塔提案](../../../../待整理/設定/06_待定與決策紀錄/職業人口金字塔提案.md)抽出已裁定條文；推薦理由、比較與未採方案只留在原提案。

**數字一律是工作值**：給作者與寫手對量級用，正文只寫概數（「數百」「上萬」）。

**照舊不動**：強者人數表（[三十二天勢力總表](../../04_勢力/三十二天勢力總表.md)，D060）；各層勢力家數與規模口徑；上界通行資格（未滿二十歲、尊者以上）；各職業的能力項、稱號與境界門檻（D073、D077、D078）。

## 第 1 件　一界各境人數帶（長亭天樣本）

兩道斷崖，落在尊者與天神。

| 境 | 長亭天約 | 說明 |
|---|---|---|
| 虛道 | 3 | 〔既有〕 |
| 天神 | 約 100 | 九界約 400 的四分之一；各大宗之主與長老 |
| 神火至真一 | 約 400 | 天神之下的高層 |
| 尊者 | 約 800 | 一方頂尖；九界約 5,000 的一成半 |
| 列陣 | 約 2 萬 | 第一道斷崖之下：一宗長老、分部主事多在此 |
| 銘紋 | 約 6 萬 | 執事、坊市管事、熟練的職業者 |
| 化靈 | 約 15 萬 | 宗門正式弟子的主體 |
| 洞天 | 約 30 萬 | 入宗門檻 |
| 搬血 | 約 50 萬 | 剛起步，多數一生停在這裡 |
| **合計** | **約百萬** | 正式宗門弟子、世家族人、散修合計 |

- 往下大約每一境兩到三倍；尊者到列陣是二十五倍上下的斷崖，天神到尊者是八倍上下。
- 長亭天高層佔九界的一成半到四分之一；其他八界分得少。
- 坊市裡一抬頭看見的人，多半是洞天、化靈。
- 年輕一代的天驕集中在列陣到尊者之間；一屆大比的前列就是一界的未來頂層。

## 第 2 件　各職業人數帶（長亭天樣本）

門檻壓頂，約一成修士有一門職業到穩的程度；只認穩階，「穩階」以下會一點的人不計入。每一品的人數不會多於那一境的人數。

| 職業 | 低品（約） | 中品（約） | 高品（約） | 頂（約） |
|---|---|---|---|---|
| 丹師 | 一至三階：1 萬 | 四至六階：1,000 | 七階以上（會引丹劫）：50 | 九階：個位數 |
| 器師 | 法器師：8,000 | 靈器師：800 | 寶器師：30 | 道器：0（虛道三人皆非器師） |
| 陣師 | 盤陣、院陣：數千 | 主持山門陣：約百 | 山河陣：只在皇朝與頂級宗門合力 | 界陣：守界傳承 |
| 禁制師 | 寫行禁：數千 | 寫力禁：數百 | 寫空禁：數十 | 則禁：0 至 3 |
| 符師 | 化靈、銘紋符師：數千 | 列陣符師：數百 | 尊者符師：數十 | 天神符師：個位數 |
| 御獸師 | 數千（西極、南荒多） | — | — | — |
| 醫修 | 接骨：數千 | 續脈：數百 | 合魂：個位數至十數 | — |
| 勘脈師 | 院級：數百 | 山門級：數十 | 山河級：個位數 | 界級：太玄閣與扃天閣 |

- 一個二流丹師（四至六階）在東溟算「少，但找得到」：一域不過兩三百人，大宗、大城才有。

## 第 3 件　凡人與依附城鎮

- 一界修士約百萬、凡人數億，平均約一比三百。
- 地域差很大：宗門所在、修仙島（留舟島一類）修士密，約一比十；凡人皇朝腹地疏，可到一比數千。
- 頂級宗門的依附人口數十萬〔既有〕，十五家頂級合計數百萬；其餘凡人住在皇朝、城國、古國。

## 第 4 件　上界的對應

飛升為主、本地為輔。

- 九界合計每年飛升約百人（大比之年多）；長亭天約佔一成半。
- 上下無極尊者以上約數十萬〔既有〕，其中九界飛升者約七成。
- 上界本地出生、尚未到尊者的修士約數十萬，多在王庭與世家。
- 上界凡人：留白。

## 第 6 件　醫修能力項

醫與丹分開：丹師的「臨床」只看服丹的人；醫修要診、要接、要護，還要管救活之後。六項，各分生、熟、精：

| 項 | 看什麼 |
|---|---|
| 診 | 以神識讀傷：斷處、接縫、錯位、毒與煞 |
| 接 | 接骨、續脈、合魂；層次見下 |
| 排 | 排丹毒、煞氣、異力 |
| 護 | 守住傷者的一口氣與神魂，撐到能治（守息一類） |
| 養 | 救活之後能否繼續生活：復元、調養、長期照看（碧梧所長） |
| 量 | 判斷救不救得回、救回要付什麼、要不要放手 |

稱號以接得到哪一層：**接骨醫**（形）、**續脈醫**（脈）、**合魂醫**（魂），只認穩定做得到的那一層。正派醫修只在病人自己身上接；太素把形、脈、魂三層推到別人身上取材。

「續脈」在此是醫修的層次名，不是太玄〈續脈手〉的招式名。

## 第 7 件　勘脈能力項

六項，各分生、熟、精：

| 項 | 看什麼 |
|---|---|
| 聽 | 以神識聽脈：流向、強弱 |
| 測 | 量脈的流量與偏移；用陣樁、測脈陣 |
| 記 | 抄錄、比對歷代脈簿（修脈簿） |
| 斷 | 判斷斷處、異動、將裂之處 |
| 補 | 修補祖脈（太玄閣所長） |
| 引 | 改道、借脈、縫脈（玄闕借脈、綴錦補縫屬此） |

稱號：**院級、山門級、山河級、界級**勘脈師，與陣的規模分級對齊（D073）；只認穩定勘得了的範圍。

## 主角群職業位置（第 7 題）

- **生**（洛生衣）：續脈醫；養、量精，接熟。
- **劫**（陸沉）勘脈：聽、斷精，記熟。
