# 修仙文明底層規格：宗門與人口（第 11–16 節）

狀態：作者定（D073，2026-10-02）的規格目錄與缺口盤點；各節「現況」標已定、部分或缺，各條依所標 D 號（同 [README](README.md)）。

> 檔頭狀態與圖例見[總則與能力檢查條](01_總則與能力檢查條.md)。

## 11　職業者能力量尺

**要定的**：丹、器、陣、禁、符、醫、勘脈、御獸等職業者的能力，不只看境界。

**現況：部分（D073 定丹師、陣師、禁制師）。**

已定：三種職業共用一個格式：對外稱號簡單，能力拆成數項，各分**生、熟、精**。
- **丹師**：稱號只認穩階（「X 階丹師」＝穩定煉得出 X 階常見丹方，偶成不算）；六項：控火、辨材、成色、改方、驗丹、臨床（[煉丹閣任事制度](../../../04_修行/04_丹道/煉丹閣任事制度.md)）。
- **陣師**：布、守、改、破、創（[陣法與禁制](../../../04_修行/06_基準與陣禁/陣法與禁制.md)第九節）。
- **禁制師**：讀、寫、守、騙、解、改（同上第十節）。
- **熟手職業**（D081，作者定（2026-10-02））：十職以外的三十種職業（採藥人、礦師、舟師、鑑寶師、拍賣師、毒師、譜師、測算師、契約見證人、遺跡隊等）不立能力卡，只分熟手與生手；十一大類見[職業樹](../02_文明細則/職業樹.md)。
- **醫修**（D079，作者定（2026-10-02））：診、接、排、護、養、量；稱號以接得到哪一層：接骨醫（形）、續脈醫（脈）、合魂醫（魂）。
- **勘脈師**（D079，作者定（2026-10-02））：聽、測、記、斷、補、引；稱號依能勘的規模：院級、山門級、山河級、界級（與陣的五級對齊）。
- **器師**（D078，作者定（2026-10-02））：辨材、控火、刻紋、孕靈、修補、改器；稱號只認穩品（「靈器師」「寶器師」）。
- **符師**（D078，作者定（2026-10-02））：辨材、調墨、落筆、封術、驗符、改符；稱號只認穩境（「列陣符師」）。
- **御獸師**（D077，作者定（2026-10-02））：辨（辨相當何境、辨是否開智）、養（照料與馴養未開智者）、約（寫獸約與解約）、治（獸傷與獸病）、並（與結伴或立約者共戰）。
- 陸沉陣法定位四檔（專精／扎實／只懂需要的／能協助但不是最強）照舊。

缺：各人數值。

**影響**：所有「找誰修陣、找誰驗丹、找誰勘脈」的場面；[仙人視角守則](../../../00_故事定位/01_寫作規則/仙人視角守則.md)「不讓陸沉成為唯一解」需要每個同伴的專業有可比的尺。

## 12　宗門規模

**要定的**：宗門分級、人數、地盤、坐鎮者。

**現況：已定（D073）。**見[三十二天勢力總表](../../04_勢力/三十二天勢力總表.md)。

- **坐鎮分級（D060，照舊）**：上界頂級＝準仙帝以上、一流＝仙王、二流＝真仙、地方＝至尊以下；九界頂級＝虛道或天神坐鎮的一界之首、二流＝列陣、地方＝其下。
- **九界一流口徑補齊（D073）**：**尊者至天神坐鎮、非一域之首**（消掉三書院院長為天神卻列一流的不齊）。
- **規模三檔（D073）**：大、中、小。九界以正式弟子數計：大三千以上（另有依附家族與城鎮數十萬人）、中五百至三千、小五百以下。標法「一流・小」「頂級・大」。上界規模留白；世家口徑另定。

仍留白：六域頂級勢力表逐家補大、中、小（下一輪）；依附人口與地盤級距。

## 13　宗門組織

**要定的**：標準組織模板：宗主、太上、長老、峰（殿）、執事、傳功、戒律、庫藏、外務。

**現況：已定（通用模板，D073）；細節部分。**

**通用組織模板**（各宗依此長出自己的名目）：

| 部分 | 職掌 |
|---|---|
| 宗主 | 對外代表、終裁 |
| 太上 | 閉關、不理事，宗門存亡時出手（可無） |
| 峰主或殿主會 | 議事 |
| 宗務 | 庫藏、外務、戒律、任事分派 |
| 傳功 | 共同教習 |
| 通用閣 | 丹、器、藏書 |
| 藏地 | 命藏一類，傳承重地 |
| 分部 | 閣、院，負責收人與推薦 |

太玄宗：主峰＋七傳承峰、主峰通用閣（煉丹閣、公共器坊、藏書）、守藏人；宗主杭既白每年親主一次終試；太上留白。見[太玄宗](../../03_故土六域/01_太玄宗/README.md)、[宗主與峰主提案](../../../03_人物/02_太玄宗/宗主與峰主.md)。

仍留白：宗主更替；各宗宗務由誰掌。

**影響**：第 13 篇杭既白壓下生的發現，走的是哪一級的權；擔保（玄殿碧梧一系被記過）在宗門內落到誰頭上。

## 14　弟子階級與培養

**要定的**：弟子階級、資源配給、師承、貢獻。

**現況：已定（兩軌制，D073）。**

- **身分軌**（師承）與**職事軌**（替宗門做什麼）分開，互不綁定。真傳不一定任事，執事不一定是真傳。
- **階級名稱各宗自訂**，底盤統一的是結構。三大宗可用外門、內門。
- **太玄宗**：身分軌＝閣生 → 入宗弟子 → 峰弟子 → 真傳；職事軌＝任事弟子 → 執事 → 教習 → 長老、閣主、峰主。宗內十人、入命藏是榮譽與資格，不是階級。見[太玄宗](../../03_故土六域/01_太玄宗/README.md)。
- **貢獻**：宗內記帳，來自任事、交丹、修器、修脈；換爐位、份額、藏書、講席、丹藥；不能帶出宗門。
- 外部：四大書院約三年、四院大比、九界大比每五年（[下界成長與相識順序](../../../../大綱/00_全書骨架/下界成長與相識順序.md)）。

仍留白：每月配給；師徒義務細則。

## 15　職業人口金字塔

**要定的**：一界之中，各境界、各職業各有多少人。

**現況：已定（D079，作者定（2026-10-02））。**數字一律是工作值，正文只寫概數。見[職業人口金字塔](../02_文明細則/職業人口金字塔.md)。

- **一界各境人數帶（長亭天樣本，約百萬修士）**：搬血約 50 萬、洞天約 30 萬、化靈約 15 萬、銘紋約 6 萬、列陣約 2 萬、尊者約 800、神火至真一約 400、天神約 100、虛道 3。兩道斷崖：尊者（上界通行線、一方頂尖）與天神（高層）。
- **各職業人數帶**：門檻壓頂，約一成修士成師（只認穩階）。例：一至三階丹師約一萬、四至六階約一千、七階以上約五十；器師法器師約八千、靈器師約八百、寶器師約三十、道器 0；寫空禁者數十、則禁 0 至 3；山河級勘脈師個位數。
- **凡人**：一界修士約百萬、凡人數億，平均約一比三百；修仙島約一比十，凡人皇朝腹地可到一比數千。
- **上界**：九界合計每年飛升約百人；上下無極尊者以上約七成是九界飛升者；上界本地出生、尊者以下約數十萬；上界凡人留白。

**影響**：坊市裡誰在擺攤、誰在排傳送陣；一個二流丹師在東溟算稀有還是常見；第 4 篇共享火院「爭爐位」的緊張感要有供需。

## 16　宗門家底卡

**要定的**：每個宗門一張卡，在同一把尺上比家底。

**現況：已定（格式；太玄宗拍板項，D073）。**太玄宗提案版全卡見[底層規格第一輪提案](../../../../歸檔/01_歷史資料/設定歷史/20261008/06_待定與決策紀錄/底層規格第一輪提案.md)第 12 件；拍板項已寫入[太玄宗](../../03_故土六域/01_太玄宗/README.md)「家底」：

- **一流・小**，正式弟子五百以下。
- **鎮宗之物**是命藏裡的無星古圖原件，一張空圖；宗門沒有能打的鎮宗兵器，家底在手藝（修補祖脈、把互斥的東西排在一起）。
- **太玄八峰在玄殿各有上游一系**。
- **太上留白。**

**卡片格式**：

| 欄 | 寫什麼 |
|---|---|
| 一、定位 | 所在、上游與隸屬、一句話特色（「通常特別擅長什麼」） |
| 二、等級與規模 | 分級（第 12 節）、正式弟子數、依附人口、地盤 |
| 三、戰力結構 | 坐鎮者、各境界人數帶、對外可出戰者 |
| 四、傳承 | 根本功法、各脈真傳、秘術、傳承載體（藏經、命藏、口傳） |
| 五、法寶家底 | 鎮宗之物、護山大陣（規模與承境）、器庫；寫「本質品階／當前可用」 |
| 六、資源 | 靈脈、份額、藥圃、礦、秘境與禁地 |
| 七、產業與財政 | 收入來源、主要開銷、可交易的手藝 |
| 八、人才管道 | 收人、培養、外送（百宗、書院、上界） |
| 九、外交 | 上游、盟友、對手、欠誰、誰欠它 |
| 十、歷代經驗 | 宗訓、吃過的虧、傳下來的規矩 |
| 十一、弱點 | 被卡住的地方 |
| 十二、劇情鉤 | 篇位、人物 |
| 留白 | 未定項 |
