# 聖土量級與兩界對等

## 八、對照鬥破的量級說明

作者要求拿《鬥破蒼穹》的勢力與人物量級對照聖土。數目不必一樣，但要看得出是一個大世界。本節是**對照說明**：原作專名只在本節出現，作為口徑參照，**不得進入本作任何設定、行文或命名**。原作的數字是憑對原作的整體印象給出的約數，口徑一律採「正文具名、有戲份或有明確地位者」；只出現在名單上的不算。

### 三條折算理由（後面各層共用）

- **受創、無帝的天地**：聖土八萬年前受創，封合縫至今未合，成帝就等於拆封，所以當代沒有鬥帝。柯涅斯是受創之盆，在世鬥聖只有六位；全聖土約六百五十位（第十節，D063）。**塔頂窄只指沒有帝，不指鬥聖少。**
- **一盆只是諸洲之一**：柯涅斯只是聖土約一百五十盆中的一盆，外洲見[當代地理：諸洲](../02_當代/當代地理_諸洲.md)。以下判斷仍適用於柯涅斯一盆之內：**中層不能少**。中層指的是一城、一宗、一行當之主，否則中心五國會顯得空，邊地會像只有幾家大戶。
- **篇幅配比**：聖土篇是全書的一段，不是整部書。原作任一大地域篇（例如中州篇）新登場的具名人物約兩三百。本作聖土篇具名人物以兩百出頭為目標，換算下來量級相當；再多就寫不完，也記不住。

### （三）不對等處與理由

1. **帝：0 對 3。**成帝即拆封（D052），聖土不能有帝。平衡的方式不是造一個帝，而是以下五件事同時成立：
   - **觸帝者四人**：走到帝前最後一步、自己停下或被拒的鬥聖巔峰。聖土的「準仙帝」一層因此與三十二天持平而略多（16 對 15）。撐得起這個數目的理由是**天花板封住了，塔尖會積人**：有帝的年代，走到頂的人要嘛成帝、要嘛死在那一步；八萬年沒有帝，到頂的人只能停在那裡。八萬年間到過這一步的約有數十人，多半老死在帝前，今日在世四人。
   - **帝天**：末代鬥帝的帝天仍卡在封合縫。它不是戰力，卻是帝級的事實：封口由兩端的帝各封一端，重開仍需兩側共同立錨（古戰與兩界衝突）。在門口，聖土一側仍有帝的分量。
   - **仙帝一側打折**：太宸停滯、未濟閉關、抱一只看內側（歸一）。仙帝到聖土拿不到任何好處，也沒有動機（境界對照與跨界「八萬年來強者為何沒有大舉往來」）。
   - **九階獸王約四十頭**，其中二三頭約當鬥聖後期至巔峰，都不計入人類。三十二天的異族化形後入道統、算在各勢力裡，聖土的魔獸不成國、不成族，只按群落另計。
   - **縫約**：古戰後諸洲共立之約，觸帝者須公開，私自拆封者諸洲共擊。見諸洲檔。
   - **魂龕先祖不算**：殘魂不出手（D050），一生至多主動傳承一次（D099 第 6 條），不能拿來平衡戰力。它平衡的是**記憶**：三十二天靠長壽的人記事，聖土靠魂龕。殘魂數百到數千年散盡，連最耐久的茵布瑞霜龕也只留得住約一萬二千年；所以聖土沒有一個人親口記得古戰，這正對著三十二天「只剩負霄老祖一人親歷、而且閉死關」。兩邊都沒有會開口的古戰證人。
2. **鬥聖初中期與半聖約為三十二天的五到六成。**理由是**存量與流量**：聖土修得快（力取天地）、活得短（當代榜單：鬥王壽約二百出頭，鬥宗四五百，鬥尊不過千年）；三十二天修得慢、活得長，準仙帝挨了削半壽的道傷還能活過八萬年。兩邊每一代成聖、成仙的人數相近，但三十二天把人存了下來，聖土的人一代一代換掉。所以聖土在長壽的上段人少，在短壽的中段人多（鬥宗約 1.15 倍）。**依據**：聖土壽元方向「借力者壽短，同格壽元短於仙」已由 D063 定案；逐境壽元數字待設計（[諸神聖土](../諸神聖土.md)待定項）。
3. **塔尖多一人（16 對 15）**：理由同第一條。三十二天的準仙帝是長壽存下來的，聖土的帝前之人是帝路封住積下來的；來路不同，數目相當。
4. **勢力總數略少（約 8–9 萬對約 12 萬）。**下無極的十萬家是碎裂養出來的：接土之間有接縫，接縫上有城，城常換主，勢力興滅極快。聖土天地完整、沒有接縫，盆與盆之間隔的是海、沙與獸嶺；勢力少而穩、壽命長，平均一家比下無極大。
5. **盆沿比九界略強、家數略多。**九界不能運轉仙力，又有列陣入境上限，是硬天花板，本土只修到虛道。聖土的盆沿只是天地能量薄，沒有硬天花板，所以盆沿頂級常見鬥尊（約當虛道至斬我）。
6. **頂級不集中。**三十二天的頂級擠在大羅與上無極內側；聖土的二十四家頂級散在約二十五個大盆，大致一盆一家。聖土沒有大羅的對應物。
7. **柯涅斯低於同級大盆。**一個大盆平均約有鬥聖十五位上下，柯涅斯只有六位。理由：古戰打在它的西緣，它的古戰鬥聖幾乎全數戰死或燃壽（古戰與兩界衝突，D057 替代表）；外洲援軍的損耗大半落在對岸，沒有落在自己的盆裡；戰前它靠界路成為最富的一盆，戰後這份收入斷了。它是聖土的「受創之盆」，對著三十二天的受創九庭。柯涅斯人至今自稱「中心大陸」，那是戰前的舊名分；外洲人叫它「縫洲」。

### （四）形狀：同心的天，多盆的地

| | 三十二天 | 聖土 |
|---|---|---|
| 天地 | 有極；由大羅向外分化 | 無極；天地完整，處處可取 |
| 地理單位 | 道域、接土：古天碎後重接的仙土 | 盆：地脈自盆頂向四方流下的一整片地 |
| 中心 | 一個，在最內（大羅） | 沒有；世界的正中是一片海（無主海） |
| 層次 | 垂直：九界、下無極、上無極、大羅，越往內越老越深 | 橫向：諸盆並列，每一盆內部自成「盆頂—盆沿」的小同心 |
| 分化 | 越往外越分化、越碎；下無極碎裂最甚，勢力興滅最快 | 分化發生在盆與盆之間（被海、沙、獸嶺隔開的流派與口音），不隨遠近遞減；盆不碎，勢力少而穩 |
| 人往哪裡走 | 往內：飛升、向極 | 往高：遷盆，往更濃的盆頂走；沒有飛升 |
| 頂級分布 | 集中在大羅與上無極內側 | 散在二十五個大盆，大致一盆一家 |
| 誰付帳 | 外圍九天沉為九界 | 每一盆都讓自己的盆沿付帳；放到全聖土，則是諸洲讓柯涅斯西緣付帳（縫約的守縫捐，見諸洲檔） |
| 傷在哪 | 外圍一整圈（九界）與無極的接縫 | 只有一處：柯涅斯西緣的封合縫 |

三十二天失去了中心；聖土從來沒有一個中心，每一盆各有自己的中心。

**古戰的對等**（估）：
- **陣容**：三十二天在場的仙帝至少四位（太宸、未濟、抱一、止戈），準仙帝數十；聖土有末代鬥帝一位、觸帝者十餘、鬥聖約八百，戰前比今日多出兩成上下。
- **戰場**：打在界路與三十二天的外圍。聖土鬥聖離了土仍是鬥聖，卻失去主場加成，力又補不回來（D065），打一場少一場；所以聖土強在中段：鬥宗、鬥尊在靈氣外放的外圍補給接近主場，人數又多。三十二天強在上段：仙在家門口滿力。兩邊一強在中段、一強在上段，加上帝境各守一端，所以打成對等，也打成誰都收不了場。
- **損耗**：聖土一側，末代帝死於封合；出征的鬥聖大半死在對岸（沒有主場，力打空了補不回）或在縫前燃壽；渡口王國衰落，柯涅斯西緣成了傷口。三十二天一側，外圍九天沉為九界；上段普遍帶道傷、削半壽；太宸落下心魔。
- **恢復**：聖土換代快，外洲一兩萬年內鬥聖人數就回到戰前的八成上下；唯獨柯涅斯，西緣天地變薄，撫恤又把資源綁在受害名分上，一直沒養回來。帝路封住，觸帝者越積越多。三十二天換代慢，靠長壽把上段慢慢存回來；下無極的碎裂則不停長出新的小勢力。**八萬年後，兩邊總量又相當了，形狀卻各自長歪到相反的方向。**

**仍須守住的四條**：
1. **沒有鬥帝**：觸帝者四人都停在帝前，各有理由。
2. **成帝即拆封**：聖土天地一次只容一片帝天，拆封與觸帝者身在哪一洲無關；遠洲的人也被綁住，縫約由此而來。
3. **陸沉不擊殺鬥聖**：第二次聖土的舞台仍在柯涅斯。外洲的人以使節、商旅、縫約的旁觀者身分進場，陸沉不必渡海。全聖土約六百五十位鬥聖，只讓「陸沉不是最強者」更穩。
4. **聖土不是反派**：外洲沒有人要打三十二天；縫約是對自家天地的謹慎，不是戰備。外洲對「仙庭一心」信得比柯涅斯淺，因為撫恤與芸香夜是柯涅斯的制度；他們是聖土放下泛名時的旁觀者，不是推手。

### （八）對第八節的修正

第八節「受創、無帝的天地」一條說塔頂比原作窄、不能靠多設鬥聖撐場面；「多片大陸壓成中心加邊地」一條說本作把多片大陸壓成一片。這兩條是對照原作時的判斷。D061 之後改為：**塔頂窄只指沒有帝，不指鬥聖少**；聖土不再壓成一片大陸，而是諸洲並列，柯涅斯是其一。第八節其餘結論（中層偏少、另立三流、規模標準表）仍適用於柯涅斯一盆，外洲建勢力時可照同一張規模標準表放大。
