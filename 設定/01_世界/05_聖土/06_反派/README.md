# 聖土反派

狀態：合成稿（2026-10-02），交作者審閱。第十三節 R1–R14 已裁定：除 R7 外全為作者定（全採推薦，2026-10-02），R7 依推薦寫、交 PM 轉作者；留白第 6 點（伊紹爾降鬥皇）亦為作者定。由四份反派稿合成：柯涅斯與邊地、尼倫斯與廷德拉、努瓦羅與茵布瑞、踏石群島與無主海。時代基準同 14、20–26 號檔：第二次聖土（第 19–20 篇，落潮後約二十二年）；篇位對照[陸沉三次入聖土](../../../../大綱/00_全書骨架/陸沉三次入聖土.md)。

- **收錄**：聖土八個區域的反派，共 81 位（主要 33、次要 48）。其中新增 76 位（含化形或九階魔獸 6 頭），沿用 5 位（德洛姆、芮特、希昂、赫索、尼達）。各稿的事實照錄，只精簡措辭；合成時所做的改動見第十四節。
- **作者定案（2026-10-01，已套用）**：
  1. 混血不設新能力。被綁的混血只當翻譯：懂兩種語言，不能同讀兩種印記。凡原稿寫「拘九界後裔讀仙家烙印」的段落，都已改成只當翻譯，或改成主使者以為讀得到、結果讀不到（扎卡里）。
  2. 「偷來的神」是騙局加狂信，不新增規則。本檔沒有收這一型反派。
  3. 縫民成立。縫腔的規則由另一組寫；本檔不寫縫民，也不定縫腔規則。（已寫：規則見[境界對照與跨界](../01_規則與跨界/跨界總則與限制.md)「縫腔」一節，縫民人物見 [30 號檔](../04_人物/30_跨兩界網絡與聯手.md)第五節。）
  4. 太素道宮在終局前碰不到聖土。太素前哨只在第 28 篇之後成立（D068），28 篇之內前哨與太素零接觸，也不知道太素之名。
- **作者定案（2026-10-02，已套用）**：第十三節 R1–R14 全採推薦（R7 待定，見該節）；伊紹爾降為鬥皇三星（第三節伊紹爾條）。
- **歸屬**：大多數完全獨立。封門派打手 2 人（奧布里、伊紹爾），冒籍宗門的打手 0 人，太素前哨〔28 後〕5 人（柯利斯、紀斯蘭〔候選〕、奇洛雅、魯諾、托娃）。其餘 74 人各有各的帳，彼此之間只有買賣、雇傭或下線關係，歸誰見第十節。沒有一條線通往同一個幕後。
- **境界**：不新增鬥聖，也不新增半聖。鬥聖反派只有 3 位，都從現有名單中挑（德洛姆、芮特、赫索，理由見各條）。原稿新增的 7 位半聖一律降為鬥尊巔峰（見第十四節與規則 R14）；沿用的半聖 2 位（希昂、尼達）照原檔。九階只有餌光一頭，是從 26 號檔「其餘四頭不具名」中具名，不增配額（R13）。陸沉不擊殺鬥聖。
- **篇位**：只用第 8、17、19、20、27、28 篇或「篇外」。陸沉不渡海，所以外洲反派除了自己渡海到柯涅斯的哈根、伊紹爾、拉庫諾（第 20 篇，2026-10-02 增）之外，全是篇外或間接。
- **揭露**：破綻一律寫成遺痕、後手、戰鬥中的選擇或名分上的失手，不寫查案。陸沉在聖土只用既有的本事：神識感知魂的「有」但讀不出內容、讀神識烙印、震魂雷穩魂、星羅察脈、雷域行走。
- **用語**：「九弱」是仙界俗稱，聖土不知道。九界人在聖土的叫法用「潮下人」（R1）。
- **命名**：勢力名照總表〇節體例，用音譯專名加西式機構詞，不接宗或堂。新人名首字母依原稿分段：柯涅斯與邊地 A–F，尼倫斯與廷德拉 G–L，努瓦羅與茵布瑞 M–R，群島與無主海 S–Z；群島人以島名作姓。
