## 十一、可鋪的聯手線（不是同一幕後）

> 各線的裂縫、爆開的篇位、被利用的正派與三種反應，以及跨兩界網絡，已在 [30 號檔](../04_人物/30_跨兩界網絡與聯手.md)第一至四節展開；本節只留索引。

| 線 | 誰 | 交疊點 |
|---|---|---|
| 魂市 | 艾薇絲 → 達羅 → 柯西瑪；魯諾的龕座也進 Nerholt 魂器市 | 邊地新魂、中心舊魂、霜龕龕座，同一個市場；各段互不知底 |
| 殘魂南運 | 魯諾 → 歐塔 → 柯涅斯轉手 → 奇洛雅 → 赫索 | 只在貨上相接，沒有人知道整條路（R3） |
| 人與貨 | 法拉蒙 → 費妮拉 → 錘廳假貨；扎卡里 → 瓦西爾、席倫 | 買賣；費妮拉買人刻烙印，法拉蒙供人 |
| 藥市 | 伯特倫 → 布琳 | 倉露的買主 |
| 雷傷藥市場 | 朗瑟蘭、格威瑟 | 療法從「補」轉「引」，兩人的貨一起貶值；日後可能合做一味「引」型假藥 |
| 門與收費 | 吉斯貝、德洛姆、芮特 | 界路、束海、渡口保契；縫約會上可能結成一票，對手是若曼 |
| 盆傾經濟 | 紀斯蘭、若斯坎、蓋蘭、勞林、林哈德、豎鬣 | 每一回盆傾各吃一段（龕、人、陣段、火、樁手、過路），局一散就散 |
| 帝路敘事 | 哈根、豪訥 | 互相看不起，卻都在擴大「縫約禁帝說」的錯誤答案 |
| 冊市 | 辛德比會館 → 鹽交所 | 會館造絕嗣，鹽交所賣代祀權；第 19 篇冒籍翻案讓這個市場暴漲 |
| 盜火 | 帕盧塔、勞林 → 雅尼克的暗跳 | 偷來的火過南支 |
| 栽贓 | 荊鼬 ↔ 艾德威 | 眼斑可能與陸沉或老鬚聯手反制 |
| 兩個「劫」 | 艾布納 × 封門派 | 見第九節 |

反制方的現成組合：珂莉瑪與朱瑪拉對帕盧塔；莫恰與裘薇塔對奇洛雅；彭圖斯、歐妲、奎德家對馬蒂斯與魯諾；寧妮與歐蘭德對尼達；凡斯與舵首對祖萊卡；校門人、采勒與獵海會對餌光；塔姆辛與皮爾斯對扎卡里。
