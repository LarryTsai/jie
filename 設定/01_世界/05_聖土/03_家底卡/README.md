# 聖土家底卡索引

狀態：聖土寫手提案（2026-10-02 起），PM 派工。各卡為提案，作者裁定處逐項標「作者定」。

**格式**：照[修仙文明底層規格](../../02_修仙文明/01_底層規格/修仙文明底層規格.md)第 16 節十二欄；每項招牌先過「能力設計檢查條」八條（源、門、象、器、傳、限、價、萬年問，D076）。家底形態照[宗門與天驕家底庫提案](../../../../待整理/設定/06_待定與決策紀錄/宗門與天驕家底庫提案.md)第三節。三十二天的家底卡在[勢力/家底卡](../../04_勢力/06_家底卡/README.md)，兩界不並表、不換算。

**聖土體例**（與三十二天卡的差別；依據[境界對照與跨界](../01_規則與跨界/README.md)）：

| 項 | 三十二天卡 | 聖土卡 |
|---|---|---|
| 功法品名 | 凡篇、靈篇、玄篇、仙篇 | 天地玄黃（黃、玄、地、天階，各分低中高） |
| 術法 | 不分層，寫最低施術境界 | 鬥技分階；「門」一欄寫鬥氣境界門檻，魂技另寫靈魂境界（蟄境、照境、靈境、天境） |
| 秘術 | 秘術，必附代價 | **秘法**，必附代價：燃壽、燃魂、傷火、一息（作者定） |
| 本命器 | 本命法寶，六品，本質／當前 | **契**：契火、契獸；聖土沒有本命器，兵器一律是外物（作者定）。八條的「器」一欄改為「契／器」 |
| 傳承載體 | 藏經、命藏、口傳 | 殘本、殘頁、上下卷；**魂龕先祖**（底蘊＝能開口的先祖數） |
| 經濟 | 靈石、份額 | 魔核（當代生活魔核表，當／銖）、丹藥與藥份、火口租、錘廳拍賣與錘保、雷晶配額 |

- 〔提案〕：本卡新設。
- **留白**：沒有來源，不硬補。
