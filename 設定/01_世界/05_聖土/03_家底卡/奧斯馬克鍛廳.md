# 家底卡：奧斯馬克鍛廳

**時點**：第二次聖土（第 19–20 篇），落潮後約十一年。

**一句話**：鍛廳的火住在一個將死的老人身上，屋頂是天上的一層雷，而那層雷是十一年前它自己點頭讓人拿走的。

---

**家底形態**：契火＋器〔家底庫〕。鎮宗之火坩主契在太上身上，人死火回野〔既有〕；兵器是外物，賣得出去，也被錘保〔既有〕。本卡補一句〔提案〕：鍛廳真正守的是一個「地方」，火井加屋頂；火與器都從這個地方出來。

## 四、傳承

- **根本功法**：《砧典》上半卷，**天階低級殘本**〔既有〕。只存上半，下半據說沉在溫德港〔既有〕。太上、廳主、前任廳主修這一部〔既有〕；修到何層、門下誰得傳，**留白**。
- **廳傳功法**：《火口經》，**地階中級**〔既有〕。魯里克所修；本卡推定〔提案〕它是門人的主修，《砧典》只傳廳主一線。
- **鬥技**（皆**地階高級**〔既有〕）：
  - 《熔同》：老哈斯。把對手的兵器與鬥氣熔成一塊〔既有〕。見下方檢查。
  - 《鍛紋》：葛瑞特。在兵器上打進可控的火紋〔既有〕。
  - 《析骨》：伊索德。以渣舌舔出對手鬥氣中的雜質，護體崩散〔既有〕。
  - 《封口》：萊安德〔既有〕；做法**留白**。
- **秘法**〔提案〕：〈傾坩〉，見下方檢查。
- **傳承載體**：
  - 《砧典》上半卷原本〔既有〕；藏處**留白**。
  - **魂龕**：萊安德殘魂在廳龕，大問龕日能答三問〔既有〕。「城在」就是他答葛瑞特的那一問〔既有〕。殘魂不傳功、不教人、不出手〔既有〕，所以龕裡沒有第二部功法，只有一句話的帳。
  - **灰牌帳**：灰牌司歷代的帳冊〔既有〕。帳上有一格「無名，免費」〔既有〕。利奧弗里克從灰牌收入逐年上升，最早算出屋頂在變薄〔既有〕；本卡把這本帳也列為載體〔提案〕：它是鍛廳唯一一本記著屋頂厚薄的東西。
  - **火口鍛法**：口傳與手傳〔提案〕。米洛帶走的是鍛法，不是火〔既有〕，可見鍛法離得開火井，熔同離不開。

**〈熔同〉八條**（招牌；火性與鬥技兩層）

燧冊把「熔同」記為坩主的火性：不同的金鐵放進去，熔成一體而無接縫〔既有〕。老哈斯的鬥技《熔同》是契主借這個火性的打法〔既有：鬥技名與效果〕。兩層分開寫：**鍛**（火口邊，誰租得到火口誰能用）與**鬥**（只有契主能用）。

| 條 | 內容 |
|---|---|
| 源 | 火井的火性，加上鬥氣控火。鍛：廳傳《火口經》（地階中級）〔既有〕打底，控的是火溫。鬥：《熔同》，**地階高級**〔既有〕，掛在《砧典》上半卷（天階低級殘本）之下〔提案〕；燃料是鬥氣與契火 |
| 門 | 〔提案〕鍛：鬥靈起（鬥氣凝物，能把火溫凝在一條線上）可在火口熔兩種金鐵；鬥王化翼在這裡沒有用，雷冠下沒人能飛〔既有〕，鍛師都走地道。鬥宗（空間之力）起能把火口的熔溫隔空引到砧上，鍛鬥尊兵器。鬥：須契坩主；鬥宗時熔的是兵器，鬥尊觸及規則，連對手鬥氣一起熔成一塊〔既有效果〕；鬥聖初期（一至三星）熔同與法則相融，被熔的地方對手再也分不出哪裡是他的兵器、哪裡是他的鬥氣。老哈斯一星衰退，只用得出鬥尊時的那一層〔提案〕 |
| 象 | 火是深紅帶黑紋的厚火，像熔岩表面〔既有〕。鍛廳的兵器沒有接縫；被他們的器打中，傷口也是整齊一片〔家底庫〕。〔提案〕《熔同》落在對手兵器上，接觸處先轉暗紅，花紋與刃口一起消失；對手的鬥氣護體在那一點變得和兵器一樣黑紅，收不回去 |
| 契／器 | 不是本命器。火的那一層是**契**：坩主契在老哈斯身上〔既有〕，他一死火回野，要重新立契，火會選〔既有〕；篇末火認奈莎（作者定，2026-10-02）。器的那一層是**外物**：熔同兵器是鬥尊兵器，可賣、可拍、可上錘廳的器保〔既有〕，不配法寶六品〔既有〕，人與器之間沒有命。把殘魂封進兵器的「器念」是禁區，鍛廳不做〔既有：禁區〕 |
| 傳 | 鍛能傳：火井每年開放一季，公會與他宗租火口煉器〔既有〕；租得到火口，就碰得到熔同的火溫〔提案〕。鍛法能被人帶走（米洛）〔既有〕。鬥不能傳：《熔同》的招式寫得下來，火性不是學的人的，沒有坩主契就只剩一門燒得比較熱的鬥技〔提案〕 |
| 限 | 離開火井就沒有熔同：斯托克斯兵器行在維索里租次級火，只能批量鍛鬥王到鬥宗級的兵器〔既有〕。開口只能趁火井換氣〔既有〕。老哈斯壽盡到坩主擇主之間，契的那一層暫停〔提案〕。雷冠下不能飛，運料、運器全靠三條熔岩古道〔既有〕 |
| 價 | 鍛：火口的時辰，一季只開一次給外人〔既有〕。鬥：被熔的兵器收不回，自己出手的兵器也熔進去〔提案〕；老哈斯是衰退的鬥聖，每用一次都在花剩下的年〔提案，依壽元表「耗損」條〕。重的代價在秘法〈傾坩〉 |
| 萬年問 | 熔同綁在一口火、一座山、一個人身上。火只有一朵，契只有一人，人死火回野〔既有〕；強者寧可控地租火，不願讓一個人的死帶走整個宗門的火〔既有〕。所以八萬年來沒有誰能把熔同帶走：拉庫諾想借它熔兩火保命，結果是坩主把落種吐了出來〔既有〕 |

**〈傾坩〉八條**〔作者定〕

契主以契把火井一次換氣的聚能全引上身，熔同之溫不再只落在一件兵器上，而是一整片。

| 條 | 內容 |
|---|---|
| 源 | 《砧典》上半卷秘傳一章〔提案〕；載體是坩主契。燃料是鬥氣、契火與火井聚能 |
| 門 | 只有契主能用。鬥宗起承得住（空間之力，能把聚能隔空引上身）；鬥尊時可把一條古道、一段火口的金鐵與鬥氣熔成一片；鬥聖時可熔到冠下 |
| 象 | 火井口忽然暗下去，布蘭堡的熱一刻退盡；契主身上浮出坩主那種黑紋；天上的雷冠閃一下又變淡 |
| 契／器 | 承載的是坩主契，不是兵器。契主身邊的兵器多半一起熔掉 |
| 傳 | 只傳廳主與契主；坩主回野期間無人能用 |
| 限 | 只在火井上用得出，離井無井可傾；一次換氣只能傾一次 |
| 價 | **傷火**：坩主受創，契主的魂跟著受創。**燃壽**：以年還帳。另有一筆不在人身上的帳：火井一次換氣的聚能被抽走，衝不上冷天，雷冠少補一層，下一次落冠錯時（與囚爐陣抽聚能同理〔既有機制〕）。每傾一次，屋頂薄一層 |
| 萬年問 | 冠厚的八萬年裡，沒有人需要傾；冠薄到將破的今天，最不能傾。這一法在鍛廳是一頁「知道有、不敢用」的秘傳 |

## 五、法寶家底

聖土的鍛廳沒有法寶，只有火、雷、地道與兵器。不寫「本質品階／當前可用」，那是三十二天的六品〔既有：聖土不配六品〕。

- **鎮宗之物**：坩主，燧冊第七〔既有〕。它是火，不是器，住在火井裡，契在老哈斯身上〔既有〕。已生靈智，擇主時會選〔既有〕。
- **次一朵**：渣舌，燧冊第十四，生在火井支脈，契在伊索德身上〔既有〕。火性「析」〔既有〕。
- **屋頂**：布蘭諾赫雷冠〔既有〕。火井噴發的熱氣衝上冷天凝成的雷雲，擋住一切從空中奪火的人〔既有〕。它不是鍛廳造的，也不屬鍛廳；殞星天雷被取走後逐年淨減〔既有〕。
- **樞**：陸沉在屋頂之帳那一夜替殘冠做的一道門，冠從此可開可關〔既有〕。開冠要鍛廳報時、陸沉的樞在場；**陸沉離開聖土之後，樞轉不動，冠只關不開，直到第 27 篇**（作者定，2026-10-02）。屋頂保住了，天路也封死了。
- **三條熔岩古道**與灰牌〔既有〕：進火井的唯一路。
- **器庫**：鬥尊兵器的存貨**留白**。
- **魔獸**：無契獸〔既有：鍛廳不在獸契一線〕。

## 八、人才管道

- **親傳**：萊安德傳葛瑞特〔既有〕，伊索德傳奈莎〔既有〕。兩派各有一線，繼承之爭就沿著親傳線走。
- **廳主家**：魯里克是廳主之子，修廳傳《火口經》；隨身那縷次級火是他自己到維索里租來、自己養熟的〔既有〕。
- **外姓鍛師**：輪不到近火〔既有〕。屋頂一破，他們寧可去有活幹的地方；斯托克斯兵器行已和幾名外姓鍛師私簽聘約〔既有〕。這是鍛廳人才最大的漏口。
- **榜**：魯里克在雛翼譜第二〔既有〕；奈莎被師門壓在榜外，怕太早成為目標〔既有〕。
- **收人**：門檻與考核**留白**。
- **外送**：**留白**。

## 十、歷代經驗

- **萊安德那一筆帳**：落冠連墜之夜，取走雷冠本源就停了墜雷，屋頂卻會逐年變薄；他選保城〔既有〕。他算冠還撐得了百年，冠薄得比他算的快〔既有〕。殘魂只答「城在」〔既有〕。
- **封口令**：對外只說「火井換氣」〔既有〕。鍛廳不想讓人知道屋頂在變薄；這讓十一年後只剩傳聞〔既有〕。
- **地道規矩**：雷冠下不飛，進火井只走地道，持灰牌，按日收費〔既有〕。
- **一季開火**：火井一年只開一季給外人〔既有〕。
- **外姓不近火**〔既有，從米洛條推得〕。
- **宗訓**：**留白**。

## 十一、弱點

- **鬥聖將死**：老哈斯一死，頂端從鬥聖掉到半聖〔既有〕。
- **屋頂將破**：雷冠本源被取走後，只剩火井每年補的一層，補不上消耗，逐年淨減〔既有〕。樞之後屋頂保住，卻要靠一個會走的外客；他一走，冠只關不開（作者定）。
- **火在一個人身上**：契主一死火回野〔既有〕。火會選人，選的不一定是派系要的人〔既有〕：篇末火認奈莎，魯里克接廳主之位的承繼（作者定）。契主與廳主從此是兩個人〔提案：作者定的直接結果〕。
- **繼承兩派**：葛瑞特一派要疏導、不靠外人；伊索德一派要守護契〔既有〕。伊索德一派半知情放外人進來攪局，被拿來偷自家的火之後將錯就錯〔既有〕。
- **功法缺半**：《砧典》只存上半卷〔既有〕。
- **外姓鍛師流失**：鍛法帶得走〔既有〕。
- **進料受制**：兵器核走 Kell 核市〔提案〕，火井以外的一切料都要從公國的地上過。
