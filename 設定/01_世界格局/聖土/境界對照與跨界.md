# 境界對照、跨界與戰力換算

狀態：重建候選稿（Q17-1）。專家五人收斂，屬 A、B 類，待 PM 入決策紀錄。上界年表已由 PM 重開，本檔不鎖定陸沉入聖土的年齡，只給規則與限制。

## 跨界戰力換算（定）

1. **對齊的是質變點，不是數值。**
2. **主場滿力才算對等**：在聖土用鬥氣、在上界用仙力，同格大致相當。以法力出力，比同格的鬥氣或仙力都弱，沿用現行「同境仙力與法力有明顯差距」。
3. **修正項可越一兩個小階，越不過質變點**：鬥氣一方看功法與鬥技品階、有無異火、化翼的機動、煉藥師後勤；仙一方看寶術神通、肉身、雷身數量，以及對方不熟悉的體系。
4. **靈魂與神識另計**：魂戰、搜魂、煉丹、感知的場合，靈魂強度可以直接決定勝負，與修為高低無關。
5. **不寫「仙高鬥低」**：同階勝負看打法，聖土不能被寫成被碾壓的配角。

## 跨界的補給與上限（定）

| 情況 | 規則 |
|---|---|
| 仙修在聖土 | 只能運轉法力，燃料是聖土的天地能量，所以補得了法力；仙力不能運轉，攜帶的仙力、仙晶、仙器只能轉作法力使用。**真仙以上**的境界本身靠仙力撐，在聖土出力約壓到至尊巔峰上下，只剩肉身、神識與見識的優勢。仙帝例外 |
| 以法力在聖土修行 | 現行「下界法力修行理論上可至至尊」同樣適用，所以在聖土可以一路修到至尊（對半聖） |
| 真仙突破 | **必須回三十二天。**真仙的條件是仙力，仙力要連得到極 |
| 鬥氣修士在三十二天 | 九界與外圍靈氣外放，氣旋吸得動，接近全力；越往上無極、大羅，氣越內斂、越繫於道脈，吸納越難，要靠自帶鬥晶與魔核撐。這同時說明古戰的正面衝撞為何集中在外圍，**但只說明外圍為何首當其衝，下沉的真因仍是內應撤去護持** |
| 鬥聖以上離開聖土 | 失去聖土天地法則的加持，實戰約退到半聖；**鬥聖必須在聖土突破**。鬥帝例外 |
| 兼修 | 不能兼修，只能轉修：氣旋往外納，返本往內收，同一副經脈不能同時兩向運轉。轉修等於散功重修，比照退境重修的規則（保留見識與壽元，不保留修為）。混血者與後裔須擇一 |
| 入聖土的境界上限 | **兩界之間不設入境上限。**列陣上限是進入九界的規則；聖土是另一座完整的天地，承得住本土的鬥聖，也就承得住外來的同級。限制在路上，見下節 |

**列陣入境上限的理由**：九界的界壁受創最深，本身就是封合縫的一部分，承載不了更高修為（入九界的壓境與退境規則見 D059）。

## 兩界之間的三條路（定）

界外虛空沒有天地之氣可補，也沒有空間座標可落點。渡虛要同時解決**補給**與**定位**。

| 路 | 誰能走 | 怎麼走 | 代價 |
|---|---|---|---|
| **低路：封合縫的界潮窗口** | 列陣／鬥靈以下的人，**含列陣**（含九界本土修士）、退境到列陣者。低路沒有錨陣，壓境者走不了（D059）。走低路過去的人若在聖土突破到列陣以上，就回不了低路 | 古界路被封合後，兩端各留一段殘骸：仙界端落在九界邊緣的險地（古時外圍就是今天的九界），聖土端就是封合縫的雷域。兩端殘骸隨道則相撞的週期彼此靠近，窗口一開，中間的虛空極短，不必另外解決補給與定位。前例是北天天幕的「依天象週期接軌」（D028） | 窗口數年到數十年一開，只開數日，一次只能過少數人；仙界端受九界列陣上限約束，聖土端要穿過雷域，雷勢最弱時才走得過。封縫由帝境以本源封成，力量越強越會觸發封縫的反擊，也越可能把縫撕大；過縫時會挨劫雲，有真實的死亡率；錯過窗口就被困在對岸，要等下一次 |
| **高路：本體渡虛** | 有穿虛能力（太虛神雷之類）又有足夠仙力存量者，約斬我以上；仙王以上若有穿虛手段也行 | 以穿虛能力解決定位，以自身仙力存量撐過補給。封合縫仍是最好的定位錨點 | 仙力只耗不補；入境後不設上限，但仙力轉法力。可帶人：定位由持雷者一人負擔，每多一人消耗倍增；補給由同行者以自身仙力存量負擔；持雷者須親自在兩端 |
| **帝境** | 仙帝；鬥帝（聖土目前沒有） | 自成天地或立極，不缺力，自帶座標 | 無上限 |

- **上無極斷峰群的漏影**（D059）：古界路在仙界一側分兩段錨地。外段錨在外圍九天，沉為九界，就是低路的仙界端；內段錨地在今日上無極，封合後崩成斷峰群，峰間的虛空縫隙時開時合，會透出封合縫劫雲的**漏影**（隔縫觀雷）。漏影只見光與雷意，**不能通行**，不是第四條路；天下異雷榜據此把九霄列為「存目」。太虛取自斷峰群，雷光在兩處接續的軌跡可反推封合縫方位，是高路定位的參照之一。
- **窗口曆法**：只有九界的異域後裔世代口傳，守界傳承略知。仙界八萬年來不在意九界，封合縫與後裔口傳因此從未被「對齊」到仙界官方版本。這是聖土一側證據「仙界竄改不到」的第二重理由。
- 低路就是溫棠追查的異域後裔村落、裴照川想「經界路找聖土方的證人」（B2）所能走的路，不必另開通道。
- **兩界往來一律本體**（作者 2026-09-30）：[雷種熔煉](../../04_修行與特殊事物/雷道/雷種熔煉與雷身修行.md)規定新雷須煉到劫當下的完整境界，在聖土取的雷都由本體在場熔煉。以列陣本體走低路者，在聖土不能突破，否則回不了低路；上界修士散功退到列陣走低路，回上界後須重修。作者 2026-09-30 定：全面不用化身，三十二天內部跨層亦同；進入九界一律本體壓境（只能走正規界路）或退境（D059）；「壓境」專指錨陣壓境，陸沉在聖土壓著關口不突破稱「壓關」。**雷身例外（D064）**：雷身不是化身，而是陸沉的本源，可以單獨入聖土；每具雷身各自留痕（壓境簿、氣機拓印、壓痕），與本體無異。代價是本源被界壁撕扯，分處越久越重，本尊首當其衝。取雷仍須本尊在場。
- **窗口密集期**：界潮週期不均，大週期數十年，其中有數年密集期，約一年一開。

### 八萬年來強者為何沒有大舉往來

1. 低路只放得過列陣／鬥靈以下（含列陣），帶不了軍隊，也載不了強者；它是走私道與流亡道，不是戰略通道。
2. 高路要罕見的穿虛之能，加上仙力存量；仙人去聖土拿不到任何修行好處，又得面對鬥聖的主場。
3. 帝境：聖土無帝，觸帝者四人都停在帝前；仙帝沒有動機（太宸要門關著），仙力在聖土也無用。
4. 鬥聖離開聖土就退到半聖，過得去也打不了；全聖土鬥聖雖有六百餘位（D063），這一條對每一位都一樣。
5. 強行撕縫等於重開傷口，壓測的「能封住的邊界正在後退」會重演，這正是當年封界的理由。
6. 兩邊的敘事都要這扇門關著：三十二天靠它維持勝利史觀，聖土靠它維持受害名分。

小規模的偷渡八萬年來一直都有（後裔、走私、流亡者），這也是物證能在兩界流動的管道；大規模往來則不可能。**這道門檻兩邊對稱，不靠棋手，也不靠禁令。**

## 陸沉的往返（交 PM 排年表）

PM 已重開上界年表，本節只給結構候選與限制。

- **首次入聖土**（作者拍板：本體、機緣、非計畫）：專家推薦十八歲九界大比後數月，以列陣本體在救人時被界潮捲過低路，在邊地待約一年，於布蘭諾赫雷冠熔煉殞星（列陣）；壓關不破，下一窗口以列陣回九界，回來後才破尊者、飛升。看得到、讀不懂、拿不到，只埋線。見[陸沉首入聖土](陸沉首入聖土.md)。
- **正式聖土篇**：本體走高路（依 PM 重排的九雷，須先有穿虛能力）。
- **收束**：帶著仙界一側的證據再入聖土，公開驗證，並在邊地同意下取雷；終局重開界路時可有第三或第四次。
- **戰力位置（原則）**：入境時若為斬我或遁一，以法力出力，約當鬥尊中段至高星；到至尊時約當半聖。聖土有鬥聖在世，**陸沉在聖土從頭到尾都不是最強者，不擊殺鬥聖**；至多付出重大代價，逼退或拖住一名低星鬥聖。
- **三場各只寫一次**：「此人身上沒有鬥氣」放在首入；「他沒吞」「第一次見劫」放在正式聖土篇。
