**家底形態**：鎮宗絕學＋契火〔家底庫〕。絕學是《九判》，柯涅斯唯一完整的天階中級〔既有〕；契火是「一線」，住在廷主身上〔既有〕。兩樣都靠人：九判的最後一判只在太上身上，一線只在廷主身上。

**一句話**：柯涅斯最強的宗門，家底一半在一部劍技，一半在一個停在帝前的人；它管得了中央高地，管不了自己的丹、兵器和門。

### 四、傳承

- **根本功法**：《高凱恩劍脈》，**地階高級**〔既有〕。引三脈交會之氣入劍〔既有〕。完整度：**留白**（現行沒有寫殘缺）。
- **招牌鬥技**：《九判》，**天階中級**劍道鬥技〔既有〕。柯涅斯唯一完整的天階中級；全聖土另有三部，各在一位外洲觸帝者一脈〔既有〕。完整度：**完整，九判俱在**〔既有〕。第一判名「線」〔既有〕；第二至第八判名**留白**；第九判傳說斬的是「自己往前那一步」〔既有，傳說層〕。
- **其他具名功法、鬥技**〔皆既有〕：
  - 《劃疆》，地階高級劍陣，達瑪莉絲自創：以空間之力沿地面劃一圈界線，界內一切鬥技的去向都要先經過她的劍。
  - 《橫欄》，地階中級鬥技：一劍橫擺成欄，專擋群衝。
  - 《井衡訣》，地階中級功法：專抗回淵的「墜」。
  - 外授：《關山劍式》，地階低級，只傳守關世家（內維爾家），劍勢以守為主。
- **秘法**：現行**沒有**。本卡提一條〈並脈〉〔作者定〕，載體是《高凱恩劍脈》，代價燃壽，見下方八條。
- **傳承載體**：
  - **劍臺**：收徒大典的入山試〔既有〕。
  - **高凱恩劍冢**：一線的原生地；廷主契火後第一次試劍，由劍冢守站在冢口見證〔既有〕。
  - 經藏、口傳：**留白**。
- **文書**（不是傳承，是家底的一部分）：帝路議事的結論〔既有，經艾默里克外流〕；賭派的「對岸情形書」〔既有〕。

**《九判》八條**（招牌鬥技）

| 條 | 內容 |
|---|---|
| 源 | 劍與空間之力。載體是天階中級鬥技《九判》；底子是《高凱恩劍脈》（地階高級），把三脈交會之氣引進劍裡〔既有〕。九判只用劍身走鬥氣，空間之力劃出的那道線就是「判」 |
| 門 | **鬥宗**起才能修第一判：一判要空間之力〔既有：鬥宗以上「裁」戰場；卡西安鬥宗二星劃一尺〕。鬥宗以下修劍脈與《橫欄》一類地階鬥技，還碰不到判。鬥王化翼與判無關，劍廷劍修出劍多半落地〔提案〕。**鬥尊**觸及天地規則，線從「一尺」長成一圈界〔推論，依《劃疆》〕。**鬥聖**鬥氣與天地法則相融，判數到後段〔既有：前六判以上只見於半聖、鬥聖〕。判數不全照境界：半聖馬雷克三判，鬥尊巔峰達瑪莉絲四判〔既有〕 |
| 象 | 劍過處地上留一道線，不散〔家底庫、既有：卡西安的一尺線不散〕；線是空間之力的痕，旁人看是一道極細的折光。戰鬥像量地的人在你腳下畫界〔家底庫〕 |
| 契／器 | **兵器**為主，外物，可拍賣、可錘保〔既有規則〕。劍廷弟子的鬥尊兵器約一半出自奧斯馬克鍛廳〔既有〕。**契火**只有廷主一人：卡西米爾以一線當劍，一線的「窄」能沿線切開空間之力布下的禁制〔既有〕。太上梅洛爾不契火〔既有〕。無契獸 |
| 傳 | 柯涅斯唯一完整的天階中級，只在劍廷內傳；客卿也學得到前幾判（馬雷克三判）〔既有〕。外人偷學只學得到皮：布琳學的「裁線」，線斷在第三步〔既有〕 |
| 限 | 鬥宗以下用不出。主場加成：鬥聖的力在自家盆頂最足〔既有〕，離開劍廷領只失加成，本身不減。在莫拉斯特深井附近，回淵的「墜」連化翼都壓得下來〔既有〕，劍廷人在井邊靠的是《井衡訣》，不是九判。雷域、雷緣內能否劃線：**留白** |
| 價 | 鬥技本身只耗鬥氣，不算秘法。第九判斬「自己往前那一步」：梅洛爾斬過三次〔既有，候選；作者未採則刪〕。斬一次的代價**留白** |
| 萬年問 | 判數長得極慢：半聖只到三至六判；九判之內只有一人走完。走完的那一判，斬的是自己往前那一步〔候選〕。一部把修士練到帝前、再叫他停下的劍技，外人搶不到，劍廷自己的人也不一定想走完。另外，劍修不煉丹、不契火來煉藥〔既有〕，九判越強，劍廷越依賴公會的丹 |

**〈並脈〉八條**〔作者定〕（秘法）

| 條 | 內容 |
|---|---|
| 源 | 《高凱恩劍脈》（地階高級）秘傳一章。平時劍脈引的是三脈在交會處已經調和過的氣；〈並脈〉同時直取三條主靈脈未調和的氣，經氣旋送進一劍。載體：功法《高凱恩劍脈》；出劍時多半接九判 |
| 門 | 鬥宗起可用：要以空間之力在氣旋旁撐出三道渠，不讓三股氣在體內相沖。鬥宗只撐得住一劍；鬥尊撐得住數息；半聖以上能把三股氣再壓回一線出手 |
| 象 | 劍廷領內，地面上三條靈脈的走向會短暫浮出淡光，三線朝使用者腳下收攏；劍身發白。外人看得出來：「他在借脈」 |
| 契／器 | 兵器承力，劍要扛得住三脈同時入劍；非鬥尊兵器常在出劍後出裂。不靠契火、不靠契獸。契火者能否以火身承載：**留白** |
| 傳 | 只傳真傳與長老；外授的《關山劍式》不含此章 |
| 限 | **綁地**：只有在三條主靈脈都碰得到的地方才能用，也就是劍廷領內；出了戈斯關就引不全三脈，等於沒有。雷域、雷緣用不了。用過之後，氣旋須數日才收得回三道渠 |
| 價 | **燃壽**：身體是三脈往外流的渠（D063 借力者壽短）。每用一次以年還帳；鬥宗一劍約折數年，境界越高、撐得越久，折得越多。具體年數**留白** |
| 萬年問 | 劍廷人本來就壽短（鬥宗約四五百年），一劍折數年，沒人肯常用。而且它綁在劍廷領：最強的一劍只在家門口用得出，這也是劍廷管不了中央高地以外的原因之一。守派長老閉關省壽，〈並脈〉正好與他們的習慣相反 |

### 五、法寶家底（聖土口徑：契火、兵器、陣、魂龕）

- **鎮宗之火**：**一線**，燧冊第八，原生於高凱恩劍冢；平時是一根髮絲粗的白熱細線，特性「窄」〔既有〕。契在廷主卡西米爾身上，當劍用，不煉丹〔既有〕。廷主一死，火回野。冢口有「廷主契火後第一次試劍」的見證規矩〔既有〕，可見歷代廷主多半契的是同一朵火；回野之後是否回到劍冢，**留白**。
- **領內的火，不屬於它**：**回淵**，燧冊第五，在莫拉斯特深井，**未收服**〔既有〕。井底暗沉、流動如熔金的重火，特性「墜」〔既有〕。千年一升，升到井口下百丈處停九日〔既有〕。
- **鎮宗之物（兵器）**：**留白**。現行沒有寫任何鎮宗之劍。
- **護山大陣**：**留白**。現行只寫三脈交會的盆頂與門環主樞；主樞在劍廷領內，建造與收費權在卡洛陣會〔既有〕。
- **器庫**：**留白**。已知：弟子的鬥尊兵器約一半出自奧斯馬克鍛廳〔既有〕。
- **契獸**：無（現行未寫）。

### 十、歷代經驗

- **一個字的規矩**：太上出關問「西邊還在嗎」，由昆廷答，答了將近千年，每次只答一個字「在」〔既有〕。

### 十一、弱點

- **五本帳只坐一本半**：戰力第一、門序第一；統治只到中央高地；經濟上丹、門、兵器都靠別家；名分幾乎沒有〔既有〕。翻臉三年，弟子破不了境、出不了門、拿不到兵器〔既有〕。

## 作者裁定（2026-10-02，全數照推薦）

1. **劍廷有沒有魂龕先祖。**推薦：**有龕，能開口者極少（0 至 1 位）**。理由：聖土頂級勢力的底蘊多記龕數，劍廷不記，正好寫成「劍廷的底蘊是一個活人，不是先祖」，與太上停在帝前的局面對得上；也解釋艾默里克為何要把亡子寄在赫爾家的龕。
2. **秘法〈並脈〉（燃壽、綁劍廷領）採不採。**推薦採。理由：劍廷現行沒有秘法；這一條長在根本功法上，有載體、有代價，又把「最強不等於統治」落到能力層。若不採，第四欄秘法改為**留白**。
3. **《九判》最低施術境界定在鬥宗。**推薦定。理由：現行「鬥宗以上以空間之力裁戰場」與卡西安鬥宗二星只劃一尺都指向這一格；鬥宗以下的劍廷弟子修劍脈與《橫欄》一類地階鬥技。
4. **一線回野後是否回到高凱恩劍冢。**推薦：**回冢，但不保證肯認下一任廷主**。理由：冢口試劍的規矩已暗示歷代廷主契同一朵火；火能拒絕的規則照用，下一任廷主契不契得上，可作卡西米爾之後的鉤子。
