**家底形態**：鎮宗絕學＋契火〔家底庫〕。絕學是《靜衡經》與它長出來的魂技；契火是蛾燈，借住在院長一人身上。

**一句話的不對稱**：伊爾瓦魂院是柯涅斯魂術最強的宗門，卻不握驗魂權；它的正當性建在「不搜」上，所以最強的手段，院規先自己禁了。

## 四、傳承

- **根本功法**：《靜衡經》，**天階低級**，魂修功法，「以魂稱物、以魂量魂」〔既有〕。柯涅斯天階在世譜上有名，未標殘〔既有〕。分前篇、後篇：執律長老修的是前篇〔既有〕；〔提案〕前篇內門可修，後篇只傳長老以上。
- **招牌術**：《稱量》，**地階高級**鬥技，以魂壓魂，被量者的魂會自己報出輕重〔既有，院長所修〕；〔提案〕作院傳招牌，見下方檢查。
- **院內魂技**〔既有〕：

| 名 | 階 | 誰修 | 做什麼、不做什麼 |
|---|---|---|---|
| 《稱量》 | 地階高級 | 伊爾瑟 | 量魂的輕重；不讀內容 |
| 《回聲》 | 留白 | 米蕾葉 | 驗魂晶有沒有被重錄、剪接、補錄；只驗真偽，不讀內容 |
| 《閂魂》 | 地階中級 | 波蒂爾 | 把犯規者自己的魂力關在體內一段時日；院內懲戒專用，不讀任何東西 |
| 靜聽 | 留白 | 松妮娃 | 在雷潮、獸潮裡聽出活魂的數目與方位；搜救用，聽不到內容 |

- **秘法**〔提案〕：〈加砝〉，燃魂。見下方檢查。
- **傳承載體**：《靜衡經》全本在院內〔既有，在世譜〕；**院律簿**，執律長老逐條記下院內每一次照魂，例如「照一息，未觸，未讀」〔既有〕。魂龕先祖：**留白**（原檔沒有提伊爾瓦魂院的龕）。

**《稱量》八條**

| 條 | 內容 |
|---|---|
| 源 | 魂修之道：《靜衡經》（天階低級）的鬥技，地階高級。燃料是魂力；兩界之魂同類，神識也量得到強弱（靈魂規則第 1 條） |
| 門 | 修為門檻留白（原檔只寫鬥聖中期的院長修成）。依靈魂境界變形〔提案〕：**照境**只稱得出身邊數丈內「有幾個魂、哪個重」，稱物也只稱得出魂印「在不在」；**靈境**魂離體成形，能把魂壓到對手身上，對手的魂會自己報出輕重，等於一次魂戰的開局；**天境**能壓住修為高過自己的魂，量出來的輕重可以當眾作準 |
| 象 | 施術者先靜，像在等秤停。周圍的飛蟲、夜蛾先繞過來〔家底庫〕。魂的場一圈圈往外擴（規則第 8 條推論），被量的人肩頭發沉，鬥氣在經脈裡慢半拍；旁人看得見對方身上鬥氣的光一明一暗，像秤桿在擺 |
| 契／器 | 不必兵器，也不必契。院長有蛾燈時，蛾燈的明暗替她報數，量得更遠更準〔提案；蛾燈本身只感強弱，既有〕。院內不養「器念」，聖土禁區 |
| 傳 | 能。同修《靜衡經》的人都可學；公會驗魂師修《魂秤錄》（地階中級），路數不同，學不了這一門〔提案〕。院外讀得懂原理，學不到的是天階低級的經 |
| 限 | 只量強弱，不讀內容（規則第 8 條、院規）；對已散之魂無效；跨兩格以上的魂只量得出「比我強」，量不出多強；量神識也一樣，量得到強度，讀不到裡面（陸沉一例） |
| 價 | 鬥技本身只耗魂力，養得回；代價在秘法〈加砝〉 |
| 萬年問 | 魂修的長進走靈魂境界那條軸，慢，而且低修為時打不贏同境的鬥氣修士；量出來的輕重又不能當證據，因為驗魂權在公會手上。修了一輩子，在法度上只算「旁人的意見」。所以大陸上的魂修少，天階魂修功法只此一部 |

**〈加砝〉八條**〔作者定〕

| 條 | 內容 |
|---|---|
| 源 | 《靜衡經》後篇秘傳一章，建在《稱量》上：秤不夠重，就往自己那一端加砝 |
| 門 | 修為門檻留白；靈魂境界**靈境**起可用：魂已能離體壓人。**天境**時能壓住修為高過自己的魂一時（天境本有此能，見靈魂境界對齊表），加砝讓這一時更長、更重 |
| 象 | 施術者周圍的飛蟲不再繞，整片落地；燈火、鬥氣的光同時往下一沉。被壓的人經脈裡的鬥氣停一口氣，化翼的會往下掉一截 |
| 契／器 | 載體是施術者自己的魂，不借火。院長若以蛾燈照著加砝，代價會多一層傷火；能不能這樣用，**留白** |
| 傳 | 只傳長老以上，每一次動用都記入院律簿〔提案，照院律簿既有寫法〕 |
| 限 | 一場魂戰只加一次；只壓不搜，壓下去的魂不會報出任何內容（院規、規則第 3 條：搜魂另是一門，院內不學）；殘魂、已散之魂不能用 |
| 價 | **燃魂**：魂力透支，事後數月魂虛，鬥氣控不穩；加得太重，靈魂境界退一段（天境退回靈境）。退了的段要從頭再養 |
| 萬年問 | 魂修的本錢就是靈魂境界，一次加砝可能燒掉幾十年。院內長老寧可輸一場，也不肯拿魂去換一場贏 |

## 五、家底（契與寶物）

## 十、歷代經驗

- **院規「只照不搜」**：院長伊爾瑟訂的，她自己守得最嚴〔既有〕。院律抄本寫明「非經閣下親許，不得以魂觸閣下」〔既有〕。
- **第一版驗魂案**：約三百年前索爾薇格在城盟議事主推，被公會以「魂修無藥理」駁回〔既有〕。院內學到的是：魂修要爭驗魂，得先證明自己懂藥。米蕾葉以八品魂丹掛徽，就是答這一句〔提案讀法〕。
- **索爾薇格那一戰**：她在凱斯卓痕緝拿私採客鐵的鬥尊，魂戰勝了，魂也傷了，閉關至今〔既有〕。院內的帳：贏了一場，賠上一位主將。
- 宗訓：留白。

## 十一、弱點

- **蛾燈只有一盞，在一個人身上**：伊爾瑟死，火回野，鎮院之火與鬥聖同時沒了〔既有通則〕。她壽元正盛，這是遠憂，不是近患。
- **最強的手段自己禁了**：只照不搜，查魂術亂象時束手束腳；龕販子達羅就靠這一點在 Nerholt 活下來〔既有〕。
- **乾淨的手要用晶**：魂晶的一部分出自戴洛家的礦籍勞工，本院是買家，不問來源〔既有〕。這件事一翻出來，「不搜」的清白就髒了。
- **商業手臂有後房**：達羅的「器念」走奧林維爾魂拍的後房〔既有〕。器念是聖土禁區〔既有〕；本院背書的商號在賣它，本院自己可能不知道。
- **傳功被看著**：傳功執事是王室暗子〔既有〕。
- **法度上輸一百四十次**：驗魂案年年遞、年年不過〔既有〕；閉關的前任主將魂傷，一出關，公會就拿「派傷魂之人爭驗魂」做文章〔既有〕。
- 北境天地能量「中」〔既有〕，化翼過寒原會凍損翼膜，北路要經諾洛兄弟會〔既有〕。

## 作者裁定（2026-10-02，全數照推薦）

1. **〈加砝〉是否採用**（秘法，燃魂，靈境起）。**推薦採**。本院現行沒有任何秘法，八條的「價」一欄空著；加砝只壓不搜，守得住院規，代價又正好落在魂修最在乎的靈魂境界上。
2. **蛾燈回野之後落在哪裡**。**推薦回北境魂晶礦**（它的原生地）。這樣魂晶礦分界就不只是錢：誰的界石圈住礦脈深處，誰就最靠近下一任院長要等的那盞火；諾洛兄弟會、德雷凡王室都有理由在伊爾瑟死前把界線往裡推。
3. **索爾薇格三百年前那一戰的魂傷，是不是加砝的帳**。**推薦是**（只作院內口傳，不改原事實）。它把秘法接到既有的歷史上，不新增人物；也說明為什麼院內長老「寧可輸一場」。若不採，〈加砝〉的萬年問照舊成立。
4. **院長以蛾燈照陸沉在第 19 篇還是第 20 篇**。人物檔 02 已依 v3 改為第 20 篇長住期，當代人物與第 14 號檔仍寫第 19 篇。**推薦照 02 的第 20 篇**，並同步另兩檔；本卡劇情鉤暫寫「19／20」。
