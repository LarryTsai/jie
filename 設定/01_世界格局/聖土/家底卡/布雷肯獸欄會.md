# 家底卡：布雷肯獸欄會

狀態：聖土寫手提案（2026-10-02），PM 派工。作者已定的項目逐條標「作者定」；其餘為提案，未經作者確認。

依[修仙文明底層規格](../../../00_故事定位/修仙文明底層規格.md)第 16 節卡片格式；能力先過「能力設計檢查條」八條（D076），照聖土體例改寫：功法與鬥技用天地玄黃，秘術稱**秘法**，「器」一條改作「契／器」（聖土沒有本命器，見[境界對照與跨界](../../聖土/境界對照與跨界.md)「秘法與契」）。兩界不換算。

標記：〔既有〕＝現行設定已有；〔家底庫〕＝[宗門與天驕家底庫提案](../../../06_待定與決策紀錄/宗門與天驕家底庫提案.md)第三節已寫、本卡沿用；〔提案〕＝本卡新設；**留白**＝沒有來源，不硬補。

**時點**：第二次聖土（第 19–20 篇），落潮後約二十二年。

**一句話**：獸欄會的家底是一欄肯跟它走的獸；它能契、能馴、能驗屍，卻契不了一頭說「不」的獸，也契不了一頭沒有核的獸。

---

**家底形態**：契獸＋契火〔家底庫〕。鬃火契在會首托拜亞身上，人死火回野〔既有：燧冊體例〕；八階契獸數頭〔既有〕，每一頭都是另一個活物，只有契連著〔既有〕。本卡補一句〔提案〕：獸欄會真正握著的是三樣「別人得經過它」的權：中嶺共管、深林驗屍、獸王錄合編；契獸是戰力，這三樣權才是它坐在一流的理由。

**看點**：人這一側只到鬥尊巔峰，獸那一側也只到八階；獸欄會的頂端是人與獸**並排**，不是疊起來。一頭八階契獸不會讓托拜亞變成半聖，只會讓他身邊多出一個鬥尊級的活物。這是本卡對「契獸算不算戰力」的讀法〔提案〕。

**《開欄》八條**（招牌；契與鬥兩層）

《同轡》是契，《開欄》是借契打的那一招〔既有：須先以《同轡》立契〕。兩層分開寫：**契**（立契、養契，誰契得到獸誰有）與**鬥**（欄門一開，人獸一起起步）。

| 條 | 內容 |
|---|---|
| 源 | 契：《同轡》（地階高級）〔既有〕，以靈魂立契、搭在魔核上〔既有〕。鬥：《開欄》（地階低級）（作者定），騎手的鬥氣順著契流進獸身〔既有，作者定〕。燃料是騎手的鬥氣，加上契獸核裡自己的力；會首領衝時再加鬃火〔既有〕 |
| 門 | 〔提案〕契：鬥師起能立低階獸契（菲昂鬥師四星與一匹角馬駒立了低階獸契〔既有〕）；契得到幾階，壓在契主境界對得上的那一階以下（魔核表一階對鬥者、六階對鬥皇、八階對鬥尊〔既有對照〕），因為搭核要以魂壓得住核。鬥：鬥靈起（鬥氣凝物，鬥氣才凝得成一股、送得過契）可帶一頭契獸開欄；鬥王化翼與《開欄》無關，騎手留在獸背上，這一招是地面的衝；鬥宗（空間之力）起，鬥氣不必貼身也能隔空順契送進整欄契獸，這才是「欄門一開，整欄衝出來」〔既有效果〕；鬥尊觸及規則，托拜亞以鬃火的「同騎」火性讓火附在獸身而不傷獸〔既有〕。獸欄會沒有鬥聖，鬥聖那一層**留白** |
| 象 | 欄門一開，人與獸同一步起〔既有〕。〔提案〕騎手的鬥氣色從掌下沿著獸的脊線流開，獸的鬃、甲邊緣浮起一層與騎手同色的薄光；整欄的蹄落與騎手的呼吸同一個拍子，一欄獸像一個人在跑。會首在時，鬃火貼在獸背上像鬃毛，跑在最前，不傷坐騎〔既有〕。門人沒有火，是不帶火的騎獸衝鋒〔既有〕 |
| 契／器 | 不是本命器。獸那一層是**契**：契獸是另一個活物，只有契連著〔既有〕；經魔核以《同轡》立契〔既有〕；獸有靈智也會選（D072 靈獸可拒絕的原則在聖土同樣成立）〔既有〕。〔提案〕六階開智起的獸聽得懂人意，契得下也走得了；八階可化形，能化而不一定化〔既有〕，化了就能用人話說不。契獸死，契斷，契痕留在契主魂上（與「契被奪走，契痕留在魂上」同理〔既有〕）。火那一層是鬃火的契，在托拜亞一人身上〔既有〕。鞍、轡、騎槍都是外物，可買可賣，人與器之間沒有命；把殘魂封進鞍具或兵器的「器念」是禁區，不做〔既有：禁區〕 |
| 傳 | 會傳：只有契了獸的門人會〔既有〕。招式寫得下來，契寫不下來：契不能傳，獸換主要重立契，而且要獸肯〔提案，依契的通則〕。所以騎乘魔獸大半出自此會〔既有〕，賣出去的是馴好的獸，不是《開欄》；買家沒有《同轡》，騎得上，開不了欄〔提案〕 |
| 限 | 沒有契獸就沒有《開欄》〔既有〕。搭不上核就立不了契：無核之獸《同轡》無處可搭〔既有〕。〔提案〕衝是直線的起步，最怕有人先在前面立欄：維拉丁劍廷《橫欄》一劍橫擺成欄，專擋群衝〔既有〕，兩家交手時這是天然的相剋。心谷是禁地，人不入心谷、不獵化形者〔既有：荊約〕，最強的獸從來不在可契之列。會首以外的人沒有鬃火〔既有〕 |
| 價 | 契：養一欄契獸的食料、欄地與人手，帳**留白**。鬥：一份鬥氣養兩個身子，騎手的鬥氣流進獸身就不在自己身上〔提案〕；契獸在衝鋒裡受的傷，契主的魂會跟著一震〔提案，輕於契火受創〕。重的代價在秘法〈點核〉 |
| 萬年問 | 騎乘魔獸大半出自它〔既有〕，八萬年來卻沒有一家靠騎獸衝鋒坐上頂級。〔提案〕三個原因：契獸的階壓在契主境界下，人到鬥尊、獸也只到八階，衝鋒不會讓人越級；鬥王以上自己會飛，騎獸是地面與獸潮線的招，到不了頂端的戰場；最強的獸是化形者與獸王，荊約護著，誰也契不到。獸欄會因此守的是獸潮最北一線〔既有〕，不是天下 |

**〈點核〉八條**〔提案〕

契主以契把鬥氣灌進契獸的魔核，讓核一時燒到牠自己撐不住的熱度，契獸短時間越出自己的那一階。

| 條 | 內容 |
|---|---|
| 源 | 《同轡》深層一章〔提案〕；載體是契與契獸的魔核。燃料是契主的鬥氣與魂，加上獸核本身的力 |
| 門 | 契主鬥宗起（空間之力，鬥氣不經皮甲、直接送進核）才點得動六、七階的核；鬥尊起點得動八階。只能點自己契的獸 |
| 象 | 契獸胸腹之間透出核的輪廓，隔著皮甲也看得見核在發光；獸身的力往上衝一截，蹄下或爪下的地先裂。會首點核時，鬃火燒到與核同色 |
| 契／器 | 承載的是契與獸核，不是兵器。**獸肯才點得起**：契是以魂立的，開智的獸不肯，核就閉著，鬥氣灌不進去〔提案，依「獸有靈智也會選」〕。六階以下獸性，不懂肯不肯；〔提案〕會規只許點開智之獸，理由寫在會規旁邊：只有說得出「不」的獸，才算問過 |
| 傳 | 只傳會首與鬥尊長老〔提案〕 |
| 限 | **一息**到數息；一頭獸一生點不了幾次〔提案〕。未契之獸點不了；化形後的契獸點不點，看牠自己 |
| 價 | **燃魂**：契主的魂墊在契上，一點一燒，靈魂境界可能退一段。**一息**：撐不久，過了就散。另有一筆不在人身上的帳：獸核上留裂，契獸折壽或掉半階（魔獸的力存在核裡〔既有〕）；這頭獸將來的核也落了價：八階核 Kell 平年一萬五至三萬當〔既有〕，帶裂的核錘廳出不出得了保，**留白**。最貴的一筆是獸記得：開智的獸被點過一次，下一次未必肯 |
| 萬年問 | 契獸是會的家底，點一次就花掉一截家底，而且花的是別的活物的命。八萬年沒有人把它當常規打法，因為點得越多，肯的獸越少。這一法在獸欄會是一頁「會首知道、輕易不開口」的秘傳。它也是托拜亞「愛到分不清愛與佔有」〔既有〕的那條線：一頭獸肯不肯，他問不問 |

## 五、法寶家底

聖土的獸欄會沒有法寶，只有火、獸、欄與幾本帳。不寫「本質品階／當前可用」，那是三十二天的六品〔既有：聖土不配六品〕。

- **鎮宗之物**：鬃火，燧冊第十五〔既有〕。貼在獸背上像鬃毛的火，不傷坐騎；火性「同騎」：與它契過的魔獸不懼火，火可附在獸身戰鬥〔既有〕。出處是索恩沃德中嶺火穴，**已枯**〔既有〕。契在托拜亞身上；他一死火回野〔既有：燧冊體例〕；回野去哪裡**留白**（見需作者拍板第 3 題）。
- **契獸**：八階數頭，契在會首〔既有〕。每一頭是否已化形、名字、品類**留白**。
- **欄**：馴好待售、待契的騎乘魔獸〔既有：騎乘魔獸大半出自此會〕；欄數、存數**留白**。
- **喉穴租火份**：鼓息（燧冊第十六，未收服）由霍洛貝克王室名義持有，獸欄會與兩個自由團輪流租火〔既有〕。租了做什麼**留白**；鼓息現行寫定的用處只有「借呼氣一刻煉成高溫丹器」〔既有〕。
- **器庫**：**留白**。

## 十、歷代經驗

- **荊約**：人不入心谷、不獵化形者；獸王不出谷、不率獸潮〔既有〕。兩王只打架、八階自己逃出來，八萬年來簽約方都承認這不算違約〔既有〕。
- **驗屍**：出林要驗，確認非化形〔既有〕。本卡讀法〔提案〕：這一條是獸欄會替荊約上的鎖，也是荊約給獸欄會的權。
- **不強取有主之獸**〔既有，托拜亞條〕。本卡推為會中不成文的規矩〔提案〕，依據是他「比誰都不能破這個例」。
- **會規**：只許點開智之獸〔提案，隨〈點核〉〕。
- **宗訓**：**留白**。

## 十一、弱點

- **火在一個人身上**：鬃火契在托拜亞，人死火回野〔既有：燧冊體例〕。出處火穴已枯〔既有〕，火回野之後連「回哪裡」都沒有現成答案（見需作者拍板第 3 題）。
- **頂端只到鬥尊巔峰**：沒有半聖、沒有鬥聖〔既有：最高戰力〕。一流的位子靠三樣權撐著〔提案讀法〕。
- **契獸會走**：開智的獸契得下也走得了；化形者能用人話說不〔提案，依 D072 原則〕。家底是活的，帳就不是死的。
- **權被兩邊拉**：王室要收回租火與配額〔既有〕，契約廳爭配額〔既有〕，自由團與冊籍人爭額〔既有〕。
- **荊約一改，獵額重算**〔既有：菲昂條〕。〔提案〕「化形者申訴」若成，驗屍權第一個被人質疑。
- **雷冠變薄的連帶**：雙蹄北移、嗡甲南擴、眼斑讓地，荊約的線一條條錯位〔既有〕；獵場在動，配額跟著動。
- **《同轡》的邊**：托拜亞一生的經驗在厄身上全數失效〔既有〕。沒有核，就沒有契。

## 需作者拍板

1. **〈點核〉採不採**。推薦採，標〔提案〕。它給獸欄會一個帶真代價的秘法（燃魂、一息，外加獸折壽、核落價），代價有一半落在別的活物身上，正好接托拜亞「愛到分不清愛與佔有」。「獸肯才點得起」把 D072 靈獸可拒絕的原則寫進機制，不必另立規則。
2. **八階契獸與荊約、三不拍**。八階能化形〔既有〕，荊約保護化形者、錘廳不拍化形魔獸〔既有〕；托拜亞卻開得出三頭八階契獸換厄。推薦讀法：三頭都**能化而未化**，不在荊約「化形者」名下；換厄是私下議價，不經錘廳；換主要重立契、要獸肯，所以那個價是他說得出、未必兌得了的價。不推薦把三頭寫成已化形，會撞荊約與三不拍。
3. **鬃火回野去哪裡**。出處中嶺火穴已枯〔既有〕。推薦**留白**到托拜亞之死真要寫時再定；不推薦現在補一個新火穴。
4. **契獸階壓在契主境界下**（本卡《開欄》「門」一欄的提案規則）。推薦定：托拜亞鬥尊巔峰契八階、菲昂鬥師契低階都對得上，也正好回答「為什麼騎獸衝鋒到不了頂端」。
