**家底形態**：鳶路＋雛翼譜編修權〔家底庫，經[改名提案](../改名提案_回瀾與四會鬥技.md)第 2.1 節更正：原寫「鎮宗絕學」，與現行設定不合〕。翼會是二流，會長鬥尊六星，全會鬥尊約三〔既有〕；沒有異火，不在燧冊〔家底庫〕。本卡補一句〔提案〕：鳶路是它的錢，雛翼譜是它的話語權。前者天天在收；後者五年收一次，收的是柯涅斯一整代年輕人的名次。

**《鳶跡》八條**（招牌）

| 條 | 內容 |
|---|---|
| 源 | 化翼後的鬥氣〔既有：化翼時鬥氣從翼尖拉出一道白痕〕。〔提案〕施術者讓翼尖那一縷鬥氣不收回氣旋，留在身後的空中，按這一條路的飛法擰成一股；這一股鬥氣帶著施術者的風勢，在一段時間裡把周遭的氣流順成同一個方向。後面的人沿痕跟飛，借的就是前人鬥氣擰好的這一道順流〔既有效果：借前人的風〕。燃料是領飛者自己的鬥氣，天地能量只是讓痕多撐一陣 |
| 門 | 鬥王起：要先化翼才有翼尖〔既有：鬥王化翼〕。〔提案〕鬥王只拉得出一條細痕，撐不久，跟得上的人少；鬥皇化翼凝實，痕更穩、更長，信使線的主力在這一層；鬥宗起動用空間之力，痕不再隨風散，能在一段空中定得較久，一位鬥宗領飛，可以替一整串鳶獸鋪一段路；鬥尊觸及規則，珀西瓦爾那一層做得到什麼**留白**。翼會沒有半聖、鬥聖，那兩層**留白**。跟飛的人不必會《鳶跡》，只要飛得起：化翼者、鳶獸都跟得上〔提案〕 |
| 象 | 一道白痕從翼尖拉出去，在身後慢慢淡掉〔既有〕。〔提案〕痕形照路走：從北崖出發的痕高而直，邊地南線的痕低而多折，同行看一眼就知道對方走哪一路、是誰教的〔既有：每條路痕不同〕。跟在痕後的人翼面平穩，像在順水裡 |
| 契／器 | 不是本命器，也不靠契。鳶獸是**馴**出來的坐騎〔既有：飛行魔獸可馴作鳶路坐騎〕，四五階尚未開智（六階才開智〔既有〕），本卡讀為不立契〔提案〕；翼會沒有獸契術的記載，現行唯一的獸契術《同轡》在布雷肯獸欄會〔既有〕。所以鳶獸死了，信使的魂不跟著一震；鳶獸換人騎也不必重立什麼〔提案〕。鞍、韁、信匣都是外物；把殘魂封進鞍具或信匣的「器念」是禁區，不做〔既有：禁區〕 |
| 傳 | 會傳，只傳化了翼的門人〔提案〕。招式寫得下來；每條路怎麼留痕，要隨老信使跟飛幾趟才學得會，靠鳶路圖加上口傳手傳〔提案〕。**痕人人看得見、人人跟得上**：這一招守不住祕，別家的化翼者也能跟翼會的痕飛〔提案〕。翼會守的是路，不是招 |
| 限 | 不走布蘭堡雷冠與邊地雷緣：化翼者在雷下最先挨雷〔既有，作者定〕。〔提案〕痕在雷域裡更糟：一道留在空中的鬥氣，雷會沿著它走，跟在痕後的整串人一起挨。封合縫上空劫雲壓頂，鳶路也繞開〔既有〕。痕留給自己人，也留給追的人：被追時拉痕，等於替對方指路。順風好用；逆風時痕被吹散，這正是林妮亞的《逆風》派得上用場的地方〔提案〕 |
| 價 | 領飛者的鬥氣一路往身後撒，前頭最累，後頭最省〔提案〕。長程輪換領飛，誰在前誰付帳。一趟急送下來，領飛的信使要數日才補得回鬥氣，這一筆算在鳶路運價裡〔提案；價目**留白**〕 |
| 萬年問 | 〔提案〕翼會八萬年來只做到二流，原因有三。一、《鳶跡》是送的招，不是殺的招，打起來不比別家強。二、鬥王以上人人自己會飛，跟痕只是省力，不是非跟不可；招守不住祕，賣不出絕學的價。三、天上有兩道蓋子，雷冠與劫雲，翼會的路永遠繞著走；最值錢的那一段天，火井上空，從來不歸它〔既有：雷冠是鍛廳的天然屋頂〕。所以翼會沒有把招做大，而是把**路**和**名冊**做大 |

**〈焚翎〉八條**〔作者定〕

信使送不到時的最後一手：把雙翼一口氣燒成一道痕，換一段越出自己的急飛。

| 條 | 內容 |
|---|---|
| 源 | 《鳶跡》深層一章〔提案〕；載體是化翼本身。平常的《鳶跡》只放出翼尖一縷，〈焚翎〉是把整對翼的鬥氣從翼根往翼尖一路推出去，全數化成推力，人借這一推射出去 |
| 門 | 鬥王化翼起才有翼可燒；鬥皇化翼凝實，才燒得出夠長的一段。信使線上真正用得起的是鬥皇以上〔提案〕 |
| 象 | 雙翼從翼根起一節一節變白、變薄，最後整對翼化成一道極亮的白痕，人在痕的最前端；身後的痕粗而短，一過就散，不像《鳶跡》能讓人跟 |
| 契／器 | 承載的是化翼與氣旋，不是兵器，也不是契〔提案〕。坐鳶的人用不了：燒的是自己的翼，鳶獸的翼燒不得 |
| 傳 | 只傳正式信使，以會規約束〔提案〕 |
| 限 | **一息**：那一推燒完就沒了，餘下的路只能滑落或落地〔提案〕。燒過之後數日內化不出完整的翼；在半空用，就得在落地前想好怎麼落。雷冠、雷緣之下照樣不能用：那道痕最亮，雷第一個找它〔提案，依「化翼者最先挨雷」〕 |
| 價 | **燃壽**：翼是氣旋撐出來的，一口氣燒盡，氣旋受震，以年去還〔提案〕。**一息**：撐不久。另有一筆翼會的帳：信使燒翎後一段時間不能飛，鳶路得另調人頂班〔提案〕 |
| 萬年問 | 只有「送不到比自己受傷更糟」的人才會燒〔提案〕。它不是戰鬥的底牌：燒完就落地，落地就是打不了的人，所以八萬年來沒有人拿它爭勝，只拿它送信、逃命。〔提案〕會規只許「為信、為人」燒翎，不許為名次燒。林妮亞想第一個飛越雷冠〔既有〕，正好卡在這條會規與珀西瓦爾「不准私飛」〔既有〕的夾縫裡 |

## 十、歷代經驗

- **化翼者在雷冠下會被雷優先擊落，這是八萬年的規則**〔既有〕。翼會的鳶路圖整部是繞著這一條畫的〔提案〕。
- **上譜須有薦**〔既有〕。本卡讀法〔提案〕：這一條是翼會的護身符：名次由別家具名擔保，翼會只編不保；刪了它，每一修的名次都要翼會自己背。這是它年年被否決的理由，也是歐雯年年提案的理由。
- **四十歲線**〔既有〕：四十歲是天才能踏進鬥宗的極限〔既有〕。
- **不准私飛**：珀西瓦爾不准林妮亞私飛，她一出事，借天書就再也遞不出去〔既有〕。〔提案〕推為會中通例：信使出事，翼會在談判桌上就少一張牌。

## 十一、弱點

- **頂端只到鬥尊六星**〔既有〕：二流，鬥尊約三〔既有〕。位子靠路與名冊撐，不靠打〔提案讀法〕。
- **天上有兩道蓋子**：雷冠、劫雲〔既有〕。東北鳶路的鑰匙在鍛廳手上；屋頂之夜後，更在一個不在聖土的人身上〔既有，作者定〕。
- **門環**：平時門環比鳶路穩、比鳶路大〔既有：中心收編邊地的物理手段〕；鳶路只在門環停擺時是唯一。
- **譜的名聲**：最常被罵的是薦書這一條〔既有〕；邊地抱怨四十歲線〔既有〕。〔提案〕雛翼譜的分量建在「大家照譜提親挖人」上；哪天大家不照了，這份家底就沒了。
- **自編自薦**：翼會既編譜、又有薦書資格、又有人在譜上〔提案讀法〕。
- **把最快的人拴著**：林妮亞想第一個飛越雷冠〔既有〕，會長不准〔既有〕。翼會最好的年輕人，也是它最可能出事的人。

## 作者裁定（2026-10-02，全數照推薦）

> 鳶獸：馴，不立契；部分購自布雷肯獸欄會。東北鳶路統一為「穿過雷冠」：冠關著時路就斷，所以第 20 篇之後到第 27 篇之前不通，這是陸沉的選擇欠下的一筆帳。


1. **〈焚翎〉採不採**。推薦採，標〔提案〕。它是信使的秘法：燃壽加一息，燒完就落地，只能送信、逃命，不能爭勝，正好說明翼會為什麼一直是二流；「為信、為人」的會規又把林妮亞的欲望和珀西瓦爾的禁令接在同一條線上。
2. **鳶獸是馴還是契**。推薦**馴，不立契**：現行寫的是「可馴作鳶路坐騎」〔既有〕，四五階未開智，翼會也沒有獸契術。這樣翼會與布雷肯獸欄會分得清楚：獸欄會的家底是契，翼會的家底是路。不推薦讓翼會也立契，會和《同轡》撞。
3. **鳶獸從哪裡來**。推薦**留白**，或寫成部分購自布雷肯獸欄會〔提案〕：「聖土騎乘魔獸大半出自此會」〔既有〕包得下飛行坐騎，兩會多一條買賣線。不推薦另立新的鳶獸產地。
4. **東北鳶路是「繞過」還是「穿過」雷冠**。總表與當代勢力寫「繞過雷冠」，林妮亞條寫「飛越雷冠」，屋頂之帳寫「冠開時讓出」〔既有〕。推薦統一為：路要從冠開的縫底下穿過，所以要鍛廳點頭、要冠開；「繞過」改為「穿過」。若保留「繞過」，就要另交代繞路為何也得鍛廳點頭（例如鍛廳管布蘭堡上空），不推薦。
