**時點**：第二次聖土（第 19–20 篇），落潮後約二十二年。

**一句話**：一場考試，考官手裡握著火〔家底庫〕。公會沒有山門可守，守的是幾張紙：徽、籤、驗魂錄、燧冊；紙背後壓著一朵只管保溫的火〔提案〕。

---

**家底形態**：制度作家底＋契火〔家底庫〕。制度是品階考核與爐紋徽、藥份與藥籤、驗魂師授印與驗魂錄、燧冊火驗與丹品錄〔既有〕；契火是伏燼，燧冊第三，契在會長奧德倫身上〔既有〕，人死火回野〔既有：燧冊體例〕。本卡補一句〔提案〕：公會的家底是「誰說了算」：誰算幾品、誰能簽藥、誰的死入得了冊、哪朵火排第幾。伏燼只做一件事，讓這些紙上的東西在時間裡不走樣。

## 四、傳承

- **根本功法**：公會沒有一部全員主修的會傳功法〔提案〕：煉藥師各帶各的火功法入會（柯林、卡特琳都是「普通火功法」〔既有〕），公會傳的是丹方、考題與章程。上層的功法是個人的：
  - 《灰爐經》，**地階高級**，奧德倫〔既有〕。
  - 《封樣訣》，**地階高級**，麗絲貝〔既有〕。
  - 《魂秤錄》，**地階中級**，驗魂師安布羅斯所修〔既有〕；本卡推定〔提案〕它是驗魂師一線的通修。
- **丹術**（丹術不分天地玄黃；現行未給階，照舊不給）：冷封（麗絲貝，讓藥液停在封存那一刻）、《分劑》（葛蕾塔，一爐分百份）、《古方還溫》（馬格努斯）、《候息》（英格瓦）、以核入藥按核質分劑（阿爾多）〔既有〕。
- **護丹**：煉藥師的本事，不讓丹雷落在丹上〔既有〕。七品起加考丹雷，考場在露天火臺〔既有〕。
- **魂技**：《讀印》，安布羅斯，讀魂印的年代與層次〔既有〕；階**留白**。
- **鬥技**：現行沒有公會記名的鬥技，**留白**。奧蒂莉以紡錘火絲纏住對手鬥氣外放之口一條，見[家底庫補遺](../家底庫補遺_聖土天驕.md)第 31 條（提案）。
- **秘法**〔提案〕：〈伏丹〉，見下方檢查。
- **傳承載體**：
  - **靜室庫**：驗魂錄、問魂魂晶（含王室封段）、古戰驗傷記錄，八萬年前封存的驗傷藥液樣本〔既有〕。雙鑰（奧德倫、麗絲貝），第三個簽名是庫吏〔既有〕。
  - **燧冊火驗錄、丹品錄**：火驗由公會出、火史由佩魯書院出〔既有〕；丹品錄隨燧冊同修、每年補錄新晉八九品〔既有〕。
  - **考場封樣**：五六品考成丹後當場封樣，存一年備查〔既有〕。本卡把它也列為載體〔提案〕：一年一年的封樣，是公會手上「誰煉得出什麼」的實物帳。
  - **章程卷首**：「魂、核、火三物，不收、不拍、不煉予界外之客」〔既有〕。沒人說得出當年防誰〔既有〕。
  - **溫德港舊分會**：古時溫德港分會編有一冊燧冊，隨城沉沒〔既有〕；舊分會庫封冊由陸沉帶回〔既有〕。
  - 丹方的藏處與等級**留白**。

**〈封樣〉八條**（招牌；手藝、火、章程三層）

「真動手時先封樣」〔家底庫〕是公會的招牌，也是它的家底怎麼運轉。三層分開寫：**手**（封樣的丹術，掛徽者都學過）、**溫**（長年封存的恆溫，只有伏燼給得出）、**章**（封樣入庫、雙鑰、存年，誰簽才算數）。

| 條 | 內容 |
|---|---|
| 源 | 煉藥師靠靈魂控火〔既有〕；封樣是把魂力與火收成一層殼，把藥液與丹氣關在裡面〔提案〕。頂端是麗絲貝的《封樣訣》（地階高級）與冷封〔既有〕。長年的恆溫靠伏燼「伏」的火性：灰下伏燒百年、溫度分毫不差〔既有〕 |
| 門 | 走品與靈魂境界，不走鬥氣〔提案〕。蟄境（約一至三品）：魂只在體內，只封得住自己爐裡剛成的丹，出爐不散。照境（約四至六品）：魂照得出身外數丈，封得住一爐之外的藥液；五六品考成丹當場封樣就在這一格〔既有：考制〕。靈境（約七品，驗魂師門檻）：魂離體成形，可隔著別人的爐封，也看得出一份封樣有沒有被動過〔提案〕。天境（九品多在此）：冷封，藥液連表面的晃動都停在封存那一刻〔既有效果〕。帶狀照[靈魂術與證據](../靈魂術與證據.md)，是常見，不是規定〔既有〕 |
| 象 | 伏燼是灰白而安靜的小火，平時伏在灰下，像已經熄了〔既有〕。〔提案〕封樣時爐口的火光一暗，丹師的魂力收成一層薄殼；封好的樣灰白、無光、摸上去是溫的，像蒙了一層灰。公會的人一出事，先把現場的藥、丹、殘渣封起來，再談誰對誰錯 |
| 契／器 | 不是本命器。溫的那一層是**契**：伏燼契在奧德倫〔既有〕，他死火回野，要重新立契，火會選〔既有：契的體例〕。手的那一層不靠契，丹爐、封匣都是外物〔提案〕。公會封藥、封火匣、留魂晶〔既有〕，不封魂入器；「器念」是禁區〔既有〕 |
| 傳 | 手能傳：從城分會到大區分會，封樣是考題的一部分〔既有〕。冷封只見於麗絲貝一人〔既有〕，傳給誰**留白**。溫不能傳：伏是火性，不是手藝〔提案〕；各分會的母火種與長年封樣都靠伏燼續命〔既有〕。章能被借：丹路的押倉章程替回藥背書，藥倉封存陣替伯特倫遮手〔既有〕 |
| 限 | 只管保溫，不還原任何東西〔既有〕：封得住，救不回。封不住雷：雷近不了身，薇琳在火驗錄上寫「不可近身，不驗」〔既有〕。封不住魂：留魂靠及時收進魂器，與封樣無關〔既有：收魂規則〕。封存陣要人按月押陣眼，不押就從陣縫漏藥〔既有，15 號檔〕 |
| 價 | 考生：封樣存一年備查，那一年那爐丹不算你的，算公會的〔提案，依考制〕。公會：母火種與長年封樣的恆溫全吊在一朵火、一個人身上〔既有〕；奧德倫一死，伏燼回野，續命斷在哪一天**留白**〔提案推論〕。冷封每封一份耗多少魂力**留白** |
| 萬年問 | 八萬年沒人搶這份家底，因為能搶的只有火，而火只管保溫〔既有：火性〕；搶走伏燼，得到的是一朵恆溫的小火和一庫沒人承認的封樣。真正值錢的是「誰簽才算數」：徽、籤、驗魂錄只有公會簽才入得了冊〔既有〕。所以公會的家底被挑戰時，挑的是簽的權，不是打的贏：伊爾瓦魂院要驗魂權〔既有〕，邊地要自簽藥份〔既有〕，沒有人要伏燼 |

**〈伏丹〉八條**〔作者定〕

契主以伏燼把將成之丹整爐壓進灰下，丹氣不往上衝，丹雷找不到落點。護丹的最後一手。

| 條 | 內容 |
|---|---|
| 源 | 伏燼「伏」〔既有〕，掛在《灰爐經》（地階高級）〔既有〕之下〔提案〕。機制照雷與火「火生於聚取，雷生於逆撞」〔既有〕：丹雷是成丹的丹氣衝上冷天撞出來的；把丹氣伏在灰下，撞不起來〔提案〕。燃料是契主的魂力與伏燼本火 |
| 門 | 只有契主能用。品與魂：九品、天境，魂要蓋得住一整爐的丹氣。鬥氣：鬥宗起（空間之力）才壓得住一座火臺連同上方一段天；奧德倫鬥聖初期一星，壓一座火臺有餘，壓一城萬爐不夠 |
| 象 | 火臺上的火一齊暗下，爐口浮一層灰；天上已聚起的雲找不到落點，散成幾聲悶雷。丹出爐時溫而灰白，沒有丹雷落過的焦痕。契主臉色跟著灰一層 |
| 契／器 | 承載的是伏燼契，不是丹爐。丹爐是外物 |
| 傳 | 不傳，也傳不了；伏燼回野期間無人能用 |
| 限 | 只在契主身邊的一座火臺。契主在 Corlay，邊地的爐輪不到：Tavistel 那一爐撫恤藥份引雷，只能靠人上臺去接〔既有：場面〕。一爐丹從聚雷到成丹只能伏一次，雷勢比魂強時伏不住〔一息〕 |
| 價 | **燃魂**：契主整爐蓋著，魂力透支，靈魂境界可能退一段（秘法體例〔既有〕）。**傷火**：伏不住而雷仍落下時，雷落在灰上，伏燼受創，契主的魂跟著受創。另一筆帳不在人身上：每伏一爐，會長就多守一爐，離不開 Corlay |
| 萬年問 | 公會最好的護丹只在一座火臺上、一個人手裡。八萬年來，Corlay 的九品爐引雷有人伏，邊地的爐炸了就是一年〔既有：邊地炸爐〕。這一法讓「中心丹穩、邊地丹苦」不只是章程，也是火的位置。奧德倫私下說自己「守了太多爐」〔既有〕，本卡讀作這一句的底〔提案讀法〕 |

## 五、法寶家底

聖土的公會沒有法寶，只有火、庫、紙。不寫「本質品階／當前可用」〔既有：聖土不配六品〕。

- **鎮會之火**：伏燼，燧冊第三，原生於 Corlay 地底古窯，契在奧德倫〔既有〕。
- **名義所屬、未取回**：恆爐，燧冊第十三，「不動之火」，以它為母火分出的子火萬爐同溫；沉於溫德港公會舊分會，八萬年未取回〔既有〕。當代勢力檔稱「鎮爐火」，本卡推定同指〔提案〕。
- **會內持火者**：岔芯（薇琳，第十七）、紡錘（奧蒂莉，第二十二）〔既有〕。火契在個人，不在公會〔既有：契的體例〕。
- **末席沼燈**：未收服，芬萊沼採火站捕養中〔既有〕。
- **靜室庫**〔既有〕：見第四節。
