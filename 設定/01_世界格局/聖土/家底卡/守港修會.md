**家底形態**：寶物（異火）＋人（名分）〔家底庫〕。寶物是誓屏，契在會長瑟維林身上，人死火回野〔既有：燧冊體例〕；人是一萬二千門人與一千一百戶冊籍，靠撫恤份額修行〔既有〕。本卡補一句〔提案〕：守港修會真正的家底是一條規矩，「寄物即身分」〔既有〕；火、人、席、份都從這條規矩長出來，翻案拆掉的也是這條規矩的一角。

**〈行垣〉八條**（宗門招牌；名與品階作者定）

會走的城牆：門人的鬥氣鎧肩並肩連成一道垣，整道往前推，人在牆後不出手；會長在陣時，前面多一面誓屏之火（《擋孤》）〔既有〕。

| 條 | 內容 |
|---|---|
| 源 | 鬥氣外放成鎧，鎧緣與鄰人之鎧相扣，眾人步與氣同律〔既有：效果；扣與同律為提案〕。燃料是每個門人自己的鬥氣；垣首的鬥氣定律〔提案〕。不掛《護脈經》：門人人人可學，不需名額〔提案〕 |
| 門 | 〔提案〕大鬥師起有鬥氣鎧甲（境界對照「形變穩固」〔既有〕），可入列。鬥靈起鬥氣凝物，鎧緣凝得出扣，才算真正連成垣，否則只是一排並肩的人。鬥王化翼對垣沒有用，垣上的人不飛。鬥皇可領一段（垣首），奧雷爾以鬥皇八星領《連營》即其小樣〔既有：連營〕。鬥宗起以空間之力把一段垣隔空扣緊，整段同步前推，不是一步一步挪。鬥尊觸及規則，可承住整道垣的受力。修會無鬥聖，鬥聖一層**留白** |
| 象 | 一道齊肩高的鬥氣牆，接縫處最亮；推進時千人一步，腳步同聲〔提案〕。會長在陣，牆前立起一面像牆的厚火（誓屏的樣子〔既有〕）。奧雷爾的鎧上刻修會「遺民承祀」的紋〔家底庫〕；賈戈的鎧比同門厚一層，最外一層總留一個缺口〔家底庫〕 |
| 契／器 | 不是本命器，也不是契：垣是眾人的鬥氣，散陣就沒有。鎧是鬥氣，不是器；考弗戴爾織坊的軟甲是外物，可買可賣〔既有〕，人與甲之間沒有命。火的那一層是**契**：誓屏契在瑟維林身上〔既有〕；垣能學，火不能學 |
| 傳 | 門人通用，能傳〔提案〕。所以翻案之後、瑟維林不在陣中，封門派照樣結得出垣：第 27 篇奧布里以「鬥氣鎧與守港修會的守禦鬥技，結陣推進」〔既有〕。他們帶走的是垣，帶不走火 |
| 限 | 要人數、要同律：一處斷了扣，整段失律〔提案〕。垣是平推的，**頭頂沒有屋頂**〔提案〕：會飛的、能隔空的對手繞得過去。窄地展不開，河階三條來路各只容一段〔既有：三條來路〕。沒有鬥尊領陣時承不住鬥尊一擊（第 27 篇封門派正是如此，鬥尊不入河階〔既有〕） |
| 價 | 每人的鬥氣持續外放，撐垣比打架費氣〔提案〕。扣把受力分給整排，一擊打在垣上，整排人的經脈都震一次〔提案〕；垣不讓一個人死，也不讓一個人單獨扛。牆後的人不出手〔既有〕：垣只守、只推，不還手 |
| 萬年問 | 一道會走的牆為什麼八萬年沒推出中心？因為垣的厚度就是份額的厚度〔提案〕：一萬二千人能修到結得出垣，靠的是撫恤份額〔既有〕；份額一斷，垣就薄。修會沒有鬥聖，鬥聖觸法則一擊破的是整道垣，強者也從沒把它當威脅（戰力表第十一〔既有〕）。它要守的從來不是地，是名分；名分不必打，只要投票（芸香席十三席，「永不重開」八萬年全數通過〔既有〕） |

**〈覆垣〉八條**〔作者定〕

會長把誓屏之火順著垣的扣鋪到整道垣上：不再是陣前一面火，而是每一副鎧都帶著誓屏的「屏」性，壁後的人不受火與鬥技直擊〔既有：屏的火性〕。

| 條 | 內容 |
|---|---|
| 源 | 《擋孤》的延伸，會長一線口傳〔提案〕；載體是誓屏之**契**與一道完整的《行垣》。燃料是會長的鬥氣、契火，以及垣上眾人的鬥氣（火順著扣走，借的是他們的氣） |
| 門 | 只有誓屏契主能用。鬥宗起可承（空間之力把火隔空送到垣的每一段）；鬥尊觸及規則，屏性才鋪得勻，不只是一層薄火。瑟維林鬥尊巔峰，鋪得滿一整道垣〔提案〕 |
| 象 | 陣前那面厚火忽然矮下去、拉長，沿著垣的接縫一路燒過去；千人的鎧上同時浮起一層火，像一面牆披上一面牆。會長本人站在垣後，身上的火光反而淡了〔提案〕 |
| 契／器 | 承載的是誓屏契，不是任何器。鋪火時契主與誓屏的連繫被拉到最長，任何一段垣破，火就從那裡受創 |
| 傳 | 只傳會長；誓屏回野期間無人能用〔提案〕。瑟維林死後火認不認人**留白**（見需作者拍板） |
| 限 | 垣在才鋪得開，垣一斷，火回縮到斷口〔提案〕。一次只撐一陣，撐不過一場鬥尊全力的對撞〔提案〕。在雷緣用即是鬥尊全力出手，引動劫雲餘波〔既有：雷緣規則〕 |
| 價 | **傷火**：火拉得越長越薄，垣上任何一處被擊穿，誓屏受創，契主的魂跟著受創〔既有：傷火機制〕。**燃壽**：鬥尊巔峰全力一戰以年還帳〔既有：補給率表〕；瑟維林約八百歲，壽元約一千〔既有，候選表〕，每用一次都在花剩下的年。另有一筆名分的帳：火鋪到冊籍子弟的鎧上，等於會長拿自己的命替「遺孤後人」作保〔提案〕 |
| 萬年問 | 冊沒破的八萬年裡，修會從沒需要拿全會去擋什麼；它守的是票，不是城。翻案之後，最想用這一法的是封門派，偏偏他們沒有火：瑟維林不在其中〔既有〕。這一頁在修會是「會長才知道、會長不想用」的口傳 |

## 五、法寶家底

聖土宗門沒有法寶六品，兵器是外物〔既有：聖土不配六品〕。守港修會的家底是一朵火、一座龕、一間庫。

- **鎮宗之物**：誓屏，燧冊第十九〔既有〕。立起來像一面牆的厚火；火性「屏」：火成壁，壁後的人不受火與鬥技直擊〔既有〕。所在 Marrowgate 山門，古戰後所得；修會稱它是「替遺孤擋火的火」〔既有〕。契在瑟維林〔既有〕。
  - **火史**：修會說誓屏是「古戰後遺孤獻給宗門的火」；佩魯書院火史卷只寫「得於古戰後，來源存宗門自述」，翻案時隨冒籍案一起被重查〔既有〕。
  - **回野**：修會內從沒有人問過瑟維林死後誓屏回到哪裡〔既有：候選伏筆〕。誓屏有無靈智、擇主時會不會拒人，**留白**。
- **遺孤龕**：Marrowgate 魂龕祠群，全大陸最大〔既有〕。供魂牌，不供兵器。
- **寄物庫**：一千一百戶的魂牌與寄物〔既有〕，以《驗封》封存〔既有〕。寄物即身分，所以這間庫的帳面價值就是修會的全部份額〔提案〕。翻案後瑟維林第一個交出本修會魂牌寄物受驗，霍諾拉開庫〔既有〕。
- **器庫**：**留白**。
- **魔獸**：無契獸〔既有：不在獸契一線〕。

## 作者裁定（2026-10-02，全數照推薦）

1. **〈覆垣〉採不採**。推薦採，標〔提案〕。它讓誓屏（火）與《行垣》（人）兩樣家底接在一起，代價是傷火與燃壽，正好壓在一個在位末期的會長身上；也讓第 27 篇的封門派有一個看得見的缺：會結垣，沒有火。**不推薦**讓它在第 19 篇登場：約戰的是多蘭，不是瑟維林，現行場面已經自足。
2. **誓屏回野時會不會拒人**。推薦暫留白，等佩魯書院重查火史的結果再定。若要定，推薦「誓屏有靈、會選」，與坩主同例；這樣「修會內從沒有人問過火會去哪」才有分量，也不必先寫出火史的答案。
3. **《行垣》的入列門檻**。推薦照本卡：大鬥師有鬥氣鎧甲即可入列，鬥靈凝得出扣才算成垣，鬥宗起能隔空扣緊整段。這樣一萬二千門人大半都在陣裡，「城牆在往前推」才推得動。
4. **翻案後的席次與份額**。推薦只寫方向、不寫數字：冒籍席剔除、帕杜家兩席保留、份額由哈特利重算都已有來源；修會丟了幾席、是否跌破二十一席的過半，留白到寫翻案後的議事場時再定。
