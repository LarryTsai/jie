**一句話**：卡洛陣會的家底是一道攔河堰。堰蓄的靈力養六千門人，也替門環西樞供力；關堰，邊地先斷門〔既有〕。它不是在搶，是在守一份合法的契，契上只寫了堰內〔既有，03〕。

### 《報堰》八條（作者定：地階中級）

| 條 | 內容 |
|---|---|
| 源 | 陣道。《堰經》堰務篇下的鬥技，地階中級〔既有〕。機制〔提案細化〕：修士以鬥氣在身前布一道閘形陣紋，把自己的鬥氣分段攔住；報出的「第幾閘、蓄幾分」就是陣紋上的刻度。蓄到報定的分數，閘一開，一口氣放出〔既有大意〕 |
| 門 | 〔提案〕最低**鬥靈**：鬥氣凝物，閘才立得住，這是一道結構。鬥王、鬥皇：可連布兩三閘，前閘放、後閘蓄。**鬥宗**（空間之力）：閘不必立在身前，可落在對手頭頂或背後的空間裡，水從對手看不見的那一側落下。鬥尊以上的門人多轉修《衡閘》或自創，不再以《報堰》為主 |
| 象 | 出手前先報數：「三閘，七分。」〔既有〕身前空氣起一道道淺紋，塵土被攔成一條直線；放的那一刻，一整片鬥氣像開閘的水落下。對手聽得見他在報數，卻擋不住整片落下來〔既有，改名提案〕 |
| 契／器 | 不需契火（太上本人不契火〔既有〕，宗風如此）。〔提案〕鬥靈至鬥皇多帶一面隨身**陣盤**刻閘紋，替自己記分數；陣盤是外物，四階核級〔生活魔核表：四階用於陣盤〕，壞了換一面，人不受傷。鬥宗起以空間之力落閘，可以不用盤 |
| 傳 | 門人通用〔既有〕。閘紋的陣理是聖土陣修共通的，外人看幾次能仿個樣子；仿不到的是堰務篇的「量」：報七分就要是七分，多一分閘裂，少一分放不滿。外人學得到招，用不準 |
| 限 | 要報、要蓄，出手前有一口氣的空檔；快攻打進這一口氣，閘未滿就得放或散〔提案〕。雷潮打亂空間的地方（雷緣；西樞受擾時〔既有：雷潮打亂西樞〕），鬥宗段的空間落閘落不準〔提案〕。埃凡德數字一對不上就先停手再算〔既有，家底庫補遺〕，這是招的毛病，也是人的 |
| 價 | 只耗鬥氣，不是秘法。蓄滿而未放（被打斷），攔住的鬥氣回衝自己經脈，這一戰內提不起第二閘〔提案〕 |
| 萬年問 | 聖土鬥技講快，生死戰裡一口氣的空檔太長；《報堰》是守站、守閘、守陣的人用的招，追不了人。陣會六千人都是守陣的人，所以人人修；別家沒有那麼多陣要守，也沒有堰務篇教他們量 |

### 〈傾堰〉八條〔提案〕

| 條 | 內容 |
|---|---|
| 源 | 《堰經》堰務篇秘傳一章〔提案〕。修士以鬥氣接上大堰或門環一座陣站的陣紋（同出《堰經》，接得上），把陣中所蓄的靈力在一息之間倒灌進自己的氣旋，一擊放出。借的是堰的力，不是自己的 |
| 門 | 〔提案〕最低**鬥宗**：要空間之力才能隔著距離接上陣紋。鬥宗只接得上次環一站；鬥尊接得上主環一站；半聖以上才接得上大堰本身。布里森有《閘》，用不著它 |
| 象 | 施法者身邊的陣站陣紋一暗；同一刻遠處一座門少開一陣，排隊的人看見門前的光滅了一下〔提案〕 |
| 契／器 | 必須站在一座陣站或陣樁旁邊，離開卡洛陣網就無處可接〔提案〕。不靠契火；陣盤只是接口，不承載那一股力，力全過人身 |
| 傳 | 只傳堰務一系與門環總司一系的真傳弟子〔提案〕；名單**留白** |
| 限 | 只撐一息；出了 Carrowmere 與門環各站就用不了；**校準夜七日全環停擺，用不了**；雷緣、雷域裡沒有陣站〔提案〕 |
| 價 | **燃壽**加**一息**：借來的靈力過身，以年還帳（借力者壽短，D063；對照「秘法與契」燃壽條）。第二筆帳記在堰帳上：每傾一次，就是一筆沒有份額契撐腰的抽脈，從西樞的供力裡扣，邊地那天少開一門〔提案〕 |
| 萬年問 | 只能在卡洛的陣網上用，出了網就是空話；用一次燒自己的壽，還讓等在門前的邊地人多等一天。鮑德溫說過門環停一天就有人等死在門前〔既有〕，所以陣會裡真敢用的人很少，用了的人被堰帳記一輩子 |

## 五、法寶家底

- **鎮宗之物**：**大堰陣** the Great Weir，護山聚靈大陣，像一道攔河堰，攔住自中心西流的地脈，蓄在福地〔既有，勢力〕。綁地，不能搬。聖土的陣不配法寶六品；聖土陣法有無分階，現行設定未寫，品級**留白**。
- **陣眼**：喬瑟林·歐蒙以身壓陣兩百年〔既有〕。大堰要加高一層，他就得出關，陣眼要換人〔既有〕。
- **門環**：空間傳送陣網；主環連五國首府與 Corlay、Brask、Kell，次環連大城〔既有〕。主樞在 Highcairn，與維拉丁劍廷合管〔既有，01、勢力〕。通邊地只有三門：Tavistel→Elsby（西，撫恤與雷望衛專線，由大堰供力）、Kell→Hollowbeck（東，魔核線）、Ivel→Grisport（南，商線）〔既有〕。
- **門環陣盤**：奎倫船塢供應〔既有，07〕；用七階魔核（鬥宗級，一枚兩千當以上）〔既有，生活魔核表〕。
- **器庫**：**留白**。
- **契火、契獸**：太上不契火〔既有〕；其餘**留白**。現行燧冊沒有卡洛陣會的條目。

## 六、資源

- **西流主靈脈份額**：有契，合法〔既有〕。抽脈是「合法份額的過度使用」，是資源問題，不是正義問題〔既有，勢力〕。
- **大堰所蓄的靈力**：一份養門人，一份供門環西樞〔既有〕。比例**留白**。
- **抽脈的下游**〔既有，地理、撫恤、03〕：
  - 地脈自東向西，經大堰、索瑞爾山脈，再沒入雷域。
  - 索瑞爾**東坡**新芽年年枯死；老樹根深撐得住，新芽搶不到地氣。邊地一整類鬥皇到鬥宗的破境丹材因此斷產，邊地鬥宗梯隊正在斷。
  - **西坡**、雷域邊緣內側的靈果林是接穗長根，不靠地氣，所以活著〔既有〕。
  - 中心這一側，潘尼克的田水也跟著減〔既有，16〕。
- **數字不在自己手裡**：大堰歷年抽脈的丈量數字在泰薩利家〔既有〕；首席丈量師吉迪恩量了大堰三百年數字的大半〔既有，06〕。

## 十、歷代經驗

- **只信丈量**：布里森最恨別人說「大概」〔既有〕。
- **契上沒寫的不量**：艾斯佩絲量遍堰內每一寸，從沒量過堰外下游一步；量了，就等於承認下游屬於堰的責任，全會的份額契都要重談〔既有〕。
- **門不能停**：門環停一天，邊地就有人等死在門前〔既有，鮑德溫〕。
- **私人長距陣是重罪**〔既有，地理〕；卡洛陣會是這條規矩最直接的受益者〔提案讀法〕。
- 宗訓原文、吃過的虧：**留白**。

## 十一、弱點

- **大堰不能關**：關堰，西邊地先斷門〔既有〕。這是護身符，也是綁住它的繩。
- **契只寫了堰內**：下游一被量，全部份額契要重談〔既有〕。泰薩利家公開調數、埃凡德的抽脈報告，都在往這一步推〔既有〕。
- **加高要換陣眼**：喬瑟林得出關，陣眼要換人〔既有〕。誰來壓、壓多久，**留白**。
- **校準夜七日**：全環停擺，天上空間裂紋如網〔既有〕；私陣人博德金趁這七天開陣運貨〔既有，29〕。
- **主樞不在自己地上**：Highcairn 主樞在劍廷領〔既有〕。
- **堰帳上的零頭**：艾姆里斯四十年每夜偷放一線脈流，泰薩利家調數時才成了對不上的零頭〔既有〕。自己的人在漏，自己的帳四十年沒看出來。
- **招式要報數**：對手聽得見〔既有〕。

## 十二、劇情鉤

第 19 篇〔既有，14〕：
- 門環西門 Tavistel 票台：考利照章收陸沉三倍無籍通行費，稱謂欄寫「外客」（第 37 條）。
- 門環校準夜：艾德里克親自請陸沉，替被雷潮打亂的西樞做空間校準旁證；鮑德溫在主陣上看完（第 40 條）。
- 靈果林封山：布里森與陸沉在雷域邊緣對峙一日，全篇唯一一場「拖住初期鬥聖」；艾斯佩絲報閘數；泰薩利家公開調數，埃凡德對數；艾姆里斯問「林子活著，是不是因為我？」（第 80–83 條）。
- 談成的是「新芽不靠地氣」，不是關堰；艾德里克簽〔既有，03〕。

第 20 篇〔既有，14〕：埃凡德在 Elsby 分會門口看陸沉作證雷煉（第 23 條）。

候選鉤子〔提案，不排篇〕：
- 大堰加高一層時，喬瑟林出關，誰接陣眼。
- 有人在校準夜之外用了〈傾堰〉，堰帳上多一筆，西樞那天少開一門。
