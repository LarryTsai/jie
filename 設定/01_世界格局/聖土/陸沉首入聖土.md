# 陸沉首入聖土與封寒送證

階段工作名：**落潮一年**（D059，待作者確認；備選「渡縫之年」「邊地一年」）。

狀態：專家推薦稿，交 PM 與作者審閱。依據作者 2026-09-30 拍板：
- 跨界一律本體（雷身例外，見 D064）；
- 陸沉第一次進聖土是本體、因機緣被帶進去，不是計畫；
- 殞星取自聖土火山雷域，九霄取自封合縫，歸墟、太虛在三十二天；
- 上界約三百五十年、終局真仙的總框保留。

地點與勢力依[當代地理](當代地理.md)、[當代勢力](當代勢力.md)。

## 結論

- **推薦（甲）：九界卷末，界潮落水。**
  - 十八歲九界大比後數月，陸沉以**列陣本體**，在救人時被界潮捲過低路，在聖土待約一年。
  - 他在布蘭諾赫雷冠熔煉**殞星**（煉到列陣）。這一年壓關不破，下一個窗口以列陣走低路回九界，回來後才破尊者、飛升。
  - **不新增任何跨界規則。**
- **備選（乙）：下無極，接縫倒灌。**約三十歲、神火，在聖子危機中重接仙土的接縫崩裂時，被倒灌的劫雲捲進聖土。須新增一條規則，也會打斷下無極的主戲。
- **封寒送證**：推薦陸沉以太虛回頭，接封寒本體入境（新增一條最小規則：穿虛帶人）；備選是封寒散功退到列陣、走低路。

## 一、硬限制

| # | 限制 | 推出什麼 |
|---|---|---|
| 1 | 殞星第六、歸墟第七、太虛第八、九霄第九，次序已定 | 殞星（聖土）必在太虛（三十二天）之前取得 |
| 2 | 新雷須煉到當下完整境界，取雷者必須本體在場 | 取雷時是什麼境界，殞星就煉到什麼境界 |
| 3 | 高路要穿虛能力加仙力存量 | 取殞星那一趟不能走高路，否則循環依賴 |
| 4 | 低路兩端：仙界端在九界險地，受列陣承載線約束；聖土端在哈羅斐。界潮只秤當下承載（D065 草稿） | 走低路的人，去時與回時的當下承載都必須在列陣以下；他是天然列陣，身上沒有錨印可掛 |
| 5 | 渡劫的破境須本尊與所有雷身同處劫域（D018；D064 不改） | 在聖土破境，全員就被困在聖土、回不了低路 |
| 6 | 下界五雷與十二至十八歲的大比線不動 | 首入不能擠進十二至十八歲 |

由 1 與 3 可知：首入只能發生在太虛之前，而且不能靠高路。剩下兩個窗口：九界期走低路（甲），或上界前期另開一條不經九界的路（乙）。

## 二、推薦案（甲）：九界卷末，界潮落水

### 時點、境界、年齡

- **十八歲九界大比後數月**，陸沉列陣後段，五雷在身，全部雷身同行。雷身全員被界潮整個捲入（這是當時的情境，不是規則）；取殞星仍須本尊在場（D064）。
- 在聖土停留**約一年**；十九歲半前後回九界，隨即破尊者。
  - 推薦：趕在二十歲前經天域門戶飛升，靠他自己的腳上去。
  - 備案：由大比時賞識他的仙境宗門接引。
- **窗口密集期**：這是把現行留白具體化，不算新規則。界潮週期不均，一個大週期數十年，其中有數年密集期，約一年一開。後裔的曆法記得這個節奏。這也說明：
  - 裴照川為何偏在這幾年聚集後裔：錯過就要再等幾十年。
  - 溫棠為何在這幾年被滅口：九界自己開路的起點正要「能用」。

  兩者都由週期推出，沒有人預知陸沉。

### 機緣的形式

每一環都是人物自己的選擇，沒有人安排陸沉：

1. 九界大比上，陸沉擋下裴照川，卻反駁不了他的事實。
2. 陸沉的目標從「擋下」轉為「承認事實」，他要親自走溫棠沒走完的路，去異域後裔村落。
3. 抵達時，後裔群龍無首，窗口正在打開，一部分人仍決定渡縫：有人照裴照川的計畫去找證人，有一名老後裔只想回祖地。
4. 劫雲在窗口中段突然壓低（低路本來就有真實的死亡率）。陸沉是現場唯一能在劫雲裡行走的人，他進雲拉人。
5. **C3 盲點第一次顯形**：老後裔不想被拉回，陸沉認定「活下來比較好」，硬拉。兩人纏在縫口時潮勢轉向，連同幾名後裔整批被捲往聖土端。

**險地位置**（作者 2026-09-30 採 (a)）：
- (a) 留舟島東岸海眼之外。長子當年要去的渡口就在陸家一帶，陸家不遷、後裔聚居都因為渡口在那裡（A8：家規的結果，不是巧合）；終局「斷階重新成為渡口」也順。修士邏輯傾向此案。
- (b) 同一界的其他邊緣險地，避免所有線索都收在陸沉家門口。

### 如何越過限制

| 限制 | 甲如何成立 |
|---|---|
| 低路只容列陣／鬥靈以下 | 他就是列陣 |
| 仙界端在九界 | 他本來就在九界 |
| 回程受列陣上限約束 | 在聖土一年壓關不破，仍是列陣 |
| 熔煉須本體、須煉到當下完整境界 | 本體在場，殞星煉到列陣；這是完整熔煉，不是先收低階再補 |

由現行規則推出的一條後果，寫進[境界對照與跨界](境界對照與跨界.md)：**走低路過去的人，若在聖土突破到列陣以上，就過不了回程的界潮**；除非求得雷望衛的縫鎖，而縫鎖八萬年幾乎不外借。所以八萬年來那些偷渡後練成鬥王的後裔都留下了，邊地因此零星有「口音古怪的家族」。

壓關不破，是這一年的內在張力：尊者關口頂在喉頭，熔煉殞星又會沖動瓶頸，他必須邊煉邊壓。依 D065 草稿的新規則，理由是**主動選擇為主，補給限制為輔，兩者皆是**：

1. **回程**：破了尊者，當下承載就過了列陣，回程的界潮不放；縫鎖握在雷望衛手裡，不會交給一個查無此人的異鄉人。他答應過要帶願意回去的後裔過縫，破了就回不去。
2. **劫**：在聖土破境起劫，全員同處劫域、困住；在雷域邊城起劫會被當成縫裂，「第一次見劫」也會提早用掉。
3. **補給**：尊者是離地的質變點，破關要一口攢滿的力。法力在聖土的補給只有主場的六到九成，熔煉殞星又吃掉積蓄，這一年**就算想破也攢不齊那一口**。

選擇是他的；補給讓這個選擇撐得住，不只是一句決心。

### 在聖土的一年

- **落地**：過縫時穿過哈羅斐，在劫雲縫隙裡看見一座沉城的屋脊與碼頭一閃而沒（溫德港）；縫的深處有一股東西頂著，像有人用一整片天地抵著一扇門（帝天）。他說不出那是什麼，只記得那股感覺。這份記憶日後成了高路的定位錨（見下文「回程與太虛」）。
- **身分**：用化名（後裔替他取一個邊地常見的名字）。後裔警告他千萬別說自己叫「劫」，這個字在邊地專指他剛走出來的那片雷域。
  - 先在雷域邊城跟著凱德雷克團當雷晶採集隊的雷域嚮導兼雜役；
  - 後隨長帳團往東，到布蘭諾赫。
  - 沒有徽、沒有星、沒有翼，冊籍上查無此人。
- **戰力**：列陣全力，約當鬥靈；跨界不削能力（D065 草稿）。法力在聖土補給約主場的六七成，住上數月就幾乎不差。靠五雷、雷身、神識，勝得過同階鬥靈；遇上鬥王只能靠雷域地利脫身。**鬥王化翼是他跨不過的質變點**，沒有一場勝過鬥王的戲。
- **三場「只寫一次」的分配**：
  - 「此人身上沒有鬥氣」放在首入：雷望衛的例行探查之後，他在雷域裡活著帶人出來，對方的結論是「雷裡出來的東西」，不是廢柴。寫下這句的是潮門望樓的年輕衛士維達·薩洛（今潮門衛督，作者 2026-09-30 確認）。
  - 「他沒吞」留給正式篇。
  - 「第一次見劫」留給正式篇；首入時他正是在壓著不讓劫落下。

### 殞星的取得：救布蘭堡

- 這一年，布蘭諾赫火井大噴發，雷冠過載，雲中接連凝出雷核墜落（落冠），一顆就能削平布蘭堡半座城。
- 雷冠之下無人能飛，化翼者被雷優先擊落；奧斯馬克鍛廳的鬥聖與半聖能撕空間短暫出入，卻壓不住雷冠的本源。**鬥氣修士沒有渡劫經驗，這是八萬年來第一次沒有人能進雷。**
- 長帳團的人記得那個「在雷裡走的邊地嚮導」。廳主的兩難是：取走雷冠的本源，墜雷就停了，但雷冠這個屋頂會逐年變薄，火井日後要靠別的東西護住。
- **廳主選擇保城**，同意這個無名少年進雷。陸沉熔煉殞星至列陣，邊煉邊壓關。這是「取雷須當地同意」的第一次實作，後果由鍛廳自己承擔，陸沉不掌分配。
- **前後呼應**：殞星是雷冠的本源核心，取走後雷冠逐年變薄。一百七十年後的正式篇，老哈斯壽元將盡，屋頂也將破，於是有了奧斯馬克鍛廳的生死題（當代勢力恩怨第二條）。**這個危機有陸沉的一份。**他當年救了一座城，也掀開了一個宗門的屋頂，正式篇他得回來面對。

**不放的線**：烏蘅殘魂、驗魂錄、船期帳、接穗長根的場景一律不碰。首入期不見烏爾溫家繼承人；至多在芸香夜遠遠看見一個捧燈的孩子，不交談，作者可刪。

**盲點收束一半**：那名老後裔死在聖土，死前沒有道謝，只說了一句「我到了」。陸沉第一次被迫承認，他以為的「更好」不是對方要的。正面挫敗留給正式篇的「門從裡面開」。

### 回程與太虛

- **回程**：一年後下一個窗口，他以列陣本體帶著願意回去的後裔過縫，至少死一名後裔，讓讀者記得這條路不是捷徑。回九界後立刻破尊者（殞星初煉，劫勢更重），之後飛升。
- **因果是單向的，沒有循環**：
  - 首入不依賴太虛：走低路，只要求列陣。
  - 太虛在上無極取得，不依賴聖土的任何東西。
  - 正式篇的高路依賴太虛，並受益於首入：陸沉的神識記得帝天抵門的那股力量，這是他比任何仙人都認得的定位錨。這是回饋，不是前提。
  - 依賴鏈：低路（列陣）→ 殞星 → 飛升 → 歸墟 → 太虛 → 高路 → 正式篇 → 九霄。

- **失蹤一年**：九界的朋友當他死在險地。封寒親自去後裔村落找人，碰到的是一群對他閉口不言的人。
- **善意之瞞**：陸沉回來後，為了保護後裔（窗口曆法正是溫棠被滅口的原因），沒把曆法與渡縫的細節告訴封寒。這餵養封寒「不許有人瞞我」的盲點；但封寒答應不碰的仍是封存記錄，違約仍是他自己的求知之錯，責任不轉嫁。
- **異域出場順序**改為：
  1. 九界：裴照川的血脈；
  2. 九界卷末：陸沉首入邊地低處；
  3. 上無極：聖土的人找上門（可從首入時認識的某人一線來）；
  4. 正式篇。
- **「九弱」一場**：他二十歲才到下無極接引處，比同屆晚，書吏另記「逾期報到，事由不明」，可作沉船頂名案裡名冊版本差異的小入口（候選）。
- **聖土的兩個時代**：[當代地理](當代地理.md)、[當代勢力](當代勢力.md)等檔寫的是正式篇時的聖土。首入比正式篇早約一百七十年（D058：首入十八至十九歲，正式篇約一百八十八至二百五十五歲），對鬥宗以上的人物只是一代之內。首入期仍在世、正式篇已不在的人，由人物檔標明。

## 三、備選案（乙）：下無極，接縫倒灌

- **時點與境界**：約三十歲，神火（對鬥皇低段），下無極聖子危機期間。
- **機緣**：商應璋與岑越讓一片衰退的重接仙土接縫小幅崩裂（B3），「深處之物滲出」，本案把它定為封合縫的劫雲倒灌。陸沉為救仙土上的修士進入倒灌的雷域，被退潮捲到哈羅斐。
- **須新增的規則**：重接仙土的接縫貼著封層；接縫崩裂恰逢界潮時，封合縫的劫雲會滲進來，形成一段不經九界的短路，直到接縫補上。封縫仍依力量反擊，只放得過真一以下。
  - 八萬年未被利用的理由：崩裂罕見又要與界潮重合；被捲走者記作死於「虛空雷災」；單程、限時，帶不了軍隊。
- **缺點**：
  - 陸沉在聖子危機的失控期被抽離，下無極主戲要重排；
  - 聖土提早登場，壓縮上無極的「聖土人找上門」；
  - 讀者會追問「別的接縫呢」；
  - 他已懂仙界官制，得刻意不讓他靠近聖物。

## 四、封寒送商玄度罪證

**前提**：
- 時點依序：上無極時封寒違約開檔 → 陸沉取太虛 → 正式篇前半陸沉獨行 → 篇後段、公開驗證之前，封寒帶罪證抄本抵達。
- 封寒約斬我至遁一。依 D065 草稿，他在聖土能力完整（斬我約當鬥尊中段、遁一約當鬥尊巔峰），但渡虛時自身仙力已耗去大半，在聖土又補不回，實際能動用的遠少於全力。

### 推薦：陸沉以太虛回頭接人

**新增最小規則**（寫進高路一列）：穿虛可以帶人。
- **定位由持雷者一人負擔**：同行者須在他的雷光通道內，每多一人通道撐寬一倍，消耗倍增。
- **補給各自負擔**：同行者以自身仙力存量撐過虛空。
- 持雷者不能隔空拉人，必須親自在兩端。

**流程與代價**：
1. 陸沉從聖土獨自渡虛回三十二天。
2. 補足仙力、備足回程仙晶。
3. 帶封寒渡虛入聖土。封寒抵達時仙力存量去掉大半，在聖土補不回來，得省著仙晶留給回程，不能燒來打架。

代價是陸沉的仙力預算少掉一整趟往返；封寒以大降的戰力，走進一片把「仙人」當凶名的土地。

**八萬年未被利用的理由**：要先有太虛這種九雷中榜次最前的穿虛之雷，兩人又都得有仙力存量；一次只帶得動一兩人；仙人到了聖土補不回力、拿不到修行好處。

**與錨印路線比較（D065 草稿）**：新規則下，封寒也可以壓境打上錨印、經九界等窗口走低路，到聖土再破印解封。比較如下，**仍推薦太虛帶本體**：

| | 太虛帶本體（推薦） | 錨印＋九界＋低路 |
|---|---|---|
| 留痕 | 高路不經錨陣，上端沒有壓境簿 | 正規界路上端登簿、取拓印，上端屬王庭、會被對齊；帶罪證抄本下九界，等於向對方的簿冊報到 |
| 時間 | 陸沉定時點 | 要等窗口，數年到數十年一開；密集期也要一年 |
| 途中風險 | 虛空中由陸沉定位 | 在九界與雷域只有列陣之力，抄本與人都在劫雲裡 |
| 到聖土後 | 能力完整，只是存量少 | 不破印就只有列陣，破印就是**第二次違約**，稀釋上無極違約開檔的分量（與散功案同一個問題） |
| 代價落在誰身上 | 陸沉的仙力預算 | 擔保宗門凍額、後裔窗口曆法曝光 |

錨印路線只作備案：陸沉無法回頭、封寒又非去不可時才用，而且要寫成封寒明知是第二次違約仍選它。

**與盲點、違約的關係**：
- **為何非本人來不可**：陸沉原本只想把抄本帶回聖土，封寒不交。他要親眼看另一半證據被讀。表面上是求知，底下是「不許有人瞞我」：那一年的事，陸沉始終沒告訴他。
- **罪證抄本的來源**：循違約開檔打開的那條線取得。這一趟不能洗白那次違約。
- **在聖土碰壁**：他要求打開烏蘅的護魂器、看裡面還有沒有剩下的魂，撞上「亡者只問一次」的禮法；他要艾勒里家說出祖上的事，撞上八萬年的愧疚。他照規矩退下，**卻沒有停下**，轉去翻 Sefra 的原冊。真正的停下留給終局。
- **回程**：由陸沉再帶一次（第二次倍耗），或封寒留到篇末與陸沉同回，交 PM。

### 備選：封寒散功退到列陣，走低路

- 不需新規則。
- 代價是回上界後須從列陣重修，終局時戰力嚴重落後。
- 他去逼問後裔，後裔網絡在朔河一線眼皮底下暴露，代價落在別人身上，正是他的盲點。
- **不推薦**：這會變成封寒第二次求知之錯，稀釋上無極那一次違約的分量。
