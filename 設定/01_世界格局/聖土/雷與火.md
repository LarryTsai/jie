# 雷與火：Q22 的刻意對照

狀態：重建候選稿（Q22）。D047 已把方向定為刻意對照、不迴避；本檔是專家收斂的具體處理，屬 A、B 類。九雷如何重排由 PM 另行處理，這裡只給聖土雷域能孕育的雷性與候選。

## 總綱（定）

**火生於聚取，雷生於逆撞。**

- 聖土的修行是順取天地，所以天地能量聚到極處就燃，異火遍地；雷只出現在「有逆」的地方，所以稀少。
- 三十二天的修行是逆行返本，劫雷是逆行的摩擦，所以異雷被收煉、被排名；三十二天沒有異火榜。
- 兩邊各自只有半張榜。這句可以直接寫進兩張榜的序言。

## 對照表（定）

| 聖土 | 三十二天 | 對照點 |
|---|---|---|
| 異火榜（編纂者候選：煉藥師公會一系） | [天下異雷榜](../../04_修行與特殊事物/雷道/天下異雷榜與色相.md) | 兩張榜都聲明「名次是見識，不是天道」。聖土榜上沒有雷，三十二天榜上沒有火 |
| 煉藥師一至九**品**，靠靈魂控火；公會考核、授徽 | 丹師以地火、獸火、靈火煉丹；下界丹一至九**階**，劫另有一／三／六／九**痕**雷煉 | 用字嚴格分開：聖土說「品」，三十二天說「階」「痕」 |
| 丹雷：高品成丹時自然引來 | 丹劫：雷煉可能牽動天機 | 同源現象，兩種叫法 |
| 靈魂力量，是煉藥師的職業資本 | 神識，是多身同修的修行負荷；震魂雷淬魂 | 同一個魂的兩種鍛鍊法，可以互相作用、互相感知；但神識烙印與魂印**互相讀不懂**（見[靈魂術與證據](靈魂術與證據.md)） |
| 異火有靈，高位者生靈智 | 異雷有本源，須熔煉 | 聖土人用「收服異火」的眼光看陸沉的雷，想買、想奪 |
| 力顯在外：化翼、徽章、星數 | 力藏在身上：境界不示人，平日不露本名 | 「你們把火戴在身上賣，我們把雷藏在身上用。」 |

## 聖土的雷域：與異火之地成對（定）

| | 異火之地 | 雷域 |
|---|---|---|
| 成因 | 天地能量順勢聚集，聚到自燃：地心、火山、火脈、隕地 | 兩股方向不同的力相撞：封合縫、火山噴發衝上冷天、丹雷反覆落在同一片天空 |
| 方位 | 往下：地心、深淵 | 往上：天穹、裂縫 |
| 性質 | 聖土本性的產物，是天地在「給」 | 聖土的傷或例外，是天地在「擋」 |
| 聖土人的態度 | 資源：收服、煉化、拍賣、鎮宗之寶，編成異火榜 | 禁區、凶兆、防線；只採邊緣的雷晶，不收煉、不排名 |
| 誰進得去 | 鬥氣修士帶著抗火寶物就能進 | 鬥氣修士沒有渡劫經驗，損傷極重；雷修、仙修相對佔優 |

### 三型雷域

1. **封合縫雷域**（主雷域，推薦）：末代鬥帝的帝天卡在聖土一端的斷口，與仙界道則殘餘長年對撞，劫雲八萬年不散、一重重往下壓雷。它同時是：
   - 聖土最大的雷域；
   - 低路界潮窗口的聖土端；
   - 帝路斷絕的原因（見[古戰與兩界衝突](古戰與兩界衝突.md#末代鬥帝定)）；
   - 聖土對三十二天的天然防線；
   - 古時最大渡口城的沉沒之處。

   一處地點承擔五種功能，是聖土篇的地理樞紐。深處有一層萬雷墜入的雷淵。
2. **火山雷域**（推薦）：異火之地噴發時，極熱的聚能衝上冷天，灰雲中生雷。**地下是火，天上是雷，同處一地**，是兩界對照最直接的畫面。
3. **丹雷積雲**（候選）：古代一座大丹城萬年大量成丹，丹雷不斷落在同一片天空。可以疊在封合縫的渡口城上：渡口時期仙界靈藥由此輸入，是兩界最大的煉藥城。

### 可放在聖土取得的既有九雷（候選，交 PM 重排）

下界五雷（星羅、兩儀、震魂、千相、流光）的取得故事已定，不動。

| 異雷 | 對應雷域 | 意見 |
|---|---|---|
| [九霄劫雷](../../04_修行與特殊事物/雷道/九霄劫雷.md)（聚雲成劫、逐重降雷） | 封合縫劫雲 | **五人一致推薦**。這是封界之劫長在異鄉的樣子：陸沉取走的，是自己那一界造成的傷 |
| [殞星天雷](../../04_修行與特殊事物/雷道/殞星天雷.md)（凝核墜爆；赤銅、熾白核、暗紅殼） | 火山雷域，或丹雷積雲 | 推薦作為聖土第二雷。形與色都貼合火山雷，現行檔的孕育地也還空著 |
| [歸墟黑雷](../../04_修行與特殊事物/雷道/歸墟黑雷.md)（萬雷墜入雷淵） | 封合縫下層雷淵，或丹城雷淵 | 有爭議。鬥破、世界、推理、修士邏輯列為候選；**原創性編輯反對**：在異火榜與吞火文化的語境裡取「吞雷」之雷，讀者會讀成「雷版焚訣」 |
| [太虛神雷](../../04_修行與特殊事物/雷道/太虛神雷.md)（穿行虛空） | 封合縫緊貼界外虛空之處 | 有因果依賴：若太虛也取自聖土，首次本體入境只能走低路，而化身取不了雷。PM 重排時須先解這一環 |

**底線**：
- 聖土不收雷，所以陸沉取雷不構成掠奪；但雷域若同時是防線或當地的修煉資源，取走之前需要當地同意。取走九霄只平息劫雲，**不破封口**，也不替聖土打開帝路。
- 不寫成每去一次聖土就收一道雷的副本。

## 陸沉在聖土靠什麼（定）

蕭炎路線的三根支柱：靠煉丹揚名、收集異火、在公會與拍賣會上靠丹藥打臉。陸沉三根都不碰。

| 爽點來源 | 內容 |
|---|---|
| 看不透的異鄉人 | 身上沒有鬥氣，靈魂力量探不出底，不化翼卻能飛。體系不同，不是廢柴；只在前期用，之後聖土會研究他，差距逐步收窄 |
| 雷域行者 | 聖土只有他能在劫雲裡長時間行走。帶隊進雷域取回古戰遺物與高階魔核；疏導雷潮，救下被雷域擴張威脅的邊城與宗門山門；打通被雷域截斷的靈脈 |
| 仙物鑑定 | 整個聖土只有他讀得懂古戰遺物上的神識烙印，公會、王室、拍賣行都需要他，他也因此能接觸證物 |
| 雷身群戰 | 一人即一支隊伍，而且每一具都是完整戰力；在聖土從未有人見過 |
| 拆鬥技 | 星羅察脈、看穿鬥氣運行的路線，千相製造錯位；聖土高手也要能反拆仙法 |
| 魂戰 | 對上煉藥師與收魂人，以神識和震魂雷取勝。**他不搜魂**，震魂雷只用來穩住自願作證者的魂 |
| 他沒吞 | 對手放出榜上異火，全場以為雷修會奪火，他只是破火、散火，一縷不收 |
| 聖土第一次見劫 | 劫落在人身上，那人帶著所有雷身渡了過去 |
| 查案 | 打臉就是破案：撫恤冒籍案破在議事席上，資源份額當場重分 |
| 被奪的一方 | 他的雷、厄，都被當成天地奇物覬覦；站在被奪的一方，再把局面反轉 |

**丹道在聖土的用處是讀證物，不是賣丹**：剖丹、封樣、驗丹力的手藝，正好讀得懂公會八萬年前封存的藥液樣本與驗傷記錄。

**只寫一次的例外**：
- 以一枚雷紋丹換一件古戰證物（他沒有聖土貨幣，仙晶也不流通）。
- 替公會分會接下一次丹雷，保住那一爐整片邊地一年的撫恤藥份。
- 教一名聖土煉藥師雷煉，作為烏蘅學接木的鏡像：陸沉是教人，不是和人比試。

**名聲弧線**：「劫」從凶名（那場雷）變成一個被好好叫出來的名字。名聲的刻度是雷望衛、公會、拍賣行在正式文書上怎麼稱他。

## 原創性紅線

1. 退婚、當眾受辱、約戰幾年後、「三十年河東」式口號。
2. **戒指老師**：殘魂寄居、傳功、代打。厄住在指骨裡，結構上已靠近這個禁區，是固定審查項：厄不說教、不傳功法、不替陸沉打他打不過的仗；指骨不改裝進戒指；聖土覬覦厄時，陸沉守的是一個會受傷的同伴，不是寶庫。
3. 吞火進化：功法吞異火升級，或把收集異火當成升級主線。
4. 多種本源揉成一個大招丟出去；九雷合用不寫成「九色雷蓮」，九霄的畫面固定為「聚雲、逐重降雷」。
5. 大比打臉模板：測驗石碑、成人禮、學院排名、丹會奪冠。陸沉不參加年輕一代的賽事，測驗石與徽章只作世界味道。
6. 原作台詞與測驗梗照抄。「此人身上沒有鬥氣」只致敬情境，不照抄原句，只用一次。
7. 拍賣會低調加價、敵人傾家蕩產的壓價打臉。
8. 一路收服女性強者。
9. 扮豬吃虎反覆使用。
10. 異火暴走、奪舍、靈魂追殺等原作中段主線照搬。
11. 帝路斷絕的原因不得寫成天地能量衰退或流失。
12. 聖土專名定稿前一律做原作撞名檢查，包括異火、鬥技、丹藥、地名與勢力名；不用「顏色＋蓮／炎／火」這種易撞格式。

檢查法：陸沉在聖土的每一個爽點，都問一句「換成原作主角，這場戲能不能原封不動成立？」能成立的就要改。

**編輯層的連動**：作者定下的「兩套體系各自完整、不混用」，本身就是終局「往來，不合一」的證據。聖土篇可以讓讀者在事後讀懂這一層。
