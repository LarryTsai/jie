# 古戰、末代鬥帝與兩界衝突

狀態：重建候選稿（Q17-4、Q17-6、Q17-7）。專家五人收斂，屬 A、B 類。底線：沒有棋手、禁止預知、聖土不是發起者、責任不被稀釋。

## 兩界衝突的結構原因：聖土角度（定）

以下每一條都不需要任何人使壞，只要界路開著就會發生。陰謀只是有人在這些結構上點的火。

1. **界路收益改寫中心與邊地的權力**：往來讓邊地繞過中心致富。對中心的宗門、家族與公會而言，往來本身就是分裂。
2. **往來磨損外圍，兩邊都磨**：
   - 仙界那一側：聖土修士在外圍吸靈氣修煉、療傷，天經地義；但外圍仙土的道脈是王庭歷代仙人以死亡養成的。渡口越興旺，常駐的鬥氣修士越多，外圍越瘦。外圍王庭一邊收界路稅，一邊看著祖先養的地變薄。
   - 聖土那一側：渡口一帶的天地能量受仙界道則滲染，氣旋紊亂、魔獸被仙氣殘留吸引而騷動。
3. **資源依賴**：仙土長出的靈藥藥性內斂穩定，是聖土煉藥師最看重的破境藥材；公會的獨佔被繞過，封界後藥源一斷，一代人卡死在瓶頸。這是聖土受害敘事的物質基礎，比單純的哀悼更硬。
4. **通婚牽動繼承**：兩套修行不能兼修，只能轉修；公主與長子的孩子是修仙法、沒有氣旋，還是修鬥氣？渡口王室的繼承看血脈也看鬥氣天賦，中心的大家族更怕出現一個與三十二天結親的邊地王國。仙界那一側看道統，同樣不接受。
5. **開放即防務破綻**：鬥宗以上能撕裂空間，界路一開，對方的強者就常駐在你最脆弱的那一圈；而且鬥氣在外圍接近全力。聖土只有一位帝，對岸有數位仙帝；渡口王國背後的鬥聖是向中心請來的，不是自己人。
6. **魔獸與化形族群**：聖土以獵魔取核為常業；三十二天有能化形、修成道統、以命輪論成年的異族。聖土獵人在外圍獵殺的「魔獸」，在仙界眼中可能是一個尚未化形的人。雙方在自己的規矩裡都沒錯。
7. **靈魂之禮**：聖土收魂、問魂、供奉殘魂，視為孝與正義；仙界視神魂不可拘。聖土依法搜仙界罪犯的魂，就是外交事故；通婚者死後魂留魂龕還是歸土，直接牽動繼承。
8. **戰後受害敘事制度化**：撫恤配額、芸香冊、芸香夜（見[地理勢力與撫恤](地理勢力與撫恤.md)）。

## 末代鬥帝（定）

| 問題 | 結論 |
|---|---|
| 古戰時有沒有帝 | 有，一位。壓測的「界外另一股帝威」不能推翻（[仙庭對峙場景壓測](../仙庭對峙場景壓測.md)第 86 行）。鬥帝不是王，超然於王室與宗門之上，比照仙帝不等於帝位 |
| 古戰時在做什麼 | 守聖土一端的界路；受創界路兩側道則相撞時，他在聖土那一端施壓封合，不讓裂傷蔓入聖土 |
| 帝威的兩種讀法 | 仙界現場讀成「異域再攻」，聖土讀成「關門」。兩種都是真的，這正是骨架第一節所說「當時現場看不到的軍情」。仙界戰後存檔再把它對齊成「異域帝威來犯，不得不封」。陸沉日後取得聖土一側的記錄，能拆穿仙界封界理由中的**這一條，但只拆這一條**：太宸是在選，這個判斷不變 |
| 封界時 | 以自己所成的天地堵住聖土一端的斷口，之後死去（道傷加上封合的本源代價）。那片帝天沒有散，仍卡在封合縫裡，與仙界道則相撞，就是雷域的核心 |
| 與太宸 | 各封一端，雙方沒有協商。他對祁承朔、撤去護持、事後竄改一無所知；他關門是為了自己的天地，與太宸「知而沉默」性質不同，也不是第二個沉默的活證人。**他的死不記到太宸帳上**，否則太宸的罪會發散，削弱「是我」。太宸只從戰報得知另一端也封了 |
| 帝路為何斷 | **封仍在。**聖土天地一次只容一片帝天，後來的鬥聖巔峰走到最後一步無處落腳；要成帝，就得拆掉末代帝留下的封，等於重開一道對著仙帝的傷口。八萬年來，有人在最後一步被天地拒絕，有人自知成帝就會破封而自己停下。**不是天地衰退，是沒有人肯拿整片邊地去賭**；這也給了聖土自己的兩難「成帝就會破門」，正對三十二天「修好就是抹除」 |
| 重開界路能否恢復帝路 | 留白，也不作為往來的獎品。陸沉取走九霄不等於替聖土打開帝路；最多寫到劫雲平息 |

備案（不採）：帝路是「見帝而成」的傳承，末代帝一死傳承鏈就斷（較薄）；封合耗盡本源、盈餘不足（太接近原作的天地衰退）。

**Q06 只需補一句**：異域那一端也同時封合，雙方沒有協商。仙帝之間的共同封界分工仍待定，不受影響。

## 大約收押撤回後：不設替代機制（定）

- 「救援方案為何需時」由壓測現行規則「受創界路兩側道則相撞、能封住的邊界正在後退」，加上內應撤去護持解釋，**不需要聖土做任何收押**。
- 骨架已有的「聖土主戰者確實調過兵」，具體寫成：**在公主案與嫁禍之後**，聖土主戰派援引界路之約「實地作質」條款（D036a），進兵界路錨地。他們說是守住回家的路（母稿那位等船的商人，就是被困在對岸的同胞），仙界眼中則是佔地。條款是理由，不是起因。
- **正文須明寫**：這次進兵不是九天下沉的原因，也不是救援需時的原因。
- 候選（交 PM，涉及主線）：主戰派能抓住時機，是因為知道山口換防的時刻（母稿「敵人知道山口換防的時刻」）；這份情報源自商玄度以演練、換防之名造成的空檔。聖土主戰者在這裡是**工具**，不是發起者。聖土軍中的舊戰報記著情報從何處、何時得來，可作商玄度一線的旁證，但不是祁承朔的證據。

## 聖土自己的錯誤答案（定）

**「仙庭一心」**：把一個人的謀殺，看成一個制度做出的決定。

| | 仙界查案者：「同一隻手」 | 聖土：「仙庭一心」 |
|---|---|---|
| 錯在哪 | 把制度洩漏、分段命令、模仿、有罪見證者，錯看成一個人持續出手 | 把一個人的謀殺，錯看成仙庭的整體決議 |
| 方向 | 把許多人看成一個人 | 把一個人看成整個制度 |
| 共同的毛病 | 都拒絕看那條由具體個人組成的鏈 | 同左 |
| 真實的根據 | 洩漏確實每次都經過具體的人 | 屍身上的仙力；仙庭是給出保護承諾的東道；信使帶來真正的仙庭令符；搜信使的魂只得到「上面說仙庭有令」；驗魂錄裡的感知空白被讀成「仙庭級遮蔽大陣」；保護文書署名「仙庭使節祁承朔代」。**每一件都是真的，錯在合併** |

**次要的錯誤**：
- 「仙斷了我們的帝路」：一半對（仙界的道則在牆上），一半錯（牆是自家的帝砌的）。
- 「學徒全數殉難」：這是冒籍的地基。
- 「仙庭畏罪封界」：其實自家的帝也關了門。

**聖土一直知道祁承朔的名字**，但只把他當作仙庭的手。

**誰在維持這個錯誤**（沒有棋手，只有分散的利益）：
1. 芸香夜本身：每年誦讀罪名「仙庭」與殉難名冊，儀式把答案固定下來。
2. 冒籍一方：撫恤的正當性建在「仙庭整體加害、學徒全數殉難」上。
3. 煉藥師公會：權威押在當年驗魂錄的結論。
4. 主戰派後人：兇手若是仙庭，當年的調兵就是正當防衛；若只是一個皇子，調兵就成了把戰事推起來的那一半。
5. 烏爾溫家：地位部分建在受害敘事上，但他們也是被冒籍欺騙的一方。

**怎麼拆**（三步，每步都有代價）：
1. **學徒活著**：船期帳上案後的魂印簽領、記門簿上的實際到港時刻，加上園師世家手裡的遺物。冒籍名冊因此垮掉，同一份記錄也證明改期是預謀。
2. **不是整體決議**：長子藏在接木根下的安全副本（A9 延伸，仙界一側），就是他原本要親自帶來的證詞，遲到了八萬年；再加上信物收存日期與仙界事後竄改的登記，證明仙庭的記錄是事後被個人改過，而不是當時的集體決議。
3. **仙庭也不是無辜的**：保護承諾是仙庭給的、簽的人是仙庭的皇子，仙庭沒有護住她；戰後的竄改沒有被阻止；太宸知情後選擇沉默。**責任不被稀釋，而是被分開寫。**

## 終局對位（定）

**仙要學會說出名字；聖土要學會放下一個集體的名字。**一邊是從無名到具名，一邊是從泛名到具名，最後都停在具體的人。

1. **芸香夜的罪狀改寫成三行**：
   - 殺她的人：祁承朔（加上同謀之名）。
   - 仙庭：許而未護，知而不言。
   - 聖土自己：未查而先動兵。

   學徒的名字從殉難冊移到生者冊，冒籍的名字刪除。另加一個新名字：**祁承晏**，那個打算親自來自請為質的人。這是聖土篇的情感收束，也是「兩界都有活人付代價」在儀式上的兌現。
2. **不許代簽**：公主就是在一份代簽的保護承諾下遇害的。聖土在新約中堅持每一方以自己的名字簽、自己擔責，不接受仙庭代九界簽約。最終畫面「九界以自己的名字簽界路之約」直接從公主案的機制長出來。
3. **聖土那一端的簽約方**，是持渡口特許的烏爾溫家與邊地，不是「諸神聖土」，也不是中心大陸。兩岸的外圍第一次繞過各自的中心往來。
4. **記錄雙存取代實地作質**：D036a 的「以實地作質」讓外圍首當其衝；新約不再押土地，改為每一份界路記錄由兩方各存一份。查案的教訓在這裡變成條約條款。
5. **門從裡面開**：邊地議事（冒籍的芸香席已剔除）自己決議讓陸沉取走九霄劫雷，劫雲平息，溫德港的河階重新露出。陸沉不掌門。取走九霄不破封口，所以重開仍需兩側共同立錨。
6. **聖土自己的墮落路：永久封門**。這是受害敘事制度化的終點，與仙界的歸一互為鏡像：一邊想把一切收回中心，一邊想把門永遠關上。由冒籍一方與部分主戰派後人承載。聖土不當反派，只是也有自己的墮落路。
7. **聖土不參與歸一**：歸一是仙界內部的墮落路（D041），聖土只作見證。
8. **接木**：園師世家把一枝自生根的接穗送給九界，由陸沉帶回，種在家鄉的斷階渡口。這是實物的往來，不是回接。
9. **兩套體系不混用**：作者的寫作規則，就是終局的證據。兩個完整的天地可以往來，不必合一。

| 結構 | 失去中心 | 中心太強 |
