# 劫故土六域與太玄宗

狀態：2026-09-28 作者確認的新版地理、勢力與成長入口。六域正式名稱與核心定位已定。

## 六域與島上起點

劫所在的一界分為六域：**東溟、中神州、北天、西極、南荒、天域**。六者都是正式域名，不再以東、南、西、北等方向泛稱代替。天域是六域之一，不是獨立一界或仙境；五域大比由天域以外的五域人才參與，在中神州舉行。

| 大域 | 核心定位 |
|---|---|
| **東溟** | **海洋文明**。東溟是強域，劫少年時所在的近海小島只是人生起點；群島、深海、海上國度與航路共同構成真正的東溟。 |
| **中神州** | **文明交匯**。其重要性來自王朝、古宗、世家、散修與歷代遺跡高度疊加，不以地處中央直接等同天下最強。 |
| **北天** | **未知疆域**。冰雪只是已知邊緣，真正核心是北方仍不斷向外延伸，連北天修士也未完全探明它有多深。現行天幕展疆規則、五方勢力與天驕見[北天宗派與天驕](五域/北天宗派與天驕.md)。 |
| **西極** | **道統與古路**。沙海只是景觀之一；古寺、帝國、仙宗、不同求道觀與前代文明沿古路交錯。現行宗派與天驕見[西極宗派與天驕](五域/西極宗派與天驕.md)。 |
| **南荒** | **活著的大地**。火脈、巨林、河川、山國、城邦與多族文明皆已成熟，土地本身仍持續變動。現行三方格局與天驕見[南荒宗派與天驕](五域/南荒宗派與天驕.md)。 |
| **天域** | **天空文明**。它與另外五域平級，擁有完整國土、農業、水源、城池與歷史；九大書院與上界門戶只是其中一部分。 |

東溟有許多島國。劫最初生活在其中一座類似臺灣的島上，島名定為**留舟島**（C2）；勢力與地理見[九界與陸沉故土](九界與陸沉故土.md)，不直接照搬現實臺灣地名或歷史。島上設有東溟三大宗派的分部，也有劫加入的太玄閣。

太玄宗位於東溟，但不是東溟三大宗派之一。各島太玄閣是太玄宗的分部，承擔弟子入門與推薦等功能；不將太玄閣另寫成平行於太玄宗的獨立宗門。

對島上的弟子而言，第一次走遠，是取得推薦、離開熟悉的太玄閣，與其他分部弟子共同參加宗門選拔。這時太玄宗已是更廣大的修行天地，中神州、天域與仙境還在更遠處。具體渡海方式、送行人物與場景待寫。

## 天域與其他八界

天域有九大書院，也有前往上界的門戶。九界各有功能類似的地方，但名稱、地域劃分與培養人才的方法各自發展，不全部命名為天域，也不強制採用六域九院。

## 留待發展

太玄宗採用[主峰＋七座傳承峰](勢力/太玄宗/README.md)，已建立各峰專檔。東溟三大宗派已定名為觀潮宗、鎮溟劍宗、千礁宗（D058，見[九界與陸沉故土](九界與陸沉故土.md)），其本宗所在與全貌、九大書院名稱、分部所在地與六域交通仍待發展；西極已建立兩古三新的大宗格局，南荒已建立三方與五個代表傳承，北天已建立天幕展疆、五方勢力與巡天試。
