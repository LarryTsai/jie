# 諸神聖土（神）

狀態：候選設定稿（D035）。「諸神聖土」是三十二天的他稱（D032）；聖土採西方命名，回歸西方諸神方向，不分三族（D034）。應名、雷身與名、聖土三層修行為作者同意採用的方向；其餘條目為候選。

**聖土自稱：Orhavel（奧哈維），意為「應答之地」**（D036，專家表決一致）：呼名即有回應，直接體現應名；仙則以能「不應」為高境，兩界差異在名字裡就讀得出來。

## 一句話

**力在彼此之間，向外立約。**

## 神是什麼

- 神是被一群人、一片疆土託付了名字的存在：以約為本、以名為契、以職為用。
- 神力以本身修為為底，名、約、職是放大器。失去全部信徒的神不會歸零，只剩個人修為，退為「無民之神」。
- **盟約是雙向的**：人獻上呼名與守誓，神負責庇護、立法與回應。神違約，自己的名就出現裂痕，誓者自然離開。這是立約雙方之間的機制，不設裁判善惡的天意。
- **名言即力，只限正式「以名立言」**：以名起誓、宣判、定義的話不能是假的；神可以選擇沉默。平常說話可以說謊。拒絕以名作答，本身就是線索。所有說真話的機制都只約束說話者自己知道的事。
- **定義的硬限制**：
  1. 只在自己的職權與疆土內生效，出了範圍只剩本身修為；
  2. 必須指認對象才能套用；
  3. 同一片疆土的同一個職，不能由兩位神完整持有；
  4. 遠離呼名之地會衰退，跨界須立聖所作錨點。
- **死亡與延續**：神可被殺，神魂全滅不可復生。殺了神拿不到他的名，須由族人重新立約。名可以傳承：換人不換名，接名者承接誓約與職責，不承接記憶。靠約可以延命，代價是「名越來越多，人越來越少」。
- **仙記得人，神記得名**：仙靠長壽的個人記住古事，神靠名的傳承記住古事。
- **時間觀**是直線的：初約 → 立名之世 → 守約之世（當代）→ 清算。「太初」指第一次立約，不是造物主，不設界外創世者。
- **空間**：聖山（神座）、人居之地、深處（未命名之物）。不疊出更高的天堂；「深處」不得與大羅之內的「道」疊加。
- **病症**：約能守住舊的，卻長不出新的。母稿裡烏蘅家鄉的果樹「老枝尚活，新芽卻年年枯死」即此。
- **墮落方向**：把一切名字永遠定住，讓萬物再也不能背約（凍結式救贖）。與仙庭封神派互為鏡像。

## 應名

作者採用（D035）。名字要本人「應」了才能拘束他；光知道名字沒有用。神要定住一個人，須同時滿足：知道本名、對方身在神的職權與疆土內、對方曾在神前應過這個名。

- 因此陸沉的本名雖在九界大比公開過，仍不等於被掌握；有人在神的疆土內喊他的本名，他不能應。
- 仙境界越高越能不應名，代價是羈絆變淡（見[三十二天](三十二天.md)）。
- 替他者取名分兩種：賜名不拘束對方；定名才立約。陸沉替厄取名屬賜名。

## 聖土的修行：三層

作者採用（D035）。

| 層 | 內容 |
|---|---|
| 底層：個人鍛鍊 | 戰士、獵人苦練身體與力量，只分三到四個大階，升級清楚。階名不用「神」字 |
| 天花板 | 只靠自己修，到某個門檻就停住；要再往上，必須向神、領主、疆土或一群人立誓 |
| 中層：誓力 | 力量來自立誓與領受：個人弱、成群強；離開領主或聖所就衰退；背誓就降階 |
| 頂層：約、名、職 | 授地、受職、受冕，見下方十八境 |
| 少數異端：無誓者 | 拒絕立誓、硬靠自修突破天花板的人，被視為不受約束之力；他們其實就是聖土裡的「仙」，是兩界往來的內部支持者 |

## 聖土十八境（D038）

作者採用。以西方封建受封鏈排列，與三十二天境界一對一；階名是三十二天的中文譯名，聖土本名採 Orhavel 系自創字根，位越高名越長。仙的境界寫自身做了什麼，是「能去之名」；聖土的境界寫被誰承認為什麼，是「能承之名」。

- **境界＝能承之名**：本身修為撐得起多重的名號，就是那一境；實際封了什麼爵是政治，另一回事。名號高過修為會被名壓身；修為高過名號稱「無主之爵」（描述狀態，非身分名）。
- **「神」是職位**：小職自男爵起可受，大職須受冕為冕君；「聖」字只用在聖王、聖帝兩級。
- **無誓者**：突破天花板後正式稱「無冕者」，傳說頂點「無冕之王」。內修走西方煉金四變，屬西方版內丹：玄化（#5–8）、白化（#9–12）、黃化（#13–15）、赤化（#16–18）。
- **墜落稱「褫爵」**：因罪被剝除名與爵，對應仙的劫敗、兵解；先前所說的「名裂」即此。
- **主場口訣**：疆內職內之事高一境；加成不跨立誓、徹夜、受冕三道門。仙在聖土只有外放之力受阻，己身之力不受影響。正文以描寫呈現，不寫數字。

備案：若日後要避開「子」字，第 10–14 境可改為男爵、伯爵、侯爵、公爵、大公。

仙越往上越自由、越孤獨；聖土的人越往上越被需要、越被綁住。不套用《鬥破蒼穹》的鬥氣階梯、煉藥師、異火榜等（原創性理由：《劫》已有天下異雷榜、雷煉丹）。聖土醫藥走祝聖、聖油、立約療癒：藥要以約起效。聖土不設排行榜，強弱看「名位譜」。

## 深處之物與無名之力

深處滲出的獸是未命名之物，其核中是無名之力。仙可以直接吞納（例如歸墟黑雷）；聖土正統須先命名、立約才能馴服或使用。仙界稱深處之物為「渾沌」，典出《莊子》鑿竅而渾沌死，意即命名即鑿竅（候選）。

## 從定義推出的兩界衝突（候選）

1. 無約之力是僭越，立誓是枷鎖：神看仙，是不欠任何人、無法問責的力量；仙看神，是被名困住的人。
2. 九界是立約的沃土：人口多、族群分化、已脫離王庭。每一座聖所都是一場主權之爭。
3. 神被自己的盟約逼著回應：誓者受害，神若不履行庇護，名就會裂；清算的方式仍是人的選擇。
4. 通婚的繼承衝突：仙界看道統，聖土看誓約。
5. 定義外溢：邊疆神的定義沿界路滲進仙土，與道則相撞，磨損外圍。
6. 本名外流即軍情外洩。
7. 戰後敘事互不相容：仙界說「渡劫」，無人負責；聖土說「罪」，一定要有名字，每年哀悼禮誦讀罪名。

古戰中聖土方不當發起者；陰謀由仙界具名的人主導。

## 互補與吸引

仙羨慕神被需要、被記得名字、承諾有重量；神羨慕仙不怕被遺忘、能長出新東西。盟約術能讓一群人共同承接力量；仙的內修能讓失去信徒的神活下去。母稿中長子說「御風半刻」、烏蘅答「其中兩個還飛不了」，就是兩種道互補的例子。

## 古戰新增歷史層（D036，專家表決）

三條皆採用，並附共同底線：**擔保與大約只說明九片外圍為何首當其衝、為何回接需時，真正讓九天受創下沉的，仍是內應出賣破綻、撤去護持；聖土不是發起者。**

1. **外圍仙土作擔保**：仙不以本名立誓，界路之約由仙庭指定外圍九天作擔保。擔保文書本身是可查的記錄。這把「量劫」的累積推到陰謀之前：中心拿外圍去擔保，本身就是一筆舊債。
2. **聖土的「大約」＝依約收押擔保**：公主案與仙界出兵之後，聖土認定界路之約已被背棄，依約收押擔保地。效力只及於擔保仙土中曾有往來者應名、設過聖所錨點之處。仙界眼中是侵略，聖土眼中是履約。九天因此被部分命名，回接須先剝除他名、需要時間，所以救援方案仍可行，太宸仍是選擇封界。
3. **長子欲以本名立誓作證**：仙極少以本名立誓，長子打算破例，在神前以本名作證。名言即力之下，這份證詞聖土無法不信，這正是共謀者必須在他開口前殺他的原因。名言只約束所知：長子不知兇手是弟弟，他能立的誓只是他相信的「仙庭未下令」。極少數人知道這個計畫；弟弟如何得知，可留給兄弟煮茶那場戲暗示。這也預示終局仙「學會說出名字」。

**古戰距今：約八萬年**（D036；專家四票八萬、兩票十萬、一票五萬；工作區間六至十萬年，壽元表定案後可調，且須小於太宸與救援派仙帝壽元）。

## 古戰的對稱結果（候選）

仙界往下失去「極」（九天下沉成九界）；聖土往外失去「名」：渡口、往來、賓客、通婚之神的名破裂死去，依靠往來的邊地成為「失名之地」，深處滲入；留下的人學會不靠神活下去。原本引渡的神改職為拒渡，成為當代的守界神。
