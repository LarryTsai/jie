# 諸神聖土

狀態：重做中（D045）。作者裁定整個聖土重做，修行與戰鬥直接套用《鬥破蒼穹》體系與原名，讓打鬥好設計、不突兀。舊版「約名職」設定已撤回並移至[歸檔](../../歸檔/撤回設定/聖土約名職版/諸神聖土.md)，不得再引用。

## 保留

- 「諸神聖土」是三十二天對那片天地的他稱（D032）；聖土人名、地名採西方風格，三十二天文書音譯。
- 「烏蘅」是三十二天譯名（D032）。
- 兩界隔界外虛空、古時有界路往來、公主與長子相愛、古戰與封界、聖土不是發起者也不當反派（D039 底線）。

## 修行階梯（D045）

直接採用鬥破原名：

鬥之氣 → 鬥者 → 鬥師 → 大鬥師 → 鬥靈 → 鬥王 → 鬥皇 → 鬥宗 → 鬥尊 → 半聖 → 鬥聖 → 鬥帝

小階依鬥破原制。

## 待重建

- 鬥氣體系與三十二天境界的對照表、跨界限制與戰力換算。
- 「諸神」在此體系中是什麼（鬥破原作沒有神的位階）。
- 聖土的社會、政體、宗門與族群。
- 從新體系重推兩界衝突原因（不依賴約名職的結構性原因仍可沿用：界路收益、往來磨損外圍、通婚牽動繼承、開放即防務破綻、戰後受害敘事制度化）。
- 聖土自稱（D036 的 Orhavel「應答之地」語意出自應名，待重議）。
- 主線中原本依賴約名職的環節，見[主線推理骨架](../05_故事主線與揭露/主線推理骨架.md)開頭的撤回說明。
