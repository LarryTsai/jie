# 九界與陸沉故土

## 古階下的集市

以下沿用[故事母稿第五、七節](../../故事母稿.md)，是地方生活的試寫，並未定案。

陸沉故鄉附近有一段向天伸去的斷階，當地人說那曾是渡口，卻講不清從前的河在哪裡。階下如今是集市，有人修劍，有人等浮石升起去採藥，陸沉則替賣紙鳶的老人看攤。

他感覺得到一隻紙燕的異常，動手削竹卻修得更壞，只好拿看攤賺的錢，換一隻破的回來拆看。過幾日紙燕能飛了，他仍走不到高處，得在坡上坐下喘氣。路過的採藥人替他撥開卡線的樹枝，燕子才越過樹梢。

古戰留下的斷階仍在遠處，眼前的人忙著謀生、學本領和照料身體。陸沉想上去看看，先是少年對家鄉高處的好奇；他並不知道這片故土曾發生的上古殺局。其他八界也應有這樣不依賴主角查案而存在的生活。

## 陸沉生活的那一界

| 面向 | 需要回答的問題 |
|---|---|
| 地理 | 家鄉、修行場所、市鎮與危險區域怎麼相連？普通人能走多遠？ |
| 生活 | 人如何謀生，修士與凡人的接觸是什麼？ |
| 權力 | 誰管地方、宗門和跨域交通？彼此如何制衡？ |
| 修行資源 | 誰能開始修行，誰掌握機會，失敗者如何生活？ |
| 對外認知 | 普通人知道仙界與其他八界存在嗎？知道到什麼程度？ |
| 歷史痕跡 | 古戰留下哪些已融入日常的地貌、習俗或禁地？ |
| 當代矛盾 | 即使沒有上古陰謀，這裡的人今天仍會為何事衝突？ |

本表是設計欄位，尚未填入新的世界事實。

## 其他八界

每界至少有獨立的地方人物、資源需求、權力衝突與值得前往的原因；古戰紀錄只是其中一條線。無須每界固定一件證物，不按編號逐關探索，也不預設陸沉故土是異域唯一入口。

[故事母稿](../../故事母稿.md)中的古階、浮石集市、浮山、火樹與季節河道均為試寫，是否採用及分屬何界尚未決定。
