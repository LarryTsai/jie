# 家底卡：下無極（斷雲劍宗、綴錦宗、荷戈盟）

狀態：三十二天寫手提案（2026-10-02），PM 派工、作者已核准任務。文末四題**作者定（2026-10-02）**（全部照推薦），各處已標；其餘為提案，未經作者確認。

依[修仙文明底層規格](../../../00_故事定位/修仙文明底層規格.md)第 16 節卡片格式；每一項能力先過「能力設計檢查條」八條。家底形態照[宗門與天驕家底庫提案](../../../06_待定與決策紀錄/宗門與天驕家底庫提案.md)第二節，不改類型。來源：[下無極勢力](../下無極勢力.md)、[下無極人物](../../../03_人物設定/三十二天/下無極人物.md)。

標記：〔既有〕＝現行設定已有；〔家底庫〕＝家底庫提案已寫、本卡沿用；〔作者定〕＝家底庫第六節已裁定；〔提案〕＝本卡新設；**留白**＝沒有來源，不硬補。

**分級口徑**：下無極本層自稱「頂級」（仙王坐鎮）、「第一等」（真仙坐鎮）〔既有〕；換成上界坐鎮分級（D060），分別是**一流**、**二流**；勢力總表下無極一流「不足 10」家、無頂級〔既有〕。兩種寫法並列（作者定（2026-10-02））。上界規模以地盤計，寄居他人地盤者標「小（寄居）」（作者定（2026-10-02），見[規模口徑提案](規模口徑提案.md)）。

**三家的不對稱**：斷雲有半部劍經和一角偷來的碑，少的是另一半；綴錦有一門天下獨到的補縫陣，補得越多越吃力；荷戈盟什麼都沒有，只有一條讓人活著回來的規矩和一桿撿來的戈。

## 一、斷雲劍宗

**家底形態**：**殘缺絕學**＋偷來（或分家時帶走）的寶物〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 下無極北側劍原〔既有〕 |
| 上游與隸屬 | 鈞天劍宗的分家，互不服〔既有〕 |
| 通常特別擅長 | 劍道殺伐；下無極同代劍修的來處〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 下無極「頂級」〔既有〕＝上界**一流**（太上仙王） |
| 規模 | **大**（作者定（2026-10-02）；上界以地盤計：北側劍原，十片接土以上） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 太上 | 道號待定，閉關〔既有〕 | 仙王〔既有〕 |

### 四、傳承

- **根本功法**：《斷雲劍經》，**仙篇下**（作者定（2026-10-02）；與《鈞天劍經》同出一部劍經）。完整度：**下篇真傳、上篇自補**。原劍經上篇講秤、下篇講斷；斷雲帶走下篇，自補的「秤」草率（作者定，家底庫第 3 題）。
- **招牌神通**：〈斷雲劍光〉（作者定（2026-10-02）；家底庫原稱「斷雲劍」），最低施術境界**銘紋**。
- **秘術**：〈絕退〉（作者定（2026-10-02）），見下方檢查。
- **傳承載體**：斷碑〔家底庫〕。

**〈斷雲劍光〉八條**

| 條 | 內容 |
|---|---|
| 源 | 劍道與「斷」；《斷雲劍經》下篇的術 |
| 門 | 銘紋（力外顯）：劍光成一條平的線，切過靈氣不帶旋。列陣（結構）：切斷陣紋與陣紋、器紋與器紋之間的連結。尊者：劍光百丈。天神（空間）：切開空間一線，像一把裁紙刀劃開天空〔家底庫〕。虛道（規則）：被斬開的地方一時「接不回」，續脈、補縫、接骨都要等劍意散了才下得了手 |
| 象 | 劍光是一條平的線，切過雲層不帶旋；斷雲劍修過招不收勢，一劍出去就不回頭〔家底庫〕 |
| 器 | 本命飛劍。法器起步；劍身越磨越薄，靈器時薄到側看不見；寶器時劍靈雛形只懂「往前」；道器時結合斷之則 |
| 傳 | 能。斬切之劍天下都有；斷雲的家底是半部真傳的劍經，和那一角碑 |
| 限 | 不收勢就不能守；斷雲劍修輸的時候，多半輸在第二劍〔家底庫〕。上篇自補，「秤」草率，看錯形勢時劍也收不回 |
| 價 | 術本身不燒什麼；代價在秘術〈絕退〉 |
| 萬年問 | 不能守的劍修死得早；萬年下來，願意修一門只會往前的劍的人不多，所以斷雲只能在下無極爭收九界劍修 |

| 萬年問 | 一劍之後人就站在原地等死；只有斷雲人覺得值得 |

## 二、綴錦宗

**家底形態**：共用但各自變形的術；太玄補的是「脈」，綴錦補的是「縫」，兩家是不同源的同類，彼此看得懂一半〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 碎錦原一帶〔既有〕 |
| 上游與隸屬 | 受白榆、岱輿供養〔既有〕 |
| 通常特別擅長 | 修補接縫的陣法〔既有〕；碎錦原的每一道縫，宗主褚素都補過〔既有〕 |
| 區隔 | 聞人錦織的是天（霞），綴錦宗縫的是地〔既有，D076〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 下無極「第一等」〔既有〕＝上界**二流**（宗主真仙） |
| 規模 | **小（寄居）**（作者定（2026-10-02）；上界以地盤計：碎錦原是白榆名下〔既有〕，綴錦補了一整片原，一寸地也不是自己的） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 宗主 | 褚素〔既有〕 | 真仙〔既有〕 |
| 其餘 | 留白 | — |

### 四、傳承

- **根本功法**：《百衲篇》，**玄篇下**（作者定（2026-10-02））。百衲是百塊碎布縫成的一件衣；修的是地脈與陣，以神識讀兩片接土的道脈走向，以法力為線。
- **招牌**：〈百衲針陣〉（作者定（2026-10-02）；家底庫原名〈綴〉），陣法；最低施術境界**銘紋**。以陣線像縫衣一樣把兩片接土縫在一起，每一針是一根陣樁；戰鬥中把對手「縫」在地上：針腳先落在對手四周，最後一針收線〔家底庫〕。
- **秘術**：〈以脈為線〉（作者定（2026-10-02）），見下方檢查。
- **傳承載體**：碎錦原本身：綴錦歷代補過的每一道縫都還在地上，弟子照著舊縫學新縫〔提案〕。

**〈百衲針陣〉八條**

| 條 | 內容 |
|---|---|
| 源 | 地脈與陣；《百衲篇》（玄篇下） |
| 門 | 銘紋（力外顯）：盤陣級，縫合一尺裂地或一件裂器。列陣（結構）：院陣級，戰中把對手縫在地上。尊者：山門陣級，補一道接縫。天神（空間）：縫的是兩片接土之間的空間縫，不只是地面。真仙：主持碎錦原級的補縫（山河陣） |
| 象 | 戰場上浮出一排排細密的光點針腳；他們的法力從不成片，永遠是一針一針〔家底庫〕 |
| 器 | 本命法寶多為陣針〔提案〕：法器起步；靈器時一針能落成一根陣樁；寶器時器靈雛形會自己找縫；道器時結合「合」之則。宗主另有頂針，見第五欄 |
| 傳 | 能。陣理共通；太玄續脈手與綴錦補縫看得懂一半〔家底庫〕 |
| 限 | 縫的東西要能承針；對整片崩塌的接土，只能縫邊，縫不了心〔家底庫〕 |
| 價 | 縫針有反震，縫得越多，手越先壞（所以要頂針）〔家底庫〕；補過的地方下一次更難補：接縫越補越多、越補越吃力〔既有〕 |
| 萬年問 | 補縫沒有盡頭，而且越補越吃力；年輕修士不想一輩子當裁縫。「讓碎土自己長根」理論上可行，實際上沒人肯出那個時間〔既有〕 |

**〈以脈為線〉八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 同《百衲篇》，秘傳一章 |
| 門 | 天神起可用 |
| 象 | 修士手腕上浮出一道發光的經脈，從皮下抽出，化成一根線，自己穿進接縫 |
| 器 | 不靠器 |
| 傳 | 只傳宗主一脈 |
| 限 | 只用在陣線不夠、接縫要當場崩的時候 |
| 價 | 把自己的一段經脈當線縫進地裡，那一段從此留在接縫中，不再屬於本人；修為退一段 |
| 萬年問 | 拿自己的經脈補別人的地；碎錦原上有幾道縫，是綴錦前人的經脈 |

### 五、法寶家底

- **鎮宗之物**〔家底庫〕：宗主褚素的**頂針**，承受縫針的反震；沒有它，縫得越多，宗主的手越先壞。品階：**本質下品仙器**（作者定（2026-10-02）），合宗主真仙的常見主人境界。

- **護山大陣、器庫**：留白。
- **靈獸**：無。

### 六、資源

- 碎錦原一帶〔既有〕。
- 白榆、岱輿的供養〔既有〕。

### 七、產業與財政

- 補縫，受白榆、岱輿供養〔既有〕。

### 八、人才管道

留白。

### 九、外交

- 白榆、岱輿：供養者〔既有〕。
- 獵虛盟：獵取接縫滲出之物，與綴錦衝突；接縫一裂就有生意〔既有〕。
- 荷戈盟守邊、獵虛盟撿漏、綴錦補縫，三家同在碎錦原〔既有〕。

### 十、歷代經驗

- 〔提案〕弟子照前人的舊縫學新縫：每一道縫都看得出是誰補的。

**留白**：宗主以外人物、人才管道、護山大陣。

## 三、荷戈盟

**家底形態**：**什麼都沒有**＋人作家底（尉遲氏與一條規矩）〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 各接縫城〔既有〕 |
| 上游與隸屬 | 無；尉遲氏為核心〔既有〕 |
| 通常特別擅長 | 傭修、接縫防務〔既有〕；陸沉在下無極接活、養修行之處〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 下無極「第一等」〔既有〕＝上界**二流**（盟主真仙） |
| 規模 | **小（寄居）**（作者定（2026-10-02）；上界以地盤計：各接縫城的城防，城不是它的）；守接縫的傭修大半出尉遲門下〔既有〕 |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 盟主 | 尉遲鋒，尉遲氏將門之主〔既有〕 | 真仙〔既有〕 |
| 傭修 | 刁五，聖子危機時第一批死於接縫滲出之物的人之一〔既有〕 | 尊者〔既有〕 |
| 其餘 | 來自九界各宗、上界各家，各會各的〔家底庫〕 | — |

### 四、傳承

- **根本功法**：**無共同功法**〔家底庫〕。尉遲氏家傳功法：留白。
- **招牌**：〈荷戈三列陣〉（作者定（2026-10-02）；家底庫原稱「荷戈三列」），陣法；入列最低施術境界**銘紋**。前列接、中列換、後列記，每一刻鐘輪一次；誰都不落單、誰都不連守兩輪〔家底庫〕。
- **秘術**：**無**（作者定（2026-10-02））。
- **傳承載體**：規矩本身；腰牌〔家底庫〕。

**〈荷戈三列陣〉八條**〔提案〕

| 條 | 內容 |
|---|---|
| 源 | 陣法通理，不屬任何一道：三列修士以腰牌連成一座輪換之陣，法力與神識在三列之間輪流傳遞 |
| 門 | 入列最低銘紋：盤陣級，三人一組。尊者領列：院陣級，三列數十人。真仙（尉遲鋒）：一座接縫城的城防輪換。過質變點時，輪換從「人換位」變成「受的傷也跟著輪」：前列受的衝擊，經陣分攤到三列 |
| 象 | 腰牌刻雇主與日期；打法雜，隊形永遠三列，輪換時沒有口令〔家底庫〕。神識看得見三列之間一道法力像接力的燈，一刻鐘換一次手 |
| 器 | 腰牌即陣符〔提案〕：刻雇主與日期，也是入陣的憑證；法器級，人人一塊 |
| 傳 | 人人能修，這正是重點：來自哪一宗、修哪一道都能入列 |
| 限 | 要人數，至少三列；單打獨鬥時沒有用。三列被衝散一列，陣就斷 |
| 價 | 每個人都要輪到前列；陣分攤傷，也就沒有人能完全不受傷 |
| 萬年問 | 這不是修行，是活下來的規矩；強者不屑，天驕學不到東西。荷戈盟靠的是誰也殺不完〔家底庫〕 |

### 五、法寶家底

- **鎮宗之物**：**無**〔家底庫〕。
- 盟主尉遲鋒一桿戈，平平無奇，是第一代尉遲氏從接縫上撿的；荷戈盟的意思就是「扛著它」〔家底庫〕。品階〔提案〕：**本質下品靈器｜當前作盟主信物用**。
- **護山大陣、器庫**：無。
- **靈獸**：無。

### 六、資源

- 各接縫城的城防〔既有〕。
- 其餘無。

### 七、產業與財政

- 傭修：受鳴珂長年僱用〔既有〕；接縫防務〔既有〕。

### 八、人才管道

- 九界飛升者、散修、上界各家的人，誰都收〔家底庫〕。
- 陸沉在下無極接活、養修行〔既有〕。

### 九、外交

- 鳴珂：長年僱主〔既有〕。
- 碎錦原：荷戈守邊、綴錦補縫、獵虛盟撿漏〔既有〕。

### 十、歷代經驗

- 三列的規矩：誰都不落單、誰都不連守兩輪〔家底庫〕。

### 十一、弱點

- 沒有一個人能單獨贏過頂級宗門的真傳〔家底庫〕。
- 接縫防務吃緊〔既有〕；聖子危機時，最先死的是傭修〔既有〕。

### 十二、劇情鉤

- 第 9–14 篇：陸沉在下無極接活、養修行〔既有〕；第 13 篇程序未決期間他靠接任務過日子〔既有〕。
- 第 11 篇：碎錦原聖子危機，刁五死於接縫滲出之物〔既有〕。
