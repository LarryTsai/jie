## 一、鈞天劍宗

**家底形態**：鎮宗絕學＋鎮宗之地（萬劍碑）〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 上無極中部群峰道域〔既有〕 |
| 上游與隸屬 | 無；上無極劍道魁首〔既有〕 |
| 通常特別擅長 | 劍道正統；以重為劍〔家底庫〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 上界**頂級**（太上準仙帝閉關）〔既有〕 |
| 規模 | 留白（上界規模未定） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 太上 | 道號待定，閉關〔既有〕 | 準仙帝〔既有〕 |
| 宗主 | 截雲（道號），生於古戰之後〔既有〕 | 仙王〔既有〕 |
| 天驕 | 駱霜，陸沉在上無極的同代劍修〔既有〕 | 天神 → 虛道〔既有〕 |
| 真傳 | 戎霈，駱霜同門，天驕中的惡人〔既有〕 | 天神 → 虛道〔既有〕 |

### 四、傳承

- **根本功法**：《鈞天劍經》〔提案名；「鈞天劍道」為既有名〕，**仙篇下**〔提案〕。完整度：**上篇真傳、下篇自補**。鈞天與斷雲原是一部劍經的上下篇，上篇講秤、下篇講斷；分家時各帶一篇，各自花了數萬年把缺的那一半補出來，補出來的都不是原本（作者定，家底庫第 3 題）。鈞天自補的「斷」笨重〔家底庫〕。
- **招牌神通**：〈鈞天劍域〉〔提案名〕，最低施術境界**銘紋**。劍意是一桿秤：一劍落下之前，先把對手每一條出路都秤一遍，讓退路比前方更重〔家底庫〕。
- **秘術**〔提案〕：〈承碑〉，見下方檢查。
- **傳承載體**：萬劍碑〔既有〕。嫡傳入門時在碑前選一道前人劍痕「接著練」，一輩子把那一劍往前推一寸〔家底庫〕。

**〈鈞天劍域〉八條**

| 條 | 內容 |
|---|---|
| 源 | 劍道與「重」：鈞是重量單位，鈞天是把天壓在劍上〔家底庫〕；《鈞天劍經》上篇的術 |
| 門 | 銘紋（力外顯）：劍比形重，劍尖下沉一寸。列陣（結構）：劍意成秤，三尺之內每一條出路都被秤過。尊者：成域。天神（空間）：域內空間變重，飛劍、遁光都被壓低一截。虛道（規則）：退路比前路重，改的是「重」的分配，不是力氣 |
| 象 | 起劍前劍尖下沉一寸，像在掂重量；劍意掃過的地方空氣變稠；神識碰上去像碰到一塊鉛〔家底庫〕 |
| 器 | 本命飛劍。法器起步；入門在碑前接一道劍痕之後，劍隨那一劍推進而加重；寶器時劍靈雛形會「掂」對手；道器時結合重之則 |
| 傳 | 能。重劍天下都有；鈞天的家底是萬劍碑，每一代都有前人的一劍可接 |
| 限 | 不快；遇上只求脫身、不求勝的對手，秤還沒秤完，人已經走了〔家底庫〕 |
| 價 | 術本身不燒什麼；代價在秘術〈承碑〉 |
| 萬年問 | 慢，而且一輩子只把前人的一劍推一寸。上無極多數劍修要的是快，要的是自己的劍 |

**〈承碑〉八條**〔提案〕

| 條 | 內容 |
|---|---|
| 源 | 同《鈞天劍經》，秘傳一章 |
| 門 | 天神起可用 |
| 象 | 劍修身後浮出萬劍碑上那一道劍痕的虛影，前人的一劍從碑上落下，壓在他的劍上 |
| 器 | 本命劍承前人一劍的全重；寶器以下的劍會在那一擊後裂 |
| 傳 | 只傳嫡傳，且只能借自己接的那一道 |
| 限 | 一道劍痕一生只能借一次 |
| 價 | 自己推進的那一寸劍意被碑收回：碑上那道劍痕倒退到他入門時的位置，數十年的功夫歸零 |
| 萬年問 | 借一次，就把自己一生唯一的一寸還給前人；所以鈞天人寧可輸，也很少承碑 |

### 五、法寶家底

- **鎮宗之物**：**萬劍碑**〔既有〕，不按器論〔家底庫〕。碑上留歷代劍修各一劍，空位越來越少〔家底庫〕。
- **斷碑**：分家時從萬劍碑上鑿走的一角在斷雲劍宗手上；碑上那一劍是誰留的，兩家說法不同（作者定，家底庫第 3 題）。
- **護山大陣、器庫**：留白。
- **靈獸**：無。

### 六、資源

- 上無極中部群峰道域〔既有〕；萬劍碑。
- 靈脈、秘境：留白。

### 七、產業與財政

留白。

### 八、人才管道

- 招收九界大比出身的劍修，只收最好的〔既有〕。
- 截雲收徒只看一件事：劍有沒有「自己的理由」〔既有〕。

### 九、外交

- 斷雲劍宗：同源分家，互不服〔既有〕；截雲看不起斷雲，卻每年都去看斷雲的弟子試劍〔既有〕。
- 封寒轉鐧後的比照對象〔既有〕。

### 十、歷代經驗

- 〔提案〕碑上空位越來越少，這是鈞天自己的焦慮：再過幾代，後人只能接前人的劍，沒有地方刻自己的〔家底庫〕。

### 十一、弱點

- 不快〔家底庫〕。
- 下篇是自補的，「斷」笨重〔家底庫，作者定〕。
- 碑位將盡〔家底庫〕。
- 同門相殘：戎霈認為劍道第一只能有一個〔既有〕。

### 十二、劇情鉤

- 第 18 篇：封寒轉鐧，截雲說「可惜」，駱霜說「對」〔既有〕。
- 駱霜在萬劍碑前接的是最淺的一道劍痕，「最淺的才推得動」〔家底庫〕。
- 斷碑拓片在千禁城禁市出現，駱霜與斷雲劍修爭拓片〔家底庫流通層第 3 項〕。

**留白**：上界規模、太上道號、護山大陣、產業、靈脈。

## 二、歐冶山

**家底形態**：手藝作家底；寶物的經手者，不是擁有者〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 上無極地火道域〔既有〕 |
| 上游與隸屬 | 無 |
| 通常特別擅長 | 仙器鍛造；器毀重鑄〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 上界**一流**（第一等；山主仙王）〔既有〕 |
| 規模 | 留白 |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 山主 | 韋鑄〔既有〕 | 仙王〔既有〕 |
| 其餘 | 留白 | — |

### 四、傳承

- **根本功法**〔提案〕：《冶爐經》，**玄篇上**。修的是火與金：以地火淬自身法力，法力帶「冶」性，能入器紋。
- **招牌神通**〔提案〕：〈點化〉，最低施術境界**銘紋**。以神識聽一件器的器紋，以帶地火的法力改其中一道，讓器換一種用法。歐冶修士出門不帶自己的兵器，打起來撿對手的、撿地上的，敲兩下、聽一聲，換個用法就用〔家底庫〕。
- **秘術**〔提案〕：〈熔兵〉，見下方檢查。
- **傳承載體**：**器譜壁**〔提案正名；家底庫原稱器譜牆〕。
- **重鑄**：器毀重鑄已非原物〔既有〕；山規：重鑄之器名字前加一個「再」字，鑄幾次加幾個〔家底庫〕。

**〈點化〉八條**〔提案〕

| 條 | 內容 |
|---|---|
| 源 | 火與金的鑄造之道；《冶爐經》（玄篇上） |
| 門 | 銘紋（力外顯）：改法器的一道紋。列陣（結構）：改靈器，整件器換一種用法。尊者：戰中觸碰對手之器即可改。天神（空間）：不必觸碰，神識所及三丈之內可改。虛道（規則）：改的不再是紋，是器所結合的那一條則（道器以上） |
| 象 | 手中器的器紋在流動，像燒紅的鐵還沒冷；神識裡他們手中的器總在「被改」〔家底庫〕。出手前先敲兩下、聽一聲 |
| 器 | 山規不立本命器〔提案〕：手上永遠是別人的器，或剛撿來的器 |
| 傳 | 能。煉器師天下都會改紋；歐冶的家底是器譜壁上數萬年的仙器紋譜：看過，才改得快 |
| 限 | 改不動高於自身兩級的器；本命器有主人的神識護著，戰中很難改 |
| 價 | 每點化一次，那件器少一分壽；改到第三次，器多半就毀了 |
| 萬年問 | 不立本命器，就放棄了修士與器之間最強的那一層共鳴；很少人肯一輩子用別人的器 |

**〈熔兵〉八條**〔提案〕

| 條 | 內容 |
|---|---|
| 源 | 同《冶爐經》，秘傳一章 |
| 門 | 天神起可用 |
| 象 | 修士掌心燒出一團不是地火的白火，對手手中的兵器從握處開始軟 |
| 器 | 以自身為爐，不需器 |
| 傳 | 只傳山主一脈的真傳 |
| 限 | 只熔得動品階不高於自身的器；一戰一次 |
| 價 | 燒的是自己的本源火：地火入脈，折壽，經脈留下灼痕 |
| 萬年問 | 拿自己當爐，熔一件別人的器；划不來，所以只在保命時用 |

### 五、法寶家底

- **鎮宗之物**：**無鎮宗之器**〔家底庫〕。
- **器譜壁**〔家底庫，本卡正名〕：山腹一面壁，凡出歐冶山的仙器都在壁上留一道紋；器毀，紋裂。山中弟子每天早課是看壁，數今天裂了幾道〔家底庫〕。不按器論。
- **再再再鳴**〔家底庫〕：鑄過三次的一柄仙器，三任主人都死在同一處接縫上；本質品階與下落留白。
- **護山大陣、器庫**：留白。
- **靈獸**：無。

### 六、資源

- 上無極地火道域〔既有〕。
- 昏曉隕金一類材料（器道宗門的價單跟著星隕漲）〔家底庫流通層第 10 項〕。

### 七、產業與財政

- 替各庭重鑄古戰遺器〔既有〕。
- 與玄闕長年合作打造陣器〔既有〕。
- 鑑偽：古戰遺器贗品（承明劍殘片一類）〔家底庫流通層第 12 項〕。

### 八、人才管道

留白。

### 九、外交

- 玄闕：長年合作打造陣器〔既有〕。
- 各庭都是客戶〔既有〕。
- 聞人氏一類的消息網：「器譜壁又裂了一道」本身就是情報〔家底庫流通層第 4 項〕。

### 十、歷代經驗

- 韋鑄總說：「重鑄的不是原物。」〔既有〕失去就是失去（D058）。

### 十一、弱點

- 沒有一件真正屬於自己的器，正面硬拚仙器時吃虧〔家底庫〕。
- 器譜壁上的裂紋人人想知道，歐冶守不住這個消息〔家底庫〕。

### 十二、劇情鉤

- 器譜壁裂紋的消息由聞人氏賣：哪一柄仙器毀了、主人還在不在〔家底庫〕。
- 古戰遺器贗品，只作鑑偽的日常；承明劍等真品**不得安排陸沉繼承**〔既有約束〕。

**留白**：上界規模、山主以外人物、人才管道、護山大陣、再再再鳴的品階與下落。

## 三、泠光王庭

**家底形態**：手藝作家底；不戰之家〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 本根在上無極〔既有〕 |
| 上游與隸屬 | 受創九庭之一（湛氏）〔既有〕 |
| 通常特別擅長 | 冰鏡與留影傳承；鑑定留影是否事先布置、是否偽造〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 上界**一流**（王主仙王、無準仙帝）〔既有：總表〕 |
| 規模 | 留白 |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 王主 | 湛寒碧〔既有〕 | 仙王〔既有〕 |
| 鏡錄師 | 湛疏影，親手鑑過的偽影比真影多〔既有〕 | 真仙〔既有〕 |
| 少主 | 湛冰壺，主張泠光不該只鑑不說〔既有〕 | 天神〔既有〕 |

### 四、傳承

- **根本功法**〔提案〕：《冰鑑經》，**玄篇上**。修的是光與冰：以法力凝霜為鏡，以神識入光。
- **招牌神通**：〈鑑影〉〔既有〕，最低施術境界**銘紋**；戰鬥用法〈千霜鑑〉〔提案名；家底庫原寫冰鏡折光〕，最低施術境界**尊者**。
- **秘術**：**無**〔提案〕。不戰之家不備秘術。
- **傳承載體**：歷代鏡錄〔提案〕：只記「哪一段影是真、哪一段是假」，不記影的內容。

**〈鑑影〉與〈千霜鑑〉八條**

| 條 | 內容 |
|---|---|
| 源 | 光與冰之道；《冰鑑經》（玄篇上） |
| 門 | 銘紋：〈鑑影〉，以神識入一段留影，辨它是否事先布置、是否偽造〔既有能力〕。尊者：〈千霜鑑〉，戰場四周凝出霜面，把對手的術「映」一次：讓對手從另一個角度看見自己的術朝自己來，慢半拍〔家底庫〕。天神（空間）：霜面之間的光被拖住，映出的那一擊真的在半拍後落一次，雖然只有原術的幾成。虛道（規則）：鑑的不只是影，是一段記錄有沒有被「對齊」過 |
| 象 | 戰場四周凝出霜面，每一面裡都有一個慢半拍的你；神識探進霜面，探到的是自己剛才的神識〔家底庫〕 |
| 器 | 本命法寶多為冰鏡〔提案〕：法器起步；靈器時能存一刻光；寶器時器靈雛形會「記得」照過的人；道器時結合光之則 |
| 傳 | 能。鑑影的手法外人學得到；學不到的是數萬年的鏡錄：見過的偽影越多，鑑得越準 |
| 限 | 鏡要光。無光、無冰，或對手根本不在乎看見自己的時候，霜廳只是一間冷房間〔家底庫〕 |
| 價 | 鑑影要以神識入影，看過的都忘不掉；泠光人人背著別家的家醜〔提案〕 |
| 萬年問 | 鑑影就是看盡別人的家醜，看了就是知道，知道了就危險；泠光活下來靠「只鑑不說」，沒幾家願意這樣活 |

### 五、法寶家底

- **鎮宗之物**〔家底庫〕：一面**無字鏡**，只鑑不存：照過的東西鏡中即忘。品階〔提案〕：**本質下品仙器**，合王主仙王的常見主人境界。這是「只鑑不說」自保之道的器物化，也意味泠光從不留底，誰也不能從泠光的庫裡搜出家醜〔家底庫〕。
- **護山大陣、器庫**：留白。
- **靈獸**：無。

### 六、資源

- 冰鏡與留影傳承〔既有〕。
- 靈脈：留白。

### 九、外交

- 霜明界守鏡臺的古影：影師會私賣給上界收藏者，泠光鑑出某段古影是真的，卻不能說〔家底庫流通層第 9 項〕。

### 十二、劇情鉤

## 四、玄闕王庭

**家底形態**：傳承寶物（古兵器下落不明）＋軍陣作家底〔家底庫〕。

### 四、傳承

- **根本功法**〔提案〕：《闕門經》，**玄篇上**。修的是地脈與兵陣：以神識接地脈，以法力替陣腳供力。家族出身不會使所有人自動掌握同一功法〔既有〕；《闕門經》是邊軍與王族的公傳，各支另有家傳。
- **招牌**：〈借脈軍陣〉〔提案正名；既有 A1 借脈〕，陣法；主陣最低施術境界**尊者**。
- **秘術**：留白（無來源）。
- **傳承載體**：公冶家陣譜〔既有〕，裡面留著古時那次調動的日期，被記成一次尋常演練〔既有，A1〕。
- **聖子的本命寶物**：商應璋分光匣六劍與《分光劍典》〔既有〕，屬他本人，不屬王庭家底。

**〈借脈軍陣〉八條**

| 條 | 內容 |
|---|---|
| 源 | 地脈與兵陣之道；《闕門經》。軍陣借脈屬山河陣級〔既有：陣法規模表〕 |
| 門 | 入陣最低列陣。主陣：尊者可主院陣級小隊陣；天神可主山門陣級；真仙可主山河陣級（狄崇山一級的統兵者）。過質變點時，陣從「人連成網」變成「地替陣供力」，再變成「一片天的道脈短暫改姓」 |
| 象 | 戰前先插樁借脈，地上草木朝陣心伏倒；成陣的修士腳步一致，神識像一張網，碰一處，全網都知道〔家底庫〕 |
| 器 | 陣樁與陣器，多與歐冶山合作打造〔既有〕；個人本命器各異 |
| 傳 | 能。軍陣天下都有；玄闕的家底是年年可借的關口之地，與公冶陣譜 |
| 限 | 陣要地：在無主的虛空、碎裂的接縫上，借不到脈，軍陣只剩人〔家底庫〕 |
| 價 | 陣腳插下的每一處，當地道脈短暫「改姓」替陣供力；陣撤之後，那片地會虛一陣子〔家底庫〕 |
| 萬年問 | 借脈要地方容許；只有握著關口的王庭年年借得到，別家借一次就是結仇。越強的經營越離不開別人的土地〔既有：權力為何不歸一〕 |

### 五、法寶家底

- **傳承寶物**：**鎖關鉞**〔既有〕：仙王層次仙器，持有人商玄度；斧鉞形重器，可在特定接口承接斷路所需的反震，只能作用於已掌握的接口，受到反攻會傷及持有者和本陣〔既有：寶物總錄〕。當代是否仍存、是否傳到商應璋手中均未定〔既有〕；**不得安排陸沉繼承**〔既有約束〕。
- **關冊**〔家底庫〕：每座關口一頁，誰租了通道、租到哪天，冊上都有。它不能打，卻是同歸會最想廢掉的東西（通道租金）。不按器論。
- **祖脈道場**：商玄度的罪證封在這裡，繼承人商應璋能入（D042）〔既有〕。
- **護山大陣、器庫**：留白。
- **靈獸**：無。

### 六、資源

- 各處關口與通道〔既有〕。
- 祖脈道場〔既有〕。

### 七、產業與財政

- 保護往來、提供兵力、控制關鍵節點〔既有〕。
- 通道租金〔既有〕；關口護送費與臨時加收的費用〔既有：住在關下的人〕。

### 八、人才管道

留白。

### 九、外交

- 同歸會最大的對手之一（通道租金）〔既有〕。
- 澄霄：玄闕想在九界界路上端派駐軍陣，衛景行一直拖著不給〔既有〕。
- 歐冶山：長年合作打造陣器〔既有〕。
- 第 24 篇商應璋與陸沉結盟〔既有〕。

### 十、歷代經驗

- 商允執的治法：讓每一處關口都真的被保護，也讓每一處都離不開玄闕〔既有〕。

### 十一、弱點

- 陣要地〔家底庫〕。
- 依賴與怨：關口真的保護人，也讓依賴它的人無處申辯〔既有〕。
- 繼位不是定局：商應琮與商應璋不同路，邊軍信堂兄〔既有〕。
- 祖脈道場裡封著商玄度的罪證〔既有〕。

### 十二、劇情鉤

- 第 11 篇：碎錦原，狄崇山的封鎖令合法，被拿來困人；他沒撤（將錯就錯）〔既有〕。
- 第 24 篇：商應璋與陸沉結盟〔既有〕。
- 第 25 篇：商應璋開放祖脈道場，三刻共振〔既有〕。
- 公冶陣譜裡那次「演練」〔既有，A1〕。

**留白**：上界規模、秘術、商應璋境界（照原檔）、苔翁境界、人才管道、護山大陣、鎖關鉞下落。
