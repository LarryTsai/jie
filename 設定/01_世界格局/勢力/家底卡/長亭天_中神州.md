依[修仙文明底層規格](../../../00_故事定位/修仙文明底層規格.md)第 16 節卡片格式；每一項能力先過「能力設計檢查條」八條。家底形態照[宗門與天驕家底庫提案](../../../06_待定與決策紀錄/宗門與天驕家底庫提案.md)第二節，不改類型。來源：[劫故土六域頂級勢力](../劫故土六域頂級勢力.md)、[故土六域人物](../../../03_人物設定/三十二天/故土六域人物.md)、[同代女天驕群像](../../../03_人物設定/同代女天驕群像.md)、[陣法與禁制](../../../04_修行與特殊事物/陣法與禁制.md)。

**分級口徑**：九界頂級＝虛道或天神坐鎮的一域之首；一流＝尊者至天神坐鎮、非一域之首（D060、D073）。規模大中小以正式弟子數計（D073）；世家口徑另定，未定前留白。

**三家的不對稱**：大衍有絕學、有一套缺一根的算籌；文家有一門外人學得到結構、學不到末筆的禁，和一疊用一張少一張的禁帖，另外守著一捧不屬於自己的燼；觀古門什麼都沒有，只有一串打不開任何東西的鑰匙，和幾千年沒人想跟它為敵。

**主角群界線**：文奕的功法、招式與八卦盤照[主角群武學譜](../../../04_修行與特殊事物/主角群武學譜.md)，本卡不新增；文家卡只寫家族的家底。

## 一、大衍宗

**家底形態**：鎮宗絕學＋傳承寶物〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 中神州西部群山〔既有〕 |
| 上游與隸屬 | 無；中神州古宗〔既有〕 |
| 通常特別擅長 | 推演、陣道；大比賽程與籤位由大衍推演，大比規則的制定者〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 中神州**頂級**（太上虛道）〔既有〕 |
| 規模 | **大**（作者定（2026-10-02）） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 太上 | 大衍老人，閉關；本界當代虛道三人之一〔既有〕 | 虛道〔既有〕 |
| 宗主 | 司馬定之〔既有〕 | 天神〔既有〕 |
| 天驕 | 奚箴〔既有〕 | 留白 |

### 四、傳承

- **根本功法**：《大衍數經》，**玄篇上**（作者定（2026-10-02））。名取「大衍之數五十，其用四十九」。修的是數與推演之道：以神識把一件事拆成靈紋，以法力讓靈紋在周身排列、推出下一步。
- **招牌神通**：〈大衍神數〉（作者定（2026-10-02）正名；家底庫原名〈衍〉），最低施術境界**銘紋**。戰鬥中的形式是**報招**：開打前說出對手接下來幾手〔家底庫〕。
- **秘術**：〈焚籌〉（作者定（2026-10-02）），見下方檢查。
- **傳承載體**：歷代推演記錄，包括算錯的那幾次〔提案〕。
- **規矩**：報錯了要認；報錯不丟人，不認才丟人〔家底庫，與奚箴「論錯了會當場認」同源〕。大衍的籤從不只推一次〔既有〕。

**〈大衍神數〉八條**

| 條 | 內容 |
|---|---|
| 源 | 數與推演之道；《大衍數經》（玄篇上） |
| 門 | 銘紋（力外顯）：推一步，算出對手下一手。列陣（結構）：推三手；排一場大比的賽程。尊者：推一座陣局的變化。天神（空間）：推演帶方位，算得出對手遁法的落點。虛道（規則）：推一地之勢，大衍老人的層次 |
| 象 | 交手前那句「第三招，你會往左」；袖中算籌相碰的聲音；神識探過去，周身有一層極淡的、正在排列的靈紋〔家底庫〕 |
| 器 | 本命法寶是一套算籌〔家底庫〕：法器起步；靈器時籌與籌之間自己會連線；寶器時器靈雛形會「搶先」排出下一步；道器時結合數之則。宗門允許真傳帶出的上限是七根（奚箴）〔家底庫〕 |
| 傳 | 能。推演天下陣師都懂一點；大衍的家底是數千年的推演記錄與那套四十九根的算籌 |
| 限 | 推演要資料。對「沒見過的東西」與「自己」都算不準；奚箴嫌陸沉是無法推演的變數〔家底庫，既有〕。吃進錯資料，會很有把握地算錯〔既有〕 |
| 價 | 推演耗神識；報錯要當眾認〔家底庫〕 |
| 萬年問 | 一輩子算別人，算不了自己；而且越有把握，錯得越大。願意修一門會「很有把握地算錯」的道的人不多 |

**〈焚籌〉八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 同《大衍數經》，秘傳一章 |
| 門 | 列陣起可用 |
| 象 | 修士捏斷一根算籌，籌中冒出一縷青火，周身靈紋瞬間排滿 |
| 器 | 燒的是自己那套算籌中的一根 |
| 傳 | 只傳真傳 |
| 限 | 燒一根推一次，一次只推一件事 |
| 價 | 算籌一根就毀，本命器從此缺一根、降一級；神識灼傷，數月推不準 |
| 萬年問 | 燒的是自己的本命器；大衍人寧可報錯認錯，也很少焚籌 |

### 五、法寶家底

- **鎮宗之物**〔家底庫〕：一套**算籌五十根，用四十九**。第五十根稱「不用之籌」，宗門傳說它算的是推演者自己，所以從不用；數百年前它丟了。今日大衍算籌是四十九根加一個空位。品階：**本質上品道器｜當前作上品寶器用（殘：缺第五十籌）**，只剩推演外物的那一部分〔家底庫，D073 對齊〕。
- **護山大陣、器庫**：留白。
- **靈獸**：無。

### 六、資源

- 其餘留白。

### 七、產業與財政

- 推演大比賽程與籤位；與胤朝共治大比〔既有〕。

### 八、人才管道

### 九、外交

- 文家：論學數百年〔既有〕。

### 十、歷代經驗

- 報錯要認〔家底庫〕；籤從不只推一次〔既有〕。

### 十一、弱點

- 第 3 篇：一名裁場陣師收了赫連驥與南榮斂的賄，陣盤紀錄露出被改的一刻，陣師自首〔既有〕。

## 二、文家

**家底形態**：共用但各自變形的術＋一次性的傳承寶物〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 中神州〔既有〕 |
| 上游與隸屬 | 無 |

### 二、等級與規模

| 項 | 內容 |
|---|---|

| 職 | 人 | 境界 |
|---|---|---|

### 四、傳承

- **根本功法**：家傳禁學〔既有〕；名與品階**留白**（作者定（2026-10-02）維持留白；[主角群武學譜](../../../04_修行與特殊事物/主角群武學譜.md)：文家家學不沿用舊《古神禁典》，品名留白）。
- **招牌**：〈落款禁〉（作者定（2026-10-02）正名；家底庫原稱「署名」）：禁的八要素天下共通〔既有〕，文家的特色是每個文家人寫的禁都有自己的末筆，族內一眼認得是誰寫的〔家底庫〕。最低施術境界**銘紋**（行禁的寫入門檻〔既有：D073〕）。
- **秘術**：留白。
- **傳承載體**：禁帖（見第五欄）；族中的末筆譜〔提案〕：記每一代人的末筆長什麼樣。

**〈落款禁〉八條**

| 條 | 內容 |
|---|---|
| 源 | 禁之道；文家家傳禁學（名、品留白） |
| 門 | 寫禁依 D073 門檻：行禁銘紋、力禁列陣、空禁天神、則禁虛道〔既有〕。落款本身不另設門檻：能寫完一道完整禁制，就能在末筆落自己的款 |
| 象 | 戰前先在地上、空中或對手兵刃上寫字；禁紋末筆一鉤〔家底庫〕。神識讀那一鉤，讀得出寫的人是誰 |
| 器 | 筆、承載物；禁帖。文奕八卦盤為本質上品靈器、文家祖傳、由他自己祭煉〔既有，D073〕，屬他本人 |
| 傳 | 能。外人學得到文家禁的結構，學不到那一筆；沒有末筆的文家禁，族人一眼看得出是偷的〔家底庫〕 |
| 限 | 禁要承載物與時間；憑空對打、來不及落筆時，文家人只能退〔家底庫〕 |
| 價 | 末筆就是署名：文家人寫過的禁，走到哪裡都認得出是誰寫的，藏不住手 |
| 萬年問 | 禁天下都有；把自己的名字落在每一道禁上，等於讓每一道禁都能追回自己身上。只有世家敢這樣寫 |

### 五、法寶家底

- **傳承寶物**〔家底庫〕：**禁帖**。祖輩寫好、只留最後一筆不落的半成禁，貼在任何能承載的東西上，補一筆就成；用一張少一張，祖輩死了就不會再有。品階〔提案〕：多為法器、靈器級的禁，不按器的品論，按禁的四類論。
- **守燼**〔既有，D075〕：文家祖上與驤鳴雷池有古約，代代替赤翎保管一捧燼；燼上的禁紋就是古約，另一半刻在雷池底；條文大意「代代守，不許散，不許用；池不能劈之日，燼歸其主」，文家不知道燼是誰。**燼不是文家的家底**：讀得懂、不准用。
- **護山大陣、器庫**：留白。
- **靈獸**：無。赤翎不列為任何家族的家底（D072）〔家底庫〕。

留白。

### 八、人才管道

### 九、外交

- 大衍宗：論學數百年〔既有〕；大衍第五十籌，文家也想要（作者定，家底庫第 7 題）。
- 驤鳴雷池：古約〔既有〕。

### 十、歷代經驗

- 守燼的代價：每代守燼人以神識溫禁、不能離燼太久；世代守一個讀得懂、不准用的禁〔既有，D075〕。

### 十一、弱點

- 禁要承載物與時間〔家底庫〕。
- 禁帖用一張少一張〔家底庫〕。
- 守燼人不能離燼太久〔既有〕。

### 十二、劇情鉤

## 三、觀古門

**家底形態**：**什麼都沒有**（無殺伐絕學）；家底是開啟權與鑰匙〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 中神州歷代遺跡〔既有〕 |
| 上游與隸屬 | 無 |
| 通常特別擅長 | 遺跡考據與開啟權；守著古戰前後的遺跡；九界原件的保存者之一〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 中神州**一流**〔既有〕 |
| 規模 | **小**（作者定（2026-10-02））：門人散守各處遺跡 |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 門主 | 龔望古，對盜掘者從不手軟〔既有〕 | 尊者巔〔既有〕 |
| 其餘 | 留白 | — |

### 四、傳承

- **根本功法**：《守古篇》，**靈篇上**（作者定（2026-10-02））。修的是陣與禁的守法：以神識讀遺跡的舊禁，以法力替舊禁續一口氣，不改它。
- **招牌**：〈護古結界〉（作者定（2026-10-02）正名；家底庫原名〈封退〉），陣法；最低施術境界**銘紋**。只守不攻，把戰場邊緣封起來，不讓打鬥碰到遺跡〔家底庫〕。
- **秘術**：**無**（作者定（2026-10-02））。
- **傳承載體**：古鑰（見第五欄）；遺跡考據〔既有〕。

**〈護古結界〉八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 陣與禁的守法；《守古篇》（靈篇上） |
| 門 | 銘紋（力外顯）：封一室。列陣（結構）：院陣級，封一處遺跡的邊。尊者：山門陣級，把一場打鬥整個框在遺跡外。過天神（空間）時可以隔空，不必先在邊上插樁；觀古門當代無天神 |
| 象 | 出手第一件事是封邊；對手打得越兇，他們退得越整齊〔家底庫〕。神識看得見一道淡金的邊，邊外的遺跡紋絲不動 |
| 器 | 古鑰兼作結界的樁：一把鑰插在地上，就是一根陣樁 |
| 傳 | 能。結界天下都有；觀古門的家底是開啟權，不是結界 |
| 限 | 只守不攻，打不贏真正想贏的人〔家底庫〕 |
| 價 | 結界吃的是自己的法力；觀古門人打完一場，自己受的傷多半比對手重 |
| 萬年問 | 這門術只為了不讓東西被打壞；修士修的是自己的路，很少有人願意一輩子替死人看門 |

### 五、法寶家底

- **鎮宗之物**：**無**〔家底庫〕。
- **古鑰**〔家底庫〕：一串，一把鑰對一座遺跡；有些鑰對的遺跡已經不在了，門人還是一代代交下去，因為「說不定哪天又找到了」。古鑰本身多是法器或靈器，值錢的是它開的門〔家底庫〕。
- **護山大陣、器庫**：無。
- **靈獸**：無。

### 六、資源

### 七、產業與財政

留白。

### 八、人才管道

留白。

### 九、外交

- 與散修、盜掘者衝突〔既有〕；穿山會盜墓，是不在乎與所有遺跡為敵的人〔家底庫〕。

### 十、歷代經驗

### 十一、弱點

### 十二、劇情鉤
