## 原則

1. **不是所有壞事都通往同一個幕後。**本表 45 個地方反派裡，連到玉壺天的 8 個、連到同歸會的 3 個（諶理兩家都賣），其餘都獨立；兩家之間還互相看不順眼。
2. **每個反派都有自己的邏輯**：配額不公、規則偏袒大宗、稀缺就是價、天賦生錯地方——他們說的都有一部分是真的。
3. **境界合該地的尺度**：留舟島列陣稱霸；九界尊者、天神；下無極至尊、真仙；上無極仙王；大羅仙王。
4. **修士手段**：斷繩符、鑿冰符、斷聲陣、劍意殘紋、斷弦陣、禁中禁。不寫凡人的刀與毒酒。
5. **打鬥用仙人方式，揭露用遺痕與後手**（D067）：反派的罪不靠查帳揭開，而是靠符痕、陣痕、取痕、氣機陣錄、凍光這類修士遺痕，或在交手中被逼出來。
6. **篇外，世界自轉**：陸沉沒碰上的反派照樣存在，是配角與同代人自己的仇敵。

## 跨兩界網絡（三十二天側）

**規則前提**（不改）：兩界八萬年沒有大規模往來，只有小規模偷渡；低路只容列陣／鬥靈以下，雷望衛掌縫鎖；九界的低路端口只有兩個——陸沉故土（留舟島海眼）與望歸縫海；異域後裔網絡散在九界；玉壺天終局前碰不到聖土（D068）。所以這張網小而精，全走低路。

### 往來重開會斷誰的財路——第 28 篇的另一股阻力

往來一旦以九界自己的名字重開，界潮窗口就不再是黑市：**縫民、涂鹹、冒沙、司寇殘、縫刃、甄四海的名額生意、申磬的稀缺**都會斷；**昝渺**的閉門也會破。

他們在第 28 篇聯手的形式：斷命樓接下甄四海與申磬的單，要在簽約時刺殺九界新簿的第一位擔保人寇平——擔保人一死，新簿就簽不成。裂縫：甄四海只要延遲，不要人死；申磬準備事後滅口甄四海；縫民只想窗口照舊半開，不想見血。到場點名的**裴照川**（刑滿）擋下刺客——第 7 篇他挾持過寇平，第 28 篇他護住寇平。這是另一股阻力，不搶第二次校正的主位，陸沉不在這一處。
