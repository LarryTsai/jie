# 鎮岳峰

## 傳承與生活

保留峰主岳沉淵、六位師兄姊與《萬體鑄身經》。根本是把肉身修成可承大道之器，不只追求力大、堅硬；教習重視站穩、承痛、不崩。弟子少，修行艱苦，各自沿自身缺陷與經歷修出不同的體。

劫由神識強、肉身弱起步，在此學習重鑄自身。選擇此峰的具體事件仍待寫，不由指骨安排命定傳承。

山體如黑鐵，保留鎮岳臺、碎石場、淬骨池、萬體碑林、鎮岳崖與峰主殿等場所。初學者在臺上學會穩住呼吸，師兄姊也可能為了新傷重新調整舊有的行力方法；苦修要有指導、恢復與個人選擇，不把受傷本身當成進步。

## 萬體鑄身經

無屬性的鑄身基礎，先鍛其身，再承其道。基礎方向為鍛骨、煉筋、熱血、通脈；不是四個新增境界。公共基礎與峰內深傳可以分層，但篇數、取得時機與新境界配合待定。

## 岳沉淵與六位師兄姊

| 人物 | 身分 | 體質與方向 |
|---|---|---|
| 岳沉淵 | 峰主，古嶽真君 | 古嶽鎮身體；身負古嶽巨人血脈，以肉身承壓、承法，並非六極之一 |
| 沈山河 | 大師兄 | 玄極重域體；重域壓制、控場，沉穩可靠 |
| 秦照雪 | 二師姐 | 太陰映骨體；冷骨、收束與精準 |
| 陸行烈 | 三師兄 | 赤陽焚身體；爆發、燃身，須承擔反噬與失控風險 |
| 柳青藤 | 四師姐 | 周天星脈體；分傷、循環、續命，不是憑空消除傷勢 |
| 韓鐵衣 | 五師兄 | 虛界不破體；隔傷、錯位防禦，不是絕對無敵 |
| 顧小滿 | 六師姐 | 剎那無痕體；節奏差與近身瞬動，不是真正停止時間 |

六極以肉身映照大道之影，不等於低境弟子已能完整掌控時間、空間等大道。表內是修行方向，開篇掌握程度、境界、年齡與成長進度需另配，不能整套巔峰能力提前登場。

師兄姊能讓劫看見不同可能，但各有自己的人生；劫不必逐一複製六體。舊稿固定雷身招式、舊命圖成果、宗內大比名次與師兄姊參賽資格不隨本次沿用；命圖形制改依 D069（太玄命藏的無星古圖，新雷新位，見[太玄命圖](../../../04_修行與特殊事物/太玄命圖.md)）。

## 劫的承身

取得兩儀玄雷、回宗閉關後凝成第二具分身「承身」，主兩儀並專修鑄身。初期陪封寒切磋的是本尊，不能提前換成承身。具體分工見[三身日常](../../../04_修行與特殊事物/雷道/太玄宗三身日常.md)。
