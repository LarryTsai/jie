# 太玄宗：主峰與七座傳承峰

狀態：作者確認新版採用問劍、鎮岳、觀心、九霄、藏玄、碧梧、赤霞七峰，另有主峰，共八峰。依作者「可以沿用的就沿用」指示承接既有傳承；各峰具體境界與新事件另定。

## 宗門所在

太玄宗位於下界東溟，不屬東溟三大宗派。各島太玄閣是其分部；劫、封寒出自不同太玄閣，在宗門選拔時相識。舊稿上界道天界、下界殘脈與孤身持令叩山的背景不沿用。

## 入宗與擇師

各太玄閣有基本推薦名額，再依弟子規模增加，具體數字未定。入宗選拔不設統一年齡上限，依修行年資綜合考察根基、悟性、實戰與進步幅度，不單以境界排高下。 閣生入閣前多已測過「三看」（根骨、神識、悟性）；三看只是起點，入宗選拔照舊看根基、悟性、實戰與進步幅度（D080，作者定（2026-10-02））。

通過者先接受共同基礎教習、接觸各峰，之後由師生雙向選擇。沒有統一拜師期限；完成共同基礎後，準備好的人先擇師，尚在探索者繼續修行。這取代舊稿「先歸峰，再接觸公開教習」的順序。

拜師後仍可自由參加其他脈公開教習。各峰真傳須由傳授者認可，不因旁聽就能取得，也不因選修而強制改換師承。

**弟子兩軌（D073）**：身分軌與職事軌分開，互不綁定。身分軌依師承：閣生（各島太玄閣）→ 入宗弟子（共同教習）→ 峰弟子（雙向擇師）→ 真傳（傳授者認可）。職事軌：任事弟子 → 執事 → 教習 → 長老、閣主、峰主。真傳不一定任事，執事不一定是真傳。宗內十人、入命藏是榮譽與資格，不是階級。**貢獻**宗內記帳，來自任事、交丹、修器、修脈，換爐位、份額、藏書、講席、丹藥，不能帶出宗門。階級名稱各宗自訂；太玄宗不設外門、內門（三大宗可用外門、內門）。

## 宗內生活與對外選拔

弟子可以修行、任事、遊歷，也能在公共丹房與器坊以工代修；太玄宗不只是參賽前的訓練場所。體修需要療傷與調整藥方，丹師需要合適爐具，禁修要把禁紋落在能承受的材料上，跨峰相識由這些實際需要發生。

百宗盟試每三年一次，每宗十名弟子，三大宗派也沒有額外名額。太玄宗需先選出十人；舊稿十二強、三支四人隊與固定新代席名單不沿用，宗內賽制待定。

## 傳承與舊稿邊界

沿用全宗共有的太玄命藏概念：它保存前人命痕、殘缺道圖與無法單靠文字記載的修行印記，與普通藏經閣不同。取得入藏資格不保證得到傳承。

**太玄命藏（D069 已定）**：入藏要宗內十人選拔（為百宗盟試選出的十人）的資格，由守藏人莫留審核。劫約十四歲入選，入藏後一路走到最深處，一張祖傳的**無星古圖**因他體內彼此打架的力量醒來，**太玄命圖在第 2 篇取得**（初開時星羅、兩儀雙星並懸，之後戰葬取震魂）。同屆其他九人各得劍痕、丹紋、星法。古圖是太玄宗祖師想把「人身」當「祖脈」來排的空圖，與宗門修補祖脈的技術同源；歷代弟子先選一條大道再修深，所以沒人修成。**古圖原件留在命藏**，陸沉帶走的是命圖在他身上長出來的那一份，宗門沒有失去傳承。命圖只排雷種，沒有外環、不排伴星（D072 撤四伴星編制）。舊稿七峰大比冠軍與既定事件結果不沿用。詳見[太玄命圖](../../../04_修行與特殊事物/太玄命圖.md)。

宗主與其他六位峰主姓名見[宗主與峰主提案](../../../03_人物設定/太玄宗/宗主與峰主提案.md)（宗主杭既白；現行提案，D060；問劍峰主裘斷為晏守拙師兄，作者定）。主峰正式名稱、宗門歷史、各人境界與入宗年齡仍未定。

太玄宗是玄殿在下界的直屬支脈；玄殿屬澄霄王庭，是太玄宗的上游。陸沉飛升後即以太玄宗弟子身分入玄殿（D060）。

## 家底（D073，2026-10-02 作者拍板）

依[修仙文明底層規格](../../../00_故事定位/修仙文明底層規格.md)第 16 節家底卡格式；完整提案版見[底層規格第一輪提案](../../../06_待定與決策紀錄/底層規格第一輪提案.md)第 12 件，以下為作者拍板項。

- **等級與規模**：**一流・小**，正式弟子五百以下（九界一流＝尊者至天神坐鎮、非一域之首）。
- **勘脈**（D079，作者定（2026-10-02））：修補祖脈屬勘脈六項中的「補」；山河級勘脈師全長亭天只有個位數，太玄閣有其一兩位，這是三大宗吞不下太玄的槓桿。
- **鎮宗之物**：命藏裡的**無星古圖原件**，一張空圖。宗門沒有能打的鎮宗兵器；家底在手藝：修補祖脈，與把互斥的東西排在一起（古圖、共同教習、跨峰旁聽同一種精神）。
- **上游**：太玄八峰在玄殿各有上游一系（洛生衣所屬「玄殿碧梧一系」即其一）。
- **太上**：留白。
- **護山大陣**：山門陣級，藏玄峰主持維護；承境留白。太玄閣地下古測脈陣為界陣級（見[陣法與禁制](../../../04_修行與特殊事物/陣法與禁制.md)）。
- 仍留白：主峰正式名稱、宗門歷史與創宗年代、宗主與各峰主境界、確切弟子數、太玄閣數量與分布、各峰根本功法名、秘術、本山靈脈、修補祖脈的收費、宗訓、洛生衣現任授業者（Q28）。
