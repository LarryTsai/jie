# 太玄宗：主峰與七座傳承峰

狀態：作者確認新版採用問劍、鎮岳、照神、九霄、藏玄、青梧、赤霞七峰，另有主峰，共八峰。依作者「可以沿用的就沿用」指示承接既有傳承；各峰具體境界與新事件另定。

## 宗門所在

太玄宗位於下界東溟，不屬東溟三大宗派。各島太玄閣是其分部；劫、封寒出自不同太玄閣，在宗門選拔時相識。舊稿上界道天界、下界殘脈與孤身持令叩山的背景不沿用。

峰名不等於能力清單。各脈弟子有自己的兵器與選擇，不能只按武器形狀分配師承；封寒可以從劍道起步，日後尋找自己的路，不因轉用鐧而抹去早年修行。

## 入宗與擇師

各太玄閣有基本推薦名額，再依弟子規模增加，具體數字未定。入宗選拔不設統一年齡上限，依修行年資綜合考察根基、悟性、實戰與進步幅度，不單以境界排高下。

通過者先接受共同基礎教習、接觸各峰，之後由師生雙向選擇。沒有統一拜師期限；完成共同基礎後，準備好的人先擇師，尚在探索者繼續修行。這取代舊稿「先歸峰，再接觸公開教習」的順序。

拜師後仍可自由參加其他脈公開教習。各峰真傳須由傳授者認可，不因旁聽就能取得，也不因選修而強制改換師承。

## 宗內生活與對外選拔

弟子可以修行、任事、遊歷，也能在公共丹房與器坊以工代修；太玄宗不只是參賽前的訓練場所。體修需要療傷與調整藥方，丹師需要合適爐具，禁修要把禁紋落在能承受的材料上，跨峰相識由這些實際需要發生。

百宗盟試每三年一次，每宗十名弟子，三大宗派也沒有額外名額。太玄宗需先選出十人；舊稿十二強、三支四人隊與固定新代席名單不沿用，宗內賽制待定。

## 傳承與舊稿邊界

沿用全宗共有的太玄命藏概念：它保存前人命痕、殘缺道圖與無法單靠文字記載的修行印記，與普通藏經閣不同。取得入藏資格不保證得到傳承。新版入藏規則、劫何時入藏及是否取得舊稿命圖，尚待發展，不沿用既定冠軍與事件結果。

主峰正式名稱、宗主與其他六位峰主姓名、宗門歷史、各人境界與入宗年齡仍未定。
