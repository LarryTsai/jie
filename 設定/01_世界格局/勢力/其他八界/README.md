# 其他八界

狀態：三十二天人物寫手提案（2026-09-30），未經作者確認。依作者指示補陸沉故土以外的八界。人物見[其他八界人物](../../../03_人物設定/其他八界/README.md)。

## 原則

- 每界不套六域九院，各有自己的分法與培養人才的方式（[劫故土六域與太玄宗](../../劫故土六域與太玄宗.md)「天域與其他八界」）。
- 每界有不依賴主角查案而存在的生活；古戰痕跡只是其中一條線。不是每界固定一件證物，也不按編號逐關探索（[九界與陸沉故土](../../九界與陸沉故土.md)「其他八界」）。
- 母稿第八節的三處景象分派如下（仍是試寫，可改）：**季節河道**→凌汛界，**長夜火樹**→昏曉界，**浮海群山**→懸岳界。
- 依 D059：上界的人進九界只能壓境或退境，不寫化身。各界界路上端的錨陣與壓境簿由對應王庭掌管，下端守界傳承持對印。
- 界名是九界本地人對自己世界的稱呼；天冊上的原名（方位、序數、二字天名，D046）本地人不知道，只在古碑殘字上見過。

## 規模

每一界約相當於原作下界諸域合計的量級：一界之內有數個到十餘個文明區，頂級勢力（天神坐鎮）三至六家，一流（尊者坐鎮）十至二十家，地方勢力數百。虛道全九界當代約十人：陸沉故土三人，懸岳界、霜明界各一人，其餘五界各零至一人（提案，見各界）。

## 與主線的對應

| 主線中段「回另一片九界」的支線 | 首選**望歸界**：異域後裔最多、越裳通譯館的舊譯例在此仍是活語言，可接上無極約一百歲「聖土的人主動找上門」；修為押在越裳王庭的錨陣。次選**霜明界**（凝影裡的古戰、泠光掌錨陣）、**凌汛界**（岑越本家的後果） |

### 照水山所在的界（三案，請作者選）

- **甲、陸沉故土**：溫棠遇害地已在陸沉那一界、後裔村落附近（D059）；九界之間沒有穩定通路（殘路只是候選），同界最省。裴照川也就在陸沉那一界成名，少年陸沉聽過「裴先生」。寫手傾向此案。
- **乙、蒹葭界**：水脈與測繪之學最合水澤之界；但溫棠須跨界到陸沉故土查後裔村落，得先定九界間殘路。
- **丙、望歸界**：後裔最多，溫棠查後裔自然；同樣須跨界。

## 待定

- 陸沉故土的界名、天冊序數與天名。
- 九界大比的舉辦地（不以共天定案）。
- 九界之間的殘缺通路是否存在、在哪幾界之間。
- 其他八界入口治理（Q03 殘項）：本檔只定各界上下端掌管者，壓境期限、錨陣容量依 D059 留白。
