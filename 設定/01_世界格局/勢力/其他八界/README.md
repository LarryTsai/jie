# 其他八界

狀態：D062 採為現行提案（可據以寫作，仍可再改）；原為三十二天人物寫手提案（2026-09-30）。依作者指示補陸沉故土以外的八界。人物見[其他八界人物](../../../03_人物設定/其他八界/README.md)。

## 原則

- 每界不套六域九院，各有自己的分法與培養人才的方式（[劫故土六域與太玄宗](../../劫故土六域與太玄宗.md)「天域與其他八界」）。
- 每界有不依賴主角查案而存在的生活；古戰痕跡只是其中一條線。不是每界固定一件證物，也不按編號逐關探索（[九界與陸沉故土](../../九界與陸沉故土.md)「其他八界」）。
- 母稿第八節的三處景象分派如下（作者照用，D062）：**季節河道**→凌汛界，**長夜火樹**→昏曉界，**浮海群山**→懸岳界。
- 依 D059：上界的人進九界只能壓境或退境，不寫化身。各界界路上端的錨陣與壓境簿由對應王庭掌管，錨印的對印留在上端錨陣；下端守界傳承持下端副印，解印須兩端合印（D065）。
- 界名是九界本地人對自己世界的稱呼；天冊上的原名（方位、序數、二字天名，D046）本地人不知道，只在古碑殘字上見過。

陸沉故土屬西方、西四之一（作者定）：長子遇害之處正是界路渡口（斷階俗稱「渡口」），界路多開在朝向聖土的西側。

### 陸沉故土的天冊原名（作者定：西之五・長亭天）

作者定（D062）：**西之五・長亭天**。本地不命名，只說「這一界」；下界無人知曉此名，只在斷階、古碑上見過殘字，陸沉到上無極才第一次得知。

以下三候選表保留作歷史；通津、來儀兩案未採用。依 D046 體例「方位＋序數＋二字天名」。不用《度人經》原天名，不用九界內部地名；序數避開本檔已用的西之一、西之六、西之八。

| 候選 | 含義 | 理由 |
|---|---|---|
| **西之二・通津天** | 津是渡口；「通津」即兩界往來的通衢渡口 | 最直接：斷階俗稱「渡口」，長子死於界路渡口；陸沉到上無極第一次讀到這個名字時，家鄉那段斷階的俗稱忽然有了來處。風險是太直白 |
| **西之四・來儀天** | 取「有客來儀」：遠客來而有禮之地 | 這一天是兩界使節、商旅與通婚者來往最多之處，烏蘅也從這裡來；名字記的是往來，不是戰爭，呼應終局「恢復的不是完整，而是往來」。含義稍隱，要一句旁白點破 |
| **西之五・長亭天**（作者定） | 長亭是送別之亭 | 長子在此作最後一別；陸家世代「等一個說要回來的人」；家鄉斷階重新成為渡口是全書最終畫面——送別之地將來也是迎接之地。情感最重，寫手傾向此案 |

## 規模

每一界約相當於原作下界諸域合計的量級：一界之內有數個到十餘個文明區，頂級勢力（天神坐鎮）三至六家，一流（尊者坐鎮）十至二十家，地方勢力數百。虛道全九界當代約十人：陸沉故土三人，懸岳界、霜明界各一人，其餘五界各零至一人（提案，見各界）。

### 照水山所在的界（作者定甲案）

照水山在**陸沉故土**。溫棠遇害地也在這一界、後裔村落附近（D059），不必另開九界之間的通路；裴照川在同一界成名，少年陸沉聽過「裴先生」。位置提案：中神州西部千溪原上游，與西極古路相接，見[劫故土六域頂級勢力](../劫故土六域頂級勢力.md)。原乙案（蒹葭界）、丙案（望歸界）撤回；蒹葭界、望歸界的水脈與後裔設定照舊，不再與照水山綁在一起。

## D066 主線路線總稿的落點

- **第 15 篇九界金丹（約 27–31 歲）**：八具雷身以太虛穿虛跑八家王庭，各自壓境入八界取材（斷脈之物離界失性，只能下界取，補丁 P4）。霜明那一味是封寒事先列給陸沉的「順路該看的地方」，雷身在冰層裡讀到長亭天，取得長子那一片的原件；望歸那一味由後裔代購，雷身沒見到塔姆林；凌汛（朔河）不給，守在下無極朔河津那具雷身沒有壓境、空手而回；其餘各界的取材與擔保依金丹專題。七枚錨印按期合印。代價是八道撕痕；同一拓印同旬見於八界，讀者以為「同一隻手」。
- **第 17 篇**：望歸界，見上表。
- **第 22 篇**：大敗前分出一具雷身壓境望歸，守住越裳譯例原件與後裔簿，按期合印，留在下無極等他。
- **第 23 篇（約 71–73 歲）**：陸沉道基碎裂，沿古界路路身外段落進**長鳴界**（路身外段只經西四界），在雷池當雜工、全篇不打架；申屠靜到長鳴收集衰退數據、招攬想「回天」的九弱。
- **第 28 篇**：寇平是九界新簿的第一位擔保人。

## 待定

- 九界大比的舉辦地（不以共天定案）。
- 九界之間的殘缺通路是否存在、在哪幾界之間。
- 其他八界入口治理（Q03 殘項）：本檔只定各界上下端掌管者；印期量級依 D065 為數月、長印最長約一年，錨陣容量數字仍留白。
