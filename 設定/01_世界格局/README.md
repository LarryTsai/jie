# 世界格局

來源：`歸檔/原始討論/` 中的《九界與上古戰爭》討論資料。以下區分已選方向與候選機制。

## 先看見兩界往來的生活

以下摘寫[故事母稿第一節](../../故事母稿.md)的試寫景象，未定為正式地理或風俗。

夜裡，孩子躺在渡口的棧橋上，從異域船帆映出的星光看另一片天空。岸邊攤販架高熱食鍋，等下船的人買飯；遠行修士帶回新劍，也帶回在另一界成家的孩子。孩子說兩地混雜的話，嫌父親故鄉的飯太硬。

這些人讓「互通」有了可以留戀的生活。戰爭一來，船停在哪邊，家人便可能被留在哪邊。世界的政治與空間關係，會落到他們能否回家、能否再見某個人的事情上。

依[敘事意圖](../00_故事定位/README.md)，本資料夾每一份世界設定都保留至少一個能被人親身經歷的地方或事件；以下總覽用來查核這些生活所處的世界。

## 世界總覽

| 層次 | 已知關係 | 尚缺的設計 |
|---|---|---|
| 仙界 | 有仙帝、仙庭及十八王庭；王庭分九強、九弱 | 制衡根基已定，具體機構與當代政治待補 |
| 九弱王庭 | 核心領地仍在仙界，各有一片外圍下沉成九界 | 同源而逐漸自主；各家具體關係待補 |
| 九界 | 源於受古戰影響的九片外圍；陸沉故土是其中之一 | 方位、環境、居民、交通與地方勢力 |
| 異域 | 古時與仙界互通，戰後難以跨越 | 內部政體、族群、生活與當代主張 |

九強不是全員同謀，九弱也不是一致受害、彼此無爭的整體。異域內部同樣可以有不同利益與立場。
