# 劫源（2026-11-28 開）

作者在對話中問：天地藏有很多空間，能不能有一個雷或劫的界，裡面都是極致之雷或劫，生靈極其強橫，呼吸都是雷。主編給三個放法，作者選「劫的源頭」。

依[競爭創作規約](../../設定/00_故事定位/02_工作規約/AI團隊競爭創作規約.md)開三寫手競稿＋獨立 Reviewer。

- [任務單](任務單.md)
- 寫手：[甲](甲.md)｜[乙](乙.md)｜[丙](丙.md)（第一輪互不讀）
- [獨立比較](比較.md)

為確保三版真正不同，主編只給每位寫手一個「源頭是哪一面」的起手傾向（甲：天邊上料正在落的地方；乙：沒活成的劫回去聚的地方；丙：自定，但不得與前兩者同面），其餘自由。

全部為候選，不升 Canon。
