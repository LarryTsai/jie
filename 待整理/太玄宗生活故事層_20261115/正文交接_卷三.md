## 一、卷三正文的語氣與句法

**句長與節奏**
- 短句為主，一句一個動作。常見三拍：「他看了一眼 X。又看 Y。」「一級。等。再一級。」數字、拍子、步數直接寫進句子（「數到十九」「第二十九天」）。
- 段落短，常一行一段。關鍵一句單獨成段（「雷是我的。」「他站著，沒倒。」）。
- 場景之間用 `---` 分隔，換場不寫過渡句；換視角也用 `---`（03-06 尾聲、04-03 開頭、04-04 收尾都是）。
- 章首一句就落時點與在場的人：「枷扣上的第十三天，顧小滿在料堆邊拋石子。」「第二天辰時，那只爐蓋擱在了何靜安的案上。」

**對白**
- 極短。陸沉多數只答一句，常是名詞或四五個字（「搬完了。」「打。」「路過。」）。不解釋自己。
- 一來一回對答常成三句組：「針是他插的。」「雷是你叫的。」不加說話人。
- 長輩、峰主說話平，一句定事，說完就走（岳沉淵、韓鐵衣、何靜安、夔聞同類）。
- 顧小滿說話快、喊、數數；滕北話多、有家底；生說話直、常反問、用簿子；蘭嫂嘴碎、手上有泥、唸靈田。

**慣用意象與身體刻度（Canon 已有，可用）**
- 本尊：骨上銀紋一節一節亮／暗；骨頭裡「磬」一聲；耳中血潮；左膝最弱；料石記號（一道橫、兩道橫、圈、圈底下一點）。
- 星羅：胸口底下的星羅轉一下、偏一下、縮成一點，他「按住」。掌心那道門開一條縫放雷絲；「閂門」。
- 叫雷：雷絲往天上走 → 雲從九霄那邊被扯過來攥成一團、壓到檐角 → 一道白的劈下 → 先進掌心 → 一線進爐 → 爐蓋「叮，叮叮，叮」。代價寫成肩頭／骨頭「脹」一夜，不寫掌心焦（04-01 口徑）。
- 雷冊：雷擊竹紙（灰白厚紙帶焦紋）、雷砂墨（暗紅透藍、磨時噝響）、焦竹筆，一筆落下紙面閃白沿焦紋跑到紙邊才滅。
- 生的纏布：三圈，打一個結（02-07 起的標記，04-04 陸沉認得）。
- 承力臺：紋一圈一圈亮、玉柱白光、第二圈「一點一點加」。
- 夜裡鎮岳是七峰裡唯一黑的那座。

**我刻意避開的寫法**
- 旁白總結、「後來他才知道」「X 天後」帶過；他想通了什麼的歸納句。
- 長輩沉默看人（「看著他，沒說好也沒說不好」被審查抓過）、想說又咽下。
- 陸沉內心長段權衡；最多兩三句具體的帳或畫面，然後一句話。
- 替雷、丹、法寶取新名；尺寸誇張（「雷粗得像一根梁」被刪）。
- 程序與帳目：價、手續、登簿只留一句（山門執事「事由。」「問丹。天黑前回。」）。

## 三、檢查清單（四次審查反覆抓到的）

交稿前逐條自查：

1. **前一章已說過的，不要重說。** 審查四章裡三章抓到：同一段台詞或資訊在前一章已當眾說過，本章又全文重唸（04-04 回報頁）；或寫成陸沉「今天才看見」而前一章他就在場。寫前把前一章正文最後三場再讀一遍。
2. **跟既有正文的次序、措辭逐字對。** 例：02-09 封寒約練撞 02-02「旬末黃昏」；03-06 寫「兩回你都說要去鎮岳」，卷二九霄坪那回其實只搖頭；04-04「雲還沒聚」與 04-03「雲壓到檐角才蹲下」次序反；04-04「禁入丹閣」與 05-04「禁的是爐不是門」衝突。引前文時去原檔查原句。
3. **「先問」只屬 05-04 柳青藤**明說一次（「真的，也要先問」）。之前任何人都不能把「先問」當規矩或台詞說出（04-04 何靜安原寫「誰要插針，先問爐主」被改）。
4. **口徑一詞之差**：冊規要分「九霄的雷全記」與「外頭的雷只記頭一道和走歪的」；雷冊冊面寫日子、地方、一行事由（照卷五〈冊上那一行〉清單格式「十二秋，主峰丹閣外爐，天雷一道，……」），不要寫「走歪」二字在冊面。
5. **代價與能力不要越級**：不寫掌心焦（04-01 之後叫雷代價是「脹」）；骨紋亮的範圍要有梯度（03-01 手臂 → 04-03 到肩頭 → 07-05 到脖子）；不要寫還沒有的身體反應（01-06 原寫「骨紋一路亮上來頂住失衡」是卷五才有的本事，被抓）；不要誇大雷的尺寸。
6. **刻度連續**：體能、步數、天數要和前後正文不倒退也不跳太快（02-09「數到十一」改「十九」才接上 03-04「一趟碼到底」）。開頭給天數錨點。
7. **主語清楚**：人多的段落，「他」要點名（02-09「崖頂只剩他一個」被改成「陸沉」）。
8. **旁人總結**：要給勝場一個落在人嘴裡的回聲時，只給半句具體的話（04-03「……九霄的針，拽不走他的雷。」），不要旁人講道理。
9. **標題人物要有自己的選擇與台詞**：04-04 原稿厲朔全章沒開口，被改成他自己告狀。配角的勝負要是他自己的（裴舟站出甘衡的影子、生一開始就在廊下）。
10. **長輩沉默看人**：「看著他，沒說好也沒說不好」「看了很久」這類，一章最多一次。
11. **沿用試寫要照實記**：方案甲／乙／補密的試寫句子若沿用，紀錄要寫「沿用試寫數句，已改寫入新前後文」並列出（04-03 被要求補記）。
12. **紀錄不替正文定沒寫的事**（02-09 紀錄寫「當夜兩具未合」被改為不定）。
13. **鄰章只改檔頭前章與段 README 狀態**；接縫表若列內文窄改才改，且先讀全文。版本行格式：「v1（2026-11-15，D193 新章）……；2026-11-15 依獨立審查修訂（……）」。
14. 篇幅以同段為準；字數用去空白後的正文字數比（Git Bash 的 `wc -m` 會算成位元組，別用）。
