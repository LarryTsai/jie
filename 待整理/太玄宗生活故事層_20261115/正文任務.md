## 寫

- 檔名、章號照正文段 README 預留的檔名；檔頭格式照同段既有章，版本行寫「v1（2026-11-15，D193 新章）」。
- 篇幅以同段各章為準，不要比鄰章長太多。
- 重要的事在場景裡發生：動作、身體、對白、刻度；不寫旁白總結、回顧、「X 天後」帶過；不寫想說又咽下、長輩沉默看人、探物插件。
- 修仙感：身體顯相、天地回應，只用 Canon 已有的異象；用丹、法器、靈氣這類詞，不用內力、輕功、傷藥、出診。
- 好看：缺什麼推出事，事留下尾巴，到手的本事馬上用；勝就寫勝；不寫成規格表，不寫細碎手續與帳目。
- 口徑：卷三一雷兩身（本尊在鎮岳、星羅身在主峰丹閣），三身白天不互感，合身才互通；D157 不新增陸沉敗場；不提前能力。
- 章綱裡寫給審查看的說明句，不要抄進正文。

## 鄰章

- 寫完後，更新後一章檔頭的「前章」連結（原指章綱「正文待寫」者改指本章正文），並更新正文段 README 本章狀態為已寫。
- 現行稿接縫表若列有本章帶來的鄰章內文窄改，照做：先 Read 全文，再 Edit 精準替換；版本行加「2026-11-15 依 D193 新章配合修正：<一句話>」。保留句一字不動。章綱與接縫表沒列的內文改動不要做，有需要寫進紀錄的「沒把握處」。

## 完成

- 自己重讀新章全文，再讀改過的鄰章前後文，確認接得上。
- 在本夾寫 `正文紀錄_卷三_<章號>.md`：字數、場景順序、刻度（天數／時辰／傷勢／物件）、鄰章改了哪幾句（原句→新句）、口徑自核、沒把握處。
- 回報：檔案路徑、字數、一句話說這章最好看的地方、沒把握處。

## 審查（每章）

每章寫完由未參與寫作的 Reviewer 審，寫 `審查_正文卷三_<章號>.md`：忠於章綱、與前後正文接縫、口徑、閱讀欲望（最好看一場、最易棄讀一段）、修仙感、有無旁白帶過；必修附行號。寫手依必修修訂後，該章才算定稿，才派下一章。
