## 寫

- 檔名照正文段 README 預留。檔頭格式照同段既有章，版本行寫「v1（<日期>，D212 新章）」。
- 篇幅以同段各章為準。
- 重要的事在場景裡發生；不寫旁白總結、回顧、「X 天後」帶過；不寫想說又咽下、長輩沉默看人、探物插件；不寫給讀者解釋口徑的否定說明句。
- 修仙感只用 Canon 已有異象；用丹、法器、靈氣詞，不用內力、輕功、傷藥。
- 口徑：卷六 14 初夏至頭場雪前；三身白天不互感，合歸才互通，合歸只往本尊疊（承身不記得本尊白天的事）；D157 不新增陸沉敗場；D159 主角群強度；不提前能力；「先問」不得出現；主峰不引天雷令已於大比開賽結束；各章叫雷與否照總綱時序表。
- 章綱裡寫給審查看的說明句，不要抄進正文。

## 鄰章

- 寫完後，更新後一章檔頭「前章」（原指章綱「正文待寫」者改指本章正文），並把正文段 README 本章狀態改為「已寫 v1；待獨立審查」。
- 章綱與 V 表列有本章帶來的鄰章內文窄改，照做（先 Read 全文再 Edit），版本行加「<日期> 依 D212 新章配合修正：<一句話>」。沒列的內文改動不要做，寫進紀錄的沒把握處。

## 完成

- 自己重讀新章全文與改過的鄰章前後文。
- 在本夾寫 `正文紀錄_卷六_<章號>.md`：字數、場景順序、刻度、鄰章改了哪幾句（原句→新句）、口徑自核、沿用試寫句、沒把握處。
- 回報：檔案路徑、字數、一句話說最好看的地方、沒把握處。
