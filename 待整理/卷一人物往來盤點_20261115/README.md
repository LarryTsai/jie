# 卷一人物往來盤點（2026-11-15）

狀態：討論區，候選，不改正式區與正文。

## 起因

作者貼來一份外部讀者對卷一〈浮石之下〉的正式評分：8.4 分。

- 《劫》較好：世界觀獨特性、主角成長細節、情緒鋪陳與回收。
- 早期《武煉巔峰》較好：角色日常互動、配角群熱鬧、閱讀輕鬆、讓人想追下去。
- 最需要改善的四點：
  1. 人物互動密度：要更多不以陸沉為中心的互動。
  2. 日常生活趣味：太玄閣生活有質感，還可以更有趣、更有變化。
  3. 劇情推進感：部分章節太依賴細節與象徵，需要更明確的事件推動。
  4. 角色個性差異：很多角色偏沉默、克制，說話方式接近。
- 核心判斷：不是缺人物，是人物之間的關係不夠；陸沉不在場時，其他人也要能讓故事好看。

### 卷二評語（同一讀者，作者 2026-11-15 續貼）

1. 前半段試煉稍密：承力、辨材、實戰、末試，再到各峰公開課，讀者有一段時間一直在考試模式。
2. 身體感受描寫重複：骨頭、銀紋、重量、氣血、脛骨的磬聲出現太頻繁，節奏變慢。
3. 配角關係：滕北、封寒與陸沉的互動已成立，鎮岳其他師兄師姐之間還缺獨立互動。
4. 費瑜的線還沒完全發揮：後續要看到他自己的選擇與發展。

### 卷三評語（同一讀者，作者 2026-11-15 續貼）

- 節奏：部分前段偏慢，尤其修煉與工作流程描寫。
- 描寫重複：骨紋、重量、脛骨、磬聲、等待等意象頻率偏高。
- 技術細節：丹陣、脈線、雷力運行有時要讀者花很多心力理解。
- 配角互動：已進步，師兄師姐彼此之間的獨立故事仍能再增加。
- 爽感：直接、俐落的戰鬥勝利偏少。
- 特別提醒：不要讓每一場衝突都變成陸沉理解某個道理的過程；有時就讓人物直接打、直接吵、直接做錯，甚至狼狽。

### 卷四評語（同一讀者，作者 2026-11-15 續貼）

1. 兩儀雷描寫偏密（吸、斥、倒轉、回捲、雷路、淡青、星羅），〈一個熔一個守〉連續多章講雷的運行；建議能力進化不要每次都用同樣密度的物理過程，有時讓結果、戰鬥、人物反應說明。
2. 人物網：希望看到封寒與顧小滿、洛生衣與秦照雪、滕北與他峰弟子各自的往來，饒沅回來時已有自己的成長。
3. 三身問題要保留：三身會互相干擾、做錯事、影響別人工作；不要太快協調完美，當長期成長線。

### 卷五評語（同一讀者，作者 2026-11-15 續貼）

1. 戰鬥文字密度偏高（六劍、兩條劍路、五行界、霧、雷絲、燈火）；偶爾讓戰鬥更直接，一拳打碎、一劍斬斷、一招反殺就夠。
2. 七峰人物關係仍多經陸沉串起；想看石魁與賀成、洛生衣與青璃、池杳與封寒等不需要陸沉的互動。
3. 「第八拍」不能變成所有問題的答案；未來要讓陸沉遇到完全不遵循這個節奏的敵人。

卷五盤點見 盤點_卷五。

### 卷六評語（同一讀者，作者 2026-11-15 續貼）

問題不是內容不夠，是閱讀方式挑讀者：
1. 前半段修煉機制密度高（碑林、石衣、兩儀、骨紋、借地、讓力）。
2. 高潮不是傳統爽點：承身找到路、生做出劍胚、封寒知道家人隱瞞的真相、陸沉從戰葬退出，都是成長，缺明確勝負、對手、結果。
3. 三身故事仍集中在陸沉；多是互相傳念、共享經歷，三個自己之間的衝突還沒展開。

### 卷七評語（同一讀者，作者 2026-11-15 續貼）

前七卷最好的一卷；問題是「建立得很好，但還沒充分使用」：
1. 新角色（卓三槳、冷照野、江先生）尚未形成長期關係（中）。先讓他們再出現，不急著加新角色。
2. 東溟勢力（長川、鳴石、滄氏、鎮溟、太玄在東溟的影響力）缺利益、恩怨、交易網（中）。
3. 行動後果要延續（中高）：赤霞爐工人受傷、九霄試場受損；生已表達界線，陸沉要真正面對。能改變，不代表有權改變。
4. 三身缺判斷上的衝突（中）：不只是三套能力，而是不同面向的選擇相撞。
總結：不要急著在卷八再開更大的世界，先讓卷七建立的人物和關係繼續發生作用。
