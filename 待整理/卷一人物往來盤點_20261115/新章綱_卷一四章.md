## 三、細綱

**時線｜年齡｜境界｜傷｜持物**：十歲早春，02-12 當夜熄燈前到隔天清早挑水（一夜一晨）｜十（除夕已滿）｜搬血前段，未淬體｜經脈受震在養，肋下悶｜丹方、木牌；厄在枕邊。

**因果入口**
- 02-11：「木片要開了洞天才理你。我血搬到後段了，還差一口。」
- 02-11、02-15：學徒舍的賭盤與搶缸，彭渚坐莊、說了算。
- 03-01 前：三宗為裂口份額上閣議事之前，千礁先派人上閣對脈簿（工作方案：每年春潮前一回；02-15「千礁每年來閣修脈的人」相容）。
- 02-01：這名弟子替錢潤在閣門口看苗子。

**場景順序**

1. **學徒舍，夜（接 02-12 章尾阿硯折圖）。**離門近的那個從外頭回來，說客房點了燈，是千礁的人，帶了兩箱脈簿，還帶了一本薄冊子。「來點人的。」屋裡躺下的又坐起來。窗邊那張鋪是空的；靠窗沒爭到的那個說：「客房的熱水，是他自己提去的。」幾個人笑。
   - 先來的學徒端著空盆回來，盆沿還冒熱氣。他不接那些笑，只說一句：「明早他要看挑水。」
   - 他走到阿硯鋪前：「你那一桶，明早給我挑。」阿硯掰指頭：「給你挑，我空手上去，簿上我那一行寫什麼？」「寫零。」阿硯想了一會兒，換了個條件：「那你告訴我，廊尾那道小門，夜裡閂不閂。」「閂。鑰匙在執事那。」「成交。」（阿硯記門的毛病換成一筆交易；04-13 廊尾小門由此先有一句來歷。）
   - 他再轉向陸沉：「你那半桶也給我。」陸沉：「不給。」「你那半桶上去，他看了只當閣裡沒人。」陸沉把他 02-11 的話還給他：「半桶也算一趟。」離門近的那個在被子裡笑出聲。先來的學徒沒再要，吹了燈。（陸沉的拒絕是他自己的小事：半桶歇幾回是他每天要讓它發生的事，不讓。）

2. **清早，水槽到石階。**天沒亮，執事陪著那名千礁弟子站在第三處平臺上，弟子手裡一本薄冊，封皮上壓著千礁的紋，在灰光裡淡淡亮著。先來的學徒扁擔兩桶，右手再提阿硯那一桶，從水槽起步。
   - **修仙感（他的身體）**：搬血後段的血一路搬到肩和手，頸側一條筋一鼓一鼓，吐出的氣在冷石階上是一道白；扁擔壓成一張弓，三只桶的水面只晃一圈就停；腳印踩在帶露的石級上，冒一點熱氣。第一處、第二處平臺都不停。阿硯空著手跟在旁邊，一邊走一邊數石級邊上有幾道門。陸沉提半桶在最後，照舊停（不報數）。

3. **第三處平臺。**先來的學徒把三只桶在弟子腳前擱下，一滴沒灑。他不等人問，蹲下，指節在下一級石階上敲了一下，篤，又挪一寸敲一下。「這一級底下空了半尺。去年秋雨沖的，再一場雨就塌。」
   - 弟子沒看那級石階，看冊子。「洞天開了沒有？」「快了。」
   - 弟子兩指搭上他的腕，停一口氣。先來的學徒手臂上那股往外搬的血像被人捏住，一下子停在肘彎，扁擔在他肩上輕輕嗡了一聲。弟子鬆手：「還差一口。」（02-11 他對陸沉說的原話，這回從別人嘴裡說出來。）
   - 弟子合上冊子：「明年再說。」走過他身邊時又加一句，口氣是說笑的：「指節倒是勤，比我們邱陣師還勤。」執事跟著笑了。
   - 執事要把場面撿回來，往下指：「那個是林閣老挑來的。」弟子往下看了一眼——第二處平臺上，一個孩子扶著山壁站著，腳邊半桶水——看完就轉回頭，沒問一個字：「簿子點完，我午前下山。」

4. **缸邊。**先來的學徒把三桶倒進缸，缸滿了。今天不是搶缸的日子，滿了也不少值一夜。學徒們圍在缸邊：
   - 離門近的：「兩年了還差一口，明年也是一口。」
   - 靠窗沒爭到的：「明年再說。窗邊那張先給我睡。」幾個人笑。
   - 阿硯沒笑，倒的是空桶（他那一桶被挑走了），開口說的是一件事：「第三級是空的。我前天踩過，有回聲。」離門近的：「你踩過有什麼用，人家又不點你。」
   - 先來的學徒對著缸沿上的宋知微：「把第三級也記上。」宋知微：「我沒踩過。」她合上簿子，自己走下去，到第三處平臺，往那一級踩了一腳——咚，悶的，底下真是空的。她回來寫：「千礁弟子到閣，看挑水，未點人。第三平臺下一級，空。宋知微踩。」
   - 先來的學徒：「記了有什麼用。」宋知微：「明年他再來，翻得到這一頁。」

5. **收尾。**執事在上頭喊：「千礁的簿箱在客房，點完了你挑下山。你腳力好。」先來的學徒應「挑」，扛起空扁擔往下走，到第三處平臺，從空的那一級上跨了過去，沒踩。陸沉這才提著半桶上到缸邊，缸是滿的，倒不進去。他站著，阿硯說：「倒屋脊上，壓火星。」他把半桶潑在石臺邊的瓦上，水在晨光裡冒一陣白氣。（章尾停在動作上，不寫陸沉想到什麼。）

**修仙感（只用 Canon 已有）**：搬血後段的身體顯相（頸側筋、白氣、扁擔嗡）；兩指探腕、血被捏停（修士隨手探脈，不新增法器名）；千礁冊子封紋自亮（同 03-02 石柱圓珠一類陣光）；伏雷坳火星飄上屋脊、缸水壓火（02-11 已立）；先來的學徒敲石聽空（02-15 已立，本章先見效、後被笑）。

**事件六要素**
- 起因：千礁春潮前上閣對脈簿，挖苗子的弟子順手替錢潤看閣裡能帶走的學徒；他要看挑水。

- 後果：學徒舍對他分出層次（有人嘲、有人要他的床、阿硯替他說一句事實）；他的指節成了千礁那邊的笑話。
- 延續：02-14（新號）經室他抱著千礁的脈簿經過、笑淬身訣慢；02-16（新號）夜裡後階獨自敲石「等籌碼」，有了被拒後那口氣；03-01 他自請送入嶺簿到千礁「北岸我熟」；03-02 錢潤把同一句嘲笑當讚美說回來，籌碼越過那名弟子落到他手裡；06-01 他替費瑜背箱子回島，是第二次挑別人的箱子。

**時線｜年齡｜境界｜傷｜持物**：十歲夏末，秋潮前十來天，一個不淬體的日子，午後至黃昏｜十｜搬血（手到腕就薄），淬體承、導｜無傷｜祖脈抄本、壓紙的舊石頁；厄在學徒舍。

**因果入口**
- 03-06 唐岫：「西段在閣後，比這裡深。這幾匣火只夠一段。要等秋潮，再燒一回。」
- 03-08 公告：秋潮進嶺取火，帶隊是簿房老人。
- 02-16 唐岫捎話「伏雷坳的劫痕不穩」。
- 03-11 魏四：「秋潮那天，船要空出來。」（閣已雇船）
- 03-01 唐岫「裂向朝山上那座閣」一路倒數。

**場景順序**

1. **簿房，午後。**陸沉在抄祖脈第九節開頭，石頁壓紙角。老人在對面案上校簿，嫌他第八節末頁有一筆抖：「提水提的？」「提水提的。」「那就晚上抄。」簿房的門朝前院開著。前院石桌邊，翁敬亭叫人去坳口請唐尋脈師。

2. **前院，請與拒。**唐岫上來，背上圖卷，手裡一塊濕布包著的東西，布邊在冒熱氣。
   - 翁敬亭先報數：「秋潮大退還有十一天。西段欠一回火。今年嶺上的霧比春天往下壓了一截，從閣頂看，已經壓到潮溝口。」再說事：「你跟著進嶺。酬加一倍。」
   - 唐岫：「不去。」她把濕布打開，擱在石桌上：一塊巴掌大的青石，從中裂開，裂縫裡一線暗紅，一明一滅，像坳裡的火線。「坳口第三塊。昨夜裂的。上旬一夜亮三回，這旬一夜九回。」
   - 翁敬亭伸掌覆在那塊石頭上。暗紅那一線在他掌下停了，石桌上的灰跟著一沉；他一抬手，紅線又亮起來，照舊一明一滅。（尊者壓得住一塊石頭，壓不住它從哪裡來——不解說，只寫手起手落。）
   - 翁敬亭：「秋潮那幾天，坳有閣老看。」唐岫：「閣老看得見火，看不見裂向。」翁敬亭：「西段釘不進去，你看清了裂向也是白看。」唐岫：「釘進去了，坳上來沒人報，你的釘打在閣後，閣一樣白守。取火是一件，看坳是一件。三宗雇我，是第二件。」翁敬亭：「酬加兩倍。」唐岫：「加十倍，我也只有一雙眼睛。」

3. **林伯潮插話。**林伯潮從廊下過來，走近石桌時，那塊石頭裡的紅線跳了一下，他腕骨底下也嗡了一聲，他把手攏進袖裡。
   - 林伯潮：「讓她看坳。春潮那幾天，坳是我看的。我只看得出它亮，看不出它往哪走。」（工作方案：春潮唐岫在嶺上時坳由林伯潮看，正文前文未寫，也無衝突。）
   - 翁敬亭轉向他，聲音不高：「閣裡的差，我派。」這句話陸沉第一次聽見翁敬亭當面對林伯潮說。
   - 林伯潮：「你派。派完了，我去坳口曬太陽。」（04-08「我在曬太陽」由此先有一回。）
   - 翁敬亭：「坳口你不准去。」林伯潮不爭，也不應，往石凳上一坐，看那塊石頭。

4. **老人插話（本章狼狽的一拍）。**翁敬亭回頭對唐岫，把底牌說出來：「隊裡是個腿僵的，帶三個孩子，霧比春天厚——」簿房裡老人擱筆，拖著那條腿走出門檻，兩個墨黑的拇指在衣襟上擦了擦。
   - 老人：「腿僵的這個，進過九回。」
   - 翁敬亭：「我不是說你不行。」
   - 老人：「你就是這麼說的。你頭一回進嶺，掉進潮溝，是這條腿蹚下去把你拎上來的。」（工作方案；若主編嫌翁敬亭前史太細，替代句見下。）井邊打水的兩個學徒噗地笑出來，又趕緊低頭搖轆轤。翁敬亭沒回嘴，耳根一下紅了。
   - 老人對唐岫：「你不來正好。嶺上兩個認路的，孩子聽誰的？」對翁敬亭：「船你雇好了，火我取。少一匣，你自己去。」
   - 替代句（若不用潮溝舊帳）：「你當閣主第一年，派我進嶺，回來嫌我取的火少。那年西段也沒裂。」

5. **定。**翁敬亭站了一口氣：「那就這樣。」對唐岫：「坳歸你。坳上有一點動靜，先報我。」唐岫包起那塊石頭：「報給付錢的。」她不往閣門走，往後山坳口那條路去。林伯潮在石凳上朝她背影說：「坳口夜裡冷，帶燈。」唐岫沒回頭，抬了抬手。
   - 翁敬亭往西牆那頭走了，一步落下，悶悶的，石板輕輕一震；隔一口氣，又一步（03-06、04-08 的節拍，本章先出現一次，不解說）。

6. **收尾，閣頂，黃昏。**陸沉晚上要抄書，傍晚先提水上閣頂。倒完水往山腳看：祠堂後頭，伏雷坳口的石脊上，一盞燈已經點起來了，燈旁坐著一個人。坳裡暗紅地亮了一下，燈沒晃。離秋潮還有十一天。（04-01 開頭同一個畫面，本章是第一夜。）

**事件六要素**
- 起因：秋潮將近，嶺霧下壓、西段欠火、坳口亮得勤；翁敬亭要再多一雙認路的眼睛。

5. **學徒舍，排人。**阿硯在門板上用炭寫：「舍門→側廊→貼左牆→拐角門不停→山門→第一個彎點人。」底下四格：第一批七、第二批十二、第三批十一、最後一批十一。
   - 扭了腳的那個看見自己在第一批：「我不跟燙手的一起走，丟人。」燙手背的：「燙手怎麼丟人？」「你們走得動，我也走得動。」阿硯不改。
   - 大個子看見自己在最後一批，又要爭：「最後走的不是值守嗎？」阿硯：「最後一批，你走前頭。門我開，路你帶。」大個子：「帶路算什麼？」「算帶路。」大個子哼一聲，沒再擠去前院看名單。
   - 抱包袱的兩個抱著鋪蓋卷站在最後一格前，阿硯：「包袱不能比門寬。」兩人各自把卷子壓了壓，沒拆。（04-13 第十一個就是被包袱角絆住。）
   - 睡對面的那個問：「你呢？你哪一批？」阿硯：「點完人，我就走。」

6. **收尾，閣頂，午前。**陸沉上閣頂添缸。一點火星從坳那頭飄上來，落進缸裡，嗤一聲冒白。他往下看：前院那張名單被風掀起一角；側廊口，阿硯一個人蹲在那口醃菜罈旁，拿炭條在牆上記了一筆。坳那頭沒有雷聲。（下一章開頭「第一聲雷是午後」。）

## 三、細綱

**時線｜年齡｜境界｜傷｜持物**：冬末，推薦試前六天入夜至前五天清早｜十一滿十二（正文不報）｜洞天、星羅一雷、雷絲｜無傷，耳裡費瑜那一下的嗡早散了｜厄在枕邊；推薦試用的嶺火匣各爐一只（閣裡發）。

**因果入口**
- 06-07：一個名額；規矩傳下；執事寫「費」；費瑜神識壓前院；阿硯飯桶邊「我不去」。
- 06-05：阿硯對閣主說了不上台；爹娘走了，他留閣看門。
- 06-04、06-07：牆角四截斷釘，學徒們都看得見。
- 06-07：阿硯告訴陸沉彭渚往執事袖裡塞了白玉片——**本章學徒群不知道這件事，也不提**（行賄由大人查處，孩子不揭穿）。

**場景順序**

1. **學徒舍，熄燈前，算帳。**不服的那個盤腿坐上阿硯的鋪沿，拿手指在鋪板上畫兩道：「我算過了。前二上台。你一個，閣頂那個一個，兩個都是我們閣的，費瑜連台都上不去。」
   - 排在後頭那個：「閣頂那個一個就夠了。」不服的：「一個？他輸了呢？兩個都是我們的，輸了也是我們的。」
   - 搬柴的：「四截斷釘是他借爐燒裂的。」不服的：「那是冬天。他天天來燒，總有一回不裂。」（06-09 費瑜的釘真的沒裂——他算對了這一筆。）

2. **湊東西。**幾個人往阿硯鋪上擱：
   - 掃地的：「下旬我替你值三夜。」
   - 搬柴的掏出一粒蠟丸，蠟封上壓著指印，一捏就聞得到裡頭的藥氣：「我娘託船捎的，叫我開洞天前吃。給你。」
   - 不服的把自己那份明天的練爐炭簽推過去。
   - 阿硯一向什麼都要討價（02-11 押夜值、新 02-13 拿一桶換一道門的消息），這回一樣一樣推回去。蠟丸塞回搬柴的手裡：「你娘叫你吃的。」再說一遍：「我不上。」

3. **說破。**
   - 不服的：「你怕。前天費瑜過井臺，你腿軟了。」阿硯：「軟了，沒跪。」不服的：「上台不是看你跪不跪，是打。」
   - 排在後頭那個轉向陸沉的鋪：「陸沉，你說句話。」陸沉：「他說了不上。」
   - 不服的：「你當然不勸。他不上，費瑜就是你一個人的。」陸沉：「是。我想打他。」屋裡一下子靜了，接著吵起來。不服的：「你打輸了呢？名額就是千礁的！」陸沉：「那你釘燒好一點，把他擠到第三。」不服的臉漲紅——他的釘是七個裡燒得最平常的，全舍都知道。
   - 阿硯坐直，當著全舍把話說完，說得很快，不講道理，只講事：「上台贏的那個，要去太玄宗。我上了台，不會故意輸。贏了我又不走，名額就空著，閣裡今年白辦。」
   - 不服的：「你贏得了陸沉？」阿硯：「爐前我贏他。」有人笑出聲。不服的沒笑：「那你就是怕走。」阿硯：「對。我不走。」

4. **動手（本章狼狽的一拍）。**不服的那個揪住阿硯的衣領往後一推，阿硯後背撞上鋪柱，鋪底那雙新布鞋被踢出來，不服的下鋪時一腳踩在左邊那隻鞋面上，黑面上一個灰白的大腳印。阿硯沒還手，彎腰把鞋撿起來，拿袖子擦，擦掉一半，針腳縫裡的灰擦不掉。
   - 不服的站在燈下：「費瑜拿了名額，是你送的。」
   - 排在後頭那個：「夠了。」
   - 靠窗那張鋪上，睡上了先來的學徒那張床的那個人，伸手吹了窗邊那盞燈：「睡。明天還要燒。」（02-15「吹了窗邊那盞燈」的人換了。）
   - 黑裡沒人再說話。陸沉聽見阿硯把鞋放回鋪底，放了兩回才放正。（只寫聲音，不寫陸沉的心念。）

5. **清早，爐排前。**執事抱著炭簍按人頭發練爐靈炭，一人一筐，黑裡透藍。七個閣裡的學徒輪著試燒，牆上名單那個「費」字已經乾了。
   - 不服的那個領了筐，沒往自己爐前走，走到阿硯爐前，倒了半筐進去：「給你的爐，不是給你上台的。燒好一點，把他壓下去。」阿硯：「壓得下去。」
   - 搬柴的跟著倒了半筐，排在後頭那個也倒。掃地的不試，沒有炭，把自己的火鉗擱到阿硯的工具架上——那把鉗口磨得最齊。
   - 執事：「練爐炭按人頭撥，不許轉。」不服的：「我燒半筐，燒出來也是那個樣子。」執事看了一眼靠窗那座爐，沒再說：「燒壞了別找我。」
   - 阿硯轉頭問陸沉：「你那筐也分我一點？」陸沉：「不分。」阿硯笑了一聲，蹲下去添炭，一次一小把。
   - **收尾**：阿硯的練釘燒到通紅，從頭到尾一個顏色，夾出來打進練石的裂口，不服的那個在旁邊數錘：「七。」釘子落到底，石頭裡嗡了一聲，沒動。不服的轉身回自己爐前，筐裡剩一半的炭。阿硯腳上穿的是舊鞋。

**修仙感**：練爐靈炭黑裡透藍、嶺火白火貼著匣底翻（06-09 已立）；釘打進裂口石頭嗡一聲（06-09 已立）；蠟丸丹的藥氣（家裡託船捎來，為開洞天前備）；費瑜那一下的威壓只在台詞裡回指；陸沉本章不放神識、不動雷絲，只在說「我想打他」時，胸口底下星羅轉了一下（Canon 已有身體顯相，一句，不解說）。

**事件六要素**
- 起因：06-07 規矩傳下、靠窗爐寫「費」、費瑜壓過前院；學徒群算出阿硯不上台等於替費瑜空出位置。

- 結果：阿硯照舊燒釘不上台；被罵「怕」「是你送的」，新鞋上一個腳印；練爐炭五個人各分半筐給他，要他的釘壓過費瑜。
- 後果：太玄閣學徒群第一次有共同的敵人和分歧；不服的那個與阿硯之間一筆帳（罵過、推過、踩過鞋，也分過炭）；陸沉想打費瑜，全舍都聽見了。
- 延續：06-09 阿硯的火最穩、錘了七錘、翁敬亭摸他那枚停得最久；「阿硯不上。前院」；費瑜第一段沒裂（不服的那個算對）；對試陸沉勝；掃地的拍那一下手。06-12 推薦定下以後，不服的那筆帳怎麼收不預定（可在 06-12 加一句，見窄改）。

# 六、與《武煉巔峰》的讀感對照（簡）

1. **值得學的效果**：凌霄閣早期，主角不在場的那些人也各有算盤、各自吃虧、各自記帳；日子靠一件件小事彼此推動。
2. **本批做到的**：先來的學徒被拒、被派去挑人家的箱子（推到 03-01 自請送簿、03-02 籌碼）；唐岫拒絕、林伯潮被「我派」頂回、閣主被老人拎舊帳（推到 04-08、06-10）；阿硯爭到撤人權並背上「少一個算你的」（推到 04-09–16、06-12）；阿硯被罵、鞋被踩、炭被分（推到 06-09）。每章都有人狼狽、有人記帳。
3. **還像清單的地方**：〈值守名單〉量息、過門那一段偏操作。寫正文時只寫兩個數（四十、六十三）和陸沉卡門框那一下，其餘交給阿硯掰不過來的指頭。
4. **不照搬**：沒有挑釁打臉、沒有主角出頭；四章的主角都是配角，陸沉只說幾句自己的話。

## 回報要點

- 〈千礁來點人〉：千礁挖苗子的弟子清早看挑水，先來的學徒三桶一口氣上第三平臺、當眾敲出空階，被兩指探腕說「還差一口」「明年再說」，再被派去挑人家的簿箱下山。
- 〈走不開〉：翁敬亭加酬請唐岫秋潮隨隊，唐岫拿坳口裂石拒絕，林伯潮站她、被一句「閣裡的差，我派」頂回，簿房老人當眾翻閣主舊帳自扛帶隊；定「坳歸唐岫，先報我」，當晚坳口點燈。
- 〈值守名單〉：雷季名單只寫「自行下山」，大個子爭值守被刷，阿硯量息算門、從執事手裡爭到「暫准」的撤人權，背上「少一個，算你的」。
- 〈誰上台〉：學徒群湊東西要阿硯上台擠掉費瑜，阿硯不收、說贏了也不走，陸沉說「我想打他」，阿硯被罵怕、新鞋被踩；隔天五人各分半筐練爐炭給他。
