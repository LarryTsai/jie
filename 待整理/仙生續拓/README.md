## 首輪取捨與接續

未參與構思的`xiansheng_review`已實讀三稿：[獨立比較](比較.md)判共同核心同構，不能直接融合。暫保[甲](甲.md)作比較基準，原[乙](乙.md)、[丙](丙.md)撤出本輪選稿範圍，仍留歷史素材，不當第二套現行故事。乙丙各自重開不同欲望與對抗，沒有共用完整劇情。

甲的D144效力誤標與鳴骨持物問題已由主編實際修入甲：羅的第一舟頭骨隨舟保有，歸山僅兩塊未煉索座骨，原缺口永久留下。首輪修後尚待Reviewer第二輪實讀，暫保甲不是工作選定。
## 第二輪、首弧實修與覆核（2026-10-16）

第二輪[獨立比較](第二輪比較.md)確認甲、乙、丙已成真正不同方向，推薦乙再構的逆雷海同行故事作第一長弧基準；[融合架構](融合架構.md)未拼入甲、丙的故事引擎。寫手完成[首弧實修](實修大綱.md)後，Reviewer先提出兩項有界修正及兩項次要修正（[初次覆核](實修覆核.md)）；寫手已將40個月候選行程、M12–M13雷身合身、海腹一季與M28會合／M40返家一致化，補完終賽三雷逐拍帳，並回收澄背鰭傷與七步地形。獨立[修正覆核](修正覆核.md)已確認上述項目通過，沒有在指定範圍發現新硬衝突。

主編據此將[海往天上走](../../大綱/06_仙途/01_海往天上走/大綱.md)整理為長亭後第一篇「工作選定」唯一大綱，並於[全書故事順序總覽](../../大綱/全書故事順序總覽.md)新增第83列。新地理、鯨族、競渡與逆息均未升格Canon；四條遠期弧仍只有候選骨架，尚未完成逐篇大綱。局部首弧通過不代表仙生全綱完成、全書級審查通過或正文解凍。
