## 主編取捨

同意 Reviewer：**以丙為主，定四條**。

| # | 名 | 人物口中 | 作者層一句 |
|---|---|---|---|
| 一 | 帶不走 | 「身上的帶得走，腳下的帶不走。」 | 境界長在人身上，跟人走；補給與主場留在原處；界壁、界潮只秤此刻放得出的力；只有帝帶得走天，聖土一次只容一片帝天 |
| 二 | 劫跟人 | 「劫跟人，不跟地。」 | 人拆了今日的自己就開縫，天地在縫上擋，相磨即劫；沒有意志，跟著拆自己的人走；不拆自己的沒有劫 |
| 三 | 門與牆 | 「隔門莫打，隔牆莫望。」 | 跨質變點正面不可勝；門拆得掉，只有少數人在自己的道上拆得開；牆拆不掉 |
| 四 | 扛天折壽 | 「扛天折壽。」 | 撼動、撐起、封住天地的出手都拿壽與本源付，仙帝亦然 |

取丙為框架的理由：天律是人口裡的老話，可以只對一半。這是唯一經得起第六弧的框架。第六弧那一夜，九界那一份劫「換到別處渡，九界照樣被頂著」，劫是跟著地走的。
- 甲把天律寫成價目表，乙把天律寫成宇宙真相，兩者都不能錯，遇到這一夜就會自相矛盾。
- 乙還提前說出大謎謎底（「天往外長」），違反 D108「天地要神秘」。

要修的四處：
- 刪甲「一天一肩」。它和帝重的多人同承、第六弧祁鈞「由我來扛」相衝，寫成天律等於天地站在祁鈞那邊。
- 劫律刪「不能代挨」。眭無恙的斷劫陣、綦毋煙的陣心都能切走別人的劫。
- 「看到第 N 道門一律退回」寫進寫作規則，門牆只當比喻、不計數。
- D157 越牆三次的配給留在後台，不進天律本文。

## 待作者裁定（一題一題問）

1. 框架：天律是人口裡可以只對一半的老話（丙），還是天地收的價、不能錯（甲）？**作者裁定（2026-11-28）：用老話框架。**
2. 「扛天折壽」單獨成第四律，還是併回門與牆成三條？**作者裁定（2026-11-28）：單獨成律，四條。**
3. D213 那四條改稱作者層「天理」（只改命名，內容不動）。**作者裁定（2026-11-28）：改稱天理。**已改 D213 效力段、丙_整合、天自己的劫（第 5、18 行）。
4. 「順則生人，逆則成仙」留候選，不入天律、不入正文（C28）。**作者裁定（2026-11-28）：留候選，不入正文。**
5. 主諺用 D065 原句「境界帶得走，天地帶不走」，還是丙的口語版？Reviewer 建議兩句都留：師門說原句，舟師說口語版。**作者裁定（2026-11-28）：兩句都留。**
