   - 檔頭狀態補一行：「2026-11-14 D186 作者釘板增章」。
2. **卷總綱 `大綱.md`**

3. **卷導覽 `README.md`**：章號對照、段範圍、總章數、流水號。
4. **正文檔改號**
   - 受影響的正文檔用 `git mv` 改檔名，例如 `017_xxx.md` 改成 `018_xxx.md`。
   - 檔內只改以下幾處：
     - 標題行「第 xx-xx 章」

5. **正文段 README**：如果有段 README，同步章列表。
6. **檢查回指**：用 grep 找本卷內其他大綱、章綱、正文檔頭用章號回指受影響章的地方，照改。
