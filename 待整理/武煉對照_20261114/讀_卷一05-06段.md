# 讀稿：卷一〈浮石之下〉第 05、06 段（05-01–06-16，35 章）

狀態：讀者紀錄（2026-11-14），討論區，非 Canon。只讀不改。對照基準：[武煉巔峰凌霄閣段寫法研讀](../卷一長篇化_20261030/武煉巔峰凌霄閣段寫法研讀.md)、[參照_成長寫法](../成長連續性_20261109/參照_成長寫法.md)。接上文讀了 04-17〈樑上〉。

## 一、總評

這兩段是卷一最接近武煉的一段：缺很具體（四縷火、差三十四枚、差五枚、盛不住），本事到手就用（雷絲當天探厄、第七天看落石、秋天收錢、洞天隔一章擋費瑜），刻度連成一條線（雷絲一根→兩根→三根→收得回；凝影一息→兩息→一臂→雷身），大翻身有兩次而且大一號（三隻鳶、對試）。放在武煉旁邊，最大的三個差距：

1. **06-01 到 06-05 陸沉沒有自己的「要」。** 推薦和殘雷兩件想要，都沒在這五章推著他走。他接費瑜的招，也看阿硯的家事，推薦卻是林伯潮替他寫好的；直到 06-08，他對推薦也只有一句被動的「要是定了，他就得坐船出島」。
2. **幾條尾巴在幕後收掉，或沒人撿。** 布包裡的錢存了兩輪沒花出去；東角碎石掉落那一刻沒寫，06-16 讀者要自己補；共天牌沒交代去向；禁這門本事兩年只出現一拍（05-09 布角）。
3. **刻度都在，「上一次輸在哪」偶爾沒接上。** 05-14 重犯 05-04 的「兩頭堵死」，卻沒想起坳口那回。另外，06-13 到 06-15 連著三章都是送別的靜場，06-12 以後沒有新的缺口往前拉。

寫得最好的是 05-02、05-04、05-06、05-08、05-11、05-15、06-06、06-09、06-11：每章都有一個非做不可的動作，刻度寫在身上，結尾交給下一件事。

## 三、修改清單

### A 必改（3 條）

**A1　06-01、06-07、06-08：陸沉對推薦沒有一句自己的「要」**

- 原句定位：
  - 06-01「閣裡的爐可以借，閣裡的名額不借。」
  - 06-07「阿硯端著碗走到陸沉旁邊坐下，沒提名額」
  - 06-08「推薦要是定了，他就得坐船出島。」
- 問題：研讀第四節給十二歲定的「非要不可」是推薦。正文裡推薦卻一路由別人推動：翁敬亭說名額、林伯潮先寫好推薦人、阿硯問「你也要走了」、汪七寫名字。06-01 到 06-05 五章，陸沉沒有一個推著自己走的想要，讀者會覺得他在等事情落到頭上。05-11 已經埋了「宗的山門，他連見都沒見過」，06 段卻沒接上。
- 修法（三處小動作，不加內心長段）：
  1. 06-01 前廳那段，翁敬亭說到「名額不借」時，讓陸沉在廊下的腳步停一下。示範：「名額。他提著空桶，在廊下站住了。閣上頭那座宗，山門他連見都沒見過。」然後照原文「陸沉從廊下走過去了」。
  2. 06-07 飯桶邊，婦人說「一個」之後，讓陸沉自己開口問。示範：「怎麼定？」婦人說：「閣主定。去年一個都沒有。」阿硯讓菜的那一拍照留，放在他問完之後。
  3. 06-08 船位表那句改主動。示範：「推薦還沒定，他先找魏四那條船在第幾行。」後面「紙上沒有他的名字」照留。
- 碰觸：無保留句、無硬口徑。06-05 阿硯「你也要走了」這句不動，有了上面的鋪墊，這句才接得上。不得寫成「想說又咽下」。

**A2　05-17 → 06-16：東角碎石掉落的那一刻全卷沒寫**

- 原句定位：
  - 05-17「坡尾東角那塊，沒人上繩的碎石，會先掉。」
  - 06-03「送簿的差事照舊每旬一回。這一旬是千礁。」
- 問題：陸沉說過的話要回來。現在的回應只剩 06-16 一個淺坑和那孩子丟來一塊石頭，中間隔了十七章。石頭有沒有照他說的在第三批掉、那孩子有沒有撿到過冬的貨，讀者都要自己補。06-16 拋回去那一下的分量，正是靠這個中段撐的。
- 修法：在 06-03 開頭「這一旬是千礁」之後補兩三句。他下山送簿，照 06-16 的路線沿坡走到坡尾，正碰上第三批：東角那塊已經不在原處，低崖下的礁石上散著一片新茬，那個水性好的孩子在水裡，一塊一塊往袋裡撿，沒抬頭。陸沉沒停。示範：「第三批的浮石剛離地。坡尾東角空了一塊，低崖底下的礁上白白一片新茬，那個水性好的孩子泡在水裡，一塊一塊往麻袋裡撿，沒抬頭。陸沉沒停，往北岸去了。」
- 碰觸：06-01「他今年沒下去看」是指不看浮石季，這裡是送簿順路，不衝突。06-16 的「淺坑」「拳頭大、新茬」照留。不寫成「暗處看人」：他是路過看見，孩子也沒看他。

**A3　05-14：重犯 05-04 的「堵死」，卻沒想起坳口那回**

- 原句定位：05-14「這一回他咬著牙，先把肩下、腰、腿和腳底全堵死，才伸手。」
- 問題：05-04 第三縷他已經「兩頭一起關」，結果被火從指縫頂出去，還領悟到「盛不住」。05-14 再堵一次，正文沒有一個字承認，讀者會以為他沒記性。05-15「送，送走了；堵，炸了」是兩次失敗加起來才得出的結論，前提要先寫清楚。
- 修法：把這一句改成承接 05-04 再加碼的動作。示範：「坳口那回他只關了兩頭，火從指縫裡頂了出去。這一回他咬著牙，把肩下、腰、腿、腳底四處全堵死，才伸手。」後面炸開、透明照留。
- 碰觸：05-15 保留句「火他等得住……雷不一樣。從十歲到現在」不動。

### B 建議

**B1　05-03 → 05-17 → 06-12：布包的錢沒花出去**

- 原句定位：
  - 05-03「你存錢做什麼？」「還不知道。」
  - 05-17「布包開春排隊時少了八枚，這回又鼓了回來。」
- 問題：存了兩輪的錢，最後沒有用處。研讀第二節說，說過的事一定回來；「還不知道」這句正好留了一個空，等著兌現。
- 修法（擇一）：
  1. 06-12 汪七寫名字時，報出船資，陸沉解開布包付。示範：「船錢兩塊。」他把布包解開，數出兩塊整的，看石頭掙的。
  2. 若船資由閣或太玄宗出，改在 06-15 把布包留給母親，說一句「看石頭掙的」，母親收下，不多說。
- 碰觸：船資歸誰出，**需主編核 Canon**（卷二入宗靈舟由誰付）。

**B2　禁兩年只出現一拍（05-09 布角）（需主編裁定）**

- 原句定位：06-09「邊上的紋一碰到外頭的風，亮了一下，又暗了。」
- 問題：04-04 得來的本事，05、06 兩段只出現一次「布」，「讀禁」「拆禁」都沒出現。武煉的做法是本事到手就用，用出新麻煩。
- 修法：06-09 夾碎陣石時，第一片一碰風就亮，他認得那是「不准」一類的紋，就用指尖在石片上壓一道「一橫，一折，收住」，石片不亮了，才夾出來；其餘照原文用火鉗。全程不叫出名字。
- 碰觸：硬口徑「叫不出禁的名字」「停」的筆形照守。總綱定案 14 寫明「禁不進星羅、不進下次先問」，06-09 兩者都不是，但這段先前被列為「碎陣石段未動」，所以標**需主編裁定**。

**B3　06-04：替 06-06 洞天種一個「火有地方待」**

- 原句定位：06-04「釘子要帶著火打進裂口，不能涼。」
- 問題：06-06「他要的不是更長的線，是線能落腳的地方」來得有點突然。06-04 現成有嶺火匣、爐膛，可以先讓他看見「留得住」的樣子。
- 修法：在這句之後補一句。示範：「匣蓋合上，白火在裡頭待著，不散。陸沉看了那只匣子一眼。」不加推論。
- 碰觸：無。

**B4　05-09：共天牌的去向沒交代（需主編核）**

- 原句定位：05-09「閣裡就三塊。」「今年這塊，你拿著。」
- 問題：閣裡只有三塊、補過七回的信物，用完就從故事裡消失了。
- 修法：06-10 西牆根下，或 06-15 下山經過西牆根時，加一拍歸還，例如把牌擱在林伯潮膝上的毯子上。若後卷要讓他帶走，就改成林伯潮擺手不收。
- 碰觸：共天後卷是否回指這塊牌，**需主編核**。

**B5　05-02 或 05-18：「想說又咽下」本段偏多，可刪一處**

- 原句定位：
  - 05-02「陸沉不知道該說什麼。他想說底下的火走錯了路」
  - 05-18「他想說點什麼，想不出來說什麼。」
- 問題：05 段已經有 05-01 的「嚥了回去」（洄辛，必要），06 段有 06-01 的「想問……他沒開口」。05-02、05-18 再各一處，會超過配額。
- 修法：05-02 這段刪到只剩「他就站著。」直接接「父親開口了」。05-18 改成「他站了一會兒，轉身出去了。」
- 碰觸：無。

**B6　06-13 到 06-15：三章送別各自已有細節，不建議加事件**

- 只提醒修訂寫手：不要再往這三章補回想或總結。若嫌靜，06-13 可把「先找門，再找第二道」提前到章中，讓章尾停在缸裡的水聲。

### C 結構建議（只列出，交作者決定）

- **C1 十一歲的夏天只有三行（05-17 開頭）。** 雷絲雙抽、二引殘雷、凝影兩息，用的是節點寫法，合參照第 10 條；但研讀要求「每一年都有它自己的事」，這個夏天沒有一件推著他的事。可考慮把「伏天再引林伯潮殘雷、自己送地」寫成一個獨立短場，或併進 05-16 之後。是否增章，由作者定。
