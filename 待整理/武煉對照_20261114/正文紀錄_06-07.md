7. 第二十天，承身傍晚從坪上下來，腳步實、磚縫灰跳、腳踝骨紋未退；「兩隻手一前一後……撲在空處」「滿盞的茶，茶面不動」（原句）；押格稀了、木牌（原句）。

## 刻度

- 三具的距離：星羅身一寸（定得太準，落在袖子剛才的位置）→ 本尊半寸 → 第十四天兩具同時，手腕互撞 → 承身兩手撲空 → 第二十七天不伸手，袖角擦指尖。
- 生的動作：肩一偏 → 右肩一沉、手連袖轉開 → 上身後讓一寸 → 腰一擰 → 第二十七天一動不動（茶面無漣漪）。
- 茶：第九天晃一圈 → 第十天起滿盞，此後各回「滿盞的茶，茶面不動」。
- 押格：衛琅一枚 → 第十天有人押十幾 → 二十以前全空、往後一格比一格稀 → 第二十七天那一格只有一枚。
- 陪練題：開場「送單子那個停在門口」→「誰也沒在門口停」。
- 爐：06-06 誤爐（手一頓）→ 第二十六天星羅身看銅匙一眼，「火候一息也沒差」。

## 沒把握處

1. **紙條一句**：派工寫「『不准吸』紙條要到下月初才出現，本章不寫它出現」。我讀作「不在第二十七、二十八天當場寫她壓紙條」，所以照正式章綱第 11 點保留原句「下個月初，石凳邊那塊石板上多了一張紙條……不准吸。」理由：正式章綱（D186 釘板）列為「搬，一字不動」，牽引欄也寫「下個月初石板上多了『不准吸』」；本夾 README 後卷回指把「生的石板上有『不准吸』紙條」列為卷四事實；卷五 01-02「那張左手寫的紙條還壓著」靠它有前文。若主編的意思是本章完全不提，刪這兩行即可，卷五 01-02 那句要改成首次出現的寫法。
2. **開場蘭嫂對白**：細綱只要「那天岳沉淵午後才上坪」半句，我用蘭嫂隔牆問、本尊在門口替承身答來交代，順帶讓「停在門口」那一個真的停在門口。嫌多可只留一句敘述。
3. **第十天押十幾**：小插一筆，讓「倒滿」被院子裡的人讀成「他近了」。不是章綱點，可刪。
4. **第二十六天「火候一息也沒差」**：回扣 06-06 誤爐，表示星羅身看了一眼也沒誤火；不寫傳念，避免先定卷五 01-02 的規矩。若嫌像在暗示規矩，可刪這一句。
5. **合歸「比頭一夜輕得多」**：06-05 第二夜「比昨夜快一點，還是疼」，到第二十六夜寫輕得多，合理但是新刻度。
6. **陪練題生的三個稱呼**「守火的。走樁的。扛石頭的。」：是新台詞，取三身當天各自的事；卷五未回指，可換。
7. 卷四正文 README、06 段 README 的狀態（06-07 待寫→已寫）未改，由主編同步。
