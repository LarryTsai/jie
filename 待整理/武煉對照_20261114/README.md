### 卷五

- **古脈：**01-04、03-02 重鑿前是半接亂拍，重鑿後「七短一長」。罰地裡有一細股斜斜往宗外去。
- **承身：**03-02 雷罰在兩條小臂留焦紋，04-02 退淨。05-05 散形，07-01 重凝「新，乾淨」。
- **淬骨池：**03-04 位置、樣貌照舊。灰線圈私鬥要入罰單。
- **04-01：**
  - 封寒冬至前化靈。
  - 老梧開春起，全峰輪班一天三回澆根液。
  - 胥匠開春把暗紅護腕（皮下嵌鐵）扣在本尊左腕。
- **04-04：**三身一劫化靈，劫紋在九霄試場方場正中。承身左臂骨裂。
- **04-05 九枚：**前六枚進青石坪，後三聲入骨（小腿骨、大腿骨、右肩胛）。05-05 石魁一拳把那三份翻出去。
- **鎮岳鐘聲：**
  - 05-01 賀成青石盾被劈開，台詞「那夜謝了。盾不讓。」
  - 鎮岳本屆五聲在 05-01、05-02、05-03、05-05、06-05。
- **05-03、05-04：**
  - 05-03 星羅雷網，雷絲銀白。
  - 05-04 青璃右手背淺裂，長界暫禁。封寒練劍簿寫「先探再折」。
- **封寒三敗：**05-04 負青璃，06-05 負星羅身，06-06 負冉晴川。
- **06-01～06-07：**
  - 生的三身傷錄壓在荊問（女）案上。
  - 06-05 星羅身左肩傷到骨，雷絲禁到大比第十六日末。本尊從 06-02 起肋痛。
  - 06-07 生把冉晴川的兩路拍成交叉，冉說「明年我試三路」。生得武冠，選天絲。
- **碧梧與丹閣：**
  - 02-02 第七口小爐帶回碧梧。
  - 伏雲參三株，一季一株。
  - 02-03 留樣盒有春夏秋三格。
  - 滕北任事在丹閣。
- **07-01～07-04：**
  - 07-01 暗場地縫。
  - 07-02 外行十席，江離第十一。石魁說「扛完了。」，甘衡粉板寫「鎮岳，五鐘。」
  - 07-03 主峰北側舊門、莫留，石令只寫「准入」，簿上九名，莫留看出「三個」。
  - 07-04 斜股往宗外東去。生不送十人入藏。鐘繩「響了五次，明年還得擦」。
