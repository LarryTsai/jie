- **高點**：入極的門前九界打雷，與長亭的降／不降。兩次都靠「這片天地本身」打出結果，不靠技術拆解，仙感和爽點同時到。
- **低點**：從入極結束到長亭五庭點兵之間，讀者要連續讀完 81、82、73 三大塊（印內約 58＋157＋359 日）。這段戲份最長，主角又最常被壓境、停戰、醫養、核印綁住，敘述也最常退回帳本和物證語氣。兩個 9 分級的高點被一條很長的谷隔開，這是本段最大的節奏問題。

## 4. 最該先改的三篇

### 一、第82列 九雷問祖與生獨立丹途（6.5 → 預估 8.5）

- **問題**：這是陸沉全書最大的一場私仇，十二山老祖也是他親手殺的真仙老怪，現在卻寫成四十條同等份量的事件條。讀者感覺不到決戰在逼近：交易、集結、論禁、居留核准、搬種、毒丹交錯推進，主戰被切成九條換端細目，勢頭散掉。四友各勝一局是對的方向，但每一局都是「先吃虧一次再翻盤」，四次同一個拍子。
- **怎麼改（故事上）**：壓成三幕。(1) 老祖先放行一批人，搶走道義上風，四友被說成搶祖產，這是敵人第一手漂亮的計。(2) 四友各打自己的一局，每局只留一個畫面（不動雲、兩塊板、照世照縫、毒丹），而且讓每一局的結果實際改變主戰條件。(3) 陸沉對老祖寫成一場有起伏的連續決戰：祖法第一擊震退數十丈 → 他棄熟路 → 「拆得開，拆了他們先死」 → 文奕念出解除條件 → 斷主環 → 三擊殺魂。文奕的居留文書、送信日數全部退回日帳。

### 二、第73列 第三份探查記（6.5 → 預估 8）

- **問題**：開頭四章是兩位本土火修自己的三場戰，這個用意很好（配角有自己的人生），但放在第三次聖土的最開頭，讀者要在主角缺席的情況下學一整套新火法，入戲門檻太高。中段的護柱與中閘本身好看，後段四章（林德物證、赫爾來信、魂晶）又回到辦案。陸沉全程壓列陣，除了第10章三息之外沒有一個讓人想轉述的主角時刻，中閘裡他的高光也是「拿開手」，屬於讓出來的高光。
- **怎麼改（故事上）**：以水門重逢和赤翎「今天下雨的人」開篇，薩爾雅與伊萊恩的三戰改成和主線交錯穿插，第三戰剛好落在護柱前夜。第22–25章四章壓成一場：薇恩在鐘腔前當眾讀出林德兩個動作（辨潮、不答），由她做選擇，不由附錄做。另外給陸沉一個壓境狀態下「以列陣打出真仙格局」的正面時刻，例如護柱外圍第一刻一人封住賈戈的撞柱線，讓「不解封」本身變成爽點，而不只是一條限制。

### 三、第71列 玄闕祖脈（7 → 預估 8.5）

- **問題**：商家兩兄弟爭祖脈是很好的欲望衝突，可是第11–18章用槽、起落、器骨、根頭推進，讀者分不清這一章誰得了什麼、誰失了什麼。祖潭最好看的畫面（九座山影浮入黑水，次日晨光先映在潭底）只出現一次，後面沒有再用來打架。星羅撤形重凝在情感上有意思，但被包在一段免責說明裡。
- **怎麼改（故事上）**：讓九座山影本身當戰場，每個有效起落都是一座山影在潭面崩、亮或被拉走，讓讀者看得見三刻是「三處同時斷」。孤石、槽形比對壓成管曜一個人的動作。最後陸沉在管曜手腕上「改一筆」、按在石沿說「長亭見」，這一拍已經很好，前面只需要多給管曜一次真的佔上風，讓這一拍成為翻盤，而不是收尾。

（第81列也只有 7 分，但篇幅短，兩場展開已經有了；只要把 B093、B096、B097 的分責語氣收進一場「當面念令」的戲就能到 8，所以排第四。）

## 5. 全段重複的套路與句型

1. **「敵計奏效一次，當場翻盤」**：玄闕、問祖、第三份、長亭各戰幾乎都是這個拍子（先吃一虧、改法、勝）。單場都合理，但連看六篇以後可以預測。建議入極那種「從頭碾到底、只停兩息半」的勝法在本段再多出現一兩次。
2. **否定句連打**：「不擒不殺」「不跪不降」「不替誰總結」「不承諾……也不……」「沒有說自己錯了，只是不再擋」。用來寫角色克制很好，可是密到每段都有，故事段讀起來像在免責。第73、82兩篇最嚴重，故事段裡還留著大量「不是……而是……」「不能……」的約束語氣。
3. **「他沒有替某人做某事」的母題**：不替她說、不替她選、不代好友批准、不替他答。這是人物尊重的好母題，但在第73篇幾乎每章都出現一次，主角因此常常只剩「讓開」這個動作。
4. **帳本句**：S／P／Q 日數、印期、合印、申核這類句子混在故事段裡（第81、82、73篇與第26篇末段）。讀者不需要知道第52日受理。
5. **一句收尾台詞的格式**：「X。」停一下。「Y。」（長亭見、我家的、第二是他、下次先拆、下次先問、這次不用再找我）。單看都好，但本段出現次數多，建議留給真正的截圖時刻。
6. **「回來了」**：在入極裡是刻意的重複，效果好；其他篇不要再借用。
