# 九分提升第二批｜融合紀錄：卷五〈七峰爭鳴〉

2026-10-23｜故事總架構師兼融合寫手｜依[比較審查](審查_比較_少年組.md) §5.1、§6 執行。成果：[大綱/01_少年/05_七峰爭鳴/大綱.md](../../../大綱/01_少年/05_七峰爭鳴/大綱.md)（工作選定，未逐章作者批准）；舊正式版保全於[舊正式_卷五七峰爭鳴](舊正式_卷五七峰爭鳴.md)。未經獨立覆核；融合者不兼覆核。

## 一、結構

44 章壓為 33 章，十段：停脈（1–4）、她的丹臺（5–6）、十與燈（7–8）、護腕與兩罰（9–12）、補齊與那場雨（13–17）、四輪鳴鐘（18–22）、師姐（23–25）、他的一場（26–27）、她的冠（28–29）、暗場與十人（30–33）。

## 二、採了什麼

**基底：丙**
- 半脈場規（七拍一沉、第八拍長沉、外放靈光暗一息）作全卷舞臺。
- 停脈「原來它一直在響」；青璃「雷雨季今年不會來了」→「那我帶一場去」→九霄試場三身一劫、一年第一場雨、方執摘冠、「……今年來了一場」。
- 四輪：一掌劈盾（賀成）、第八拍空衣落地（岐影）、池杳假第八拍與星羅雷網、石魁赤腳接拳回送「……鎮岳的。」
- 八強第八拍「你聽脈的拍子走。我聽你的。」＋「吸的那一下最盛，盛了就要回。我等的是你回。」
- 點戰移到八強次晨：「他昨天輸了。我今天點他，不是撿。」封寒最後一叩放在第八拍，陸沉不動。
- 評議只寫第十席與宗主一問；江離石階；碗；斜股兩次閃現。

**從甲借**
- 對手研究上一版：賀成研究「牽金鐵」、岐影研究「力大」、池杳研究「第八拍」、石魁研究「斥鐵」；寫進四輪與對手表。
- 七峰鐘預埋兩次（停脈夜七鐘嗡、雷罰第八拍鎮岳鐘極輕一聲），暗場「六。七。」「走。」七鐘同響、沈山河手裡的布。
- 九枚：開賽前夜承身掛九枚坪不裂，力停在骨頭裡；兌現卷首「明天起，掛九個」，並作為石魁一戰接拳回送的來源。另加「韓鐵衣補了一年的坪」一筆。
- 暗場真險：雷壓過線、試具砸落、方執喊停、二十多人擠北門；石魁隔著半個暗場跟著他的數放樑。
- 甘衡賭板只留首尾：丹臺「鄔九賠洛一」與石榜後「鎮岳，五鐘」不寫賠率。
- 「鐘樓老役：鎮岳的鐘繩積灰」與「讓那口鐘響」的欲望句。

**從乙借**
- 迴流無拍：暗場雷壓「一口氣不停」，全宗都知道的第八拍失效，有人數到八被雷掀回；陸沉聽的是底下仍在的長氣。我把它接上生的那一課：亂雷撞頂一次比一次高，「盛了就要回」，他等的是它回——輸掉的那一課在暗場兌現，不加「這才是真正的勝負」之類的句子。
- 讓三招三下都打實：掌風斷髮、白線外石柱裂；雷印撕開袖緣，她真退一步；地面裂向她，三指舊傷那手一麻。本尊上場、第一招最重一掌。
- 石魁一戰強度：回送一拳打出白線、撞斷赤霞看臺護欄。
- 顧小滿纏布「我自己收的。他今天收他的。」放第四輪當夜。
- 暗場「趴。」「起。」一拍。

**保留現行**
- 鎮鈴七枚全段與卷四翻盤；丹臺兩章；七盞燈；護腕、反弄、雷罰、收重、誰要你付；沈山河山崩由顧小滿講、鐘繩擦淨；封寒「先探再折」夜改與晏守拙；點戰三回合手感與「兩人差的是一路雷身」；生四強撥燈、決賽雙主路；天絲「我贏來的」；衛琅二比二、傷錄第一筆豎畫、甘衡辰時沒到；十人名單與江離第十一。
- 四十八場、前段順位表原樣搬入附錄；淘汰樹結果不動，只改日序。

## 三、刪了什麼、為什麼

| 刪 | 理由 |
|---|---|
| 乙的費瑜、儲迅、錢鶴年整條線（觀禮團、碎陣石、評議收帳） | 撞已融合的卷十三五域（生夾碎陣石、「有人姓千礁吧」、石頭放回杯旁）與卷二十三「費瑜五域那夜就怕了」；三卷同一招會成套路；也把卷主題擠到外宗 |
| 乙的鎮鈴移到大比前夜 | 改動 D157 卡二落點 |
| 雙人奪旗與「兩人失分」 | 新骨架無需團體失分；江離的拒絕移到撤離 |
| 丙的青璃四強「她也在數」、暗場「第八拍走」舊解 | 第八拍限四場；暗場改真險 |
| 甲的「你換過借的地方，沒換過先付的辦法」 | 新骨架前四場已非全靠借，台詞會指控讀者沒看到的習慣；改用丙的台詞 |
| 甲「你見過七鐘那天嗎」、岳沉淵抬頭 | 防七鐘被讀成第二場世界作證；只留沈山河的布（鐘繩線收尾） |
| 甲「十九年沒響」 | 年數無法核；改「積灰」 |
| 甲中段賠率變動 | 鐘、第八拍、賭板三裝置同跑太擠 |
| 現行護送青璃／穆苡／岐影一組、八強三場短場細寫、評議七峰主輪發、任事08／12 評議細節、醫席逐場驗傷、T 碼 | 讀者會跳；評議各峰所爭移附錄一段，八強三場壓成一句 |
| 現行「他再也沒跟她正式分過勝負」三處重複 | 只留第24章一次 |
| 現行鐵掌靴斥開一指的勝法 | 改正面接拳回送 |
| 現行化靈在鎮岳崖 | 移九霄試場（露法帳只綁「陸沉自己的劫邊」） |
