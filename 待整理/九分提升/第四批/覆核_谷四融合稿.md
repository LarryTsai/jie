## 1.【一般讀者】

### 1.1 還像戰報嗎？

大致不像了。舊稿三條師門長線有 18＋24＋12 件事，都是「各出三手、真勝、養五整日」的模板。新稿整段只有一個主要危機，配一個看得見的母題（古臺會照出你最薄的地方）：
- 第37列靠冉桑在槽裡數日子撐住倒數。
- 第38列靠「斷下艙」撐住道德危機。
- 第44列只剩三師兄一條火線。

**仍有戰報殘影的兩處**，就是最想壓縮的兩處：
1. **第44列第4段〈他們都不用你〉**：六位峰主的勝局寫成一封信，一人一句，仍是清單。只要讀者讀得到「各峰都在往前走」，加上那句笑著說的「他們都不用你」就夠了。建議信裡只點裘斷、梅予兩件，其餘用「還有四封」帶過。
2. **第47列第7段後半**：「保證仙晶湊夠了份額，玄殿的核驗還沒定」，加上遲望護渡申請，是聽月夜之後馬上回到行政事務。建議只留葛重新點燈與「落得晚」，以及他自己挑的古林委託；保證仙晶與遲望移到〈約束〉或〈附錄〉。

第37列第4段〈一個下午，六座臺〉也是六句戰果，但有冉桑在槽裡看、槽光換色這個框，能讀，算邊界情況。

### 1.2 新舊分數與理由

**37 師父下山：6.5 → 8.7**
- 「挑他不在的那一季」把主角拉進一篇他不在場的故事。
- 「輸一臺，輸的人進槽」讓六個人一個接一個站出來。冉桑在槽裡第五日，杜衡跪在重域裡。
- 九槽一齊暗，接著胸骨一點光。
- 結尾「那一掌是師父的。我們的呢？」直接把讀者送進第38列。
- 扣分處：湛峽三掌的段落仍是三步說明。

**38 六極再聚：5.5 → 8.8**
- 讀者C要的共同危機和「失去一件放不下的東西」都做到了：斷艙令與三百盞燈，溫火燒盡。
- 「刻六個人」與那個「七」。
- 尾聲「收過了」、六條縫，加上讀信那三句，是谷四最飽滿的一段。
- 扣分處：第2段〈六樣東西〉仍偏清單。

**39 一碗粥：5.5 → 8.5**
- 雨祠的夜雨與門口那碗粥，是不必說破就動人的設計。
- 三隻翻倒的碗給了主角情緒，雨停在半空是奇觀。
- 「給沒回來的」，他沒有喝。
- 扣分處：第2段於恬的針方仍偏解說。

**44 故人入仙途：5.5 → 8.1**
- 倒紅山是不可替換的場地，「三息」有節奏。
- 秦照雪不在場，卻用袖口的針線在場。
- 這篇仍是谷四最弱的一篇，原因是第4段的清單（見 1.1），以及溫火名詞太雜（見 S5）。

**47 鳴石臺：6.0 → 8.7**
- 掛牌「求試雙汐神火」，接「價開低了」。
- 解暘死於一照面，屍體上有他家的路線「另售」。
- 聽月夜「只有一聲」，接六聲收回一聲、鳴石啞了、燈滅。
- 舊稿的停籍籌錢與丹單勒索全部消失。
- 扣分處：M1、M2 兩個邏輯洞，以及 S1 高潮那一刻主角偏被動。修完可到 9.0。

### 1.3 三個最好的場面

1. **第37列第8段〈剩下的，我來〉／九槽一齊暗**。試寫一的節奏很好：「天潮的金線正好漲了一分。雲海沒有響。」
2. **第38列第4段〈古舟從雲裡掉下來〉**。斷艙令、六個人往下艙走、溫火塞進翼樞、浪把三百盞燈掀高一尺沒一盞翻、三十人一個沒少。這是一個完整的英雄群像場面。
3. **第47列第5–6段〈只有一聲〉→〈六聲收回一聲〉**。前一個黃昏的一照面，到聽月夜被石頭再唱一次，斷命樓老人折單走人；接著劫雷落下，石頭存不下這一聲。這是跨四篇回收的伏筆。

次選：第39列第4段，雨停在半空，魂絲在雨珠裡現形。

### 1.4 哪裡想跳

- 第44列第4段、第47列第7段後半（見 1.1）。
- 第38列第2段第一節，五人各得什麼。
- 其餘段落都有鉤，沒有明顯想跳的地方。

### 2.2 鳴石臺同夜破真一是否寫成高潮

**是**。第6段的層次完整：
1. 聽月重唱那一戰「只有一聲」，斷命樓收單。
2. 核驗使在場，崖下有人押他敗。
3. 葛磨了三個月的新長音連斷兩節，直逼第三節。
4. 劫雷落下，六雷各走一路收回一聲，六條縫合上。
5. 鳴石啞了，燈從他腳邊一路滅到崖口。
6. 「這一聲，我錄不到。」

**一個保留（S1，強烈建議）**：寫法是「劫雷就在這一刻落下」，他「沒有躲，也沒有擋，讓它落進身體裡」。讀者可能讀成劫雷的時機救了他：葛已經斷了兩節，差一節就勝。第一次月試他是主動留斷節當回口，這一次應該也要有一拍主動。
- 最小修法：在長音斷到第二節時加一句，讓他看得見那條音、讓它斷兩節而不補，「他在等雷」。日子本來就是他自己定的（一句話段已寫「他把真一定在月圓聽月那一夜」）。
- 這樣是他選的時刻，不是被救。符合作者「要氣魄」與「勝就寫勝」。

### 2.3 陸沉在師門線不在主戰，會不會變成旁觀者

**不會**。設計上三拍各自成立：
1. 第37列他不在場，但敵人的動機是怕他（「這一季不爭，下一季那小子要是回來了」）。不在場也有份量。
2. 第38列尾聲有四拍主動：
   - 問「震岫在哪？」得到「收過了」。
   - 站進古臺，看見自己的六條縫。
   - 學那一掌，一步退散。
   - 讀信問「是因為我不在？」，沒被說服，把信收進懷裡。
   - 十九歲回山那幾天他仍會笑、會被顧小滿搶一肩。D097「角色是當下的人」照到了。
3. 第39列他有欲望：替父親的傷求醫法。他會被拒（測臺推他出來），會愧（三隻碗），會引敵（「下次要什麼，來問我。別來這裡。」）。主戰讓給雲行，他有一句「這是我的」被按住。
4. 第44列有切磋 D 與外岸一肘 C，他是「學的人」，有清楚的定位。

**風險**：第37、38、39列連三篇不是陸沉主戰（形狀表_乙提醒）。新稿用「怕他／替他／因他」三拍把他留在故事中心，可以接受。寫正文時建議第37列開場用一兩句交代他此刻在聖土，讓讀者知道是同一時段的另一頭；這是正文階段的處理，大綱不必改。

### 2.4 主角三拍（第49列「又是因為我」）

讀信、翻碗、路線另售三拍各只出現一次。故事段沒有寫成他每篇都自責。驗收提示第7條照落。

### 4.2 第51列那句不受影響

- 第51列（`09_渡劫淵到路身` 第40行）的「真一……你在自己的劫裡殺人？」原文未動。
- 第47列的設計（殺手死在劫前、葛只試法不殺）守住了「第一次在自己的劫裡殺人」這件事。
- **但有一個洞（M1）**：第6段寫「劫雲在鳴石臺上空聚了三天」，試寫二也寫「劫雲壓了三天」。也就是說，解暘死的那個黃昏，同一座臺的上空劫雲已經聚了兩天。讀者會說他在自己的劫雲底下殺了人，第51列那句「第一次」的份量就被削掉。

### 4.3 其他邏輯點

- 鳴石「一塊一塊啞了」，沒有交代會不會恢復。這和「這臺是養家的器」、對手表「葛保……完整臺」、06 九等天劫「葛鳴秋保自己的完整臺」互相矛盾（**M2**）。
- 第38列第6段寫「沈山河從水裡被撈上來還沒換衣」，但第4段沈在下艙托龍骨，沒有落水的那一拍（S4）。
- 第38列尾聲：師父「胸前的傷還看得出來」，站進槽裡卻全暗。第37列的胸骨光正是從傷處來的，讀者可能會問（S6）。
- 第39列第4段寫雲行「第三記之前，他念了一聲佛號」，但對手表寫「坐雨三記不動」，試寫一也只有兩記（S2）。
- 第47列第1段「牌上另外六個名字，那一週摘掉了四個」，是誰摘的、怎麼摘的沒有寫清（S3）。
