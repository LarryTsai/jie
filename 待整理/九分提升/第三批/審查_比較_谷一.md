### 1.2 甲：8.0

- **想翻頁的原因**：名字線。望潮港海訊牌上「鎮溟霍驍、長川冷照野、滄氏滄漣——沒有太玄」（L102），讀者從這一刻起就在等太玄被刻上去；百宗看臺第一次有陌生弟子喊「劫」（L185）；天城那面牆東溟一百年最高只到第十一（L226）；最後八十日後的碼頭牌子寫著「亞，劫（太玄）——決賽棄」，兩個少年爭「放棄第一的，有什麼好記？」「預賽三十息那個。」（L280）。這是全段唯一讓七篇讀成一條升級路的東西。東溟一代天驕各有一場（L188–195）：滄漣第九十招敗、冉晴川一路砍不到底、封寒第三十息笑一下。雷潭接通的喜劇最好笑：第一夜算錯一拍，三身蹲在乾澡盆裡等到天亮；第二夜封寒嫌麻煩說只看，線通那一刻第一個脫鞋（L221）。
- **差在哪**：①第11、12列時序錯：「離開北天後轉普通商舟」再遇霧舟（L267），與北天行工作日程「往北普通舟二十日」相反；器坊在第11列（L259）、古城在第12列（L275），也與「古城三日、器坊七日」先後相反。②冉晴川「砍掉一路」（L67、L79）撞七峰「說明年試三路」「三路未成」。③雷吼澳「去年秋天開始吼」（L115）見第4節。④奇觀最少：北天、霧舟、古城幾乎照現行。⑤鍔娘寫化靈後段、卜鐵寫化靈（L302–303），都與反派表尊者不合。
- **最想保留**：
  1. 海訊牌名字線：望潮港（L102）→卓三槳「到這時才從海訊牌上知道太玄的榜首是誰……多送一包魚乾」（L125）→東境碼頭（L280）。
  2. 雷潭接通：乾澡盆等天亮、封寒第一個脫鞋（L220–221）。
  3. 玉譜拓本一面牆（L226–227），刪「中神州少年問『這裡也有一欄？』」，改用丙的老舟師那句。
  4. 次選：霍驍的前因「破了鎮溟封航的人站不站得住」（L178、L181）；海眼前「另一個理由他先告訴了封寒」（L165）；封痕裡石魁「他喊的不是你」「我還是討厭你」（試寫二）；卓三槳「這傀儡幾塊靈石？」（L98）。
- **最想刪**：冉晴川自砍一路；雷吼澳「去年秋天開始吼」與「離太玄山門半日」並寫的因果暗示；第7列雷吼澳一段劫「把一條自己的雷線釘在礁頂、每一拍重續一截」（L117）這種技術描寫壓短。

### 1.3 乙：8.5

- **想翻頁的原因**：底牌與骨。〈借地〉不是用一次就丟：一推冉晴川（L87）→前臂兩儀脈燒（L92）→古圖熄滅最後熄的是那道短臂的影子（L98）→一個月拆成「地力只借到腰，腰以上交兩儀」，推出去「短、醜，像搬缸」（L102）→百宗四強第一次上真場，一步一步把冷照野那條永不斷的劍河推到臺沿（L216）。這是三案裡唯一讓第6列的所得在第9列兌現的。戰葬四瞬（L42–53）正文一句不說，但讀者會在船底、海眼、封痕裡自己對上，尤其「回頭」——戰葬那個女人沒回來，他回頭了。戰葬「他倒著走出來」（L119）是全段最好的一個身體動作。懸潮觀把封寒的錯和真險合成一拍：封寒剛踏回實廊，身後整段空廊被吞，「我又追了聲。」（L184）。第11列合篇後霧舟是真生死局：霧深處「像海底下趴了一座山」，他照樣上帆；首帆陣盤碎後霧裡懶懶一句「這一船，不要了。」（L269–271）；皮老鴉抓住繩才看見另一頭拴在拘舟上，「繩給你。」（L272）——卷一第77章「年前搭黑帆」最好的一次收帳。
- **差在哪**：①偷接雷潭：岳沉淵拎著頭髮冒雷的少年站上鎮岳臺，各峰落到臺邊都看見（L164），卻又要「全宗不知道是他」，偵探讀者過不去。②中段偷接三次「韓鐵衣夜巡、沈山河在鐘樓、封寒望風睡著」壓成一句（L169），正是讀者A說的「壓成一段」。③第10列雷潭接通有免責句「辦法是自己想的，沒撿到任何東西」（L238）。④霧鐘島把封寒的定型句改成「誰再瞞我一件，我就自己去驗」（L108），人物卡的「不許有人瞞我」要保。⑤天城實景最少；第11列合篇後偏長（寫手自己也承認，L498）。⑥沉喉是鮑橫丟人的洞（L143），離〈約束〉「雷潭不改成販魂者佈置」只差一步。
- **最想保留**：
  1. 〈借地〉自己的一版（L101–103）與四強冷照野（L215–217）。
  2. 戰葬倒著走出來（L114–119）。
  3. 霧舟尊者在霧裡、首帆索七三合、「這一船，不要了」、「繩給你」（L266–274，試寫二）。
  4. 懸潮觀潮頭在封寒身後吞廊、「我又追了聲」（L183–185）。
  5. 次選：霍驍天城碼頭剛破銘紋、「冠軍不是我的」、把冠軍牌收進衣襟往後不掛（L254–259）；天城懸賞牆「黑帆鍔娘，尊者，劫正航」（L245）；封寒沉喉「沒人上來，是聽說。」（L144）；封痕「亞名。」（L224）；秤婆「走的人，不留吃飯的傢伙。」（L133）。
- **最想刪**：鎮岳臺當眾拎人（改用丙）；L169 一句帶過三次險被抓；L238 免責句；霧鐘島改寫的定型句；第11列器坊壓到半段。

### 1.4 丙：8.5

- **想翻頁的原因**：天地本身在演。碑林手按上碑「像穿一件石頭做的衣服」（L52）；沉雷峽雷從地底往上打、認金鐵，封寒把劍連鞘裹在外袍背著走在前面（L117）；冷照野抱著一把裹了三層的劍在雷雨裡站兩天，「路是我先探的」（L121–122），到百宗四強「劍終於拔得出鞘」（L210）——同一把劍的前後兩刻；陸沉是峽谷裡「唯一一個雷不想劈的人」（L123），修仙感與身分感一次到位；雷潭「溫的，像洗澡水」（試寫一）。古脈翻身那章（L137–142）是三案裡最照 D098 的寫法，喜劇也最足：師兄姊每個人都知道、每個人在飯桌上裝不知道，顧小滿夾菜看他一眼憋笑憋到嗆。霧鐘島：潮圖上孩子的歪腳印畫到一半，筆跡換成父親的，「從那一夜以後，家裡所有潮圖都是父親畫的」（L75）——不用任何人開口，讀者先懂。百宗會場搬到海上一百座石臺，腳下的靈力就是潮（L198）；封痕在海床，兩面海牆往中間壓（L217）。周棲岸被打離石柱後「落在已經翻到上面去的那一層，倒著掛在一片星河似的燈底下」（L275）。晚市城每晚重演千年前的夜市，只有一條燈街是斷的，他把手收回來，「那條街就那麼一明一暗地亮下去」（L301–308）。
- **差在哪**：①結構沿用現行：第11列北天「八十日的路，先往北」（L264），第12列又「從東溟北上的第一段」穿霧海（L290），讀者照樣倒著讀；器坊（L283）也排在古城（L301）之前。②鍔娘改「化靈後段（工作值）」（L334），等於改反派表。③中段偷接寫成第10列裡的回顧句「百宗前他偷接過一回，被九霄巡夜的賀成撞見」（L239），D098 要的「卷四中段」小拍變成倒敘。④把錨點陣石「全收進行囊：這個家他要帶去中神州」（L240），接通條件是雷潭的雷力範圍，陣石帶走用不了；D098 原話的「帶著這個家」是心情，不是器物。⑤刪了霧舟的器測誤讀（L474），東境有接口。⑥江停燈的接環整段沒寫（現行 D105 介面）。⑦冉晴川寫「她」（L61），甲、乙寫「他」，須核人物。⑧天城長街若寫成各域真天象搬家，會碰 D108「有意未知」（寫手自己標了，L483）。
- **最想保留**：
  1. 沉雷峽→冷照野兩天→雷潭（L115–129，試寫一）。
  2. 古脈翻身一整章（L137–142）。
  3. 霧鐘島換了筆跡的潮圖（L74–78）。
  4. 海上百臺與海床封痕（L197–199、L214–220，試寫二）。
  5. 晚市城收手（L300–309）；長街九片天（L243–247）。
  6. 次選：〈借地〉腳印比對、岳沉淵丟續脈丹「地上的印擦了」（L66–67）；青石坪在鎮鈴七枚那天裂開的地方約練（L61）；霍驍「五域你別先輸給別人」（L225）；長川港碼頭「太玄的劍，也敢到東溟來護貨？」「護得住就敢。」（L102）。
- **最想刪**：第10列賀成回顧句；陣石帶去中神州；鍔娘降境。

## 3. 鍔娘境界：定案

**查證**：[陸沉故土反派表](../../../設定/01_世界/04_勢力/05_反派/陸沉故土.md)東溟節，鍔娘與黑帆「劫修船團｜**尊者**」；該表狀態「三十二天人物寫手提案，未經作者確認」。同表卜鐵也是尊者、皮老鴉銘紋。[戰鬥共同語法](../../../設定/00_故事定位/01_寫作規則/戰鬥共同語法.md)第三節：化靈、列陣、尊者都是質變點，**跨質變點正面不可勝**；門牆越境律第3條，**陸沉自九界大比與領印日起才一場能拆一道門**。十五歲化靈的劫對尊者，要跨列陣門與尊者門兩道，且此時他拆門數是零。

**判定**：現行第12列與甲、丙的「帆索三合、雷絲貫穿鍔娘握陣的手」是**化靈正面擊退尊者，違反越境律**。丙把她降為化靈後段（L334）能過規則，但一個讓千礁宗付「讓路錢」、島國奉為半個英雄的劫修船團首領只有化靈，世界尺度不對，也要動反派表。

**定案寫法（照乙 L266–274，主編可直接定，不必問作者）**：
1. 帆索上打的是**黑帆首帆索七**（工作新人物，化靈圓滿，與劫同境），陣盤碎在索七掌中、索七自斬帆索連人帶半張黑帆墜霧。形狀仍是主編裁量准的 C，三合照現行節奏（反吸雷他不收、撞進三尺、雷絲貫穿握陣的手）。
2. **鍔娘本人尊者，留在霧深處**，讀者要在交手前就讀得到她（D162）：封寒「霧裡還有一個」，劫感到「像海底下趴了一座山」，照樣上帆。陣盤碎後她一句「這一船，不要了」，撤走全隊、斬皮老鴉拖繩。
3. 第10列天城懸賞牆先貼「黑帆鍔娘，尊者，劫正航」（乙 L245），讓讀者帶著這個境界上船。
4. 智取歸封寒照留（讀船身傾斜、推正舟頭）；不殺、不追、不得航圖照留。
5. 同步：總覽第12列「逼退鍔娘」改「擊退黑帆首帆、鍔娘撤隊」；人物境界登場紀錄加索七；反派表**不改**。
