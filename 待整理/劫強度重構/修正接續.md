# 劫強度重構：逐場修正接續表

2026-10-16｜主編整合候選｜依[診斷](診斷.md)、[三案獨立比較](獨立比較.md)及[主編整合架構](主編整合架構.md)整理。**非 Canon、非正文，不改正式篇綱或設定。**本表是下一輪逐篇改綱的工作底稿；「改寫」是建議重做場面呈現，不代表必須更改原定勝負。九界金丹豁免五檔完全未納入。

## 讀法與判斷

- **維持**：保留現有勝負和人物因果，重寫鏡頭、招法和反應，讓強度清楚可見。
- **改寫呈現**：結果不動，重整出手順序、對手反制、劫的判斷及代價。
- **重議結果**：現有勝負可提案改動；本表給出主編建議和保留條件，仍須作者確認後才能同步正式區。
- **待逐場核算**：要核年齡、境界、雷種、門牆、傷勢、物件與在場知情者；不以新增能力補洞。

主編建議的總體結果方向：保留少數真敗及同伴主場，不設敗場配額；少年中段起建立持續的同代優勢；陸沉主戰場讓他親自完成決勝動作；越境勝利依既有能力和可讀條件成立。對手可以贏、逃、改目標或造成持久損失，不能只充當他下一次升級的材料。

## C. 能力與連續性逐場檢核表

每張場面卡改寫前，先填完以下欄位；有一項不通就重寫勝法或場面，不先新增萬能規則。

| 核對欄 | 必填內容 |
|---|---|
| 時點 | 年齡、卷篇、所在位置、此前間隔；傷勢是否已復原。 |
| 修為 | 境界、雷種數與雷種性質、是否壓境／解封、場中其他人的境界。 |
| 越境 | 對手門／牆、陸沉實際拆的門、拆門者、同場次數、拆門媒介、是否跨質變點。 |
| 方法 | 只用已建立的雷身、禁、神識、雙刃、劫厄、天譴、九雷術或環境；首次使用要在此前有可讀鋪墊。 |
| 反制 | 對手的情報、計畫、有效招法、可選退路；至少一項在場面中真造成損失或迫使陸沉改變方案。 |
| 勝負 | 清楚寫出目標、達成條件、最後造成勝負的動作；區分擊殺、擒獲、逼退、撤離、任務完成。 |
| 代價 | 具體落在時間、位置、器物、陣勢、情報、承諾、關係或傷勢；不能每場默認自傷，也不能勝後空泛記帳。 |
| 角色 | 配角做出的不可替代動作、對手自己的目標、旁觀者實際可知的事；不得靠降智、全場觀眾化襯托主角。 |
| 後續 | 勝負改變的關係、資源、敵人策略、名聲或修行路徑，接到哪一篇。 |

## D. 建議執行次序與門檻

1. **先鎖結果候選，不改正式檔**：把五域、雙汐、碎錦原、玄闕逐一寫成「原結果／候選結果／受影響後續」。若某場勝法與現有規則衝突，先試兩種場景解法再提出改規則。
2. **先寫四個高回報樣卡**：五域、領印日清算、甄四海成年回收、碎錦原。它們分別測主角勝場、主題代價、敵人能動性與斷階回收。每卡要有對手反制、劫的決勝判斷、代價、配角分量。
3. **逐篇從少年到入極同步候選篇綱**：先跑每篇主人公／同伴主場，再填力量依據和狀態連續性。不得碰八身救生五檔。
4. **獨立復核**：由未參與改寫的人按本表核故事吸引力、因果、D128、角色自主與篇間接續；有問題就回改候選稿。
5. **一次性呈作者審閱**：交付一份主編推薦版、明確列出仍須作者裁定的結果與精確修改後果；在作者選定前不覆蓋正式 Canon，也不把候選列設為作者選定。
