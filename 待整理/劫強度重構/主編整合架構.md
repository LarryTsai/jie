# 劫強度重構：主編整合架構

2026-10-16｜主編依作者全面重構令及[獨立三案比較](獨立比較.md)提出的唯一工作方向。**候選提案，非 Canon、非正文；未經作者確認，不改正式戰鬥規則、人物卡或篇綱。**正文凍結，九界金丹五檔仍豁免。

## 一、我選什麼

以甲的外顯強者承諾作主軸：十三歲起，讀者、對手與旁觀者都能從實際戰果看見陸沉強；同代最高位置由他長期承擔，關鍵主戰篇由他本人做出勝負決定。保留乙的長線清算場作成年後的重量範本，採丙「同伴主場不搶最後一擊」的分場規則；不採三案任何一份全套逐卷勝負表。

這不是「陸沉每場都贏」。要建立的是穩定而有邊界的強者氣象：他多數時候先看穿、先制住、先贏；少數真敗必須讓對手贏得有力，並在之後改變兩人的關係、方法或局勢。不能用固定配額令他為了證明強而突然犯錯，也不要求每個敵人先怕他。

## 二、整合後的六條故事規則

1. **戰績先於傳聞。**名號、榜位與敵人反應由具體戰果自然生出，不新設一張全界統一榜、不要求每個對手提前改計畫。外界反應只在會改變旁人行動時寫。
2. **同代第一是長期事實，不是每次都要重演。**正式戰鬥中，他的同代位置逐步升高並穩住；同伴可以在其主場擊敗他、平手或贏別項。保留七峰生勝陸沉等已裁定的高光，不以「惟一敗者」削弱別人。
3. **敗場稀少但不配額。**保留能推動人物或世界的真敗，例如七峰敗生、鷹崖時限未達、甄四海早期壓制、月下共逃承月、斷階婁直。五域俞清漪敗場可重議，但重構建議改為陸沉最終獲勝：俞先以自己的法與判斷掌握比賽，逼陸沉即場改法；她不是被降智或被一次新招抹掉，戰後仍保留名望與後續對手地位。其餘保留或改寫以故事因果為準，不硬湊敗場數。
4. **「變」是升級，不是每次自傷。**新法初用可以失手，損失落在時機、位置、資源或戰局；不可慣例性地讓陸沉以肉身挨傷替方案付費。天譴裂被打斷的反衝等已有具體硬代價照留。
5. **越境靠已建資產和逐場條件。**D128的門／牆質變分界保留為結構，但逐場能力須寫明他拆了哪一門、使用什麼已學方法、對手如何反制、因此付出什麼。解除「每段必有敵人拆門」的強制配額；拆門的代價可落在戰局，不必每次是本源傷。至尊牆終身一次、真仙牆不可正面越先維持；任何修改需先呈明確條文與逐場證據，不能用「天的劫不算他的力」作免查捷徑。
6. **主角主戰與同伴主場分明。**陸沉主導的篇章可以群戰、連續收敵、完成最後一擊；生、妖、封寒、文奕、雲行、赤翎等人物自己的核心篇章仍由其本人造成勝負轉折並承擔結果。避免把同伴留在場上只說一句、而陸沉代收其戰果。

## 三、必須保住的人物因果

- **寇平與領印日：保留陸沉的責任。**甲不改作者原定的事故點，這一點優於乙把事故責任移給巴篆與寇平。重構可以讓陸沉同時在同一篇先完成一場乾淨、清楚的強者勝場，再因擅自替寇平決定而欠下關係的帳；不要把勝利本身寫成事故或當場抵銷。寇平仍須有自己承受、表達與後續選擇的完整主體性。
- **七峰與配角主場：保留局部真勝。**生擊敗陸沉、嬋九歌在月落古國反勝、雲行在萬獸天幕做成自己的目標、封寒在驤鳴守山承擔主戰、三千花夜由生收束。這些不是陸沉「讓」出來的名次，也不由他在同篇或下一幕取回。
- **斷階：保留真敗與長期改變。**不要把它改成暗中已贏、替婁直留手或立刻反殺；主角跌落仍是全書罕見且真正改變他與眾人生活的一次失敗。碎錦原重逢可以讓他正面擊敗婁直，但要靠兩年重構後的新方法和當場判斷，不用預設「舊敵第二次必敗」作規則。
- **「下次先問」：只在替別人決定其身體、道、物件或選擇時成立。**保留既有主幹節點；戰鬥中主動制敵不自動等同干涉自主。贏後仍可能發現自己越界，但須由受影響者的真實反應造成後果，而不是固定補一句自責。
- **仇必報但不濫殺。**採乙甄四海長線清算場的準備、對手反制與等待回收；移植的是因果與對抗密度，不是「舊敵全收進名單逐個處決」。每次清算要看當下行為、證據與仍在持械者，不傷無知弟子或退場者。

## 四、逐段落綱順序

1. 先鎖上述規則與保留事件，再逐篇列舊勝負、改後勝負、力量依據和受影響人物；不先改人物卡或寫作規則。
2. 逐場校正D128。首批先核甲案點名的領印日與千礁清算、23歲神火生擒岑越、借壽崖、碎錦原、玄闕。若在既有門數、牆與時間窗中無法成立，重寫場面勝法；不先擴規則救稿。
3. 重新設計五域決賽與九界大比／領印日銜接。五域可以改變勝負，但不改俞清漪既有能力；九界冠軍與千礁後果須分成兩件事，使主角既有明確大勝，也仍須為自己做錯的選擇負責。
4. 逐篇回查同伴主場、同代關係、傷勢、雷種、境界、年表、物件和知情界線；救生五檔不讀不改。
5. 只有逐篇方案閉環後，才同步人物卡、戰鬥共同語法、武學譜、年表、總覽與各篇大綱；總覽每列列明改掉與新增的勝負、所得、代價及未決點。
