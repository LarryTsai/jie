**目的：增加仙感、奇觀、天驕、女天驕、友情、競爭、愛情、生活與探索。** 不要把小說寫成醫療流程、物流日帳或技術規格書。技術有時就應該正常好用；也不必每次都服務八萬年前的陰謀。陸沉不是所有技術的發明者，必須能遇到更專業的高手。

## 3. 重點第十三種：仙道開源與萬法合卷

| 現代概念 | 仙道工作名 | 作用 |
|---|---|---|
| Open Source | 萬法公卷 | 開放基礎功法、禁制、器紋 |
| Repository | 萬法母卷 | 保存原始傳承與可追溯版本 |
| Fork | 分脈衍法 | 修士依材料、地域與自身本源改良 |
| Pull Request / Merge | 合卷論道 | 提交、辯論、實試後吸收改法 |
| Version History | 卷序道痕 | 記錄改動者、改動與驗證 |
| Diff | 對紋 | 比較兩套法門的差異 |
| Revert | 返卷 | 失敗後恢復舊法，保留教訓 |
| Release | 封卷定本 | 經驗證可廣傳的穩定版本 |
| License | 傳法契 | 署名、分潤、開放與限制 |
| Security Review | 驗禁 | 查反噬、暗門、奪舍與缺陷 |

**文明衝突**：公開派、封藏派、售法派、家傳派各有理由。有人怕錯法害人，有人靠售法養宗門，有人相信知識應共享，也有人被奪去署名。不能一律寫成邪惡宗門阻止主角拿寶。

**四人差異**：劫的道是「變」，喜歡拆改但可能真錯；瘋的道是「知」，必須親身碰到底；雲的道是「無」，能不執著但並非永遠正確；文奕是理解者，推究何以成立，不立第四條道。
