# 寫手三方案：岸

> 2026-10-29｜無間招式競稿第一輪，寫手三。非 Canon、非正文；試寫標「試寫／非正文」。未讀寫手一、二方案。

**一句話核心**：無間讓陸沉成為天下唯一把世界看成「岸」的人——別人看見距離，他看見哪兩處互為對岸；招式從「過岸」（自己過去）到「隔岸」（讓近的變遠），最後是鎮雷大術〈萬岸無渡〉：一場之內天地碎成萬岸，人人看得見彼此，沒有一條路相通，只有他岸岸相鄰。

---

## 一、這條線為什麼好看

### 1　讀者會看見的天地

無間的招式畫面全從《劫》已有的界潮長出來：雙岸、聲音晚到、界軌像斷橋浮著發光、渡口、撕痕、界壁。本方案只加一個招牌畫面——**對岸的光**。

無間發動時，兩處同亮，中間沒有東西經過，可是兩端會借對方的光一息：午夜林子裡忽然落下一方正午的日光，山頂聞到一口海風，雪崖上映出別處一盞燈。讀者不用懂術理，看到這一方錯位的光就知道：他已經在那裡了。

陸沉眼裡的世界也從此不同。界軌是兩道會發光的岸；渡口是兩岸天然挨近、一抬腳就過的地方；撕痕是被扯破的岸，邊上一直滲光；界壁是**看不見對岸的岸**——看不見對岸，就過不去。Canon 的硬限制（須感知另一端、不免費開九界門、過不了界壁）因此不必寫成條文，讀者從畫面就懂。色相建議：**無間無自色，借兩岸之光**（候選；無間雷檔色相待設計）。

### 2　三招一術，一條人物課題

| 招 | 一句話 | 和他這個人的關係 |
|---|---|---|
| 〈過岸〉（基礎） | 此岸彼岸同亮一息，人已在彼岸 | 十八歲的重構：兩處不必有路也能相連 |
| 〈隔岸〉 | 一步之遙，從此隔岸：近的變成對岸，看得見，到不了 | 二十六歲剛付完「未先問就把古路接起來」的帳；他學會的第一件事是：不是每兩處都該連 |
| 〈萬岸無渡〉（鎮雷大術） | 天地碎成萬岸，只有他是渡 | 仙途的「一個人渡」：他成了唯一的渡口，同伴也成孤岸 |
| （王域「接」職，化己） | 九職之一，不再是全部 | 朔河之後接只是九分之一；帝落之後，八職不用接也能成域 |

這條課題線不是新編的，它全掛在 Canon 已有的轉折上：十八歲熔雷的「重構」、九界金丹「未先問便以成熟無間重接古路」、仙途全線「陸沉的答案是渡，但他是一個人渡」、帝落大潮〈定垣〉釘死「接」位後的「八職不用接」。本方案只是讓每一步都由一招落地。

### 3　對手怎麼反制無間（全書往返的兩組宿敵）

無間要岸，所以對手的辦法都在岸上：

- **鎖岸——岑家**：朔河岑氏。雙汐（約23.5）陸沉落在岑越的轉身點上，拆他自己第一道天神門；古林外（約24）空禁師岑墟以兩枚石錨鎖住藏嶽環的外接點，岸還在，卻不再朝他，他選人棄環；沉天鐘墟（約26.55）他把這一手反過來用在岑墟身上，〈隔岸〉就此成形。三次往返，一次比一次換新口。
- **釘岸——司空絳**：不二（約27.6）〈定垣〉把無間「怎麼折都折回原處」，計真奏效一次；第一重（約45）〈萬岸無渡〉在他的星垣裡出生，〈換垣〉換回來的是他自己的星；帝落大潮（第87列）他研究了千年，第一手就釘死星天王域的「接」位。宿敵親眼看過大術出生，帶回家拆了兩千年，這是《武煉》式往返最好看的那種。
- **讀岸——宓長庚**：讀出撕痕把無間每一折扯偏半步，把最後一劍算在那半步上；斬我後一折到位，那一劍斬空（Canon）。
- **隨岸——婁直**：無間換的是位置，帶不走身上尚未放下的承力；他把下一股力壓在撕痕盲處，換了位置照樣被帶壓（Canon，斷階）。這是無間第一次整個被破，之後舊支點碎。

## 二、基礎招：〈過岸〉

| 欄 | 內容 |
|---|---|
| 歸屬｜運轉｜最低境 | 術・雷｜法力化無間雷，神識認定兩端｜列陣（取得時） |
| 一句話 | 此岸彼岸同亮一息，人已在彼岸 |
| 異象 | 兩端各借對方的光一息；起點留一方淡淡的空光，像燈剛被端走 |
| 大代價 | ①**只過得去認得的岸**：須感知另一端、界標、渡標、既有界軌／界脈或界潮近接之一（無間雷檔原條）。②**過岸不藏身**：兩端同時亮，在場的人都看得見他去了哪裡。 |
| 來源 | 悟道（主）／被逼出來 |
| 取得 | [無間航道](../../大綱/01_少年/29_無間航道/大綱.md)第7段「懂的那一息」：不看中間，只看兩端，坐到對岸的自己身上 |

招名取界槎舟子口語「過岸」：坊市的人說渡船靠岸、人上對岸，就叫過岸。短、動詞、帶碼頭氣，接得上他第一次熔雷是在兩岸之間。

**舊〈隔山〉併入〈過岸〉，不另立名。**理由：舊〈隔山〉是太虛「穿行虛空」，有經過；無間中間無跡，本來就不經過山。隔著山、牆、閉口，只要認得對岸，都是〈過岸〉。另立一招只會讓讀者分不出兩者。

## 三、舊太虛四術的現行版

| 舊條 | 本方案處理 | 理由 |
|---|---|---|
| 〈隔山〉 | **併入〈過岸〉** | 見上；無間沒有「穿行」 |
| 〈太虛斷界〉 | **改名〈隔岸〉，立為第二招** | 「斬開空間關係」是舊條唯一可發展的方向；改成「把相鄰變成對岸」，畫面清楚，也和〈過岸〉成一正一反 |
| 〈折門〉 | **不立獨招，其魂併入大術** | 「撤路另一端折回戰場」最好的首用是約31 斬甄四海（現行已在甄的遁路落三個無間近點），但那一篇已給雷瞳，一事一招不容；單獨立招也只是一個對單人的把戲。〈萬岸無渡〉之內，所有退路都開在他身邊的岸上，這就是折門，而且是全場的 |
| 〈此間無路〉 | **不立獨招，成為大術的代價** | 舊條「自身和同伴也在圈中」正是〈萬岸無渡〉的大代價：同伴也成孤岸。名字退休，留作陸沉第一次說出來的一句話 |

### 〈隔岸〉

| 欄 | 內容 |
|---|---|
| 歸屬｜運轉｜最低境 | 術・雷｜法力化無間雷，神識認定「本來相鄰」的兩處，抽掉其相連一息｜天神（候選；天神門即空間門） |
| 一句話 | 一步之遙，從此隔岸：看得見，到不了 |
| 效果 | 打來的一擊、敵人的一次挪移、飛出去的一件法寶，它的落點忽然成了對岸：力停在半途，像倒影浮在水面上散掉；挪移落不下去；法寶懸在主人手邊一尺，回不到手裡。能截天神改場的一次挪移，是陸沉**自己的**拆天神門手法 |
| 異象 | 咫尺看成天涯：對手明明在三丈外，看上去忽然小得像站在對面山頭；兩人之間那一段空氣映出另一邊的光 |
| 大代價 | ①**隔是雙向的**：隔住的那一段，他自己也過不去、打不過去。②**一次只隔一道「之間」**。 |
| 來源 | 敵人（岑墟的封錨） |
| 與同伴分工 | 文奕以預布禁域「此處空間不准被改」；雲行〈定〉讓門所倚的動先慢；生秋掉這一次挪移的壽。陸沉不禁、不慢、不秋，只把落點變成對岸（[天譴](../../設定/04_修行/03_武學/01_主角群武學譜/03_天譴.md)第十節分工不重疊） |

**種子（約24，[下無極亡命期](../../大綱/02_離鄉/06_下無極亡命期/大綱.md)）**：岑墟以兩枚實石錨封住藏嶽環的外接點。陸沉看得見那隻環，環就在三丈外，可是岸不再朝他：他第一次知道，鎖不是牆，是把一處的「對岸」抽走。他選人棄環，臨走一記落冠在石錨上留雷痕（現行不動）。

**首用（約26.55，[沉天鐘墟](../../大綱/03_崛起/07_沉天鐘墟/大綱.md)第五節）**：兩山斷口間倒懸半口古鐘，斷梁在峰風裡響人耳聽不見的餘聲。岑墟換節點要把鎖位往下移，陸沉把他新側接的落點隔成對岸——岑眼看自己的定橋簪就在手邊，側接卻像落在對面山上，一路空了。他沒有再找二十四歲那個口，岑說過不再給同一個口，他這回給的是岑自己的鎖。其後渡影步落渡標脫罩、兩儀撞定橋簪、整梁入匣，全照現行。

這一招出生的時機是本方案最在意的：九界金丹剛結束（約26.5），他剛為「未先問便把古路接起來」付完生的封傷。他下一招不是更遠的接，是**隔**。

## 四、無間鎮雷大術：〈萬岸無渡〉

| 欄 | 內容 |
|---|---|
| 名稱 | **萬岸無渡** |
| 一句話 | 一場之內，此間每一處都成了彼此的對岸——人人看得見彼此，沒有一條路相通；只有他，岸岸相鄰 |
| 最低境 | 真仙（候選） |
| 前身 | 〈過岸〉、〈隔岸〉；舊〈折門〉〈此間無路〉併入 |
| 照式 | 約45，[第一重：斷峰定](../../大綱/06_仙途/02_第一重/大綱.md)中段4，借司空絳的星垣作岸（見第七節試寫） |
| 化己 | 約105，[朔河不沉](../../大綱/06_仙途/03_朔河不沉/大綱.md)星天王域成，九職之「接」 |
| 名的來由 | 斷峰群守路人的老話：「峰峰是岸，沒有渡。」陸沉照落冠的老規矩，拿別人的話替自己的招命名 |

**天地級氣象**：術成的一息，場中天地碎成無數岸。地面、山、海、雲都還在原處，可是每一塊都亮起別處的光——這座峰上落著那座峰的雪光，這片海上映著那片崖的燈。聲音晚到，像界潮裡一樣：敵人先看見自己的同伴張口，半息後才聽見那一聲喊。人人看得見彼此，伸手卻是一片看不見底的水。陸沉在每一道岸邊都只隔一步。

**做得到**：敵人的合擊、援兵、陣與陣的連線一齊斷開；每一條退路都開在他身邊的岸上（折門之魂）；打向別人的力落進岸與岸之間；他一人在萬岸之間來去，每一步都是〈過岸〉。

**大代價（只兩個）**：
1. **同伴也成孤岸**（舊〈此間無路〉）。術中他的人也互相到不了，所有的連線都得經過他。他一鬆，所有人一起被困在自己那塊岸上。這正是仙途「一個人渡」的畫面化。
2. **一場一次，用完無間位入夜**。之後數日他連最近的〈過岸〉也點不亮。

**硬邊界（照共同底線，不另堆條件）**：不出術域；過不了界路與界壁；不越真相層、不碰第十雷；高一大境的王域可以從外面把整片岸按住。

**為什麼最低境是真仙、首用在仙途**：見第九節第1條。故事上的理由是：無間是全書被打碎得最徹底的一道雷（斷階舊支點碎、兩年不出場），也是唯一靠「重構」走到大術的雷——它最晚成大術，讀者會覺得那是他重新長出來的，不是年紀到了就發。

## 七、試寫：萬岸無渡第一次（試寫／非正文）

> 檢驗目的：大術第一次以照式出現，畫面是否到天地級；能否完全落在[第一重](../../大綱/06_仙途/02_第一重/大綱.md)中段4的現行節點裡（〈定垣〉釘一格、不拆格、兩儀作軌、格子兩端接到同一處、〈換垣〉換回自己的星、三十息碎一角、兩句台詞）。不是正式章節。

斷峰群的外緣沒有地。

八萬年前斷開的峰浮在虛空裡，一座一座慢慢漂，像一條沒有水的河裡擱淺的冰。峰與峰之間是黑的。偶爾有碎石從一座峰的崖邊掉下去，掉很久，才落到另一座峰的背面，連聲音也沒有。

司空絳站在最外那座峰的尖上，星垣從他靴底流出去。星光越過黑，搭上一座又一座漂峰，每一座峰頂落一顆星，星與星之間拉起細線。整片外緣成了一張網。

「觀星廊那一格，」他說，「你還記得。」

陸沉記得。星光從頭頂合下來，四條線一收，他被釘進一格，三丈見方，和不二之土那一夜一模一樣。他抬腳，腳落回原處。無間往外一折，折回來的還是這三丈。

那一夜，他拆這格子拆到一身是血。

今天早上，他沒打算拆。

兩儀從他腳心落下去，一陰一陽各咬住一條格線。格子不再是牢，是一截軌。

然後他閉上眼。閉眼的時候，他看得最清楚。

星垣裡每一格都有兩端。對司空絳來說，那是一張網，網眼一個挨一個；對無間來說，那是幾百處岸，每一處都隔著水，望著別處。

他把自己這一格的兩端，點成同一處。

格子還在，他還在格子裡。格子動了。

遠處一座峰上有人在記星位，筆停住了：網中央那一方星光，正沿著格線滑過去，像一條船自己離了岸。

司空絳不等。陸沉一抬手，殞星在指間凝成小冠，往他扔過去；他的第二手〈換垣〉已經伸進星圖裡——不二之土那一夜，就是這一手，把陸沉自己的小冠換到他自己腳邊炸開。

這一次，他往網裡找能換的那一格。

網裡每一格，都只望著一處。

所有的岸都轉過來了。幾百座漂峰同時亮起別處的光：這座峰的黑岩上落了那座峰的雪光，那座峰的斷崖邊映出另一座峰上誰點的一盞燈。整個斷峰群外緣忽明忽暗，像一片碎掉的鏡子被人從底下照亮。

聲音晚到了。司空絳看見自己的指尖收攏，半息之後，才聽見自己那一聲「換」。

換是換了。星圖肯換的只有望著同一處的兩格。他伸手出去，碰到的是陸沉那一格；他換出去的，是自己腳下那一格。

他本命星的光，落進陸沉掌心。

那頂小冠，落在他原本站的地方。

赤銅色的光從最外那座峰的峰尖炸開。星垣的一角像被燒穿的紙，捲起來，往黑裡掉。

陸沉睜開眼。掌心那顆星很冷，還在跳。他沒有握，手一翻，讓它沿著原來的線回去。

三十息。

司空絳站在少了一角的星圖邊上，腳下的峰尖缺了一塊，衣袖燒黑了半截。他看著陸沉，看了很久。不二之土那一夜，他看出這個人的無間每一折都偏半步；今天他看不出它往哪裡偏。它沒有偏，它根本沒有往哪裡走。

「你這一版，」他說，「是不二之後才有的。」

「是今天早上。」

他收起殘了一角的星垣，退出斷峰群。臨走時，他從一座正在漂開的碎峰上揭下一片星，那是帝重落軌留下的。他比所有人都早一步量出了第二重的方向。

陸沉站在原地，四周的漂峰一座一座暗回自己的顏色。

蒼梧說過，斷峰群守路的人有一句老話：峰峰是岸，沒有渡。

他想，這句話可以借來用。

## 八、《武煉巔峰》讀感對照

依作者給的閱讀印象比較（未直接讀原作，不宣稱掌握細節）：

1. **值得注意的效果**：主角一級一級升，每一級都有一件事、一個人；同一批人物多次往返，每次重逢彼此都變了。
2. **本方案做到的**：〈過岸〉七版每一版都掛在讀者已讀過的場面上（領印日、九弱、雙汐、陽閘、古路閘室、玄闕），升等就是那一場的勝法，不是境界欄的一格。宿敵往返兩組：岑家三次（雙汐→古林外→鐘墟），每次換一個口；司空絳三次（不二→第一重→帝落），他看著大術出生，帶回去拆了千年，第三次釘死「接」，陸沉再改一版。低谷（斷階失岸、兩年不出場）讓玄闕的歸來有分量。
3. **仍像清單或沒做到的**：十九到二十三歲無間只有改版沒有新招，讀者可能覺得這道雷「停著」；大術在約45才出，主線前二十八篇讀者看不到無間大術；〈折門〉「逃走的人發現自己回到原地」這個爽點，被併進大術後不再有單獨一場。
4. **怎麼改成本書的場面**：不加招，加往返——建議 PM 在第40列上界追仇或第41列九弱裡，讓岑家人第一次露面記下他的無間（不給新招，只給宿敵一個「記住」的鏡頭），讓二十四歲的鎖岸有前因；甄四海那一場（約31）把三個近點寫成讀者第一次看見「你的退路在我腳下」，作為大術〈折門之魂〉的預告，而不是新招。

## 九、Canon 風險與需作者裁定處

1. **大術篇位（核心題）**：主線第21至28篇劫的新招已滿——第21篇雷瞳、第22篇〈劫數・落〉、第23篇〈噤〉悟、第24篇〈噤〉用與三才局完整、第25篇短承、第26篇〈合轍〉（候選）、第28篇〈劫數・降〉與十雷一體；至尊之年的子篇〈日月藥天〉〈雨山見劍〉也明寫不新增神通。所以本方案把大術放進仙途第84列。該篇為**作者選定**（D158），本方案只替中段4已寫的「格子兩端接到同一處」「〈換垣〉換回自己的星」命名，不改事件與台詞；但該篇高潮另有「引渡／從往來放出去」，若作者認定那也是劫的新招，則一篇兩項，需作者裁定：(a) 引渡屬第十雷之用、不入招譜，照本方案；(b) 大術照式改為「此篇無名，化己於朔河時才命名」。
2. **大術最低境真仙**：高於其他四門已定大術（天神／虛道／至尊），候選，請作者看是否接受「最晚成的大術」。
3. **〈隔岸〉改寫一句工作選定文字**：[沉天鐘墟](../../大綱/03_崛起/07_沉天鐘墟/大綱.md)第五節「劫先以本人天神有限空禁截一小段已知側挪移」改讀為〈隔岸〉照式；結果、所得、十二日不動。
4. **〈折門〉〈此間無路〉不立獨招**：兩項是012「轉無間方向採用」的舊方向名目，捨名需作者同意；本方案保留其作用（併入大術）與「此間無路」作台詞。
5. **玄闕「這一次他換位了」**：本方案讀作無間落在管曜手腕；若作者原意是千相〈換位〉，〈過岸〉七版改掛第一重或刪去。
6. **王域「接」職＝大術化己**：星天王域本身是工作創作・候選；本方案只把其中一職與大術連起來。
7. **色相「無自色，借兩岸之光」**：無間雷檔色相待設計；與雙刃九雷入刃之相如何呈現未處理。
8. **〈隔岸〉拆天神門**：以「落點成對岸」區別文奕、雲行、生三種拆法；仍請 Reviewer 核是否被讀成搶文奕的空間門專長。
9. **九界金丹**：作者豁免檔，本方案只引用「成熟無間有限跨界、八道撕痕、未先問重接古路」作人物課題的前因，不提任何修改。
10. **強度紅線自核**：無新增陸沉敗場（亡命期棄環是選人，斷階不敗皆 Canon）；不新增越至尊牆；跨界仍本體、錨印；〈萬岸無渡〉不出術域、不成全界交通；少年期只有〈過岸〉一版。

## 十、自評

- **最看好的一招**：〈隔岸〉。畫面最好拍（三丈外的人忽然像站在對面山頭），它是陸沉自己的拆天神門手法，出生時機正好接在九界金丹的帳後面，讀者會懂「他學會了不連」。
- **最可能讓讀者覺得重複或無聊的地方**：〈過岸〉七版說到底都是「一閃到別處」，正文若每次都寫成短距接換加一記雷，讀者第三次就會膩。補救靠兩件事：每一版都有不同的岸（敵人的轉身點、扣成之前、自己的雷身、敵人的手腕），以及「對岸的光」每次借來的光都不同。另一個風險是〈隔岸〉「力停在半途」若用太多，會像一面萬能盾；正文宜全書寫三四次，每次隔的東西不同（挪移、法寶、援兵）。
