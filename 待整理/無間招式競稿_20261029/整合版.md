## 一、一句話與主幹

無間是「兩處同亮，中間無跡」，真正能打它的不是比他快的人，而是**搶他兩端的人**：讀他落點的、釘住他這一端的、拿別人的端來壓他的。劫一招一招把端搶回來：先握住自己的兩端（〈折〉），再把敵人的門接回戰場（〈折門〉），最後一域之內，天涯的那一端也在他手邊（鎮雷大術〈天涯無間〉）。

**異象（借寫手三）**：**無間無自色，借兩岸之光。**每一折，兩端各借對方的光一息：午夜林子裡落下一方正午的日光，山頂聞到一口海風，起點留一方淡淡的空光，像燈剛被端走。讀者不必懂術理，看見錯位的光就知道他已經在那裡了。

**口頭禪（借寫手一）**：同伴問「這是新的？」劫答「舊的，改了一版。」全書只用三次：雙汐、古路閘室、玄闕。不要每版都說。

**誰打無間，劫怎麼還手**（敵人先得手的那一計全是現行已寫的；本表新增的只是「他專打無間哪一環」與劫的改版）：

## 二、招式條目

### 1　基礎招〈折〉

| 欄 | 內容 |
|---|---|
| 歸屬｜運轉｜最低境 | 術・雷｜神識同時點亮兩處已驗之端，法力隨無間雷在兩端同時落定｜列陣 |
| 一句話 | 一張紙對折，紙角碰紙角，中間的紙還在，兩點已經貼著 |
| 效果 | 本尊與雷身、或本人與一處驗過的落點，兩處同亮，人已在那一端；中間有山、有牆、有禁，原封不動 |
| 異象 | 兩端各借對方的光一息 |
| 大代價（一條） | **只認驗過的端**：親身踩過、按過渡標、雷身正站著，或感知得到的界標、界軌近接（守無間雷檔「初期至少需能感知另一端」） |
| 來源 | 悟道 |
| 名字 | 航道歸來五日，替生改一隻紙燕的翅膀，對折、展開、再對折，兩個翅尖碰在一起；坊市賣紙叫折紙，兌錢叫折錢，都是把兩頭變成一頭。現行大綱本來就寫無間「每一折」「一折到穿崖點」，不必改字 |

**〈折〉的版本**（都是版本，不另計招；各版只命名現行已寫的場面，不加事件）：

| 版 | 年齡｜境｜篇（總覽列） | 多做到的一件事 |
|---|---|---|
| 一版・接己 | 17–18｜列陣｜無間航道（32） | 本尊與雷身互折；回程一枚一枚認界標 |
| 搶拍・種子 | 18｜列陣｜領印日（33） | 折到裴照川第二記扣成之前 |
| 標 | 約20.5｜神火｜九弱（41） | 渡標成鏈（渡標仍屬渡影步長成，無間沿標落點）；折四丈從船骨裡出來 |
| **搶拍**（借寫手一） | 約23.5｜神火｜雙汐（46） | 讀熟岑越換口前必回的轉身點，落在那裡，早他半息（現行第214行一帶）。封寒問：「新的？」「舊的，改了一版。」 |
| 載人 | 約27.5｜虛道｜陽閘（58） | 一次帶一人折過摺縫；撕痕裂開兩道（現行） |
| 持兩端 | 約31｜至尊｜一炷香古路閘室（63） | 兩處同亮不熄，一手按一半，撐到祁承晏補完最後一筆，兩掌被兩片道則撕開（現行）。「舊的，改了一版。」 |

舊〈隔山〉併入〈折〉：隔著山也是一折，無間本來不經過中間；另立一招只會讓讀者以為無間平時要繞山。「人不動、只送雷」不在少年期給，留給大術的攻勢一面（見下）。

### 2　〈折門〉

| 欄 | 內容 |
|---|---|
| 歸屬｜運轉｜最低境 | 術・雷｜神識讀出對手遁、挪、傳送或陣門的兩端，無間把遠端折回近端｜天神 |
| 一句話 | 你的路照舊開著，只是另一頭接回了戰場中央 |
| 異象 | 對方退路那頭與劫腳下同時一亮；折回來的人出來時，姿勢還是走的姿勢 |
| 大代價（一條） | **撐門時，他自己的無間被那扇門佔滿，本人折不出去**——所以他要事先備好別的退路（渡標、渡影步、同伴） |
| 不能 | 折界路、錨印、界壁；折沒開出來的路。用在天神以上對手身上，就是「改戰場的人被鎖住空間」，計入他一場的拆門數，不另開越境例外 |
| 來源 | 偷學（岑墟的封運法）／敵人 |
| 照式 | 約26.55｜天神｜**沉天鐘墟（54）**：岑墟在定橋簪與節點之間來去，劫踩過前一日的斷橋，把他的門折回原地；撐門時自己折不出去，改以渡影步落渡標脫罩（現行骨架）。見第六節試寫 |
| 熟用 | 約31｜遁一→至尊｜**一炷香與至尊之年（63）**：甄四海捨陣遁走，遁的是最近那條路，三個近點已在路上（現行第43、45行）——那是三扇折門。他一遁，就回到劫雲底下，第七重同壓兩人，越至尊牆③（不新增越牆） |
| 化己（借寫手一） | 約34.5｜真仙｜**玄闕祖脈（71）第14段**：不再靠自己事先驗的端。第10段他自選用肩接管曜一掌，那道仙力的紋走進身體（現行）；第14段管曜收法域要連盤走，劫不追，肩上的紋往西北一扯，他把管曜退路那一頭點成自己的另一處。管曜一沉，從他面前出來，手腕還牽著盤。「路是你的，那頭是我的。」穿針、殞星、九霄一重，手腕斷（接現行）。「舊的，改了一版。」這一版的端是敵人的力紋，滿足無間「須感知另一端」 |

〈折門〉化己屬既有招的改版，**不佔第25篇新招位**（第25篇本篇所得仍是短承）。

### 3　無間鎮雷大術〈天涯無間〉

| 欄 | 內容 |
|---|---|
| 一句話 | 一域之內，天涯也是鄰座：敵人的每一扇出口都接回此間，他的雷從敵人身邊亮起 |
| 起手語 | **「此間無路。」**（舊〈此間無路〉併入，作者裁定） |
| 最低境 | 真仙 |
| 前身 | 〈折門〉（守）；〈折〉（攻：不送人只送雷，在域內才成立） |
| 性質 | 不封空間、不造新空間、不是瞬移大陣；是**重排一片戰場的遠近**。域內誰與誰相鄰由他排。三面：**守**，域內每一扇出口的遠端折回此間（此間無路）；**攻**，他的雷不走路，直接從對手身側亮起；**斷**，域外接進來的力，他看得見兩端的，一念可熄（劫自己管這一手叫「銷標」，回收袁寄舟那一夜） |
| 異象 | 域內每一處都借別處的光：這座峰上落著那座峰的晨光，聲音晚到半息（借寫手三〈萬岸無渡〉氣象，收到一場之內） |
| 大代價（兩條，不再加） | ① **同伴也成孤岸**（借寫手三）：域內所有相連都經他，同伴彼此也到不了，伸手三丈是對岸；要讓同伴動手，他得先收術。② **他本人是唯一的樞**：打中他本人，域裡改過的遠近一齊回彈到他身上 |
| 不能 | 出域；碰界路、界壁、錨印、王庭本根；撕痕盲處不在域內（看不見的端就不是他的端）；不把同伴修為合給他（守第82列「不把低境朋友合成真仙力」）；不越真仙牆 |
| 首用 | 約35｜真仙｜**九雷問祖・十二山（82）B122**（作者裁定）。見第七節場面卡 |
| 以後 | 成王後化為星天王域九職之「接」（朔河不沉現行九職已列「接」，王域本身仍工作候選）；帝落〈定垣〉釘死這一職、八職成域（現行）。長亭截脈管曜九樁，可用「斷」一面熄樁與樁之間的接，第九根在盲處照舊沒找到（現行失手）——屬大術的用法，不是新招，列為候選窄修 |
| 命名 | 十二山戰後，晏亢掛在第四座山的山腰上看完全場，只說一句：「十二座山，那一刻都在他手邊。」封寒在帳上記「此間無路」，劫在後面補了四個字 |

## 三、舊太虛四術的處理

| 舊條 | 處理 | 理由 |
|---|---|---|
| 〈隔山〉 | 併入〈折〉；「只送雷」成大術攻勢一面 | 無間不經過中間，隔山是雷性本身。不另立名 |
| 〈太虛斷界〉 | 併入大術「斷」一面，劫口稱「銷標」，不另計招、不單列譜名 | 原案「斷階〈銷標〉照式」不成立：[斷階頂上](../../大綱/04_成道/02_斷階頂上/大綱.md)第90行是「接穗法反用」，不是無間，且斷階為作者選定。主線第21–28篇新招已滿，沒有其他乾淨篇位；勉強單立會變成第三種「熄」，與〈折門〉、大術守勢重疊。併入大術後，「斬開空間關係」仍有落點，名字裡袁寄舟那筆帳也保住 |
| 〈折門〉 | 保留名；照式天神，鐘墟 | 作者裁定。天神門就是空間門；舊真仙門檻不繼承；舊「第25篇管曜截殺」改為玄闕化己 |
| 〈此間無路〉 | 大術起手語 | 作者裁定。單立會是「把圈內所有門都折回」，與〈折門〉同功能 |

## 六、試寫｜〈折門〉第一次（試寫／非正文）

> 只檢驗〈折門〉第一次出手。事件骨架照〈沉天鐘墟〉§四、§五（岑墟換節點反制、渡影步落渡標脫罩、定橋簪折兩截、整梁入匣）。依 Reviewer 意見刪去開頭的封運陣解說，改以動作呈現；加入「借兩岸之光」異象。

鐘梁在半空響了一聲。人耳聽不見，劫的牙根聽得見。

岑墟站在斷橋那頭，身前一根定橋簪斜插在橋石裡，簪尾連著兩根外露礦釘，把先得的那半段梁釘在原處。另一個節點壓在劫身前三丈，看不見，只有落在上面的雲屑不往下飄。

「古林那一回，你斷的是我的側錨。」岑墟說，「今天沒有側錨。」

劫一雷打過去，落在一根礦釘上，釘子碎了——那根早撤了供，真的鎖位往下挪了一尺。岑墟沒有動腳，人已經在橋的另一段。

劫的護臂裂了，血順著腕子滴進匣口。匣裡的器靈縮了一下，不肯開快門。

他不再打釘。他看岑墟走。

岑墟第二次挪，從簪邊到節點；第三次，從節點回簪邊。兩處亮，中間無跡——不，有跡。那兩點之間拴著一根線，像兩頭釘死的樁。那不是無間。那是一扇門，岑墟有鑰匙，兩扇都是他自己埋的石頭。

前一日他沿這條斷橋走過一遍。簪插的那一點，他踩過。

岑墟第四次起身。劫沒有攔他的人。他把神識搭在那扇門上——不是門口，是門的另一頭——輕輕一折。

簪邊的峰風忽然帶著節點那頭的雲屑。岑墟從簪邊消失，從簪邊出現。

他自己也愣了半息。腳下仍是剛離開的那塊石頭，簪尾還在手邊顫。像一個人推門出去，看見的是自己剛關上那扇門的背面。

「你的門，」劫說，「我借一下。」

岑墟再挪。節點亮了，他卻落回原處。他換第三條，一條劫沒走過的——那一條通了，他到了半橋外，劫折不到那一扇。可半橋外是斷口，梁在簪下，他得回來護。一回，就得走劫踩過的路。

那一刻劫覺出代價：他的無間被那扇門佔滿了。他想往旁邊折一步，折不出去，像兩隻手都扶著一扇正要倒的門。

岑墟看出來了。押了十幾年貨的人，一眼就知道對手把力壓在哪裡。他不挪了，抬手往下一罩。罩勢像一口倒扣的箱子，劫腳下的石頭先黑了。

劫沒有放門。前一日他在斷橋那頭按下過一點冷銀。渡影步沿著影標一抹，人從罩勢底下滑出去，落在渡標上。罩勢合攏，關住的是一塊空石頭。

「說過不給你同一個口。」岑墟的聲音從簪邊傳來。

「我沒要你的口。」劫從袖裡抽出一根普通陣樁，落在岑剛換供的那一點，「我要你的門。」

兩儀掛印，一端吸住定橋簪，雷從另一端劈下。岑墟只有兩條路：放簪，丟梁；護簪，就得用自己那條側橋硬接這一雷。他想挪——門還在劫手裡，挪出去也是挪回來。

他護梁。雷落在側橋，橋石燒白。劫的手掌按上定橋簪，掌心的雷與簪裡的封運法力硬撞了一息；簪身先彎，再斷，一截落進斷崖的雲裡，很久才聽見響。

門鬆了。劫的無間像一口憋了很久的氣，一下子回到胸口。

岑墟抱著自己那半段梁退出外庭。走之前他回頭看了一眼那塊石頭，他從它離開、又落回它的那一塊。「你這一手，叫什麼？」

劫正把匣口對準剩下的那一彎梁。器靈終於肯開慢路了，梁尖一節一節沒進去。他想起十八歲那年在甲板邊摺的那隻紙燕。摺過一次的紙，再摺一次，就是門。

「折門。」

## 七、大術首用場面卡：十二山（B120–B123 修訂，事件概要）

> 第82列〈九雷問祖〉B117–B126 其餘照現行。只動 B122 後半與 B123 開頭；B119 第一擊、B120–B121 短承與老祖割鍊、B124 解契、B125 斷主環與殺實身魂、B126 晏澹寧全照現行。勝負、傷帳、紋材損失、日帳不動。

**B120–B121（照現行）**　第二擊他棄熟路，以玄闕練成的短承讓一具雷身在兩個能退的點之間承下。老祖見他接住，割斷身邊金鍊改成自供，十二山一座一座暗下去，光全收到老祖一人身上。「斷十二山就斷他的力」算空了。

**B122（改寫：〈天涯無間〉第一次）**
1. **一個人的十二山**：老祖不再讓山轉向，他自己沿十二條金鍊換方位出手——鍊是十二山之間唯一的路，他每一記都從不同山的方向來，帶著那座山殘留的轉向。劫肩上吃一擊換一次看清（現行「星羅重讀自己的供轉」保留）：老祖每打完一記，一定先退回主環續一口力，再上鍊。退與續，是兩個點。
2. **此間無路**：劫不追。他說：「此間無路。」十二座暗下去的山頂同時亮起別處的光——第七座山上落著第三座山的晨光，谷口那條河映著祖峰的鍊影；聲音晚到半息。老祖踏上東四鍊，鍊的另一頭落在劫左手邊；他退回主環續力，退路的盡頭也在劫面前。退與續，成了同一個點，就在劫身前一步。
3. **送雷不送人**：劫本人不動。無妄截住老祖當境可截的外續，有隙只保一處已驗的短端（現行），兩記雷不走路，從老祖身側直接亮起（現行「無間兩點落在老祖側面」）。
4. **敵計真奏效一次**：老祖是真仙，看兩記就看懂了：整片山的遠近都掛在這個年輕人身上。他第三擊不打別處，直打劫本人。域裡改過的遠近一齊回彈——十二條鍊的力同時找回自己的山，全從劫身上過。劫把回彈全導進短承，讓一具雷身在兩點之間承下，那具身散了（之後在醫養期重凝，計入現行70日醫養，不加日）。
5. **勝**：就是那一息，退與續還疊在他身前。殞核落在那一點（現行「殞核落在他退與續之間」），本人的真仙雷打碎祖法的核心（現行）。九雷有限輪用，不是十雷一體，九雷合一不出（現行）。
6. **孤岸**：域裡的同伴互相到不了。文奕在外環，那兩塊讀通的副板就在三丈外，手伸過去是對岸；封寒在鍊下，和掛在山腰的晏亢之間隔著一片看得見底的空。劫知道這筆帳。祖法一碎，他收術。

**B123（開頭加一句，其餘照現行）**　十二山的遠近回到原處，光還暗著。文奕的手按上了副板。（下接現行：「死了的弟子，能回來？」……老祖沒倒。）B124 文奕逆副板正好接上——同伴能動手，是因為劫先收了術。

**守則**：同境真仙對真仙，不越牆、不計拆門、不用〈劫數〉；大術不合同伴修為；B124「拆得開。拆了，他們先死」全書一次照原句，不改成大術；B125 熄魂中退路仍是星羅，不用大術。

## 八、《武煉巔峰》讀感對照

> 未讀原作，只依作者提供的閱讀印象（慢慢升等、每一步有故事、人物多次往返）。

1. **值得注意的效果**：升等是「在誰面前、為什麼拿到」，舊人再出場時雙方都變了。
2. **做到的**：三招各掛在一張臉上，而且多半是那張臉第二次出現：岑墟古林先贏、鐘墟被折門；管曜第10段打進一掌、第14段那一掌變成他自己退路的鑰匙；甄四海十一年後把命押在最近那條路上。十二山老祖第一擊把他震退數十丈，第三擊看穿了樞，他仍勝。
3. **原本的空窗**：18–25 歲無間沒有新招。整合後用〈折〉的搶拍版（雙汐）、口頭禪與「借兩岸之光」，讓讀者每一版都看得出換了一版，不必新增招名。32–34 歲的低谷改成刻意留白，玄闕那一折就是歸來。
4. **仍要小心**：「折回原處」的畫面在折門三版與大術守勢反覆出現；正文要讓每次的端長得不一樣（驛石、劫雲、力紋、十二條鍊），也不要每場都先講一次「只認驗過的端」。
