## 〇、這個方案在做什麼

**一句話**：晏九歌的故事從頭到尾以她自己的仙途為主軸：南荒選拔、北院、宗門任務、四院選拔、九界、自己破尊登天、在本闕查案。她每次走到陸沉身邊都有自己的理由；陸沉不在的時候，她也照樣在贏、在輸、在查。

**和另兩條常見路線的核心差異**（依競爭規約至少兩項成立）：

1. **大師姐不進倒雷井，也不死在倒雷井。** 倒雷井 D1–D38 的殺局時間表一刻不動。大師姐的罪是在上界轉遞站提出的「撤單月封」建議：她知道扣裡有死傷，仍提議把撤單封一旬，讓申查期過去。這筆帳由晏九歌在宗門裡一頁一頁查出來。她死在《月下共逃》第四幕，由陸沉親手清算，晏九歌親手破她的月域。**她查出，他清算；兩人分別承擔。** 狐闕的追殺是她死後才全面升級的，母稿「命玉報死、追殺擴大」這一拍仍在，只是往後移了。
2. **晏九歌不是報信的人，而是追殺隊的一員。** 大師姐派她進狐闕追殺隊，理由是她「認得那個人」。她比別人先找到陸沉，靠的是她認識這個人，不是情報網。她先跟他動手，再向他要那半枚求援扣。這樣和聞人錦「多給線索、替人引走追兵」的功能從開場就分開。
3. **少年期走合法書院路**：百川會入選五域，再被北院選入書院，四院選拔取得九界代表位。院內有自己的宿敵甘不晦，有勝也有敗。《月落古國》由狐闕下院的宗門令帶動，放在南荒四幕結案之後、溫棠命牌熄之前的新增窗口，不碰第四雷。
4. **陸沉落潮那一年（18–19歲）是她自己的一年**：她不去留舟島找他（那是俞清漪的戲），而是自己破尊、自己登天，到下無極狐闕本闕當新人。她在那裡被大師姐壓著做雜務，也因此看到了那本外務簿。

**本方案最值得期待的四個場面**

- 《月落古國》第三幕：她在古月臺用滿月強攻，反被古臺借力打傷；隔夜改用缺月的弦刃，從甘不晦手裡贏回月臺。「滿月不是唯一答案」在一場敗、一場勝裡成形。
- 《月下共逃》第一幕：客舟底艙，追殺者和被追殺者先交手三招，再把兩半證據放在同一張桌上。宗門的外務簿抄頁、尹遷撤單留印上的月痕，與陸家半扣拼合。
- 第四幕：晦日夜裡沉舟月市的天上出現一輪假滿月，那是大師姐的月域。晏九歌的月影在月域裡一具一具被收編，反過來刺向她。她換成沒有月華的「晦影」破域，陸沉報出「九界，陸家」，收下第四筆帳。
- 第五、六幕：《蝕月・九影歸寂》只斬開一丈缺口，持續三息；陸沉揹她穿過去。八天後洛生衣乘同層客舟到半弦渡，三階段救回她。醒來後她第一次沒把玩笑說完。

## 一、人物卡要點

### 晏九歌（暫名）

- **出身**：太陰狐闕南荒下院弟子。**建議定為月狐混血**：母為林中妖族月狐血裔，父為河網城邦人族修士（已亡）。理由如下：一、全庫沒有狐族設定，混血比「太古上位天狐」對世界的衝擊小得多，「太古天狐」只當作狐闕自稱的古譜；二、命輪成熟度與人族同齡，可以合法參加五域、九界與登天；三、河網對開智異族「可登記參選、但限大型本相入城」的歧視，正好落在她身上。按 D077，血脈覺醒只在質變點發生（列陣、尊者），每次覺醒多一道月痕尾影；「九尾圓滿」是狐闕祖傳的唯一正道，也是她後來要超越的東西。
- **大道**：太陰盈缺（若怕與秦照雪的「太陰」撞詞，可改稱「盈缺月道」）。她的核心信念是：缺不是弱，滿不是唯一。法門分四相：**媚月**擾亂對手的注意與節奏，可被識破，也可用計算破解；**弦月**是真實的月刃，主殺傷；**望月**是全盛強攻，最大的弱點是容易被借力；**蝕月**內斂、冷、專殺。另有她自創的「缺經」一系，以**晦影**為代表：沒有月華的暗影，不受同源月階壓制。
- **月影**的限制寫進人物卡，避免蓋過千相：月影是由本命月供能的實體分影，能真持刃、真受擊。銘紋期只能撐一具十息；列陣兩具；尊者三具，距離三十丈內，約一炷香。月影不帶獨立神識，分出去越多，本人的感知越薄。影被打碎時，反噬回到本命月。月影不能獨立修煉、不能跨界，與陸沉雷身的長年獨立完全不同類。和蒙晝「凝影」的差別：凝影是光影誘敵，她的月影是有重量的刃。
- **性格**：笑是她的武器，也是她的反抗，從不討好人。她會調戲陸沉，也會在一瞬間收起笑，冷得讓敵人膽寒。她是好偵探，因為她記得一切細節：月相印、筆跡、誰在哪一天做了哪件雜務。
- **欲望**：想走出一條狐闕祖譜上沒有的路，當自己的祖師（母稿那句「我想當她祖師」保留）。對陸沉是欣賞、好奇，後來加上生死互信；但她不為感情放棄自己的道，也不和洛生衣爭位置。
- **境界**：15歲銘紋前段；17歲列陣（第二次覺醒）；約18.9歲尊者（第三次覺醒，未滿二十，極罕）；19.4歲尊者前段。

### 大師姐（暫名；工作代稱「望月首席」）

- **身分**：狐闕前代下院首席，比晏九歌大四歲多。晏15歲時，她約19.8歲破尊登天，進入下無極狐闕本闕，成為本闕首席嫡傳。她走祖傳九尾圓滿之道，晏19歲時已是**尊者後段**。
- **真實月道實力**：本命「望月全盛」，正面殺術是「滿弓」。月域**「圓魄」**能在百丈內升起一輪假滿月，域內同源月華依尾階服從最高者，**所以晏的月影進了她的域會被收編、反刺晏本人**，這是狐闕祖傳等級制的力量表現。另一門手藝「月封」能把一份紀錄或一股器勢封在當時的月相裡，一旬內無法被他人讀取或散去。
- **與葛照庭是真道侶**：兩人相識於上界三年，器法互補。她在葛長戈的接杆裡刻了一圈月紋，讓長戈承接到的「退勢」能多留半息，這正是葛「接杆借退勢」的練習基礎（不改倒雷井戰鬥，只補前史）。她是真心愛他，也真心怕他被層霞刑律查辦。
- **罪責（可查證）**：轉遞站截扣當天她在場（上界，不下界），聽見喬疏月讀出殘訊「宅中有死傷」。她提議：「扣別毀，毀了要報失；讓費撤單，撤單留印我替你們月封一旬，申查期一過，這就是一筆普通買賣。」事後她親手月封了撤單。尹遷事後到外堂申訴無果，原因之一就是撤單紀錄被封、查無此件。狐闕規矩是凡對外施月封，都要在本闕外務簿登記月相與事由，她登記了。報酬是倒雷井換潮推算的分潤，以及井中太陰古材的優先權。**她知道有死傷，仍然推進。**
- **制度性欺壓（逐件，都有後果）**：
  1. 百川會（晏15歲）：她以下院代報人身分，把晏編進水陣實試最險的河段，搭兩名不肯配合異族本相的河網修士。規則允許，結果晏護送失敗、真敗，只以末席進入五域。
  2. 月泉名額（晏16歲）：本闕首席有權分配下院月泉，她扣下晏的名額，晏只能去北嶺外泉做險得多的「代泉試」，差點失去第一具月影。
  3. 半張圖（晏約17歲）：月臺令由本闕下達、加蓋她的首席印，只給晏半張圖；同時另派應弦帶密令同行。
  4. 刑堂護短（晏約17歲）：應弦在月臺打傷師妹戚小禾，因她以首席身分作保，只受輕罰。
  5. 壓功（晏19歲）：晏剛上本闕，就被她以「下院新上，先做外務三年」為由壓住嫡傳登記；倒雷井換潮推算由晏代算，署的是她的名字。外務簿謄錄這份雜務也被丟給晏。
- **她怎麼看晏**：「靠血脈贏一局，也算本事？」她真正怕的不是晏的血脈，而是晏不需要祖譜也能贏。她不是只會罵人的惡女：她的推算精準，對本闕外務也確實盡責。

### 太陰狐闕：上下界派系

- **結構**：比照玄殿與太玄宗、丹岫與千礁的上下關係。**本闕在下無極**，與碧梧、九弱同層；**南荒下院**寄居在雲根山國北嶺，面向林海，與羋山國約定以月潮推算預報上游汛期，換取月泉租權。下院不進南荒五代表，不凌駕三方，與萬生古盟只有往來。這也一併解決命玉問題：大師姐的命玉放在上界本闕，所以死在上界時當場報死。
- **本闕派系**：
  - **闕主**（神火巔，名字暫不定）：重宗門存續，不願為私仇和三宗綁死。
  - **圓魄長老**（神火後段，大師姐的師尊）：護徒、護祖道，第五幕親自封路。
  - **守約派刑堂**：承認外務簿制度，程序慢但不能無視證據。這是晏九歌的合法戰場。
  - **奪權者**：大師姐死後想把首席之位、甚至「叛徒」之名都往晏身上推的人。
- **下院**：應弦是大師姐的心腹師兄，列陣，後來也登天；戚小禾是師妹，混血，崇拜晏，月臺一戰中受傷。

### 同代對手

- **甘不晦**（新角，北天量天臺出身，北院同屆）：修推步之學，能從月華顏色讀出她體內本命月處於哪一相：「今夜妳是下弦，七成。」五域時他贏過她一次（真敗）；北院三年是她的院內宿敵；月臺一戰他輸了；四院選拔她拿到代表位。他的道是「天上的東西都可以算」，她的道是「我可以自己選缺在哪裡」。
- **權明**（既有名冊：霜明凝光宗，列陣，未排對陣）：九界上她的真勝對手。凝光術能吸收、反映她的月華。
- **斛律鳴**（既有，驤鳴，九界「保留高位」）：九界上贏她的人。這場勝利正好補強他的高位，不動陸沉的籤表。
- **上無極的古陽道統對手**：第五篇另設，不在此預支。

## 三、五篇逐篇事件鏈與逐章場景卡

> 章數是故事容量估計。「晏」指晏九歌視角章；「同」指與陸沉同場；「陸」指只需在陸沉視角補一兩句的接口。

### 第一篇《月下初逢》｜百川會與五域（15歲；新增約6章，插入卷十二、十三）

**事件鏈**：大師姐以代報人身分安排晏的水陣分組，晏在實試中真敗，只以末席進入南荒代表名單。五域前夜，她在仙市找到古月晷殘針，陸沉讀出殘針上的禁紋，兩人互相欣賞也互相討價。正式賽中她以弦月真刃贏下一場，第二輪敗給甘不晦。她在場邊看俞清漪擊敗陸沉，然後被北院選中。

| 章 | 場景卡 |
|---|---|
| 1 晏 | **百川會・個人鬥法**。對手是河網修士，賽前在場邊說「狐狸別露本相，場地小」。她不露本相，只用一具月影（銘紋期十息）當誘餌，再以弦月破對手護身。這一勝很乾淨。大師姐在監察席旁冷言：「靠血脈贏一局，也算本事？」晏回：「那下次不用血脈，師姐陪我打一場？」 |
| 2 晏 | **百川會・水陣實試，真敗**。她被分到改道最急的河段，兩名隊友拒絕與「本相未收的人」共撐陣眼。她的月影在亂流裡反光散形，護送的凡人目標被沖走，由監察席撈回。排名跌到南荒代表最後一席。她第一次看清大師姐的手法：處處合規，沒有一處可以申訴。 |
| 3 同 | **五域前夜・仙市古月晷殘針**（放在集合月裡，避開借月山與賭石主場）。殘針是古月臺的計相器，攤主當廢銅賣。陸沉讀出針尾還有一段承相禁，於是兩人在攤前討價。母稿那段「人家都笑給你看了，還不夠？」「差一半。」原樣保留。最後兩人各付一半：她拿針，他抄走禁紋一頁。她說：「你倒比傳聞裡難騙。」 |
| 4 晏 | **五域分組戰，獨立勝場**。對手是西極鳴野宗天驕（新角，未定名）。他認定狐族只會魅惑，一開場就封神識硬攻。她收起笑，媚月完全不用，以弦月正面接下三擊，第四擊才放出月影封住他的退路，一刃破甲。陸沉在觀眾席上，什麼也沒做。 |
| 5 晏 | **第二輪，敗給甘不晦**。量天臺的推步之學讀出她當天本命月處於下弦，提前算準她月影收回的那一息。她輸得清楚，也記住了這個人。她不在陸沉的晉級路線上，排籤一處都沒動。 |

3. **重新承載**：她不讓日月合一，而是讓它們輪替盈缺：日盛時月缺，月盛時日缺。缺經在這裡第二次救她。
4. **實戰驗證**：第一具日影成形，在陸沉不在場的一戰中擊敗古陽道統的守傳人。

## 八、自評弱點

1. **兩段增時是硬成本**：約50日加約77日。月落古國依賴候選年尺的17歲餘量，九弱鬆動也只是推算值，都需要聯排驗證；若作者不採西極年尺，N2 窗口要重算。
2. **晏的少年線篇幅大**，約30章插入陸沉主線，會稀釋卷十二到二十三的密度。可行的縮法是：代泉試與落潮之年改成晏視角短章，月落古國壓到18章。
3. **「追殺隊員先找到他」與「合扣」的推理鏈**依賴一個新制度（狐闕外務簿的月封登記）。設計上自洽，但屬於新世界細則，Reviewer 可能認為太方便。補救方式：序章 P1 先讓她因為這條規矩吃過一次虧。
4. **大師姐的死在第四幕，不在倒雷井**。作者修訂稿明說「四人一起進入倒雷井」，本方案改動了作者給的骨架。補償是場景重量與追殺升級的因果更清楚，但這屬於作者核心題，必須由作者拍板。
5. **生的出診改動了兩句工作選定文字**，並讓九弱 Q 段的生回聲要重寫；Q9 前後的情感節奏需要重核。
6. **晏在九界兩場（勝權明、敗斛律鳴）**仍要看完整籤表，若後排籤表與此衝突，要換對手。
7. **月相印不符的推理**依賴讀者相信本命月相會留在印上，第一次出現時需要在序章前兩章先展示一次。
8. **晏的魅力最容易流失在共逃中段的生活章**；若 Reviewer 認為第三幕八章過長，可刪拍賣一章，把第14章她的獨立勝場前移。
