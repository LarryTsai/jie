# 《劫》人物卡｜妖・晏九歌（候選）

> 狀態：2026-10-13 人物卡工作稿，非正式 Canon。依據 GitHub `待整理/生與妖_輪迴日月/作者投放原文.md` 整理；晏九歌、太陰狐闕均為暫名。不可直接覆寫既有正式設定。

## 一、人物定位

- 代稱：**妖**；姓名候選：**晏九歌**。
- 性別：女；出身候選：太古天狐，純血或混血未定。
- 所屬候選：南荒古宗**太陰狐闕**（暫名，不能凌駕既有南荒勢力）。
- 初遇：五域大比時期，約十五歲；與陸沉在仙市古月臺殘器前相識。
- 核心定位：擁有宗門、道統、對手、敗績、機緣與獨立人生的絕世女天驕。不是主角的跟班、專屬情報員或感情競爭工具。
- 角色印象：笑時妖媚狡黠，言語半真半假；動殺意時極冷、極準、極狠。既能在月下逗人，也能在擂臺上正面鎮敵。

## 二、性格內核

她習慣以玩笑試探人，但不是任何時候都不認真。她欣賞陸沉的眼力、敗後反省與不服現成答案，而非一見鍾情。她願意為同行者冒險，也不願把自己的仙途交給任何人決定。

**外層**：機敏、從容、敢逗敢笑、善觀察；**中層**：好勝、獨立、守承諾、懂分寸；**內層**：在宗門義務、個人自由與真實情感之間作出有代價的選擇。

禁止寫法：每句都調情；靠媚術無解取勝；只在陸沉身邊才有劇情；因洛生衣而自卑退場；用犧牲自己證明愛情。

## 三、修行與大道

### 初始：太陰盈缺

她不接受「九尾圓滿／望月最盛」就是天狐唯一終點。月缺不等於弱，圓滿也不是全部答案。這是她突破祖傳道路的起點。

| 能力 | 戲劇作用 | 必須保留的限制 |
|---|---|---|
| 媚月 | 月華干擾注意、判斷節奏 | 非無解精神控制 |
| 弦月 | 真實高殺傷月刃，正面攻伐 | 受境界與防禦反制 |
| 望月 | 當境太陰全盛爆發 | 有供能與時機代價 |
| 蝕月 | 收斂、冷酷的凝練殺術 | 不等於任意越境秒殺 |
| 月影千身 | 可戰月影、換位、包夾、錯位 | 距離、時限、供能、破滅反噬；不得等同雷身長年跨界修煉 |

### 中期：蝕月斷路

《月下共逃》候選禁術**蝕月・九影歸寂**：燃盡已成月影道痕，集中一擊斬開高境封鎖的缺口，並非斬殺高境強者。代價是月影本源崩潰、太陰經脈重創、瀕死；生救回性命也不能立刻恢復全盛。

### 後期：太陽道 → 日月同天

她在上無極或更高階段**自行**取得太陽機緣，經日月相斥、真敗、閉關、重煉、實戰驗證，逐漸修成日影與日月並立。太陽不是治傷捷徑，也不是陸沉代悟。最終氣象：金日銀月同升，日影月影交錯，晦明盈缺皆能攻伐；不等於掌控全部陰陽法則。

## 四、人物關係

**劫・陸沉**：五域相識，因殘器禁紋與試法相互欣賞；南荒《月落古國》雙人旅行中互相逗趣、共闖古臺，各有目的；九界再會；下無極《月下共逃》各帶追兵並肩，真敗、共處、冒死撤離。感情可以深，但不預設結局，也不要求她為他放棄道。

**生・洛生衣**：生是有殺劍與丹道勝場的強者，妖是有日月攻伐的強者。兩人首次正式相識可由醫案開始：生只救天狐本源傷，不替劫處理追殺、清算、作證或伏殺。往後《日月藥天》可共同採藥、論道、對敵，彼此有不涉及陸沉的交情與分歧。禁止爭寵模板。

**瘋・封寒**：可短暫三人合作，但不能抹去劫與妖的兩段雙人長篇；封寒已有獨立上界行程，不可為讓位而降智或失聯。

**宗門與同代**：太陰狐闕、大師姐、葛照庭、倒雷井四人殺局、狐闕追殺，均須參照另份修訂母稿核對；在核實前不填死具體血緣、師承與叛變動機。她需要能反覆交鋒的同代對手，而非只靠主角團製造衝突。

## 五、人生階段與故事承載

| 時段 | 篇章候選 | 妖的獨立目標與不可失去的戲份 |
|---|---|---|
| 約15歲 | 五域大比《月下初逢》 | 古月臺殘器、與陸沉切磋、至少一場不靠媚術的同境真勝；不改俞清漪擊敗劫 |
| 約16歲 | 南荒《月落古國》18–30章 | 追索月經、古宗派系、月臺爭鋒；先真敗後靠自己修正月影再勝；有仙市與旅行日常 |
| 約18歲 | 九界大比《九界再會》 | 依法取得參賽席次，獨立對戰他界天驕；不改陸沉五雷奪冠 |
| 約19–21歲 | 下無極《月下共逃》候選20–35章 | 自己的追兵與古月傳承、月影雷絲聯手、共處、蝕月斷路、瀕死；不得抹去九弱原勝敗與神火修行 |
| 上無極 | 《日月未央》／《日月藥天》 | 自行求太陽道，與生、劫可各有目標同行；她必須有自己的真敗真勝 |
| 高境 | 日月同天 | 不在劫身邊也有獨立巔峰戰績與道統抉擇 |

以上章數與年齡為候選母稿工作值，非已排定章表。

## 六、關鍵人物弧線

**第一階段：以笑試人。** 她用月華與言語觀察他人，但戰鬥不靠他人輕敵才能成立。

**第二階段：以敗知缺。** 古月臺真敗後，拒絕由陸沉替她解題，自己調整月影的供力與回收。

**第三階段：以命作選。** 下無極她主動承擔蝕月禁術代價，救出的是兩人共同爭取的生路，不是替男人擋刀的功能性犧牲。

**第四階段：活下來，仍然離開。** 洛生衣保住性命，卻無法替她修好大道。她感謝生、珍惜劫，仍自行踏上求陽之路。

**第五階段：日月同天。** 她不再以祖傳的「圓滿」界定自己，真正開出自己的道。

## 七、代表語氣（示範，非正文定稿）

> 「陸公子，你有那麼多個自己，總有一個特別喜歡我吧？」
>
> 「都是我。」
>
> 「真不公平，我只有一個，怎麼跟你們算帳？」

> 「陸公子，下次見面，記得想我呀。」
>

## 九、待作者與 Agent 核實

1. 晏九歌與太陰狐闕是否定名、天狐血統純混。
2. 大師姐、葛照庭、倒雷井四人殺局及狐闕追殺的最新修訂，是否與本卡一致。
3. 五域／九界席次、南荒四幕時間窗、下無極合法登天條件。
4. 蝕月禁術的敵我境界、反噬、洛生衣當期醫道及交通可行性。
5. 太陽道取得時點、日影限制、日月同天各境界武學階梯。
6. 至少三場妖獨立勝場、一場真正敗場、一段不涉及劫的宗門人際戲。

**核心句：她可以愛一個人，卻不必為愛成為那個人的附屬。她笑著與人同行，也能笑著獨自走向自己的太陽。**
