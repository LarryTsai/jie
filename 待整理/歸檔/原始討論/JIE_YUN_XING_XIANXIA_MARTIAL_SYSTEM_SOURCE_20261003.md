# 《劫》｜雲・雲行修仙武學與傳承體系提案

## ——心燈、四重定、千燈、背燈與「空手」

> **狀態：候選 Source／待 Canon Review（討論底稿，非終局）**
>
> 以 GitHub 現行雲行設定為硬底：**道（作者層工作詞）是「無」：有，可以；沒有，也可以。捨是他走的路，無是他走到的地方（D071）。技能越來越無；年輕時多術，一門一門放下，放下的那一刻都有事件；化己是省、是收，最後不用；放下的是術與法相，不是根本功法（D074）。**
>
> 本提案**不改** D074 已定的九項：定、叩壺、沙行、空手羅漢（已放下）、無念行、撥珠、守一息、背燈、攏天（已放下）。本提案只做兩件事：**把他「拿起過」的東西做大**，讓每一次放下更重；**把「定」往上推到仙道尺度**，讓「無」有天地級的樣子。
>
> **劫：越學越多 → 越改越多。**\
> **瘋：越驗越深 → 越刪越少 → 只剩唯一。**\
> **雲：越拿越大 → 越放越輕 → 最後空手。**

# 一、人物根本

雲行的難處在於：「無」一旦寫成戰力，就會變成「什麼都不怕的人」。這條路不能走。

他的強，是**真的拿得起**。法相、上界真傳、能把天攏進一掌的術，他都拿過，而且用得好；然後在某一件事上看見那東西底下壓著誰，放下。

所以技能趨勢與封寒同樣「先多後少」，但動詞不同：

| | 封寒 | 雲行 |
|---|---|---|
| 為什麼少 | 驗完了，**不需要再演一遍** | 看見了代價，**不需要再拿著** |
| 放下時 | 已經通理 | 常常還沒想懂，只是不用了（攏天：放下時不到通理） |
| 最後剩下 | 一擊（唯一的落點） | 不出手的那一招 |

> 封寒放下，是因為知道了。\
> **雲行放下，是因為看見了。**

# 三、根本功法｜《心燈經》（工作名）

沙燈院是古路上的在家禪門，世代承燈。燈陣是外面的燈；禪門根本是**裡面的燈**。

> **燈不滅，不是因為一直添油；是因為風進不來。**

核心不是「清空自己」，而是**讓心裡那盞燈不被外面的風吹動**。這就是「定」的來源：不是壓住別人，是自己不動，周圍的急才慢下來。

- 品名依 D073 留白（凡篇／靈篇／玄篇／仙篇），本提案只歸類：**根本功法，禪門秘傳，雲紓也修同一部**。
- **放下的是術與法相，不是《心燈經》**（D074）。這部經他到終局都在修。
- 伏筆：雲紓承燈、雲行遊方，兩人修的是同一部經的兩種讀法：她守外面的燈，他守裡面的燈。第 22 篇他選燈，是第一次把裡面那盞拿到外面來。

# 四、「定」的四重｜從禪定到天地之定

現行 D074：定＝入定之後，周圍的法、勢、念先靜下來；越強的術越先慢下來。

本提案把「定」排成四重，對應他一生的尺度。**每一重只能讓東西慢，不能讓東西停。**停時、凍結、禁止施法一律不寫。

| 重 | 名 | 範圍 | 異象 | 篇位候選 |
|---|---|---|---|---|
| 一 | **定己** | 自身 | 酒壺裡的酒面不晃 | 少年，隨照塵遊方 |
| 二 | **定人** | 身邊的人（叩壺、守一息由此長出） | 叩壺每聲一圈淡金漣漪（現行） | 第 8、22 篇 |
| 三 | **定域** | 一片地（背燈的燈域由此長出） | 燈域內塵埃緩緩下沉，像水底 | 第 22、28 篇 |
| 四 | **定天** | 一方天地的靈氣與道則運轉，先慢下來 | 風住、雲停在半空，落葉落得極慢；雷雲裡的雷要很久才落下來 | 正文外，或終局只露一角 |

**第四重「定天」的邊界**：

- 跨質變點正面不可勝（境界與能力尺度:59）。定天讓天地慢下來，不能讓高他一個質變點的人慢下來。
- 定天是**他自己先慢**，天地跟著慢；他在定天裡也動不快。這是代價：用了就打不了。
- 「越強的術越先慢下來」保留：越急的、越想取的東西，在他身邊越先被拖住。這是「無」在道則上的樣子：**不爭的地方，急的東西沒有著力點**。

> 陸沉的雷越來越快。\
> 雲行身邊，一切越來越慢。

# 五、上界真傳｜〈千燈〉（新增候選：拿起最大的一件，然後放下）

現行雲行「拿起過」的有空手羅漢（法相）與攏天（術）。兩者都是少年時的東西。本提案建議再給他一件**上界級**的東西，讓他的「放下」到中段仍然有重量。

## 來源

第 7 篇九界大比，照塵以上界長老身分露面、挑中雲行（現行）。照塵屬未濟道場外院的遊方長老；外院的遊方禪門有一門神通，給**一個人走遍一方天地**用的。

**照塵把它交給他**：照塵當年放下了燈；他給雲行的，是一門「不必守燈也能照千處」的法。這門法本身就是照塵的答案，也是照塵的盲點。

## 效果

神通〈千燈〉：一念分出千點心燈，落在千里之內的千處；每一處都是一次小小的「定」。走過的地方，燈留著：迷路的人看得見路，躁動的禁先靜下來，臨死的人那口氣慢一點散。

異象：夜裡從高處看，他走過的路上，一點一點亮著極淡的燈。

## 代價與限制

- 千燈每一盞都只是「定」的一點，不能治、不能戰，撐不過一場正經的鬥法。
- 燈越多，每一盞越淡；他自己越空。
- 千燈照得到千處，**照不到要一直守著的那一處**：燈留下了，人走了。

## 放下

**第 16 篇回西極拆信，見到雲紓。**

雲紓守的是一盞燈，守了一輩子。他在千里之內點了千盞燈，沒有一盞是替她點的。

他當場收掉千燈。不說理由。

第 22 篇選燈，是同一個答案的後半句：**千盞照過就走的燈，不如一盞背著的燈。**

> 照塵給他千燈。\
> 他最後背回去的是一盞。

（若作者不想給他上界真傳：〈千燈〉可退為「年輕時自悟的遊方術」，放下篇位不變。）

# 六、空手羅漢｜做大，讓第 11 篇更重

現行：少年在西極古路石窟看古僧法相殘影七天，自己長出一尊空著手的羅漢；第 11 篇碎錦原放下，從此不再用（D074）。

本提案只做**放大**，不改事件：

- 法相成長候選：少年時數丈；九界大比前後已是**百丈法相**，敵術先落向它，同境之內能替整支隊伍擋住一輪。
- 天地異象：法相所在處，天光像經過一層琉璃；羅漢垂眼，**原本該持燈的那隻手空著**（現行）。
- 第 11 篇碎錦原：法相太大，玄闕軍陣的火力全朝它來，落點正好在要撤的人頭上（現行）。**法相越大，放下越重**：他收掉的是同代天驕裡最大的一尊法相之一。

> **遵守**：殘影只能看，不教（紅線 2，遺念不傳功）。\
> **不得**：日後法相回來。D074「從此不再用」不動。

# 七、鏽一重｜捨修為，仙道裡的「無」

現行：第 22–24 篇為守燈留過了印期，**自己選擇鏽掉一重**；照塵當年也這樣（作者定）。

這是全書最「仙」的一次捨：修仙世界人人往上爬，他自己讓修為剝落一層。

本提案建議把它寫成雲行武學的**轉折點**，而不是單純的損失：

- 鏽掉一重之後，他的境界掉了，**定沒有掉**。《心燈經》修的是燈，不是油。
- 從這裡開始，他的強不再跟境界走。
- **但跨質變點仍正面不可勝**：他不會因此越級打贏誰；他只是在比他強的人面前，仍然坐得住。

> 別人的修為是一路疊上去的。\
> 雲行的修為裡，有一層是他自己拿掉的。

# 八、背燈｜從燈域到「長夜不牽」

現行：背沙燈院母燈，以定撐起燈域，域內神識不被牽；第 28 篇守錨之戰第一次全開，校正之陣牽人，燈域裡的人牽不走（D074）。

本提案只補**仙化的天地尺度**：

- **燈域異象**：母燈一盞，光不遠，只照得到身邊幾步；可是燈域裡每一個人的影子，都朝燈的方向落。
- **全開（第 28 篇）**：燈域不是光照得到的範圍，而是**定得住的範圍**。校正之陣把道脈往一個方向扯，燈域裡的念、名、神識，像沉在水底的石頭，扯不動。
- **與空手羅漢對稱**（現行）：那尊法相原本該持燈的手是空的；到背燈，他才真的拿起東西。

# 九、撥珠｜全書兩次，不加

現行：收壺、逐顆撥照塵的舊佛珠；每撥一顆，定深一層；全書只撥兩次（第 22–24 篇、第 28 篇）。

本提案**不加次數**，只補一層仙化讀法：

- 平常的定是「讓急的東西慢下來」。
- 撥珠的定是**讓自己的念頭一顆一顆靜下來**，直到心裡只剩一件事：這個人今天要死。
- 異象：每撥一顆，天光暗一度（現行）。最後一顆撥完，四周靜得**連雷都不敢落**。

> 他捨得的東西很多，取命不在其中。（現行）

# 十、最終道術｜〈空手〉（工作名）

## 一生的手

| 階段 | 手 |
|---|---|
| 少年 | 空手羅漢：法相的手是空的，**因為還沒有東西值得拿** |
| 中段 | 千燈、攏天：手裡抓過整片天、千盞燈 |
| 第 22–28 篇 | 背燈：**第一次拿起不能放的東西** |
| 終局之後 | 空手：**不是因為沒有，是因為放得下，也拿得起** |

## 機制（候選）

〈空手〉是「定」與「無念行」在道則層的合一。

- 無念行（現行）：心裡沒有要取、要破的念頭，認念之禁就不起。
- 〈空手〉：他身上**沒有任何可以被抓住的東西**：沒有執、沒有求、沒有怕。凡以「取」為根的術（牽、奪、吞、校正、拘名），在他身上找不到把手。

**它不殺人，也不救人。**它只讓他自己走得過去。

異象：沒有。這是全書唯一一門**沒有異象**的大術。旁人只看見一個空著手的人，從一片誰都過不去的陣裡走過去。

## 限制

- 只對以「取」為根的術有效；正面一拳打過來，照樣會傷。
- **用〈空手〉時，手裡不能有東西**。背著燈，就用不了空手。

## 最重要的一條：第 28 篇他不用

第 28 篇守錨之戰，校正之陣牽人。

他已經會〈空手〉。他可以一個人從陣裡走過去，什麼都牽不走他。

他選擇**背燈**。因為燈域能護住的是別人，空手只護得住自己。

> **能捨，不等於該捨。**（現行終極難題）

〈空手〉第一次真正用出，留在終局之後：**輪到雲紓背燈的日子**（現行：第 28 篇後與雲紓輪流守燈）。那天他空著手走在古路上，喝酒，問死者的名字。

> 「如果你今天已經天下無敵，明天要做什麼？」\
> 「吃飯，睡覺。」（現行）

# 十四、紅線（本提案自己要守的）

1. **不當導師**（D071、紅線 4）：他的「定」讓急的東西慢下來，不替別人做決定，不講道理給主角聽。
2. **「不用碰」至少錯一次**（D071）：每段同行至少一次他的不碰是錯的。〈空手〉不得讓他的迴避變成永遠正確。
3. **不碰幻術**：破幻、辨真是池杳與觀心峰的專長。定讓幻境慢下來，不讓幻境消失。
4. **不搶鑑月的記名**：燈域護念、護神識，不記名。名字是鑑月的事。
5. **法相不回來**：空手羅漢放下就是放下。
6. **只慢不停**：四重定都不寫停時、凍結、封印施法。
7. **招名不同時用「風」「雲」**（攏天守則）。
8. **跨質變點不可勝**：鏽一重之後，他的強不跟境界走，但打不過的人仍然打不過。

- 第 16 篇放下千燈：與「陸沉不在場」、拆信場景是否衝突。
- 第 28 篇「會空手、不用」：何時學會〈空手〉（建議第 24 篇赫連晴之後、第 28 篇之前，寫成一閃而過）。
- 每一門放下的法，放下前至少有一次真正的高光。

## character

每拿起一門法都問：

1. 他為什麼拿起？（不能是「隨便就有」）
2. 他用得多好？
3. 哪一件事讓他看見這門法底下壓著誰？
4. 放下時他想懂了沒有？（多數時候沒有，只是不用了）
5. 放下之後，誰替他「有」？（盲點：雲紓背燈）

# 十六、作者層一句話

> **雲行不是沒有東西的人。**
>
> **他是什麼都拿過，最後只背起一盞燈的人。**

而他真正的強，從來不是能放下多少。

而是終於有一天，他什麼都放得下，**卻選擇不放下那盞燈。**

這就是雲。

這就是「無」：**有，可以；沒有，也可以。**
