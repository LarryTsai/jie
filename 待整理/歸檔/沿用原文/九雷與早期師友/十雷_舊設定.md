# 十雷唯一設定表

狀態：現行唯一來源 v1.2

本文件是十雷名稱、進階、法則、取得階段與代價的唯一設定入口。其他角色檔、圖片文字或舊版名稱若與本文件衝突，以本文件為準。

## 一、總綱

> 追九雷而承九劫，悟無始而成自身。

雷種是承載不同劫數的器，雷法只是外在表象。陸沉確實會像追尋天地異火般主動追逐本源雷種，但目的不是把十種屬性當收藏品，而是進入九種雷道生態、親身承受九類大劫，再由自身回答第十劫。

第一至第九雷皆為外界真實存在的完整天地異雷，各有雷池、雷域、雷界或同等完整雷道生態；不得只因一次戰鬥、救援、頓悟或情緒爆發便在體內自然生成。第一雷完整歸屬、雷體成立後，陸沉須主動蒐集雷跡與古籍、選擇啟程並進入對應雷境。第十雷無始是唯一不存在外部本源、只能由九雷齊備後自身領悟而成的例外。

每雷取得故事至少包含：**需求／舊缺口 → 雷跡與線索 → 主動追索 → 雷境生態與歷史 → 守關者或競爭者 → 首次收服失敗 → 承受該雷對應之劫 → 取得 → 磨合代價與後續改變**。雷池不是寶箱，雷域不是背景；環境、雷種與取得者都必須在故事後發生改變。

**十雷不是十件獎品，而是十次回答。** 每一雷的「需求／舊缺口」必須先在正文造成一次無法靠現有手段抹平的失敗、失去或倫理難題；陸沉追雷不是因命圖有空位，而是因上一段人生留下了他不能再逃避的問題。取得後也不能只多一種招式，必須改變他看待生命、死亡、承擔或選擇的方式。若刪去雷名仍只剩「到新地點、打守關者、得到能力」，該段即視為未完成。

十雷的共同人物主軸固定為：**怕死而先看 → 看見後學會算 → 以禁制預先安排風險 → 天地雷火使禁制流動 → 肉身成為最後一道可移動的禁 → 命圖讓多重代價得以分擔 → 完整劫難迫使他由控制轉向承受與結算。** 十雷可以回答不同問題，但不得離開這條成長因果另開收集線。

天地異雷沒有子種、主種、祖種、劫源等分級。取雷成功即取得完整本源；持有者只能發揮多少，取決於境界、肉身、神魂、理解與磨合。取得完整，不等於能立即展開完整天然場域。

「未穩定／穩定」只描述持有者能否讓完整異雷在自身體內安全運轉。正文一律直接使用自然雷名或命圖位名，再以承載、精度與可用範圍描述掌握程度。

同名雷種可由不同雷池孕育；同一枚本源核心不可同時屬於多人。

**天譴執譴邊界**：天譴不能讀心或按血脈定罪。陸沉須主動進入刑衡雷界，通過問罪雷劫取得外部本源與執譴資格；其後仍須依逐人罪證、閉合因果、公開反證與刑責分級落雷。若混入私怨、隱藏反證或擴大連坐，天譴回灼命圖並使裁決失效。

「天若不罰，我罰」只能是陸沉主動走入刑衡雷界的道德起點，不能直接生出第九雷。他在帝關、異域與投降派身上看見天道沒有替受害者完成的清算，因而決定自己承擔查證、裁決與判錯反噬；刑衡天雷則要判斷他是否有資格把這句意志變成不受私怨支配的公正行動。意志是叩門，完整外部雷界與問罪雷劫才是取得。

第九雷的個人首敗固定發生於刑衡雷界：陸沉把黑水城活人承災案與帝關交荒軍令並排，因兩者都有「以大局填入未同意犧牲者」的結構，險些先合併為同一項罪。雙面案卷石承認兩邊證據都真，卻反灼他寫下的等號——結構相似不能省略逐人責任鏈。此敗必須保留到取得章，並由右手鎖痕證明完整問罪雷劫沒有替他刪去判錯。

**第一雷命名與破陣邊界**：初始正式名為照命，進階後稱煌命，兩者始終是同一枚雷種。照命所見「命線」包含生命、招式、禁制與陣法實際運轉的脈絡；它能照出能量交會、裂口與將斷節點，使任何仍在運轉的陣都有理論上的可追索破法，但不直接提供摧毀高境大陣所需力量。完整流程與境界上限見 `systems/SYSTEM_LU_CHEN_FORMATION_SCOPE.md`。

### 二之一、天地雷名、命圖雷位與招式三層結構

天地異雷本名描述雷在陸沉出現以前便已存在的孕育地、顏色或天然異象；命圖雷位名是陸沉取得完整本源後，依自身經歷賦予的兩字理解；進階、招式與場域名只描述具體運用。固定句法為：「取得玄寂神雷，完整本源歸入命圖，第四雷位名為歸寂；展開時形成寂界。」

九個本名不是九個孤立的華麗詞，而是陸沉成長次序的五組答案：

| 組別 | 本名 | 名稱所回答的問題 |
| --- | --- | --- |
| 命 | 照命／劫命 | 先看清哪條命路仍在，再決定何者該斷、何者必須續下去 |
| 魂與死 | 鎮魄／歸寂 | 鎮魄使每一道魂回到自身位置；歸寂只讓互相撕扯的災亂沉下，不把生命一併抹除 |
| 界與身 | 鎮界／空手 | 鎮界守住萬物可變而不失其位；空手在外物盡失後，確認自身就是最後的承載之器 |
| 時與命火 | 剎那／燃身 | 剎那尊重時刻交接後縮短抵達；燃身支付肉身與力量，卻必須替求生保留回返路徑 |
| 責任 | 天譴 | 能降罰不等於該降罰；名字指向公開罪證、判斷責任與判錯反灼 |
| 九雷之外 | 無始 | 不是再收一雷，而是承認所有失去之後，仍由自己重新開始 |

驗收標準：讀者只看名字便能回想取得故事的核心選擇；名字不直接洩漏完整招式，不與守關者、伴星或兵器共名，也不靠「神、聖、帝、至尊」等強度字眼冒充分量。

### 二之二、雷色與強度判定

雷色是法則顯化，不是由弱至強的固定品階。同一種完整異雷會因持有者境界、掌握程度與場域展開比例改變純度、核心色與異象，不能僅憑「黑、紫、金」判定勝負。

持有者能發揮的雷霆強度統一由五項判定：**色澤純度、雷光凝實度、雷聲延遲、環境異象範圍、法則作用的不可逆程度**。初掌多為散亂雷弧，進一步形成固定雷紋，再逐步開啟局部雷域與法則異象；直到承載足夠，才可能讓一片天地短暫服從該雷劫序。

| 雷種 | 主色與核心色 | 固定視覺語言 |
| --- | --- | --- |
| 照命／煌命 | 銀白，進階後含淡金 | 照出命光、災點與虛妄裂痕；不是審判之金 |
| 劫命 | 暗紅紫，伴血色細線 | 雷線如命脈被截，命中後外援與氣機逐段熄滅 |
| 鎮魄 | 靛青，內含銀青 | 雷聲低沉如鐘，魂影與心魔被壓回本位 |
| 歸寂 | 深黑，邊緣僅餘暗紫 | 光與聲先被吞沒，雷落後才出現無聲黑痕 |
| 鎮界 | 玄黃土金，裂處呈黑金 | 雷紋如界樁與山脈，先定空間再承崩壓 |
| 空手 | 熾白，淬體後可留黑色肉身雷紋 | 白雷穿行骨、筋、血、脈；黑紋只記錄承劫傷痕 |
| 剎那 | 青藍，帶銀白殘像 | 人先至、雷後鳴；殘像呈錯序而非時間倒流 |
| 燃身 | 暗紅轉金紅，燃盡處灰白 | 血骨如炭火重燃，越明亮代表代價越接近不可逆 |
| 天譴 | 冷金，核心熾白 | 雷路沿閉合罪證與因果落下；不得與煌命淡金混用；冷金與荒的暖金／熾赤大道之光需明確區分色溫，避免正文中兩人同場時視覺混淆 |
| 無始 | 近乎無色，極短暫映出諸色 | 不是彩雷疊加，而是萬劫歸源前的無色雷光 |

第四雷的黑色正式稱為 **玄寂神雷**，是完整本源歸入「歸寂」雷位後的主要顯化。「玄寂」表示光、聲、死氣與暴亂法則一同沉寂，不代表它天然高於其他九雷。玄寂神雷的視覺核心是「無聲、無光、吞噬感」的靜態黑——雷落之前光聲先一步消失，雷落之後才顯出無聲黑痕，沒有具體雷紋質感。此黑色與荒的代表色「玄黑」重疊度最高，須以一靜一動做出區隔：玄寂神雷強調靜態的吞噬與寂滅，荒的玄黑保留其開闢、破局的動態爆發感，不得在正文中互相借用描述語彙。

第六雷收服過程中，骨、筋、血、脈反覆被域心本源雷流擊穿並重鑄（見六、第六雷・空手形成），這個煉化過程會在肉身表層留下焦黑雷紋，俗稱「**淬骨黑紋**」——它是陸沉以自身接住空手本源的傷痕，不是另一枚外來雷種。淬骨黑紋是有形的、刻在皮肉表層的傷痕，伴隨可見焦痕與反震裂口，與玄寂神雷「無聲無光、無雷紋質感」的靜態黑在視覺上一眼可辨。淬骨黑紋**不是獨立雷種，也不是第四雷玄寂神雷**，不能使用寂界、沉法或壓制怨念；此傷痕會在陸沉肉身劇烈承雷時隱隱作痛、該處皮肉較脆，不是純粹的力量加成。

旁白不得僅憑雷色或雷紋直接告知讀者陸沉當前的戰力層級；角色靠雷色做出的戰力判斷只能是主觀推測（揭露等級對應 S2 錯誤解釋），必須留有被實戰推翻的空間，不能被旁白追認為準確。

由雷推演出的獨立能力（例如剎那位移、神魂震懾等，見 `docs/WRITING_GUIDELINES.md` 十四）可視需要收斂視覺、不必冠雷字；但玄寂神雷與淬骨黑紋（因需與彼此區隔）、天譴（因需公開執譴、可被驗證）仍須保留最低限度可辨識標記，不適用「不必雷光滔天」的內斂原則。空間類推演一律歸屬第五雷鎮界雷，時間／位移類推演一律歸屬第七雷剎那，不新增獨立的「空間之雷」「時間之雷」雷種。

## 三、名稱規則

- **九個命圖雷位名一律採兩字**：照命、劫命、鎮魄、歸寂、鎮界、空手、剎那、燃身、天譴；第十雷位同樣稱無始。這些是陸沉的個人理解，不是天地榜本名。古籍、榜單與外界人物談論異雷時，應使用界淵銀雷、斷生血雷等完整天地本名。
- 進階名、招式名與場域名不得冒充天地異雷本名或命圖雷位名：煌命是照命雷位的進階視界；寂界是玄寂神雷經歸寂雷位展開的場域；鎖界、剎那踏、餘命燼火、業火天譴與天譴截矛皆是運用或顯化。

- **「雷胚」不再作九雷階段名或現行俗稱**：第一至第九雷一經取得便是完整外部本源；早期只能發揮微小效果，須寫成持有者境界、肉身承載與駕馭不足，不得再以雷胚、雛形、成種、子種、主種、祖種或補齊本源解釋。歷史文件若保留舊案，必須明標已作廢，不能成為正文依據。
- 照命進階為煌命；兩者是同一雷種的不同階段。
- 第二雷正式名是劫命。「截命」只作能力或進階顯化，不作雷種本名。
- 第五雷本名鎮界，鎖界是對敵運用。
- 第四道天地異雷本名為玄寂神雷；歸寂是命圖第四雷位名，寂界是場域顯化，三者不得互換。
- 第六雷本名空手，外界本源存在於無兵雷域核心；陸沉須以自身走到域心並完成煉化，不能再寫成雷種完全由體內憑空生成。虛渡與其形成、進階及底層法則皆無關。
- 第九道天地異雷本名為刑衡天雷；天譴是命圖第九雷位名，天譴截矛只是兵器顯化，不是另一道異雷。
- 第十雷本名無始，無始劫天是十雷總歸一的終極顯化。

## 四、取得節奏

| 雷 | 專屬雷境 | 主動追雷與取得故事定位 |
| --- | --- | --- |
| 照命 | **界海雷淵**（上下界交界雷界） | 百斷山雷火建立承雷資格；下界守閣後陸沉主動追殘雷入界隙，在雷淵取得照命初期，穿越界壓後穩定運行。這是由被雷追逐轉為主動追雷的起點 |
| 劫命 | **補斷生雷池** | 洛氏祭脈只打開取得關；陸沉循被截斷卻未散的命光主動追池，先因把「延續」當成一律正確而失敗，再辨明何者該斷、何者必須留下 |
| 鎮魄 | **雷魂池／雷魂域**（太玄雷魂秘地深層） | 七峰大比只提供接觸線索；陸沉交換情報並主動申請入域，兩度誤把鎮魂理解成壓服，最後逐魂辨名、保住各魂歸位才取得鎮魄 |
| 歸寂 | **無聲雷池／死寂雷域** | 陸沉辨出每九息沉默的寂雷線索後主動放棄短路追入；先因抹除萬物節律而被逐，後只沉下互相撕扯的災亂，從外部雷池取得歸寂 |

| 空手 | **無兵雷域** | 陸沉因追查能斷外物依賴的雷種而主動前往；雷域剝奪兵器、法器、陣盤與外放術法，核心空手雷種只承認以本身走到域心者。洛生衣受困使時限惡化，但不是偶然生成雷種的來源 |

### 四之一-C、CP兩層論證（2026-09-12 新增，回應 `CHECKLIST_PENDING_DECISIONS.md` 第161題）

陸沉承受的修煉難度遠高於正常天驕，若簡化成「難度越高、戰力越高」的單一倍率關係，會直接破壞既有戰力階梯與同代角色平衡。正確理解方式是拆成兩層，且**兩層都不得使用具體倍數或百分比**（呼應十之二既定呈現鐵律）：

- **第二層：可能性空間**——雷數越多，雷與雷之間、雷與陸沉既有體系（神識、禁制、陣法、傳送與空間道標、肉身、雷電煉器、雷池網、後期命圖與四伴星）能組合出的戰術可能性越大。九雷真正的份量不是「九份傷害相加」，而是九種不同性質的雷與陸沉既有能力形成的組合空間——這一層才是接近指數增長的部分，且只描述「可能性變多」，不代表每次都會被用到極限，也不代表可以無視第一層的戰力階梯上限。

### 四之一-D、修煉環境與效率的正向循環（不得用來讓陸沉突破快於荒）

雷池、雷域、雷界不只是「取得一顆雷種的副本」，也是貫穿陸沉一生反覆使用的修煉生態（完整世界觀延伸見 `systems/SYSTEM_THUNDER_POOLS.md` 四）。其正向循環為：更多雷種 → 雷身更強 → 能承受更高階的雷池／雷域／雷界 → 修煉效率提高 → 雷身重新達到當前階段的圓滿標準（見四之一-B「舊滿皆非滿」）→ 能承受下一級環境。

**硬性排除**：這個循環只解釋陸沉為何能在難度幾何上升的情況下仍跟得上既定進度，**不得用來讓他在正式境界對照上超越或快於荒**——`WRITING_GUIDELINES.md`「幾乎每次正式相遇，陸沉名義修為低荒一個小境界」的既定節奏維持不變。正文呈現時只能質性描述環境的兇險程度與陸沉承受力的變化，不得出現具體修煉量或效率倍數的換算式。

### 四之一-B、舊滿皆非滿（2026-09-12 新增，使用者裁定「給個讓劫能很強的方向」）

> 每多取得一種新雷，舊雷不會變弱——但舊雷「圓滿」的標準會被重新拉高一次。陸沉的強大不是把新雷疊在舊雷之上就結束，而是新雷的到來逼著他重新審視所有舊雷，讓每一道舊雷都有機會被推到比昨天更深的一層。

## 五、共通限制

- 每雷必須先有需求、條件與代價，不得作臨時解題能力。
- 取得完整本源不等於完整掌握；穩定、進階與場域展開描述的是持有者掌握程度，不是異雷本身殘缺。
- 雷種不可消除對應劫數的代價，只能讓陸沉有資格承受並理解。
- 無始不能無代價復活死者或任意重置世界，只能作用於已被命圖納入的區域與因果。終局中，無始一度讓陸沉有機會回到沉雷谷滅族以前，但會抹除後來與洛生衣、太玄宗、四伴星及荒共同經歷的一切——他主動拒絕這個回到過去的**誘惑**，選擇在當下重整失序世界，第十雷因此真正形成。正文須明確寫出他拒絕的是誘惑本身，並未真的執行重置，不與本條限制矛盾。無始展示給他看的只是一條「回到最初」的可能性映照，不是他已擁有任意重置世界的權力。
- **正文落點（Volume11 ch045～048）**：陸沉先完整公開左耳失聰、胸前舊裂、九星互斥、雷身記憶倒灌、面孔流失與可能死亡，不再替同伴刪減風險；此處明確回收仙王看穿「你不是會算，你是怕死」，指出藏住恐懼也會藏走他人的判斷權。其後正式拒絕的不是「沒有痛的世界」，而是由單一承載者替所有已存在者重選人生。回溯從未啟動。白光倒灌後九雷仍各自完整，陸沉主動拆掉唯一主軌，由兩具雷身分組承載，不能再以固定次序同時擠入本尊；第十空位亦沒有天雷補入。普通抄錄、七席及四伴星互不相同的自主選擇先行承壓，無始才由未消失傷痕、矛盾共同記錄及最底層生種自行落定。它把仙王所授「預知敵人會走到哪」的第一道禁，推至「限制自己不能替所有人決定往哪走」的最後一道禁；極致肉身仍是最終兵器，卻不再是無限代價。此階段只能重開雷序，不能恢復傷勢、死者、姓名、苦味或完整記憶，十雷劫序仍待最終幕完成。

> 無始不是回到從未失去之時，而是承認失去之後，仍願意重新開始。
> 他看見一條回到最初的路；拒絕踏上那條路後，才真正得到無始。

## 六、第六雷・空手形成

空手是陸沉主動追入無兵雷域取得的第六枚本源雷種。雷域核心確有外界空手雷種，但它不接受法器、術法或他人力量搬取，只有以本身走到域心者才能接觸並煉化。

形成地為 **無兵雷域**。此地以雷意排斥一切外物：法器越強，承受雷擊越重；外放術法、護甲、符籙、陣盤與儲物法器會逐步失效。它真正排斥的不是兵器，而是依賴；域心本源雷種也正因這條規則長年無人能帶走。

陸沉進入後，萬劫兵胎被壓制，外放雷法被撕散，《無相離身卷》的虛渡亦受空間雷壓限制。他只能以血肉承雷，使拳、掌、肘、膝和整副肉身成為雷路。骨、筋、血、脈反覆被擊穿並重鑄後，他才有資格接住域心本源，使外界空手雷種與自身肉身雷路完成煉化；不是由體內憑空誕生。

其肉身雷路的運轉原則是「骨承壓、筋傳力、血運雷、脈載劫」。雷不必先化成劍、矛或雷海；只要肉身接觸敵手，雷便能沿對方的發力結構逆入，打散肩、肘、腕與軀幹之間的力量傳遞，使敵人的攻勢由內崩散。故空手不是拒絕兵器，而是不再依靠兵器定義自己：身無一處不是兵，觸敵一寸皆可落劫。

初成的空手難以留力，觸碰兵器、陣紋甚至同伴時都可能本能尋找結構弱點，陸沉自身也要承受同等反震；他必須重新學會如何觸碰與收力。這項限制使空手不是無條件破法，更不能免除近身接觸的風險。

骨、筋、血、脈反覆被擊穿並重鑄的過程，會在肉身表層同步留下焦黑雷紋（「淬骨黑紋」，見二之一），與本源雷種入體煉化是同一場收服過程的兩面，不是另一次獨立事件；外來的是雷種本源，真正使其成為空手道路的仍是陸沉親身承雷。

此行與他同行的是洛生衣。雷域切斷丹藥、法器、陣盤與外放生道後，她被困於崩塌雷層中，只能以自身生機暫時維持傷勢，不能替陸沉破域。陸沉因此沒有等待萬劫兵胎恢復，而是以血肉打穿雷域救她。洛生衣的存在提供必須立刻抵達域心的理由；本源雷種來自無兵雷域，最後承接、煉化與付出肉身代價者仍只有陸沉。

> 兵可斷，器可失，劫不可卸。

空手不否定萬劫兵胎。兵胎把殺伐效率推到極致；空手證明即使失去所有外物，陸沉自己仍是根本之兵。

### 六之一、制勢指——空手的深化具名招式

取得完整無兵白雷後，經第九篇命圖初成、第十篇天神書院、第十一篇帝關初戰等大量實戰磨練，陸沉逐步完成「重新學會觸碰與收力」的成長弧線。第十二篇「十凶血路」Volume09 ch025～028中，他先以空手誤傷聞硯右臂三條主脈，再重組多年近身判力與救援搬運經驗；聞硯短暫清醒時親自指出肩、肘、腕發熱次序，並提出「不能運力，不是不能活」的停手界線，洛生衣與顧小滿分別護住命線、承接倒地，才完成空手的精度版本：錯開對方力勢，使其無法運力但不傷經脈根本，正式命名「制勢指」。

制勢指只解決「如何不殺地介入救人」，不是天譴執譴資格的捷徑，也不用於直接制服司天鑑。Volume09 ch030～039另行完成主動入刑衡雷界、承接群體命線、不逆返本命刑罰、問罪雷劫取得天譴後首先不落雷，以及司天鑑自承反噬並放下令牌的獨立因果。

## 七、第四、第五雷與蒼梧（2026-09-12 改版：界潮／古界，取代死寂雷域版本）

歸寂與鎮界屬同一段追雷遠征的前後兩層，卻有不同本源孕床：界潮只提供追殺與合作的線索，本身不孕育雷種；歸寂本源位於界潮深處，鎮界本源位於界潮之後正式進入的千年古界。兩雷功能與取得故事不可混用，也不能因時間相連便寫成一次獲得兩雷。此版本推翻舊有「死寂雷域」場景，完整敘事見 `events/EVENT_DEADSTILL_DOMAIN_XUANHENG.md`（現行標題〈界潮、古界與定疆雷界：蒼梧同行〉，2026-09-23已隨全庫改名同步更新）。

前段，陸沉與封寒（`characters/CHARACTER_FENG_HAN.md`）強行闖入界潮奇異點，蒼梧依巡查秩序的既定邏輯判定二人是非法闖入者，展開追殺——這是執法邏輯而非災源誤判。三方因界潮持續惡化被迫合作，陸沉、封寒證明自己願意承擔穩定界潮的代價，蒼梧也承認「依令行事」與「抓對真正的破壞者」未必是同一件事。此時不形成新雷，蒼梧只停止敵對。陸沉其後主動追入界潮深處，首次因抹除所有節律而失敗，改為只沉下互相撕扯的災亂後，才取得外部歸寂。

後段，三人一同進入千年一遇開啟的古界——歸寂只能讓暴亂停止，鎮界要求陸沉在持續變動的古界結構中守住相對位置、出口與可變邊界。陸沉第一次誤以為「穩定＝不准動」，試圖固定所有事物反而造成問題，後來才理解真正的鎮界是「即使一切都在變，整體結構仍然不崩」。鎮界本源來自古界內部本源，蒼梧與界潮殘雷都不能養出或替代它；永久界痕則早在界潮作臨時界樁時留下，取雷首敗令其再度崩裂。蒼梧在陸沉拒絕把他留作永久界樁後結下伴星命印；待太玄命圖形成可辨識骨架後，才正式占據外環。蒼梧的登場與加入外環時間點不變，仍固定在三千州天才戰後（Volume04）。（2026-09-12訂正：原「禁都之前」定位語與 `MACRO_OUTLINE.md` 已確立的禁都排序矛盾，予以刪除。）

> 歸寂使災停止暴亂；鎮界使破碎世界重新穩定。
