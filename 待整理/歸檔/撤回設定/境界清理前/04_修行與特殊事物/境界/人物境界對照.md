# 人物境界對照

> 2026-09-28 版本註記：本檔先前提出的築基／金丹／合道／金仙／仙君等境界體系已由作者撤回。現採搬血→洞天→化靈→銘紋→列陣→尊者→神火→真一→聖祭→天神→虛道→斬我→遁一→至尊→真仙→仙王→準仙帝→仙帝；聖祭為特殊過渡階段。下界使用法力，無法直接運轉仙力，真仙突破需仙力條件；當代本土高層為天神，少數達虛道。人物境界、器物分級及相關招式限制尚待按新體系重配；以下舊標註僅供修訂對照，不作現行定案。降臨境界上限仍未定。

本輪以人物正在參與的事件為時間點，不將同一人的後期境界倒灌到早期。主角群不在此次分配範圍。

| 人物 | 故事位置 | 採用境界 | 能力位置 |
|---|---|---|---|
| 祁宗岳，太宸仙帝 | 上古大戰 | 仙帝 | 改變戰局，封界仍需外部條件與代價 |
| 祁承晏，仙帝長子 | 上古遇害前 | 仙王初期 | 查案止戰、保護與統合；非無敵繼承人 |
| 祁承朔，心機皇子 | 上古設局時 | 仙君圓滿 | 擅長遮蔽、切斷術法聯繫，須藉兩位仙王同謀才能對付兄長 |
| 烏蘅，異域公主 | 上古遇害前 | 仙君後期 | 遠射、護送與擊破敵方器陣，不以種樹概括整套力量 |
| 商玄度，九強同謀 | 上古大戰 | 仙王後期 | 玄闕王庭核心人物，兵陣與斷路 |
| 厲文恪，九強同謀 | 上古大戰 | 仙王中期 | 長離王庭核心人物，界舟及運路 |
| 裴照川，英雄前輩 | 母稿救災及女子調查期 | 洞虛後期 | 高強修士，有負傷與失手的可能 |
| 裴照川 | 九界主要衝突期 | 合道中期 | 靠後續修行、資源和選擇達到，不能用悲痛瞬間升境 |
| 溫棠，調查女子 | 救災及查案期 | 化神中期 | 辨紋、測流、護送，自主查證而非讀取歷史 |
| 商應璋，九強聖子 | 當代陰謀期 | 金仙初期 | 仙界本體與權力資源；九界投影不具同等戰力 |
| 岑越，九弱聖子 | 當代陰謀期 | 真仙中期 | 仙界本體；下界行走法身上限化神圓滿 |
| 許成蹊，溫棠同門師弟 | 救災及查案期 | 元嬰初期 | 救渡、測繪、複核與保存材料 |

本表沒有裁定古代仙帝是否仍在位、皇子戰後是否繼位，也沒有指定兩位古代同謀在當代的生死。商應璋屬商玄度同族後世一脈，並非其跨越年代的同一身分。
