# 推薦世界方案：巡回船市與有限界封耳

2026-10-11｜主編唯一推薦候選，採世界乙完整底案及獨立比較後的修訂。不是Canon，不覆正式、不解凍正文，豁免五檔未讀審改。

本方案讓九界民間互通的核心成為**巡回船市與地方學問**，而非九個城市每天直飛的船網。商人帶著住家和技藝在同一船市生活多年，停港的人可以上船交換，也可以隨下一段去別界；一個地方終於等到船，不代表所有人都能出發。特殊仙術主要用來讓船市在陌生界外找到仍願意迎接自己的港，不替每位乘客打開随意門。

與一般固定兩港班輪有兩項本質差異：交通利益由九界地方守界者與船市共分，**船市本身是會遷移的生活聚落**，某港拒泊便影響全船人的下一季家業；航線的主要困局是路址與報港失配、地方准入及商人季節生意，不以帝境船長任意穿虛兜底。通訊另採天神時期私用「界封耳」實驗，七個受許可界口各一条細縫，支持九具本人定時有限話語，但明確改D066／D082，不假裝仍完全相容。

## 一、船上的生活比路線圖先成立

候選人物「喬瓷娘」是千根出身的列陣器匠，在船市養兩個孩子，修的是可供列陣以下使用的普通聚聲器、盆種架與駒籠。她在驤鳴港租過三年鋪，女兒在當地學箏，母女卻沒有因此知道鳴珂王庭的軍政內情。她今年想留船，把新做的聚聲器賣到昏曉；女兒想下船學一年。兩人不能用一句「家人要同行」解決。

候選人物「蒲七槳」是船市的領舟列陣修士，能在既核的外層界軌上讀到船偏了哪一段；護舟由船禁、地方港牽引與多人輪值完成，不讓他列陣徒手扛整艘城。他想買下自己住了二十年的船段，卻不肯拿乘客的下一季保費去買。候選人物「翟行硯」是借停港教器紋的小學堂修士；他每站只收當地弟子一門真學問，帶回的是學生也能驗的工藝，非古史答案。

船上有人賣成品、有人修舊器、有人帶病求醫、有人只想見火樹。久住者未必歷遍九界，因為輪值、路費、錯過回港和家人選擇都會改變人生。船市不要求每次停泊都變成陸沉接任務。

### 一次可獨立成篇的船市事件

1. 船市在驤鳴停十二日，萬俟箏來聽喬瓷娘的空盆聲器，發現它保住的只是一聲形狀，不能辨今日鳴石的返路。她買下器，為的是做自己的試驗，商人也清楚說它做不到甚麼。
2. 蒲七槳下一站的舊港照引失去應答，船尾已開始被外層界軌拖偏。他能用船上存量退回驤鳴泊位，但退回後必須等另一段接港，大家的貨可能錯季。喬瓷娘要退，女兒卻说退了也要下船。
3. 船上兩個器匠合修一段已知港牽引，把錯誤照引隔離，不能就地創未知港。翟行硯带實件港牒去岸上詢核；港主不是等主角代擔保，先決定另給一處較小泊位，少装四分之一货，船禁方能承。
4. 船市卸掉喬瓷娘原要卖的重器，换回临岸仓位，所得不是假成品；她取較少貨仍可真販賣。女兒留下，不以船難迫她服從母亲。萬俟箏拒絕替船永久維持聲路，但把自己已核的一夜回聲借给港值守，交接後由本土船禁實供。
5. 這次船市真離港，只有一段舊路恢復。學生的空盆器只學到隔開失真的一声，港也得到一套普通可維修工藝；沒有因此知道帝骨、古界路路身或九界沉落之謎。

## 二、航站、班次、票價與承載

以下全是待採工作數字，**不是現行船班Canon**。不把D130無間航道8倍自動套民船；本案民船外層軌約1倍，航四日就是本人／外界四日。

### 兩條巡回船市

- 一支順行、一支逆行，各按九港順序巡回；每段外層航程工作四日、停港十二日，一圈九段共144日。每支一年兩圈288日，餘77日維修、輪值與壞天候；四日只對已核本條民用外層路尺，不宣稱九界全兩兩四日直達。
- 正常巡回圈內候船0至144日；跨77日維修、壞天候或拒泊須另付停航日，可能超過144日，沒有全年144日必到保障；順逆兩支錯班可縮短，但貨艙／乘額不是無限。從某港去鄰港理想4日，到較遠港要把中間十二日停港逐段相加；一圈不是買票後立刻到。
- 凌汛封凍七月、開河五月，**境內河港與界外泊位分開**。船市可到界外停泊，河岸入港须该季牽引和报水实件；北河口若未报安，乘客留船、不能停船即算已入凌汛。船市另站候泊最多十二日，未核就越站，此界可連續半年無可買的實際入界席。
- 別界的港可拒一季外客；船市失一港就失一段確定補給，不能拿剩餘船禁保證繞到任何目的。目的停港改期由港船本人帶實件传遞，不新增全九界即時航運網。

票價不指定靈石絕對數，與本界普通生活可比較：最短鄰港座席約列陣普通器匠兩月純所得；船上住滿一圈約半年所得另付食藥；搬血／洞天學生有少量地方助席，不能人人免費。普通貨按重、占艙、靈性封存与船禁干擾收费；不許靠低價儲物袋把一座軍陣當一箱日用品。高境無法自行在民船上解印，舱中修为攀升超过准承便须在安全泊位中止，不由船票赦免界壁。

### 准入與下行印

1. **船票只買运输，不買目的居籍。** 源港核身份、承載、目的准件；目的港核入境與攜貨許可，肉身真的跨過界界才登目的簿。每名本人都記，雷身不例外。
2. 天然列陣以下可買普通民間席，須目的愿接。低界本土高境旅人也不能自封入他界，须依法走上端壓境、各人本人印及外钥。故土尊者不能自稱九界居民就免押修为。
3. 已有甲界壓境印者不能拿甲印直接自由入乙界。本案提供**在界外中转泊位重新核目的印**的候選程序：甲源印先送甲上端與乙上端合核，在肉身仍留甲泊位／許可中轉艙時另封目的印、目的外鑰置乙上端；本人不得有一刻裸露高于准承，具体双封怎么交替是新准入機制，**尚未定**。未批准前，高本源壓境者不乘民船跨低界，仍用兩條正規路。
4. 關在上端、未曾壓境的凌汛身不能直接登低界民船。上端只是上端；民船外層艙不是飛升站。若他借別界先下行，必須真获該界錨印、本人下降、再取得凌汛目的准件；沒有紙上一句「绕一船」省掉任何一项。
5. 外界移民需要來源真实户籍、目的限期居許与土地／洞府条件；居期可半年至数年候选，不能代替升境／续印。生孩子、结婚與拥有铺子不自动取消原印约。已在故土定居的他界後裔可以成普通本土居民，不因父母来自異界而都能讀古語或擁有跨界特权。

## 三、界槎、仙術與五種去處不能混

| 所做的事 | 真機制／資格 | 本案沒有授予的東西 |
|---|---|---|
| 本界境內 | 灵舟、近域陣链、御器 | 不把島間靈舟叫跨界槎 |
| 九界民間互通 | 本案巡回船市，源港／目的港／外層界轨与限期准入 | 不免下行錨印、不飞上界、不直达聖土 |
| 九界大比 | 原無間航道、护舟、正式获准乘员，既定8倍 | 民船世俗居籍不等于代表队作业份额；新民船不替原24内日／3外日求生故事 |
| 九界上行／上界下行 | 登天接引、上端錨印核、本人资格 | 買民船票不能让超龄者第一次飛升；文首次上界不提前 |
| 三十二天与聖土 | 稀少界潮低路／真正具備定位存量的高路 | 九港外軌不連聖土窗口，也不因船能跨小界便穿完整天地 |

**界槎**仍是载具通稱；本案船市可用其技术的民用一型，不能偷说所有民船已有大比护道与8倍。特殊仙術给有技藝和存量的高境領舟人做三件有限事：重寻一个已有且愿接的港址、在已核短段失穩時推回上一泊位、在本次存量内牽一艘受限船跨已知外层軌。它不创造对岸，不带未知乘客直入港，不強破拒入。列陣船师负责读轨和禁运转，高境領舟人若在船上超过准承，停在界外许可護航位，不与乘客一同入低界。

「特殊跨界仙術」的機緣可真实可欲：一位領舟人完成自家航術後，不必看王庭每旬上行班次，可以带一小隊依已核九港路自由出行；她仍得知目的、备回程、取得准入，不成为人人无限随意门。此为候選新術，非成熟無間自动新增人群能力。

## 四、凌汛真的嘗試了四條路，仍空手

来源[凌汛界](../../設定/01_世界/04_勢力/04_其他八界/凌汛界.md)已载第15篇「朔河不給」「岑越家人拒絕交易」「該身没有壓境、止於上端」，本輪不读豁免原細節。本案不能让拒入只靠一句新法规，作如下**具体候選冲突弧**；不声称已经是原稿事实。

1. 他在朔河津本人提交救生事由與足價，岑家知其身份，拒供指定份額及下行。朔河认为不是普通材料買賣，是既有案怨；桂暄之類地方醫者可以不同意拒药，但没有目标成熟份额的处置权。原拒绝的责任清楚属于人，不属于「界壁恨主角」。
2. 他实去上端民船联售铺，买一张可退的另一界入泊预约、付查验费，询问从千根或昏曉转凌汛。掌船者提供源界可核的普通票，却查出凌汛目的准件明确不收**本次指定救生买家本人**；他要求只作商旅。准入仍拒，因为指定拒入与买家的源气机已在本次联售查验中由朔河具名提供，不是所有港即時全网黑名单。他未获首个中轉完整票，不下降、不新增第八枚印。掌船者退款票价、不退实际查核人工和已花的候班时间。政治目的准入规则是候选，不冒称D065本来已有这条。
3. 他不放弃，請在下端有真的铺子的天然低境船商代理买药；纸契经人下行、代理确实跑到当地库。可以买到普通治冻药和往年样材，指定救生份额却是本季成熟、已登记归岑家处置的一批，族人逐项拒售、拒以普通样材替换。**封泥可以保性**，因此失败不能归因「任何材料都无法运出」；真实失败是目标材料根本没买到。代理把空封泥盒、正式拒交易书和普通样材带回，陸承认样材不能代目标，不骗本尊已得药。
4. 他请一位拥有有限领舟仙術的修士，出价带自己去澌臺外泊位，并付一次目的问泊定金。领舟人答应问，不答应偷入；目的实件答覆到手后拒帶，他可以在界外看见北河口的雲色却不会有取材的入境地点。領舟人若強帶，本人無印高源会被界壁剪，不能用船禁代錨印。他没有买下仙术当免费破解。
5. 最後他本人向具名上端下季分採受理處提出公開詢問，G86遞函、87–96境內到處、97–106實收拒件、107–116親攜返匯件處；不再另指七界中某一身代詢，不讓任何身替自己造第八條成功。答复是下一成熟季可谈一般买家，但岑家仍不供**本次救生**目标份额；临床处方要求的该季份额不因此从明年倒流回来。他带回完整拒件及真损失，药仍一份没有。不是世界永久禁绝任何其他材料，而是这个人、这批材料和这次救生真正失败。

### 本次凌汛外部排程候選
採出發後本人上端求路，不用尚未發生的救生事由預詢。G1–10本人正常到朔河津受理，G11–20聯售實查並退款，G21–30有限領舟人本人問泊、目的拒件實到；均為上端本地已核行路，不假跨低界當日答覆。G31代理「衣穗」（新候選、天然列陣）持紙契出發，32–41候合法旬班，42–47本人下降六日，48–53本地跑庫查指定批，54–59返站，60–69候上行，70–75六日上行，76–85上端普通舟驛，G85將拒書、空封泥盒與普通樣材真交本人。這是單條醫藥代理候選路尺，不是全九界六日通行定律，班位及兩端許可列待作者採案。G86本人同界遞函，87–96到下季分採受理處，97–106取得對本次買家的正式拒件，107–116本人攜件返醫療匯件處；不假另一身已跨界代詢。第5步改由這次具名上端受理處實詢，不製造第八成功。
**這116日只閉合拒售支路因果，不證救生總壽限或其餘七路日帳。** 指定成熟批及樣材不合仍是待採醫藥接口；原七入一失、七印、九身合爐、八撕痕與生昏迷不改。

世界热闹与失败可同场：旁边衣三叔的侄女拿着普通求学准件，有望登一张便宜助席；救人的强者却买不到一批被人拒卖的材料。没有因此禁止衣苗自己的生活，也不让陸沉挟持她入界。

## 五、真支持九身定時有限話語的Proxy候選

### 這次真改了甚麼

现行[交通／D082](../../設定/01_世界/01_天地結構/機構與跨界交通.md)规定九界间及九界上界无網、**跨界一律走人，不用短码**，雷讯网为后期候选。以下「界封耳」明确提议新增：**在双方准许的固定讯位与专用接转分站一对实体器具之间，允许闭门状态下有限声码越过界壁**。不是只说「Proxy」就当已有规则；采用后须改D066、D082的绝对句，保留一般公文和物体走人。本案不让同本源直接越壁读念，技术效果是发话者自己说话、器具测成有限声码、对面器具复述。

### 實器、天地層與本人部署
上下無極同屬三十二天不同層，正式已有跨層仙路；第八對跨的是層，不是三十二天與聖土等完整天地。本人實運用合法仙路，四日醫舟班程在另一候選明列；聲碼仍須逐端新許可與實測，不能以同天地為由省掉跨層延遲。

### 它沒有提前變成雷訊網

界封耳只在七对获准下界固定讯位↔下無極新增接轉分站及第八對上下無極醫站實器、只对预制对应码页起效；是固定實址配對，不是沿原古界路口自动成網；通用雷訊网仍是后期候选。为甚么早期没人这样做，候選理由有两层：界路两端政治上不许私人开口；技术上本雷身共源的有限声码可由七种界封都认同一套发话签，却不能保证任意陌生人之码可穿过去。**这一层必须经故事实际试炼和作者采用，不能把「独有」当不用验证的万能钥匙**。普通民船与普通修士仍带书，商人不能花一张票就盗用这七对医用私器。

得知「山跑了」「药买错了」「门没进去」使本尊能问真实问题，不能让他立刻掌握山的地形、错药全配方或拒入的全部官史；各身收到别身描述也只知道其说出的128字，不共享现场记忆。需要图式时只可付字额传一张8×8点位图的有限摘要，不影像、不完整功法；若作者坚持更大图式，应另裁增加容量而不能藏在「推演」一词。

**采用后的危机重写**：原靠单条「勿来」迟到的医路选择要逐场核，不得保旧误会又让即时话可问清；深远在地路者离固定讯位仍会真迟讯，作者可保合理迟讯。真材料、庾凝全文、药方签批、医疗复杂过程仍不能128字传完。旧等信危机须是本人不在固定讯位、线路被毁或需要全文，不能无事装作不能问。

若不批准界封耳，九界间／上界继续只走人；以书吏在七口轮收实件，上端近域节点汇总后到医床。可有定时上端**整理会**，凌汛身和本尊对真正已抵的文件交流；七界的回答来自异夜并有送达日期。七身不在同一会期现场，因此明确牺牲母稿九身同夜插话，仍保128字有限知情、融合完整交换与导气不停。共天那一月只帮助九界之间全文，不能接上端医床。

**历史不能靠「都不知道」一句护住。** 商人可售公开本地史、互相争论古碑残字，有的猜对、有的说错；民间亦可有「九界从高处落下」传闻。所缺是同一天同一批地块的原始序号／帝批附册／撤护持责任与完整古语互证。民船港的本地年代册近几百年、没有八万年前军阵原件；官方重抄的史和民间残文可互相不合，所以走船不自动拿到标准真相。

D062仍要求陸沉到上無極才第一次知道故土天冊原名；票／商人正常稱「你那一界」「留舟港」「東溟」等，不把設定方便称长亭天放进儿童嘴里。若有跨界商人恰持包含原天名的古货签，必须作为真正提前揭露候選待裁，不能稀里糊涂偷给。居民知道另界真实生活却不知道完整宇宙，是地理／政治／历史不同深度，不让他们每卷重新失忆。
