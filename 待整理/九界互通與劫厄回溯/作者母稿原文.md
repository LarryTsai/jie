# 《劫》｜九界互通與劫厄全書回溯審查

**狀態：作者候選重構母稿；尚未修改 GitHub 正式設定。**

## 一、重構核心

這不是在故事中多加幾句小龍叫聲，而是重新檢查每一場戲：**劫厄一直在，牠會看見什麼、想做什麼、改變什麼？** 牠不是道具，也不是單純的雷法加成。牠是陪陸沉長大的生命，具有自己的感情、恐懼、偏好、戰鬥與選擇。

第二項修訂：**九界可以透過跨界法船／界槎與特殊跨界仙術互通**。陸沉成長的故土有異界商人、天驕、修士、器材與故事；居民知道九界與上界存在，但不知道上界的真實結構、故土天冊原名及八萬年前的墜界陰謀。九界民間交通、九界往上界的登天接引、上界下行的錨印、三十二天往聖土的界潮，必須分開設計。

## 三、九界交通新方案與硬衝突

| 交通 | 新提案 | 保留限制 |

| 本界內 | 靈舟、傳送陣 | 費用、路程 |

| 九界→上界 | 登天路 | 接引、境界與資格 |

| 三十二天↔聖土 | 界潮低路或高路 | 窗口、承載、補給與封印 |

**P0 衝突：**《九界金丹》凌汛雷身在上端朔河津被拒入界。若九界間有民船，為何不能繞行？必須提出有因果的法律、材料、身份或航線限制，不能直接保留舊版「無法進入」而不解釋。世界認知時間線、九界大比、八界王庭、舊界路、跨界傳訊均須重審。

**雷訊 Proxy（候選）**：陸沉與文奕在八身出發前研製中繼法器，支持九具身體定時神識夜議、短訊、推演與求援；不能因此即時同步完整記憶修為、傳送藥材或免費跨界。現行遠距傳訊需要節點，故須核定中繼、消耗、截聽、延遲與故障。

## 四、全書「劫厄在場」審查矩陣

逐篇逐章建立下表，必須有來源路徑與原文依據：

| 欄位 | 審查問題 |
|---|---|
| 時間／篇章 | 此時牠已誕生、沉睡或成熟？ |
| 所在位置 | 肩上、指骨、留守、同行、劫藏？ |
| 牠知道什麼 | 有沒有超前知道古史、陰謀或其他人內心？ |
| 牠如何表達 | 叫聲、動作，還是已解鎖完整人話？ |
| 自己的選擇 | 好奇、親近、抗拒、恐懼、堅持？ |
| 戰鬥改動 | 示警、吞厄、劫吼是否改變原本勝負與撤退？ |
| 朋友關係 | 與生、瘋、雲、文、師父、故人、靈獸有何累積？ |
| 成長代價 | 休息、受傷、暴走、首次成功、真敗？ |
| 處置 | P0 硬衝突、P1 大場景缺失、P2 日常、P3 不改 |

**審查不是要求每章牠都出風頭。** 重要的是牠始終像活著的同行者；有時只在肩上看，有時回指骨休息，有時反對陸沉，有時真正改變戰鬥。

## 五、逐故事群回頭重寫的方向

### 1. 童年、留舟島、伏雷坳、太玄閣

十歲後家人怎樣照顧小龍？牠第一次回指骨休息、第一次受傷、第一次護住陸沉；坊市小孩會不會把牠當奇獸？陸沉修符紙靈鳶時牠會不會好奇？不能讓島民提前看穿古劫起源。

### 2. 太玄宗、藥閣、宗門大比、四人小隊

牠何時認識洛生衣？生可以研究牠卻尊重牠。封寒對未知有興趣，不能把牠當工具；雲行與牠有獨特的禪修與生命交流；文奕可設計小法器；岳沉淵和師兄姊要有真正相處。比賽時牠出手是否違規，必須核對。

### 3. 五域／九界大比、禁都、南荒四幕、北天行

牠能感斷處，不等於破解所有禁制、揭穿所有陰謀。與其他界天驕、異族和靈獸形成交情。南荒千相與北天的異常環境，應對牠的能力、疲憊或認知留下後果。

### 4. 西極地獄行

西極是雲行主場，雲帶劫、瘋、厄見故人、遊雪寺、萬獸原、草原酒館。獸族會如何看一條沒有龍血的劫龍？牠能感同源劫痕，卻不能替三人解出亡者心願或直接定位震魂雷。

### 5. 第一次聖土：索爾、伊萊恩、莉森娜、馬杜恩

厄作為無核之獸引起當地人的好奇；百國燈夜、雙刃練習、鍛刀、離別都有牠的反應。莉森娜可記得這條小龍，後續重逢能回收。此時牠仍不能完整說人話。

### 6. 九界金丹／八身救生

**生在八身行動期間昏迷，不得醒來參加夜議；本尊雷導氣續命一刻不停。** 厄陪在床邊，會好奇雷訊法器，也會等待生醒。八界取材有簡單打怪、直接購買、拍賣、故人相贈、古遺跡、兩具雷身聯手奪材、凌汛真失敗；難易不同，不可八次同構。新 Proxy 若縮短通訊延遲，原大綱靠延遲成立的危機須改寫。

### 7. 兩訪驤鳴、先返太玄、跌境重修

第一次《九界金丹》雷身認識萬俟箏；融合後本尊記得。新候選為跌境先回太玄親歷守山，再主動赴驤鳴。**此時厄已在第22篇伴命後沉睡**，不能突然出來聊天、作戰；萬俟箏發現昔日肩上小龍不在，是非常重要的情緒場景。生剪節須分清死節與沉睡的厄。

### 8. 第二次聖土、異域臥底、悟道茶會

第19篇厄籠中一夜、第20篇人形與語言成熟。異域臥底時黑紫劫龍是否暴露身分？藏指骨是否影響戰術？悟道茶會是否能公開現身？都需重審，不可因熱鬧破壞偽裝。

### 9. 第22篇大敗、第24篇歸來、終局

唯一伴命須靠前面長年相處才能有重量；成熟歸來後要有自己的戰鬥、朋友重逢與修行變化。第28篇守伏雷坳是牠自己的選擇，必須在更早篇章反覆種下故土牽掛。

## 六、四個候選正文場景（供改稿參考）

**藥閣初識。** 生看著陸沉肩上的小龍：「你帶了什麼？」陸沉答：「厄。」她說：「我是問牠是什麼。」陸沉想了想：「還在查。」小龍嗅了嗅藥草，打個噴嚏，爐腳溫紋微亂。生換一株藥草，小龍卻主動湊近。她笑道：「原來牠也會挑。」陸沉才發現自己一直研究牠能做什麼，卻還不知道牠喜歡什麼。

**九雷夜議。** 生始終昏迷，陸沉雷導氣不停。懸岳傳訊：「山跑了。」千根：「藥買錯了。」凌汛：「門沒進去。」厄伸爪按上雷訊子印，八路雜音齊起。本尊把牠抱回來：「你也要開會？」牠沒有回答，只伏在生手邊，輕輕碰她的指尖。她沒有醒。牠仍等著。

**第二次驤鳴的空位。** 萬俟箏看見陸沉搬引雷木，先認出他，再看見肩上空空的。「你那條小龍呢？」陸沉答：「睡了。」「睡多久？」「不知道。」她沒有再追問，只帶他走到初學者鳴石前。「當年你嫌這裡的聲太慢。現在呢？」陸沉把手放上去，等到第一聲細響：「現在，剛好。」

**師門日常。** 岳沉淵把桌上的測雷珠移開：「看可以，別吞。」陸沉一愣：「師父怎知道牠想吞？」岳沉淵道：「你小時候也這樣。」厄聽不懂所有字，卻看得出兩人笑意，尾巴一甩，把雷珠推回桌中央。

## 七、交付 AI 團隊的工作順序與驗收

1. **Continuity Agent**：逐篇逐章完成劫厄在場矩陣，找出「牠應在卻消失」「牠不該在卻出現」與知情、語言、戰力衝突。
2. **World Agent**：設計九界跨界法船、跨界仙術、異界移民與貿易；對照原交通與認知設定，特別解決凌汛拒入。
3. **Character Agent**：從十歲到終局建立厄的關係、喜好、恐懼、成長、獨立決定時間線。
4. **Power Agent**：逐戰核對斷處感知、吞厄、劫吼、休息與代價；不能靠厄抹掉原本真敗。
5. **Chapter Editor**：按 P0→P1→P2 排序，逐篇提出具體插場、重寫場、對話與篇幅；保留原精彩故事，不以一句摘要取代。
6. **Independent Reviewer**：檢查厄是否像真正的生命、是否搶主角戲、是否讓所有謎題變簡單、是否破壞後期唯一伴命。
7. **作者裁定後才修改 Canon**：先交變更清單、時間線、依賴關係、正文差異、風險報告；確認後再按卷逐步回填，最後跑全書連續性檢查。

**驗收標準：** 每一大篇都能回答「厄當時在哪、做了什麼、為什麼、留下什麼」，每一個重大戰鬥都核對牠的能力是否會改變結果；不能讓牠只是偶爾露面的寵物，也不能把牠寫成萬能答案。九界交通要使世界更熱鬧，但不能讓所有界壁與境界制度失去意義。
