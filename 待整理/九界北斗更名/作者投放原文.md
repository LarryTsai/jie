# 《劫》｜九界更名：北斗九星方案

> 狀態：作者於本次討論選定的**命名方向**；供 AI 團隊同步 GitHub 使用。本文不是已完成的 GitHub 修改紀錄。
>
> 核心原則：**只更換九界名稱，不變動地理、文明、宗門、人物、境界、歷史、通行規則及既有故事因果。**

## 一、九界新舊名稱對照（採用）

| 序 | 原名稱 | 新名稱 | 已有世界特色 |
|---|---|---|---|
| 1 | 長亭天（陸沉故鄉） | **天樞界** | 五域、天域、太玄宗，陸沉成長的故土 |
| 2 | 凌汛界 | **天璇界** | 七河、逆流河、季節河道與通行爭議 |
| 3 | 昏曉界 | **天璣界** | 長夜火樹、星燈與歸宿宗 |
| 4 | 懸岳界 | **天權界** | 浮海群山、遊山與錨山 |
| 5 | 蒹葭界 | **玉衡界** | 淡澤、石蓮臺、藥圃與藥道文明 |
| 6 | 千根界 | **開陽界** | 冠層、幹層、根層三重巨木文明 |
| 7 | 望歸界 | **搖光界** | 十二渡、異域後裔與口傳七家 |
| 8 | 驤鳴界 | **洞明界** | 七帳、鳴石、雷池、騎陣與傭約；陸沉後期重修的重要舞臺 |
| 9 | 霜明界 | **隱元界** | 古冰凝影、讀冰與守鏡臺 |

**九界完整名稱：天樞、天璇、天璣、天權、玉衡、開陽、搖光、洞明、隱元。**

## 二、命名意圖

採用北斗九星的名稱，使九個原本同屬三十二天、後來被打落的天地擁有簡潔、統一、古老而具仙道氣息的稱呼。此方案採用「洞明、隱元」作為第八、第九名，不使用「左輔、右弼」作為本次九界正式命名。

- **天樞界**：陸沉的故鄉；「天樞」有九星之首的語感，**不表示此界必然最強或掌管其他八界**。
- **洞明界**：保留原驤鳴的雷池、鳴石與重修故事；名稱與陸沉重新洞察自身大道形成文學呼應，**不新增特殊洞察神通**。
- **隱元界**：保留原霜明的古冰、凝影與歷史疑雲；**不因名稱而直接指定其藏有最終真相**。

其餘六界同樣保留各自原有文明，不能因星名而改造成九個單一屬性的元素世界。

## 三、世界觀邊界

1. 九界原本是三十二天的一部分，八萬年前的歷史與打落因果沿用既有設定；更名不自行增補歷史真相。
2. 九界**不自動對應九雷**；不得因九星命名新增「九星陣」「九界合一神通」或命定九雷位置。
3. 九界仍是彼此不同的天地，既有界壁、錨印、合法通行與跨界成本不因更名改變。
4. 九界居民、上界文書與古天冊究竟何時使用新名，屬敘事用名同步問題；**不得未經作者批准新增雙層正式命名體系**。
5. 「長亭天」若在既有八萬年前古天冊、天名、古文原句中具有歷史證據作用，先標記並請作者確認應替換成「天樞界／天樞天」或保留為歷史舊稱，不可無差別全域取代。
6. 「驤鳴」若也是雷池、地名、篇章標題或本地文化專名的一部分，不得因「驤鳴界→洞明界」而全部改掉。其他舊名亦同。

## 四、對既有大故事的名稱影響

| 故事 | 更名後應如何稱呼 | 不得改動的內容 |
|---|---|---|
| 少年故鄉、太玄宗、五域大比 | 天樞界的故土故事 | 五域與天域地理、太玄宗及人物關係 |
| 《九界金丹》 | 八具雷身分赴天璇、天璣、天權、玉衡、開陽、搖光、洞明、隱元八界 | 原取材路線、凌汛未入界的失敗、救生時限與洛生衣昏迷續命設定 |
| 驤鳴重修 | 洞明界重修；篇名《驤鳴》是否保留由作者決定 | 赤翎、萬俟箏、賀逢山、辛照晚、雷池、雷鯨及重修因果 |
| 太玄宗守山 | 陸沉先返回天樞界太玄宗 | 作者選定「跌境先返故鄉、再赴洞明界」的方向與待解交通規則 |
| 八萬年前九界歷史 | 九界新名稱可作現行稱呼 | 三十二天、古族、曉與各界遺址的既有因果 |

## 五、交給 AI 團隊的執行指令

### Phase A：先盤點，不直接批次替換

1. 全庫搜尋九個舊界名及其簡稱、歷史天名、相關篇名、人物口語稱呼。
2. 區分每一筆出現屬於：**現行界名／歷史文獻引文／地方地名／宗門名／篇章標題／人物台詞／檔案路徑**。
3. 建立九界名稱對照表與影響檔案清單，標出不能直接替換的地方。

### Phase B：同步名稱

1. 優先修改九界總覽、各界設定、人物與勢力索引、跨界交通、九界金丹及全書年表。
2. 故事正文與章綱按敘事時間決定使用新名，避免角色在不知古史時突然使用只有上界才知道的名詞。
3. 保留一份永久新舊名稱索引，供 GitHub 搜尋與舊討論追溯。
4. 舊檔案路徑若需更名，須同步更新 Markdown 連結；避免先改檔名造成引用失效。
5. 原始作者投放、決策歷史與歸檔證據應保留原文，不可用批次取代破壞歷史紀錄。

### Phase C：檢查與驗收

- 新九界名沒有互相重複或對錯世界。
- 陸沉故鄉固定為**天樞界**；原驤鳴界固定為**洞明界**。
- 八雷身前往的是故鄉之外的八界，沒有因命名改動變成九個目的地。
- 原地理、角色、取雷、丹方、交通、修為、戰鬥與歷史設定均未被無意改寫。
- 所有跨檔 Markdown 連結可正常開啟。
- 作者核准後再回填正式設定與大綱，完成前不得宣稱 GitHub 已全面更名。

## 六、最終一句話

**九界以北斗九星為名，各自仍有自己的山河、宗門、天驕、歷史與未來；九星是一套名字，不是一套強制命運。**
