# 生・洛生衣 鳳凰血脈重規劃｜競稿任務單

狀態：候選競稿任務單，非 Canon。2026-11-20 主編。

## 一、作者方向（2026-11-20 對話原意）

作者想把生改成**鳳凰血脈**：生死輪迴、死後復生。對主編首輪可行性分析逐點回覆：

1. **赤翎也許可以拿掉**，故事可以大改。（「也許」：寫手可提出拿掉、改寫或把她的線併進生，但要說清楚代價，特別是文奕的同命契與文家守燼線。）
2. **第 15 篇封傷**：若那一次禁制造成的死亡，正好是**克制鳳凰復活**的，所以要九界金丹才化解。
3. **世界規則可以改**（〈涅槃借火〉「涅槃不在凡人身上成立」、南荒無確認存活純血鳳凰等）。
4. **涅槃只能自己**：生能死後復生，但不能用來復活別人。
5. **第 20 篇「拒絕犧牲他人復活師父」可以換成別的故事**。

最後一句：**對整個生做個重新規劃**。

## 二、主編轉成的創作約束

- 交付是**生一生的完整重規劃**：身世與血脈來源、覺醒時點、涅槃規則與代價、與陸沉的感情線、她自己的仙途（丹、劍、生死輪迴道）、逐篇走向（至少覆蓋主線第 1–28 篇＋成道後遠弧方向）。
- 「死後復生」是真的，而且要好看：讀者知道她會回來時，危險與懸念從哪裡來？每次死的重量從哪裡來？不能讓她變成不會死的人，也不能讓能力只是擺設。
- 封傷＝克鳳之禁 → 九界金丹化解，這條作者已給，要寫通：誰下的禁、為何在那裡、為何恰好克鳳、為何只有九界金丹能解。
- 第 20 篇換新故事，仍要是一個她自己的、不可由陸沉代選的重大選擇。
- 生是強者（D157、D159）：同代唯一正式場正面勝陸沉、丹道同代第一。血脈不能讓她變得「靠天賦」，也不能吞掉「證明蘇聽瀾教法」與碧梧／荊問師承；要讓血脈與教法互相成全或衝突出戲。
- 修仙感：鳳火、丹火、涅槃異象、天地回應要能寫成場面（見共用創作準則與 memory 的「處處修仙感」「要氣魄不要小家子氣」）。

## 三、硬邊界（不可違反）

1. **已完成正文最優先（D172）**：`正文/01_少年/` 卷一至卷十（含 07支）已定稿，生大量出場。查 `正文/` 中她的戲，確保新設計與已寫正文不衝突。最自然的處理是血脈此時**未覺醒／隱而不顯**；若方案需要回頭在已寫正文埋伏筆，列成「建議回補清單」（章、改哪句、為何），不得要求重寫情節。
2. **作者豁免檔**：`大綱/03_崛起/02_九界金丹/` 五檔內容不審不改。你的方案只能說明「封傷的來因改讀為克鳳之禁」，並列出需要作者同意的最小改點，不在方案中重寫該篇內部故事。
3. **雙環第三形態是作者底牌（D058）**：不提案、不推演、不引用細節。
4. 她的境界、年表、師承（蘇聽瀾已故啟蒙者、不帶滅門；荊問現任）、知秋與生環、路線 A（不進陸沉的案子）、感情線節點（第 15、23、28 篇）、日月藥天、三千花夜等工作選定內容：可以調整，但每一處改動要列出「原本 → 改為 → 理由」。
5. 長期人物封頂（A 類約二十五人）：新增重要人物要標明，盡量用既有人物（例如南荒燼梧諸氏、烏照夜、丹穴熾、寧枕微、桑遲）。
6. 不給陸沉新敗場（D157）。
