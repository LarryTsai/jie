## 一、總評（先說結論）

陸沉是一個**真的在推動故事的主角**。全書大多數高潮由他先選、先付價：卷一不問就引盡林伯潮殘雷、百宗放棄第一去封痕、九弱當著遲家交出陣錄、斷階自抽道基作釘、至尊之年把渡劫往前挪十天。他前後是同一個人：手停不下來、先做再改、看得見更好就想替人改，冷只對敵人。D157 的強度重構沒有把他寫壞。強者感來自具體動作，盲點戲多半放在他贏了以後，這兩點都做到了。

問題不在「他不夠強」或「他太被動」，而在**情感帳**：

1. 他欠得最重的一個人，寇平，全書只得到一次正面處理（十八歲「我知道是你，所以收回去」）。此後寇平替他照看母親、擔保他回家、為新簿裂道基、交出拓本，陸沉一直在收，從沒有自己回頭結帳。
2. 千礁返鄉死掉的「護持者」到現在沒有名字。
3. 第一段長弧的人生問題「能改，不等於該改」，在第 28 篇只用一個分句答完。
4. 「下次先問」的源頭林伯潮，第一卷之後只在南荒千相幻景出現過。

這四處都是他最該被碰到、卻沒被碰到的地方。

## 三、全書尺度的內在弧線

```
7歲「你在下面等」──→ 我來改（偷改丹方）──→ 替人改（林伯潮・不問）
        │                                         │
        │              12–17 太玄：被顧小滿／江離／生拒絕，「沒學會」
        │                                         │
        │              18 冠軍日強啟 → 寇平一重不剩【盲點最高峰】
        │                                         │
        │   ╳ 斷裂①：聖土一年，愧與怒沉到水面下，未浮上來
        │                                         │
        │              19–25 收帳、選遲家、家二次被襲（缺「又是因為我」）
        │                                         │
        │              25–28.5 陽閘自鎖；縮界只問一邊；斬我「不斬十八歲，他欠的帳還沒還」
        │                                         │                ╳ 斷裂③：這張欠條全書沒兌現
        │              28.5–31 鐘舌（贏後過度）→ 九天等待（學會先問）
        │                                         │
        │              31 挪十天渡劫給母親；不開匣「開了就真的沒有了」
        │                                         │
        │              32 自碎道基作釘（把自己列為成本，盲點另一面）
        │                                         │
        │              37 長亭：開匣「我們替你留了一塊」／「下次先問」傳給少年
        │                  ╳ 斷裂②：「能改不等於該改」只以「不降」一個分句完成
        │
        └──→ 105 朔河「這次你在下面等我一下」：願望第一次被回答（等可以是自己選的）
                     2500 帝落：「能改不等於該改」用在天地之邊；救人的人也可能在餵另一樣東西
                     7500 立極：「改完了，也留一處不改」；浮石習慣一筆都不改
```

**長出來，不是換掉**：從「替人改」到「先問」再到「渡、等、不改」，每一步都由他自己的錯推出來。鐘舌→九天、強啟→寇平→陽閘自鎖，這條鏈最扎實。

**斷裂處**

1. **18→19 聖土**：剛犯下全書最重的盲點錯、剛看見家燒，下一段卻是一年工匠生活，情緒沒有過渡。
2. **28 主題答案太輕**：第一段長弧的人生問題，在最該發生的地方被壓成一句。仙途帝落、立極又各答一次，讀者會覺得第 28 篇只是預告。
3. **十八歲的欠條**：「他欠的帳還沒還」指的是雷冠和寇平。雷冠在〈屋頂之帳〉還了；寇平那一份，他始終讓寇平自己往前走，他只在旁邊收。
4. **28 後的回退**：海往天上走、第一重、間章裡反覆出現「他沒先問／他先問」，像同一課被重修。成長在 28 已經交出去，仙途應該換新的盲點（例如「渡」的傲慢：別人等他來救），而不是再教一次先問。帝落大潮其實已經找到新盲點（「一個人肯渡，世界就會等他來救。他不想要這個」），可以更早接上。

## 四、問題清單

### 必修

**M1｜寇平這筆帳，他從沒親手還過**
- 位置：`大綱/01_少年/30_九界大比與返鄉/大綱.md`〈二之一〉強啟、墨乙；`大綱/03_崛起/05_不二與借壽崖/大綱.md` 第四節之 6-4「這個我不斬。他欠的帳還沒還」；`大綱/04_成道/01_一炷香與至尊之年/大綱.md` 第 3 章「問寇平親自去看她」；`大綱/05_入極/04_長亭/大綱.md` 第 8、9、19 章；`大綱/06_仙途/02_第一重/大綱.md` 中段 1「他記下，不動」；`大綱/06_仙途/07_立極/大綱.md` 中段 5。
- 問題：寇平因陸沉不聽勸強啟而「一重不剩」。十八歲以後，陸沉一路請他照看母親、轉交父匣、擔保自己回家；寇平為新簿裂道基時，他只收字條、記帳、按兵不動。立極最後一面兩人只談簿。陸沉「替人決定、把自己列為成本」的人，面對自己毀掉的人卻一直被照顧，這不像他，讀者也會替寇平不平。斬我那句話開了一張欠條，全書沒有兌現。
- 改法（擇一，不加敗場）：
  1. 朔河「下面的一年」寇平說「剪掉的是修為，不是我走過的路」之後，陸沉第一次主動提起十八歲那天：「那天是我沒問。」寇平答一句就夠，不需和解儀式。
  2. 第一重寇平道基裂時，陸沉不是「記下，不動」，而是壓境下去、站在簿房門口，寇平不讓他替自己出手（「這筆是我的」），他照做。他依然沒有動尹懷素，但人到了。
  3. 立極最後一面由陸沉先開口，把當年的欠說出來；寇平交拓本時回「那就拿上去。我在下面記」，讓這一句同時成為原諒與拒絕被補償。

**M2｜千礁返鄉死去的護持者沒有名字**
- 位置：`大綱/01_少年/30_九界大比與返鄉/大綱.md` 第五節「島上一名阻止行兇的護持者死亡，其身份須從既有可用島上人物中核選，未核前不冒寫名字」；`大綱/02_離鄉/02_上界追仇/大綱.md` 場景 22「護持者真死」。
- 問題：這是陸沉十八歲第一個因自己而死的熟人，也是追仇的一半理由，到現在仍是空位。雲行教他戰後記錄要多一欄「姓名」，倒雷井他每殺一人前都先叫名。為家而死的人沒有名字，主題直接自相矛盾。
- 改法：從卷一既有島民裡選。鮑十一最合適：第一個把他當真的大人，十年前拉住祁望後領，這次替陸家擋在巷口。卞老、魏四也可以。倒雷井報名後補一拍：殺費嶽前，陸沉先說的是死者的名字，再說「九界，陸家」。

**M3｜第 28 篇「能改，不等於該改」只答了一個分句**
- 位置：`大綱/05_入極/04_長亭/大綱.md` 第 18 章「他看見天地的缺，有能力對天地再降一次，不降」；第 20 章「斷階缺角的邊沿有人擺新攤」；第 21 章父匣。
- 問題：人物檔寫明這是他「一生真正要回答的」。前期長弧收束時，這個答案是一句旁述，沒有選項、沒有誘惑、沒有代價。後面開父匣、看見新浮石的情感高點，因此少了一層「他剛剛親手選了不改」的鋪墊。
- 改法：把「不降」做成一個場面。第十雷生成、劫印仍在指間時，漏樁拉走的坊市一角就在眼前。他有能力以〈劫數〉把那一角硬拉回來，也就是用改天換一個圓滿。生或母親不必勸他，只要那一角已經有人在邊上擺新攤。他看了一會兒，收手。下一章才開泥匣。代價：那一角永遠失去，管曜這一計的實得照留，抱一的教義此刻仍有一半是對的（帝落、立極回收）。

**M4｜「下次先問」的源頭林伯潮，第一卷之後再沒見過**
- 位置：`大綱/01_少年/01_浮石之下/大綱.md` 第 74 章；`大綱/01_少年/25_南荒四幕/大綱.md` 千相幻景；`大綱/01_少年/30_九界大比與返鄉/大綱.md` 第三節「太玄閣讓他看見自己最早練不成的地方」；`大綱/03_崛起/06_王室臥底/大綱.md` 八之 4；`大綱/05_入極/04_長亭/大綱.md` 第 25 章。
- 問題：十八歲他才在冠軍日重犯同一個錯，隨後回閣，卻沒有見那位老人。三十歲學會先問、三十七歲把這四個字傳給少年，也沒有回頭告訴說這句話的人。林伯潮是生是死，大綱沒有交代。南荒千相裡他想要的第一個畫面就是「林伯潮的傷好了在閣頂曬太陽」，可見作者知道他放不下。
- 改法：九界大比返鄉回閣時加一拍，寇平剛被剪，他去見林伯潮，只說一句「我又沒問」，老人照舊嘴硬。或者在長亭第 21 章宗訓石旁補一行：林伯潮已故，墓或閣頂石臺在現場，他把「下次先問」說給少年聽之前先去那裡。二者擇一即可，不必兩處都寫。

### 建議

**S1｜第一次聖土：讓愧與怒浮上水面一次**
- 位置：`大綱/02_離鄉/01_第一次聖土/大綱.md` 第一、二節；`大綱/00_全書骨架/10_索爾與莉森娜/大綱.md` A06「他不講仇案」。
- 一年五十二週裡加一個場面，不必多：例如鷹崖勝後或熔殞星前夜，他把那片界屑拿出來看了一夜（寇平那條路被剪下的一塊），第二天照常練刀。人物檔說「壓關不破是他自己選的……他答應過要帶願意回去的後裔過縫」，這個自選壓關的決定目前在大綱裡沒有場面。補上它，正好讓他「不能為自己破境」的克制有來處。

**S2｜第二次家園被襲，缺「又是因為我」**
- 位置：`大綱/02_離鄉/07_故土越線清算/大綱.md` 第 2 節。
- 十八歲和二十四歲兩次，仇家都衝陸家而來。第二次他「親手抬完」兩名藥役，很好，但應該再補一拍：父親或母親對他說「不是你」，或者他自己沒說出口地意識到這一點。這樣他後來在第 21 篇選擇「留上端拆樁，先堵住會伸到家門下的手」，才有累積的理由。

**S3｜仙途前段別再重修「先問」**
- 位置：`大綱/06_仙途/01_海往天上走/大綱.md` 第 2、3 節（澄背「沒先問牠」）；`大綱/06_仙途/02_第一重/大綱.md`「所以先問你」；`大綱/06_仙途/04_重與重之間/大綱.md` 第 2 件；`大綱/06_仙途/05_帝落大潮/大綱.md` 中段 3「全仙生明說的唯一一次」。
- 「先問」在 28 篇已經交出，仙途裡應該把它寫成習慣，而不是課題。澄背那一處可以改成新的盲點：他太熟悉自己的力量，把海變成「抵達」，這一點生衣已經點過；不要再寫成沒問。「全仙生明說的唯一一次」與其他幾處明寫先問並存，讀者容易誤會，建議改成「全仙生唯一一次問『要我渡嗎』」。

**S4｜封寒「這次別碰」和「瞞」的線懸空**
- 位置：`大綱/03_崛起/05_不二與借壽崖/大綱.md` 第五節之 3 表「『這次別碰』原封不動，留給殮錄線」；同檔第九節之 1「殮錄……善意之瞞已撤」；`設定/03_人物/01_主角群/陸沉.md` 兩兩關係「17–18 決裂、19 和解」。
- 殮錄線已撤，表格仍把收尾交給它；人物檔的劫×瘋落點也還寫舊版決裂與和解。對主角來說，他「瞞封寒、被看穿、讓封寒替他記帳」是劫×瘋最好的一條線，需要一個收點：他在聖土拿過、沒還的那樣東西，第 20 篇〈屋頂之帳〉還完時，封寒在場，陸沉把剩下那一半說完。這是 Canon 同步項，交 Canon 核對員或主編定。

**S5｜朔河試寫與卷一事實不符**
- 位置：`大綱/06_仙途/03_朔河不沉/大綱.md` 試寫「父親背著匣子上船，回頭對他說的也是『在下面等』」；同檔中段 4 寫第六天吐血，試寫寫第四天。
- 卷一第 4 章，「這事沒辦法，你在下面等」是父親在浮石坡替別家孩子打結時，按住他的手說的，不是上船。試寫標明非正文，但它是檢驗這個回收的樣稿，應該對準原場面，日數也應一致。

**S6｜長亭第 13 章「九界那端不用我」少一拍牽掛**
- 位置：`大綱/05_入極/04_長亭/大綱.md` 第 13 章。
- D159 要讓同伴主場，這句保留。母親在島上、家鄉被拖，他說這句時應該有一個動作，例如手在泥匣上停一下，證明信任朋友不等於不想家，與第 8 章「不能用忙解釋成無負擔」接上。

**S7｜第一段長弧與仙途各答一次「能改不等於該改」，要分層**
- 位置：長亭第 18 章；帝落大潮〈所得與改變・道心〉；立極〈道心〉。
- 修好 M3 以後，建議三處各自分工：28 篇答「人與故鄉」（不改那一角、開匣）；帝落答「天地之邊」（渡不是唯一答案）；立極答「自己」（改完了，也留一處不改）。現在三處的措辭太像，容易讓人覺得是同一個答案說了三次。

### 主角群順看（只記與陸沉弧線相關的）

- **封寒**：「聽說／驗過」貫穿全書，從先探、開河、吞天、照世、求真界到唯一，都是他自己驗出來的，沒有給陸沉當陪襯。只差 S4 的收點。
- **雲行**：攏天→叩壺→定→撥珠→背燈→斬我（約 2703 歲，「捨不得那個什麼都不押的自己」）。這條弧最完整。他問陸沉「想破局，和非破不可」，正好量出陸沉的轉變。
- **文奕**：「給我三天」→抱一前夜陸沉第一次說「好」。這是劫×文最好的回收。中段長期不在場是 D071 的設計，不算問題。
- **洛生衣**：每一卷都有她自己的勝負，從沒有成為獎品。勿沉→告白→帝落大潮道侶（「他連問都沒有，只是等」），正好回答陸沉的盲點，寫得很準。
- **寇平**（雖非主角群，卻是陸沉弧線的關鍵人物）：他自己的修行與守簿線完整，問題只在陸沉一方，見 M1。

## 五、最像他的 3 刻

1. **第 21 篇第 4 章，把至尊劫往前挪十天**（`04_成道/01_一炷香與至尊之年/大綱.md`）。他回不了家，就算好遞書日期，讓母親在安牌位那天能說一句「兒子成了」。為此他把甄四海的困陣只布到七成，用一場更險的仗換一封準時到的信。「我來改」、把自己列為成本、對家人的愛，三件事在同一個決定裡。
2. **卷一第 74 章，引盡林伯潮殘雷**（`01_少年/01_浮石之下/大綱.md`）。出於最善意的動機，沒有商量，硬做成了，還覺得自己終於替老人做成了；老人只回四個字。他的優點和盲點同時長出來。
3. **朔河第九天的石階**（`06_仙途/03_朔河不沉/大綱.md` 中段 4）。他看得出那爐火該怎麼扶，問了「要我上來嗎？」，聽到「不要」就坐回去，把兩隻手壓在膝蓋上。七歲那句話第一次被回答，而且是由他自己選擇等。這是同一個人長了七十年之後的樣子。

（次選：借壽崖「這個我不斬。他欠的帳還沒還」；王室臥底拆鐘舌之後等了九天。）

## 六、最不像他的 3 刻

1. **第一重中段 1，寇平裂道基，他「記下，不動」**（`06_仙途/02_第一重/大綱.md`）。十八歲時他願意拿自己的修為根去換寇平的路，現在卻只把它當成一條帳目。可以不出手打仙王，但不該連人都不去看。見 M1 改法 2。
2. **第一次聖土一整年，家剛燒、寇平剛被剪，他卻像沒事的工匠**（`02_離鄉/01_第一次聖土/大綱.md`）。他的冷只該對敵人，這一年連自己都冷掉了。見 S1。
3. **九界大比後回太玄閣，沒有見林伯潮**（`01_少年/30_九界大比與返鄉/大綱.md` 第三節）。他剛因為不問害了寇平，回到「下次先問」的出處，大綱卻只寫他看見小時候練不成的地方。依他的個性，他會先去找那位老人。見 M4。

（次選：海往天上走開頭重犯「沒先問」，像 28 篇的成長被重置，見 S3。）
