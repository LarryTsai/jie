### 01 地裂與兩條時間線

| 章 | 判定 | 理由／想跳處 |
|---|---|---|

| 01-05 可惜 | 想 | 他不搶石子，算準崩角站到底下去接，這招很聰明，一出手就看出他是什麼樣的孩子。看骨後半有點像流程，想跳處：「測骨的人沒急著落筆，領他們到攤後一塊遮光的布幕裡」。 |

| 01-07 改一筆 | 普通 | 安靜，母親照他的痕跡重抄丹方，這個回應寫得好。問題是開頭「開春後」沒交代是哪一年，我一開始以為是地裂後的春天。 |
| 01-08 改一息 | 想 | 第一個真正的爽點：往身體裡看，找到卡住的結，再從結的邊上繞過去，隔天提滿桶。祁望拋圓石「太圓」、父親半夜搬石臼，這兩筆都很好。 |
| 01-09 多一碗 | 普通 | 和泥、封匣、多擺一碗粥，三件事都是伏筆，本章自己沒有起伏。想跳處：「陸沉舀了半勺。父親看了一眼，讓他自己倒進去。」 |
| 01-10 窗外的人 | 想 | 祁望冒雨翻窗，嘴硬心軟寫活了。「你為什麼對我這麼好」「我哪裡對你好了」。 |
| 01-11 我自己走 | 普通 | 扛臼、修鳶、爬斷階三件事平鋪，像日誌。爬到第三段沒上去、祁望把石子踢在他那一側，這段好；扛臼那段可以只留一句。 |
| 01-12 背陰面 | 想 | 只有他看見有人割繩，沒有大人信，祁望摔下來，父親的手按著他的肩不放。這章很重。 |

### 03 春潮差事與嶺火

| 章 | 判定 | 理由／想跳處 |
|---|---|---|
| 03-01 埋王嶺 | 普通 | 三宗來議事有開會感；唐岫一句「那個孩子」點他。坊市小孩吵龍王、海王，林伯潮「嶺上的東西，只拿火」，這兩處讓人想往下看。 |
| 03-02 送簿·千礁 | 想 | 傳送陣開陣，邱九敲兩下、遠處回兩下，畫面一流；錢潤把籌碼合進學徒掌心，「想來，自己來找我」；阿硯守著沒有門的門口，說家裡搬過四回。 |
| 03-03 潮路 | 想 | 走出護島陣光的「碗沿」，耳朵裡一直有的聲音停了，這是上半最有仙感的一刻。嶺會改路，阿硯壓的石子還在，路卻接到別處，也很好。 |
| 03-04 潮藤 | 想 | 千礁的人說「潮不等人，走」；陸沉卸下匣子就跳下去；「別動」三次，三個孩子都陷進泥裡；唐岫一手一個把人拎出來。救完那孩子一聲不謝就跑，很真實。 |
| 03-05 嶺火 | 想 | 上半最好的三章之一。白火靜靜地流進匣子；他忍不住往霧裡走三步；阿硯靠潮響數步把他找回來，「你喊得太小聲了」。阿硯從「記路的人」變成救人的人。 |
| 03-06 潮轉 | 想 | 重新走回陣光裡，鼻子一酸；厄爬到頭頂，一滴水都不沾；翁敬亭一錘一錘敲得整條支脈嗡響，旁人說是林閣老的手藝，他擦錘、不辯。宋知微這回沒寫「存疑」。 |
| 03-07 送簿·觀潮與鎮溟 | 想 | 前半階下等潮，又是「站著等」，但那是故意給他下馬威，最後換來卓青指的潮時表；後半鎮溟那人就是 02-04 的一指，「回去」兩個字前後扣上，讀到很爽。 |
| 03-08 缺一刻 | 普通 | 地下樓的紋、抄簿缺一刻、宋知微陪他下去，最後補上「已看」，有餘味。但「存疑」這個梗本章用了四次，開始像固定程式。想跳處：「祖脈那一冊，抄起來比挑水還累。」到發現缺一刻之前那段。 |
| 03-09 客人買的是這一隻 | 想 | 「點頭沒了」「飛這麼高，那頭看不見是我」，讓他學到「壞」也可能是別人要的。祁望和阿硯初見，鳶掛到祁望自己後領，陸沉笑到扯痛舊傷。石頁「這個你修不壞」。 |
| 03-10 我想去船上 | 想 | 回條被撕、他用修鳶的手法修回條、執事收進抽屜；祁望說「我不修了」，他改好的吐納紙被推回來；最後一個人上山，在心裡數「一」。收得好。 |

**統計**：想 29、普通 16、想跳 0。沒有整章讓我想放下書的，普通章大多是中段某一段可以壓短。

## 2. 重複感

整體說：句子層面的「看、觀察、不說話」比外部讀者描述的少了，大多數觀察後面現在都接著動作（喊、指、放鳶、拉繩、跳下去）。重複感主要在**結構**，不在句子。

1. **「只有我看見，沒人信」用了很多次**：01-12（割繩）、01-15（執事）、02-01（閣門口存疑）、02-06（學徒不信霜線）、03-08（抄漏一刻）。前兩次很痛，02-06 是漂亮的翻盤；到 03-08 再來，我已經能預料「最後會證明他對」。03-08 好在換成宋知微陪他去驗、且結果是「看不出來」，算有變化，但開頭那段爭執可以短一半。
2. **宋知微記簿與「存疑」**：02-09、02-10（同章記三次）、02-11、02-13、02-14、02-15（同章記三次）、02-16、03-01、03-06、03-08（同章四次）。這是她的個人特色，我喜歡；但 02-10、02-15、03-08 用得太密，像每場戲都要她記一筆收尾。建議每章最多一次，留給有轉折的記錄（「已挖，實漏」「倒滿」「已看」「沒寫存疑」）。
3. **數歇腳**：02-01（五次、逐次寫）、02-06、02-07（三次、逐次寫）、02-11（歇四、祁望報數）、02-15、03-10。這條成長線很好，02-11 和 03-10 靠它出彩。但 02-01 和 02-07 先把停頓一次次細寫過了，02-11 的新鮮感被提前用掉一點。
4. **胸口發緊、扶牆喘**：01 段「胸口」出現 27 次，01-14、01-19、02-01 尤其密。傷要讓讀者記得，但不必每次挪步都寫一次。
5. **伏雷坳「三天一縷」**：02-14 到 02-15 是「三天後」「第二個三天」「三天後」，像在原地打轉。
6. **「看了一會兒／看了很久」**：03 段有 11 處「看了一會兒」，集中在 03-03、03-09（各 4 處）。句型小事，順手改掉幾處就好。
7. **「看、不說話」仍明顯的地方**：01-03（整章躺著聽）、01-06（捧燈看母親治人）、02-02（跟著唐岫看）、02-05 後半（護礁夜坐著聽）、02-13 後段（核對時辰）、03-07 前段（階下站著等）。03-05 那句「他沒有往前。他站著」反而用得好，因為前面他剛違規走進霧裡。

不算重複、建議保留的呼應：「先穩骨，再沿原紋接」（01-01、01-06、02-15、03-10）、彈石子和踢石子（01-11、01-16）、揮手（01-01、01-19）、「回去」（02-04、03-07）、祁望報數（02-11、03-10）。這些都是越讀越有味道的回扣。

## 3. 看不懂或跟不上

1. **01 段的兩條時間線**：有「七歲／八歲／九歲那年」開頭的章都很清楚，但有幾章沒標年份：
   - 01-07 開頭「開春後」：我先讀成地裂後的春天，讀到看骨、測骨人口訣才回神。建議改成「八歲那年開春」或「看骨回來後」。
   - 01-09「那年換封泥」：不知道是哪一年。
2. **01-14 提到「地裂前三天，斷繩那日」**：這時讀者還沒看過這個場面（01-18 才寫），我以為自己漏了一章。01-18 開頭只寫「浮石季第六日」，夾在 01-15（地裂後）和 01-19（地裂後）中間，也沒說是地裂前，要讀到「近十歲」才拼得出來。改法：01-18 第一句改成「地裂前三天，浮石季第六日」；01-14 那句改成「這張臉他見過，就蹲在繩樁後頭收刀」，不指名是哪一場，讓 01-18 來揭。
3. **01-15「翻開舊卷，照著上面的『以力作骨』」**：這時讀者還不知道「舊卷」是什麼，《無相離身卷》要到 01-17 才買。可以直接寫卷名，或改成「卞老那卷」。
4. **人名沒介紹就出場**：
   - 鮑十一（01-13）：「幾日後，鮑十一也來了」，不知道他是誰、為什麼會來問。補半句身分（管繩的、守樁的）就行。
   - 卓青（01-13）：御器救人，不知是哪一宗的。
   - 沐潮生（01-04）：念名冊的人，到 02-01 才知道是觀潮主事。
   - 唐岫（02-02）：從「那女人」直接切成「唐岫」，中間沒人叫過她名字。
   - 02-01 一口氣列出「沐潮生、宮霽、錢潤」三個主事，宮霽在上半再也沒出現，可以拿掉。
5. **術語**：「搬血前段／後段」「洞天」「淬」從上下文都猜得出，沒問題。「長亭天」只出現一次，不影響閱讀。
6. **「先來的學徒」一直沒有名字**：我覺得是優點，拇指撥木片的動作讓他從頭到尾都認得出來，不必改。

## 4. 最好看三章與最該改三章

### 最好看三章

1. **01-16 第三段**：成長不靠旁白，靠抽掉的木片、三口氣、往下彈的石子；祁望那句「你在那做什麼？」「等你」，前面八章的情分都在這裡兌現。
2. **02-06 拿鏟子的人**：讀者這時已經憋了一段「沒人信」，這章用一鏟白氣翻盤，而且是祁望用自己的工錢押上，不是陸沉獨贏。
3. **03-05 嶺火**：奇觀（白火、斷紋全朝同一處）、他的缺點（忍不住想看）、同伴的本事（阿硯數潮）三樣同時發生，不必解釋就懂。

候補：02-11 半桶、03-04 潮藤、01-19 以後呢、03-09 客人買的是這一隻。

### 最該改三章（照做的改法）

1. **02-01 閣門口**（第二段的門面，現在最重）
   - 刪掉「觀潮、鎮溟、千礁三宗留島分部的列陣主事——沐潮生、宮霽、錢潤——各帶圖卷……」這一句的名單，只寫「三宗的主事也得排隊等學徒記名」，錢潤留到他自己看陸沉那一下再點名。

## 5. 節奏分數與總評

**節奏 8.0／10**（01 段約 7.5，02 段約 7.5，03 段約 8.5）

總評：上半已經不悶。最弱的是 02 段前半和中段那幾章日常，越往後越好看，03 段幾乎每章都有一個讓人想翻頁的動作或奇觀。

「看、觀察、不說話」的模式還在，但已經不是主要問題：句子層面的重複明顯少了，多數觀察後面都接著動作。現在讓我覺得「又來了」的，是兩種**結構**：「只有我看見、沒人信、後來證明我對」，以及宋知微每場都記一筆收尾。前者到 03-08 已能預料，後者在 02-10、02-15、03-08 太密。這兩處改掉，節奏可以再往上半分。

人物方面：祁望最活，每次出場都在推進他自己的人生（摔腿、扛貨、排不上船、上船）。阿硯從「只記路」長成「數潮救人」，有累積。先來的學徒從撥木片到拿籌碼，雖然沒有名字，弧線卻完整，令人難忘。父親的沉默是刻意的，到 01-15「等一個說要回來的人」得到回報。比較只是功能性的：鮑十一（救人關鍵，卻沒有自己的面目）、卓青、02-01 的三位主事。
