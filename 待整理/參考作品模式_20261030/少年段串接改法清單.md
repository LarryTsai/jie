# 少年段串接改法清單

狀態：討論稿（2026-10-30），非 Canon，未改任何大綱。承接[三書模式萃取](三書修仙模式萃取.md)第五節。

## 先修正上一稿的判讀

逐篇讀過各卷開頭後，**真正靠「拿到名額所以去」串接的沒有一半那麼多**。不少比賽篇的入口已經是餘波、人物或欲望：

- 越界：天域行院錄多了「未受令」，舊例允許單挑令主——**餘波橋**，好例子。
- 登天塔：南院耗材見底，逼他闖塔——**尋物橋**，好例子。
- 百宗盟試：赴會路上先遇故鄉海眼、洄辛來求——**人物牽引**夾在名額前面。
- 七峰爭鳴：宗門停脈重鑿，大比踩在半條雷脈上——**地方慢住**，比賽長在宗門的事件裡。

「比上去」的感覺，主要不是來自串接，而是來自**獎勵結構雷同**：

| 比賽 | 贏了得到什麼 |
|---|---|
| 七峰爭鳴 | 入命藏資格 |
| 五域大比 | 書院入學、擂洲天露 |
| 登天塔 | 額度桌選資源 |
| 四院選拔 | 九界代表席 |
| 九界大比 | 上界印記 |

幾乎每場的獎品都是「進下一層的門票」。讀者因此感到一層一層比上去。

## 逐處改法

### 不動（已經好，或作者硬裁定）

| 串接 | 理由 |
|---|---|
| 浮石之下→山門之上 | 人生起點，推薦入宗最自然；卷一作者選定 v1.9，正文進行中 |
| 鎮岳→七峰爭鳴 | 比賽長在停脈重鑿的宗門事件裡 |
| 萬體無我→東溟行 | 封寒主動接護料任務，是任務＋人物牽引 |
| 東溟→百宗盟試 | 海眼故鄉線已在名額前面 |
| 入院→登天塔 | 耗材見底，資源需求驅動 |
| 天域行→越界 | 未受令的餘波 |
| 無間航道→九界大比 | 作者硬裁定：安全抵達、壓倒性第一 |

### 要改的三處

#### 1. 七峰爭鳴→萬體無我（命藏）

**現況**：大比前十帶傷入命藏，是大比的獎品。
**改法**：獎品保留，入藏理由改成陸沉自己要找東西。他剛在八強輸給青璃（「你聽脈的拍子走，我聽你的」），想找一條不跟著拍子走的路；命藏裡的〈借地〉碑正是鎮岳的反面。
**規模**：窄修，只改出發動機一兩段，事件不動。

#### 2. 五域大比→入院

**現況**：大比結果帶來書院入學。中間已有倒懸石山、西極地獄行，報到時三人帶魂傷，入口本身不算硬。
**改法**：把五域大比的獎品從「入學資格」改成**擂洲天露帶回東溟**（現行已有），入學改由別的事件促成。例如地獄行留下的魂傷，只有書院南院能接手；或南院因西極那件事主動來要人。
**規模**：窄修；需核五域大比與入院兩檔的獎勵敘述。

#### 3. 溫棠的路→四院選拔→九界（最值得動）

**現況**：四院選拔是九界前最後一場擂臺式選人，緊接著就是九界大比。兩場比賽背靠背，最像「比上去」。
**改法三選一**：

| 方案 | 做法 | 得到 | 失去 |
|---|---|---|---|
| **甲：選拔換形式**（推薦） | 九界代表不靠擂臺，靠一次界槎試航或護舟任務選出；劫對韋執圭的收束改在任務裡完成（兩人搶同一個隊長位、同一條航路） | 少一場擂臺；韋執圭宿敵線在實戰裡收，接得上無間航道 | 霍驍對嬋九歌那種同代擂臺看頭要另找場合 |
| 乙：併入航道 | 選拔壓成一章，併進無間航道開頭 | 篇幅省、節奏快 | 韋執圭與霍驍的宿敵收束被壓扁 |
| 丙：獎品換性質 | 擂臺照留，但贏的不是代表席，而是自己想要的東西（例如一條古航路的使用權），代表席另外決定 | 改動最小 | 仍是兩場擂臺背靠背 |

---

## 通則：其餘比賽篇不改串接，只改獎品性質

每場比賽的回報，盡量有一部分不是門票，而是：
- **陸沉自己想要的東西**（一門法、一件器材、一個人的認可）；
- **比賽製造的麻煩**（得罪的人、輸家的新路、名次本身是陷阱）。

這樣即使比賽場數不變，讀者看到的也是一連串人與欲望，而不是一層一層的關卡。
