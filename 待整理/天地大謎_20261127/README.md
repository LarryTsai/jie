# 天地大謎（2026-11-27 開）

狀態：討論區。三案和比較都是候選，不升 Canon；正式區、全書總覽都還沒動。

## 起因

作者請主編拿《仙逆》《遮天》《武煉巔峰》對照兩界的設定與歷史。主編的診斷是：歷史有人味，天地太小，最大的謎只是一樁兇案，天地級的問題全部留白。作者選「先做天地大謎」。

## 主編取捨

同意 Reviewer：**以丙為主**。
- 只有丙讓「劫，是誰的？」從伏雷坳一路問到邊外，公主案揭完後每個階段都有新的實物推著走。
- 第六弧「九界自簽、一夜萬劫」把墊天的代簽翻成九界自己簽，跟第28篇「不許代簽」互相加力。

採用前必修四項（比較第五節）：
1. 墊天句改寫，重心放在「帝座本職是站在邊上讓劫落，他不站」，不讓讀者讀成「沒有墊天就灌滿」。
2. 劫回到 Canon「天地在擋」的寫法。
3. 清掉劫靈殘影，改名「未成」（撞〈天地未成〉）。
4. 第六弧代價收窄。

若必修 1 改不掉、太宸仍有洗白風險，改以甲為主。乙不作基底：「兩半天地」直接撞上獨立天地、D039、底層規則二與五。
