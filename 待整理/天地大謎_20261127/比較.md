# 天地大謎三案比較

審查角度：一般讀者、修仙愛好者、Canon 核對，依規約讀者類先審，Canon 放最後。讀過的檔案：根 AGENTS、獨立讀者 Reviewer、審查員 README 與兩份角度檔、競爭規約第二至四節、[任務單](任務單.md)、甲乙丙全文、[遠弧比較](../仙生續拓/遠弧_比較.md)、[舊遠弧丙](../仙生續拓/遠弧_丙.md)（抽讀太初劫、劫樞、元厄各段）。另外親自開檔核對下列 Canon，不只採信寫手的引用：`第十雷用語`、`帝重與帝路`（#26、〈本大綱不做的〉）、`立極`、`帝落大潮`、`諸神聖土`（底層規則、突破有無劫、鬥帝存續、留白）、`仙庭與王庭權力根基`、`古戰與當代陰謀因果鏈`（第6、10、11環與第三節）、`九界與陸沉故土`（D069）、`三十二天`、`世界建構方向`、`歸一派`、`世界認知揭露時間線`、`九界共通神識天地`、`第26篇入極`、`第22篇斷階頂上`、`無間航道`、`卷十九`、`卷二十三`、`古戰與兩界衝突`、`烏蘅`；正文抽查卷一〈蓄〉〈有人來看那孩子〉、卷三〈先看天〉、卷五〈鎮鈴七枚〉。

## 一、結論

**推薦以丙《天自己的劫》為主，但要先完成四項必修（見第六節），再吸收甲的少年段兩拍，以及乙、甲各一兩個小元素。不採乙作基底。**

理由用一句話說：丙是唯一能把書名的問題「劫，是誰的？」從卷一的伏雷坳一路問到第六弧的方案；公主案揭完以後，它的中段（仙途弧一、弧三、弧五）每一層都有新的實物。它的第六弧「九界一夜萬劫」，也把墊天的「代簽」翻轉成九界「自簽」，跟公主案互相加力的程度是三案最高。

甲的天地觀最乾淨，Canon 風險最低，「霧捲成一圈繞著孩子轉」又已經寫在卷一正文裡，重讀時的回報最漂亮。少年段的抬頭感也是甲最好。但甲的謎走在讀者看不到的地方：「天在轉」要到第26篇才看得見，從帝落（38歲）到萬簡庫（2800歲）中間沒有任何新層，邊外又只是一面不動的鏡子，寫手自己也承認中段冷、第六弧容易溫吞。

乙的「九塊泥」是三份試寫裡畫面最好的一場；但乙另起了一整套宇宙觀「天地原是一口氣」，撞到的 Canon 最多，第六弧的形狀也最接近舊遠弧丙。

閱讀欲望（輔助，不是結論）：丙 8／甲 7.5／乙 6.5。Canon 安全度（輔助）：甲 8／丙 6.5／乙 5。

**附帶警告**：丙最大的風險就在本輪的紅線上。丙的作者層第一句寫的是「封口，是太宸拿九片天去擋天自己的劫」。這句話如果照原樣進作者層，讀者很容易讀成「他其實是在擋天災」。必修第一項就是改掉它（第六節）；改不掉，就應該改以甲為主。

## 二、逐案評：閱讀欲望、中段牽引、四人的道

### 甲〈極會死〉：天繞著一個人坐出來的靜轉，那份靜正在死

**最值得保留的場面與揭露**
- **卷二十三九界大比的交流夜**（試寫）。八界少年拿各界的「那一天」對日子，三個人都答「七天」，桌上的石子、火種、浮石，影子一齊往同一邊偏。雲行說「先吃」。這是三案裡唯一一場讓九界的同代一起抬頭的戲，有人味，也不靠講解。凌汛界的村子「開春要搬了」，讓代價落在一個少年的家上。
- **雷池池壁的刻痕：九、七、五、三**（卷十九）。這是一條能量的徵兆，會一次比一次短，最接近《遮天》那種反覆回來的天地警訊。老人自己下池，燒焦了兩手。
- **萬簡庫「坐」變「重」**。歷代帝座每天烙「坐」，封界次日起全變「重」。這一筆把太宸的罪加重，沒有替他減。
- **封寒看了臉而不說**：「是一個坐著的人。他不肯起來。」立極那句「總要有一個人不知道」，在這裡倒過來落到陸沉身上。這是三案處理「知」最好的一筆。
- **雲行坐在帝座旁邊**：「三十二天坐上去的人那麼多，他是第一個坐在旁邊的。」這是三案寫「無」最好的一筆。

**最弱、最容易棄讀的層**
- **層一（卷十四）沒有東西**，只是重讀。
- **層七帝落（38歲）到層八萬簡庫（2800歲）之間是空的**，跨過帝落大潮、朔河、抱一。公主案收在37歲，接手最需要力氣的正是這一段，甲在這裡斷了。
- 謎本身是「被動的物理」：心在衰，衰得很慢。邊外之物沒有意志，也不靠近。讀者在中段沒有「它要來了」的牽引，甲在附錄裡自己承認了這一點。
- 第六弧〈送極〉的高潮是「讓它好好死完」，情感成熟，但跟作者要的「氣魄」有距離；倒轉期「上無極有幾座城沒保住」也只有一行。

**修仙感**：「極是一個人坐出來的靜」直接接上修行觀：向極、歸一、立極、抱一道場散成無極。仙帝之極在人死後散去，也因此有了解釋，內部最自洽。缺的是跟「劫」的連結：甲的劫照舊是摩擦，跟書名與主角的雷道只有間接關係。

**四人的道**：三案最好。陸沉「變到知道什麼該讓它結束」，封寒「知到底，也知道什麼該停在自己這裡」，雲行坐在旁邊，文奕「網心我站過，站一下就走」，四人各有自己的答案。

### 乙〈天地原是一口氣〉：劫是撕口在疼，邊外是天地沒渡完的那場劫

**最值得保留的場面與揭露**
- **「九塊泥」試寫**（卷二十二回程私路）。九點光，朝內的一面齊齊截平，朝外的一面一圈圈燙痕，接著接到父親在裂牆前和泥。三份試寫裡這場畫面最強，情感也最準。
- **第28篇伏雷坳的餘火熄了**，林伯潮卷一按過的地方第一次是冷的。這是一筆小而重的收束。
- **聖土古約首句「兩岸一息，往來不禁」**，邊地人背了八萬年，沒有人當它是字面意思。
- **公主的接木就是天地的答案**：「根各是各的，活是一起活。」

**最弱、最容易棄讀的層**
- 卷一到卷二十一只有重讀，第一個新層要到十七歲。
- 第八層「約四十一至二千八百歲」把兩千多年壓成一段讀法：每渡一重就瞥一眼，看見背面的劫雲有年輪。這等於沿用現行遠弧的「瞥見」，沒有新的實物。
- **天律太多、講得太滿**。五條天律，加上「由此推出」五條，把鬥帝、魂龕、下方層域、大羅核心、界潮全部收進同一個機制。這碰到創作準則「不把所有機緣綁成同一最終秘密」，也讓天地像一份規格書。
- 第六弧「兩界一起渡一場大劫」場面最大，但對手眭無恙只是重演一次「斷」；聖土新帝成帝這一步，由陸沉經錨寫信催動。聖土人吵了一百年，只寫成一行。

**修仙感**：「另一片天不劫人，丹雷斜著從縫那邊來」有天地之大的味道。可是「每一次渡劫都是在自己身上把天地再撕一次」，會把讀者讀過的每一場突破改寫成傷口。這是重讀上的大翻轉，但修行的喜悅會被打折。

**四人的道**：最弱。封寒「不看」重複立極現行，文奕「接」重複第28篇的錨，雲行「裡面沒有誰」只是一句話。

### 丙〈天自己的劫〉：天還沒長完，劫是天落在你身上的那一份；邊外是天沒落完、凝成了命的那一份

**最值得保留的場面與揭露**
- **「界潮有床，別往床上看。看久了，人會想下去。」**（卷二十二試寫）。陸沉用林伯潮教他數伏雷坳火的那個拍子，去數界潮底下那個東西的呼吸，數完刻在一根骨頭上。用的是他此刻會的東西，也接上已寫正文卷一〈它什麼時候弱〉，叫得出名字，帶點恐懼。三案裡最接近《遮天》禁地感的一句話。
- **第28篇錨成那一息，留舟島所有浮石離季升起一指，沒有落回去。**同一夜讀者聽見「是我」，也看見九界被托起。這是公主案與大謎第一次並排，三案最好的交接點。
- **帝落大潮的帳上註了名字**：牆上十萬人都活著，他們的劫還在外面。
- **萬簡庫「長」字**：古戰以前帝座每天記天又長了多少，封界那天斷掉。效果和甲的「坐」同等，而且直接證明「帝主守外」是帝座本來的差事（見第五節）。
- **它的臉是九界的形狀**：頂了九界八萬年，被壓成九個凹，長亭天那一處最深。立極時封寒沒看的那張臉，原來是家。這是全場最有《仙逆》失重感的一個答案。
- **第六弧祁鈞坐上帝座，第十條帝路亮起**：「叔祖壓了九片天。這一次只壓我一個。」最高貴的錯誤答案，而且是和解後的舊對手。讓他站起來的不是陸沉，是寇平送上來的那頁九界簽名。眭無恙問牆上的人「要不要拿回來」，九界「一個一個人寫上名字，寫明要接哪一份」，一夜萬劫，浮石全升。這一弧把墊天的「代簽」翻成「自簽」，接回第28篇「不許代簽」，氣魄與群像都是三案最好。

**最弱、最容易棄讀的層**
- 卷十一到卷二十一同樣只有重讀，寫手自己也認了。
- 第二層「一片沒有主人的劫」（18–31歲）只加了一拍感覺：九霄入體時劫雲是斜灌的。這一層偏薄。
- 第六弧代價開得太多：九界雷季沒了、寇平壽盡、邊極從此關不上、天缺留一隻小厄。其中「九界雷季沒了」把整個九界的雷都說成天劫壓下來的那一份，回頭動到陸沉家鄉的整個雷修文明，太大了（見第五節）。
- 結尾「邊上那個小東西在他手邊碰了一下」，可愛，但會讓「凝成了命」往元厄那邊滑。

**修仙感**：三案最強。「順」就是天還在長，「逆」是天自己在逆行，跟底層規則二「天地由大羅向外分化」完全咬合，也對得上第26篇的年輪和外推之風。九界每一個破境的修士，渡的都有墊在九界身上的那一份。宗政拂那句「有。在下面。你們沒問。」因此變得更真，讀過的每一場九界渡劫都多了一層意思。

**四人的道**：好，次於甲。封寒「該知的時候，總得有人付這隻眼睛」，跟甲同構。文奕「它是照著我們長的」是好台詞。雲行「身上不開縫，劫找不到他」偏機制，不如甲的「坐在旁邊」。陸沉「是門，不是墊」清楚。

## 四、和舊遠弧丙（太初劫）的關係

舊遠弧丙被擋，[遠弧比較](../仙生續拓/遠弧_比較.md)寫了三個理由。一，天劫的起源與意志跟 `第十雷用語`「仍留白」直接衝突（天在擋、在問，有劫樞）。二，它是「第二套宇宙觀」：太初劫比三十二天還早，吃過八百個天地，三十二天的劫是天學它的樣子做出來的。三，四個高潮都押在劫的把戲上，元厄還把陸沉過去的每一版放出來打他。當時的結論是「現在不該解，日後開第六弧時再當作者題」。

本輪是作者明確選擇「先做天地大謎」，任務單〈可創造區〉也列出了「天劫」，所以理由一的「現在不該解」已經不成立。要判斷的是理由二和理由三有沒有真正解決。

- **甲：不是舊案重提。**劫照 Canon 仍是摩擦，邊外之物不是劫，也沒有意志。甲只替「摩擦」補了一個「為什麼」：逆著轉。三案裡甲跟舊丙最遠。
- **乙：形狀上是舊案重提，宇宙觀問題反而更重。**乙的邊外是「比邊老、沒渡完的劫，正在落回來」，第六弧是「仙帝替天地渡一場落下來的巨劫，眭無恙在邊上斷」。骨架就是舊丙弧四「渡太初劫」換成內生版。乙確實拿掉了吃天地、劫靈、舊版本打人和第二次墊天，意志也留白。但「兩界原是一口氣、被修行撕成兩半」本身就是一套新的宇宙觀，比舊丙改得更深：它改寫兩界的出身，也改寫每一次渡劫的意義（見第五節）。舊丙被擋的那個核心問題，乙沒有解決。
- **丙：同題，但已經真正改過核心。**丙明寫跟舊丙的差異：天缺是三十二天自己的，不吃天地，不打人，第六弧沒有和它對打的戲；四條天律全從現行的順逆、劫跟著逆行者走、劫凝成命（厄、走潮者）推出來。我核對過，丙的天律確實是現行 Canon 往下延伸，沒有另立宇宙。比如「天由大羅一點長出來」，直接對應底層規則二與第26篇〈外推之風〉。留下三個殘影要清：
  1. 「未成」一詞撞上 `帝重與帝路` 〈本大綱不做的〉裡的「〈天地未成〉作仙帝之天」，要改名。
  2. 「凝成了一條命」「轉了方向朝著邊極」「在他手邊碰了一下」，讀起來會像劫靈。要把「轉向」寫成落點的物理（天律四「極在哪裡，劫往哪裡落」本來就有），結尾的小東西拿掉或寫得更遠。
  3. 第六弧那位王主「再按深一寸」是第二次墊天的影子；丙只讓它當一句冷話、由九界否決，可以保留。

結論：丙已經解掉舊丙的「第二套宇宙觀」和「劫把戲高潮」；剩下的是用詞和劫靈殘影，窄修就能處理。乙沒有解掉。

## 五、Canon 風險（附位置與證據）

### 甲

| 位置 | 風險 | 判斷 |

## 六、推薦與融合清單

### 以丙為主：整合前的必修四項

1. **改寫丙的一句話真相與第二節〈古戰那一夜〉。**作者層第一句改成：「撤護持撕開了天正在長的那一圈，天自己的劫從破口灌進來；帝座的本職就是站在邊上讓它一份一份落，太宸不站，把九片天壓進去當墊。」重心從「擋」移到「不站」。救援派的「帝主守外」要寫明成功的可能：歷代帝主每天都在做這件事，萬簡庫的「長」字就是證據。墊天擋住的也不是天劫本身，只是讓它不再落進來、不再長，墊下的九界從此替他扛了八萬年。這樣，大謎越大，太宸的罪就越大，不留「不得不」的空間。
2. **天律二改回 Canon 的「擋」。**劫是人身上開了縫，天落進來，縫在擋，兩股相磨，就是摩擦。「渡過了成了你」保留為渡劫的結果，不寫成劫本身是在給。
3. **清掉劫靈殘影。**「未成」改名；「轉了方向」改寫成落點物理；結尾的小東西刪掉，或留在遠處不碰手。
4. **第六弧代價收窄。**「九界雷季沒了」改成「伏雷坳那團火熄了」（可借乙的「冷的石面」畫法）。寇平壽盡照丙自附的備案列為作者題。「邊極從此關不上」保留。
