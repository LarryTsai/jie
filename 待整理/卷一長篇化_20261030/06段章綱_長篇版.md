## 新章細綱

### 第 06-01 章〈千礁的第二批〉

**時線｜年齡｜境界｜傷｜持物**：11 → 12 浮石季初（冬）｜搬血；星羅一雷，雷絲能探，存不住｜無傷｜—。

**因果入口**：05-03 千礁第一批修閣、換脈釘手藝；03-02 碼頭上收回籌碼、看他一眼的外戚孩子；03-02、03-04 彭渚拿籌碼轉千礁、鹽沼跟著走；人物表費瑜動機（長輩「拿得到別家閣的推薦，才算你自己的」）。

**場景順序**
1. **閣門口，第一批浮石升起那天。**千礁第二批修閣的人上山，抬的是新燒的承雷磚。隊尾跟著一個和他差不多大的少年，衣料是全隊最好的，手腕紅繩上串著白玉片，手裡沒拿東西；替他背箱子的人走在後面，陸沉認出那個背影——閣裡先來的那個學徒，比兩年前高了一個頭，肩上壓著兩隻箱子，腰間那片磨亮的木片不見了。錢潤回頭喊：「彭渚，箱子放下，去打水。」陸沉這才知道他叫什麼。
2. **前廳外。**錢潤向翁敬亭說：這是錢家的外戚子弟費瑜，來學燒脈釘，住千礁分部，每旬上山。翁敬亭答應他來學，說：「閣裡的爐可以借，閣裡的名額不借。」費瑜笑了一下，沒答。
3. **廊下。**費瑜經過掃廊的陸沉，停了一步，看他的臉：「碼頭上那個，看陣最好的。」說完走了。三年前那一眼，他也記得。
4. **井邊。**彭渚放下箱子去打水，陸沉在井邊。兩人隔著井沿，誰也沒先開口。彭渚把桶提上來，說：「千礁的人，不提一桶，提兩桶。」提著走了。

**連續性**：費瑜在此報名（現行 06-01 的報名移來）；陸沉認白玉片（對齊 03-02、06-07 正文）。翁敬亭不賣名額。費瑜要的推薦是他自己順手想拿的。彭渚在此第一次由他人當面叫出名字（02、03 段正文不回填亦成立）；新設定只此：兩年在千礁仍是底層、沒開洞天。

**收尾與牽引**：→ 06-02–04 三次碰撞；彭渚 → 06-08。

### 第 06-02 章〈飛得是挺高〉

**時線**：同季，旬日｜同上｜—。

**因果入口**：01-01、01-10 那隻會飛的鳶掛在攤竿上（「明天還放」）；06-01 費瑜認出他。

**場景順序**
1. **卞老攤。**費瑜帶著兩個千礁弟子逛坊市，在攤前停下，指著攤竿上那隻鳶：「這隻賣嗎？」卞老說那隻不賣。費瑜放下一把靈石，比攤上所有鳶加起來還多。卞老看了陸沉一眼，陸沉沒說話；卞老收了錢。
2. **斷階下。**費瑜當場放鳶，放得很好，鳶一路過斷階第三段、第五段、第七段——比陸沉從前放到的浮石的高度還高。他看了一會兒，指尖一縷靈火貼著線燒上去，火走到第七段之上，線斷了。鳶在高處停了一息，翻下來，落進海裡。「飛得是挺高。」他把線軸丟回攤上。
3. **低崖下，傍晚。**陸沉一個人下到低崖，在潮線邊撿回那隻鳶的殘骨，左翼第三折斷了（01-01 那一折）。
4. **夜，閣裡。**他照卞老教的「先穩骨，再沿原紋接」，一折一折接回去。天亮前修好，旬日結束前他下山，把鳶掛回攤竿。卞老看著那隻鳶，又看了他一眼，沒說話，把那把靈石推到他手邊。陸沉推回去。

**連續性**：費瑜洞天（神識只貼身數尺，D082；放鳶靠手、斷線靠靈火），境界不報。陸沉不與他動手。

**收尾與牽引**：→ 06-03。

### 第 06-03 章〈陣要開了〉

**時線**：同季，數日後｜同上｜—。

**因果入口**：05-09 陸沉補了八枚碎靈石、讓他進棚的那個「兩塊半」少年（散修）；05-10 營火邊那一點頭；03-02 傳送陣「一潮開一次、一次只送幾人」、船位押份額。

**場景順序**
1. **千礁傳送陣前。**陸沉送簿到千礁分部。陣邊排著等陣的人，排頭是那個散修——他從共天出來後，攢夠了錢要出島，排了三潮才排到。
2. 費瑜帶人走到陣邊，只說了一句「讓開」。管陣的人看看他手腕上的白玉片，回頭就叫散修讓位。散修沒動，臉色發白。
3. 陸沉走過去，站在散修和費瑜中間，什麼也沒說，只是不讓。費瑜走到他面前，貼身數尺之內，神識壓下來——不是掃，是壓，整個人像被一座山按住。他的膝蓋發軟，往下沉了半寸，他想起扛臼的時候、想起第三段，把那口氣往下送，站住了，沒有跪。
4. 陣師邱九在陣眼邊敲了兩下，聽完回音，頭也不抬：「陣要開了。」費瑜收回神識。白光一圈升起，散修走進光裡，回頭看了陸沉一眼，陣光合上。
5. 費瑜離開前說：「你站得倒穩。」

**連續性**：陸沉不還手；「不跪」是他自己的贏。邱九的一句是陣師職分，不是替他出頭。

**收尾與牽引**：→ 06-04 費瑜開始注意他到哪裡都在。

### 第 06-04 章〈爐邊兩截〉

**時線**：同季，下一個旬日｜同上｜—。

**因果入口**：03-06 他替翁敬亭拉風箱、看燒脈釘；人物表：嶺火是石縫裡的白色雷火，外火越猛越吃不住；費瑜家傳靈火最快最亮。

**場景順序**
1. **閣裡的爐房。**翁敬亭替千礁燒脈釘，叫陸沉拉風箱（照 03-06 的老規矩）。爐邊牆角扔著兩截裂成兩半的脈釘，斷口焦黑，比翁敬亭燒的釘多一圈燎痕。陸沉看了一眼：不是翁敬亭的手筆。
2. 他不知道為什麼會裂，只看見裂口從釘心往外，像從裡面被撐開。他多看了兩眼。
3. **費瑜進來。**費瑜來借爐，看見陸沉在看那兩截釘，走到他旁邊：「替我也拉一回。」陸沉沒停手，照常替翁敬亭把那一爐拉完。費瑜站著看他拉完，看了一眼牆角的釘，又看了他一眼，轉身走了，那天沒借爐。
4. 翁敬亭打完釘，看見牆角那兩截，撿起來看了看，丟回原處，什麼也沒說。

**作者層（正文不寫明）**：費瑜每旬借爐試燒，一直燒裂、一直瞞；現在有人看見了。他怕的不是對試，是推薦試第一段燒釘。後面買動執事排爐、投碎陣石，從這一眼長出來。

**連續性**：陸沉只看見「裂」，不知為什麼；原因在 06-09 台上才懂。他不接費瑜的差，是他自己的選擇，不是對抗。

**收尾與牽引**：→ 06-07 費瑜買執事；06-09 裂釘上推薦冊。

### 第 06-05 章〈看門〉

**時線**：同季末（除夕前）｜同上｜—。

**因果入口**：人物表阿硯「隨小宗門反覆遷移，先看門與退路」；04-13 退路；06-09 現行「阿硯試前已向翁敬亭說過他要留閣（他家跟著宗門搬了太多次，想待在一個不搬的地方），燒釘不爭對試」——本章把這句旁述搬到台前。

**場景順序**
1. **閣門口，午前。**阿硯的父母上山：他們跟著的那個小宗門又要搬，往千礁的地界去，船已經訂了。父親背著行李，母親拉著阿硯的袖子，說一起走。
2. 阿硯站在門檻內，看了很久，說：「我要留在這裡。這裡不搬。」父親問他留下來做什麼，他說：「看門。」母親哭了。父親沒罵，把背上的一個小包解下來，放在門檻上。
3. **前廳。**阿硯一個人走進去見翁敬亭，出來時陸沉在廊下等他。阿硯說：「我跟閣主說了，我留閣。推薦試我燒釘，不上台。」「為什麼？」「我家跟著宗門搬了四回。這裡，我想待著。」（現行 06-02 正文這段對話移來）
4. **夜值。**兩人值前廊。陸沉問：「你爹娘走了，你不怕？」阿硯反問：「你也要走了，你怕不怕？」陸沉答不出來。阿硯也沒等他答，起身去看門閂。

**連續性**：阿硯家與小宗門不命名。陸沉不勸、不插手。

**收尾與牽引**：→ 06-09 阿硯燒釘不爭對試；06-13「會不會回來」兩人份的重量。

### 第 06-08 章〈碼頭上的袋子〉

**時線**：十二歲開春，推薦試前三日傍晚｜洞天｜—。

**因果入口**：03-10 汪七的船位表貼在千礁傳送陣邊、排序看份額；06-07 費瑜買動執事排爐；06-01 彭渚在千礁仍是底層。

**場景順序**
1. **北岸。**陸沉送完簿，順路去看汪七的船位表——推薦若定，他得有船出島。表上還沒有他的名字。
2. **千礁碼頭邊。**天快黑，碼頭人散了。他看見彭渚蹲在棧橋盡頭，背對著岸，手裡一個灰布袋。彭渚把袋口朝下，倒了一半進海裡，倒出來的東西黑黑碎碎，落水沒聲音；再從腳邊撿碼頭上的碎礁，一塊一塊填回袋裡，填到原來那麼滿，紮緊。
3. 彭渚起身，看見岸上的陸沉。兩人隔著半條棧橋。彭渚把袋子背到身後：「千礁的東西，你少看。」走了。
4. 陸沉站了一會兒。他不知道那是什麼，也沒用雷絲去探。

**連續性**：陸沉不知袋裡是碎陣石；不連推薦試；不告訴任何人。彭渚不傳話給宋知微或任何人（審查 B2）。讀者知道一半。

**收尾與牽引**：→ 06-09 碎陣石裡夾著碼頭碎礁；06-12 領用帳；06-14 補網。

### 第 06-14 章〈補網〉

**時線**：離島前三四日｜洞天，星羅分身新架、手掌纏布｜手傷（06-11）。

**因果入口**：06-12 彭渚被千礁趕回島北漁戶家；06-08 碼頭上那句話；02-11 彭渚「血搬到後段了，還差一口」。

**場景順序**
1. **島北漁港，午後。**陸沉去北岸跟魏四確認船期，經過漁港，看見彭渚坐在一條漁船的船頭補網，手指被網線勒出一道道白印。
2. 陸沉走到船邊。彭渚沒抬頭，梭子一穿一拉：「千礁的爐，底下要看。」陸沉說：「看了。」彭渚的手停了一下，又繼續補。
3. 陸沉問他還開不開洞天。彭渚說：「天亮前出海，船頭風大，吐納比閣頂好。」沒說開不開。
4. 陸沉走的時候，彭渚叫住他，把腰間一片新削的木片丟過來——和從前那片一樣大小，還沒磨亮。「閣裡鋪底下落了一片，阿硯收著。這片你拿走。」陸沉接住。

**連續性**：兩人不說破碎陣石與那半袋。彭渚的去處不預定（可接卷八回鄉或第 10 篇）。

**收尾與牽引**：木片入行囊。
