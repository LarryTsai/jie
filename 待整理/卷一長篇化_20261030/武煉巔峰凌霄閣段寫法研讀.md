# 《武煉巔峰》離開凌霄閣前的寫法研讀

狀態：討論稿（2026-10-30），寫法參考，非 Canon。依作者要求研讀；只萃取寫法，不搬人物、橋段與措辭（[修仙故事創作準則](../../AI團隊/修仙故事創作準則.md)）。

## 讀了什麼

- 起點目錄：卷一〈崛起凌霄閣〉第 1–116 章、卷二〈鋒芒畢露〉第 117–217 章、卷三〈聲名鵲起〉第 218–365 章；第 366 章卷四〈翻中都〉起才離開凌霄閣回中都。也就是說，**主角離開宗門前寫了三百六十五章。**
- 逐章讀第 1–116 章（免費章；117–120 只有標題與開頭）。三份逐章分析在主 Agent 暫存區，要點已收進本檔。

篇幅尺度先記一下：楊開從淬體三層到開元用了 64 章，到氣動用了 156 章，到真元用了 259 章。一個境界、一座山、一次外出，動輒三四十章。故事寫得長，不是因為拖，是因為那段日子裡一直有事。

---

## 一、它怎麼寫故事：七件事

### 1. 窮和缺，是發動機

楊開幾乎每章都缺一樣具體的東西：這個月的貢獻點、香爐少的兩味藥、陽氣、種子、一顆能破關的丹。大欲望（變強、守住黑書）只說一次，之後全部翻成「眼前缺什麼」。缺了就得出門、得求人、得跟人交易、得冒險——事情就這樣長出來。

### 2. 一件事還沒收，下一件已經冒頭

第 18–19 章，進山晚歸那天，正好是蘇木帶人上門報仇那天——不是作者另起一事，是兩條已有的線時間表撞在一起。第 28 章，對手來找麻煩，主角先開價要草藥，報復者送來的正是他缺的東西。第 31–32 章，對手夜襲，被他忘了收的香爐毒倒。每件事收尾時，都把一個道具、人情或疑問交給下一件事。

### 3. 得到的東西，幾章內就用上

苏木送的丹換成陽炎石，兩章後拿來殺人；路上採的碧血玄陽花，二十章後被他故意丟下當誘餌，再循著它追殺撿丹的人。境界每六到九章升一層，升完兩到六章內一定被拿去打。新本事的限制也當場顯現（只能練半個時辰、陽液只剩幾滴）。

### 4. 金手指一次只開一頁，每頁都帶一個新缺口

黑書第一頁給金身，條件是「不屈」；淬體篇一天只能練半個時辰；香爐要有毒的藥；真陽訣要去外面找陽氣。金手指不給答案，給新問題，逼主角往外走。主角自己推論、自己實驗，讀者跟著他解謎。

### 5. 配角先有自己的事，才撞上主角

蘇木想追米行老闆的女兒；夏凝裳的職責是記錄戰績；夢掌櫃要扒皮賺差價；獵戶只是分他一頓乾糧。他們各自往前走，路線交叉時才成為主角的事。外出黑風山那一段，**所有敵人都是從宗門帶出去的舊帳**：吃醋的、替人報仇的、找失蹤弟弟的，三筆互不相干的帳被「楊開離宗」一個消息同時引爆。敵人裡每人各有算盤，主角贏，很大一部分是他們自己裂開。

### 6. 小事沿著人際一層層升級

魏莊打蘇木一事，從小輩毆鬥升到執法堂、師姐、情敵、長老殿，最後到掌門口諭，升了六層。每一層都是一個有私心的人推上去的，沒有人是為了讓主角過關而出場。宗門是一個社會，不是一張地圖。

### 7. 欺壓與反擊分兩種

同輩欺他，一兩章內自己打回去，方式輪替：動嘴、出拳、開價、拆穿、意外、硬碰。高一境、高一層的人欺他，不硬拚，記帳，變成修煉的動力，或由更高層翻盤。壓了 21 章才第一次真贏，中間每隔幾章給一個小翻身，讀者等得住。

## 二、對照我（AI）寫卷一時的毛病

這一節是作者要我做的「調整自己的邏輯」。

| 我的習慣 | 武煉的做法 | 我要改成 |
|---|---|---|
| 先立規矩再寫故事：必埋台帳、「全卷只說一次」「四字不改」、間隔 ≤15 章、守閣後 ≤20 章 | 沒有台帳，只有「他現在缺什麼」 | 規則留在後台當查核；動筆時先問「這段日子他想要什麼」 |
| 怕主角太主動：不還手、不告狀、不打贏、不學到教訓、不推論 | 主角章章想要、章章動手，有分寸地動手 | 主角可以要、可以爭、可以贏同輩；不贏的只該是真的贏不了的人 |
| 一章一個安靜小場面，做完就收 | 每件事留一個尾巴，尾巴長成下一件事 | 寫完一件事先問：它留下了什麼？誰會因此回來？ |
| 配角是功能位，常常無名，出一次就退 | 配角各有所求，一再回來，每次多揭一層 | 會回來的人給名字、給他自己的日子 |
| 得到的本事被規則封住（禁只一拍、「無新能力」） | 得到就用，用出新麻煩 | 新本事三五章內上場；限制也當場顯現 |
| 用刻度代替變強：歇四回→歇三回→歇一回 | 刻度有，但刻度之後一定有一場用它贏的事 | 刻度留著，加上「用它換來的那一場」 |
| 時間跳過：七到九歲幾個片段，十一到十二歲幾乎空白 | 365 章都在同一座宗門的日子裡 | 每一年都有它自己的事，不用旁白帶過 |
| 主角說過的願望沒兌現（「我爹的牆每年都裂」） | 說過的事一定回來 | 主角說出口的想要，全卷要有回應 |
| 以「沒人信他」反覆製造委屈 | 委屈之後很快翻身，翻身大一號 | 委屈是為了翻身準備的，不是氛圍 |

一句話：**我把卷一寫成了一份不能出錯的規格，武煉把凌霄閣寫成一段一直有事的日子。**

## 三、不能照搬的地方

- 楊開十六歲上下，陸沉在卷一是七到十二歲。孩子的「動手」是鬥鳶、搶缸、修鳶、記帳、在大人眼前搶先一步，不是殺人。
- 武煉的女角線、殺伐、以利為先的人情帳，與《劫》的基調不同，不搬。
- 《劫》已有 D157（陸沉真敗限額）、D097（強大分次露）、D098（修仙不是武俠）。孩子之間的比賽不算敗場，但不宜大量製造「陸沉輸」的場面。
- 武煉的節奏是兩千到三千五百字一章、每章切在最高點；《劫》卷一正文每章五千到九千字，質地較細。學的是事件怎麼長、人怎麼回來，不是學字數與勾子密度。

## 四、落到卷一的做法

見[卷一長篇故事](卷一長篇故事.md)。重點：

1. 每一年給陸沉一件非要不可的東西：七歲那塊浮石、八歲一口氣與一卷書、九歲第三段、十歲讓父親的牆不再裂、十一歲能把殘雷引出來的本事、十二歲推薦。
2. 讓會回來的人回來：彭渚（先來的學徒，取名）、坡尾的拾浮幫孩子（不命名）、費瑜提前上島；每次回來處境不同。
3. 新本事三五章內上場：導火→守閣後回家導開牆根的餘火；禁→在閣裡亂讀亂抽、抽壞一缸米；雷絲→坡上收錢、探人被記、探牆根碰到深處就退。
4. 十一到十二歲補成卷一第二座山：千礁修閣換脈釘手藝→費瑜來學燒釘→三次碰撞→彭渚倒掉一半碎陣石→推薦試與帳。
