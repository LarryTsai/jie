## 五原則與優先序

五原則（主角階段目標、挫折留後果、成長可見刻度、支線有去處、高潮有情緒回報）已併入 [修仙故事創作準則](../../AI團隊/修仙故事創作準則.md)〈讓日子推著故事走〉。優先序：主動性 > 事件回報 > 高潮情緒張力 > 配角獨立但交會 > 伏筆設定密度。
