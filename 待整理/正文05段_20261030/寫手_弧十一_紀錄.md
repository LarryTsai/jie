| 05-04 一次的價錢 | 林伯潮靠新西牆曬太陽，左手纏靈帛；給信物（像渡牌、補過七回、七個人的手）；「九界的人一年碰一回頭」「閣裡就三塊」「進去看。看見什麼想要的，自己去要」；坊市苟全老樹下秤靈石、草棚裡少年入定；一次三塊，隊頭兩塊半、後面的人湊一枚碎的；少年讓半步「閣頂那個」，「我不買」「閣裡發的？」「那你命好」；卞老攤東北角石頭被踢到路上、布角翻；他畫「一橫，一折，收住」，布不翻；卞老按布的手懸住、看角看人、沒問，把石頭塞進攤布底下；此後那角不壓石 | 全落地。禁一拍，不讀石頁、不講體系 |
| 05-05 外山的營地 | 半夜信物熱，七處補紋亮；阿硯捲被靠牆守、厄下巴壓在他手腕上不跟；入定見共天：無頂之天、四方光無影、灰白平地流紋、互不相連的山、光點落地成人（有角、有翼）；神識在這裡一直走不發虛；外山凹地，缺靈石少年營火；高個子佔暖壁，他以溝邊岔路換位置，畫在樹皮上；舊護腕（口音上揚）「畫這麼細，給螞蟻看的？」拿去找回滾進溝的水囊，「那塊活石頭，你畫得對」，讓出火邊半個位置；火邊各說明天去處（泉、劍碑、只是來坐坐），報宗門的被看一眼就閉嘴 | 全落地。不報家譜、不約重逢 |
| 05-06 雷山 | 營地散；舊護腕要去雷山「泡一個月，泡到它不怕雷」；火邊人說內山只放搬血洞天、裡頭養著一道星羅、找不到；同行；雷山是整座立起來的雷，雷流照出山裡還有一座山；外山眾人坐雷邊淬，老人坐細流正中；半山那條線，中年人走到線下像走進稠水，笑一聲下山；全場一片片靜下來：有人走在最粗的雷河中，雷落身上碎成光點，抬手抹臉像抹雨；陸沉神識探進去像往井裡扔石頭聽不到落地，猛收、手心汗；那人擰袖擰出銀光，一眼掃過，化光上天；舊護腕「我們那裡最高那個……他走在雷裡，像淋雨」；陸沉想起宮霽、三宗、翁敬亭；起身指那條線；「別散在裡頭」 | 全落地。不報境界、只寫看不透與尺度 |
| 05-07 最亮的 | 過線像被山掂一掂放進；按石壁見石中星河；每個岔口挑最粗最亮的走（不用多想）；到洩雷口：數十脈匯流往天上噴成倒流銀瀑、雷聲是吼；比守閣那夜亮十倍；對面一條更亮的縫，貼洞壁石棱走去；第三步右掌緣變光屑、左手也是，又邁半步、散得更快，停住；閉眼反而看見來時眼角留下的細流，一條條暗縫退回，找錯一次；手透得見光；跨線摔回外山；爬回營地，水囊抓不牢兩次滑落；舊護腕撿起放他腳邊「先拿著。拿不動就靠著」「你再不出去歸體，下回進來就沒有手了」；歸體：厄咬袖口拽，阿硯端飯在門邊，「你進去兩天了」；神識一放眉心如針，「還剩二十多天」 | 全落地。險些潰形是修行受挫，非對決 |
| 05-08 細的那一路 | 第五天眉心脹，閣頂看伏雷坳灰白一明一滅，在場地想起十歲坐兩天、第三天說「現在」；對照雷山一眼都沒多看；第七夜重入，營火剩兩堆、位置空一半，舊護腕留下燒焦纏布，新來的說「前天往山上去了」；他在線下坐著看雷潮整輪：漲時亮的全往洩雷口、每回路不同，退時全暗；第二輪只看暗的，幾條細銀漲退都在、路從不變、往山身正中去；過線順細流擠窄縫；岔口遇舊護腕（看了那人後決定進內山、外頭泡不夠），互報那條到底是牆、洩雷口過不去；「別散在裡頭」「你也是」；左縫轟亮，他轉身擠進右邊細的；縫到頭，一片大暗，正中一點銀光慢慢轉 | 全落地。可埋「不追最亮的」以動作埋，不說出口 |
| 05-09 失敗 | 山腹：點聚成圓、旋臂綴光點，轉過之處四壁脈、礦、裂、凝光一一亮起，像夜空翻過來扣在頭上；第一回伸手，十歲以來的承導路比念頭快，肩下一轉、腰、腿，銀雷穿腳底打上石壁，一點不剩；第二回堵全身，三條雷亂竄撞在胸口，胸口透明擴到手臂，鬆手跪地；縫口外舊護腕右手整隻焦黑，並肩喘、互不問；灰袍與皮甲幾人越過他先前歇腳處進縫；歸體，共天第十九天，阿硯化半粒母親寄的養神丹餵他；閣頂一遍遍走運轉，阿硯數到第三遍：「你每到拐彎那裡就快。」點肩下、點腰；西牆根林伯潮搭脈量「比去年寬，這條路能裝三圈」；問怎麼接，「你去看」，不給答案 | 全落地 |
| 05-10 星羅 | 第二十四天，灰袍那幾人已搖頭走了；不伸手，看銀雷整整轉一圈，看出到彎會慢、會自己轉；想起伏雷坳、阿硯的手指；第一縷進來不送不堵，肩下那一轉按住想快的勁等它自己轉，到腳底不出去、繞回掌心成一圈；第二縷胸口一段擠不過，放走，下一圈因前一縷走鬆而過；接得住留、接不住放；第五第六貼著一起擠進，掌緣又散、手腕淡，「三圈」，把硬併進的兩條放走、守住三圈，掌緣凝回比原來實，再一條一條引回；山腹銀光縮進他身上，最後一團白藍落進掌心慢下來，龍眼大，像縮小的星河留住；山腹暗，四壁脈剩餘光；他笑出聲撞回來；出山營地收火、光點往上飄；把水囊放回舊護腕空乾糧袋旁；石上一片粗刻樹皮，畫的正是那條岔路，「刻得一點也不細，可是一處也沒錯」，活石頭刻成大圈；自行歸體；黑屋裡掌心一點銀光，厄抬頭看很久、鼻尖碰他手指 | 全落地。勝就寫勝，不接傷病抵銷 |
| 05-11 雷絲 | 星羅沉在胸口底下不走；第四天抽出第一縷雷絲；先探厄，牠甩尾跳開，他換到窗臺另一頭坐著等，太陽挪過窗臺，牠爬上膝，再搭線才看見牠彎得奇怪的暖脈；第七天鮑十一在山門外托人傳話，「你那雙眼睛，能不能幫我看看，哪塊要落？」問完就等；「能」；季後沉回坡上的浮石因地裂坑歪脈歪而亂擱，他一塊塊把雷絲送下土看脈斷不斷，挑出九塊，看到第三十塊手指抖；祠堂屋後那塊一拽，坑正塌在他說的地方；父親端水、不說話；「明天」；回閣林伯潮伸手「搭」，經脈裡一團團暗紅殘雷，只試腕邊最外一團；引得出，暗紅不走彎、直撞，與星羅一碰運轉岔亂，老人扣手拔出；「今天到這。往後再看。」；他認定「不是不會引，是盛不住」「明明能行」；夜裡試離身卷，輪廓立一息從頭頂散，阿硯夢話「又是半個你」；黑暗中一縷雷絲送到燈芯又收回 | 全落地。被問了才出手（反線）；未用摘要替他完成突破 |
| 05-12 蓄 | 十二歲浮石季第一批木梆響，他在閣頂不看；一年後雷絲能伸到缸那頭、同時三根，但收回指尖即散；阿硯「鮑十一問了兩回你來不來」；整季不下山，宋知微在石臺下記了什麼；對林伯潮那一縷念念不忘：他盛不住；除夕閣頂兩人吃偷來的年糕看坊市符火，「十二了」；開春大霧清晨，石臺浮在霧上；不往外放、一縷縷收回壓在胸口，第三縷經脈脹燙、指尖抖、要炸，他不鬆；丹田底下一道門被撐開（像井冰被漲水撐裂），三縷沉進深處有了地方待；霧被吸進的氣捲成一圈繞石臺；林伯潮坐缸邊不知多久，等他走三遍運轉穩住才開口「坐著，別起來」；想試雷被看一眼閉嘴，一炷香插在缸沿裂縫；搭脈停在門前很久，「洞天。」；下午試：一縷雷絲進出不散、鑽過石臺入山循脈深探自止；神識身後有線繫在門裡，遠到港邊仍不飄；林伯潮忘了毯子，他搭在臂上下石階，指尖繞一縷雷絲收回門裡 | 全落地。破境在場；為 06-01 擋神識、06-02 探爐底鋪來由 |

## 必埋、可埋與約束守約

- **必埋 7 浮石**：05-01 口袋捂溫、05-03 閣頂與第七段兩次摸口袋（大綱口袋 05-03）；腳不碰浮石。
- **必埋 1、3、11** 不涉；未近似重複「你在下面等」。
- **可埋「斷階殘字」05-03**：摸過每道都斷，讀不出；不上頂、不用禁。
- **可埋「不追最亮的」05-08**：只以動作與選擇表現，全章不出現這句話。
- **暗排「名字與事件」**：05-02 人群喊「又是陸家那孩子放的？」、卓青問「去年停在半空那隻，也是他？」；05-03 鮑十一朝閣頂點頭；05-04 讓半步「閣頂那個」。無人叫「劫」或「劫族」。
- **暗排盲點／反線**：洄辛拒絕二他聽了（05-01）；被問了才出手（05-11 鮑十一先問、等）。
- **禁的時序**：05 段只在 05-04 布角一拍；星羅六章（05-05～10）不用禁，共天裡看見的紋不讀不拆；05-02 不用禁、不用雷。
- **定案 18／05-02 約束**：他不踏浮石、人在祠堂門檻；不追、不打、不指認；抓人查處歸觀潮；皮老鴉自己跳艇；沒畫符、沒改符，只改翼摺與鉤位；不寫事後說明、不寫反省燒手。卞老「這隻，不是客人要的那一隻」回扣 03-09。
- **約束 05-10**：第一雷熔成即與當下修為相合，掌心那團直接留住，無半成品階段。
- **約束 05-11**：不用摘要完成新突破；突破在 05-12 在場寫。
- **石頁**：本段未出場，只寫布角「從前壓的是那片舊石頁」；不讀、不發光。
- **禁止清單**：無長亭天、長子、指骨暗示；無「仙王」「禁典」；無「以後你就懂」。
- **時序**：05-01 入冬近十一歲；05-02 第一批前四天修鳶、第一批當日局崩；05-03 同季第三批與當夜／翌晨；05-04 過年後（季尾除夕已滿十一）；05-05～10 同一次共天開啟（第 1、3、5、7、19、24 天）；05-11 共天後早春；05-12 十二歲浮石季→除夕→開春。共天開啟時點緊接年後為本稿工作安排（見疑慮 4）。

## 疑慮與 Canon 待核

1. **斗笠客是否即皮老鴉**：章綱寫「面生的人（無名）」，又寫「他約定由自己在低崖數兩下」，而低崖斗笠人斗笠落地是皮老鴉。陸沉 01-14、01-18 已兩次看清皮老鴉的臉，本稿以「斗笠壓低、只露下巴、新留鬍渣」讓攤前認不出，局崩時才與全坡同時認出。若原意是無名中間人，只需把 05-02 攤前客人改成另一人、低崖斗笠人另寫，約三句。
2. **陸沉是否預見火會燒回放線人的手**：本稿不寫他事前想到這一層（不加內心說明），只寫他見火往下走立刻喊「鬆手」。Reviewer 若覺得讀者會質疑「他明知袋落鳶線仍讓孩子拉」，可在 05-02 改鉤處加半句動作（如他多看了一眼鳶線線軸），不寫解釋。
3. **母親在 05-02 現身上玉膏**：章綱是父親「叫人帶他們去敷藥」；本稿改為父親回頭喚屋裡的母親出來上玉膏（祠堂即家，母親是藥修），避開「敷藥」。屬小改動。
4. **共天開啟時點**：設定只說一年一個月；本稿排在年後緊接，讓 05-11 早春鮑十一找他看季後沉回坡上的浮石。「季後浮石沉回坡上、因地裂坑歪而亂擱」是本稿為落實章綱「地裂後浮石落得亂」的工作細節，不升 Canon。
5. **閣裡信物「就三塊」、苟全「一次三塊靈石」、草棚入定**：新工作細節，不升 Canon。
6. **共天物品**：水囊、樹皮、乾糧袋都寫成共天裡的東西，沒有帶回肉身（05-11 刪去樹皮在枕下的寫法）；舊護腕的護腕與手臂焦痕是形體的。
7. **舊護腕的去向**：本稿讓他自己在內山泡手臂（右手整隻焦黑），與星羅不爭；他最後是否得手不寫。若將來要回收此人，屬「跨大境界帶可新造」範圍，不受舊人優先限制。
8. **05-12「洞天。」**：首次由人物口中點出主角境界名；前序正文已用過「洞天」（02-11）。若希望只寫象，可改為林伯潮只說「開了。」。
