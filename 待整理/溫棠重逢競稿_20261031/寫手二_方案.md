# 寫手二方案：同路人——她找到了那條路，代價是十七年回不了家

狀態：溫棠重逢競稿第一輪，寫手二。**候選，非 Canon**；新地方、新機制、新人物皆標工作設計，待獨立 Reviewer 比較後送作者選。場景試寫標「試寫／非正文」，不得擴寫成正式章節。未讀其他寫手方案。

## 一句話與核心取捨

**一句話：**溫棠要找「一條九界自己能走的路」。截殺那一夜，她燒掉命牌牽著的那一點神魂，把照水尺釘進水眼，自己掉進正在開窗的低路，活著落到聖土。她在聖土量了十七年，把只靠口傳的窗口曆量成兩岸都對得上的曆。回到九界時，她的命牌早就熄了；照修士的律，人還在走、牌已經熄，就是奪舍。

**核心取捨：**她不是被誰藏起來的受害者，是自己選擇繼續「死著」的同路人。前幾年是傷重，窗也還沒開，回不去；後來是她選了把一整個窗期量完，選了不讓殺她的人知道那扇門還在，代價是裴照川、許成蹊和量水山為她白白付了十七年。重逢時兩人的關係倒了過來：當年她教十五歲的他「先看原陣」，如今他替她走完了醫所、結了她的案；她替他、也替九界走完了另一半。兩人各欠對方半條路。

我保留派工給的「同路人」傾向，沒有推翻，理由有三：一、Canon 早已把她的動機寫成「舊渡口可能成為九界自己開路的起點」（主線推理骨架 B2），讓她活著把那條路走通，是兌現，不是另起爐灶；二、長亭的新簿本來就「兩岸紀錄雙存」，她的歸來與九界有自己的簿是同一件事的兩面；三、做對手的話，會把一個「量不準的事不愛替人下結論」的人改成陸沉的反派，不合人物。

## 一、她怎麼活下來

### 那一夜（約陸17.4歲，Y880前後，工作值）

溫棠為核實後裔村的口傳獨自上路，Canon 的這一步不變。口傳說的是：千溪原上游那隻水眼，平時只在汛峰張開；**每隔十七年左右，會在無汛的日子自己張開一次，那幾日它不是水眼，是一扇門。**（工作設計：千溪原水眼是一條低路的九界端口，屬「仙界端殘骸落在九界邊緣的險地」；聖土端是封合縫雷域的另一段，不是陸沉十八歲走的那一段。）

誘引信寫的時刻，是開窗那夜子時。帶令者翟七按分段命令，帶著僱來的本地人手提前到水眼邊截殺，以藏曜遮住現場，再布成涉水意外。這些全照 D059、D066 與第12篇。

她打不過。列陣中段對天然列陣加一群人手，又被藏曜遮住了眼，她只量得出水被動過，看不見是誰。重傷倒在水眼邊時，她做了兩件事：

1. **燒掉命牌牽著的那一點神魂。**量水山弟子都知道「牽」落在自己神魂的哪一點。那一點是她當時唯一能燒、燒了還不會死的東西，燒出最後一口力：前半口寫進照水尺，讓尺記下截殺地最後一段水紋（包括那塊藏曜空白與雙汐潮紋），再把尺釘進水眼的石喉，這就是 Canon 的後手；後半口護住心脈。
2. **自己滾進正在張開的水眼。**殺手以為她會淹死在這個無底的洞裡；她知道這是門。她是列陣，低路放她過。

命牌堂看到的是：活水一點一點收，像燈油燒乾。這正是**散熄**的紋，而她確實是自己燒乾的，不是秘術騙出來的熄，完全合「騙不出熄，要熄只能真斬」。熄的時刻在誘引約刻之前，第12篇「命牌早熄」這條證據**一字不動**。

### 過縫

縫雷落下來縫天，她在昏沉裡踩到一段剛縫上的亮線，沒有被雷打第二次。代價是左肩到右腰一道斜疤，像一行粗針腳，是縫雷在她身上縫過的痕。

### 為什麼人前要當她死了

依序分三層，一層比一層由她自己選：

- **前三年回不去。**她傷到第三年才能遠行，而千溪這一條要再過十幾年才開窗。別條低路的窗口在聖土另一頭，也不通量水山。
- **她選了不傳訊。**從聖土往九界遞話只有一條路：望歸通譯館經越裳上界，走的正是上界的簿。殺她的人她看不清，只知道是「上面」，也知道他們殺她是為了這扇門。消息一旦傳出去，門會被封，後裔村也保不住。人是她引去的，她不肯再引第二次。
- **她選了量完。**她要做的是兩岸都對得上的窗口曆，必須在聖土端看完一整個窗期，中斷一年就前功盡棄。有一次她明明能動身（陸沉二訪聖土的年份），她沒走。

在九界與上界，沒有任何人知道她還活著。背曆的婆婆只看見她掉進開著的眼，不知道她過去之後是死是活。

## 二、她不在的這些年（約陸17.4–34.4，工作值）

### 她想要什麼

和生前一樣，找一條九界自己能走的路，只是現在她知道那條路在哪裡，也知道它有多窄：只容列陣以下，十幾年才開一次大窗，過縫會死人。她要把「十七年碰一次運氣」量成「看得懂、算得準、別人也走得了」的路。

### 她怎麼過

| 年（陸沉年齡） | 她 | 事件與改變 |
|---|---|---|
| 0–3年（17.4–20） | 列陣中段，傷 | 落在封合縫雷緣，被一家縫民採晶戶撿回去，家長是採晶婦**妮薇**（工作名，非A類，聖土寫手可改名）。她靠後裔口傳裡零碎的聖土舊詞開口說話。神魂少了一點，從此神識只有原來七成遠，終身不補。 |
| 3–8年（20–25） | 列陣後段 | 用《水紋經》量縫域的雨。錯接的地方兩邊的雨往不同方向下，她從雨的方向讀出界壁哪裡在靠近。縫民靠這個少死人，叫她「量雨的」。她開始把妮薇家採晶的路線、時令和她的水紋記錄對起來。 |

| 約11年（28） | 北崖譜房 | 她以縫民雨錄去薩內爾翼會北崖譜房換抄錄避雲紀錄，翻出一疊九界記法的校對：一站一站從受雷擊的舊痕往回看原痕，再把數百年的改道疊成一條會呼吸的線。譜官說，上一個來抄這份的，是個九界雷修，十八九歲，境界欄填不了。她認出那是「先看原陣」的看法。**她的天上那一半，是站在他的校對上做成的。** |
| 12–14年（29–31） | 選擇 | 陸沉二訪聖土，名聲傳到縫緣。她知道那個九界雷修也許就是當年南院的少年。這時她離量完一整個窗期還差三年，離開縫緣，記錄就斷了。她沒去。 |
| 15–17年（32–34.4） | 量成 | 兩岸窗口曆成形：水的一半是她的，天的一半是避雲紀錄加他的校對，九界端還差後裔口傳那一半，要回去對。她用縫雷落過的雷晶殼和縫域的水石磨了一根新尺（**兩岸尺**，工作設計，一般法器，不升品）。妮薇送她到窗口，只說一句：「我兒子那段，你算進去了沒有？」「算進去了。」 |

**有沒有人知道她活著：**聖土那頭只有妮薇一家和幾個縫民知道，北崖譜官只知道有個量雨的九界女人；九界與上界一個人也不知道。

## 三、重逢

### 時點、場合、在場者

- **篇位：**新增 **81A〈千溪倒流〉**，插在第81列〈兩宗清算與第三宗故人〉的下界印期之內（約陸34.4，第26篇奸細罪撤銷之後、第27篇第三份探查記之前），兩夜一日，從第81列日帳的「餘裕」支付。列號不順延，比照85A體例。
- **在場：**陸沉、溫棠、背曆的婆婆（第30列千溪原那位只抱祭燈的老婦，既有工作人物）。
- **起因：**婆婆八十多了，十七年一次的窗又要開。她託孫女把一句話送到太玄：「上一回窗開那夜，溫姑娘在眼邊。」十七年前她沒對任何人說，是後裔的規矩；如今她說了，是因為怕殺手再來，而祭陣曾為這個人亮過。
- **她帶回來的新處境：**
  1. **照律她已經死了，而且看起來像奪舍。**命牌熄了，人還在走。要證明她是她，需要一件沾著她死前神識的舊物，與她現在的神魂共鳴；她的遺物早在「熄後一旬」分掉了，只剩一件從沒進過遺產的東西：**借給陸沉、又被陸沉還給許成蹊的那枚勘測玉簡**。玉簡在許的懷裡，許在上界。
  2. **她是從聖土私渡回來的。**奸細罪剛撤銷，一個九界人在聖土住了十七年、又從沒人知道的低路回來，這件事一公開就會被拿去重開。
  3. **她手上有兩岸窗口曆**，正是當年她被殺的原因，如今量成了。
  4. **她還沒面對裴照川。**

### 81A 事件鏈

1. **倒流（試寫）**：開窗夜，一千條溪倒流進水眼，天被縫雷一針一針縫起來，她踩著剛縫上的線走出來。陸沉壓著列陣、身帶錨印，站錯一步就會被捲進聖土、構成破印。他先看她的原陣，認出不是奪舍；她叫他退後半步，然後問玉簡在哪裡。
2. **官樁亮了**：對岸玄殿的官樁陣盤記下這一夜的錯接。陸沉能以〈活修〉讓陣盤少記這一夜。溫棠攔住他：「抹了，就是一塊空白。我尺上那塊，就是有人這樣抹出來的。」他沒動手。**後果：**玄殿官樁上從此有兩筆相隔十七年、形狀相同的錯接，量得出這是一扇會開的門。這筆記錄長亭之後會被玄殿翻出來，成為她仙途的長線對手（見第四節）。
3. **燈下三半**：後裔村，婆婆屋裡。她攤開兩岸曆：水的一半、天的一半，再請婆婆背出九界端那一半，第一次三半合在一起，算出往後的小窗（工作設計：每二至四年一次、每次一夜，只有兩岸合算才看得出來）。陸沉在天的那一半上認出自己十八歲寫的校對。「北崖那幾十頁，是你？」「是。」
4. **兩人的帳**：她問自己是怎麼死的。陸沉說了涉水意外、照水尺、雙汐，案用她的名字結了。她沒問下令的是誰，只問雙汐那一夜的潮紋：「原來那叫雙汐。」那道紋她記了十七年，叫不出名字。陸沉再說裴照川：越界、挾官、錯傷許成蹊、挾寇平、寇平被剪、自請受審、十年刑役剛滿。她很久沒說話，然後說：「他替我走的那條，不是我的路。」陸沉也說了寇平那一下是自己強啟陣盤造成的。她說：「那一下，你沒先看。」他說：「沒有。」**改變：**她不再是只會教他的長輩，他也不再是她的學生。兩人互相說出對方的錯，誰也不替誰原諒。
5. **約定**：她要三件事：玉簡、一本九界自己的簿、親口告訴裴照川。陸沉答應不替她說，也答應把話帶給許成蹊。天亮前他回清算的行程，她留在後裔村。

### 試寫｜千溪倒流（第81A列，試寫／非正文）

> 只用來檢驗三件事是否可讀：人前已死的人從縫裡走回來；用「先看原陣」辨認真身；重逢帶出新處境，而不是互報近況。不是正式章節。

子時前一刻，千溪原的一千條溪同時不走了。

水沒有乾，一條一條亮在月底下，像整片原上的弦都被人按住。背曆的婆婆把祭燈擱在水眼邊的石頭上，燈芯剪得很短。陸沉認得這盞燈。那年汛水漲到最高，她什麼都沒帶，只抱著它上了高地。

「上一回開窗，」她說，「溫姑娘就站在你現在站的地方。」

陸沉往後退了一步。他身上壓著列陣，錨印在骨頭裡。這種夜裡站錯一步，人會被拽到另一片天底下，回來就是破印。

然後溪倒著走了。

一千條溪一齊調頭，往上游、往水眼裡流。水眼張開，水柱直立起來，越立越高，頂上那一段天忽然錯開：另一片天疊在千溪原的夜上，那邊正下著雷雨，雨斜著往另一個方向落，這邊的月光照不進去。

第一道雷落下來，在錯開最狠的地方拉成一條亮線，久久不散。第二道，第三道。一針一針，把天縫回去。

陸沉認得這片天。十八歲那年，他就是從這樣的天底下掉進聖土。

亮線上有個人。

她走得不快，每一步都踩在雷剛落過的那一段：剛縫上的最穩，雷不在同一處落兩次。她從水柱頂上一針一針往下走，踩著最後一針，落到岸邊的濕石上。鞋是濕的，左肩到右腰斜著一道疤，像一行粗針腳。

婆婆跪了下去，沒出聲。

陸沉沒動。他見過那塊命牌，活水停了，清得像冰。牌熄了，人還在走，修士聽見這句話只會想到一件事。他掌心扣著一縷震魂雷，先看她的原陣。

列陣，到頂了，壓在門上，壓得很久，很穩。《水紋經》的路子一圈一圈走，該停的地方都停一拍。沒有第二層疊上去，沒有被誰對齊過的痕。只有神魂裡缺了一點，缺口齊整，像是自己燒掉的。

奪舍藏不住層疊。這是她教的。

他把震魂收了回去。

她也在看他，看了很久，像在量一段量不準的水。

「南院讀禁的那個。」她說。又看了一眼他身上壓住的東西：「壓著的。壓了幾重？」

「很多重。」

「退後半步。」她說，「窗還沒關，你身上有印。」

他退了半步。

「我借你的那枚玉簡呢？」

陸沉愣了一下。她以前從不記得要。

「還了。給了許成蹊。」

「好。」她點了一下頭，像一筆帳總算對上，「我要用它證明我是我。」

身後的天還在一針一針地縫，水柱矮下去，一千條溪慢慢轉回原來的方向。她蹲下，把手伸進退回去的水裡，停了很久。

「他們記的是什麼？我怎麼死的？」

「涉水意外。」陸沉說，「後來不是了。案結了，用你的名字結的。」

她沒有問是誰。她問：「那間醫所呢？」

「找到了。牆上留了一句話。」他說，「撤令早於停兵，我們留下。」

溫棠的手還在水裡。過了一會兒，她說：「我找了十年。原來是這句。」

對岸，玄殿的官樁陣盤一盞一盞亮了起來。

## 四、對主線的影響

### 溫棠案揭曉那天（第46列雙汐，約陸23.5）她在哪、知不知道

她在聖土封合縫雷緣，第六年，列陣後段，正在量雨，**不知道**。她第一次聽到「雙汐」「岑越」「翟七」，是十一年後在千溪原從陸沉口裡。雙汐那一夜萬人看見藏曜輪廓與照水尺的空白同形，與她無關，是陸沉、許成蹊和那把尺做成的。這個勝果完整保留。

### 溫棠案、讀者挑戰書：不改答案，只補一層

- 下令者岑越、帶令者翟七、提前截殺、命牌早熄、藏曜空白、雙汐潮紋，**全部不動**。她活下來不是因為殺手手軟，是低路恰好開著，加上她自己燒魂。殺令照樣下了，也照樣執行了，岑越的罪名是下令殺人，不因她生還而減輕。
- 結案的意義不變：案以她的名字結，量水山命牌堂裡照水尺旁那塊熄牌也一直留著。補的一層只在81A之後：熄牌不等於她的魂散了。這一層對推理公平：Canon 寫的是「水停了」，散熄的紋本來就是「燈油燒乾」，她確實是自己燒乾的，沒有任何先前的證據說謊。
- 註：主線推理骨架與 D059 記溫棠案挑戰書已由 D067 撤銷，任務單仍按 D066 列為挑戰書。不論採哪一條，答案都不變。
- **可選的公平線索（加在第30列，不改事件）：**許成蹊帶命牌來那天多一句：「值守說師姐的牌熄得慢，像有人一口一口把油喝乾。」散熄本來就是這個樣子，所以不算洩底；重讀時才看得出那是她自己燒的。

### 奸細罪：不碰

她的歸來排在撤銷之後（第72列之後）。她之所以繼續隱身到長亭，就是**怕被拿去重開**。撤銷的三條根據（自願歸還界屑、寇平證詞、罪名句式同構）都不涉及她。

### 岑越線，順手補「終身禁錮」與「至尊守潮門」之間的缺口

這一條與溫棠方案無關，可以單獨採用。建議補一句：朔河的「終身禁錮」執行成**禁錮於潮門**。禁制釘在潮門上，他一生出不了潮門的範圍。禁錮中仍可修行，到第85列已是至尊；「帶族人守潮門」是因為他走不了，不是被赦免。
可選的一場（第85列時段，只加不改）：溫棠以尊者之身經正規界路到朔河潮門，看了一眼下令殺她的人。他從沒見過她的臉。她只說：「我是溫棠。千溪那扇門，今年走了十一個人。」說完就走，不清算，也不原諒。這是她自己的收尾，不分走陸沉第85列的任何事件。

### 她回來後的長線：同路人兼九界的守路人（A3 理由）

我不把她做成陸沉的對手。她作為 A3 的理由是：**她是九界自己那條路的守路人，也是全書唯一一個有資格對陸沉說「你沒先看」的人。**她的長線對手是「對齊」的一方，也就是想把千溪這扇門收進上界官史與上界簿的人。

## 六、風險與待作者裁定

**最先要問作者的一題：**「人前已死」允不允許是她自己選擇延續的？也就是說，第三年以後她其實可以設法傳訊卻沒有傳，裴照川的十年刑役、許成蹊被錯傷、寇平被剪，都在她不知情、也沒救援的空白裡發生，她回來要承擔這份重量。這是本方案的核心，如果作者要她是完全身不由己的受害者，方案會改成「前十年在縫腔裡出不來」，同路人的分量會變輕。

其餘風險：

1. **新增九界端口與小窗**屬世界層新設計。Canon 允許端口多條、各自開窗，但「兩岸合算才看得出小窗」等於把低路變得比較可走，要守住 Canon 定性的「走私道、流亡道，不是戰略通道」：只容列陣以下、一夜、會死人。須世界編劇核。
2. **燒牽**是 D082（作者定）的延伸用法。我刻意讓它是真熄，不是騙出來的熄，但仍要作者確認「本人燒掉牽點，紋同散熄」可以成立。
3. **陸沉站在開窗的水眼邊**，帶著錨印、壓著列陣，有被捲入的風險。試寫只用來營造緊張，**他沒有被捲入**。不可借此新增一次聖土行或破印。
4. **81A的日帳**：從第81列「餘裕」撥兩夜一日，須核那段日帳仍有餘裕，不夠就延後到第82列下界前的短印。
5. **裴照川刑滿後留在渡劫淵**是我補的工作設計，用來說明重逢前他為何不在九界；如果其他來源已排他刑滿即返九界，就改成「溫棠請陸沉不說，她在等新簿」。
6. **長亭的增筆**：長亭是32章的大篇，我只加三拍（門外、復名、可選守點），不動作者既定的總名單與點名。可選守點如與借脈機制不合，直接刪掉。
7. **與裴照川怎麼收**：我建議**不直接復合**。他為她犯的罪她不收，十七年也不能當作沒發生；但她讓他護自己的關（75A）。要不要再走到一起，留給作者。
8. **新人物**：妮薇（縫民採晶婦）、背曆婆婆的孫女，都是非A類的工作人物。溫棠本人已是A3，沒有新增A類。D165舊人優先：重逢與後續用的都是許成蹊、裴照川、寇平、背曆婆婆這些舊人。
9. **D157**：本方案陸沉沒有任何戰鬥，沒有敗場。
10. **順手發現的來源衝突（不在本題範圍）**：[第30列大綱](../../大綱/01_少年/27_溫棠與四院選拔/大綱.md)寫「一位叫晁不疑的後裔交給他一枚傳訊玉符」，[其餘九庭人物](../../設定/03_人物/05_三十二天/其餘九庭人物.md)則記晁不疑是商應璋的至尊幕僚、不下九界，話經玄闕信使帶下。兩處身分不一致，請主 Agent 另案處理。
