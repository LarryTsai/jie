## 不可被整理改掉的作者裁定

九界奪冠後領通行印、自主分路，陸沉先返宗、太玄閣與家鄉，返鄉清算後追上界仇敵，受傷墜入聖土；不能再把大比前安全抵達寫成返鄉。第一次聖土先求回三十二天，因尋路遇修行機緣；第六雷殞星在首訪，第九雷九霄在第二訪遁一，火蓮反向啟發雷丸不提前。

第一次、第二次、第三次聖土目的不同。曉有自己的行動，不能成為所有奇遇的操縱者；歷史真相分階段揭露，不提前公布祁承朔，不減輕太宸責任。正式正文依[全書大綱完成前凍結](../../../設定/00_故事定位/02_工作規約/大綱完成前正文凍結.md)，本區樣稿只作檢驗。

八身救生為作者明確豁免：卷篇大綱的〈九界金丹_封傷與八界取材〉、〈卷七_九界金丹〉與本區〈八身救生_八路故事與後續人生〉、〈八身救生_完整工作弧與交叉節奏〉、〈八身救生_百日聯排與傷後決定〉維持原檔，不因本輪年表及清理改寫。

## 本輪獨立審查

九個舊工作目錄收成七個主題，故事完整後才移除過渡資料。獨立Reviewer先審追讀、人物自主與修仙戰鬥，再核來源、時間、交通、揭露及效力。王室段八四項實讀通過；原薄弱的屋頂與九霄已展開，火蓮不是永久實物、封寒新舊傷分清，均經覆驗。其餘各組的具體審查與尚待裁定內容見各主題入口，不用分數代替批准。
