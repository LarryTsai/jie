# 界屑事故

[界屑與寇平故事線](../../../../大綱/01_少年/23_九界大比與返鄉/界屑與寇平故事線.md)保存作者採用的領印日完整事故、留舟島生活與襲家拒證、怒闖警告，以及歸墟吞入至大羅／入極撤罪的持物鏈。

事故在奪冠慶賀隔天，〈循〉首用於劫強啟受損陣；成人方案只損寇一重，劫的方案令其破印被剪，責任不推暗殺。界屑首次聖土靜默，不能導航或跨界。寇平拒他人材料，住陸家、拒費兄指認、封地窖口保留。

善意之瞞未採，十五年揭謊／焚誌決裂／和解已撤；譚晚潮、塔姆林、封寒壓尊一年與否認簽名不是必做待辦，不保留一份暗示應復活的附錄。寇平剩餘境界若日後要正面戰鬥須配當場承載，現故事不造完整恢復能力。
