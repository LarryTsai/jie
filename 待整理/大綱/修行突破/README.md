## 先讀故事

三位寫手已各自交出完整候選，而非照抄提案的問爐／死軌／百煉三題：

- [甲：懸雷崖爭骨](../../競稿/雷身重煉/甲.md)：兩季機緣，對手帶走煉入背骨的成果，劫用逐雷與可破外釘真正爭回最後骨紋。
- [乙：雷鯨遺蛻](../../競稿/雷身重煉/乙.md)：對手先贏兩場、煉自己的移動道場，最後毀鼓反制；女骨修得盾先走，劫放掉三筋全取，贏可帶走的身法。
- [丙：倒掛骨河](../../競稿/雷身重煉/丙.md)：模仿者先勝、再學主角九禁封窟，主角以重新煉過的承雷身與本地女修爭回半片髓石。

獨立比較只推薦乙，五項必修已實改、正式接口經同一位未參與寫作的Reviewer覆核。甲丙未採，留競稿追溯；乙只升為唯一工作核心，沒有升格Canon。

## 已落地的連續故事

**先在驤鳴拆活路，再在成仙後真正重凝雷身。** 劫不是等傷好就復原：他主動撤仍可用的返力禁路，暫時變慢、輸掉雷鯨爭場兩次；賀逢山先煉移動道場，第三戰還毀自己的鼓反制。劫真放掉完整三筋，以不同雷性重新配合爭回上行位，短筋片實測後耗盡。辛照晚取骨盾後按自己船期離開。

- [第21篇](../../../大綱/04_成道/01_一炷香與至尊之年/大綱.md)：第20段加返力小量對練前因，原20段不增。
- [第23篇](../../../大綱/04_成道/03_驤鳴/大綱.md)：15→28事件章段；原生死、公告、醫道與聽斷完整保留，新增13段雷鯨爭場與有限重組。
- [第24篇](../../../大綱/04_成道/04_碎錦原/大綱.md)：17段不增；至尊領陣者反用新法連壓，逼出一身九主雷首次真正承載。保現行戰前療養回合，未修改正式設定的戰後明文。
- [第25篇](../../../大綱/05_入極/01_玄闕祖脈/大綱.md)：19→23事件章段；新增一具星羅身仍快而好用卻自願撤形，帶真傷收源、等待不能展、第四日凝形失敗、第六日重凝成功，失快讀、贏穩定辨收。祖潭外陣短承仍是另一個要親自失敗與練成的機緣。

這是分段改造的一條完整工作故事；未宣稱全體雷身都完成同樣重凝，也未復刻舊8→0→8。其餘活身仍須自己實修、共域同劫。24合身時點及25展形詞義的正式來源差異留效力邊界，命圖全重鑄／全雷清零／死源重造未採。

十八境盤點另提出六個不重複的突破候選，最優先是20.5神火、24真一、25首次天神；本輪完成來源與具體故事種子，不把六案直接塞進正式大綱，更不聲稱全書突破已補完。聖祭不強排，37歲主角仍真仙。
