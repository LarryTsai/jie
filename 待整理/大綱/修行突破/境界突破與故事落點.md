## 六處真正缺口：可以放進現有篇中的故事

以下全為 **[I]新候選**。姓名若新造只屬工作設計，機緣是本次事件中的選擇，不是全天下突破必備材料。每次共同破境均須全部現存雷身達標並在同一劫域；不把留遠處的雷身犧牲掉以避門檻。

### 一、十五歲銘紋：他刻的是自己，不是古神

**承載：少年卷十一〈神州東境〉（總覽11），十五歲。** 不改禁都地方比試得丹方玉簡的作者裁定，不把文奕家學或全部禁都人收編曉。

1. 劫要在集合期限前證明自己能布一座獨立的禁；文奕要讓家學的原陣用途被承認，兩人不以同一目標陪跑。地方比試原賽制、名次仍待選，以下不預定劫第一。
2. 新候選禁師同輩**岑照**擅長將自己的紋藏進器物。他選同一場地，故意讓劫先讀器上的漂亮古紋，再換掉真正供力的一角；劫靠拆別人的禁追回局面，卻發現自己的承載也跟著崩。岑照是真正贏了這一局，不因劫有雷便送分。
3. 兩人反解古禁取得完整文字後，劫試刻其中一式，身上的雷一換性質便衝掉原紋。文奕拒絕替他把自己的雷紋抹成古人的雷紋；他要的是保住原用途，劫要的卻是刻出自己的路。
4. 劫帶三身回到同一處修行，改刻能由自己承力的紋，不求完整古式。他進銘紋的可見結果：器被岑照取走後，他仍可由自身紋續起**自己布的禁**，在公開再驗中保住有限區域，不能因此改寫別人的完整禁。岑照仍保有器道所得與名次權利。
5. 所得是自己的承法紋；代價是報廢試板、耗材與一場真敗。完整禁典需後續系統學習，丹方現在仍不能煉。此段不要擴成第二場五域大比。

### 二、十七歲列陣：不是四種雷各贏一場，而是整個人站得住

**承載：溫棠與四院選拔。** 醫所受傷先治穩、四雷已消化，不能用破境洗掉柏鶴齡接脈與生接不回的既有因果。

1. 代表名額將定，北院皇道同代要爭自己的資格。他不是劫的陪考者：場上逐角佔地，逼劫在千相誤判後一再拆自己的佈置。
2. 劫此前以外陣補身內未成系統的缺口；對手連拔地上四個支點，四雷每一種仍強，卻無法令同一擊完整落下。輸在自己的架構，不是裁判臨時封雷。
3. 文奕能指出哪個介面壞，不能代刻陸沉的體內陣。封寒守自己的劍路，雲也按自己的恢復狀態配力；四人不集合給劫送材料。
4. 正式破境落在兩次選拔實驗之間的共同劫域。劫把承力與轉換做成體內可運作的陣；再戰北院同代時，對方照樣能拔外陣，卻拔不走陸沉身內的連續供力。劫靠同場真打取得代表資格，別人仍可憑專長得額。
5. 列陣是新結構，不是立刻九禁、更不是第五雷。代價保留神識負荷、千相混用失誤與備戰時間；無間航道才取得第五雷。

### 三、20.5歲神火：沉船裡有人也在等自己的火

**承載：第9篇多宗獵殺／九弱沉船，仍屬待補篇的核心候選。** 不把古船自動接古戰、仙庭或曉。

1. 被追殺的劫想搶在封海前離開，沉船裡卻有一道能讓他看清自身神火路徑的舊護舟火。新候選尊者**阮扶舟**是失船家族後人，先於劫潛下去；她要帶走祖爐、維持自己的渡舟行當，不願交出全火。
2. 追兵中的神火強者封住船外，兩人先為火爭鋒，再發現舊爐起火便會暴露船位。劫的雷能裂封，阮的舟法能過潮，誰也不能一人拿全所得逃走。
3. 中段反轉：祖爐不是替後人備的升級丹，它當年靠吞舟材續燃；若把火全取走，船腹會塌，另一隊還在內的修士便出不來。阮寧可失去整爐也先帶活人，並非聽劫一說才覺醒。
4. 劫放棄整爐，與她爭取切下一縷可帶走的殘火，再以既有尊者手段穿過封堵；不能先用尚未取得的神火持續承法或天神空間能力解圍。阮取回家族可用的爐骨，劫取得修行引子，不建立「此火人人必需」規則。
5. 脫離追兵後，全部現存雷身集於可承劫處。首次點火試驗燒壞承載，劫終於停止把神火當第七種雷，選擇以自己的修行維持火而非吞掉全部舊火；20.5首次神火。
6. 第二次追擊才驗新境：他能持續驅動原本續不上去的護身手段，但依然不敵追兵首領的完整神火修法，靠阮已掌握的潮道撤出。勝利是奪路與保有所得，追仇沒有因此結束。火的具體修煉本質仍須由設定核定，不能拿[P]概述冒充[J]。

### 四、24歲真一：把自己的命拿回來，才有錢談保證

**承載：第13篇程式未決。** 法定保證與還界屑程式不能被突破取消。

1. 斷命樓阻斷劫籌取保證資源，設局讓他追一位扣住資源的真一殺手；生正在辨別不同脈與九弱兒的護道需求，不能全程停醫道為劫開問心課。
2. 殺手不辨真假分身，而是把劫每次換身後尚未穩住的回應節拍當破口，逼他以替換逃命。這是一次具體技法對局，不宣稱所有真一都克雷身。
3. 劫搶到資源卻失去退路；殺手故意留一條「再換一身就能走」的路，等候同源再傷。生只能指出哪次強行接力會致傷，不能替他回答哪個才是真我。
4. 劫把現存身召回同一可承劫域，拒絕以「留一身死掉、其餘便是真我」取巧；完成神火至真一後，再設局逼殺手出現在他能連續承法的範圍。新境實證是換打法不再被對方固定節拍截斷，不是獲得免疫本源共傷。
5. 他擊敗殺手、取回一筆實際保證資源，代價是追查身份曝光與籌資期限更緊。真一不證清白，仍要赴渡劫淵及正式還界屑程式。此候選需補完整殺手本體戰法與真一能力核定，未選以前不寫入正式第13篇。

### 五、25歲天神：雷能打碎那塊巖，卻打不到巖後的人

**承載：第14篇渡劫淵，首次取歸墟前後、赴九界及鏽回之前。** 裴刑、生死古骨、十二劫反派與誤納界屑保持原介面，不新增天神能自由跨雙界的能力。

1. 劫追歸墟與可補保證的所得，十二劫反派要取走生死古骨的一段痕。兩方各有目標，不是對方特意替劫設突破課。
2. 淵中候選奇觀是一片看得見卻走不到的層巖：聲音與碎石往返，兩個落腳面卻相隔一層。劫用雷炸開表面，對手從另一層取痕；舊境能破巖，不能完成真正的空間定位。
3. 裴刑能護住他選定的退路，不能替劫把全部寶物端出。中段對手搶先取痕，使劫必須在放棄古骨、奪歸墟、護那家兒的既有承諾間付出實際取捨。
4. 雷種與境界分開兩場處理：先釐清取得／熔煉歸墟的先後，待全存活身滿足同境同劫域後，才在25歲破天神；不可一句「吞雷順便突破」，也不能在赴九界後靠錨印自動破境。具體先後須第14篇競稿確定。
5. 新境驗證是定位兩個既有空間面、搶到退路上的真實一擊，擊敗同境追奪者；不是任意改寫空間或穿越封界。取得歸墟仍可能誤納界屑，程式與路身鏽化照來：更高境界沒有救掉後面的跌境。
6. 本輪只補首次天神承載。第15篇重破天神與第八雷／合爐只記受保護總覽介面，不代審不重構。
