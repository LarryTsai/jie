# 太玄宗 R2：寫手討論會第二輪

狀態：第二輪討論紀錄（2026-10-03），主持人整理。五位寫手讀過彼此 R1 後各自回應七個分歧，最後是「共識與仍對立之處」。**不是定稿**，待 PM／作者裁定。
依據：[東溟（二）太玄宗簡報](../東溟_二_太玄宗.md)、[R1 節奏與鐘](太玄宗_R1_節奏與鐘.md)、[R1 人物與情感](太玄宗_R1_人物與情感.md)、[R1 宗門生活](太玄宗_R1_宗門生活.md)、[R1 修行與成長](太玄宗_R1_修行與成長.md)、[R1 少年群像與犯蠢](太玄宗_R1_少年群像與犯蠢.md)、[新卷一](../../../../大綱/01_少年/01_浮石之下/大綱.md)（人物表：費瑜「新卷二入宗選拔」）。

七個分歧（簡稱）：①鐘　②礦谷與卷收　③新角　④霧鐘島與封寒化靈　⑤費瑜　⑥師兄姊寫法　⑦卷二的節奏與鉤子。

## 一、節奏與鐘

**立場**

- ①**主鐘仍是古雷脈重鑿告示**，但我接受它不是唯一的鐘，條件是所有鐘貼在**同一面主峰牆**上：重鑿告示、爐位牌與帳頁（宗門）、上一屆十人的榜（群像），讀者只要經過那面牆就知道三件事走到哪。副鐘我收兩個：貢獻帳（宗門的短針，而且重鑿本來就徵工、以工代修，帳和主鐘是同一筆錢），以及鎮岳四試（修行；考不過延一月，正好給中段一個會跳的日子）。**我反對把病人的斷脈當鐘**：「撐不過一年」是醫療倒數，會把共爐續脈寫成救命驚悚，也等於卷一「災朝他來」換張臉。十人選拔維持遠鐘。
- ②礦谷入卷二，五人一致，不再爭。卷收我讓一步：最後一章是**十人選拔告示貼出那一夜**（人物、群像要的那一夜），但它前面必須是古雷脈「只接回一半」。化靈不放卷末：兩儀、承身、化靈三個力量節點擠在最後二十章，卷二就變成「數量加一」，正是修行寫手自己在 R1 第〇節警告的事。
- ③**一人**。三個〔新〕合成一個：同舍（滕北的功能）、九霄、在古雷脈洩口以工代修時被回流打斷雷脈（我的鐘）、共爐的病人（簡平的功能）、續上後轉職事軌、進不了十人（甘樸的功能）。名字交 PM。
- ④霧鐘島卷三。封寒先入化靈：若作者確認〈劍吟〉最低境就是化靈，我接受，而且它正好填我 R1 第 42→57 章那段最長的空檔（痛點：朋友先上去）；若只是候選，不要為它硬改時點。
- ⑤費瑜要出場（卷一人物表已寫他在新卷二入宗選拔），**一場、錯身、不搶名額**。過或不過我都能接，但不能變成孩子們揭穿他（卷一已定「本卷不被孩子揭穿」，選拔場上也一樣）。
- ⑥群像寫，挑二三位深寫；深寫的人要在主鐘需要時出現（回流那一夜鎮岳頂住）。
- ⑦水平取代垂直、約取代謎、選取代等。章末鉤子請各組照「少謎多約」寫，三個戰績數字（池杳、封寒、帳）要真的出現數字。

**最想採用的三個點子**

1. 宗門的「七盞燈」（第一夜看七峰的光，鎮岳一片黑）：水平感最省字的一個畫面，放第 1–7 章之間。
2. 修行的「又在吸」回聲：第 7 章某峰長輩閉關、靈田減產；卷末換他讓別人罵（即使化靈移卷三，也可以在承身凝成時讓鎮岳後山的田減一次產）。
3. 群像的「師兄姊當年也去過礦谷，是韓鐵衣叫回頭的」：前面的山也是孩子變的，而且不花章數。

**最反對**：修行 R1 第 38 章讓他在古雷脈現場**當眾說出「先停再修」**。說出口就把〈活修〉的起點寫成他的勝利（或寫成峰主們不聽勸的蠢），兩邊都毀；他應該當夜一個人看出、對封寒說「不確定」。

## 二、人物與情感

**立場**

- ①我 R1 的「外鐘十人＋內鐘病人」讓一半。結構上的主鐘交給古雷脈告示（看得見、會移動，我同意節奏說的「鐘是一張紙」）；但**鐘要落在一張臉上**：牆上的日子每被劃掉一次，就要有一個人瘦一點、傷一點。我收回「撐不過一年」這個倒數（節奏、修行的批評成立），改成：病人在共爐前**一直躺在丹閣**，每次分身去當差都看見他；不倒數，只在場。
- ②礦谷入卷二。我仍要「這才第二道」在全卷後段而不是中段：所以順序是**共爐（中段收）→ 礦谷 → 承身 → 古雷脈一半 → 告示那一夜**。「需藥」全卷只傳一次，必須跟著礦谷走；古雷脈之後節奏 R1 第 71 章又傳一次「需藥」，請改成別的（例如他什麼都不傳，是生自己來）。
- ③一人，同意節奏的合併。我只堅持兩件：**他要有名字和臉**（共爐需要一個讀者在乎的病人），以及**他活下來、換一種活法**（不死人）。宗門的收尾我照單全收：雷脈斷了的天才轉去排爐位牌。
- ④霧鐘島卷三：礦谷那夜的封寒要是還沒定型的封寒，「怕和想知道同時在」才成立。封寒先入化靈：情感上我喜歡（他第一次打不贏朋友），但只在一個條件下：**不能讓礦谷變成封寒帶他飛**；兩儀熔煉仍只能陸沉一個人，封寒只守外圍。
- ⑤費瑜：一眼。他在選拔場上神識掃過一排孩子，陸沉這次沒擋，因為有考官在；他第一次看見規矩會替他擋。不給台詞。
- ⑥我 R1 給六位師兄姊各一個場景，讀了修行與宗門之後我承認那是簡報禁的模板。改法：場景保留其中三個（沈山河「這座峰不說這句」、柳青藤「這是我的亂」、韓鐵衣「我沒看見」），因為這三個都長在他的盲點梯子上；秦照雪、陸行烈、顧小滿的台詞拆進修課與飯桌，不單獨成章。
- ⑦日夜兩軌，加上我 R1 的翻轉：**卷一他是唯一看得見的人，卷二他是每個人眼裡被看穿的那一個**。這不是節奏手法，是每段關係第一場的寫法。

**最想採用的三個點子**

1. 群像的韓鐵衣「先看退路」：和我的「我沒看見」接成一條，礦谷前夜他在山門讓路說「先看退路」，礦谷後丟外衣說「我沒看見」，前後兩句，就是他信任的開始。
2. 宗門的「兩欄 → 爐位牌」：病人最後在蘭嫂手下排牌，把陸沉的名字掛在牆上，掛的還是最底下一格。
3. 修行的托壺偷用雷絲被判不過：這是他盲點（以為自己的辦法比規矩好）落在修行上的最好一場，和柳青藤、生的「問了被拒」同一條梯子。

**最反對**：群像 R1 第 66 章礦谷後**傳「尚安」說謊**、回宗被叫全名。它把全卷唯一一次「需藥」換掉了：這一卷他學會的是「向人要」，不是「從小就用短碼騙她」（那是七折的喜劇，不能在礦谷這一夜用）。

## 三、宗門生活

**立場**

- ①我 R1 的帳頁是短針、終試到終試是長針。讀過節奏之後我同意主鐘換成古雷脈：**重鑿本身就是宗務**，徵工、以工代修、器坊缺礦、名冊，都是帳上的條目，我的帳不必另立一根針，直接掛在重鑿告示旁邊（爐位牌與告示同一面牆，我接受）。「帳赤到頂、暫停領料」仍要保留，作為礦谷的少年動機：去找礦是去還帳，也是替重鑿補料。終試長針我放棄當鐘，第二次終試改成可刪的尾聲（見下）。
- ②礦谷入卷二；礦交器坊折成貢獻，**帳第一次轉正**要在礦谷後出現一次。卷收同意「一半」＋告示那一夜。我想保留最後一頁的一個畫面：他在告示牆前，牆邊爐位牌最底下一格掛的是一個新來的孩子（不必寫第二次終試整章，一行就夠）。
- ③一人。滕北併入。我 R1 給滕北的四個功能（大閣子弟對照、九霄雷法的代價、病人、職事軌）合併後都還在。**群像的甘樸請刪**：R1 寫他是「赤霞峰外門」，太玄宗**不設外門內門**（D073），這不是措辭，是整個身分軌／職事軌制度；修器的功能交回胥匠與秋澗，合夥欠帳的欠條改簽在器坊帳上即可。
- ④霧鐘島：卷二最多一封信，回島卷三。封寒化靈不表態，只提醒：若有人破境，就要寫吐納讓靈田減產、雜務上門算帳，這是宗門的日常面。
- ⑤費瑜**必須出場**（卷一人物表已寫），而且要用宗門的規矩處理他：他走另一處閣的推薦進選拔場，向松登名、終試由宗主親問；我傾向群像的「被刷下」：卷一的規則買得到推薦，太玄宗的規矩買不到山門。這是卷二對「規矩」最乾淨的一個證明。
- ⑥依功能，但我要補一條：**每位師兄姊至少一刻不是在教他**（沈山河挪份額給顧小滿、陸行烈差點失控、韓鐵衣坐最遠的凳子）。他從旁看見，學到的是這裡每個人都在撐自己的事。
- ⑦水平之外加縱深：一件事後面還有一個管它的人。鉤子除了「約」還可以用「帳」：月底對帳就是一個每六到十章撥一次的小鉤。

**最想採用的三個點子**

1. 節奏的告示牆：日子被劃掉重寫、名冊貼出、撕下換十人；我的爐位牌就掛在旁邊。
2. 修行的「又在吸」：長輩閉關、靈田減產、雜務罵人，是宗門經濟和強者高度同一件事。
3. 群像的「合夥欠帳」：一張欠條把兩個少年黏在一起，帳本就是友情；欠條簽在器坊帳上。

**最反對**：群像的甘樸（「赤霞峰外門」）。功能可以給合併後的那一人，設定上的「外門」不能進卷二。

## 四、修行與成長

**立場**

- ①我 R1 的鐘是十人＋四試。我同意主鐘交古雷脈告示（節奏的「會移動的紙」比我的遠鐘好用）。**四試保留為中段的短鐘**：「不准借雷」是卷二修行的脊椎，托壺不過延一月、只剩肉身的一個月、鎮鈴斷一根白線，這些日子要掛在牆上一樣的明確。我同意節奏與人物：病人的斷脈不能是倒數；洞天經脈傷依自癒表一兩月，「撐一年」沒有規則背書。
- ②礦谷入卷二。我讓兩件事：
  - **化靈移到卷三**（節奏、群像的批評我接受：卷末三個力量節點太擠）。卷二保留「三身共同破境卡在洞天圓滿」作卷末的修行狀態：星羅分身因白天煉丹落後，他知道要破境就得停丹閣任事、斷收入。卡住本身就是接卷三的鉤，化靈在卷三十人選拔中途破。
  - **「先停再修」不當眾說**。我 R1 第 38 章是錯的；照節奏，夜裡看出、只對封寒說「不確定」。代價改由其他事付（夜出山門被藏玄記下、扣貢獻）。
  - 順序我接受共爐在礦谷之前：劫痕「引」來自星羅，不需要兩儀。
- ③一人，病人由古雷脈回流造成（我 R1 第 40 章的調度和節奏一樣），合併後的同舍、九霄、職事軌都接受。
- ④霧鐘島卷三。**封寒先入化靈我仍主張**：武學譜〈劍吟〉習得在礦谷，若最低境定為化靈，封寒就必須在礦谷前入化靈，這是規則推出來的，不是我想要。但它確實只是候選，請作者裁；若改成「劍吟最低境洞天」，封寒與陸沉同在卷三入化靈，我 R1 的第 44 章改成「師兄打不贏」。
- ⑤無立場。費瑜的神識掃人是同齡人的力量刻度（卷一已用過一次），卷二不必再用。
- ⑥**依修課功能出場**是我 R1 的主張，不改：韓鐵衣主考踏罡托壺、柳青藤分傷、沈山河示範、陸行烈燃身是反面教材、岳沉淵主考鎮鈴。人物要的三場可以全部落在這些功能裡（柳青藤「這是我的亂」可以發生在分傷之後）。
- ⑦刻度變細：上來之後第一次看見上面一格一格。強者只寫規則後果，不報境界。

**最想採用的三個點子**

1. 節奏的古雷脈告示牆：八峰合力只接回一半，是全卷最高的「仙人的厲害」，放卷末比我放中段好。
2. 人物的岳沉淵「自己弄的傷，要報」：當成鎮岳的第一條規矩，和四試「不准借雷」一起立，兩條都是「不准偷」。
3. 宗門的帳：三身共同破境卡住，代價直接落在帳頁上（停任事、丟爐位），多身從「好方便」變成「好貴」。

**最反對**：人物 R1 的「簡平撐不過一年」內鐘。沒有醫修規則背書，而且病人倒數會讓共爐變成搶時間的救援戲，壓過「兩人一起承」這件事本身。（人物已在本輪收回，記錄在案。）

## 五、少年群像與犯蠢

**立場**

- ①我 R1 主鐘是十人榜期。我接受古雷脈告示當主鐘，只要它和十人的榜**在同一面牆**；我的每段收尾「回看榜牆」照樣成立，只是牆上多了一張重鑿告示。但我要求：末段十人的分量要升上來，告示貼出那一夜讀者要感到「這一桌明天要被拆開」，不只是「卷三開始了」。
- ②礦谷入卷二。我 R1 要收在選拔前夜；改成收在**告示貼出那一夜**可以接受，條件是最後一章是**全桌最後一次「今晚去看看」**（爬上鎮岳臺頂看七峰燈火，青璃說「順路」）。古雷脈一半放在它前面，我同意：一半之後全桌去看燈，正好是不同形的收尾。
- ③合併成一人，我同意，而且我讓出甘樸：宗門指出「外門」違反 D073，我接受。但甘樸的核心功能必須給合併後的那個人：**這一桌裡進不了十人的那一個**。雷脈斷了、轉職事軌、坐在石凳上算全桌的帳；比甘樸更痛，因為他本來是最有可能進十人的。
- ④**霧鐘島我仍主張卷二**，放陸沉閉關凝承身那段（陸沉本來就不在場）。理由：「以後不許有人瞞我」要在卷三開場前定型，卷三起陸沉每一個沒說的秘密才有重量。可讓到宗門的版本：卷二只寫一封信和封寒回來後變了一點，那句話留卷三。封寒先入化靈我反對：約練是這一桌最好玩的固定節目，朋友先上去之後約練只剩「拖」，中後段的少年感會掉一截；作者若定〈劍吟〉最低境化靈，就讓它發生在礦谷之前很短的時間內，不拉長「打不贏」。
- ⑤費瑜**被刷下**。規則能買到門口，買不進山門；他只出現在選拔，第 28 篇照回。不讓孩子揭穿他，是規矩刷掉他。
- ⑥我 R1 也給師兄姊各一場，本輪改成依功能（同意修行）；但保留一場**全峰的戲**：顧小滿說漏六人當年也去過礦谷、是韓鐵衣叫回頭的。那不是教他，是上一屆的孩子。
- ⑦人數分段（一個人 → 兩個 → 一桌 → 一整座峰 → 兩個 → 全部）可以和節奏的分段疊用：犯蠢合夥、罰合罰、帳合帳。每段收尾要有一次「今晚去看看」的鉤。

**最想採用的三個點子**

1. 人物的「礦谷那一夜寫滿」：封寒坐的那塊石頭、劍橫在膝上、每隔多久回頭看一次雷光；第 19 篇他要交出去的每一樣實物。
2. 人物的韓鐵衣「我沒看見」：接在我的「先看退路」後面，一前一後。
3. 宗門的爐位牌最底下一格：卷末合併後的那個人把一個新孩子的名字掛上去，或把陸沉的名字從最底下往上挪一格。

**最反對**：修行 R1 的**化靈收卷末**。卷末是全桌最後一次一起去看燈，不是他一個人破境、被頂回、被罰；（修行本輪已讓到卷三，記錄在案。）

## 六、共識與仍對立之處
