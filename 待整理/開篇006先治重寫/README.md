# 開篇第6章〈先治〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。災後傷者持續上門，陸沉在門邊提燈、不問傷者是誰；父母各自做事，飯反覆等到人走才端上桌。歪落浮石傷者帶來拾浮幫線索與第二批墜海、剩兩批的消息。母親只在怕苦的受傷孩子面前先喝一口丹湯，不把這個動作寫成她平常對所有人的習慣。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照修仙生活與人物來回共同推進。本章把外部局勢放在傷者自己的生活裡傳進陸家：老採石人一邊換藥一邊惦記坡上的人，第二批落海後仍靠著門框想去看；父親也沒有只當背景，回家後默默把冷飯重熱、收木料。陸沉的修行等級沒有增加，卻開始以提燈和讓路參與這個社群，選擇不追問來者身分。對照後保留急事中的家常動作，並讓「先喝」只為眼前那個怕苦孩子發生，避免重複到變成母親的固定劇情招式。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。

## 覆核

- 時間維持地裂後第十六至十八日；陸沉可坐在門邊提燈，沒有新增行走能力。
- 母親先治傷者、老手提供地裂夜拾浮幫與第二批作廢消息、照章綱保留剩兩批。
- 母親為特定怕苦孩子喝一口丹湯，沒有把這個動作寫成習慣；它可與第7章七歲那次相互照應，但兩次關係情境不同。
