# 討論區工作規則

先讀根 [AGENTS](../AGENTS.md)與 [ROADMAP](../ROADMAP.md)。本區放競稿、任務單、審查往返、舊稿與原始討論，不放第二套現行正式來源。

創作與審查讀 [AI團隊](../AI團隊/README.md)共用準則及派工角色。大篇、核心弧及作者否定後重構依三寫手規約：同一邊界、第一輪互不讀方案、各寫專屬檔案；每人交完整故事，至少兩項核心差異，不是場景換名。世界與長線支援不得洩漏競稿者構思。未參與構思者比較閱讀欲望，再核邊界；全弱可全退重構。

選後由主 Agent 整理唯一工作版本入正式區，標明效力與作者批准範圍，更新相關總覽；原稿留追溯。已選版本可迭代，不為每次窄修重開競稿。整理、PASS 或提交不等於 Canon 升格。

正文仍凍結；檢驗大綱的樣稿標「非正文」，不得擴寫成正式章節。作者投放區不屬此區，禁止搬入、刪改作者原文。禁止覆蓋其他 Agent 工作檔。
