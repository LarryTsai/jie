## 主編取捨

同意 Reviewer：**融合，三層疊成同一部歷史的三個面**。
- 紀元刀口用丙的四次天象：九界都看得見，各界叫得出同一個名字，又和 D213 咬合。
- 少年段讀者摸得到的人和物主要取甲（補紋年輪、殘槎、守門）。
- 上界段的權力史取乙（拉天夜只裂不低、澹臺問保下帝批頁）。
- 降重三條：
  - 每紀最多兩位具名傳說人物。
  - 三層分在不同讀者時段：九界層在少年段，上界層在飛升後，天象層只在作者層。
  - 紀元名只由人物在事件中說出，不列表、不講課。

已查清：Canon 裡約三到四萬年前衝準仙帝劫失敗、神魂全滅的就是祁承朔（D042）。乙、丙的指定沒錯。

## 待作者裁定（一題一題問）

1. 太宸在祁承朔死前就已知情，他的沉默裡要不要加「護子」動機？主編建議不加（碰 D088，會分走「只顧關門」）。**作者裁定（2026-11-27）：不加。**太宸知情仍照烙「重」，不寫心裡想什麼；丙稿「護子」一層撤。
2. 「斷年」（共天有一年沒開）要不要成為九界共同的歷史事實？連帶決定轉角由誰發明。**作者裁定（2026-11-27）：要，用斷年。**轉角用丙的一折，甲的時折併進這個人，不另立；斷年與第一爐養壽丹同年。
3. 拉天夜與「帝在，王不相伐於帝前」舊約要不要一起入 Canon（接受只裂不低）？**作者裁定（2026-11-27）：要，只裂不低。**拉天夜與舊約來歷一起入 Canon；天裂一夜，九界高度不變，越托越低仍只由 D213 負責。
4. 主編可先處理、作者知道即可：丙「越托越高」改為「托高不變」；丹丘第一爐年份對上陶令儀「數萬年」；紀元名不做公開課。

5. 「沉鳴」（封界後九片天又落一萬多年、共天一次沒接通）要不要成為九界共同記憶？覆核認為與斷年同類，應問作者。←**目前在問**
