## 設定狀態

- **已選方向**：來源明確記載作者選定的大方向，細節仍可能未定。
- **候選**：正在考慮的方案，不當成已發生的史實。
- **待設計**：目前沒有答案。
- **設計採用**：作者授權本輪設計後，選用一套具體名字或規則繼續工作；不表示作者曾逐條口述，新場景也不因此自動定案。
- **正式定案**：後續由作者明確確認，記入決策紀錄後才使用此標記。

兩份探索資料沒有整體升格為正式設定。母稿負責試寫人物與世界；各主題文件管理已整理的方向與問題；原始來源保留討論脈絡，不覆寫。若後續作者明確修正，以決策紀錄及更新後的主題文件為準。
