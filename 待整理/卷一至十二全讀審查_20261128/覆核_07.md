# 覆核 07：卷四〈兩儀雷淵〉修寫結果

> 覆核人：審查員 07（審查_07 的作者）。依 [修正_07](修正_07.md) 逐條對照，實讀 `git diff -- 正文/01_少年/04_兩儀雷淵`（17 檔）的改動處及前後文。未改正文，未做 git。

## 結論

- 必修 1 條、建議 4 條、記錄 3 條（07-08 拆成 5 小項），加上第四節 5 項，全部有處理。**關閉 17 項，未關閉 0 項。**
- 沒做的兩件（小粟與護腕的去處、補樁老人段不縮），理由都站得住。
- 沒看到改壞的地方：沒有旁白說理，修仙用詞沒有新錯，降頻後的句子都讀得通。
- 有三處可以順手再磨（07-03、07-05、07-06），都是記錄級，不影響關閉：
  - 07-05 新加的一句地理寫法和前文略有出入；
  - 07-03 器坊那場，「時辰、地點」由胥匠說出；
  - 07-06「那一行數還要再長一截」的因果稍虛。

## 逐條

| 條號 | 判定 | 理由 |
|---|---|---|
| 07-01 必修 報帳清單兩遍 | **關閉** | 05-03 的七行清單刪了，換成「每一樣後頭補一句丟在哪裡。寫到礦，筆停了一下，才落下去」。郜三秤的加總和「頭一個記帳的」都還在，人物戲沒少。05-04 改成「眼睛往下走，走到最後一行」，只唸「礦兩袋，剩一袋」和「另一半沒帶出來」，下面直接接「夜出兩次」。帳味去掉了，「這次報了」的分量反而更集中。 |
| 07-02 建議 06 段單據太密 | **關閉** | 06-08 不再唸單子內容，挪班保留（滕北那一場要用）。06-09 記單那場壓到四行，「鎮岳記鎮岳的，我記他的」單獨成立：前一章剛誤過一爐，讀者不需要「守火那一具」那句也懂。06-07 第一、二條合成一句唸，韓鐵衣一句「兩條都真的」，本尊說一聲「是我」，顧小滿晃腕接得上，後面「伍岑念下去。三，……」也順。06-06 排班簿沒動，我原審查本來就沒要求改，理由成立。 |
| 07-03 建議 陸沉被動 | **關閉** | 06-07 加了兩行：他往九霄峰頂那片雲看一眼，說「這一條，我記住了」。語氣是他的，不頂撞，也和 07-03 開頭「九霄峰頂壓著一大片雲」呼應上了。07-01 刪掉「他答應了」，改成天沒亮承身進器坊說「那一把，我叫」，決定發生在場景裡。時序我核過：入秋當天凌晨胥匠說「明天午時」，正好是 07-03 的入秋第二天，接得上星羅身早上報外爐、牌子「從昨天早上掛到現在」，沒有矛盾。可再磨（記錄）：「明天午時。外爐。」現在由胥匠說出，等於時辰地點是別人定的；改成承身說「明天午時，外爐」，胥匠只把火鉗擱回砧邊、點一下頭，主動性會更完整。 |
| 07-04 建議 封寒在卷尾消失 | **關閉** | 07-03 牆頭靠東那一頭加了封寒一筆：劍在鞘裡往雲那邊偏，左手垂在腰側，身子沒被帶走。沒有台詞，也不搶星羅身的戲，04-06 和 06-08 兩處都回扣到了。和本章現有細節不衝突：同一場一百一十九把鑿子的紋都「像被叫了一聲」，鐵器對這道雷有反應，劍跟著偏一偏說得通。修寫者說已核過卷五 08-03 和 01-01，無衝突，我沒有另外重核卷五。 |
| 07-05 建議 沈山河無反應 | **關閉**（附記錄級窄修一處） | 06-04 補苗時，沈山河放下大石，揀了最小一塊扁石擱在陸沉手邊，說「這裡缺一塊」。回扣 01-01 他遞最輕那袋，不揭答案，人物語氣對。新出的小矛盾在地理上：「往峰後那條下坊市的路看了一眼」。前文去坊市都是出山門走石階（01-04、02-01），靈田在後山（06-03），「峰後下坊市的路」沒有出處，讀者會以為多了一條路。改法：改成「又往山門那頭看了一眼」，或「往北邊裂谷那個方向看了一眼」。 |
| 07-06 記錄 夜出動機 | **關閉** | 回山石階上加了封寒那句「三成，抵不了那一行數」，以及陸沉想到胥匠說的「等不了」，「急」有了。原本含糊的「他說」也改成「封寒說」。可再磨（記錄）：「下個月再來，那一行數還要再長一截」，前文沒有帳會隨時間變多的設定，可以改成「下個月再來，還得再支一筆」。 |
| 07-07 記錄 說話人與語意 | **關閉** | 改成「陸沉說」和「那一扯，你記錯了人」，兩處一讀就懂。 |
| 07-08 秦照雪重寫 | **關閉** | 第二次改成她挪半步、用肩擋在他和爐口之間，接一句「他骨頭上的紋跳了一下」。動作不同了，又和 01-04「骨頭上的紋輕輕跳了一下」形成一條可追的線：她在擋他的雷靠近寒爐。 |
| 07-08 顧小滿五指 | **關閉** | 豎到第五根，朝自己鼻尖點一點，第五條她扛了，意思清楚。「一根一條」稍帶旁白解釋，但很短，可留。 |
| 07-08 用詞 | **關閉** | 靈圃、靈膳用的靈草、外敷的丹膏、換一回膏、丹單，都對。〈需藥〉是章名不改；淬骨池的藥力屬體修淬體用語，理由成立。 |
| 07-08 小粟、護腕去處 | **關閉**（轉主編，理由成立） | 這兩件要卷五以後的章綱或伏筆台帳接，屬大綱區，不該在卷四正文硬收。 |
| 07-08 02-01 空格 | **關閉** | 刪掉「頭三天空了過去」，改成「跟上一旬一樣」，和後文「下一旬，照舊」「明天辰時開爐」一致。 |
| 四節 合歸回顧收章 | **關閉** | 只留 06-05、07-03 兩處。06-07 章末改寫成隔天走樁慢半步、已經知道爐房的靜和滕北的筆、峰後的霜化了，不再回顧，讀起來比原來輕。06-09 只留雷擠一擠，加上銅匙收回右袖袋那一下，第二十七天的前提還在。07-01 刪掉「疊回來」兩句，直接接本尊想胥匠那句話。 |
