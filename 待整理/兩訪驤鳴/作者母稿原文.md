# 《劫》｜兩訪驤鳴：八身救生與跌境重修

> 詳細候選故事母稿。依 GitHub《九界金丹》《八路完整工作弧》《驤鳴：雜工看天驕》、D062、D064，以及作者提出「先返太玄、再赴驤鳴」方向整合。新增場景與對話尚未升格 Canon。

## 一、為何這條線值得保留

驤鳴界是故鄉長亭天以外的八界之一，天冊原名「西之六・騰驤天」。陸沉第一次以雷身前來，是為了救洛生衣；第二次以道基破碎的本尊主動前來，是為了重修九雷。雷身就是他本人，回歸融合後完整記得第一次的交情。這不是兩個主角，更不是萬俟箏第二次才認識他。

| | 第一次《九界金丹》 | 第二次《驤鳴重修》 |
|---|---|---|
| 時間 | 約27–31歲工作窗口 | 約32–33歲 |
| 陸沉 | 八具雷身之一，合法壓境 | 道基碎裂、列陣以下的本尊 |
| 目的 | 取救生丹材 | 重新理解九雷承力 |
| 朋友 | 萬俟箏、斛律鳴、伶素 | 故人萬俟箏，再認識赤翎、賀逢山、辛照晚 |
| 情緒 | 強者願意向當地人學習 | 故人看見他最弱的一面 |

**不可改的硬條件**：本尊始終為昏迷的生以雷導氣續命；八具雷身出發、七具依法入界、凌汛一具止於上端且空手；九身合爐與八道撕痕；新經歷必須融合才完整交換。雷身平時可傳訊，但跨界神識課會的中繼法器、延遲與消耗仍是待批准設計。

## 二、第一次驤鳴｜《鳴石故人》

### 第一幕：錯的不是圖，是時間

七帳遷帳，雷風掠過靈駒與車隊。雷身帶合法錨印與舊藥路圖入界，按圖抵達的卻是空曠舊場。帶路人沒有騙他：三年前這裡確實有藥脈，只是鳴石移位，雷路早已改變。

遠處三聲箏響，幾塊鳴石依次回聲，一支車隊避開尚未顯形的雷裂。

「那是誰？」陸沉問。

「萬俟箏。想找今天的路，別拿三年前的圖問她。」

### 第二幕：萬俟箏不是等他來的嚮導

陸沉願付報酬請她帶路，她卻正在護送遷帳隊。

「我知道你急。」她說，「可我答應了這隊人，今日要把他們送過雷坡。」

「我可以幫忙。」

「你聽得懂鳴石？」

「現在還不懂。」

「那你守什麼？」

「你告訴我哪裡會斷，我替你撐住。」

她看了他一眼：「別把雷撐得太滿。這裡不是比誰的雷大。」

### 第三幕：她教他聽雷

陸沉以星羅看見最亮的雷紋，準備先截。萬俟箏忽然喝道：「左後方！」那道亮紋只是舊回聲，真正裂紋從隊尾升起。陸沉以兩儀偏開地面回力，她連撥七聲，車隊逐段通過。

夜裡她問：「你明明能飛，為何跟著車走？」

「我需要你知道的路。」

「只是這樣？」

「也想學你怎麼聽。」

「你不是來取藥？」

「取藥和學東西不衝突。」

萬俟箏笑了：「那明早先替我搬鳴石。」

這裡是兩人關係的起點：陸沉能讀正在流動的雷，萬俟箏能辨將發未發的聲路。不是主角一眼學會後立刻超越她。

### 第四幕：斛律鳴的試戰

逐鳴頭名斛律鳴正猶豫是否簽上界傭約。他對上界來客有戒心，邀陸沉穿越三段變聲雷場。第一段陸沉以速度領先，第二段斛律鳴以本地經驗反超，第三段陸沉才借剛學的聲路思路追上。結果可採平手或斛律鳴微勝，不讓本地天驕成為陪練。

「你們上面的人，都覺得努力就能上去？」

「我不替上面的人說話。」

「那你替誰說？」

「替我自己。我有想救的人。」

斛律鳴的傭約選擇仍屬於他，不能被一句話點化完畢。

### 第五幕：九雷夜議

**新增候選**：陸沉與文奕出發前煉製雷訊子印、合法上端中繼法器（Proxy）與夜議主印。只傳有限神識話語、圖式與情報；不傳藥材、修為、完整記憶，不免錨印或跨界交通。具體通訊代價需正式審核。

本尊坐在昏迷的洛生衣身旁，雷導氣**一刻不停**，只分出少量神識參與夜議。

「驤鳴？」

「在。」

「藥呢？」

「找到路了。」

「我問的是藥。」

「路還沒走完。」

千根那具插話：「你不是去取藥，怎麼變成牧人？」

「雷路跟著遷帳隊走。」

「那你現在在做什麼？」

「搬鳴石。」

本尊沉默：「搬完記得取藥。」

「我知道。我也是你。」

這樣夜議既能搞笑，也能讓各路交換推演：有的簡單打怪，有的拍賣購買，有的靠故人天驕幫忙，有的闖遺跡，有的需要另一具雷身依法跨界支援。不能把八路寫成八次「救村換藥」。凌汛仍必須真正失敗。

### 第六幕：取得藥材與未完約定

千根一路傳來可核驗的寄路記錄，萬俟箏核對上一季遷帳路號，找到當季真正的雷脈聲位。斛律鳴護前段，萬俟箏辨聲路，陸沉承受取材所需的雷力，依法取得可分的成熟材料。不必額外塞守關魔王。

離別時，萬俟箏交給他一段鳴石聲譜（能否攜實物跨界待核）。

「下次再來，我考你。」

「考什麼？」

「聽得出今天和昨天有什麼不同。」

「好。」

「別再拿舊圖來。」

陸沉難得笑了：「這次記住了。」

雷身回歸後，本尊完整記得這一切。救生完成不抹去八道撕痕；洛生衣在取材期始終昏迷，若原稿要她親自改方，必須在昏迷前已有可執行備案，不能中途醒來。

## 三、兩訪之間：驤鳴自己仍在生活

萬俟箏繼續研究能帶離鳴石的箏陣，可能屢次失敗；斛律鳴仍面對傭約、家族與前程。遷帳隊改路，孩子長大，老修士老去。伶素仍定石聲，賀蘭嘯仍守界路。赤翎、賀逢山、辛照晚有自己的生活，但不強迫第一次就與陸沉熟識。這樣二訪才有真正的歲月感。

## 四、第二訪前｜先回太玄宗

**採作者最新候選，尚非 GitHub 已定順序**：約32歲陸沉遭婁直真仙真正擊碎道基，跌至列陣以下；先循待核合法路線返回長亭天，見母親、父墓、岳沉淵與同門；古族策動下界勢力攻太玄，七峰六極與岳各有真勝，陸沉只能低境有限參戰。

守山後，他想起萬俟箏與驤鳴的辨音傳承。太玄能護住他，卻不能替他重新走出九雷之道。他決定主動前往驤鳴，而非墜落時被動落入。

「又要走？」岳沉淵問。

「嗯，去驤鳴。」

「去做什麼？」

「重新學怎麼用雷。」

岳沉淵點頭：「想回來，隨時回來。」

兩個低界沒有已定直通門，須走合法上端轉接、錨印及申核；不得免費跨界。

## 五、第二訪｜《故人看我重修》

### 第一幕：搬引雷木的人

雷池清晨，石縫落下一道短暫亮光。陸沉只能搬動一截引雷木，不能碰昔日不在意的池心雷。萬俟箏在遠處試箏，聲音突然停了。

「陸沉？」

他抬頭：「好久不見。」

她先看他的臉，再看他微顫的手和引雷木。

「你的雷呢？」

「還在。」

「那你怎麼……」

「接不起來了。」

萬俟箏沉默片刻，指向雷池另一側。

「那邊有塊鳴石，初學者都從那裡開始。」

陸沉點頭：「帶我去看看。」

**這個名場面不能刪。** 她不是憐憫他，而是接受他今天必須從頭學。

### 第二幕：再一次，聽完

萬俟箏讓他聽三次回聲。陸沉總想在回聲尚未走完時補力，舊返力禁路便反咬裂傷。

「停。」

「我還能試。」

「我知道。可我叫你聽完。」

「聽完就錯過了。」

「你現在急著追的是什麼？」

她撥一聲箏，任回聲散盡。

「第一次來時，你問我為何不追最亮的雷。」

「記得。」

「現在呢？」

陸沉終於沒有立刻催雷。

### 第三幕：她也有未完成的道

萬俟箏試圖把依石才響的箏陣煉成可帶走的法，紙燕只飛回半隻。陸沉想替她補一道禁，她搖頭：「我要帶走的是我的聲，不是把你的雷放進我的箏。」兩人互相討論失敗與新方法，但不代替對方成道。

### 第四幕：赤翎與雷池

二訪後再與赤翎建立交情。強接派為重建測脈路在驤鳴打樁，雷池炸裂；赤翎選擇守住自己的家，犧牲不可逆。萬俟箏可以參與救場、修復與戰後悲傷，不能取代赤翎的選擇，也不能讓陸沉憑第一次的舊交情預知陰謀。

### 第五幕：雷鯨兩敗一勝

賀逢山與辛照晚各有自己的雷道追求。曾是至尊的陸沉仍在雷鯨遺蛻真敗，之後主動拆掉仍能使用的舊返力禁路，重新學會獨立承力。恢復尊者不是瞬間恢復至尊；碎錦原仍要付出完整重修代價。

### 第六幕：兩人的約定回收

離開前，萬俟箏問：「這次聽懂了？」

「比上次多一點。」

「那你當年答應的考試呢？」

陸沉看著鳴石，等最後一道回聲散去。

「今天的聲，跟昨天不一樣。」

「哪裡不一樣？」

「不是石變了。」他說，「是我一直用昨天的辦法聽它。」

萬俟箏收起箏：「下次再來，換你教我一招。」

「好。」

她不是等待主角歸來的工具人，而是始終走在自己大道上的天驕。

## 六、必須交 AI 團隊解決的衝突

1. 《斷階頂上》原本落驤鳴，先回太玄須重寫路身落點及合法返鄉交通，不能只換地名。
2. 洛生衣「三試剪節」究竟在太玄先完成，或驤鳴後完成？兩案比較，保留她的醫道自主與代價。
3. 強接派炸池是否能合理排到第二訪後？不能為等陸沉而讓敵人無理由停工。
4. 《驤鳴》原有萬俟箏初見場景要改為重逢；第一次見面的知情與後續熟識程度須逐場核對。
5. 雷訊可傳訊已定；跨界神識夜議、Proxy 法器、延遲與授權仍須補正式機制，不得自動同步完整記憶。
6. 洛生衣取材期昏迷，本尊雷導氣不間斷；原有「生自己改方」改為昏迷前備案或交作者裁定。
7. 驤鳴第一次入界雷身壓境、第二次本尊跌境；不得以昔日至尊戰力解決所有問題。
8. 赤翎真死、雷鯨兩敗一勝、九禁與劫藏、碎錦原至尊重修、後續兩宗清算及九雷問祖均不得壓縮刪去。

## 七、整合工作方式

先對照 GitHub 既有八路、驤鳴與全書日帳，列出所有衝突。再把第一次驤鳴擴成有場景、有對話、有修行、有當地人物勝負的故事；第二次把「故人重逢—辨音—赤翎—雷鯨—拆舊路」逐章接起來。保留本稿所有對話作候選素材，不可只抽成一句「萬俟箏教劫雷道」。作者確認後才覆寫正式大綱與正文。

**主題句：第一次，他帶著足以撼動雷池的力量，向她學怎麼聽；第二次，他失去了力量，卻終於聽懂。**
