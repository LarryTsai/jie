# 聖土去鬥破：人工處理規則（2026-11-28）

機械替換已完成，見 commit 1ea76ec2 與[寫回報告](工具/寫回報告.txt)。對照表見 [README](README.md) 〈執行準備〉與[丙](丙.md)第五節（依比較修正：巔峰叫「長滿」；丹匠用「品」；鬥技→戰技；魔獸、魔核→核獸、獸核）。

以下是腳本分不出、要逐處看的五類。

1. **異火**：依文意改。
   - 講火本身、火地、榜上的火，改「野火」。
   - 講人與火的關係、火在誰身上、契了誰，改「契火」。
   - 分不出時寫「野火」。
   - 「異火榜」正名處改「燧冊」，口語處改「火冊」，不要寫出「燧冊（燧冊）」。
   - 「吞火進化」這條原創性紅線的意思不變，字可改成「吞火長形」。
2. **帝境**：
   - 只有靈魂境界那一義改「覆境」（靈魂境界現行是蟄境、照境、明境、穹境、覆境）。
   - 兩界通用的帝級（「帝境自成天地」「仙帝境」之類）不改。
3. **談鬥破本身的句子**，例如「照鬥破」「依原作」「原作行文」「修行整套走鬥破」「對照鬥破的量級」：
   - 改寫成現行說法：聖土修行是本書自己的體系（D216），境界是身上長出的形，小階看分。
   - 不是只刪字，句子要讀得通。
   - 原創性紅線、參考作品對照裡提到《鬥破蒼穹》作為「不要像它」的地方，可保留。
   - D045、D047 的決策原文不改，那是歷史。
4. **尊稱回補**：機械替換後，稱人的「戴天」「落根」，依語氣改回「帝」「聖」。
   - 例：「那位戴天」→「那位帝」，「五位戴天」→「五位帝」，「落根們」→「聖者們」。
   - 講境界本身的保留，例如「破落根」「落根初根」。
   - 也順手修機械替換造成的不通句子。
5. **不改的**：
   - 事件、人物、勝負、數字、境界對照位置。
   - 連結目標與檔名（例如〈境界功法魔獸對照〉檔名照舊）。
   - 決策紀錄、正文、歸檔、其他討論區資料夾。
   - 已釘板的第 27 篇（`大綱/05_入極/03_第三份探查記/`）只做第 1、4 類的名詞處理，不動句意。
