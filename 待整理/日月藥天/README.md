**作者已裁定採 A**（見[作者裁定](作者裁定.md)，本資料夾唯一作者裁定來源）：

- **《日月未央》＝嬋九歌獨立求道前傳**：下無極瀕死後至約31歲前；古宗首席之爭、太陰本源修復、從活根養回一道淡月影、十年追索古陽道統；不得有任何日影。不是《日月藥天》的同篇展開。
- **《日月藥天》＝第一次日影主事件**：約31歲，三人同行探索古陽遺跡；她親自取得太陽傳承、經相斥、失敗與代價，自己凝聚第一道日影。日月同天留待大羅或更後期。
