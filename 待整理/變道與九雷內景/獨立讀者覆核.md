## 最想保留的場面

1. 屋頂冠真正打開、鍛坊爐火仍續：可欲的真成品與公共器物的主人同時成立。陸沉不是只修損傷，也真的造出從前沒有的法。
2. 四極獨立落點真贏燕停舟一季，婁直隨後不再攻四面而改刺返力共同終端：新解釋沒有取消舊成果，強敵有研究與改局。
3. 賀逢山兩次真贏、第三次仍毀鼓守兩筋；辛拒陸用殞核砸自己的盾、攜成盾照舟期離開；箏輸贏酒局與獨立留聲。當地人願意爭自己的事，重修不是排隊給主角當老師。
4. 舊九雷協同真的省力、真的勝新我；陸沉一味斷共同路反而更早敗。這使『能改不等於該改』有具體對抗，末戰不是殺死被作者削弱的過去。
5. 行樓一念想清三扣仍被第四扣打下、半樓再爭與樓檻飲酒；白沙園未知游魚仍可不解。念術改變選項，勝利與喜悅都不被立即收成道德課。

## 第一輪具體退修

### DR01｜P1｜劫化核心只用『淬鍊』動詞跳過方法

位置：書院稿 E01 石坪第一次同量星羅試銅，以及養後重試。

證據：『將吐納、骨脈與神識收成一股，對同量星羅做本人淬鍊』後即出現銅孔捲入與砂槽加深；養後只減為一粒。讀者看到力變強和反震，尚未看到他究竟試了什麼、失敗如何改變具體煉法。這是本輪新增劫化承諾的第一次落地，不能以名稱或品相自證。

實修要求：在同一低量窗口給可追蹤的煉法動作及觀察，讓第一方法真遇阻、第二方法只改一個可見步驟，再以同量對照證明當下所得。可以新創候選機制，但需明標並列出影響；不需另加倍率、境界、另一场犧牲或仙經。

驗收：唯一主稿中可回答『他做了什麼』『哪一步失敗』『第二試改哪一步』『為何可判同量質變』『反震仍如何發生』；不靠附錄宣稱已完成。

### DR01 直接驗收

| 問題 | 成品中的實際答案 |
|---|---|
| 他做了什麼？ | 先封普通雷用量及孔痕，再走掌脈短路；改以一粒雷由本人逐次收攏散逸支絲，每次放回掌脈測停、回。 |
| 哪一步失敗？ | 原承力法只走慢，銅孔不變，文當場否定；第一次粒雷縮聚後不能停，陸撤回普通雷重起。 |
| 第二試改哪一步？ | 不一次逼整線至承量，僅收自己仍辨得清的一層，凝定一粒，其餘雷量不變。 |
| 為何是同量质變？ | 同料、同距、同總雷量，撤外接增幅、換未通雷銅對照；孔壁與封砂痕有差異。不是老師說已得劫力便算。 |
| 傷及前後後果是否仍在？ | 第二片斜銅引回目脈，兩儀接反力傷掌骨，震魂本源受牽；七日禁淬及後七日低量回收仍付。之後僅一粒可用，敵人改攻手腕仍能逼他撤回原雷。 |

修後沒有把劫化縮成免費倍率；具體步驟足夠讓第一次修煉成立，尚未證明所有雷能同法或成熟劫力已成。這些仍是候選新機制，作者確認與完整排期核查保留。

## 方法回顧

DR01 應由既有『修行過程』及『因果完整』角度抓住，本輪已抓住並實修驗收，現有技能足夠，沒有泛化改技能的證據。本專案教訓是：能量質變第一次出现，應把『淬鍊』動詞拆成可見嘗試与反證；保存在本審查紀錄即可。
