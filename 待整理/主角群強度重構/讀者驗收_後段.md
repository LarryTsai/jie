# 讀者驗收：後段強者感（第18–28篇八卷）

非正文。驗收員未參與 D157／D159 寫作與審查；只讀 AGENTS、三份審查員檔、兩份裁定與八卷大綱，依序當故事讀。行號指各卷 `大綱.md`。

## 逐卷

**不二與借壽崖**
1. 前半偏弱，後半很強。強：碑外八雷撐禁「兩篇第一次全力」（L184）；冬至一折不偏、三雷越牆、「你借別人的壽，我借你的劫」（L329–331）；「這個我不斬」（L322）。像輸／被救：觀星廊殞星炸回自己（L142）、第十九洞只拖（L159）、碑外不閃挨劍靠鞘鳴「夠劫活」（L186）、夜上崖一招不還丟九門（L241–243）。連三次「讓他刺、看偏哪裡」，讀感是被餵。
2. 封寒冬至〈吞天〉＋「我數了兩篇」（L309）是全卷最好的同伴戲；燈下「念」（L279）好。
3. 宓長庚極強，贏他有分量。
4. D157 標記 54 處，L136 千劍廊、L227 鑄鐧是規則說明書。

**王室臥底**
1. 段七藏身為主，合理但長。強：九息打落鄔爾加（L521）；九霄一人入雲（L726–766）；伊索德「送回」（L654）。但 L520 薇恩一箭先斷鏈，他才撐爆鐘，仍像被協助。
2. 封寒〈照世〉「收了六次，第七次還你」（L508）、徒手撈鐘燒見骨（L510）、一尺之外（L709）都記得住。
3. 鄔爾加只鬥尊七星（L180 自承），勝利分量輕；壓迫來自身分不是敵人。
4. L1–174 是設定史，未進故事；L547「門與牆」帳目打斷高潮。

**赤沙谷**
2. 生的越門乾淨：迎河首拆折谷、劍在身體裡等替命燒完、「你折得了谷。折不了秋。」（L20–24）。鄒十三套生環好。
4. L9–11 路費與承載三行行政；L24「全場沒有先敗」是註記混入故事。

**一炷香與至尊之年**
1. 本卷最強。甄四海：為母親信提前十天渡劫、令牌碎片按胸（L41–43）；九身「一個人，九個方向，同一息」（L112–114）；聯席堂十七枚命玉（L118）。弱：大羅開頭被推著走（L15–21）；古路七章多是扶枝、守門框，刻意的客場。
2. 鈞天劍坪「驗過。它在我身上住了三年。」（L104），封寒與駱霜都立住。
4. L29 遞送排期、L128、L192–194、L208–214 是日帳，嚴重拖速度；全卷簡繁混用。

**斷階頂上**
1. 第5章承一劫後雙指點眉心（L52）、第10章反接之釘「換你這一窗」「剩下六重，我回來收」（L94）是真強者。
2. 文奕「三尺」、活禁倒送（L66）；封寒十二息「你們的圖上沒有我」（L86）都好。雲行只一句「他沒說」（L58），像補丁。
3. 婁直夠強。
4. **代價與痛**：釘下那一刻有痛，但 L94 緊接「道基碎不是婁直打出來的、也不是散功換力」把痛解釋掉；真正痛到要到驤鳴「半柱香」（驤鳴 L74）才感覺到。L100 作者註框「真敗〔D157改：不敗〕」、L102／114／118 仍寫「入驤鳴」，與驤鳴 B01 矛盾，讀者會迷路。

**驤鳴（含西極）**
1. 重修卷，強者感本來就低；他在傷棚看岳師父肩裂（L84）很動人。賀次戰「兩人都真失、陸真贏」（L98）是唯一硬勝。
2. 雲行撥珠一：「是他自己那一衝，用了九顆珠的時間才落到這裡」（L68），全八卷最有仙味的殺法。
4. F／G／R／B 編號、遞書吏 59 日（L92）、B02 全是公文；九日守山十幾場仗各一句帶過（L79–85），完全是旁白。

**碎錦原**
1. 「那些……只是給你們看的」（L67）漂亮；九雷合一（L97–99）。但兩路斷供一半是仙王截的（L77），九重是婁直自己收陣時落的（L105），最後 L109 明算「他沒有以己力正面勝過真仙本質」。
2. 四同伴幾乎不在場。
4. **「上一版」那一刻**：「你收集的是我以前的每一場。這一場，你沒見過。」（L105）被夾在「第五重他退了一步」和收陣行政之間，又在婁直已決定撤之後才說，沒有爆發力。主幹句（L11）先把結局講完。

**長亭**
1. 〈劫數・降〉「管曜本無劫，他來了便有了」（L122）、「看見天地的缺，有能力再降一次，不降」（L132）很強。前段一直丟先手、誤驗（L19、L53）。
2. 雲行背燈＋撥珠二「名字我替你們記」（L88–92）；文奕拒補祖圖、管曜記「下次先拆」（L112）。封寒唯一（L23）太乾。
4. **先問與戰力**：不互相抵銷——「九界那端不用我」（L98）是信同伴，「下次先問」（L176）留給孩子，位置分得開。真正削弱高潮的是 L124 一串「不硬炸王級能量、不吞整座大羅」否定句。L65–69 點名、L186–194 日帳過重。

## 總評

**6.5／10**。高點真的到了荒／王林級：越牆三次各有私仇與場面，斷階那根釘、九身、劫數降都讀得出「這人很強」。扣分在三處：一、勝利常被共簽（鞘鳴、薇恩箭、仙王王域、天自己落雷），再由明算段落親口說「不是他贏的」；二、每段都有「不是…不能…不等於」否定句和日帳，強者氣勢被稀釋；三、王室、驤鳴兩卷長時間藏身或重修，敵人境界又低。

### 最該改五處

1. **斷階 L94、L100–118**：刪 L94 解釋句與 L100 註框，把「入驤鳴」三處改成殘臺；在釘下那一息加身體感受（九雷離道基的聲音、厄的錘落下）。
2. **碎錦原 L105–109**：「上一版」移到婁直決定撤**之前**——他想撤，劫用還重先打掉他第一個陣手退口，再說那句，逼他留下；L109 明算移到追溯；L11 刪結局。
3. **不二 L241–243**：夜上崖保留受兩劍，但讓劫最後還一手（如以已讀的偏向逼宓長庚換掉一門他留給冬至的劍），讀者要看到他也在收帳；L186「夠劫活」改成「替他省下一成」。
4. **王室 L520**：劫自己以殞星撐爆調音鐘斷鏈，薇恩那箭只救貝提爾（L472），兩件事分開；刪 L520 括註與 L546–552。
5. **一炷香 L29、L128、L192–214**：日帳全移附錄；驤鳴 B04（L79–85）擇兩場（杭毀庫、岳對長垣）寫成場面，其餘併一句。
