## 〇、故事先看

陸沉十二歲進太玄宗那年，碧梧峰的洛生衣跟他差不多大，卻已經入峰四年、修到化靈，在主峰丹閣自己掌一座爐。全宗都知道她：丹閣最難的單子交給她，問劍峰的師兄排隊找她試劍，被她拒絕的丹方沒有第二家敢接。陸沉第一次去領淬體丹，想要快一點的服法，她兩根手指按在他的傷脈上，他整條手臂便抬不起來。「你知道你的身體？那你抬手。」

她的道從丹爐起步。別人煉丹，是先把藥殺了再取藥性；她讓藥在爐裡活著，依序走完一生，等每一味都走到最盛，在那一息收丹。所以她的丹是溫的，剖開有年輪，丹香帶著季節。十四歲那年，碧梧古木群裡一棵千年老梧走到了壽盡，全峰輪班續了它三個月，只有她蹲在樹根前說：「它沒有病，它活完了。」她親手收了它最後一口生機。老梧的死心材撐了那棵樹一千年，赤霞峰把它鍛成一柄細長的刺劍，護手是老梧最後一年抽的新枝。她給劍取名**知秋**。

後來她發現，劍招、火幕、陣法、法相和保命術，也都會經歷生、盛、衰、謝。丹爐教她讓萬物活滿，劍讓她學會在最盛的那一息替它收尾。秋是肅殺的季節，所以知秋是一柄殺劍：她迎著敵人最強的那一招出劍，那一招就在最盛時凋謝；接下來是人，人要死在真劍之下，殺不殺由她判斷。每送走一個她判定該死的人，死木劍脊上便多一圈年輪。她記得每一圈是誰。

左腕那枚淡青的生環，是啟蒙者蘇聽瀾丹爐上的爐環，入峰前由她帶走。環只有一枚，套在爐口、戴在手腕、罩在傷者身上，三處只能擇一。她一生大半的取捨，都是在決定這枚環此刻該在哪裡。

生是她起步的道，死從生裡長出來。走到高境，知秋所指是秋岸，生環圈出春岸，中間一條淺而無聲的河：這就是她的**生死輪迴道**。

## 一、生死輪迴道：核心一句、界限與一魂雙相

### 1. 核心一句

**萬物有壽：她讓它活滿，也在它最盛的那一息替它收尾。收的是丹時叫生，收的是法時叫死；收下的靈機落回天地，成為下一季的生，這就是輪迴。**

生與死是同一隻收的手：丹與生環承「生」，劍承「死」。她的「死」是在丹爐前學會的，不是從醫術反轉出來的；辨身、續脈、剪節、留生一線始終是醫，不用劍，也不拿來殺人（D116）。這正是作者 10-13 所說「不是把醫術倒轉就能殺人」。

### 2. 劍上的「死」：界限寫死（作者裁定一、必修 1）

> **秋只作用於法、勢、護體法相與保命術，不作用於人壽、血肉自癒、經脈；人死於真劍與劍意。**

其餘界限：

| 界限 | 寫法 |
|---|---|
| 必須劍觸 | 知秋的劍尖或劍身要碰到那道法。沒有遠程、沒有凝視、沒有一眼生效 |
| 必須到盛 | 法還沒走到盛，她給不出秋。對手刻意不到盛就收、瞬發不經盛、斷勢重起，都能剋她 |
| 物不秋，只秋物所承載的法 | 純器、傀儡本體、陣基、甲冑、法寶外殼沒有「法的壽」。她秋掉的是器所發的護勢、陣所發的法、縛住傀儡的那道術；器與陣基本身照舊，只是失了依憑 |
| 葉可落，根不動 | 同境：一道法可整道秋掉。越一大境、未跨質變點：只秋得掉伸到她面前的那一片，對方須付本源才能重起。跨質變點：正面不可勝，照跨境律第三條，只能逃、拖、護人、改變勝負條件 |
| 不拆門 | 生不在 D128 可越門名單內；她沒有拆門能力，全文不寫 |
| 天地之勢不秋 | 雨、潮、季候、地脈本身的壽遠超過她，她只能順著 |
| 不讀人壽 | 不讀活人的壽元，不判人死期，不看一眼奪命 |
| 不復活、不以殺換救 | 被秋之法散出的靈機落回天地，不歸她、不歸任何她選定的人；她不讓死者復生、不查前世、不給人轉世（D116；不採丙案高境「一謝一春」） |

### 3. 死怎樣從生裡一步步長出來

| 步 | 時點（工作） | 她學到的「死」 | 怎樣發生 |
|---|---|---|---|
| 1 | 幼年至少年丹閣 | 藥的死 | 生道讓她感覺得到爐裡每味藥還活著；盛極不收，下一息便衰。收丹那一刻她感覺每一味藥死去，那是一個好死 |
| 2 | 十二至十四歲，太玄宗 | 勢的盛 | 宗門大比裡她讀出陸沉最後一招的盛點，在他招勢要回的那一息贏下（第五節）；還不會秋，只會讀 |
| 3 | 約十四歲，碧梧 | 樹的死 | 千年老梧壽盡，她辨出「不是病，是活完了」，與荊問一起決定不再續命，親手收它最後一口生機 |
| 4 | 約十六歲半霜降 | 勢的死 | 知秋開鋒，她第一次在劍上給出秋：對手的劍勢在最盛時凋謝（第六節之一） |
| 5 | 下無極 | 人的死 | 第一次親手殺人。她發現殺人不是秋：法死在盛點，像落葉；人死得不好看，只能靠自己的判斷與一柄真劍。劍脊出現第一圈年輪 |
| 6 | 上無極 | 保命術的死 | 保命術在觸發的那一息就是它的盛；被她劍觸，便走不掉（第三節、第六節之三） |
| 7 | 高境 | 一季的死與輪迴 | 春秋兩岸：一手秋，一手春；收下的法散回天地，戰場上長出新芽 |

第 20 篇拒還形先師，給死道第一次道上的意義（吸收 A10，不改事件）：「先師已經走完了她的一生。我不讓她再活一次不屬於她的季。」

### 4. 一魂雙相，不是雙重人格（作者 10-13 第二節）

洛生衣只有一個完整的自我。她的溫柔、俏皮、好勝與殺伐，都是同一個人的選擇。全稿禁止任何「殺相」「死相」模式、眼色變化、另一個聲音或人格切換。殺完人，她回頭先問藥童的手燙傷了沒有；拒煉一張丹方，是因為她感覺得到那些東西怎麼死。劍脊年輪是同一個人的帳。少年時她不敢殺，是成長的一段，不是另一個人格還沒醒。

## 二、知秋與生環

### 1. 刺劍：知秋

**名字**：首選**知秋**，取「一葉落而知天下秋」，也取秋決肅殺。候選：梧心、一葉。

**樣子**：劍身細長筆直，淺金帶褐，像一片秋天的梧葉被拉成一線；劍脊中間有一道深色髓紋。刺出去的聲音不是金鳴，是乾葉擦過的「颯」。華麗的杯形加枝形護手，由老梧最後一年抽的二十七根新枝經赤霞金絲纏成半籠，罩住她的手；新枝以碧梧泥封保住青金色，枝梢留著幾片極小的葉。柄首鑲老梧最後結的一枚梧子。

**活護手（吸收 A6、必修 12）**：泥封之下的新枝其實還活著，吃的是她握劍時手心的生機。她心緒一動，護手會悄悄吐一片新葉，極少時開一點白花，出賣她的嘴硬。規則：**全書少於十次**，只在私下或極近的人看得見時出現；不做感情計量器，不做戰鬥量表，不吸收乙案的葉色資源條。另保留甲案一拍：陸沉握劍時，護手金枝一收，夾住他的虎口。

預排的冒芽處（工作，總數六，留四次餘裕）：①霜降開鋒當夜，陸沉說「很好看」；②下無極私下樣場（第七節樣場二）；③三千花夜 B35 丹香使夜芽開時，她說是丹香熏的；④三千花夜 A29「你呢？你不陪？」；⑤第 23 篇她照樣來的那一夜（只寫一片葉，不寫花）；⑥第 28 篇「現在可以沉一點了」。

**意義**：
- 劍身是死，護手是生。她握殺劍的手，由一棵樹最後的生護著。
- 刺劍是決鬥的劍，講端正、正面與宣告，適合一位會說「這一劍我要贏」的仙子。細長的刺擊延續她收丹訣的兩指與針，但她的道不是「刺穿」或「精準」，是「收」；刺只是收的手勢。
- 劍會長年輪。死木本不再長，但每當她親手送走一個判定該死的人，劍脊便多一圈極細的輪紋。只計人，不計被秋掉的法。

**來歷**（吸收 A5；必修 10 縮小改動）：
1. **秋澗的舊帳**：她十二歲在丹閣任事時，赤霞器師秋澗每逢雨季斷脈作痛，來領止痛丹。她以活藥配了一爐，那一季他第一次一覺睡到天亮。她辨過他的劍脈，確認接不回；他也不要她接：「劍死了，我還活著。妳們碧梧不是最懂這個？」此後他教她最基本的刺、收與步法，換她每季一爐丹。這是她少年能在宗門大比勝陸沉的劍底子。
2. **老梧之死**：卷五古雷脈重鑿只接回一半，碧梧木脈受牽動，巡田帶回減產葉樣。碧梧古木群中一棵千年老梧（**不是碧梧峰得名的那一棵**，峰名與峰的意象不受影響）因此露出壽盡之相。全峰輪班續了三個月，她辨出「它沒有病，它活完了」，請荊問讓它好好死；荊問嚴厲的教法在這件事上第一次和她站在一起。她親手收了最後一口生機。
3. **心材歸屬**：峰主梅予本要把心材交宗庫作公器。生請求承接：「它最後一口生機是我收的，它的死我也該帶著。」梅予要她自己去赤霞峰說服雍離。雍離說千年梧心太窄，只出得了一線細刃，不能做寬劍，也做不成陣器。秋澗在旁說了一句：「那就是刺劍。」
4. **火養木一百天**：重鑿後赤霞火溫忽高忽低，養木要穩火，前兩輪都失敗，秋澗守爐。劍胚成時她已在準備赴中神州，那年霜降錯過；胚在赤霞器窖等了一年。她帶著沒開鋒的劍胚練「一葉」。
5. **開鋒**：赤霞山腹爐每年只在霜降那一日起霜火，一口爐只開一把劍的鋒。她得在霜降爐約戰中贏下爐位（第六節之一）。

秋澗三句劍理（吸收 A5，與甲原句合為同一課）：「妳不揮，妳收。」「刺劍最危險的不是刺出去，是收回來那一下；我就是被收回來的劍斷的。」「劍最怕的不是弱，是盛。到了盛，就得交代後事。」秋澗只用既有 Canon（斷劍脈、在赤霞修器），不新增他與晏守拙的細節。

### 2. 生環：蘇聽瀾的爐環（作者裁定二）

**來歷**：原是蘇聽瀾丹爐上的爐環。蘇聽瀾活煉時把它套在爐口，讓爐中藥命在轉火時不斷。蘇聽瀾死後，八歲的洛生衣入碧梧峰前把它從爐上拆下帶走——這是她從蘇聽瀾那裡帶走的第一件實物，另一件是那套還沒被證明的教法（人物卡起始目標）。荊問認得這枚環，從沒要她交出來。

**樣子**：一枚淡青素環，比手鐲略寬，內圈有一道洗不掉的舊爐煙痕。戴在左腕。

**分工：劍承死，環承生。** 環不打人，只托、只護、只撥擋。

| 位置 | 做法 | 限制 |
|---|---|---|
| **爐口** | 套住爐口，以她的生機托住爐中藥命，一爐到底不斷 | 環在爐口，就不在腕上；開爐期間她只有劍 |
| **腕上** | ①**左手撥擋**：古典刺劍配左手撥擋器的形制，環在腕上撥開短刃、偏開來勢（吸收 A4）。②**續回劍**：在她收劍那一下續住步與勢，補刺劍最大的空門 | 誰壓住她環的那一側，誰就逮得到她回劍那一下 |
| **傷者** | 環飛出或套在傷者身上，生衣經環外放，護住一人的一道傷不往下走、生機不被外力抽走 | 一次一人一傷；護人時她的左手空了 |

**三處擇一**：一枚環不能同時在爐口、腕上和傷者身上。每一戰、每一爐都要選。

**護撤路：春徑**（必修 5）
- **做法**：她把環擲落地面，環沿她選定的方向抽出一條一人寬的青色細徑，最長十數丈（隨境界加長）。徑上的人生機不被外力抽走、傷勢不往下走，腳下的地托得住人（冰崩、泥流、熱面在徑上不陷人）。
- **它不做什麼**：只護生，不擋刀。刀劍、法術照樣打得進徑裡；它不是護罩，也不是陣。
- **限制**：一次只護一條路、約一刻；環一離腕，她的回劍就露空，左手也沒有撥擋。徑上同時走的人越多，維持越短。敵人可以斬斷徑的起點（打環），或專挑她失環那一側進攻。
- **成長**：春徑是高境「春岸」的前身。少年時只有數丈，用來護一個傷者撤出；上無極可護兩三人；高境才圈成岸。

**與其他能力分開**：第 22 篇「輪印」照舊是生機道紋的護持顯化，與生環、知秋都分開。生衣、留生一線是她本人的醫術，不靠環也能用；環只是讓生衣能外放到一臂之外。

### 3. 少年（太玄宗，化靈至銘紋）：讀盛 → 一葉

- **招法**：刺、收與步法來自秋澗口授，加收丹訣的兩指。十二至十四歲只會**讀盛**：看完同一種招走過一次完整的生、盛、衰，認得它的盛點，在它要回的那一息出劍（還不會秋）。約十五歲得劍胚後練成**一葉**：在對手一記劍勢或法術最盛的一瞬以劍尖點中，那一記勢便凋謝。
- **樣子**：對手的劍光不是被擊碎，是像葉子一樣枯黃、捲邊，一片片落地即散。圍觀的人看見一記全力殺招在半空忽然「秋了」。
- **限制**：第一次碰到的招，她要先硬吃或閃開一輪才認得盛點；只認得出同境的盛。生環在腕上時劍少一分護，環離腕則回劍露空。
- **真被剋**：沈照野的「不謝劍」每劍八成、沒有盛點，她第一場真敗（第六節之一）。

### 4. 下無極（尊者至神火）：秋決

- **招法**：不必先看完整週期，從法的根就能讀出它的盛點，像從根皮看出一株藥的年歲。殺招**秋決**：先秋掉對手最強的一招或護體法相，下一劍取人，劍上帶真正的肅殺劍意。極少數真取人命時，她說「我送你」（D116 候選台詞；第一次殺人時她什麼都沒說）。
- **樣子**：敵人的火鳳法相在全盛時撲來，她迎面一點，火鳳從喙到尾一路轉成灰金落葉，紛紛墜下，她從落葉中穿過去，劍已在對方喉前。
- **限制**：讀根很耗神識，一戰只秋得了寥寥數記大招。陣法、地脈法的根在地裡，她只秋得掉陣所發的那一枝法，陣基照在。
- **真被剋**：蚨渡聶長庚以瞬發遁符脫身——遁符不經盛，她秋不到（第六節之二）。

### 5. 上無極（真一至天神前中）：秋決＋保命術之秋＋春徑

- **新增（吸收 A1、必修 3）**：保命術在被觸發的那一息就是它的盛。替命符、血遁、斷肢續命之法、殘魂奪舍之法、遁一類保命法相，只要觸發時她的劍正觸在對方身上或那道法上，便秋掉。同境完整；越一大境未跨質變點只秋一層，對方須付本源；跨質變點照跨境律第三條，正面不可勝。秋掉的是保命之法，人仍要死於真劍，或由她決定不殺。
- **春徑護撤路**：見第二節。
- **救與斬**（作者 10-13 第三階）：她可以秋掉敵方的法，回頭以生環護敵方傷者；也能斬仍在加害的人。選擇由她自己承擔。
- **真被剋**：偽盛——血河客把一張假符做成全力觸發的樣子，引她秋空，她神識白耗一記、肩上中刀（第六節之三）。日月藥天第19章炅舟學會「半推即收」，連壓她三輪（第九節）。

### 6. 高境（天神後段起）：春秋兩岸（吸收 A2、A12；必修 4）

- **道域**：一條很淺、無聲的河從她腳下展開（D116：月白、墨黑、淡金、幽青）。知秋所指是**秋岸**，生環圈出的是**春岸**。攻勢渡河向她，每渡一尺都在走完它的一生：出手時盛，到河心衰，抵她身前已是落葉。敵人向她衝，衝勢也是一道勢，身位便一寸寸偏向秋岸。春岸上，被護的人傷勢不往下走，花開著。
- **樣子**：晴天下飄起金黃落葉，敵方陣光、火幕、劍氣在同一片秋色裡由盛轉謝；唯一的綠是她身後那一片春岸。一場仗打完，被秋之法散出的靈機落回地面，戰場上長出新芽——不歸她、不補她，她拿不走。
- **限制**：兩岸**不分敵我**，同伴的法渡河一樣會老，同伴必須站在春岸或河外。天神空間能力可一步跨出她的岸；虛道觸及規則，她碰不到規則本身。對手以本源硬撐，可讓攻勢在河心不衰，代價極大。河的源頭是左腕生環，打斷環，春岸消失、河淺一半。用後神識要長時間調養。
- **不是什麼**：河不是冥河，不通真實彼岸，不送人去任何地方；不復活、不讀前世、不越境秒殺、不以殺換救。高境只寫到「春秋兩岸」這個構圖，具體形態、境界點與名稱留待全書聯排（守 D116）。

## 四、丹道：為什麼她的丹是極品（必修 13，吸收 A7、A8）

**原理**：一般丹師先炮製、殺青，把藥殺死再取藥性。藥在不對的時候倉促死去，只交出一部分藥性，殘生留在丹裡慢慢腐敗，丹毒的根多在這裡。她的做法是**養青**：生道讓她感覺得到每一味藥在爐裡還活著，她把它們養著，依序走完一生；等所有藥同時走到最盛，她才收丹。藥活完了，藥性就全部交出來。

**看得見的特徵**：
1. **出爐溫，不燙**，像剛摘下、還帶日頭餘溫的果子。
2. **丹面時紋即剖丹年輪**：丹面有細細的輪紋；剖開斷面一圈一圈，每一圈是爐裡一轉。懂行的人一數就知道這爐轉了幾次。她在人前說過「若數不清，明年我再來，帶多一圈的」。
3. **丹香帶季**：聞得出藥是哪個季節採的；香氣強時，周遭本已到花期的芽會短暫開放（三千花夜 B35）。
4. **久存不壞**：丹裡沒有殘生，封存多年仍如初成。連服的遞減來自服用者的抗藥性，不是丹本身壞了——正對齊三千花夜 B36「第二服弱於首服、未觸停線、仍是上品」。

**無瑕與丹劫**（D073）：她最好的一爐能到**無瑕**（作者口語的「極品」；D073 正式品名仍是無瑕）。近無瑕會引丹劫，丹劫不受控，常常毀丹。所以她平時**在最盛前一息刻意收手，停在上品**；人前看得見的樣子是：屋外雲聚，她兩指在爐沿一點，雲便散了。與陸沉共爐時，她才讓藥走完最後一息，劫由陸沉上身接住——「她把藥活完，他把劫接走」，兩人同爐不同道的分工從此有實際內容。

**為什麼別人學不來**：要同時感覺爐裡每一味藥的生命並從頭陪到尾，這要生道的感知；收丹那一息她會感覺到每一味藥死去，這是她願意承受的事。多數丹師既感覺不到，也不願感覺。

**代價與限制**：
- **慢**：每爐都得她本人陪完，不能量產。賀春望分火快、量大，在三千花夜真贏過她，前提照舊。
- **只對活材有效**：曬乾死透的藥材到她手上最多上品，所以她總帶著活根小爐（三千花夜那座）。陌生季候的古方，她第一次煉也只是好丹師的水準——三千花夜交春題先中品、改序才上品，正因如此。
- **耗神識**：一爐上品以上要停數日；卷三共爐留下的右手三指麻痛期間，她要靠生環守爐口才收得了丹。
- **不收有靈之物**：必須活取開智生靈之物的丹方，她拒煉；她感覺得到那些東西是怎麼死的。

她的煉丹第一交椅就坐在這上面：別人的丹是藥性的總和，她的丹是一群藥活完一生的總和。

## 五、太玄宗初期的生（作者 2026-10-13 追加方向）

### 1. 人物定位句

洛生衣初登場時，便是太玄宗令人仰望的天之驕女：入峰早、修為高、丹閣自掌一爐，美麗、驕傲、強大。她對陸沉帶著幾分戲謔、幾分管教與不自覺的偏愛；早期是陸沉追趕她，不是她等陸沉保護。兩人一起長大以後，這份居高臨下的親暱轉為平等的愛慕，她骨子裡的強勢、護短與師姐氣度始終不變。

**不硬套師徒**：她是師姐，不是師父。親暱靠四樣撐：**修為**（卷二跨化靈質變點，他推不開她兩根手指）、**資歷**（她入碧梧那年，他還沒進太玄閣）、**天賦**（丹閣最難的單子交給她）、**氣度**（她拒絕長老、試劍師兄、九霄老資歷的方式）。日常互動用「師姐」稱呼、領丹規矩、陪練與丹錢往來，而不是傳功、拜師或命令。

### 4. 第一場正式互動：卷二第11章改法（保住既有功能）

**保住**：拒快服、要求先養上一回摔傷；記下領用與傷處；不承諾治好全部承雷根基；收簿時夾著碧梧驗植紀錄；接續分場以生機、脈動、體溫辨出兩具（「上次來的不是你」）；封寒候丹旁聽；**不在本卷報全名、不訂三碼、不建立只給他一人的待遇**（三碼與報名照留卷三第4章）。

**改法**：
1. 陸沉要快一點的服法，說「我的身體我知道」。旁邊排隊的弟子悄聲說「那是碧梧那位師姐」，讓開半步；陸沉沒讓。
2. 她不爭辯，兩根手指按在他摔傷的那條脈上。洞天對化靈，他整條右臂沉得抬不起來。「你知道？那你抬手。」他抬不起來，臉漲紅，仍說「再一次」。她鬆手，在簿上記傷處：「七日後再來。早來一天，我讓你多等七天。」
3. 她收簿時，夾在裡面的碧梧驗植紀錄滑出一角；同日還有要驗的藥樣。她為一個洞天新弟子放慢，是因為辨錯重驗教過她要慢，不是因為他特別。
4. **接續分場**：星羅身來，她辨出「上次來的不是你」。他說是我，她說不是。她看他一會兒，忽然笑：「那上次那個欠我一句謝，你替他還？」他說「謝」；她說：「不是你欠的，不收。」封寒在旁聽見，沒插嘴。這一拍是全書她第一次捉弄他。

- **第4章（報名與三碼）**：保留原事件。加一拍：她要他叫「師姐」。「妳跟我差不多大。」「我入碧梧那年，你還沒進太玄閣。」鎮岳的病人她都給三碼，「別人一欄，他兩欄」照留。
- **第5章（護短）**：九霄兩名老資歷撥下星羅身的爐位牌，他先刷爐。原本蘭嫂翌日照排撥回；改為生當日看見，先問兩人：「誰排的？」他們說資歷；她說：「爐位是蘭嫂排的，不是資歷排的。」蘭嫂照排撥回，仍不替他出氣。私下她對星羅身說：「被撥了牌不吭聲，刷完還開自己的爐——傻。下次先問排程。」本尊回歸後才知道整件事、沒有去找人，照留。
- **第12章（原則）**：他燙傷顧小滿。顧小滿來丹閣，她先處理手腕；陸沉擦破的手肘她不接：「自己弄的，排後面。」與岳沉淵「自己弄的傷，要報」同向，不袒護。
- **第14章**：「劫，出去接雷」照 M1 歸她說。
- **第16章石凳**：一桌人坐滿時，路過的弟子向她點頭行禮；池杳打趣她「師姐架子」，她說「架子是丹閣給的，脾氣是我自己的」。
- **第22章採藥**：她傳碼問他有沒有空，名義是「少一個揹筐的」。厄墊窩的雷紋石照留。
- **第24章百宗十人回山**：「有人帶傷直接送碧梧」——送來的是問劍峰衛琅，她接手（見本節第8小節）。

### 6. 宗門大比：卷五七峰爭鳴的「守擂」（工作設計）

**落點與規則**：卷五七峰爭鳴分兩段——峰對峰的對抗（**陸沉與封寒的正式交手在此，勝負照章綱另定，本稿不動**），與十人選拔的個人輪。個人輪新增工作設計「**守擂**」：每峰可推一名**不報本屆十人**的弟子守擂；個人輪連勝四場者可挑一擂，勝者直入最後名單考核（仍不保證入選），敗者無罰，只失面子。**本屆十人名單不因本場改動。**

**她為什麼守擂、不報十人**：她的志向是煉丹第一交椅與證明蘇聽瀾，百宗要出宗一年。「十人是去外面打給別人看的。我先把太玄的擂守住。」碧梧推她守擂，前兩日她連退六名挑擂者，其中有赤霞的器修與問劍峰的師兄，名聲傳遍七峰。

**起**：陸沉三身剛同破化靈，個人輪一路連勝四場（對手照章綱，至少含石魁），每一場最後都用同一手：以兩儀吸住對方兵勢，借力換腳搶進。看臺開始議論「這一屆是不是出了個怪物」。他挑擂，眾人以為他挑最弱的一擂；他挑碧梧。

**承**：銘紋對化靈。她只拿一柄赤霞公器坊借來的細劍，生環在左腕。開場她讓了三招，刺、收、步，一劍都不搶；他三招都打空，看臺笑了。第四招她開始還手，每一刺都落在他搶位前肩外那一寸——那是他「寧可挨一下也要擠進去」的習慣。

**轉**：他被逼到擂邊，只剩那一手。兩儀一吸，她的劍勢被牽住半寸，他換腳搶進——這一下是他整個人最盛的時候。她沒有抵抗那一吸，順著被吸的方向把劍收回來，盛極要回的那一息，她的劍尖已經停在他喉前一寸。

**合**：「你最後那一招，第一天對石魁就用過了。」她收劍，「吸的那一下最盛，盛了就要回。我等的是你回。」他不服：「再一次。」「明年。」看臺先靜後鬧。她沒有放水，堂堂正正贏，一句客套都沒給。

**賽後（私下）**：當夜他在鎮岳碎石場一個人練換腳。她提燈來了，說是「順路收藥」。她指出他搶位勢的毛病：肩外先挨一下才擠進去，是把一記傷當成過路費；遇上會等的人，那一下就是收你的地方。她陪他練到深夜，用細劍點他的肩，點了九十九次，他躲過最後三次。他問：「妳為什麼幫我？」她說：「我贏得太容易，不好看。明年讓我多出兩招。」臨走塞給他一枚化瘀丹，沒收丹錢。讀者看得出，她不說。

**與霜降爐的關係：並存。** 宗門大比是十四歲的「實力壓制」，她還不會秋，只會讀盛；霜降爐是十六歲半的同境正面勝場，第一次給出秋、神兵開鋒。兩場不同對手、不同年紀、不同劍理階段，前者是兩人關係的地基，後者是她自己的劍道機緣，各有用處，不合併。

### 7. 丹道大比：卷五重鑿後的主峰丹閣「開爐試」（工作設計）

**落點**：卷五重鑿只接回一半，主峰幾處爐位重新開火、丹庫空了。丹閣（何靜安）辦開爐試，定次年**首爐位**與丹庫主供名分。題目同材「回元丹」，供重鑿傷者，一人一爐；試場**不准引劫**（防毀丹傷人）。由何靜安與兩峰長老剖丹驗毒。

**人物**：鄔行簡（工作名，何靜安首徒，銘紋，分火九路、快而穩，真天才）；撥過陸沉爐位牌的九霄老資歷；陸沉的星羅身也報了名。生右手三指仍麻（卷三共爐）。

**起**：陸沉初試就出局——他的好丹要引劫，試場不准；不引劫的那一爐只中品。他只能到臺下。鄔行簡真心勸生退出：「三指這樣，妳收不了丹。」她把生環套上爐口：「我收得了。」

**承**：鄔行簡九爐齊開，一個時辰便成九枚上品；臺下押注一面倒。她的爐看起來什麼都沒發生，藥在裡面一味一味地活。

**轉**：最後一刻，丹閣屋外雲聚起來，雷聲壓著檐角。全場轉頭看陸沉，有人喊「劫，出去接雷」；陸沉在臺下說：「不是我。」是她的丹走到了近無瑕，自己引來了劫。照規矩，劫一落她就出局、丹也毀。她兩指在爐沿一點，在最盛前一息收丹——雲散了。

**合**：剖丹。她的丹溫的，斷面九圈年輪，毒近乎無；鄔行簡九枚上品乾淨，卻沒有年輪，長老驗出藥性只交七成。何靜安判首位洛生衣。鄔行簡的九枚先入丹庫、先救了更多人，這份真本事不被抹掉；他問她為什麼不讓它到無瑕，她說：「再一息劫就來。傷者在等，丹不能賭。」

**陸沉在臺下**：他看了很久，只說了一句：「她把天上的雲收回去了。」他自己正在學把雷收成一線，這一句是驚嘆，也是他記住的事；不搶她的場。

**所得**：次年首爐位、自選材資格、丹庫主供名分；三指仍麻。全宗從此叫她「碧梧小丹君」（工作外號）。

### 8. 全宗的天之驕女：名望、追求者、對手與驕傲

- **名望**：宗門大比守擂不敗（陸沉之前已退六人）；開爐試首位；丹閣最難的單子交給她；外號「碧梧小丹君」。外宗長老出三倍價要她連煉三十爐，她說「長老要的是三十爐，還是這一爐？」（第七節樣場一的少年版可用）。
- **追求者：衛琅**（工作新人物，問劍峰，上屆百宗十人之一，劍好、人傲）。卷三第24章十人回山，他帶傷送碧梧，她接手。他痊癒後每季送一條劍穗，請她試劍；她每次都應，每次都贏，劍穗退回。卷五守擂，他是她連退的六人之一，輸了仍在看臺第一排替她鼓掌。他看見她深夜提燈去鎮岳碎石場，第二天沒有再送劍穗，改來丹閣排隊買丹。他有自己的路：百宗後轉修劍陣，後來在上界自立。不做丑角，也不做情敵戲。
- **競爭對手**：丹上鄔行簡（快與量）；劍上日後的沈照野（同代劍敵）；心上池杳（「生辨的是身體，池杳辨的是心」，兩人互不服）；書院後寧枕微（丹醫對丹毒，對手兼摯友，照 Canon）。
- **她自己的驕傲**：不收「大概」的丹方；不接替人選路的請託；輸了當面承認（三千花夜 B6「她的火候比我好」）；贏了指尖在膝上輕叩一下（碧梧師妹說，那是她贏了才有的小動作）。

## 六、成長四階的錨點事件

### 之一　少年：霜降爐（勝沈照野，神兵開鋒）

**時點**（必修 11）：第5篇之後、第8篇飛升之前；首選卷十九「劫生回太玄」休整空窗，待聯排與霜降節氣核對。生約十六歲半，**銘紋後段**；沈照野同為銘紋後段，同境；不碰列陣門（刪甲原稿「可能已觸列陣門檻」）。陸沉在場只看，不出手、不出主意。私人約戰，不改任何宗門賽果。

**她要什麼**：知秋已成胚，還沒開鋒。赤霞山腹爐每年只在霜降那一日起霜火，一口爐只開一把劍的鋒。今年爐位已許給外宗交流而來的**沈照野**（東溟長川劍派首徒，工作新人物）；他為衝擊列陣、成就劍道，用宗門珍材換來這一爐。

**他要什麼、他的本事**：「不謝劍」是一門連綿劍法：每一劍在前一劍將盡未盡時就已生出，劍勢始終八成，不起高峰也不落低谷。他要開鋒的長川劍，就是為了讓這股勢永遠不斷。他在赤霞峰當眾說：「死木開什麼鋒。碧梧該做的是救活東西。」雍離不裁決：「爐只一口，你們自己定。」三場，十日內先勝兩場者得爐位。

**起：第一場，真敗。** 她已會一葉：先看完一記招式的完整週期，再在盛點秋掉。沈照野的劍沒有盛點。她等，他不給；第四十招，她的腕被長川劍背震麻，劍胚脫手，插進爐外焦土。沈照野沒有羞辱她：「妳在等我開花。我的劍不開花。」

**承：死了的劍告訴她的事。** 她不去練劍，去赤霞器坊請秋澗再讓她辨一次那條斷了的劍脈——不是想接，是想看它死在哪裡。斷在回劍那一下，正是一劍最盛、即將折返之處。秋澗說出三句劍理（第二節）。她想起爐裡有些藥不到時令不開花，你得給它夏天，它才有秋天。她的打法整個變了：**逼他開花。**

**轉（一）：第二場，勝。** 她主動壓上，刺擊一記比一記重，生環在腕上撥擋空側。第六十三招，他接不住，長川劍一劍拔到十成——整場唯一一次盛，一葉正落在那裡。他的劍光枯黃捲邊，一片片落在兩人之間，他連退七步出圈。一比一。

**轉（二）：第三場，她又落下風。** 沈照野一夜沒睡，想通了：死守八成，只在她壓得過深時反撩。第三十一招，長川劍割開她右腕，筋脈一麻，劍胚差點脫手。她以生環貼腕，生衣護住這道傷，再以續脈手法把麻掉的腕脈自己接續十息——醫術用在自己身上，不用來傷人；代價是事後三日拿不穩丹勺。十息之內必須贏，他不開花，她也逼不動了。

**合：兩朵花，一個人知道怎麼謝。** 她自己先開花：一劍推到最盛，毫無保留地遞出去，等於把自己整個破綻亮給他。沈照野是真天才，看出這是唯一的勝機；要截一記十成的劍，他只能用十成去接。兩把劍同時走到最盛。下一息才是勝負：他只會延續，不知道盛之後怎麼辦；她從小在爐前做的，就是在最盛那一息收。她的劍在盛點收住、一轉，秋落在他的劍勢上，長川劍光從劍尖一路枯到劍格。劍胚的尖停在他喉前一寸。「我的劍會開花，」她說，「也會謝。」

**所得與餘波**：
- **霜降開鋒（神兵出世）**：霜降日赤霞山腹爐起霜火，雍離親自開鋒，秋澗口述劍理。鋒成那一刻，封閉的山腹憑空落下一片梧葉，整座赤霞所有爐火同時暗了一息，像一齊感到了秋。知秋自此成為殺劍。當夜陸沉說「很好看」，護手第一次吐葉（冒芽①）。
- **沈照野**：失爐位，帶走自己真正的空門：他的劍不敢盛。回長川劍派要把「不謝劍」改成「謝了還會再開」，約上界再見。
- **碧梧**：有人說她不務正業，荊問只說：「她收得乾淨。」
- **傷帳**：右腕三日不穩，第五日回爐前。贏了就是贏了。

### 之二　下無極：蚨渡——第一次親手殺人（必修 6）

**時點與邊界**：第9篇天狐本源傷案之後、第15篇封傷之前，建議約二十一歲，待聯排；與《月下共逃》生的時程（攜爐親赴至先走）不重疊。生尊者中段。**這是她自己的事件：守路線 A「不進他的案子」**，與陸沉在下無極的追殺、清算、九弱、狐闕、三宗、同歸會都無關；她不傳三碼求援，陸沉不在場。

**人物（工作）**：**桐兒**，十二歲，下無極東陲蚨渡的藥工；**聶長庚**，散修丹師，尊者後段，與蚨渡坊正有合約，經營「養青坊」。

**起：她自己的傷者。** 桐兒被送到玄殿碧梧丹閣時，生機亂跳，像一株被催早開的藥。生陪了她三旬，一點一點把生機放回原來的節拍。桐兒想回家，生問過她本人、答應了，給她帶了三個月的丹。兩個月後，蚨渡的丹單停了。生向丹閣告研究假，自付路費去看。

**承：救不回的命。** 蚨渡的養青坊收藥工，餵他們聶長庚的催生丹，讓血裡的藥性提早熟，熟到盛時取血入爐，煉成「青蚨丹」賣給求延壽的修士。藥工拿工錢，按了手印。桐兒又被收了回去。生找到她時，她的生機已經被催過了盛、正在衰，爐裡沒有東西可以收，也沒有東西可以續。生用了留生一線、續脈、她身上所有的丹，桐兒還是在天亮前死在她懷裡。她問過的那句「想回家嗎」，答案是想。坊裡還有七個人。

**轉（一）：她想不殺。** 她當眾到坊裡要聶長庚停手。坊正站在他那邊：「合約、手印、工錢，哪一樣不對？」聶長庚把爐中的青蚨火催成法相嚇她；法相全盛撲來，她迎上去一點，整座爐火從火頭一路化成灰金落葉，坊裡的人第一次看見那種秋。知秋指著他：「停。」他沒有讓火走到盛的第二次機會——他捏碎一枚瞬發遁符，帶走兩個藥工。遁符不經盛，她秋不到。**這是她真被剋的一次。**

**承（二）**：她留下來安頓五個人，先做醫者的事：救活之後能不能繼續生活。其中一個藥工說出聶長庚上游二道灣還有一座坊。她沒有傳碼給任何人：「這是我的事。」

**轉（二）：人質與選擇。** 二道灣，聶長庚已把被帶走的女孩放進養青陣，今夜就到盛。他拿女孩當人質，要她退。她把生環擲上女孩，生衣經環罩住孩子的生機不被陣抽走——她的左手空了，回劍露空，聶長庚一刀從她左肋切進去（尊者可當場止血）。他催陣到盛，要在她近身前把血取完；陣所發的那道取血之法在盛點被她劍觸，秋了，陣基還在，法死了，女孩脫出。知秋抵在他喉前。他說合約、說錢、說「我也救過人」，手往袖裡第二枚遁符摸——她在他撕開符之前，一劍穿過他的心口。

**合：殺人不是秋。** 法死在盛點，像落葉，乾淨；他死得不好看，半句話卡在喉裡，血流了很久。她的手從爐前到現在第一次抖。她什麼都沒說——「我送你」是後來的事。劍脊多了第一圈年輪。她把兩個孩子帶回蚨渡，把桐兒的名字寫進自己的傷錄最後一頁。從此她把送和殺分開：**法可以秋，人只能由她決定。**

**得失**：第一圈年輪；判斷成形；左肋傷數日；研究假超期，碧梧罰她三月不得領上等材；桐兒仍然死了。坊正與合約的後續交地方處理，不擴成組織陰謀。

### 之二（續）　下無極：晚霜蘭一夜——獨立丹道勝負（必修 6）

**時點**：約二十二歲，蚨渡之後，待聯排。不靠劍、不靠劫、不靠陸沉。

**局**：下無極古丹家岑氏庭中有一株晚霜蘭古株（工作設定），六十年開一夜。岑氏辦燈會：受邀丹師每人得兩朵，一朵丑時「初剖」，一朵天明「終剖」，當夜煉成；首位得岑氏《陪藥錄》殘卷與晚霜蘭分株。《陪藥錄》記的是古人「陪藥活完」的煉法——她想知道蘇聽瀾那條路，古時有沒有人走通。對手**岑栩**（工作名，岑氏少主，尊者後段），死煉名手：摘即殺青，一朵花分火九路成九丹。他當眾說：「碧梧是醫，不是丹。」

**起與承（真敗）**：子時花開，人人認定那就是盛。她把第一朵養在爐口生環上，子時一到就收。初剖：上品，年輪卻斷了一圈，帶一絲霜毒；岑栩九枚上品乾淨。她輸了初剖，當場承認。

**轉**：她不再看花。她守在古株旁看了半夜，發現花的盛和藥的盛不是同一息：花在子時開到最盛，藥性要等天明前那一層霜結上花瓣才走到最盛——霜也是它一生的一段。她不收第二朵，讓它帶著爐火一路活下去。其他丹師陸續交丹離席，岑栩笑她等過了時辰。

**合**：卯前霜落，她收。丹走到近無瑕，庭外雲聚，岑氏長老變了臉色——丹劫若落，古株也要遭殃。她兩指一點，在最盛前一息收手，雲散。終剖：她的丹溫的，年輪十二圈連霜紋，無霜毒；岑栩九枚乾淨，沒有年輪，藥性只交七成。長老判她首位。岑栩問她為什麼不讓它到無瑕。「再一息劫就來。這是你家的院子，花還要再開六十年。」他第二天來找她，問下一個六十年能不能一起陪那株花。

**所得**：《陪藥錄》殘卷——證明古人走過「陪藥」的路，卻沒有寫怎麼收，收是她自己的；晚霜蘭分株，活根養在碧梧。岑栩的「量」真贏了賣價，不被抹掉。

### 之三　上無極：血河客——秋掉敵人的法，回頭護敵方傷者（必修 7，吸收 A11）

**時點**：約二十九歲，上無極，她自己的採藥行，待聯排。生真一後段至天神前（依年表推）；血河客同大境後段。

**人物（工作）**：**血河客**，以血河法殺採藥人取血；**鄒十三**，他從小收養的徒弟，血河客的替命符是用鄒十三的本源煉的——每燒一張，鄒十三便虧一分本源。

**起**：她在赤沙谷採藥，撞上血河客屠一隊採藥人，只剩一個採藥童。

**承（真被剋）**：第一回合，血河客捏碎一張符，做成全力觸發的樣子；她迎上去秋——秋空了，那是假符，偽盛。她神識白耗一記，鄒十三從側面一刀砍進她肩上。

**轉**：她把生環從左腕褪下，擲向採藥童，淡青的光罩住孩子；她手裡只剩劍。血刃十三道在盛點撲來，她迎上去一點，血刃從刃尖一路轉成鐵鏽色的落葉。她斜進一步，劍從他第四根肋骨間穿過去，停在背後外一寸。他還在笑，捏碎第三張真替命符——替命之法觸發那一息就是它的盛，她的劍正在他身體裡。符燒了，什麼都沒發生。他想往血裡遁，血遁之法再觸發一次，也在她劍上秋了，血不肯接他。「我送你。」她抽劍。

**合（救敵方傷者）**：鄒十三倒在地上。前兩張替命符已經抽走他大半本源，第三張剛開始抽就被她秋斷，人還活著，正在往下掉。一刻鐘前他還在砍她。採藥童已經安全；她走過去，把生環從孩子身上取下，套到鄒十三的腕上，生衣罩住他那道本源傷不再往下走。「他拿你的命替他的命。現在你的命是你的。」鄒十三後來去哪裡，他自己選。

**得失**：劍脊一圈年輪；右肩刀傷；神識耗盡，三日不開爐。殺與救在同一場裡，都由她決定。

### 之四　高境：縛屍谷——春秋兩岸的構圖（必修 4，吸收 A12）

**規則先統一**（修丙案自相矛盾）：屍傀本身是死物，沒有法的壽；驅動屍傀的是煉屍者的**縛屍之法**，那道法有壽、會盛——屍傀撲擊的那一息，縛屍之法最盛。所以她秋的是縛，不是屍。**純石傀、器傀沒有縛，本體是器，她只能用劍。**

**奇觀**：煉屍宗主驅三百具屍傀過谷，谷後是一個整村逃不出去的人。她展開兩岸：春岸在身後，全村人站進去；秋岸在前。屍傀渡河，每一具撲到她面前時縛屍之法正盛，她一刺，縛化成一片金葉飄向秋岸，屍身落地，還成一具屍。三百處落點一路落滿金葉。最後十二具是純石傀，她只能一劍一劍拆，劍刃崩了兩處。她走出谷口時臉白如紙，劍在發抖。煉屍者本人高她半境，在谷外重新縛屍，她還得拖著這身子去找他。

**界限**：屍傀不是人，不計年輪；被秋的縛散回天地，不給任何人；她不讓屍身復活，也不讓村人多活一日，只讓他們能走出谷。高境只到這個構圖；具體戰果與後續留全書聯排。

## 七、非正文樣場

### 樣場一：人前仙子（非正文；下無極，玄殿碧梧丹會；合寫甲樣場一與乙樣場一，吸收 A7）

> 長老把她的丹放在白玉盤上：「碧梧一系今年的上品，有三枚出自同一人之手。老夫活了一千二百年，沒見過這種事。」
>
> 意思很明白。洛生衣起身，素衣，腰間懸著知秋，枝葉形的金絲護手在燈下一亮。她向長老行了一個不深不淺的禮：「請長老借刀。」
>
> 丹剖開，斷面一圈一圈，細得像頭髮，還是溫的。
>
> 「十一圈。」她說，「霜燈草走了三轉，赤節藤兩轉，桂管苔一轉……長老若要，我把爐冊送到您府上。」
>
> 世家來的另一位長老撫鬚笑道：「洛丹師好手藝。老夫出三倍價，今夜再煉三十爐，名分好說。」
>
> 「三十爐煉不出這樣的丹。」她把丹封回玉匣，語氣仍然客氣，「長老要的是三十爐，還是這一爐？」
>
> 「年輕人，丹師也要吃飯。」
>
> 「所以晚輩只賣這一爐。若長老數不清這十一圈，明年我再來，帶多一圈的。」
>
> 看臺上有個年輕劍修高聲問：「聽說洛丹師腰間那柄也不是擺設？」
>
> 她這才轉頭看他。「不是。你若想試，明日辰時，丹堂後院。別遲到，我要趕下一爐。」
>
> 滿堂靜了一息，接著都笑了。她回座時，指尖在膝上輕輕叩了一下。

## 九、給《日月藥天》的接口（必修 8；兩張可替換場景卡草案）

**接口原則**：以知秋主攻、迎盛而秋，破炅舟的熾陣與真身法相；以生環春徑護撤路。勝法核心是**劍上的生死判斷**——哪一息讓它盛、哪一息收、殺不殺——不是醫術判斷，也不是讀對方換氣。她在本篇的獨立丹道成果（錯時丹、錯時散）照原稿，不靠妖、不靠劫。以下只寫可直接替換的場景卡，不改日月藥天現稿。

**境界前提**：沿用日月藥天現行工作假設（生約斬我、炅舟遁一中期），斬我對遁一是越一大境、未跨質變點，照第一節「葉可落，根不動」：她只秋得掉伸到面前的那一環、那一層法相，炅舟須付本源才能重煉。若作者採年表「終局天神後段」，生約三十一歲在天神前段，炅舟與正午宮修士要整體下調到天神同境，否則跨虛道門，正面不可勝（見風險 R1）。

### 第13章（替換卡）　她收的時候我出｜第22–23日

- **局**：炅舟帶三名正午宮修士來缺廬拆〈夜樞〉。缺廬在晷影深處，熾陣失主場，三環只撐得住一環半。妖掌傷未癒，一運〈落暉〉就燒；淡月影只撐一次換位。缺廬後門通霜林，是兩人唯一的撤路——熾熱一灌進霜林，妖掌上的灼傷就會重新燒起來。
- **第一輪（真被壓）**：生環在左腕作撥擋，知秋主攻。炅舟的熾陣專壓她回劍那一瞬，回劍一收前胸就空；她被逼退，右手虎口裂開（照原）。
- **她的選擇**：她把生環擲落缺廬後門，春徑沿石座一路抽到霜林口，一人寬，一刻。妖站進徑裡：熾熱抽不走她的生機，掌傷不再往下走，她可以從徑沿出弦月。代價是生左手空了、回劍露空。
- **第二輪（迎盛而秋）**：生不再躲熾陣。她看熾陣第一環從起熱、推出到全推的那一息——那是它的盛。她迎著那一推踏進去，知秋一點，第一環的熱從環頭一路褪成黃昏的顏色，化作灰金色的落葉落在霜上，第一環斷了。這一步她要判斷的是：這一息迎上去，她會不會先被燒穿。她判斷不會，於是去了。妖在她收劍那一拍從徑沿出弦月，兩人輪流，不同時出手（照原）。
- **背刺（照原，因果改緊）**：一名正午宮修士看準她環不在腕、回劍露空，從背後取她要害。妖收起笑，一刀斬落。生回身，確認他死了，替他闔上眼。「他要殺我。」「嗯。」「謝謝。」
- **收**：炅舟護體日身還在，生剛秋掉一環、神識已耗；她選守住撤路，不追。炅舟敗走，帶走〈夜樞〉三分之一樞片（照原）。
- **後果**：照原——正午宮死一人，正午祭提前到第39日。

### 第19章（替換卡）　生迎炅舟｜第39日午（生的段落；妖對暘芷照原）

- **局**：炅舟熾陣第一環在第13章被秋後未及重煉（越一大境，他須付本源才能重起，正好沒來得及），只剩兩環；他在日道頂受日光加持，生在影道口背著暗處。
- **真反制（對手學習）**：炅舟記住了第13章——她只在盛點出手。他改為**半推即收**：每一推只推到七分便換下一環，連推不歇，不給她盛點。第二環的熱真打中她左臂，她退三步，連被壓了三輪。她以收焰丹壓住臂上灼傷（照原）。
- **她改的一步**：她把生環擲落影道口，春徑沿影道往下抽出一刻——那是兩女萬一日道頂失手時唯一的撤路，也是炅舟今天受命要封死的路。炅舟不能讓這條徑留著：他必須一推燒斷它。要燒斷一枚環圈出的春徑，七分不夠，他只能推到十成。
- **迎盛而秋**：熾陣最後一環推到最盛的那一息，她從徑旁迎上去，知秋一點，最後一環從環心一路秋成落葉。炅舟的護體日身法相在他身前全盛亮起，要擋她下一劍——那也是盛。她第二劍點在法相最亮處，只秋得掉擋在喉前那一層（越一大境，葉可落、根不動），已經夠了。知秋停在他喉前一寸。
- **殺不殺**：他是來封路、拆樞的，不是來殺村的；她要的是樞片，不是他的命。「樞片。」炅舟把三分之一樞片拋在地上，退出日道（照原）。春徑後來沒有用上——妖贏了；但炅舟不知道。
- **收**：她把樞片收進泥封，左臂灼傷留到戰後自己處理（照原）。**這是生本人贏下的一場，也是她本人贏回的一件東西。**
- **原句替換**：「勝法的核心是她的醫道判斷；器形待接生道重設」改為「勝法的核心是她劍上的生死判斷：逼他盛，在盛點收；不殺，由她決定。器為知秋與生環」。

## 十、與嬋九歌區隔（必修 9）

**一句話**：生讀的是**法的一生**（生、盛、衰、謝），逼出你的盛並收掉它；嬋讀的是**力的盈缺**（供力、晦明、潮），等你那一下供不上時進去。生死是生命的來去與她自己的判斷；日月是兩種力量的晦明與並立。不寫成籠統的陰陽大道。全稿描述生時不用盈、缺、虧。

| | 生・洛生衣 | 妖・嬋九歌 |
|---|---|---|
| 讀的是 | 法的一生：哪一息最盛 | 力的盈缺：哪一下供不上 |
| 出手姿態 | 正面迎對手最強的一招，像宣判；必要時逼對手盛 | 笑裡藏刀，換位、繞行、從對手供不上的那一拍進去 |
| 收尾 | 那道法死了，不可逆；只有天地會長出新的 | 晦明循環，月會回來 |
| 器 | 一柄有年輪的殺劍、一枚爐環 | 月刃、月影千身、蝕月，後期日影 |
| 殺意 | 「我送你」，殺前說理由 | 笑一收，冷殺，不解釋 |
| 精彩 | 決鬥、宣告、劍域奇觀、迎強而勝、丹臺奪首 | 狡局、險地、交易、捨身禁術、日月相斥 |
| 私下 | 人前端莊；私下逗陸沉、丹爐被拆會羞惱、主動邀試劍、嘴硬被護手出賣 | 主動調戲、話說滿、半真半假 |
| 終極 | 生死輪迴：春秋兩岸 | 日月同天 |

**同場分工**：嬋讓對手亂、換位，生逼出對手的盛並收掉它；兩人都有自己的殺著，不是一個打一個治。日月藥天第13章就是樣板：生在盛點收，妖在她收劍那一拍出；正午宮修士背刺時，殺人的是妖。兩人不一起「等時點」：嬋等，生逼。

**不讓妖負責精彩、生負責深情**：生有沈照野、聶長庚、岑栩、血河客、炅舟這些自己的對手與勝敗，有劍脊年輪的帳，有開爐試與晚霜蘭的丹臺高光；嬋有師姐的罪、闕的道統與日月。兩人各有一次「我不殺」與「我殺」，理由各自不同。
