# 《劫》｜洛生衣：生命大道重定位與故事補強

**狀態：作者討論候選，尚未回填 GitHub Canon。** 本稿依目前對話與已核對的洛生衣人物卡、《三千花夜》《日月藥天》等整理；新神通與故事都需審查。

## 一、人物重新定位

**洛生衣不是專門醫修，而是修生命大道的絕世女天驕。煉丹是獨立專長，醫道是生道的一種應用，雙生環是正面戰鬥兵器。**

推薦「生道為根、萬生為象、生滅為戰、造化為遠景」，不是四種大道同時兼修。最終偏造化還是輪迴，暫不定。借鑑《仙武傳》楚萱兒的清麗仙子氣質、強者威嚴、私下俏皮羞惱與感情主動性，不照搬師徒關係或情節。

| 層次 | 定義 | 避免 |
|---|---|---|
| 大道 | 生命生長、延續、演化、止息、生滅 | 只等於治傷 |
| 戰鬥 | 雙生環、生道術、道域 | 永遠輔助 |
| 專長 | 煉丹、丹方、古爐、丹道競爭 | 萬能丹藥 |
| 應用 | 醫道、續脈、護元、承載判斷 | 唯一身分 |

## 二、保留既有設定

1. 生先在太玄宗，劫入宗後於丹閣相識；蘇聽瀾已故、荊問現任；不恢復滅門線。
2. 保留「尚安／需藥／勿來」、「勿沉」與第28篇才說破的主感情線。
3. 第5篇她接不回陸沉傷勢，柏鶴齡接得回來，是真敗。
4. 九界金丹拒絕犧牲無辜經脈；第20篇她獨自拒絕以九弱生命還形蘇聽瀾。
5. 第23篇驤鳴「勿來」仍前往、剪死節點，交通按「真正先返太玄」新裁定重接。
6. 《三千花夜》賀春望、獨立成爐、四時仙池、丹題首位、108日保留。
7. 《日月藥天》生與嬋先行、劫第三位受邀；生有自己的丹道成果與雙環勝場。
8. 雙生環、兩岸、輪印、輪迴方向先核 D116 與正式武學譜，不搶先解鎖。

## 三、大道成長

**少年・萬生**：理解活力、韌性與成長，雙環先練真正的器武、步法與攻防，不必靠生機干涉贏。

**上界・生滅**：理解生命不只是增長，止息也是生命的一部分。能截斷敵人實際可觸及的續力節點，但不能看一眼便奪壽或判死；強敵可反制。

**高境・兩岸**：生與滅進入雙環法相與道域，具體形態、境界與輪印按既有設定。

**極境・造化／輪迴（待裁）**：探索生命能否走出既有形式，不能無限復活、無代價造生命。

## 四、性格與魅力

**人前**清麗、有禮而有距離、敢向同代強者邀戰；**朋友前**有好勝心、會笑、會記住輸過的丹題，能與池杳、寧枕微、賀春望談自己的修行與趣事；**陸沉面前**溫柔又偶爾羞惱、嘴硬、主動邀約；**戰鬥時**冷靜凌厲，能殺敵但有自己的判斷。

>
> 「沒有。我拿了古碑拓片來給妳看。」
>
> 她把拓片推回去：「今日不看。」

讓她自己發起故事，而非每次都由陸沉受傷觸發。

## 五、雙生環候選戰法

| 技法 | 作用 | 限制 |
|---|---|---|
| 回環 | 一環出、一環接，回收連擊 | 依器武步法 |
| 交錯 | 一環封退、一環斬入 | 強敵可拆角度 |
| 折勢 | 借敵攻擊落點反截 | 須讀準節奏 |
| 續勢 | 接上自身將斷的攻勢 | 消耗承載 |
| 斷續 | 截敵實際供力的一拍 | 不等於直接斷命 |
| 兩岸初形 | 生滅道理進入雙環 | 須核 D116 |

雙環只是兵器，沒有雙環她也應能施展生道術。後期可有一環萬物復甦、一環萬象止息的仙道奇觀，但必須有代價與反制。

## 六、新增故事一：《雙環問道》（8–12章候選）

**落點**：少年太玄宗，先核大比與丹閣年表。

- 起：有人認為碧梧弟子只會療傷，生主動爭一份古環戰法。
- 承：遇上專克回環收招的同代天驕，真正敗北。
- 轉：她自行改變雙環出收節奏，靠器武與步法正面反勝。
- 合：得到有限古環傳承與長期對手，成為同代公認的能戰女天驕。
- 情感：陸沉賽後問傷勢，她先問：「你覺得我最後那一環如何？」他認真分析，她才笑。

## 七、新增故事二：《萬生古庭》（25–40章候選）

**定位**：生獨立大冒險，陸沉可以完全不出現。下無極或上無極空窗待核。

**仙境**：古庭仙木隔漫長歲月自行換根，舊根沉地成古道。各宗以為萬生種可延壽，真正試煉卻考驗不同生命的成長與止息。

1. 入庭（5–7章）：與寧枕微、木靈天驕、器修對手競爭，寫仙市、古木、交易與生活。
2. 真敗（6–8章）：她誤判古木節律，失去機緣；敵手先得手。
3. 分路（6–8章）：她與寧枕微各自求道，理解新生有時需要舊根讓位。
4. 天驕戰（5–9章）：以雙環與生道正面擊敗強敵，取得有限生滅古痕，不靠救人順便獲勝。
5. 歸途（3–5章）：開出下一階段環法與丹道研究；同伴、敵人各有所得。

**禁止**：全篇寫成救災、萬人跪拜、撿一株神藥；要有奇觀、爭鋒、真敗與修士生活。

## 八、新增故事三：《兩人問仙》（30–45章候選）

**定位**：劫與生真正的雙人仙道旅行，不以救治為核心，不重複《三千花夜》。

- 起：生主動邀劫探索一條隨古界換季開啟的仙路；她求生道古痕，劫求古禁與雷身承載。
- 承：陌生仙域、仙市、奇獸、同代爭道會。生先取得關鍵資格，也有真正悠閒日常。
- 轉：劫想破禁探真，生擔心強開破壞當地生命演化；兩人各有道理，分路查證。
- 合：劫找到可逆破禁法，生找到古跡自主開啟的生機節律；兩人各有成果，互不替代。
- 尾聲：不提前告白、同命契；留下共同看過的仙景、輸過的比試與夜裡的玩笑。

## 十、生與嬋的區隔

| | 生・洛生衣 | 妖・嬋九歌 |
|---|---|---|
| 氣質 | 清麗、有威嚴、私下俏皮 | 妖媚、狡黠、半真半假 |
| 戰鬥 | 雙生環、生滅、生命本源 | 月影、蝕月、日月 |
| 大道 | 生命延續、止息、造化 | 盈缺、日月並立 |
| 與劫 | 長年相知、共同創造未來 | 天驕爭鋒、雙人逃亡、生死情誼 |

**不能讓妖負責精彩、生負責深情。** 兩人都要有獨立冒險、真勝真敗與吸引力。

## 十一、AI 團隊導入指令

1. **盤點**：核洛生衣人物卡、D116、主角群武學譜、核心感情線、第5/15/20/23/28篇、《三千花夜》《日月藥天》與全書年表。分「硬約束／可調／新增」。
2. **定位**：把專門醫修印象改為生命大道修士；煉丹獨立、醫道為應用。不可機械刪除既有醫術。
3. **武學**：建雙生環各境界能力、反制與真敗帳，不提前輪印、兩岸或第三形態。
4. **競稿**：三個新故事各交獨立寫手，提出可行落點、篇幅、場景與既有故事的差異，不為湊章數重複救人。
5. **審查**：檢查生是否有陸沉不在場的勝敗、獨立朋友、主動性、人前仙子與私下俏皮；不照搬楚萱兒。
6. **聯排**：核年齡、境界、交通、傷帳、丹方、感情節點、兩岸武學與《日月藥天》接口。交影響檔與 diff，**作者確認後**才回填 Canon；正文維持凍結。

## 十二、驗收標準

- 少年時有一場不靠救人的雙環正面勝場。
- 至少一部陸沉不在場、生自行爭奪機緣的長篇。
- 劫與生有不靠受傷、不只煉丹的完整雙人旅行。
- 生會笑、會惱、有勝負心，主動邀約，仍保留溫柔與原則。
- 生道有仙道奇觀、真敗、限制與反制，不是萬能救命。
- 既有《三千花夜》、九界金丹、驤鳴、《日月藥天》因果不被推翻。
