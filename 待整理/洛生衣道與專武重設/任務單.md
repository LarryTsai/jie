# 洛生衣：生道搭刺劍｜三寫手競稿任務單

2026-10-12｜主編發派。依[團隊競爭創作規約](../../設定/00_故事定位/02_工作規約/AI團隊競爭創作規約.md)：三位寫手獨立、互不讀方案，各寫自己的檔（甲.md／乙.md／丙.md）；之後由未參與構思的獨立Reviewer比較。候選、非Canon、非正文；不得修改正式區或其他檔案。

## 作者已定方向（硬約束）

見[作者方向紀錄](作者方向紀錄.md)：
1. 人物核心保留：她珍惜生命。**生道是她開始的道（丹承生）；劍走死的道；最終合為生死輪迴道。** 要重做的是戰鬥表現——更強、更帥。**劍是殺劍**：真正的殺伐之劍，能鎮殺強敵；殺與不殺由她自己判斷，仍受境界與反制約束。
2. **主武器：偏華麗護手的古典刺劍。** 兵器是人物的延伸，不能把她的道寫成「刺穿／精準」。
3. **煉丹第一交椅必須保留**；她的「生」正是讓丹藥成為極品的獨有品質來源。醫道是理解生命的一種技藝，不是她的唯一身分。
4. **魅力**：類似《仙武傳》楚萱兒的感覺——人前清麗仙子、強者威嚴與好勝；私下俏皮、羞惱、嘴硬；感情主動卻不放棄自己的仙途。只借氣質，不照搬師徒關係或情節。
5. **雙環只保留「生環」一枚**作次要器（承生：丹道、護生），另一環撤。D058「雙環第三形態」是作者底牌：**不得提案、推演或引用其細節**。
6. **留碧梧峰**：荊問現任授業、蘇聽瀾為入峰前已故啟蒙者，不動。

## 每份方案必交

1. **生死輪迴道的核心一句**：生（丹）與死（劍）如何是同一條道的兩面，從「生道」起步如何一步步長出劍上的「死」，最終合為輪迴；劍上的「死」有何界限（不看一眼奪壽、不越境界牆）。
2. **刺劍**：名字（可候選）、華麗護手的樣子與意義、來歷（如何取得；可考慮赤霞峰雍離鍛造、啟蒙者遺物或本人機緣等，自行選擇並說明），與生環的分工（劍承死、生環承生）。
3. **戰鬥體系分階**：少年／上界尊者神火期／天神虛道期／高境，每階：招法或劍意、看起來的樣子（要帥、有仙道奇觀）、真實限制與可被反制處。不能萬能、不能看一眼奪命、不越境界牆。
4. **丹道**：生道如何讓她的丹成極品（具體可見的特徵、為何別人學不來、代價或限制）。
5. **魅力場面**：至少三段非正文樣場（每段200–400字）：人前仙子、私下俏皮羞惱、戰鬥中凌厲。
6. **一場少年正面勝場**：不靠救人觸發，用刺劍與生道正面贏下同代強者的完整事件（起承轉合、真敗再勝）。
7. **既有場面改寫方案**：三千花夜（A25–A28雙環戰虞靈狩）、索爾三訪C05／C13（雙環採托與互試）等雙環戰鬥場面，逐場說明改為殺劍主打、生環輔助，或場面怎麼重寫，理由為何。
8. **與嬋九歌區隔**：不能讓妖負責精彩、生負責深情。
