# 青璃三段大故事｜獨立比較與審查

狀態：第一輪獨立 Reviewer 報告；三案皆為候選，沒有作者批准或 Canon 升格。審查依據為《競稿任務單》、作者原文、來源盤點、寫手甲／乙／丙三份獨立方案及任務涉及的青璃／封寒人物資料、相關正式篇綱、修行規則與往返規則。未讀取或修改八身救生五檔，未改其他文件。

## 審查結論

**三份完整三段方案目前都不能直接選定或回填。** 我最推薦以**寫手丙作為第一、二段的候選骨架**，再獨立重做第三段的抉擇承載；不是整案通過。丙的第一段交手最有清晰的對手反制與勝法變化，第二段「雨往天上走」有最鮮明、可見的仙道奇觀，角色各自犯錯、失去東西後再改法。甲、乙的可取之處分別是甲把團隊故事的欲望與觀測所得扣得最緊、乙讓長篇中段的行會利益和共同生活較完整。

**全案共同的重大缺陷是第三段的結果已被下游 Canon 預先鎖成「保留五行」**：青璃約32歲仍以相界守孩子，35–36歲仍在上端；鬥氣轉修會散功，而且列陣以上不能回無極。故三案雖都安排了誘惑、試驗與拒絕，讀者仍會知道她不能真的選轉修而不改動既定篇章。作者要求故事推動她面對選擇，不能先替她決定；現有大綱只能把「她拒絕」做成有代價的情緒選擇，還不能讓「她轉修」成為同樣有效的故事結果。這不是靠換地點、加試煉或改台詞能修好的局部問題，須先由主編把這個限制如實帶回作者裁定。

### 哪些場面最值得留

1. **丙第一段的「回音坡」**：青璃不是全知地報答案，而是把水痕、火舌、雷聲和換勢時刻對起來；封寒第一輪多探半步、第二輪停手驗聲，生判出盛點、陸沉收住雷，各人有自己的判斷。對手鄔行嶽的回環仍保住核心，不因青璃一招就失去本事。這比單純的「她看見弱點，大家照做」更有對抗性。
2. **丙第二段的雨海**：升雨、逆風、回音與山壁構成能想像且不能換成普通山路的旅程；青璃的相界只能動五行，沒有代替她操控空間。封寒測到真回音卻錯解為直線，失去自己的航窗；青璃判錯邊界、相裂加深。這兩次錯誤讓中段推進不依賴新房間或新規則。
3. **乙第三段的轉修席與巡橋**：一門道路能給青璃一個真工作、一個名分和在聖土長期立足的能力，拒絕後失去席位；鬥氣有成果，不是專為襯托五行而設。它是三案最具體的誘惑，但仍受「結果被 Canon 預定」的根本限制。
4. **甲第一段的單人定標**：青璃把相界當精確刻度反而判錯，停下改用乾石和落腳點取勝；這是能讓她獨立贏一場、又不只是重演卷五勝封寒的好事件核心。需壓縮賽事配套。

### 想讀／想跳判斷

- 我最想讀丙的第一、二段；再讀乙第三段如何把真實誘惑演出來。這三者各自有明確的場面問題、人物失誤和當下回報。
- 我最擔心跳讀甲的卷十一連續賽務，以及三案第三段的前半段規則說明。甲第一段同時安排四人爭標、團體採測、額外個人定標與測材；乙、丙也都新增協作賽或公開切磋。若只是為了讓四人同場而把地方比試擴成小型競賽篇，會直接違反作者給的「卷十一不擴大型比賽、不延兩月」邊界。
- 中期三案都能維持雙人冒險，不是把陸沉或生拉進來。乙、丙的日常（煮食、守夜、切磋、分路）可支持共同生活；但現有情節主要證明兩人尊重彼此界線，尚未充分呈現青璃對封寒的興趣如何從「容許同行」長出變化。甲的「我會再找你」最像關係進步，卻有先開口留人的語義風險；丙避開這句而將重點放在各自分路，較穩但感情推進也最淡。三案都不應把第27篇留人節點只當作禁用某句話：需核的是這次分離是否已讓她主動替封寒保留位置。

## 逐案審查

### 寫手甲

**優點與證據**

- 少年段人物欲望有分流：劫看古禁與港務，封寒追潮路，生取藥樣，青璃研究五行交界；決勝時青璃辨出前一輪水汽落地改變土脊，四人依她的窗口各有行動。這讓青璃不是替陸沉服務，也不是純粹隊伍第四人。
- 青璃的單人勝利和團隊勝利分成兩場，且她在個人賽中承認相界不能當刻度，能區分「看見」與「控制」。這是明確的人物修正。
- 中期兩人都以自身判斷失誤、再修正；封寒錯把山徑當固定模型，青璃在近本源純火前收手。採晶隊不是純惡人，兩人也不替其錯圖造成的損失開脫。
- 聖土段把青璃放在第27篇之後，不讓她出席封寒看魂冊，也不再用封寒說服她；守冊者對名簿、索引與是否被徵用有自己的立場。

**重大問題**

1. **卷十一規模與日程過載。** 四人競爭賽加隔日個人定標，再加採測牌和獨立標石獎，與「禁都地方比試不擴成大型比賽」不相稱；12日內8–10章也要和雨光螺三夜、古禁、聞人錦、易材、銘紋等既有安排競時。此問題不能只把章數改小，需先決定是否把團隊破局變成地方比試中的一場短事件、並移除多餘獎項／副賽。
2. **聖土段的故事引擎偏程序。** 青璃的核心選擇是保留相界，但主要試煉是查冊、索引與保護名字；鬥氣的力量由他人口述，沒有像乙、丙那樣讓青璃親自看到一種她會想要的戰鬥／修行本事。故事標題《未歸之名》與事件更像身世、身份管理篇，尚未兌現作者要求的「面對要不要轉修」。
3. **聖土交通與年表代價高。** 35–37歲另開一趟獨立行程，時間落在密集期及第三次聖土／立錨相關窗口附近。現規則有低路窗口、承載、錨印、擔保與王庭批准等限制；「另立後續行程」不是交通方案。不得假設她能搭封寒高路或自由使用第三訪窗口。

**局部問題**

- 團體終局同時讓青璃挪水勢、隊長救人棄旗、陸沉雷法截旗，勝因多頭；須確定核心是青璃看穿轉向，還是衡浪隊隊長為同伴放棄旗位。對手隊伍首輪／決勝的固定地勢與浮脊轉向關係也要更清楚。
- 隔日個人勝場、傷勢、採測權等所得重疊，且潮蝕石在第二段作為觀測工具前，應先說明其是普通材料如何成為可用對照物，不要升成特殊機緣。
- 第二段「近路私有、錯圖」和採晶隊維持通行權的結局仍需交代責任如何補償被錯圖引去的採晶人；若只要求改圖、隊長仍留村任教，受害代價可能被消解。
- 甲第二段的「我會再找你」不是明確約期，但在封寒已收器離開時仍是青璃先提出下一次聯繫，可能被讀作她首次留人。改成真正中性的行程收束才能守第27篇節點。

**判斷**：不建議整案選定。團隊故事的角色分工和個人勝利值得保留作元素；第三段需重作為具體修行誘惑，而非把文件程序擴成高潮。第二段有長篇骨架，但還要證明測路中段不重複。

### 寫手乙

**優點與證據**

- 少年段的隊伍合作是「送承水石穿越場地」，明確與封寒、陸沉、生各自的卷十一目的相接；青璃有自己的研究目標和個人切磋，生只短暫參與，不更動百宗十人名單。
- 第二段浮峰錯位與空峰雲海是清楚的仙道奇觀，且目標是兩人自己想看的空峰，不是撿古宗門答案。顧迴川先交易航線、封寒失去自己的路標與名額、青璃失去藥材，兩位主角各自付帳，地方人物有不依主角而行的生計。
- 第三段轉修席把修行選擇連到工作、名分、長期居留和低路往返；已轉修者有可見力量，也失去原來境界。這是三案中最能讓讀者理解「為什麼青璃可能會想要鬥氣」的一案。

**重大問題**

1. **第一段新賽制與資格流程容易把地方活動擴大。** 四人必須走三條線才能爭取十年一次的空峰觀潮，還有每季引峰權、季末實測、合作賽和另行個人短賽；這些在短期禁都地方比試上堆得過滿。雖說沒有改百宗資格，事件容量仍可能侵蝕卷十一原有內容。
2. **中期「觀測」的重複風險。** 三條路、逐次量測、記錄、重畫、再爭空峰觀潮，核心有意思，但若每次只是拿到更多風聲／水勢資料，26章會像行程及規則報告。需要每次試路帶來不同且不可撤銷的局勢變化；目前顧迴川售路、青璃失藥、封寒失記錄是差異化的起點，空峰高潮仍偏向他們讓出入口、看景、收圖，沒有充分的修行所得或實際造詣完成感。
3. **第三段的身分揭露缺少合理觸發。** 診氣師僅在入場前看出「兩種運行方向」，但人物卡明確寫血脈資質是否覺醒、何時覺醒、由誰揭露都待設計；而青璃身分需延後揭露。這可設計，但不是已知的診斷能力，需補足為何此人能辨、為何此時發現、她此前如何理解自己。
4. **第三段選擇最明顯被下游鎖死。** 即使巡橋上席十分可欲，約24歲她仍必須保留五行才能在32歲守孩子、35–36歲維持上界行程。現在「兩個可行的完成辦法」其實不是兩個可同等保留的長期道路；若她簽了，後續作者選定事件即失效。避免先替她決定需要先處理年表限制。

**局部問題**

- 少年勝場把生的藥粉、承水石、水獸和陸沉雷身等工具都放在決勝；注意青璃看出的關鍵不要被團隊物件過度分散。
- 第二段「顧迴川把航線交大商會」的交易與「季末實測／引峰權」需明確其權利邊界，否則讀者不知他是否能出售公共路線，也不知兩主角怎樣獲准入空峰。
- 第三段「譯氣可熟悉補給」是新用語／新規則，需核來源，不要讓短暫接觸看起來像部分兼修。
- 青璃與封寒有共同生活與切磋，但大多只證明彼此不越界；感情從「一起探索」到「慢慢加深」還缺一個雙方都主動承擔的情感變化事件。她拒絕封寒問下一趟日期，能守住自主，卻不能單獨承擔感情發展。

**判斷**：不建議整案選定。乙第二段有可長篇化的場域和社會關係，第三段是當前最佳「誘惑具體化」參照；須改掉賽事流程過載，並在作者裁定選擇是否開放前，不可稱第三段已完成真實二選一。

### 寫手丙

**優點與證據**

- 第一段的回音坡把對手能力做成可反制的完整循環；首輪封寒、陸沉、生的嘗試都令對手取得資訊或優勢。青璃不是神奇地看到答案，而是需要比對水痕、火勢、雷聲；決勝後對手仍守住核心器物。她另用普通五行術法而非相界贏個人切磋，避免把相界變成唯一戰力。
- 第二段雨海的規則以眼前可感的雨柱、回聲和側風表達。封寒錯在把真實回音理解成直路，青璃錯在把水風界面當成可挪的整體；兩人的能力邊界不是只在附錄宣告，而是實際改變選擇。舟師蘇問汀自己選擇先保船隊，兩人也放棄全景換取能交付的三段航路。
- 第三段人物沒有把青璃變成族群代表或封寒感情線附屬品；青璃在不能用相界的近純火路上仍親自走完，能呈現她不是只有一項法術的人。對手／傳承不是惡意逼迫，鬥氣道路有可見效能。

**重大問題**

1. **卷十一窗口仍須降規模。** 四人協作演示、鄔行嶽此前擊敗他隊、三輪交手、個人切磋、陸沉取玉簡與四人再集合都擠在數日。把協作賽改名為「演示」不會自動令其不擴大地方比試；得回到既有比試容量和日帳，證明能容納而不擠掉其他事件。
2. **第三段只有一次場外診斷就揭血脈，揭露時點尚無因果。** 診氣師能辨認混血是新規則／新設計；作者明定身份延後揭露，新入宗動機也未定。此處要先核揭露必須由誰、什麼可觀察徵象、青璃此前如何知情，並避免把她寫成因一次檢查便立即得到完整族群答案。
3. **轉修結果預先確定。** 青璃最後拒絕鬥氣，因後續 Canon 需要她保留相界；巡橋試雖讓她親自選路，但「留五行」仍是唯一不毀下游的選項。另有「不簽也完成安全線」的第三種勝法，會降低她拒絕上席的實際代價：她既保留自己道路，又完成對渡口的幫助，還取得回訪路牌，需明確損失是否足以讓選擇痛。

**局部問題**

- 近純火單人勝場有意思，但「火勢耗盡後用普通五行術法擊中對手」可能被讀成對手先讓法術自然熄掉而她撿勝；需交代規則、時間和對手的主動失誤，避免她的勝利只是對方力量耗盡。
- 團隊高潮裡青璃偏界、封寒斬導流石、陸沉雷法、洛生衣收藥粉，各動作都清楚，但封寒斬石是否構成在場地中改變地形／規則、青璃能挪的到底是水火哪一股，需用原有相界規則精確限定。另需保住鄔行嶽為強敵的賽後所得，不能讓「承認青璃」替代競事結果。
- 雨海中青璃挪水救舟且相裂增加；她既有「不肯求助、看不起以傷換命」性格，需說清她為何認為這是可接受的局部用力，而非把增加相裂當常態英雄代價。現有作者指令也不希望以傷換命。
- 封寒第二段用劍、22歲符合第27.55之前仍用劍；但甲、乙、丙均未給封寒該年境界，青璃除13歲多化靈外沒有專屬境界數字。不得用「已飛升」掩蓋任何場景的承載、航行和戰鬥尺度。
- 第二段結尾各自離開能保自主，但感情改變落得較輕；相反甲的「我會再找你」較明確，卻可能侵蝕第27篇首次留人。此節必須以實際主動行為及既定節點對讀，不靠台詞聲稱未搶。

**判斷**：三案中最值得進入下一輪的底稿，但目前只能推薦其前兩段的故事引擎與場面，不能推薦整個三段包。若選用，第一段須按卷十一實際容量重排；第三段須先處理作者期待與下游鎖定的矛盾，而不是先填滿細節。
