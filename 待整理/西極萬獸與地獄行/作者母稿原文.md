# 《劫》｜西極萬獸原與地獄行
## 方案 B：劫、瘋、雲少年三友大長篇

> **候選故事母稿，非 Canon，未修改 GitHub。** 作者新方向：西極是雲行的主場；地獄行改為從西極入口下行，擴充遊歷期。新增場景與人物待核對雲行人物卡。

## 1. GitHub 已有的故事錨點

現行《卷十四 地獄行（暫名）》：五域大比後、書院正式報到前，劫、瘋、雲同行，文奕不下去；陸沉在下方層域取得第三雷「震魂」。戰葬殘響是線索，不是雷本體。原自由期20日，行前4日、下行7日、返程3日、休整6日；下方世界名稱和入口尚未定。原稿要求三人各自犯錯、修正，不得用擊敗守關 Boss 直接拿雷核；不提前確立完整輪迴或八萬年前真相。

《南荒四幕》後續取得第四雷「千相」，不能提前。西極已定地貌包括草原、大漠、雪山、獸族、荒獸血裔、地靈與鳴野宗的人獸共生傳承。**西極不是地獄本身，而是下方層域入口所在。**

## 2. 新故事的主題

**上面是萬獸奔騰的活人世界；下面是萬籟俱寂的殘響天地。** 陸沉追求第三雷，封寒追問未知，雲行回到故鄉，面對舊友與舊事。這次雲行不是陪同者，而是領路者、當地關係的承擔者、擁有真正獨立勝場的人。

- **劫**：能改，不等於有權替殘念改。
- **瘋**：不是每個死亡背後都有隱藏陰謀；求證仍有意義。
- **雲**：不是所有痛苦都該留下，也不是所有名字都該被抹去；他要親自選擇。

## 4. 第一幕：雲行的酒館

三人踏進西極草原渡營，掌櫃一見雲行便擺出三只酒杯。

「和尚，你還知道回來？」

雲行笑道：「路過。」

「上回也說路過，喝了我三壇。」

封寒問：「你們連他喝多少都記？」

掌櫃抽出帳冊：「他每次說只喝一壇，第二壇總要記在我帳上。」

陸沉看向雲行：「原來你在這裡比我有名。」

雲行接過酒杯：「你剛來，還沒欠人錢。」

掌櫃忽然放下一封舊信，笑意淡去：「有人等你回來很久了。」

雲行看著信印，沒有立即拆。劫與瘋第一次發現，他在故土也有難以開口的事。

**這段要慢寫**：渡營夜市、獸族交易、草藥與雪山鹽、各家修行法、酒館裡的普通修士。有人敬雲行，也有人不歡迎他；他不是西極人人仰望的神僧。

## 5. 第二幕：萬獸夜行

萬獸夜行原是季節遷徙，不是所有靈獸都受地獄召喚。當地人關心草場、幼獸、商路與生計；只有少部分獸群異常改道。安排鳴野宗人獸共生修士、真正強大的獸族天驕、草原商隊、雪山來客，各有自身勝負。

### 場景：先問牠

渡道上，一頭成年靈獸不肯走。商隊準備強拖。

陸沉觀察束環：「禁紋在反覆收緊，我能拆。」

封寒望向牠身後：「牠每次退都偏同一側。是不是還有幼獸？」

雲行把酒葫蘆交給陸沉，向靈獸走去。

「你做什麼？」封寒問。

「問牠。」

「牠能回答？」

「未必。」雲行道，「可總不能只問自己的禁制。」

三人查明束環、幼獸與改道的衝突，最後由獸主與靈獸族群自己決定。這場小事是下方層域的伏筆：**死者無法完整回答時，生者又有多大資格替他決定？**

## 6. 第三幕：雪寺與黃沙

安排一位雲行尊敬卻與他意見相左的雪寺故人（姓名、師承待核）。故人守著亡者名錄，認為公開部分名字會再次傷害家屬；雲行認為其中一人仍有家屬在等待。

「你在外面走了這麼久，還以為每個名字都該有人知道？」故人問。

「不是每個。」

「那為什麼還來？」

「因為這一個，還有人在等。」

「你能替等的人承擔知道之後的事嗎？」

雲行沉默。陸沉沒有替他回答；封寒也收回了已到嘴邊的問題。

此幕要有沙海夜航、雪山禪修、獸族古市、地靈居所、當地天驕切磋與失敗。入口線索分散在古籍、遷徙路與親歷者記錄，不能一位老人講完。

## 7. 第四幕：黃泉古門

入口位於西極深處，接向尚未命名的下方層域。須符合潮期、承載、退路標記與守門規則；不是上界／九界萬能捷徑。其他修士也有找人、考證、尋器等獨立目的。

守門老者看見雲行：「你還敢回來？」

陸沉與封寒對望。

雲行放下酒葫蘆：「這次不是一個人。」

「帶兩個人來，就以為門會替你開？」

「沒有。」

「那你求什麼？」

「求一條能回來的路。」

陸沉核禁制承載，封寒校正空間錯位，雲行面對守門者提出的真正條件。三人各有不可取代的作用。

## 8. 第五幕：魂河無岸，三人各自犯錯

**陸沉的錯**：一段殘響反覆走到斷橋前，他以為補橋、帶對方過去便能結束執念。禁制成功，殘響卻把「有人來救」當成新一輪重演的起點。他必須親手拆掉自己的好意。

**封寒的錯**：兩段矛盾記錄使他認定背後有被抹去的陰謀；追到最後，可能只是兩個生者在恐懼中記錯同一夜。這不是叫他放棄求知，而是不准他替死者捏造答案。

**雲行的錯**：他想讓痛苦的聲音止息，卻發現其中還有個可辨認的名字，正是西極有人在等的失蹤者。他不能把安靜當作唯一的慈悲，也不能讓所有痛苦永遠留下。

魂河、鬼城、白骨、冥火、無聲橋有各自規則與仙感；不預設所有死人輪迴，也不提前揭開八萬年前完整真相。

## 9. 第六幕：震魂

第三雷不是擊敗守關 Boss 後掉落的雷核。陸沉要辨清自己的施力、外來殘響、天地自然回震，不能吞食殘念作資源。具體熔雷法須以 GitHub 震魂專檔為準，不自行創造不相容魂道。

三人各撤回一個曾相信的錯誤做法，共同保住返程標記。陸沉得第三雷，卻不自動精通魂道或立即凝出新雷身；魂傷與新雷負荷仍須修行。封寒帶回互相矛盾的實測，雲行帶回有名字的普通遺物；兩人都有自己的所得。

## 10. 第七幕：生者歸途

三人回到西極，不是拿雷便瞬移天域。必須交還遺物、面對故人、養魂傷、修器，完成真正的告別。

掌櫃見他們回來，只問：「都回來了？」

雲行點頭：「都回來了。」

掌櫃放下一壇酒：「這壇不記帳。」

封寒問：「為什麼？」

「因為有些帳，回來就算清了。」

陸沉望著杯中酒，想起下方層域那些再也回不來的人。

雲行舉杯：「這次先喝。」

封寒道：「你不是說還有一條路沒查？」

「有。」雲行說，「但今天不查。」

三人把酒喝完，第二天再帶著各自未解的問題回到書院。

## 11. 日常與小故事池

1. 雲行被酒館掌櫃追酒帳，劫瘋第一次知道他少年時也會闖禍。
2. 三人在草原學獸群禮節，陸沉的推演不如雲行熟悉人情。
3. 封寒與獸族天驕爭論一條看似不可能的獸徑，雙方實測後各修正一次。
4. 西極市集買錯草藥，陸沉以太玄藥閣所學換當地藥師真指點。
5. 夜宿雪山寺，雲行與同門談修行、舊願與尚未走完的路。
6. 靈獸幼崽迷路，處理須尊重族群，不把牠隨手收成主角靈寵。
7. 三人喝酒談釀法，封寒連酒也想追根究柢。
8. 草原天驕有自己的比試、戀情、師承與失敗。
9. 沙海商隊女性修士拒絕主角援手，獨立完成一件難事。
10. 地獄行後三人有一晚不談取雷，只談人間飯菜與想回去見的人。

## 14. 最終故事定位

**這不是《地獄行》換一個入口，而是《劫》少年篇一部完整的三友仙途。**

第一次到西極，陸沉和封寒終於看到雲行的故土、故人、能力與傷口；三人在活人世界裡真正享受冒險，再進入無聲的下方天地，帶著不一樣的答案回來。第三雷震魂是大機緣，但不是這趟旅程唯一值得記住的東西。
