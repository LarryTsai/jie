# 仙，不必閉環

狀態：D108，2026-10-04。作者指定新版 Writer Rule；三句原則採用，本文的天地異象與插入場面是工作候選，不因此自動成為世界史實。

> **因果要嚴密，天地要神秘。**
>
> **人物行為要合理，仙道不必完全可解。**
>
> **力量可以有規則，但規則之外必須永遠存在未知。**

「仙，不必閉環」指天地不必提供最後一個解釋，不是劇情可以不交代結果。世界裡的人可以研究、爭論、誤認、繼續生活；作者不用在檔案另一端藏一個終將公布的標準答案。

## 一、先辨是哪種問題

| 問題 | 必須完成什麼 | 可以保留什麼 |
|---|---|---|
| 黎為何能換樣本 | 他有哪段持樣權、何時換、為何換、如何被驗出、造成什麼後果 | 上家未揭可延後，但不能用天地未知逃掉眼前責任 |
| 劫為何能用一門新法 | 來源、當時會到哪一步、施術條件、反制、代價與消化 | 不必推導整個天地為何容許修行；「不明」不能送他額外權柄 |
| 傷者是否帶回、居民是否同意 | 誰選擇、誰行動、誰受損，眼前目標完成或失敗的結果 | 個人的全部心事不必當場自述，不用旁白替所有人判對錯 |
| 山為何像在睜眼、井中為何有異地的雪 | 寫清誰看見什麼、當時有何可觀測影響；離開或留下是誰的選擇 | 起源、目的、是否有主體、真正週期、終極機制均可不答 |
| 仙王對一種現象沒有共識 | 各人的觀察與證據確實不同，不能讓強者一句話裁決 | 三種解釋可以都留，敘述者不替任何一派蓋章 |

**有意未知**與**待設計**分開。待設計是目前尚未選好、將影響事件可否成立的創作問題；有意未知是這個存在不需要終極答案，列入本檔維持其敘事邊界，不登記成必修缺口。已向讀者承諾追查的失蹤、凶手、關鍵物證與古戰責任，不得事後搬進有意未知來免交代。

作者也不必裁定它客觀上「絕對沒有答案」。能說的是作品不作終極裁定；不把「凡人不懂」改成「仙王必定懂」，也不把神秘變成另一套可測的無解法則。

## 二、寫手怎麼留下仙

- 每個**大篇**至少保留一個不用解釋的存在。大篇指一條主要地域／人生故事弧，不是每卷、每章的配額；同一片天地可以反覆遇見，無須逐卷新造奇觀。
- 先寫人在其中的感受、日常與行動。看見後可以繼續喝酒、買藥、修劍、等舟；不必有人問來歷，也不必以「這是某某機制」作結。
- 大部分天地之異不接主線、不送戰利品、不生成任務。陸沉可以想看、看得很高興、試了卻說不出，並不每次都受傷或悟道。
- 不寫「境界再高一點就能解」作固定出口；換了眼光可能看見另一面，也可能仍不知道。仙王知道上次有人見過，不等於知道它為何存在。
- 不把每種異象收成同一場古戰、同一個古人、同一組織或某雷的殘留。與既定古戰相關者仍按物證查；新異象不自動作證。
- 傳說、觀測、學派解釋和敘述者事實分開。居民說九百年一次，可以只是留下的紀錄；不補精密周期、觸發器與下一次時間表。
- 神秘若參與危險，交代本次可見的變化、人物試過的手段及後果。撤離不能等一個毫無前史的異象忽然救場，失敗不能只說「天地不許」。一次實測能支持本次選擇，不必升格普遍定律。
- 不自動給異象名字、境界、器品、可採材料或收藏位置。遠處一座山可以只是山，不必先問如何把它搬走。

## 三、現行大篇的有意未知位置

以下是一份**可選場面名單**，不是把全部景物批量塞進正文。每大篇選留至少一項，地獄可留兩三項，南荒多留散在地方生活的不同存在；已選者仍不指定終極機制。場面不改現有能力、航程、取雷與戰鬥結果。

| 大篇／插入位置 | 不作解釋的東西（工作候選） | 人當下怎麼經歷它 | 不讓它承擔什麼 |

| 南荒・第二幕古今共處 | 古屋空窗裡有不合屋內光線的日落，搬進去的人仍按外面的天色作息 | 住戶會把藥盆從窗前挪開，沒有因此棄屋；劫第一次看見，屋主已懶得看 | 不藏控制接點，不給江完整入口觀測，不是唐拆路引起 |
| 南荒・第三／四幕生活間歇 | 旱季一段河水像生了根，水仍向下流，岸邊找不到根附著的地方 | 古今住民各有見過和沒見過的人，仍共用岸邊洗器；有人想養一盆，離水卻只剩濕手，不為此停掉撤離 | 不驗血籍、身份或真假，不選千相繼承者，不替皇血派決定誰有權留下 |
| 九界後續遊歷 | 一界有石落水而水面映星不映石；另一界有背陽仍朝日開的花，各自不是同種現象 | 雷身取材之外遇見地方生活。可見的怪事漸多，有人研究一生也沒有取走什麼 | 不合成八路密碼，不替凌汛補味，不把有意未知通通判為封界餘禁 |
| 下無極／上無極長住 | 有一片夜光不在同一批星圖上；不同長住者各指得出自己觀過的位置 | 長者可持數代觀星簿，另一位拿出同夜沒有夜光的影錄；生活仍有課、路費與修煉 | 不作免費定位、時差計算或突破材料，不讓接縫交通因此任意失效 |
| 大羅及仙王所見之高層天地 | 一種無名青光：有人稱道的顯影，有人稱死去世界的夢，有人說從未有這個東西 | 第一人留下共見記錄，第二人持遠古睡者的相似夢錄，第三人有同地同期無光的親測；各證據有來源與局限 | 不裁定某派正解，不揭為太宸新權柄；調查他的罪仍靠既定真相層物證 |
| 聖土長住 | 山中雪面偶映一片無聲的海，腳踩過仍只是雪，當地人對那海有不同叫法 | 園師照舊趕季節，外來者第一次停步；有居民願講自己的稱呼，無人能替另一人證明來歷 | 不替接穗傳法，不改聖土補給差，不變兩界互通的新路 |

南荒的多不是一口氣列十種奇觀。讓不同人對不同存在熟悉、驚奇、無所謂，放在採藥、候潮、睡前與行路中。九界後續每個真正展開的地方篇仍選自身的未知，不用上表兩例冒充九界都寫完。

## 四、陸沉與封寒遇到拆不了的東西

陸沉仍分析、理解、拆解、重構，這些能力要有真正的成功。另一方面，井水可以量，字影可以抄不成，夜光可以記錄；做完這些，也未必回答它是什麼。讓他能停在一份誠實的紀錄，或者改日再來，不把未知一概演成主角技不如人。

少年可以說「我只是還沒看懂」；往後有一次承認「我不知道」，不等於不再修行、不再改自己的法。**何時、面對何物、是否長年研究，均不在此鎖人生年表。**作者的仙王／數千年比喻是長期人物可能，不把目前八十八歲主幹擅自拉成幾千年，也不承諾最後一定破解。

封寒可以想知道，也可以在另一次相遇時笑「不知道不是挺好的嗎？」這是未來場面候選，必須有他當時自己的經歷，不替他提前完成大道，也不因一句笑就撤掉《唯一》的修行。〈唯一〉只在資訊與條件足夠時成立，不需要解釋全部天地才能對一場具體戰鬥求證。

雲可以想看、想拿或不想停步，不必永遠負責提醒兩人。文奕能解清一段禁的用途，仍不知廊上字影；生能驗藥、救自己的病人，也可以留一片不當藥的花。五個人不能每見異象便輪流發表大道總結。

## 五、審稿多問這幾句

1. 本篇的承諾、行動與後果是否完成？哪個問題是人物必須負責的，不能留給天地背鍋？
2. 這個大篇留下了什麼不用解釋的存在？讀者是否真的見過，還是只在作者檔案掛了一行？
3. 是否因為寫了奇觀，下一段立刻有人補來源、用途、週期與破解法？能否停在眼前經驗？
4. 是否把「此人沒有見到」寫成「它不存在」，或把一位強者的意見寫成敘述者真相？
5. 是否把每個未知又排進未來揭露、TODO或必得獎池？有意未知不需補答案，也不必給後續線索。
6. 異象若影響勝負，人物是否真的觀察、選擇、付代價並完成行動？拿掉臨時救場，劇情仍須成立。
7. 人物能否只是喜歡、驚奇、厭煩或略過？沒有研究結果的觀看也可以值得留下，不強行接修行回報。

這些問題是本案 Writer Rule，與[仙人視角守則](仙人視角守則.md)及[修士邏輯基準](../04_修行與特殊事物/修士邏輯基準.md)並用。觀測邊界供作者保持一致，正文不把本表寫成流程，也不用這條規則免除人物因果。

## D109：禁止解釋清單與正文呈現

[禁止解釋清單](禁止解釋清單_WriterRule.md) 接本規則，明記井雪／古山候選的終極答案連作者也不定，上界青光不暗選正確學說；陸沉可得局部規律而不破解全部。其餘候選保持有意未知，不另增加奇觀或安排逐項揭露。D107的資源與驗證是後台，正文讓人經歷所學、所失與後悔，不把所有理由講完。
