# 第十雷命名三案

狀態：寫手提案，2026-10-09；回應[待決總清單](../../../決策/02_待決/待決總清單.md) 1-06（作者選乙：寫手提三名，由作者選）。**名字由作者選**，本檔不改任何 Canon；選定後由主 Agent 同步雷道 README、[第十雷與規則補丁](../../../設定/04_修行/02_雷道/第十雷與規則補丁.md)、武學譜第十一節與第 28 篇。

## 〇、不動的邊界（三案共同遵守）

- **能力照已定，不改**：單獨時不作戰，只記往來、讓錨成立（D066）；十雷一體裡增幅（D087）；不入天譴、不出自〈天地為爐〉、不在〈周而復始〉的環裡；不收集、不吞、不上榜、不交易、不能被搶。
- **形成照已定**：第 22 篇成胎，第 23 篇剪不走的一絲，第 27 篇隨窗口起伏，第 28 篇錨成立那一刻生成，第一道往來是太宸的「是我」。門由文奕、翁蒂娜與簽約者打開，雷只是結果。
- **命圖照已定**：主星位長在劫核旁，通往往來（候選，D072）；職＝往來；「變」第十步＝不改（D088）。
- **舊名「無始」不沿用**；避開鬥破「異火」的影子（C10、Q22）。

### 命名格式的共同建議：不帶色字

九雷正式名多是「二字意象＋色＋雷」（星羅銀雷、兩儀玄雷、千相紫雷、歸墟黑雷、流光金雷），或「二字意象＋天／神／劫＋雷」（殞星天雷、無間神雷、九霄劫雷），震魂為「太古震魂雷」。色字來自[天下異雷榜與色相](../../../設定/04_修行/02_雷道/天下異雷榜與色相.md)：上榜、被辨識、被記載，才有公認的色。

第十雷**不上榜**、是長出來的不是取來的，所以三案都建議正式名只用「二字＋雷」，不配色字、不配天／神／劫。九個四五字的名字之後忽然一個三字名，讀者一眼就知道它不在那張榜上。這是格式上的「不同」，不靠解說。若作者偏好與九雷同長，各案附一個四字備用全稱。

## 甲案：交泰雷（取「往來」）

### 命名由來與字義

出自《易》泰卦。泰卦是地在上、天在下，天氣下降、地氣上升，兩氣相交，所以通；反面是否卦，天地不交，閉塞。卦辭「小往大來」，字面就有「往來」二字。

八萬年封界就是一個「否」：兩界不交。錨成立、兩界之氣第一次有規律地往來，就是「泰」。名字直接對應第十雷的職。

四字備用：交泰玄雷（玄＝天色，接《易》；但與兩儀玄雷同色字，見風險）。

### 與九雷命名風格

協調度高。兩儀已取自《易》（太極生兩儀），交泰也來自《易》，首尾呼應：第二雷「選路」用兩儀，第十雷用交泰，九雷之間有一條暗線從「分」走到「交」。字面莊重，與星羅、九霄、歸墟同一個量級。

### 第 28 篇第一次被叫出（場景概要，不是正文）

錨成立後，九界舊院一位管新簿的老書吏看著兩界之氣一進一出、像潮又不是潮，隨口念出卦辭「小往大來」；陸沉看著劫核旁剛亮起的那一點，說這道雷就叫交泰。

### 讀者在終局會感到什麼

開闊、通暢、終於鬆一口氣。八萬年不通，現在通了。熟《易》的讀者會想起否極泰來，得到「苦盡」的滿足。

### 風險

- **最大風險：「交」容易讀成「合」**。泰卦彖辭「上下交而其志同」偏向和合，與本書「往來，不是合一」的核心論點有拉扯。正文要靠場景守住：兩氣一進一出，各自回去。
- **撞名**：「交泰丸」是常見古方（黃連配肉桂，交通心腎）。本書丹道比藥重要（D098），丹修角色或讀者可能想到丹方；「交泰殿」是故宮殿名，影響小。
- **太直白**：卦名本身就是答案，懂的人一看就知道它代表通；少了一層讓讀者自己體會的餘地。
- **否極泰來太順**：容易讓終局讀起來像「好了，太平了」，沖淡太宸「是我」的重量與錨之後仍要守的代價。
- **洩底**：低。名字在第 28 篇才出現，不提前揭任何真相層。

## 乙案：問津雷（取「錨／渡」）

### 命名由來與字義

津＝渡口；問津＝打聽渡口在哪、問怎麼過河。出自陶淵明〈桃花源記〉末句：漁人走過一次之後，再也沒人找得到那條路，「後遂無問津者」。另一個出處是《論語》子路問津：孔子讓子路去問渡口，被隱者譏為「是知津矣」。

本書八萬年正是「後遂無問津者」：兩界之間的路被封，漸漸連問都沒人問。第 28 篇是渡口第一次重新有人問、也第一次有人答。第十雷不開門、不渡人（門由文奕、翁蒂娜與簽約者打開），只是渡口成立時長出來的東西，所以名字取的是**「有人問了」這件事**，不是「它渡人」。

錨的那一半：渡口必須先有錨住的岸，才有人能來問。問津的「津」本身就是「固定的過河處」，不是隨水漂的船。兩岸各自是岸，船往來，岸不合併，正好是「往來，不是合一」。

四字備用：問津長雷（「長」取長在劫核旁，不是色字）。不建議配色。

### 與九雷命名風格

中高。九雷多取天象、空間（星羅、九霄、殞星、歸墟、無間），問津是人間事、典故名，量級較低、較安靜。這是刻意的落差：九雷是取來的天地之物，第十雷是人與人之間長出來的東西。與千相、震魂這類「作用名」也能並列。

### 第 28 篇第一次被叫出（場景概要，不是正文）

簽約時，聖土那頭持渡口特許的邊地人隔著錨問了八萬年來第一句「誰」，第一道經錨傳過來的回答是太宸的「是我」；陸沉感覺劫核旁那一點把這一問一答記了下來，事後被寇平問起，他說它叫問津。

### 讀者在終局會感到什麼

先是一陣靜，然後是酸。整本書的問題（誰做的、路為什麼斷）以「有人問、有人答」收住；答的人是太宸，答的是「是我」。讀者會意識到第十雷記下的第一筆不是勝利，是一句認罪。名字安靜，重量落在那一問一答上。

### 風險

- **與九霄「先問」相近**：九霄的「變」是「先問」，第十雷是「不改」。問津有「問」字，讀者可能以為第十雷也在主動問。正文要寫清楚「問的是邊地人、雷只記」，或把九霄的先問當成鋪墊，讓問津成為那條線的收尾，二選一，需要作者或第 28 篇寫手定調。
- **典故意涵**：桃花源有「烏托邦、避世」的聯想；本書渡口是政治、簽約與代價，要防讀成「找到仙境」。
- **太文**：不熟典故的讀者只看到「問路」，第一次讀可能覺得平淡；需要場景把「八萬年沒人問」先寫出來。
- **撞名**：本庫未見「問津」（已檢索）。外部有書名、店名常用「問津」，不算仙俠熱門招名。
- **洩底**：低。名字只說有人問，不說誰答。

## 丙案：鴻爪雷（取「記」）

### 命名由來與字義

出自蘇軾〈和子由澠池懷舊〉，成語「雪泥鴻爪」：飛鴻落在雪泥上，偶然留下爪印，鴻飛走了，印還在。指往來的人事留下的痕跡。

鴻雁是候鳥，依季節在兩地之間來回，正對第 27 篇「胎隨窗口起伏」與界潮的季節性；鴻雁也是傳書的鳥（鴻雁傳書），兩地書信往來。第十雷的工作就是**記下往來**：不是那道往來本身，是往來留下的痕。

另一層：本書稱兩界之隔為「鴻溝」（歷史時間線第 5 項）。「鴻溝」的鴻原是地名不是鳥，但讀者的耳朵會聽到：隔著鴻溝，第一次有鴻飛過，留下了爪。

四字備用：雪鴻素雷（素＝無色，暗示不上榜；但「雪」會被當色）。不建議配色。

### 與九雷命名風格

中等。名字最小、最輕，是一個痕跡，不是天象。與星羅、九霄放在一起量級落差最大，可能被讀成「怎麼最後一道雷這麼小」。好處是與「劫核＝陸沉本人」「第十步不改」最貼：它不改天地，只留下一個印。

### 第 28 篇第一次被叫出（場景概要，不是正文）

「是我」經錨傳過之後，陸沉內視命圖，劫核旁新亮的不是一顆星，而是一個淺淺的印子，像什麼東西走過留下的；他想起少年時在太玄閣抄過的一句詩，把它叫作鴻爪。

### 讀者在終局會感到什麼

惆悵與溫柔。人會走，往來會散，只有痕在。最適合尾聲的餘韻，讓全書在一個很小的畫面上結束，而不是一聲巨響。

### 風險

- **意涵相反**：原詩下句是「鴻飛那復計東西」，強調人去無定、萬事偶然；第十雷的核心是錨、是有規律的往來，兩者有拉扯。熟詩的讀者可能覺得「偶然留痕」不對味。
- **「爪」字的戰鬥感**：仙俠讀者看到「雷爪」會想到抓擊類招式，與「單獨時不作戰」相反。
- **撞名**：本庫北天天驕裴雁回有〈雁歸線〉，已避開「雁」字改用「鴻」；歸檔舊設定有「驚鴻雷身」，已撤，不影響現行，但老讀者或審查員可能聯想。
- **量級太小**：在十雷一體增幅的場面裡，叫出「鴻爪」氣勢不足。
- **洩底**：低。

## 寫手推薦：乙・問津雷（由作者選）

理由：

1. **最守本書核心論點**。渡口兩岸各是岸，船來去，岸不合併，名字本身就在說「往來，不是合一」；甲案的「交」最容易滑向合一。
2. **把第一道往來「是我」變成名字的一部分**。全書的問題以「有人問、有人答」收住，答的是太宸的認罪。第十雷記下的第一筆是一句認罪而不是勝利，這是三案裡唯一由名字直接承載的。
3. **守住「雷只是結果」**。問的是邊地人、開門的是文奕、翁蒂娜與簽約者；第十雷不出手，只記下「有人問了」。名字取的是別人的行動，正合「長出來的、不是取來的」。
4. **量級落差有意義**。九雷都是天地之物，第十雷用一個人間詞，配合「不上榜、不帶色字」，讀者不需要解說就知道它不一樣。

需要作者或第 28 篇寫手接著定的一點：九霄「先問」與問津的「問」要寫成同一條線的首尾，還是刻意分開（雷只記，不問）。若作者覺得兩個「問」太近，次推薦甲案交泰，但正文必須補一處讓兩氣各自回去的畫面，守住不合一。

以上三名皆由作者選；也可三案全退，寫手再提。
