# 家底卡：雷望衛

**時點**：第二次聖土（第 19–20 篇），落潮後約十一年；第 27、28 篇另標。

**一句話**：九千個有鬥氣的人守一道八萬年沒人回來的門，不收雷、不排名，只記；記了八萬年「潮起」，從沒問過為什麼。

---

**家底形態**：手藝＋人（記錄）〔家底庫〕。手藝是三門軍中的活：《十三樓》把十三座望樓連成一張警訊網、《截線》在雷緣截出退路、《扣鎖》給縫鎖上芯〔既有〕。人是九千衛士與他們手上的帳：潮簿、探查記、點名冊、異物記〔既有〕。雷望衛沒有契火、沒有契獸〔既有：燧冊與當代榜單皆無雷望衛之火；家底庫「不收雷、不排名」〕，唯一稱得上寶物的是潮骨庫，而那是一把鎖，不是契〔既有〕。本卡補一句〔提案〕：雷望衛真正的家底是「寫下來」這個習慣；八萬年沒有人讀，到第 27、28 篇才有人拿來對帳。

## 一、定位

## 四、傳承

- **制式功法**：《磐石經》，**地階中級**，雷望衛制式〔既有〕。西格妮、托瓦爾所修〔既有〕。做法**留白**。本卡推定〔提案〕：「制式」的用處不在高，在齊：九千人修同一部經，鬥氣同律，警訊才傳得過去（見《十三樓》）。
- **鍛體**：《承石功》，**地階中級**，硬接落雷餘波的衛士多練這一門〔既有，03〕。坦伯軍團出身的軍官帶著《負山經》的鍛體底子進來〔既有，03〕；那是坦伯的功，不是衛傳。
- **軍陣**：
  - 《十三樓》：西格妮。把十三座望樓的警訊連成一網〔既有〕。品階**留白**。見下方檢查。
  - 《連城》：鄧莫爾家軍陣，貝內特帶進衛裡〔既有〕。
- **鬥技**：
  - 《截線》：托瓦爾，**地階低級**。以軍陣在雷緣截出一條落雷不及的退路，一次只撐一炷香〔既有〕。
  - 《望樓》：霍林。以軍陣把一隊衛士的鬥氣連成一面盾〔既有〕。品階**留白**。
- **陣技**：《扣鎖》：翁蒂娜。以鬥氣對準鎖芯的陣紋，給縫鎖上芯、退芯；全聖土會的不過數人〔既有〕。品階**留白**。
- **秘法**〔提案〕：〈長截〉，見下方檢查。
- **傳承載體**：雷望衛不藏經，藏帳。以下各本都列為載體〔提案〕：
  - **潮簿**：潮門逐窗記錄，每個窗口開與不開、開幾日、雷勢幾分。全聖土最長、最無人讀的一套記錄〔既有〕。
    - 邊頁零星有八萬年不到十筆「斯特蘭」（strand，一道線）：衛士只記見到縫雷亮線上有蹄、背脊或角在走，不問是什麼，從未升格為異物記〔提案，2026-10-08 作者定名，見[界潮奇觀](../界潮奇觀_縫雷與走潮者.md)〕。
  - **潮曆底稿**：翁蒂娜從潮簿反推的窗口曆法，封在鎖庫〔既有〕。第 27 篇開封〔既有〕。
  - **探查記**：潮起後的例行探查，照例歸檔，歸檔之後沒人再翻〔既有〕。維達十一年前那份寫「雷裡出來的東西」，另一欄記「一道黑紫的影子」〔既有，D069 推薦〕。
  - **異物記**：托瓦爾把陸沉第一次從雷緣帶出採晶人的報告扣三天，重寫成雷望衛第一份「異物記」〔既有〕。
  - **點名冊**：採晶季閉場點名，每年總有幾十個名字不應〔既有〕。霍林在冊上劃掉過一個「亡」字〔既有〕。
  - **傷亡冊**：溫斯洛每次雷潮後寫的那份，比任何一場仗都能要到錢〔既有〕。
  - **偵騎名冊**：古戰後初期上鎖過縫的偵騎，大多沒有回來〔既有〕。翁蒂娜給封寒看的就是這份〔既有〕。
  - **正式文書**：雷望衛對陸沉的第一份正式文書，稱謂欄寫著「劫」〔既有〕。
  - **第三份探查記**：第 27 篇陸沉以雷刻刻在一枚雷晶上，交雷望衛歸檔（作者定的用語：雷刻）〔既有〕。不當證據，與維達、翁蒂娜兩份成一條線〔既有〕。
  - 本卡記一句〔提案〕：這九本帳之中，只有第三份不是雷望衛自己寫的；它是雷望衛八萬年來第一次替外人存檔。

**〈十三樓〉八條**（招牌；名與總衛長所用為既有，機制為提案）

把十三座望樓的警訊連成一網〔既有〕。本卡補的是網怎麼連、靠什麼連〔提案〕。

| 條 | 內容 |
|---|---|
| 源 | 軍陣。〔提案〕每座望樓頂有一座陣基，值守衛士把鬥氣送進陣基，樓長定律，陣基把一記鬥氣脈動推到下一樓，一樓接一樓傳回 Cairnhold。燃料是值守衛士的鬥氣。能接得上，是因為九千人修同一部《磐石經》（地階中級），鬥氣同律；律不同的鬥氣進了陣基只是一團噪聲〔提案〕 |
| 門 | 〔提案〕鬥師起鬥氣外顯，送得進一口氣，可值守。鬥靈起鬥氣凝物，能把一記警訊凝成固定的形，幾圈就是雷勢幾分，下一樓讀得出來。鬥王是樓長的門檻〔既有：一樓一鬥王〕：定一樓的律，判報不報。鬥王化翼在雷潮裡沒有用，望樓是站著守的。鬥宗起以空間之力隔空接線：雷潮吞掉一座前哨、網斷一格時，衛督能把斷口兩頭接上。鬥尊觸及規則：總衛長在 Cairnhold 一次讀得完整張網，也能把一道令沿網送回去。雷望衛沒有鬥聖，鬥聖一層**留白** |
| 象 | 〔提案〕樓頂陣基亮起一圈灰白的鬥氣光，幾圈就是雷勢幾分；一樓亮完下一樓亮，沿雷緣一路亮過去，像有人在雷下一個接一個報數。樓長出戰先看天、報雷勢幾分〔家底庫〕，就是把這個習慣帶到了陣外 |
| 契／器 | 不是本命器，也不是契。網是眾人的鬥氣與十三座樓，樓倒網斷，人走網散〔提案〕。陣基是外物，砌在樓裡，屬衛不屬人。雷望衛不收雷〔既有〕，網裡不用雷晶當燃料〔提案〕 |
| 傳 | 能傳：制式功法人人修，值守人人輪〔提案〕。總衛長那一層跟著職位走，任期兩百年一換〔既有：任期〕。帶不走：網綁在十三座樓上，離了樓只剩一門會報數的軍中手藝〔提案〕 |
| 限 | 綁地：只在封合縫外緣那一圈樓上〔提案〕。只傳訊，不傳力：網讓 Cairnhold 知道雷要來，擋不了雷〔提案〕（例外是秘法〈長截〉）。雷勢越大，雷息越擾脈動，最需要報的時候最容易報錯〔提案〕。潮門那一樓照規矩只記「潮起」、不問原因〔既有〕，網上傳得到「潮起」，傳不到別的 |
| 價 | 值守的鬥氣天天往陣基裡送，修行跟著慢〔提案〕。重的是另一筆〔既有〕：雷緣是薄地，鬥宗在薄地住久了修為會鬆（薇蘿恩條）；托瓦爾鬥宗六星在薄地守了三百年，修為一年比一年鬆。守網的人拿自己的修為付帳 |
| 萬年問 | 一張這麼大的網，為什麼八萬年沒人搶、沒人改？因為它只對一件事有用：告訴你雷要來〔提案〕。雷望衛不收雷、不排名〔既有〕，網底下沒有寶，強者不爭；中心五國寧可出錢讓它守在邊上，也不想要一支邊地的軍隊進中心〔提案〕。它防的「階上人」八萬年沒有回來〔既有〕，所以真正撐著它的是雷潮：雷潮本身在替雷望衛證明它不能裁〔既有〕。取九霄之後劫雲平息，網的理由少一半〔既有〕 |

**〈長截〉八條**〔作者定〕

《截線》截的是一條退路；〈長截〉把一段網反過來用，十三樓的鬥氣不往 Cairnhold 傳，往外推，相鄰幾座樓的截線接成一條，截出一整段雷緣的退路，夠撤一座採晶營或一處前哨。

| 條 | 內容 |
|---|---|
| 源 | 《截線》（地階低級）〔既有〕的延伸，載體是《十三樓》的網〔提案〕。燃料是那一段望樓所有值守衛士的鬥氣，由持陣者一人定律、一人承力 |
| 門 | 持陣者鬥宗起，以空間之力能接兩樓之間的一段；鬥尊觸及規則，才承得住三樓以上的一長段〔提案〕。實際上只有總衛長與副總衛長能開長段，首席衛督能開兩樓之間〔提案〕 |
| 象 | 那一段的望樓頂上，灰白的光一圈圈熄下去；光不在樓頂，沉到地面，順著雷緣拉成一條長線。落雷砸到線外，像砸在一道看不見的坡上，滑開〔提案〕 |
| 契／器 | 無契。承載的是陣與人，持陣者與值守衛士之間只有陣的律連著；誰的鬥氣先斷，那一格先塌〔提案〕 |
| 傳 | 堡傳，只在總衛長與首席衛督之間口傳〔提案〕。不寫進制式 |
| 限 | 同《截線》，只撐一炷香，延不了〔既有：一炷香；提案：不可延〕。只在外緣用得出，沉域無樓可借〔提案〕。開長截的那一段，網是瞎的：陣基的鬥氣全推出去了，相鄰各樓收不到也報不出，雷潮正好在最該報的時候失聲〔提案〕 |
| 價 | **燃壽**：持陣者以一人承一段雷，等於鬥尊全力一戰，以年還帳〔既有：補給率表與壽元表耗損條〕。西格妮任期兩百年，每開一次都在花剩下的年〔提案〕。另一筆在衛士身上：值守的鬥者、鬥師被抽乾，氣旋受損，有人從此跌星〔提案〕；這筆帳會進溫斯洛的傷亡冊，也就變成向五國要錢的數字 |
| 萬年問 | 用得越少越好的一法。它救得了一處採晶營，代價是整段網失聲、持陣者折壽；雷潮年年有，總衛長只有一個〔提案〕。八萬年開過幾次**留白**。第二次聖土陸沉開始疏導雷潮之後，這一頁在衛裡第一次有人說「可以不用了」〔提案〕 |

**〈扣鎖〉附記**（手藝；不另過八條）：源是鬥氣對準鎖芯的陣紋〔既有〕；縫鎖的鎖芯是潮骨，鑰留在潮門、不在被鎖者身上，界潮只認外鑰之封〔既有〕。它是一把鎖，不是契：被鎖的人與鎖之間沒有命，鎖期一過就逐重剝落〔既有〕。價在鎖芯：每上一次鎖就薄一層，庫裡的小片一年比一年少〔既有，29 號檔〕。

## 五、法寶家底

聖土宗門沒有法寶六品，兵器是外物〔既有：聖土不配六品〕。雷望衛的家底是一座庫、十三座樓、一櫃帳。

- **潮骨庫**：潮門鎖庫，藏縫鎖鎖芯與潮骨〔既有〕。潮骨是潮門一帶古界路聖土端殘骸的碎片，界潮認得它是「路的一部分」〔既有〕。
  - 容量：鎖鬥王至半聖用小片；鎖鬥聖要整塊，庫裡八萬年只剩幾塊〔既有〕。
  - 禁採：採潮骨會蝕掉潮門本身〔既有〕。所以這座庫只減不增。

## 十、歷代經驗

- **只記「潮起」，不問原因**〔既有〕。低路不歸國家，所以不扣人〔既有〕。這條規矩護住了雷望衛不被講成違約，也讓潮門替縫市遮了八萬年〔既有〕。
- **偵騎之後封鎖**：古戰後偵騎大多沒回來，縫鎖從此廢置〔既有〕。
- **禁採潮骨**〔既有〕。
- **冊籍人優先**：採晶季照配額發牌〔既有〕。
- **年年點名**：閉場點名，總有幾十個名字不應〔既有〕。

## 十一、弱點

- **錢在別人手裡**：五國攤派，守縫捐斷了三萬年〔既有〕。
- **理由在雷手裡**：取九霄之後劫雲平息，存在的理由少一半〔既有〕。改制「開渡衛」是候選〔既有〕。
- **頂端薄**：兩位鬥尊〔既有〕；無鬥聖、無半聖。
- **守的人在鬆**：薄地磨修為〔既有〕。
- **潮骨只減不增**：禁採，庫裡的小片一年比一年少〔既有〕。
- **縫約第三條**：潮曆與縫鎖都可以被講成經營窗口〔既有〕。守縫派要翁蒂娜燒掉潮曆〔既有〕。
- **鎖庫的內漏**：縫鎖官被法拉蒙騙去開鎖，就在衛督巡別段的那幾夜〔既有〕。
- **帳沒人讀**：探查記歸檔之後沒人再翻〔既有〕。記了八萬年，第一次對帳要等一個外人。
- **守縫與改制兩派**：護道一議衛內分裂又彌合，都走過托瓦爾這一關〔既有〕。

## 作者裁定（2026-10-02，全數照推薦）

1. **〈長截〉採不採**。推薦採，標〔提案〕。它給雷望衛一個有真代價的秘法（持陣者燃壽、衛士跌星、整段網失聲），又不給它任何寶物；代價最後進傷亡冊、變成向五國要的錢，正好扣住「雷潮證明它不能裁」。**不推薦**把第二次聖土那位殉職樓長寫成開了長截而死：「下次早一天」現行已自足。
2. **《十三樓》的機制**。推薦照本卡：陣基加制式同律，只傳訊、不傳力；這樣《磐石經》「制式」兩字才有用處，也不讓雷望衛的網變成攻城陣。
3. ~~潮門的鑰、鎖芯與潮骨庫誰管~~：已處理，照本題推薦分層寫入境界對照與跨界「縫鎖」一節：衛督維達握鑰，縫鎖官艾爾溫日常經手，鎖庫守翁蒂娜管備用鎖芯與潮骨（2026-10-02）。
