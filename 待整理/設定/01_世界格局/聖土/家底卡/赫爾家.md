**一句話**：一鍋熬了一百年的藥〔家底庫〕。赫爾家守的是三樣慢東西：地裡的年份、龕裡的五個先祖、爐底一朵百年不必添薪的火；三樣裡只有火會在一個人死的那天走掉〔提案〕。

---

**家底形態**：地（藥田）＋魂龕＋契火〔家底庫〕。地是 Greave 格里夫城的大陸最大藥田群與三條靈脈份額〔既有〕；魂龕能開口的先祖五位〔既有〕；契火是長收，燧冊第十一，契在老祖科爾文身上〔既有〕，人死火回野〔既有：燧冊體例〕。本卡補一句〔提案〕：赫爾家賣的是**年份**。年份長在地裡、熬在火上、記在龕前；地與龕是家族的，火是一個人的。這就是「長收的下一任契主」為什麼是全家的兩難〔既有〕。

## 四、傳承

- **根本功法**：《年輪訣》，**地階高級**〔既有〕。科爾文、茱莉安娜所修〔既有〕；修為隨藥田歲收慢慢累積〔既有〕。本卡推定〔提案〕它是家傳主修：功法把修士的吐納節律綁在藥田一年一收上，收成好的年份修為進得多，荒年進得少，所以赫爾家的修士多半晚成。家主、喬里只記「藥修」〔既有〕，是否同修《年輪訣》**留白**。
- **鬥技**：《剪枝》，羅德里克，以鬥氣斷敵經脈一段〔既有〕；階**留白**。
- **丹術**（丹術不分天地玄黃；現行未給階，照舊不給）：《接溫》，茱莉安娜，把長收的餘溫分進子爐〔既有〕。喬里「借家族長收火溫煉丹」〔既有〕，本卡讀作他煉丹用的是《接溫》分出來的子爐〔提案〕。
- **秘法**〔提案〕：〈搶收〉，見下方檢查。
- **傳承載體**：
  - **魂龕**：能開口的先祖五位〔既有〕。規矩照聖土通例：只答「問」，不傳功、不教人、不出手；問龕點魂香，一次最多三問；殘魂越問越淡，所以大家族一年只在春初大問龕日大問一次〔既有，當代生活〕。龕裡沒有第二部功法，只有五個記得年份的先祖〔提案讀法〕。養魂由誰經手（龕匠會、洛姆家）**留白**。
  - **地契與丈量證**：三條靈脈份額的地契與泰薩利家的丈量證，在肯沃德手裡〔既有〕。本卡把它列為載體〔提案〕：每一塊田在哪條脈上、份額佔幾分，紙上寫的比人記得久。
  - **老祖的記性**：科爾文記得每塊藥田的地契年份〔既有〕。本卡讀作〔提案〕：這是赫爾家第三份帳，比地契多一層「這塊地哪年荒過」。老祖若入龕，這份帳就從「活人隨時答」變成「一年三問」。
  - **長收的爐**：一爐藥可熬一世紀〔既有〕。爐裡熬著的東西本身就是傳下去的東西：上一代點的火，下一代開的爐〔提案〕。爐數**留白**。
  - **仙土藥種殘根**：古戰前的殘根，長槌大拍期間請陸沉鑑定〔既有〕；若能養活，由茱莉安娜來種〔既有〕。活不活得了**留白**。

**〈緩熬〉八條**（招牌；地、火、手三層）

長收的火性是「緩熬：可維持一個溫度數百年不動，一爐藥可熬一世紀」〔既有，榜單〕。赫爾家的招牌是把這個火性變成生意。三層分開寫：**地**（藥田年份，誰握份額誰有）、**火**（緩熬本身，只有契主給得出）、**手**（《年輪訣》與《接溫》，族人學得到）。

| 條 | 內容 |
|---|---|
| 源 | 地：三條靈脈份額養出的藥田群，加韋瑟比蜂場的授粉驅蟲〔既有〕。火：長收的「緩」：低矮穩定的暗金火，百年不必添薪〔既有〕。手：《年輪訣》（地階高級）打底，煉藥師靠靈魂控火〔既有〕；《接溫》把長收餘溫分進子爐〔既有〕。燃料是長收本火、契主的魂力（只在點爐、開爐兩頭用）與藥田歲收〔提案〕 |
| 門 | 火不走鬥氣，也不走魂：緩熬是長收自己的火性，點起來之後不必有人守〔既有：百年不必添薪〕。只有點爐與開爐要契主或守爐者在場〔提案〕。手走品與靈魂境界〔提案〕：蟄境（約一至三品）只在主爐邊打下手，自己不碰火。照境（約四至六品）能在《接溫》分出的子爐上煉，喬里四品就在這一格〔既有：借火溫〕。靈境（約七品起）能自己分溫：茱莉安娜七品，《接溫》出自她手〔既有〕。老祖閉關時替他守長收主爐，是八品的事（霍薇絲）〔既有〕。帶狀照[靈魂術與證據](../靈魂術與證據.md)，是常見，不是規定〔既有〕。鬥氣只管一件事〔提案〕：開一爐熬了百年的藥，藥氣一次湧出，七品以上的丹可能引雷〔既有：七品起引雷〕，要有人護丹；鬥宗（空間之力）起才隔得開一座丹房的上方 |
| 象 | 長收是低矮的暗金火〔既有〕。赫爾家子弟身上有長年熬藥的暗金氣〔家底庫〕。喬里在的地方，一碗藥放一整夜也不涼〔家底庫補遺第 33 條，提案〕。〔提案〕格里夫丹房的爐一排一排，最老的一爐爐壁顏色跟旁邊的土一樣；開百年爐那一天，Greave 整城聞得到藥 |
| 契／器 | 不是本命器。火的那一層是**契**：長收契在科爾文〔既有〕，他死火回野，要重新立契，火會選〔既有：契的體例〕。生前解契也可以，火即回野，契痕留在科爾文魂上〔既有：秘法與契〕。〔提案推論〕回野之後長收回到它的所在格里夫藥田丹房〔既有：榜單所在欄〕：赫爾家佔的是地利，不是名分，火選誰不由家主。爐與丹房是外物〔提案〕。地的那一層是**份額**：靈脈份額是脈契與丈量證，不是契〔既有〕。不封魂入器；「器念」是禁區〔既有〕 |
| 傳 | 地能傳：地契、份額、丈量證都是紙，跟著家族走〔既有〕。手能傳：《年輪訣》在族內至少傳了老祖與孫女兩代〔既有〕，《接溫》由茱莉安娜傳給子爐上的人〔提案〕。火不能傳：一人一契〔既有〕。能做的只有在老祖死前把孫輩送到火邊，讓火先認得人；「老祖試火時喬里第一個退下」〔既有〕本卡讀作這件事〔提案〕。茱莉安娜的「家火」之議想把火也變成能傳的，龕燈是先例〔既有〕；可不可行**留白**（見需作者拍板第 3 條） |
| 限 | 緩熬只管「溫度不動」，不管藥好不好：放進去的藥材年份不夠，熬一百年也只是同一味藥熬了一百年〔提案〕。所以火離不開地。長收一爐只守一個溫度〔既有：維持一個溫度〕，要換溫就得開爐〔提案〕。《接溫》分出的子爐，分得越多、每爐越淡〔提案〕。最大的限：火在一個人身上〔既有〕 |
| 價 | 地：份額要泰薩利家丈量才作數〔既有〕，蜂場要用份額拴住〔既有〕。時間：一爐熬一世紀，等於一爐藥押住一百年的本〔提案〕；修士隨歲收晚成〔提案，依《年輪訣》〕。人：科爾文「慢，節儉」〔既有〕，本卡讀作也是在省壽：他多活一年，火就多穩一年〔提案讀法〕。百年爐熬到一半契主死了，那一爐怎麼算**留白**（見第十一節） |
| 萬年問 | 八萬年沒人把這份家底整個拿走，因為能拿的那一半拿了沒用：搶長收，火會選主，離了格里夫的地，緩熬只是一朵很穩的小火〔提案〕；搶地，份額是城盟境內有丈量證的脈契，搶了不作數〔既有：份額要丈量才作數〕。赫爾家真正怕的不是人搶，是兩件事繞過它：一是渡口重開，仙土靈藥不經赫爾家藥田〔既有〕；二是年份可以做出來：「催年」貨在第二次入境前十年左右開始流進柯涅斯〔既有，29 號檔奇洛雅條〕，騙得過眼、騙不過入爐〔既有〕。赫爾家的回答一直是同一句〔提案讀法〕：真年份熬給你看 |

**〈搶收〉八條**〔作者定〕

契主以《年輪訣》把藥田裡尚未收成的藥氣一次收上身，經長收熬成能用的鬥氣，短時間越出自己一截。名取農家在大雨前把未熟的田搶收進倉。

| 條 | 內容 |
|---|---|
| 源 | 《年輪訣》（地階高級）〔既有〕：平時修為隨歲收慢慢累積〔既有〕；本法把一年一收的節律倒過來，提前收〔提案〕。燃料是藥田裡的藥氣與靈脈份額裡尚未被藥材吸盡的那一份；載體是長收契：生藥氣雜，要經長收一熬才入得了經脈〔提案〕。雜氣未經熬煉而入身，就是倉露那種「藥力雜、氣旋暗裂」〔既有，29 號布琳條〕 |
| 門 | 只有契主能用全本（要長收熬）。鬥氣：鬥宗（空間之力）起才能隔空收一片田，一次一塊；鬥尊觸及規則，能收藥田群的一角；鬥聖初期（一至三星）可收 Greave 藥田一季。科爾文二星，收得動，撐不久。魂：靈境以上，否則分不清哪一股是藥氣、哪一股是地氣〔提案〕。修《年輪訣》而沒有契的人（如茱莉安娜）知道法門，收得上來，熬不了〔提案〕 |
| 象 | 藥田從收的那一頭開始，一壟一壟由綠轉灰，像一夜入冬；韋瑟比蜂場的蜂群先起飛〔提案〕。契主周身的暗金氣變濃，長收在他氣旋旁亮成一圈；他的鬥氣裡聞得到藥。收過的田不是燒焦，是空：草還站著，摸上去是乾的 |
| 契／器 | 承載的是長收契與《年輪訣》，不是兵器、不是爐。藥田是地，不是器 |

## 作者裁定（2026-10-02，全數照推薦）

1. **〈搶收〉採不採**。推薦採，標〔提案〕。它給赫爾家一個帶真代價的秘法（燃壽、傷火，外加一季荒田與蜂場鬆綁），載體落在現行《年輪訣》「修為隨歲收累積」與長收契上，並借倉露的「藥力雜、氣旋暗裂」說明沒有契的人為什麼用不了。不動現行任何場面。
2. **長收回野回到哪裡**。推薦寫成「回到格里夫藥田丹房爐底」（依榜單所在欄）：赫爾家佔地利、不佔名分，火仍會選，選的不一定是家主要的人。這把「地＋契火」兩樣家底綁在一起，也讓「老祖試火」有地方可試。不寫長收在赫爾家傳了幾任。
3. **茱莉安娜的家火之議**。推薦本卡不定結局，只寫門檻：長收已是契火，要成為家火，唯一看得見的門是科爾文**生前解契**，火回野、契痕留在他魂上，再看火肯不肯不契一人。代價具體（老祖生前失火），霍薇絲「家火養魂，長收養藥」的反對也有了落點。
