**分級口徑**：九界頂級＝天神以上坐鎮的一域之首；一流＝尊者至天神坐鎮、非一域之首（D060、D073）。西極兩大古老傳承（天山、大日）列頂級，三家後起大宗（御嵐、赤鼎、鳴野）列一流〔既有〕。「古老」與「後起」描述傳承年代，不直接判定當代弟子強弱〔既有〕。

**四家的不對稱**：天山的家底是一座座山，天隙峰只剩一位老師；大日有一門絕學和一塊曬了萬年的石，沒有一件佛器；赤鼎器最多，祖師那一套卻缺了三件；鳴野最大的家底是一頭隨時可以走的狼。

## 一、天山劍宗

**家底形態**：鎮宗之地（劍峰）＋一個人撐場面（天隙峰）〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 西極連綿雪山〔既有〕 |
| 上游與隸屬 | 無；西極兩大古老傳承之一〔既有〕 |
| 通常特別擅長 | 劍道；各座劍峰保存歷代劍修不同的劍意，弟子逐峰問劍，不設只有一種正統劍法〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 西極**頂級**〔既有〕 |
| 規模 | **大**（作者定（2026-10-02）） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 宗主 | 閻山〔既有〕 | 天神〔既有〕 |
| 天隙峰主 | 覃孤，宋明川之師；峰中能指點的師長只剩他一人〔既有〕 | 尊者〔既有〕 |
| 天驕 | 宋明川（天隙峰）〔既有〕 | 留白 |

### 四、傳承

- **根本功法**：《天山劍綱》，**玄篇下**（作者定（2026-10-02））。只是入門總綱，人人共修；真傳不在書裡，在峰壁裡。
- **招牌神通**：〈峰石劍意〉（作者定（2026-10-02）），最低施術境界**銘紋**。逐峰問劍是修法〔既有〕：弟子面壁，讓壁中前人的劍意入身，選一峰或開一峰。天隙峰另有「一線破隙」：凝劍成線、尋隙而入〔既有〕。
- **秘術**：**無**（作者定（2026-10-02））。
- **傳承載體**：各劍峰峰壁〔既有〕。

**〈峰石劍意〉八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 劍道；歷代劍修留在峰壁上的劍意（近[修士遺痕](../../../04_修行與特殊事物/修士遺痕與後手.md)中的「遺念」與「傳承」兩類）。《天山劍綱》只是入門 |
| 門 | 銘紋（力外顯）：面壁問劍，一縷劍意入身，出劍帶本峰的形。列陣（結構）：劍招成了本峰劍意的骨架，各峰形不同。尊者：選定一峰，或在壁上開一峰、留下自己的劍意。天神（空間）：隔空借峰，劍意從遠處峰壁落下，像雪山上一線天光〔家底庫〕 |
| 象 | 出手前報峰名：「天隙峰，宋明川。」報峰是禮，也是警告〔家底庫〕。劍落時，遠處某座雪峰上亮一線 |
| 器 | 本命飛劍；另隨身帶一塊本峰的石，作劍意的承載〔家底庫：出山遊歷帶一塊本峰的石〕 |
| 傳 | 能。劍道天下共有，各峰也互相切磋爭論〔既有〕；天山的家底是山，不是劍譜 |
| 限 | 劍意存在山裡，人離山越遠，劍意越薄〔家底庫〕；峰石丟了，在外就只剩自己的劍 |
| 價 | 術本身不燒什麼 |
| 萬年問 | 劍意存在山裡，人就離不開山；天山劍修少有在外揚名的，遊歷越遠越弱 |

### 五、法寶家底

- **鎮宗之物**：各劍峰的峰壁本身〔既有〕，不按器論〔家底庫〕。
- **人作家底**：天隙峰兩壁相夾、只見一線天；昔日守山一戰失去大半師長，峰中能指點的只剩覃孤一人〔既有〕。一峰的家底是一座山、一位老師、一個徒弟〔家底庫〕。
- **護山大陣、器庫**：留白。
- **靈獸**：無。

### 六、資源

- 其餘留白。

### 七、產業與財政

留白。

### 八、人才管道

- 弟子逐峰問劍〔既有〕；其餘留白。

### 九、外交

- 與中神州萬仞閣、天域東院劍道一脈爭劍名〔既有：萬仞閣一行〕。

### 十、歷代經驗

- 天隙峰守山一戰〔既有〕。
- 各峰可以切磋、爭論，不設只有一種正統劍法〔既有〕。

### 十一、弱點

## 二、大日禪寺

**家底形態**：鎮宗絕學＋鎮宗之地〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 西極大漠〔既有〕 |
| 上游與隸屬 | 無；西極兩大古老傳承之一〔既有〕 |
| 通常特別擅長 | 金身與降魔；以禪定穩住心神，以苦修淬鍊肉身；近身掌印及護身神通〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 西極**頂級**〔既有〕 |
| 規模 | **中**（作者定（2026-10-02）） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 住持 | 覺岸〔既有〕 | 天神〔既有〕 |
| 戒律院首座 | 覺愚，明定之師〔既有〕 | 尊者〔既有〕 |
| 天驕 | 明定〔既有〕 | 留白 |
| 師叔（走火入魔） | 覺妄：修熾身到極處，壓不住怒〔既有〕 | 天神〔既有〕 |

### 四、傳承

- **根本功法**：《大日金身經》，**玄篇上**（作者定（2026-10-02））。修的是日與身：以禪定收心，以日光淬身，法力凝於肉身。
- **招牌神通**：〈大日熾身〉〔既有暫稱〕，最低施術境界**銘紋**；〈降魔掌印〉〔既有〕，最低施術境界**尊者**。心神越穩，力量越凝；動怒不會變強〔既有〕。
- **秘術**：〈焚壽照夜〉（作者定（2026-10-02）），見下方檢查。
- **傳承載體**：午時石（見第五欄）：寺裡傳的是「什麼時辰坐上去」〔家底庫〕。

**〈大日熾身〉與〈降魔掌印〉八條**

| 條 | 內容 |
|---|---|
| 源 | 禪定與日之道；《大日金身經》（玄篇上） |
| 門 | 銘紋（力外顯）：熾身，肉身發熱，法力凝於皮下。列陣（結構）：金身成形，骨與肉有了「殼」。尊者：〈降魔掌印〉印成形，掌出時印在對手身上留一道日紋。天神（空間）：身周數丈被拉到「正午」：影子縮短，陰處變亮〔家底庫〕 |
| 象 | 出掌前，地上的影子先縮短一截，像身周忽然到了正午〔家底庫〕；明定越平靜，掌越燙〔家底庫〕 |
| 器 | 寺中沒有一件傳法的佛器〔家底庫〕；金身即器，不立本命兵器〔提案〕 |
| 傳 | 能。金身之法天下都有；大日的家底是午時石與禪定，熾身離了禪定只會燒自己 |
| 限 | 入夜、地底、陰天時熾身較難起；寺中弟子夜戰要先坐定一刻〔家底庫〕 |
| 價 | 心神不穩時熾身反噬：覺妄修到極處壓不住怒，認定自己在「降魔」，降的卻是路過的妖族與後裔〔既有〕 |
| 萬年問 | 苦修加禪定，缺一樣就會走成覺妄；大多數修士修不來那份靜 |

**〈焚壽照夜〉八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 同《大日金身經》，戒律院所藏一章 |
| 門 | 尊者起可用 |
| 象 | 夜裡，修士身周亮成白晝，影子縮到腳下 |
| 器 | 不靠器 |
| 傳 | 戒律院首座點頭才傳 |
| 限 | 一夜一次，撐到天亮為止 |
| 價 | 以壽元為薪，在無日之時強起熾身；一夜燒去數年壽 |
| 萬年問 | 燒的是壽；禪寺的規矩是夜裡先坐定，不是先燒自己 |

## 三、赤鼎宗

**家底形態**：本命寶物（弟子各煉成套）＋**殘缺的傳承寶物**〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 大漠深處的地火與礦脈〔既有〕 |
| 上游與隸屬 | 無；西極後起大宗〔既有〕 |
| 通常特別擅長 | 煉器；成套法寶，單件各有職責，合用時構成完整攻守；弟子須修多器協同，不能只以法寶數量取勝〔既有〕 |

### 二、等級與規模

| 項 | 內容 |
|---|---|
| 分級 | 西極**一流**〔既有〕 |
| 規模 | **中**（作者定（2026-10-02）） |

### 三、戰力結構

| 職 | 人 | 境界 |
|---|---|---|
| 宗主 | 焦赤〔既有〕 | 天神〔既有〕 |
| 煉器長老 | 熊炬，程燁之師〔既有〕 | 尊者〔既有〕 |
| 天驕 | 程燁〔既有〕 | 留白 |

### 四、傳承

- **根本功法**：《赤鼎爐經》，**玄篇下**（作者定（2026-10-02））。修的是火與器：以地火煉法力，法力能同時分給數件器。
- **招牌神通**：〈連環器陣〉（作者定（2026-10-02）；既有「多器協同」），最低施術境界**銘紋**。
- **秘術**：〈碎器焚爐〉（作者定（2026-10-02）），見下方檢查。
- **傳承載體**：祖師留下的成套法寶（缺組，見第五欄）。

**〈連環器陣〉八條**

| 條 | 內容 |
|---|---|
| 源 | 火與器；《赤鼎爐經》（玄篇下） |
| 門 | 銘紋（力外顯）：兩件法器互相呼應。列陣（結構）：三件成陣（程燁三鼎分掌鎮壓、護身與地火攻伐，合用圍成爐陣〔既有〕）。尊者：五至七件成套，圍成一座爐。天神（空間）：器與器之間的地火連線封住空間，爐內遁法出不去 |
| 象 | 器件之間連著細線般的地火；開戰先擺器，像擺攤〔家底庫〕 |
| 器 | 本命法寶成套〔家底庫〕：弟子各煉一套，成套一起祭煉、一起升品；法器起步，靈器時能互換職責，寶器時器靈雛形「認得」同套的其他件 |
| 傳 | 能。成套法寶天下都有人煉；赤鼎的家底是地火礦脈與多器協同的教法 |
| 限 | 器件被打散一件，整組就斷一處；赤鼎修士最怕先被拆掉中間那一件〔家底庫〕 |
| 價 | 成套本命器，一件受損，本人跟著受傷〔既有規則：本命器受損牽連本人〕 |
| 萬年問 | 養一件本命器已經很累，養一套要翻倍的資源與神識；多數修士養一件就夠 |

**〈碎器焚爐〉八條**（作者定（2026-10-02））

| 條 | 內容 |
|---|---|
| 源 | 同《赤鼎爐經》，秘傳一章 |
| 門 | 列陣起可用 |
| 象 | 套中一件器自己炸開，地火順著連線灌進其餘各件，整座爐瞬間收緊 |
| 器 | 自碎成套本命器中的一件 |
| 傳 | 真傳 |
| 限 | 碎一件，少一件；整套降一級 |
| 價 | 本命器碎，本人重傷；整套此後永遠缺一件（程燁「真打起來捨得碎鼎換勝機」〔既有〕） |
| 萬年問 | 自己的器自己碎；赤鼎人一輩子在找祖師缺的三件，卻也一輩子在碎自己的 |

### 五、法寶家底

- **鎮宗之物**〔家底庫〕：**缺組**。祖師留下一套成組法寶，散失三件；剩下的仍能合用，但永遠有一處破綻。品階：**本質下品道器｜當前作上品寶器用（殘：缺三件）**（作者定（2026-10-02））。
- **宗規**〔家底庫〕：任何弟子尋回一件，即入真傳。所以赤鼎弟子遊歷時都在找三件不知長什麼樣的東西。
- **護山大陣、器庫**：留白。
- **靈獸**：無。

### 六、資源

- 大漠深處的地火與礦脈〔既有〕。
- 昏曉隕金一類材料〔家底庫流通層第 10 項〕。

### 七、產業與財政

- 煉器〔既有〕；其餘留白。

### 八、人才管道

- 尋回缺組一件即入真傳〔家底庫〕；其餘留白。

### 九、外交

- 天域西院器道一脈：爭器道高下〔既有〕。

### 十、歷代經驗

- 不能只以法寶數量取勝〔既有〕。

### 十一、弱點

- 先被拆掉中間那一件〔家底庫〕。
- 缺組永遠有一處破綻〔家底庫〕。

### 十二、劇情鉤

- 程燁也在找宗門缺組的三件〔家底庫〕。
- 散修都知道「尋回一件即入真傳」，假貨滿天飛；程燁一路驗貨，驗出來的多半是假的，真的那一件在誰手上，留白〔家底庫流通層第 2 項〕。

**留白**：人才管道、護山大陣、程燁境界、三鼎正式名稱與品階（程燁人物檔待定）。

## 四、鳴野宗

**家底形態**：**鎮宗靈獸**（可拒絕、可離開）〔家底庫〕。

### 一、定位

| 項 | 內容 |
|---|---|
| 所在 | 草原、荒漠與山麓交會的遼闊原野〔既有〕 |

### 四、傳承

- **根本功法**：《萬野同息經》，**玄篇下**（作者定（2026-10-02））。修的是生靈之間的息：人與獸同呼吸、同起臥、同受傷，修的是「不用說」〔家底庫〕。
- **招牌神通**：〈並息〉〔家底庫名〕，最低施術境界**銘紋**。
- **秘術**：**無**（作者定（2026-10-02））。
- **傳承載體**：弟子與幼獸一同長大；結伴不靠印、不靠契〔既有〕。

**〈並息〉八條**

| 條 | 內容 |
