# 19–27.5段「守得住、帶得走的回報」｜獨立比較

2026-10-23｜獨立讀者 Reviewer，未參與本輪構思。依[任務單](任務單.md)比較[寫手甲](寫手甲.md)、[寫手乙](寫手乙.md)、[寫手丙](寫手丙.md)。審查角度：一般讀者、修仙愛好者、主角視角；Canon 最後核。對照讀了主編後補的[九分差距_前段](../主角群強度重構/九分差距_前段.md)處方2、7，並回查 09、06、07、03、陽閘大綱、劫武學譜。九界金丹除 README 外未讀。本檔只代表本輪審查，不代表作者批准，候選不升格，正文仍凍結。

## 〇、結論先講

**推薦甲（渡標／〈遲雷〉）作基底，借兩項：**
1. **乙的主動換圖一（程序未決→古林）**：葛鳴秋說起古林「遲雷」，劫自己挑往古林的送材委託。正好給甲的〈遲雷〉一個事前欲望，也補上甲在 05 卷幾乎沒動的缺口。
2. **乙的第六重「訊號斷了，所以他也出不去」這個判斷**：改用甲自己的道具來做。淵壁三枚渡標在第六重壓下時忽然感應不到，劫由此判斷至尊和自己一起被封在劫場裡，才倒用歸墟。這讓越牆①多一個由劫推理出來的轉折，也兌現甲自己埋的「聲音走不出去的地方，雷能不能」。

乙是三份裡情感最好的，但它的主軸實際上是一套信號網，而且它對作者選定的陽閘改動實質，落稿風險最高。丙與乙同構，兩者比較，乙的情感做得較好，丙的作者選定邊界守得較好；但丙的岸扣最容易被讀成一張傳送網。

**累積感**：任務的核心，是八年不能讀成一再歸零。
- **甲**：累積最「硬」，讀者每一張圖都看得到他多了一手：遲雷、讀閉口、一指的形狀、近點定位。最有力的是**周見霜之戰排在鏽退之前**。天神被鏽掉的那一刻，讀者已經看過他贏天神、討回帳，「境界被收走了，贏過這件事收不走」是用場面證明的，不是旁白宣稱。弱點是渡標本身留在下無極，上界同代年那段的用途只靠「虛道憑的就是渡標」一句撐，略虛。
- **乙**：累積最「暖」，「握扣的人一個也沒少」在鏽退的斷口裡數扣，讀者感受得到。但扣的數目增加是被告知的；扣本身的力量刻意壓低，只能叫人、推一寸，讀者不會覺得他變強了。
- **丙**：「七、八扇門」最像累積，也最容易變成外掛（見第三節）。

## 二、修仙感（修仙愛好者）

- **甲**最有修仙手感。〈遲雷〉來自古林殘雷紋「遲一拍才落」，用的是武學譜已有的子母禁（母禁本來就可寄在舊雷痕上），是看天地異象悟出來的己法，不是天上掉下來的。淵壁三標裡的遲雷，讓至尊「捨殼與左臂」有了劫事先布下的因，越牆①從「天替他打」變成「天與他的布局合打」，修仙讀者會買帳。缺點：「掌渡者／門與路」這層主題講得太多。
- **乙**的雷扣是兩儀掛印的延伸，根在武學譜（掛印：拍一枚雷印，吸或斥），很自然。但它在戰鬥裡幾乎不出力，仙感來自人情，不來自修行。第六重的扣斷聲是全稿最好的「修行讀法」：用自己的術判斷劫場的性質。
- **丙**的岸扣把「已驗近點會漂、別人撐的點不漂」做成空間法，概念漂亮；可是到故土「沿扣直落文身側」、九弱「從試槽一步落到浮棚飯桌邊」時，就從修行變成傳送功能。

## 三、主角視角

- **甲**：最像劫的一刻，是收周見霜時「只開口要一樣東西：盧那份工錢」，記帳、收帳、不多拿，和追仇卷同一個人。最不像的一刻，是淵壁按標「不是為了誰，只是想知道」，事後剛好成了至尊逃路上的雷，巧得有點像作者替他布局（借乙的判斷可以補：他是讀出劫場封閉後才「用上」標，而不是預知）。主動性最強的是聖物末夜「我要天神的那一折，不要人給的」。
- **乙**：母親拒扣、三年後自己要一枚空扣，附一句「下次，我自己決定要不要拉」。這是三份裡唯一正面碰劫「替人決定」盲點的設計，而且不說教，是全段最好的主角戲。陽閘「他把手拿開」由八年的扣撐住，也成立。缺點是劫多半在「被叫」，八年的欲望是當別人的救援，而不是往高處去；任務單要求的「想打敗的人、想取得的傳承」較弱。
- **丙**：渡劫淵自己關門，是三份裡最強的單一抉擇。但它和 Canon「這一計真奏效：他退不出劫域」打架：丙寫成「一步渡影就出去，只是劫雲會跟著」，等於說至尊的計其實沒困住他，是他自己選擇留下。這改了作者層「敵人的計奏效」的意義，見第五節。

### 2. 乙（雷扣）與丙（岸扣）是否實質同構

**是。** 兩者都從丹台夜那兩半燒過的陸家求援扣起源，都主張「收不走的在別人手裡，另一端自己允才成」，都在虛道讀成規則，都在陽閘「這一端填誰」那一下收束。差別只在功能方向：乙是「你叫，我去」（信號），丙是「你開，我落」（落點）。核心欲望、主要對抗者（乙設邴初貫穿，丙設「關門的人」）有差，但讀者感受到的主軸相同。

**誰做得好：乙。** 乙每一枚扣都有一個具體的人和一個代價：胡湛沒趕上、母親拒絕、盧的扣被沒收落到邴初手裡、遲望晚到的那一拉。丙的岸多半在發揮功能，人情反而較少（阮、謝不收扣只各一句）。丙勝在邊界守得好，並把「讀閉口」接到九弱換圖。但兩者都不如甲那樣讓讀者看見劫自己變強。

### 4. 渡劫淵越牆①擴寫

三份都保住結果：擊退十二劫一系至尊初段、捨殼與左臂、歸墟脈裂一指、第一道終身劫痕、天神成、越牆僅一次、場次仍標工作版A待作者確認（D157）。三份都把現行一段擴成九重起落，回應處方7。

- **最好看：甲。** 遲雷三標讓至尊的逃法落在劫事先走過的路上，「第一點的雷晚了一拍。至尊回頭看了一眼，左臂已經不在身上」是三份樣稿裡最乾淨的一個截圖。
- **乙**的第六重扣斷聲推理最聰明，所以借進甲。
- **丙**自己關門的情感最重，但它讓「退不出劫域」變成「不肯退」，而且把封寒的「第六重以後」讀成淵底第六「層」，劫場與地形混用，不採。

- **甲**：①九弱→故土（陣錄裡讀到過不去的閉口，想去讀它）半主動；②聖物→渡劫淵（要天神的那一折）真主動。

### 6. 同代名位場面是否變相立榜（D159）

- **甲井欄**與**丙觀記壁**同構：都在 Y320 雷井戰後，場吏問何宗何籍，筆停，由輸家替他寫。甲較好：霆刻「劫」、自刻「單雷井道，逼退八丈」讓她的實得也被看見；邴初掛「第三骨補完」帖、牧昭剪燈芯，都是對手的主動姿態。丙的「寄處」有實用後續（尋仇遞帖、免舟資），也好，但較平。
- **乙會河**最壯觀，但死扣的來路（盧的渡樁→舟殿證物房→周見霜賣給太素工席→邴初研究兩年、磨出三根骨）鏈太長，偵探視角會問「一枚熄掉的扣能研究出什麼」。「旁人不必再替同代排次序」一句接近立榜語氣。
- 三份都沒有排名、沒有榜，在 D159 與太素「不排名」之內。甲的「掛帖」是戰帖，不是名次，可留；若主編仍嫌像榜，依甲自己的退路改成只刻名、不掛帖。

### 8. 敗場、越牆、提前能力、武俠詞、新術撞譜

- **新增敗場**：三份皆無。乙的林緣試扣受傷屬練功，丙的不落岸屬選擇。

## 五、甲落稿時須處理（交主編派修）

1. **周見霜要有一手反制**：現稿一回合碎主輪，對一位老牌天神太輕。給周一次真能壓住劫的鎮舟術（例如先鎖整段水路的退路），劫靠近點定位破這一手才收帳。結果不變：周活、主舟保、只付工錢。
2. **核時序**：09 第四段寫劫以天神七雷「合法壓境護家」。須確認上端回程口在壓境之前，劫當時是完整天神，「同境」才成立；也要和 07:9「周要把劫逼回指定的上端回程口」的地點寫法對上。
3. **借乙換圖一**：05 §8 出口加葛鳴秋說起古林遲雷，劫自挑委託；06 §3 燒盤那次改成他帶著目的去試。甲原有的「看清晚一拍」保留為第三試的領悟，秦的「鬆」不動。
4. **借乙扣斷聲判斷**：淵壁三標在第六重壓下時感應全斷，劫由此知道封場不認主客，才倒用歸墟。三標原本「不是為了誰」的動機保留，但改成「想知道聲音出不去的地方，雷出不出得去」，把巧合變成他事先量過、臨場讀出來的。
5. **40A 那句選路理由**移到 03 九弱檔，40A 檔不動。
6. 古林雷花：寫明殘雷紋遲落仍是古林的天地現象，劫是「借」那一拍按下自己的雷，篇名「古林雷花」的奇觀不被收成單純的術。
7. 上界同代年渡標的用途再補一場（任一處，例如鐘墟換口時落在他自己留的標上），不要只靠虛道那一句。
