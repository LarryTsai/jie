## 故事改變

機構收走的是門：籍、印、席位；收不走的是劫自己走出來的路。八年每次登頂，他從一個具體的「掌渡者」（岑越、周見霜、柯臨、羅不凋與至尊殷枯朔、公孫逾）手裡贏下一處過法，在親身走過、驗過的落點按下只認他本源的**渡標**；二十四歲古林起標裡能留一縷〈遲雷〉。境界被鏽、籍被除，標仍認他；虛道所憑的落點就是上界這一年按下的標；二十七點五歲收在陽閘閘權。

- **亡命三篇**：古林〈遲雷〉初成（借古林雷花的晚一拍，是他的手），奪回藏嶽環；盧一丈水渡是第一處盟友的渡；聖物次晨「我要天神的那一折，不要人給的」。
- **劫不能贏天神的回收**：約25歲天神七雷穩住後、壓境登記前，上端回程口一回合同境勝周見霜（周先以鎮舟術逼他換落點），只收回盧的工錢與料費簽——鏽退之前，讀者先看見他贏過天神。
- **主動換圖**：九弱→故土（讀到渡影步讀不穿的閉口）；程序未決→古林（借乙：自挑往古林的委託）；聖物→渡劫淵。
- **渡劫淵越牆①**擴成九重完整高潮；第六重三標遲雷斷感，劫判出劫場封死、至尊也出不去（借乙）；結果、次數不變，仍標工作版A待作者確認。
- **同代名位**：雷井勝霆孤衡後，場吏刻不下他的宗籍，霆親手在井欄只刻一個「劫」。
- **去小家子氣五點**（[審查](../去小家子氣/審查_02離鄉03崛起.md)）：雙汐六息寫成萬人看見的勝利；十三劃執事裘寒沙、淵底至尊殷枯朔補名與招，十三劃人數矛盾修正；崛起自貶句清除；離鄉撤走／失物串補強者動作；日帳移附錄。
- **作者裁定**（[紀錄](../去小家子氣/作者裁定.md)）：一、藏舟追孟改由劫同境正面擒孟，太玄師長事後接人；孟押送途中被同黨截走，不是從劫手上逃；劫收起器核殘片，外港讀的就是它。二、三千花夜 A25 改「迎盛而上」正面壓倒虞靈狩，勝負傷帳日帳兩獸活不改。

效力：**工作選定**，非作者逐卷批准；渡標、〈遲雷〉、裘寒沙、殷枯朔、井欄為工作設計。作者選定列：40A月下共逃未改；56三千花夜只依裁定二改A25；58陽閘只加〈帶走〉一行並刪兩句旁白。九界金丹未讀未改；上界追仇開頭登天日前後留空給另一工作線的玄殿場。
