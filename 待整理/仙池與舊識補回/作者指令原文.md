- **兩部故事都要補回來**：仙池篇與舊識篇功能不同，不能二選一，也不能只留「兩人仙池救獸」「丹會生擊敗舊識」兩句。

- 角色和對手都要有自己的能力、選擇、真正勝負與後續人生；所有新姓名、血緣、境界、器物、交通、時點先核對 Canon。

## A.《四時仙池：花開時，她仍握著雙環》——七幕約24–30章

**第一幕（1–4）春雪同池**：生為隨季候變藥性的古根而來，劫為四季轉動的天然雷紋而來；倒懸花瀑、東春南夏西秋北冬、銀瓣溫泉與移動季候界線必須具體描寫。出口自然封閉二十餘日，不強拆仙境。保留「出路封了，又沒說不是好事」的喜悅。

**第二幕（5–8）霧隔兩岸**：溫泉只調息、滋養與穩修，不讓人泡一次就突破大境。劫用自煉丹爐試泉脈供火，生研究活藥，互相指出盲點。保留最佳泉眼、岩壁水霧隔開的曖昧、互相尊重而非偷窺；烤果、留飯、夜談童年與共同觀景不可略去。

**第三幕（9–12）銀角小鹿**：生發現受捕獸鎖魂器重創靈脈、血脈及神魂連接的幼獸；牠起初戒備劫，漸漸信任生。生清傷止痛守夜，劫也陪伴並逗牠。保留生的核心台詞：「牠是什麼我不知道，但我知道牠會痛。」候選小鹿「霜霜」的種族和名字未定，不能強迫認主。

**第四幕（13–18）九轉同爐**：「九轉」暫指九次藥性轉化，**非直接等於九轉仙丹品階**。生主導藥方、活藥節奏、停爐、最後丹紋；劫以自煉丹爐、禁制改造、有限隔空雷煉作真正丹師貢獻。前三轉雷分藥性失敗、生改分煎；四至六轉劫改爐禁；七至九轉生捨棄表面最強藥效，保留幼獸可承的續命藥性。保留「是妳的方／也是你的爐」。幼獸服丹後多日漸好，不能瞬間滿血。

**第五幕（19–23）她打得敵人只能偷襲**：御獸道統循捕獸痕追來；劫在外圍攔大批追兵，生以雙環正面戰候選御獸天驕虞靈狩。敵方兩本命獸、魂念與短兵確實很強，但生拆其合擊，逼得敵人護器裂、兩獸失位，**敵人確知再打必敗，才暗令同伴以鎖魂器偷襲幼獸**。生不是輸了才護獸；她本來再追一環便能贏，主動放棄勝勢回身擋招，肩臂受傷、護住幼獸，仍能再戰。

**第六幕（24–27）劫怒而靜、生親自決勝**：劫見血，越怒越冷靜，先問傷、再破偷襲者之器與術，不失智、不亂殺、不越境。生說「她是我的」，劫讓出她的決戰。生親自以雙環拆獸、封退路、斷魂念續接，逼虞靈狩棄刃失護器，環停眉心。保留「你在偷襲之前，就已經輸了」。戰後劫給藥、生自行處理傷，保留「第二環回得早了半息／還有，很好看」的感情候選對話。

**第七幕（28–30）她自己選擇留下**：幼獸恢復後，生讓牠回花林，牠自由走回來，選擇同行。池畔月光、靈獸睡在兩人之間、安靜離別都要留；不要提前告白或立刻插入新陰謀。後續靈獸自主成長、平等靈契可能、生的雙環聲望與共同丹法要有回收。

**時序硬核**：母稿候選為陸沉**八雷時期**，與《三千花夜》82日、80場景卡、18日分路、傷養和候審有依賴；請逐場對照提出「保留／替換／擴寫／衝突」，不得自行增加時間或硬塞進驤鳴跌境養傷期。

## B.《洛生衣舊識：丹道宿敵與護短》——六幕，建議70–90章雙主角長篇的組成部分

**人物前提**：生幼時舊識曾有更好師承、資源、聲望，至今仍以舊眼光看她。優先找現有角色；關係可選遠房姊妹、幼時玩伴同窗、世家往來，母稿**推薦幼時玩伴為主、兼熟悉感和公開衝突**。候選「洛清瑤」僅在確定洛氏親族且查無撞名時可用。舊識必須有真正丹道本領、獨立野心與至少一次真勝，不能是惡女工具人。

**第一幕 百草仙城**：生因殘缺古方主動邀劫遠行；兩人分別逛攤、約好見面卻各自遲到。生重逢舊識，先真心高興，後逐漸感到被居高臨下安排旁聽或丹侍；劫聽見生童年炸爐糗事。先寫人情與生活，不一見面就辱罵。

**第二幕 丹會門前**：舊識師兄公開質疑生的師承與資格，舊識未阻止。劫護短，反問「看丹術還是看師門？」但他爭的是**公平參賽機會**，不能靠身分逼主辦違反真正資格規則。若有合法門檻，生自己按規則取得資格。

**第三幕 丹道兩戰**：標準限時丹試，舊識以火候穩定性**真勝**，生承認、劫不找藉口；殘缺古方或未知藥性，生憑共爐、採藥與多年實驗**真勝**，自己完成判斷與成丹，劫不偷偷灌雷。丹成花開等異象要核規則。

**第四幕 陸沉的天驕約戰**：對方丹宗師兄／火道天驕有真實名額或護道資格之爭，火幕、火種連鎖先逼劫變招；劫以已掌握雷、身法、禁制與近戰取勝，對手有反制，不羞辱敗者。可以啟發劫研究，但**不得在第二次聖土火蓮之前提前完成雷丸**。

**第五幕 萬生天苑**：生與舊識各帶隊入古藥境，各有真正所得；舊識先取傳承，生另闢藥性道路。劫也有自己的雷木、禁制、古器探索，不是全程護衛。最終丹臺由生主導關鍵一爐，**生必須有無可爭議的重大丹道勝利**，劫另有強敵勝場。

**第六幕 多年後**：舊識承認生走出另一條丹道，仍保持自己的驕傲與仙途，不必臣服或變跟班。保留兩人童年共抄丹方、賽前緊張與劫備料、分路重逢展示所得、慶祝與安靜夜談。核心對話保留候選：「你不是知道我自己能贏？」「知道。」「那你還說那些話？」「她們連讓妳上臺都不肯。」

**篇幅與時間**：母稿提議百草仙城12–15章、萬生天苑16–20章、三千花夜14–18章、丹成天地18–22章、與君同歸10–15章；這是**嵌入一部70–90章雙主角長篇的候選**，不是不查重就另增90章。時間候選16–18歲或26–28歲；須核對南荒、四院、九界大比、封傷金丹、火蓮雷丸與感情階段，不得擅定。

## C. 整合原則與不得做的事

1. 兩篇分別有完整高潮：仙池是共同煉丹、靈獸與雙環守護；舊識是童年關係、丹道競爭、公開護短與古藥境。**不能用一篇替代另一篇**。
2. 不得將仙池壓成「泡溫泉→救獸→打敵」三場，也不得將舊識壓成「宴會打臉→丹會勝利」兩場。
3. 不得把生寫成被敵人打敗才護獸，或劫替生打贏御獸天驕／丹道決戰。
4. 不得抹除舊識的真正勝利、獨立機緣與多年後人生。
5. 不得新增無代價跨界、境界、神丹、雷法、靈契；不准偷提前告白、火蓮、雷丸或修為突破。
6. 不得把所有日常、對話、溫泉曖昧、煉丹試錯當作可壓縮冗餘；這些正是作者希望的閱讀體驗。
7. 與《驤鳴》重構只需核對時序與人物狀態，**不要強行把兩個快樂仙道冒險改成跌境醫療支線**。

## D. 執行與驗收

**Phase 1：核對來源**。實讀兩份母稿全文及 GitHub 相關正式大綱、人物、武學、感情線、年表；提交「母稿每幕／每場／重要對話 → 現有場景 → 保留／補入／替換／衝突」矩陣，另附姓名、境界、雷數、丹道、雙環、交通、傷養與日數衝突表。

**Phase 2：獨立構案**。仙池至少兩位寫手各交30章完整事件綱與五場試寫（仙池初見、溫泉相處、照顧幼獸、九轉成丹、偷襲至雙環決勝）。舊識至少三個獨立方案（親族、玩伴、丹會古藥境），均有舊識真勝、生真勝、劫護短、火道真戰、古藥境與情感戲。

**Phase 3：獨立覆核**。人物 Reviewer 核生的主體性；戰鬥 Reviewer 核能力與勝敗；丹道 Reviewer 核九轉藥理及兩戰；感情 Reviewer 核曖昧、日常、慢熱節點；Continuity Reviewer 核82日、80卡、18日分路、跨篇前後；修仙讀者 Reviewer 評仙感、節奏與是否真想讀下去。每個審查要指出具體場景，不接受「已覆核 PASS」空話。

**Phase 4：作者裁定再入綱**。交付：①來源與場景映射表；②獨立方案比較及推薦；③兩部完整逐章事件大綱（不能只寫章名）；④至少十場正文檢驗試寫；⑤作者需拍板清單（時點、舊識身分、靈獸、御獸敵人、篇幅與是否整合）。作者確認後，才更新唯一正式大綱與總年表；不得直接改正文或將工作候選冒稱 Canon。
