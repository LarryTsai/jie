# 開篇第11章〈背陰面〉正文

**狀態：** 新寫 v1.0，完成參考作品對照與內部覆核，待作者閱讀。正文連結見[第1–17章正文索引](../../正文/01_少年/01_浮石之下/01_地裂與兩條時間線/README.md)。

## 本章方向

沿用作者選定 v1.9 章綱。第二個浮石季由別人帶隊，父親在坡下陪陸沉坐一個上午、幾乎不說話；陸沉誤以為被看管而生氣。陸沉看見浮石背陰有人割護繩，喊了卻無人相信；午後祁望摔下並摔斷腿。保留兩件事的相鄰發生，不替陸沉補出他無法取得的證據，也不把他當時的所見當成大人已經確認的事實。

## 《武煉巔峰》閱讀感對照

按作者提供的印象，參照友情要在反覆相遇中累積，也要容得下失誤與關係改變。本章承接第4章祁望在上坡時回頭揮手、第10章兩人一起爬斷階：這次陸沉見到朋友墜落，卻被父親留在坡下；祁望即使疼得發白，仍朝他晃手，陸沉則推開父親後獨自坐回去。信任沒有因一個救援動作就解決，父子也因「你為什麼留我在下面」產生未說出口的摩擦。成長仍是八歲搬血初段，陸沉看見得多，卻沒有力量阻止事故。

本次對照只依作者在對話中描述的閱讀感，不宣稱掌握原作未在此提供的具體橋段，也不借用原作情節或文字。獨立審查認為陸沉重複確認「看錯會害大家停下」削弱墜落前節奏；修訂後保留無證據的窘迫，但壓成一句，讓注意力留在他喊出來、父親處理、祁望失足的連續動作。

## 覆核

- 時間是第二個浮石季、陸沉八歲；父親陪坐、換人帶隊、陸沉以為被看管並氣了一天均保留。
- 陸沉看見背陰面有人割護繩，旁人未確認；沒有讓大人突然相信或成功抓人。
- 祁望摔落後腿傷清楚可見，沒有立即治好；這承接第9章他的濕天腿痛，但摔斷經過第一次在本章呈現。
- 陸沉想衝過去，被父親留住；他不能靠神識或先知改變結果。
