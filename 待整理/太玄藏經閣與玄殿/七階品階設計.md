## 一、三十二天七階細則

作者已定七階名：**凡、靈、玄、地、天、道、仙**。以下是細則推薦。

### 1.1 用「階」，不保留「篇」（推薦）

推薦寫法：**「天階上品」**、「地階下品」、「仙階中品」。「篇」字退出品名。

理由：

1. **「篇」在全庫已有三種別的意思，正好撞在功法上。**
   - 卷次：《鈞天劍經》「上篇真傳、下篇自補」與品名「仙篇下」寫在同一行（[上無極](../../設定/01_世界/04_勢力/06_家底卡/上無極.md) L45），讀者分不清。
   - 書名：《百衲篇》《鳴律篇》《潮信篇》《泊陣篇》《守古篇》《照幕篇》《天孫機杼篇》，會寫成「《百衲篇》玄篇下」。
   - 篇章：《萬體鑄身經》本身就有「公開四篇＋真傳四篇」；故事又有「第 N 篇」。
2. **作者自己的用語是「階」。** 提案寫「凡階→……→仙階」「天階上品」，裁定一也說「天階上品」可照用。
3. **三十二天的分層慣例本來就是「階＋品」。** 丹藥是「一至九階＋下中上品」；改後功法是「七名階＋下中上品」，結構一致。丹藥用數字、功法用名字，兩者不會混。

### 1.2 細分用下、中、上三品（推薦）

推薦**每階分下品、中品、上品**，不沿用 D073 的上下二分。

理由：

- 「天階上品」成立後，二分制只剩「上、下」，「上品」讀起來像最高格，而不是兩格中的一格。
- 三十二天其他軸都已用三分：法寶與材料「各分下中上」、丹藥「下中上品＋無瑕」、符「下中上品」（[底層規格 04](../../設定/01_世界/02_修仙文明/01_底層規格/04_經濟流通與校驗.md) L72–77、D078 第 7 條）。功法也用三分，全書只有一種細分語感。
- 七階乘三品共二十一格，夠用。正文多半只寫到「階」，「品」只在有意義時才標。

**不設「無瑕」**：無瑕是丹藥成品的雜質判定，功法沒有對應物。功法的「好壞」由完整度（殘卷、全本、真傳）表達，不由品級表達。

### 1.3 各階對應境界與稀有度

**口徑**：下表是「著者常見境界」與「修全所需境界」，作為**世界常識與尺度**，**不是**每部功法逐一標注的承境欄。D073 不採承境欄這一點維持不變：卡片上只寫品名，不必另填「承到哪一境」。

- **寫出**：能著出該階完整本的人，常見落在這一帶的後段或更高。
- **修全**：要修到全本最後一段，本人須到這一帶。低境者可以先修適合自己的前段，這延續[逐卷修行所得總表](../../大綱/00_全書骨架/01_人物線/逐卷修行所得與消化總表.md) L17「高階傳承可先讀適合自身境界的一段」。

| 階 | 寫出／修全約當 | 名與境的呼應 | 稀有度（世上） |
|---|---|---|---|
| **凡階** | 搬血、洞天 | 凡人入道 | 遍地。凡間武館、坊市書攤、宗門外門的入門總綱 |
| **靈階** | 化靈、銘紋 | 化靈：力開始外顯 | 九界中小宗門的根本功法，世家的家學主幹；一般修士一生修的多在這一階 |
| **玄階** | 列陣、尊者 | 列陣：九界承載線；尊者：上界通行 | 九界一流、二流宗門的根本功法與峰傳；上界的尋常貨 |
| **地階** | 神火、真一、聖祭 | — | 九界頂級宗門（一域之首）的根本功法、一流宗門的秘傳；上界一流宗門的常備 |
| **天階** | 天神 | 天神：空間之力 | 九界一域只有一兩部，多是頂級宗門的鎮宗秘傳或祖師遺著；**天階上品在九界屈指可數**。上界頂級宗門與王庭世家才算「有」 |
| **道階** | 虛道、斬我、遁一、至尊 | 虛道門＝觸規則，至尊＝法力上限 | 九界幾乎不存（只有古傳殘卷）。上界頂級、王庭本家才有完整本；一界數得出來 |
| **仙階** | 真仙以上 | 仙力 | 以仙力運轉的功法。仙王以上道統、仙庭、王庭本家與古傳才有；上品多出自仙王以上，仙帝所著也只叫仙階上品，**不另設帝階**（依提案「先不加帝階」） |

**對藏經閣一案的意義**：天階上品落在「天神所著、九界頂級宗門鎮宗級」的位置。太玄是「一流・小」（D073 第 12 條），藏有一部天階上品，已是九界少見的重寶，但不是全世界唯一或最強。往上仍有道階、仙階，符合提案 3.1「不必立刻升到帝階」與 3.2「能支撐相當長的修煉階段」：劫取得時只能用前段，要到天神前後才修得全。

> 待競稿交代：太玄家底卡寫「宗門沒有能打的鎮宗兵器，家底在手藝」（D073 第 12 條）。一部天階上品攻擊典要與這句相容，可以讓它是**長年無人修成的典**（有書無人能用，所以不算能打的家底），或來自玄殿上游一系的寄存。具體寫法交三寫手，本檔不定。

### 1.4 品階評的是「卷」，不是「術」

D073 第 3 條：**術法不分層**，只標最低施術境界。裁定三又說藏經閣所得是「攻擊類招式典」。兩條要相容，推薦這樣讀：

- 品階評的是**一部卷**：根本功法、輔修卷、秘術卷都可以評階。
- 招式典屬**輔修卷**：一卷之中收錄一組術，以及修這組術所需的法力運行與心法。
- **卷**標「天階上品」；卷中**每一門術**仍只標最低施術境界與熟練四段。
- 所以「天階上品招式典」成立，但不能寫成「天階上品的某一招」。

### 1.5 與器品、材料、丹、符、陣是不同的軸

| 軸 | 名稱 | 細分 | 判定對象 |
|---|---|---|---|
| **功法**（本案） | 凡、靈、玄、地、天、道、仙階 | 下、中、上品 | 一部卷的高度 |
| 術法 | 不分層 | 熟練四段 | 最低施術境界 |
| 法寶（D073／D078） | 法器、靈器、寶器、道器、仙器、帝器 | 下、中、上；另分本質與當前 | 器的取材、器紋、器靈三者最低者 |
| 材料（D073） | 凡材、靈材、道材、仙材 | 下、中、上 | 承力 |
| 丹藥（D073） | 一至九階 | 下、中、上品＋無瑕；雷紋另計 | 煉製難度與丹力 |
| 符（D078） | 以所封之術的最低施術境界標（「列陣符」） | 下、中、上品 | 所封之術 |
| 陣（D073） | 盤陣至界陣 × 承境 | — | 規模 |

**不混用的規則**：

1. **同字不同軸。** 功法的凡、靈、道、仙，和器的靈器、道器、仙器、材料的凡材、靈材、道材、仙材共用字，但**不一一對應**。例如「道階功法」不等於須配道器或道材，「靈階」也不是「靈器」的功法版。
2. **一律寫全稱。** 正文一律寫「地階」「靈器」「道材」，不寫單字「靈品」「道級」。
3. **數字與名字分開。** 丹藥用數字（「七階丹」），功法用名字（「天階」）。功法不寫「第五階」「五階功法」。
4. 舊的「三十二天說篇、聖土說階」分法，改為**兩界品名不共字、細分詞不同**：三十二天用「下中上品」，聖土用「低中高級」。詳見第二節。

### 1.6 舊 D073 四篇怎麼對到新七階

## 二、聖土七層名稱（三套候選）

### 2.1 共同框架（三套共用）

**不保留天地玄黃。** 作者要求聖土七層的名稱和三十二天不同；三十二天新制已用玄、地、天三字。若沿用「黃、玄、地、天」再往上下延伸，七層中至少三層與三十二天同名，正好違反裁定，也會重演舊 D073 加註「兩邊都有玄」的混讀。所以**延伸天地玄黃一案不提**；要走這條路，須作者先改「名稱須不同」的前提。

**層與境界**：三套名字不同，但對應的聖土境界相同。

| 層 | 寫出／修全約當（聖土） | 稀有度 |
|---|---|---|
| 一 | 鬥之氣、鬥者 | 遍地；冊籍戶入門名額（不限人數）所授 |
| 二 | 鬥師、大鬥師 | 小宗門、城席家族的主幹 |
| 三 | 鬥靈 | 地方高手的天花板；**邊地所見最高**（舊「地階中級」） |
| 四 | 鬥王、鬥皇 | 中心大宗的根本功法；撫恤傳承名額的上段 |
| 五 | 鬥宗、鬥尊 | 柯涅斯在世譜上的幾部（舊天階低級：《靜衡經》《堰經》《散頁》《砧典》殘） |
| 六 | 半聖、鬥聖 | 柯涅斯只有《九判》完整一部；外洲另有三部，都從帝經殘頁推衍 |
| 七 | **鬥帝** | **只有帝境寫得出**。八萬年無帝，今日無完整本，只剩《量潮書》七卷殘頁（舊「天階高級以上」） |

**細分**：一至六層照舊分**低級、中級、高級**，聖土「低中高級」這組字不動。第七層只見殘頁，推薦**不再細分**，寫「第七層殘頁」即可。

**舊天地玄黃落到新七層**：聖土內部要換名，所以需要一張落點表；兩界之間仍不換算。

| 舊 | 新 | 現行筆數（正式區） |
|---|---|---|
| 黃階低／中／高 | 一層低／中／高 | 只見於規則條文 |
| 玄階低／中／高 | 二層低／中／高 | 3／23／64 |
| 地階低級 | 三層中級 | 65 |
| 地階中級 | 三層高級（仍是邊地最高） | 99 |
| 地階高級 | 四層中級 | 103 |
| 天階低級 | 五層中級 | 46 |
| 天階中級 | 六層中級（《九判》與外洲三部） | 16 |
| 天階高級（以上） | 七層 | 5 |

舊階多落在新層的「中級」，是為了上下各留一格，給日後新設計用。舊「地階」包含三層與四層兩段，所以「地階傳承名額」這類籠統說法要逐處判讀，見第三節。

### 2.2 甲｜鍛序（金屬）

**鐵階、銅階、銀階、金階、秘銀階、精金階、冕金階**

- 細分照舊：「銀階高級」「金階中級」。
- 聖土的契約廳、自由團、錘廳拍賣，本就是西式冒險者行會的氣味，金屬分級最接近這種語感。
- 第七層「冕金」取帝冕：帝境才鍛得出的金。可改為「帝金」，更直白，但「帝」字與三十二天的帝器同字。
- 示例：《九判》（舊天階中級）→ 精金階中級；《護脈經》（舊地階高級）→ 金階中級。
- **一句優缺**：前四層一看就懂高低，舊稿多數只要改一個字；但「秘銀、精金、冕金」的順序要靠正文建立，與鍛廳的兵器材料、星羅銀雷、流光金雷也有混讀風險。

### 2.3 乙｜環序（氣旋）

**一環、二環、三環、四環、五環、六環、七環**（第七環俗稱「帝環」）

- 品名字改用「環」：「三環高級」。
- 世界內的理由（候選）：聖土修行從體內**氣旋**開始，佩魯書院以「這部功法能把氣旋推到第幾環」定級；七環只有帝境推得動。
- 中文奇幻譯名本來就用「環」作術法等級，西式語感明確。
- 兩界品名字也就分開：三十二天說「階」、聖土說「環」，延續舊的「用字分開」原則。
- **一句優缺**：與聖土氣旋同形，品名字與三十二天完全分開；但聖土已有魔獸一至九階、煉藥師一至九品、鬥者一至九星三套數字，再加一套數字最容易讀亂，也會撞卡洛陣會的「門環」。

### 2.4 丙｜燈序（光）

**燭階、燈階、炬階、烽階、月階、日階、冕階**

- 細分照舊：「炬階中級」。
- 意象接聖土的守渡、守港、修會、龕匠：燭、燈、炬、烽是人點的火，一層比一層照得遠；月、日不是人點得起的；冕取「日冕」，日外之光，也是帝冕。
- 示例：舊玄階高級 → 燈階高級；舊天階低級 → 月階中級。
- **一句優缺**：七名都是單字，意象最有畫面，第七層「冕」一字兼含日冕與帝冕；但聖土的異火、燧冊（異火榜）、煉藥火候都是火，燭、燈、炬、烽容易被讀成火的等級，月、日兩名也不夠西式。

### 2.5 推薦：甲（鍛序）

理由：

1. **最好讀。** 舊稿約四百處裡，玄、地兩階佔九成，改後落在銅、銀、金，讀者不必學就知道高低。
2. **改動最小、最機械。** 保留「階＋低中高級」，舊稿多數只換一字，最適合一次性批次替換後人工抽核。
3. **最合聖土氣味。** 契約廳、自由團、錘廳加金屬牌級，是西式行會的直覺。
4. **兩界不會混。** 三十二天七名（凡靈玄地天道仙）與甲的七名沒有一個字重複，細分詞（下中上品對低中高級）也不同，雖然共用「階」字，也不會讀混。

若作者更在乎「兩界品名字也要分開」，次選**乙**。

### 4.2 條文草稿（只寫在本檔，不建 D 檔）

> # D162：功法品階改七層（2026-10-22）
>
> 作者裁定（2026-10-22，[太玄藏經閣與玄殿・作者裁定](../../待整理/太玄藏經閣與玄殿/作者裁定.md)裁定一）：兩界功法品階都改為七層，兩界不換算。
>
> ### 一、條文
>
> 1. **三十二天功法七階**：凡階、靈階、玄階、地階、天階、道階、仙階，各分下品、中品、上品（例：天階上品）。品名不再用「篇」。不設帝階。
> 2. **評卷不評術**：品階評的是一部卷（根本功法、輔修卷、秘術卷；招式典屬輔修卷）。術法照 D073 第 3 條不分層，只標最低施術境界與熟練四段。
> 3. **口徑**：凡階約當搬血至洞天，靈階化靈至銘紋，玄階列陣至尊者，地階神火至聖祭，天階天神，道階虛道至至尊，仙階真仙以上。這是著者與修全的常見境界，是世界尺度，不是逐部承境欄（D073 不採承境欄照舊）。低境者可先修適合自己的前段。
> 4. **聖土功法與鬥技七層**：〔作者選定的一套名稱〕，一至六層各分低級、中級、高級；第七層只有帝境寫得出，今日只存殘頁，不細分。舊天地玄黃依落點表改名（黃→一層；玄→二層；地低→三層中級；地中→三層高級；地高→四層中級；天低→五層中級；天中→六層中級；天高以上→七層）。
> 5. **兩界不換算**：不並表，不寫「某層約當某階」。兩界品名不共字；細分詞分開：三十二天用下中上品，聖土用低中高級。
> 6. **不同軸**：功法品階與法寶六品、材料四等、丹藥九階、符、陣各是一軸，同字不對應；正文寫全稱，不寫「靈品」「道級」這類單字稱。
> 7. **既有品名重核**：正式區已定品名的二十二部，照〔批准的對照表〕改寫；主角群根本功法仍留白。
>
