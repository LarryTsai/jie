# 藏經閣天階功法與玄殿道境｜三寫手競稿任務單

2026-10-22｜主編發派。候選、非Canon、非正文。依[團隊競爭創作規約](../../設定/00_故事定位/02_工作規約/AI團隊競爭創作規約.md)：三寫手獨立、互不讀方案，各寫 `甲.md`／`乙.md`／`丙.md`；完成後交未參與者比較。

## 作者裁定（硬約束，見[作者裁定](作者裁定.md)）

1. 功法品階：三十二天改為**凡、靈、玄、地、天、道、仙**七階（細則另由設定線整理）；本篇功法為**天階上品**。
2. 功法定位：**輸出型攻擊招式典**（作者舉名風格「鳳凰盛世典」「大道浮屠經」），不是根本主修；萬體鑄身經的根本地位與一人主修一部不動。
3. 玄殿＝**上界玄殿**（澄霄王庭官史機構），約19歲初入玄殿登籍期；陸沉**親歷仙階道境、只懂一個局部原理**；不新增「意境」正式名詞；與約27.5歲孤光原前仙王道境拉開。

## 每份方案必交

1. **功法**：典名（要有作者舉例的氣派）、來歷、屬性與核心原理、三到五式招式（各寫樣子、威力層級、限制與反制）、為何是天階上品、與九雷／天譴／劫數／萬體鑄身經的互補分工、修煉層次與後續成長。
2. **取得**：在哪裡、怎麼取得——太玄宗**沒有藏經閣**，命藏（D069）卷六主題是「不作傳承商店」。請自行設計合法取得處（例：卷十九〈歸山〉山中第16–28日空檔、太玄某處、或其他可證的窗口），附神魂試煉「見萬法→辨其法→選其路」的完整場面：他放棄了哪門更耀眼的、為何選這門、付了什麼。不得推翻卷六主題。
3. **首驗與再驗**：功法第一次實戰兌現在哪一場（不得戰場用未驗新法，D157第9條）；再驗在哪；不得用削弱陸沉來襯托。
4. **玄殿道境**：約19歲在上界玄殿的完整場面：進入理由、道境裡經歷的問題、他理解的那一個局部原理、尚未理解的部分、後續哪一場回收；與「變」的大道探索相呼應但不替他下結論。
5. **對正式區的 diff 清單**（只列不改）與待作者題（至多2題）。
6. 至少一段非正文樣場（各300–500字）。
