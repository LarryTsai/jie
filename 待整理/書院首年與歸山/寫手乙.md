# 書院首年與歸山：寫手乙方案「三響與第二對腳印」

2026-10-22｜寫手乙｜競稿第一輪，**候選**，不是工作選定，也沒有作者批准。正文凍結；第八節是非正文樣稿。新人物、地名、器物與法的名字都是工作名。

## 〇、先說故事

北院這一屆有個少年，九歲那年就替一整座城下過令。

他叫**戚鳴鉦**。天域外緣的浮城「燧垣」浮基崩落那三天，他父親先死在燧臺上；收城令依血脈落到他手裡，他用家傳的〈三息令〉讓八百人照他的拍子，三息一批走上渡舟。最後六十三名守燧人得留下來扛住浮基支點，讓別人走完，這也是他下的令。燧垣沉進雲海。他燒掉十一年壽元，換來一本薄冊，第一頁寫著六十三個名字。

十六歲入院，他和陸沉都想要登天塔頂那口**承天鐘**裡的東西。鐘壁內鑄著一部殘法《百足承山》：百隻腳扛一座山，誰都不必扛全部。陸沉想用它治三雷同用時的過載。戚鳴鉦想用它讓〈三息令〉別再燒自己的命。鐘只開給敲響它的人，一次只能抄一段。

書院這一年，陸沉在塔頂贏下鐘，院城第一次聽見三個音同時響起；接著在天域行，他親手把新生旗交給戚鳴鉦，承認那天把人帶回來的不是自己；越庫那夜，他欠下戚鳴鉦一次。回到太玄，他要學會在任何一個支點被人拔掉時仍站得住，於是在鎮岳臺上，讓師父的腳往後挪了半寸。

**本稿最值得期待的場面**：

1. 第四日黃昏，北院七人令陣搶先佔住撞座，陸沉沒有撞座可敲，讓三具身各敲一隻鐘腳。他沒有把三雷合成一股，而是第一次不盯著自己的身子。整座院城聽見一口從沒聽過的三聲和鐘（卷十六，書院登頂）。
2. 鎮岳臺上，岳沉淵那對站了不知多少年的腳印後面多出第二對。岳沉淵說「我失敗了，陪我坐」，帶著老七去崖上坐（卷十九，歸山高點）。

## 一、北院宿敵：戚鳴鉦

| 項 | 內容 |
|---|---|
| 名字 | **戚鳴鉦**（工作名）。燧令世家照烽火號令給後人取名，父親戚舉燧，名字取舉烽示警；他叫鳴鉦，取鳴金收兵。院裡同代叫他「戚鉦」。 |
| 境界、年齡 | 十六歲，銘紋，和陸沉同境，北院同屆。 |
| 出身 | 天域外緣浮城燧垣，世代守燧臺、替天域外圈航路點燈。九歲那年浮基老陣崩落，北院緊急撤城隊第三日才趕到，前兩日都是他在下令。北院師長看過他的令簿，破例收他入院：北院本來就收普通統御人才，不只收貴胄。 |
| 皇道專長一｜**拔點** | 看得出一個結構靠哪幾個支點撐著，也看得出哪幾個能拔、拔了之後力往哪裡走。這是九歲時在將沉的浮基上學會的。今天他用神識加一指，能拔掉同境修士的陣樁、禁點、供力線與釘在地上的雷絲。他不追幻影，專拆已經看清的供力。 |
| 皇道專長二｜**〈三息令〉** | 燧令家傳，皇道統御法。接令者自願接下他識海裡那一聲鉦響，一息聚、二息合、三息發，眾人的法力起落被壓成同一拍，七名銘紋能打出一記遠超各人的齊擊，一船人也能三息不亂。**代價由令者一人承擔**：把別人拗成同一拍的反力全回到他身上，扣的是壽元。七人三息約耗月餘，一舟三息約耗一年（工作設計）。受令者不吃虧，這正是他的道。 |
| 隨身 | 父親留下的掌大青銅燧令鉦（家傳法器，品名留白）；一本**令簿**，每次下令都記時辰、人數、息數、代價與結果。 |
| 他相信什麼 | 總得有人替大家決定，決定的人就得扛下全部的帳。天域四院設定裡的北院題「能力強的人能否代人決定」，他的回答是「能，但要付」。 |
| 他此刻想得什麼 | ①近處：承天鐘裡《百足承山》的「眾足」段。若一個令能讓眾人各扛一段，而不是令者扛全部，他就不必再燒命；當年燧垣也許不必留下六十三人。②遠處：四院選拔後，當代表隊上界槎時那個在全舟面前數息的人。 |
| 劫不在場時他在做什麼 | 每旬休沐，他自費搭舟去天域外緣一座老浮村**落雁坪**，教村人照拍子撤離。坪長荀阿蒲（化靈老嫗，工作名）不肯被人教怎麼逃，孩子們卻跟著他練。這一年裡他照北院協調值守排班，申請調閱承天鐘的鑄錄，十九卷時期隨北院獸遷見證隊南下記錄獸群。北院同屆的嬋九歌是唯一當面拒接他令的人：「我的拍子我自己數。」（只作一句旁筆，不佔她的線。） |
| 為什麼值得被打敗 | 他不是錯，而是把陸沉自己的盲點長成了一條道。陸沉後來會用〈改一筆〉、〈鵲巢印〉悄悄替人或替一座禁決定，戚鳴鉦則是公開替人決定、公開付帳。打敗他不是證明他錯，而是陸沉找到第三條路：**百足各扛一段，頭不扛全部，也不放腳各走各的**。這條路一年後在選拔場上，正好用來反制他的拔點。 |
| 他不是什麼 | 不是貴胄，不傲慢，不蠢。他的令在天域行真的救下整隊人。他不知道南荒臥底，也不知道古戰，與黎、唐、江、袁都無關。 |

## 二、故事主幹

### 2.1 卷十六　登天塔：四日與一口鐘（Y405–423，入口年尺不動）

**塔前四日（Y405–408）**：五人按各自所求報塔。陸沉要的是塔頂那份額度，也就是承天鐘的抄閱；三雷一起用就吵得他識海發疼，卷十五老師為此要他停手，這件事一直沒解決。他聽說鐘腳鑄成百足形，鐘裡的法講的是「多腳扛一物」。戚鳴鉦在報塔處排在他前面，報的也是頂層。兩人第一次說話只有一句。戚問：「你一個人？」陸沉答：「我有幾個我。」

**登塔四日（Y409–412）**，外人看不到塔裡，只看得見塔外每層窗口按人點亮的燈。院城的人整夜在看兩串燈往上爬：北院那串金色、按拍子一亮一歇；南院那串是銀、青、紫三色亂跳。

- **第一至二日**：戰、生存、神魂、悟性各層。瘋、文、生、雲各在自己的層停下，換自己要的額度（第六節照現行）。這兩日不寫陸沉對戚鳴鉦的勝負。
- **第三日｜舊試煉「帶出同伴」**（主線介面照留）：顯眼的出口能多拿獎材，卻會把另一端的照明抽掉。陸沉與封寒找到更巧的分流，陸沉以承力輔修卷替另一端撐光，**撤供能時先後用錯，被震傷**（舊法首驗與承力失敗照留）。戚鳴鉦先分配、後撤退，秩序井然，**少耗一份材料**。陸沉看見戰力以外的強（010 原意保留）。分流時陸沉摸到牆內救援派向內另開小口的舊痕，取得合法殘禁拓印玉簡；文辨得出有人改過，不能指名；黎只取正式記錄（照現行）。
  - 戚鳴鉦看清了陸沉怎麼撐光：他的供能點在哪裡，雷絲釘在哪裡。他記進令簿。
- **第四日上午｜第八層千鈞廊**：越往上，天壓越重，同境單人只能靠釘點牽絲一段一段收過去。陸沉照舊把星羅雷絲釘在廊壁，以牽絲遁前進。**戚鳴鉦兩次拔掉他剛釘下的點**，陸沉兩次墜回一段，北院令陣先出廊（戚的真本事，同場的一段壓制，不是敗）。
  - 陸沉改了一版：不再往牆上釘，讓雷身互相當支點，前一具釘住後一具，像蜈蚣一樣一節一節往上蠕。活的身子不是「點」，戚拔不到。代價是每一具的落點、承重、天壓都回到本尊識海，他鼻血滴在廊石上，趕到頂層時已經虛了。
- **第四日黃昏｜承天臺與承天鐘**：見第四節。陸沉敲響承天鐘，抄得《百足承山》「三足」段，放棄承天甲。
- **塔後（Y413–423）**：傷養八日、低檢三日照現行，文在公共推演臺覆算外架公告照現行。額度兌換時，**生排在戚鳴鉦後面，看見他換的是固元丹**：這是壽元虧損的人吃的丹。十六歲換這個做什麼？她記下，沒有問（生的醫眼，一行即止）。

### 2.2 卷十七　天域行：旗換手（Y424–447）

鐘響的人照塔規執新生旗，也就是這一年第一次四院混編任務裡新生小隊的隊首；成人護送師仍主導全案。陸沉不想要這面旗，但旗已經在他手上。

護送醫材與古器途經收古物商隊停駐的城（照現行）。地方侵害者用古器「連環枷」（工作名）把取材者和一部分新生串成一條鏈，想拿低價醫材、控制採集地。成人護送師牽住侵害者本人與古器主壓，高境沒有變弱。陸沉破開一環，壓力立刻跳到鏈上最弱的一個取材少年身上。他只好用低階承力法扛住那一環，**救得了一段，保不住全隊**（照修行所得總表）。

戚鳴鉦走到他旁邊：「把旗給我。」陸沉看了他三息，把旗交出去。

戚鳴鉦用的是同一雙拔點的眼睛，只是反過來用。他先看清侵害者真正靠什麼撐住立場：他怕北院通行見證把他的採集地主張記成非法。戚便拿見證去談，換對方先放傷者，侵害者付出的代價很小，所以肯。接著他看清連環枷哪幾環可以先鬆、按什麼節拍鬆，鏈上的力才不會擠到最弱那一環。他以〈三息令〉三人一批、三息一放，把整條鏈拆完。生在鏈尾接一個救一個；封寒是最後一批，守斷後，照戚的拍子退，沒有搶一步。

陸沉後來問：「你聽他的？」封寒：「他算得對。」

案件就在當地結束；北院留下自己的通行見證，黎換樣、文的副樣、生的病例都照現行。封寒看見戚鳴鉦每下一令，耳根就滲一線血。回程時生把固元丹的事告訴陸沉。陸沉去找戚，說在鐘裡匆匆瞥過「眾足」段幾行，可以說給他聽。戚鳴鉦拒絕了：「你看了一眼的東西，別拿來替我決定。」

**卷十七出口**：這一次把人帶回來的，主要不是陸沉更強。這一點照 010 保留，但他承認的是自己親手交出的旗，不是被動旁觀。導流小器兩次實練、四極出發的前因都照現行。

### 2.3 卷十八　越界：值守的人（Y448–461）

劫瘋為副樣用途而來，合法查閱額度不夠，便利用換庫空窗潛入西院限制庫，摸到一段限制記錄，觸動警報（照現行）。

那一夜的換庫路線，是北院協調值守排的，值守的人正是戚鳴鉦。他在外廊撞見兩人，警報已經在響，西院庫衛還要數息才到。他沒有遮掩，也沒有替他們抹去警報，只指了一條他自己排的撤離路線：

「欠我一次。」

他事後照實報「有人觸警，已撤」，沒有報名字；西院循痕查核，兩人照樣受處分，禁入與減額照現行，人情不抵罰。他放人有三個理由，全是他自己的：撤得出的人先撤，這是燧垣留在他骨子裡的反射；西院一旦封庫一個月，他申請承天鐘鑄錄的進度也會跟著卡住；他要陸沉欠他。

**他自己的這一年**：一個月後鑄錄批下來，上面只有一行：「眾足不著紙，唯在鐘。」要「眾足」段，只能再敲一次鐘。他在令簿上寫下明年報塔（日後是否敲響是他自己的故事，候選，不排進本稿年尺）。同一季，落雁坪浮基鬆了一尺。荀阿蒲沒有照他練的撤離走，而是讓全村每戶扛一段樁、分著把浮基頂回原位。他站在坪邊看了一整夜，沒有下令。這是他第一次看見不靠令的「眾足」。

劫瘋只拿到用途摘要與缺件資訊，副樣仍由文保管，封寒持用途摘要；四人自籌舟費，照常去天外四極（照現行）。陸沉把限制記錄裡古承接片「一片只承一段」的形制拿來對照自己的三足殘段（對應修行所得總表「劫將殘法與現物互證」）。他沒有讀出更多，只覺得兩件東西長得像。

### 2.4 天外四極（Y504–629）：一字不動，只多一層回讀

戚鳴鉦不在四極。不過受雷骨嶺陶千燼從陸沉的固定點逆送細雷時（事件9），讀者會記得：四個月前，也有一個人專挑他的固定點下手。陸沉這次不設固定點，是第二次被同一類對手教會同一件事，這回他自己改對了。事件5三雷並行反推相加，也可回讀成他把三足殘段用錯了地方：三條路走同一道石廊，就不是「各扛一段」。兩處都不改原文。

### 2.5 卷十九　歸山：第二對腳印（Y630–671）

**他為什麼非回去不可**：除了家，他還有一件只能在家裡學的事。塔上兩次被拔點，他知道選拔場上一定還會碰到戚鳴鉦。他要學會在任何一個點被拔掉時，人仍然站得住。天下最會「不靠點站著」的人，是他師父。

- **山1–3**：回峰、飯桌、三雷回峰仍叫老七（照現行）。
- **山4｜第一按**：岳沉淵的實打指點就是「按一下」。他把境界壓在徒弟承得住的上一格，一隻手按在陸沉肩上。鎮岳臺坐落在重脈露頭上，地是滿的，不收人往下卸的力，這正是此地的難處。陸沉照〈不崩〉沿骨節往足底卸，十息後跪下。
- **山5**：上午再跪（照現行，師門實打不計敗）；下午在圍觀人群裡看生輸第一場。
- **山6–8**：胥匠在器坊示範接環、核對江修過的行路扣（照現行）。陸沉注意到那枚環不是靠一處焊口撐住，而是靠一圈細小的咬口。他記下這一點，沒有說破，胥匠也沒有替他說。山7的指點，他把力分給幾具身子扛，可每一具承多少、有沒有晃，都回報到本尊識海。他吵得撐不住，第三十息跪下。岳沉淵只說一句：「你在數腳。」
- **山9**：只在場邊看生贏第二場。
- **山10（Y646）｜第二對腳印**：見第五節。
- **山11–15**：看生贏第三場；行路扣交還封寒；送她忘下的丹匣。霜降爐三場、知秋開鋒與三拍一字不動。
- **山16–28**：藏經閣選法屬另一條工作線，本稿不寫、不碰。舊地方、雷池三息、巡天舟照現行。南荒上報與藥價、獸遷不合的消息傳到太玄，陸沉翻開北院那份獸遷見證，署名欄寫著戚鳴鉦。下一張地圖的方向，是那個總想替別人決定的人替他們先記下來的。卷末鉤子仍落在陸沉這條線上。

## 四、書院首年的登頂：承天鐘

**他為什麼要**：卷十五起，三雷一起用就讓他識海吵到失控，老師要他停手。他手上有三種雷，卻一次只能好好用一種。《百足承山》講的是多隻腳扛一座山，他要的就是這個。這份額度也是他在三樣長用寶物與一次抄閱之間主動挑的，他挑了「能讓自己改一版」的那一樣。

**場地**：登天塔頂沒有屋頂，承天臺上天空大開。承天鐘不是吊著，是坐在一圈一百隻青銅小腳上。數百年來鐘只響過寥寥幾次，每一次都是北院令者帶陣，從撞座齊擊敲響，聲音整而沉，院城的老人聽得出那是令鐘。鐘只在天光照臺的一刻內接受敲擊；天光一走，塔頂就閉。

**對手先動**：北院令陣先到。戚鳴鉦把六名接令者排在撞座四周，自己站在陣心，鉦聲起，**第一息聚**。他算得清楚：撞座只有一個，誰佔了撞座，鐘就是誰的。這是他的第一手反制。

**陸沉怎麼贏**：他到臺上時已在戚的第一息裡，識海還吵著廊上的過載，也沒有撞座可敲。他不敲撞座，也不把三雷合成一股去轟，因為那正是讓他失控的老辦法。他看見的是那一百隻腳：每隻腳只扛自己頭上那一小塊鐘身，從不知道別的腳在做什麼，鐘卻穩穩坐著。

他讓三具身各站到一隻鐘腳旁：星羅那具以〈穿針〉沿腳上的鑄縫刺進去；兩儀那具在對面一隻腳上〈掛印〉一斥；震魂那具把〈鳴〉的雷音灌進第三隻腳。最難的是本尊這一步：他只說一個字「敲」，然後**關掉三具身回報的感覺，不再看它們**，只把手掌貼在鐘肩上，聽鐘。

三雷沒有在他身內合流，所以沒有過載；合在一起的是鐘身。**第二息**，鐘從腳底響起，三個音同時起來又不混，像三個人同說一句話。

**對手再反制**：戚鳴鉦當下變令，第二息不發，改合：六名接令者撲向六隻鐘腳去按，要把聲音從支點上拔掉。若鐘聲在開鐘前斷了，就等於沒人敲響，他第三息仍可從撞座補上。拔點用在鐘上，這一手又快又準。可鐘有一百隻腳，按住六隻，聲音仍從九十四隻往上走。鐘照響。

戚鳴鉦看懂了，**提前散令**。他若硬發第三息，六人會一齊敲在一口已經在響的鐘上，回震由他們分吃；散令則是反力全回令者。他吐了一口血，站著沒倒。

**見證**：整座院城聽見了。那不是令鐘的聲音。四院師長抬頭，塔下各層的瘋、文、雲、生都聽見；最後一層燈由銀、青、紫三色一起點亮。第二天院城有人叫他「三響」，這是陸沉在書院的第一個名號。

**贏到什麼**：

- 塔務問：「甲，還是字？」陸沉答：「字。」他放棄承天甲（長用護具，現行「少一份長用護具」照留）。
- 一炷香內，他鑽進鐘下，就著天光摸讀內壁。能辨認的有兩段：「三足」與「眾足」，其餘磨平了。他抄了「三足」。
- 出鐘時，戚鳴鉦等在臺邊，嘴角還有血：「哪一段？」「三足。」戚點頭：「你的。」陸沉當時還不知道「眾足」對他意味著什麼；勝利當下不被道德帳抵銷，重量要到卷十七才落下。

**《百足承山》三足段（工作名，品名留白）**：三隻腳各扛一段，只在所扛之物上相會，不經由彼此，也不經由頭。陸沉當下真會的是「外用」：讓各身各打一處，交給一個有結構的東西（鐘、陣、器、地脈）去合。三雷因此第一次能在同一刻出手而不炸。「內用」，也就是讓本尊不去看每一具身，他還做不到：在鐘下做到了一次，平時做不到。

## 五、歸山的高點：第二對腳印（山10，Y646）

**他要什麼**：在任何一個支點被拔掉時仍站得住。對手是戚鳴鉦的拔點，老師是岳沉淵的「按」。

**為什麼是鎮岳臺**：鎮岳臺壓在重脈露頭上，地是滿的。〈不崩〉講的是把力卸進地脈，在這裡卻卸不進去，所以人人會跪。岳沉淵那對腳印就踩在臺心，不知站了多少年，從沒挪過。

**山10的一按**：陸沉讓各身散到鎮岳臺四角，每一具與本尊之間只連一根星羅雷絲。這根絲只運力，不回報。岳沉淵的手按下來，他照樣只說一個字，不數腳。按力從他肩上分出去，本尊只留自己扛得住的那一段，承身扛最大一段，其餘幾段由雷絲送到四角，各自往重脈裡卸一小片。

一片滿的地，一處卸不進去，四處各卸一點就卸得進去，像百足走泥。可重脈是一整條脈，四處同時往下壓，脈的重量就往唯一沒被壓的地方挪：岳沉淵腳下。

大師兄沈山河是玄極重域體，第一個覺出地裡的重在走，臺面的塵沙一線線往師父腳下聚攏。岳沉淵左腳跟往後滑了半寸。

鎮岳臺上，那對老腳印後面多了一對新的。

岳沉淵收手，看了那對新腳印很久。他說話只說一次：「三成。」意思是本尊這回自己扛了三成。說完他轉身走向鎮岳崖。他輸了的時候才會去崖上坐，這是全峰都知道的。韓鐵衣推了陸沉一把：「師父失敗了。還不去陪？」

崖上，岳沉淵說：「我失敗了。陪我坐。」過了很久又說：「本尊那三成，你還在看著它。」陸沉答：「看著。」岳沉淵：「下回不看。」

柳青藤在臺邊看了沈山河一眼。這位總是一個人扛事的大師兄，盯著那對新腳印站了一整個下午（只作旁筆，沈的路由他自己走）。

**見證與名位**：鎮岳峰六位師兄姊都在場。消息當晚傳遍太玄：「老七讓師父挪了腳。」岳沉淵不許顧小滿掃掉那對腳印。生那天在丹閣，替第三場準備，不在場，也沒有人替她轉述成她的戲。

**和霜降爐、藏經閣不同型**：這不是比劍，沒有對手可打敗；也不是選法，沒有得到任何典籍或招式。它是一道修行難關，加上師門的承認：鎮岳的「承」，被徒弟改了一版。時段落在陸沉自己的指點日（山4–10）最後一天，夾在生的第二場與第三場之間，不碰她的三場，也不碰山16–28。

**所得**：

- **「承三成」**：他清楚知道本尊在滿地上能扛的那一段有多大，其餘交給各身與地。這就是現行「劫找到自己能承的一小段」，從此有了數，也有了做法。
- **「斷一足不仆」**：任何一處支點被拔，其餘照扛。這是從鐘腳到鎮岳臺學會的，一年後在選拔場上兌現。
- **留下的矛盾**：本尊仍在看那三成，所以三身用新輔法仍不一致，承身可用不等於本尊可用（現行原句照留）。真正讓本尊不看，要等十七歲列陣，自己悟出「撤去每一路都補全部」（卷二十一照現行）。

## 八、非正文樣稿：第二息

> **非正文樣稿**。只用來檢驗卷十六登頂場面能否成立，不得擴寫成正式章節。約七百字。

天光斜斜鋪滿承天臺，再過一炷香就要走了。

陸沉上臺時，鉦聲已經響過一次。北院六個人圍著撞座站成一圈，戚鳴鉦站在圈心，掌中那面小青銅鉦還在顫。第一息。

撞座沒了。

陸沉的識海還在吵。廊上那一路，三具身子的每一步都擠回他腦子裡，像有人往一個罈子裡倒三罈水。他舔到嘴唇上的血，抬頭看鐘。

鐘是坐著的，坐在一圈青銅小腳上。他數不清有幾隻，只看見每隻腳都只托著頭上一掌寬的鐘沿，腳和腳之間隔著空。沒有哪隻腳回頭看別的腳在做什麼。

他忽然想笑。

三具身子落到三隻腳旁。銀絲沿鑄縫鑽進第一隻；第二隻腳上拍下一枚印，往外一斥；第三具張口，雷音從喉底灌進青銅。

「敲。」

他只說了這一個字，然後做了一件從沒做過的事：不看它們。

那三股感覺他一股一股鬆開，像鬆開三根勒了他一整年的繩。罈子空了。他把手掌貼在鐘肩上，只聽鐘。

第二息。

鐘從腳底響起來。先是一聲很細的，接著一聲很重的，再一聲沉進骨頭裡的，可它們不是先後到的，是同時起來，又各自分明，像三個人同時說了同一句話。

圈心的戚鳴鉦臉色變了。鉦聲一轉，六個人同時撲向六隻鐘腳，掌心按下去，要把聲音從支點上掐斷。

陸沉沒有動。他聽見那六隻腳啞了，也聽見聲音從其他每一隻腳往上爬，一隻都沒停。

鐘照響。

戚鳴鉦看著那圈腳看了半息，抬手，鉦面一按，令散了。六個人鬆手跌坐。他自己往後退一步，一口血落在臺上，人沒倒。

塔下很遠的地方，院城一盞一盞亮起燈來，有人推開窗。

陸沉從鐘下鑽出來時，天光只剩一線。戚鳴鉦站在臺邊，用袖子擦嘴。

「哪一段？」

「三足。」

戚鳴鉦點點頭，好像早就知道。

「你的。」

他轉身下塔，經過陸沉時停了一下，沒有回頭：

「你也下令。」

陸沉想了想。

「我只對自己。」

## 九、和「最順手的寫法」哪裡不同

**最順手的寫法（我的推測）**：北院出一位貴胄天驕，傲而有禮；登天塔頂一對一，劫越戰越強擊敗他；他在十七、十八卷用談判與人情扳回；歸山時劫在宗門比試或鎮岳考核中勝出，或得一門法。

本稿至少在下列四項不同：

1. **主要對抗者**：宿敵不是貴胄，是墜城遺孤。他的力量是別人（〈三息令〉）加上專拆支點（拔點），代價是自己的壽元。他想要的東西和陸沉同源（同一口鐘、同一部殘法），為的是讓被他下令的人和他自己都少付一點。他在天域行是對的，而且真把人救出來。
2. **高潮的選擇與代價**：書院登頂不是正面擊倒他，而是同一場比試裡的方法之爭。陸沉的勝法是不再命令自己的身子；對手的力量則來自命令別人。陸沉贏後主動選了「三足」、放棄承天甲；代價的另一半，也就是戚燒的命，不在當下抵銷他的勝利，要到下一卷才落下。歸山高點不是打贏誰，而是讓師父的腳挪了半寸，師父說「我失敗了，陪我坐」。
3. **關係衝突**：兩人是鏡子。陸沉日後「替人決定」的盲點，在戚身上是公開的道。封寒照戚的拍子退，說「他算得對」；陸沉親手交旗；他的好意被拒：「別拿來替我決定。」這一年的帳不只是勝負，還有誰替誰決定。
4. **帳的形狀**：不是「先輸後贏、最後打臉」。宿敵在本稿贏兩次、輸一次、放人一次；選拔時先得兩分再被翻盤；航道上的債沒還成，帳本翻開到下一頁。
