# 核心人物選擇盤點（2026-11-14）

作者轉來一則外部評語，要點是：不要再增加大道概念；把核心人物放進更多人生情境，讓他們做出會傷害、改變彼此的選擇。讀者讀了幾百章，即使沒人提「變、知、捨」，也知道這幾個人會怎麼做。作者選擇「盤點並提案」。

狀態：討論區工作夾，非 Canon。

## 範圍

- **已寫正文**：卷一至卷八，看陸沉、封寒、洛生衣（生）三人。卷七、卷八正文有多少讀多少。
- **後續大綱**：卷十二以後雲行、文奕登場，加上陸沉、封寒。

## 判準：什麼算「會傷害、改變彼此的選擇」

一個人在有代價的處境裡，為自己在乎的東西做決定，結果傷到、虧待、拖累或改變了另一人。另一人因此有回應：關係、行為或信念變了，而且之後的故事記得這件事。

以下都**不算**：
- 並肩同行
- 互相幫忙
- 切磋
- 口頭爭論，但沒有後果
- 作者層的道（概念）被說出口
