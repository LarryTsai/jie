## 正文盤點

逐章讀你負責的範圍，可先讀各卷 README 與章綱抓位置，再讀相關章全文。列出：

1. **選擇相撞表**：章號｜誰選了什麼｜代價落在誰身上｜對方怎麼回應｜後文有沒有記得。只收符合 README 判準的。
2. **擦邊表**：有機會相撞、但寫成同行、幫忙、旁觀或口頭的場面。寫明為什麼沒撞起來，可以怎麼撞，例如只動一個選擇、不加新事件。
3. **人物辨識度**：讀完這段，讀者不提「變、知、捨」，能不能預測陸沉、封寒、生面對兩難會怎麼做？各舉一到兩場證據；不能預測的，說出缺口。
4. **總結**：三行內。
