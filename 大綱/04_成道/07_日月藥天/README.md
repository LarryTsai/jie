# 日月藥天

狀態：**作者批准回填（2026-10-16「接著做日月藥天回填」）；具體事件為工作選定；正文凍結**。分篇依作者裁定A（2026-10-12）。

## 定位

上無極三人同行長篇，22章45日。閱讀位置：[第21篇](../01_一炷香與至尊之年/大綱.md)第12章三宗撤賞之後、第13章守約日之前；陸沉約31歲至尊初9雷，嬋九歌斬我初，洛生衣天神前段。嬋九歌在昃晷原取得太陽傳承〈昃篇〉，經相斥、真敗與代價，自己凝出第一道日影——日月之道的起點，不是圓滿；洛生衣煉成錯時丹、錯時散並本人勝晁明取回樞片；陸沉讀古禁、兩敗一成自煉半晷、受贈昃環殼，不替兩女解題，本人無真敗。

前傳：[日月未央](../../00_全書骨架/11_日月未央/大綱.md)（下無極瀕死後至約31歲的嬋九歌獨立求道長線）。
