# 立極：天有一缺

狀態：**作者選定**（2026-10-18，[D158](../../../決策/01_決策紀錄/D158_仙生遠弧帝重九重.md)，作者選定整稿方向）；新人物、新天地、上層越境律與帝重法則仍為工作創作・候選，不升 Canon。

本篇承接[抱一：帝牆之前](../06_抱一/大綱.md)：陸沉身扛第三、第七兩重，抱一眉心落六重、沉三重。本篇是仙生遠弧最後一弧；邊外的更遠一弧日後另經作者裁定，本大綱到此為止。帝重法則、上層越境律與跨弧台帳見[帝重與帝路](../00_帝重與帝路.md)。全書正文仍凍結。

**相對時間**：約2710歲 → 約7500歲成帝，之後不設終點。
**境界**：準仙帝巔 → **仙帝**（劫中破境，三次之三）。

## 他想要什麼

- **想放下**：兩重在他身上扛了幾千年。他想把它們放下，不是丟掉。
- **想證**：極不必在中間。抱一的整套道理，靠的是「天地要有一個中心」；他要立一個不在中間的極。
- **想殺**：明夷太上那筆帳，抱一還欠著；他眉心那三重，也還沒收完。
- **想看**：每次渡完都瞥見的那個邊外。他想走到邊上，好好看一次。

## 主動的強敵

**抱一**。他是全書最有耐心的敵人：眉心有印，他就整整近五千年不出手，因為不出手，印就不落。他只等一天：陸沉破仙帝的那一天。仙帝之劫是陸沉這一生最大的劫，劫中的人不能分心。抱一只打算出一手，認落一重，換陸沉死在劫裡。他甚至把這件事說了出來，因為他知道陸沉不可能不破境。

這五千年他也沒有閒著。抱一道場的人去了每一處陸沉渡過的邊：去斷峰群量根有多深，去朔河看汐，去月影底下坐。他要知道那圈邊有多牢。

## 中段

1. **扛著兩重過日子**（約2800歲）。他在大羅記注司的萬簡庫住了一年，翻太宸承重的那八萬年。沒有日記，只有每天一道神識烙印，同一個字：「重」。八萬年，兩千九百多萬道。他翻遍了，沒有一道提到那九片。祝伯言陪他坐了一夜，什麼都沒說，臨走留下一壺茶。
2. **生衣的第三爐**（約4000歲）。生衣（仙王）在明夷開爐，煉卸重丹：讓承重的人放下重時，重不落地，而是交到下一個願意承的人手上。三爐只成一爐。陸沉要把第三重交還明夷，先問新王主。新王主是負暄老祖的首徒（樊晦之早已退位），當年被生衣穩住道基的十一人之一。她說要：「那是師父被殺時想守的東西。」這是生衣的勝場，也是明夷的。
3. **祁鈞自己來問**（約5700歲）。祁鈞在外面流浪了三千年，回來時已是準仙帝巔。他站在陸沉面前：「第七重，叔祖扛過，我扛過，你扛著。……你渡了吧。」這一次是對手先開口。陸沉以引渡第七重，付的是本源和壽。劫落完時，他的半極補全了另一半，錨在斷峰群。極的兩半，一半在路上，一半在他二十五歲掉出來的地方。
4. **這一境不破了**（約6900歲）。母親（遁一）在壽限前破至尊，這是全仙生第二次、也是最後一次明寫她「最後一刻才破」。
   - 劫雲已經壓在斷峰群丹堂頂上。門外來了一個走險路上來、斷了三根經脈的九界孩子。
   - 她讓劫雲在頭頂翻了一炷香，捲起袖子，以丹氣先把那孩子斷的脈接完，才走出門去渡劫。生衣在門口替她守爐。
   - 陸沉到的時候劫已經散了。母親坐在門檻上喝水，對他說：「這一境不破了。」不是破不了，是她不要了：丹堂裡還有人，她想把剩下的幾千年用在這裡。
   - 陸沉沒有勸。這和他自己即將走到的「改完了，也留一處不改」，是同一件事。
5. **最後一次回家**（約7480歲）。第九重就要落了。他知道成了仙帝，就再也進不了九界：仙帝自成天地，九界界壁承不住，沒有壓境這回事（[境界與能力尺度](../../../設定/04_修行/01_境界/境界與能力尺度.md)「仙帝壓境：不採」）。他以準仙帝之身最後一次壓境回去。
   - 母家的屋早換了人住，祠還在，宗訓石上宋知微的字還在。
   - 他上了一趟太玄宗。宗主杭既白、師父岳沉淵都走了幾千年，六位師兄姊也都不在了，最晚走的六師姐顧小滿也走了兩千多年。鎮岳峰如今是顧小滿的再傳弟子在守，守峰的少年不認得他，問他是誰。他說：「鎮岳峰，最小的那個。」少年翻開峰譜，在岳沉淵名下最後一行找到「陸沉」，底下什麼都沒寫。冉晴川做過一任宗主，石魁的名字在七峰歷代峰主裡（D163，工作值）。
   - 留舟島上鎮溟劍宗的分部還在，練的仍是霍驍的分潮劍。回瀾宮的水門是俞清漪的再傳弟子開的，她已走了六千多年；渡劫淵口的碑上刻著裴照川，替九弱護道的人換了好幾代；鑑月的名字記在雲行那一半契玉上，雲行遊方往邊，還沒回來（D163，工作值）。
   - 厄在伏雷坳守渡口，比他記得的老。他在坳裡坐了一夜，厄沒說話，天亮時用蹄子碰了碰他的手。
   - 他去補了一處屋頂。不是自家的，是伏家第七任擔保人伏簪（工作創作・候選）家的漏瓦。
   - 文奕（至尊，九界上限）和赤翎在錨網的網心等他，三個人吃了一頓飯。文奕還能上來，他們還會再見。
   - 寇平（至尊）不上來。他被除籍，困在九界（既定），正規界路不再放他；要走低路就得再散一回修為。他不肯：「簿在下面。」而陸沉成帝以後也下不來。這是兩人此生最後一次見面。寇平從簿房取出新簿第一頁的拓本交給他：那是太宸那道往來的原記錄，是他擔保的、他用身體壓著保住的那一頁。
     - 寇平：「字還認得出嗎？」陸沉：「認得出。」
     - 寇平：「那就拿上去。我在下面記。」
6. **第九重開始落**。最後一重是太宸承重的核心。它不往外落，而是往下落，落在帝座上。它落完那天，就是他破仙帝的日子。封寒問他要不要等一等，先把傷養好。他說：「抱一也在等。」

## 高潮：極不在中間

**節點**：第九重落向帝座 → 陸沉以渡第九重為仙帝之劫 → 抱一出手 → 一掌打在「中間」 → 極不在那裡 → 陸沉在劫中成帝 → 同境仙帝對決 → 印收完 → 抱一死 → 第九重落完 → 天冊 → 帝座。

**場景概要**：
- 陸沉坐在帝座前的臺階上，不坐座上，引第九重。仙帝之劫與餘壓同落，劫雲從大羅一路壓到九界上空，全三十二天都抬頭看。
- 抱一出手，只出一手，認落一重。仙帝一擊正中陸沉胸口的劫核，所有修士的極都在那裡。
- 那裡沒有極。他的極從一開始就不在身上，而在一圈渡過、生了根的邊上：斷峰群、朔河、蝕月那一片天、第六重落下的大羅外緣、第七重的錨、第八重的劫骨、九界十一處小錨與長亭新錨，一條一條路連著。抱一這幾千年派人量過每一處邊有多牢，卻沒想到它們連成了一個圈。這一掌打穿了一具準仙帝的肉身，打不到一個圈。
- 劫核旁「往來」那一位亮起，圈合上，仙帝境成。帝牆他沒有越過，他是在劫裡變成了牆的另一邊。
- 同境了。抱一剛才那一手讓眉心落了一重，第七重。他不能停：停下來，就是看著陸沉渡完第九重，天地從此不必再收。他打。
  - 陸沉九雷合一，星天王域收成極域，雙刃一斬「承」、一留縫，〈劫數〉一重一重落。
  - 抱一的帝域是「抱」，一切出手都被收回中心，九雷每一道打出去，都被往回拉。
  - 第八重落下時，有隙在帝域上開了一道縫，抱一收不回那道縫。第九重落下，印熄。
- 抱一倒在帝座下方三寸，他的極所在的地方。他最後看了一眼那圈邊。（作者裁定二：同境斬殺。）
- 第九重落完。帝路最後一條線熄了。

**關鍵台詞**：
- 抱一（一掌打空）：「你的極在哪裡？」陸沉：「在外面。在你一直想收回來的地方。」
- 抱一臨死：「沒有大羅，它們不能存在。」陸沉：「它們存在了八萬年。你沒去看。」
- 萬簡庫：陸沉把寇平的拓本放在天冊正本旁，以第十雷記著的那一道往來對上原記錄。記注令祝伯言親手開庫。這是補記，不是竄改：寇平是原記錄的擔保人，拓本由他親手交出。祝伯言：「正本即真。」陸沉：「那就讓它真一次。」天冊上多了一行：**是我。**太宸的筆意，寇平的擔保，陸沉的雷記下。八萬年的帳落在帳上，罪也落在帳上，一分沒少。
- 帝座：天冊在仙帝境那一欄記下他的名字。帝位那一欄要由在世的同境者承認，而此刻三十二天沒有第二位在世的大羅仙帝（其他仙帝境待定），那一欄就空著。他在座上坐了十息，站起來。祝伯言：「帝位那一欄，要我替誰留著？」陸沉：「這張椅子讓人坐了八萬年。往後不用了。」他走出大羅，往邊上去。
- **門外的人**（2026-10-23 讀者斷層修，候選・待作者看）。引第九重之前，他把藏嶽匣最裡那片「勿來」取出來，這回由他發給她；她照做了，第一次。劫雲壓了三十二天，生衣（仙王）坐在大羅南門外一塊石上，沒有進他的劫域一步。他走出門，她先看他的手，再看胸口那個被抱一打穿、還在一寸一寸重塑的洞，不問疼不疼，只說：「回來了。」「回來了。」她遞的是一枚自己再煉的丹，不卸重，只穩肉身重塑的頭一年。兩人一起往斷峰群走；到丹堂門口她停下：「邊上是你們兩個的。」他和封寒往外走，她在丹堂替母親看爐。

## 尾聲：邊上，與一塊浮石

- **看與不看**。封寒陪他走到斷峰群最外面的那塊碎峰，這裡已經是天地之邊。陸沉往外看，那個每次渡完都瞥見的東西還在，比弧三時又大了一些。封寒的看潮之眼能看得比他更遠。他看了一會兒，在要看清之前閉上了眼睛：「外面有東西，比邊老。我沒看它的臉。」陸沉沒有問為什麼。總要有一個人不知道。（封寒失去看潮之眼留給更遠；邊外是什麼，本大綱不回答。）
- **還有一處**。陸沉說：「還有一處。」眭無恙走出去的方向，綦毋煙留著的陣心，都在那邊。（邊外的第六弧日後另經作者裁定。）
- **浮石**（約7800歲）。數百年後，留舟島陸家祠一個十六歲的孩子，陸家旁支，列陣境，第一次經錨走正式界路上界。他背著一個泥封小匣，在斷峰群丹堂問了三天路，才找到陸沉；老夫人先讓他吃了三頓飯。匣裡是一塊浮石：「祠裡說，替你留了一塊。」父親當年泥封的那一塊，他在第28篇時已在家裡打開過，這一塊是新的。陸家那一脈每年浮石季，都替一個再也回不去的人留一塊。現在他在上面，下面的人一直上來。他不改這個習慣，一筆都不改。
  - 生衣（2026-10-23 讀者斷層修，候選・待作者看）先接過那個匣看了封口：留舟島的海泥，和她十幾歲飛升前替他裹那塊浮石用的，是同一路藥修手法。她沒問是誰教的，也沒拆，交到他手上：「封得還行。」

## 所得與改變，以及成帝的代價

- **境界**：仙帝（約7500歲，工作值）。極名候選「**邊極**」：極不立在中心，立在天地之邊，是一圈渡過的劫與往來的路。這本身就是對歸一的回答：無極不再是失去中心的仙土，它們的邊上有了一個極。
- **帝位**：天冊只記仙帝境，帝位一欄空著，等在世的同境者承認；他不求，也不坐。帝座從此不承重。仙帝境與帝位分開記，照現行。
- **天有一缺**：九重最後熄七、承二。明夷承第三重，是一家人自己選的；司空絳扛第四重，是一個人自己選的，要扛一輩子。天地之邊因此有一段，永遠由一個人親手守著。《天有一缺》（武學譜終局候選道術）在此落成：缺口不是缺陷，是一個人自己選的位置。陸沉每隔千年去看他一次，兩人不說話，喝一壺。
- **道心**：從「既然還能更好，為什麼不改」，走到「改完了，也留一處不改」。
- **成帝的代價**：
  1. **他從此不能入九界**。仙帝不能壓境。留舟島、祠、伏雷坳、九界十一錨，他只能從天幕外看。
  2. **寇平此生不能再見**。寇平除籍，正規界路不再放他，要走低路就得再散一回修為，他不肯；他成帝下不去。往來只剩第十雷記著的新簿：寇平每天在簿上記的那一行，他聽得見，人卻見不到。
  3. **厄不上來**（既定），伏雷坳那一夜就是最後一面。
  4. **肉身與壽元**：劫中被仙帝一擊打穿肉身，重塑以年計；與抱一一戰燒去萬年級壽元（仙帝百萬年級工作值，交核）。
  5. **殺仙帝的餘波**：抱一道場的仙土失極，緩緩散成無極。嵇元朗帶還本派留下來護那片土，這是他自己的選擇。
  6. **這回換他等**（2026-10-23 讀者斷層修，候選・待作者看）：生衣仍能壓境回九界行醫，他不能陪。她說過「你去哪我不一定跟，回來一定見」；現在倒過來，她下九界，他在天幕外等她回來。她每次回來先發「尚安」，帶一撮留舟島的海泥上來；他不托她替自己見寇平——那是他自己認的帳。
- **更遠**：他站在邊上往外看，說「還有一處」。本大綱到此為止。
