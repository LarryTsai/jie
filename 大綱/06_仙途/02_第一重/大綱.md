# 第一重：斷峰定

狀態：**作者選定**（2026-10-18，[D158](../../../決策/01_決策紀錄/D158_仙生遠弧帝重九重.md)，作者選定整稿方向）；新人物、新天地、上層越境律與帝重法則仍為工作創作・候選，不升 Canon。

本篇承接[海往天上走](../01_海往天上走/大綱.md)：陸沉 M40 返抵家園後第二個月，第一重帝重開始從帝座飄出。帝落那夜（首弧 M4）他在逆雷海看雨往下下，此後帝座殘力撐了約三年；天裂的方向，就是他在天海倒影裡看過的那塊黑（帝落為既成事實，不補大羅現場）。下一篇[萬法合卷大會](../08_萬法合卷大會/大綱.md)寫斷峰定後一季的晝衡海合卷與入關；第二重與宗政拂接[這次在下面等：朔河不沉](../03_朔河不沉/大綱.md)。帝重法則、上層越境律與跨弧台帳見[帝重與帝路](../00_帝重與帝路.md)。全書正文仍凍結。

**相對時間**：海往天上走 M40 返抵家園（約41歲，與首弧逐月對齊，見[帝重與帝路](../00_帝重與帝路.md)待核第22條）→ 約60歲。
**境界**：真仙前段 → 閉關後真仙中段（不在劫中破境）。

## 他想要什麼

返家後第二個月，大羅方向的天裂了一道縫。第一重帝重像一顆不發光的黑星，從帝座往外飄，飄了四年。白榆推演它會落在上無極斷峰群：那裡是古界路路身的出口，封寒和蒼梧剛在那裡立了同命契，二十五歲的陸沉也是從那面牆裡掉出來的。

他要那一重，有三個理由同時成立，沒有一個是任務：
- **想看**：他身上帶著太宸最後那句「是我」。他想知道一個人扛的是什麼，扛到最後只剩這兩個字。
- **想護**：斷峰群一沉，路身就斷了。九界通往上無極唯一不經錨陣的路沒了，封寒那一紙約也沒地方守了。
- **想爭**：全仙域的天驕都往斷峰群走：鈞天劍宗的駱霜、太素的邴初、量天臺的顧星遲、雲洲的燕停舟；斷峰群在地的謝照棠、祝暘守著自家的峰，誰也不讓。他從十四歲起，沒讓過一樣他想要的東西。

黑星飄的那四年裡，43–44歲第76／78／79列（石聞川、車遠、馮碧）照原來源發生，不挪、不代打。

## 主動的強敵

- **祁鈞**（帝裔，太宸姪孫，真仙巔，九千歲；祁氏宗親照待決3-17，工作創作・候選）。祁家看著叔祖扛到心魔停滯、壽盡而死。祁鈞把仙王壓了三千年不破，就等這一天：在真仙巔承下第一重，以重為王域之心成王，王域生來就是帝域的一角。「叔祖扛死了。這回由祁家人扛，扛得比他好。」他手上有兩份別人沒有的情報：白榆的落點推演，和管曜八簿裡陸沉十九年的出手紀錄。
- **尹懷素**（太宸帝座近侍，仙王；既有人物，本弧行動為工作創作）。侍奉太宸數萬年，最想讓陛下臨終前「修好些什麼」。陛下最後把罪認在一本下界的簿子上，他受不了這件事變成下面的人手裡的帳本。他要抹掉「是我」，讓帝座乾乾淨淨交給下一個人。他有一半是對的：太宸的罪該由太宸擔，不該變成別人的把柄。
- **司空絳**（紫垣天驕，既有人物；本弧真仙前段）。不二之土的觀星廊上，他用〈定垣〉釘過陸沉一次。「路只一個人走」：他要一個人接住第一重，不靠紫垣。
- **背景**：止戈道場的**宗政拂**（仙王巔；工作創作・候選；壽元見弧二）只出場一次，埋弧二。

## 中段

1. **新簿上的第一行**（九界）。尹懷素不肯親自下界：仙王壓境要進壓境簿、要人擔保，帝座近侍的名字一上簿就露了。他派一名天然列陣的遞書吏，帶著帝座近侍親手封的對齊烙印，走正規界路進九界，要把新簿第一道往來「對齊」成別的字。這是玄殿官史用了幾萬年的手藝。
   - 寇平守簿，看出墨下有人在改筆。他領印日那天修為被剪到列陣以下，對方是天然列陣。他知道自己打不贏，沒有喊人，用身體壓住簿頁，在斷階渡口的簿房裡和刺客打了半炷香。
   - 他的力不到列陣，見識仍是真仙的見識，刺客每一手都被他先封住，他只求拖。最後一記烙印反震，裂了他的道基。簿保住了，第一行只糊了一筆。
   - 陸沉在上界收到寇平的字：「簿在。字糊了一點，認得出。」信末還有一行：「剪掉的那些，我想自己再走一遍。」
   - **改局**：三天後他就知道這筆帳的主人是誰。對方是仙王，他是真仙前段。他記下，不動。寇平的重修從這一行字開始。
   - **藥圃那一夜**（落前兩月；2026-10-23 讀者斷層修，候選・待作者看）。他往斷峰群去之前，自己繞到生衣的藥圃。她在收逆根，沒停手。她不給他保命的丹，跟立海那回一樣，只問：「那一重，你要接還是要渡？」「還不知道。我想先看它有多重。」她把最後一株逆根放進匣裡：「看完回來告訴我它有多重。」他答應了。這句話他到第88列扛起兩重那天才答得出來。
2. **最好的位子先被佔了**（落前四十日）。祁鈞照推演搶下落點正下方的主峰，以祁家備了三千年的承重陣，把整座峰釘成一隻手掌。陸沉到時，主峰已沒有位子。他去了路身出口，就是他二十五歲掉出來的那面牆。**改局**：他讀出路身本身就是一條通往邊的舊路，重若落在峰上，劫勢會順著路身往外走。他不要接住，他要讓劫往他這邊落。
3. **帶著舊卷宗的人**（同一旬）。祁鈞去求婁直。婁直自請受審後在析木等判，三年卷宗還在手上。他仍是真仙中段（工作值），等判這些年境界沒退也沒進，仍比真仙前段的陸沉高一段；祁鈞是真仙巔，站在他面前仍收著仙威，因為要買的是他的眼。他只說一段話：「我研究他三年，殺到的是上一版。你要上一版，我可以賣你；這一版，我也沒有。」祁鈞買了。這份卷宗後來真的奏效一次。（「上一版」類台詞全仙生兩次之一，另一次見中段4。）
4. **觀星廊那一格，這次換人釘**（落前十日）。司空絳在斷峰群外緣攔他，天驕要先分出誰有資格站進落點。
   - 〈定垣〉落下，把他釘進星圖一格，和不二之土一模一樣。司空絳特地用同樣的手法，要看陸沉這些年怎麼解。
   - 陸沉不拆那一格。他以兩儀把格子本身當成軌，以無間把格子兩端接到同一處：格子還在，他在格子裡，格子在動。
   - 司空絳第二手〈換垣〉要把打出去的雷換位，換回來的卻是他自己的星。三十息後，星垣碎了一角，他退出斷峰群。
   - 司空絳：「你這一版，是不二之後才有的。」陸沉：「是今天早上。」
   - 司空絳臨走帶走一片帝重落軌的星片，比所有人早一步量出第二重的方向。這是舊敵的實得，埋弧二。
   - 同一旬的外緣，其他天驕也在分位次。燕停舟在雲脈一端敲鐘：至尊之年她說過「半季之後再比」，後來兩場一勝一和，那一句一直沒兌現，一拖十幾年，這回兩人都是真仙前段。她先放雲，他在雲裡一步一步走到鐘前，一指按住鐘口，鐘沒再響。她收鐘：「這次是你的。」駱霜與邴初各在一座斷峰上拿到落點外圍的一席；顧星遲把量出來的落點圖攤在石上，誰都可以看，謝照棠、祝暘看完各自回峰。
5. **老王要先把這裡壓下去**（落前三日）。宗政拂來了。他不搶重，他要在重落之前，把斷峰群連同路身一起封出去，讓帝重落進空處，換其餘的邊少退一寸。「八萬年前，我們封了九片，換來八萬年。今天封一片，換來的不會更少。」
   - 真仙擋不住仙王。擋住他的是封寒和蒼梧，這是**同伴主場**。
   - 蒼梧站上路身，動用舊約：在界路上，約力壓過個人修為（既定），宗政拂的封落到路上就鬆。舊約禁文第一次在白天亮滿整條路身。
   - 青璃站在封寒身後的路身上。宗政拂的封近於本源，她的相界碰不得，她也不碰；她只把路上行路人被封力震散的五行一個一個撥回原位，把人接下路身。她是真一，擋不了仙王，她接人。
   - 封寒背對禁文，面朝宗政拂，鐧橫在胸前，一眼也沒有回頭。他守這條路以來，每一枚禁文都親手摸過。宗政拂的封要釘進路身，只能釘在其中一枚上，而那一枚他驗過。他一鐧斷了它的結構層（「鐧拆規則門，限親手驗過的點」，照主角群強度重構裁定三）。
   - 封鬆開了。宗政拂看著封寒的背：「約。好。八萬年前，我也守過約。」他收了手。臨走時他看了陸沉一眼，像在量一件東西。

## 高潮：斷峰定

**節點**：帝重落地 → 祁鈞承下，世界先替祁鈞作證 → 陸沉以觸、引引動懸劫 → 劫雲同壓兩人 → 婁直的卷宗奏效一次 → 陸沉當場改一版 → 尹懷素出手抹第十雷 → 陸沉承下，落〈劫數〉 → 渡完。

**場景概要**：
- 第一重落在祁鈞的主峰。祁鈞承下了，三千年的準備是真的：承重陣把那一團黑全收進他的道基，人沉了三尺，峰沒有沉。斷峰群外緣原本往界外滑的那一片停住了。全場天驕看著帝路第一條線的末端落在祁鈞身上。**這一刻，世界作證的是祁鈞。**
- 陸沉在路身出口雙指點天。他不搶祁鈞道基裡的東西，他觸的是那道懸了八萬年的餘壓：以劫痕的觸、引引動它，讓它不是被接住，而是一重一重往下落完。劫落在路身，也落在主峰；劫雲不認主客，兩人同壓。
- 祁鈞在劫裡第一手就用了婁直的卷宗。他專打陸沉命圖上那條死軌（第22篇長亭天那具雷身被滅後永不復原的空軌），以承重陣把帝重的壓力往那條空軌導。這一計真的奏效：陸沉右半身的九雷輪轉斷了一拍，咳出一口雷血。
- 陸沉當場改一版。他不再把壓力往命圖裡收，而是從第十雷那一位「往來」放出去：壓力從劫核旁那條路經過他，落向路身，而路身是舊界路，本來就通往邊。死軌沒有補，也不需要補。卷宗裡最準的那一頁，打在一個他不再用來承重的地方。
- 承的人在劫裡只會越扛越重，渡的人卻越渡越輕。第七重劫雲落下時，祁鈞的承重陣碎了。陸沉一記天譴・逐星把他從主峰上打下去，第一重被劫雲從祁鈞的道基裡拔出來，回到劫中。
- 尹懷素此時現身。他不是為祁鈞來的，是為第十雷：一道仙王的對齊烙印直取陸沉劫核旁那一位，要把「是我」從劫裡抹掉。陸沉沒有閃，用胸口接下（〈劫數〉「落」要先承下一次真招），雙指點在尹懷素眉心，落三重。尹懷素是仙王，陸沉是真仙；但從此尹懷素每出一次手，劫雲落一重。他退了。
- 第九重劫雲落完。那一重帝重化成一截灰白的劫骨，落在路身出口他的腳邊。斷峰群那片八萬年來一直在虛空裡緩緩漂移的碎峰，停了。

**關鍵台詞**：
- 祁鈞（承下時）：「叔祖，這一重，我替你接了。」
- 陸沉（引劫前，對祁鈞）：「劫要落了。不想在裡面的，現在走。」祁鈞沒走。
- 劫後，陸沉對倒在主峰下的祁鈞：「你叔祖最後一句話在我這裡。你要聽嗎？」祁鈞：「那是祁家的話，不是你的。」陸沉：「我知道。所以先問你。」祁鈞轉身走了。
- 長離界舟的航誌，那一天多了三個字：**斷峰定**。

## 所得與改變

- **境界**：沒有在劫中破境。以引渡付的是本源與壽元：劫後他鬢角白了一縷，再沒黑回來。劫後調息一月，赴晝衡海合卷一季（[萬法合卷大會](../08_萬法合卷大會/大綱.md)），散會後回路身出口，斷峰定後約一百三十日在那裡入關，閉關約十年，把「讓壓力穿過自己」磨成自己的法，出關時已是真仙中段。這一段是修行，不是高潮。
- **帶進關的傷**：右半身（死軌側）九雷同時作主時仍斷半拍，帶進關；十年閉關與引渡之法一併磨回，出關時已收，不帶進弧二〈朔河不沉〉（仙生線2026-10-22定；大會回填新增，工作選定）。
- **帶進關的器**：三料換口護爐架（普通法器，大會本人實器），只是一件實物與一套說法，不是閉關的答案（工作選定）。
- **法寶材料**：第一截劫骨，世上唯一一截已經落完的封口餘壓。
- **〈劫數〉**：尹懷素眉心三重。仙域開始流傳：「近侍額頭那道印是誰的？」
- **道心**：他第一次在別人只會扛的地方讀出「這東西可以落完」，也第一次感覺到太宸八萬年每天扛著的那份重量。而他只扛了幾十息。
- **改下一弧**：仙域知道了「渡」這個字。宗政拂、祁家、紫垣都改了打法：下一重，不能讓他靠近。
- **同伴**：寇平道基有裂，在九界重修；他的壽元仍是真仙所得（見[帝重與帝路](../00_帝重與帝路.md)待核第2條）。封寒、蒼梧在斷峰群守路，路從此有人走；青璃與封寒同住斷峰群，真一後段（鏽一重的代價留著），守路時接路上的人。生衣在自己的藥圃，天神後段。（2026-10-24 萬法合卷重構，候選・待作者看）斷峰定後她先隨他赴晝衡海一季，N+130 他入關那天清晨才回藥圃。斷峰定後，駱霜回鈞天劍宗，邴初帶走外圍一席的見識，燕停舟回雲洲養鐘，顧星遲留在斷峰群續測路身漂移；各人往後的去向見[帝重與帝路](../00_帝重與帝路.md)〈同代去向〉。
