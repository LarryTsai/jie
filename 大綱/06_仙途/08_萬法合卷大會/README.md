# 萬法合卷大會

狀態：**工作選定（作者裁定落點；2026-10-22 依 D152 回填）**。作者裁定的是落點（長亭後約45–49歲、斷峰定之後）、跨壁只開具名例外（[D160](../../../決策/01_決策紀錄/D160_跨壁具名例外.md)）與九界金丹維持豁免（[作者裁定](../../../待整理/仙道文明與萬法合卷/作者裁定.md)一至三）；具體事件、新人物、晝衡海地理、器與卷事制度為工作創作・候選，作者未逐場批准，不升 Canon。回填依 [D152](../../../決策/01_決策紀錄/D152_候選補綱授權.md)候選補綱授權。正文凍結。

## 定位

仙途獨立篇，閱讀位置在[第一重：斷峰定](../02_第一重/大綱.md)之後、[這次在下面等：朔河不沉](../03_朔河不沉/大綱.md)之前：斷峰定後一季，陸沉約45.6–45.9歲（工作值），真仙前段、帶著斷峰定的殘損赴上無極晝衡海三爐灣十二年一次的萬法合卷，會期72日，散會後回斷峰群路身出口入關。封寒、雲行、文奕、生衣同行，各有自己的題目。

主題呼應仙途「要不要有人替別人扛」，但不使用帝重機制：晝衡海三座走爐坊萬年不裂，靠的是換口與換班。邴初的單肺先扛住四拍、第五拍裂；第二坊三十六口由化靈爐工、四位同伴與陸沉一班一班換過去，陸沉的右手抬到一半又放下。女天驕符湄在護爐主卷試真勝陸沉，奚箴以實測贏第一論次，駱霜、寧枕微、魏班各有自己的一場。（2026-10-24 依[獨立比較](../../../待整理/萬法合卷重構_20261024/獨立比較.md)合併重構；重構前原稿見[原稿備份](../../../待整理/萬法合卷重構_20261024/原稿備份.md)。）
