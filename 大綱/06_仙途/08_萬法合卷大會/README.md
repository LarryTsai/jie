# 萬法合卷大會

狀態：**工作選定（作者裁定落點；2026-10-22 依 D152 回填）**。作者裁定的是落點（長亭後約45–49歲、斷峰定之後）、跨壁只開具名例外（[D160](../../../決策/01_決策紀錄/D160_跨壁具名例外.md)）與九界金丹維持豁免（[作者裁定](../../../待整理/仙道文明與萬法合卷/作者裁定.md)一至三）；具體事件、新人物、晝衡海地理、器與卷事制度為工作創作・候選，作者未逐場批准，不升 Canon。回填依 [D152](../../../決策/01_決策紀錄/D152_候選補綱授權.md)候選補綱授權。正文凍結。

## 定位

仙途獨立篇，閱讀位置在[第一重：斷峰定](../02_第一重/大綱.md)之後、[這次在下面等：朔河不沉](../03_朔河不沉/大綱.md)之前：斷峰定後一季，陸沉約45.6–45.9歲（工作值），真仙前段、帶著斷峰定的殘損赴上無極晝衡海三爐灣十二年一次的萬法合卷，會期72日，散會後回斷峰群路身出口入關。封寒、雲行、文奕同行，各有自己的題目。

這是一篇與帝重、古戰、帝室全無關係的上界生活與技藝長篇：女天驕韶照微在技藝評比與同至尊禁台真勝，陸沉的拆禁新法在試爐裡真敗、在練功房驗出一版、在護標局同場翻盤，帶走一件普通法器與一套合法外卷。十三類仙道文明題材在本篇全部有生活場景。
