## 一、全書一句話

> 一個從小被說「你在下面等」的少年，把天地一路改到最後，才明白：在下面等他的人，一直在替他留東西。

## 二、全書的四條線

| 線 | 起點 | 終點 |
|---|---|---|
| **劫的道（變）** | 少年願望「不要再在下面等」；起始目標「讓家裡不再說沒辦法」；盲點：替人決定 | 第 28 篇看見天地的缺，**沒有改**；父親泥封的浮石：「我們替你留了一塊」 |
| **真相（同一隻手）** | 溫棠之死、照水尺空白、殞星色相被扣奸細罪 | 公主案、長子案、下沉（墊天）全部收束；太宸說「是我」 |
| **時鐘（第二次校正）** | 第 20 篇公布第一次校正日期 | 第 28 篇立錨之日就是校正之日 |
| **生** | 第 1 篇丹閣短碼「尚安／需藥／勿來」 | 第 15 篇他知道；第 23 篇她救他；第 28 篇「現在可以沉一點了」 |

同行四人各自的一題貫穿全書：瘋「把劍練到分毫不差」→《唯一》與終生不讀舊約；雲「沒有目標」→ 選燈；文「證明家學沒有失傳」→ 立錨；生「證明先師的路」→ 自己的醫道。

## 三、卷

每卷：一句話、這一卷的問題、主要走向（起 → 轉 → 合）、人物推進、武學與雷、留給下一卷的因。

### 卷一　雷季以前（第 1–2 篇）

- **一句話**：體弱的守祠之子，帶著指骨入閣，第一次替別人引雷。
- **問題**：「現在不行……以後呢？」
- **走向**：留舟島陸家、七歲浮石季「你在下面等」、偷改藥方 → 十歲地裂、劫厄成形、入太玄閣、星羅（看見）→ 替閣老引盡殘雷、入宗、認識封寒與生 → 百宗大比放棄第一名去封舊戰痕，「劫」之名傳開；兩儀（選路）、震魂（看見別人：封寒在外圍，兩人都沒問名字）。
- **人物**：封寒「把劍練到分毫不差」；生在丹閣訂短碼；池杳的幻境他從沒贏過。
- **留下**：名聲帶他進五域集結。

### 卷二　五域與書院（第 3–4 篇）

- **一句話**：第一次真的輸，第一次有人死在他追不到的地方。
- **問題**：「先看原陣」——前人的答案，要先懂，才能改。
- **走向**：中神州集結，四人第一次同框（觀古門古禁區）→ 五域決勝輸給俞清漪；認識溫棠 → 書院生活、雲行與文奕第一次夜談；南荒藥潮霧中取千相（看錯：先信了假影）→ 篇末溫棠命牌熄。
- **人物**：文奕「證明文家禁學沒有失傳」；雲行「沒有目標」；俞清漪線起。
- **留下**：他要追死者沒找到的遺跡。

### 卷三　溫棠的路（第 5–7 篇）

- **一句話**：替一個死人把她沒走完的路走完，走到九界大比當眾。
- **問題**：「她一個人走那條路，是因為她在找——」他答不上。
- **走向**：白老九的禁標殘片 → 救援派醫修洞府，醫禁、選擇門、文奕受傷、兩人大吵；九界金丹丹方；生接不回他，玉壺接回（別人的經脈）→ 千溪原雙岸：汛前取流光（重構），汛期取照水尺；後裔祭陣見指骨即亮 → 九界大比（S）：寇平被剪；照塵挑走雲行；雲行以〈攏天〉勝一場卻不要名次，赫連晴「你從沒真的想要過」。
- **人物**：生的起始目標第一次撞牆；文奕「這不是禁，是祭」。
- **留下**：傷後三凳並坐；他去攔第二天要下低路的人。

### 卷四　落潮一年（第 8 篇）

- **一句話**：第一次聖土，一年生死不明。
- **問題**：「仙庭」為什麼是罪名？
- **走向**：被捲入落潮 → 公主案前段、維達探查記、塔姆林與「劫」之名、茉瑞德「他沒要」→ 殞星（付帳）→ 回來，未滿二十飛升。
- **人物**：生七日一問；俞清漪來留舟島找他，早他一個月回南荒（錯過）；文奕第一個選擇留在九界；雲行代他去陸家。
- **留下**：正規飛升的落點是「九弱」。

### 卷五　九弱（第 9–11 篇）

- **一句話**：上了天，才知道自己在上面是最低的那一層。
- **問題**：誰在抹九界的痕跡？
- **走向**：下無極九弱日常、沉船陣錄 → 拿自己釣魚：壓境回鄉，照水尺空白＝遮蔽術輪廓；上門的是朔河的人；母親「這張是我的」→ 碎錦原：只救下一半；第一次聽見「歸一」；留一具雷身壓脈。
- **人物**：雲行「有幾個是你勸留的？」；放下空手羅漢。
- **留下**：岑越暴露，必須親手滅口。

### 卷六　雙汐與渡劫淵（第 12–14 篇）

- **一句話**：贏了一場破術之戰，換來奸細罪。
- **問題**：要活下去，路只剩哪一條？
- **走向**：雙汐（S）：藏曜＝照水尺空白，溫棠結案；殞星色相暴露，被扣奸細罪；裴照川「那節骨是長子的」→ 程序未決：生探出別人的經脈；接護道 → 渡劫淵：鑑月與雲行立同命契；取歸墟（被劫破）；封寒「這次別碰」；自選路身，掉進上無極。
- **留下**：候審。

### 卷七　九界金丹（第 15 篇）

- **一句話**：為救她，他把八個自己送進八界。
- **問題**：「下次先問」——他沒問，帳落在她身上。
- **走向**：候審中閉關熔太虛，沒先問（越權）→ 封界餘禁困住九弱雜役，生自己選擇進去，中封傷 → 拒絕玉壺，八身入八界取材，七歲那塊浮石成了故鄉一味 → 九界金丹救回她；八道撕痕；聞人錦賣拓印，「同一隻手」成立；重破天神。
- **人物**：**他差不多知道了，不說**；雲行守續命雷三月沒睡；蒼梧起同行。
- **武學**：首次越質變點正面取勝最早可在本卷。
- **留下**：候審擱下，延到第 26 篇。

### 卷八　同代與決裂（第 16–18 篇）

- **一句話**：同代都上來了，最近的那個人卻走了。
- **問題**：瞞，是保護還是背叛？
- **走向**：上界同代檢核點（群像）；太宸批註「九弱，先撫」；越裳口供「找一個雷修」→ 送塔姆林回縫海，碧梧擔保凍結十年，抄送落到封寒手上 → 封寒違「這次別碰」，長離焚誌讀殮錄；拆「陸家祖先有份」；兩人決裂。
- **人物**：封寒轉鐧（第 18 篇），駱霜第一個說「對」；雲行回西極見雲紓（放下千燈為候選）。
- **留下**：長子一側已讀到盡頭，公主案只在聖土。

### 卷九　見劫（第 19 篇）

- **一句話**：走高路回到聖土，第一次看見劫，沒有吞。
- **問題**：「這回你收不收？」
- **走向**：高路五年序段 → 冒籍案，「主戰派合謀」成為新錯誤答案 → 接穗與私稱；厄的第一次意願 → 見劫（S），沒吞 → 聖土以單契與異物記收他。
- **人物**：封寒自鑄問底鐧；青璃「我的事，別替我查」。

### 卷十　聖土長住（第 20 篇）

- **一句話**：在聖土住了二十七年，雷第一次在他身上共一核。
- **問題**：那道光是誰？
- **走向**（四段）：前段兩匣人之戰，《天譴》誕生（二雷）→ 中段屋頂之帳，天譴・三相 → 中後驗魂錄半句「像他的光，又不是他」；九霄（先問）入位，天譴・四極 → 後段九霄映出渡口那道光不是長子；歸席公布第一次校正日期；父親在九界壽終，他回不去。
- **人物**：生拒絕祿安（他不在場）；茉瑞德、菲昂、翁蒂娜。
- **留下**：時鐘公開；高路回程的拉力。

### 卷十一　登頂與墜落（第 21–22 篇）

- **一句話**：爬到最高處，被專打自己剛學會的東西。
- **問題**：分身是他選的，帳也是他的。
- **走向**：一炷香潛入大羅外緣，雷瞳被逼出；擔保附冊的「抹除空白」；蒼梧依舊約離開；父親死訊 → 斷階頂上（S）：婁直專打天譴的裂，天譴碎、反衝回他身上；道基碎裂；帝天骨架（太宸是在選）；第十雷成胎；墜落。
- **人物**：雲行選燈、守一息、第一次撥珠；長亭天雷身被滅時文奕在陣核旁。

### 卷十二　從底部重爬（第 23–24 篇）

- **一句話**：雜工看天驕，從列陣以下爬回至尊。
- **問題**：舊名頂不回去，剩下什麼是他自己的？
- **走向**：驤鳴雜工、壓境不出天譴；**「勿來」，生照樣來**，自扛錨印、剪死節點、留下「勿沉」；赤翎死在炸池；第二次校正公開：整個長亭天 → 碎錦原（S）：天譴・萬象、天譴・還重第一次大勝；**九雷合一第一次**；拿回至尊；「同一隻手」拆成三件。
- **人物**：文奕的燼熱了；雲行鏽一重、赫連晴再遇放下；聞人錦以天道誓承認。

### 卷十三　證據與入極（第 25–26 篇）

- **一句話**：證據齊了，帶著證據走進大羅。
- **問題**：長子案收在哪裡？
- **走向**：玄闕祖脈：三刻共振、分段命令原句、荀恆推演；文奕與封寒、奚箴下太玄閣地下讀出「九界自己造過鎖」（陸沉不在場）→ 入極：神識決鬥加發掘；長子遺念；奸細罪撤銷、合籍；天譴・諸天（候選）。
- **留下**：公主案只剩聖土那一側。

### 卷十四　第三份探查記（第 27 篇）

- **一句話**：第三次聖土，全程不解封，照樣打。
- **問題**：「仙庭一心」是真的嗎？
- **走向**：壓境入聖土（劫、封寒、生）→ 封寒在魂冊前第一次自己停下（止一層、再一次）→ 拆「仙庭一心」；第三份探查記 → 窗口落在校正日期前夕。九界那一端：赤翎回來，與文奕立約（他第一次在推完之前做決定）。
- **留下**：兩個公開時鐘落在同一天。

### 卷十五　長亭（第 28 篇）

- **一句話**：守錨之日就是校正之日。
- **走向**：總點名與祠堂 → 守錨之戰：雲行背燈全開；封寒鐧守北段、駱霜劍守南段；文奕在九界立錨、翁蒂娜在聖土驗錨 → **十雷一體以胎入局**，打出全書最高一擊 → 錨成立，第十雷生成，單獨亮起不殺，有人看見回家的路 → 太宸「是我」 → 封寒在同命契上寫「終生不讀舊約」→ 他看見天地的缺，沒有改 → 「勿沉」歸還，「現在可以沉一點了」→ 打開父親的泥封小匣 → 四人對酒。
