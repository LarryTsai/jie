## 一、全書一句話

> 一個從小被說「你在下面等」的少年，把天地一路改到最後，才明白：在下面等他的人，一直在替他留東西。

## 二、全書的四條線

| 線 | 起點 | 終點 |
|---|---|---|
| **劫的道（變）** | 少年願望「不要再在下面等」；起始目標「讓家裡不再說沒辦法」；盲點：替人決定 | 第 28 篇看見天地的缺，有能力改，**沒有改**（作者定保住）；「下次先問」；父親泥封的浮石：「我們替你留了一塊」 |
| **真相（同一隻手）** | 溫棠之死、照水尺空白、界屑、殞星色相被扣奸細罪 | 公主案、長子案收束；下沉（墊天，作者層）；太宸說「是我」 |
| **時鐘（校正）** | 第 20 篇中後段公布第一次校正日期 | 第 28 篇立錨之日就是第二次校正之日 |
| **生** | 第 1 篇丹閣短碼「尚安／需藥／勿來」 | 第 15 篇他知道；第 23 篇她救他、留下「勿沉」；第 28 篇「現在可以沉一點了」 |

### 五段長弧（作者定，2026-10-03）

| 階段 | 卷 | 陸沉的位置 |
|---|---|---|
| 少年 | 1–3 | 我想改變我做不到的事 |
| 離鄉 | 4–6 | 世界比我想像的大，而且有人在改世界 |
| 上界 | 7–9 | 我開始有能力改，但開始傷到身邊的人 |
| 成道 | 10–12 | 我的方法本身出了問題 |
| 入極 | 13–15 | 不是能不能改，而是什麼該改、誰有權決定 |

貫穿全書的不是雷、不是陰謀，而是陸沉「總想把事情變好」的優點，如何一路長成他的錯，再長成他的道。主幹：第 15 篇沒問 → 第 18 篇瞞的帳 → 第 22 篇分身與自己的選擇反噬 → 第 23 篇生留下「勿沉」→ 第 28 篇下次先問。

### 兩條紅線（作者定，2026-10-03）

1. **雲行後半一定要從「會捨」走到「主動背」**：不能一直寫「他又放下了」。第 22 篇選燈是真正的轉折：以前是「我能得到，但我不要」；之後是「我本來可以走，但這次我選擇留下來背」。第 28 篇背燈全開、第二次撥珠是他的完成態。
2. **陸沉終局一定要讓「有能力改、卻選擇先問」壓過單純的最高戰力展示**：十雷一體的最高一擊之後，「看見天地的缺，沒有改」（作者定保住）才是「變」的完成。不是被馴服，是成熟：少年是「看見不好 → 改」；最後是「看見不同 → 理解 → 問 → 再決定要不要改」。

同行四人各自的一題：瘋「把劍練到分毫不差」→《唯一》，終生不讀舊約；雲「沒有目標」→ 選燈；文「證明家學沒有失傳」→ 立錨；生「證明先師的路」→ 自己的醫道。

### 卷與卷之間的四個鉤（必寫；作者定凍結，2026-10-03）

1. **界屑**：第 7 篇落地他沒上交 → 第 14 篇吞入本源 → 第 21 篇拿不走 → 第 26 篇歸還、撤罪。
2. **善意之瞞**：第 8 篇他否認縫口的名字 → 第 17 篇抄送「瞞了他十五年」→ 第 18 篇決裂 → 第 19 篇和好。
3. **封過兩次**：第 4 篇巡天舟巡過、雷池靜三息 → 第 26 篇太宸「巡天舟過你們那一界那天，我沒有看」，拆「太宸是受害者」。
4. **裴照川那句話**：第 7 篇說到一半 → 第 28 篇說完：「……找一條九界自己能走的路。」

四鉤各司其職：界屑是**物證鉤**，每一次意義都變；善意之瞞是**人物鉤**（他最大的錯不是打不贏，是「我替你決定什麼真相你應該知道」）；封過兩次是**世界真相鉤**（讀者二十多篇後才懂那三息不是氣氛描寫）；裴照川那句話是**主題鉤**：最後不是陸沉替九界找到路，而是九界自己能走的路。

## 三、卷

每卷：一句話、這一卷的問題、主要走向、人物推進、留給下一卷的因。

### 卷一　雷季以前（第 1–2 篇）

- **一句話**：體弱的守祠之子，帶著指骨入閣，第一次替別人引雷。
- **問題**：「現在不行……以後呢？」
- **走向**：留舟島陸家，家規「等一個說要回來的人」；七歲浮石季「你在下面等」、偷改藥方 → 十歲地裂，劫厄成形；入太玄閣、星羅（看見）；以身引雷守閣，宋知微在樑上刻「這裡」；太玄閣古測脈陣「祖脈第七節缺一刻」→ 替閣老引盡殘雷、入宗、認識封寒與生；取得太玄命圖 → 東溟百宗會場放棄第一名去封舊戰痕，「劫」之名傳開；兩儀（選路）、震魂（看見別人：封寒在外圍，兩人都沒問名字）。
- **人物**：封寒「把劍練到分毫不差」，霧鐘島立下「不許有人瞞我」；生在丹閣訂短碼；池杳的幻境他從沒贏過。
- **留下**：名聲帶他進五域集結。

### 卷二　五域與書院（第 3–4 篇）

- **一句話**：第一次真的輸，第一次有人死在他追不到的地方。
- **問題**：「先看原陣」：前人的答案，要先懂，才能改。
- **走向**：中神州集結，四人第一次同框（觀古門古禁區）→ 五域決勝輸給俞清漪；認識溫棠 → 天域書院生活；雲行與文奕第一次夜談；寧枕微、聞人錦初遇；巡天舟巡過，雷池靜了三息；玉壺山百年義診的名字第一次出現；南荒藥潮霧中取千相（看錯：先信了假影）→ 篇末溫棠命牌熄。
- **人物**：文奕「證明文家禁學沒有失傳」；雲行「沒有目標」；俞清漪線起。
- **留下**：他要追死者沒找到的遺跡。

### 卷三　溫棠的路（第 5–7 篇）

- **一句話**：替一個死人把她沒走完的路走完，走到九界大比當眾。
- **問題**：**前人沒走完的路，活人還要不要接著走？**（承卷二「先看原陣」：卷二是先理解，卷三是理解以後要不要接著走。懸念「她一個人走那條路，是因為她在找——」他答不上，保留為卷內事件）
- **走向**：白老九的禁標殘片 → 救援派醫修洞府：醫禁、選擇門、文奕受傷、兩人大吵；遺念「撤令早於停兵，我們留下」；九界金丹丹方；生接不回他，玉壺接回（別人的經脈）→ 千溪原雙岸：汛前取流光（重構），汛期取照水尺；裴照川越界；晁不疑玉符；後裔祭陣見指骨即亮 → 九界大比（S）：寇平被剪，墨乙開價；照塵挑走雲行，「不是不救，是救不得」；裴照川挾持寇平，那句話說到一半；**陸沉強啟受損的陣，界屑落地，他沒上交**；雲行以〈攏天〉勝一場卻不要名次，赫連晴「你從沒真的想要過」。
- **人物**：生的起始目標第一次撞牆；文奕「這不是禁，是祭」。
- **留下**：傷後三凳並坐；他去攔第二天要下低路的人。

### 卷四　落潮一年（第 8 篇）

- **一句話**：第一次聖土，一年生死不明。
- **問題**：**有些真相不說，是不是也是在保護人？**（他否認縫口的名字：當下完全合理，十五年後證明傷人。「仙庭」為什麼是罪名退為卷內謎題）
- **走向**：被捲入落潮 → 公主案前段、維達探查記；厄在縫口第一次出力；塔姆林與「劫」之名；**他否認縫口的名字（善意之瞞）**；德維第一次問「收不收」；茉瑞德「他沒要」→ 殞星（付帳）→ 回來，未滿二十飛升。
- **人物**：生七日一問；俞清漪來留舟島找他，早他一個月回南荒（錯過）；文奕與封寒合推「窗口」，文奕第一個選擇留在九界；雲行代他去陸家。
- **留下**：正規飛升的落點是「九弱」。

### 卷五　九弱（第 9–11 篇）

- **一句話**：上了天，才知道自己在上面是最低的那一層。
- **問題**：誰在抹九界的痕跡？
- **走向**：下無極九弱日常；沉船陣錄（晁不疑玉符接上）；當原主家人的面二選一，**選了那家人，讓沉船線索曝光** → 拿自己釣魚：壓境回鄉，照水尺空白＝遮蔽術輪廓；上門的是朔河的人；族譜同一天被挖去一行；母親「這張是我的」→ 碎錦原：朔河線指向岑越；玄闕軍陣封鎖、岑越擅自升級；只救下一半；第一次聽見「歸一」；驗魂師求問帖流入契書市；留一具雷身壓脈。
- **人物**：雲行「有幾個是你勸留的？」，放下空手羅漢；裴照川、寇平各自的處境。
- **留下**：岑越擅自升級失手，必須親手滅口。

### 卷六　雙汐與渡劫淵（第 12–14 篇）

- **一句話**：贏了一場破術之戰，換來奸細罪。
- **問題**：**被世界判定為錯的人，要照世界給的路活嗎？**（自選路身不是逃亡：你說只有這幾條路？那我自己選一條）
- **走向**：雙汐（S）：藏曜＝照水尺空白，溫棠結案；商應璋立天道誓；殞星色相暴露，被扣奸細罪；裴照川「那節骨是長子的」→ 程序未決：生探出別人的經脈；裴照川判刑役三十年；察變署判指骨與厄為災源；答應護道 → 渡劫淵：鑑月與雲行立同命契；取歸墟（被劫破）；界屑吞入本源，察變署記下；除籍立案「合印即收押」；封寒「這次別碰」；蒼梧「你從哪裡進來的？」；文奕在九界那一端送他進路身；自選路身，掉進上無極斷峰群。
- **留下**：被押回合印、候審。

### 卷七　九界金丹（第 15 篇）

- **一句話**：為救她，他把八個自己送進八界。
- **問題**：「下次先問」：他沒問，帳落在她身上。
- **走向**：候審中閉關熔太虛，沒先問（越權）；太虛雷殘影：長子為傷兵停下的那道光 → 封界餘禁困住九弱雜役，生自己選擇進去，中封傷 → 拒絕玉壺，八身入八界取材，七歲那塊浮石成了故鄉一味；霜明「西天最先暗下去的是長亭天」→ 九界金丹救回她；八道撕痕；聞人錦賣拓印，「同一隻手」成立；蒼梧起同行、在場量界；重破天神。
- **人物**：**他差不多知道了，不說**；雲行守續命雷三月沒睡。
- **武學**：首次越質變點正面取勝，最早可在本卷。
- **留下**：候審擱下，延到第 26 篇。

### 卷八　同代與決裂（第 16–18 篇）

- **一句話**：同代都上來了，最近的那個人卻走了。
- **問題**：瞞，是保護還是背叛？
- **走向**：上界同代檢核點（群像）：邴初「你我其實是一種人」；嵇元朗講衰退並承認代價；池杳照出他「替人決定」；太宸批註「九弱，先撫」；篇末越裳口供「找一個雷修」→ 送塔姆林回縫海；越裳記「包庇」；碧梧被記過、擔保額凍結十年；**抄送落到封寒手上** → 封寒違「這次別碰」，長離焚誌讀殮錄：帝批「吾兒」、缺一指；閔家航誌玉冊（改期令、船是弟弟要的）；閔庚年熔玉，封寒留下照顧他；拆「陸家祖先有份」；鞘鳴告別劍道；兩人決裂。
- **人物**：封寒轉鐧（第 18 篇），駱霜第一個說「對」；雲行回西極見雲紓。
- **留下**：長子一側已讀到盡頭，公主案只在聖土。

### 卷九　見劫（第 19 篇）

- **一句話**：兩人和好，一起走高路回聖土，第一次看見劫，沒有吞。
- **問題**：「這回你收不收？」
- **走向**：上界五年序段：瓊華講法會；封寒自鑄問底鐧；封寒把礦谷那一夜的記憶交給檀翁 → **和好**：「若你還要去那邊，算我一個」／「我帶你去看我瞞你的東西」→ 走高路，帶封寒同去 → 塔姆林重逢；翁蒂娜「有一條不靠潮的路」；冒籍案，「主戰派合謀」成為新錯誤答案 → 接穗與私稱；厄的第一次意願 → 見劫（S），沒吞 → 聖土以單契與異物記收他〔候選〕。
- **人物**：青璃「我的事，別替我查」。

### 卷十　聖土長住（第 20 篇）

- **一句話**：在聖土住了二十七年，雷第一次在他身上共一核。
- **問題**：**看見，等於看懂了嗎？**（如果我一直認錯了，我現在相信的還剩多少是真的？回扣卷一星羅「看見」；暗弧：看見 → 看原陣 → 理解前人 → 看見不等於看懂 → 先問。「那道光是誰」退為卷內謎題）
- **走向**（四段）：
  - **前段**：兩匣人之戰，《天譴》誕生（二雷，逐星）→ 屋頂之帳，天譴・三相（年歲〔候選〕）。
  - **中段**（約 50–60）：驗魂錄半句「像他的光，又不是他」。
  - **中後段**（約 60）：歸席公布第一次校正日期。
  - **後段**（68–70）：至尊；主祭開門；九霄（先問）入位，天譴・四極；九霄映出渡口那道光不是長子；河階露出；厄的雷色與九霄同色，他起疑。
- **人物**：父親在九界壽終，**他當時不知道**；生拒絕祿安（他不在場）；茉瑞德、菲昂、翁蒂娜。
- **留下**：時鐘公開；高路回程的拉力。

### 卷十一　登頂與墜落（第 21–22 篇）

- **一句話**：爬到最高處，被專打自己剛學會的東西。
- **問題**：分身是他選的，帳也是他的。
- **走向**：封寒同行離開聖土；察覺拉力後選擇順勢進去，一炷香潛入大羅外緣；雷瞳被逼出；無名老仙「讀吧，讀完就走」；界屑拿不走；擔保附冊的「抹除空白」；蒼梧依舊約離開，無人替他量界；回到上界才收到父親死訊 → 斷階頂上（S）：分兩具雷身下界（長亭天守陣核、望歸合印）；婁直專打天譴的裂，天譴碎、反衝回他身上；道基碎裂；厄伴命，融回指骨（全書唯一一次）；帝天骨架（太宸是在選）；第十雷成胎；長亭天雷身被滅時文奕在陣核旁；墜落。
- **人物**：**雲行選燈（他的真正轉折：本來可以走，這次選擇留下來背）**，照塵重傷，雲行拒絕玉壺、守一息，鑑月替燈陣亡者記名；守燈期間第一次撥珠；青璃守撥濟九弱的孩子，第一個不屬於封寒的選擇。

### 卷十二　從底部重爬（第 23–24 篇）

- **一句話**：雜工看天驕，從列陣以下爬回至尊。
- **問題**：舊名頂不回去，剩下什麼是他自己的？
- **紅線（作者定）**：**絕不能寫成傳統廢功重修爽文。**武力只是外層，真正重新長出來的是「陸沉這個人」：以前重爬靠「我能改」，這次開始學「我不能替你決定」。邴初「三天接好道基」→「差在我會先問」比天譴・萬象、九雷合一、太古星天圖都重要。
- **走向**：驤鳴雜工，壓境不出天譴；**「勿來」，生照樣來**，自扛錨印、剪死節點、留下「勿沉」；玉壺揭開（無聲谷古騎軍骨上的取痕與他身上的接痕同源）；劫藏成形；畫下帝天骨架；孩子的禁標「怪人」；赤翎死在炸池，文奕的燼熱了；第二次校正公開：整個長亭天 → 邴初「三天接好道基」→「差在我會先問」；第一次與玉壺正面動手；未濟一系給新籍；碎錦原（S）：天譴・萬象，天譴・還重第一次大勝；太古星天圖第一次觸規，悟出〈天有一缺〉；九雷合一〔候選：不早於本卷〕；拿回至尊；與望歸雷身合身；「同一隻手」拆成三件；嵇元朗決裂；商應璋上門結盟。
- **人物**：雲行鏽一重、赫連晴再遇，想要了還放下；聞人錦當面承認「我只是想讓你需要我」。
- **留下**：強接派要毀荀恆推演盤。

### 卷十三　證據與入極（第 25–26 篇）

- **一句話**：證據齊了，帶著證據走進大羅。
- **問題**：**真相已經證明了，然後呢？**（封寒一路追到了答案，陸沉拿到了證據，世界沒有因此自動變好；劫與瘋的道在這裡第一次真正碰撞）
- **走向**：玄闕祖脈：在三十二天破真仙；商應璋開放祖脈；三刻共振、分段命令原句；三方合擊（陸沉、封寒、嵇元朗）；〈折門〉追擊護證；申屠靜伏根曝光，記注官案收束；拆「此乃量劫」「歸一就是修復」；荀恆推演；文奕、封寒、奚箴下太玄閣地下讀出「九界自己造過鎖」（陸沉不在場）→ 入極：歸還界屑（帝道場、未濟擔保）；巫峙；接木與私稱兩把鑰開副本匣；**匣禁「封過兩次」，太宸「巡天舟過你們那一界那天，我沒有看」，拆「太宸是受害者」**；神識決鬥加發掘；長子遺念；奸細罪撤銷、合籍；婁直自請受審；抱一「沒有大羅，它們不能存在」；閔庚年帶玉冊上大羅；蒼梧「這次你走門」；天譴・諸天〔候選〕。
- **留下**：公主案只剩聖土那一側。

### 卷十四　第三份探查記（第 27 篇）

- **一句話**：第三次聖土，全程不解封，照樣打。
- **問題**：「仙庭一心」是真的嗎？
- **走向**：出發前在長亭天以殞星劈回赤翎，她第一個認出的是文奕；回瀾宮俞清漪開水路，「還活著？」「你都沒死，我急什麼。」→ 壓境入聖土（劫、封寒、生）；生與茉瑞德交換方子 → 記門石柱、主祭親開特許、封門派；記門魔核映出渡口那一夜；果林三訪；鑑月的辨名信物；殘魂只問一次 → 封寒在魂冊前第一次自己停下，止一層（再一次第 23–25 篇已學會、已用，兩者在此成為走向《唯一》的最後兩步）→ 拆「仙庭一心」；第三份探查記 → 窗口落在校正日期前夕。九界那一端：文奕與赤翎立約，他第一次在推完之前做決定。
- **人物**：青璃第一次先開口留封寒。
- **留下**：兩個公開時鐘落在同一天。

### 卷十五　長亭（第 28 篇）

- **一句話**：守錨之日就是校正之日。
- **走向**：總點名與祠堂；宗訓石是宋知微的字 → 守錨之戰：雲行背燈全開、第二次撥珠；封寒鐧守北段、駱霜劍守南段；生與寧枕微守被牽動的人；文奕在九界立錨、翁蒂娜在聖土驗錨 → **十雷一體以胎入局**，打出全書最高一擊 → 錨成立，第十雷生成，單獨亮起不殺，只記下第一次往來 → 裴照川把那句話說完：「……找一條九界自己能走的路。」→ 管曜「沒有大羅，它們不能存在」，陸沉「萬年以後呢？」→ 九界以己名簽約、紀錄雙存 → 太宸「是我」 → 斷命樓刺殺寇平，裴照川擋下；寇平做九界新簿第一位擔保人，擔保陸沉回家 → **他看見天地的缺，有能力改，沒有改，先問（作者定；比十雷一體的最高一擊更重）** → 生「現在可以沉一點了」→ 打開父親的泥封小匣 → 四人對酒；伏雷坳三讀。
- **篇後**：封寒回上界路過斷峰群路身出口，與蒼梧立同命契，寫下「終生不讀舊約」（陸沉不在場）。
- **尾聲**：厄自己去守伏雷坳；一個少年掉出來，他問：「你從哪裡進來的？」——「下次先問。」辛未雨改判；玉壺白鶴繞一圈就走。
