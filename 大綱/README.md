## 命名

- 資料夾一律「兩位數序號＋底線＋名稱」，序號是在上一層的排列順序：五段為 `01_少年` 至 `05_入極`，全書骨架為 `00_全書骨架`；段內卷篇依總覽先後編 `01`、`02`……
- 待補且只有總稿條目的篇保留序號、不建資料夾；有故事稿後依序號建夾，其他資料夾不改號。
- 卷號、篇號、年齡不放資料夾名，寫在檔內標題與總覽。
- 資料夾說明檔一律 `README.md`；故事資料夾主檔一律 `大綱.md`；其他檔用主題名（如 `裁定與接口.md`）。
- 檔名不放日期、版本號、狀態字（v1.7、20261009、候選、工作稿、高優先等）。
- 例外：`全書故事順序總覽.md` 保留檔名作頂層入口。

## 與討論區的分工

- 本區只放現行版本：不放競稿、任務單、審查、修訂往返、試寫樣稿、已撤或被取代的舊稿。
- 發展與審查都在 `待整理/`（討論區）進行；作者裁定或選定後，由主 Agent 整理進本區，同一次提交同步總覽與決策紀錄。原稿留在討論區追溯。
- 作者豁免的八身救生五檔在[九界金丹](03_崛起/02_九界金丹/README.md)，內容不審不改；2026-10-09 作者同意只改連結路徑。
- 卷一統一（PM 討論區）結案前不動；其成果已併入卷一大綱。
- 狀態只用五種：作者選定、工作選定、候選、待補、撤用；以總覽為準，本區檔案整理不等於批准候選。

## 不可被整理改掉的作者裁定

九界奪冠後領通行印、自主分路，陸沉先返宗、太玄閣與家鄉，返鄉清算後追上界仇敵，受傷墜入聖土；第一次聖土先求回三十二天，因尋路遇修行機緣；第六雷殞星在首訪，第九雷九霄在第二訪遁一，火蓮反向啟發雷丸不提前。三次聖土目的不同；曉有自己的行動，不是所有奇遇的操縱者；歷史真相分階段揭露。大綱完成並經作者宣布前不寫正文。
