# 地區路線圖

狀態：**草稿 v0.1**（2026-10-03），PM 起草。作者指示：「先知道大概會在哪些地區轉移、何時轉移；中間在該地區停留的時間，就是要放入這些節奏：地區內有什麼宗門、有什麼遺跡、有什麼禁區、有什麼生活、賭石、拍賣場，或是主線、或是附線。」

用法：本檔先定**路線**（第一節）；每個地區再有一張**盤點卡**（第三節），列出該地區可用的宗門、遺跡、禁區、生活、坊市（賭石、拍賣、黑市）、主線節點、附線（長線副線 L／E）。卷／篇大綱寫某地區的停留期間時，從盤點卡取材排節奏，不另造。地區名、年齡、篇號照[主線路線總稿](../設定/05_故事主線與揭露/主線路線總稿.md) v3 與[全書大綱](全書大綱.md) v0.4（D093）。

**觀察**：
- 前段（段 1–7，卷一至卷十一）全在九界長亭天，地區密度最高、停留最長；作者要的「我真的跟著這個人活過很多地方」主要在這裡長。
- 大地區共七種：長亭天（東溟、中神州、南荒、西極、千溪原等）、聖土、下無極、上無極、其他八界、大羅、驤鳴。每種至少停留兩次以上的（長亭天、聖土、下無極、上無極），盤點卡要寫得最厚：會回來的地方，讀者才認得。

## 二、停留期的節奏公式

每一段停留，從該地區盤點卡裡取：

| 類 | 例 |
|---|---|
| 宗門 | 太玄宗七峰、東溟三大宗、文家、大衍宗、九鄉會…… |
| 遺跡 | 仙王遺跡（D092）、古戰遺跡、修士遺痕 |
| 禁區 | 觀古門古禁區、西極古路外緣古禁區、渡劫淵、聖土沉域…… |
| 生活 | 坊市、節令、宗門日常、喝酒、師兄弟、戀愛萌芽 |
| 坊市 | 賭石坊、拍賣場、黑市、靈鳶攤、契書市 |
| 主線 | 該段的主線節點（總稿） |
| 附線 | 長線副線 L1–L12、E1–E16；羅蘋與福爾摩斯 |

規則：主線節點只是骨架；停留期的大部分篇幅由其餘六類填，守「不連續四篇比賽」。
