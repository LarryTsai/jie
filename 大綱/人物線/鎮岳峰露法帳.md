## 二、岳沉淵（峰主）

### 本性→衍生

| 層 | 內容 |
|---|---|
| **本性** | **ISTJ（速記）**：最內斂。沉默、守規矩、記得每個人的傷與來歷；相信「先站穩，再談其他」。他自己曾幾乎崩毀、無人可救，所以一生只做一件事：讓被判了死刑的身體重新站起來 |
| **修行** | 不借山勢、不控重力，只修「承」：承壓、承痛、承法、承劫（古嶽鎮身體）。路是用命換來的，所以只傳「站穩、承痛、不崩」；他卡的不是境界，是只會這一套 |
| **招式** | 沒有招。他的厲害長在「站」「坐」「看」「按一下」裡：腳下石裂人不動、一眼數傷、按肩池平。不崩、承道是他的樣子，不是他放出去的東西 |
| **行事** | 決定一次說完，不說第二遍；大事當前越不動。失敗時不解釋，去崖上坐著。弟子性命優先於宗門顏面 |
| **待人** | 關心＝記得、陪坐、看碗、簽帳；拒絕＝不說話；說話一句頂十句。不說安慰的空話，也不會問心事（延誤心結） |
| **親疏** | 與沈山河最像（也最像在彼此身上看見自己的毛病：都不說痛）；最留意陸行烈；對韓鐵衣話最少；對顧小滿最寬鬆；對陸沉不特別優待，只數他的傷。**會成為他敵人的**：把弟子當耗材、拿人命換顏面的人（宗門內外都算） |

### 峰主的平常樣子

他不是只在主考、壓場時出現的人。平常的他：

- **話只說一次**〔既有〕：同一件事不說第二遍；弟子都知道「師父說過了」比「師父說了」重。
- **吃飯最後放筷**〔D097·寫法〕：他吃得慢，吃完不起身，先把桌上每個人的碗看一遍：誰剩了、剩在哪一側。誰傷了，他從碗裡就知道。陸沉燙傷顧小滿後睡不著那幾天（第 33 章前後）的一頓晚飯，看見他在自己的碗前停了一下；第 72 章他床邊那一夜之後才懂。
