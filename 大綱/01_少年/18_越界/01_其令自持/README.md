本段：Y448–451（272 日表第 53–56 日），十六歲，銘紋，三雷三身。卷十七見證貼出、院錄多了「未受令」，陸沉照北院軍中舊例遞狀，單身挑韋執圭的令陣；北院演令場一炷香，陣先贏、韋護著最慢的褚禾、劫讀拍、韋換令「隨我」；香八分劫學韋把三身壓成一拍而互搶，然後放手——承身「站著」、星羅身「去敲鼓」，本尊照《承流試錄》刪去一行後的法子先接後撤，鼓響；院錄改「其令自持」、北院陣門題名、得閱覽一旬與例金；本尊胸肩鈍傷，當晚對著錯頁想：這次沒併。
