# 02_庫門

本段：Y452–461（272 日表第 57–66 日），十六歲，銘紋，三雷三身。破陣贏來的一旬，陸沉與封寒天天坐在北院封路記錄前追文奕副樣的用途，只讀到「依五域協議，已停止使用」；文奕不開全庫；陸沉看見西院限制庫換庫時禁有半盞茶是鬆的。換庫那夜劫瘋摸進去，只拼出「停用之後，還有人試著接」，警報響；夜巡的韋在庫門停了一口氣，不封門，「欠我一次」，巡簿照實寫。處分照下，禁入西院限制庫、課務額度減一份，閱覽不收回；文奕在廊下聽陸沉背記錄、對副樣推缺件，推到一半「後面要的東西不在庫裡」；三個人手上，誰也沒有一張完整的圖。
