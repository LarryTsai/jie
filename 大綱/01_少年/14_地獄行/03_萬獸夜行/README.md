本段：X15–27（Y273–285）。先問牠；封寒輸一條路、贏一個測法，「再一次」；烏苒與賀凌川先贏，陸沉三息拉穿沙七刺的沙幕、把席讓封同坐；雲首敗、自練、扳回、真勝，笑得比兩個朋友還大聲；看完天幕；淺泉旁只有一支獸群避開泥地，識海回震似戰葬。
