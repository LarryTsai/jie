本段：X28–39（Y286–297）。冰裡一只鐘有許多年代的影；聞舟扣牌是怕，雲承認自己上回沒來；宋明川自己贏回問劍；晏雀拒凍砂，程燁燒掉半份砂；四份碎片縮到伏聲坳，相向腳印、白花留著；門前各有所求。
