# 01_天域未散

> 此資料夾收錄卷十四〈西極萬獸原與地獄行〉第 01-01–03 章章綱（共 3 章，全卷第 1–3 章）。

本段：U1–8（Y221–228，石山前）＋X1–3（Y259–261）。冠軍選來的承力卷翻到底，沒有第三雷的去處；文奕兩份洩口記錄只有一份寫「獸過而地不鳴」；陸追低震、封要驗無聲、雲想回家喝酒給朋友看天幕。八日覆診申核，南東兩院批准延期、西院不能代批，三人放棄首輪共用場、自付藥費；雲劃掉多住的幾日，封把回程標記放進行囊，陸拿剩下的錢買舟票。先往倒懸石山（第 18 列）。回到天域，文與季蓁各換半頁，只給兩處位置與退路標記讀法。
