本段：X4–14（Y262–272）。商舟七日到渡營；掌櫃先擺三隻杯再翻帳冊，舊信說岑郁的銅牌回來了；夜市買錯「月下開」，換一次採靈同行與三份辨藥；雲紓談完燈油才收鹽，叫哥哥先擦瓶口；舉風原上獸影在雲腹往南走，雲想登中間風脊，白角少女烏苒也要那一段。
