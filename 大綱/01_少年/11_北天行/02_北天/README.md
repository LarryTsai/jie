本段：Y112–136。北天岸上等了五天，封寒天天看那道天幕，幕從中間掀開時他第一個走進去；照夜洲的夕陽從山腹裡升起，夜裡群山的燈像倒立的星河；天幕一開一合，梯田的水跟著灌滿又退回山腹，星羅身拿自己的丹換了一包靈種。開殿那天葉迴燼先取走赤爐膽，他沒搶；破臺下的黑銀裡，兩道雷各留一片夜空，誰也不吞誰。夕陽升到臺頂、古臺整層倒轉那一刻，要先廢人的周棲岸撲上來，冷槽邊一個照面，兩雷分路把他連人帶柱打到翻上去那一層。他取出完整的玄胎銀母核，捨下外板，從臺脊撤，一個北天少年拿短杵扛住錯開的山脊讓人過去；照夜洲照舊合幕，封寒看著它合上。
