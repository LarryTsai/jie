# 北天行・往中神州

工作選定（2026-10-23 九分提升第三批融合，未逐章作者批准）。十五歲（Y36–115）、化靈末二雷三身，卷九東溟天城碼頭出發到 Y116 抵中神州東境；原第11列北天行與第12列往中神州（卷十）合成一篇，照旅程先後寫；故事順序依[全書總覽](../../全書故事順序總覽.md)。資料夾序號不改原卷號。

[大綱](大綱.md)是霧舟（首帆索七帆索三合擊退、鍔娘霧裡撤隊）、北天照夜洲（黑銀、赤爐膽、冷槽）、晚市城、器坊一試到抵東境的唯一完整來源。[卷十](../12_往中神州/大綱.md)只留旅程接口短檔。[無妄與有隙](../../00_全書骨架/04_無妄與有隙/大綱.md)管理後期揭價、宗師、珍材冒險、成品與升器。

北天天幕、物權與回程遵D028；暖谷、霧海、索七、晚市城等新人物、地方與八十日工作日程未經作者逐項批准。鍔娘仍是尊者，不與劫交手。劫不在此取新雷、破銘紋或發現古戰真相。刻紋師授與基礎試片不等於少年立即成靈器師。
