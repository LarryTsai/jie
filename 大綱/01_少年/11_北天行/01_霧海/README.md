本段：Y97–111，往北的兩桅普通舟穿霧海十五日。測流殘器綁上舟舷、碰到水才第一次抖；霧比水沉，這一路的命是帆給的。每夜承身吊進霧裡壓骨，他對封寒說「一炷香」，封寒自己掛了一夜驗出是錯。第五日黑帆吸風，他認出斷繩符，封寒一刀推正舟頭；星羅身上帆索三合打碎首帆索七的陣盤，霧深處趴著懸賞牆上那個尊者，一句「這一船，不要了」撤走船團；他把一捆繩丟給落海的皮老鴉，另一頭拴在拘舟環上。當夜封寒下霧，霧底站著一片沉船林，承身「再撐一口氣」散形三日，索七被擒；「我欠你一口氣。」「記著。」承身散形那三天，本尊一個人頂兩份差，直到它重凝回來。出霧那天，封寒說起哥哥，第一次把那顆能補識海的丹說出口。
