本段：大比前最後幾日，合石分到的小礦一夜一夜養紋，第一刀遇裂材，那一片他不刻，剩下的切成有限試板；開幕前一夜（Y204）回到酒樓窗席，封寒、雲行、文奕在，鄰桌的話一句句傳回他耳裡——誰的丹最穩、誰把誰喝倒，屠蒼那一場被傳成「劫三息」，他沒糾正；同一夜名單在城心石壁一個一個亮起，登天渡開。Y205 登天，下一卷。
