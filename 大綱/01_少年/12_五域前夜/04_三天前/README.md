本段：陸沉從借月山回城（Y195），城裡傳的是南榮氏「文家禁學已失傳」和萬禁會那張籤，文奕的門已經關了兩天；神識隔門讀得到裡面的禁，他沒讀。Y197 守禁局：南榮玦開場直取陣口，計真奏效，觀臺以為文家又要輸；第六步，腳下那一面先亮，他沒有第七步；文主動劃開最穩一筆救協作者、拓下第一張南榮反噬紋；「三天前改的」；奚箴與文吵到天亮；「文三天」。陸沉在觀臺，不出手。
