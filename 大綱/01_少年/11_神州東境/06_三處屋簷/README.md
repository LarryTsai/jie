本段：比試後第三夜，他想看那段古式到底要多少，不急著往身上刻，先在唯一那塊試板上照原樣走一遍——紋亮出板外半尺、院裡防潮禁跟著顫，板裂得比他想的大，裂線正落在兩儀一換的那一處，他才看懂照抄那一筆在自己身上是反的；文奕只講原用途：「你身上那筆，得是你的。」他把港口的星羅身叫回禁都，三具身各要各的順序，骨不到誰也不准下筆；照鎮岳的規矩，骨先鑄到承得住才下筆——承身先到，星羅身次日，本尊差一夜。那一夜葛負山追到客寮後院掏出一枚丹：「我那年就是沒等這一夜。」他還回去：「骨頭追不上來的。你就是追的那一個。」他等了。次夜三處同一息落下最後一筆，三處屋簷的防潮禁一齊亮了一下。首驗，整塊板上唯一沒斷的是他自己那一線。自由期末一夜，他在夜市拿殼換芯，然後往中央去。
