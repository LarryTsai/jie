本段：雨光螺三夜之後。禁都舊城伏泉台，樂正葭守擂三年，此擂只受四人。太玄四人各為自己的理由走到同一座擂下，報了同一個隊名。他的雷落下去被土環與地火眼吃掉，他看懂了才停手；封寒驗出五拍一圈；生說盛跑到地下去了；青璃看著那道一寸寬的土縫：「都別動。」偏一寸，相生斷成相剋一息，他一步踏進五環中心，穿針兩儀正面一推。禮函裡是一枚煉不了的九界金丹丹方玉簡；當夜生借去拓了副簡，也把承身刀口裡那縷鱗刃刃意拔了出來，刀口收住。
