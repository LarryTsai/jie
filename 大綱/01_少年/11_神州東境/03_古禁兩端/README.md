本段：古禁外圍斷廊，殘禁每轉一圈抽走腳下法力；那個少女只報「錦」，藏著一經流霞看他怎麼走，他先讀出換手會挪、拿一塊錢去探刀路，錢都托不住，人自己走；走出來時點破她進廊十二色、出廊十一色。城外倒扣的禁殿像一本合起來的書：文奕從東端讀原用途，陸沉從西端要完整文字，封寒只想知道最裡面封了什麼；穿山會的掘陣者先撬走供力板；文奕要他托板，他說「托得住錢，托不住它」，跪在脊上截住整座殿的回彈；「……別處，算你對」，兩人換到讀完兩端的時間。出口有人只買一片承接面。兩端的文字合上，一整部《古神禁典》落進兩人神識，都從第二頁開始——第一頁是他十歲起揣著的那片石頭。
