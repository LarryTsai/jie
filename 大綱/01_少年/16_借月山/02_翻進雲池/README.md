本段：Y191 出城，Y192 抵外山。上層夜航每次三艘；韓映渠的雙骨短舟能逆風切進最窄巖縫，曲洗星的雲翼最快，兩人都覺得劫臨時上場成不了舟。劫在框架布禁、兩儀整平，刻橫板；Y193 晨試航離岸，逆風從舟底起，三人翻進淺雲池；韓把自己的舟開過同一道風給他看——風從兩側不同時抵達；曲先取第一枚航標。
