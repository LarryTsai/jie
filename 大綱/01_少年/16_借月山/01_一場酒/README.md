本段：Y190 夜，中央酒樓窗席被外放氣勢佔住；雲行坐在風最急的空沿，酒面不晃，短時一定放緩劍氣，對手猛推自己失衡；他收手搬到樓下，仍賠那一角木錢；劫幫他提酒，封寒追問怎麼定的，三人同桌。賣浮巖鹽的舟客說最高那塊巖像月亮掛在腳底下；陸沉查過集合日，放掉第二場賭石：「石頭下次還有，月亮這次就從那裡過。」
