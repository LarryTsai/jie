本段：Y188 古礦盛會。看臺上世家子笑東溟，冷照野按劍站起來，「長川還是比太玄強」「我知道」；一塊人高的古礦殼六種人六種讀法；他讀得篤定、一刀開了是空的，錢與場費真出去；冷汗黑殼前收手；與文奕合出一塊石，「你開，我保」，剖出低階古礦。Y189 封寒在共天上問切法，真有人回「認得」，文奕按住他，他抄進玉簡，沒去。
