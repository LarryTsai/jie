本段：Y186 夜，夜市上太玄護隊的三師兄陸行烈不用火、只憑力氣和西極屠蒼比腕力，把人連手帶桌按下去，還嚷「我師弟比我還硬，你去試試他！」；Y187 屠蒼在練武坪當眾攔人，「我不信傳聞」，三息——承身正面接、兩儀一斥、星羅身的雷按後頸——趴在石板上：「傳聞說輕了。」全卷劫唯一一場私下交手。
