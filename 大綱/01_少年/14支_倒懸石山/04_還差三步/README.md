本段：Y251–258。回程那天早上，崔砧提著兩罈新酒站在驛前石臺中心：「我站穩了，你再打一次。」陸只出本體對拳；五域那回第三拳他跪進沙脊，這回膝蓋沒彎，人被推出石臺三步。他把一罈遞過去：「還差三步。」舟起，八日回天域。
