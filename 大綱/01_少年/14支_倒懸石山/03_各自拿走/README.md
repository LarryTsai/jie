本段：Y247–250。第二輪開口，石走自己聽出的實層先到碑根旁；阮不再假聲，親手拆掉自家三代釘的上層石鉤，要斷所有別人的路，落下的鉤砸斷了承身的浮石印線；石以回壑震打已確認的橫裂，阮自己的落樁斜進空腔、人掉到石面前，短杵正面放倒他，取橫裂邊鬆出的小石骨；陸在碑背讓自己的細雷折回、截在舊燙痕前一寸，取有限斷路拓痕，從另一口出；山在他們身後整座倒過去，翻上來的山底還有一層誰都沒讀出；兩人約下次再比，阮把那枚鉤釘在驛崖上。
