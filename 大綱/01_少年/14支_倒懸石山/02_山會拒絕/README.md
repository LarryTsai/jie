本段：Y238–246。第一輪旋迴開口，三個人從三條路進同一座碑廳；阮一聲假裂，石的負嶺樁插進空層，肩受反震，失了碑位；陸提前讀定三紋，裂口將合時賭兩紋接續，賭對了，山卻不認外來的雷，禁路把他的細雷折回來燙在右腕上；裂口在臉前合上。退養三日，星羅身煉丹，石夜裡學回聲學到假裂那一聲停住；合看失敗：石只問一句「那它認誰？」；石自己以兩次真回聲確認一條通到碑根的實層，舍最大一片碑，只要小石骨；陸舍多讀兩紋，在浮石上三試，布出第一段停得住的禁。
