# 02_海眼一夜

本段：護礁第一夜淵下傳上來他十歲那夜聽不懂的潮聲，裡面有洄辛被送下去的表姊，她天亮前爬上崖來請他：「我要知道下面是誰在唱。」封寒去對帶隊長老說「要罰就罰兩個」，祁望的舊快艇、魏四錨在線外的大船，星羅身擰出一條打「停」結的雷絲長線、承身扛，本尊只握線頭；滄漣先下去了。第三夜三身分工送潮聲下淵，孩子們改唱上面的歌，暗流倒轉；承身抱著洄辛的弟弟正面扛水、左臂吃一刀鱗刃，滄漣咬住鱗刃；宮霽一指定界，星羅身想追，指意未落他自己先停了，「守住了。」回來七個。回家半日，母親治臂，父親「路上小心」，船離港。
