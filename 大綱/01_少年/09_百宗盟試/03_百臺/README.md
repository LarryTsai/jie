本段：百宗盟的會場是內海上一圈一百座石臺，臺底古陣釘在海床一道古戰痕上，腳下的靈力就是潮。鎮溟首徒霍驍的「分潮」專抽這口潮，抽到他的兩人當場棄權，第三支籤是陸沉。預賽，承身正面吃下「分潮」不退一步，青石臺從腳跟裂到臺沿，二十幾息霍驍劍脫手落海；一個陌生宗門的弟子先喊「劫」，半座看臺跟著喊。霍驍從海裡爬上來，抹了一把臉，看他。
