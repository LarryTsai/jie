本段：百宗出發，生不同行，給每人一枚出行丹，「拿第一回來。」太玄十人搭魏四護舟的商舟走陸沉提的留舟港航線，另一個理由他先告訴了封寒；鎮溟護礁封航三夜，鱗娘攤上海眼靈材漲了三成，滄漣出價壓過所有人；洄辛在礁上領唱送礁歌，今年要下去的是她弟弟，他還沒開口，她先說「不要」——第三次。
