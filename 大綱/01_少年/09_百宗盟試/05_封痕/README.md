# 05_封痕

> 狀態：**工作選定（2026-11-14 D173 結構化＋承接窄修；待作者釘板）。釘板前不寫正文。** 依[逐章解凍規則](../../../../設定/00_故事定位/02_工作規約/逐章解凍與正文寫作規則.md)，作者釘板後正文才依序撰寫。

本段：決賽鐘前，場務在通道口喊他上臺，他的腳已經踩上第一級臺階——那是他想要的，真的想要——腳底下那聲低震變成了裂；窗外外海陷下一個圈，海水往海床戰痕裡倒灌，正把外圍救援舟往裡吸，外圍井口有石魁、穆苡、賀成。他和封寒對看一眼，轉身往下走。海床上兩面海牆往中間壓，維護長老吼「少年只准碰側路」；封寒跪著壓住他驗過的那一點，石魁閉眼扛承石聽他數拍，承身把兩道雷一針一針縫進裂縫，裂裡的舊東西爬進右前臂那段燒過的脈，他咬住不讓它過肘。頭頂上決賽的鐘響了，第一名的名字隔著一整片海傳下來，像在叫別人。他沒抬頭。霍驍站上冠軍臺，往空出來的選手通道看了一眼。
