# 04_八強與四強

> 此資料夾收錄卷八〈百宗盟試〉第 04-01–03 章章綱（共 3 章，全卷第 11–13 章）。

> 狀態：**工作選定（2026-11-14 D173 結構化＋承接窄修；待作者釘板）。釘板前不寫正文。** 依[逐章解凍規則](../../../../設定/00_故事定位/02_工作規約/逐章解凍與正文寫作規則.md)，作者釘板後正文才依序撰寫。

本段：八強日東溟一代各打各的仗——滄漣九十招敗給封寒、龍血沒放；青璃只鋪得開短界，冷霧被「分潮」一抽就散；冉晴川三路第一次全出，砍不到冷照野留兩分的劍底；池杳「這次我不看你的腳」，星羅身一步沒停走穿；其餘五人留在外圍幫百宗維護者守井。四強另一邊，封寒在「分潮」下站滿三十息，「站滿了。」陸沉的四強是冷照野：「別讓。」〈不謝劍〉劍劍八成，承身自己的一版〈借地〉第一次上真場，十成對八成，一步一步把那條劍河推下臺沿。冷照野落臺劍還在手裡，「長川比太玄強」；承身低頭看腳——腳底先覺出臺底那條戰痕在響，看臺上的本尊認出，像戰葬那夜。
