# 01_空洞府

本段：X75＝Y333 報到當下＋E1–8（Y334–341），十五歲，銘紋，三雷三身，本尊帶魂傷。分院臺前四道院門，各人進各人的院；南院給陸沉一間空洞府、一句「南院給你選擇和時間」；低負荷神魂課上三雷同走失控，教習定下「三雷一起響，你就停」；耗材房門口孟守衡劃一條線，最弱的那一隊先領。
