本段：E60–71（Y393–404），十六歲，銘紋，三雷三身。文奕授權外禁試拆牽動共底，陸沉三格一起亮，照實失敗、重布能撤的側路；E65–67 封寒在洞府門口放一根竹籤，要驗玉簡上「聽說：劫是三個人」，第四、第五劍落在本尊右前臂兩儀脈的淬痕接口，第六劍陸沉一掌停在劍格上；E71 第一件本人完整成器三門法器，厄拍了三盞燈；耗材見底，卷末逼出闖塔（接卷十六）。
