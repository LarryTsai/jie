本段：E36–64（Y369–397），十六歲（前接 04 段〈過天〉，除夕 Y365 過生日），銘紋，三雷三身。開春，他第一次被人讀：共天開門前一日席燭修信物，說了牌角那一道「斷年以後添的」；院際試招霍驍照買來的舊錄出「分潮」，逼他把承身從地上拔起、兩身互為根，未分；同日陸沉在院錄堂買自己這場的錄，架上空了一格，遇只用右手收錢的隗知年；三雷過載課上他當眾說「這卷要雷作骨」，救了三個人，也交了底；隗知年在簿頁邊添兩行，他不知道。
