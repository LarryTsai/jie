# 02_鳴丘三日

本段：E9–11（Y342–344，三日含往返），十五歲，銘紋，三雷三身，醫准二雷低量採材（只出星羅身、承身兩具，震魂不動）。陸沉要一截八尺分叉角骨，普通芥囊轉不過去；器道天驕蔣扶岳以本人作品先收走整骨（器道取材，不計敗，D157），陸沉查根起出回鳴核與連著骨尖的斷角根；第二日黃昏下坡骨杉林崩塌，黎照野揹出不在名單上的蘇棹；山火旁蔣不送家傳主式，兩人約下次各憑作品；回院〈先報名〉，黎照野挪床位、擔藥、教成對封樣。
