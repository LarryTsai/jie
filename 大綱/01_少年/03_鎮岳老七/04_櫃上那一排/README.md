本段：十二歲秋：真賺錢、清欠條、月市一錢；雷被九霄的同輩半路截住，他一線進爐、剩下那截送下地，厲朔禁丹閣一季，「外爐叫雷，前一日掛牌」；先師的法子、採靈還謝；孟稷離宗；每月替丹閣往山腹送丹，一枚不貼籤的丹讓門裡的老人第一次笑。洩口越來越亂，他聽見卻沒開口。
