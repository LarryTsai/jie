本段：十三歲開春至春仲：正月鎮岳臺反送半口、開春約練回一半；雷雨季先問青璃；衛琅一比一；雷爐師兄名聲、照母親的方第一爐；同代把下一屆十人押上一棵槐樹，他替生掛一塊牌；還息穗割盡留種，快方上櫃，生寫「吃了會怎樣」，何靜安不判。
