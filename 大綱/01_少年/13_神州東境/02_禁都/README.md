本段：自由期第一旬。禁都外城一座水做的橋漏了，兩個少年同時伸手，一個托人、一個重開原禁，「你的也在抖」。封寒把卷四那片切面小樣放上古材攤，攤主削了一刀：這種切法是要拿去再接的。白老九的賭石坊裡，一個少女請他辨殼，拿他當托，「我付了托錢」。禁師坊裡和文奕又撞上三回，第三回他說能托、文奕說不能，托住了：「這一處你對。」文奕說他來禁都，是為了城外一處文家找了幾百年的古禁。
