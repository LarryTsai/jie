# 05_還擂

本段：次日，樂正葭點名青璃一對一，連夜把擂改到禁都上空無地無泉無火的懸台，把環轉快到界不停。青璃左手兩指被回勢劃開，改以冷霧退，邊退邊在懸台五方各落一片自己的術——「妳說要地。」「我帶了。」五環合成一枝矛、五道界同時靜止的那一息，她偏移金與木的交界，矛散成五色細雨。她能讓它炸，選了讓它散：「我還想再看一次。」陸沉在看台上。
