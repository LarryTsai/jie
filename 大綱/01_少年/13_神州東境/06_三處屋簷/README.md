本段：比試後第三夜，他把禁典一整段古式照抄進自身，兩儀一換，落點正好落在自己承力的反面，試板裂、紋散；文奕只講原用途：「你身上那筆，得是你的。」他把港口的星羅身叫回禁都，三具身各刻各驗各改；照鎮岳的規矩，骨先鑄到承得住才下筆——承身先到，星羅身次日，本尊差一夜。那一夜葛負山追到客寮後院掏出一枚丹：「我那年就是沒等這一夜。」他還回去：「骨頭追不上來的。你就是追的那一個。」他等了。次夜三處同一息落下最後一筆，三處屋簷的防潮禁一齊亮了一下。首驗，整塊板上唯一沒斷的是他自己那一線。自由期末一夜，他在夜市拿殼換芯，然後往中央去。
