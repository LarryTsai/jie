本段：生在峰內，她的主場，陸沉不在場。夏季那一爐芯發苦，她改了自己的先後；入秋，從自己第三季那一爐想到老梧供進去的命去了哪裡，「不是我判，是它判了」，滿樹轉金，只剩二十七根青枝；她帶天絲、梧心與青枝去赤霞，先綁斷一根試材。
