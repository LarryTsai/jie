本段分兩弧（不拆段）。

- **弧二之一〈圈與腳印〉（02-01～02-03）**：出藏第二日，問劍練劍坪灰圈，承身借地一掌把冉晴川連人帶六柄劍推出圈；當夜在鎮岳練功房把整條路走滿，地力與兩儀的斥在前臂脈裡對撞，燒斷一段，鐵石地上的腳趾落在那個人的腳跟上；次日生兩指一壓：「哪來的燒？」
- **弧二之二〈陸家的火〉（D191，02-04～02-07）**：二嬸帶陸燧上山，陸行烈退到紋暗、拆方要人念「丹須寒手收」；石魁收孩子進赤霞第三座爐，陸行烈站在自己砌的第四座旁答應揹磚；月底孩子上崖被兩股赤陽互引，承身不等第二遍就上崖挨了火，本尊不問就去叫人，秦照雪三丈一指；秦照雪第一次貼籤。
