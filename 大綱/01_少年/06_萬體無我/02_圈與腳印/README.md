本段：出藏第二日，問劍練劍坪灰圈，承身借地一掌把冉晴川連人帶六柄劍推出圈；當夜在鎮岳練功房把整條路走滿，地力與兩儀的斥在前臂脈裡對撞，燒斷一段，鐵石地上的腳趾落在那個人的腳跟上；次日生兩指一壓：「哪來的燒？」
