本段：第一輪開藏三日。十人帶傷憑「准入」石令進主峰北側舊門，門後是滿谷數不清的命痕碑，每塊碑是一件會往人身上穿的石衣（不同於卷二鎮岳山腳只給人看的碑林）；十人各走各的碑。承身在一塊碑主自刮名字的矮碑前愛上鎮岳的反面〈借地〉；第三夜承身不套碑自己站，地力第一次順腿上來，碑邊裂出一圈往內收的細紋。
