本段：秋天，兩人各有理由，夜半偷溜出宗去方執說過的西北那片會響的古戰場；封寒在外緣停步，本尊一個人進斷劍谷，聽見四個死人的最後一瞬；「回頭」扳過他半隻腳，他倒著走出來，退到封寒的手按上他的背；回宗扣貢獻、禁足一旬，養魂創、養燒傷，在她爐房看見二十七根青枝；封寒接下宗外護送任務。D191：出旬後第三天江離補採石道舊陣、連影子也布了，往後只走山門；頭場雪前一夜寒潮，石階結冰殼，鄒老肩摔在九百級那個彎，三身下山不借地、換肩不停步，燈一盞一盞亮回山門（新卷末）。
