本段：秋天，兩人各有理由，夜半偷溜出宗去方執說過的西北那片會響的古戰場；封寒在外緣停步，本尊一個人進斷劍谷，聽見四個死人的最後一瞬；「回頭」扳過他半隻腳，他倒著走出來，退到封寒的手按上他的背；回宗扣貢獻、禁足一旬，養魂創、養燒傷，在她爐房看見二十七根青枝；卷末封寒接下宗外護送任務。
