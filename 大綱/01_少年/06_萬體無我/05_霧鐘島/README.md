本段：封寒的主場，陸沉不在場。命藏與戰葬之間向晏守拙告假一旬回霧鐘島，玉簡末行還是「沒有臉」；兄長封沂簷下聽霧、神識薄得像紙；他翻到換了筆跡的潮圖，沒問哥哥，帶〈看潮〉到霧邊自讀那一夜，再回去問母親；「以後不許有人瞞我」；回太玄，「還行」。
