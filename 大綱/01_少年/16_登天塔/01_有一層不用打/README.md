# 01_有一層不用打

本段：E72–79（Y405–412），十六歲，銘紋，三雷三身。塔前四日，陸沉算過要從塔裡換耗材、最好一件長用護具；熟人各帶著新的人來，北面塔門前韋執圭在等隊裡最慢的褚禾；第一日陸沉把五樣東西擠進同一招；第二日一盞燈、一張桌，這一層什麼都沒打；第三日暗渠層，兩隊同渠，三具身各往一邊扯，收供能先後用錯而震傷，受韋〈同息令〉三十息；第四日上午雲、文、生各撞一層、各被反制一項方法（增章）；下午額度桌，韋拿分承護符給最弱的人，陸沉選《承流試錄》抄閱。院錄堂調了暗渠層的留影，隗知年添眉批。
