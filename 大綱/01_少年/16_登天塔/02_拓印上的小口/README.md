# 02_拓印上的小口

> 此資料夾收錄卷十六〈登天塔〉第 02-01–05 章章綱（共 5 章，全卷第 7–11 章；02-03 為增章）。
>
> 狀態：**工作選定（總覽第 21 列；未逐章作者批准）；結構化 2026-11-28；章綱未釘板，待作者釘板。**依[逐章解凍規則](../../../../設定/00_故事定位/02_工作規約/逐章解凍與正文寫作規則.md)，作者釘板後正文才依序撰寫。

本段：E80–90（Y413–423），十六歲，銘紋，三雷三身（震傷初養）。塔後三件事都是記下的和現物對不上：文奕借陸沉那枚拓印看了半夜，「有人從裡面往裡又開過一個小口」，同一時間黎照野在試煉記錄房停在一張器材表上；推演臺前文叫住一隊同代「那一塊換過了」；生辨出暫存藥樣已變，陸沉只改自己的記位禁。陸沉自己的一件：傷養期讀《承流試錄》，找人死在哪一步，拆出「先承後撤」（增章）。最後三日低量收段，三門一格一物輕收放；卷末陸沉帶走拓印玉簡，文帶走一個材質問題，黎回東院接下一批任務。

本卷讀完後讀總覽第 21A 列〈三十年後再上峰〉（[鎮岳與瘋故事層](../../../00_全書骨架/12_鎮岳與瘋故事層/大綱.md)故事 6，並行列，不併入本卷；理由見[卷十六導覽](../README.md)），再接[卷十七](../../17_天域行/大綱.md)。
