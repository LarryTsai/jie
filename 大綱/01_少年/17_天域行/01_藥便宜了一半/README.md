本段：Y424–427（去程），十六歲，銘紋，三雷三身。任務牌掛出來，四院少量混編護送醫材與古器過天域外環（陸沉為任務貢獻與耗材接這趟；名單有南院陸沉、雲行），韋執圭以塔裡層績任執令，東院有人不服；出城前貼著扃天閣外牆走，韋說了一句「向晦」；途經收古物商隊停駐的城，生笑著說南荒的藥便宜了一半。
