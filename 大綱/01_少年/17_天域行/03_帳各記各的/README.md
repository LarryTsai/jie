本段：Y438–447（回程四日、交接與重現六日），十六歲，銘紋，三雷三身。事做完了，帳各記各的：冷開場黎照野在回院短途把主樣最小一片接面換成普通碎片，那一片被攔路的人拿走（作者層）；回院驗樣重現不出，文奕「我要補測」，案錄貼出登作常見類別；陸沉讀顧小滿的信「記你頭上」，想起禁都夜市那枚芯，不拿任務封樣作私人試料，把導流小器從偏重練到分先後；封寒來約戰，〈懸鋒〉第一次演成，陸沉從側面切開（增章，不計勝敗）；交接期末韋親筆兩行見證貼出，「南院陸沉未受令。末批出口由其獨守。」陸沉被扣貢獻，遞北院破陣狀（接卷十八）。
