# 02_站在拍子外面

> 此資料夾收錄卷十七〈天域行〉第 02-01–05 章章綱（共 5 章，全卷第 4–8 章；02-05 為增章）。

> 狀態：**工作選定（總覽第 22 列；未逐章作者批准）；結構化 2026-11-28；章綱未釘板，待作者釘板。**依[逐章解凍規則](../../../../設定/00_故事定位/02_工作規約/逐章解凍與正文寫作規則.md)，作者釘板後正文才依序撰寫。

本段：Y428–437（地方事件十日），十六歲，銘紋，三雷三身。城外採集地閘口，一件古器把一整隊取材者鎮住，陸沉破一處，其餘更緊——敵方改了拍子；韋執圭要全隊受令分批放人，陸沉看出最後一批會合攏、須有人站在拍子外面——「這次我不受令。」「沒有人站在拍子外面。」；韋談判分批、生救人、封寒斷後、雲在分承裡接人、黎照野肩上挨一記，最後一批從陸沉獨守的那一點出來；搜行兇者的庫，舊承接片上的殘禁開始散；文先譯後布、封寒改一寸落點、雲替生壓躁幾息，護住大半（增章），分成主樣、副樣，加上丹錄與通行見證。
