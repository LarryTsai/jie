# 02_月照滿院雨

> 此資料夾收錄〈雨光螺〉（卷十一自由期支線）第 02-01–02 章章綱（共 2 章，全篇第 3–4 章）。
>
> 狀態：**工作選定，待作者釘板**（2026-11-15 依 [D173](../../../../決策/01_決策紀錄/D173_卷大綱結構標準.md) 結構化）。依[逐章解凍規則](../../../../設定/00_故事定位/02_工作規約/逐章解凍與正文寫作規則.md)，作者釘板後正文才依序撰寫。

本段：第三日分頭去看，各看見一半：螺只受當下外光，滴水改變出光方向；少掉的星是被屋簷擋掉的一小片天，牆月是雨滴把今夜月光送到牆上。第三夜大雨，兩人不再想修全螺，只想看一次月照滿院雨：文守原環可承的轉動，他在自己帶的薄石上布窄側禁托住被風壓偏的雨線；第一回太密，月碎成一道白牆；第二回讓雨先散再承，滿院的雨，每一滴裡都有一個月亮。天亮歸器，環仍缺；兩人各劃掉自己的錯字。
