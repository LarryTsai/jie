## 新章細綱

### 第 05-02 章〈手〉

**時線｜年齡｜境界｜傷｜持物**：十歲入冬，05-01 那個旬日之後的下一個旬日（近十一）｜搬血；淬體承、導，不能蓄｜守閣傷剛好，右臂偶麻｜小浮石；厄在衣襟。

**因果入口**：02-07 林伯潮問他為什麼來閣門口：「我爹的牆每年都裂。」；04-07 父親白髮多了；04-14「最痛的不是最先垮的」；04-16 天亮時伏雷坳還亮著；01-08、01-11、01-16 石臼與「到哪了？」。

**場景順序**
1. **下山。**下一個旬日，閣裡不派差，他可以去攤上、去港邊找祁望。他走到坊市口，停了一下，轉向坡腳。
2. **祠堂後牆。**守閣那夜之後坳一直沒全靜，入冬了牆根還是溫的；新補的泥上又多一道裂，父親蹲著和泥。陸沉不看那道最長、最顯眼的新裂，沿牆根一塊一塊摸過去，找到最底下一條還沒裂開、摸上去發燙的磚縫。
3. **導。**他把手貼上去，照「它什麼時候弱」那樣等。一縷餘火沿地縫上來，在磚縫裡晃；他等它不晃，讓它從掌心過，照淬體路線過肩下那一轉、腰、腿，跪著從膝下送進牆根外的地裡，地上冒一縷白氣。他再等下一縷。一個下午導了四縷。那條磚縫沒有再往上裂。
4. **父親。**父親停了手，看了很久。「到哪了？」——他小時候扛臼，父親天天這樣問。陸沉把燒紅的掌心攤開給他看：「手。」父親沒說什麼，把和泥用的石臼往旁邊挪，搬一塊平石放在牆根騰出來的地方——兒子下回回來坐的地方。
5. **回閣。**天黑前他回山，掌心的紅到第二天才退。

**可量的變化**：牆根那條縫這個冬天不再往上裂。

**連續性**：只導、不讀；不碰祠堂封紋、石匣；不探餘火從哪來（05-19 才探）。母親可一句「在屋裡碾丹」。不添新傷。

**收尾與牽引**：牆 → 05-19。「到哪了？」本卷父親最後一次問；06 段〈那一夜〉父親不問（照現行正文「早點睡」）。

### 第 05-03 章〈手穩了〉

**時線｜年齡｜境界｜傷｜持物**：十歲入冬（守閣傷好、05-01 之後），近十一｜搬血（淬體：承、導；不能蓄）｜無傷｜小浮石、石頁壓的抄簿；厄。

**因果入口**：守閣後島上傳「劫族那家的孩子，在閣頂接雷」（04-17）；03-09 卞老「客人買的是這一隻」；04-16 閣毀西牆、灶房，閣窮；03-02 錢潤「想來，自己來找我」。

**場景順序**
1. **閣門口，冬日（旁景，一兩句）。**千礁的人抬著承雷石與鎮爐砂上山，學徒傳說是千礁出料修閣、太玄閣替千礁北岸碼頭底下那段支脈釘幾根脈釘。錢潤出門時看見掃階的陸沉，只說一句「傷好了？」。
2. **觀潮執事上山。**觀潮量裂帶的執事（第 01-15 章冊上寫「陸家：不遷」那位）來問裂帶走沒走，說是唐岫留的話「坡下那孩子看得出來」。陸沉跟他先看閣後西段、再看山道第三彎東段（三根），都釘住了；再沿浮石坡那段沒釘的地裂走到坳口，有一道更舊的縫，不走了。執事記下，臨走從袖裡摸出一枚碎靈石放在他手裡：「勘裂的例錢。」他第一次有人付錢請他「看」。
3. **卞老攤，旬日。**攤後堆著一堆修不好的鳶，卞老說是守閣後坊市孩子拿來的，指名要「閣頂那個」修。陸沉一隻一隻修。有一隻客人要的是「飛得低、穩、給三歲孩子拉」的，他修到一半手癢想把翼改長——停住，照客人說的修。卞老在旁補一隻舊鳶，眼角看著他，等他修完一排、一隻都沒改過原樣，才說：「手穩了。」修鳶的錢卞老照件算，給的是碎靈石。
4. **夜，閣裡。**他把勘裂的那枚、修鳶得來的幾枚碎靈石倒在床上數，用布包起來，塞到石頁底下。阿硯在對面鋪上問他存錢做什麼，他說還不知道。

**可量的變化**：第一次有人付錢請他看；修鳶不再擅改（03-09 那一課接住）。

**連續性**：千礁換的是脈釘手藝，不是名額（費瑜不在這一批）；錢潤不提籌碼。觀潮執事無名。

**收尾與牽引**：錢 → 05-04 問價；千礁靈材 → 06 段第二批。

### 第 05-04 章〈一縷留不住〉

**時線**：同冬，數日後｜搬血（承、導）｜無傷｜碎靈石布包。

**因果入口**：02-12 林伯潮「盼有一天有人能把困在經脈深處的殘雷引出來」；04-10 林伯潮推雷後倒在前院；04-08 「別看」；02-14 能承、能導，不能蓄。

**場景順序**
1. **夜值，林伯潮的屋外。**守閣後老人經脈裡的殘雷壓得更深，夜裡睡不著，屋裡的燈一夜不熄。陸沉值夜三回經過，三回都亮著。第四回他在門外站了一會兒，聽見裡面老人起身倒水，手抖，碗磕在桌沿上。
2. **他自己去試。**旬日一早，他一個人去伏雷坳外圍（02-13 林伯潮帶他坐過的那塊石頭），等一縷餘火最弱的時候伸手接。接住了，照淬體路線走到掌心，他不送出去，想讓它停在身上——火在掌心晃了一息，從指尖走掉，打在地上燒出一個焦點。他試了三次，三次都一樣。淬體練出來的只有承和導，他的身子盛不住。
3. **坊市，午後。**酒館門口有人在講共天：九界的人一年碰一回頭，「裡頭什麼都有」，有人進去一個月出來，境界就不一樣了。斷階底下那棵老樹下，散修苟全擺著一張矮桌賣共天的「一次」。陸沉去問價：「一次，三塊。共天開春才開，要買趁早。」他摸了摸懷裡那包碎靈石（05-03 共十四枚）；苟全的秤上碎的十六枚才當一塊，他還差兩塊多。
4. **夜。**他把布包拿出來又數了一遍。他沒有對林伯潮說，也沒有對任何人說。讀者知道他為什麼想去，老人不知道。

**連續性**：島上只傳「共天裡什麼都有」，雷山照現行在營地才打聽到（05-11）。他不知道要找的是「雷種」，只知道要「能留住」的身子。苟全在此先露面，05-09 照現行讓他擺隊頭。

**收尾與牽引**：差一大截 → 05-07 賞錢補足；「盛不住」→ 05-15 星羅、06 段〈蓄〉。

### 第 05-05 章〈先來看一眼的鳶〉

**時線**：同冬，坡重開前一個月（浮石季前）｜搬血｜—。

**因果入口**：01-18 繩樁上的斷繩符、01-14 浮石底下的臉、01-19 鳶停在錨扣旁；04-17 坊市說法傳開。

**場景順序**
1. **卞老攤。**一個光頭、手背有刺青的中年人（不是皮老鴉本人，正文不交代是誰；與 05-06 戴斗笠的客人分開）拿來一隻舊鳶，說骨裂了，要修，付錢爽快。陸沉接過來，神識一碰鳶骨：腹下那根橫骨上刻著一道細得看不見的焦紋，紋的起筆、收筆，和九歲那年繩樁上那一道是同一隻手。紋是死的，沒有接符袋，碰上受力的線也燒不起來——它什麼都不做，只在那裡。
2. **他想了一刻。**他知道這隻鳶不是來修的，是來看他認不認得。他用修鳶的細砂把那道紋磨掉，磨到骨面光滑，再照原樣補好裂口，交回去。卞老拇指摸到磨過的那一截，停了一下；陸沉沒看見。取鳶時光頭按著那一截看他一眼，他以為那裡已經什麼都沒有了。
3. **坡尾，傍晚。**陸沉收攤回閣，從斷階上往下看見那個光頭走到坡尾低崖，把剛取走的鳶丟進海裡，轉身走了。他以為紋平了、鳶沉了，這件事就乾淨了。章尾不寫「沒有對任何人說」。（2026-10-31 節奏盤點：自以為乾淨，錯到 05-07 由卞老點破。）
4. **作者層（正文不寫明）**：皮老鴉由此知道兩件事——這孩子認得他的符；這孩子不會去找觀潮。所以下個月他敢把三隻鳶送到同一個攤上。

**長篇化補（2026-10-31）**：「陸沉認得那個背影」補「地裂前那年冬天坡尾鬥鳶，燒斷他鳶線的也是他」（接 01-13，九歲正月、季後；2026-10-31 依 01–04 段改動審查由「八歲那年」更正，與正文同步）。

**連續性**：不用禁、不用雷，只有神識與修鳶手藝。陸沉不指認、不報觀潮（守 05-06 約束的同一路）。皮老鴉本人不現身。

**收尾與牽引**：→ 05-06 三隻鳶他照修時想起這一隻。

### 第 05-07 章〈弟弟的手〉

**時線**：浮石季第一批當日，夜｜搬血｜—。

**因果入口**：05-06 兩個坊市孩子被燙傷，母親當場抹玉膏、裹靈帛，其中一個被衝出人群的哥哥拉走；卞老當眾認「我攤上修的」；客人付的是一把落石碎。

**場景順序**
1. **祠堂外，掌燈。**那個水性好的孩子蹲在院外牆根下等，弟弟的手已經裹好，先被他打發回去了。陸沉出來倒水，看見他。
2. 那孩子站起來，沒罵，只說：「火是順你改過的線燒下來的。」——他不知道陸沉知不知道拉線的是誰，他只知道那條線是誰修的。陸沉沒答。那孩子盯著他看了很久，看他手裡的盆、看他的臉，什麼也沒再說，走了。（不寫陸沉事後解釋或反省，守 05-06 約束。）
3. **三天後，卞老攤。**卞老把那個戴斗笠的客人付的那把落石碎推到他手邊：「修鳶的工錢。客人要什麼，就修什麼；這三隻多修了兩處，算你的。」那客人不會回來取找頭了。收攤疊布時卞老補一句：「上個月那隻灰的，你磨平了，他就知道你認得。」陸沉沒答。（2026-10-31 節奏盤點：點破 05-05 的錯。）
4. **夜。**他下山到鱗娘攤上把落石碎換成靈石，和石頁底下那包並在一起，數了兩遍。夠三塊了。

**連續性**：沒有指認賞錢（他不指認，05-06 約束）；落石碎本是皮老鴉付的修鳶錢，卞老的說法不點破他改了什麼。弟弟只是「坊市孩子」之一，不命名；水性好的孩子不命名。

**收尾與牽引**：錢夠了 → 05-09 排隊；帳沒算完 → 05-17 山路扔石。

### 第 05-17 章〈坡上收錢〉

**時線**：十一歲秋，下一個浮石季前一個月｜搬血，星羅一雷，雷絲能探｜—。

**因果入口**：05-16 鮑十一上山請他看哪塊要落，大人先問他；01-19 皮老鴉改畫錨扣；05-07 帳沒算完；05-09 錢讓掉了，他手頭又空。

**場景順序**
1. **坡上，秋。**鮑十一之後，別家帶子弟上繩的人也來請他：雷絲順錨扣探進浮石底下，哪一扣鬆、哪一塊下季升起來會先掉，他一塊一塊點出來。各家照鮑十一的價付錢。他收了。
2. **坡尾。**那幾家把要掉的浮石先加了扣，季前試升時一塊也沒落。坡尾低崖下空空的，拾浮幫剩下的幾個孩子在礁上坐了一天。
3. **山路，傍晚。**他回閣，路邊忽然一顆石頭砸在腳前。再一顆。那個水性好的孩子在坡尾的礁石上，一路沿著山路往上扔，扔到半山那個彎（02-08、02-11 祁望等他的地方），扔不到了才停。
4. **半山那個彎。**陸沉站住，回頭朝下面喊：「下一季，第三批，坡尾東角那塊沒人上繩的碎石會先掉。」那孩子手裡的石頭停住了。陸沉沒等他回答，上山。

**連續性**：雷絲只探浮石與錨扣，不探人。落石沒人認領、撿去賣不犯規矩（01-06 作者層），他告訴對方的是一塊沒人上繩、本來就要落的碎石——不是替拾浮幫做事，是還他一季的飯；正文不解釋。

**收尾與牽引**：東角那塊 → 06 段離島那天坡尾丟來的浮石。

### 第 05-18 章〈未問〉

**時線**：同秋｜星羅、雷絲｜—。

**因果入口**：05-16 雷絲第一件事探厄，「牠甩尾躲開，他換到一旁等牠肯靠近」；02-09 宋知微「不確定就寫存疑」；02-11「我只記發生的事」。

**場景順序**
1. **簿房，午後。**他好奇閣裡每個人的經脈長什麼樣——阿硯的、宋知微的、簿房老人的。宋知微低頭抄簿，他的雷絲從桌下伸過去，碰了她手腕一下。她的筆停了。
2. 宋知微抬頭看他，什麼也沒說，在簿上寫了一行，轉過來給他看：「陸沉，雷絲探人，未問。」他漲紅了臉。「你也記這個？」「發生了。」
3. **前廊，同日。**阿硯聽說了，走過來，把袖子捲起來，手腕伸到他面前：「探吧。」他探了，阿硯的經脈走得慢、穩、每一處拐彎都先停一下，像他看門的樣子。陸沉說了，阿硯笑：「那是我。」
4. **夜。**他在床上想宋知微那一行字，想了一會兒，睡著了。（不寫他學到什麼。06 段〈不問〉時他照樣沒問。）

**連續性**：不出現「下次先問」四字（必埋 3 只在 06 段〈不問〉）；陸沉不問、也不學到「先問」（定案 7）。雷絲探人只此兩次。

**收尾與牽引**：「未問」→ 06 段〈不問〉，讀者記得、他不記得。

### 第 05-19 章〈牆根下面〉

**時線**：同秋，雷季剛過（與 05-17 前後相接）｜星羅、雷絲｜—。

**因果入口**：05-02 去年冬天他只能等餘火來了導開；05-16 雷絲能探。

**場景順序**
1. **祠堂後牆，旬日。**雷季剛過，坳裡未靜，牆根那條地縫還發溫。去年他只能等餘火來了導開；今年他把雷絲順著地縫往下送，想找它從哪裡來。
2. 雷絲往下走了一段，地縫分成兩股，一股往坳的方向，一股往祠堂底下。他順著往坳那股再送，送到分叉的盡頭，雷絲再也送不下去了——搬血的雷絲只走得到這裡。盡頭底下有個很大、很舊的東西壓著，不燙、不亮。他整條手臂發麻，麻到肩，立刻把雷絲收回來。
3. 他坐在牆根喘了一會兒，沒再往下。他只找到了分叉的那一處。
4. **父親。**父親蹲在旁邊和泥。陸沉指著牆根一塊磚：「這段縫，從這裡分出來。」父親看了看他指的地方，又看了看他的臉，沒問底下是什麼，照那個位置封了一層泥，抹得比平常厚。
5. **入冬後一句**：那一冬，祠堂的牆只多一道短裂（往年入冬兩三道）。他沒再往下探，也沒對誰說起底下那個東西。

**連續性**：只探地縫，不讀祠堂封紋、石匣（約束）；底下的東西不寫是什麼、不連指骨、不連伏雷坳劫痕之名，不連埋王嶺；雷絲不越過分叉（伏雷坳本卷只到坳口，定案 4）；牆只少裂、不是不裂。

**收尾與牽引**：→ 06 段〈蓄〉他想要更深的落腳處；底下的東西留給第 10 篇伏雷坳二讀。
