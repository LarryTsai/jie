| 61A | 三隻鳶 | **浮石季第一批前數日**：旬日下山回卞老攤，一個面生的人（無名）拿來三隻退回的舊靈鳶要修，錢付的是一把落石碎；要鳶能停在浮石的高度，腹下加一枚小鉤，線上連拽兩下就鉤開、收翼往下撲；他約定由自己在低崖數兩下作暗號，兩個受僱孩子看見後照做。卞老接了：「客人要什麼，就修什麼。」陸沉說他來修。他的神識順著那枚鉤走一遍：鉤開時袋子正好落在下面一條繃緊的繩上——繩樁旁那道斷繩符，就是要碰上受力的繩才燒。他照要求修好三隻，沒對卞老說，也沒上山告訴誰；八歲那年他喊過割繩，沒人信。他只各動兩處：左翼第三折反摺，拽兩下不是收翼往下撲，是翼張到底、鎖死，鳶停在原處；小鉤挪到線結旁，鉤開時符袋改落在鳶自己的繃緊線上；他只把落點從鮑十一的錨扣繩移開，符仍會被受力的鳶線引燃。客人只在攤前試飛；陸沉提出試鉤，他按住線，說鉤要留到繩樁旁再拉，只驗三鳶能升高、停空，便收走。**浮石季第一批**（坡重開後第一次）：觀潮弟子這回不只守繩樁，卓青帶人連石底也翻看過；鮑十一領子弟上繩；坊市孩子照年例在坡尾放鳶，滿天幾十隻。陸沉向閣裡告了半天假，站在祠堂門檻邊，父親在旁和泥。他的神識只數那三隻：升到浮石的高度，挨近鮑十一那塊的錨扣。低崖戴斗笠的人抬手數兩下，坡尾兩個坊市孩子照暗號各拽兩下，他自己也拉動第三隻——三隻鳶在錨扣旁一齊停住，不撲。全坡先看見的是停在半空的鳶，人群裡有人喊：「又是陸家那孩子放的？」鮑十一一聲吼，繩上子弟全扣上第二道繩。下一息，三枚鉤依暗號先後彈開，各自掛著的符袋落在繃緊的鳶線上，符受力從接觸處引燃；陸沉看出火沿繃緊的線往持線者手上走，喊「鬆手」，兩個孩子立即甩線，仍被末端燙傷掌心。鮑十一喝人截斷餘線、把孩子帶離坡尾；父親放下泥，叫人帶他們去敷藥，確認只是淺燙、沒有傷筋骨。低崖那人也甩脫燒著的線，斗笠落地，全坡第一次在白天看清皮老鴉的臉。卓青御器從繩樁那頭撲過去，皮老鴉從低崖跳進霧裡一條等著的黑帆小艇，艇一轉就不見；卓青只撈回半截燒斷的線。三隻鳶斷了線，各自在半空停了一息，才翻落坡上。兩個孩子哭著說是有人給錢、叫拽兩下；觀潮的人問鳶從哪來，卞老從人群裡出來：「我攤上修的。」他撿起一隻翻過來，看見反摺的翼和挪過的鉤，朝門檻那邊看了一眼：「這隻，不是客人要的那一隻。」卓青把半截線交給觀潮弟子，問鮑十一：「去年停在半空那隻，也是他？」鮑十一：「嗯。」「多大了？」「還不滿十一。」卓青朝門檻看了很久。陸沉沒過去，看著坡尾那兩個孩子被帶去敷藥，手指在袖裡縮了一下。祁望從港裡跑上坡，站到他旁邊，看著低崖：「又跑了。」陸沉：「他的臉，大家都看見了。」 | **爽**（壞人的局當眾崩在他改過的鳶上）；**修**：符器、神識；**壓**（反向）：大人回頭看一個孩子；**引**：情 | |

| 64 | 一次的價錢 | 林伯潮給他一枚信物：九界共通的神識天地；坊市裡散修苟全在賣共天信物的「一次」，窮少年排著買，有人讓了他半個位置，嘴裡說「閣頂那個」；他路過卞老攤，原本壓石頁的那個布角空著，攤布被風掀起一角，他蹲下在布角畫一道「停」，布不翻了；卞老把原本壓那角的石子收回攤下，從此那角不再壓石 | **生**：共天也有價錢；**引**：盼（新地圖）；**修**（禁一拍） | |
| 65 | 外山的營地 | 持信物入定，睜眼是另一片天；肉身留在閣裡由同伴照看，厄趴在他的衣袖旁，沒有跟進共天。外山一群和他一樣缺靈石的少年紮營，他拿自己走過的一段岔路換一處歇腳地；一個來自別界、綁舊護腕的少年嫌他畫的路太細，卻照著找回落下的水囊，回來讓開火邊半個位置。這些人來求的造化各不相同，明早各走各的，不報宗門家譜、不預約日後重逢 | **修**；**生**；**引**：盼 | |
| 66 | 雷山 | 打聽到雷山：外山有人修行，內山只許搬血、洞天；一個看不出境界的修士在雷流裡散步，雷落在身上像雨，營地少年都停下來看 | **壓**：島外的「上面」更高；**修** | |
| 67 | 最亮的 | 他追最明亮猛烈的雷流，誤至多脈匯聚的洩雷口；去路比來路更亮，他還想往前，直到神識凝成的手掌邊緣開始散，才沿自己尚記得的細流間隙退回外山，險些潰形。營地裡舊護腕少年看他連水囊都抓不牢，把水囊放到他腳邊，讓他先拿著；陸沉得退出歸體休養，睜眼時厄正扯他的袖口，端飯的阿硯還在門邊。少了幾日，不是共天裡睡一覺就好 | **引**：危 | |
| 68 | 細的那一路 | 休養後重入共天，原來營火的位置空了一半；他想起伏雷坳外圍看了三天的雷，這次停下來，等雷潮強弱完整走過一輪，發現細弱、持續的銀雷才指向本源。舊護腕少年已循另一條路往深處走，兩人在岔口互報哪一段走不通便分開；陸沉捨掉最亮的那一路，沿細流進山腹。這是尋到本源的改法，後面的熔煉還得另學 | **修**；**引**：轉 | 可埋：「不追最亮的」 |
| 69 | 失敗 | 山腹裡銀色雷紋緩緩旋轉，像一條縮小的星河；他伸手去接，淬體那幾年練出來的手比念頭快：一接住就往外送，銀雷從他身上穿過去，打在背後石壁上，一點不剩；第二回他咬牙把整個身子關起來，幾道細流在胸口撞成一團，神識凝成的形一下子薄得透光，他只好鬆手退出山腹。舊護腕少年從另一條岔路出來，一隻手焦黑，兩人在山腹口並肩坐著喘，誰也沒問對方得手沒有；其他修士已越過他先前歇腳的地方。一次開啟的一個月耗掉大半，他得歸體養神識。閣頂上他照《萬體鑄身經》一遍遍走運轉，阿硯在旁替他數氣，數到第三遍說：「你每到拐彎那裡就快。」林伯潮只替他驗承受得住多少，不給山腹的答案 | **引**：危＋鐘 | |
| 70 | 星羅 | 再入山腹，他不伸手，先讓銀雷繞著他走完一整圈。第一縷穿身而過時他不送也不堵，跟著它在經脈裡走，到拐彎處停住，等它自己轉過去；有一段接不住，就放它過去，下一圈再等。最難的一圈，他的掌緣又開始散，他把硬併進來的兩道細流放走，守住已在身上轉起來的那幾圈，掌緣重新凝實，才把放走的兩道一一引回。銀雷在掌心慢下來，收成一團，像一條縮小的星河留住不走。出山時營地的人正在收火，他把水囊還到舊護腕少年放乾糧的石頭旁，少年已經走了，石頭上壓著一片畫了岔路的樹皮；共天尚未關閉，他自己歸體。厄在枕邊抬頭，看他掌中第一次留住的一絲銀光 | **爽**（卷內最大）；**修** | |
| 71 | 雷絲 | 帶回肉身，開始能蓄；學會的第一件事是雷絲探查，他先探的是厄，牠甩尾躲開，他換到一旁等牠肯靠近。地裂後浮石落得亂，鮑十一上山來問他能不能看看哪塊要落——大人先問他，他才出手，在坡下第一次幫上忙；回閣手指仍在顫，林伯潮讓他伸手搭脈，兩人只試著引出老人經脈邊緣一縷殘雷。雷引得出，他的運轉卻亂了，林伯潮先收住：「今天到這。往後再看。」陸沉盯著那一縷已散的雷，覺得自己的辦法明明能行；此後到十二歲仍淬體、練雷絲、試《無相離身卷》，能拉出輪廓卻立不住 | **爽**；**生**；**引**：情 | |
| 71A | 蓄 | 「翌年春，離島前」；十二歲。第 71 章那一縷之後，他認定是自己的身子盛不住：雷引得出、留不住，才會亂。十二歲那個浮石季他沒下山看，在閣頂一縷一縷收雷絲；過年後開春一個清晨，他在閣頂石臺上練雷絲，這回不放出去，一縷一縷往回收、往身子裡壓，想像星羅在掌心那樣留住；收到第三縷，經脈脹得發燙，搬血的身子到了頭，指尖抖得收不住，雷絲眼看要炸散——丹田底下像有一道門被撐開，脹滿的雷沉了進去，有了地方待；石臺四周的晨霧被他吸進的靈氣捲成一圈。林伯潮本是上來替他驗脈的，坐在石臺邊一直沒動，等他自己把運轉穩住才開口：「坐著，別起來。」他想立刻去試雷，被按著再坐了一炷香。當天就試出不同：雷絲能在身上存一縷不散，放出去能鑽進石縫、走得比從前深；神識有了落腳處，不再一用就飄（第一次跨大境：搬血→洞天，在場；72 擋神識、72A 探爐底的來由） | **修／爽**：第一次破境；**引**：盼 | |
