## 弧四　十歲：地裂之後到入閣（第 02-01–07 章）

| 章 | 標題 | 一句話 | 看點 | 埋 |
|---|---|---|---|---|
| 01 | 閣門口 | 季末，三宗與各家為份額吵到坊市執事包三郎面前（包三郎在此報名；即第 01-01 章收攤位費的人）；千礁靈舟商會管事汪七在牆上貼船位表，船資拿來季浮石份額抵，祁望家份額落了海，排不上；他在人群腳邊聽懂「份額」兩個字的分量。人群裡有人講退任閣主林伯潮當年修祖脈、在雷火裡受傷的英雄往事，也有人說林閣老打聽過坡上那隻停在半空的鳶。第二天他自己爬山去太玄閣，山道上歇了五回；閣門口三宗分部主事輪流排隊求修祖脈，千礁主事錢潤帶著挖苗子的弟子（無名）也在。他擠到門檻邊，神識順著山道邊那段支脈看下去，說東段在第三個彎底下漏；先來的學徒把他趕下山。門內有個少女把他那句話記上簿：「坡下孩子稱支脈東段漏於山道第三彎下。存疑。」（宋知微，此處不報名） | **壓**（反向）：三宗都得求這座閣；**修**：份額綁浮石、支脈；**引**：盼（誰會來看他） | |
| 02 | 裂向 | 尋脈師唐岫上島勘裂，他和祁望跟在後面，她不帶也不趕；她讀石層與裂向，在自己的圖上畫了一筆，不說；臨走一句：「裂向朝山上那座閣。」（鐘開始走） | **修**：尋脈；**引**：鐘 | 可埋：陣痕接口（唐岫圖上一筆，不說） |
| 03 | 斷崖 | 那季過後他和祁望偷上東岸斷崖；海族攤販鱗娘的攤是門路（鱗娘在此報名），他們先在攤上認得海眼的深海靈材；崖下寄礁戶的孩子洄辛撿殼，不跟島上孩子玩；兩人交換詞，他教岸語，洄辛哼潮聲 | **修**；**引**：盼 | |
| 04 | 一指 | 從崖上遠看：鎮溟分部主事宮霽站在數里外凹下去的水面上，沒有回頭，一指；兩個孩子在崖上被定住整整一潮，動不了、喊不出，只能看海；潮轉時鬆開，風裡一句「回去」。不罰、不告；回家晚了，父親第一次動怒，罰他和泥一個月 | **壓**：本卷最重的一次「被隨手處置」；**引**：危 | |
| 05 | 這是我們的事 | 洄辛平靜地說，寄礁戶每年要獻一個孩子護礁；他說要想辦法，洄辛說：「這是我們的事。你們岸上的人都想幫，幫完就走了。」他聽了（拒絕一）；護礁那夜他一個人坐在斷崖上到天亮，什麼都沒做；海上只傳來一陣長長的、他聽不懂的潮聲，天亮前停了 | **引**：情；**壓**（遠）：海上的聲音 | |
| 06 | 有人來看那孩子 | 林伯潮聽說了兩件事：坊市在傳坡上那隻停在半空的鳶；閣簿上那句「支脈東段漏於山道第三彎下」，他叫人去挖，真漏。他親自上門，問他為什麼要來閣門口，他說：「我爹的牆每年都裂。」（家裡沒人請他修那面牆）；看他跑坡（歇三次）、看他搬血；臨走在伏雷坳外隨手一按，外溢的餘火熄了一片，同一刻祠堂供桌上石匣的新泥跟著暗了一層；他回頭看那石匣一眼，開口要帶指骨走：「這東西跟坳裡的火一起起落。放在裂帶邊上，我不放心。」留下他不是因為天才，是因為基礎與認真 | **壓**：閣老隨手一按；**引**：危（家裡肯不肯？） | |
| 07 | 封存 | 父親把指骨重新泥封入祠堂石匣（有封紋的石匣），一層乾了再抹一層，封了三層（第三個「留」）；他蹲在旁邊看，問：「你的泥能封多久？」父親說：「封到換泥。」；母親塞給他一張丹方；他捧石匣上山，厄跟著；祁望送到山腰，約好每旬下山一次；第一次離家，只到山上，回頭從上面看祠堂，和四周搬空的那幾戶 | **生**；**引**：情 | 可埋：父親泥封手藝 |

## 弧五　十歲：閣（第 02-08–13 章）

| 章 | 標題 | 一句話 | 看點 | 埋 |
|---|---|---|---|---|
| 08 | 太玄閣 | 三宗裡最小的那座閣；現任閣主翁敬亭替他登名，有實權、少威望；記錄者宋知微（第 02-01 章門內記他那句話的少女）什麼都記，不確定就寫「存疑」；同輩阿硯到哪都先看門和退路 | **修**；**生**；**引**：盼 | |
| 09 | 誰多吃一碗 | 掃閣、打水、值夜、分飯；先來的學徒說「新來的先值」，把一旬的夜都排給他和阿硯；他用神識把值夜要走的廊道看過一遍，哪幾段廊燈是陣光自己亮著、不必繞，重排了路線，和阿硯輪著睡，反比先來的睡得多；第二旬先來的學徒看出來，又多排他一份夜；翁敬亭身邊管差事的執事（無名）分飯給他少一勺：「體弱的，吃不下。」他吃得下，沒說；宋知微連飯桌上誰多吃一碗都記，學徒們笑她，那位執事那碗她也記了；阿硯覆誦每一件差事。夜裡陸沉把厄安置在床腳疊好的舊衣上，牠偏要沿他的袖口鑽到枕邊；他搬回去兩次，第三次自己挪開半個枕頭 | **生**；**壓**（小）：閣裡也分上下 | |
| 10 | 英雄也會錯 | 他去問那個英雄故事；林伯潮承認當年過度自信、延後求援，也說盼有一天有人能把困在經脈深處的殘雷引出來 | **引**：盼（長鉤） | |
| 11 | 今天不淬 | 第一次要淬體，林伯潮帶他到伏雷坳外圍，讓他坐著看雷火，一整天什麼都不做；第二天又一天；他急得要命：這不就是在下面等？林伯潮只說「你看清楚它什麼時候弱」 | **修**；**引**：情 | |
| 12 | 它什麼時候弱 | 第三天他自己說出餘火的間隔，第一次伸手；《萬體鑄身經》殘篇，雷火走過身體；能承、能導，不能蓄 | **修／爽**：第一個力量兌現 | |
| 13 | 多導一次 | 嫌慢，夜裡偷偷多導，經脈傷了半個月；他說「我撐得住」，閣老按住他發顫的手腕：「疼，不是站穩。」不罵，把下一次往後推一個月（待決 2-05，工作選定）；唐岫捎來話：伏雷坳的劫痕不穩 | **蠢**；**引**：鐘 | |
