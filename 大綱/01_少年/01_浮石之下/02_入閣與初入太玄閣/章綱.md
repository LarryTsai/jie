**時線｜年齡｜境界｜傷｜持物**：十歲，第 02-05 章護礁夜後數日、第 02-07 章林伯潮上門之前（季尾除夕後約兩個月；護礁為季後第三個朔大潮）｜搬血｜第 01-19 章經脈受震，恢復中：能走山道，跑坡仍要歇｜鮑十一在第 01-19 章放在他腳邊的那截備繩；小浮石；厄在衣襟（白氣衝出時縮進去，無新能力）。

**因果入口**
- 第 02-01 章他在閣門口說「東段漏了，第三個彎底下」，先來的學徒擋他下山；簿上「存疑」；章末「總有一天，會有人拿鏟子下去」。
- 第 02-07 章既有：林伯潮照簿上那句叫人去挖，第三彎底下真漏。本章把這次挖掘搬到台前。
- 第 01-19 章鮑十一把一截備繩放在他腳邊；第 02-01 章祁望家份額落了海、沒排上船位，「下回再往上試，先叫我」；封坡後鮑十一沒有浮石的活。
- 第 02-04 章一指：神識剛離眉心便撞上牆，推兩次推不動。第 02-05 章洄辛教他先看水、看水每年留下的線；「你們岸上的人都想幫，幫完就走了」。

**場景順序**
1. **坊市。**護礁夜後幾天，祁望說閣裡雇人去山道第三彎挖土，按日算工錢，他要去；鮑十一也被雇去管繩，第三彎外側是斷崖。陸沉：「我也去。」「你去挖？」「我去看。」這回是他先叫祁望。
2. **山道。**陸沉背著那截備繩上山。上回走到這裡他歇了三回，這回兩回。
3. **第三彎。**坑已挖兩天，翻出來的只有石頭，土上插著幾把鏟子。帶工的是閣門口擋他的那個先來的學徒，拇指撥著腰間一片磨亮的木片；看見陸沉，木片停了：「又是你。」陸沉沒接話，把那捆繩放下。
4. **石壁前。**神識往石裡探，半寸就過不去——和海邊那天一樣，像一條線繃到盡頭；那天推兩次一次也沒推動，所以這回不硬推，退後一步看石面。晨霧剛散，靠上幾道淡白的痕一道疊一道，舊得像洗過很多遍的布；最底下另有一道，比別的都新、都低，斜斜往東，沒進一塊半埋在土裡的石頭後面。洄辛在淺水裡指給他看過：那是每年留下的線。他指著最上面那道：「你們挖的是這道。霜化了留線。今年的在下面。」學徒笑一聲：石頭上的霉斑也看得出年份？陸沉不解釋，只說：「你蹲下來，從這裡看。」學徒沒動。祁望先蹲下，臉貼近石面，手指在空中順著那道線畫過去，畫到半埋石便停：「真的有，斜的。」「那是光。」「那你也蹲。」雇工都停手看。學徒拇指又撥一下木片，還是蹲下去，看到霧又薄一層；日光斜過石面，那道最低的白線浮起來。他沒說話。陸沉：「挖那塊石頭後面。」學徒：「挖錯了呢？閣裡按日算錢，白挖一天，誰付？」祁望把鏟子拔出土：「扣我的。」——他家份額落了海、船位表上沒有他家的名字，他上山挖坑就是為了這一天的工錢；他對學徒又說一遍。坐在坑邊理繩的鮑十一起身，抓起陸沉放下的繩頭看一眼，認出是自己那天擱在他腳邊的那截，不說話，把繩繞過那塊半埋石打結，另一頭遞給兩個雇工：「拉。」石頭拖開半尺，底下是黑土。祁望三鏟：第一鏟土，第二鏟碰石一聲脆響，第三鏟一撬——一股白氣從縫裡噝地衝出來，撲他滿臉，眉毛、鬢角、鼻尖眨眼結了一層細霜，坑邊每個人的鞋面都白了，陸沉衣襟裡的厄縮成一團。祁望坐倒在土堆上，抹一把臉上的霜，抬頭咧嘴：「這回，真有人拿鏟子下去了。」
5. **他沒走。**學徒蹲在坑邊看那道縫，手裡的木片握得很緊；起身掏出炭筆和紙記下位置，抬頭問：「你叫什麼？」陸沉：「簿上寫了。坡下孩子。」白氣還在漏，學徒叫人搬石頭壓；壓一塊，氣就從旁邊鑽。陸沉蹲下看氣往哪裡繞，指給他們：「先壓東邊那角。」他一直待到縫口暫時壓住、霜在日頭下化成水，才和祁望下山。這是對洄辛「幫完就走了」的無聲回答，不說破；真正釘住要等第 03-06 章東段脈釘。
6. **下山。**鮑十一把那捆繩捲好塞回他手裡，一句話沒說。學徒照數付了祁望的工錢，一枚沒扣，也沒多說一句，揣著那張畫了位置的紙往閣裡去；陸沉回頭，看見那個背影往上走。祁望掂著工錢說，明天去北岸碼頭找扛貨的活。

**角色行動與選擇**
- 陸沉選擇不硬推神識（一指的教訓），選擇讓別人自己看見（洄辛的教法），選擇指完不走。
- 祁望拿自己最需要的那份工錢替他作保。
- 鮑十一認出繩，動手而不表態。
- 學徒輸了面子、不記仇：照數付錢、記下位置回閣稟報。陸沉沒有還手、沒有告狀、沒有和誰比試；是學徒照他所指自己蹲下來看見、自己叫人挖出漏點，守住定案 4／12「不打贏」。

**可量的變化**
- 坡腳到第三彎：上回歇三回 → 這回兩回（經脈恢復中）。
- 挖掘：兩天挖空 → 三鏟見氣。

**連續性**
- 名字不報：陸沉只答「簿上寫了。坡下孩子。」（此時簿上只有「坡下孩子」，名字到第 02-09 章才由宋知微補上，對上「那天你沒說」「那天你也沒問」）。
- 「支脈漏出的靈氣晨間結霜、霜化留線」是**小設定，只在本章用一次**；若日後與尋脈設定衝突，改為靈苔生長帶，場面不變。解說只留「霜化了留線。今年的在下面。」一句，其餘讓學徒蹲下來自己看。
- 學徒不御物，木片只是認臉的道具（見本節上方御物門檻）。
- 鮑十一認的是第 01-19 章他放在陸沉腳邊的那截備繩（是地裂那季最後一批那天的繩，不是更早哪一季的）。

**收尾與牽引**：學徒回閣稟報 → 第 02-07 章林伯潮上門第一句「第三彎那一鏟，是你指的？」「是祁望挖的。」；第 02-09 章宋知微在「存疑」旁補「已挖，實漏」；第 02-10 章他加排夜值照原文「你路熟，多走兩趟」，不加回扣面子的暗示；祁望去碼頭扛貨 → 第 02-11 章肩上的紅印；東段漏點 → 第 03-01 章三宗要閣在雷季前釘住裂口。

### 第 02-11 章〈半桶〉

**時線｜年齡｜境界｜傷｜持物**：十歲，入閣第二旬末的旬日。第一旬新來的照名單夜夜輪值、旬日也在值，他沒能下山（祁望在半山那個彎白等了一個下午）；這是他入閣後第一個下山的旬日，在第 02-10 章第二旬加排兩夜之後｜搬血（工作座標：前段）｜經脈受震仍在養｜木牌、母親的丹方；石匣已由管事收進閣裡；厄跟著他（無新能力）。

**因果入口**
- 第 02-09 章他看石臺下練御物的木片，想等安頓下來便問自己什麼時候也能學；木片停在其中一人掌心——就是擋門的學徒。
- 第 02-10 章先來的學徒排夜值，第二旬又多排他兩夜（「你路熟，多走兩趟」）。
- 第 02-08 章祁望：「以後每旬你下來，我就在半山那個彎等。」「下次你得自己走到這個彎。」
- 第 02-06 章祁望拿了工錢，去北岸碼頭找扛貨的活。

**場景順序**
1. **天亮前，閣頂石階。**閣頂石臺的缸要在早課前提滿（防坳裡飄上來的火星）。先來的學徒照學徒舍的分法說：「後段兩桶，中段一桶，前段半桶。」他沒問陸沉，直接把半桶推過來：「半桶也算一趟。」——有閣門口、第三彎的前史，這句是冷淡的公道。石階有三處平臺。學徒挑兩桶一口氣上去，桶面不晃；阿硯一桶，在第二、第三處平臺各歇一回；陸沉半桶，三處平臺都歇，第二、三處之間又停一回，歇四回。
2. **閣頂石臺。**石臺下有人在練御物，木片繞柱。陸沉問學徒：「那個要到什麼時候才學得了？」學徒看著木片，語氣不像對新來的：「木片要開了洞天才理你。我血搬到後段了，還差一口。」他自己也在等。
3. **缸邊。**宋知微記缸的水位與每人提了幾趟。陸沉請她在他名字後也記歇幾回。她說：「我只記發生的事。」他說：「那就讓它每天發生。」她寫「陸沉，半桶，歇四」，轉過簿子讓他看過。她的簿子從此是閣內的尺。
4. **午後旬日，半山那個彎。**陸沉自己從閣門走下山到那個彎，一回沒歇（下山）。祁望在彎口，肩上有扛貨磨出的紅印——他在北岸碼頭替人搬貨，自己的日子也在走；他先說上一旬自己在這等了一個下午。兩人坐在彎口往下看港口，千礁的靈舟正出港，祁望看了很久：「船上不用爬坡。」（本場只埋這一項）陸沉說閣裡有人一口氣挑兩桶上閣頂；「那你呢？」「半桶，歇四回。」祁望又問那天上閣門口歇了幾回，「五回。」「下回我問，你得說三回。」兩人下坡到坊市，耗到太陽偏西，他得回閣了。
5. **回山。**祁望陪他從坊市往上走到半山那個彎，路上他歇的那一回祁望替他數「一」，到彎口就站住不走。陸沉自己往上，祁望看得見那段山道，每見他停一次就大聲數，風把數字送上來：「二！」再一段，「三！」到了閣門，陸沉回頭，祁望還站在彎口，雙手攏在嘴邊喊：「比上回少兩回！」——第 02-01 章那天上閣歇五回，這回全程三回；同一把尺被朋友當面讀出來。
6. **夜裡。**他在廢紙上寫：「閣頂：半桶，四。山道：三。」想對自己的數字有沒有記錯，向宋知微借簿，翻著翻著，看見另一頁上林伯潮的名字與一行修脈舊事 → 第 02-12 章開頭。

**角色行動與選擇**
- 陸沉不爭半桶（定案 12：不還手、不告狀），但要宋知微把歇幾回記下來，把「少歇一回」當成自己的目標。
- 先來的學徒不是惡人：分桶是學徒舍的規矩；他也想要那片木片。
- 祁望自己替陸沉立了一個數，也在自己的路上（碼頭、船）。

**可量的變化**
- 閣頂：半桶歇四回（新的起點）。
- 山道：坊市到閣門全程歇三回（第 02-01 章五回）。
- 同輩三個刻度同時立起：兩桶不歇、一桶歇兩回、半桶歇四回。

**連續性**
- 境界座標全是工作座標，只由學徒的分桶話與御物那句帶出；正文不報「中段」「前段」以外的境界術語，不寫進設定檔。
- 不另寫祁望比坡（〈半山那個彎〉不採）。
- 「船上不用爬坡」只此一句，不提魏四、不提拜師。

**收尾與牽引**：借簿 → 第 02-12 章開頭「那夜借簿對自己的桶數時」；「想少歇」→ 第 02-13 章「這不就是在下面等？」更有分量（可選窄改：他想起簿上那欄「半桶，歇四」）；閣頂石階 → 第 02-15 章換一桶、第 04-11 章〈閣頂石臺〉。

### 第 02-15 章〈先穩骨〉

**時線｜年齡｜境界｜傷｜持物**：十歲，第 02-14 章第一次導火（第 0 天）之後第一至第七天｜搬血；能承、能導、**不能蓄**；一次一縷、一天至多一次、火全導出（林伯潮定的規矩）｜經脈受震仍在養，本章不添新傷｜袖中默寫的氣息次序（最後一轉空一筆、林伯潮畫的圈），夾在母親丹方裡；厄在枕邊（無新能力）。

**因果入口**
- 第 02-14 章第一次導火：「你現在會承、會導，還不能蓄。一天只做一次。」「三天後，我再帶你來」；那一縷火碰到受震後尚未恢復的地方時停了一下；默寫最後一轉空一筆，林伯潮畫了一個小圈；他想起洄辛的兩道水線（窄改）。
- 第 01-01 章卞老補鳶：「先穩骨，再沿原紋接。斷口還在晃」；「剛才為什麼停？」「骨還在晃。」
- 第 02-11 章閣頂半桶歇四；學徒「木片要開了洞天才理你」。

**場景順序**（重心在閣頂與夜裡；坳內只寫兩次導火的變化，不寫等待過程）
1. **第二天清早，閣頂。**還是半桶。學徒在缸邊看他的手掌：「看了三天火，導一縷就把手燒紅？」陸沉沒答。第一處平臺他本要停，腳卻自己邁過去——歇三回。宋知微寫「半桶，歇三」，筆停了一下，抬眼看他，沒問。
2. **第三天，伏雷坳，第二縷。**他照第 02-14 章的看法等內側那縷沉下去才伸手。火進來，走到經脈受震那處又停了一下，在晃。他想把它留住的念頭剛起，想起卞老的手指捏住第三折：骨還在晃。他等那一處不晃，才讓火沿原路走出指尖。林伯潮：「這回你等了一息。」「它在晃。」老人看了他很久，問他剛才嘴裡數什麼。「火在身上走了幾息。這回五息。」「數到多少都得送出去。火走得慢，是你的路寬了，不是你留得住。」回閣後他在那個小圈裡填上一行：「等它不晃再走」。林伯潮看過，沒改，只說：「每一轉的地方都不一樣，下回再看。」
3. **第四天夜，夜值經過後階。**先來的學徒一個人蹲在階邊，拿指節一塊一塊敲石頭，敲一下，聽一下。陸沉停住，沒出聲。學徒頭也不回：「千礁每年來閣修脈的人裡，有人說過，耳朵要練到聽得出石頭裡哪裡空。」「你練了多久？」「兩年。」又說：「閣太小。」「那你還在這裡？」「等籌碼。」他反問：「你呢？你想去哪？」陸沉看閣頂最高那重屋脊，夜裡有修士御器掠過：「上面。」學徒笑了一聲，接著敲。陸沉繞路走完夜值，沒把這件事告訴任何人。
4. **第五天清早，閣頂。**半桶，歇兩回。學徒把一整桶推過來：「半桶的不用歇兩回。」位置換了。滿桶比半桶沉一倍，他又歇回三回；宋知微寫「一桶，歇三」。阿硯在後面說：「你別趕在我前頭上去。」兩人提一樣的桶，第一次有了可以比的東西。
5. **第六天，伏雷坳，第三縷。**火走到受震那處，照樣在晃；他照樣等，等它不晃才走。七息，導得乾淨，手臂不麻。他笑出了聲，林伯潮沒叫他忍：「乾淨。」他問：「要是再多一縷——」「三天後。」林伯潮又要他等三天。
6. **第七天清早，閣頂。**一桶，三處平臺只在最後一處歇了一回。學徒挑著兩桶在缸邊看他上來：「最後那個平臺，是給你歇腳的？」宋知微寫「一桶，歇一」。再少一回，就和學徒一樣一口氣。
7. **當夜。**他躺著想：三天後才能再去；可只要再一縷，明早就不用歇了。→ 第 02-16 章〈多導一次〉。

**角色行動與選擇**
- 陸沉照規矩：一縷、一天一次、全導出；把卞老補鳶「先穩骨」的規矩變成自己導火的規矩——這也是下一章他要破的規矩。
- 學徒換桶，是閣中孩子對境界最直接的承認；夜裡敲石頭，他第一次是個在往上爬的人，不只是排夜值的群像。
- 林伯潮兩次把「數得多」壓回「送得出」。

**可量的變化**（一章只讓兩組數字出現）
- 閣頂：半桶歇四（第 02-11 章）→ 歇三 → 歇二 → 換一桶歇三 → 一桶歇一（由宋知微寫、學徒推桶說出）。
- 導火：火在身上走五息 → 七息（由陸沉回答林伯潮說出）。累計三縷都承住，接第 02-16 章「三縷都承住了」。

**連續性**
- 一次只接一縷；不寫「兩股並著走」，不寫「熱留幾息」（第 04-11 章他在守閣時才知道自己一次只接得住一縷）。不能蓄、不破境；一口氣到閣頂留給第 04-17 章之後。
- 洄辛水線只在第 02-14 章出現一次，本章不重複。
- 學徒不御物，本章不寫他的木片。籌碼的來處不寫「千礁看苗」，只寫學徒聽來的一句。
- 日程：導火在第 0（第 02-14 章）、三、六天；第九天以前的夜裡他偷去（第 02-16 章）。約多七天，合停淬滿月與第 03-01 章春潮的時序。
- 連續三章在伏雷坳的問題：本章坳內只兩拍，全章重心在閣頂與夜值。

**收尾與牽引**：三縷乾淨把信心推高 → 第 02-16 章貪心多導；第 02-16 章的錯正好是「連受震那處晃不晃，他都沒等」，違背他剛寫進圈裡的那行字；摔回半桶時宋知微只寫「半桶」、沒寫歇幾回。學徒「等籌碼」「上面」→ 第 03-02 章錢潤把籌碼放進他手心。
