# 北天行

工作選定。十五歲、化靈二雷三身，插在卷九出發後、卷十往中神州旅途中；故事順序依[全書總覽](../../全書故事順序總覽.md)。資料夾序號不改原卷號。

[大綱](大綱.md)為照夜洲探索、母材競取與第一次試鍛的唯一完整來源。[卷十](../10_往中神州/大綱.md)管理這段旅程與其後赴中神州的交通。[無妄與有隙](../../00_全書骨架/04_無妄與有隙/大綱.md)管理後期揭價、宗師、珍材冒險、成品與升器。

北天天幕、物權與回程遵D028；暖谷、新人物與八十日工作日程未經作者逐項批准。劫不在此取新雷、破銘紋或發現古戰真相。刻紋師授與基礎試片不等於少年立即成靈器師。
