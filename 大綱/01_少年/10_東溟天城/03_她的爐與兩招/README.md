# 03_她的爐與兩招

本段：海丹行在天城碼頭搭了一座半浸在海裡的試爐臺，爐底下就是冷海。生報名，要一張能反覆取海藥的交換券和跨域丹行推薦，不是替誰賺名聲。海族同代蘭汐把爐沉進冷水裡，預試先勝；生照原方同時投兩味，外熟內未合，這一次敗了。陸沉要拿雷火替她救那一爐，她把爐蓋按住：「這次是我的。」當夜他帶兩根木杖敲門：「明年到了。」她驗過他抬手收勢正常才接杖，十二撥，他不用兩儀吸，真碰到她的袖緣；她兩刺便停：「兩招。剛好。」「明年你在中神州。」「妳也是。」「那就中神州。」末場她不追蘭汐的低溫，另起一爐，成丹少、每一粒都穩；兩個人各拿各的，蘭汐一句「妳的芯是活的」，生才笑。候船時兩人各守半爐，他終於留住了回香——丹閣那一爐沒留住的那一下。
