# 02_天城

本段：東溟天城建在跨域傳送的節點上，塔頂一日三次亮。城裡一條長街走下去，各駐地帶來的仿天一段一段換：北天的幕、西極的獸星、南荒的樹冠、中神州的禁光；街盡頭的天門裡是另一片海的夜，一艘比太玄主峰的殿還長的大飛舟慢慢駛出來。收帆的中神州老舟師問他名字：「劫？沒聽過。哪個島的？」午後是封寒的天城：技藝分會裡他拿自己的劍路換一手不碰兵也能探出虛實的起手，陸沉在旁邊看見那一手；交流中心收碎片的商人拒收他的小樣；商盟懸賞牆上千礁重賞「黑帆鍔娘，尊者，劫正航」，陸沉沒揭；他用星羅身煉的一小瓶丹換回一件失了供能的測流殘器。第二天推薦處執事翻了一陣才找到「太玄，陸沉，百宗亞名」；技藝分會長廊掛著一百年的五域玉譜拓本，東溟那一欄最高只寫到第十一。他把整面牆看完，轉身去買船票。
