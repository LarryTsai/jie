# 04_碼頭

本段：回宗一日。胥匠用亞名定額的材料修現有的護具，把測流殘器的外殼修好，看了一眼封寒行路扣上的接環，只說這接法不是本地常見。出發前最後一夜，三身加一個封寒，泡在雷潭接來的水裡，沒人說話。Y97，天城往北的候船碼頭：剛破銘紋的霍驍等在那裡，整排候船的人自動讓出一圈。「冠軍不是我的。打一場。」陸沉看了一眼他還沒收穩的氣息，又看了一眼他腰上那塊冠軍牌：「五域見。」霍驍把冠軍牌解下來，收進衣襟裡，轉身走了，沒有留在碼頭目送。
