# 01_下海與先到的人

> 狀態：**工作選定，待作者釘板（2026-11-15 D173 結構化＋承接窄修）。** 依[逐章解凍規則](../../../../設定/00_故事定位/02_工作規約/逐章解凍與正文寫作規則.md)，作者釘板後正文才依序撰寫。

本段：鳴石港交貨後，兩人自己出船錢坐客舟一天到東邊外海的礁港，再雇一個只肯載到礁邊的小舟師。夜裡站在雪礁上聽見海底的鐘，封寒背上的劍在鞘裡跟著吟，他沒按：「這次我自己去驗。」退大潮下到倒生石脊，一層空、一層實，水面在腳下，魚群的影子從頭頂游過；外廊口已經有人——散修少女柏星瓢等了三天，「你雷一下去，過路的螺群就散了。」她測水長針一探就找到內廊，先到鐘亭、取走她做琴的殼；兩人那天看不懂潮、跟不上，時辰到了只能出水。
