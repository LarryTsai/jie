# 02_窄廊與鐘

本段：第三日窄廊，陸沉用聽得全的右耳在三處孔口先後聽鐘，一次判對——鐘聲先到、實水後到；封寒偏走〈看潮〉讀出的另一支廊，那是聲的路，潮頭在他身後把整段空廊一口吞掉，連他們走過的那幾層也翻成實水，他回頭笑：「我又追了聲。」陸沉當場把那個「又」說破，從此封寒要去驗他不攔，自己先把退路算好。兩人摸到鐘，上萬透明小螺穿過朝下照的日光撞在鐘上，封寒親手敲一下：「原來不是敲得重。」出觀時劍還在吟，他用皮繩把劍柄連鞘扎住，護劍、不壓它；岸上喫熱魚，吵風還是螺；第四日客舟回鳴石港，卓三槳押的艙位還在，人不在了。
