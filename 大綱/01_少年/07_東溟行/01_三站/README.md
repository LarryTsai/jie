本段：頭場雪後貨出庫，三身隨封寒憑「外」字牌出山門，走海岸線押貨。渡口散修卓三槳問「這傀儡幾塊靈石？」；長川港首徒冷照野問「太玄的劍，也敢到東溟來護貨？」，往南追失蹤的外門弟子；鳴石港交了貨，海訊牌上東溟這一代沒有太玄。卓三槳押護腕換回程艙位，「四天後見」；兩人自費去聽海面下的鐘（卷中支線[懸潮觀](../../08_懸潮觀/大綱.md)）。
