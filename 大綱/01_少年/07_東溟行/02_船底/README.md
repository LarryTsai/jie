# 02_船底

> 狀態：**工作選定（2026-11-13 D173 結構化＋承接窄修；待作者釘板）。釘板前不寫正文。** 依[逐章解凍規則](../../../../設定/00_故事定位/02_工作規約/逐章解凍與正文寫作規則.md)，作者釘板後正文才依序撰寫。

本段：從海底回來，卓三槳不見了，護腕還在秤婆櫃上；運鹽船吃水深了兩指。當夜兩人以回程貨客身分上船，船底四座鎮魂禁箍，船牙鮑橫震傷封寒護人的手臂、拖少年推向暗流；本尊一息兩事——兩儀吸住少年腳上的鐵鐐連人扯回、把船牙按上自家的箍；押艙的鉤子一支一支落地，回程靈料滑進暗流。「早一批的，下沉雷峽了。」
