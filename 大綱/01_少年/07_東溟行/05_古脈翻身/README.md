本段（整段喜劇）：回宗第三夜，三身分站三角，本尊泡在浴桶裡把雷絲一路接到雷潭——成了，護山大陣第一次在非敵來犯的夜裡亮出全形，全宗警鐘大作；他當場收乾淨。岳沉淵把濕淋淋的老七拎出桶，對滿天法相說「古脈翻身」；師兄姊排成一排各照脾氣。懸案簿「異動，源不明」，戒嚴五日，鎮岳一家飯桌上裝不知道；生只說「照記」，寫爐不寫人。
