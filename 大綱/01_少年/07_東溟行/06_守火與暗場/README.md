# 06_守火與暗場

本段：本尊魂創未好、荊問仍不准引大雷，白天去碧梧問雷火，在她的爐房撞見生緩放一爐，自願坐守外火；他追響添早半息，之後等她抬兩指才添；她夜夜守赤霞撐不住，在爐邊短睡，他看外火；收丹時她點明那爐給燎了手背的赤霞爐工，他認「那一寸是我」，她「我知道」，他「下一回，不從赤霞底下過」（2026-11-14 依核心人物選擇盤點窄改同步）；她講夏季那一爐的敗丹，天黑前收好爐照樣去赤霞。備百宗那些日子，他扛三塊陣石摸進九霄暗場想小接一口，遠端雷潭換拍扯斷接線、燎了半邊眉毛；賀成「那夜謝了。盾不讓。」盯著他扛回鎮岳，沒報上去。
