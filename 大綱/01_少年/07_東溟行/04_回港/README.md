本段：上岸，冷照野當著地方執事指證鮑橫一句不少，轉身要打一場；陸沉看著那把還裹著的劍，「百宗。」寄放鋪門口，江先生為先撈出七個人丟了追蹤匣，照實記下沒救回來的那一個，替封寒的行路扣補一個接環，「沒人回來，跟沒人去看，是兩回事。」當夜海訊牌刻上「太玄二人」，卓三槳多送一包魚乾；回宗前陸沉先把雷潭告訴了封寒。
