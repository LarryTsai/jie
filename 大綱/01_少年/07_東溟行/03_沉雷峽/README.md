本段：一個想截暗流、一個要親看；封寒吊著傷臂、劍裹外袍第一個進峽，本尊解下嵌鐵的護腕一起裹，數著古脈「七短一長」的拍子替兩人定步（承身守船回港）。峽谷盡頭冷照野抱著裹三層的劍在從地底打上來的雷火裡站了兩天，「路是我先探的」；星羅身在前引雷，雷散在他抬不高的左肩上成細光。本尊一個人往裡十步，一潭雷像泉水一樣湧上來——太玄地底雷脈的另一頭。
