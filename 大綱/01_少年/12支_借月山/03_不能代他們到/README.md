本段：Y193 白天。他不試拉舟，把星羅身立上岸邊最高那塊巖，只看、夜航報拍；韓頂一句「那我也雇十個人在岸上拉」，場方說岸上拉的不算舟；三身不等於三舟席位。雲行自己踩兩塊漂巖登上入口、碰到航標，又笑著折回：想三個人坐同一條船上看。封寒先看真實裂口，等巖轉，一劍切出幾息可見的風隙；曲洗星拿走過的圖換他的切風法。
