本段：Y191 出城，Y192 抵外山。上層夜航每次三艘；韓映渠的雙骨短舟能逆風切進最窄巖縫，曲洗星的雲翼最快，兩人都覺得劫臨時上場成不了舟。劫在框架布禁、兩儀整平，刻橫板；韓只說「你那條過不去」，不說為什麼。Y193 晨試航，他讀出兩股力不同時到，「差多少，我要吃一次才知道」，三人翻進淺雲池，他數到「半息又一拍」，橫板扭裂；韓看他們付了這一次，把自己的舟開過同一道風給他看，「你數得對」；曲先取第一枚航標。
