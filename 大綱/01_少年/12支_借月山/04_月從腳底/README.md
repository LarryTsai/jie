本段：Y193 晚夜航最後試段：韓換道搶先、曲取第二席；剩一席，外巖正移離高巖，只剩一道正在張開的縫；陸沉順著 02-02 扭裂的橫板布禁成鉸，岸巖上的星羅身報拍，封寒切側流、雲行一瞬放緩、他兩儀分收兩側——唯一一艘從兩塊正在分開的移巖之間穿過去的舟，歪著取第三席，「歪的好，睡得穩」。漂山頂一條長雲河，月從腳底出；封寒看見遠處白光，「還沒驗」；「那睡到天亮」。Y195 回集合城。
