本段：器坊前石魁捏扁顧小滿的護腕，承身不問就一斥替她做主；鎮岳四人各照脾氣反弄、兩罰，陸沉在雷罰地把第八拍站進骨頭、碰到往宗外去的斜股；沈山河收重；顧小滿一句「你讓結果不糟，是你的不糟」；石魁有了陸沉不在場的人生。D191：寒爐斷了寒苔，本尊帶著師兄姊塞給他的碎靈石下山，鄒老肩託他把孫兒帶回來；灰井一吸一吐，石魁在井上數爐門、他在井下揹人，朱六倒了；秦照雪寒爐的第一枚推到他面前。
