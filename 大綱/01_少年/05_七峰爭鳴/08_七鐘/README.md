本段：暗場迴流失了拍子，他等它回，數到七說「走」，七峰鐘無人敲同響；評議堂第十席給了遲了還回來搬的石魁，江離沒做錯也落選，第十一；夔聞摘下檐柱那塊牌，把空了快兩年的名字一格一格補上；藏玄石階上沒有人教他一課，江離在石階上重布自己的禁；鎮岳晚飯收住大比，老七的碗，斜股比秋天粗了。
