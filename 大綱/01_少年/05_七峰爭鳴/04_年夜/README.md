本段：星羅身停丹閣補進度，三身帶傷趕化靈期限；封寒先過去，在問劍峰頂讓天雷把劍推回來；冬裡三身各練各的（北屋乾地、九枚卡在第七枚震裂坪、神識跟步）；年關顧小滿那一瓣買下朱六的母石，赤霞剖成燈心，北壁根下沒有縫的那塊石頭給了賀成；年夜一人添一樣，陸沉十四，封寒「開春」。
