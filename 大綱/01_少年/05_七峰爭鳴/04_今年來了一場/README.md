本段：星羅身停丹閣補進度，三身帶傷趕化靈期限；封寒先過去，在問劍峰頂讓天雷把劍推回來；冬裡三身各練各的（北屋乾地、九枚卡在第七枚震裂坪、神識跟步）；年關顧小滿那一瓣買下朱六的母石，赤霞剖成燈心，北壁根下沒有縫的那塊石頭給了賀成，年夜一人添一樣；開春三口氣齊高，抬石壓住他的急；槐樹第十鉤空給過得去的人；雨裡厲朔空天自燒；沈山河的背、擦鐘繩，鐘變成一家人的；陸沉去九霄引劫，「那我帶一場去」，三身一劫讓封了一年的半邊亮一息，劫雲落下九霄這一年唯一的雨；開賽前夜承身掛九枚，坪不裂。
