本段：開春三口氣齊高，抬石壓住他的急；槐樹第十鉤空給過得去的人；只入隙，雲繞開九霄，雨裡厲朔空天自燒；沈山河的背、擦鐘繩，鐘變成一家人的；陸沉去九霄引劫，「那我帶一場去」，三身一劫讓封了一年的半邊亮一息，劫雲落下九霄這一年唯一的雨；開賽前夜承身掛九枚，坪不裂。
