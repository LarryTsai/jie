本段：第三日一個跑屋簷、一個跑街上的水面，午後巷口撞個滿懷，同時開口「屋簷！」「月光！」——少掉的星是被屋簷擋掉的一小片天，牆月是雨滴把今夜月光送到牆上；誰先說的，吵到賣糖的收攤。第三夜大雨，最後一題是第一個月亮亮在誰手底下：文守原環可承的轉動，他在自己帶的薄石上布窄側禁，讓雨先散再承，一次架成，滿院的雨，每一滴裡都有一個月亮；子時雨頭猛一倍，承身扛著薄石冒雨跑到院東再承一側，「這一角的月，有我三條巷子」。天亮歸器，環仍缺；「平手」，租錢一人一半，各在對方頁邊補一個字，笑著互認「那我們都猜錯一半」。
