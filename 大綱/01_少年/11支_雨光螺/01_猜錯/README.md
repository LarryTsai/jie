本段：古禁共得之後，劫文去買解禁用的小材，看見器鋪屋簷懸著一隻破舊的雨光螺：銅環裡滴下一滴水，地上亮了一片細碎星光，雲遮月後就沒有了。兩人付錢借三夜。第一夜他以為舊器藏了光，引雷照內壁，雷光被算進去；文奕以為是排星的禁，八卦盤推得整齊，雨落後總少一顆。第二夜各想救回自己的解釋，都不成；一只灰碗被鄰家孩子端去洗菜，院牆外亮了一輪極薄的月。
