本段：古禁共得之後，劫文去買解禁用的小材，看見器鋪屋簷懸著一隻破舊的雨光螺：銅環裡滴下一滴水，地上亮了一片細碎星光，雲遮月後就沒有了。兩人付錢借三夜，賭誰先讓它照出天上的樣子，輸的付租。第一夜他只放一縷雷，盆裡所有星跑成一個亮點——「它吃光。誰的都吃」；文奕的八卦盤推得整齊，少的那顆跟著盆走——「是水」。第二夜他用承身扛石換的錢買薄石覆盆，驗出載光的是雨；文奕照殘序排水，星與天疏密不合；「你的光沒有水」「你的水沒有天」。一只灰碗被鄰家孩子端去洗菜，院牆外亮了一輪極薄的月，兩人都沒猜到。
