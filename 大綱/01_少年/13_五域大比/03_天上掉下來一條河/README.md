# 03_天上掉下來一條河

本段：Y208 水患夜。南荒洲高過白線，河頭翻過天邊，一整條河砸向青蘆渡；俞清漪第一個跳，他第二個，雲行跟著，文奕已蹲在三千年沒開過的古禁上；堤是人斬的，第四處在上游；他在河底殺了三個斬堤的胤朝死士，把一具承身散進水裡，量出七息；回到堤上，「後天打你」。同一夜河的另一邊，韓鐵衣在天域邊緣的渡口留下兩個送石的活口，後腰挨一記；天亮水缸邊，「抖是後來的事。後來抖了，我在。」
