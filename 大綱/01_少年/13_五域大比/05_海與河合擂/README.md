本段：Y210 決賽。東溟、南荒兩條天索交叉，海與河合出一道潮線。雲行開口數「一」，全場跟著數；第三疊他讓左臂打實；她亮出藏了三年的七八併拍，他往前一步踩進她換氣的那半息，那具只要七息的身散在第八疊回勢裡；數到「七」，再沒人數「八」。東溟擂洲升三丈，五條天索一齊響。
