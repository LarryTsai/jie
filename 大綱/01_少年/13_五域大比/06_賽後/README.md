本段：Y211–220（＋回東溟七日）。閉幕夜天露落在東溟洲，整碗海從裡面亮起來，費瑜躲不開；俞清漪說青蘆渡的人有房子住，「那三個人，你沒報」「報了，報給他了」；玉譜上他那一行擦掉，只剩一個字「劫」，崔砧的兩罈酒喝光了；傷復第二天，他在青蘆渡遇見背長尺的溫棠：「先看原陣。」五索齊鳴時不響的那一條，是從雲行家那邊拉上來的，照塵從雲裡走上來；回東溟七日，一船人平安，韓鐵衣交給師父一張紙：「我放的。」
