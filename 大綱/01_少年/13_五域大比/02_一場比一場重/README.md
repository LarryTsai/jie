本段：Y206–208 小組三場。西極洲上本尊正面對拳，壓得崔砧膝蓋跪進沙脊；當夜生在丹醫考核爐裡夾出一塊千礁碎陣石，場邊鎮岳五師兄看著她的袖口（生的視角）；中神州洲上三身分立三角、第四角是一塊他自己布禁的試板，一息四路，斷公冶旌十二旗，看臺第一次喊「劫」；當夜天衢夜市，一頭鹿不上橋，半片鏡銅一人一半；回院路過試劍臺，看封寒與宋明川同時落劍。Y208 南荒洲，俞清漪九疊回潮把他推出白線、星羅身散在河裡——全卷唯一敗場、第一次見血；傍晚生把碎陣石包在丹紙裡放在他手邊。
