本段：Y209，八強與四強同一天，當著全場改版。晨，他只用本尊把整塊北天洲推傾半度，石聞川連人帶樁滑出白線；巳時雲行吃滿十二印不出線，被收買的裁場判負；午，四強他一步陷一寸走到赫連驥面前，一腳踩碎歪掉的地，一掌斷他持印的右臂，三塊宮牌落在他腳邊：「你的人。在河底。」另一半區，封寒砍到俞清漪第八疊。同一天，韓鐵衣為一船人把兩個活口放了；夜裡他把碎陣石放在費瑜杯旁，躺在白線上把散了一日夜的承身重凝，只打算用它七息。
