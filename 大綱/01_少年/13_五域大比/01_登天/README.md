本段：Y205 登天；當夜開幕，他一口真元把睡了一百年的東溟洲吹醒，費瑜在代表團裡笑「島上的」，三師兄解開那圈布，五師兄只說「退」；玉譜排他第三十九，「東溟島子」。同一夜舟尾，費瑜把東溟留影遞給赫連驥；次晨奚箴當眾落籤，乙組：陸沉、俞清漪、崔砧、公冶旌。
