本段：十三歲入秋前一日到入秋次日。胥匠託承身帶話，脈口那一把鑿子要先吃一道雷，他答應，知道會記在九霄冊上；滕北的父親上山，滕北當著父親不摘「明日雷」、再驗「指抽，臂未抽」、不上船；入秋次日午時外爐叫雷淬第一百二十把，夔聞把那一行再送宗主殿。接卷五鎮鈴與重鑿。
