# 02_還山

本段：頭場雪落到第三寸，整座山的石頭一起講〈還山〉。賀成第一刻就睡，岐影去殿外生火，石魁「這不是拳」、靠著柱子打呼打得瓦在響，顧小滿把飯熱了三次；本尊撐到子時睡去，承身和冉晴川坐到天亮。天亮承身推寺前老松，借來的力收回借它的那一塊岩，借地的裂紋第一次往裡合回；第二次挪了半步就亂了。下山時小燭追到寺門口，「懂了就回來」「不懂也回來」。
