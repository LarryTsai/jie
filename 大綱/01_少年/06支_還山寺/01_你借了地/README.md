本段：頭場雪就要落了。承身站完樁開門，冉晴川站在廊外、肩上一層霜——灰圈之後他第一次自己找上門，不帶劍、不問那一推怎麼練，只問「你借了地。拿什麼還？」承身答不出。外嶺有座比太玄還老的寺，石講席每年頭場雪那一夜自己講一遍古法，聽過的人都說聽不懂——「去過兩年。睡著了兩年。」第二天本尊、承身上寺，石魁、顧小滿、賀成、岐影跟來；寺裡只有掃雪的老婦和添油的小燭，「天亮的時候，都在睡。」
