# 日月未央

狀態：**作者批准回填（2026-10-16「接著做日月藥天回填」）；具體事件為工作選定；正文凍結**。分篇依作者裁定A（2026-10-12）。

## 定位

嬋九歌跨篇人物長線：下無極《[月下共逃](../../02_離鄉/11_月下共逃/大綱.md)》瀕死、月下別君之後，至約31歲首席遊歷上路為止，26章五段。她在太陰狐闕依誓月祖制判負、朔養修復太陰本源、拒祖血而失泉、在虧庭從活根養回**一道淡月影**、月籠取鏡就任首席，經虛道、斬我，最後在闕議撤銷狐闕對陸沉的懸賞。她與劫分別十一年，不依賴他；太陽在本篇只是線索與「先把月養穩，再去見日」的決定，沒有任何太陽傳承或太陽影身。

後接：[日月藥天](../../04_成道/07_日月藥天/大綱.md)（約31歲，三人同行）。人物卡：[嬋九歌](../../../設定/03_人物/03_下界天驕/嬋九歌_天狐月道.md)。
