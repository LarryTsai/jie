# 全書骨架

跨卷跨篇的全書級工具：骨架、年表、對照與長線。單一卷篇的故事不放這裡；故事以[全書故事順序總覽](../全書故事順序總覽.md)為入口。

| 檔 | 內容 |
|---|---|
| [全書大綱](全書大綱.md) | 一句話、四條線、五段長弧、兩條紅線、四鉤；後段原篇摘要保留追溯 |
| [卷號與篇號對照](卷號與篇號對照.md) | 前十九工作卷號與原二十八篇對照 |
| [全書年表與門牆尺度](全書年表與門牆尺度.md) | D128：十八歲到約三十七歲的十四段、外界曆齡與門牆 |
| [世界認知揭露時間線](世界認知揭露時間線.md) | 留舟島到上界，劫每一步看見多少世界 |
| [世界開放與往返矩陣](世界開放與往返矩陣.md) | 各層世界何時開放、能否往返 |
| [大比利益階梯](大比利益階梯.md) | 百宗、五域、四院、九界四場大比的利益設計 |
| `01_人物線/`（[主線人物行動與反制總圖](01_人物線/主線人物行動與反制總圖.md)等七檔） | 主線人物、反派、敵手、聞人錦、文奕、修行所得、鎮岳峰露法帳 |
| [古路與烏蘅](02_古路與烏蘅/README.md) | 跨第 15、17、20、21、27 篇的古路長線與中閘七日 |

主線路線總稿、九雷取得與大比年齡線仍在設定區，待設定區整理時決定是否移入本夾。
