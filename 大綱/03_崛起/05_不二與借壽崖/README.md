# 不二與借壽崖

[連續大綱](大綱.md)保留兩篇完整主幹與中段天驕交鋒、封寒轉鐧、燈下分工、冬至高潮及非正文檢驗樣稿。這是現行候選，尚未批准新人物、孤光局部地規及宓長庚斬下之我禁術；不更新正式設定。

原競稿三案與逐輪修補表移除，不再把落選舞台存為待辦。作者若選此主幹，真正需要一起裁定的是禁術代價與局部地規三條，詳大綱第九節；封寒境界應依人物及年表統一，不以推估升格。兄弟衝突產生記招分工，不安排決裂。記憶交易留太素道宮；古路、烏蘅與中閘不靠孤光原再添一套真相。
