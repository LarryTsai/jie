# 競稿任務單：第 17 篇〈陽閘〉

2026-10-09，主 Agent 依[AI 團隊競爭創作規約](../../../設定/00_故事定位/AI團隊競爭創作規約.md)開立。三位寫手收到同一份任務單，第一輪互不讀稿；完成後由未參與的 Reviewer 比較。**只寫篇章大綱與競稿，不寫正式正文、不改任何設定檔。**

## 一、作者裁定與要求

作者 2026-10-09 同意第 17 篇（現為待補空位）安排〈陽閘〉，但**只批准篇位與核心方向，九道閘問的具體故事未定稿**。要求：

1. 〈陽閘〉是**真正的大型修仙秘境篇**，不是取得跨界鑰匙的前置任務。
2. 九道閘問要有不同的修仙奇觀、試煉、傳承、機緣與天驕競爭，**不能只是九道解謎題**。
3. **駱霜、戎霈、顧星遲**各有自己的動機、戰鬥、所得與代價，不是陪陸沉闖關。
4. 陸沉取得陽閘印之外，要有**值得記住的戰鬥高潮**，以及**禁制或雷道上的實質成長**。
5. 聖土古鐘第一次響起，但兩界人物都**不應立即理解真正原因**。
6. **保留八萬年前古路的歷史懸念**：不在第 17 篇提前揭露烏蘅與祁承晏的完整真相。
7. **拿掉未來跨界伏筆，整篇仍是獨立精彩的修仙故事。**
8. 不要寫成九章流水帳：由寫手自行設計大型事件、天驕衝突、意外轉折與高潮。

## 二、三位寫手的核心方向（必須真正不同）

三版至少在「核心欲望與承諾、主要對抗者、探索結構、高潮的選擇與代價」中改變兩項。為避免撞車，各給一個核心方向（可在其內自由發揮）：

| 寫手 | 核心方向 |
|---|---|
| **甲** | **天驕爭局**：陽閘開啟是上無極各宗的大事，名額、規矩、背後的宗門與勢力角力推動全篇；主要對抗者是同代天驕與其背後勢力的主動布局 |
| **乙** | **秘境自身的危機**：陽閘（或斷峰群）正在出事，闖閘者被迫在求傳承與保命、救人之間抉擇；主要對抗者是失控的古禁／天地異變與趁亂者 |
| **丙** | **閘的意志與道之辯**：九道閘問在測「理解」而非力量，閘中留有古代守閘者的遺意或殘影；主要對抗者是一個與陸沉道路相反、卻同樣能解閘的人，高潮是兩種解法的交鋒 |

## 六、每份方案必交

1. 一句話總綱；**為什麼拿掉跨界伏筆仍然好看**。
2. 完整弧：陸沉、駱霜、戎霈、顧星遲（及主要對手）各自想要什麼、為何進閘、如何受阻、對手如何主動反制、轉折、高潮的選擇與代價、各自所得與後果。
3. 秘境結構：九道閘問如何組成**大型事件**（可分組、可並行、可崩塌、可被人搶跑），各有什麼奇觀、試煉、傳承、機緣；不要九章流水帳。
4. 陸沉的戰鬥高潮與禁制／雷道成長（具體寫明學到什麼、付出什麼、之後怎麼用）。
5. 鐘響：如何發生、兩界各誰察覺、為何不懂。
6. 中段牽引：至少三個中段事件，各說讀者此刻期待什麼、誰在追什麼、局面怎樣改變。
7. 兩場試寫（可讀的場景散文，各約 1000–1500 字）：一場天驕衝突或意外轉折；一場陸沉的戰鬥高潮。
8. Canon 影響表與新增人物／機制清單。
