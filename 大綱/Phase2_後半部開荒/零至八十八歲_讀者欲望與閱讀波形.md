# 零至八十八歲：讀者慾望與閱讀波形

2026-10-07。作者指定：先畫整條人生的爽感、期待感與仙感，不先添十個遺跡。依現有[全書大綱](../全書大綱.md)、[年齡線](../../設定/05_故事主線與揭露/九雷取得與大比年齡線.md)及Phase 2續開稿作定性審查；不是正文閱讀測試，沒有實際章數，不能聲稱已量出讀者分數。

本輪借作者提出的兩種閱讀經驗作設計問題：一場冒險能否打開整片世界；一段安靜歲月能否仍把人帶向更深的修行。這是本書的工作方法，不作兩部作品的逐章研究，也不搬用其人物、寶物或情節。

## 一、三條曲線要分開看

**爽感**：讀者現在得到了什麼——發現、取寶、勝負、突破、反殺、重逢和情緒回報。不是隻有戰力碾壓。

**期待感**：讀者是否有一個具體、很想知道答案的問題。威脅很大卻答案顯然，未必牽引；人物很忙卻不知在等什麼，也可能平。

**仙感**：這一段是否讓人感到身在陌生的修行天地，看到法、生命、歲月與世界的新尺度。奇觀羅列不等於仙感，普通生活換術語也不算。

理想波形不是三條都長期高位。可以爽感暫低、期待很強；可以戰後安靜、仙感更深。危險的是三條同時鬆掉，而且下一站只剩「另有一項工作」。

以下「強／中／弱」是大綱目前能提供的引力，不是文筆評分。「待展」表示骨架有承諾，尚無足夠故事證明。

## 三、示意波形：不要把安靜誤畫成低谷

| 大段 | 期待的起伏 | 目前判斷 |
|---|---|---|
| 少年至九界 | 家中願望 → 私探 → 得雷 → 修行與朋友 → 大比 → 深界未知 | 波形與世界逐層展開已在，不需為新方向回頭重造 |
| 首聖土至下無 | 陌生天地 → 回返 → 上界壓迫 → 追殺／反殺 → 背罪 → 非正規上升 | 引力強，需補探索的喜悅，不能只增加苦難 |
| 上無入口 | 對新天地興奮 → 誤判古路 → 救生百日 → 合爐 → 傷後餘韻 | 完整波形雛形；餘韻要把慾望交給下一站 |
| 同代至聖土前段 | 城與同代 → 真相逼近 → 決裂 → 各自遠行 → 再入聖土 | 情緒引力在；分路期的求法與未知尚不足 |
| 聖土長住中後段 | 日常與地方 → **長段缺主慾望** → 校正日期 → 九霄 → 河階 | 最大斷層；不是把每一年加一場大戰，而是缺一個能展開世界的大篇 |
| 墜落至復出 | 高處敗落 → 雷池未知 → 炸池 → 餘痛 → **復修追索未展** → 重返碎錦原 | 下降應更深、更仙；不能降成普通工作的成長故事 |
| 真仙至終局 | 祖脈共振 → 大羅認責 → 壓境護柱 → 窗口逼近 → 守錨 → 回家 | 大波峰已有，需有短餘韻避免真相與戰役互相淹沒 |

「父亡後整理家信」「雷池戰後看殘留古痕」「長住後第一次發現一種舊法在自己身上改變」都可以慢，但下一個問題仍在。吃飯、做工、交接若只回答是否善待人，不接修士此刻真正想追的東西，就只能短留。

## 四、一篇要打開一片世界，而不是一項任務

下一個選中的代表大篇，先寫一張展開圖：新天地、不同生靈、各有目的的天驕、值得爭的實物或法、可親見的歷史痕跡、現在的敵人，以及出口才看見的更大尺度。

不是七項逐件配發。它們要因同一場探索彼此作用：某種生靈的承雷方式使古痕可讀；古痕引出可爭的法；天驕因各自需求結盟與翻臉；大戰改變去路；所得在下一篇可以真的使用。讀者先想知道入口裡有什麼，再想看誰搶得到，最後想知道新路通向哪裡。

每篇記兩個問題：**眼前要收的問題**與**收完後想追的問題**。前者不能一直拖成遠期伏筆；後者不能都指向同一場古戰。真正拿到的寶物、贏過的對手、互相認可的朋友與主動選的遠行，都是慾望接力。

## 五、這輪先保住、先看、先停的東西

先保住少年私探、地獄行、南荒多幕、無間界潮、九界大比、首次聖土、渡劫淵、八身救生、九霄與終局守錨。它們天然有強問題，不因本輪轉向就回修。

下一輪先查看31–35的既有禁制城是否已能承載一片世界，再選50–60聖土平段作代表大篇；73–78復修追索是第三優先。不是每個十年必須有同樣一座秘境；決裂期可以由封寒的求知遠行和劫自己的修行異變形成不同波形。

停下[八個冒險缺口](二十至八十八歲_高潮密度審查與八個冒險缺口.md)末段「立刻先展開逐天仙藏」的順序。八案降為種子庫，沒通過本篇慾望接力與世界展開核對，不因名字好看就插進年表。生活線也不刪，先調主次，避免把已補的一切推倒重來。

這份是全人生第一版閱讀波形，不是全書已好看的結論。下一次開一篇，先給讀者能追的問題與不同階段的回報，再以因果、能力、地方自主和代價檢查可行性。品質控制負責讓冒險站得住，不能代替冒險本身。
