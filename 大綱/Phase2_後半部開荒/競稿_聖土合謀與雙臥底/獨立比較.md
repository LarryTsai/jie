# 獨立比較：聖土合謀與雙臥底（方案 A／B／C）

Reviewer，2026-10-09。沒有參與三份方案的寫作。依規約先比較閱讀欲望、人物和中段，再核 Canon。所有內容仍是工作候選，不升 Canon。

## 〇、結論先講

**推薦排序：B ＞ C ＞ A，不全退。**以 B〈鐘守與啞鐘〉為主幹，但交作者前要先修三處（第五節）。

- **B 的長處**：中段的牽引最強，揭露鏈最守得住第 26、27 篇，和現行選定大綱咬合得最緊。救人之後，賭注從「救一個朋友」升到「劫自己骨頭裡那條線會不會斷」（啞鐘）。
- **C 的長處**：反派最好（最想重開渡口的人，就是要人閉嘴的人），中段的兩難也最強（手上握著真話，卻只能用假名字說）。可惜玉簡把公主案的機關幾乎全寫在紙上，第 26 篇的揭露會被提前吃掉，這要大修。
- **A 的長處**：八萬年那條線的情感對稱最漂亮（「兩個人都被自己的兄弟出賣了」），也最貼近作者原話裡的「皇族」。但盛會裡劫只是捧燈的人，兩匣人被擠到遁一之後，錯誤答案又把罪推到受害者身上，臥底大篇本身最弱。

## 一、閱讀欲望與中段（先比故事）

### 1　逐段牽引

| | 讀者在追什麼 | 最值得留的場景 | 最容易棄讀的地方 |
|---|---|---|---|
| **A** | 進得去嗎？→ 撐多久不露？→ 薇恩為何自己上？→ 劫知道鐘是自己叩響的 → 米蕾救不救得回 | 試寫二〈潮門〉：三個人事先沒說好，伊萊恩自己決定燒哪一處；那道拐了直角的雷，後來成了追查劫的線索。第十段劫用本名走進王庭，伊萊恩說「不是借。是我按的。」 | 段三盛會：劫是燈奴，三輪試裡他只能捧燈、敲暗號，天驕交鋒都是別人的。段七又是一次救援（米蕾），像第一次救援的重播 |
| **B** | 誰在聽鐘？→ 兩匣人冠頂露餡 → 啞室有人敲回來 → **救人不夠**：啞鐘一響，陽閘自封 → 回爐夜 | 試寫二〈送縫〉：貝倫認出自己教過的撤離暗號，配合著退到崖邊，臨墜前說「下次記得付爐租」（接得上四人隊「為誰付爐租吵」的舊事）。回爐夜劫拆下鐘舌，威斯坦說「原本該由我們來選」，這句話一路壓到段八的先問 | 第 1–5 月的生活段偏流程（學呼吸、炸爐蓋）。新勢力與新名詞密度最高，前兩關要靠試寫的質感撐住 |
| **C** | 進得去嗎（照魂）→ 誰才是反和睦者 → 讀玉讀成什麼 → 米蕾拒絕被救 → 大議 | 試寫二〈讀玉〉：劫只讀一句真的「不是寫給鄧莫爾的」，塞奧德的局當場塌掉。米蕾說「我要從正門出去」。阿爾賓「兩樣都不算」 | 幕九大議劫不在場，主角的高潮交給別人。整段的事件密度最擠（C 自己也承認） |

### 2　中段是改變局面，還是只多一份資訊

- **A**：段四的轉折是好轉折。劫知道塔姆林是因為他叩響的鐘才被抓，罪疚變成他自己的事；薇恩讀了假頁，從此不再替塔姆林說話。段五到段七是「反制→假戰→受疑」，一路推進局面。弱點是劫本人的修行沒有長進：除了雷丸失手和遁一，臥底期間他沒學到任何東西。
- **B**：段四之後，劫要同時辦三件事：救人、保住手鐘、不讓啞鐘響。最後一件直接接上乙案第二輪寫定的「陽閘的問沒人答就會收回，斷峰群的漏會更兇」（〈方案乙_第二輪〉L323、L371），這是劫自己欠雜役營的債，不是替別人辦事。兩匣人放在「聽冠」一關，是三案中唯一把既定事件變成盛會一部分的。
- **C**：幕五到幕七是三案裡最好的權謀中段，對手主動製造錯誤答案，主角被迫用假身分說真話。代價也收得很漂亮：見劫那夜，假名字和它說出口的真話一起被拖倒。

### 3　拿掉「查古戰」還好不好看

- **B**：仍然好看。聽鐘會（四關）、妮薇的「邊外有沒有人」（真正的奇觀渴望）、霍林的友情、艾姆里斯這個誠實的獵手、鐘骨廊裡有人敲回來，都不靠古戰撐。
- **C**：仍然好看。換翼會有三條場可看，伊萊恩對喬里是真打，芮恩看穿了沒說破，關娜照魂接上首訪的舊事。
- **A**：拿掉古戰，盛會本身是一場議婚競賽，很好看，但看頭在薇恩、喬里、伊萊恩身上，劫的部分只剩捧燈和暗號。

### 4　舊版骨架搬得怎麼樣

舊版第十八部的骨架：潛入立足 → 茶會 → 與荒交會、假戰 → 受疑 → 追獵 → 反殺 → 拆王。

- **B 最完整。**假戰（護衛當眾挑戰受刑者，每一鐧都打在鎖上）忠於舊版「封寒挑戰荒，金鐧震碎禁錨」，又換成了新版自己的人物和暗號。「拆王」對應成拆下啞鐘的鐘舌，還帶出「替人決定」這筆債，正好接上終局的「看見缺、不改、先問」。
- **C 也忠實。**假戰是決勝場上鐧「打偏」，打在陣節上；生活小事直接搬了桌下互踢和「不行／我還沒說」。試寫一的「理論上／身分上」幾乎是舊版茶會的原句，致敬可以，正文要改寫。
- **A 的假戰最有原創性**（三方都沒有事先說好，最貼近舊版那句「連彼此都沒有完整說明的戲」），但缺少「拆最上層」的對應物。

**偽裝原理的一個提醒**：任務單第二節寫的「修改自己去通過規則」，是舊版在第 192 題裁定**之前**的寫法。舊稿 L1936 的更正說明已經改成「陸沉改變系統認為他是什麼」，不改肉身與血脈。

- B 的「靜者＋虛晶」讓驗氣器本來就讀不出東西，最接近裁定後的版本。
- C 的禁封死區、殞星烘疤，A 的殞星雷疤，都是在自己身上做表層的痕，不算改血脈，可以接受。但 A 把雷疤「烙在丹田外層」，是三案中最接近改肉身的一個。
- 三案都沒有萬能偽裝術。

## 三、Canon 查核

### 1　「第 17 篇陽閘」是不是撤出的內容（特別要查 1）

**不是撤出的內容，而且是現行選定大綱。任務單這一條已經過時。**

- **撤出的是舊第 17 篇〈你說過你叫劫〉**（〈第17至19篇_撤出版舊案〉L29 起）。
- **新第 17 篇〈陽閘〉作者已在 2026-10-09 選定**：見總稿 L609–617「選定大綱為〈陽閘〉融合版大綱」，以及〈古路與烏蘅／作者裁定紀錄〉第 3、5、7 條。該篇所得裡寫著「印朝西叩，聖土鐘腔的古鐘響」。
- **作者選定的〈中閘七日〉大綱**（裁定紀錄第 13 條）第 20 篇開場寫的就是：「斷峰群那枚古印沉進陸沉的道基之後，他骨頭裡一直有一條線往西拉。他帶著封寒，走高路進了聖土。」
- **任務單過時的地方**：它說「第 17–19 篇空位約 27.5–28.5 歲，作者尚未決定要寫什麼」，引的是〈統一新年表〉L57、L163（10-08 的口徑）。10-09 第 17 篇已有〈陽閘〉，只有第 18、19 篇仍「待補」（總稿 L619–627）。

**風險評估**

- A、B 依賴陽閘當起因，風險**低**。
- 但〈陽閘〉只批准了篇章大綱，正文未寫；古路的歷史與閘的機制仍是工作方案。B 新加的「答『不』就讓陽閘立刻自封」（啞鐘），是在乙案第二輪「沒人答就收回」之上再加一條規則，要作者認可。
- C 完全沒用陽閘。這不算衝突，但漏了選定大綱「往西拉」那條線。另外，乙案第二輪原本給第二次聖土的主動理由（陽閘的問會收回），C 沒有用上。
- **主 Agent 應先更正任務單第三節**，否則下游還會有人以為第 17 篇是空位。

### 2　「聖土皇室」（特別要查 2）

依據：〈勢力總表〉L831「不設帝朝、不設共主」；〈當代勢力〉L12「沒有帝，也沒有共主」。

- **A**：明確改成烏爾溫渡口王室（地方王國）。這也是三案中最貼近作者原話「臥底到聖土皇族」的處理。
- **B**：舞台是鐘院（王室旁支，鑄鐘為業），沒有碰到皇室問題，但**離作者原話最遠**。
- **C**：舞台是奧德米爾的莫凡王室（中心的一國，國君西里爾，見 03 檔 L78），沒有衝突。

三案都沒有寫出聖土皇族。作者原話裡的「皇族」只能讀成「一國王室」，這點要先向作者說明。

### 3　揭露鏈（特別要查 3）

| | 新錯誤答案 | 提前說完公主案了嗎 | 分走太宸的責任了嗎／陰謀是不是全部戰爭責任 |
|---|---|---|---|
| A | 「公主自己把陰閘潮曆交給了使節」 | **中度風險**。改過的那一頁寫明潮曆流向使節，再加上段八「光不是長子」，讀者在段七、段八就能懷疑使節。第 26 篇遺念「行程只交給弟弟」反而會被讀成揭曉。另外，這個答案把罪推到受害者身上，雖然和乙案寫的「錯二：沒讓第二個人看行程」（〈方案乙_第二輪〉L182）呼應，讀來會不舒服 | 沒有分走太宸。主戰派「未查先動兵」仍算他們自己的。第 27 篇讓薇恩在芸香夜**加念艾蒙之名**，這違反主 Agent 已作的處理「芸香夜公開改讀，不另加祖上一份」（裁定紀錄「主 Agent 依授權自行處理」第一條），也讓第 27 篇更滿 |
| B | 「守門人合謀」：聖土鐘守主謀，對岸關口之主下手 | **守得最好**。手鐘殘存三行把讀者引向玄闕和商玄度。他們是真的共犯，卻不是佈局者，祁承朔留到第 26 篇。第 21 篇玄闕閘衛鎖關、第 25 篇玄闕祖脈都能接著加固，再裂開。**但有兩處要修**：(a) 殘存的第三行「鐘響七次，我說不許答」，等於先交出第 27 篇的七道刻痕，也先交出薇恩在王室庫自己對出七個日期的那場發現（〈方案乙_第二輪〉L420）；(b)「那道兩人共守的閘」在段七就點出中閘，削弱了段八「門後面是什麼？」 | 合謀者在第七叩時「已聽出是長子的印仍說不許答」，構成聖土一側的在選，與太宸的在選互為對照，有稀釋太宸的風險，B 自己也標了。另外，「不答」從烏爾溫議會的集體羞恥（三方抹除表 L256）部分移到一個人身上，第 27 篇薇恩答鐘的重量會被分掉 |
| C | 先由塞奧德製造「鄧莫爾受仙庭指使」（段七中拆），再立「歐溫·莫凡是主使」（第 26 篇裂、第 27 篇破） | **嚴重**。C 第四節幕六把玉簡全文寫出：「學徒舟期依閣下所贈潮曆另排一潮；臺上由使節迎，烏爾溫隨行停外泊……事畢，閣下在門口候……祁承朔代」。改期、隨行外泊、臺上是使節，等於把第 27 篇記門石柱要拆的整套機關在段七交了出去。再加上段八「光不是長子」，讀者在段八就能推出兇手 | 沒有分走太宸，「不答」仍由議會承擔。芸香夜第三行要改寫，同樣讓第 27 篇加一拍 |

A 和 C 都讓合謀者「把陰閘潮曆交給祁承朔」，接乙案第二輪四之 3（L229「潮曆上不存在的潮次」）。這是兩案重疊的元素。三案也都讓合謀者把換防情報轉給主戰派。

**其他小衝突**

- **B 的合謀者身世自相矛盾**：伊森巴德既是「烏蘅祖母的弟弟」，又是「向中心請來的鬥聖入贅後留下的院」。而〈地理勢力與撫恤〉L37 寫烏爾溫家古戰前「沒有鬥聖……不是自己人」。三者要擇一。
