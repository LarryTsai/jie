**第 4 條的取得方式與可信性（主 Agent 依現行來源整理，待覆驗）**：
- 取得：總稿第 25 篇已定，玄闕祖脈裡有商玄度生前從未觸發的「罪證保險後手」，由繼承人商應璋放行，在校正試陣牽動道脈、三刻共振時開啟。這一頁就收在同一份後手裡，不另造取得途徑。
- 可信：它是商玄度親手留的、為日後要挾聖土那頭準備的保險，從未對外動用，不是事後為脫罪偽造；內容又與段七伊森巴德手鐘殘存三行（「與對岸關口之主約，令那道閘失信」等）互相印證，兩界兩方的自留記錄指向同一份約。
- 不可盡信：保險只記對商玄度有用的部分，突出鐘守應允、隱去他自己知道的暗殺與祁承朔的角色；這正是第 25 篇「合謀者互相防備」的反轉，也替第 26 篇留下缺口。
