# 競稿：界屑與善意之瞞的新落點

## 三版差異

|---|---|---|---|
| 主要對抗 | 劫自己的「我能」 | 裴照川 | 劫自己＋封寒的執著 |

## Reviewer 結論與主 Agent 判斷

Reviewer 推薦 **C ＞ A ＞ B**，不全退；以 C 為底，只借 A 的「成人方案少一重、劫的方案一重不剩」代價對比。主 Agent 同意。

C 勝在**必須當面否認**有場景支撐：封寒為了走低路壓在列陣巔峰一年，劫一句「沒有什麼聖土」，換來「那我不用去了」，封寒當夜破尊。讀者當下會覺得劫做對了；十五年後，封寒在抄送裡讀到否認那行字下面是自己的簽名。

需要如實記下的是：**界屑這一半，三版收斂成同一條鏈**。三版共有的元素是：
- 寇平前一日許諾補驗；
- 劫說「用我的」；
- 界屑被當成「寇平的一塊，留著還他」；
- 三凳移到會場；
- 寇平讀出兄長的令痕，並警告劫別怒闖。

三版只有強啟動機不同，所以這一半不能宣稱已經過三方獨立競構，只能說三位寫手各自都走到這條路。

寫手 C 已在原檔修完七項（修訂紀錄見方案 C 第六節）：

5. 寫明封寒大比時是列陣巔峰、未領印，並給他自己的一年：再試約、劍修、青璃邊界；冬天試潮的傷只落在他自己身上，保住第 18 篇首發；

7. 譚晚潮一隊只剩她和一名同伴，回程四人出發、三人抵達。
