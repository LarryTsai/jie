# Phase 2：後半部大綱開荒

狀態：D110五區骨架；第一區已深化至D111；D112補情緒債與清算；D113深化第二區落潮一年（2026-10-04）。作者指定的新工作階段；以下新增故事均為大綱工作候選，不冒記正式章綱或已定正文。既定節點仍以現行主線與年齡線為準。

這輪的問題是「這一生還有哪些值得讀的故事」，不是全書要湊多少卷。前十九卷與南荒四幕不再反覆打磨；從九界大比往後開荒。原二十八篇是追溯座標，不是新卷數。

## 五個故事區塊

1. [九界大比：少年時代的大收束](01_九界大比.md)。讓不同文明、同代與受傷的五雷一起上場；比試有自身的勝負與願望，接引事故有自己的因果。
2. [離鄉與九界遊歷：五個人分開走](02_離鄉與九界遊歷.md)。從大比後的分路，穿過落潮、飛升與後來回到各界的旅程。不是五人一起逐界打卡。
3. [九弱至碎錦原：第一次在上界活下來](03_九弱與碎錦原.md)。把原第9–14篇從事件摘要長成謀生、修行、選擇與失去的生活。
4. [上界：世界重新變大](04_上界開世界.md)。承接金丹、同代、決裂與聖土長住；先找出可長出故事的人與地方，不填滿每座仙庭。
5. [成道至入極：守住節點，留下未來](05_成道至入極.md)。保留跌落、重爬、清帳、第三次聖土與立錨的生命變化，不預定所有遠期答案。

這五區有時間交疊。第二區是長期遊歷與分路的線，第三、四區是人生主幹，不能把它們依檔案順序串成另一張年表。金丹八界取材是後來的一段旅行，不移到十八歲，也不把大比交流當成已取得八界下行權。

## 本輪可長大的地方

大比的臺上與臺下、落潮四季、文留下後的家學與地方生活、九弱的工作與同鄉、返鄉釣魚、碎錦原前後、七雷路身與本尊分離、同代人的上界生活、決裂後五年、聖土二十七年，均已有獨立矛盾與前後改變，可以繼續展開。

新增篇幅先通過四個問題：有人想要什麼？他試過什麼？哪個選擇真的付出代價？結果如何改變下一段人生？沒有這些，就不因景觀或設定多而宣稱能增加一卷。

修行所得以人需要什麼來生長，不每段五人各發一件。歡喜、切磋、朋友、技藝與見識也能承載故事。反派不每逢陸沉出現才啟動；地方利益不全歸「曉」。天地之異遵守D108/D109，不另建一份全解答案。

## 情緒債與清算（D112）

[四次清算工作方案](情緒債與四次清算.md)補回各階段欠債、踩線、追殺與收帳：少年留舟島、九弱境界牆、兄弟出事、後期追到盟主。甄四海與申磬的尾款留終局；新人物與死亡為工作提案，其他五區不因此重新膨脹。具體強度按當時境界，不用停職與談道理代替已選的殺局。

## D111.5：利益與認知補件

[利益階梯](大比利益階梯.md)明確本輪九界分下一屆前共同回潮古域的勘採、材料與作業界槎增量，梓葉冠軍為千根取得首入窗口；全隊成績使雲退賽有別人要付的帳。[認知揭露時間線](世界認知揭露時間線.md)校準共天、巡天舟與醫席已見的事實，將大比震撼落在九界文明真人同台與近距離看上界來人的限制。兩者已接入D111；此補件當輪未推第二區；[原Source](../../設定/06_待定與決策紀錄/來源存檔/JIE_TOURNAMENT_STAKES_AND_WORLD_DISCOVERY_SOURCE.md)已原文歸檔。具體配額與新標的均為工作方案。
