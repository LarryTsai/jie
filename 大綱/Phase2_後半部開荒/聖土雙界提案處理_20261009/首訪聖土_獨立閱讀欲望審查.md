# 首訪聖土：獨立閱讀欲望審查

2026-10-09。Reviewer 未參與甲、乙、丙構思，完整讀三稿、任務單、原提案、多線主幹與本轮矩陣，核對境界對照及故土名錄。這是比較與退改意見，不是作者選定、不升 Canon；尚未審整合稿。

## 結論：有值得留的故事，競稿差異沒有完全達標

**有限推薦丙作一條族河後裔核心弧；甲作真正留居活人線的另一候選，乙保留比較而不整弧拼入。** 丙在目前長篇的位置最好，甲的人物最令人想再見，乙的外圍隊長最有自行動的潛力。沒有一稿能原樣進主幹，亦不能稱三稿已各造出不同類型的中型故事。

三稿共有同一條骨架：近代仙道移民轉修 → 本土年輕後人改法 → 傳法歸屬／祖輩舊債 → 曉外圍買斷改接器路 → 返界核原圖和供貨。甲乙尤近，祖母改父親、線刃改護臂，沒有改掉核心對抗。丙的已故祖父、族河公開爭席與活人聲譽代價，確實改變關係、欲望和對抗場域，超過換名；但仍是同一題的變體，沒有交出三種不同探索方式。

不要求再開完整聖土競稿。本輪可取一條有價值的局部弧，誠實記錄競爭未充分分化，不能把三份數量當創作成功。

不給九分門檻：這些稿是可取材的工作候選，不是已可寫數十章而不乏味的完成章綱。

## 核心弧取捨

丙只保留「凱爾短疑 → 骨庭各得材 → 祖父真欠債、今人真有新法 → 退水爭席 → 戰後奪器反制 → 返界拒索整法」這條鏈。赫連要維持能拆器、能反制、主動作惡的敵人，不改成最後只談價的牙人。裂槍、骨甲代價和弟子是否願拜，給勝利後留餘味。

**不借甲的祖母整場鬥王戰，不借乙的另一外爐護臂爭寶。** 若借乙，只借對手的取捨：外圍經手人可拒拿同伴作耗材、卻照樣以獨占收購傷害其他人。這種矛盾須化成所選對手自己的行動，不能把朔璃也塞進丙的場面。赫連已主動壓價作惡，不應用「有妹妹」自動洗白；妹妹離隊亦要自己選。

甲暫存的理由不是不好看。祖母留下、本土青年想遠行，確實比單純查祖父帳更有生活厚度；只是本輪骨架已有沈與杜、薇瑟、梅菈、伊萊恩、奧默，浮城不能再收兩套完整人物高潮。若未來選甲，應作替換而非增加。

## 必修：三稿都有的重複

1. **新假古器取消或改功能。** 沈仿刻牌已承擔「材質可驗、年代口述不可靠」。丙改成劫錯認供力順序或師承來源，不再用又一件近代器揭假年代；甲乙若用同樣改。兩種誤認有區別，不能同一課講三遍。
2. **返界不強湊三場。** 普通家書交付、當場拒索整法、一次真強奪／辨器即可同場發生。相似器尺寸只是疑點，不能自動證兩端曉貨鏈或辨照塵；實物交接者、時間與可過縫載荷才可能讓證據增加。
3. **不是既有早期伏筆。** 三稿均坦白未查得移民原章，這點合格。矩陣也須同步：新增弧可自起自收，不能給「九界舊物二次發光」掛名。原有藥方與辨禁習慣可回應，不必補一個早年失蹤恩師。
4. **活人目標誠實留白。** 若選丙，原提案真正遇三十二天來人的要求本輪未交付；不能把已故祖父算活人，也不能臨時復活祖父。已有來人只在實際能提前相見、資訊鎖允許時才補，不能挪闞拙、西門曉代填表。

## 必修：乙的兩個具體問題

乙試寫「長亭。南渡。」使陸沉認故鄉，不可採。現行[九界與陸沉故土](../../../設定/01_世界格局/九界與陸沉故土.md)明定下界不知長亭天名，須到上無極才知；十八歲只能認已建立的留舟島地方稱呼、具體渡口筆畫，不能用作者側天名。

桑鐸忽然要求朔璃隊員接器試場，使護臂變成第二個試人器。本稿沒有交代該器功能、風險與必要性，且與定識匣重複。若有限借用朔璃取捨，改成對手要求隊員承接一擊或背負超額器重以引火，讓隊長拒絕一個可見戰術犧牲，不新增神魂試場。

## 規則核對與未完成條件

三稿均說低境天然過縫、之後散功轉修，保留見識而非兩套修為，沒有假自封過界；甲今日鬥王不由劫越階擊殺，也不直接回低路。均未使用高路，不需憑空填高境穿虛補給。曉外圍限本地單價／交付點，不讀跨界魂印、不知道高層，全體紅線基本守住。

但「三十一年前／二十餘年前／七十餘年前過縫」只是時間占位，尚未核港口、疏密期、雷勢及实际窗口。所選弧必須給一個可成立的外界年份与端口，或明標選後待核；不得稱已完成通行前史。转修后寿元按現行保留規則，人物年歲不靠通道内時間另加壽。

陽閘大綱已選，不使古路共同起源、雙界封禁或本支殘器變成已定機制。丙的父祖筆記最多排除一處廢口，不能和封箱航記各排一遍同義路；直接刪其航記功能亦不傷人物弧。

## 整合複核標準

整合稿需保留所選女修一個不用劫代打的勝場、劫一次真正有代價的選擇、曉外圍具體失物／失款与后续行动，并留出伊萊恩原游爐與索恩解契舞台。返界九界插段必須短於復仇主線的實際重啟，不增一年查帳。若只是多了族議、器簿與規格敘述，即使Canon全合也退稿。

## 第二輪：乙首稿撤回，新乙改變推薦

完整讀新版[接入方案乙：追獸骨的人，不追歸路](接入方案乙.md)後複核。**上文乙欄、長亭／護臂試人批評均指已撤首稿，不能算新稿仍犯同錯。首輪比較保留作真實退稿紀錄。** 新版撤掉父女祖債、假古器與浮城外爐弧，沒有靠換名交差。

**主推薦改為新乙的活人修行弧，甲、丙不整弧借入。** 三稿現在具有可比較的差異：甲是仍在世的兩代故鄉／傳法；丙是後裔爭席與祖先責任；新乙是未轉修本人正在爭寶、敗給異族對手、學會分清救命勝利與切磋勝負。至少欲望、關係、對抗和探索方式已改變兩項。甲丙仍近，不能反過來宣稱首輪本就充分獨立。

新乙最好看的不是「有同鄉提供舊記」，而是齐見山明知可走仍選留下，斐珞贏他後不照顧他、也不等他；最後他救了她，兩人仍不把救命當比試獲勝。這使陸沉看見真正另一條修行人生，並完成原提案真正遇仙道活人的要求。人物可能再會，卻不在主角門口排隊等十一年。

仙感由身體、骨聲、續力反折與對手退路反制產生，勝場有器材、半核、破器與敗戰。索莉亞拒活餌、仍截傷者器，保持自利，沒有第二個神魂試器；這次組織違單是保隊員的實際選擇。最大風險移到**族河負荷與敵人連續反拆是否像演算展示**：既有珂魯／烏薩爾、索恩解契和伊萊恩承架仍須足額，不能把這條弧插成另一套完整巨獸脊藏。

### P0：不得跨過的功體邊界

未見新乙將活節寫為吞噬、神魂容器或功體保命；目前它是適境護脊器／背刃材料，並不硬衝突。整合須保持這個明確功能，**不能讓少年偷吞活節後免異火失败、不能讓兩儀免費保命或補回耗力、不能把陸沉已形成的雷種因弃勢／碎器而寫成消失再生成**。「捨前五節餘勢」只指齊已用體術打出的動量與連勁，不是放棄道基、本源或境界。

兩儀要牽實有金鐵接片與陣脚，不能隨意控制獸骨；千相被礦骨聽振破一種假位，不代表所有感知迷惑永久失效。斐珞兩次已勝與本輪再勝須分清：劫的敗戰是傷未清，同鄉仍付力，不宣稱同階仙修必勝五雷。

### P1：可入整合之前必修

1. **齊年歲與通行窗口**：現檔寫二十八歲、十九歲過潮，實為留居九年，並非三年。主稿只能取一套数字。九年前具體窗仍未核，必须标待排；若改三年，改過潮二十五歲而保天然列陣资格，不讓兩套前史並列。无需为留居久而假定必升尊：刻意磨同境體術成立，但须一场主动拒突破／不急破境的短动作让选择可见。
2. **補給語句校準**：列陣法力初到吐納六七成、數月熟地後幾乎不差，是現行規則；不是仙力那種雷晶唯一足量存糧。九年熟地居可以成立。删「沒有十成補給」作为此低境人物统一上限的断言，改成陣器大用仍需自供、連戰耗力及既有傷勢不會被熟地立刻補滿。若用雷晶加補，须说明配额／来源，不能让无籍来人无限买雷晶。禁止用免费補給替傷后连战开脱。
3. **战斗之间真留恢复**：凱爾敗劫、族河斐珞再敗齊、脊藏終戰不是同上午連開；傷與存力进终战，齐弃续势亦不是回血。劫集合时点必须与原隊路线一致，按约一轮夺位后真退出，不口头有限打完又守几日。
4. **返界敌人不要復活已清算者**：截擊只可用尚存敵方的人／另有利益者，具体身份、尊者前后双方当下境界及短巷为何值得动手待联排。聖土承力接片真碎、不是主角新九節功法；把一次决策带回追仇成立。
5. **器模回聲不硬绑敌宗为曉**：同内空尺寸只证明结构需求相近，不证明同订单。为何该器模能束接片，需要一条可见器械作用，不能随身道具当场万能变武器。若不能成立，删器模，返界戰保留接片回收；曉回声继续由沈既有线承担，胜过为了验收数目制造巧合。

### 整合的份量

保新乙凱爾一場對招、族河一次再敗／真爭寶與合勝、離別一個留居選擇、返界一場追仇接敵。旧渡記可只留一页岸形用作人物生活痕迹，不再和封箱航記重复排除廢口。甲的祖母与丙的晏家、舊債、清算師門都不加入；族河本土新角色以斐珞、齐、索莉亞与一名对手就足够，不另增外宗全部長老群像。

此推薦是編劇接入建議，未成作者採定。三稿現在值得真比較，新乙改善了創作責任；主幹仍須整合複核，不能只因本輪成功重構就宣布整個首訪已精彩完成。

## 最終整合複核：接入成立，不能刪掉原浮城高潮

完整讀最新乙、[整合大綱](首訪聖土_長篇整合大綱.md)、矩陣、暗線比較、橫向事件圖與入口後，結論為：**可交作者評閱的一條主推薦候選，不是正文通過或全部Canon採定。** 推薦新乙不變，甲丙沒有被偷偷全部拼入。

主線仍由十八歲傷墜、急返追仇，到族河只陪一輪、浮城捨傳承取航記、布蘭堡完整熔雷、西返與十九歲破尊上界連續推進。同鄉在同一世界選另一種人生，不用多一座遺跡或祖輩對帳才成立。返界舍接片确实改一場動作，這比檔案注明「他理解了」有閱讀回報。

新乙補給已改為低境熟地，九年前望歸密期只證相容、不冒稱已查得實窗，兩端落點待排明示。活節純器材、傷後休整、雷種不被碎器抹去、兩儀不牽純獸骨、破尊前獨立搶器者、撤同尺寸模、地方曉購器者不為劫知身份，第二輪主要必修均已處理。**目前未見必須退整份的P0。** 當下敵人同階勝場是本場安排，不是禁止越境的新世界規則。

### 保存前的P1：浮城仍需一個明確承接段

整合稿初讀將浮城縮為離場談消息、沈得匣劫得航記，未直說原有三方奪箱真戰與奧默其後內爐獨占／陣殺是否仍發生。雖暗線表保留部分名冊鏈，獨立讀主稿容易以為大型高潮被新版接入取代。**須明确原舊器支段只奪真箱一次，沈取匣、劫取航記、杜追名冊；奧默後續因自身內爐支配欲被擊敗，並非第二次奪箱。** 引用既有大篇／暗線工作稿即可，不要求重写整場戰綱。

這不是再要一個新高潮，而是保住已經有的精彩。不能因加了齊見山，就讓少年游爐、薇瑟所得、杜追責及奧默終戰只剩背景名詞。新乙的族河側枝已写若擠主段則削回合，此原則正確；正文交錯時仍須核索恩解契與伊萊恩承架至少各有一個自己的轉折及勝場，不能只用總表宣稱自主。

### 不阻此輪交付的已明列接口

九年前雙端窗口具體落點、骨庭集合時點、返界短巷城鎮，以及藥材來源／小試都是後續聯排項，現在诚实保留，不作已有正式章號。母方回收未写场面，不能拿它凑「已有三條完整伏筆」。普通聖土字須与阳闸既選字形聯排，而非在首訪新造一枚字再宣稱舊碑已讀過。

曉兩地拆器者同屬組織是作者側新增候選，讀者可見各自試敗停單；對陸沉只是一個具體的人作了選擇。它提供組織仍在活着的感覺，尚未提供能追跨界貨流的证据，正文不能把此场的成果吹成查清两端秘密。

最終閱讀判斷：這輪多了一個讓人願追的活人弧，沒有僅把提案十列再展成十項任務。人物有自己要贏的仗，主角回去的願望也真付代價。故事是否足以承载長篇仍要靠完整場面證明；現階段可保存供作者選擇，不能以提交或審查通過宣布第一次聖土已成功。

### 最終修正確認

重讀主稿最新浮城段：已保上爐競取權換抄、拒異火使用權；少年敗貝倫後自行補承火柱取游爐部件，而非劫替他打朋友；三方奪箱的實戰、名冊分持與沈殺舊買家、奧默失寄存收益後的內爐支配及雙驕陣殺，全部明接既有來源。沒有第二箱、少年獨殺奧默或主角離城後終戰被省掉。**上述保存前P1已關閉。** 入口概要仍可把「外爐名次」措辭統一為「上爐競取權」，免讀者以為另一次離場談消息；不影響主鏈成立。

此輪P0無、保存前P1無；年窗、場地、回合與藥材接口維持正文前待聯排，不變成虛假的正式章綱完成聲明。推薦新乙接入，未要求升Canon，甲丙替代稿仍只供作者比較。
