## 一、這次旅程的主承諾

劫最初只有回三十二天這件事。確知下一個安全低路窗口還需等待，而且目前身體無法再闖界潮後，他沒有變成等船的病人：他想恢復本事、準備能活著走出的退路，也想知道眼前那些不同的修士究竟怎麼戰鬥。朋友則各自有想去的地方。他們一起出發，走着走着真的分開，再憑自己的選擇重逢。

首入的三場非火源大冒險是：

1. **霜落王庭**：北境雪下古武王庭甦露，活着的後裔與外來探境者爭一批實際可用的傳承。劫吃下聖土女天驕的一場敗戰，第一次因自己的判斷失掉本可到手的寶。
2. **族河與千歲脊藏**：走入真正有城、有宗族、有成年修士與外交關係的嶙族文明。契獸朋友尋族，眾人捲入一頭壽終巨獸留下的脊藏爭奪；族內與外界各有利益，沒有人族少年替整族決定未來。
3. **灰洋沉舟宮**：一位女天驕船主搶回自己選擇出海的資格；散修、船塢弟子與海中修士爭一座古代海舟修行宮。劫以預備撤路取勝，卻必須放棄一件足以令他心動的高階器物，才能帶走真正可用的所得。

三者分別提供古武修行文明、活異族文明、海上修行文明，不以三個火坑充當三個世界。**百爐浮城仍在首入兌現少年的游爐所得**，但不再獨占整個聖土；布蘭堡殞星是最後獨立的雷道高潮，不是一路探索唯一有價值的獎勵。

回家消息不拆成三份匙。早期便由可驗潮況知道大致窗口；各冒險即使完全不發回家線索，也值得他與朋友去。劫最初用「我要準備回去」解釋所有停留，後來終於能直說「這裡我想看看」。復仇仍牽着他，並非一交朋友就忘掉家傷。

## 二、同行的四個人與不能隨意替換的人

新增人物先鎖欲望，再排精確星數：

- **塞芙琳**，二十二歲上下、鬥靈，北境古武世家女天驕。她要取回先祖帶入霜庭的完整步法，免去家族向宗門永遠借法的依賴。懂得在硬雪上改變受力方向，善用分層鬥氣護體；會先試探陌生雷術。她是霜庭戰場上的主動競爭者，後續還有家族與師門之間的選擇，沒有輸贏後愛慕主角。
- **達維恩**，二十七歲、鬥靈後段，北境小宗門帶隊者。曾在探境裡救過人，也肯殺直接爭寶者；要拿王庭完整兵法重建本門的青年隊。主動搶先斷掉對手最好走的路，不被聲光幻景反覆騙同一招。
- **珂魯**，嶙族年輕女修、鬥靈；年齡按族群生理另排，不與人類十八歲硬換。她想帶自己的支族重回族河上段的藥岩岸，爭脊藏是為取得能支撐這種生活的所得。她不是等待人族替她伸張公道的公主，能打、敢取，也會隱瞞一部分族內情報。
- **烏薩爾**，嶙族青年修士、鬥靈後段，珂魯堂兄。主張把脊藏整批換給人族宗門，以換自己的師承和支族遷城機會；他對外界有吸引力，並非背叛祖先的臉譜。他與珂魯會真動手，各自取得部分所求，不能一場勝仗就判定一種生活全對。
- **梅菈**、**薇瑟**，沿原 C 的爐法女天驕與持槍女天驕。她們有自己需要取的傳承與競爭，主要在浮城出場；不把五六名女天驕全寫成同一個性格。
- **諾維雅**，二十四歲上下、鬥靈，灰洋近海船主兼船塢旁支弟子。被家族指定接手沿岸船務，她想走更遠的外洲線，也懂得船員不是自己夢想的耗材。沉舟宮所得能讓她保住一艘真正屬於自己的舟與一門適境御舟鬥技；她與少年有一段信任和失約，未預設戀愛。
- **霍森**，船塢真傳青年、鬥靈後段。與諾維雅曾同修，認為她不該把師門的航路資格拿去賭外海。他想取沉舟宮的古舵器，以爭下一次宗門外洲行席，不只是阻止她自由。
- **伊索妲**，海中高階魔獸修士，能化形是因其真實高階，不是低階魔獸免費成人。她有族群與獨立利益，取的是舟宮中曾被人族封藏的族寶；她能在高層爭奪中和人族強者交手，不陪少年在低階區刷存在。

高境者必須入場。北境王庭有鬥皇以上帶隊者爭上庭；族河有族老與人族鬥皇談判、交手；沉舟宮有船塢鬥宗與海族高境修士爭深層；火山由當地強者抵住高階災勢。青年有自己的戰場，非所有遺跡都突然禁止大人進去。

## 三、旅程起點：先被救，後確定等得起什麼

第一月，西側雷域外緣。救援保留四人共同付代價，傷勢恢復非一夜：拋貨、改藥、背人、避免錯誤催氣；劫聽不懂話，先從給水與借衣識人。一次地方截奪中，少年以一種火做不同事，劫以五雷有限協同接住同伴開出的攻口；第五無間只接自己辨明、已試過的近端，傷勢牽動使他不能連換。劫贏後仍要朋友抬回去，多火啟發從這裡起。

第二月，由西側合法入口與已有城市門環接到凱爾；初次大城完整展開魔核市、鬥技試器場、爐街、煉藥與各種修士。卡多克與塔姆林於同行段接入，不奪四人首救位置。商會登場是探境組隊、估寶與交通的生活背景，不讓運貨、修器、買消息佔主體。

劫向真能分清界路的修士詢問，再以自己的墜落潮痕與西側望樓回訊核對。得到的是：可驗低路還需數月等下一個完整季窗，回原世界須先九界；傷未養好亦不宜早闖。仍不能取得永久通行保證。這個答案是旅程的時間邊界，不是每個遺跡拆下一件零件才能湊回家。

四人原要探境養成自己的能力，貝倫聽見霜庭開啟的消息，伊萊恩想看完整古武如何與異火配合，米蕾想取王庭藥學；劫答應同行，最初只是想練回承力，也確實需要適境護器。門路費由已可公開的普通器材出售、四人原積蓄與有上限的合隊出資承擔；不把仙晶直接當當地錢，不安排未知豪商免费養整隊。

## 四、大冒險一：霜落王庭——九界第一也會失掉想要的東西

地點為德雷凡境內候選谷地，與已有凱斯卓痕並非同一祕境，離門環可達城市還有實在支路行程。王庭是數千年前一個本地古武王族留下的修行宮，非全古戰指揮所。斷脈後埋入冰層，此次因積雪与地勢变化露出幾處入口；高境隊從上庭進，青年與散修爭下庭。

**進入與初勝。** 貝倫要護臂與完整鬥技入門，塞芙琳要家傳步法，達維恩要兵法。劫見下庭雷擊石壁能承較強衝擊，想取其內一件護器。隊伍先在冰階上奪兩處落足，伊萊恩熔掉薄冰卻引出冷泉，沒有「火一亮全部冰牆就化開」；米蕾辨出舊傷藥凍後藥性變化，自己爭到一箱可研究的藥，而非跟在隊後撿。

**第一次敗戰。** 塞芙琳用凝物護體分層換面，主動逼劫把攻勢落在自己可承的那面。劫用星羅看出一處較薄，卻把她故意露出的第二層當真正缺口；刺入後對方轉腳卸力，將他逼離護器台。他想用無間去早先看過的石台，發現對方已踢落該台，另一端不能再驗，必須停手。她真正贏，拿走護器。劫不靠王庭宣布自己是異界天才反領更大神器，這個損失保留。

**中段反轉。** 達維恩第一次爭兵法慢了一步，沒有轉而封出口收過路寶。他辨出兵法主卷與其演練用的陣盤分在兩處，先以自己帶隊者的凝物陣形壓住奉王台，再搶主卷。他令一名同門帶卷先走，自己留下爭能將兵法用到本門青年隊的完整陣盤。塞芙琳已取得步法前卷，仍想爭台上續篇；劫則要陣盤旁可拆的適境護盾與陣材。兩隊合作是為了再爭一份真正想要的東西，當場談清各自所得與不追擊已撤者的底線，不是不得已合隊逃生。塞芙琳的護器始終屬於她，沒有借器替劫補平敗戰。

**高潮：奉王台上的古武與雷術互拆。** 達維恩用自己已學的凝物陣形佔住高台，並依台上既有演武落點輪替隊員：一人承、一人攻、一人補，使劫先前在渡槽贏过的錯位分割無法照抄。劫看見弱點卻不能只追弱點——他每追一處，對方另一人就補上。伊萊恩先以火線逼第二位承陣者換位置，貝倫以護臂正面搶下一個落點，米蕾辨出陣盤周邊舊藥煙對人族的影響，自己選一條不會被藥煙拖住的取物路。劫不直接搬走整盤，改用兩儀牽动陣盤邊暴露的金鐵校柱，迫使對手下一次輪替多走一步；塞芙琳以真正熟練的步法截入續篇台，她既有的勝戰能力在這裡再次成立。

達維恩立刻反制，拆掉自己一個凝物承點，用更短隊形壓住陣盤，再親自和劫交手。他看穿第一個千相假位，劫也吃下其回身一擊；無間只能接劫此前親自試過的兩處台角，對方踢翻其中一處，劫便停用這條接法，不用傷後連換翻盤。最終劫與少年以一次誘使達維恩先承火、再接劫實擊的配合窄勝，打散其餘隊形，劫奪到適境護盾和陣材；達維恩仍將陣盤的主軸交同門帶走，敗在這場正面戰卻保住本門所求。塞芙琳取得續篇、並未與劫當場再比一場來平掉原先敗戰。各自取走能帶的東西後分路撤出，沒有唯一退廊、輪番封路或共同突圍的末段。

上庭強者爭到高層所得後撤隊，殘宮再封；他們也拉出一部分受困散修，不人人是魔頭。塞芙琳帶完整步法與此前贏來的護器回家，和劫留下一個往後真正較量的約定。達維恩受傷活着，本門取得兵法主卷與陣盤主軸，也留下與劫的新仇，不被故事遺忘。

**實得與後果。** 貝倫護臂与學宗門深法的決心、米蕾舊藥學、劫的護盾與陣材、少年一次能自行帶隊的經驗；沒有回家線索也值。劫承認「看見力量」不等於「知道對方下一步」，之後偵查不再只信眼前弱點。傷势影响下一场不能把寒伤当当天消失。

## 五、大冒險二：族河與千歲脊藏——異族有自己的城市，不是獸王洞外一群怪

返回凱爾後，索恩從當地獸材市找到岬耳族群的可驗遷徙痕，追到索恩沃德外側一條候選盆谷。地理不穿荊約心谷禁區、不把兩位獸王領地送給年輕隊伍。盆谷有嶙族的「柱城」与药岩岸，是人族商隊偶爾来、但不熟悉的活文明。

**嶙族的生活。** 他們是本就有智慧、可修鬥氣的候選族群，體表生礦骨，非普通低階魔獸化形。力源仍守聖土體系；礦骨共鳴既可傳短訊，也可教幼者聽族河下的地脈，外人學不懂時不能靠神識讀心。家屋围着活药岩建，藥師刻骨記診、族內成家與分支，各有自己的生計與师承。有人喜欢人族城、有人成婚后留下、有年轻人争宗门外修资格，不能用一场文化说明会代替相处。

岬耳一族在藥岩岸与嶙族共生，不是嶙族全员契兽。索恩终于找到牠认得的同族，先高興，後知道牠當年由人類販獸隊帶走。他自願暫解契，讓牠選。珂魯正在爭回一段失去的藥岩岸，却没有义务免费替人族照顾契兽；她邀索恩与队伍参与脊藏，因为他们能补上她小队缺的本领。

**爭什麼。** 一头千歲巨獸在遷徙季寿终，脊骨內的礦髓、骨庭裡的藥物与數件曾嵌入其身的器物暴露。這是承認可競取的天然遗藏，不是所有人盜族墓。族老管祖骨不可破的區段，人族与本地支族各争开放处；珂魯要矿髓养药岩，乌萨尔要较完整骨器换入人族宗门，伊萊恩要可用作游爐承架的礦骨，劫要炼體与陣材。收益不同，合作才会真有分歧。

**失败不是大家误会。** 珂魯隱瞞骨庭有一段潮水會迅速倒灌，為了先追堂兄而让合队涉险。伊萊恩跟了她的抢进法，米蕾受傷、劫護盾破掉一角；少年應承自己選跟進的責任，不全推異族骗子。米蕾拒絕下一次继续深入，提出自己留下外骨庭取藥，不是等所有人失敗再無限救傷。索恩無契，不能照舊合击；他明说能力边界，不再隐瞒。

**真正調整。** 劫和少年退回已能維持的骨庭，自己探出两段撤路；珂魯要么共享真实潮况，要么分队，她选择把族内所知拿出来。烏薩爾不等主角准备，先以祖传凝物骨弓锁住相对安全的出口，再用自己带的族人轮替借力，迫众人走较危险的脊腔。他的族老與人族鬥皇在外部爭一份大型礦髓，不能双方老人喝茶等小孩决定全部资源。

**高潮。** 千歲脊藏中段翻轉，在巨獸的肋骨间形成上下交錯的骨梯。珂魯與堂兄打一場自己的爭位戰：她选择护住可养药岩的活髓，放弃最值钱的骨器；乌萨尔真的取到骨器，卻失去獨佔活髓的機會。劫對烏薩爾的人族合隊帶隊者作適境戰，先讓兩儀改动外露铁器的位置，千相只偽造可觀聲光，對方亦用族骨聲響辨出一部分假位；劫要在被反拆後換戰術，與少年共同擊敗守出口的人。沒有把未知骨梯當無間端點直接穿走。

伊萊恩放棄自己一份礦髓，換一條当下可用的撤隊路线與祖骨承架，不是白送所有所得。米蕾用自己取来的骨庭藥處理創口，却因配方与人族体质不合，只能限量，兩方各有要學的东西。岬耳从族群跟来帶索恩走最后一段，是牠自己选择；出庭後重立契與磨合需時間，不把解契视为白演一场。

**實得與後果。** 珂魯得部分活髓、能重養藥岩，却還要族內談判，不突然當女王；堂兄得入外宗的資本，日後可能带外宗回族河，成为長期牽引。米蕾与嶙族药师建立平等交换，少年得到祖骨承架與一次自己作撤退決斷的勝利；劫得煉體材料、阵材和一段異族修士能反拆他的記憶。索恩決定留族河一段時間，米蕾亦留學診法，隊伍第一次真正剩下三人。

## 六、原 C 的位置：百爐浮城仍有完整勝利，縮的是壟斷世界的比例

原 C 的浮城不是因为新题目就删除，也不把游爐所得挪到二十多年後。它承接在族河之后：少年带回祖骨承架，有了競取游爐的實際准备；劫已有两场陌生体系败胜经验，貝倫想進宗门的意愿更明确。

浮城露出十九日、內爐院多隊爭奪、奧默封通道、薇瑟與劫爐橋較量、梅菈与少年竞取，保留原 C 完整因果與真正战利品。依新版图改变四件事：

1. 不以浮城封箱作回家引擎；劫此时已知低路窗口。封箱有外来器、局部航记即可，不成为冒险必要钥匙。他去争适境器、练本事，明确是自选探境。
2. 索恩與米蕾未必全程一起。米蕾為自己的藥學分支回到浮城，索恩则留族河照顾重立契与族群事务；保留他的人生，不为了第三次合照把他拉回。
3. 貝倫取得銅穹院的试学邀請後離隊，加入另一條隊。浮城后段他會助開散修撤路，但不退出师门重新當少年保鏢。宗门真的有值得他学的深法。
4. 少年取得完整游爐主器与可修爐法，在离城后已用自己的祖骨承架搭起第一座可用的私人爐；首次成功炼出适境药、让朋友试用，是首入的实际兑现。後續多火仍靠自己的实验和人生，不能只留下「未来会很强」預告。

劫與奧默的適境終戰、奧默真死、主器競取、失古器換米蕾脫險等原 C 回報保留。高境者爭上爐、帶走自身所得，遺跡地勢變化會影響青年，绝不把他們排除到觀众席。原 C 把浮城放整篇中心的做法在本新版圖撤用，但浮城故事本身沒有因此通過 Canon。

## 七、大冒險三：灰洋沉舟宮——想出海的不是劫一個人

浮城后少年原打算留凱爾搭爐，劫则想去近海看看古代渡舟如何抵御異質力量，對無間的近端穩定也有可觀察的實物價值；不是去灰洋找另一條界路。諾維雅与少年早在凱爾探境組隊場有过交易，她委託的是同行爭舟宮外层器物，所得按份分，不承担所有人一年旅費。

原游爐可拆运但不用把一座大型爐院带上船，少年只带必要组件，剩余托已有合法商會存放、付保管费。米蕾回族河继续短期學習，貝倫回师门，索恩与岬耳先走自己的野路；劫与少年两人应诺乘舟。两主角首次没有原四人包围，也要接触能争得更狠的散修与女修。

**文明与入口。** 由凱爾—艾維爾—格里斯港的已有门環、最後近海船程抵达，一年不跨五個月大洋。沉舟宮是數千年前一艘本地鬥尊的修行靈舟沉在灰洋近海，與傳說「沉鍛」異火之地不同。它的船楼层层套于船腹，高境者从深层进，外层本有低阶修士留下的生活与争斗痕；海族能走人族不能直接呼吸的水道，不能等主角给他们地图。

**诸人先得到东西。** 諾維雅带队赢第一处外舵台，真正取到适境御舟法；少年從古藥倉找到一份海上傷藥方，与自己熟悉的爐法不同，決定帶回米蕾共同试；劫爭到一套能各自立足的陣器，當前只能适境供力，不因它出自鬥尊便随手施鬥尊威能。航程途中他們见外洲海客与异族海市，远方有具体邀请，但不宣布今年立即全洲走完。

**反转。** 霍森抢先占外舵控制处，揭穿諾維雅並没有足够资格把刚取到的舟宫外壳安全拖上来。她想赢过家族的急迫，让她答应了超出自身能掌控的航程段；船员主张先带已有所得走，不願意為船主理想全部陪葬。少年站到先撤者一边，說自己要爐，也不因此默认朋友应留下；諾維雅與他关系真破一次，不拿她當单纯勇敢女英雄。

**少年独自闯的段落。** 劫接受諾維雅另一小队的限时潜入，去取阵器的最后一枚完整脚；少年選擇率受伤者先撤，却发现霍森的另一支青年队要收回所有外层所得。他用自己新取的游爐部件作短时護器，一種火多种形态守住狭道，以自己的判断分散对方，與一名同境青年真打并胜，不靠劫从水下忽然回来代赢。他能率不是自己旧队的几个人走出來，拿到对方器材作为实际回報。

**劫的深水失手。** 劫讀得到陣器受力，却看不懂海族封禁的全部标記；被霍森利用水路与封禁分流，原先看得见的端点没入浑水，不能用无间跨過未知舱墙。高层的人族鬥宗与伊索妲争族宝，挪動船宮一侧舱体，青年必须撤离力量范围。劫失去原定返回的短路，殘傷与储力都要算，不能全篇一件宝都不丢。

**高潮。** 霍森向諾維雅提出最后交易：他取古舵器、她交回师门航路，兩人都能帶人走。她不把全队强押在自己梦想上，先明確放走想撤者，与劫选择留在仍可承载的一段甲舱，争自己的份。劫先夺回两处实测落足，再用有限无间把甲舱与近侧開放廊口相接；霍森用自己凝物舵輪堵住一端，强迫他放弃该接点，真正改变战术。劫以千相掩住自己撤开陣脚的动作，改走其早先已踩过的普通舱道，在對方以为他仍要穿舱时反擊。

最終是諾維雅與霍森爭御舵、劫對其合隊鬥靈爭出口的兩場戰。兩人分工勝：她奪可用外舵，劫帶走完整適境陣器。此時高層破舱的震動鬆開古舵器的卡架，**完整高階古舵落在劫尚能抵達的近側舱台**；他已驗過到那處的普通落足，敵隊又暫退，確實有機會取到。它不是碎掉後只剩惋惜的寶。古舵有封裝、可搬運，日後修為足夠或出售都有巨大價值；拿它不是當場便能施展鬥尊威能。

但要完整封妥古舵、搬回集合處，必須放下已收齊的陣器重新分裝，並多耗一段他預先測過的往返時間。諾維雅已按約讓受傷者先上舟，只替仍在舱內的劫等到第三次實際收錨號；船員與少年靠這個期限安排撤行，不知道他會臨時追新寶。劫能拿古舵，代價是毀掉自己承諾的回船時限，讓舟上那群人再次替他的欲望冒風險；他也會放棄已確認當前可用的完整陣器。他親手試了古舵封口、確認其真值，仍抽回手，帶走陣器按時回舟。這是有寶可拿時的取捨，不是高階器已毀、無路可去才被迫撤退。古舵留给後到者，是否被別人取得不在此刻抹除；劫之後仍會想起自己放掉了什麼。

霍森受傷活着並帶走其隊先得的一卷法，今後仍能在宗門爭航路，不讓敗者只剩替主角揚名的功能。伊索妲取回族寶，人族強者亦拿到其所求深舱器，各有勝負。

**实际结局。** 諾維雅保住一艘较小但真正由自己掌控的舟与合适法，沒有當夜把鬥尊靈舟整艘抬起。她公开向自己船员说明这次失误、补付实际所得份额，願留者重新同行；這是人格改变，不是开总结会取代高潮。少年與她仍有未平的失約，對方日後邀他上外洲線時，他可能要她先把旧债还了。

劫與少年先到者不再同一路撤出：少年回格里斯港等约定消息，沒有一天不見便認定劫已死；劫绕近海回港付实在路费与伤药。重逢先看到少年带出来的人也在等，这次他真的能独当一面。米蕾接回海藥方，有愿意研究的自己的课题；海族与外洲牵引留未来，不变今年必去清单。

## 八、末段：各自的路暂时再交会，殞星所得绝不低境先用

沉舟宮后，大致距安全低路窗口還有兩至三月。劫已经取得适境阵器，伤也须养；火山雷域是最后一场自选雷道冒险。伊萊恩想把游爐在真正火山环境用成自己的东西，不依賴收第二火。两人从港经现有内地门环返凱爾，再走布蘭堡前哨路，不飞越雷冠。

貝倫随宗门一次适境火山修行前来，米蕾完成族河短期學習、帶著要交給朋友的藥方來凱爾；索恩与岬耳也会因采兽材的自己行程接近布蘭堡。重聚是时间与欲望交会，不宣稱大家放弃自己人生永久回队。

殞星取雷骨架取原 B 的修正時距：**先取得當地鍛廳同意，本尊在雷冠外围与本源之间留月余，逐段熔煉；未完整成功一律不能用殞星。** 體内舊五雷恢復、外来补给、神魂与肉身相容都必须在这段承担，不写给伤者每天闭眼一分钟就全成。

火山探索前置仍有青年爭器與真正雷域奇觀，不拿整月写数值报表；正式场景以几次不同失败、一次适境取护器胜利和朋友彼此选择呈现。冠鸣末夜，当地高境者压火井、挡城不能由列阵替代；本尊完成最後相容，把第六雷完整煉到自身列陣後段，融身、魂与功法才算成功。其后首次有限凝核墜爆，缓解一段当地强者已控住外围的灾势，不能一炮管全城所有问题。

游爐在這裡第二次兌現：少年以自己已練的單火爐法护住适境器，不施火莲；貝倫用真正学过的宗門法護低路，米蕾决定后续怎么救伤，索恩靠真实野路与契兽分工。所有人有适境行动，但殞星属于劫本尊的熔炼成果。雷冠此后變薄、当地雷炼条件变动保留，救城不自动免去第二次的账。熔煉成功后的日子只养伤与精控，不补欠境界。

最終先九界：等到路窗，劫亲验撤出时间、載荷與伤后承力，不走未验高路。塔姆林若沿现有接口同返，需要本人的冒险愿望、承载與風險知情，不强加四人跟走。分別时少年已有游爐、法与能真正配合的朋友，决定探索第二火；劫五雷启发没有给他现成承火术。兩人留下可履行的交换与再见意愿，不承诺明年必到。

## 九、原 B 放哪裡，為何不把兩場爭火完整黏在一起

原 B 最值得留的是宗門曾真正教人、朋友真正接受師承、青年與師門責任衝突；不是必须把祖炉易主整战再塞進今年。這張新版圖不採 B 全弧到首入：已经有霜庭、族河、浮城、沉舟、火山，多塞完整祖爐爭權會吞掉养伤与主角自己探索的空間。

**新的候选建议**：貝倫在首入浮城後入宗，仍保留「我選了師門」的真实分路。B 的祖爐易主、洛緋与故乡旧友季淮的矛盾，移作少年離別後数年中第一场自主大篇；更換工作名或與已用候选人物对照後，才能正式采用。那时少年有自己的游爐、法、朋友與债，與师门争火不再是劫在场替他赢的事。不是因为未来能写就取消首入他的高潮——首入他已赢游爐、帶队勝、独立撤队、用自己的法护器，成长现在就发生。

原 C 前后单一「浮城封箱—西端航記—火山雷冠」寻路链撤用，浮城本体保留；原 B 铜篷页回家零件链也不复制。两个旧候选仍是材料，以上位置只是本候选的主动取舍，不宣称主 Agent 或作者已定。

主體估量合計約44週；以約52週的首入年為容量，尚有約8週未分配機動，扣除日期取整與可能開期錯位後，以**約6–8週可用余裕**審閱。相較原三段各按八週占满，六週估量釋放的六週來自支路與事件實際分解，不刪戰後恢復、不縮月餘熔雷，也不靠一年多出幾个月。

機動份額的優先用途是：開篇傷勢比預期重與霜庭／沉舟戰後再傷、門環或鳶路額外候班、浮城開期對齊、最後西望樓路況。可先以約2週額外恢復、2週候班／開期、2週西望樓額外支路留位，另約2週不預派；這不是保證每項延誤都不超支。三場若實勘都需八週，會用掉六週機動，便不再具備這版宣稱的6–8週余裕，須重排而非繼續標可行。

这是仍須核驗的容量预算，不锁章数、最终日期。主體遠行、探索、取寶、高潮可在九至十二日的實際入境時段承載大量場景，故事規模不等於每場必須連住兩月。交通以现有五國／城市门环、三边地入口、鳶路和近海船为骨架；新增遗跡的可接入支路長度是本估量的條件，选后要排明确相对位置。既有地理表主要属第二次年代，首入站点、强者与某些门环运营情况须逐一复核，不能用后期人物战力倒填。门环费用高，首战与各遺跡可卖所得负担後续，留有失败后降用度的后果，不靠无上限赞助。若實際支路、票價不足造成的慢路、傷势或開期無法容納於44週主體加機動池，則此版一年排程不成立；不能用壓傷、壓熔煉或讓窗口等人補洞。

首次世界很大，但只走柯涅斯与灰洋近海。外洲人、族河迁居者、諾維雅的远海愿望让全聖土有延伸，不能一年跨完九宽天地。

## 十一、Canon 与后续具体待排

- 前五星羅、兩儀、震魂、千相、無間；第八流光時間系另案候選，首入不碰。無間不自動穿未知禁壁、不加速、不替代跨界資格；已验端点被挪、沉水、失感知即不可续用，伤势与反冲逐场入账。
- 劫約十八、列陣後段，异火少年同齡先一火。多雷是协同，不是混源雷丸；少年已取得实际主器和法，却不因有匣有爐直接双契、火莲。
- 第一场敗、取寶所得、神器放棄與護器毁角都是真账；不讓每败一场就领更大神宝。正式戰綱須核每一敌境与可承时限，不能只因標青年就视为同境。
- 嶙族是智慧种族候选，不是低阶魔兽化形；海中化形者则按真实高阶。族群不能给高阶契兽让鬥師索恩免费驾驭。
- 殞星先当地同意、月余本尊熔炼、末夜完整当前境界成功后首用；雷冠變薄、第二次账保留。九霄、高路、成熟天譴、〈折門〉与全古战史揭露均禁提前。
- 回程早期已得大致窗口，各冒險独立有价值；最后仍核低路现况，返回九界破尊才正式上界复仇。新阵器、勘退路经验与敌方反拆的记忆可用于上界伏杀，不直接给上界无敌杀阵。
- 最初四人有两次真实分路、自己的學習與責任；第二次约四十重逢时少年也四十上下，不降为年幼徒弟。多人未必还愿同桌，第三次人生各有分量。
- 尚待：新增专名撞名、种族谱系与地理位置、各场星数/储力、足额票价与变现、低路同行者名单、月余雷炼与灾势精确分段。此次不改 Canon 主录、不宣称正文或年月已验收。

本候选要让读者在首入末尾既急着看劫回去报仇，也知道聖土仍有未完的人生：塞芙琳把古法带回家会面对什么，珂魯能否真建回藥岩岸，烏薩爾去外宗会成为什么人，諾維雅有没有带船员抵达她想去的远方，伊萊恩的第一座爐后来能容下多少种火。那些人不会等劫回来才重新开始活。
