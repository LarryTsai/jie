# 第一次聖土：先有冒險版圖，再選其中的大篇

2026-10-08，第二輪競構入口。以下是供作者閱讀與選擇的候選，不是三個只能擇一的完整世界，也不是已採用 Canon。原 A/B/C 是大故事材料；新版圖負責試驗它們如何與其他文明、獨立人物人生組成整段旅程。不改正文與主設定。

## 三條旅程

| 新版圖 | 真正深入的天地 | 舊故事的位置 |
|---|---|---|
| [A：借來的一年](冒險版圖A.md) | 獸嶺斷巢、沉鐘海、雲階古都、火山雷冠；勝利之後各自有能力離開隊伍 | 改造原 C 的分層巨構為多道統古都；原 B 留少年離別後的大篇 |
| [B：群山以外還有群山](冒險版圖B.md) | 河底活異族城、斷天橋兵道、宗門爐山、北地沉眠宮、火山雷冠 | 原 B 是旅途中段的人物核心；原 C 完整浮城不塞進今年 |
| [C：霜庭、族河、沉舟](冒險版圖C.md) | 古武王庭、活異族柱城與巨獸脊藏、浮城、近海沉舟宮、火山雷冠 | 原 C 浮城保留游爐實得；原 B 作少年离別後自主故事的候選 |

三稿的姓名與新族群各自屬於本稿，不能全數搬入人物總錄。同類題材不是同一事件；例如 A 的海底亡城與 C 的海上女船主必須比較承諾、對抗與高潮，再選擇或重創，不能兩個地名都好聽便全加。

## 主 Agent 的推薦方向

以 C 作下一層旅程設計的優先候選，原因是回程窗口較早建立，後面的冒險不必假裝每處都有回家答案；少年也有離開劫視線、帶陌生隊伍打出勝場的完整段落。這只是工作推薦，未替作者選定。獨立比較見[Reviewer 紀錄](冒險版圖獨立比較.md)，原始三稿推薦 B 的判斷只針對單一大故事，不能機械沿用到整張版圖。

推薦旅程中的追讀變化是：先想活下來與回家，接着想試一試陌生的法，再為真正想要的寶物與道路競爭，最後知道還有想看的遠方，仍選擇回去。末段不是忘掉家傷，也不是所有收穫都換成一張出境票。

B 的河底活城與沉眠修士有強烈陌生文明感，是值得保留的另一方向；它們可替換某一篇，不能直接加在 C 五篇後面。A 的勝後分路、競爭者帶同門先走、飯桌再聚仍各自離開，則是值得在任何採用版中重新創作的關係品質，不能只抄一句「朋友不是工具人」。

## 這輪的驗收與仍待完成之處

已完成三寫手獨立架構與獨立比較，新增非火源冒險有主動對手、反制、所得與人物後果。沒有正文、沒有候選升 Canon。沒有預定卷數章數，一年仍是現行年代邊界；精確地理、交通、票價、持物、傷勢和逐招能力須在採用後排實際戰綱。

共同需防止的模板是每次進遺跡都由長老在高層忙、青年封出口、主角舍寶突圍，以及女天驕先勝後窄敗的均分勝負。首輪比較不得把這些藏在「都很精彩」之後。此輪局部重構與勘誤只修具體問題，不表示故事已經通過正文閱讀驗收，也不以修到某個分數結案。
