# 跨界試煉：獨立比較

2026-10-08。Reviewer 未參與三稿寫作；讀過任務單、舊版核對、現有聖土長篇多線主幹與 A／B／C 全稿。以下是候選比較，不能代替作者選定，也不升 Canon。不以反覆修到某個分數作驗收。

## 裁決

**整體推薦 C，B 次之，A 保留。三份都值得留下，但尚不能宣布跨界關聯已證成，也不能把它們合成三座新古地。** C 最能把「更龐大體系的不同難題」做成可見奇觀；B 的當場衝突與舊勝法失效最有戲；A 的現代文明改造、異族真取成果最完整。

競構還有一項真限制：三稿都圍繞發力、承力、轉承與回收，也都選第二訪取代墜羽臺。它們不是換名同稿，但規則與戰術的差異，沒有三種關聯標題看起來那麼大。不能把這次交付稱為三種完全不同的冒險體系。

| 面向 | A 鳴骨澤 | B 折照渡 | C 不歸海 |
| --- | --- | --- | --- |
| 閱讀吸引力與仙感 | 骨葦、活承架、獸族鍛器有鮮明觸感；後段較像一場高階材料與爐器競取。 | 石階倒影與走成的法留下實物，有修士歲月感；舊勝法在新地失效容易留下記憶。 | 海已不在、船礁仍懸、潮退後法能否留存，是三稿最容易使讀者想親眼看的奇觀。 |

## 各稿真正需要解決的地方

**A 的長處不是「承力教法很合理」，而是有人先成功，真的抽走別人需要的承架。** 赫戎不須作惡便能改變戰場，薩芮也不是守關解說員。弱點是少年再爭一座完整爐，可能與首訪小爐、浮城游爐重複。選後必須讓弟子承載失敗與新爐用途在此前已成真問題，不能臨開場補一句理由。瑟維恩與少年、劫的分別勝負，也需戰綱明確先後，避免同一敵人連續敗兩次卻仍供高潮。

**B 最好的場面是劫用自己的舊解，反而更疼。** 這不否定昔日勝利，卻逼他承認自己學到的是地方讀法。倪弦與老師的衝突不是師徒立刻和解，也值得留。弱點是影面、借負載、換面、承石同時出現，若正文依次解說會像規則課。應讓初敗先給讀者一個可辨的因果，再逐步增加戰術；不能每次交鋒都靠切斷供力空檔。其少年敗槍修、再以有限火蓮奪回承火材，與既有墜羽臺主幹高度相近，取代成本低，新增驚喜也因此有限。

**C 的奇觀與對照問題最適合作者這次要求。** 當年的路送人上去，眼前的海讓法留下，舊故事因此增值。堂姐與翎嵐的分歧也不是善惡族群二分。弱點是劫有完整強敵戰，少年主要有取材、護巢及即用成果；若本弧被宣稱雙驕大高潮，少年這一側仍不夠重。不能只加一個敵人名字交差，應從奪走大材的器師或既有利益衝突發展實際競爭。此外「法在失去載體後留存」不能悄悄變成兩界共同修煉法；薄璧是有限耗材，禁紋仍有既定近端與供力，不創無介質無限施術。

## 關聯是否可信，與 Canon 檢查

三稿均正確標明：舊版前兩次已落正文，仙界第三次未寫；新版只有古臺與人物入口，不能據此偽造劫已闖過、已拿黑褐片。若重新安排早年試煉，境界、對手與所得必須重造，不能搬舊洞天燕照來和五雷列陣劫同境競賽。A 尤其依賴兩段早年經歷，前置成本最高；C 允許反向先見聖土、後闖三十二天，調度最自由，但那會延後「當年原來還有另一面」的回報。

三稿都沒有把古物共鳴改成導航、開門或授能；黑褐歸劫、灰白歸封寒的邊界有保留。也未安排曉打造、古戰活魂傳功、混修或藉此直接證公主案。第二訪已完整殞星，C 終戰選五雷配合可讀作只用其中五雷，不能據此倒退角色為僅有五雷。星數與客場消耗未核，是待細設，不能當成已完成戰力驗收。

**一般的承力難題、相似步序或七個孔，皆不足以讓角色斷言同源。** 日後需具體可比較的改造層、罕見工法組合或可被排除的版本差異；若來源不足，就讓相似仍是疑問。第三处也不必立刻證實最大古體系，而應提供能推翻現有解釋的證據與自身勝負。

建議將 C 保留為最優先細化候選，B 保留為不同人物衝突讀法，A 保留文明改造方案；不整份拼接、不改首訪行程、不回寫主錄。這輪證明跨界試煉有故事潛力，尚未證明其完整長線已經成功。

### 追讀後補判：C 的撤離高潮尚有同構問題

C「三條退出礁帶只剩一條，槍修據穩位，劫奪回撤離位」仍然以通路收縮啟動決戰。雖非收費封門，卻與前輪屢用出口受限的高潮同構，奇觀新鮮不能替它免審。**所以推薦 C 是優先細化，不是通過可採。** 若要採用，高潮須把主要勝負改由角色主動爭留存之法、材料或已立承諾發動，不能只換一句「我不是封路」。這是核心弧的局部重構要求，不是重開第四套聖土。

C 另有持物文字需勘誤：斐洛恩攜本宗槍胚而來，中段「已取槍胚」不能讀成又在現場取得同一胚。應維持一條保管鏈，當地新所得另明其為槍法或整料。A 骨盤、B 影階與 C 灰白潮的規則皆屬新候選；正文細化還須說清實際載體、供力與失敗如何发生，不能讓古機關因人物悟道就自行認證。若 C 不願改撤位高潮，則暫留比較而退回可採位置，不以綜合排序替作者定案。

## C 一次定向修訂後的獨立複核

初稿另存供追溯；本節不改原比較排序，不重打分，只核兩项退改原因。

| 初稿問題 | 修訂後具體事件 | 複核結果 |
| --- | --- | --- |
| 通路縮成一條、據撤離位發動終戰 | 東側飛越、西側舟槽與碎礁均保留；斐敗後真的搭舟撤走。劫初戰敗後可離海，仍為完整斷潮璧留下；觀璧背、試薄石失敗、中段再決定爭璧，終戰先完成留法取璧、再近戰守所得。 | 已真正改動目標、準備與終局，不是只把「封路」改名。戰鬥不再是逃不出去才必須打，這項退改原因已解。 |
| 少年只有護巢取材，缺自己的强敵勝場 | 既有搶大材者具名盧鐸，赤銅爐甲利用少年留火反擊、奪其砂袋；少年用已取骨砂承换火、鎖導槽擊關節，付游爐破損而勝。取回砂袋与旁礁砂脈，盧鐸仍帶最大原材離開。劫未代打，少年也未在爭璧終局補刀。 | 已形成獨立初敗、觀察、戰術反攻與有限所得；護巢選擇实际改变首敗及追擊止點。第二項退改原因已解。 |

槍胚持物也已明確：本宗帶入，當地新得續槍法與鍛材，帶敗保胚而非重複取得。第二訪諸雷未被錯限成只剩五雷。修訂值得存檔，仍不是章綱或 Canon 採用批准。

剩餘風險有三項。第一，璧面「自身法完成一次作用，薄殼才脫離」已有具體操作，却仍需解釋潮、薄殼與法的實際物性關係；尤其斐先裂殼、劫另從璧背震開，不能在正文顯得古物臨時偏袒劫。第二，少年兩火與骨砂的配合成立於已有能力，低逸散凝火、第三火餌如何被感知及引偏爐錘，尚需戰綱落实，不靠敵人忽然愚笨。第三，相似工法仍不足以證共同源頭，新三十二天端未寫之前，熟悉回憶只能保留為條件式接法。

本輪只作這一次針對明確問題的重構與複核。兩項缺點解決，不表示其他風險全消失，也不表示三稿已變成毫無同質的三套規則。作者仍可依閱讀喜好選、退或延後。
