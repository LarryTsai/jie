# 不進遺跡，大城還值得追嗎？——第三輪獨立比較

2026-10-08。Reviewer 未參與三稿創作，讀共用任務、最新活城 A／重構 B／修訂 C，以及跨界境界、當代生活的城市秩序與無間入口後比較。原 B 初稿也讀過，其退稿原因另記。依小說審查矩陣分辨閱讀、因果、人物與 Canon；本輪沒有正文，不假稱逐章節奏、語感與全年容量已驗收。以下推薦僅是工作方向，三稿仍非 Canon。

## 判斷：值得繼續，但三稿都不能直接變成全年城市主幹

**推薦修訂 C 優先，重構 B 為另一種較狠的方向，A 作獨立的溫暖競構。**不是將三份各取一場，湊成城市六戰。C 最能讓不同人的願望改變故事發生方式；B 的師承與實戰能拉住讀者，尚須補足對手和同城關係；A 最容易使人喜歡住處，但連續三次以技法取勝收束，追讀牽引較弱。

這輪已部分回答作者的要求：少年不靠劫也能有主勝場，強大女修不等青年救場，朋友可加入真正值得加入的師門。也開始有「我還想回這個院門」的感情。仍不能稱整個聖土已活起來：三版主要是幾條街與一群朋友，城市其他修士的更大關係網尚未完整，成年角色也容易都在同一段時間迎來人生大決裂。

## C：最接近欲望會自行生長的城市

最想追的是少年承認自己想贏費恩、買爐，卻發現長時間壓溫傷了自己的契火。朋友仍有可用的另一份藥，不會因友情便吞危險藥；她自己選擇延後衝關。少年把火留下養復，以較慢且需長時親控的普通爐火完成答應的事。提沃前場已有慢煉示範，異火的優勢是速度與多試一輪，不是此藥唯一准入資格：修訂後已解掉「普通火可用，為何此前非要傷異火」的主要因果缺口。

這一場可兼有煉藥的緊張、契火的重量和技藝的喜悅，不必用丹賽評出誰整體更強。萊緹婭另一次自己破鬥靈，少年收真正藥費買爐，費恩未得到報酬、仍不認自己整體輸了。各人實得不同，失敗沒有被酒席洗平。少年離開劫後仍有想再贏的同鄉、敢拒藥的朋友與需要照顧的火，主角級人生已有現在的根。

阿蕾莎也是 C 最大優勢。她有可住的城、師弟妹、外洲同道，仍想親殺當年撤位害死朋友的舊同行者。勝後受傷，吃早先答應的魚；死者徒弟不肯原諒她，也沒有立刻啟動全宗追殺。這個拒絕比又送少年一套神功更有歲月重量。她復仇前後都有生活，不是為劫解釋報仇觀念的講師。

劫的器源恩怨也有可記住的誤判：他想看陌生器法，誤以為懂材料便足以控制接觸，受傷後親贏捕雷者、取器付藥費。可是兩個弱點不能放過。第一，試器前場若展開成連續數據驗證，會重回作者已拒的研究流程；真正要看的是善意如何越界與劫察覺、斷接。第二，「傷人後再邀合規賭物」尚需更強的當場情緒和對方接受理由，不能像安排一場公平售後。捕雷器有限牽扯本源是新候選術理，不能拿一句只能抽一點便當完整驗證。

C 的城市辨識度是爐街店桌、朋友有時不到場、店主也準備走。不是人人永久守一張桌等主角。三高潮分別為停催後独煉、私人器戰與成熟修士殺仇，已有兩條結構差異；兩場法鬥仍都是凝物防面被改承力突破，正式戰綱須再拉開。

## B 重構：讀者更容易想知道下一步，卻有把城市寫成壞師父圍徒弟的危險

最強的場面不是收徒名額，而是齊鶴第一次衝关失敗後，真發現自己連舊細火也握不住。他先拒燕寄秋、趕走岑燧，後來自己找朋友說不想再按老師時間破境。少年的勝場因此是幫一個自主改選的人帶走自己的爐器，使用剛學過的火殼薄用擊敗攔路同境者；不是替朋友決定人生後得表揚。燕寄秋受恩於舊師，卻為第一次肯收的弟子與舊師翻臉，贏後道傷加重、暫停遠行。她想成為能教人的師父，和 A 的伴侶離城、C 的舊仇清算確有不同。

劫不是旁觀城市客。他從邀約、餌人被換和採辦異常辨局，先勘坡布禁，對方燒禁、繞後，他再換位殺共同奪雷者。這是主動、帶怒又有準備的劫，也有自己的傷與取得的護器。青年各自戰後回院，先問衣服還能否穿，再說起家人與仇，這段比結尾宣布互相理解有用。

但 B 現稿較短，部分高潮仍是骨架。岑燧救友、劫反伏殺、女修擊敗舊師都以城外實戰收束，刺激強，變化仍不足。霍青峒起初教真法，失手後立刻拘徒催再試，需保留他真相信法的吸引力與同門分歧，否則仍是好老師換皮成壞老師。杜問峯也會強押人，兩位長輩連續以拘徒維權，容易把師承文明縮成暴力控制。聞崖的好師承應有可看的小段與不那麼善解人意的邊界，不能僅在外圍保管傷者。

最重要的驗證仍未完成：傷中劫如何在兩名同層者圍攻下殺一人、再殺季衡，對手各自什麼階段、出手多少、已有雷法能供到哪裡，不能由「同層可勝」包辦。兩場截徒與野外殺人會留下誰真想追、谁选择止步，也须具体化；不能为让院子重新安静，立刻把宗门后果都延期至另一篇。

## A：留戀最自然，戲劇推進尚未走出連續約戰

陸沉先羨慕塞恩的重屏，主動邀戰，輸後晚飯吃得很快；少年有異火仍輸給獸火藥師。這是陌生文明令主角真心想學的喜悅，沒有全城侮辱才啟動。塞恩拿姐姐敗績替她定修法，姐姐帶刀回城後仍去尋自己的師父，她沒有被劫一席話治好。妮拉留院爭丹方，少年買可帶走的小爐；柏恩拿到名額值得真慶祝，日後也只是較少回來吃飯。坡街因此有住過的感覺。

問題是核心連續三次：先失手或受限、改技法、打贏約定對手、因此走自己的路。艾薇即使輸也有自由，所以翼戰勝負不決定離開，只驗修法可行；人物成立，追讀壓力卻較輕。借爐較量又由降低產量保穩定贏過正規藥術，和其他稿早期少年套路重疊。若把各弧都當數十章重篇，讀者很快知道下一場會如何結束。

A 不是無用的日常，也不應丟棄朋友學法的高興；它適合作另一份獨立城市方案繼續發展，當前不足以勝過 C 或 B 的主要因果。不能直接從 A 抽出飯局塞進其餘稿便宣稱補好了城市。

## 競稿差異與退稿記錄

原 B 初稿實際沿「少年對煉買爐、劫同境約戰、成年伴侶分器離開、四友分路」組織，與 A 至少兩條核心同形。已退回重構，保留《活城B_初稿》而不把改名當競爭。新 B 改為危險師承、救友實戰與女修首次授徒；C 少年高潮也從同日對煉改成受創契火、停催、獨煉，女修核心一直是舊仇殺戰。故最終三稿有不同欲望與高潮結構；仍共享求爐、朋友分路、雷端受限，這些共性須誠實保留。

## Canon 與下一步驗收

目前未發現可斷言的新增 P0 硬衝突。五雷均使用現行無間，初期近端可驗，不把流光速度、成熟雷丸、高路放回十八歲；青年沒有替鬥皇贏戰。A 庭內切磋、B 城外襲殺、C 高階生死戰分別需要不同秩序，不能都寫成登記即可免罪。第二次年代的「只接冒籍約戰」、高階鑑定職位與成年舊人物戰力，不是首入一概禁止或可搬用的規定。新人物、新火匣與新器術仍是候選，不因尚無檔案就判違 Canon。

P1 共通項是傷勢、補給、跨界學法負荷與全年時距；B 的圍殺戰量，C 的本源牽扯和契火養復尤其須核。約一年應重排剩餘候選，不能把城市免費加在原五遺跡表上。末段殞星须先完整熔炼到当下境界才首用，返九界才破尊；塔姆林同返等接口仍须日历排实。

若採 C 工作方向，下一個可審閱里程碑應先把城市關係與因果補完整：具體是哪句要求令少年催火过头、费恩为什么真愿留退路、劫为何信多尔文、阿蕾莎与旧徒关系如何积累。讀者應能在不預告新遺跡時仍想知道他們下次見面如何說話、有何物可爭；也要有一次成法與相聚的喜悅，不让每顿饭都只是受伤和出走后的疗伤。

反省：本輪最晚才看見的是稿間同形，單獨閱讀容易被人物有欲望掩蓋。現行結構審查本已有重複與因果要求，應在競稿對照時實際比較欲望、反制、高潮及所得，無需新增泛化技能或強制比分。此次只留本輪比較紀錄。未寫正文、未選 Canon、未宣稱小說審查全閉環。
