# 第一次聖土三稿：獨立比較

2026-10-08。Reviewer 未參與 A／B／C 構思，已讀三稿、任務單、團隊規約、同齡雙驕弧，以及首入、雷道、跨界與地理來源。本文只比較候選，不修改三稿，不升 Canon。本轮作者明確不急正文，故不以缺正文試章拒稿；目前判斷的是故事主幹承載力，不是已驗證的章節閱讀品質。

## 結論先說

**推薦順位 B → C → A。B 最值得先讀完整展開；C 是真正可選的另一種讀法；A 有漂亮的競爭與友情場面，但整體仍偏收斂，距作者要求的龐大聖土最近一輪之外還有明顯差距。**不建議全退：B 的宗門轉變、同伴真打與女天驕敵友轉換，C 的浮城垂直奪寶與雙線高潮，已長出作者沒逐項提供的新主幹。也不宣稱任何稿已成為令人停不下來的長篇。

三稿有一项共同的實質 Canon 錯誤：**第五雷寫成流光搶位，現行第五應是無間。**這會影響逐招勝因，需要主 Agent 修正候選層，不應帶進選稿後戰綱。它不改本輪故事推薦順位，但三稿皆不能被報成 Canon 已通過。

核心對抗、探索結構、關係選擇至少三項有真差異，不能說只是換名字。**但尚不是三個完全不同的世界想像**：三稿都把少年獨立煉爐放在中心，都以火器競取推進，都回到同一場雷冠救城與低路返鄉。末段相近部分來自現行作者定雷檔，不能為求不同擅自刪除；中段卻仍有擴大想像的餘地。

## B：最想追的是曾經值得信任的人，為何走到必須交手

最有吸引力的不是鄒荻爭權，而是洛緋先教唐峭、替岑燧擋傷，後來真的封住他們的路。她保護宗門的願望始終連續，沒有變臉成魔頭。唐峭新學凝橋攔下岑燧，岑燧拆爐掌震裂那座橋：**同一份師承既讓朋友變強，也讓朋友與自己站到相反位置。**這是可記住、能撐長篇的人物事件。

獸地段也不只是善良救獸：烏岐未提前告知解契，岑燧仍按舊合擊冒進，唐峭因而肩傷。唐峭指出兩人責任，讓每個人都不能躲進一個漂亮價值觀。季淮把共同願望的爐房鑰匙嵌进兵器，則讓少年與舊友的決戰有能看見的感情重量。

代表高潮值得保留：懸砧窟七件承火器逐次落下、每人只能追兩处；唐峭與岑燧真打；辛珞與洛緋爭火、少年與季淮爭法、劫與洛緋破封三場交錯。每次機緣都改變後戰，不是到站領新材料。

拿掉劫，少年仍有故鄉舊友、祖爐繼承、分炉篇、宗門条件及好友守橋這條完整冒險。三稿中這一點 B 最強。劫則不是隨隊拳頭：他另選風砧進法、用器換通行、辨銅篷頁、搶逃路、主動接洛緋一戰。兩人所爭不同，合作才有價值。

最容易棄讀處：封山前後如果反覆說明「宗門壟斷不對、自由承火對」，會變成制度辯論。燧席選老守爐者也可能讓青年所有爭鋒像替長老候選清場。稿中已有早露面承諾，但還須讓守炉者有可見的選擇与不足，不能靠火最後宣布正確答案。長老在天空交手只是分層標籤；選後須排明青年如何能保住既得，而非鬥宗到場一言定局。

B 世界很有社會縱深，地理廣度尚有限。適合作第一次聖土的核心大篇，不應直接宣稱它已展開諸洲全貌。異族石頌、辛珞、季淮值得延續，但暫留「愛侶與背叛」幾字不等於少年數十年人生已完成。

## C：仙感最直接，雙驕兩場取勝最清楚

浮城樓街由谷底百爐熱升托住，宗門走上爐、散修攀排煙道、獸族另入獸藥庭，具有能在腦中看見的龐大遺跡。劫在爐橋真敗給薇瑟，落到城底只找到外來封箱、沒有回家門；這把挫折、陌生文明與另一位天驕的實力放在同一場裡，勝過拿拓片逐次檢測。

最值得讀的中段轉折是兩主角想分路。少年說「你有地方能回去，我還沒找到」，劫說家人受傷；兩個願望都成立，稿没有用主角家仇压倒朋友人生。米蕾拒絕被貝倫代決是否離城、索恩明明能追獸族卻守完承諾，也讓隊友有行動權。

代表高潮是劫、薇瑟、貝倫分路破奧默隊陣，与少年、米蕾、梅菈爭主爐同步。劫殺直接封撤路的敵人，少年贏火候競取、實際帶走游爐。既有主角狠勁，也有少年自己的勝場，讀者能享受寶物真拿到手。

拿掉劫，少年仍會争游爐、遇上商宗買斷與梅菈競爭；但最後退路依靠劫測定，後續仇又部分来自劫殺奧默，獨立人生比 B 更倚賴本篇協作。這不致退稿，只要不把「商宗追討」當他全部後半生。

最容易棄讀處：藥窟、浮城、火山若都寫成搶藥器—落下—找到另路—付器物撤離，連續形式會相似。浮城目前最鮮明的是取物機制，死去文明的活人痕跡、奇異生物與不能只靠熱力說明的未知仍薄。十九日開城很適合紧弧，卻不能靠前後各加月份就宣稱數十章每段都有事。中层抢炉与高层斗皇战的联系还要更具体。

C 未拿第七雷、沒有高路捷徑；先西後東再西又東最後西，具體月份比其餘稿清楚，卻也最有跨地理壓力。選後須核合法門環接駁、入場費、等候與受傷停留，不能全用一句「費用待聯排」跳過。

## A：競爭與友情最好呼吸，但尺度最保守

奧倫為小宗百餘口人争火，伊岑想自己的爐，兩人都不是錯的。浮灰古道中奧倫先讀懂熱流、抢走大份，少年輸得服氣；懸爐山少年靠爐息留下低溫空隙贏一爐，對手取得残技而不被羞辱。這種長期競爭是可靠的支柱。

最值得保留的安靜場面是柏恩把入宗牌放上饭桌，大家祝賀後，伊岑独自洗爐，劫陪著他。沒有「變強就能留住朋友」的空話。兩隊爭石眠，最後火拒絕兩人，也让「不是作者發獎」成立。

弱處在其主要競爭多以各拿一份、平手、協商、保留下一次收束；古道失望、獸道失材、第二火未成，幾場接起來後，讀者可能觉得旅途一直很懂事，却缺真正非追不可的危局。瑟芙反拆雷身很有戰鬥看頭，但两次較量都服務於拿適用導架；薩孟逼塌山道的惡事與後來去向没有形成足夠強的懸念。不能只增加爆炸或死人，要讓既有選擇碰撞到不可兼得的主弧結果。

少年拿掉劫仍能與奧倫爭火、建立試爐，成立；洛婭與梅芮的選擇也成立。但 A 目前像一場有趣、细腻的少年遠遊，還不能單靠它兌現作者說的龐大修仙世界。推薦保留为獨立候選或另篇征途素材，不主張立即把其好場面全拼進 B，破壞競稿真正取捨。

## Canon：硬衝突、舊節奏與尚未核實分開

1. **三稿硬衝突：第五雷。**《無間神雷.md》狀態明写 2026-10-04 本輪設計採用，第五無間、唯一空間／界系，取代流光第五位；《雷種熔煉與雷身修行.md》首行與《主角群武學譜.md》首行都停用舊第五流光高速。A/B/C 首戰與中段仍寫流光搶位；B 更列五雷為星羅、兩儀、震魂、千相、流光。任務單的「五雷」沒有授權恢復舊雷序。應刪舊流光勝因，依現行無間早期有限接點重排，不能把流光改名無間便全保留高速效果，更不能因持第五空間雷便直接跨界返家。
2. **A 後續承諾与作者最新方向不一致。**「第二次重逢時…多火協同、後來才創造融合火蓮」容易把已定的再會火蓮展示延後。作者要求第二次重逢前少年已走出融合，反向啟發劫。B、C 明寫重逢时已有融合杀招；A 必須訂正時間，不得当一般留白。
3. **殞星完整熔煉是硬規則；月餘是舊事件節奏。**《雷種熔煉與雷身修行.md》7–11 行：煉到劫當下完整境界才成功，不允許低階先用、後補。雷檔没有规定固定天数；旧《落潮一年事件骨架.md》406、415 行寫最後一段月餘完成、臥床月餘，屬這次獲授權重排的舊故事安排。因此 A 三日、B 至天明不因缩短天数自动硬冲突，却比旧难度显著压缩，不能只用受伤和咬牙當解釋。C 的「當夜熔、後續數周養煉」最容易形成未完先用歧義，需明確後續是成功後恢复精控，還是尚未完成。任何版本一旦首次殞星出手前未達完整列陣，才構成硬衝突。
4. **首用小核不等於偷用〈天隕〉。**雷檔允许速凝小核與蓄力重擊，〈天隕〉为後續鎮雷大術且門檻待定。A 打石塞、B 拆碎冠、C 取雷使用方向未直接偷招；必須控可承量、壓縮時間和波及范围，不能小核一下摧毀高境無法處理的大主冠。
5. **高境介入没有明顯越階硬錯，但分層理由仍需實排。**三稿均讓鬥王以上行動，没有列陣斬鬥聖；B 青年拿法而非弑鬥皇，C 上爐強者有真所得，A 高境追薩孟，成立。警惕把「他们忙高處」用於每一場直到主角打完；尤其 B 封山决战、C 强者崩城、三稿冠鸣，需要进入、出手、退場的时间与目标。
6. **雷冠救城不能因作者不想救災報告便自行撤掉。**《殞星天雷.md》天然雷性与主线咬合明定救布蘭堡、當地同意、本尊熔至列陣、冠逐年變薄。三稿共用此高潮有来源；反覆救援職能清單是寫法风险，非保留这一场就违反作者。必须以修行争取与承力选择为中心，而非谁负责疏散的工作表。
7. **年月尚未完成，不報通過。**A 各段相加約十一至十二月、含東西接駁仍緊；B 只有大段数月，最不够可核；C 月段明确但多次東西折返。當代地理是第二次時點，人物戰力不能倒填二十二年前。地名與門環網可作空間骨架，具体强者与空窗须另排。約一年先返九界、回來破尊再正式上界的出口，三稿均保留。
8. 老人送終、譚晚潮死亡及舊採隊首次救援属于已授权重排旧内容，没有必要为保存旧验收强塞三稿；本次末段未宣称同步 Canon。多火與雷丸新授權覆蓋舊一概禁止多火條款，仍不授权第一篇直接融合或常態混一本源。
