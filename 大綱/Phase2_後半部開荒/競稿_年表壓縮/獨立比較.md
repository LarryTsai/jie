# 年表壓縮競稿：獨立比較

2026-10-08，獨立 Reviewer（未參與三案寫作）。依[規約](../../../設定/00_故事定位/AI團隊競爭創作規約.md)先比較閱讀欲望與節奏，再查 Canon。三案都是工作候選，本檔不改任何現行文件。

## 一、結論

**推薦順序：C ＞ B ＞ A，不全退。**以 C 為底，只向 B 借一件事：**把第二次聖土拆成兩場冒險**（終局因此約晚一年，落在約 36–37 歲；C 的帝壽時鐘本來就是「約 36、37 歲壽盡」，放得下）。

三項關鍵理由：
1. **C 解釋「為什麼這麼快」時沒有新增成長引擎。**它的答案是三座外部時鐘：太宸餘壽、界潮密集期、追殺。陸沉快，是因為「從來沒有機會慢」。A 靠「以劫養境」把歸墟擴成破境燃料，B 靠「引齡制」改寫譯氣。C 是唯一一案讓聖土譯氣規則照原意運作：強者住不久，他在聖土只到客階。
2. **C 的「門與牆」最符合作者「劫有五雷，本來就能越境打，打鬥宗可以」，也保住敵人的威脅。**拆門就能越境，拆得掉的門有限，至尊牆、真仙牆擺在那裡。敵人也會拆門，婁直拆的是天譴之裂。每一段都有一道他拆得掉的門，也有一道拆不掉的。
3. **C 終局約 35 歲，十八歲後約 17 年，介於兩案之間。**A 只有 12 年，後段擠爆，第二次重逢的分量也太輕。B 拉到 41 歲，三十歲以後已不像「少年天驕」。C 是三案裡唯一同時守住「每場一到兩年」和「少年天驕」兩頭的。

## 二、閱讀欲望與節奏

### A：十二年天驕，終局約 30 歲

- **最強設計**：劫雲是燈。被追殺時破境會暴露位置，「他敢不敢在被追時破境」是全書最好的懸念鉤之一。歸墟之後每一劫都吞，第二次聖土遁一劫第一次不吞，使 Canon 原有的「他沒吞」由輕變重。試寫是三案最好的場景，伊萊恩那句「我讓它們先吵完」把火蓮和雷丸的題目一次立住。
- **最易棄讀的段落**：
  - **②獵仇之年（19–20）**：一年內塞了破尊、上界、拍賣、伏殺、命玉報死、三宗獵殺、破神火、沉船二選一、斬天神追索使。追殺需要的「喘不過氣又逃不掉」被事件數量淹掉。
  - **⑦第二次聖土（24–25.5）**：一年半要容下重逢、雙匣人、屋頂之帳、遁一、至尊、九霄、校正公布和父親壽終，每一件都只能過場。此時距初遇只有六年，伊萊恩隊伍做不出〈同齡雙驕〉第七節要的「幾十年從具體變化裡出現」，重逢分量最輕。
  - **⑨重爬（26–27.5）**：一年半拿回至尊，大敗的代價顯得便宜。
  - 整體看，天神約 21、至尊約 25，又每劫都吞，破境容易變成例行公事，碾壓風險最高。

### B：一潮之書，終局約 41 歲

- **最強設計**：「快的帳」。十九到三十四歲連過八個大境，道基是長太快的樹，三十五歲斷階時連根碎掉。這把第五段長弧「我的方法本身出了問題」做成了物理原因，主題上最深。第二次聖土拆成Ⅸ（火蓮與見劫）和Ⅹ（屋頂與九霄）兩場，各有主敵、所得與出口，中段牽引是三案最好的。十三年後重逢，斷指、刮花的名字、「從不讓他插隊」，分量最足。Ⅶ讓讀者親眼看見撕痕使他破不了境，也是正確寫法。
- **最易棄讀的段落**：
  - **Ⅵ–Ⅷ（26–31）**：金丹兩年、同代一年半，再接空位，五年裡缺少壓在劫頭上的外部時鐘。主角三十歲還在「同代之城」爭寶，少年感開始流失。
  - **ⅩⅢ**：至尊（37）到真仙（38）只隔一年，B 自己也承認這是全案最薄處。
  - 終局 41 歲，比作者說的「少年天驕快速成長」多出一個十年級。

### C：時鐘倒推，終局約 35.5 歲

- **最強設計**：三座時鐘決定每一段的出口，段二被命玉推出、段八被校正推落、段九被第二次校正的公告推起，讀者每段都知道下一個期限。「時鐘咬合」解釋兩個公開時鐘為什麼必然落在同一天，修好了現行「強接派選日撞窗」的巧合感。帝壽依據核實：見〈歸一派〉第 97 行「日期定在太宸餘壽將盡之前」，以及〈祁宗岳_太宸仙帝〉第 42 行。試寫裡布魯諾一戰把火蓮放在場上，Canon 已有「伊萊恩以火蓮勝他」的接口；雷丸第一次試，「直接合」就失手，失敗有價可算。
- **最易棄讀的段落**：
  - **段七第二次聖土（29–30.5）**：問題同 A，一年半太擠。這正是建議向 B 借拆分的原因。
  - **段八**：至尊移到上無極，破境幾週後就迎來第一次校正。「爬到最高處」幾乎沒有好日子，反差夠，但讀者沒享受到登頂。
  - **段十一**：第三次聖土距第二次只有四年。伊萊恩的「一方巨擘」要改成「替聖土選立場」，C 的轉法成立，但分量比舊稿輕。
- **與 B 的試寫高度相似**：坑邊炭筆牆、欠一頓餅、爐、雷丸第一次失手，兩案都有。不是抄襲，是同一份任務單自然長出的同一場戲。選定後可只留一版。

**不早於荒**：三案都推定天神以上會早於荒，但都沒有數字。總稿第 1052–1067 行說 PM 已依原作比過天神到至尊，「數字不寫入本稿」，並說「最緊的一境是至尊」（舊年表 68 歲）。**這不必猜，PM 手上就有數字，應先交出來再請作者決定。**真一以前三案都成立：真一最早的是 A 的 21 歲，荒是 18–19。

**新增或接近萬能的機制**：
- **A 的「以劫養境」最接近萬能。**〈歸墟黑雷〉只寫「吞納外來雷霆……轉成自身可用的雷力」，並限制「吞納速度與承載有限，強雷能撐破」（第 15、37 行）。多身之劫按〈雷種熔煉與雷身修行〉第 39 行是「幾何級增長」。A 把歸墟擴成「每吞一劫換得下一境大半的量」，形同常駐的修為倍率，也稀釋了 D066「真一劫非吞不過」那一次的特殊性。
- **A 的雷晶「一次撥出一代人的配額」**：用一筆資源補掉三十年住期，A 有寫布蘭堡缺晶數年作代價，但代價落在他人身上。
- **A 與 B 都改了 Canon 明文。**〈境界對照與跨界〉第 303 行寫殞星「只給通階的門檻，不省時間」，A 主張撤用；B 的引齡制等於推翻這一句，卻沒有列入「需作者決定」，只放在 Canon 風險裡。這算半誠實。
- **C 的「時鐘咬合」**：限定只用於校正和立錨，屬局部新推論，有列為候選，可以接受。
- **C 把「只有陸沉越質變點」放寬為主角級同代可越一道門。**這動到作者定的 D087，C 有列入待決。
- **B 為盧修斯一戰新設崖門規則（落地滿三息即破門）。**這實際上是舊通則「改變勝負條件」那一格，沒有真正用到新的越境能力。

**暗中刪改**：
- **A 有兩處違反作者當日續定，屬最大硬傷。**
  1. 停籍前移到 20.5 歲。〈Phase2 README〉第 7 行等多檔的 10-08 續定明寫「D124 二十四歲停籍不前移」。A 雖列入待決第 8 條，但這是同日作者已定的事項。
  2. 歸墟改到 21 歲。〈年齡線〉第 75、110 行 D066 定為約 25；A 的新年表把它寫成既成事實。
- B 和 C 都守住停籍 24、歸墟約 25，壓縮全部放在 26 歲以後。
- **界潮週期**：〈境界對照〉第 371、456 行寫疏期「數年到數十年一開」，守約「幾乎做不到」，低路的稀少靠這條撐住。A 的 12 年週期只剩約 7 年疏期，最傷這條；A 又把第 27 篇回程窗與立錨窗合一，改了第 595 行的讀法。B 和 C 也都提高了窗口頻率，但疏期仍有 11–13 年，可以維持。
- **父親壽終**：〈境界與能力尺度〉第 28 行銘紋壽元一百二十至一百六十。三案都得用「以修為換封泥」去撐五、六十歲壽終。A 最緊，B 最寬，C 主動排除費氏之傷，這一點正確。
- **救生豁免檔**：〈九界金丹〉第 3 行寫「約 27–31 歲」。任務單允許改時點，但能否改豁免檔裡的字，只有 B 提出來請作者決定。

## 四、越境尺度與盧修斯

- **A**：表格最清楚，代價最實（熔雷後兩雷暗到養回）。但列陣能正面打下雛翼譜第二的鬥宗，聖土鬥宗這一層的威嚴在第一年就被打穿。之後每年一次越二，越境的稀有感也會消失。
- **B**：級差最精細，同伴上限寫得最好，例如雲行「守得住」不求勝。但九身合爐以前，二級差只能在規則場勝。作者說「打鬥宗可以」，B 的首入其實只兌現了一半。
- **C**：門與牆有兩個好處。第一，與質變點的本質區分相符：有的質變點加的是能力，技法拆得掉；有的質變點換的是本質，拆不掉。第二，給敵人同一套工具。真仙牆在他成為真仙前誰都越不過，保留了天花板。

**盧修斯那場以 C 的收法最好。**劫把他拉下地，地上那一段真的贏了；他重回天上，劫追不上。作者要的「打鬥宗可以」在場上兌現，兩個質變點的差距也讓讀者親眼看到。對人物卡的改動最小，〈鬥場人物卡_首入〉第 33 行的勝負照舊，只改語義和那一句台詞。若作者要劫「整場勝」，A 的熔雷收法次佳，代價要寫足；B 甲的規則場勝最弱。

## 五、共同風險

1. **聖土「當代」錨點要重算。**〈鬥場人物卡_首入〉第 5 行寫的是「落潮後約二十二年」。三案的間隔分別是 6、13、12 年，總名冊與兩時點人物卡都要減齡或改境。賽拉斯首入約 190 歲，當代已故：A 只隔 6 年仍可成立，但要改成新近才死。盧修斯 22 年升到鬥宗九星的幅度要重排。建議先定終局，再一次性重錨，不要逐卡修。
2. **台詞與敘述裡的年數**：文奕「九界這六十年」、厄「走了七十八年」、赤翎「推了我幾十年」、大羅巡界「追了六十年」、聖土「二十二年來第一個」、俞清漪「回瀾宮主、南荒巨擘」（三案都在 30–40 歲前後，偏快）。〈同齡雙驕〉第 3 行作者原話是「數十年後的變化」，十二到十三年勉強夠，六年不夠。
3. **第 17–19 篇空位**：三案容量都只有約一年到一年半，出口都須是斬我，並且要給出去聖土的理由。若作者日後要補一個大故事，這裡放不下。C 說空位可以為零，這彈性可留，但要先告訴作者這個容量上限。
4. **五雷解鎖會回溯到十五歲。**三案都寫「五雷起可越」，但五雷是十五歲取得，第 4–7 篇的戰鬥是在「不可越」的規則下寫的。〈九雷人生節點〉第 117 行早就警告「否則少年期就能越階，壓掉第 3–14 篇的節奏」。須明定為「自首入聖土起第一次寫」，或回頭核查大比前各戰。
5. **同代與世界尺度**：宗門正常尊者在 60–150 歲（〈境界與能力尺度〉第 50 行）。終局時同代封寒、生要到斬我或遁一，全員都是極端離群值。三案只有 B 給了同代落點，須補理由，說明為何整代都快。
6. **篇號與時鐘的掛法**：兩個時鐘、三鉤、「天譴一篇最多升一階」（〈戰鬥共同語法〉第四節）都以舊篇號寫成。合篇之後要改成依冒險段計，否則 B 那樣一段內連升數階，就會和這條規則互相打架。

## 六、可借用的單一元素

**從 B 借「第二次聖土拆成兩場」，放進 C。**C 段七改成兩場：第一場是火蓮、見劫、雙匣人；第二場是屋頂之帳、九霄、父亡。合計約兩年半到三年，終局約 36–37 歲，帝壽時鐘順延一年。

這樣能直接解決 C 最擠的一段，也給重逢與父親壽終留出喘息。不建議再借 A 的吞劫引擎或 B 的引齡制，兩者都會破壞 C「不加引擎」的誠實。

A 的試寫場景（不吞之劫、火蓮接雷、「先吵完」）與年齡無關，可留作日後擴寫的場景素材，不算結構借用。

## 七、需作者先拍板（按重要性排序）

1. **終局年齡與跨度**：約 30、約 35–37 或約 41。界潮大週期、「當代」錨點和全部年齡隨它連動，界潮週期只是它的推論，不另外問。
2. **越境律取代 D087／D088**：是否採「門與牆」；解鎖點是五雷還是首入聖土起；「只有陸沉」是否放寬到主角級同代越一道門；盧修斯一戰的收法。
3. **天神以上的「不早於荒」是否撤用**：請 PM 先交出原作比對數字再決定。若要保留，三案都得往後推。
4. **聖土至尊的地點**：留在聖土要靠通階捷徑（A 的配額或 B 的引齡），移回上無極則要改第 20 篇補句「境界也要到至尊」與九霄的取得境界（C）。

次要、可由 PM 先提案再請作者過目：父親壽終年齡與耗損理由；裴照川刑期；救生豁免檔的年齡字樣能否改。
