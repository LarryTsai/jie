# 競稿：全書年表壓縮與五雷越境尺度

2026-10-08，作者決定壓縮年表：每次大冒險約一到兩年，整體是少年天驕快速成長；並說「劫有五雷，本來就能越境打，打鬥宗可以」。本輪依[競爭創作規約](../../../設定/00_故事定位/AI團隊競爭創作規約.md)由三位寫手獨立競稿，未參與寫作的 Reviewer 比較。所有稿件都是工作候選，**作者尚未拍板，未改任何現行文件**。

- [任務單](任務單.md)
- [方案A](方案A.md)：終局約 30 歲，以歸墟吞劫作成長引擎，越境有冷卻
- [方案B](方案B.md)：終局約 41 歲，一個界潮大週期；快到 35 歲道基碎裂；級差越境
- [方案C](方案C.md)：終局約 35.5 歲，三座時鐘（太宸餘壽、界潮密集期、追殺）倒推；門與牆越境

## Reviewer 結論與主 Agent 判斷

Reviewer 推薦 **C ＞ B ＞ A**，以 C 為底，借 B 把第二次聖土拆成兩場，終局約 36–37 歲（仍在 C 的太宸餘壽時鐘內）。主 Agent 同意這個方向。

- **C 勝在沒有新增成長引擎**：快來自外部時鐘。A 的吞劫引擎接近萬能機制；B 的引齡制推翻了「殞星只給通階門檻，不省時間」卻未列入需作者決定。
- **C 的門與牆最貼近作者原話，又留下天花板與敵人反制。**
- **A 太擠、B 太晚**：A 違反「二十四歲停籍不前移」並移動歸墟年齡；B 三十歲後已不像少年。

勘誤：Reviewer 報告把「五雷」寫成十五歲取得；實際十五歲是三雷，五雷在十七至十八歲。它提出的共同風險（越境解鎖會回溯影響大比前各戰）仍成立，只是起點是大比與首入聖土。

## 作者已決定

1. **終局約 35–37 歲**（2026-10-08）：以方案 C 為底，借方案 B 把第二次聖土拆成兩場冒險。
2. **撤除「每一境不早於荒」**（2026-10-08）：作者說「不用考慮荒，不存在」。境界進度不再以荒作比對基準，全書各處此條於年表同步時一併刪除。
3. **越境律採「門與牆」，從九界大比起算**（2026-10-08）：尊者、天神、虛道是門，至尊、真仙是牆；劫自九界大比起一場能拆一道門，九身合爐後兩道；只有劫能越兩道門，封寒、文奕、異火少年在苛刻條件下可越一道；敵人也會拆門。取代 D087／D088「首次越質變點不早於第 15 篇」。盧修斯一戰照方案 C 收：地上那段劫贏，按時限判盧修斯勝。
