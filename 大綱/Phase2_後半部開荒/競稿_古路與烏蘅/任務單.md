# 競稿任務單：古路與烏蘅

2026-10-09，主 Agent 依[AI 團隊競爭創作規約](../../../設定/00_故事定位/AI團隊競爭創作規約.md)開立。三位寫手收到同一份任務單，第一輪互不讀稿；完成後由未參與的 Reviewer 比較。

## 一、作者核心構想（必須服務）

1. 八萬年前的古戰要從「歷史設定」變成讀者想追下去的**傳奇故事**，而古界路本身是故事核心。
2. 陸沉在三十二天與聖土兩端各自闖過壯觀的古老秘境／取得古印或雷，**兩端的遺留開始呼應，古路某一段重新產生感應或局部接通**，起初兩界強者都不知道發生了什麼。
3. **三層揭露**：第一層是兩個各自精彩的修仙冒險（讀者不知相連）；第二層是古路與烏蘅之死有關，且有人刻意抹去一段歷史；第三層是「當年的選擇」重新發生，陸沉可能面對與她相似的選擇。
4. **烏蘅要成為有血有肉的主角級歷史人物**：有修為、強大術法、驕傲、朋友、敵人、不願承認的錯誤。**祁承晏**（仙帝長子）也不只是悲傷戀人：兩人是兩個文明最頂尖的年輕強者，有合作、有衝突、各自想守的東西。
5. **不准把全部責任推給一名幕後陷害者**。陷害可以引爆危機，太宸、仙庭、王庭、聖土各方的選擇仍有獨立責任。聯姻悲劇最多是點燃既有矛盾的導火線。
6. 作者偏好的參考畫面（可用可改）：陸沉取得一道古印後，體內另一道沉寂多年的印記亮起，兩組禁紋「原本就應該連在一起」；他改動一處，遠在聖土一座古遺跡裡八萬年沒響過的古鐘響了，守廟老人抬頭，不知為什麼；陸沉眼前出現一條通往聖土的線。另一個主題：**禁制八萬年沒有壞，一直照設計運作，只是後人不懂它在阻止什麼**；陸沉能破解，卻不確定該不該破解。

## 二、三位寫手的前提（各寫一種，不得換）

| 寫手 | 前提 | 作者給的種子 |
|---|---|---|
| **甲** | **烏蘅已死，但她留下的封禁仍在戰鬥**；可借「當年陷害者／被封之物仍活著」的危險感 | 她把敵人一部分力量與關鍵證據封進古路；兩界秘境的怪試煉其實是她的封禁程序；陸沉接通古路也讓被封的東西甦醒；高潮見她八萬年前留下的最後一式，不是要人報仇，而是完成她沒完成的事 |
| **乙** | **烏蘅肉身已死，但她的一段歲月還活著** | 古路深處保留一段尚未走完的時空；陸沉走進去，能見到當年的她、交談、並肩迎敵；不是復活、不是可帶走的殘魂；高潮：他明知她會死，卻要在她還活著的那段時間親眼看她做最後的選擇 |
| **丙** | **烏蘅仍以某種形式活著，已成為封印的一部分** | 她當年沒有真正死去，以自身承載古路封禁，八萬年失去肉身、時間與自由，逐漸與古路融為一體；她不是等人救的公主；陸沉接通後她有機會離開，但她一離開封禁可能崩；高潮：救一個人與守兩個世界可能無法同時完成 |

**作者明令**：不准一開始拿 D055（烏蘅殘魂只問一次、早散）或其他既有定案當理由否決自己的前提。先把故事寫到最高，再在方案末尾**如實列出**要改哪些既有定案與代價。

## 三、每份方案必交

1. **一句話總綱**與**為什麼讀者會期待陸沉再次進入古路**。
2. **完整弧**（規約第二節）：人物當下想要什麼、何事迫使出發、進入後怎樣受阻、對手如何**主動**反制、局勢與關係如何轉折、高潮的選擇與代價、留下什麼實得與後果。要排進現行篇位（見第五節），說明第二次、第三次聖土各自「非去不可」的理由。
3. **八萬年前的真相**：烏蘅與祁承晏各自想要什麼、兩人的合作與衝突、她的錯誤、陷害如何發生、太宸／王庭／聖土各方獨立的責任。不改「太宸封界是在選、第 28 篇認罪『是我』」。
4. **三場試寫**（每場可讀的場景散文，不是功能標籤，各約 800–1500 字）：
   - 場一：八萬年前古路上的悲劇（烏蘅在場、活著、做選擇）；
   - 場二：陸沉第一次觸動雙界秘境／雙印呼應；
   - 場三：陸沉最後進入封印核心。
5. **中段牽引**：至少列出三個中段事件，各說讀者此刻期待什麼、人物在追什麼、局面怎樣改變。
6. **Canon 影響表**：要改的既有定案（含 D055、第 26 篇長子遺念、第 27 篇魂晶封段與鑑月辨名、第 20 篇九霄殘影等）、改動範圍、代價；以及保留不動的。

## 六、上一輪構想為何不夠

現行公主案靠石柱、遺念、封段、刻錄等**物證與記錄**揭開，烏蘅與祁承晏多半只在證據裡出現，讀者沒有親眼看他們活著、強大、犯錯、選擇；古界路是背景與通道，不是讓人想進去的冒險場。

## 七、寫作規則

- 修仙不是武俠：丹、法器、神識、法力詞；不用內力、輕功。
- 重要事件在場景裡發生，不用旁白摘要、回顧、蒙太奇帶過。
- 角色是當下的人：強大分次在需要時露，特色不經意出現。
- 不新增萬能規則解困，不提前後期招法，不把局部路變成全界自由交通。
