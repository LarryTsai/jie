# 第二輪任務單：乙案《閘裡還有七日》重構

2026-10-09，作者定：採乙為主幹，融合甲的「三方歷史抹除」與丙的「閘鐘響，不許答」。**不升格 Canon，不直接重寫第 15、26、27、28 篇**；本輪只產出重構後的工作方案。

## 作者六條要求

1. **烏蘅維持八萬年前真正死亡**；遇害地點與遺體處理須與 D055 核對（現行：[主線推理骨架](../../../設定/05_故事主線與揭露/主線推理骨架.md) L72「公主死在仙界外圍，遺體運回聖土驗看後火化」；並查[靈魂術與證據](../../../設定/01_世界格局/聖土/靈魂術與證據.md)烏蘅之魂一節）。
2. **七日封存時光要有嚴格自洽的因果規則**：陸沉能與當年人物互動，但不能任意改變已發生的歷史，也不能成為免費加速修煉的秘境。
3. **三方抹除**（仙庭、外圍王庭、烏爾溫家；可依故事調整三方）各有動機、能力與責任；不能把太宸的責任轉嫁給新的陰謀家（第 22 篇封口錯開、太宸在選；第 28 篇「是我」不動）。
4. **保留雙界秘境各自完整的試煉、天驕競爭、傳承與機緣**，不能只剩找兩枚鑰匙。
5. **第二次聖土要有強烈的主動進入理由；第三次聖土要有獨立且不可替代的冒險與歷史高潮。**
6. **古路重新接通後不能讓兩界高境修士自由通行**，須與雙界封禁及既有界路／低路承載規則相容（作者原文此條末尾截斷，主 Agent 依上下文補讀為「既有界潮、低路承載與三條路規則」）。

## Reviewer 第一輪指出、須一併修正

- 場三陸沉走出陰門在八萬年前河階扎破藏曜＝當代人改過去；記門直接映出一張臉，違反〈靈魂術與證據〉L184「名字不由任何一件載體自己報出」。
- 候潮室若不限定即成加速修煉房（違反時間流速 v1）。
- 時間倍率數字自相矛盾（「約 50 倍」對「閘內一日＝外面半個時辰」；阿勒隆守門時長）。
- 與第八雷流光（時間系候選）須事先分界。
- 遇害地點移到溫德港河階，與 L72 衝突（見第 1 條）。
- 其餘見 [Reviewer 比較紀錄](Reviewer比較紀錄.md) 第六節「採用前必修六項」與乙案各節意見。
