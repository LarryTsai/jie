# 卷十二　五域前夜

狀態：004 整合，2026-10-04；大比前最後一個月，中央主要比試與交流區。

各域天驕匯聚，中央仍只是比賽交流核心，不能代表整個中神州。讓酒樓、切磋、論法、私下挑戰與各域差異成為人物生活；只選有因果的活動，不全部照排。俞清漪等人先有目的、朋友、對手與自己的判斷，正式比賽才有重量。

自由期分流的人再相見，有些故事陸沉不知道。禁典只開始消化，二雷三身已成熟；不能用第三雷或魂錨預演。雲行同框與文奕家學支線依實際因果安排，不把相識等於立刻同行。收在大比開幕前。

## 005 深化：未開戰，已經在比

前夜獨立成卷。傳聞、宗門名、共天留字與百宗後的「劫」第一次對上真人；有人真人與名聲差得很遠，有人始終不公開共天身份。東溟受到禁學、規模與修法的刻板評價，部分差距確實存在，但不能推導整域無人值得看。東溟內部仍互相競爭；最討厭陸沉的人也可先站出來，因為受輕視的是自己的出身，不代表與太玄和解。

雲行在本卷正式出場：先喝酒、好相處、有趣，一出手才見實力；不以大道哲學自我介紹，也不與文奕、禁典同時搶首次出場焦點。初遇具體場景待章綱，正式比賽有相識前史。

大型賭石／古礦盛會作本輪設計採用的核心活動之一，不吃掉全卷。不同人用結構、古禁、血脈、殘念、聽石或觀氣讀同一塊石；陸沉神識有邊界，會判錯，資源損耗真實。劫文較量從有無、性質到怎麼開；陸沉能開啟，文奕保住原物，合做比硬判輸贏更有用。未知危險先辨徵兆，不能以輸不起為理由無限加註。

丹、破禁、道場、酒量與拒絕挑戰構成私下評價，正式排名仍未開始。具體賭石與掉馬角色只選少數，四人假名暫不命名。收卷可採抽籤遇熟人，正式對戰須承接本卷喝酒、交手、欣賞與不快的前史。

006 修訂：中央集合區只作前夜、確認名單與登天域集結，不在中神州正式開五域大比。卷末昇天域，正式賽下一卷。

## D106 現行場面與出口

共天留字與自選名延續聚會、酒、賭石及同代相處。封寒想用此問切法來源，文提醒自選名與第一記錄不驗真人，不能把一句回覆當認人證據；有用回覆可留下技藝疑問，不作即時跨界情報網。江唐沒有因主角留言便出場。

雲行的討喜與真本領在眼前的飲酒、交手、願不願承諾一件小事中建立，不能一見面就預告唐的魔面。前夜結束依名單登天域，禁都地方比試與天域正式賽兩者不混。
