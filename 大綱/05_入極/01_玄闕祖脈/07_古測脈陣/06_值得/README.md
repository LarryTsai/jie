本段：天亮，雲行先把封寒推到婆婆面前：「你自己跟她說。」說完才遞鋤頭：「值得？」「值得。」「那走。」封寒一鐧一個點敲碎琉璃殼；文奕還那二十息，布下四道「雷火離土三寸」；午飯凳子還是三張。午後文奕寫信「我叫的，它留的，你付的」，宋知微在舊冊添「陸沉沒抄錯。已看。」，封寒依正路回返。
