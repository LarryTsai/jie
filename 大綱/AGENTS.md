# 大綱區工作規則

先讀根 [AGENTS](../AGENTS.md)與 [ROADMAP](../ROADMAP.md)。本檔只補大綱責任，正文凍結及作者豁免照根規則。

構思與重構讀 [AI團隊](../AI團隊/README.md)及共用準則，按派工讀角色。交完整故事：主動欲望、強敵反制、修仙機緣、中段選擇、具體高潮、實得與後續；不能把設定報告當大綱。重要配角有主角缺席時的人生，跨篇回收推動新事件。

正式區一個故事一個現行來源；競稿、任務單、審查及標非正文的檢驗樣稿放討論區。主 Agent 可依獨立比較整理唯一工作選定，不冒稱作者選定；重大 Canon 變更仍列候選。新大綱、選定、撤用或裁定同次同步全書總覽，沿用根規則五種狀態與批准範圍。
