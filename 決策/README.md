# 決策

作者裁定紀錄（D 號）與待作者決定的清單。只記作者裁定與待決題；提案原稿、競稿與審查留在討論區（待整理/）。

## 讀法

1. 先看本檔「最新覆蓋」：最新作者指示優先，舊條目只供脈絡。
2. 查 D 號從[決策紀錄索引](01_決策紀錄/README.md)開單條；最新條目在索引最後。
3. 待作者拍板的題目在 [02_待決](02_待決/README.md)。

## 結構

| 資料夾 | 放什麼 |
|---|---|
| [01_決策紀錄](01_決策紀錄/README.md) | D 號條目，一條一檔，檔名如「D128_全書年表壓縮與門與牆越境.md」（D 號即序號，是命名規則的例外）；同批裁定用區段號如「D014-D019_…」 |
| [02_待決](02_待決/README.md) | 待作者決定的題目清單 |

## 寫入規則

- 只由主 Agent 依作者裁定寫入；寫手、Reviewer 不直接改。
- 每條寫明：D 號、日期、範圍（影響哪些設定或大綱檔）、出處（作者原話或對話日期、方案檔連結）。
- D 號連號遞增；作者裁定才給號。未編號的作者裁定由主 Agent 補號後寫入。
- 過時條目不刪：加註「已由 Dxxx 修改」與修改範圍。
- 新條目建新檔並加進[索引](01_決策紀錄/README.md)；寫明取代哪個候選方案。尚未回答的問題留在待決；提議和範例不自動成為故事事實。
- 作者裁定後同一次提交：寫決策條、改設定或大綱對應檔、同步全書故事順序總覽。
