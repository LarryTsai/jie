# D047C：C 組作者選定與連動深度

作者逐題選定（2026-09-29）。Q24 連動深度選乙：體系加鬥破式世界味，地名、勢力、人物全部自創西式，原作人物不出場；聖土重建另由聖土寫手 session 進行。C1 舊版人物關係優先保留。C2 母稿斷階坊市、浮石採藥、紙鳶攤轉正，家鄉島名**留舟島**，勢力與生活依修仙者視角重做（作者強調「這是仙人世界，不要凡人視野」）。C3 親友餵養盲點。C4 開篇從斷階坊市、符紙靈鳶起，章末接地裂。C5 閣老為**林伯潮**，退任閣主。C6 封寒師父為嚴守劍理、曾誤傷同門的中年劍修。C7 第一具星羅分身在離閣引殘雷時才凝成。C8 第三至第九雷與上界年表重開：中途可能去聖土，一兩道雷可能取自聖土（Q25）。C9 基本招固定、逐步擴充。C10 第十雷由兩界交會而生，須避開異火的影子。見[待定問題](../02_待決/待定問題.md)與各專檔。
