# D135：界潮奇觀縫雷與走潮者（2026-10-08，作者裁定；2026-10-09 補號）

本條原未編號，2026-10-09 依作者裁定紀錄補號。

作者定向「當新創意做，避開三個衝突點」。封合縫界潮改採縫雷與走潮者。避開蒼梧、無間航道界樁、封合縫既有劫雲三處衝突。只升級景觀與體驗，不改低路承載、窗口週期與通行規則。

1. **同源**：走潮者與劫厄是同一場古劫最後一道，被封口截成的兩截，各自凝成一條命。作者原提「厄萬年前的本體」，因撞厄的出身改採此案。厄的出身與三次自己的意願不改。
2. **終點**：第 28 篇尾聲，厄自己選擇去守伏雷坳，兩截在伏雷坳合一，斷口合上，成為渡口守路者。此後仍叫厄，住伏雷坳，不再隨陸沉遠行。作者否決「煉成神兵」（撞 D072 同行者不是法寶）。
3. **正式名稱**：斯特蘭（Strand），寫在雷望衛潮簿的邊頁。
4. **第 27 篇（甲）**：厄不同行，比照鑑月過不了低路，留在伏雷坳。過縫時陸沉第一次看清走潮者全身，牠朝九界那一端回頭，目光越過他，落在伏雷坳。第 28 篇回收。
5. **第 28 篇（採一）**：掉出伏雷坳的少年是封合縫縫民的孩子，踩著走潮者的蹄印跟來。正文不說明，只寫雷灰、邊地口音與他回頭指身後淡去的蹄印。

全書沒有人說出兩截同源。
