# D167：分段章號從 01 起編，不再全卷累加

2026-10-29｜作者在對話中提出方向：「我其實希望每個都是001開始～所以大綱其實不該累加～這樣很難調整局部章節」，並指示「可以先把大綱都先改掉」。

## 背景

卷一《浮石之下》分六段，章綱原本用全卷累加章號（第 1–78 章）。只要局部增章、併章，就得出現 61A、71A、72A 或「39（併入第 40 章）」這類補丁，後面所有章綱、伏筆台帳、時序表與人物表裡的章號也要跟著改。[D166](D166_正文可增章.md) 開放增章後，這個問題會反覆出現。正文檔名早已是段內 001 起編。

## 方向

1. **章的唯一識別碼是「段號-章號」**，例如 `03-05` 是第 03 段〈春潮差事與嶺火〉第 5 章。章綱、伏筆台帳、人物表、時序表、跨卷承接一律寫段內識別碼，寫法如「第 03-05 章」；同段範圍寫「第 03-01–06 章」。
2. **段內插章、併章、拆章只重排該段**的章號，不動別段；不再使用 A 號，也不保留「併入」空號。
3. **全卷連續章號不手寫在章綱裡**，只放在卷一資料夾導覽的對照表，供作者通讀與日後發布使用；段內有增減時同步重算該表。
4. 不分段的卷（單一章綱檔）照舊用卷內章號，本條不要求改寫。
5. 歷史紀錄（附錄版本史、討論紀錄、歸檔、待整理的舊稿）保留當時章號，不回改。

## 效力邊界

- 只改編號體例，不改任何章綱事件、年齡、境界、伏筆與作者選定狀態。
- 正文同步跟進（2026-10-29 作者指示「一起改正文」）：正文檔名維持段內 001 起編；章標題寫「第 02-13 章　多導一次」，檔頭的章綱來源、前章連結與正文 README 一律用段內識別碼。全卷連續章號只在卷一資料夾導覽查。
