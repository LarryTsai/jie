# D063：聖土勢力改名與對等擴建（2026-09-30）

來源：[聖土勢力總表](../../設定/01_世界/05_聖土/04_人物/00_勢力總表.md)第〇節與第十節。

### 一、命名體例（作者指示）

- 聖土勢力一律改為**音譯專名＋西式機構詞**，例如維拉丁劍廷、伊爾瓦魂院、卡洛陣會、契約廳；首長與附屬用語跟著機構走。完整舊名→新名對照表見勢力總表開頭「〇、命名體例」，此處不複製。
- 「宗門」只作修士勢力的泛稱；聖土的「宗門序」改稱**門序**。三十二天仍用「宗門序」，中式宗名不改。

### 二、諸洲（作者照用）

聖土不再壓成一片大陸，而是諸洲並列：**柯涅斯**（外洲人稱「縫洲」）、**尼倫斯**、**努瓦羅**、**茵布瑞**、**廷德拉**，另有**踏石群島**與**無主海**。封合縫在柯涅斯西緣。柯涅斯一盆之內的名單、排名、戰力與分檔照舊，它只是諸洲之一。見[當代地理：諸洲](../../設定/01_世界/05_聖土/02_當代/當代地理_諸洲.md)。

### 三、對等數字：乙案

作者採勢力總表第十節（七）的**乙案「形狀不同、總量相當」**，落實 D061：

| 層 | 全聖土 |
|---|---|
| 觸帝者 | 4 |
| 鬥聖後期 | 12 |
| 鬥聖中期 | 約 80 |
| 鬥聖初期 | 約 550 |
| 半聖 | 約 6,000 |
| 九階獸王 | 約 40 |
| 頂級勢力 | 24 |
| 一流勢力 | 60 |
| 二流勢力 | 約 320 |
| 三流勢力 | 約 1,800 |

**理由**：聖土「活得短、修得快」，每一代成聖的人數與三十二天相近，卻存不下來，所以長壽的上段人少、短壽的中段人多；帝路封住（D052），到頂的人只能停在帝前，塔尖因此堆積（觸帝者加後期 16 對準仙帝約 10）。乙案以壽元方向成立為前提，所以**聖土壽元方向「借力者壽短、同格壽元短於仙」轉為定案**；逐境壽元數字仍待設計。

> **作者補記（2026-10-02）**：聖土人的一生金字塔照九界比例（一百個孩子的停境分布與九界相同）。「修得快」讀成時間上的快：同一境，聖土人走得早、老得也早；不是機率上更容易到高境。另，聖土瞬時短碼定為「龕線」（同魂晶切兩片、照境以上按印成對，公祠成網、按碼收香火錢，印按一次淡一分），不過海；「地階功法傳承名額」仍有限（與入門名額不限人數是兩回事）。

對照表見勢力總表第十節「與三十二天的對等表」；甲案（一比一）、丙案（只放大一個量級）不採。

### 四、合併範圍

- 待定問題 Q17 殘項「聖土壽元表」改為方向已定、數字待設計。
- 本條未動聖土目錄、諸神聖土與聖土重建交接；勢力總表第十節「狀態：專家提案」「依賴壽元表候選」等字樣、諸神聖土待定項「聖土壽元表（候選）」應隨本條更新，已列清單轉聖土寫手。
