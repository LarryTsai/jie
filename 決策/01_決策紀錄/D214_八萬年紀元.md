# D214：八萬年分紀元

2026-11-27–28｜作者在對話中分四步裁定：第一題「不加」；第二題「要，用斷年」；第三題「要，只裂不低」；第四題「要」。

## 起因

主編對照《仙逆》《遮天》《武煉巔峰》提出四刀改法，第一刀天地大謎已定（[D213](D213_天地大謎採丙與墊天讀法.md)）。這是第二刀：八萬年歷史是扁的，只有戰前、古戰、當代三段，中間沒有時代、沒有傳說人物，遺跡分不出層。

流程：三寫手競稿（下面的人、上面的權力、天地漲落）→ 獨立比較 → 故事總架構師融合 → 覆核條件通過、十二項必改落稿。全在[八萬年紀元討論區](../../待整理/八萬年紀元_20261127/README.md)。

## 作者裁定

1. **太宸的沉默不加「護子」動機**。他在祁承朔死前就已知情，照烙「重」；正文與作者層都不寫他心裡想什麼，罪照 D088、D213。
2. **斷年成為九界共同歷史**：約兩萬一千年前有一年共天沒開。轉角只立一人「一折」（甲的時折併入）；斷年與丹丘第一爐養壽丹同年。
3. **拉天夜與「帝在，王不相伐於帝前」舊約一起入 Canon，只裂不低**：越裳先王謝挽潮帶六庭拉天，六片天各裂一夜，九界高度不變；托高只由帝座承重決定。
4. **沉鳴成為九界共同記憶**：封界後九片天又落了一萬多年，地底整夜長鳴，這期間共天一次都沒接通。

- 紀元名只由人物在事件中說出，不列表、不講課；作者層工作詞照 D088、D213 不入正文。
- 卷一到卷十正文、卷十一到十四釘板章綱一字不改，只重讀。
- 第六弧「河倒回第一塊退碑」未採。
- 杜若、郗未央是真仙，卻跨了數萬年，超出 D042 壽元。這是既有張力，交人物負責人。
