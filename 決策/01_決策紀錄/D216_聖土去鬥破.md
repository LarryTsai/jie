# D216：聖土去鬥破皮，改以「形」為骨

2026-11-28｜作者在對話中依序裁定六題：
1. 「撤，保住目的」；
2. 「丙的形」；
3. 「入，限三件門形」；
4. 「照舊保留」；
5. 「改名」；
6. 知會三十二天《完美世界》境界名，本次不動。

隨後作者確認其他 session 已暫停、第 27 篇改字清單已過目，說「可以，開始替換」。

## 起因

主編四刀改法的最後一刀；前三刀見 [D213](D213_天地大謎採丙與墊天讀法.md)、[D214](D214_八萬年紀元.md)、[D215](D215_天律四條.md)。

聖土整套用《鬥破蒼穹》體系，三十二天用《完美世界》境界名，讀者容易讀成同人跨界，本書自己的概念因此被蓋住。

流程是三寫手競稿（換名不換骨、魂龕為骨、向外成形重長）、獨立比較，再由主編以腳本替換並做人工處理。全部在[聖土去鬥破討論區](../../待整理/聖土去鬥破_20261128/README.md)。

## 作者裁定

1. **撤 [D045](D045_諸神聖土改用鬥破體系重做.md)、[D047](D047_聖土修行全面走鬥破.md)「直接套用鬥破原名、修行整套走鬥破」，保住它們的目的**：
   - 打鬥好設計、不突兀、強弱一眼看得出，由「形」承擔；
   - 兩界的連動感，由「向內拆／向外長」「火對雷」「根對極」承擔。
   - D047C Q24 乙「地名、勢力、人物全部自創西式」照舊。
2. **骨架用「形」**：境界就是身上長出了什麼。

   | 現行 | 原名 | 對齊三十二天（不變） |
   |---|---|---|
   | 白身 | 鬥之氣 | 搬血 |
   | 點塘 | 鬥者 | 洞天 |
   | 披紗 | 鬥師 | 化靈 |
   | 著甲 | 大鬥師 | 銘紋 |
   | 留形 | 鬥靈 | 列陣 |
   | 展翼 | 鬥王 | 尊者 |
   | 實翼 | 鬥皇 | 神火至真一 |

   | 起穹 | 鬥尊 | 虛道至遁一 |

   - 小階看「分」，巔峰叫「長滿」；白身用段；落根另分初根、中根、深根、根滿。
   - 其他名詞：
     - 鬥氣改身火，氣旋改火塘，鬥技改戰技；
     - 煉藥師改丹匠，品級照用「品」；
     - 魔獸、魔核改核獸、獸核；
     - 納戒改廓匣；
     - 異火依文意分野火或契火；異火榜正名用燧冊，口語叫火冊。
   - 量階石、丹雷保留。
3. **本料入正式區，只限翼、廓、穹三件門形**：一形一料，終身不換。人物不回填，出場時再定。
4. **功法與戰技的天地玄黃四階照舊**（D178 第 4 條）。
5. **靈魂境界改名**：靈境、天境、帝境改為明境、穹境、覆境。蟄境、照境不動，格位不動。
6. **知會**：三十二天的《完美世界》境界名，本次不動，日後另議。
