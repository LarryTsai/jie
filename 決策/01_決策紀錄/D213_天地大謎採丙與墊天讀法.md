# D213：天地大謎採丙「天自己的劫」，墊天作者層讀法改定

2026-11-27｜作者在對話中分三步裁定：第一題「要，採丙」；第二題「照這句定」；第三題「照這個開」。

## 起因

作者請主編拿《仙逆》《遮天》《武煉巔峰》對照兩界設定。主編的診斷是：歷史有人味，天地太小，最大的謎只是一樁兇案，天地級的問題全部留白。作者選擇先做天地大謎。三寫手競稿、獨立比較、整合與覆核都在[天地大謎討論區](../../待整理/天地大謎_20261127/README.md)。

## 作者裁定

1. **天劫的起源在作者層有答案，採丙**（現行稿：[丙_整合](../../待整理/天地大謎_20261127/丙_整合.md) v2）。
   - 三十二天還沒長完。天外的料（作者層工作詞「天胚」）一直從邊上落進來，被活成天地；落在修行開縫的人身上，與守著自己形狀的天地相磨，就是劫。所以劫仍是天地在「擋」，仍跟著逆行者走。
   - 意志定為沒有。
   - 聖土無劫，仍只用「鬥氣順取、不拆自己、身上無縫」解釋，聖土不是缺陷天地（D039）。
   - 放行第十雷用語、[帝重與帝路](../../大綱/06_仙途/00_帝重與帝路.md) #26、[世界建構方向](../../設定/00_故事定位/世界建構方向.md)三處對天劫起源的留白。舊遠弧丙被擋的理由「現在不該解」不再成立。
2. **墊天的作者層讀法**（補 D088，不取代）：

   > 撤護持撕開了天正朝聖土長去的那一圈，天胚從破口落進來；破口沒人擋，就越撕越大，有人站上去，它就一份一份落、一份一份長成天，帝座歷代就是這樣擋的，以前人撕開的口子也守回來過。太宸不肯讓那一圈再開著：他認定聖土殺了他的兒子，要的是最快把門關上，於是把九片天整片壓進破口，削掉自己半壽也要封，往後又以帝座承了八萬年。他選的不是較輕的路，是只顧關門的路；代價交給了九片天，還有往後八萬年。

   - D088 照舊：有替代方案而他在選；封界時不知合謀；罪不減，反而更重。
   - 他「認定聖土殺子」正是祁承朔嫁禍要人相信的事。人的罪由人負，天胚沒有意志，不替任何人做選擇。

3. **開第六弧〈天自己的劫〉**，照整合稿主軸：邊極改坡、陸沉認下自己那一份；祁鈞坐空帝座獨承；九界議三年逐人簽名；綦毋煙反用陣心，九界一夜萬劫；天又長、斷峰群外新岸。
   - 新增的永久代價只有伏雷坳火熄；渡失敗者死、陸沉燒萬年級壽元與本源、封寒失看潮之眼，照現行規則。
   - 兩項預設一併採用：寇平活著；邊極不寫成「從此關不上」。
   - 唯一大綱：[天自己的劫](../../大綱/06_仙途/14_天自己的劫/大綱.md)；全書總覽新增第 89A 列。

## 效力邊界

- 作者選定的是**核心真相、墊天讀法與第六弧主軸**。「天胚」「天缺」是作者層工作詞，正文不用；天律措辭、揭露階梯、各層場面仍是工作選定或候選。
- 尚待作者裁定（討論區 README 第 4、5 題）：作者選定遠弧的增補（立極萬簡庫「長」「守」、弧一到弧三各一處）；卷二十三加交流夜。這兩題答完前，不改這幾篇的事件內容。
- 立極「天有一缺」只是回聲，不與「天缺」畫等號。
- 正文已寫部分不改事件。
