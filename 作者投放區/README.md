# 作者投放區

作者把想法、草稿、方向放在這裡，給 AI 團隊取用。原名 `tmp/`，2026-10-09 改名。

- 作者自己的區域：AI 只讀取，不改、不搬、不刪、不整理這裡的檔案。
- AI 用到這裡的想法時，在對應的處理紀錄或競稿任務單註明「來源：作者投放區／檔名」，再把結果寫到討論區或正式區。
- 處理完的想法不從這裡刪除；要不要清理由作者決定。

2026-10-10 作者本輪明確指示「全部用 AI AGENTS 處理，處理完畢就歸檔」，授權四份現有材料處理後移至[原文歸檔](../待整理/歸檔/作者投放/20261010/README.md)，原文內容不改。[處理與驗收入口](../待整理/作者投放處理/20261010/README.md)記錄每份結果。這次授權不改變其他投放只讀的預設。
