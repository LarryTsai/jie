# 一、兩卷共同定位

前六卷目前是：

1. 《浮石之下》——故鄉、第一雷、離島。
2. 《山門之上》——入宗、選峰、成為老七。
3. **《鎮岳老七》——真正住進修仙世界。**
4. **《兩儀雷淵》——第一次真正走出宗門，把第二雷帶回來。**
5. 《七峰爭鳴》——同代競爭、顧小滿事件、雷重域、十人選拔。
6. 《萬體無我》——命藏、戰葬、第三雷震魂。

因此卷三、卷四是一組：

> **卷三：住下來。**  
> **卷四：走出去。**

卷三讓讀者愛上太玄宗與這群少年；卷四讓陸沉、封寒第一次離開熟悉生活，真正走入宗門之外的修仙世界。

# 二、卷三《鎮岳老七》

## 2.1 現行骨架

〔現行〕

- 十二歲春後至十三歲春前後。
- 洞天，一雷兩身：本尊＋星羅。
- 卷首：剛成為鎮岳「老七」。
- 大故事：滕北斷脈 → 生提出續雷脈方案 → 共爐續脈 → 生三指受傷 → 滕北養後試雷仍刺痛。
- 卷末不是「治好了」，而是「接上之後還有人生要走」。

本卷問題：

> **找到地方以後，我怎麼在這裡活？**

## 2.2 創作總綱：低波幅，高累積

〔作者方向＋強建議〕

卷三不能是 filler，也不能只是快樂日常。

> **低波幅，高累積。**

表面沒有世界級危機、沒有新雷種，但人物關係、修行熟練度、宗門認知、感情、價值觀、未來因果全部持續前進。

| 線 | 卷首 | 卷末 |
|---|---|---|
| 陸沉 | 剛被叫老七 | 真正成為鎮岳的人，形成自己的修行節奏 |
| 劫×瘋 | 約練、覺得對方有趣 | 有事真的會找對方 |
| 劫×生 | 丹閣、看傷、三碼 | 開始懂彼此怎麼看世界 |
| 鎮岳 | 六師兄姊＋新人 | 讀者真正理解「這是一家人」 |
| 太玄宗 | 大宗門 | 完整修仙社會：工作、資源、人情、競爭、離開、失敗都有 |

修行也不能停：星羅要用熟、體修真正進入鎮岳體系、禁開始日常化、丹術能接任事。卷首陸沉應明顯打不過卷末陸沉，但不是靠新外掛。

# 三、卷三要補的修仙憧憬

〔作者方向〕

這卷應讓讀者覺得：

> **如果真的有修仙世界，我也想在太玄宗住幾年。**

## 3.1 〔強建議〕一次沒有大事故的宗門快樂篇

候選：七峰仙市、問道夜、換丹會、開爐日、法器夜市、七峰燈會、公開講法夜。

可以自然展開，但：

- 不死人；
- 不出陰謀；
- 不拿仙王傳承；
- 不突然變 Boss 戰；
- 不要求所有細節日後回收。

可用畫面：生逛藥攤逛到不見；封寒買沒人知道用途的東西；陸沉問法器能不能拆，店家立刻收走；顧小滿欠攤主東西；陸行烈到處有人認識；雲上煮酒；半空開爐；少年爬屋頂偷聽講法。

> 封寒：「你聽懂了嗎？」  
> 陸沉：「三成。」  
> 「我兩成。」  
> 「那你點什麼頭？」  
> 「旁邊的人都在點。」

〔紅線〕這一夜可以真的什麼大事都沒發生。價值就是：**他們曾經真的很快樂。**

# 四、宗門厚度：好的、壞的、普通的都要有

〔作者方向＋強建議〕

### 好的人情
- 沈山河順手替人收重。
- 秦照雪不認同陸沉的雷，仍會留下丹。
- 柳青藤會煮飯，但她也會累。
- 老七半夜沒回來，有人不問，門卻留著。

### 普通的人情
- 任務合作一次後不再深交。
- 借靈石真的會催。
- 爐位照排。
- 有些人根本不在意陸沉。

### 不好的關係
- 資歷壓人、看不起小閣出身、看不起鎮岳。
- 搶資源、搶任務、嫉妒、記仇。
- 昨天一起喝酒的人，今天也要同一個名額。

這些人不必變反派。

## 4.1 〔強建議〕有人離宗

一名普通弟子修了多年仍過不了關，決定回家。

> 「不再試一次？」  
> 「試過了。」

或：

> 「我想回家。」

陸沉當下不理解。與卷一祁望形成遠呼應：**不繼續修仙，不等於人生失敗。**

〔紅線〕此人不必日後成大人物，甚至可以永遠不再出場。

# 五、劫×生：第一次不是醫療的同行

〔強建議〕

安排一次小型雙人任務：去附近山谷採一味靈藥。

- 生要的是藥。
- 陸沉感興趣的是當地雷／禁／地勢。
- 不是約會。
- 不拿大機緣。
- 不需要陸沉救她。

核心效果：

1. 生第一次在自己的領域比陸沉更早讀懂環境。

> 陸沉：「那邊可以走。」  
> 生：「不行。」  
> 「為什麼？」  
> 「那邊的草全往另一側長。」

2. 第一次聊傷病以外的事：家、小時候、母親、煉丹、她為什麼學醫。
3. 讀者先產生「嗯？」；角色不必知道自己喜歡。

候選收尾：

> 生：「你拿那塊石頭做什麼？」  
> 陸沉：「不知道。」  
> 「那你還拿？」  
> 「所以才拿。」

〔現行＋強建議〕

現行已有約練、同一張欠條、夜探古雷脈、被護山大陣抓。

可再少量補：聽說山下面有東西 → 半夜去 → 挖錯牆／被活禁追 → 什麼寶都沒拿到 → 回來被罰。

目的：

> **以前兩個人亂跑很好笑。**  
> **卷四同樣往下走時，第一次真的可能回不來。**

# 七、青璃原則

〔作者方向〕

青璃暫時不強行補完整角色弧。

> **不是每個人都要同時間發生自己的大故事。**

她只需存在、修行、留下性格與判斷方式；真正屬於她的故事後續再自然長出。

---

# 八、卷三伏筆：埋根，不插旗

〔強建議〕

例如仙市有人賣殘禁：

> 「這裡少了一筆。」  
> 「少一筆才值錢。」

現在只是市場厚度；到了中神州禁都才自然回響。

每個小故事最好自然推進至少兩項：關係＋世界、修行＋性格、生活＋伏筆、感情＋價值觀。但不能排班式寫作。

> **所有功能都藏在「他們正在生活」。**

---

# 九、卷三收束：共爐續脈仍是重要大故事

〔現行〕

古雷脈異常加劇 → 重鑿提前 → 小回流 → 滕北斷脈 → 生提出先師方案 → 滕北自己同意 → 共爐 → 回衝 → 生喊「陸沉！照順序。」 → 三指受傷 → 脈接上但試雷仍痛。

這個結局的核心：

> **救回一個人，不等於把他恢復成原本那個人。**

因此卷三同時擁有：修仙憧憬、宗門生活、感情厚度、人情好壞、修行熟練，以及一個真正有代價的中大型高潮。

# 十、卷四《兩儀雷淵》總定位

## 10.1 現行骨架

〔現行〕

- 十三歲春夏。
- 洞天，一雷兩身進，二雷三身出。
- 共爐餘波 → 欠料／鎮鈴受阻 → 找礦。
- 出發時不知道第二雷在哪。
- 礦谷 → 吸斥異常 → 深入 → 判錯退路 → 封寒守外圍 → 陸沉獨自熔雷 → 第二雷兩儀。
- 受傷出谷 → 傳「需藥」 → 回宗受罰／養傷 → 凝成承身。
- 卷末第一次三身。

本卷問題：

> **我還想往下走，他還願意跟嗎？**

# 十一、卷四不是「拿第二雷」，而是第一次真正行路

〔作者方向＋強建議〕

更完整的定義：

> **兩個剛在宗門找到位置的少年，第一次真正走進宗門之外的修仙世界；一路遇見世界、遇見同代、遇見分岔，最後走到所有人都不再同行的地方，只剩彼此，然後從那裡帶回第二雷。**

任務既然必須出宗，出宗本身就應成為故事，而不是從山門直接切到礦谷。

# 十二、建立《劫》的「行路法」

〔作者方向〕

未來任何宗外任務都可由四條線疊加：

1. **任務線**：真正要做什麼。
2. **行路線**：宗門 → 城鎮 → 荒地 → 目的地。
3. **偶遇線**：同路人、天驕、散修、商隊、女天驕。
4. **世界線**：丹會、拍賣、禁盟、商會、地方勢力、修士生活。

最後才進正文主故事。

〔紅線〕每趟旅程不能固定「城鎮→拍賣→美女→打臉→遺跡」套餐。每次只取少數最適合的模組。

# 十三、卷四出宗途中可插的可生長模組

以下不是全部都要用。

## 13.1 丹會〔候選〕

- 劫瘋只是路過／補物資。
- 生可能因丹會有自己的事，不必同行到底。
- 可自然認識丹道天驕或女天驕。
- 後續百宗／中神州再見時，讀者已認識。

## 13.2 拍賣會〔候選〕

不是為了拍神器。可拍舊礦圖、殘器、雷晶、禁片、古礦工遺物。

陸沉可以第一次真的被坑錢，不需要立刻打臉掌櫃。

## 13.3 禁盟地方分會〔候選〕

- 陸沉帶著埋王嶺野路子去問。
- 第一次有人說：「你這根本不叫××。」
- 不在此完成正統禁學。
- 只替中神州「禁制師的世界」埋根。

## 13.4 修士酒樓／飛舟港／散修市〔候選〕

讓宗門外修士社會成立：護送、挖礦、賣消息、低境界但走過很多地方的人、喝醉御器被城衛攔的人。

## 13.5 天驕／女天驕同路〔候選〕

核心：

> **大家有自己的目的，只是這一段剛好同路。**

例如某女天驕護送丹材去同一座城，和劫瘋搭同一艘飛舟；途中一起遇事，到城門便分開：

> 「我往東。」  
> 「我們往北。」  
> 「百宗見。」

後面百宗再見，讀者自然產生「是她」。

〔紅線〕女性天驕不能全部成主角潛在感情線。有人跟生更熟、有人跟封寒更聊得來、有人根本對陸沉沒興趣。

# 十四、可生長節點：不是每個伏筆都必須回收

〔強建議〕

拍賣會有人買一塊殘器：

> 陸沉：「裡面有禁。」  
> 對方：「我知道。」

當下結束。

未來需要 → 長成 B 級支線；不需要 → 就只是一次相遇。

這能避免「只要作者寫了名字，讀者就知道一定很重要」。

# 十五、卷四主體節奏：熱鬧逐漸消失

〔強建議〕

### A. 宗門／準備
共爐餘波、欠料、鎮鈴受阻、找礦理由成立。

### B. 城鎮／行路
第一次真正看到宗門之外的修仙社會。熱鬧、好玩、有天驕、有交易、有真假。

### C. 外層礦區
仍有人：礦修、散修、舊礦道、雷晶、廢坑。

### D. 深入
人越來越少。訊息斷、神識縮短、地形開始不講道理。

### E. 兩儀雷淵
最後只剩陸沉與封寒。

> **前面越熱鬧，最後只剩兩個人時越有重量。**

# 十六、第二雷完整生命週期

〔作者方向＋強建議〕

卷四不能是「探索→Boss→拿第二雷→回宗→卷終」。

它應完整呈現：

> **發現 → 探索 → 取得 → 失控 → 試用 → 濫用 → 組合 → 日常化。**

## 16.1 發現

出發時不知道有第二雷。

先看到：劍受吸斥、礦灰不往下落、雷潮倒轉、碎礦懸空、進退方向反覆改變。

第二雷是兩人自己追出來的，不是任務提示。

## 16.2 探索

〔現行〕陸沉讀雷與退路；封寒在吸斥中修正劍路。兩人的能力真正互補。

〔強建議〕在此讓兩人第一次出現真正的判斷分歧，而不是誰想到瘋事另一人就答應。

候選：陸沉認為還能往下；封寒看完說：

> **「能走。但不值。」**

他不是怕，也不是 Yes Man；他同樣想知道答案，但會判斷代價。

是否最後仍往下可由章綱決定，重點是兩人可以理解彼此卻不同意。

## 16.3 取得

〔現行〕封寒守外圍、散修與九根釘；陸沉獨自熔兩儀。兩條現場互相牽動。

〔強建議〕兩儀不應靠單純硬壓「收服」。其吸／斥、承／卸、進／退本質，應讓陸沉第一次碰到「越硬抓越失衡」的力量。

第二雷取得應是卷內最大修行高潮，但不是故事結束。

## 16.4 失控與試用

拿到後不能自動滿熟練。

候選：
- 第一次吸太多，自己撞牆；
- 第二次斥太大，把封寒彈出去；
- 想拿來加速，結果停不下來；
- 想和星羅強併，兩種雷搶同一段運轉，必須拆開重來。

封寒從坑裡起來：

> 「再來。」

## 16.5 濫用

陸沉一定會開始問：

> **「這還能怎麼用？」**

因此兩儀要進入生活：

- 隔空吸杯子；
- 推門；
- 搬石；
- 偷懶拿東西；
- 搶飯；
- 搬器材。

而且要有玩壞的時候：門框一起飛、東西吸過頭、搬石反而更累。

沈山河可看一會：

> 「你這樣搬比較累。」  
> 「但不用走過去。」

## 16.6 星羅 × 兩儀：第一次建立「多雷組合」語言

這是第二雷真正的長線價值。

不是「第二雷又多十招」，而是：

> **第一雷 × 第二雷開始產生組合。**

例：星羅身從 A 點攻，承身在 B 點產生吸／斥，本尊瞬身；封寒的劍第一次被吸偏半寸，下一次他反過來利用吸力順勢切入。

這會讓讀者第一次明白：十雷真正可怕的不只是十種雷，而是雷與雷、雷身與位置、順序之間可以組合。

## 16.7 承身：不是「多一條命」

〔現行〕回宗閉關凝第二具分身「承身」，主兩儀、專修鑄身。

〔強建議〕三身初期節奏應該對不上：

- 本尊想往前；
- 星羅已經到了；
- 承身還在承力。

這迫使陸沉第一次真正把神速思考用在「同時管理多個自己」。

## 16.8 日常化

真正掌握力量的象徵，不一定是轟掉一座山，而是：

> **他已經自然到拿它過日子。**

卷四現行收在第一次三身；後續可在卷五、卷七繼續沿用、濫用、修正。

注意：現行雷潭與三身夜浴已排到卷七《東溟》，不要硬搬回卷四。卷四只需建立「新力量開始進入生活」的第一階段。

# 十七、卷四回程也要是故事

〔強建議〕

現行已有「需藥」、同一步幅出谷、韓鐵衣「我沒看見」、照規受罰，這些全部保留。

如果前段加入城鎮，回程可形成漂亮對照：

出去時兩個乾乾淨淨的少年；回來衣服破、傷一堆、東西少一半，但多了一道雷。

回城第一件事不必報告重大發現，可以只是：

> **吃飯。**

甚至碰到出發前坑過他們的商人：

> 「你們居然回來了？」  
> 「嗯。」  
> 陸沉：「你上次多收我三枚靈石。」

讓「冒險回來」有真正的人間感。

# 十八、卷三 → 卷四 → 卷五的情緒接力

## 卷三《鎮岳老七》

> **我住下來了。**

讀者愛上鎮岳、太玄宗、這群少年；共爐告訴讀者宗門生活也有真正代價。

## 卷四《兩儀雷淵》

> **我第一次真正走出去。**

先看見宗外修仙世界的熱鬧，再一路走到只有劫瘋兩人的深處；第二雷成為第一次真正行路留下的東西。

## 卷五《七峰爭鳴》

> **我帶著外面得到的東西回來，開始和整個同代碰撞。**

古雷脈重鑿 → 顧小滿事件 → 雷重域 → 三身共同化靈 → 七峰競爭與十人選拔。

這樣三卷不是三個副本，而是：

> **家 → 路 → 人群。**

# 十九、目前不建議新增的東西

〔紅線〕

1. **不要再加一個大型遺跡**：卷四已有兩儀雷淵，卷六有命藏／戰葬。
2. **不要新增一個專門服務卷四的大反派**：散修、商人、同路人、地方勢力足夠。
3. **不要提前主陰謀**：公主案、古戰真相不要污染少年期。
4. **不要把每個女天驕都變感情線。**
5. **不要讓每個小故事最後都有用。**有些酒就是難喝，有些東西就是買錯，有些人真的只見一次。
6. **不要讓第二雷取得等於自動熟練。**拿到後的試錯、亂用、組合才是《劫》的辨識度。
7. **不要為了篇幅硬塞事件。**正式章數依故事容量自然長。

# 二十、兩卷最終創作目標

## 《鎮岳老七》

不是「日常卷」，而是：

> **讓陸沉第一次真正知道修仙的人怎麼生活；讓讀者真正愛上太玄宗；讓很多未來最重要的關係與價值觀，在沒有巨大波瀾的日子裡長出根。**

它應是前期最重要的「情感資產卷」。

## 《兩儀雷淵》

不是「第二雷副本」，而是：

> **兩個少年第一次真正走出宗門，看見宗門外的修仙世界；一路有人同行、有人分岔，最後只剩彼此往下走。第二雷不是掉落物，而是這趟行路、判斷、犯錯、互信與生死冒險留下的東西。**

取得第二雷之後，故事仍要繼續：失控、試用、濫用、組合、承身、生活化。

如果兩卷都成功，讀者對前期《劫》的感受應該是：

> **我不只知道陸沉發生過什麼。**  
> **我真的覺得自己跟他們在太玄宗住過，也跟劫瘋一起走過那條路。**

# 二十一、交給後續寫手的簡短指令

> **卷三：不要急著推主線，但每件生活都要讓人物、修行、世界或未來至少有一項真正長大；讓讀者捨不得這群少年長大。**
>
> **卷四：不要從山門瞬移到雷淵。讓任務真的走過修仙世界；熱鬧一層層退去，最後只剩劫瘋。第二雷拿到後不要收卷，讓它先被用錯、玩壞、重新理解，再帶回生活。**
