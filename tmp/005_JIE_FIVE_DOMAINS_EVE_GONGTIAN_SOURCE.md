# 一、卷十一《五域前夜》正式升格

上一輪仍保留「最後一個月若故事量不足可併入五域大比」。本輪討論後改為：

> **《五域前夜》應獨立成卷。**

它不是等待開賽，而是：

> **天下同代第一次集中在同一區域；正式規則還沒把所有人關進擂台，但所有人其實已經開始比較。**

核心句：

> **未開戰，已經在比。**

# 二、這卷真正的快感：名字第一次變成真人

卷十一以前，五域人物可能透過宗門、古族、地方戰績、東溟百宗、中神州遊歷、共天紀錄、共天假名、榜單等方式被聽過。

但很多人從未見過真人。

因此這卷要做到：

> **散落在各域、榜單、傳聞與共天石壁上的名字，第一次開始有了臉。**

有些人成名多年；有些現實沒名、共天很有名；有些共天假名響亮但真人身分從未公開；有些到五域前夜才第一次冒出來。

# 三、東溟被看不起：整卷背景，不是一場打臉

不要只安排一個紈絝喊「東溟垃圾」再被陸沉打。

更自然的是不同人對東溟有刻板印象：
- 禁制體系較不完整；
- 宗門規模較小；
- 天驕較少；
- 雷修、體修偏粗；
- 沒見過真正的大世面。

其中某些甚至部分正確。

陸沉可以承認中神州某些東西確實更完整，但不接受「東溟沒有人值得看」。

# 四、東溟內部也不能突然一家親

百宗才剛打完。有人仍討厭太玄、有人不爽陸沉放棄第一、有人覺得「劫」被吹太高。

所以外域人看不起東溟時，可以出現：

> **最討厭陸沉的東溟天驕反而先站出來。**

不是喜歡陸沉，而是：

> 「我罵他可以，你算哪個？」

這比機械式一致對外更真。

# 五、雲行放卷十一正式出場

卷十已有文奕與古神禁典，雲行不宜同時搶焦點。

卷十一五域天驕匯聚時，雲行正式登場更自然。

其他人可能是古族少主、宗門聖子、共天紀錄者、劍仙傳人；雲行先讓讀者看到的是：**喝酒、好相處、很有趣，但一出手很強。**

不要初登場就講「無」的大道哲學；先讓讀者喜歡這個人。

# 六、最大賭石活動＝非正式第一場五域大比

五域前夜可有中神州極有名的大型賭石／古礦盛會。

紅線：不能變成「主角神眼看穿全部→賺爆→打臉」。

更好的功能是展示不同修行體系如何看同一塊石：
- 陸沉：線、禁、雷、結構；
- 文奕：古禁、封法、石皮人工痕跡；
- 古族：血脈感應；
- 魂修：殘念；
- 特殊天驕：聽石、觀氣；
- 甚至有人靠運氣。

因此它是：

> **五域天驕第一次沒有正式賽規的公開較量。**

# 七、劫 × 文的賭石較量

不要只比「誰挑的石頭最貴」。

可分三層：

1. **看石**：判裡面有沒有東西。
2. **判物**：不開石，先判性質。
3. **怎麼開**：一塊危險／難開古石。

陸沉：
> 「可以開。」

文奕：
> 「不能這樣開。」

最後不必硬判輸贏：

> **陸沉的方法能打開；文奕的方法能保住裡面的東西。**

兩人一起開反而更好。

它深化兩人的根本差異：
- 劫：能不能做到？
- 文：做了以後，原本的東西還剩多少？

# 八、沒有正式排名，卻一直在排名

卷十一可以比較：
- 現實名氣；
- 共天紀錄；
- 賭石；
- 丹；
- 破禁；
- 道場切磋；
- 試煉台；
- 誰拒絕誰的挑戰；

- 同代私下評價。

正式大比尚未開始，但人物關係、恩怨、欣賞與競爭已經成立。

# 九、傳聞與真人要有落差

「劫」在外界傳聞中可能冷酷、像災星；真人卻可能蹲在賭石攤問：

> 「這個能拆嗎？」

反過來，陸沉聽過多年的某天驕真人可能很矮、愛講話、很有禮貌，但出手完全不同。

目標是把設定卡變成人。

# 十、正式大比前必須已有前史

卷十二抽籤時，對手不應是陌生人 A。

可能是：
- 前一卷一起喝過酒的人；
- 賭石較量過的人；
- 看不起東溟的人；
- 共天交手過的人；
- 只知道共天假名的人；
- 文奕禁制圈認識的人；
- 雲行剛認識的人。

這樣抽籤本身就有戲。

# 十一、候選收尾

整卷一直有挑釁、賭石、論道、共天舊名、小切磋、榜單與真人掉馬。

最後一天反而不再打。

正式抽籤榜展開。所有人第一次被放進同一套正式規則。

封寒：
> 「誰？」

陸沉看著對手：
> **「熟人。」**

# 十三、共天現行運作

〔GitHub現行〕
- 每年開一次，一次一個月；
- 持引導信物，以神識進入；
- 肉身留在原界；
- 神識凝成可修行、交戰的形體；
- 九界修士可相遇、切磋、探索、約定來年再見；
- 開啟期間可自由退出、重新進入；
- 初學者需定時歸體休養；
- 宗門普遍持有信物但數量有限；
- 太玄閣可以安排弟子進入；
- 散修亦可從坊市或公開接引場所取得機會；
- 不是少數天驕專屬考試。

# 十四、形體、造化與風險

〔GitHub現行〕
- 形體以本體境界為基礎；
- 神識影響感知、控制、穩定；
- 陸沉神識強有優勢，但不會因此取得高境力量；
- 一般敗亡＝形體潰散、神識受傷、被迫退出；
- 少數險地能傷神魂本源，但事前有可辨徵兆；
- 共天有真實天地造化；
- 雷種等特殊事物完成煉化後可隨神識帶回肉身；
- 普通物品不能任意帶回。

# 十五、境界限制

〔GitHub現行〕共天大部分地域互通，不把整界切成境界層；但特定機緣地可以有境界限制。

已定例子「星羅雷山」（描述稱呼，正式地名未定）：
- 外山不限境界；
- 內山只容搬血、洞天。

陸沉在此取得第一雷星羅銀雷。

# 十六、第一雷與共天

〔GitHub現行〕陸沉不是被閣老指定送去取雷。

他進共天後向修士打聽雷山，主動前往；第一次追最明亮猛烈的雷流而誤入洩雷口，脫險後重新觀察，循細弱持續銀雷找到星羅，完成熔煉後帶回肉身。

# 十七、作者補充：共天「第一留名」玩法

〔作者補充；待回填 repo〕

共天除了探索、切磋、造化，還有重要的少年天驕文化：

> **只要在某項挑戰／紀錄達成「第一」，就能留下文字，以及自己選擇留下的名稱。**

名稱可以是真名、道號、假名，甚至無名。

核心：

> **紀錄是真的，名字未必是真的。**

共天不替修士公開或驗證現實身分。

# 十八、留字不是現代排行榜

不要只寫「第一名 XXX、時間 00:32:16」。

更有仙感的是：

> **「第三步別回頭。」——折枝**

幾百年後沒人知道折枝是誰，但後來的少年都會看到。

因此共天逐漸像：

> **九界修士共同寫出來的一本書。**

# 十九、什麼可以成為「第一」

〔候選〕不只戰力：
- 同境登山最快；
- 雷域停留最久；
- 劍碑最少出劍數；
- 禁路首破；
- 幻境最短；
- 試煉最深；
- 承受紀錄；
- 第一個找到真正出口；
- 第一個完成特殊條件；
- 第一個用非常規方法通過。

這讓不同類型天驕都能留名。

# 二十、假名＝卷十一的真人掉馬系統

因為可用假名：

> **大家可能認識一個名字很多年，卻第一次知道那張臉是誰。**

有人現實只是小宗弟子，共天假名卻極有名；有人現實是聖子，共天戰績反而普通；有人兩邊都強；有人從不公開共天身份。

這讓卷十一的真人見面天然有戲。

# 二十一、三層名聲系統

可形成：

| 身分 | 名聲來源 |
|---|---|
| 現實真名 | 宗門、家族、現實戰績 |
| 共天名稱 | 共天探索、紀錄、交手、留字 |
| 後來稱號 | 真正重大事件後世界給他的名字 |

陸沉尤其適合：
- **陸沉**：現實中的人；
- **某個共天假名**：少年共天身份（待定，不宜現在亂取）；
- **劫**：百宗封舊戰痕後世界開始傳開的稱號。

所以卷十一可以同時出現：
- 認識「陸沉」的人；
- 只聽過「劫」的人；
- 不知道陸沉與劫，卻認識他共天假名的人。

# 二十二、不要讓陸沉早期包辦共天第一

〔紅線〕

十歲進共天後不能所有榜都第一。

第一雷星羅本身就是重要造化，不需要再附贈全榜第一。

後續若安排陸沉留名，更適合偏門、符合人物的紀錄，例如某雷區同境停留、某特殊解法等，而不是「最強攻擊第一」一路包辦。

如此共天才能真正屬於九界所有少年，不是主角個人排行榜。

# 二十三、封寒與文奕的共天玩法

〔候選〕

封寒可以在劍碑／出劍數／特殊劍道挑戰留下假名紀錄；真人出手後，有人不是靠臉而是靠「那一劍」認出他。

文奕則可在禁制紀錄上早有痕跡。陸沉與文奕現實相識後，可能很晚才發現彼此曾看過對方共天留字。

不要急著全部揭露；有些假名可以直到五域大比甚至更後面才對上。

# 二十四、雲行與共天

〔候選〕

雲行也可有共天痕跡，但不必為了四人組整齊而強行每人一個馬甲。

若使用，應符合他：
- 留字很隨意；
- 紀錄很強；
- 本人不太在乎；
- 真人被問時甚至懶得解釋。

重點仍是先讓雲行作為「人」在卷十一成立。

# 二十五、共天應提前幾卷埋，但不能過量

〔強建議〕

不要回頭硬塞「陸沉每年都在共天認識未來所有天驕」。

比較自然：

1. 太玄閣：星羅雷山是第一次重大共天故事。
2. 太玄宗少年期：偶爾進共天；有少數小故事、聽過少數名字、可能交手兩三人。
3. 東溟期：開始知道某些共天名字可能來自哪一域。
4. 中神州／五域前夜：大量真人第一次對上。

這樣卷十一的 payoff 是幾百章累積，而不是臨時設定。
