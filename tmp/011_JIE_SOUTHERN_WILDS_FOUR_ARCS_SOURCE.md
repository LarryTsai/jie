# 《劫》南荒長篇四大故事 Source

> 狀態：2026-10-04 討論整合稿／南荒最新長篇方向。  
> 承接：四大書院、天域五卷、地獄行第三雷、主線反派埋線。
>
> **最高紅線：南荒不能寫成救援工程、水利工程、醫療隊、修陣隊披著仙俠皮。**
>
> 南荒是陸沉進入天域書院時代後第一次大型跨域「出差」。四院、南荒本地勢力、皇族王族、古族妖族、普通惡徒、臥底、反叛者與未知跨域高階勢力會逐步交錯。

# 一、核心起點：南荒不求援，南荒想隱瞞

南荒最早看到的不是災難，而是**天地把消失的東西重新還給南荒**：

- 絕種仙藥重新開花；
- 古靈獸重新出生；
- 消失古林重新出現；
- 古道場顯形；
- 古疆長回現世；
- 斷掉的生命／血脈重新出現；
- 古代天地異象再次運轉。

南荒第一反應：

> **「南荒要變強了。」**

如果公開，東院會看古法、西院會研究仙藥古禁、北院會介入古疆皇族秩序，其他四域、商盟與散修也會湧入。

因此部分南荒皇族、王族、大宗、古族可能形成共識：

> **先封消息，先吃下第一波機緣，再決定告訴天域多少。**

這不是純邪惡。南荒的合理問題是：

> **「這是我們土地長回來的東西，憑什麼一出現就要分給天下？」**

# 二、天域如何發現

南荒上報可能只寫：

> 「本年度藥潮提前，南荒自行可控。」

但外部資料逐漸對不上：

- 西院發現南荒藥價突然大跌；
- 北院收到妖獸異常遷徙情報；
- 東院在天域拍賣會看到八千年前已絕種的靈植。

天域要求補報，南荒仍稱一切正常。

四院第一批人馬因此前往，名義上是交流／查驗／確認是否具有跨域風險，實際上是：

> **查南荒到底藏了什麼。**

# 三、四院是出差，不是救世主

| 院 | 主要關注 |
|---|---|
| 東院 | 是否是古法、大道、天地規則層級恢復 |
| 西院 | 古藥、古禁、古器、靈獸、地脈與百藝價值 |
| 北院 | 古疆、皇族王族、封地與五域秩序是否被改寫 |
| 南院 | 處理無法分類的異常，且內部立場最不統一 |

陸沉只是南院派出的成員之一，不是救援總指揮。

四院也不同心：

- **東院**看似超然，但古經仙法回歸時未必無欲。
- **西院**嘴上研究，背後連著丹器商會與龐大利益，南荒可能最防他們。
- **北院**最強硬：「若可能影響五域，南荒就沒有完全隱瞞的權利。」
- **南院**沒有統一答案；有人支持南荒自主，有人認為跨域風險不能隱瞞。

# 四、真正異變：消失的東西正在回來

「生機過盛」只是表象。真正異變是天地似乎在**重新長回古代某個狀態**。

可回來的包括古藥、古妖／古靈獸、古林、古疆、古道場，以及古代天地異象，例如山自行渡劫、河倒流上天、花海返老、霧中出現非現世生命。

核心不是「東西回來了」，而是：

> **回來的東西開始要求自己的位置。**

古林會繼續恢復八萬年前疆界，現代城池擋在前面，它也照樣長。

一個滅絕數萬年的妖族重新出生，發現祖地已被另一族生活萬年。

古族：
> 「出去。」

現代族群：
> 「我們已經住一萬年。」

兩邊都不必是邪惡，但一定可能開戰。

真正問題：

> **消失的東西回來後，現在活著的人要去哪裡？**

# 五、南荒本地勢力必須很強

南荒有自己的皇族、王族、大宗、古族、妖族、丹道勢力、城邦、散修、商盟，以及俞清漪的地方關係。

有人想繼續復甦，有人想停止，有人想據為己有，有人認為祖先回來了，有人認為天域只想搶。

四院不一定被歡迎，甚至可能被要求離開。

# 六、南荒同時存在五種敵人

1. **南荒既得利益者**：想封鎖消息，把復甦紅利留在南荒；不一定壞。
2. **真正異變後的敵人**：古妖、古生靈、古疆、古林開始與現世爭位置。
3. **普通惡徒**：搶藥、抽古妖血、活人試藥、屠新生族群；這些可以直接打。
4. **臥底／反叛者**：四院或天域內部有人帶隱藏任務，也有人後來才改變立場。
5. **未知跨域高階行動者（工作稱「曉級」）**：真正主線第一次公開站台。

再加上：

> **四院彼此也不同心。**

# 七、南荒由四個大故事接連構成

| 大故事 | 核心問題 |
|---|---|
| **Ⅰ《南荒藏天》**（暫） | 南荒藏了什麼？機緣還是災難？ |
| **Ⅱ《萬物歸來》**（暫） | 回來的生命與疆域如何跟現在共存？ |
| **Ⅲ《無名之敵／千相》**（暫） | 那群誰都不認識的強者是誰？第四雷於此出現 |
| **Ⅳ《皇血之亂》**（暫） | 皇族、古王血、臥底、反叛與未知勢力目的開始交叉 |

每個大故事可約 2～3 卷，整個南荒篇約 8～10 卷都有可能，目前不鎖死。

# 八、第一大故事《南荒藏天》

**起**：天域發現資料異常，四院進南荒。  
**承**：四院看到南荒真的正在變強；讀者甚至理解南荒為何不想分享。  
**轉**：古林、古疆、古生不再只是出現，而是持續擴張、要求位置。  
**合**：四院確認不是普通藥潮；某個本應存在的重要古物／節點卻已被人提前取走，留下無人認得的手法。

第一幕結束第一次產生：

> **「還有別人在這裡。」**

# 九、第二大故事《萬物歸來》

古林侵入現代城池；古族重新出生；古疆重疊現代封地。

四院第一次真正立場分裂：
- 北院先定秩序；
- 東院先理解古道；
- 西院不願直接毀掉無價古物；
- 南院沒有統一立場。

真正惡徒開始大量出現：
- 抽古妖血返祖；
- 活人試古藥；
- 搶古疆；
- 屠剛回歸的小族群；
- 人為加速異變獲利。

這類人不必每次哲學辯論，故事需要讓陸沉等人真正開打。

# 十、第三大故事：第一個「曉級人物」正式站台

「曉級」只是工作稱呼，不是正式組織名，代表跨域、高階、主線級、身份未知的行動者。

第一次出現必須讓所有人都問：

> **「他是誰？」**

要求：
- 南荒不認識；
- 北院／皇族名冊沒有；
- 東院認不出傳承；
- 西院認不出術式；
- 甚至不知道「劫」是誰。

候選：

有人：
> 「他是劫。」

對方：
> **「誰？」**

這能瞬間把陸沉從五域知名天驕放回巨大世界。

## 第一次一定要真的打

不能神秘人出現一招就走。

要讓四院第一次真正聯手：
- 東院成熟正統仙術；
- 西院禁陣、法器與百藝；
- 北院皇道、軍陣、統御；
- 南院各種無法預測的怪招。

結果仍然沒留下對方。

最好是：

> **對方完成自己的目的後自行離開。**

所有人共同反應：

> 「那到底是哪來的人？」

这才是主線反派世界第一次真正站到台前。

# 十一、未知勢力不能圍著主角寶物轉

第三大故事中陸沉開始追第四雷千相。

但曉級人物：

> **不是來搶千相。**

他們找的是另一樣大家甚至不知道用途的東西。

陸沉只是因為追千相：

> **意外撞見他們真正的行動。**

如此雷線與主線第一次真正交叉，而不是所有敵人都為主角寶物而來。

# 十二、真正大藥潮與第四雷・千相

前兩大故事成立後，真正大藥潮才來。

潮霧裡：
- 萬物暴長；
- 古生與今生交錯；
- 神魂殘響；
- 紫雷穿過無數藥性、生靈與古今痕跡；
- 每個人看到的雷都可能不同。

陸沉第一次判錯。

他想起第一雷星羅教他的：

> 「別追最亮。」

於是改追最暗。

结果：

> **仍然錯。**

第四雷真正教他的不是「亮是假、暗是真」。

而是：

> **把過去成功經驗變成固定規則，本身就是另一種盲信。**

因此第四雷的人生題仍是：

> **看錯。**

# 十三、千相必須放在南荒中點，不是篇末獎品

這是本版的重要新決定。

拿到千相後：

> **南荒故事不是結束，而是第一次真正變大。**

千相讓陸沉更敏銳地看出：

「南荒異變」其實不是單一來源，而是多種「相」疊在一起：

- 自然復甦；
- 下方沉降重新流動；
- 人為加速；
- 古戰殘留；
- 未知跨域勢力干預。

所以：

> **取得第四雷＝南荒後半開門。**

不是「Boss 打完領獎」。

# 十四、第四大故事《皇血之亂》

古疆恢復後，可能帶回早已滅亡的古王血／古皇族合法性。

問題：

> 現代南荒皇族已經統治數萬年。

古王血回來後：

> **古代合法性與現代秩序正面碰撞。**

因此北院、南荒皇族、天域皇族、王族、俞清漪與地方勢力自然被拉進中心。

皇族線不是為了硬加政治戲，而是：

> **天地異變本身逼政治出現。**

甚至天域某皇族可能與南荒古王朝存在血脈／歷史關係。

# 十五、臥底在南荒第一次真正「工作」

天域五卷埋下的學長姐／前輩／師長臥底，到南荒才真正收到重要任務。

他可以一直：
- 幫陸沉；
- 救人；
- 查異變；
- 甚至真的跟曉級人物打得很兇。

所以所有人都認為：

> **他不可能是那邊的人。**

但他的任務與公開出手的曉級人物未必一致；同一勢力不同成員也不必知道彼此完整任務。

某個關鍵封鎖：

> 只有四院內部知道。

卻仍然被打開。

這時才第一次真正出現：

> **「我們裡面有人。」**

不必立刻揭身份。

# 十六、反叛者不要等於臥底

**臥底**：從一開始就有隱藏任務。

**反叛者**：原本真的忠於四院／天域，但在南荒生活、看見事情後改變立場。

例如北院命令封鎖／清空某片古疆。

某人拒絕：

> 「不。」

「你知道這是拒令嗎？」

> 「知道。」

讀者甚至可能支持他。

其他人一開始可能以為：

> 他就是內鬼。

後來才知道：

> **不是。他只是改變了。**

這能把「臥底」與「理念反叛」分開。

# 十七、真正壞人必須存在

不要讓全篇都是灰色倫理。

可有南荒王族／宗門／商會中的真正惡徒：
- 抓古妖幼崽抽血返祖；
- 活人試古藥；
- 屠新生族群搶祖地；
- 故意加速異變賺取利益；
- 操縱古王血做權力工具。

這些人：

> **不用辯，打。**

讓南荒同時有複雜灰色衝突，也有真正能爽快開戰的敵人。

# 十八、四院四條視角線

南荒篇不能永遠只跟陸沉。

## 東院組｜封寒、生等
古法、古生命、正統仙道如何理解「回來的生」。

生可以處理「重新出生到底是不是同一種生命」等問題。

封寒會追問：

> 「它到底算活著，還是只是天地記得它？」

## 西院組｜文奕等
古禁、古丹、古器、靈獸、技術與利益。

西院可能最早發現：

> **某些東西已經被人提前拿走。**

## 北院組｜皇道天驕等
皇族王族、古疆、封地、談判、軍陣與秩序。

很多問題：

> **他們會比陸沉處理得更好。**

## 南院組｜劫、雲等
被派往最難分類的異常區。

立場最自由，也最容易跑進沒人知道怎麼處理的地方。

四條線各自看到南荒的一部分，最後交叉。

# 十九、陸沉不能每次都是唯一解題者

必须安排：
- 某個生命問題由生解；
- 某個古禁由文奕先發現；
- 某個皇族衝突由北院天驕處理得比劫漂亮；
- 某次魂／執念事件由雲行成為關鍵；
- 某場硬戰由封寒扛掉。

陸沉只是其中一個很重要的人。

直到千相真正出現：

> 雷線才自然把他推到中心。

# 二十、敵我關係必須一直變

南荒可依序讓讀者感受到：

1. **南荒 vs 四院**：你們憑什麼來查？
2. **今人 vs 古生**：誰有權住在這裡？
3. **大家 vs 真正惡徒**：有人趁亂害人。
4. **無名強者 vs 所有人**：這群人到底是誰？
5. **四院內部互疑**：情報為什麼一直外洩？
6. **真正反叛**：有人不是臥底，但選擇拒絕天域。
7. **皇族／古王血衝突**：古代合法性與現代秩序正面碰撞。

因此故事不能變成「找到 Boss → 打 Boss」。

# 二十一、曉級人物的出場節奏

不要一次全員登場。

南荒只需先正式出現一人，後面再出第二人。

兩人甚至不要看起來像同一組織。

直到某個很小的共同特徵：
- 同一稱呼；
- 同一個印；
- 同一個動作；
- 同一種辨認古物的方法；

讀者才開始懷疑：

> **「等等，他們是一邊的？」**

正式組織名、全貌與真正目的都不要急著揭。

# 二十二、南荒四大故事的升級問題

第一大故事问：

> **世界出了什麼事？**

第二大故事问：

> **回來的東西與現在的人怎麼共存？**

第三大故事问：

> **那些人到底是誰、又在找什麼？**

第四大故事问：

> **我們自己裡面又有誰？誰有資格決定南荒的未來？**

這樣外部未知 → 異變衝突 → 主線敵人 → 內部裂痕，複雜度逐步升高。

> **8～10卷。**

但不是為了湊長度，而是每一幕故事類型真的不同。

# 二十四、南荒核心句

第一層：

> **生得太多。**

第二層：

> **消失的東西，正在回來。**

真正核心：

> **它們回來以後，現在活著的人要去哪裡？**

而陸沉的問題逐漸從：

> 「這東西怎麼修？」

變成：

> **「誰有資格決定什麼叫修好？」**

# 二十五、與《劫》大主線的功能

南荒是全書第一次：

> **古老主線問題真正大規模影響現在活著的人。**

前面主線多是：
- 古史；
- 痕跡；
- 共天；
- 戰葬；
- 地獄；
- 外圍人物；
- 臥底。

南荒開始：
- 未知高階勢力公開出手；
- 四院真正與其交戰；
- 臥底開始工作；
- 普通反派利用主線異變；
- 皇族政治被捲入；
- 反叛者因現實選擇改變立場；
- 第四雷與主線第一次直接交叉。

但仍然不能在南荒揭完仙帝長子、異域公主與終極真相。

南荒要做到的是：

> **讓所有人第一次知道：世界上真的存在一群我們完全不認識、卻早就在處理這些東西的人。**

# 二十六、Continuity 紅線

1. 南荒最初想隱瞞復甦，不是主動求救。
2. 南荒隱瞞有合理利益與地域立場，不可扁平成自私反派。

# 二十七、一句話總綱

> **地獄行後的天地沉降重新流動，使南荒首先出現「古代之生重新回來」的現象。南荒皇族、王族與大宗最早看到的是仙藥、古獸、古道場與古疆帶來的崛起機會，因此刻意向天域淡化甚至隱瞞異變；天域從藥價、妖獸遷徙與絕種靈植等外部跡象發現資料不對，四院各帶不同目的前往查驗。四院很快發現南荒不是單純生機過盛，而是天地正在重新長回古代：古林開始奪回八萬年前疆界，滅絕古族重新出生並要求祖地，現代居民與古生都沒有天然錯誤。就在南荒、四院與古生彼此拉扯時，真正惡徒開始利用復甦牟利，而一名誰都查不到來歷的高階人物突然出手，四院聯手仍留不住他；更詭異的是，他根本不是為第四雷而來。真正大藥潮隨後爆發，陸沉在萬道紫雷中連續看錯，最終取得第四雷千相；但千相不是終點，而讓他第一次看見南荒異變其實由自然復甦、下方沉降、人為加速、古戰殘留與未知勢力干預多種『相』疊成。南荒後半因此進入皇血與古疆之爭：古王血重新出現，現代皇族合法性被撼動，四院內部情報外洩，臥底真正開始工作，又有人並非臥底卻因認同南荒而公開反叛。南荒最終不再問『怎麼把世界修回去』，而是逼所有人回答：消失的東西回來以後，現在活著的人要去哪裡；而有能力改變世界的人，又憑什麼替所有人決定什麼叫做修好？**
